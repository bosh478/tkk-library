# 招投标黑幕大揭秘：陪标、串标、围标、控标、挤标五大违规操作

> 来源：广联达新干线（fwxgx.com）  
> 作者：造价狮老康  
> 原文：https://www.fwxgx.com/articles/248198

招投标的初衷是让企业公平竞争，选出最合适的供应商或承包人。但现实中，不少项目从一开始就偏离了正轨，出现各种违规操作。

行业内有一些约定俗成的叫法——陪标、串标、围标、控标、挤标。它们分别是什么意思？有什么法律后果？以及如何进行维权？本文将在下文予以说明。

---

## 一、几大概念必须知道

### 1. 陪标

就是陪别人投标。投标人明知自己不会中标，仍然按照约定参与投标，目的是凑够法定数量，让程序看起来合规。

**实际操作中，陪标方的报价要么明显偏高，要么明显偏低，或者技术方案存在明显缺陷，确保不会意外中标。陪标方事后通常会拿到一定补偿。**

### 2. 串标

即串通投标，串标的核心特征是信息互通、利益交换。主要分为两种情况：

- **投标人之间串通**：几家公司事先商量好谁中标、谁陪标、谁弃标，统一报价策略。
- **投标人与招标人串通**：招标人提前泄露标底、评标委员会名单，或者为特定投标人修改招标文件。

### 3. 围标

可以理解为多家公司联手围堵。几家投标人结成临时或固定联盟，把外部竞争者挡在门外，内部分配中标机会——这次你中，下次我中，轮流受益。围标往往伴随着陪标和串标，是一种有组织的排外行为。

### 4. 控标

即控制招标结果。通常是招标方利用编制招标文件的权力，在资质、技术参数、业绩要求等方面设置具有指向性的条件，使得只有某一家公司能够完全满足，从而确保其中标。控标不一定都违法，但如果条件明显不合理、排他性过强，就属于违规操作。

### 5. 挤标

是指通过各种手段把竞争对手排挤出局。常见方式包括：

- **恶意低价竞标**：把价格压到成本线以下，让正常企业不敢跟。
- **虚假投诉/恶意举报**：拖垮竞争对手的投标资格。

**挤标的目的是**：我中不了，你也别想中；或者把对手挤掉，让我或我的人中。

## 二、三类主体的典型违规手法

### 招标人的常见做法

1. **泄露信息**：泄露其他投标人的情况、标底、评标委员会名单等。
2. **量身定制**：在招标文件中设置明显倾向性条款；截标后允许特定投标人补充或更改报价。
3. **提前内定**：招标前已确定中标人，然后组织其他单位配合；或者拆解标段，让内定者各占一块。
4. **授意暗示**：暗示评标委员会倾向性打分，或让招标代理机构区别对待。
5. **低价陷阱**：以远低于成本的价格中标，项目实施过程中通过变更设计、增加工程量等方式提高结算价。
6. **装傻不管**：发现一人代签多家投标文件、不同投标人资料混装等明显违规情形，却不制止，继续评审。
7. **拒签合同**：无正当理由拒绝与中标候选人签订合同。

### 投标人的常见做法

1. **事先约定**：投标人之间约定谁中标、谁陪标、谁弃标，统一报价策略，给未中标方补偿。
2. **容易露出的马脚**：
   - 不同投标人的总报价异常一致，或呈现规律性差异
   - 分项报价不合理，且解释不通
   - 故意制作无效投标文件，主动废标
   - 一年内多次报名购买招标文件，但不递交投标文件、不参加开标
   - 多家投标人几乎同时撤回投标文件
   - 不同投标人的保证金由同一账户缴纳，或使用同一人出具的保函
   - 售后服务条款雷同，或法定代表人签字出自同一人
3. **文件雷同严重**：
   - 投标文件格式、字体、颜色、错误内容高度一致
   - 电子投标IP地址相同，或文件由同一台电脑编制、同一台设备打印
   - 一家投标人的文件中出现另一家投标人的公章、签名
   - 装订形式、厚薄、封面等外观特征相似甚至相同
4. **行为反常**：
   - 投标人代表说不清本公司法定代表人的联系方式
   - 签字时手抖，签名与名片不一致
   - 开标前同车前往、有说有笑，开标现场却装作互不相识

### 评审专家的常见做法

1. **不作为**：发现投标文件不符合招标文件规定、报价明显不合理、技术部分明显缺漏，却不指出、不处理。
2. **区别对待**：明知与投标人有利害关系而不回避；暗标中发现有人做特殊记号也不报告；打分时无合理理由给某家打高分，给其他家打低分，或者不按招标文件规定的评分标准打分。
