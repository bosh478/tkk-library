# references 索引

本目录包含 `tkk-legal-ingest` skill 的详细操作文档，被主文件 SKILL.md 引用。

## 文件说明

| 文件 | 内容 |
|------|------|
| `ingest-workflow.md` | ingest（消化新资料）五阶段详细流程 |
| `query-workflow.md` | query（基于 wiki 回答）详细流程 |
| `purge-workflow.md` | purge（删除 wiki 页面）详细流程 |
| `lint-workflow.md` | lint（健康检查）详细流程 |
| `command-ref.md` | 常用命令速查参考 |
| `templates.md` | 各类输出模板库 |
| `VERSION-full.md` | 完整版本历史 |

## 使用方式

当需要查看某个操作的详细内容时，引用对应的 references 文件：

```markdown
详细流程见 [[references/ingest-workflow.md]]
```
