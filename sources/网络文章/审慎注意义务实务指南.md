# 非法集资案件两罪区分实务指南——以"非法占有目的"认定为核心

## 引言

在非法集资类犯罪案件中，**非法吸收公众存款罪与集资诈骗罪的区分**是司法实践的核心难题。两罪的根本区别在于行为人是否具有"非法占有目的"，而**审慎注意义务的违反**是判断这一目的的重要依据。

本文以实务为导向，通过典型案例、裁判规则、辩护要点，为法官、检察官、律师提供可操作的办案指引。

---

## 一、两罪法定刑对比——为什么区分如此重要

| 对比维度 | 非法吸收公众存款罪（第176条） | 集资诈骗罪（第192条） |
|----------|---------------------------|---------------------|
| 核心要件 | 非法吸收/变相吸收公众存款 | 以非法占有为目的 + 使用诈骗方法 |
| 主观方面 | 故意，**不要求**非法占有目的 | 故意 + **必须有**非法占有目的 |
| 第一档 | 3年以下有期徒刑或拘役 | 3-7年有期徒刑 |
| 第二档 | 3-10年有期徒刑 | 7年以上有期徒刑或无期徒刑 |
| 第三档 | **10年以上有期徒刑** | 无 |
| **最高刑期** | **15年有期徒刑** | **无期徒刑** |

**实务意义**：同一集资行为，定性不同，量刑可能相差数年甚至十余年。辩护人的核心工作之一就是争取将"集资诈骗罪"辩护为"非法吸收公众存款罪"。

---

## 二、"非法占有目的"的司法认定——七种法定情形

根据《最高人民法院关于审理非法集资刑事案件具体应用法律若干问题的解释》（法释〔2022〕5号）第7条，以下情形可以认定"非法占有目的"：

### 情形一：集资后不用于生产经营或比例明显不成比例

**裁判规则**：
- 集资款进入个人账户后，未投入任何经营项目
- 虽有经营项目，但投入资金与集资总额严重不匹配（如集资1亿，经营投入仅100万）
- 经营项目明显是虚假的或无法产生收益的

### 情形二：肆意挥霍集资款

**裁判规则**：
- "挥霍"指任意花钱、奢侈消费，无节制地使用资金
- 典型表现：购买豪宅、豪车、奢侈品，高档消费，赌博等
- 关键：**致使集资款不能返还**

### 情形三：携带集资款逃匿

**裁判规则**：
- 携带资金逃匿是非法占有目的的直接证据
- "逃匿"包括潜逃、藏匿、更换联系方式等
- 无需证明资金全部被带走

### 情形四：将集资款用于违法犯罪活动

**裁判规则**：
- 将资金用于赌博、吸毒、贩毒等违法犯罪活动
- 将资金用于行贿等犯罪活动
- 用于非法经营等行政违法行为

### 情形五：抽逃、转移资金、隐匿财产

**裁判规则**：
- 抽逃资金：将已投入经营的资金抽回
- 转移资金：将资金转移到他人账户或境外
- 隐匿财产：隐藏资产，逃避追缴

### 情形六：隐匿、销毁账目或搞假破产、假倒闭

**裁判规则**：
- 隐匿账目：故意不记录或隐藏资金流向
- 销毁账目：故意销毁财务凭证
- 假破产、假倒闭：虚构经营困难，逃避返还

### 情形七：拒不交代资金去向

**裁判规则**：
- "拒不交代"指拒绝说明或虚假说明资金去向
- 关键是"逃避返还资金"的意图
- 需与其他证据结合判断

## 三、典型案例裁判要旨

### 案例一：张业强等私募基金非法吸收公众存款案（检例第175号）

**案件信息**：
- 案号：检例第175号
- 审理机关：最高人民检察院
- 发布日期：2023年6月13日

**裁判要旨**：
私募基金管理人不得违反私募基金管理规定变相募集资金，不得通过拼接、拆分单一私募基金产品变相突破合格投资者人数限制。

**基本案情**：
被告人张业强，男，国盈资产管理有限公司、国盈投资基金管理（北京）有限公司等7家国盈系公司实际控制人。2012年7月至2018年间，张业强、白中杰相继成立国盈系公司，在中基协先后取得私募基金管理人资格后，以私募基金名义向社会公众募集资金。

**裁判规则**：
1. **私募基金登记备案的性质**：不构成对私募基金管理人投资能力、持续合规情况的认可
2. **非法性认定**：虽按规定进行了登记、基金亦进行了备案，但集资行为违背私募基金非公开募集、收益不固定及投资者特定化等特性
3. **非法占有目的的判断**：综合考察私募基金运行全过程

### 案例二：某基金公司、闫某某等非法吸收公众存款案（2025年度刑事案例）

**案件信息**：
- 裁判书字号：河北省廊坊市中级人民法院（2023）冀10刑终119号刑事裁定书
- 案由：非法吸收公众存款罪
- 涉案金额：23.1亿元
- 判决结果：基金公司罚金30万元；闫某某有期徒刑8年，罚金10万元

**裁判要旨**：
私募基金管理人违反私募基金投资规定，以私募基金投资名义通过公开宣传的方式向不特定社会公众吸收资金，并承诺返还本息，构成非法吸收公众存款罪。

**裁判理由**：
1. **私募基金非法吸收公众存款的认定**：
   - **非法性**：集资行为违背私募基金非公开募集、收益不固定及投资者特定化等特性
   - **公开性**：通过公开宣传吸引了大量不特定社会公众参与投资
   - **利诱性**：向投资人承诺固定年收益
   - **社会性**：向社会不特定人群吸收资金

2. **非法吸收公众存款罪与集资诈骗罪的区分**：
   - **本质区别**：行为人的主观上是否具有非法占有目的
   - **本案定性**：被告单位吸收集资参与人投资后，确有正常投资和经营活动，对集资参与人也有还本付息行为，并非以非法占有为目的

3. **注销登记后的行为定性**：
   - 被注销私募基金管理人资质后继续非法集资的行为，应当认定为非法吸收公众存款行为的延续
   - 不能据此认定集资诈骗罪

## 四、审慎注意义务的违反——推定非法占有目的的关键因素

### （一）审慎注意义务的具体内容

在非法集资案件中，行为人对投资人资金负有以下义务：

| 义务类型 | 具体内容 | 违反表现 |
|----------|----------|----------|
| **资金保管义务** | 资金存入专用账户，不得混同、挪用 | 混同于个人资金、私自转移 |
| **资金使用义务** | 按约定用途使用，不得擅自改变 | 挪作他用、改变用途 |
| **投资审慎义务** | 投入约定的、风险可控的项目 | 高风险投机、明显不合理投资 |
| **风险披露义务** | 向投资人披露真实状况和风险 | 隐瞒、欺骗 |
| **风险控制义务** | 建立风控体系，控制投资风险 | 无风控、风控失效 |
| **信息报告义务** | 定期报告资金状况 | 不报告、虚假报告 |

### （二）违反审慎义务推定非法占有目的的裁判规则

**规则一：挥霍型违反——推定强度强**

> **案例**：某公司负责人吸收资金2000万元，其中800万元用于购买奢侈品、高档消费，1200万元投入期货交易亏损。法院认定：挥霍行为直接表明无返还意愿，推定非法占有目的成立。

**规则二：高风险投资型违反——推定强度中等**

> **案例**：某公司负责人吸收资金5000万元，全部投入虚拟货币交易，最终亏损3000万元。法院认定：虽然投资有风险，但将全部集资款投入高风险领域，且无任何风控措施，表明放任资金损失，推定非法占有目的成立。

**规则三：经营失败型违反——通常不推定**

> **案例**：某公司负责人吸收资金1亿元，投入实体经营，因市场环境变化导致经营失败，亏损6000万元。法院认定：资金确实用于经营，经营失败是商业风险，不具有非法占有目的，以非法吸收公众存款罪定罪。

**规则四：保管不善型违反——需结合主观状态判断**

> **案例**：某公司负责人吸收资金3000万元，因管理不善导致资金链断裂，亏损1500万元。法院认定：保管不善是过失，但行为人在资金链断裂后携款逃匿，表明具有非法占有目的。

### （三）"挥霍"与"投资失败"的实务界定标准

| 判断维度 | 挥霍 | 投资失败 |
|----------|------|----------|
| **资金用途** | 个人消费、奢侈消费 | 经营投入、投资投入 |
| **主观认知** | 明知不可能返还 | 相信可能盈利 |
| **客观行为** | 无对价消费 | 有对价投入 |
| **风险程度** | 超出正常范围 | 在正常范围 |
| **返还意愿** | 无返还意愿 | 有返还意愿 |
| **事后态度** | 消极逃避 | 积极弥补 |

## 五、辩护要点与法院态度

### 辩护要点一：资金用于正当经营

**辩护策略**：
1. 提供资金流向证明，证明集资款投入了具体经营项目
2. 提供经营合同、发票、银行流水等证据
3. 提供经营成果证明（如项目完工、产品销售等）

**法院态度**：
- 如果资金确实投入经营，且经营是真实的，通常不认定非法占有目的
- 但经营投入与集资规模严重不成比例的除外

**典型案例支撑**：廊坊国某股权投资基金案——私募基金管理人将资金用于正常经营，有还本付息行为，认定不具有非法占有目的。

### 辩护要点二：有还款意愿和能力

**辩护策略**：
1. 提供还款计划、还款记录
2. 提供资产证明（房产、车辆、存款等）
3. 提供担保、抵押等增信措施
4. 证明案发后积极筹措资金返还

**法院态度**：
- 有还款意愿和能力的，通常不认定非法占有目的
- 但还款意愿需要有实际行动证明

### 辩护要点三：投资失败非挥霍

**辩护策略**：
1. 区分"投资"与"挥霍"：证明资金有对价投入
2. 证明投资行为是正常的商业决策
3. 证明投资失败是客观原因（市场变化、政策调整等）
4. 证明有风控措施

**法院态度**：
- 投资失败是商业风险，通常不认定非法占有目的
- 但全部投入高风险领域且无风控的除外

**典型案例支撑**：某公司吸收资金1亿元投入实体经营，因市场环境变化导致亏损6000万元，法院认定不具有非法占有目的。

### 辩护要点四：无非法占有目的

**辩护策略**：
1. 综合证明无挥霍、无逃匿、无隐匿财产等行为
2. 证明有实际经营行为
3. 证明经营失败是客观原因
4. 证明有还款意愿和能力

**法院态度**：
- 需要综合全案证据判断
- 存疑时有利于被告人

### 辩护要点五：私募基金特殊规定

**辩护策略**：
1. 证明已完成私募基金管理人登记
2. 证明基金已完成备案
3. 证明遵守了私募基金的相关规定（虽然最终被认定违规）
4. 证明资金主要用于合同约定的投资方向

**法院态度**：
- 私募基金管理人登记和基金备案不构成对合规性的认可
- 但可以作为证明无非法占有目的的参考因素

## 六、证据审查指引

### （一）控方需要收集的关键证据

| 证据类型 | 具体内容 | 证明目的 |
|----------|----------|----------|
| **资金流向** | 银行流水、转账记录 | 证明资金去向 |
| **消费记录** | 购房、购车、奢侈品消费记录 | 证明挥霍行为 |
| **经营证据** | 经营合同、发票、项目资料 | 证明是否有实际经营 |
| **主观证据** | 被告人供述、证人证言 | 证明主观目的 |
| **事后表现** | 还款记录、逃匿记录 | 证明事后态度 |
| **私募基金材料** | 基金管理人登记证书、基金备案证明、投资合同 | 证明私募基金性质 |

### （二）辩方需要收集的关键证据

| 证据类型 | 具体内容 | 证明目的 |
|----------|----------|----------|
| **经营证据** | 经营合同、发票、银行流水 | 证明资金用于经营 |
| **还款证据** | 还款计划、还款记录 | 证明有还款意愿 |
| **资产证明** | 房产、车辆、存款证明 | 证明有还款能力 |
| **投资证据** | 投资合同、项目资料、风控制度 | 证明是投资行为而非挥霍 |
| **风控证据** | 风控制度、执行记录 | 证明有风控措施 |
| **私募基金材料** | 基金管理人登记证书、基金备案证明、投资人适当性材料 | 证明私募基金合规性 |

### （三）举证质证要点

**控方举证要点**：
1. 证明集资行为存在
2. 证明资金损失存在
3. 证明推定基础事实存在（挥霍、逃匿等）
4. 证明行为人具有非法占有目的

**辩方质证要点**：
1. 质疑资金流向证据的真实性、完整性
2. 质疑挥霍行为的定性（是挥霍还是合理消费）
3. 质疑推定基础事实的证明标准
4. 提供反证证明无非法占有目的
5. 质疑私募基金管理人登记和基金备案的证明力

## 七、实务判断标准总结

### （一）两罪区分的判断流程

```
第一步：行为人是否实施了非法集资行为？
    ↓ 是
第二步：行为人是否具有"非法占有目的"？
    ↓ 需要判断
第三步：是否存在司法解释规定的七种情形？
    ↓ 存在 → 集资诈骗罪
    ↓ 不存在 → 第四步
第四步：是否违反审慎注意义务？
    ↓ 违反 → 推定非法占有目的（可反驳）
    ↓ 未违反 → 非法吸收公众存款罪
```

### （二）非法占有目的的综合判断因素

| 因素 | 考虑内容 | 权重 |
|------|----------|------|
| **资金去向** | 是否用于经营、是否挥霍 | 高 |
| **还款意愿** | 是否有还款计划、是否积极弥补 | 高 |
| **还款能力** | 是否有资产、是否有担保 | 中 |
| **事后态度** | 是否逃匿、是否隐匿财产 | 高 |
| **经营状况** | 经营是否真实、是否盈利 | 中 |
| **私募基金合规性** | 是否完成登记备案、是否遵守投资规定 | 中 |
| **投资人过错** | 投资人是否尽到审慎义务 | 低 |

### （三）辩护策略选择

| 案件情况 | 辩护策略 | 预期效果 |
|----------|----------|----------|
| 资金全部用于经营 | 证明无挥霍、无逃匿 | 争取非法吸收公众存款罪 |
| 部分资金挥霍 | 证明挥霍比例小、有能力返还 | 争取从轻处罚 |
| 投资失败 | 证明是商业风险、非挥霍 | 争取非法吸收公众存款罪 |
| 有还款意愿 | 证明有还款计划、有资产 | 争取从轻处罚 |
| 私募基金案 | 证明已完成登记备案、资金主要用于约定方向 | 争取非法吸收公众存款罪 |
| 投资人有过错 | 证明投资人未尽审慎义务 | 争取从轻处罚 |

---

## 八、结论

在非法集资案件中，**非法吸收公众存款罪与集资诈骗罪的区分**关键在于"非法占有目的"的认定。**审慎注意义务的违反**是推定这一目的的重要依据。

**实务要点**：
1. **七种法定情形**是认定非法占有目的的直接依据
2. **挥霍与投资失败的界定**需要综合判断资金用途、主观认知、客观行为等因素
3. **私募基金案件**中，登记备案不构成对合规性的认可，但仍可作为无非法占有目的的参考
4. **辩护工作的核心**是证明资金用于正当经营、有还款意愿和能力
5. **证据审查的关键**是资金流向、主观目的、事后态度、私募基金合规性

**最终目标**：在打击犯罪与保障人权之间寻求平衡，确保每一起案件都能得到公正处理。
