# SRC-004 · 转化型案件的罪名选择标准

## 核心问题

"前无后有"型案件取得财物后,如果行为人实施了新的危害行为,可能触犯多个罪名(侵占罪 / 拒不执行判决、裁定罪 / 虚假诉讼罪)。这些罪名的适用边界是什么?在多重触犯时,如何选择定罪?

**待研究问题**:
1. 侵占罪(刑法第 270 条) vs 拒不执行判决、裁定罪(刑法第 313 条) vs 虚假诉讼罪(刑法第 307 条之一)三者的适用边界?
2. 民间借贷占有借款是否属于"代为保管"(侵占罪要件)?司法实务如何处理?
3. 拒不执行判决、裁定罪(经法院判决仍拒不执行)与虚假诉讼罪(通过虚假诉讼合法化)的同时触犯,如何按想象竞合从一重处断?
4. 各级法院对"拒不执行"的认定标准(尤其是"有执行能力"的认定)?

## 检索方向

  - 同义/近义词:`代为保管` / `执行能力` / `隐匿财产` / `合法化`
