# SRC-001 · 两阶层 vs 四要件实务差异的本土化路径

## 核心问题

我国传统刑法学界长期使用四要件体系(犯罪客体、犯罪客观方面、犯罪主体、犯罪主观方面),司法实务(法院判决书、检察院起诉书)也以四要件为主要分析框架。两阶层体系(构成要件该当性 + 违法性 + 有责性)源自德日,在学术上渐成主流,但在司法实务中的适用仍存在显著差异。

**待研究问题**:
1. 最高人民法院、最高人民检察院的司法解释(如《关于办理诈骗刑事案件具体应用法律若干问题的解释》法释〔2010〕7 号)在实质内容上是四要件还是两阶层?
2. 各级人民法院的判决书中,审查顺序是"主客观相统一"还是"阶层递进"?
3. 辩护方在司法实务中如何运用"出罪事由先行"(客观不成立即出罪)?
4. 两阶层体系在中国的本土化路径是什么?是否需要"中国版两阶层"?
