# SRC-003 · "前无后有"型案件的具体判例

## 核心问题

"前无后有"型案件(借款时无非法占有目的,取得财物后才产生)是不构成诈骗罪但需转入其他罪名评价的转化型情形。本任务的核心论点"取得财物时 = 临界点"是**通说**,但司法实务中是否有**扩张判例**(即使取得财物时无非法占有目的,后续的逃匿、挥霍行为也被评价为诈骗罪)?

**待研究问题**:
1. 2015-2026 年间,"前无后有"型案件的具体判例有多少?主要分布在哪一级法院?
2. 扩张判例存在吗?如果有,扩张的理由是什么(后续欺骗行为单独构成诈骗罪 / 取得财物时点重新解释 / 客观行为持续性)?
3. 转化型罪名的适用比例(侵占罪 270 / 拒不执行判决罪 313 / 虚假诉讼罪 307-1)?
4. 各级法院对"前无后有"型案件的审查逻辑是否有差异?
