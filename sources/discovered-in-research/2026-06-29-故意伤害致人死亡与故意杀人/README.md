## 一、核心论断

**主客观结合说**:故意伤害致人死亡与故意杀人的实务区分,本质是主客观结合的判断:
- 主观故意内容(认识 + 意志,《刑法》第 14 条)是核心
- 客观行为(工具 / 部位 / 力度 / 次数)只能佐证,不能独立推定
- 「伤害行为 → 死亡结果」因果链需保持完整;异常介入(被害人特异体质、医疗过失、第三人二次伤害)可能改变罪质认定

## 四、关键发现

### 4.1 实务判断框架

司法实务在两罪区分中并非简单适用"主观罪质说"或"客观危害说",而是采用"主客观结合 + 综合判断 + 罪疑唯轻"三位一体的判断装置:
1. **主观罪质**:从认识 + 意志两个维度认定(《刑法》14 条)
2. **客观推定**:工具 / 部位 / 力度 / 次数四要素复合推定
3. **综合判断**:主观面证据 + 客观行为 + 行为人事后态度
4. **罪疑唯轻**:证据不足以认定故意杀人时降至故意伤害致死

### 4.2 反向假设法嵌入反对者审查

3 道反向假设(在 working-draft §6 中已标注):
1. **若"主观罪质说"不成立**:复合推定路径可径行推定杀人故意,主客观关系的论文价值将被稀释
2. **若"间接故意不存在未遂"命题不成立**:实务处理更富弹性,但刑事审判参考第 21 辑第 129 号曹成金案立场仍占主导
3. **若特异体质一律作为出罪事由**:显著扩张罪轻辩护空间,但削弱被害人特殊群体保护

### 4.3 实务辩护的五个转身点

律师从故意杀人拉回到故意伤害致死的 5 个主要转身点:
1. **主观面证据重建**(供述 + 现场监控 + 关系背景)
2. **客观面对比分析**(同一行为在故意伤害语境下也能解释)
3. **因果链断裂**(特异体质 + 医疗过失 + 第三人介入)
4. **间接故意反向论证**(事后救助 / 即时停止暴力)
5. **罪疑唯轻**(《刑事诉讼法》200 条第二款)
