## 五、阶段一·b 关键发现（差分驱动）

### 5.1 责任主体清单（13 类）

旧 L1 仅"复合之诉"概述，本指南**精确列举**：
- 车辆所有权类：所有人 / 实际管理人 / 挂靠人 / 被挂靠人 / 被套牌人（5 类）
- 侵权关系类：实际驾驶人 / 雇主 / 试乘服务提供者 / 驾驶培训机构（4 类）
- 保险责任类：投保义务人 / 保险公司 / 道路救助基金（3 类）

### 5.2 上海地方规定（《上海市机动车道路交通事故赔偿责任若干规定》第六条）

上海地方性法规级别材料：
- 机动车 ↔ 非机动车/行人：100% / 80% / 60% / 40%
- 机动车 ↔ 机动车：主要 70% / 次要 30%（统一比例，±10% 调整）

### 5.3 最高法指导案例 / 上海高院参考性案例

- **最高法 19 号**（套牌机动车致害）
- **最高法 24 号**（特殊体质参与度）
- **上海高院 87 号**（结果性赔偿 vs 过程性赔偿）
- **上海法院精品案例 3 件**（挂靠/共同侵权/商业三者险）

### 5.4 2020.1.1 上海城乡统一标准

- 残疾赔偿金 / 死亡赔偿金：上一年度上海市居民人均可支配收入
- 被扶养人生活费：上一年度上海市居民人均消费支出
- **不再区分城镇/农村**

### 5.5 关键免责规则

- 商业三者险免责条款：提示 + 明确说明双重标准
- 车辆贬损费：原则上不予支持（最高法答复 4 大理由）
- 未按时年检：不直接免责，须判断危险程度是否显著增加
- 超医保用药：保险人举证，不能证明的无效抗辩
