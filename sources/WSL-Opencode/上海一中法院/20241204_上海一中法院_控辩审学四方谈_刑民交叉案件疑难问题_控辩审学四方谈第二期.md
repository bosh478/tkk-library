# 刑民交叉案件疑难问题 | 控辩审学四方谈第二期



点击图片查看更多内容

2024年12月4日下午，由中国刑法学研究会、上海高院指导，上海一中院与华东政法大学联合主办的第二届“刑事知行研讨·控辩审学四方谈”活动在华东政法大学举行。

活动研讨主题为“刑民交叉案件疑难问题”，上海高院、上海一中院及辖区法院、上海检察一分院、上海市公安局、上海市律协、中国刑法学研究会、上海市法学会、西北政法大学、华东政法大学、上海财经大学、华东师范大学等单位的实务界人士、专家、学者共70余人参加会议。

与会人员围绕研讨主题、结合三个典型案例展开充分讨论。上海一中院党组成员、副院长徐世亮主持。

丁某欲购买甲公司挂牌出售的两间门面房，经人介绍与甲公司销售人员赵某、王某洽谈，后双方签订房屋买卖合同。按照合同约定，丁某向赵某、王某提供的“公司账号”全额支付了购房款，但甲公司一直未按合同约定如期交房。为此，丁某向公安机关报案称甲公司涉嫌诈骗。经公安机关调查，发现赵某、王某另行开办乙公司，分别担任法定代表人和出纳，二人向丁某提供的付款账号实际为乙公司所有，且钱款到账后被用于支付乙公司非法吸收公众存款的到期本息。公安机关遂以赵某、王某涉嫌职务侵占罪（非法占有甲公司的房屋销售款）和非法吸收公众存款罪展开刑事追诉。同时丁某向法院起诉要求判令甲公司交房或者退还购房款本息，支付相应的违约金。

上海市公安局法制总队副总队长税兵、上海高院刑事审判庭副庭长李长坤、上海一中院商事审判庭副庭长何建围绕“本案所涉房屋买卖合同是否合法有效”“甲公司的法律责任性质及范围如何确定”等问题，分别发表了自己的观点。

黄甲（系黄乙之女）因借款3万元而遭遇套路贷诈骗，三个多月就被不断垒高债务达32万元。因无力还债，黄甲被迫偷拿家中的房产证，以与母亲黄乙共有的房屋作抵押，转向套路贷诈骗犯引荐的职业放贷人高某某借款45万元，并办理了相应的公证手续。在归还前债及支付砍头息之后，黄甲实际得款5万元。在套路贷诈骗犯罪案件判决生效后，高某某以借款合同及抵押公证文书为依据，请求法院执行并拍卖系争房屋，市值110万元（与借贷本息大致相当）。

被告人潘四隐瞒非法占有目的，以虚假的项目施工合同及资质文件向B银行申请贷款，同时骗取C公司信任为其提供担保。刑事判决认定：被告人潘四虚构事实，以签订虚假的贷款合同与担保合同为手段，骗取贷款6000万元，构成贷款诈骗罪。在刑事追诉期间，司法机关依法追缴赃款1300余万元。与此同时，B银行向人民法院提起民事诉讼，请求法院判令C公司按照担保合同约定承担连带担保责任，赔偿贷款本息及违约金，合计1.3亿余元。

上海检察一分院第一检察部副主任朱能立，上海市律协民事专业委员会主任王琦，上海一中院刑事审判庭副庭长张金玉，华东师范大学刑法学教授、博士生导师钱叶六围绕“本案所涉贷款合同、担保合同是否有效”“担保人的法律责任性质如何，是合同违约责任，还是侵权损害赔偿责任”“刑事、民事诉讼程序如何展开，是先刑后民，还是刑民并行”三个问题分别发表了自己的观点。

讨论后，上海高院研究室（发展研究中心）主任张果，华东政法大学刑事法学院院长、教授孙万怀，中国刑法学研究会副会长、西北政法大学教授王政勋，华东政法大学司法改革与案例研究中心首席专家黄祥青进行总结点评。

上海高院研究室（发展研究中心）张果主任指出，本次研讨会聚焦司法实践中的真问题、好问题、难问题展开，控辩审学四方专家通过思想碰撞和交流，充分展示分歧观点，力求凝聚更大共识。希望理论界与实务界、刑法界与民法界进一步加强沟通，共同破解刑民交叉难题。

华东政法大学刑事法学院院长、教授孙万怀就本次会议的成功召开对参与各方表示衷心感谢，本次研讨为刑民交叉问题的理论研究提供了新的切入点，今后将继续深化理论和实践的融合，进一步扩大“知行研讨·控辩审学四方谈”的辐射范围和影响力。

中国刑法学研究会副会长、西北政法大学教授王政勋指出，刑民交叉问题是长期困扰理论界和实务界的重大问题，并从“刑民一体”“刑民异质”“刑民并举”三个维度阐释了刑民关系，强调要善于通过法律解释实现案件审理“三个效果”的有机统一。

华东政法大学司法改革与案例研究中心首席专家黄祥青指出，今天研讨会主要围绕四个问题展开讨论，一是明确研究对象，一个犯罪行为引起受损的权利需要刑事与民事两种诉讼手段来救济的案件是刑民交叉案件；二是突出研究重点，即主要解决引发权利受损后果的多个行为主体法律责任的分担问题及刑民程序的有效衔接问题；三是法律责任的范围或限度问题，即应以侵权责任还是违约责任来确定相关民事权利的救济范围；四是诉讼程序衔接问题，即应先刑后民还是刑民并行。解决这些问题需遵循三项原则：一是充分保护和救济受损的合法权利；二是裁判应为相关行为提供规范和指引；三是注重法秩序统一，维护法律的权威性。
