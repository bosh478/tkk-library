## 核心观点

### 402-406. 劳动人事争议仲裁裁决的执行

| 序号 | 要点 |
|------|------|
| 402 | 劳动争议仲裁委员会作出的先予执行裁决不可诉，但可以申请强制执行 |
| 403 | 劳动仲裁不适用《民事诉讼法》第217条关于仲裁协议的规定，法定仲裁无需仲裁协议 |
| 404 | 劳动者申请执行仲裁裁决在先，用人单位不申请撤销仲裁裁决而直接申请不予执行的处理规则 |
| 405 | 能否强制执行劳动仲裁裁决中"其他请求事项，根据该企业有关规定办理"的内容 |
| 406 | 执行依据应具有给付内容且具体明确 |

**先予执行裁决**（法释〔2020〕26号第10条）：用人单位不履行预先支付劳动者劳动报酬、工伤医疗费、经济补偿或者赔偿金裁决的，劳动者依法申请强制执行的，人民法院应予受理。

### 407-414. 公证债权文书的执行

| 序号 | 要点 |
|------|------|
| 407 | 银行金融债权风险的防控中公证书的强制执行效力 |
| 408 | 赋予强制执行效力的公证债权文书申请执行期限 |
| 409 | 签发执行证书时当事人应否到场 |
| 410 | 债权人能否不经执行程序直接起诉 |
| 411 | 审查处理不予执行公证债权文书案件时，实体审查对象原则上限于公证债权文书本身 |
| 412 | 债权人转让部分债权是否构成不予执行公证债权文书的理由 |
| 413 | 公证债权文书执行过程中案外人主张排除执行的救济 |
| 414 | 含担保协议的公证债权文书是否应予执行 |

**关键规则**：
- 对于具有强制执行效力的公证债权文书，债权人能否不经执行程序直接起诉：原则上不能
- 公证债权文书执行中案外人主张权利的救济：通过执行异议程序处理

### 415-418. 刑事裁判涉财产部分的执行

| 序号 | 要点 |
|------|------|
| 415 | 审查处理刑事裁判涉财产部分执行案件案外人异议、复议，即使案情并非疑难复杂，也应当公开听证 |
| 416 | 执行追缴程序中在赃款赃物不存在的情况下能否直接对被执行人执行退赔 |
| 417 | 关于刑事裁判文书制作的规范要求 |
| 418 | 刑事财产执行经过无底价拍卖仍不能变价的，不能退还被执行人 |

### 419-424. 行政案件的执行

| 序号 | 要点 |
|------|------|
| 419 | 政府征收决定直接导致物权变动，但在被征收人未获安置补偿前，不能强制执行 |
| 420 | 责令采取补救措施判决执行内容及是否执行完毕的认定 |
| 421 | 在获得人民法院准许强制执行裁定前，行政机关没有直接强制拆除被征收房屋的权利 |
| 422 | 劳动行政部门作出责令用人单位支付劳动者工资报酬、经济补偿和赔偿金的劳动监察指令书是否属于可申请法院强制执行的具体行政行为 |
| 423 | 行政文件不能作为人民法院强制执行的依据 |
| 424 | 人民法院能否裁定准予执行土地管理部门的行政处罚决定 |

**关键规则**：
- 政府征收决定导致物权变动，但未获安置补偿前不能强制执行
- 行政机关强制执行须有法院准许裁定

### 425-427. 涉外与港澳台案件的执行

| 序号 | 要点 |
|------|------|
| 425 | 如何理解"被执行人在我国领域内有实际可执行的财产" |
| 426 | 申请执行香港仲裁裁决时，法院在作出认可和执行裁定前，可以依申请采取保全措施 |
| 427 | 内地仲裁机构在香港设立的分支机构以香港为仲裁地作出的仲裁裁决属于香港仲裁裁决 |

**关键规则**：
- 申请认可和执行香港仲裁裁决前可采取保全措施
- 仲裁地的认定决定裁决的地域属性
