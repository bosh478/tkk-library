# 校园体育伤害事故各方责任认定规则

> **作者**：李家兴（上海市第一中级人民法院，三级法官助理）
> **案例类型**：限制民事行为能力人在校参与体育活动遭受人身损害纠纷
> **核心结论**：学校充分履行四类职责（安全教育/设施安全/现场管理/应急处置）则无需担责；无故意或重大过失的比赛参与者无需担责，损害由受害方自担

## 案件核心事实

| 要素 | 内容 |
|------|------|
| 受害者 | 小亮，15岁（高中学生，限制民事行为能力人） |
| 致害人 | 小明，15岁，同校学生 |
| 事故经过 | 学校组织足球比赛，小明在阻挡小亮过程中发生肢体碰撞，小亮倒地受伤，右肘关节多发骨折并伴脱位 |
| 比赛状态 | 双方均依规参赛，未出现任何犯规行为 |
| 判决结果 | **驳回小亮全部诉讼请求**（学校、小明及其监护人均无需担责） |

## 学生双方责任认定规则

### 核心标准：侵权方是否存在过错

| 侵权方情形 | 法律后果 |
|------------|----------|
| **存在故意或重大过失** | 根据过错程度承担相应责任 |
| **无故意且无重大过失**（规则允许范围内的正常碰撞） | **损害后果由受害方自行承担** |

### 足球运动的固有风险理论

> 活动参与者既是**潜在的风险制造者**，也是**潜在的风险承受者**

- 在规则允许范围内的争抢、肢体碰撞等行为，属于运动本身的正常范畴
- 该属性不因参与主体为未成年人而消除

### "故意或重大过失"的认定要素

需结合**监控录像、证人证言、当事人陈述**等证据综合判断：

1. **冲撞行为是否明显违反运动规则**
2. **行为人是否具有预见并避免伤害发生的可能性**

### 典型对比：棒球 vs 足球

| 运动 | 规则特点 | 违规碰撞致伤的法律后果 |
|------|----------|----------------------|
| **棒球** | 明确禁止跑者冲撞捕手 | 违规碰撞被认定为故意或重大过失的概率**远高于**足球 |
| **足球** | 允许正常身体对抗和争抢 | 正常碰撞无故意或重大过失则不构成侵权 |

## 学校责任认定规则

### 法律依据

**《民法典》第1200条（2021-01-01 施行 / 2021-01-01 最新修正）**：
> "学校或其他教育机构未尽到教育、管理职责的，应当承担侵权责任。"

### 四类职责详解

#### 1. 安全教育责任

| 要求 | 说明 |
|------|------|
| 最低频率 | 每名学生至少每月接受一次专题安全教育 |
| 核心内容 | 校园体育运动中的**自我保护、伤害防范知识** |
| 认定标准 | 未开展安全教育，或**无法提供已开展安全教育的有效证据** → 认定存在过错 |
| 法规依据 | 《中小学幼儿园安全防范工作规范（试行）》第16条 |

#### 2. 设施安全责任

| 要求 | 说明 |
|------|------|
| 场地标准 | 符合国家及地方相关标准，适配未成年人使用需求 |
| 管理义务 | 对设施履行**定期检查、维护、管理**的注意义务 |
| 认定标准 | 设施存在缺陷，且该缺陷与伤害事故的发生存在**直接关联** → 承担过错责任 |

#### 3. 现场管理责任

| 要求 | 说明 |
|------|------|
| 教师在岗要求 | 体育课及学校组织的体育活动中，体育教师应**全程在岗** |
| 管理内容 | 对学生活动进行专业指导；及时制止违规操作、危险拼抢等行为 |
| **注意** | 课余、周末等**非学校组织时间**，学生自行在校园开展体育活动 → **不苛求教师全程管控** |

#### 4. 应急处置责任

| 要求 | 说明 |
|------|------|
| 法律依据 | 《学生伤害事故处理办法》第15条 |
| "及时救助"内涵 | ① 事故发生时的**现场紧急处置**；② 对伤情严重者的**及时送医**；③ **第一时间联系监护人**；④ 为后续治疗提供**必要协助** |

### 学校四类职责检查清单

| 职责类别 | 关键证据 |
|----------|----------|
| 安全教育 | 课程记录、签到表、安全提示告知记录 |
| 设施安全 | 场地检查记录、设施维护台账、国家标准符合性证明 |
| 现场管理 | 教师在岗记录、活动组织方案 |
| 应急处置 | 事故处理记录、送医记录、家长通知记录 |

## 司法政策导向

### 核心价值取向：公平与效率的平衡

> 既不能纵容过错方逃避应承担的责任，也不能为规避所有风险而过度限制校园体育活动的开展，牺牲教育教学效率。

### 2025年司法政策信号

**最高法张军院长2025年人民法院工作报告**明确提出：
> "**孩子虽在校，家长也有责**"

**关键数据**：校园侵权案件中**学校担责的案件占比**，较2023年**下降5.3个百分点**。

这一变化体现了人民法院：
- 科学厘定家庭与学校各方权责
- 切实保护未成年人健康成长的坚定立场

### 多方协同原则

构建安全校园运动环境需要**家庭、学校、社会三方协同发力**：
- **家庭**：引导未成年人正确认识体育活动风险，履行监护职责
- **学校**：充分履行教育、管理、保护职责
- **社会**：为校园体育活动提供支持

## 知识缺口

> [!gap]+ 知识缺口

1. **《民法典》第1200条（2021-01-01 施行 / 2021-01-01 最新修正）的适用年龄分层**：本文未明确说明《民法典》第1199条（2021-01-01 施行 / 2021-01-01 最新修正）（无民事行为能力人）和第1200条（限制民事行为能力人）在责任认定标准上的具体差异，需查阅原文确认
2. **本案小明是否属于限制民事行为能力人（15岁）的进一步论证**：文章提及"限制民事行为能力人"但未展开说明；根据《民法典》第19条（2021-01-01 施行 / 2021-01-01 最新修正），8周岁以上未成年人为限制民事行为能力人，需核实本案的法律推理是否完整
3. **"孩子虽在校，家长也有责"原文出处**：仅依据文章转述，未获取最高法2025年工作报告原文核实该表述的准确性和上下文
4. **学校担责率下降5.3个百分点的具体统计口径**：未获取原始统计数据，无法确认该数据的统计范围（全国/部分地区）及年份范围
