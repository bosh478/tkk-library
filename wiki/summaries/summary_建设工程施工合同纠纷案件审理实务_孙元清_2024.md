## 一、核心定义与概念

### 1.1 建设工程施工合同的概念

**定义**：建设工程施工合同是指发包人（建设单位）和承包人（施工人）为完成约定的建设工程，协商一致签订的明确相互民事权利、义务的协议。

**合同主体限制性**（与一般承揽合同的核心区别）：
- 承包人必须是具有相应资质的法人，自然人不具备承包资质
- 依据：《建筑法》第12-13条、第26条；《建工司法解释（一）》第1条

**合同形式法定性**：
- 根据《民法典》第789条（2021-01-01 施行 / 2021-01-01 最新修正），建设工程合同应当采用书面形式
- 中标通知书到达中标人时承诺生效，合同成立（非预约合同）

### 1.2 实际施工人的概念与范畴

**定义**：实际施工人是指建设工程施工合同无效情形下，实际完成建设工程施工或者实际投入资金、材料和劳动力违法承包的单位和个人。

**三类实际施工人**：
1. 违法的专业工程分包和劳务作业分包合同的承包人
2. 转承包人（层层转包中的最终施工方）
3. 借用资质的承包人（挂靠承包人）

**不认定为实际施工人的情形**：
- 农民工（仅从事劳务，依《工资支付条例》主张工资，非工程款）
- 施工队、施工班组（不提供资金、机械设备、建筑材料，仅承担简单劳务的，是劳务关系非实际施工人）
- 中间环节的转包人、违法分包人（未实际投入资金、材料、人力）

**实际施工人审查九要素**（综合判断）：
1. 是否在合同签订前即与发包人进行联系、沟通、协商
2. 是否直接以被挂靠人名义参与投标、合同签订、办理施工手续
3. 是否存在组织工程施工管理、购买建材、租赁施工机具、支付水电费等实际施工行为
4. 对工程建设是否享有管理支配权（人财物独立管理支配权）
5. 是否在项目中存在投资或收款行为（直接出资、收取工程款）
6. 是否与出借资质企业存在劳动关系（工资、社保）
7. 出借资质企业是否只收取管理费
8. 是否与发包人形成事实上的建设工程施工合同法律关系
9. 是否全程参与施工管理、签订补充协议、结算工程款

## 二、合同效力认定

### 2.1 建设工程施工合同无效的法定情形

依据《建工司法解释（一）》第1-5条：

| 无效情形 | 法律依据 |
|----------|----------|
| 承包人未取得建筑业企业资质或者超越资质等级 | 《民法典》第153条（2021-01-01 施行 / 2021-01-01 最新修正）第1款 |
| 没有资质的实际施工人借用有资质的建筑施工企业名义（挂靠） | 《民法典》第153条（2021-01-01 施行 / 2021-01-01 最新修正）第1款、《建筑法》第26条第2款 |
| 建设工程必须进行招标而未招标或者中标无效 | 《招标投标法》第3条、第46条 |
| 承包人转包、违法分包建设工程 | 《民法典》第791条第2款、第3款 |

### 2.2 必须招投标范围的重大调整（2018年）

**大幅缩小后的范围**（五大类）：
1. 能源基础设施项目（煤炭、石油、天然气、电力、新能源等）
2. 交通运输基础设施项目（铁路、公路、管道、水运、公共航空、A1级通用机场）
3. 通信基础设施项目（电信枢纽、通信信息网络）
4. 水利基础设施项目（防洪、灌溉、排涝、引水）
5. 城建项目（城市轨道交通）

**删减内容**：民间资本投资的商品住宅项目等不再列入必须招投标范围

### 2.3 合同效力补正

| 情形 | 补正规则 |
|------|----------|
| 未取得建设工程规划许可证等规划审批手续 | 允许效力补正：起诉前取得规划审批手续的，合同有效 |
| 超越资质等级许可 | 允许效力补正：建设工程竣工前取得相应资质等级的，合同有效 |
| 必须招投标项目政策调整后不再需要招投标 | 依据"有利溯及"原则，可认定合同有效 |

### 2.4 劳务分包与转包、违法分包的区分

**劳务分包的判断标准**：承包范围是否包含大型机械租赁、主要建材采购、现场管理

| 情形 | 认定 |
|------|------|
| 劳务分包（承包范围仅含简单劳务及小型机具、辅材） | 有效 |
| 劳务分包包含大型机械租赁、主要建材采购、现场管理 | 可能构成转包或违法分包 |

**劳务分包合同效力**：依据《建工司法解释（一）》第5条，具有劳务作业法定资质的承包人与总承包人、分包人签订的劳务分包合同，当事人请求确认无效的，人民法院依法不予支持。

## 三、工程价款结算

### 3.1 合同无效情形下的结算原则

**核心法条**：《民法典》第793条（2021-01-01 施行 / 2021-01-01 最新修正）

> 建设工程施工合同无效，但是建设工程经验收合格的，可以参照合同关于工程价款的约定折价补偿承包人。

**三层含义**：
1. 建设工程经验收合格才符合支付工程价款的条件
2. 合同中的结算条款可以参照适用
3. 合同无效适用的是折价补偿原则（非支付工程款）

### 3.2 结算条款参照适用范围

| 条款类型 | 能否参照适用 | 说明 |
|----------|--------------|------|
| 工程价款计价方式（下浮率） | 可参照 | 须结合具体情形判断 |
| 工程款支付时间、支付条件 | 可参照 | 属于结算条款 |
| 工程质量保证金条款 | 可参照 | 约定超过2年或3%并非无效 |
| 管理费条款 | 原则上不支持 | 须查明是否进行了实际管理，一般不宜超过总工程款的3% |
| 逾期付款利率条款 | 不能直接参照 | 应参照同期同类贷款利率或LPR计息 |
| 垫资利息条款 | 不能直接参照 | 实际支持的利率不超过同期贷款利率 |

### 3.3 "背靠背"条款的效力

**2024年8月最高法批复明确**：

大型企业与中小企业约定以第三方支付款项为付款前提的条款，因违反《保障中小企业款项支付条例》第6条、第8条的规定，依据《民法典》第153条（2021-01-01 施行 / 2021-01-01 最新修正）第1款，应当认定无效。

**适用要点**：
1. 仅适用于大型企业与中小企业之间
2. 合同条款无效后，应当根据案件具体情况合理确定付款期限及违约责任
3. 利息计付标准有约定的按约定，无约定或违定的按LPR计息

### 3.4 固定价格合同的相关问题

**固定总价合同的认定**（三个考量因素）：
1. 合同中是否有"包死价""包干价""闭口价""固定总价"等明确表述
2. 合同是否明确约定承包范围内的工作内容总价固定、不再调整
3. 合同为总价合同、承包范围确定，且计价方式反映出承包人承担量、价风险

**工程未完工终止时的结算**：
- 原则上按合同约定予以结算
- 按约定无法确定已完工程价款的，允许通过鉴定确定
- 计算方法：固定总价×（已完工程量/全部工程量）

### 3.5 管理费的处理

| 情形 | 处理方式 |
|------|----------|
| 未实际参与管理 | 不予支持 |
| 实际参与部分工程管理 | 可部分支持，一般不宜超过总工程款的3% |
| 实际参与管理并承担施工协调职责 | 可收取，但需综合考量管理内容、程度、人员数量、工作量等 |

### 3.6 人工费、材料费调差

**调差基本原则**（表2-1 总结）：

| 情形 | 处理原则 |
|------|----------|
| 正常工期 + 约定可调差 | 合同有效/无效，均按约定调差 |
| 正常工期 + 约定不调差 | 合同有效/无效，均不调差 |
| 正常工期 + 未约定或约定不明 | 无论合同是否有效，均可按调差文件进行调差 |
| 因发包人原因工期延误 | 无论合同是否有效、是否约定，均可按调差文件调差 |

**签订合同时人工工资低于当地最低工资标准的强制调差**：
- 合同约定的人工工资标准低于当地当期规定的定额最低人工工资标准 → 约定无效
- 应按合同签订时的定额最低人工工资标准予以强制调差
- 法律依据：《民法典》第8条（2021-01-01 施行 / 2021-01-01 最新修正）（不得违背公序良俗）+ 《民法典合同编通则解释》第17条第1款第2项（损害社会公共秩序）

### 3.7 规费、税金问题

**不可竞争性费用**（三部分）：
1. 安全文明施工费（环境保护费、文明施工费、安全施工费、临时设施费）
2. 规费（社会保险费、住房公积金、工程排污费等）
3. 税金

**不可竞争性费用的处理原则**：
- 不得作为竞争性费用，发包人不得以任何形式扣减
- 双方约定排除不可竞争性费用的约定，因损害社会公共利益而无效
- 自然人作为实际施工人能否取得规费尚有争议，但实际投入的材料费、劳务费已物化为工程价值，应享有相应利润

## 五、典型裁判规则

### 5.1 合同效力黑白合同规则

**法条**：《建工司法解释（一）》第22条

| 中标合同效力 | 结算依据 |
|--------------|----------|
| 中标合同有效 | 以中标合同作为结算依据 |
| 中标合同无效（多份合同均无效） | 以实际履行的合同作为结算依据；无法区分的，以后签订的合同为准 |

### 5.2 实际施工人突破合同相对性的条件

**法条**：《建工司法解释（一）》第43条

实际施工人向发包人主张工程价款的条件：
1. 存在转包、违法分包、挂靠等情形
2. 合同无效
3. 建设工程经验收合格
4. 在欠付工程价款范围内向发包人主张权利

**不支持突破合同相对性的情形**：
- 农民工工资案件（应适用《工资支付条例》，主张工资而非工程款）
- 中间环节转包人、违法分包人（未实际投入资金、材料、人力）
- 实际施工人的合伙人、实际出资人（内部关系，另行处理）

### 5.3 工程质量与工程款支付的关系

**核心规则**：质量合格是支付建设工程价款的前提条件

| 情形 | 处理 |
|------|------|
| 建设工程未经竣工验收，发包人擅自使用 | 以转移占有建设工程之日为竣工日期 |
| 发包人擅自使用后，又以使用部分质量不符合约定为由主张权利 | 不予支持 |
| 承包人原因导致工期延误期间的人工费上涨 | 承包人可主张该期间的人工费差价 |
| 逾期结算的责任 | 发包人拖延结算的，应承担从应付工程款期限开始计算的逾期付款利息 |

## 六、附：湖南省高级人民法院裁判指引（摘要）

| 解答条款 | 主要内容 |
|----------|----------|
| 第1条 | 四类建设工程合同纠纷适用专属管辖（施工、分包、勘察设计、债权转让） |
| 第2条 | 仲裁条款对实际施工人的约束力（实际施工人不受发包人与承包人仲裁条款约束） |
| 第3条 | 非必须招标项目未经招投标主张合同无效的不予支持 |
| 第5条 | 建设工程规划许可证允许效力补正（多次诉讼，发包人在最后一次起诉前取得可认定有效） |
| 第7条 | 黑白合同结算规则（中标有效以中标合同为据；均无效以实际履行合同为据） |
| 第8条 | 合同无效不影响结算协议效力（双方自行达成结算协议后不得反悔） |
| 第10条 | 合同无效可参照索赔条款计算损失（质量、工期、进度款支付等） |
| 第11条 | 管理费原则上不支持，一般不宜超过总工程款的3% |
| 第12条 | 转包差价属非法利益，不宜超过差额部分工程款的8% |
| 第13条 | 约定以行政审计、财政评审作为结算依据的按约定处理，审计结论不真实客观的可申请司法鉴定 |
| 第14条 | 预支工程进度款的借条可在工程款结算中抵扣 |
| 第15条 | 以房抵顶工程款协议原则上有效 |
