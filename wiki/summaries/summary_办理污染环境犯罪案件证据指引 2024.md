## 正文

### 一、基本原则

1. **依法规范原则**：合法、科学规范地收集、固定、审查、运用证据
2. **全面客观原则**：收集有罪证据和罪轻证据，不得选择性取证
3. **证据裁判原则**：以事实为根据、以法律为准绳

### 二、证明犯罪客观方面的证据

**（一）证明实施排放、倾倒或者处置行为的证据**
- 现场勘验、检查笔录，扣押清单及现场照片、执法记录视频
- 聊天记录、通话记录、短信记录、监控录像
- 排放、倾倒、处置污染物的内部记录，生产、排放日志
- 证人证言、被害人陈述、犯罪嫌疑人供述和辩解

**（二）证明污染物种类的证据**
- 环境影响评价文件、排污许可证、排污登记表
- 专业机构出具的检验、检测报告、监测数据
- 鉴定意见
- 有专门知识的人就案件的专门性问题出具的报告

**（三）证明"严重污染环境"的证据（10种情形）**

| 情形 | 数额/数量标准 |
|------|--------------|
| 在重点保护区域排放有毒物质 | - |
| 非法排放危险废物 | 3吨以上 |
| 超过污染物排放标准3倍/10倍 | 含铅、汞、镉、铬、砷、铊、锑等3倍；含镍、铜、锌、银、钒、锰、钴等10倍 |
| 通过暗管、渗井、渗坑等逃避监管方式排放 | - |
| 通过非紧急情况下开启大气应急排放通道排放 | - |
| 2年内因重污染天气预警期间超标排放受过2次以上行政处罚 | - |
| 重点排污单位篡改伪造自动监测数据 | - |
| 2年内因排放有毒物质受过2次以上行政处罚 | - |
| 违法所得 | 30万元以上 |
| 致使公私财产损失 | 30万元以上 |

### 三、证明犯罪主体方面的证据

**（一）自然人身份**
- 户籍证明、居民身份证、居住证、工作证、护照
- 岗位任职文件、劳动合同、岗位职责

**（二）单位身份**
- 企业法人营业执照、工商注册登记证明
- 单位财务账目、银行账号证明、年检情况
- 单位内部组织的有关合同、章程、协议书等
- 聊天记录等电子数据

### 四、证明犯罪主观方面的证据

**故意推定的情形**：
1. 企业没有依法通过环境影响评价或未依法取得排污许可证
2. 擅自更改工艺流程、原辅材料导致产生新的污染物质
3. 不使用验收合格的防治污染设施或者不按规范要求使用
4. 防治污染设施发生故障，发现后不及时排除
5. 生态环境主管部门责令限制生产、停产整治后继续生产
6. 将危险废物委托第三方处置，明知对方无资质或明显低于市场价格
7. 通过暗管、渗井、渗坑、灌注等逃避监管方式排放
8. 通过篡改、伪造监测数据的方式排放

### 五、证明共同犯罪的证据

注意审查：各犯罪嫌疑人主观上是否知道或应当知道他人实施污染环境的行为，客观上是否参与污染物收集、运输、排放、倾倒、处置等环节，或向实行犯提供资金、场地、许可证明等帮助。

### 六、证明量刑情节的证据

**法定量刑情节**
- 自首及其他发破案经过
- 共同犯罪地位、作用
- 认罪认罚
- 检举立功
- 前科劣迹

**酌定量刑情节**
- 阻挠环境监督检查或者突发环境事件调查
- 在人口集中的地区及其附近排放污染物
- 特定期间排放、倾倒、处置污染物
- 危险废物经营企业违规排放
- 案发后及时采取措施防止损失扩大、消除污染、积极修复生态环境
