## 律师办理国家核证自愿减排量CCER业务操作指引（2026试行）

**（2025年12月30日上海市律师协会通讯表决通过，试行一年）**

### 核心要点

#### 一、CCER 定义
国家核证自愿减排量（China Certified Emission Reduction），是指我国境内境外的温室气体减排项目，经国家发改委认可并登记的减排量，用于抵消碳排放。

#### 二、项目开发流程
| 阶段 | 内容 |
|------|------|
| 项目识别 | 筛选适合的减排项目类型 |
| 项目设计 | 编制项目设计文件（PDD） |
| 项目审定 | 第三方机构审定 |
| 项目备案 | 向国家发改委申请备案 |
| 项目实施 | 减排量产生 |
| 项目监测 | 按照方法学监测 |
| 减排量签发 | 申请签发CCER |

#### 三、律师服务内容
1. **项目识别与评估**：评估项目是否符合方法学要求
2. **PDD 编制**：协助编制项目设计文件
3. **审定核查**：协助选择审定机构、配合审定
4. **交易服务**：CCER 买卖合同起草、谈判
5. **合规咨询**：项目备案、减排量签发程序

#### 四、交易要点
| 事项 | 内容 |
|------|------|
| 交易场所 | 北京绿色交易所、上海环境能源交易所等 |
| 交易方式 | 挂牌交易、协议转让 |
| 注意事项 | CCER 未来可用于全国碳市场抵消 |
