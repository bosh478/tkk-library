## ❓ 常见问题

> 问：庭审的中心环节是什么？
> 答：法庭调查阶段是庭审的决定性环节，包括公诉人宣读起诉书、听取证人证言和鉴定意见、出示核实有关证据。

> 问：法官在庭审中应遵循哪些基本原则？
> 答：依法独立行使审判权、法官中立、诉辩平等、兼听则明、善于决断、安全有序。

## 正文

### 一、核心理念：从卷宗主义到庭审中心主义

传统审判模式以"卷宗主义"为主，法官主要通过阅读卷宗形成心证。以审判为中心的诉讼制度改革要求：
- 坚持严格司法原则，树立依法裁判理念
- 规范庭前准备程序，确保法庭集中审理
- 完善证据认定规则，切实防范冤假错案
- 庭审成为解决案件问题的主要场所

### 二、庭审的品性与构成

**剧场性**：庭审作为法律物理空间，是维护社会公平正义的舞台，充满仪式感。

**动态性**：
- 庭审过程的系统性
- 庭审主体之间的互动性
- 庭审信息处理的即时性和语境依赖性

### 三、庭审的基本构造：等腰正三角结构

法官居于其间、踞于其上，形成"三方组合"式结构，当事人双方平等对抗。

**基本权利**：
1. 陈述权
2. 辩论权
3. 选任辩护人权
4. 调查证据申请权
5. 对质权

### 四、庭审的五阶段

1. **庭前准备阶段**：熟悉案情、拟制庭审提纲和预案、制定工作方案、开好预备庭
2. **法庭调查阶段**：公诉人宣读起诉书、听取证人证言和鉴定意见、出示核实证据
3. **法庭辩论阶段**
4. **被告人作最后陈述阶段**
5. **评议案件与宣告判决阶段**

### 五、庭审的原则

| 原则 | 要点 |
|------|------|
| 依法独立行使审判权 | 不受行政机关、社会团体和个人的干涉 |
| 法官中立 | 不与争议事实和利益有关联，不得歧视任何一方 |
| 诉辩平等 | 诉讼手段对等 |
| 兼听则明 | 听取双方意见 |

### 六、庭审的基本要求（法官行为规范）

| 要求 | 说明 |
|------|------|
| 耐心听讼 | 给当事人充分表达机会 |
| 指挥得当 | 有效控制庭审节奏 |
| 重点突出 | 抓住案件核心争点 |
| 善于决断 | 冷静果断应对突发事件 |
| 安全有序 | 维护法庭秩序 |

### 七、庭审提纲（参考范例）

刑事一审庭审提纲包括：开庭前准备、法庭调查前准备、法庭调查（含量刑事实调查）、法庭辩论（定罪辩论、量刑辩论）、被告人最后陈述、休庭评议、宣判程序。
