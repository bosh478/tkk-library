## ❓ 常见问题

> **问：行政诉讼的受案范围有哪些？**
> 答：主要包括12类：行政处罚、行政强制措施和执行、行政许可、行政确认（土地、矿藏等自然资源权属）、征收征用及补偿决定、行政机关不履行法定职责、侵犯经营自主权/农村土地承包经营权、滥用行政权力排除限制竞争、违法集资/摊派费用、支付抚恤金/最低生活保障/社会保险待遇、行政协议（政府特许经营、土地房屋征收补偿）、侵犯其他人身权财产权。

> **问：哪些事项不属于行政诉讼受案范围？**
> 答：包括国防外交等国家行为、行政法规规章或具有普遍约束力的决定命令、行政机关对工作人员的奖惩任免、法律规定由行政机关最终裁决的行政行为。

> **问：行政诉讼中的证据规则是什么？**
> 答：被告对行政行为的合法性承担举证责任，应当在收到起诉状副本之日起15日内提交证据和规范性文件。原告需证明起诉符合条件、被诉行为存在。法院有权要求当事人提供或补充证据，也可依职权调查收集证据（须2人以上进行）。

## 概述

本指引由内蒙古自治区高级人民法院编著，人民法院出版社2021年8月出版，是人民法院审判程序指引丛书之一。全书687千字，系统规范行政诉讼各阶段程序要点。

## 体系结构

全书共六编：
1. **第一编：第一审程序** - 受案、证据、期间送达、审理、裁判
2. **第二编：第二审程序** - 一般规定、审理与裁判
3. **第三编：审判监督程序** - 再审启动、审理与裁判
4. **第四编：执行** - 诉讼案件执行、非诉执行审查
5. **第五编：裁判文书上网与案卷归档**
6. **第六编：案例汇编** - 指导性案例、公报案例

## 核心程序要点

### 一、登记立案

**立案登记形式**：当场立案、网上立案、跨域立案、巡回立案、12368热线立案

**审查内容**：
- 起诉状内容和材料是否完备
- 是否符合法定起诉条件
- 诉讼请求是否具体明确

**工作要求**：
- 对符合法定条件的起诉，当场登记立案
- 7日内决定是否立案（当场不能判定时）
- 材料欠缺须一次性告知补正内容
- 不予立案须出具书面裁定，载明理由

**恶意诉讼情形**：
1. 以危害国家安全、领土完整等为目的的起诉
2. 反复大量诉讼滋扰行政机关
3. 违反《政府信息公开条例》立法目的的诉讼
4. 明显无值得保护的实际利益
5. 请求公开已公布或已知晓的政府信息

### 二、受案范围

**受理范围**（《行政诉讼法》第十二条）：
- 行政处罚、行政强制措施和执行
- 行政许可
- 行政确认（土地、矿藏等自然资源权属）
- 征收征用及补偿决定
- 行政机关不履行法定职责
- 侵犯经营自主权、农村土地承包经营权
- 滥用行政权力排除限制竞争
- 违法集资、摊派费用
- 支付抚恤金、最低生活保障、社会保险待遇
- 行政协议（政府特许经营、土地房屋征收补偿）
- 侵犯其他人身权、财产权

**不受理范围**（《行政诉讼法》第十三条）：
- 国防外交等国家行为
- 行政法规、规章或具有普遍约束力的决定命令
- 行政机关对工作人员的奖惩任免
- 法律规定由行政机关最终裁决的行政行为

**常见问题**：
- 会议纪要：内部纪要不可诉；直接对相对人权利义务产生实际影响且外化的可诉
- 过程性行为不可诉（准备、论证、研究、层报、咨询等）
- 备案行为一般不可诉（但不排除许可、确认性质且设定权利义务的）
- 信访处理行为不可诉
- 交通事故责任认定书不可诉
- 火灾事故责任认定不可诉

### 三、管辖

**级别管辖**：
- 基层人民法院管辖第一审行政案件
- 中级人民法院管辖：海关案件、本辖区重大复杂案件、国务院部门或县级以上政府为被告的案件等

**地域管辖**：
- 被告所在地法院管辖
- 不动产案件由不动产所在地法院专属管辖

**跨行政区划改革**：
- 经最高法批准，高级法院可确定若干法院跨行政区域管辖行政案件

### 四、证据规则

**当事人举证**：
- 原告：证明起诉符合条件、被诉行为存在
- 被告：证明行政行为合法（被诉行政行为证据、依据）
- 法院有权要求当事人提供或补充证据

**调查收集证据**：
- 法官可依职权调查收集证据
- 必须2人以上进行

**鉴定、勘验、评估、审计**：
- 当事人申请鉴定，法院准许后由鉴定机构出具意见
- 勘验笔录须载明时间、地点、对象、内容

### 五、审理程序

**简易程序**：
- 事实清楚、权利义务关系明确、争议不大的案件
- 审理期限：45日
- 程序简化：一名法官独任审理

**普通程序**：
- 审理期限：6个月（可延长）
- 开庭审理，传唤当事人，公告案由、时间、地点

**规范性文件审查**：
- 原告可请求一并审查规章以下规范性文件
- 法院审查合法性，不合法的不得作为依据

**一并审理民事争议**：
- 适用于：行政许可、登记、征收、征用、裁决案件
- 当事人可在起诉时或法庭辩论终结前申请

### 六、裁判方式

| 裁判类型 | 适用情形 |
|----------|----------|
| 驳回起诉 | 不符合起诉条件 |
| 撤销判决 | 行政行为违法或明显不当 |
| 变更判决 | 行政处罚明显不当或款额认定错误 |
| 确认违法 | 撤销已无意义或需维持情形 |
| 确认无效 | 重大且明显违法 |
| 履行判决 | 行政机关不履行法定职责 |
| 给付判决 | 行政机关依法应给付义务 |
| 赔偿判决 | 行政行为造成损害 |

### 七、执行

**诉讼案件执行**：
- 依据生效判决、裁定、调解书
- 被告不履行的，原告可申请强制执行

**非诉执行审查**：
- 行政机关作出行政决定后，相对人不起诉又不履行
- 法院审查是否准予执行
