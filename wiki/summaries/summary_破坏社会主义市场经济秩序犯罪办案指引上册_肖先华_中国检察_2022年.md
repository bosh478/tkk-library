## 关键内容摘要

### 一、生产、销售伪劣商品罪（7罪名）

**罪名体系**①：
| 罪名 | 对象 |
|------|------|
| 生产、销售假药罪 | 假药 |
| 生产、销售劣药罪 | 劣药 |
| 生产、销售有毒、有害食品罪 | 有毒有害食品 |
| 生产、销售不符合安全标准的食品罪 | 不符合安全标准食品 |
| 生产、销售伪劣产品罪 | 一般伪劣产品 |
| 生产、销售不符合标准的医用器材罪 | 医用器材 |
| 生产、销售不符合安全标准的产品罪 | 不符合安全标准产品 |

> ①来源：行330（立法沿革）[^fn1]

**立案追诉标准**②：
| 罪名 | 标准 |
|------|------|
| 假药 | 只要生产、销售即构成犯罪（无需数量） |
| 劣药 | 造成人体健康严重危害 |
| 有毒有害食品 | 掺入有毒有害非食品原料 |
| 伪劣产品 | 销售额5万元以上或货值15万元以上 |

> ②来源：行330, 行332, 行1198[^fn2]

### 二、《刑法修正案（十一）》对药品犯罪修改③

**修改要点**：
- 删除了《刑法》第141条（1997-10-01 施行 / 2024-12-27 最新修正）关于假药的定义
- 增加了药品使用单位人员提供假药的规定
- 增设妨害药品管理罪（第142条之一）

> ③来源：行332[^fn3]

### 三、生产、销售假药罪

**法律条文**④：
- 《刑法》第141条（1997-10-01 施行 / 2024-12-27 最新修正） ✅：生产、销售假药的，处三年以下有期徒刑或者拘役，并处罚金；对人体健康造成严重危害或者有其他严重情节的，处三年以上十年以下有期徒刑，并处罚金；致人死亡或者有其他特别严重情节的，处十年以上有期徒刑、无期徒刑或者死刑，并处罚金或者没收财产

> ④来源：行330（修正案内容）[^fn1]

**销售金额认定**⑤：
- 已生产或已购进但尚未销售的金额
- 已售出但尚未收到的金额
- 与售出已得金额同等认定

> ⑤来源：行1198[^fn4]

### 四、生产、销售有毒、有害食品罪

**概念**⑥：在生产、销售的食品中掺入有毒、有害的非食品原料，或者销售明知掺有有毒、有害的非食品原料的食品

> ⑥来源：行2136, 行2162[^fn5]

**法律条文**⑦：
- 《刑法》第144条（1997-10-01 施行 / 2024-12-27 最新修正） ✅：在生产、销售的食品中掺入有毒、有害的非食品原料的，或者销售明知掺有有毒、有害的非食品原料的食品的，处五年以下有期徒刑，并处罚金；对人体健康造成严重危害或者有其他严重情节的，处五年以上十年以下有期徒刑，并处罚金；致人死亡或者有其他特别严重情节的，依照本法第一百四十一条的规定处罚

> ⑦来源：行2136[^fn5]

### 五、走私罪（7罪名）

**罪名体系**⑧：
| 罪名 | 对象 |
|------|------|
| 走私武器、弹药罪 | 武器、弹药 |
| 走私核材料罪 | 核材料 |
| 走私假币罪 | 假币 |
| 走私文物罪 | 文物 |
| 走私贵重金属罪 | 贵重金属 |
| 走私珍贵动物、珍贵动物制品罪 | 珍贵动物及其制品 |
| 走私普通货物、物品罪 | 普通货物物品 |

> ⑧来源：行3783[^fn6]

### 六、走私普通货物、物品罪

**概念**⑨：偷逃应缴税额10万元以上的走私行为

> ⑨来源：行3783[^fn6]

**量刑档次**⑩：
| 税额 | 刑罚 |
|------|------|
| 10万-50万 | 3年以下有期徒刑或拘役 |
| 50万-250万 | 3-10年有期徒刑 |
| 250万以上 | 10年以上有期徒刑或无期徒刑 |

> ⑩来源：行3783[^fn6]

### 七、走私废物罪

**概念**⑪：以原料利用为名，进口不能用作原料的固体废物、液态废物和置于容器中的气态废物

> ⑪来源：行2286[^fn7]

**法律依据**⑫：
- 《刑法》第152条（1997-10-01 施行 / 2024-12-27 最新修正） ✅：逃避海关监管将境外固体废物、液态废物和气态废物运输进境，构成犯罪的，依走私废物罪定罪处罚

> ⑫来源：行2286[^fn7]

### 八、走私国家禁止进出口的货物、物品罪

**概念**⑬：走私珍稀植物、珍稀植物制品等国家禁止进出口的货物、物品

> ⑬来源：行3783[^fn6]

**立法背景**⑭：
- 《刑法修正案（七）》扩大第151条第3款犯罪对象
- 从"珍稀植物、珍稀植物制品"扩大到"珍稀植物、珍稀植物制品等国家禁止进出口的货物、物品"

> ⑭来源：行3783[^fn6]
