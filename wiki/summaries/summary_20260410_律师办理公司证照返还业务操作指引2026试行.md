## ❓ 常见问题

> **问：公司证照返还纠纷中，原告主体资格如何确定？**
> **答：** 公司作为证照所有权人是适格原告。股东代表公司提起诉讼需满足：已向公司监事或监事会、董事会书面请求提起诉讼，且公司拒绝或在30日内未提起诉讼；或属于"紧急情况"若不立即起诉将导致公司利益无法弥补。有限责任公司股东、股份有限公司连续一百八十日以上单独或合计持有公司百分之一以上股份的股东可提起股东代表诉讼。

## 正文

### 一、公司证照的法律定义与范围

#### （一）证照法律定义
公司证照是指可以对外代表公司法人意志、或公司正常生产经营过程中所必不可少的执照、印章、许可证书、财务账簿和其他权属证明等物品和资料。

#### （二）证照双重属性
1. **物权属性**：属于公司法人财产权的保护对象
2. **意思表示工具属性**：公司行为能力的外部表征

#### （三）证照主要类别

**公司法人资格和特定经营资质的直接体现：**
- 营业执照、税务登记证、银行开户许可证、银行U盾及密码
- 公章、财务章、合同专用章、法定代表人印章等

**与控制公司核心资产和重大经营活动有关的特定财产资料：**
- 股东名册、章程、股东会决议
- 各类经济合同、业务合同及劳动合同
- 与生产、经营有关的土地使用权证、竣工资料等重要文件、资料

#### （四）占用证照的判断

**有权占有的判断依据：**
1. 公司章程的约定
2. 公司法定代表人的意志
3. 股东会决议或董事会决议的授权
4. 其他因执行职务等而临时授权的情形

**特别注意：** 法定代表人并非公司证照的当然保管人；在公司没有对公司证照保管形成约定或授权的情况下，依法登记的法定代表人是公司证照的法定保管人。

### 二、证照返还争议解决

#### （一）适格原告审查

1. **公司作为原告**：需提交最新营业执照、公司章程、工商登记信息等证明原告资格
2. **股东代表公司提起诉讼**：
   - 有限责任公司股东需已向监事或监事会、董事会书面请求提起诉讼，公司拒绝或在30日内未提起诉讼
   - 股份有限公司股东需连续一百八十日以上单独或合计持有公司百分一以上股份
   - 或属于"紧急情况"

#### （二）被告主体审查

| 被告类型 | 审查要点 |
|----------|----------|
| 原法定代表人 | 工商登记变更记录、曾保管证照的证据、公司要求返还的书面通知、拒绝返还的证据 |
| 原股东 | 股权转让协议、股权变更登记记录、无继续持有证照的授权文件 |
| 董事、监事、高级管理人员 | 职务任免文件、内部授权文件、拒不移交证据 |
| 公司员工 | 劳动合同、岗位说明书、离职证明、未移交证照的证据 |
| 利害关系人 | 与公司的关联或合作协议、协议终止或期限届满的证明 |

#### （三）举证责任

**原告举证目标：**
1. 证明"被告实际占有"证照：持有/交接证明、微信/短信自认证据、使用证据、身份与职责关联、经营行为关联、证人证言
2. 证明"被告无权占有"：授权终止证据、主体变更证据

**被告反驳举证：**
1. 反驳"占有"：已移交证据（交接单、公司出具的接收确认书）、证照遗失证据、"他人占有证据"
2. 反驳"无权占有"："仍有权占有"证据、"返还条件未成就"证据、"紧急保管事由"证据

### 三、证照遗失的处理

#### （一）紧急措施

1. **立即报警**：向企业所在地公安机关报案，取得《受案回执》
2. **挂失登记**：在省级以上公开发行的报刊刊登遗失和作废声明；在国家企业信用信息公示系统公告遗失和作废
3. **暂停使用**：通过企业内部系统通知全体员工原证照暂停使用

#### （二）补办证照申请材料

1. 《补办证照申请表》（需法定代表人签字并加盖公司公章）
2. 刊登遗失公告的报纸原件及公示系统公告截图
3. 公司最新的营业执照
4. 法定代表人身份证明文件
5. 经办人授权委托书及身份证明文件
6. 发证机关要求提供的其他证明文件

**风险提示：** 虚假报案或进行虚假登记挂失骗取补办公司证照的，存在被行政处罚的风险

### 四、证照被占用的救济措施

#### （一）救济途径

1. **协商解决**：与占有人进行沟通协商，明确要求返还并告知法律后果
2. **发送律师函**：正式提出返还证照的要求，设定合理返还期限
3. **申请先予执行**：在占有行为已严重影响公司正常运营或存在证照被滥用重大风险且证据充分、情况紧急时
4. **提起诉讼**：请求法院判令占有人返还证照，并可要求其承担因占用证照给公司造成的损失
5. **申请行为保全**：在诉讼过程中为防止占用人进一步转移或损毁证照

#### （二）证照被占用的分类

| 类型 | 说明 |
|------|------|
| 内部侵占型 | 董事、高管利用职务便利将保管的证照占用 |
| 离职未交型 | 员工离职时未按约定移交证照 |
| 变更拒交型 | 原法定代表人或原股东完成工商变更登记后拒绝移交证照 |
| 股东争夺型 | 公司股东矛盾激化时一方强行占有公司证照 |
| 越权持有型 | 授权期限届满或权限终止后仍继续持有证照 |
| 外部侵占型 | 合作方、客户等外部主体以"业务需要"等理由不及时归还借用的证照 |

### 五、"人章分离"的应对

#### （一）"人章分离"定义
公司的法定代表人与公司的公章、财务章、合同章、营业执照正副本等核心证照由不同主体实际控制或支配，导致法定代表人无法依其职权正常、合法地代表公司行使权利、履行义务的状态。

#### （二）"人章分离"风险
1. 公司内部治理的失衡与权力冲突
2. 对外意思表示混乱，签订的合同效力待定或引发争议
3. 公司诉讼主体资格认定困难
4. 融资与经营活动受阻
5. 可能引发行政处罚或刑事风险

#### （三）"人章分离"应对措施

1. **股东之间因争夺公司控制权发生纠纷**：遵循公司利益优先原则，基于公司登记主义，法定代表人的意志视为公司意志
2. **因公司股权转让发生纠纷**：优先根据股权转让协议完成公司的股东、法定代表人、董监高的工商变更登记
3. **及时申请补办相关公司证照资料**
4. **诉讼纠纷在所难免，积极准备起诉或者应诉**

### 六、证照合规管理建议

#### （一）证照合规管理制度内容

1. **证照清单**：明确实体证照与电子证照的具体范围，建立证照台账
2. **保管责任**：按"谁保管、谁负责"原则，明确各层级保管人的职责与安全保管义务
3. **使用流程**：设置"申请-审批-用印/用证-登记"闭环流程
4. **外借规范**：建立审批、归还期限等的外借制度，明确外借期间的保管责任与风险承担
5. **交接程序**：岗位变动时应当填写《证照交接确认单》，由监交人签字确认
6. **责任追究**：明确越权使用、遗失、拒不移交等行为的内部处罚及外部追责路径

#### （二）证照动态管理要求

1. **定期检查**：按月或按季度由合规部门联合审计部门核查证照保管情况
2. **动态调整**：当法定代表人变更、分公司撤销、关键岗位人员离职时，应尽快更新相应的证照保管文件
3. **电子留痕**：对电子证照使用实行"数字水印+操作日志"双轨记录
