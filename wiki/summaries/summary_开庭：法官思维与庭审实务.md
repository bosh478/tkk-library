## 内容结构

### 一、诉讼主张与诉讼请求篇

#### 1. 原告如何确定诉讼主张（王剑平）

**三步确定诉讼主张**：
- **第一步：厘清什么权益受损**
  - 按时间顺序，参照六要素（时间、地点、人物、起因、经过、结果）归纳事实
  - 从案件事实中提取关键词，确定法律关系
  - 根据法律关系，找出请求权基础，确定权益保护方式

- **第二步：向谁主张**
  - 根据法律关系的主体、客体和权利义务三要素确定
  - 涉及三方以上时，找出关键主张对象（法律关系的前提方）

- **第三步：如何主张**
  - 寻找最契合的法律条文
  - 确定具体的诉讼请求
  - 夯实诉讼请求所依据的事实

#### 2. 诉讼请求如何提出（任明艳）

**诉讼请求三大重要性**：
1. 起诉的前提条件
2. 决定法院的审理范围（超裁、漏裁均属程序瑕疵）
3. 影响当事人实体权益能否实现

**诉讼请求三匹配原则**：
- 与诉讼目的相匹配（明确首要诉求，考虑诉讼成本，选择最优请求权）
- 与法律关系相匹配（诉讼请求须与案件法律关系一致）
- 与诉讼理由相匹配（事实依据和法律依据须与诉讼请求有逻辑关系）

**诉讼请求三精准要求**：
1. 请求事项具有周延性（全面，不遗漏）
2. 请求内容具体化（确认之诉、形成之诉、给付之诉各有具体要求）
3. 请求事项具有可执行性（给付之诉须有具体履行内容）

#### 3. 备位诉请如何提出（叶佳）

**备位诉请**：在同一诉讼中提出主位和备位两个先后顺位的诉讼请求

**适用场景**：
- 同一行为合法性引发不同法律责任（如合法解除vs违法解除）
- 对执行能否兑现胜诉利益存在不确定性
- 对事实认定、法律定性存在疑虑

**四大误区**：
1. 主位诉请与备位诉请无先后顺序之分（必须有明确次序）
2. 备位诉请与主位诉请分属不同法律关系（须基于关联事实）
3. 备位诉请与主位诉请不存在互斥关系（须相互排斥）
4. 备位诉请可以随时提出（最迟于法庭辩论终结前提出）

#### 4. 反诉的提出与审理（成阳）

**反诉与抗辩的区别**：

| 维度 | 反诉 | 抗辩 |
|------|------|------|
| 性质 | 独立之诉 | 诉讼行为 |
| 内容 | 有实体权利义务主张 | 可为实体或程序抗辩 |
| 范围 | 可超出原告诉请范围 | 未超出原告诉请范围 |
| 目的 | 抵消、吞并原告诉请 | 否定原告诉请 |

**反诉受理条件**：
- 应在一审法庭辩论结束前提出
- 反诉当事人应限于本诉当事人范围
- 反诉与本诉须有牵连关系（基于相同法律关系、诉讼请求有因果关系、基于相同事实）

**合并审理判断标准**：本诉请求与反诉请求的成立是否相互影响（"非此即彼"关系）

### 二、庭审准备篇

#### 5. 理想的上诉状怎么写（何建）

**四大写作要点**：
1. 确定适格主体，准确表述内容（切中要害，简洁明了）
2. 厘清争议事实，指明法律依据（事实与法律的四种组合）
3. 列明程序问题，分析法律适用
4. 提供权威案例，关注类案规则

#### 6. 民事二审案件庭审准备（王韶婧）

**三大准备要点**：
1. 明确审理范围，固定上诉请求
2. 梳理案件事实，补强薄弱证据
3. 厘清法律适用争点，提供有效参考

**发回重审法定情形**：
- 原判决严重违反法定程序
- 原审未审理已提出的诉讼请求
- 必须参加诉讼的当事人未参加
- 原判决基本事实不清且二审难以查清

#### 7. 民商事案件阅卷方法（敖颖婕）

**模块化阅卷法**：
- **模块一：程序性问题**（时间轴式标记法）
  - 起诉与立案受理时间
  - 送达情况
  - 管辖问题

- **模块二：实体性问题**（金字塔式案情铺陈）
  - 顶层：主张（诉讼请求）
  - 中层：理由（请求权基础）
  - 底层：依据（证据和法律规定）

## 核心要点

### 一、诉讼请求确定的黄金法则

```
权益受损 → 法律关系 → 请求权基础 → 诉讼请求
```

关键：先厘清法律关系，再确定诉讼请求，避免"诉讼请求与法律关系不符"的致命错误

### 二、法官最看重的庭审品质

1. **逻辑清晰**：诉讼请求、事实主张、法律依据三者逻辑一致
2. **重点突出**：争议焦点明确，论述详略得当
3. **证据充分**：关键事实有证据支撑，证据链条完整
4. **程序规范**：遵守举证期限、遵守法庭纪律

### 三、常见诉讼失败原因

| 原因 | 表现 |
|------|------|
| 诉讼请求不当 | 请求与法律关系不符、遗漏请求事项 |
| 举证不力 | 关键事实无证据、证据形式不规范 |
| 程序失当 | 超过举证期限、未遵守管辖规定 |
| 法律适用错误 | 请求权基础选择错误、法律条文引用不当 |

### 四、法官释明权的运用

- **诉讼请求不明确**：法官可直接发问，引导当事人明确
- **诉讼请求不充分**：法官应释明变更或增加诉讼请求
- **诉讼请求不正确**：法官应将法律关系性质作为焦点问题审理
