# 上海律协《律师办理商业诋毁案件业务操作指引（2026）（试行）》

> **发布主体**：上海律协反垄断与反不正当竞争专业委员会
> **执笔人**：王晶、吴聪聪（上海沪通律师事务所）
> **审稿人**：林文（主任）、黄凯、陈云开、潘志成（均为专委会副主任）
> **成稿日期**：2025年7月19日

---

## 一、核心要点速览

### 1.1 商业诋毁构成要件（核心三要素）

| 要素 | 内容 |
|------|------|
| 行为主体 | 经营者（消费者不能成为行为主体） |
| 行为模式 | 编造和/或传播虚假信息或误导性信息 |
| 损害后果 | 损害其他经营者的商业信誉、商品声誉 |

### 1.2 2025年修法核心变化

| 旧法（2019） | 新法（2025） |
|-------------|-------------|
| 损害"竞争对手"的商业信誉 | 损害"其他经营者"的商业信誉 |
| — | 新增"指使他人编造、传播" |
| 要求竞争关系 | **去掉竞争关系考量** |

### 1.3 误导性信息三种类型

1. **真实但片面**：仅呈现有利部分，忽略不利信息
2. **真实但无关**：信息真实但与商业竞争力无必然联系
3. **真伪不明**：事实处于未决状态或使用歧义措辞

---

## 二、商业诋毁 vs 名誉权侵权 对比

| 对比维度 | 商业诋毁 | 侵害法人名誉权 |
|----------|----------|----------------|
| 法律依据 | 《反不正当竞争法》第11条 | 《民法典》第1024条（2021-01-01 施行 / 2021-01-01 最新修正） |
| 言论虚假程度 | 虚假或误导性信息 | 需达到侮辱、诽谤程度 |
| 归责原则 | 无过错责任 | 一般过错责任 |
| 管辖原则 | 知识产权管辖（侵权行为地+被告住所地） | 侵权结果发生地（原告住所地） |
| 救济手段 | 民事赔偿 + 行政处罚 + 刑事（商誉罪） | 民事责任（无行政/刑事） |
| 赔偿标准 | 法定赔偿，金额较高 | 法院酌定，金额较低 |
| 赔礼道歉 | 不适用（应适用消除影响） | 适用 |

## 三、律师实务要点

### 3.1 行为主体认定

- **经营者**：狭义竞争关系经营者
- **延伸主体**：
  - 具有广义竞争关系的经营者
  - 提供信息咨询服务的网络信息平台
  - 网络公关公司和"黑水军"
  - 第三方评测机构
  - 消费者保护协会

> **注意**：消费者无法成为商业诋毁的行为主体

### 3.2 传播行为认定

"传播"包括向不特定人或特定人传播：

- **案例**："供客户自取"的郑重声明 → 构成公开传播
- 网络平台主动添加标签导致误导性言论传播 → 构成商业诋毁
- 组织操纵"网络水军"进行"流量造假" → 典型商业诋毁

### 3.3 损害认定

- **不要求实际损害发生**
- 可能造成的损害也足以构成商业诋毁
- 法定赔偿依据：《反不正当竞争法》第17条第3款

### 3.4 救济途径

| 途径 | 依据 |
|------|------|
| 民事赔偿 | 《反不正当竞争法》第17条 |
| 行政处罚 | 《反不正当竞争法》第23条 |
| 刑事追究 | 《刑法》第221条（1997-10-01 施行 / 2024-12-27 最新修正）（损害商誉罪）：2年以下有期徒刑或拘役 |

## 四、典型案例裁判要旨

### 案例1：消费者无法成为商业诋毁行为主体
- 上海凯聪 vs 乔安科技案
- 观点：消费者非竞争者，不适用商业诋毁条款

### 案例2：网络平台主动添加标签构成商业诋毁
- 脉脉案（2023京73民终1258号）
- 观点："实名声明"标签超出信息存储空间服务者行为方式

### 案例3：真实但片面信息构成商业诋毁
- 林达 vs 快凯案
- 观点：选择性披露诉讼信息，隐瞒终审败诉

### 案例4：真实但无关信息构成商业诋毁
- 广药集团 vs 加多宝案
- 观点：强调与竞争无关的事实（行贿潜逃），贬低竞争对手

### 案例5：真伪不明信息构成商业诋毁
- 巧速美 vs 亚威案
- 观点：发布未生效的专利无效审查决定书，配以"侵权仿冒"标题

### 案例6：赔礼道歉不适用法人商誉纠纷
- 圣莱科特 vs 华奇案
- 观点：法人商誉纠纷应适用消除影响，不适用赔礼道歉

## 五、执业建议

1. **证据收集**：关注行为人的竞争目的、获利情况、竞争利益争夺
2. **管辖选择**：信息网络侵权的，可选择原告住所地管辖
3. **损害赔偿**：优先主张法定赔偿，金额往往较高
4. **救济组合**：民事+行政+刑事可同时主张
5. **企业风控**：协助建立商业信誉保护机制，防范商业诋毁风险
