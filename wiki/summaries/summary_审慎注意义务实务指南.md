## 正文

### 一、两罪区分的判断流程

```
第一步：行为人是否实施了非法集资行为？
    ↓ 是
第二步：行为人是否具有"非法占有目的"？
    ↓ 需要判断
第三步：是否存在司法解释规定的七种情形？
    ↓ 存在 → 集资诈骗罪
    ↓ 不存在 → 第四步
第四步：是否违反审慎注意义务？
    ↓ 违反 → 推定非法占有目的（可反驳）
    ↓ 未违反 → 非法吸收公众存款罪
```

### 二、辩护要点与法院态度

#### 辩护要点一：资金用于正当经营

**辩护策略**：
1. 提供资金流向证明，证明集资款投入了具体经营项目
2. 提供经营合同、发票、银行流水等证据
3. 提供经营成果证明（如项目完工、产品销售等）

**法院态度**：
- 如果资金确实投入经营，且经营是真实的，通常不认定非法占有目的
- 但经营投入与集资规模严重不成比例的除外

#### 辩护要点二：有还款意愿和能力

**辩护策略**：
1. 提供还款计划、还款记录
2. 提供资产证明（房产、车辆、存款等）
3. 提供担保、抵押等增信措施
4. 证明案发后积极筹措资金返还

**法院态度**：
- 有还款意愿和能力的，通常不认定非法占有目的
- 但还款意愿需要有实际行动证明

#### 辩护要点三：投资失败非挥霍

**辩护策略**：
1. 区分"投资"与"挥霍"：证明资金有对价投入
2. 证明投资行为是正常的商业决策
3. 证明投资失败是客观原因（市场变化、政策调整等）
4. 证明有风控措施

**法院态度**：
- 投资失败是商业风险，通常不认定非法占有目的
- 但全部投入高风险领域且无风控的除外

#### 辩护要点四：私募基金特殊规定

**辩护策略**：
1. 证明已完成私募基金管理人登记
2. 证明基金已完成备案
3. 证明遵守了私募基金的相关规定
4. 证明资金主要用于合同约定的投资方向

**法院态度**：
- 私募基金管理人登记和基金备案不构成对合规性的认可
- 但可以作为证明无非法占有目的的参考因素

### 三、证据审查指引

#### （一）控方需要收集的关键证据

| 证据类型 | 具体内容 | 证明目的 |
|----------|----------|----------|
| **资金流向** | 银行流水、转账记录 | 证明资金去向 |
| **消费记录** | 购房、购车、奢侈品消费记录 | 证明挥霍行为 |
| **经营证据** | 经营合同、发票、项目资料 | 证明是否有实际经营 |
| **主观证据** | 被告人供述、证人证言 | 证明主观目的 |
| **事后表现** | 还款记录、逃匿记录 | 证明事后态度 |
| **私募基金材料** | 基金管理人登记证书、基金备案证明、投资合同 | 证明私募基金性质 |

#### （二）辩方需要收集的关键证据

| 证据类型 | 具体内容 | 证明目的 |
|----------|----------|----------|
| **经营证据** | 经营合同、发票、银行流水 | 证明资金用于经营 |
| **还款证据** | 还款计划、还款记录 | 证明有还款意愿 |
| **资产证明** | 房产、车辆、存款证明 | 证明有还款能力 |
| **投资证据** | 投资合同、项目资料、风控制度 | 证明是投资行为而非挥霍 |
| **风控证据** | 风控制度、执行记录 | 证明有风控措施 |
| **私募基金材料** | 基金管理人登记证书、基金备案证明、投资人适当性材料 | 证明私募基金合规性 |

#### （三）举证质证要点

**控方举证要点**：
1. 证明集资行为存在
2. 证明资金损失存在
3. 证明推定基础事实存在（挥霍、逃匿等）
4. 证明行为人具有非法占有目的

**辩方质证要点**：
1. 质疑资金流向证据的真实性、完整性
2. 质疑挥霍行为的定性（是挥霍还是合理消费）
3. 质疑推定基础事实的证明标准
4. 提供反证证明无非法占有目的
5. 质疑私募基金管理人登记和基金备案的证明力

### 四、典型案例裁判要旨

#### 案例一：张业强等私募基金非法吸收公众存款案（检例第175号）

**裁判要旨**：私募基金管理人不得违反私募基金管理规定变相募集资金，不得通过拼接、拆分单一私募基金产品变相突破合格投资者人数限制。

#### 案例二：某基金公司、闫某某等非法吸收公众存款案

**裁判要旨**：私募基金管理人违反私募基金投资规定，以私募基金投资名义通过公开宣传的方式向不特定社会公众吸收资金，并承诺返还本息，构成非法吸收公众存款罪。

### 五、综合判断因素

| 因素 | 考虑内容 | 权重 |
|------|----------|------|
| **资金去向** | 是否用于经营、是否挥霍 | 高 |
| **还款意愿** | 是否有还款计划、是否积极弥补 | 高 |
| **还款能力** | 是否有资产、是否有担保 | 中 |
| **事后态度** | 是否逃匿、是否隐匿财产 | 高 |
| **经营状况** | 经营是否真实、是否盈利 | 中 |
| **私募基金合规性** | 是否完成登记备案、是否遵守投资规定 | 中 |
| **投资人过错** | 投资人是否尽到审慎义务 | 低 |
