### 一、完善一体化、跨区域协同履职机制

**检察一体原则：**
- 最高人民检察院领导地方各级人民检察院的工作
- 上级人民检察院领导下级人民检察院的工作
- 统一调用辖区的检察人员办理案件

**具体举措：**
1. 健全上级检察机关对下级检察机关的检查和指导机制
2. 强化案件备案实质化审查机制
3. 健全横向沟通协作机制
4. 探索实现跨区域协作办案机制
5. 强化一体推进，注重资源融合

### 二、完善自行补充侦查工作机制

**重要意义：**
- 完善证据体系，提高办案质效
- 实现权力制衡和侦查活动监督

**开展原则：**
1. 补充性原则
2. 效益原则
3. 协作原则

**健全路径：**
1. 规范细化自行补充侦查的适用
2. 激励引导检察人员正确行使自行补充侦查权
3. 持续提升检察机关自行补充侦查能力
4. 强化与监察机关、公安机关的沟通协调

### 三、完善调查核实工作机制

**内涵：**
- 狭义：对非法取证行为的调查核实
- 广义：查明案情工作和有关强制措施是否合法

**必要性：**
1. 调查核实是行使检察权的重要体现
2. 有利于核实疑问、查明事实、收集证据
3. 有利于维护和保障当事人的合法权益

**完善途径：**
1. 丰富调查核实的实施方式
2. 完善基础设施，加强技术及设施保障
3. 加强队伍建设，提升调查核实能力水平

### 四、完善指控能力建设机制

1. 完善公诉人出庭实训机制
2. 完善专家型、专门型公诉人培养调配机制
3. 完善出庭公诉质量考核评议机制
4. 完善公诉人出庭安全保障机制

### 五、深化数字检察战略

- 运用大数据发现犯罪线索
- 使用多媒体示证系统
- 完善电子证据审查规则
- 运用侦查监督与协作配合平台

## 完善与监察机关、侦查机关配合制约机制

### 一、完善提前介入工作机制

#### （一）完善提前介入监察调查工作机制

**实践价值：**
- 最大限度凝聚共识
- 有效完善案件证据

**应当把握的原则：**
1. 介入的政治性
2. 介入的限定性
3. 介入的被动性
4. 介入的时效性

#### （二）完善提前介入侦查工作机制

**主要任务：**
- 对案件涉嫌罪名、证据发现收集等提出意见
- 了解和掌握案件情况及涉案人员社会危险性
- 对侦查活动是否合法进行法律监督

**注意原则：**
- 参与不干预、参谋不代替、指导不包办
- 监督与支持并重

### 二、完善退回补充侦查工作机制

**存在问题：**
1. 退回补充侦查率较高
2. 补充侦查提纲说理性不强、可行性不高
3. 未建立跟踪监督反馈机制
4. 自行补充侦查工作开展较少

**完善路径：**
1. 发挥"捕诉一体"机制优势
2. 分析审查起诉阶段退回补充侦查原因
3. 在文书质量上下功夫
4. 建立退回补充侦查工作跟踪监督反馈机制

### 三、完善侦查监督与协作配合机制

**重要意义：**
- 推进以审判为中心的刑事诉讼制度改革的必然要求
- 构建新型检警关系的必然选择

**存在问题：**
1. 侦监协作办公室职能作用发挥不够充分
2. 检察人员业务素能有待提升
3. 信息壁垒仍不同程度存在

**完善路径：**
1. 推动共建检警大控方格局
2. 打造跟进式、预防式监督新模型
3. 打造信息互通、数字化监督中枢
4. 建立双向互动的考评机制

## 完善与审判机关配合制约机制

### 一、完善新型诉审关系

**需要把握的问题：**
1. 强化庭审活动的中心地位
2. 准确理解"以审判为中心"与"分工负责、互相配合、互相制约"的关系
3. 推动构建以公诉为主导的审前程序
4. 扎实做好检察环节的审前程序分流工作
5. 强化检察机关对审判活动的法律监督

### 二、完善以抗诉为中心的刑事审判监督机制

**理念更新：**
1. 强化对刑事审判监督工作重要性的认识
2. 不断更新抗诉理念
3. 注重从粗放监督向精准监督转变
4. 从零和思维向双赢多赢共赢转变
5. 从常态监督向典型引领转变

**具体举措：**
1. 提升能力，聚焦刑事抗诉工作重点
2. 凝聚共识，做好认罪认罚案件抗诉工作
3. 完善制度机制，形成刑事抗诉工作合力
4. 借力数字检察提升审判监督智慧化、智能化水平

### 三、完善检察长列席审判委员会制度机制

**功能价值：**
1. 检察机关履行法律监督职责的重要方式
2. 有利于案件公正审判
3. 有利于提高诉讼效率

**完善路径：**
1. 深化对制度的认识
2. 适当扩大列席案件范围

## 构建良性互动的新型检律关系

### 一、新型检律关系的内涵
"对抗而不对立、交锋而不交恶"的对立统一的合作关系。

### 二、构建新型检律关系的必要性

1. 实现依法治国的必然要求
2. 保障人权的必要措施
3. 推进以审判为中心诉讼制度改革的必要途径

### 三、构建良性互动检律关系的路径

#### （一）革新工作理念增强法律职业共同体认同
- 秉持行使法律监督职责必须接受监督的理念
- 坚持客观义务理念
- 增强法律职业共同体认同

#### （二）以更加有力的举措推动律师权利保障
- 强化诉讼中律师知情权、辩护权、申请权等权利保障
- 完善听取律师意见制度
- 健全规范保障律师执业权利的相关制度

#### （三）以积极有效的举措促进检律沟通
- 加强信息的交流
- 全面落实听取律师意见制度
- 探索聘请律师担任检察机关专家咨询委员会委员

### 四、深入推进审查起诉阶段辩护律师全覆盖试点工作

**律师辩护全覆盖发展阶段：**
1. 2017年：北京等8省市试点
2. 2018年：全国范围内试点
3. 2022年：《法律援助法》施行
4. 2022年10月：审查起诉阶段律师辩护全覆盖试点

**审查起诉阶段律师辩护全覆盖价值：**
1. 顺应庭审实质化的现实需要
2. 强化人权保障的司法举措
3. 确保认罪认罚从宽制度精准适用
4. 助推审查起诉阶段的控辩平等
