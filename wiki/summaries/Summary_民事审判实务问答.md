# 民事审判实务问答

最高人民法院民事审判第一庭编，法律出版社2021年出版。本书收录315个实务问答，涵盖民事审判实体与程序两大领域，是法官裁判参考和律师实务指引的重要资料。

## 内容结构

本书分为**实体**和**程序**两大部分，共315个问答。

---

## 第一部分：实体（Substantial）

### 一、物权（Q001-006）

| 序号 | 主题 | 核心要点 |
|------|------|----------|
| Q001 | 公证能否引起物权变动 | 不动产物权变动以登记为生效要件，公证不产生物权变动效力 |
| Q002 | 明示属于个人的绿地 | 需规划部门批准+向其他业主明示 |
| Q003 | 小区车位归属 | 规划车位归开发商；规划外新增车位归业主共有 |
| Q004 | 房屋善意取得 | 未登记不发生物权变动效力，不能善意取得 |
| Q005 | 业主表决权计算标准 | 建筑面积或使用面积均可，同一区划内统一即可 |
| Q006 | 公路桥梁收费权出质 | 属于应收账款，可依据《民法典》第440条出质 |

### 二、合同总则（Q007-033）

#### 合同当事人（Q007）
- 第三人实际履行合同：依《民法典》第522、523条判断当事人身份

| 序号 | 主题 | 核心观点 |
|------|------|----------|

| Q010 | 租赁房屋优先购买权 | 出卖人未通知承租人，承租人仅可请求赔偿，不能主张合同无效 |
| Q011 | 合同成立与生效区别 | 成立看要约承诺；生效看生效要件；两者时间上成立先于生效 |
| Q012 | 未生效与无效合同 | 未生效合同有约束力仅欠缺程序要件；无效合同自始无效 |

| Q014 | 合同未生效与无效区别 | 四方面区分：认定前提、条款效力、适用条件、法律后果 |
| Q015 | 醉酒签订合同撤销 | 法定代表人过量饮酒不能免责，公司应担责 |
| Q016 | 催收公告与诉讼时效 | 已时效届满的债权不因催收公告"起死回生" |

#### 合同的解除（Q018-021）
| 序号 | 主题 | 核心观点 |
|------|------|----------|
| Q018 | 自动解除条件 | 约定条件成就仍需通知，不能不经通知即解除 |
| Q019 | 委托合同任意解除权 | 无偿委托放弃无效；有偿委托放弃原则上有效 |
| Q020 | 解除通知效力 | 须具备法定或约定解除条件，通知方发生解除效力 |
| Q021 | 合同解除溯及力 | 原则上溯及力；继续性合同（如租赁）无溯及力 |

#### 合同的违约责任（Q022-023）
- **Q022**：违约解除后违约金条款可继续适用
- **Q023**：200万元"信誉保证金"性质认定为定金而非违约金

#### 赠与合同（Q024）
- 任意撤销权与法定撤销权的三点区别：法律依据、适用条件、法律后果

#### 旅游合同（Q025-027）
- **Q025**：旅游合同之诉可获精神损害赔偿的条件（人格权侵害+违约责任与侵权责任竞合）
- **Q026**：单方解除权不导致违约金条款无效
- **Q027**：旅行社对游客购买假冒伪劣产品一般不承担责任

#### 承揽合同（Q028）
- 定作人提出质量异议期间：显性瑕疵应即时通知；隐性瑕疵2年内提出

#### 民间借贷（Q029-033）
| 序号 | 主题 | 核心观点 |
|------|------|----------|
| Q029 | LPR4倍利率外的律师费诉讼费 | 不含在利率上限内，应予支持 |
| Q030 | 逾期利息计算基数 | 以本金为基数，不含利息 |
| Q031 | 单位内部借贷 | 用于本单位生产、经营且无法定无效情形的，有效 |
| Q032 | 自愿支付利息后反悔 | 借款人自愿支付利息不得不当得利返还请求 |
| Q033 | 以物抵偿利息 | 折算金额超过LPR4倍部分不予支持 |

## 实务要点总结

### 一、合同效力判断
1. 不动产物权变动以登记为生效要件，公证、交付占有均不能代替登记
2. 合同解除须具备实质性解除条件，通知到达对方方生效
3. 违约金条款在合同解除后可继续适用
4. 施工合同无效但工程合格，承包人仍享有工程款优先受偿权

### 二、房地产纠纷
1. 开发商逾期交房违约责任按租金标准计算，不能按银行按揭贷款利息
2. 房屋差价可作为损失请求赔偿（约定违约金低于损失时）
3. 限购政策导致合同不能继续履行，不支持继续履行但支持违约赔偿
4. 连环买卖中第三人不能直接请求开发商过户

### 三、婚姻家庭
1. 离婚协议中赠与子女条款非单纯赠与，不可撤销
2. 父母出资购房未约定视为对夫妻双方赠与
3. 夫妻共同财产一方擅自赠与全部无效，非部分无效
4. 生育权纠纷中女方有最后决定权

### 四、劳动争议
1. 用人单位不得以未办理工作交接拒绝转移档案
2. 经济补偿金年限分段计算，2008年前后分别适用
3. 临时工身份不具法律意义，按实质要件判断劳动关系
4. 提成工资争议由主张方举证，但用人单位管理证据亦须提供

### 五、程序要点
1. 证据保全错误赔偿以过错为要件，与诉讼结果不直接挂钩
2. 二审中提出时效抗辩应予审查
3. 执行异议之诉与另行起诉只能择一适用
4. 证据采纳理由须在裁判文书中阐明
