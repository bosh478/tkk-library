## 正文

### 一、公诉人出庭概述

**出庭任务**：
1. 代表国家指控、揭露和证实犯罪
2. 对法庭审判活动是否合法进行监督
3. 维护诉讼参与人的合法权利
4. 结合案情进行法治宣传和教育

**基本原则**：
| 原则 | 说明 |
|------|------|
| 系统性原则 | 出庭各环节有机衔接 |
| 关联性原则 | 证据之间、证据与事实之间、事实与法律之间相互关联 |
| 规范性原则 | 依法规范出庭行为 |
| 充分性原则 | 充分准备、充分举证 |
| 客观性原则 | 客观公正履行职责 |

### 二、公诉人出庭的基本要求

**扎实的庭前准备**：
- 积极引导侦查，提高案件质量
- 细致审查证据，强化证明效力
- 发挥庭前会议作用

**精心制作出庭预案**：
- 探求行之有效的讯问方式
- 做好相关人员出庭准备
- 科学合理布局示证体系
- 全面准确预测辩护观点
- 准备细致透彻的公诉意见
- 提出客观公正的量刑建议

**方法和技巧**：
- 层次清晰地开展法庭调查
- 扎实有效地进行法庭辩论
- 展示良好公诉形象

**稳定沉着应变**：
- 从容化解危机
- 有效应对突发事件

### 三、公诉人出庭的常见问题

| 问题类型 | 具体表现 |
|----------|----------|
| 规范性问题 | 不抬头发言、宣读起诉书不起立、发言缺乏感染力 |
| 应对能力问题 | 遇到突发情况进退失据、庭审发言激化矛盾 |
| 效率问题 | 庭审拖沓冗长、消极懈怠 |

### 四、庭前会议常见问题及应对

**庭前会议的启动与职能**：
- 庭前会议的启动程序
- 参与人员范围
- 基本职能

**常见程序问题应对**：

| 场景 | 应对要点 |
|------|----------|
| 被告人要求更换公诉人 | 依据回避和影响案件公正处理的理由处理 |
| 要求移送全部同步录音录像 | 说明出示范围依据，庭前会议不进行实质性质证 |
| 辩护人/诉讼代理人不应担任身份 | 依据《律师法》《刑事诉讼法》处理 |
| 被告人未委托辩护人，法院应指定未指定 | 依法保障被告人辩护权 |
| 要求被害人、证人出庭对质 | 根据案件情况决定是否准许 |
| 检察官助理没有庭审发言资格 | 依据《人民检察院刑事诉讼规则》处理 |
| 提出非法证据排除 | 庭前会议提出并达成一致意见的，说明线索或材料 |
| 对开庭地点提出异议 | 依据程序合法要求处理 |

### 五、宣读起诉书阶段常见问题及应对

| 情形 | 应对建议 |
|------|----------|
| 起诉书有失误 | 及时向法庭说明情况 |
| 被告人部分否认或全面否认起诉事实 | 做好讯问准备，有效衔接过渡至讯问阶段 |

### 六、出庭规范要求

**着装规范**：公诉人出庭应着制服，保持良好形象

**安全保障**：涉及危害国家安全、黑社会性质组织犯罪等案件，需做好安全保障准备
