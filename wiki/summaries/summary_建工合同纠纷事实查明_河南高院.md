## 🧠 核心方法论

### 方法 1：合同相对性原则（贯穿全文）

**基本原则**：
> 建设工程施工合同纠纷的原告一般应依据合同相对性要求合同主体承担责任，部分情况下原告主张突破合同相对性要求非合同主体承担责任，则**必须有法律法规的明确规定或债的加入等其他充分理由**。

**实务应用**：
- ✅ 原则：合同相对性
- ⚠️ 例外：法律法规明确规定（如实际施工人向发包人主张权利）

### 方法 2：事实查明三层逻辑

```
第一层：查明基础事实（合同、施工过程、效力）
   ↓
第二层：查明权利义务关系（合同关系、责任主体）
   ↓
第三层：查明实体内容（工程价款、质量、违约、损失）
```

### 方法 3：综合审查方法

**实际施工人认定**：综合 3 个维度
1. 合同签订（参与磋商 + 委托代理）
2. 资金投入（投标保证金 + 履约保证金 + 大量付款）
3. 合同履行（劳务/材料/机械 + 施工资料 + 进度款申报 + 实际参与结算）

**转包 vs 借用资质区分**：综合 5 个维度
1. 合同签订时间（先后关系）
2. 招投标情况（参与程度）
3. 总承包合同磋商/订立（代理签名）
4. 内部合同表述
5. 施工范围对比

### 方法 4：黑白合同识别

| 情形 | 结算依据 |
|------|----------|
| 工程未招投标 + 多份合同 | 签订时间在后的合同 |
| 工程招投标 + 中标有效 + 黑白合同 | **中标合同** |
| 工程招投标 + 中标无效 | 实际履行的合同 |

## ❓ 核心常见问题（FAQ）

### Q1：原告没有书面合同，能否主张工程款？

**A**：✅ **可以**，但**举证责任重大**：
- 原告须证明涉案工程**一部分或全部由其施工**
- 证明施工过程能作出合理解释
- 举证责任转移 → 由否认存在合同关系的相对方举证

**反向情形**：原告不能证明由其施工 → 主张基本不能成立（行 146-148）。

### Q2：如何区分转包/违法分包/借用资质？

**A**：综合审查 5 个维度（行 162-174）：

| 维度 | 转包/违法分包 | 借用资质 |
|------|---------------|----------|
| 合同签订时间 | 晚于总承包合同 | 早/晚于总承包合同均可能 |
| 招投标 | 承包人完成 | 实际施工人参与 |
| 总承包合同签订 | 承包人签订 | 实际施工人以承包人名义签订 |
| 施工范围 | 可能小于总承包 | 与总承包一致 |

**实务要点**：再审审判发现部分当事人/法官未作区分，**影响责任范围判定**。

### Q3：发包人在转包/违法分包情形下的责任范围？

**A**：
- 转包/违法分包：发包人在**欠付工程款范围内**向实际施工人承担责任（**不包括利息、损失**）
- 借用资质（发包人明知）：发包人承担**全部付款责任**（包括工程款 + 利息 + 停工损失赔偿）

**法理依据**：建工司法解释（一）第 43 条。

### Q4：多层转包/违法分包中，实际施工人 D 能否要求 A、B 承担责任？

**A**：
- ❌ **不能**突破合同相对性要求 A 承担责任
- ❌ **不能**将 B 视为发包人而要求 B 承担责任（建工司法解释（一）第 43 条**仅适用三方关系**）
- ✅ D 只能向其上手 C 主张合同权利
- ⚠️ 例外：C 构成对 B 的**表见代理** → B 承担责任

### Q5：固定价款合同，一方要求按定额结算，能否支持？

**A**：❌ **一般不予支持**（行 250）。

**例外情形**：
- 工程未完工 → 可委托司法鉴定
- 按合同优惠率或工程完成比计算已完工部分价款

**计算方法**：鉴定机构在同一取费标准下，分别计算已完工部分价款和合同约定工程总价款，对比计算系数。

### Q6：合同约定以政府财政审计结论作为结算依据，是否有效？

**A**：✅ **有效，对当事人有约束力**（行 262）。

**例外**：因发包人原因未审计或发包人怠于配合审计 → 承包人可通过司法鉴定结算。

### Q7：停工损失如何审查？

**A**：分 4 步（行 312-340）：
1. **停工事实**：核查停工的真实性
2. **停工原因**：归责（疫情/大气污染/政府行为/对方违约）
3. **停工损失数额**：分项审查（人员窝工 + 机械闲置 + 材料积压 + 现场管理费）
4. **合同约定条款**：审查双方对停工损失分担的约定

**特殊处理**：
- 新冠疫情：按不可抗力处理（按比例分担）
- 大气污染防控：政府行为，按比例分担
- 租赁费损失：按实际发生 + 必要性审查

### Q8：工程价款司法鉴定的关键要点？

**A**：7 个关键要点（行 358-388）：
1. **必要性审查**：是否必须鉴定（避免拖延 + 减少诉累）
2. **举证责任分配和释明**：明确鉴定事项由谁申请
3. **鉴定机构资质**：核查司法鉴定许可证 + 鉴定人执业证
4. **法院先行确定事项**：合同效力 + 工程是否合格 + 工程范围
5. **鉴定事项审查**：避免重复鉴定 + 超出申请范围
6. **鉴定材料提供**：双方质证 + 法院确认
7. **工程质量鉴定**：特殊要求（鉴定机构资质 + 现场勘验）
