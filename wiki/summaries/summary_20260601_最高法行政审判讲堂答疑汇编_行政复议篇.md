# 最高人民法院"行政审判讲堂"答疑汇编（行政复议篇）

> **发布主体**：最高人民法院行政审判庭
> **整理人**：刘万金（山东省东平县人民法院原审判委员会专职委员、四级高级法官，山东省首届审判业务专家）
> **发布时间**：2026年5月10日

---

## 一、核心要点速览

### 1.1 复议机关被告资格认定

| 情形 | 被告资格 |
|------|----------|
| 复议机关仅改变法律规范，未改变处理结果 | 共同被告 |
| 复议机关改变处理结果 | 单独被告（复议机关） |
| 复议机关确认违法（非程序违法） | 单独被告（改变原行为） |
| 复议机关以违反法定程序为由确认违法 | 共同被告 |

### 1.2 复议前置范围

| 行政行为类型 | 是否复议前置 |
|--------------|--------------|
| 土地确权决定 | ✅ 是 |
| 土地征收决定 | ❌ 否 |
| 责令交出土地决定 | ❌ 否 |
| 没收土地使用权决定 | ❌ 否 |

### 1.3 非诉执行期限计算

- **起算点**：起诉期限 + 复议期限均届满之日
- **申请期限**：期限届满之日起 3 个月内
- **注意**：单行法仅规定起诉期限的，仍需等待复议期限届满

## 二、十问十答精要

### 问题1：复议机关确认违法的被告认定

**核心规则**：确认违法决定原则上属于"改变行政行为"，复议机关作单独被告。

**判断标准**：
- 复议机关认为原行为适用依据不合法应撤销
- 但撤销会给国家利益/社会公共利益造成重大损害
- 故决定确认违法 → 属于改变原行为 → 复议机关单独被告

### 问题2：受票企业行政复议申请人资格

**核心规则**：以税务处理决定是否影响受票企业权利义务为判断标准。

**一般情形**：
- 税务处理决定 → 受票企业取得的增值税专票不能抵扣进项税额 → 有利害关系 → 有权申请复议

**例外情形**：
- 有充分证据证明受票企业符合例外情形 → 税务处理决定不影响权利义务 → 无权申请复议

**实务要点**：对复议申请人资格不宜严格限制，应发挥行政复议"低成本、高效率、宽口径"的制度优势。

### 问题3：土地处理决定复议前置问题

**核心规则**：只有土地确权决定须复议前置，其他土地处理决定不须复议前置。

**复议前置条件**：
- "已经依法取得" = 拥有所有权/使用权证书，或已实际使用多年并有证据
- "决定" = 对自然资源权属的确权决定（不含行政许可、行政处罚、行政强制）
- "确认" = 针对权属争议的确权决定（不含初始登记）

### 问题4：限期拆除非诉执行期限

**核心规则**：行政机关申请强制执行，须在起诉期限、复议期限均届满后进行。

**期限计算**：
- 起诉期限：《土地管理法》第83条规定为 15 日
- 复议期限：《行政复议法》规定一般为 60 日
- 申请执行期限：两期限均届满之日起 3 个月内

**注意**：《土地管理法》第83条未剥夺申请行政复议的权利。

### 问题5：行政协议约定排除行政复议的效力

**核心规则**：行政协议中约定排除行政复议的，一般不宜认可其法律效力。

**理由**：
1. 行政复议申请权是公法救济权利，不能通过合同约定预先排除
2. 约定排除复议意味着排除复议机关监督，违背立法宗旨
3. 法定复议前置情形下，可能导致相对人无法通过行政诉讼获得救济
4. 行政协议效力具有"外溢性"，第三人仍可申请复议

### 问题6：复议机关自行撤销复议决定的可诉性

**核心规则**：复议机关自行撤销复议决定属于行政行为，可提起行政诉讼。

**要点**：
- 自行撤销复议决定 = 作出否定原复议决定的新的行政行为
- 只要权利义务产生实际影响，即可提起诉讼
- 第三人权利受不利影响的，也有权起诉
- 撤销后复议决定自始不生效力，复议机关应及时作出新决定

### 问题7：复议调解书的强制执行

**核心规则**：复议调解书具有法律效力，当事人不履行的，可依法强制执行。

**执行方式**：
| 情形 | 执行主体 |
|------|----------|
| 复议机关有法定强制执行权 | 复议机关依法强制执行 |
| 复议机关无强制执行权 | 申请人民法院强制执行 |

**程序参考**：《行政强制法》第五章、《行诉解释》第十二节"执行"

### 问题8：复议驳回后起诉原行政行为

**核心规则**：非复议前置情形，复议机关驳回复议申请后，当事人可就原行政行为提起行政诉讼。

**期限扣除**：
- 复议期间属于"不属于自身原因耽误起诉期限"的情形
- 复议期间不计算在法定起诉期限内

**依据**：《行政诉讼法》第48条（1989-04-04 施行 / 2017-06-27 最新修正）第1款、法释〔2026〕3号第4条第2款

### 问题9：赔偿复议决定的诉讼策略

**核心规则**：当事人不服赔偿复议决定，可直接针对赔偿争议提起行政赔偿诉讼。

**两种路径**：
| 路径 | 优劣势 |
|------|--------|
| 起诉复议决定 | 程序繁琐，难以直接解决赔偿争议，易循环诉讼 |
| 起诉赔偿义务机关 | 救济效果更直接 |

**起诉期限**：自复议决定书送达之日起 15 日内

### 问题10：禁止不利变更原则的适用限制

**核心规则**：《行政复议法》第63条第2款禁止不利变更原则有适用限制。

**不适用情形**：
1. 申请人与第三人均对行政行为提出异议
2. 行政行为无效（自始无公定力）

**重新作出行为的例外**：
- 原行政行为适用法律错误
- 重新作出行为的事实基础与原行为不同

## 三、实务要点汇总

### 3.1 复议机关被告资格判断流程

```
复议决定类型
├── 维持原行为 → 共同被告
├── 改变处理结果 → 单独被告（复议机关）
├── 改变法律规范但未改变结果 → 共同被告
└── 确认违法
    ├── 以违反法定程序为由 → 共同被告
    └── 以适用依据不合法为由 → 单独被告
```

### 3.2 非诉执行期限计算公式

```
可申请执行日期 = max(起诉期限届满日, 复议期限届满日)
申请执行截止日 = 可申请执行日期 + 3个月
```

### 3.3 复议期间起诉期限扣除

- 当事人申请复议 → 积极行使救济权 → 主观无拖延意图
- 复议期间客观上不得就同一事项提起诉讼 → 非自身原因耽误
- 结论：复议期间不计算在起诉期限内
