# 机动车交通事故责任纠纷案件的审理思路与要点丨办案心法

> 上海市奉贤区人民法院王卫民副院长、张慧法官、梅杨助理系统梳理机动车交通事故责任纠纷案件的审理流程与赔偿标准。

## 文章信息

- **供稿法官**: 王卫民、张慧、梅杨
- **所属法院**: 上海市奉贤区人民法院
- **专业领域**: 民事
- **来源**: 上海高院"办案心法"栏目

## 一、审查诉讼材料与鉴定程序

道交案件大多需鉴定，收到案件后应先审查：
- 有鉴定申请的联系原告提交材料组织鉴定
- 无鉴定申请的查看诉状判断是否已鉴定：已鉴定的关注被告是否有重新鉴定申请；未鉴定的主动询问是否申请
- 鉴定一般针对"三期"（营养期、护理期、休息期）和伤残等级
- 先要求伤者提交病史材料，组织质证排除无关伤病材料，再移送鉴定机构

## 二、诉讼主体与理赔顺序

### 诉讼参与人
常规主体：被侵权人、驾驶员、交强险及商业险保险公司。驾驶员与所有人不一致时，所有人或管理人应纳入；挂靠车辆的被挂靠公司也应纳入。

### 理赔三步法

**第一步，查保单**：交强险先行赔付。现行限额：医疗费项目18,000元、伤残赔偿项目180,000元、物损项目2,000元。

**第二步，查事故**：交强险不足部分由商业险按事故责任比例赔付。需查明是否存在保险免责情形（逃逸、醉酒等）。

**第三步，查赔偿主体**：未投保交强险、商业险免责或保险不足时，由侵权人赔偿。投保义务人（车辆所有人及管理人）也是赔偿主体；挂靠人与被挂靠人承担连带责任。

## 三、损失金额及赔偿比例

### 损失项目及标准（上海2024年适用）

| 项目 | 标准 |
|------|------|
| 医疗费 | 发票金额，扣除医保统筹及住院伙食费 |
| 住院伙食补助费 | 20元/天×住院天数 |
| 营养费 | 20-40元/天×营养期 |
| 护理费 | 40元/天至3,373元/月×护理期 |
| 误工费 | 月均收入×休息期-实际收入 |
| 伤残赔偿金 | 上年度城镇居民人均可支配收入×伤残系数×年限（2024年标准89,477元） |
| 丧葬费 | 上年度职工月均工资×6个月（2024年标准12,183元） |
| 被扶养人生活费 | 上年度城镇居民人均消费支出×扶养年限×扶养系数（2024年标准54,919元） |
| 精神损害抚慰金 | 5万元×伤残系数 |
| 残疾辅助器具费 | 依据处方和发票 |
| 交通费/衣物损失 | 酌定 |
| 车辆修理费 | 依据票据 |
| 鉴定费/评估费 | 依据票据（属于商业险赔付范围） |
| 律师费 | 依据票据酌定 |


### 赔偿比例

交强险限额内全额赔付（不分责任比例），限额外按责任比例赔付：
- 机动车全责：赔付100%
- 机动车主责：赔付80%
- 同等责任：机动车赔付60%
- 机动车次责：赔付40%
- 机动车无责：交强险无责限额赔付（医疗费1,800元、伤残18,000元、物损100元）

法律依据：《民法典》第1213条、《道路交通安全法》第76条。
