## 概要

本文是上海高院发布的案外人执行异议之诉中另案生效法律文书可否排除强制执行的司法认定要点，围绕权属纠纷与债权纠纷的确权判决、排除执行效力及例外情形展开系统阐述。

## 核心问题

案外人执行异议之诉的实质：
1. 案外人与被执行人对执行标的的纠纷
2. 案外人对执行标的所享有权益与申请执行人在生效裁判文书等执行依据项下请求权的**优先效力**纠纷

## 要点一：可排除强制执行的情形

### 一、可排除执行的民事权益类型

| 权益类型 | 说明 |
|----------|------|
| **物权** | 所有权、用益物权（地役权等） |
| **担保物权** | 对特殊财产的担保物权（法律或司法解释赋予） |
| **不动产租赁权** | 债权物权化，可对抗第三人 |
| **物权期待权** | 如预告登记的房屋债权 |

### 二、审查依据：《执行异议和复议规定》第26条

| 时间节点 | 情形 | 处理 |
|----------|------|------|
| **查封前**作出的另案生效法律文书 | 权属纠纷（物权纠纷） | **支持**排除执行 |
| | 保管、租赁、借用等债权纠纷（返还标的物） | **支持**排除执行 |
| | 其他债权纠纷（交付、返还执行标的） | **不支持**排除执行 |
| | 拍卖/变卖成交裁定、以物抵债裁定（权利能排除执行） | **支持**排除执行 |
| **查封后**作出的另案生效法律文书 | 无论何种情形 | **不支持**排除执行 |

### 三、确权判决性质判断要素

| 判断要素 | 说明 |
|----------|------|
| 诉的类型 | 债权纠纷、物权纠纷还是其他 |
| 请求权性质 | 物权、债权还是其他权利 |
| 案外人身份 | 与执行标的的关系 |
| 判决查明的具体事实 | 对价给付、流转过程、权利变更等 |

### 四、股权转让案件特殊规则（新《公司法》第86条）

**股权变动时点**：受让人自**记载于股东名册时**起可以向公司主张行使股东权利

**判断规则**：
- 股东名册记载变更前 → 仍为债权纠纷，不能排除执行
- 股东名册记载变更后 → 已取得股权，基于权属纠纷，可排除执行

## 要点二：排除强制执行的例外因素

### 一、信赖保护原则（商事外观主义）

**适用条件**：
- 申请执行人对执行标的具有**信赖利益**
- 属于**交易领域**（非普通债权）

**注意**：普通债权（如民间借贷纠纷）不适用商事外观主义，不存在交易中的信赖利益

### 二、恶意串通规避执行

**风险点**：
- 被执行人与案外人恶意串通
- 通过确权诉讼将查封、冻结财产确权给案外人
- 借助诉讼拖延执行

**特征**：
1. 确权诉讼中申请执行人未参与，无法发表意见
2. 当事人陈述高度一致
3. 确权法院与执行法院不同
4. 可能存在地方保护

**处理**：
- 查封后作出的法律文书 → 不能排除执行
- 伪造证据、恶意串通 → 民事权益不足以排除执行

---

## 要点三：典型案例

**云南某公司案**：
- 2014年1月：签订股权转让协议并支付款项
- 2014年5月：修改公司章程，记载云南某公司为股东（未办变更登记）
- 2015年6月：昆明中院判决确认股权归云南某公司所有
- 2015年10月：内蒙古某公司因民间借贷纠纷被诉，股权被冻结
- 2018年10月：继续冻结
- **结论**：因股东名册已变更，云南某公司已取得股权，判决属权属纠纷确权，可排除执行
