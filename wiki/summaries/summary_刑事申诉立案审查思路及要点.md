## 概要

本文是上海高院发布的刑事申诉立案审查指南，从申诉主体、申诉材料、申诉期限、申诉事由、管辖权限五个核心维度，梳理刑事申诉案件立案审查的思路及要点。

## 核心框架：五维审查

| 维度 | 内容 |
|------|------|
| 一 | 申诉主体资格审查 |
| 二 | 申诉材料审查 |
| 三 | 申诉期限及层级审查 |
| 四 | 申诉事由审查 |
| 五 | 管辖权限审查 |

---

## 一、申诉主体资格审查

### 核心申诉主体

| 主体 | 说明 |
|------|------|
| 当事人 | 被害人、自诉人、被告人、附带民事诉讼原告人和被告人 |
| 法定代理人 | 针对无/限制民事行为能力人行使代理权 |
| 近亲属 | 配偶、子女、父母、同胞兄弟姐妹 |

**注意**：除法定近亲属外，其他亲属不具有申诉主体资格，但可依法代理申诉。

### 特殊主体

| 主体 | 说明 |
|------|------|
| 案外人 | 认为生效裁判侵害其合法权益可申诉 |
| 律师代理人 | 需提交授权委托书、执业证书、律所函 |

### 重点审查情形

1. **主体资格转移**：当事人死亡后，近亲属可继续提出申诉
2. **冒用他人名义**：直接不予受理
3. **多重主体重复申诉**：正在进行可并案；已处理过，除新事实外可不予受理
4. **被害人特殊权限**：请求加重刑罚应向检察机关申请抗诉，法院一般不得自行启动再审加重刑罚

## 二、申诉材料审查

### 必备基础材料

| 材料 | 要求 |
|------|------|
| 申诉状 | 载明身份信息、联系方式、申诉请求、事实与理由，签名盖章捺印 |
| 身份证明 | 自然人提交居民身份证；法人提交营业执照、法定代表人证明 |
| 生效法律文书 | 一审/二审判决书、裁定书；复查、再审相关文书 |

### 新证据材料

**"新证据"认定**：
- 与原审定罪量刑事实相关
- 相对于原审法院为"新"
- 具备真实性、合法性、关联性
- 八种法定证据种类均可
- 游离于法定种类但能证明原裁判错误的材料也可纳入

### 委托代理材料

- 授权委托书（明确代理权限）
- 代理人身份证明
- 律师：执业证书、律师事务所函
- 公民代理：关系证明、法定代理资格

---

## 三、申诉期限及层级审查

### 申诉期限

- 司法实务中一般不得简单以超过期限为由拒绝受理
- 该期限仅作为立案审查的参考因素

### 申诉法院层级

**基本原则**：申诉人对已生效判决、裁定提出申诉，应当首先向作出生效裁判的人民法院提出。

**层级规则**：
1. 向作出生效裁判的法院提出
2. 申诉被驳回后，可向上一级法院提出
3. 上级法院可交下级法院审查，或直接审查
4. 未经终审法院审查处理直接向上级申诉的，告知向下级提出

**注意**：符合条件的申诉人被驳回后均可依次向上一级法院申诉，不得因多次多层级申诉而简单拒绝受理。

## 四、申诉事由审查

### 可立案复查的法定事由

#### 1. 认定事实确有错误

- 主要事实不清、证据不足
- 定罪量刑核心证据缺失、矛盾无法排除
- 认定事实与客观事实不符，遗漏重要事实
- 有新证据证明原判认定事实确有错误且可能影响定罪量刑

**区分**：事实认定错误 vs 证据瑕疵（轻微瑕疵不影响主要事实认定的，做好沟通工作）

#### 2. 适用法律确有错误

- 适用法律条文与案件事实不符，罪名认定错误
- 适用的法律条文已失效或未生效
- 量刑不当（未考虑法定从轻减轻情节或量刑超出法定幅度）
- 违反法律适用规则（应适用上位法、特别法却适用了下位法、一般法）

**区分**：法律理解分歧 ≠ 法律适用错误

#### 3. 诉讼程序严重违法

- 违反管辖规定、回避规定
- 剥夺或限制当事人法定诉讼权利
- 审判组织组成不合法
- 非法取证、庭审程序严重违法

**区分**：严重程序违法 vs 轻微程序瑕疵

#### 4. 办案人员违法违纪

- 贪污受贿、徇私舞弊、枉法裁判行为

**要求**：需提交证据线索证明违法违纪行为与原审判决错误存在直接关联

### 刑事附带民事案件特殊规则

- 仅就附带民事部分申诉的，一般不予再审立案
- 除外情形：有证据证明民事部分明显失当且原审被告人有赔偿能力
- 原审附带民事已调解，刑事再审后若调解违反自愿原则或内容违法，可对附带民事一并再审

---

## 五、管辖权限审查

### 法检管辖分工

- 申诉人可向法院或检察院提出申诉（非选择排斥关系）
- 同时向双方申诉的：由先收到材料的机关先行受理
- 后收到材料的机关暂缓受理，先受理机关处理完毕后申诉人仍不服的，另一机关再予受理

### 特殊情形

- 上级法院可径直办理下级管辖的申诉案件
- 上级法院可交下级法院办理本院管辖的申诉案件

---

## 审查理念

| 理念 | 说明 |
|------|------|
| 客观公正 | 以事实为依据、以法律为准绳 |
| 有错必纠 | 维护司法公正 |
| 权益保障 | 摒弃机械适用期限、层级的做法 |
| 实质审查 | 五维度全面细致审查 |
