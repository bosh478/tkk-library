## 核心观点

### 573-580. 一般不动产买受人的权利不能对抗优先受偿权

| 情形 | 结论 |
|------|------|
| 普通物权期待权 vs 建设工程价款优先受偿权 | 不能对抗 |
| 新增建筑物不属于抵押财产 | 不能排除对抵押建设用地使用权及新增建筑物的执行处分 |
| 非消费者购房人 vs 抵押权人 | 不能排除抵押权人的强制执行 |
| 一般不动产买受人 vs 担保物权 | 不能对抗担保物权的优先受偿权 |
| 物权期待权 vs 担保物权 | 不能排除担保物权人申请的强制执行 |

### 581-600. 特殊情形不能排除执行

| 序号 | 情形 | 原因 |
|------|------|------|
| 581 | 冻结到期债权后，次债务人以新增债权提出抵销 | 停止执行 |
| 582 | 股权受让未经工商登记 | 不能排除强制执行 |
| 583 | 借用人与出借人的煤矿采矿权约定 | 不能排除强制执行 |
| 584 | 房产代持协议 | 不具有物权变动效力，不能排除执行 |
| 585 | 执行标的被查封后案外人依据另案生效裁判提出异议 | 不予支持 |
| 586 | 案外人依据另案生效裁判对非金钱债权的执行提起异议 | 应通过其他程序解决 |
| 587 | 次债务人在冻结债权法律文书生效后以履行另案法律文书为由提出异议 | 可以阻却执行 |
| 588 | 借用资质开发房地产中的借用人 | 不能排除执行 |
| 589 | 房屋被查封后转卖、合同倒签或改底单 | 需审查第一手购房人是否符合排除条件 |
| 590 | 以购买车位为由主张排除抵押权人执行 | 不符合商品房消费者优先保护规定 |
| 591 | 另案查封之后签订不动产买卖合同 | 不能排除执行 |
| 592 | 未取得预售许可证签署的商品房买卖合同 | 不得排除执行 |
| 593 | 以民事调解书形式达成的以物抵债协议 | 不能排除强制执行 |
| 594 | 房屋备案登记（非预告登记） | 不能产生物权效力，不可排除强制执行 |
| 595 | 以物抵债权利人 | 不能排除一般债权人的执行 |
| 596 | 买受人仅要求扣除使用价值的处置措施 | 不能排除执行 |
| 597-598 | 期待权阻却执行的要件 | 未支付价款、未占有房屋且有其他用于居住的房屋，不享有足以排除执行的民事权益 |
| 599 | 售后回租合同中买受人未形成事实上的管理、控制 | 不能排除执行 |
| 600 | 认购协议书不符合法律法规规定 | 不能依据第29条排除执行 |

### 601-620. 更多不能排除执行的情形

| 序号 | 情形 | 结论 |
|------|------|------|
| 601 | 小区商铺买受人物权期待权 | 不能排除被抵押商铺的强制执行 |
| 602 | 故意将房屋交由他人代持 | 不享有排除强制执行的民事权益 |
| 603 | 为担保债权实现而办理的预告登记 | 不能排除执行 |
| 604-606 | 误汇款后的不当得利请求权 | 不能阻却款项的执行 |
| 607-608 | 误划至被执行人账户的款项 | 不应支持排除强制执行 |
| 609 | 所有权保留中的取回权行使有障碍 | 不足以排除执行 |
| 610-612 | 账户借用 | 借名账户为被执行人实际控制使用的，可以执行 |
| 613 | 借名买房规避限购政策 | 不能排除对房屋的执行 |
| 614 | 依据民事调解书取得财产物权请求停止执行 | 不予支持 |
| 615 | 未作房屋初始登记的执行标的物主张所有权 | 不予认可 |
| 616 | 明知房屋未依法登记取得房产证依旧受让 | 不能排除强制执行 |
| 617 | 仅依据以房抵债协议主张排除强制执行 | 不能支持 |
| 618 | 隐名股东 | 不能对抗名义股东的债权人对该股权申请强制执行 |
| 619 | 投资收益分配请求权 | 是普通债权，不能排除强制执行 |
| 620 | 显名股东的债权人申请执行代持股份 | 有权申请 |

### 621-628. 特定类型不能排除执行

| 序号 | 情形 | 结论 |
|------|------|------|
| 621 | 显名股东的债权人 | 有权申请执行显名股东代持的股权 |
| 622-624 | 隐名股东与显名股东关系 | 隐名股东不能依据内部约定对抗申请执行人；登记具有公信力 |
| 625 | 父母离婚协议约定房屋归子女但未过户 | 子女不能以此对抗强制执行 |
| 626 | 挂靠转包分包情形下的实际施工人 | 不能排除强制执行 |
| 627 | 以物抵债协议达成后债权人未实际受领抵债物 | 不能对抵债物排除强制执行 |
| 628 | 执行款计算方法错误 | 案件终结执行后提出申诉不予支持 |
