## ❓ 常见问题

> 问：阅卷只是简单地阅读案卷文字吗？
> 答：不是。阅卷是法官"输入"案件事实信息的重要渠道，需要把握案件事实、证据关联、法律适用，是认知建构的过程。案卷材料的多少、装订排列、建構性均影响法官认知的范围、效率和真实性。

> 问：阅卷的核心任务是什么？
> 答：逐一审读吃透案情，既审事实又审法律，立足案情延伸案外。具体包括核实被告人基本情况、案件侦破情况、管辖、控辩双方意见、犯罪事实及认定依据。

> 问：阅卷笔录有什么作用？
> 答：把疑难复杂案件的案卷变薄，反映案件概况，进行阅卷归纳，为审理报告制作提供依据，让阅卷笔录成为审查报告的草稿。

## 核心要点

### 一、案卷的品性与构成

#### 1. 案卷材料的三大构成

| 类别 | 内容 |
|------|------|
| 证据材料 | 物证、书证、证人证言、被害人陈述、被告人供述和辩解、鉴定意见、勘验检查辨认笔录、视听资料、电子数据 |
| 法律文书 | 起诉意见书、起诉书、判决书等对案件事实起固定化作用的文书 |
| 控辩意见材料 | 辩护词、公诉意见、专家意见书、出庭意见等 |

#### 2. 案卷的认知特点

- **数量影响认知范围**：案卷多少直接影响法官认知的信息量
- **装订排列影响认知效率**：符合法律专业规律的排列顺序便于快速获取信息
- **建构性影响认知真实性**：案卷材料经过多方主体加工，法官二手感知容易偏离客观真相

#### 3. 司法认知的三种指向

| 指向 | 说明 |
|------|------|
| 事实指向 | 对案卷、现场、庭审、证言的认知 |
| 法律指向 | 对法条的认知（因个体知识结构、经验而异） |
| 社会指向 | 对社会的认知（主观印象的人格特色） |

### 二、阅卷的功能

#### 功能一：掌握证据、熟悉案情

- 掌握证据材料的物理状况（卷宗数、页数、种类）
- 掌握有无涉密材料错误装订（防止泄密）
- 掌握定案的证据状况
- 掌握量刑的证据状况（自首、立功、赔偿、谅解等）
- 掌握有利于被告人的证据状况

#### 功能二：简化卷宗、方便办案

- 为提讯被告人提供依据
- 为庭审讯问提供依据
- 为审理报告制作提供依据

#### 功能三：发现疑点、精准审查

- 发现被告人身份疑点（冒用他人身份）
- 发现案件侦破疑点（破案过程和方法）
- 发现定案的证据疑点（排除合理怀疑）
- 发现量刑的证据疑点（自首、立功等情节）

#### 功能四：确定思路、明确方向

- 为庭前准备提供依据
- 为庭审质证做好准备
- 为案件审理指明方向

### 三、阅卷的主要任务

#### 任务一：逐一审读、吃透案情

**（一）审查核实被告人基本情况**
1. 户籍证明情况（姓名、出生年月日、籍贯、文化程度等）
2. 强制措施情况（刑事拘留、逮捕、取保候审的时间地点）
3. 受审能力情况（身体条件、语言、宗教信仰）
4. 委托辩护人情况（委托手续、执业资格）
5. 赔偿能力及家庭成员情况

**（二）审查核实案件侦破及抓获经过**
- 受案登记表、破案登记表
- 专门的侦破报告或情况说明（重点审查内容）
- 相关证人证言及被告人首次供述

**（三）审查核实案件管辖**
- 犯罪地管辖（《刑事诉讼法》第25条（1979-07-01 施行 / 2018-10-26 最新修正））：犯罪预备地、犯罪行为实施地、犯罪结果发生地、销赃地
- 被告人居住地管辖：流窜作案、民愤大、可能判处缓刑等情形
- 共同管辖的移送或指定（《刑事诉讼法》第26、27条）

**（四）审查把握控辩双方主要意见**
- 公诉机关的指控内容（罪名、事实、情节、诉讼请求）
- 被告人的供述和辩解
- 辩护人的主要辩护观点

**（五）审查核实犯罪事实及认定依据**
1. 现场勘查笔录、物证等客观性证据
2. "言词证据"与客观性证据的印证情况
3. 被告人供述的变化情况及印证（"先证后供"vs"先供后证"）
4. 辨认、指认笔录及印证情况

#### 任务二：既审事实、又审法律

| 方式 | 说明 |
|------|------|
| 以事实为重心 | 在事实指引下寻找规范 |
| 以规范为重心 | 在规范指引下"建构"事实、"筛选"事实 |
| 事实与规范交错 | 设证、类比、解释等方法交替进行 |

#### 任务三：立足案情、延伸案外

- 了解被告人方面的信息
- 了解被害人方面的信息
- 了解当事人诉讼的原因与动机
- 了解有无调解可能
- 了解是否存在外部干预
- 了解案件处理的社会效果

### 四、阅卷的形式与种类

| 形式 | 说明 |
|------|------|
| 承办法官单独阅卷 | 庭前阅卷、庭上阅卷（以必要为条件）、庭后阅卷（全面性、精准性、针对性） |
| 合议庭成员共同阅卷 | 分工阅卷（按罪名/犯罪事实/被告人分工）、交叉阅卷 |
| 全面阅卷与重点阅卷 | 逐一阅卷（逐卷/逐份/逐罪）、按内容重点阅卷、按任务补充阅卷、按疑点反复阅卷 |
| 程序性审查与实质性审查 | 程序性问题（来源、自然状况、时间、强制措施、证据收集）、实体性问题（主观性证据审查、客观性证据审查） |

### 五、阅卷的技巧与方法

#### 技巧一：全貌意识——全面阅卷，防止信息遗漏

- 审阅全部卷宗材料，不遗漏每一页
- 增强宏观意识，尽量恢复案件原貌（不受被害人陈述、起诉意见书、起诉事实范围的限制）
- 整体性考虑，证据逐一审查与综合判断相结合
- 透过现象看本质，不被表象所迷惑

#### 技巧二：关键行为决定定性

- **主干行为决定定性**：犯罪主体、主观方面、客观方面、客体
- **目的行为决定定性**
- **关键手段决定定性**
- **重行为决定定性**

#### 技巧三：边阅卷边讨论

讨论途径：法官会议讨论、向上级请示、适时提讯被告人
讨论益处：弥补阅卷遗漏、修正阅卷思路、调整阅卷重点、提高阅卷效率

#### 技巧四：围绕犯罪构成要件展开阅卷

将案件事实准确归入法律规范，围绕犯罪构成要件所涵摄的事实要素确定重点

#### 技巧五：分层次分步骤"通读""精读""深读"

| 阶段 | 内容 |
|------|------|
| 初入卷面 | 总揽全局（审查卷宗数、案号、案情基本情况） |
| 通读案卷 | 搭建框架（通读目录、主要法律文书、庭审笔录、主要证据） |
| 精读案卷 | 填充细节（抓重点、围绕证据"三性"精细审查、综合分析反思） |
| 深读案卷 | 发现矛盾 |
| 掩卷沉思 | 形成判断 |

### 六、阅卷笔录的制作

#### 总体要求

1. **反映案件概况**：受理基本情况、诉讼参与人情况、侦破抓获经过、案情事实及证据、争议情况、需说明情况
2. **有阅卷归纳**：事实证据审查结论、存在问题、开庭重点和方法、上诉辩护理由、阅卷看法和结论
3. **字迹清楚**

#### 按犯罪事实细分

| 情形 | 方法 |
|------|------|
| 犯罪次数不多 | 集中摘录法（先供后证法/先证后供法/对照法） |
| 犯罪次数多 | 分别摘录法（逐次摘录顺序阅卷法+表格法） |
| 多人多次犯一罪 | 逐人摘录、逐次摘录 |
| 多人多次犯数罪 | 逐罪制作、逐人制作、逐次制作 |

#### 按案卷多少细分

| 情形 | 方法 |
|------|------|
| 案卷多 | 逐卷制作 |
| 案卷少 | 逐笔制作 |

### 七、典型案件的阅卷审查要领

#### 命案审查要点

1. 案件线索来源是否清楚，证据是否确实充分
2. 被害人身份是否清楚（DNA鉴定、辨认笔录）
3. 被告人身份是否清楚
4. 犯罪事实是否清楚
5. 量刑情节是否清楚
6. 关联事实是否清楚

#### 重大毒品犯罪案件审查要点

1. 被告人主体身份情况
2. 被告人主观上是否具有毒品犯罪故意（"贩卖目的"、"明知"的审查）
3. 毒品犯罪的客观方面（言词证据、物证书证、勘验检查辨认笔录、鉴定意见、视听资料和电子数据）

#### 盗窃犯罪案件审查要点

1. 立足一般证据规格
2. 立足盗窃犯罪特点
3. 立足盗窃犯罪案件的证据特性
4. 立足"五类盗窃"的特殊性（多次盗窃、入户盗窃、携带凶器盗窃、扒窃、网络盗窃）

#### 诈骗犯罪案件审查要点

1. 立足诈骗犯罪一般规律
2. 立足诈骗犯罪主观目的的外化行为要素（合同主体资格、履约能力、欺诈手段、履行行动、财物处置、事后态度）
3. 立足特殊诈骗犯罪的法条交叉竞合
4. 立足电信网络诈骗犯罪的证据特性

#### 职务犯罪案件审查要点

1. 职务犯罪的主体要件（"受委派从事公务"、"其他依照法律从事公务的人员"、"受委托管理、经营国有财产的人员"）
2. 职务犯罪的客观方面
3. 职务犯罪的主观方面
4. 全面客观审查在案言词证据（逐一审查法、同一认定法、比较印证法）

### 八、阅卷能力的培养

#### 阅卷的基本规范

- 要全面、要细致、要深入、要掌握

#### 阅卷的目标境界

1. **阅卷像读书**：读得滚瓜烂熟
2. **阅卷像做作业**：干真万确（真实性、准确性）
3. **阅卷像做笔记**：井井有条（整齐、有条理、讲逻辑）

#### 影响阅卷质效的因素

- 已有图式的影响
- 知识、经验的影响
- 其他因素（情、意、行）的影响

#### 提高阅卷质效的路径

1. 养成良好的阅卷习惯
2. 知识体系的互联互通
3. 隐性知识的有效传承（经验分享、发展实践技能、培养系统直觉）
4. 法官"传帮带"
