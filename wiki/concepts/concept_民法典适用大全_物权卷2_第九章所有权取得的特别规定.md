# 民法典第九章【所有权取得的特别规定】综合

## 章节目录

本章共 12 条（Articles 311-322），涵盖所有权取得的**特别方式**——善意取得制度、遗失物处理规则、拾得漂流物/埋藏物、从物转让、孳息归属、添附等。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第311条 | 善意取得 | 三要件：善意 + 合理价格 + 登记/交付 |
| 第312条 | 遗失物的善意取得 | 特别规则：权利人追回 + 2 年除斥期间 |
| 第313条 | 善意取得的动产上原有权利消灭 | 知情例外 |
| 第314条 | 拾得遗失物的返还 | 拾得人通知/送交义务 |
| 第315条 | 有关部门收到遗失物的处理 | 通知权利人 / 公告招领 |
| 第316条 | 遗失物保管 | 故意/重大过失致损责任 |
| 第317条 | 权利人领取义务 | 必要费用支付 |
| 第318条 | 公告期满无人认领 | 归国家所有（1 年） |
| 第319条 | 拾得漂流物/发现埋藏物或隐藏物 | 参照遗失物 |
| 第320条 | 从物随主物转让 | 当事人另有约定除外 |
| 第321条 | 天然孳息和法定孳息 | 所有权人/用益物权人/约定优先 |
| 第322条 | 添附 | 约定→法律→物尽其用+无过错原则 |

## 核心制度一：善意取得（第311-313条）

### 第311条 法条原文

> 无处分权人将不动产或者动产转让给受让人的，所有权人有权追回；除法律另有规定外，符合下列情形的，受让人取得该不动产或者动产的所有权：
>
> （一）受让人受让该不动产或者动产时是善意；
>
> （二）以合理的价格转让；
>
> （三）转让的不动产或者动产依照法律规定应当登记的已经登记，不需要登记的已经交付给受让人。
>
> 当事人善意取得其他物权的，参照适用前两款规定。

### 善意取得三要件

| 要件 | 内容 |
|------|------|
| **主观要件：善意** | 受让人受让时不知道且不应当知道转让人无处分权 |
| **客观要件：合理价格** | 转让价格符合市场一般标准（非明显过低） |
| **公示要件：登记/交付** | 法律规定应当登记的已登记；不需要登记的已交付 |

### 法律效果

- 受让人**取得**所有权/其他物权
- 原权利人的权利**消灭**
- 原权利人可向**无处分权人**请求**损害赔偿**

### 关键司法解释

《最高人民法院关于适用〈中华人民共和国民法典〉物权编的解释（一）》：

- 第14条：受让人受让时是否为善意的判断标准
- 第15条："合理价格"的认定
- 第16条：真实权利人主张受让人不构成善意的举证责任
- 第17条：动产占有改定不构成善意取得的交付方式
- 第18条：善意取得其他物权的参照适用
- 第19条：无权处分不影响合同效力

## 核心制度二：遗失物处理（第312、314-318条）

### 第312条（遗失物的善意取得 — 特别规则）

> 所有权人或者其他权利人有权追回遗失物。该遗失物通过转让被他人占有的，权利人有权向无处分权人请求损害赔偿，或者**自知道或者应当知道受让人之日起二年内**向受让人请求返还原物；但是，受让人通过拍卖或者向具有经营资格的经营者购得该遗失物的，权利人请求返还原物时应当支付受让人所付的费用。权利人向受让人支付所付费用后，有权向无处分权人追偿。

**特别要点**：
- 遗失物的善意取得比一般善意取得**对原权利人更有利**
- **2 年除斥期间**（自知道或应当知道受让人之日起）
- 受让人通过拍卖/有经营资格经营者购得 → 权利人返还原物时**须支付受让人所付费用**

### 第314-317条 遗失物处理流程

| 阶段 | 规则 |
|------|------|
| **拾得** | 拾得人应**及时通知权利人领取**，或者**送交公安等有关部门** |
| **公告招领** | 有关部门知道权利人的，及时通知；不知道的，及时**发布招领公告** |
| **保管责任** | 拾得人/有关部门在送交/领取前应妥善保管；**故意或重大过失致损/灭失** → 承担民事责任 |
| **权利人领取** | 应当向拾得人或有关部门**支付保管遗失物等支出的必要费用** |
| **无人认领** | 自发布招领公告之日起**1 年**内无人认领的，**归国家所有** |

### 第319条 漂流物/埋藏物/隐藏物

> 拾得漂流物、发现埋藏物或者隐藏物的，**参照适用拾得遗失物的有关规定**。法律另有规定的，依照其规定。

## 核心制度三：从物、孳息、添附（第320-322条）

### 第320条 从物随主物转让

> 主物转让的，从物随主物转让，但是当事人另有约定的除外。

**原则**：从物随主物转让（保证物的整体效用）

### 第321条 天然孳息和法定孳息的归属

> 天然孳息，由所有权人取得；既有所有权人又有用益物权人的，由用益物权人取得。当事人另有约定的，按照其约定。
>
> 法定孳息，当事人有约定的，按照约定；没有约定或者约定不明确的，按照交易习惯取得。

**归属规则**：

| 情形 | 天然孳息归属 |
|------|------------|
| 仅所有权人 | 所有权人 |
| 既有所有权人又有用益物权人 | **用益物权人**（保护用益物权人对物使用收益的权能） |
| 当事人另有约定 | 按约定 |

### 第322条 添附（附合、混合、加工）

> 因加工、附合、混合而产生的物的归属，有约定的，按照约定；没有约定或者约定不明确的，依照法律规定；法律没有规定的，按照**充分发挥物的效用以及保护无过错当事人的原则**确定。因一方当事人的过错或者确定物的归属造成另一方当事人损害的，应当给予赔偿或者补偿。

**归属规则**：

1. 约定优先
2. 法律规定
3. 物尽其用 + 保护无过错当事人原则
4. 因过错或归属造成损害 → 赔偿或补偿

## 适用指引综合

### 审判核心要点

1. **善意取得审查三步走**：主观善意 → 客观合理价格 → 公示要件
2. **遗失物特别保护**：2 年除斥期间是核心
3. **公告招领 1 年**：归国家所有（**无人认领**）
4. **从物随主物**：维护物的整体效用
5. **孳息归属**：所有权人与用益物权人并存时→用益物权人
6. **添附争议**：物尽其用 + 保护无过错 + 损害赔偿

## 实务问答精选

> **问**：善意取得的三要件是什么？
>
> **答**：① 受让人受让时**善意**；② 以**合理价格**转让；③ 法律规定应当登记的已经登记，不需要登记的已经交付给受让人。三要件**同时满足**才构成善意取得。

> **问**：遗失物的权利人追回期限是多久？
>
> **答**：**自知道或者应当知道受让人之日起 2 年**（《民法典》第312条）。这是除斥期间，不适用中止、中断、延长。

> **问**：无人认领的遗失物归谁所有？
>
> **答**：**归国家所有**。自发布招领公告之日起 1 年内无人认领的（《民法典》第318条）。

> **问**：天然孳息和法定孳息的归属规则有何不同？
>
> **答**：**天然孳息**：所有权人取得；既有所有权人又有用益物权人的，**用益物权人取得**（保护用益物权人对物的使用收益权能）；约定优先。**法定孳息**：按约定；无约定按交易习惯。

> **问**：添附物的归属发生争议时如何处理？
>
> **答**：① 约定优先；② 法律规定；③ **物尽其用 + 保护无过错当事人**原则；④ 因过错或归属造成损害 → 赔偿或补偿。
