## 核心制度深度解读

### 一、肖像权定义与权能（第1018条）

**条文原文**：自然人享有肖像权，有权依法制作、使用、公开或者许可他人使用自己的肖像。

**肖像权四项权能**：

| 权能 | 内容 |
|------|------|
| 1. 制作权 | 制作自己的肖像（如自拍、写生） |
| 2. 使用权 | 使用自己的肖像 |
| 3. 公开权 | 公开自己的肖像 |
| 4. 许可使用权 | 许可他人使用自己的肖像 |

**"肖像"的含义**：
- 通过影像、雕塑、绘画等方式在一定载体上所反映的特定自然人可以被识别的外部形象
- 涵盖摄影、摄像、雕塑、绘画、AI生成等多种形式

**肖像权的专属性**：
- 仅自然人享有（法人、非法人组织不享有肖像权）
- 不得放弃、转让或继承（第992条）
- 许可使用权可授权他人

### 二、肖像权保护与新型侵害方式（第1019条）

**条文原文**：任何组织或者个人不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权。未经肖像权人同意，不得制作、使用、公开肖像权人的肖像，但是法律另有规定的除外。

**侵害肖像权的主要方式**：

| 方式 | 含义 | 典型例子 |
|------|------|----------|
| 丑化 | 故意歪曲、贬损肖像 | AI换脸、P图丑化 |
| 污损 | 物理或数字方式损坏肖像 | 涂抹、撕毁照片 |
| 伪造 | 利用信息技术手段伪造 | AI生成虚假肖像、深度伪造（Deepfake） |
| 未经同意制作 | 未经许可制作他人肖像 | 偷拍 |
| 未经同意使用 | 未经许可使用他人肖像 | 商业宣传中擅自使用 |
| 未经同意公开 | 未经许可公开他人肖像 | 网上发布他人照片 |

**第1019条的两款规定**：

| 款项 | 内容 |
|------|------|
| 第1款 | 不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权 |
| 第2款 | 未经肖像权人同意，不得制作、使用、公开肖像权人的肖像，但是法律另有规定的除外 |

**典型案例**：
- AI换脸：将他人肖像用于色情视频的，构成肖像权侵权
- 深度伪造（Deepfake）：利用AI技术伪造他人肖像的，构成肖像权侵权
- 偷拍：未经同意拍摄他人肖像的，构成肖像权侵权

### 三、肖像权合理使用（第1020条）

**条文原文**：合理实施下列行为的，可以不经肖像权人同意：

1. 为个人欣赏、艺术鉴赏、课堂教学或者科学研究，在必要范围内使用肖像权人已经公开的肖像
2. 为实施新闻报道，不可避免地制作、使用、公开肖像权人的肖像
3. 为依法履行职责，国家机关在必要范围内制作、使用、公开肖像权人的肖像
4. 为特定目的，为展示特定公共环境，不可避免地制作、使用、公开肖像权人的肖像
5. 为维护公共利益或者肖像权人合法权益，制作、使用、公开肖像权人肖像的其他行为

**五项合理使用情形**：

| 情形 | 适用条件 |
|------|----------|
| 1. 个人/教学/科研 | 个人欣赏、艺术鉴赏、课堂教学、科学研究；必要范围；已公开 |
| 2. 新闻报道 | 不可避免地制作、使用、公开 |
| 3. 国家机关履职 | 依法履行职责；必要范围 |
| 4. 公共环境 | 展示特定公共环境；不可避免 |
| 5. 其他公共利益 | 维护公共利益或肖像权人合法权益 |

**理解要点**：
- 合理使用是对肖像权人权利的限制
- 必须满足"必要范围"或"不可避免"等限制
- 超出合理范围的，仍需经肖像权人同意

### 四、肖像许可使用合同（第1021-1023条）

#### （一）合同解释规则（第1021条）

**条文原文**：当事人对肖像许可使用合同中关于肖像使用条款的理解有争议的，应当作出有利于肖像权人的解释。

**理解要点**：
- 合同条款理解有争议时 → 作出有利于肖像权人的解释
- 立法目的：保护肖像权人（弱势方）

#### （二）合同解除（第1022条）

**条文原文**：当事人对肖像许可使用期限没有约定或者约定不明确的，任何一方当事人可以随时解除肖像许可使用合同，但是应当在合理期限之前通知对方。

**规则**：

| 情形 | 解除权 |
|------|--------|
| 约定明确的期限 | 依约定 |
| 未约定或约定不明确 | 任何一方可随时解除 |
| 通知要求 | 应当在合理期限之前通知对方 |

**"合理期限"的认定**：
- 依合同的性质和目的
- 依交易习惯
- 应当给对方必要的准备时间

#### （三）姓名等的许可参照（第1023条）

**条文原文**：对姓名等的许可使用，参照适用肖像许可使用的有关规定。

**参照范围**：
- 姓名许可使用 → 参照肖像许可使用规定
- 名称许可使用 → 参照肖像许可使用规定
- 其他可许可使用的人格要素 → 参照肖像许可使用规定

## ⚠️ 司法适用难点

### 难点一：AI伪造肖像的侵权认定

**争议**：AI伪造肖像（如Deepfake）的侵权认定？

**主流观点**：
- 构成对肖像权的侵害
- 受侵害人可主张人格权请求权和侵权损害赔偿
- 情节严重的，可主张精神损害赔偿

**法律依据**：
- 《民法典》第1019条第1款"利用信息技术手段伪造等方式"
- 《互联网信息服务深度合成管理规定》
- 《生成式人工智能服务管理暂行办法》

### 难点二：合理使用的边界

**争议**：肖像权合理使用的边界？

**主流观点**：
- **必要范围**：必须限于必要的范围
- **不可避免**：新闻报道中的不可避免
- **比例原则**：使用方式应与目的相称
- **损害最小**：选择损害最小的方式

### 难点三：肖像许可使用合同解除后的处理

**争议**：合同解除后，已经使用的肖像如何处理？

**主流观点**：
- 解除前的使用合法
- 解除后的使用应停止
- 已经制作但未公开的肖像不得公开
- 合同另有约定的依约定

## ❓ 实务问答

> **Q1：肖像权的权能包括哪些？**
> 
> A：① 制作权；② 使用权；③ 公开权；④ 许可使用权（第1018条）。

> **Q2：侵害肖像权的主要方式？**
> 
> A：① 丑化；② 污损；③ 利用信息技术手段伪造（如AI换脸、深度伪造）；④ 未经同意制作；⑤ 未经同意使用；⑥ 未经同意公开（第1019条）。

> **Q3：哪些情况下可以不经肖像权人同意合理使用肖像？**
> 
> A：① 个人欣赏、艺术鉴赏、课堂教学或科学研究；② 新闻报道不可避免的使用；③ 国家机关依法履行职责；④ 展示特定公共环境不可避免的使用；⑤ 维护公共利益或肖像权人合法权益的其他行为（第1020条）。

> **Q4：肖像许可使用合同条款有争议时如何解释？**
> 
> A：作出有利于肖像权人的解释（第1021条）。

> **Q5：肖像许可使用合同未约定期限的，如何处理？**
> 
> A：任何一方当事人可以随时解除肖像许可使用合同，但是应当在合理期限之前通知对方（第1022条）。

> **Q6：姓名等的许可使用参照肖像许可使用规定吗？**
> 
> A：是。对姓名等的许可使用，参照适用肖像许可使用的有关规定（第1023条）。

> **Q7：AI换脸是否构成肖像权侵权？**
> 
> A：是。利用信息技术手段伪造等方式侵害他人肖像权的，构成侵权（第1019条）。AI换脸、深度伪造均构成肖像权侵权。

> **Q8：肖像权被侵害的救济方式？**
> 
> A：① 停止侵害、排除妨碍、消除影响、恢复名誉、赔礼道歉（不适用诉讼时效）；② 财产损失赔偿；③ 精神损害赔偿（造成严重精神损害的）。
