| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第161条 | 代理定义 | 民事主体可以通过代理人实施民事法律行为 |
| 第162条 | 代理效力 | 代理人在代理权限内，以被代理人名义实施的，对被代理人发生效力 |
| 第163条 | 代理类型 | 委托代理和法定代理 |

|------|------|----------|
| 第165条 | 授权委托书 | 委托代理授权采用书面形式的，授权委托书应当载明代理人的姓名/名称、代理事项、权限和期限 |

| 第168条 | 自己代理禁止 | 代理人不得以被代理人的名义与自己实施民事法律行为，但被代理人同意或追认的除外 |

### 第三节 代理终止

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第171条 | 无权代理 | 行为人没有代理权、超越代理权或代理权终止后实施的代理行为，未经被代理人追认的，对被代理人不发生效力 |

| 第173条 | 委托代理终止 | 代理期限届满或代理事务完成；被代理人取消委托或代理人辞去委托；代理人丧失民事行为能力；代理人或被代理人死亡等 |

## 核心制度深度解读

### 一、代理概述（第161-163条）

**第161条**：民事主体可以通过代理人实施民事法律行为。

**代理的法律特征**：

| 特征 | 内容 |
|------|------|
| 1. 涉及三方 | 被代理人、代理人、相对人 |
| 2. 以被代理人名义 | 代理人以被代理人名义实施（区别于代表） |
| 3. 代理权限 | 代理人在代理权限范围内实施 |
| 4. 法律后果 | 行为后果由被代理人承受 |

**代理 vs 代表**：

| 维度 | 代理 | 代表 |
|------|------|------|
| 主体 | 被代理人是民事主体 | 代表人是法人的法定代表人 |
| 法律性质 | 代理人行为 → 被代理人 | 代表人行为 = 法人自身行为 |
| 责任承担 | 被代理人承担 | 法人承担 |
| 越权效力 | 效力待定或表见代理 | 构成表见代表 |

**第162条**：代理人在代理权限内，以被代理人名义实施的民事法律行为，对被代理人发生效力。

**理解要点**：
- "代理权限内"：在授权范围内
- "以被代理人名义"：区别于代表行为
- "对被代理人发生效力"：法律后果由被代理人承受

**第163条**：代理包括委托代理和法定代理。

| 类型 | 产生依据 | 适用情形 |
|------|----------|----------|
| 委托代理 | 基于被代理人的授权 | 一般民事行为 |
| 法定代理 | 基于法律规定 | 无、限制民事行为能力人的监护人 |

### 二、代理人的责任（第164条）

**条文原文**：代理人不履行或者不完全履行职责，造成被代理人损害的，应当承担民事责任。

**代理人责任类型**：

| 情形 | 责任 |
|------|------|
| 不履行职责 | 民事赔偿责任 |
| 不完全履行职责 | 民事赔偿责任 |
| 超越代理权 | 依第171、172条处理 |
| 违法代理 | 依第167条处理（连带责任） |

### 三、职务代理（第170条）

**条文原文**：执行法人或者非法人组织工作任务的人员，就其职权范围内的事项，以法人或者非法人组织的名义实施的民事法律行为，对法人或者非法人组织发生效力。

**职务代理的特征**：

| 特征 | 内容 |
|------|------|
| 1. 主体 | 法人或非法人组织的工作人员 |
| 2. 范围 | 职权范围内的事项 |
| 3. 形式 | 以法人或非法人组织名义 |
| 4. 后果 | 对法人或非法人组织发生效力 |

**职务代理 vs 一般委托代理**：

| 维度 | 职务代理 | 委托代理 |
|------|----------|----------|
| 授权基础 | 职权 | 授权 |
| 权限范围 | 职权范围内 | 授权范围内 |
| 适用人员 | 法人/非法人组织工作人员 | 任何被授权人 |
| 责任承担 | 法人/非法人组织承担 | 被代理人承担 |

### 四、委托代理的特别规则（第165-169条）

#### （一）授权委托书（第165条）

**条文原文**：委托代理授权采用书面形式的，授权委托书应当载明代理人的姓名或者名称、代理事项、权限和期限，并由被代理人签名或者盖章。

**必备记载事项**：
1. 代理人的姓名或名称
2. 代理事项
3. 代理权限
4. 代理期限
5. 被代理人签名或盖章

#### （二）数人代理（第166条）

**条文原文**：数人为同一代理事项的代理人的，应当共同行使代理权，但是当事人另有约定的除外。

**规则**：
- 共同代理：数人为同一事项代理的，应当共同行使
- 例外：当事人另有约定的，依约定

#### （三）违法代理的连带责任（第167条）

**条文原文**：代理人知道或者应当知道代理事项违法仍然实施代理行为，或者被代理人知道或者应当知道代理人的代理行为违法未作反对表示的，被代理人和代理人应当承担连带责任。

**连带责任情形**：

| 情形 | 责任 |
|------|------|
| 代理人知道代理事项违法仍实施 | 代理人与被代理人连带责任 |
| 代理人应当知道但实际不知道 | 同上 |
| 被代理人知道代理行为违法未反对 | 代理人与被代理人连带责任 |
| 被代理人应当知道但实际不知道 | 同上 |

#### （四）禁止自己代理与双方代理（第168条）

**条文原文**：代理人不得以被代理人的名义与自己实施民事法律行为，但是被代理人同意或者追认的除外。

**禁止的代理形态**：
- **自己代理**：代理人以被代理人名义与自己实施
- **双方代理**：同一代理人代理双方当事人实施

**例外**：被代理人同意或追认的除外。

#### （五）转委托（第169条）

**条文原文**：代理人需要转委托第三人代理的，应当取得被代理人的同意或者追认。

**转委托规则**：

| 情形 | 效力 |
|------|------|
| 经被代理人同意的转委托 | 有效，代理人仅就选任和指示承担责任 |
| 经被代理人追认的转委托 | 有效，同上 |
| 未经同意/追认的转委托 | 代理人应对转委托的第三人的行为承担责任 |

### 五、无权代理与表见代理（第171-172条）

#### （一）无权代理（第171条）

**条文原文**：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，未经被代理人追认的，对被代理人不发生效力。

**无权代理的三种情形**：

| 情形 | 含义 |
|------|------|
| 1. 没有代理权 | 自始未获授权 |
| 2. 超越代理权 | 有部分代理权但超出范围 |
| 3. 代理权终止后 | 曾经有代理权但已终止 |

**无权代理的法律后果**：

| 情形 | 后果 |
|------|------|
| 被代理人追认 | 有效，对被代理人发生效力 |
| 被代理人不予追认 | 无效，由行为人承担责任 |
| 相对人有理由相信行为人有代理权（表见代理） | 代理行为有效 |

#### （二）表见代理（第172条）

**条文原文**：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效。

**表见代理的构成要件**：

| 要件 | 内容 |
|------|------|
| 1. 行为人无代理权 | 没有、超越或终止后 |
| 2. 客观上存在代理权外观 | 持有公章、合同书、授权委托书等 |
| 3. 相对人主观上善意 | 不知道也不应当知道无权代理 |
| 4. 相对人有理由相信 | 信赖代理权外观 |

**表见代理的典型情形**：
- 持有公章、合同章、财务章
- 持有空白合同书
- 持有授权委托书（虽已撤销但未告知相对人）
- 在被代理人办公场所办理业务
- 长期以代理人身份处理业务

**表见代理的法律后果**：
- 代理行为有效，对被代理人发生效力
- 被代理人因此遭受损失的，可向无权代理人追偿

#### （三）无权代理 vs 表见代理

| 维度 | 无权代理 | 表见代理 |
|------|----------|----------|
| 相对人主观 | 不知道无权代理 | 有理由相信有代理权 |
| 客观外观 | 通常无 | 有权外观 |
| 行为效力 | 效力待定（追认后有效） | 有效 |

### 六、代理终止（第173-174条）

#### （一）委托代理终止（第173条）

**委托代理终止的情形**：

| 情形 | 内容 |
|------|------|
| 1 | 代理期限届满或者代理事务完成 |
| 2 | 被代理人取消委托或者代理人辞去委托 |
| 3 | 代理人丧失民事行为能力 |
| 4 | 代理人或者被代理人死亡 |
| 5 | 作为被代理人或者代理人的法人、非法人组织终止 |

#### （二）法定代理终止（第175条）

**法定代理终止的情形**：

| 情形 | 内容 |
|------|------|
| 1 | 被代理人取得或者恢复完全民事行为能力 |
| 2 | 代理人丧失民事行为能力 |
| 3 | 代理人或者被代理人死亡 |
| 4 | 法律规定的其他情形 |

#### （三）委托代理终止的例外（第174条）

**条文原文**：被代理人死亡后，有下列情形之一的，委托代理人实施的代理行为有效：

1. 代理人不知道也不应当知道被代理人死亡
2. 被代理人的继承人均予以承认
3. 授权中明确代理权在代理事务完成时终止
4. 被代理人死亡前已经实施，为了被代理人继承人的利益继续代理

**理解要点**：委托代理原则上因被代理人死亡而终止，但有例外情形保证法律关系的稳定性。

## ⚠️ 司法适用难点

### 难点一：表见代理的认定

**争议**：如何认定"相对人有理由相信"？

**主流观点**：
- 客观要件：存在代理权外观（公章、合同书、授权委托书等）
- 主观要件：相对人善意且无过失
- 综合判断：依交易习惯、相对人审查义务等

**实务要点**：
- 公章使用是重要的代理权外观
- 但公章持有不等于有权代理（需结合其他因素）
- 相对人应尽到合理审查义务

### 难点二：职务代理与表见代理的区别

**争议**：职务代理与表见代理如何区分？

**主流观点**：

| 维度 | 职务代理 | 表见代理 |
|------|----------|----------|
| 授权基础 | 职权范围内 | 无权代理但有外观 |
| 主体 | 法人/非法人组织工作人员 | 任何人 |
| 行为效力 | 直接有效 | 依表见代理规则有效 |

### 难点三：转委托的责任承担

**争议**：转委托未经同意的责任承担？

**《民法典》第169条**：
- 经同意/追认的：代理人仅就选任和指示承担责任
- 未经同意/追认的：代理人应对转委托的第三人的行为承担责任

**实务要点**：
- 紧急情况下为被代理人利益的转委托，无需事先同意
- 但应在事后及时告知被代理人

## ❓ 实务问答

> **Q1：代理与代表的区别？**
> 
> A：① 代理：代理人以被代理人名义实施，行为后果由被代理人承担；② 代表：代表人（法定代表人）行为即法人自身行为。

> **Q2：代理的类型？**
> 
> A：① 委托代理：基于被代理人的授权；② 法定代理：基于法律规定（如监护）（第163条）。

> **Q3：什么是表见代理？**
> 
> A：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效（第172条）。

> **Q4：表见代理的构成要件？**
> 
> A：① 行为人无代理权（没有、超越或终止后）；② 客观上存在代理权外观（公章、合同书、授权委托书等）；③ 相对人主观上善意且无过失；④ 相对人有理由相信行为人有代理权。

> **Q5：什么是无权代理？**
> 
> A：行为人没有代理权、超越代理权或者代理权终止后实施的代理行为。未经被代理人追认的，对被代理人不发生效力（第171条）。

> **Q6：自己代理和双方代理的效力？**
> 
> A：代理人不得以被代理人的名义与自己实施民事法律行为，但被代理人同意或追认的除外。原则上自己代理和双方代理无效（第168条）。

> **Q7：转委托未经同意的法律后果？**
> 
> A：代理人需要对转委托的第三人的行为承担责任，除非紧急情况下为被代理人利益（第169条）。

> **Q8：违法代理的连带责任？**
> 
> A：代理人知道或应当知道代理事项违法仍实施，或被代理人知道或应当知道违法未反对的，被代理人和代理人承担连带责任（第167条）。

> **Q9：被代理人死亡后代理行为效力？**
> 
> A：原则上委托代理因被代理人死亡而终止。但下列情形代理行为有效：① 代理人不知道也不应当知道被代理人死亡；② 被代理人的继承人均予以承认；③ 授权中明确代理权在代理事务完成时终止；④ 被代理人死亡前已经实施，为了被代理人继承人的利益继续代理（第174条）。
