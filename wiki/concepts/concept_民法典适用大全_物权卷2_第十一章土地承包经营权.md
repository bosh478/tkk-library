# 民法典第十一章【土地承包经营权】综合

## 章节目录

本章共 14 条（Articles 330-343），规定农村土地承包经营权制度，是**"三权分置"改革**的法律基础。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第330条 | 双层经营体制与土地承包经营制度 | 家庭承包 + 统分结合 |
| 第331条 | 土地承包经营权人享有的基本权利 | 占有、使用、收益（农林业生产） |
| 第332条 | 土地承包期限 | 耕地30年 / 草地30-50年 / 林地30-70年 |
| 第333条 | 土地承包经营权的设立和登记 | 合同生效时设立 |
| 第334条 | 土地承包经营权的互换、转让 | 依法批准 + 不得非农建设 |
| 第335条 | 互换、转让的登记 | 未经登记不得对抗善意第三人 |
| 第336条 | 承包地的调整 | 特殊情形 + 严格程序 |
| 第337条 | 承包地的收回 | 法定情形 + 补偿 |
| 第338条 | 承包地的征收补偿 | 依第243条 |
| 第339条 | 土地经营权的流转 | 出租、入股等方式 |
| 第340条 | 土地经营权人享有的基本权利 | 占有 + 农业生产经营 |
| 第341条 | 土地经营权的设立与登记 | 5年以上流转登记对抗 |
| 第342条 | 其他方式承包的土地经营权流转 | 经登记可流转 |
| 第343条 | 国有农用地承包经营 | 参照适用 |

## 核心制度：三权分置

### 三权分置的法律结构

| 层级 | 权利 | 归属 |
|------|------|------|
| 第1层 | 土地所有权 | **农村集体经济组织** |
| 第2层 | 土地承包经营权 | 承包该土地的**农民家庭** |
| 第3层 | 土地经营权 | 流转受让方（5年以上可登记对抗） |

**三权分置的政策演进**：
- 2015年中共中央办公厅、国务院办公厅《深化农村改革综合性实施方案》
- 2019年《中共中央、国务院关于保持土地承包关系稳定并长久不变的意见》
- 2018年中央"三权分置"改革政策贯穿民法典编纂

### 第330条 双层经营体制

> 农村集体经济组织实行家庭承包经营为基础、统分结合的双层经营体制。

**核心特征**：
- **基础**：家庭承包经营
- **结合**：统（集体统一经营）+ 分（家庭分散经营）

### 第331条 土地承包经营权人的基本权利

> 土地承包经营权人依法对其承包经营的耕地、林地、草地等享有占有、使用和收益的权利，有权从事种植业、林业、畜牧业等农业生产。

**核心权利内容**：
1. 较长的承包期及承包期满后可继续承包
2. 依法享有土地承包经营权流转的权利
3. 依法流转土地经营权（**三权分置**核心）
4. 承包期内发包人**不得收回承包地**
5. 承包地被征收的，有权获得相应补偿

### 第332条 土地承包期限

> 耕地的承包期为**三十年**。草地的承包期为**三十年至五十年**。林地的承包期为**三十年至七十年**。

| 土地类型 | 承包期限 |
|---------|---------|
| 耕地 | 30 年 |
| 草地 | 30-50 年 |
| 林地 | 30-70 年 |

### 第333条 土地承包经营权的设立和登记

> 土地承包经营权自土地承包经营权合同生效时设立。

**设立时点**：**合同生效时设立**（不以登记为要件）

### 第334-335条 互换、转让规则

| 条款 | 规则 |
|------|------|
| 第334条 | 土地承包经营权人**有权互换、转让**；**未经依法批准，不得将承包地用于非农建设** |
| 第335条 | 互换、转让可向登记机构申请登记；**未经登记，不得对抗善意第三人** |

### 第336-337条 承包地的调整与收回

| 情形 | 规则 |
|------|------|
| **承包地调整**（第336条） | 承包期内发包人**不得调整承包地**；特殊情形（自然灾害严重毁损等）+ 2/3 以上成员或代表同意 + 乡（镇）政府和县级农业农村等主管部门批准 |
| **承包地收回**（第337条） | 承包期内发包人**不得收回承包地**；法律另有规定的，依其规定 |

### 第338条 承包地的征收补偿

> 承包地被征收的，土地承包经营权人有权依据本法第二百四十三条的规定获得相应补偿。

## 核心制度：土地经营权（第339-342条）

### 第339条 土地经营权的流转

> 土地承包经营权人可以自主决定依法采取出租、入股或者其他方式向他人流转土地经营权。

### 第340条 土地经营权人享有的基本权利

> 土地经营权人有权在合同约定的期限内占有农村土地，自主开展农业生产经营并取得收益。

### 第341条 土地经营权的设立与登记

> 流转期限为五年以上的土地经营权，自流转合同生效时设立。当事人可以向登记机构申请土地经营权登记；未经登记，不得对抗善意第三人。

**5 年是关键节点**：5 年以上流转 → 登记对抗；5 年以下则不发生物权效力。

### 第342条 其他方式承包

> 通过招标、拍卖、公开协商等方式承包农村土地，经依法登记取得权属证书的，可以依法采取出租、入股、抵押或者其他方式流转土地经营权。

### 第343条 国有农用地

> 国家所有的农用地实行承包经营的，参照适用本编的有关规定。

**参照适用**：承包期限、设立登记、流转等均可参照。

## 适用指引综合

### 涉土地纠纷审判三大要点

1. **三权分置查清**：首先查清土地所有权、土地承包经营权、土地经营权的归属与流转
2. **承包期保护**：耕地 30 年、草地 30-50 年、林地 30-70 年；承包期满可继续承包
3. **登记对抗**：土地承包经营权互换、转让、土地经营权（5年以上）未经登记不得对抗善意第三人

### 承包地调整 vs 收回的严格限制

- 调整：原则上不得调整；特殊情形（自然灾害严重毁损）需严格程序
- 收回：原则上不得收回；法律另有规定的依其规定

## 实务问答精选

> **问**：土地承包经营权何时设立？
>
> **答**：**土地承包经营权合同生效时设立**（《民法典》第333条）。登记不是设立要件，而是**对抗善意第三人的要件**。

> **问**："三权分置"是哪三权？
>
> **答**：① 农村集体的**土地所有权**；② 农民家庭的**土地承包经营权**；③ 流转受让方的**土地经营权**。三权分置是农村土地制度改革的核心，2018年中央政策贯穿民法典编纂。

> **问**：耕地、草地、林地的承包期分别是多少？
>
> **答**：耕地 **30 年**；草地 **30-50 年**；林地 **30-70 年**。承包期满，由土地承包经营权人按照农村土地承包法律规定**继续承包**。

> **问**：土地经营权流转期限 5 年以上和 5 年以下有何不同？
>
> **答**：5 年以上的土地经营权**自流转合同生效时设立**，可登记对抗善意第三人；5 年以下的土地经营权**不发生物权效力**（《民法典》第341条）。
