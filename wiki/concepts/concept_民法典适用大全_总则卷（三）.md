# 民法典适用大全·总则卷（三）

| 字段 | 内容 |
|------|------|

| 核心主题 | 民事法律行为效力、附条件附期限、代理制度、民事责任、诉讼时效、期间计算 |

## 内容定位

本卷是总则卷第三册，围绕《民法典》第143条（2021-01-01 施行 / 2021-01-01 最新修正）至第204条，涵盖民事法律行为效力（无效、可撤销）、附条件和附期限、代理制度（委托代理、法定代理、表见代理）、民事责任（按份责任、连带责任、正当防卫、紧急避险）、诉讼时效和期间计算等总则编核心制度。

## 章节结构总览

### 第六章 第三节 民事法律行为的效力（第143-157条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第143条 | 民事法律行为有效条件 | 行为人具有相应民事行为能力；意思表示真实；不违反法律、公序良俗 |
| 第144条 | 无民事行为能力人实施的效力 | 无效 |
| 第145条 | 限制民事行为能力人实施的效力 | 纯获利益或与年龄智力精神健康状况相适应的有效；其他需法定代理人同意或追认 |
| 第146条 | 通谋虚伪和隐藏行为 | 虚伪意思表示无效；隐藏行为的效力依法律规定处理 |
| 第147条 | 重大误解 | 因重大误解实施的民事法律行为，行为人有权请求撤销 |
| 第148条 | 欺诈 | 一方以欺诈手段使对方违背真实意思的，受欺诈方有权请求撤销 |
| 第149条 | 第三人欺诈 | 第三人实施欺诈，对方知道或应当知道的，受欺诈方有权请求撤销 |
| 第150条 | 胁迫 | 一方或第三人以胁迫手段使对方违背真实意思的，受胁迫方有权请求撤销 |
| 第151条 | 显失公平 | 一方利用对方处于危困状态、缺乏判断能力等导致显失公平的，受损害方有权请求撤销 |
| 第152条 | 撤销权消灭 | 知道或应当知道撤销事由之日起1年内未行使；重大误解90日内；胁迫行为终止之日起1年内 |
| 第153条 | 违反强制性规定及公序良俗 | 违反法律、行政法规的强制性规定的民事法律行为无效；违背公序良俗的无效 |
| 第154条 | 恶意串通 | 恶意串通损害他人合法权益的民事法律行为无效 |
| 第155条 | 无效或被撤销的效力 | 自始没有法律约束力 |
| 第156条 | 部分无效 | 不影响其他部分效力的，其他部分仍然有效 |
| 第157条 | 无效或撤销的法律后果 | 返还财产、折价补偿、赔偿损失 |

### 第七章 代理（第161-175条）

#### 第一节 一般规定（第161-164条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第161条 | 代理适用范围 | 民事主体可通过代理人实施民事法律行为；法律规定或当事人约定应由本人实施的除外 |
| 第162条 | 代理的效力 | 代理人在代理权限内以被代理人名义实施的民事法律行为，对被代理人发生效力 |
| 第163条 | 委托代理和法定代理 | 代理包括委托代理和法定代理 |
| 第164条 | 代理人不当行为的责任 | 代理人不履行职责造成损害的，应承担民事责任 |

#### 第二节 委托代理（第165-172条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第165条 | 授权的形式和内容 | 委托代理授权采用书面形式的，授权委托书应载明代理人的姓名或名称、代理事项、权限和期限 |
| 第166条 | 共同代理 | 数人为同一事项的代理人的，应共同行使代理权 |
| 第167条 | 违法代理 | 代理人知道或应当知道代理事项违法仍实施的，或被代理人知道的，承担连带责任 |
| 第168条 | 自己代理或双方代理 | 原则上禁止，被代理人同意或追认的除外 |
| 第169条 | 复代理 | 转委托代理需经被代理人同意或追认；紧急情况下除外 |
| 第170条 | 职务代理 | 执行法人或非法人组织工作任务的人员，就其职权范围内的事项以法人或非法人组织名义实施的民事法律行为，对法人或非法人组织发生效力 |
| 第171条 | 无权代理 | 没有代理权、超越代理权或代理权终止后实施的代理行为，未经被代理人追认的对被代理人不发生效力 |
| 第172条 | 表见代理 | 行为人没有代理权、超越代理权或代理权终止后仍实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效 |

#### 第三节 代理终止（第173-175条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第173条 | 委托代理的终止 | 代理期限届满或代理事务完成；被代理人取消委托或代理人辞去委托等 |
| 第174条 | 被代理人死亡后代理行为有效 | 代理人不知道且不应当知道被代理人死亡等情形下继续有效 |
| 第175条 | 法定代理的终止 | 被代理人取得或恢复完全民事行为能力；代理人丧失民事行为能力等 |

### 第八章 民事责任（第176-187条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第176条 | 民事义务与责任 | 民事主体依照法律规定或当事人约定履行民事义务，承担民事责任 |
| 第177条 | 按份责任 | 二人以上依法承担按份责任的，各自承担相应份额 |
| 第178条 | 连带责任 | 二人以上依法承担连带责任的，权利人有权请求部分或全部连带责任人承担责任 |
| 第179条 | 承担方式 | 停止侵害、排除妨碍、消除危险、返还财产、恢复原状、赔偿损失、支付违约金等 |
| 第180条 | 不可抗力 | 因不可抗力不能履行民事义务的，不承担民事责任 |
| 第181条 | 正当防卫 | 因正当防卫造成损害的，不承担民事责任 |
| 第182条 | 紧急避险 | 因紧急避险造成损害的，由引起险情发生的人承担民事责任 |
| 第183条 | 因保护他人权益受损的责任 | 因保护他人民事权益使自己受到损害的，由侵权人承担民事责任，受益人可给予适当补偿 |
| 第184条 | 紧急救助 | 因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任 |
| 第185条 | 英雄烈士人格利益保护 | 侵害英雄烈士等的姓名、肖像、名誉、荣誉，损害社会公共利益的，应承担民事责任 |
| 第186条 | 违约与侵权竞合 | 因当事人一方的违约行为损害对方人身、财产权益的，受损害方有权选择请求其承担违约责任或侵权责任 |
| 第187条 | 民事责任优先 | 民事主体因同一行为应承担民事责任和行政责任、刑事责任的，财产不足以支付的，优先用于承担民事责任 |

### 第九章 诉讼时效（第188-199条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第188条 | 普通诉讼时效 | 向人民法院请求保护民事权利的诉讼时效期间为三年 |
| 第189条 | 分期履行债务 | 当事人约定同一债务分期履行的，诉讼时效期间从最后一期履行期限届满之日起计算 |
| 第190条 | 对法定代理人请求权 | 无民事行为能力人或限制民事行为能力人对其法定代理人的请求权的诉讼时效期间，自该法定代理终止之日起计算 |
| 第191条 | 未成年人遭性侵害 | 未成年人遭受性侵害的损害赔偿请求权的诉讼时效期间，自受害人年满十八周岁之日起计算 |
| 第192条 | 诉讼时效届满的效力 | 诉讼时效期间届满的，义务人可以提出不履行义务的抗辩 |
| 第193条 | 法院不主动适用 | 人民法院不得主动适用诉讼时效的规定 |
| 第194条 | 诉讼时效中止 | 在诉讼时效期间的最后六个月内，因不可抗力等障碍不能行使请求权的，诉讼时效中止 |
| 第195条 | 诉讼时效中断 | 权利人向义务人提出履行请求、义务人同意履行义务、权利人提起诉讼或申请仲裁等，诉讼时效中断 |
| 第196条 | 不适用诉讼时效的情形 | 请求停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费或扶养费等 |
| 第197条 | 诉讼时效的强制性 | 诉讼时效的期间、计算方法以及中止、中断的事由由法律规定，当事人约定无效 |
| 第198条 | 仲裁时效 | 法律对仲裁时效有规定的，从其规定 |
| 第199条 | 撤销权、解除权等的除斥期间 | 法律规定或当事人约定的撤销权、解除权等权利的存续期间，不适用有关诉讼时效中止、中断和延长的规定 |

### 第十章 期间计算（第200-204条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第200条 | 期间的计算单位 | 民法所称的期间按照公历年、月、日、小时计算 |
| 第201条 | 期间的起算 | 按照小时计算的，自法律规定或当事人约定时起算；按日、月、年计算的，开始的当日不计入，自下一日开始计算 |
| 第202条 | 期间的最后一日 | 以日、月、年计算的，期间的最后一日是法定休假日的，以法定休假日结束的次日为最后一日 |
| 第203条 | 期间的最后一日截止时间 | 截止时间为二十四时；有业务时间的，停止业务活动的时间为截止时间 |
| 第204条 | 期间的确定 | 本法所称的"以上""以下""以内""届满"，包括本数；所称的"不满""超过"，不包括本数 |

## 核心制度解读

### 一、民事法律行为效力体系（第143-157条）

**有效要件**（第143条）：行为人具有相应的民事行为能力；意思表示真实；不违反法律、行政法规的强制性规定，不违背公序良俗。

**无效情形**：无民事行为能力人实施的（第144条）；通谋虚伪意思表示（第146条）；违反强制性规定或公序良俗（第153条）；恶意串通（第154条）。

**可撤销情形**：重大误解（第147条）；欺诈（第148-149条）；胁迫（第150条）；显失公平（第151条）。

**撤销权除斥期间**（第152条）：知道或应当知道之日起1年；重大误解90日；胁迫行为终止之日起1年。

### 二、表见代理制度（第172条）

**构成要件**：行为人没有代理权；相对人有理由相信行为人有代理权；相对人善意且无过失。

**法律效果**：代理行为有效，对被代理人发生效力。

**制度意义**：保护善意相对人的合理信赖，维护交易安全。

### 三、紧急救助免责（第184条）

**立法意义**：被称为"好人条款"，鼓励见义勇为、紧急救助。

**适用条件**：自愿实施紧急救助行为；造成受助人损害；救助人不承担民事责任。

### 四、诉讼时效制度（第188-199条）

**普通时效**：3年（原《民法通则》为2年）。

**特殊规定**：
- 未成年人遭性侵害的请求权：自受害人年满18周岁之日起计算（第191条）
- 法院不得主动适用诉讼时效（第193条）
- 不适用诉讼时效的情形：停止侵害、排除妨碍、消除危险等（第196条）

## ❓ 常见问题

> 问：什么是表见代理？
> 答：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效（第172条）。表见代理保护善意相对人的合理信赖。

> 问：普通诉讼时效期间是多长？
> 答：向人民法院请求保护民事权利的诉讼时效期间为三年（第188条）。自权利人知道或者应当知道权利受到损害以及义务人之日起计算。

> 问：哪些情形不适用诉讼时效？
> 答：请求停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费或者扶养费；依法不适用诉讼时效的其他请求权（第196条）。

> 问：紧急救助造成受助人损害，救助人是否需要承担责任？
> 答：不需要。因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任（第184条）。

> 问：民事责任与行政责任、刑事责任竞合时如何处理？
> 答：承担行政责任或者刑事责任不影响承担民事责任。民事主体的财产不足以支付的，优先用于承担民事责任（第187条）。
