# 民法典合同编第三章【合同的效力】综合

## 章节目录

本章共 7 条（Articles 502-508），规定合同的生效、无权代理合同追认、越权代表行为效力、超越经营范围合同效力、免责条款无效、争议解决条款独立性等合同效力制度。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第502条 | 合同生效时间 | 依法成立时生效+特殊生效要件 |
| 第503条 | 无权代理合同追认 | 追认规则 |
| 第504条 | 越权代表合同效力 | 表见代表规则 |
| 第505条 | 超越经营范围合同 | 不因超范围而无效 |
| 第506条 | 免责条款无效 | 人身损害+故意/重大过失 |
| 第507条 | 争议解决条款独立性 | 不因合同无效而无效 |
| 第508条 | 法律适用援引 | 援引总则编规定 |

## 一、合同生效时间（第502条）

### 法条原文

> 第五百零二条　依法成立的合同，自成立时生效，但是法律另有规定或者当事人另有约定的除外。
>
> 依照法律、行政法规的规定，合同应当办理批准等手续的，依照其规定。未办理批准等手续影响合同生效的，不影响合同中履行报批等义务条款以及相关条款的效力。应当办理申请批准等手续的当事人未履行义务的，对方可以请求其承担违反该义务的责任。

### 合同生效的三层规则

| 层级 | 规则 |
|------|------|
| **一般规则** | 依法成立的合同**自成立时生效** |
| **法律另有规定** | 依法律特别规定（如不动产登记生效、批准生效等） |
| **当事人另有约定** | 附条件/附期限生效（依第158-160条） |

### 批准生效合同的特殊规则

**第502条第2款的重大意义**：

| 维度 | 规则 |
|------|------|
| **批准义务的独立性** | 未办理批准手续影响合同生效的，**不影响合同中履行报批等义务条款**以及相关条款的效力 |
| **违反报批义务的责任** | 应当办理申请批准等手续的当事人未履行义务的，对方可以请求其承担**违反该义务的责任** |
| **意义** | 防止"未批不生效"导致违反报批义务方**免责**，督促报批义务履行 |

**典型需批准合同**：
- 中外合资经营企业合同
- 中外合作经营企业合同
- 涉及国家安全的特殊行业合同
- 国有资产转让合同（依《企业国有资产法》）

## 二、无权代理合同的追认（第503条）

### 法条原文

> 第五百零三条　无权代理人以被代理人的名义订立合同，被代理人已经开始履行合同义务或者接受相对人履行的，视为对合同的追认。

### 无权代理的核心规则

| 规则 | 内容 |
|------|------|
| **效力待定** | 无权代理合同**效力待定**（不是无效） |
| **追认** | 被代理人可以**追认**使其有效 |
| **追认的方式** | ① 明确表示追认；② 第503条规定的**默示追认**（开始履行/接受履行） |
| **未追认的后果** | 合同对被代理人不发生效力，由**无权代理人**承担法律责任 |
| **善意相对人** | 善意相对人有**撤销权**（第171条） |

### 默示追认（第503条）

**默示追认的两种情形**：
1. **被代理人已经开始履行合同义务**
2. **被代理人接受相对人履行**

**意义**：实务中常常存在被代理人虽未明确表示追认但已实际履行合同的情形，第503条将此种行为认定为追认。

## 三、越权代表合同的效力（第504条）

### 法条原文

> 第五百零四条　法人的法定代表人或者非法人组织的负责人超越权限订立的合同，除相对人知道或者应当知道其超越权限外，该合同代表行为有效。

### 越权代表 vs 表见代理

| 维度 | 越权代表（第504条） | 表见代理（第172条） |
|------|------------------|------------------|
| **行为人** | 法定代表人/负责人 | 代理人 |
| **超越的内容** | 代表权限 | 代理权限 |
| **法律基础** | 代表制度 | 代理制度 |
| **合同效力** | 除相对人恶意外**有效** | 除相对人恶意外**有效** |

### 相对人善意的判断

相对人**知道或者应当知道**其超越权限的 → 合同对法人/非法人组织**不发生效力**，由越权代表行为人承担责任。

**实务判断**：相对人是否知道，应当以**一般理性人的标准**判断，结合交易习惯、相对人的经验、合同条款等综合判断。

## 四、超越经营范围的合同效力（第505条）

### 法条原文

> 第五百零五条　当事人超越经营范围订立的合同的效力，应当依照本法第一编第六章第三节和本编的有关规定确定，不得仅以超越经营范围确认合同无效。

### 超越经营范围的法律后果

| 情形 | 法律后果 |
|------|---------|
| **当事人超越经营范围订立合同** | 不得仅以超越经营范围为由确认合同无效 |
| **违反法律、行政法规的强制性规定** | 合同可能因违反强制性规定而无效（第153条） |
| **违反特许经营、限制经营规定** | 合同可能因违反限制经营、特许经营规定而无效 |

### 与原《合同法》司法解释的对比

**重大变化**：原《合同法司法解释（一）》第10条规定"当事人超越经营范围订立合同，人民法院不因此认定合同无效，但违反国家限制经营、特许经营以及法律、行政法规禁止经营规定的除外"。

**《民法典》第505条**：
- 删除了"违反国家限制经营、特许经营以及法律、行政法规禁止经营规定"的但书
- 直接援引总则编第6章第3节（民事法律行为效力）和合同编有关规定
- 实务上仍区分**经营范围违反**（一般不影响合同效力）vs **强制性规定违反**（影响合同效力）

## 五、免责条款的无效（第506条）

### 法条原文

> 第五百零六条　合同中的下列免责条款无效：
> （一）造成对方**人身损害**的；
> （二）因**故意或者重大过失**造成对方**财产损失**的。

### 免责条款无效的两种情形

| 情形 | 内容 |
|------|------|
| **1. 人身损害免责** | 造成对方**人身损害**的免责条款**绝对无效**（无过失程度区分） |
| **2. 财产损失免责** | 因**故意或重大过失**造成对方**财产损失**的免责条款**无效** |

### 免责条款无效的范围

| 免责情形 | 是否无效 |
|---------|---------|
| 造成**人身损害**（任何情形） | ❌ **无效** |
| 因**故意**造成财产损失 | ❌ **无效** |
| 因**重大过失**造成财产损失 | ❌ **无效** |
| 因**一般过失**造成财产损失 | ✅ **可以免责**（依条款） |
| 不可抗力免责 | ✅ **有效**（依第590条） |
| 约定排除对方主要权利（格式条款） | ❌ **无效**（依第497条） |

### 免责条款无效的后果

免责条款无效**不影响合同其他条款的效力**。合同其他部分仍然有效（第497条 + 第506条）。

## 六、争议解决条款的独立性（第507条）

### 法条原文

> 第五百零七条　合同不生效、无效、被撤销或者终止的，不影响合同中有关**解决争议方法**的条款的效力。

### 争议解决条款的独立性意义

**核心规则**：合同效力瑕疵**不影响**争议解决条款的效力——争议解决条款**独立于**合同其他条款。

| 合同效力状态 | 争议解决条款效力 |
|------------|--------------|
| 合同**不生效** | 争议解决条款**有效** |
| 合同**无效** | 争议解决条款**有效** |
| 合同**被撤销** | 争议解决条款**有效** |
| 合同**被终止**（解除/终止） | 争议解决条款**有效** |

### 争议解决条款的类型

| 类型 | 内容 |
|------|------|
| **仲裁条款** | 选择特定仲裁委员会 |
| **管辖条款** | 选择特定法院管辖（依《民事诉讼法》第35条） |
| **法律适用条款** | 选择特定国家/地区的法律 |
| **协商/调解条款** | 约定协商或调解前置 |

### 争议解决条款独立性的法理

- 争议解决条款的**目的**：解决合同争议 → 合同无效也需要解决争议
- 争议解决条款的**性质**：**程序性条款**，区别于实体性条款
- **国际通行规则**：多数国家立法承认争议解决条款的独立性（《纽约公约》《UNCITRAL 国际商事合同通则》）

## 七、法律适用援引（第508条）

### 法条原文

> 第五百零八条　本编对合同的效力没有规定的，适用本法第一编第六章第三节的有关规定。

### 适用顺序

合同效力问题 → 合同编第三章（第502-508条）→ **没有规定的**，适用**总则编第6章第3节**（民事法律行为的效力）

### 总则编第6章第3节的主要内容

| 制度 | 法条 |
|------|------|
| 民事法律行为的成立 | 第134条 |
| 意思表示 | 第137-145条 |
| 民事法律行为的效力 | 第143条（生效要件）+ 第144-145条（成立与生效） |
| 无效民事法律行为 | 第153-156条 |
| 可撤销民事法律行为 | 第147-152条 |
| 效力待定民事法律行为 | 第145、171、503条 |

## 八、合同效力瑕疵的体系

```
合同效力瑕疵
├── 1. 合同无效
│   ├── 全部无效
│   └── 部分无效（部分条款无效）
├── 2. 合同可撤销
│   ├── 重大误解
│   ├── 欺诈
│   ├── 胁迫
│   └── 显失公平
├── 3. 合同效力待定
│   ├── 无权代理
│   └── 限制民事行为能力人超出行为能力
├── 4. 合同不生效
│   ├── 附条件未成就
│   ├── 附期限未届至
│   └── 应当批准未批准
└── 5. 合同有效但效力受限
    ├── 越权代表（相对人恶意时不对法人发生效力）
    └── 超越经营范围（一般不影响效力）
```

## ❓ 实务问答精选

> **问**：合同何时生效？
>
> **答**：依第502条规定，**依法成立的合同自成立时生效**，但法律另有规定或者当事人另有约定的除外。**特殊生效要件**：
> 1. 法律特别规定（如不动产登记生效）
> 2. 行政法规规定（如批准生效）
> 3. 当事人约定（附条件/附期限）

> **问**：未办理批准手续的合同效力？
>
> **答**：**合同不生效**，但**报批义务条款有效**。第502条第2款是重大亮点：未办理批准等手续影响合同生效的，不影响合同中**履行报批等义务条款以及相关条款的效力**。违反报批义务的，对方可以请求承担违反该义务的责任。

> **问**：法定代表人越权订立的合同效力？
>
> **答**：原则上**有效**，除非相对人知道或应当知道其超越权限。第504条规定，法定代表人超越权限订立的合同，除相对人知道或应当知道其超越权限外，该合同代表行为**有效**。

> **问**：人身损害免责条款效力？
>
> **答**：**绝对无效**。第506条第1项规定，造成对方**人身损害**的免责条款**无效**，不区分故意/重大过失/一般过失。这一规则体现了对人身权益的优先保护。

> **问**：争议解决条款在合同无效后是否有效？
>
> **答**：**有效**。第507条规定，合同不生效、无效、被撤销或者终止的，不影响合同中有关**解决争议方法**的条款的效力。争议解决条款**独立于**合同其他条款。
