# 《合同法总论》第三章 合同的订立

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第三章 合同的订立 |
| 行号范围 | 1734-3065（书籍） |
| 核心议题 | 合同的订立与成立、合同形式、要约承诺规则、缔约过失责任 |
| 涵盖 | 7 节内容，覆盖合同订立全流程与先合同责任 |

## 🎯 核心论点

**合同的订立 vs 成立**：
- **订立**（Vertragsabschluss）= 动态概念，过程
- **成立**（Zustandekommen von Vertrag）= 静态概念，结果
- 订立 = 有机体的孕育过程；成立 = 有机体的诞生

**合同成立路径**：
- 主要路径：要约 + 承诺（合意）
- 替代路径：交叉要约 / 意思实现 / 事实的合同关系
- 特殊要求：要物合同（标的物交付）+ 要式合同（特定形式）

**合同成立的效力基础**：合同约束力表面看是法律的赋予，实质上有着当事人意思（合意）作为基础。

## 第一节 合同的订立与成立

## 一、概念

- **订立**（Vertragsabschluss）= 动态过程，描述合同孕育
- **成立**（Zustandekommen von Vertrag）= 静态结果，描述合同诞生

## 二、合同成立的一般要件

### （一）当事人

- 当事人 = 合同主体，权利义务的承载者
- 须为**平等主体**的自然人、法人或非法人组织
- 当事人须有**两方或多方**（单方法律行为 ≠ 合同）

**注意区分**：
- **合同当事人** vs **缔约主体**
- 缔约主体可能是合同当事人本人（亲自订立）或代理人（通过辅助人订立）
- 代理人包括委托代理人和法定代理人（《民法典》第163条）

### （二）对必要合同内容达成合意

#### 1. 合意的内涵

- **合意**（consensus ad idem; a meeting of minds）= 双方意思表示达成一致
- 包含两层：
  1. 对合同**必要内容**的合意
  2. 对**意思表示受法律拘束**的合意
- 《民法典》第472条第2项：要约须表明"经受要约人承诺，要约人即受该意思表示约束"

#### 2. 主观说 vs 客观说

| 学说 | 立场 | 适用 |
|------|------|------|
| **主观说**（subjective theory of assent）| 当事人实际的/主观的意思 | 早期理论；意思主义 |
| **客观说**（objective theory of assent）| 当事人通过行为表现出来的外在/客观的表象 | 现代商业社会主流 |

**我国立法**：
- **以表示主义为原则**（客观说）
- 仅在合同因欺诈、胁迫等情形采取意思主义
- 合意原则指双方当事人**表示内容的一致**，对合同条款在客观上意思表示一致

**比较法**：
- 英国普通法：关注客观表征（the objective appearance），例外关注实际合意
- 美国：19世纪末客观说主导
- 德国流派：合意指经解释确定的"表示内容的一致"，而非内心意思一致

### （三）特殊合同成立要件

| 合同类型 | 额外要件 |
|---------|----------|
| **要物合同**（实践合同）| 标的物的交付或其他给付的完成 |
| **要式合同** | 符合特定形式要件 |

> 合意内容与内心效果意思不一致时，**不是合同是否成立的问题，而是合同效力问题**（重大误解等制度处理）。

## 三、合同成立的法律意义

合同成立后通常同时生效，并因此在当事人之间发生债权债务关系。

## 四、所谓"意向书"或其他先合同文件

**意向书 vs 合同**：

| 文件类型 | 法律性质 |
|---------|----------|
| **合同** | 具有法律约束力 |
| **意向书**（letter of intent / term sheet）| 视具体条款判断 |
| **备忘录**（memorandum of understanding）| 视具体条款判断 |
| **框架协议** | 视具体条款判断 |

**判断关键**：
1. 内容是否已具备合同的核心要素
2. 是否明确表示"将来另行协商"
3. 当事人主观上是否有意受拘束
4. 是否已实际履行主要义务

## 第二节 合同的形式与内容

## 一、概要

合同形式指合同的**载体或外观表现**；合同内容指合同**实质性的权利义务条款**。

## 二、合同形式的目的

1. **举证功能**：固定证据，便于举证
2. **警示功能**：提醒当事人慎重
3. **行政管理**：满足法律监管要求（如登记、批准）
4. **透明度与可说明性**：政府采购合同等使用财政资金场合

## 三、合同形式的类型

| 形式类型 | 内涵 | 立法例 |
|---------|------|--------|
| **口头形式** | 当面或电话洽谈 | 一般合同（不要式为原则）|
| **书面形式** | 合同书、信件、数据电文（《民法典》第469条）| 建设工程合同、融资租赁合同、技术开发合同、政府采购合同 |
| **默示形式** | 通过行为推定 | 要约承诺的实践常态 |
| **登记形式** | 在主管机关登记 | 房地产抵押登记、股权转让工商变更登记 |
| **批准形式** | 经主管机关批准 | 外商投资企业股权转让合同报批义务 |

## 四、合同形式与合同内容的连接点：合同条款

合同条款 = 合同形式（外观）与合同内容（实质）的连接点。

**合同条款分类**：
- 必要条款（必备条款）：决定合同类型
- 一般条款
- 偶然条款（待定条款）
- 格式条款（《民法典》第496-498条）

## 五、合同形式缺陷的后果

| 形式要求 | 违反后果 |
|---------|----------|
| 不要式原则 | 一般无形式缺陷问题 |
| 书面形式 | 法律效果视具体规定而定 |
| 登记 | 未登记可能影响物权变动效力（如《民法典》第215条）|
| 批准 | 未报批不生效（外商投资企业股权转让等）|

## 六、形式瑕疵因履行而治愈

**重要规则**（《民法典》第490条）：
> 当事人未采用书面形式但已经履行主要义务的，合同成立。

**条件**：
1. 当事人未采用法律要求的书面形式
2. 已经履行主要义务
3. 对方接受履行

## 第三节 要约

## 一、要约的概念

**要约**（offer / Angebot）= 一方当事人向另一方表示希望与之订立合同，并提出合同主要条款的行为。

**《民法典》第472条**：要约是希望与他人订立合同的意思表示，需具备：
1. 内容具体确定
2. 表明经受要约人承诺，要约人即受该意思表示约束

## 二、要约的构成要件

### （一）主体合格

要约人须有相应的行为能力（通过代理人作出时，代理人须有相应授权）。

### （二）内容具体确定

内容"具体确定"指要约的内容足以**确定合同的主要条款**（如标的、数量、价格、价款、履行期限、履行地点等）。

### （三）表明经受要约人承诺即受拘束

要约须表明：经受要约人承诺，要约人即受该意思表示约束。

### （四）向相对人作出

要约须向特定人或特定范围的人作出；向不特定人作出通常构成**要约邀请**。

## 三、要约与要约邀请

| 类型 | 法律性质 | 典型例子 |
|------|---------|---------|
| **要约** | 一经受承诺即成立合同 | 商品标明售价、自动售货机 |
| **要约邀请**（要约引诱）| 邀请他人向自己发出要约 | 广告、招标公告、拍卖公告、寄送价目表 |

## 四、要约的形式

| 形式 | 说明 |
|------|------|
| **具体方式** | 口头、书面、数据电文 |
| **构成要约与否需具体分析的情形** | 商品标价、自动售货机、商品广告、悬赏广告、招标投标 |
| **要约邀请的具体情形** | 拍卖公告、招标公告、寄送价目表、一般的商业广告 |

## 五、要约的法律效力

### （一）要约的生效时间：**到达主义**原则

- **对话者间的要约**：了解时生效
- **隔地者间的要约**：到达受要约人时生效（《民法典》第474条）

### （二）要约法律效力的内容

要约生效后：
- 对要约人：要约人受拘束，不得随意撤回/撤销
- 对受要约人：取得承诺的权利（而非义务）

### （三）要约的存续期间

| 情形 | 存续期间 |
|------|----------|
| **定有承诺期限** | 在承诺期限内有效 |
| **未定有承诺期限** | 对话要约：即时承诺有效；非对话要约：合理期限 |

## 六、要约的撤回和撤销

| 行为 | 含义 | 时点 |
|------|------|------|
| **撤回**（withdrawal）| 要约人在要约生效前取消要约 | 要约到达受要约人**之前** |
| **撤销**（revocation）| 要约人在要约生效后取消要约 | 要约到达受要约人**之后** |

**撤销的限制**（《民法典》第476条）：
> 要约可以撤销，但有下列情形之一的除外：
> 1. 要约人以确定承诺期限或者其他形式明示要约不可撤销
> 2. 受要约人有理由认为要约是不可撤销的，并已经为履行合同做了合理准备工作

## 七、要约的失效

《民法典》第478条规定的要约失效情形：
1. 拒绝要约的通知到达要约人
2. 要约人依法撤销要约
3. 承诺期限届满，受要约人未作出承诺
4. 受要约人对要约的内容作出实质性变更

## 第四节 承诺

## 一、承诺的概念

**承诺**（acceptance / Annahme）= 受要约人同意要约的意思表示。

**《民法典》第479条**：承诺是受要约人同意要约的意思表示。

## 二、承诺的构成要件

1. **由受要约人作出**（特定人或特定范围）
2. **向要约人作出**
3. **内容与要约内容一致**（实质性变更构成反要约）
4. **承诺期限届满前到达要约人**

## 三、承诺的方式

| 方式 | 内涵 | 立法例 |
|------|------|--------|
| **明示方式** | 口头、书面、数据电文 | 一般承诺 |
| **默示方式**（意思实现）| 通过履行行为作出承诺 | 《民法典》第484条：作出承诺的行为 |
| **沉默** | 一般不构成承诺 | 例外：当事人约定或交易习惯 |

## 四、承诺的生效时间

| 要约方式 | 承诺生效 |
|---------|----------|
| **对话要约** | 了解时生效 |
| **非对话要约** | **到达主义**：到达要约人时生效（《民法典》第484条） |

> **对照传统**：英美法采"投递主义"（mailbox rule），承诺发出即生效；我国采到达主义。

## 五、承诺的撤回

承诺的撤回（《民法典》第485条）：
- 撤回承诺的通知须**先于承诺到达**或**同时到达**要约人
- 撤回承诺 = 阻止承诺生效

## 六、"格式之争"问题

> **格式之争**（battle of forms）= 当事人通过各自的格式合同条款进行交易时，各方格式条款不一致时的处理问题

《合同编通则解释》的处理思路：
1. 先达成合意的部分优先于格式条款
2. 实质性变更不构成承诺，构成反要约
3. 非实质性变更 → 承诺有效，冲突条款不生效

## 第五节 依要约承诺以外的方式成立合同

## 一、交叉要约

**交叉要约**（cross-offers）= 当事人互为要约，且内容一致。

**效力**：
- 多数学说认为交叉要约不当然成立合同，但有理由认为可成立合同
- 实务中通常仍以承诺或履行为准

## 二、意思实现

**意思实现**（Willensbetätigung; performative acceptance）= 通过履行行为作出承诺。

**《民法典》第484条**：承诺应当以通知的方式作出；根据交易习惯或者要约表明可以通过行为作出承诺的除外。

**典型情形**：
- 预先交付标的物
- 预先付款
- 履行其他主要义务

## 三、事实的合同关系

**事实的合同关系**（faktische Vertragsverhältnisse）= 因事实过程而成立的合同关系（详见第二章讨论的豪普特 1941 年理论）。

**适用情形**：
- 自助加油站
- 公共交通乘坐
- 自动售货机购物
- 医疗服务（紧急救治）

## 第六节 合同成立的时间与地点

## 一、合同成立的时间

| 合同类型 | 成立时间 |
|---------|----------|
| **要式合同** | 完成特定形式要件时 |
| **要物合同** | 标的物交付时 |
| **承诺生效主义**（一般）| 承诺生效时（到达主义）|
| **交叉要约** | 双方要约均到达时 |
| **意思实现** | 履行行为完成时 |
| **事实合同关系** | 事实过程发生时 |

## 二、合同成立的地点

| 情形 | 成立地点 |
|------|----------|
| **对话要约** | 要约人所在地 |
| **非对话要约** | 承诺生效地点（一般承诺到达要约人所在地）|
| **数据电文** | 收件人主营业地；无主营业地时为经常居住地 |

**意义**：
- 合同纠纷的地域管辖（民诉法）
- 法律适用（涉外合同）
- 合同签订地证明

## 第七节 缔约过失责任

## 一、概要

**缔约过失责任**（culpa in contrahendo）= 缔约一方因违背诚信原则导致合同不成立或无效，给对方造成损失的，应当承担赔偿责任。

**《民法典》第500条**：
> 当事人在订立合同过程中有下列情形之一，造成对方损失的，应当承担赔偿责任：
> 1. 假借订立合同，恶意进行磋商
> 2. 故意隐瞒与订立合同有关的重要事实或者提供虚假情况
> 3. 有其他违背诚信原则的行为

## 二、缔约过失的类型

| 类型 | 立法例/案例 |
|------|-----------|
| **恶意磋商** | 《民法典》第500条第1项："假借订立合同，恶意进行磋商" |
| **隐瞒重要事实或提供虚假情况** | 《民法典》第500条第2项 |
| **其他违背诚信原则的行为** | 《民法典》第500条第3项：兜底条款 |
| **合同无效时的缔约过失** | 《民法典》第157条：民事法律行为无效时的后果 |
| **合同被撤销时的缔约过失** | 《民法典》第157条类推 |

## 三、缔约过失之赔偿责任的归责事由

**主流观点**：**过错责任原则**

- 须以缔约人主观上有过错（故意或过失）为要件
- 不要求主观恶意；过失违反诚信原则即可

## 四、缔约过失责任的性质

| 学说 | 立场 |
|------|------|
| **缔约上过失说**（德国通说）| 法定特别债之关系 |
| **侵权行为说** | 适用侵权责任一般规则 |
| **合同责任说** | 介于合同与侵权之间 |

**我国主流**：法定特别责任（《民法典》第500条独立规定）

## 五、缔约过失赔偿责任的构成

| 构成要件 | 内容 |
|---------|------|
| **违法行为** | 违反诚信原则的行为（恶意磋商、隐瞒、提供虚假情况等）|
| **主观过错** | 故意或过失 |
| **损害事实** | 对方因合同不成立/无效/被撤销所受损失（信赖利益）|
| **因果关系** | 违法行为与损害之间有因果关系 |

**赔偿范围**：**信赖利益损失**（非履行利益损失）

| 类型 | 范围 |
|------|------|
| 信赖利益 | 缔约费用、准备履行的费用、丧失与第三人缔约机会的损失 |
| 不包括 | 履行利益（合同有效可获利益）|
| 例外 | 履行利益赔偿如不超过履行利益数额 |

## 六、先合同义务

**先合同义务**（vorvertragliche Pflichten）= 缔约过程中基于诚信原则产生的义务。

**主要类型**：
1. **协力义务** = 相互协助促成合同订立
2. **通知义务** = 及时告知与缔约有关的重要事项
3. **保护义务** = 保护对方人身和财产安全（缔约场所安全）
4. **保密义务**（《民法典》第501条）= 不泄露对方商业秘密
5. **不欺诈义务** = 不得隐瞒重要事实或提供虚假情况
6. **真实陈述义务**

## 七、缔约过失的法律后果

### （一）赔偿范围

**信赖利益**（Vertrauensschaden）：
- 已支付的费用
- 准备履行支付的费用
- 丧失缔约机会的损失

**与履行利益的关系**：
- 原则上信赖利益不超过履行利益
- 赔偿后达到如同合同从未谈判过的状态

### （二）请求权基础

| 法律基础 | 适用 |
|---------|------|
| 《民法典》第500条 | 合同订立过程中的缔约过失 |

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **合同订立**（Vertragsabschluss）| 动态过程 |
| **合同成立**（Zustandekommen）| 静态结果 |
| **合意**（consensus ad idem）| 双方意思表示达成一致 |
| **主观说** | 看重当事人实际意思 |
| **客观说**（表示主义）| 看重当事人外在表征 |
| **要约**（offer）| 希望与他人订立合同的意思表示 |
| **要约邀请**（invitation to treat）| 邀请他人向自己发出要约 |
| **承诺**（acceptance）| 受要约人同意要约的意思表示 |
| **格式之争**（battle of forms）| 双方格式条款不一致时的处理 |
| **交叉要约**（cross-offers）| 当事人互为要约且内容一致 |
| **意思实现**（Willensbetätigung）| 通过履行行为作出承诺 |
| **事实的合同关系** | 因事实过程而成立的合同关系 |
| **缔约过失责任**（culpa in contrahendo）| 缔约方违背诚信原则的赔偿责任 |
| **先合同义务**（vorvertragliche Pflichten）| 缔约过程中基于诚信的义务 |
| **信赖利益**（Vertrauensschaden）| 因信赖合同有效所受损失 |
| **履行利益** | 合同有效可获利益 |
| **到达主义** | 意思表示到达相对人时生效 |
| **投递主义**（mailbox rule）| 承诺发出即生效（英美法）|
