# 诈骗罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(数额较大)** | 三年以下有期徒刑、拘役或者管制 + 罚金 | **3 月拘役-1 年** |
| **第二档(数额巨大)** | 三年以上十年以下有期徒刑 + 罚金 | **3-4 年** |
| **第三档(数额特别巨大)** | 十年以上有期徒刑 / 无期 | **10-12 年** |

## 二、第一档 · 3 月拘役-1 年起刑点

**入罪触发**:数额较大起点。

**基准刑递增**:犯罪数额每增 **1500 元** → + **1 月**。

## 三、第二档 · 3-4 年起刑点

**入罪触发**:数额巨大 + "其他严重情节"。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 犯罪数额每增 **5500 元** | + **1 月** |
| "其他严重情节"每多 1 种 | + **6 月-2 年** |

## 四、第三档 · 10-12 年起刑点

**入罪触发**:数额特别巨大 + "其他特别严重情节"。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 犯罪数额每增 **35000 元** | + **1 月** |
| "其他特别严重情节"每多 1 种 | + **6 月-2 年** |

## 五、从重情节(3 类,13 种电信网络诈骗 + 累犯)

**1. 13 种情形成 +30% 以下**(每多 1 种 + 10% 以下):
- 短信 / 电话 / 互联网 / 广播 / 报刊不特定多数人诈骗
- 诈骗抢险 / 优抚 / 扶贫 / 移民 / 救济 / 医疗款物
- 以赈灾募捐名义
- 弱势人员(残疾人 / 老人 / 丧失劳动能力)
- 造成被害人自杀 / 精神失常
- 冒充司法机关 + 电信网络诈骗
- 组织 / 指挥电信网络诈骗团伙
- 境外实施电信网络诈骗
- 曾因电信网络诈骗受过刑 / 2 年内行罚
- 利用电话追呼系统
- "钓鱼网站" / "木马"程序 / 网络渗透

**2. 多次实施 → +20% 以下**
**3. 为吸毒 / 赌博 → +20% 以下**

## 六、从宽情节(4 类)

1. 生活所迫 / 学习 / 治病急需 + 人身危险性不大 → **−20% 以下**
2. 案发前归还 → **−30% 以下**
3. 诈骗近亲属 + 谅解 → 一般**不作犯罪**;确需追究 → **−20-50%**
4. 其他从轻情形

## 七、罚金

- 单处罚金:**1-2 倍**,最低 5000 元
- 三年以下:**1000-50000 元**
- 三年-十年:**20000-200000 元**
- 十年以上:**100000-500000 元**

## 八、缓刑适用(电信网络诈骗从严)

**一般可以适用**(任一):
1. 生活所迫 / 学习 / 治病急需
2. 案发前主动归还
3. 积极退赔大部分 + 谅解
4. 其他可适用情形

**一般不适用**(任一):
1. 为吸毒 / 赌博 / 违法犯罪活动诈骗
2. 弱势人员(残疾 / 老年 / 未成年 / 在校学生 / 丧失劳动能力)
3. 医院病人或亲友
4. 抢险 / 优抚 / 扶贫 / 移民 / 救济 / 医疗款物
5. 曾因诈骗受过刑 / 一年内行拘
6. 造成被害人自杀 / 死亡 / 精神失常
7. 造成恶劣社会影响
