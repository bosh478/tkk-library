# 非法占有目的（张明楷 · 理论提炼）

> **理论定位**：诈骗罪**主观要件的核心**——是否具有非法占有目的，是区分诈骗罪与民事纠纷、合同纠纷、贷款纠纷、骗取贷款罪、贷款诈骗罪等罪与非罪、此罪与彼罪的关键。

---

## 一、非法占有目的的概念

### 张明楷的核心命题（行 2374-2537）

> "非法占有目的，表现为**排除意思**与**利用意思**"

**两个核心要素**：
1. **排除意思**（排除权利人对其财物的利用）
2. **利用意思**（按财物可能具有的用途进行利用）

① 来源：行 2374-2537[^fn1]

### "占有" ≠ 民法占有

> "非法占有目的中的'占有'并不等同于民法中的占有，否则根本不能说明贷款诈骗罪的非法占有目的。"

**张明楷的解释**：
- **民法占有**：所有权四项权能之一（占有、使用、收益、处分）
- **刑法占有**（非法占有目的）：**排除意思 + 利用意思**（实质判断）

**意义**：借款人取得贷款**民法上**已构成"占有"，但**刑法上**仍需判断是否具有"非法占有目的"。

① 来源：行 2472[^fn2]

## 二、排除意思

### 定义

行为人**永久性地或持续性地排除权利人对其财物的利用**的意思。

### 核心争议：永久性 vs 持续性

| 类型 | 含义 | 典型情形 |
|------|------|---------|
| **永久性** | 永久剥夺权利人所有权 | 取得财物后**挥霍/转让/用于违法活动** |
| **持续性** | 长期占有 | 取得财物后**携款潜逃/隐匿财产** |

**张明楷的立场**：

> "在一时性地取得他人财物的行为不具有刑事违法性等情况下，通常只有具有**永久性或持续性的排除意思**时，才能认定行为人具有非法占有目的。"

### 排除意思的认定

| 情形 | 是否具有排除意思 |
|------|------------------|
| 取得财物后挥霍 | ✅ 是 |
| 取得财物后携款潜逃 | ✅ 是 |
| 取得财物后隐匿/转移 | ✅ 是 |
| 取得财物后用于经营（无力归还） | ⚠️ 待判断（一般认为**否**） |
| 取得财物后短期借用 | ❌ 否 |

## 三、利用意思

### 定义

行为人**按财物可能具有的用途进行利用**的意思（包括享受财物本身的利益 + 利用财物换取其他利益）。

### 利用意思的必要性

**张明楷的核心命题**：

> "仅有排除意思而没有利用意思，难以认定非法占有目的。例如，将他人财物藏匿但不使用，可能构成侵占罪而非诈骗罪。"

### 利用意思的认定

| 情形 | 是否具有利用意思 |
|------|------------------|
| 用于个人消费 | ✅ 是 |
| 用于经营/投资 | ✅ 是 |
| 用于赠与/还债 | ✅ 是 |
| 用于违法犯罪活动 | ✅ 是 |
| 单纯藏匿不使用 | ❌ 否 |

## 四、非法占有目的的产生时间

### 张明楷的立场（行 2374-2537）

> "犯罪目的是犯罪人主观上通过犯罪行为所希望达到的结果或形成的状态；**目的只能是行为时的目的**，目的的有无以及目的的内容都应以**行为时**为基准进行判断。"

**反对"事后目的说"**：

> "行为人完全可能在行为时没有责任能力，但事后具有责任能力。我们显然不能因其事后具有责任能力，就追究其刑事责任。"

> "如果以行为前或者行为后的心理状态为根据认定行为人具有刑法所要求的'目的'，便导致刑法对目的的规定丧失了意义，从而**擅自取消了法定的责任要素**。"

① 来源：行 3600-3700[^fn3]

### 实务命题

| 时点 | 是否成立非法占有目的 |
|------|-------------------|
| **行为时**已有 | ✅ 成立诈骗罪 |
| **行为前**已有 | ❌ 行为前犯意 ≠ 行为时故意 |
| **行为后**产生 | ❌ 行为后目的 ≠ 行为时目的 |
| **行为时部分有** | ⚠️ 部分行为时已有 → 既有诈骗罪又有其他罪 |

### 张明楷的具体应用

**典型情形**：
- 行为人非法吸收公众存款时具有归还本息的意图；但在取得了公众存款之后产生非法占有的目的的 → **不认定为集资诈骗罪**，依然只能认定为**非法吸收公众存款罪**
- 行为人向银行申请贷款时具有归还本息的意图；但在取得银行贷款之后产生非法占有目的不再归还本息的 → **不成立贷款诈骗罪**

**意义**：**严格责任主义**——非法占有目的必须行为时存在。

## 五、非法占有目的的"非法"含义

**张明楷的解读**：

> "非法的含义 = 违反法律或者公序良俗"

**关键**：
- 违反法律 = 违反民事法律/行政法律/刑事法律
- 违反公序良俗 = 违反社会一般道德观念

## 六、非法占有目的的认定方法

### 1. 客观推定方法

通过客观行为推定非法占有目的：

| 客观情形 | 推定结论 |
|----------|---------|
| 取得财物后挥霍/转移 | ✅ 有非法占有目的 |
| 取得财物后携款潜逃 | ✅ 有非法占有目的 |
| 取得财物后隐匿财产 | ✅ 有非法占有目的 |
| 取得财物后拒不返还 | ✅ 有非法占有目的 |
| 取得财物后用于经营（部分） | ⚠️ 待结合其他情形 |
| 取得财物后积极归还 | ❌ 一般无非法占有目的 |

### 2. 主观陈述方法

通过行为人的供述/书面材料认定：

- 行为人明确表示"不打算归还" → ✅ 有非法占有目的
- 行为人表示"准备归还" → ⚠️ 待结合其他情形

### 3. 综合判断方法

主客观结合：

- 客观行为 + 主观陈述 + 行为人经济状况 + 行为人履约能力 → 综合判断

## 七、非法占有目的与共犯

### 张明楷的核心命题（行 2570-2580）

> "非法占有目的表现为使自己或者第三者占有，所以，**即使取款人仅具有使正犯非法占有的目的，也能认定为具有非法占有目的**。"

**意义**：
- **正犯**：具有**为自己或第三者**非法占有目的 → 成立诈骗罪
- **共犯**：**只要知道正犯具有非法占有目的**即可 → 不要求共犯具有独立的非法占有目的
- **共犯具有独立非法占有目的** → 成立更重的共犯

## 八、非法占有目的的体系性意义

### 1. 区分诈骗罪与民事纠纷

| 维度 | 诈骗罪 | 民事纠纷 |
|------|--------|----------|
| 非法占有目的 | ✅ 有 | ❌ 无 |
| 虚构事实 | 主观虚构 | 主观误解 |
| 履行能力 | 没有 | 有/部分有 |
| 财物用途 | 挥霍/转移 | 经营/投资 |

### 2. 区分贷款诈骗罪与骗取贷款罪

| 维度 | 贷款诈骗罪 | 骗取贷款罪 |
|------|-----------|----------|
| 非法占有目的 | ✅ 有 | ❌ 无 |
| 欺骗手段 | 5 种特定 | 一般欺骗 |
| 犯罪形态 | 数额较大即可 | **结果犯**（重大损失） |

### 3. 区分集资诈骗罪与非法吸收公众存款罪

| 维度 | 集资诈骗罪 | 非法吸收公众存款罪 |
|------|-----------|------------------|
| 非法占有目的 | ✅ 有 | ❌ 无 |
| 公开宣传 | 是 | 是 |
| 对象 | 社会公众 | 社会公众 |
