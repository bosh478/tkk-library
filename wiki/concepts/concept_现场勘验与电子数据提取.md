# 现场勘验与电子数据提取

## 本章重点内容与学习要求

电子证据分析的每一个步骤都环环相扣，任何一个步骤的失误或者错误，都可能导致一个不同的鉴定结论，影响司法公正。作为计算机调查人员，规范、科学、准确地做好每一个调查环节，非常重要。

与传统案件一样，涉计算机案件也需要进行现场调查。现场勘验是调查工作的第一步，后续所有工作都是基于现场勘验的结果来进行，因此它是整个取证工作最重要的环节之一。充分做好现场调查准备工作，可为今后的工作打下坚实的基础。

**学习要求**：
- 掌握现场勘验规划与准备的常识
- 了解现场取证所需的设备
- 掌握如何有效地进行现场勘验
- 掌握如何提取和固定有效的电子证据

## 第一节 电子数据现场勘验

### 一、电子数据现场勘验的任务

电子数据现场勘验的核心任务包括：

1. **发现**：发现与案件相关的电子数据
2. **固定**：固定电子证据不被破坏
3. **提取**：提取与案件相关的电子数据
4. **封存**：封存电子设备
5. **搜查**：对现场进行搜查，提取传统物证及其他信息
6. **记录**：制作和存储现场信息资料
7. **判断**：判断案件性质，确定案件方向和范围，为诉讼工作提供线索和证据

**重要特点**：由于电子数据具有**易失性**和**易修改性**等特点，在电子数据现场勘验过程中的任何疏忽都可能导致后期鉴定工作出现偏差，进而影响鉴定结论的方向和公正。因此，对电子数据现场勘验的每个步骤都做了详细要求和规定。

### 二、现场勘验规划与准备

#### （一）物理位置因素

前往现场进行勘验之前，必须做好充分的准备工作，包括了解案件的基本情况、现场所在位置、现场可能有哪些人、要取证的对象可能包括哪些等。

**关键考量**：

1. **人身安全保障**：充分了解现场所在的位置有助于保障人身安全

2. **证据安全**：证据安全决定了勘验工作的成败，必须考虑勘验地点的相关环境
   - 楼层：对象有可能从窗户丢弃计算机存储介质（移动硬盘、U盘、笔记本计算机等），勘验人员应将现场门窗所对应的一定范围也列入搜索范围
   - 勘验范围：可能是一个人的住所，也可能是一个拥有百台计算机的公司或网吧

3. **大规模取证解决方案**：对于机器非常多的案件，可能面临人手不够、无法确定重点对象、时间紧等问题。解决方案：需借助专用取证设备，预先定义要获取的特定数据，并生成多个"取证精灵"，快速提取多台机器数据，之后再汇总分析

4. **损坏介质处理**：对于被故意破坏的介质，也应作为证物进行收集与封存，后期进行物理恢复将有可能从中得到关键证据

#### （二）现场人员因素

根据现场可能出现的情况，确定到场人员的名单。一般把我方人员分成两组：

1. **安全保障组**：主要负责现场人员和设备的安全，防止现场的疑犯伤害调查人员或破坏设备

2. **现场勘验组**：
   - 职责：记录现场笔录，收集所有与案件有关的证物（计算机及外围设备、移动介质及其他载体），根据案件特点和现场情况妥善处理计算机
   - 要求：现场勘验人员必须是经过现场勘验相关培训才能执行勘验任务
   - 培训内容：电子证据的固定方法、保护所扣押计算机安全的手段、从Windows交换文件及计算机硬盘中提取遗留的网页浏览记录、对相关文件使用MD5算法计算散列值、使用文件头信息从介质中恢复图像文件、文件存储结构及对回收站中数据的解析

#### （三）应用系统因素

**必须考虑以下环节**：

| 考量因素 | 具体内容 |
|----------|----------|
| 证据类型 | 不同案例类型所需电子证据内容不同（经济类案件侧重文档、报表和财务系统；软件著作权类案件侧重编程环境、语言及源代码） |
| 搜查范围 | 是否只允许查找某台计算机或相关文件 |
| 计算机数量 | 决定需要前往的人数和所携带装备 |
| 操作系统 | 不同操作系统直接造成现场提取方法的差异 |
| 加密情况 | 是否使用微软EFS、PGPDisk、BestCrypt等加密手段 |
| 联网状态 | 原则上在调查过程中应断开网络，防止远程数据删除 |
| 服务器位置 | 是在单位内部还是主机托管，运行什么操作系统 |
| 网络拓扑 | 网络拓扑图可帮助发现更全面的计算机及相关设备位置 |
| 备份位置 | 本地备份还是远程备份 |
| 日志位置 | 代理服务器、Web服务器、防火墙和其他重要系统的日志位置 |
| IT管理 | 内部人员还是外包，网络管理员是否需要调查 |
| 无线网络 | 是否存在无线网络，类型和覆盖范围 |
| 关机需求 | 根据当前系统判断计算机是否需要关闭及如何关闭 |
| 嫌疑人情况 | 多少人，是个人犯罪还是集体犯罪，使用什么设备 |
| 关键字搜索 | 需要使用什么关键字进行搜索 |
| 易失数据 | 网络连接、运行进程或其他易失数据对调查是否重要 |

#### （四）装备规划与准备

**基本原则**：在调查人员的工具包里至少应具有必需的基本设备。检查列表是很有必要的，调查人员应根据实际需要定制一个设备列表清单。

**常带设备清单**：

1. **勘查箱**：
   - 照相机或摄像机：对现场及屏幕信息进行拍照或录像
   - 螺丝刀、小钳子：用于移除线缆接头等
   - 标签：用于标记系统各个组件，包括线缆和插座
   - 运输过程中用于保护证物的纸箱或纸袋
   - 彩色水笔：用来对要搬运的证物进行编号
   - 电磁信号屏蔽袋：用于对手机等设备进行信号屏蔽
   - 多功能充电器：为设备补充电源
   - 电子证据只读锁

2. **取证专用介质复制设备**：
   - 硬盘（赴现场前应先擦除干净）
   - 高速硬盘复制机：利用专门复制设备将原始存储介质（主要是硬盘）中的电子数据完全镜像下来

3. **现场取证工具**：
   - 取证大师、EnCase、FTK、X-Ways等分析软件
   - 关键数据获取系统
   - 仿真系统
   - 密码破解系统

4. **袖珍式打印机**：方便现场进行快速打印相关涉案文档，让对象或证人进行签字确认

**现场保护原则**：

1. **禁止嫌疑人接触数字化设备**：现场勘验时禁止任何非司法人员接触计算机、电源、网络设备和数字化证据存储设备

2. **防止被隐蔽手段故意破坏证据**：
   - 嫌疑人可能通过网络、拨入设备远程控制计算机或网络
   - 可切断有线网络和无线网络连接（关闭交换机、HUB或无线接入设备）
   - 嫌疑人可能通过切断电源的方式破坏数据，需将嫌疑人控制在不可能接触任何电源开关的区域

3. **防止调查人员无意中破坏证据**

4. **防止正在运行的系统破坏证据**：对于正在运行的系统，处理的基本原则是尽可能减少电子数据被湮没的可能性，如果存在写入或删除等操作，应及时停止

### 三、现场电子数据处理

#### （一）记录现场情况

对现场进行记录是搜查小组开展工作的前提。在对所有设备触摸与移除之前，通过绘图、录像、拍照等方式对现场进行记录。

**方位草图应包含**：发案地点、发案时间、制图单位、制图人、制图时间、现场方位、中心现场位置、图例说明等

**拍照要求**：
- 进入现场后应拍摄现场概貌图，记录下现场的基本情况
- 应对中心现场进行拍照记录
- 对涉案计算机及周边设备进行编号并拍照，按证据编号将其记录到现场勘验笔录中

#### （二）识别潜在证据

计算机和相关证据的覆盖范围从大型计算机到微型掌上电脑再到软盘、CD或者最小的芯片。这些介质上的图形文件、音频文件、文本文件以及其他数据很容易改变或丢失。要求调查人员依照相关的法规、方针和方法对这些设备进行识别、保护和搜查。

#### （三）全面搜查证据

**搜查原则**：

1. **检查与目标计算机互联的系统**：
   - 查看网络、电缆、电源等线路的连接走向，是否有连接到其他地理位置
   - 查看是否有无线局域网或其他无线网络连接方式
   - 检查系统是否通过调制解调器提供拨入服务

2. **搜查数字化证据存储设备**：
   - 计算机、PDA、移动存储媒介（优盘、活动硬盘、ZIP盘、软盘、光盘、存储卡等）
   - 移动电话、电话、扫描仪、打印机、复印机
   - 备份磁带、数码相机、数码摄像机、数码录音笔
   - 智能卡、磁卡、嵌入式微电脑等

3. **外部设备的搜查**：
   - 搜查存储媒介的读写设备
   - 打印机色带（包括废弃和当前使用的），可能存留最近打印信息
   - 与无法识别设备相关的说明书、软件、配套硬件
   - 专用软件的说明书、软件狗、配套光盘、配套硬件

4. **其他证据的搜查**：
   - 嫌疑人使用的笔记本、纸张等记录信息（账号、口令、联系人等）
   - 计算机周边物品（便笺、已打印文档、废纸篓中废弃纸张等）
   - 现场周边设施（工作台、书房、床头柜、储藏室、箱包、文件柜、抽屉、衣柜、窗户周边等）

#### （四）固定易失证据

**易丢失证据**：在关闭电源之后或者在运输过程中可能丢失的信息

**需要固定易丢失证据的情形**：

1. **犯罪行为正在发生**（如系统正在对外实施攻击、群发垃圾邮件，或者犯罪嫌疑人正在使用该计算机），则应当提取易丢失证据。提取内容：时间信息、屏幕上显示的内容、系统运行状态等

2. **犯罪行为已停止且系统曾重新启动**：只需提取时间信息，无须提取其他易丢失证据

**时间信息的提取**：
- 任何情况下，对于任何有内置时钟的设备，都必须记录：当前时间、该时间与北京时间的时差、时区设置
- 计算机处于开机状态时可用截图方式；关机状态时可通过进入主机BIOS提取时间信息

**系统运行状态的提取**：

| 系统类型 | 需提取的系统状态信息 |
|----------|---------------------|
| 传统案件 | 系统当前运行的进程、每个进程当前打开的文件、每个进程内存中的内容、当前网络连接状态 |
| 计算机入侵案件 | 当前运行的进程、每个进程当前打开的文件、每个进程内存中的内容、每个进程提供的网络服务端口、每个进程所依赖的模块列表、当前网络连接状态和网卡当前运行模式、是否存在侦听、当前网络共享列表、MAC地址、ARP缓存表、当前登录用户及登录时间 |
| UNIX/LINUX系统 | 还需提取当前登录用户正在执行的命令、以前执行的命令列表 |

**其他电子设备易丢失证据**：对于传真机、电话、打印机、复印机、扫描仪、GPS导航仪等，在切断电源前必须提取最近的相关信息

**提取原则**：
- 不得使用目标系统上的程序实施提取（可能被攻击者替换）
- 不得使用消耗大量资源的软件实施提取（一般不建议使用图形界面软件，而要使用命令行界面软件）
- 不得将提取的信息存储在目标系统原有的存储媒介中
- 提取过程中必须有见证人或嫌疑人在场，详细记录提取过程（执行的命令或使用摄像机记录）和时间
- 对于提取得到的信息必须使用散列算法（MD5或SHA1）计算散列值，打印并由见证人或嫌疑人签名

#### （五）关闭计算机

**关机原则**：调查人员应尽量避免对任意证据造成破坏，并不得在这些部件上留下调查人员的指纹。全程使用防静电手套来处理电子设备。

**关机方式由操作系统决定**：

| 操作系统 | 系统特征 | 关机过程 |
|----------|----------|----------|
| DOS | 全屏幕黑色背景，显示系统提示符 | 拍摄屏幕，注意运行着的程序。把插头从计算机背部拔下 |
| Windows 3.1/95/NT | 使用程序管理器，具有Windows标志的启动按钮 | 拍摄屏幕，注意运行着的程序。把插头从计算机背部拔下 |
| Windows 98/Me/2000/XP/2003 | 具有Windows标志的启动按钮（XP/2003为绿色按钮） | 拍摄屏幕，注意运行着的程序。把插头从计算机背部拔下 |
| Linux/Unix | GUI查找启动按钮符号或图标；控制台模式提示符：[user@host dir]$ | 使用正常关机处理过程，需具有根目录权限。如为图形界面，右击桌面选择控制台或终端，查找#提示符，输入su命令，输入：synch;synch;halt |
| Macintosh | 顶层左边角落有苹果标志和回收站图标 | 拍摄屏幕，记录系统时间，从尾部把插头拔下 |

**注意事项**：
- 如果决定拔下插头断电，应把插头从机箱背部拔下，不应拔墙上的插头（计算机会连接UPS，拔墙上插头会触发UPS发出关机信息，可能导致数据写入）
- 关闭笔记本需同时拔下电池和电源适配器
- 关机后应记录所有行为以及进行相关操作的方法与原因

#### （六）封存与包装

**缆线标识**：在封存计算机前，需要把所有在计算机尾部的线缆做标识并拍照。使用唯一字母标识每根电缆和每个端口，从不同角度拍摄计算机尾部，展示计算机如何进行连接。

**封存与包装目的**：防止证据在运输过程中被破坏

**封存原则**：
1. 保证封条贴在正确位置，除非破坏封条否则无法使用封存设备
2. 对于可移动介质（移动硬盘、U盘等），贴上标签后用防静电袋装好，封条贴在封口处
3. 每个封装必须贴上具有唯一标识的封条，并让嫌疑人在封条上签字确认
4. 证物需贴上标签，注明提取时间、人员姓名以及设备名称、型号等信息

**标签内容**：日期、位置、时间、案件、机构名称等，同时提供流程监管功能

**电子介质包装方法**：
1. 使用大小合适、能够吸收碰撞能量的包装材料
2. 加硅凝胶吸潮材料
3. 使用防静电袋进行静电放电保护
4. 固定存储介质，防止运输过程中损坏
5. 使用大小合适的外包装箱
6. 推荐使用软硅胶硬盘保护套和硬塑胶硬盘保护盒

**相关单据**：
- 现场勘验笔录：记录现场勘验时间、处理方法及处置理由
- 封存电子证据清单：记录所封存物证的名称、型号、特征和数量等
- 勘验检查照片记录：勘验过程中所拍摄的照片及说明
- 固定电子证据清单：记录所固定的电子数据文件名称、来源、校验值等
- 现场勘验笔录签名：记录参与现场勘验人员的信息及签名

## 第二节 电子数据提取、固定的方法

### 一、使用硬盘复制机进行数据提取、固定

**现场电子数据固定工作流程**：
1. 记录现场计算机的连接现状
2. 固定当前对象计算机的易失性数据
3. 关闭当前计算机系统
4. 拆卸当前计算机取出硬盘介质
5. 对硬盘介质进行写保护处理
6. 使用专用设备进行硬盘复制
7. 计算原始硬盘介质Hash值并封存
8. 封存硬盘介质副本
9. 现场固定结束

**高速硬盘复制机**：
- 基于位对位复制原理的硬盘复制设备
- 可进行原始硬盘介质完整的副本制作
- 制作的硬盘介质副本与原始硬盘介质完全一致
- 可通过MD5等散列算法进行一致性验证
- 得到全世界大多数国家司法调查部门的认可

**注意事项**：硬盘接口类型众多，不同型号硬盘复制机支持的硬盘接口不尽相同，需注意选择与原始硬盘接口匹配的复制机

#### （一）不同接口介质复制

使用DC PRO硬盘复制机进行复制：
1. 正确识别硬盘接口（如IDE接口需将对象硬盘跳线设置为主盘Master模式）
2. 准备容量不小于原始证据硬盘的空白硬盘（如目标硬盘包含数据需先用DC PRO擦除）
3. 将原始证据硬盘与目标硬盘连接，仔细检查连接是否妥善牢固
4. 连接DC PRO电源，打开设备电源开关，等待主机初始化
5. 设备默认为"COPY"复制模式，直接按下"执行"按键即可开始复制

#### （二）非标接口硬盘复制

对于2.5英寸、1.8英寸规格的特殊硬盘，需使用特定转换卡将接口转换为标准的3.5英寸硬盘接口后方可进行复制。

### 二、使用只读锁+软件进行数据提取、固定

**只读锁**：用于保护原始数据介质不被修改的硬件设备，能够阻止任何对所连接的设备的修改操作

**CyberBlock电子数据只读锁**：
- CyberBlock-SATA/IDE只读锁
- CyberBlock-SCSI只读锁
- CyberBlock-USB只读锁
- CyberBlock-Card只读读卡器

所有CyberBlock只读锁均采用硬件方式进行写保护，能够有效保证原始数据介质不被修改。

**使用方法**：
1. 选择只读锁类型
2. 选择电源（两种适配器供电方式，不能同时使用）
3. 连接设备电缆（三种主机接口：FireWire-A、FireWire-B及USB 2.0，只能选择一种；FireWire接口可级联，USB不可级联）
4. 硬盘设置（IDE硬盘跳线必须设置为主盘模式Master）
5. LED灯显示状态判断
6. 更换硬盘时需遵循正确步骤
7. 分析结束断开硬盘时需按正确顺序操作

**取证分析软件固定方法**（以"取证大师"为例）：
1. 打开取证分析软件，进行新建案例操作
2. 添加设备，将通过只读锁连接的原始数据硬盘添加到案例中
3. 软件对原始数据硬盘进行载入后，选择需要获取镜像的硬盘分区
4. 右键点击获取，开始镜像获取工作

**WinHex软件固定方法**：
1. 启动WinHex，选择磁盘克隆选项
2. 选择要克隆的原始证据硬盘和目标路径
3. 点击"确定"开始数据文件的获取工作

### 三、现场数据固定应急方法

**通过修改注册表实现USB接口设置为只读**：

操作步骤：
1. 打开注册表编辑器：点击"开始"菜单→选择"运行"→输入"Regedit"→确定
2. 打开键值：HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control
3. 在Control项目下新建项"StorageDevicePolicies"
4. 在StorageDevicePolicies右边面板新建Dword值"WriteProtect"，键值为1

开启USB软件写保护后，可使用取证分析软件或磁盘编辑软件进行证据固定工作。

此方法对任何可使用USB接口读取设备的介质（硬盘、存储卡、移动硬盘、SIM卡等）均有效。

### 四、电子数据提取、固定的后处理工作

不论使用什么样的工具、采用何种方法，其目的都是制作与原始数据介质完全一致的介质镜像或者电子数据文件。

**重要提示**：电子证据最为显著的特点之一是**易修改性**，一旦原始数据被修改或损坏，其存储介质本身以及固定的证据副本、证据文件的有效性也随之丧失。

因此，对原始数据介质进行固定的同时，对电子数据及电子数据副本的保护也同样重要。建议使用专用的物证袋将原始介质进行封存保护，并且对于封存后的原始介质的每次拆封和使用都需要做严格的管理和监控，从根源上防止原始介质受到破坏。

## 第三节 实验室中数据固定与检材管理

我国《司法鉴定程序通则》第12条规定："委托人委托鉴定的，应当向司法鉴定机构提供真实、完整、充分的鉴定材料，并对鉴定材料的真实性、合法性负责。"

**电子数据司法鉴定中的术语**：
- **检材**：承载与鉴定事项有关电子数据的存储介质（硬盘、光盘、闪存等）
- **鉴定资料**：存在于各种载体上与鉴定事项有关的记录
- **检样**：包含存储介质的电子设备（笔记本、台式机、移动硬盘等）

### 一、检材接收

#### 委托登记

委托人委托鉴定时，鉴定机构应取得鉴定委托书或聘请书，并将委托人的身份证明复印留档。鉴定委托书应包含：委托人、委托日期、受托机构、鉴定事项、鉴定材料、案情摘要。

**受理条件判断**：
- 若鉴定事项明显满足鉴定范围，委托人提交鉴定材料充分，可以当场受理委托
- 若鉴定事项明显不在鉴定范围之内，可以当场拒绝受理委托
- 若提交鉴定材料不够充分，应要求委托人补充鉴定材料
- 若无法当场判断，应在7天之内给予答复

#### 检材接收

**文字记录**：
- 记录检材所有特征
- 若检材送检时已有封条或封存袋，需记录封条或封存袋上的信息（封存人、见证人、封存地点、封存时间、加盖公章情况等）

**电子数据检材应记录的信息**：
- 电子设备：外观、颜色、品牌、型号、序列号或产品号等
- 手机：还需记录IMEI号、SIM卡的ICCID号等
- 存储介质：品牌、型号、序列号、容量、扇区数、接口类型、Hash值等
- 内置存储介质的电子设备（如笔记本电脑）：应同时记录电子设备和存储介质的信息

**外观拍照**：
- 照片应展示检材所有特征，与文字记录结果相对应
- 保证照片中检材上的标记清晰可辨

**全程摄像**：
- 条件允许情况下建议整个检材交接过程全程摄像
- 拆封过程必须有委托人在场，最好封存人也在场

**Hash值比对**：
- 若委托人已提供检材Hash值，鉴定机构应重新计算并比对
- 若出现Hash值不匹配，应场告知委托人并在检材记录中说明

**复杂网络环境检材**：
- 对于机房里的服务器、专用服务器等，可要求委托人提供扣押现场的照片或连接情况记录
- 对于特殊领域专用电子设备，还应要求提供使用说明书或操作指南

**检材标识**：
- 鉴定机构在接收检材后应对每个检材制作唯一性标识
- 标识内容应包含检材编号和检材状态
- 检材状态分为：待检（在鉴定前）、在检（鉴定中）、已检（鉴定后）

### 二、检材预检

**预检的两个特征**：
1. 预检不能影响后续鉴定，要保证检材的原始性
2. 预检不必得出与鉴定要求相关的结果

**预检内容**：主要是判断检材（存储介质）是否能够正常读取

**预检步骤**：

1. **连接检材**：通过电子数据只读锁等设备连接检材，通过硬件阻止数据写入，保证检材的原始性

2. **通电测试**：给检材供电，查看检材通电后的运行情况（指示灯、电机运转是否正常）
   - 若发现硬件问题，应当场告知委托人
   - 若委托人送检时已说明存在硬件问题，切不可通电测试

3. **读取检材**：在检材正常运转的情况下，对检材的识别、读取情况进行检查
   - 若无法读取，需判断原因（硬盘加密或只读锁通信失败）
   - 若是硬盘加密，可送至硬盘解密区域或专门机构进行解密

4. **计算Hash值**：通过专门的Hash计算工具得出检材的Hash值
   - 该Hash值可作为证明送检检材原始性的依据
   - 若检材存在坏扇区，应场告知委托人并在检材记录中说明
   - Hash值算出后应请委托人确认

### 三、检材备份

**备份原则**：
- 电子数据类检材易于复制，应尽量采用备份检材代替原始检材进行鉴定
- 备份检材与原始检材具有同等的鉴定效力
- 同时避免误操作对原始检材的破坏

**备份方式**：

| 方式 | 特点 |
|------|------|
| 盘对盘复制 | 将原始硬盘数据完整复制到另一硬盘，两个硬盘相同扇区数据完全一致。与原始环境完美兼容，适合需搭建原始环境进行鉴定的情况。但备份检材消耗量大。 |
| 制作镜像文件 | 将原始检材数据镜像成一个或多个文件，文件大小可根据存储需求自由定义。可高效利用大容量备份硬盘，但与原始环境兼容性不如盘对盘复制。 |

**备份注意事项**：
- 备份应在鉴定开始前完成，鉴定过程尽量使用备份检材
- 若原始检材因特殊原因无法备份，应采取必要措施（减少使用次数、缩短使用时间等）
- 备份检材应有唯一性标识，与原始检材相对应，包含原始检材的容量、扇区数等信息

### 四、检材存放

#### 安全要求

**环境要求**：防磁、防静电、防震、防潮

**存放要求**：
- 每起鉴定涉及的检材应有明显的区域分开存放
- 建议采用专门的检材柜存放
- 检材与检样（如台式机内部的硬盘与外壳）可分开存放
- 检材应远离高磁场、高温、灰尘、积压、潮湿、腐蚀性化学试剂等
- 使用检材时应铺设防静电地板，佩戴防静电手套和防静电腕带

#### 保密要求

- 鉴定机构应有检材及其他委托方提供的技术资料和数据的保密隔离保管措施
- 检材应有专门人员（如检材管理员）管理
- 检材柜要具有保护机制（设置密码或安装锁）
- 检材管理人员应定期检查并及时更新检材状态
- 与检材对应案件无关的人员不能接触检材

### 五、检材流转

**流转原则**：保证原始检材的原始性和完整性

**操作要求**：
- 原始检材必须在只读环境下操作
- 使用硬盘套、硬盘盒等工具避免检材碰撞
- 备份检材无特殊情况也应在只读环境下操作
- 若鉴定方法不得不向检材中写入数据，必须使用备份检材，且备份应制作多份

**手机类检材**：鉴定过程中需保持手机始终处于开机状态，容易受到外来信息干扰导致内部数据变化，应采用电磁信号屏蔽措施

**记录要求**：
- 检材管理人员应及时记录检材的相关状态
- 用于分析检材的取证计算机应设置屏幕保护和密码
- 鉴定人员离开工作位时应将分析计算机切换到屏幕保护状态
- 鉴定结束或检材不使用时，应及时将检材交还检材管理人员保管

### 六、检材清退

鉴定完成后，鉴定机构向委托人提供鉴定报告，同时将检材退还委托人。

**退还步骤**：
1. 与委托人一起确认检材是否完整
2. 再次计算Hash值并与收领时记录的Hash值比对，证明检材在鉴定过程中未作过任何更改
3. 将检材装入一次性封存袋，填写封存信息
4. 形成检材退还记录（文字记录、拍照和摄像相结合）

### 七、备份检材清理

鉴定机构结束鉴定后，原始检材已连同鉴定报告一起交给委托人，但鉴定期间使用的备份检材（留样）还留在鉴定机构。

**留样保存规则**：
- 考虑到诉讼时效，一般情况下，若委托人无特别要求，鉴定机构将保存留样6个月
- 保存期间应参照原始检材的存放规则，存放于防磁、防静电、防震、防潮的环境中

**留样处理**：
- 保存期届满时，通知委托人
- 若委托人同意销毁，采用专门的电子数据销毁设备将留样内的数据销毁
- 电子数据销毁采用国际通用的DOD擦除模式
- 数据销毁后的留样可由鉴定机构回收以供其他鉴定委托备份使用
- 若委托人要求继续保存，可协商保存条件或要求委托人自备存储介质存放

## 第四节 小结

现场勘验与电子数据的提取、固定是涉计算机相关案件当中的重要一环，它将决定后期鉴定、分析工作的质量，影响鉴定结论的正确性。调查人员应掌握相关技术和规范，避免行为和技术差错。
