# 《合同法总论》第四章 合同的效力

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第四章 合同的效力 |
| 行号范围 | 3066-6257（书籍） |
| 核心议题 | 合同效力评价体系：有效 / 无效 / 可撤销 / 效力未定 |
| 涵盖 | 6 节 + 全章节综合法律后果 |

## 🎯 核心论点

合同效力评价体系 = **四类效力评价**：
1. **有效合同**：合同生效要件齐全，发生当事人预期的法律效果
2. **无效合同**：严重欠缺生效要件，自始、当然、确定不发生法律效力
3. **可撤销合同**：存在效力瑕疵，须经撤销权人行使撤销权才不生效力
4. **效力未定合同**：效力发生与否取决于第三人同意或追认

**合同法 vs 民事法律行为法**：
- 民法典基于体系安排，合同的效力主要由**第一编总则第六章民事法律行为**规范
- 合同编第三章"合同的效力"仅含 7 条（第502-508条）
- 法律适用：合同编无规定的，适用总则编第六章（第508条）

## 第一节 合同的效力概述

## 一、合同效力与民事法律行为效力

- 民法典将民事法律行为效力规定在**总则编第六章**（民事法律行为）
- 合同编第三章"合同的效力"内容已大幅削减（仅7条）
- 适用顺序：合同编 → 总则编第六章（第508条）

## 二、合同成立与合同生效

**合同成立 vs 合同生效**：

| 维度 | 合同成立 | 合同生效 |
|------|---------|----------|
| **性质** | 事实判断 | 价值判断 |
| **核心要件** | 当事人 + 合意 | 主体合格 + 内容合法 + 意思表示真实 + 形式合法 |
| **时点** | 承诺生效时 | 成立 + 满足生效要件 |
| **效力** | 已具法律约束力 | 发生当事人预期的法律效果 |
| **不成立的法律后果** | 不构成合同，无合同权利义务 | — |
| **无效的法律后果** | — | 自始、当然、确定无效 |

## 三、效力评价与效力内容

- **效力评价**：合同是否符合生效要件（价值判断）
- **效力内容**：合同有效后发生的法律效果（权利义务）

## 四、合同效力与合同拘束力

- **合同拘束力**（pacta sunt servanda）：合同对当事人的约束力
- **合同效力**：合同产生的法律效果（对外、对内）

## 五、对合同效力的特别限制

合同生效受下列特别限制：
- 需经审批的合同（《民法典》第502条第2款）
- 附条件/附期限的合同
- 需办理登记等手续的合同

## 六、合同效力的发生根据

合同效力发生的根据：
- **法律的规定**
- **当事人的约定**
- **法律的强制性规定 vs 任意性规定**

## 第二节 有效合同

## 一、合同生效的一般要件

### （一）主体合格

- 当事人具有相应民事行为能力
- 限制民事行为能力人纯获益或与其年龄智力相适应合同有效
- 越权代表行为效力问题（《民法典》第504条）

### （二）内容合法

- 不违反法律、行政法规的强制性规定
- 不违背公序良俗
- 不损害社会公共利益

### （三）意思表示真实

- 不存在欺诈、胁迫、重大误解等情形
- 意思表示自由

### （四）形式合法

- 符合法定或约定的形式要件
- 形式瑕疵可能因履行而治愈（《民法典》第490条）

## 二、合同效力及其具体表现

合同生效后发生的法律效果：
1. **在当事人之间产生债权债务**
2. **对当事人产生法律约束力**
3. **产生违约责任**
4. **可请求法院/仲裁机构救济**

## 第三节 无效合同

## 一、合同无效概述

**《民法典》第155条**：无效的或者被撤销的民事法律行为自始没有法律约束力。

**合同无效的情形**（《民法典》第153条）：
1. **虚假行为**（通谋虚伪表示）
2. **恶意串通损害他人合法权益**
3. **违反法律、行政法规的强制性规定**
4. **违背公序良俗**

## 二、虚假行为无效

**虚假行为**（Scheingeschäft）= 当事人通谋以虚假的意思表示实施的民事法律行为。

**《民法典》第146条**：
> 行为人与相对人以虚假的意思表示实施的民事法律行为无效。
> 以虚假的意思表示隐藏的民事法律行为的效力，依照有关法律规定处理。

**构成要件**：
1. 须有意思表示
2. 意思表示与内心真意不一致
3. 双方当事人**通谋**（相互知道非真意）
4. 表意人与相对人

**效力**：
- **虚伪表示**无效
- **隐藏行为**：依其性质适用相关法律规定

**例外**：真意保留（单方虚伪表示）原则上有效，对方知情的除外

## 三、恶意串通损害他人合法权益

**《民法典》第154条**：
> 行为人与相对人恶意串通，实施民事法律行为损害国家、集体或者第三人利益的，该民事法律行为无效。

**构成要件**：
1. 当事人主观上有恶意串通（通谋+故意）
2. 损害国家、集体或者第三人合法权益
3. 行为与损害结果之间有因果关系

## 四、违反法律、行政法规的强制性规定

**《民法典》第153条第1款**：
> 违反法律、行政法规的强制性规定的民事法律行为无效。但是，该强制性规定不导致该民事法律行为无效的除外。

**判断规则**（"三步审查法"）：
1. 是否属于法律、行政法规的强制性规定（不含地方性法规、行政规章）
2. 是否属于"效力性强制性规定"（vs 管理性强制性规定）
3. 强制性规定是否导致该行为无效

**识别效力性强制性规定的参考因素**：
- 法律法规的明确措辞（如"应当""必须""不得"）
- 立法目的（是否意在限制合同效力）
- 典型情形（违法建筑买卖、违章建筑租赁、违反限购政策等）

**典型案例**：
- 违反限购政策的房屋买卖合同效力
- 违反招拍挂规定的建设用地使用权出让合同效力
- 违反特许经营规定的合同效力

## 五、违背公序良俗

**《民法典》第153条第2款**：
> 违背公序良俗的民事法律行为无效。

**公序良俗**= 公共秩序与善良风俗

**判断标准**：
- 违反社会一般道德观念
- 违反社会公共利益
- 违反国家一般利益

**典型情形**：
- 违反基本人权的行为
- 违反人格尊严的行为
- 违反家庭伦理的行为
- 违反社会公德的行为

## 六、《民法典》第153条第1款和第2款的关系

| 条款 | 内涵 | 适用 |
|------|------|------|
| 第153条第1款 | 违反强制性规定 | 法律、行政法规明确要求 |
| 第153条第2款 | 违背公序良俗 | 法律未规定但违反社会一般道德 |

**关系**：
- 第1款是具体的、形式上的判断（违反具体规定）
- 第2款是兜底的、实质上的判断（违反社会一般利益）
- 二者可能存在竞合

## 七、无效的免责条款

**《民法典》第506条**：下列免责条款无效：
1. 造成对方人身伤害的
2. 因故意或者重大过失造成对方财产损失的

**立法目的**：
- 保护人身权益（生命权、身体权、健康权）
- 惩戒故意或重大过失行为

**效力**：合同其他部分效力不受影响（《民法典》第156条）

## 八、合同无效的补救

合同无效后：
- 不得履行
- 已经履行的，须返还财产、折价补偿、赔偿损失
- 法院可主动审查合同效力
- 当事人可请求确认无效

## 第四节 可撤销的合同

## 一、可撤销合同概述

**《民法典》第147-151条**：基于重大误解、欺诈、胁迫、显失公平等情形订立的合同，遭受不利益的一方可请求撤销。

**撤销权性质**：形成权（依单方意思表示即可发生法律效果）

**撤销权的行使**：
- 通过**法院或仲裁机构**行使（《民法典》第147-151条）
- **除斥期间**（不能中止、中断、延长）

**撤销权消灭**（《民法典》第152条）：
| 情形 | 期限 |
|------|------|
| 一般情形 | 自知道或应当知道撤销事由之日起**1年内** |
| 重大误解 | 自知道或应当知道撤销事由之日起**90日内** |
| 受胁迫 | 自胁迫行为终止之日起**1年内** |
| 明示放弃 | 知道撤销事由后明确表示或者以自己的行为表明放弃撤销权 |
| 最长保护期 | 自民事法律行为发生之日起**5年内**未行使的，撤销权消灭 |

## 二、欺诈

**《民法典》第148条**：
> 一方以欺诈手段，使对方在违背真实意思的情况下实施的民事法律行为，受欺诈方有权请求人民法院或者仲裁机构予以撤销。

**欺诈的构成要件**：
1. 欺诈方主观上有欺诈的故意
2. 欺诈方实施了欺诈行为（虚构事实、隐瞒真相）
3. 相对人因欺诈陷入错误认识
4. 相对人基于错误认识作出意思表示

**欺诈的类型**：
- **积极欺诈**：虚构事实、歪曲事实、捏造事实
- **消极欺诈**（沉默欺诈）：负有告知义务而故意不告知

**第三人欺诈**（《民法典》第149条）：
> 第三人实施欺诈行为，使一方在违背真实意思的情况下实施的民事法律行为，对方知道或者应当知道该欺诈行为的，受欺诈方有权请求人民法院或者仲裁机构予以撤销。

## 三、胁迫

**《民法典》第150条**：
> 一方或者第三人以胁迫手段，使对方在违背真实意思的情况下实施的民事法律行为，受胁迫方有权请求人民法院或者仲裁机构予以撤销。

**胁迫的构成要件**：
1. 胁迫人有胁迫的故意
2. 胁迫人实施了胁迫行为（以威胁方式迫使对方）
3. 相对人因胁迫产生恐惧
4. 相对人因恐惧作出不真实的意思表示

**胁迫的方式**：
- 生命、身体、健康、自由
- 名誉、荣誉、隐私
- 财产

**第三人胁迫**（《民法典》第150条后段）：无论相对人是否知情，均可撤销

## 四、重大误解

**《民法典》第147条**：
> 基于重大误解实施的民事法律行为，行为人有权请求人民法院或者仲裁机构予以撤销。

**重大误解的构成要件**：
1. 表意人主观上有错误认识
2. 错误认识与意思表示有因果关系
3. 错误是重大的

**重大误解的典型情形**：
- 标的物的性质错误
- 标的物的品种、质量、规格、数量错误
- 标的物的当事人错误
- 合同性质错误（如将租赁误认为买卖）

**表示错误**（Erklärungsirrtum）：
- 内容错误（《民法典》第147条）
- 传达错误
- 动机错误（原则上不构成重大误解）

## 五、显失公平

**《民法典》第151条**：
> 一方利用对方处于困境、缺乏判断能力等情形，致使民事法律行为成立时显失公平的，受损害方有权请求人民法院或者仲裁机构予以撤销。

**显失公平的构成要件**：
1. 合同成立时显失公平
2. 一方利用对方处于困境、缺乏判断能力
3. 显失公平与利用对方困境有因果关系

**典型情形**：
- 趁人之危（对方处于紧迫困境）
- 利用对方缺乏判断能力（如年幼无知、重大误解、醉酒等）

**两要件关系**：须同时满足，单有显失公平不构成（如市场风险导致的）

## 第五节 效力未定的合同

## 一、效力未定合同概述

**效力未定合同**（schwebende Unwirksamkeit）= 合同成立但效力发生与否取决于第三人同意或追认。

**典型类型**：
1. 限制民事行为能力人订立的超出其行为能力的合同
2. 无权代理人以被代理人名义订立的合同
3. 无权处分行为（《民法典》第597条）

## 二、限制民事行为能力人订立的合同

**《民法典》第145条**：
> 限制民事行为能力人实施的纯获利益的民事法律行为或者与其年龄、智力、精神健康状况相适应的民事法律行为有效；实施的其他民事法律行为经法定代理人同意或者追认后有效。

**效力状态**：
- **有效情形**：纯获益 + 适应年龄智力
- **效力未定**：其他合同（待法定代理人追认）
- **无效情形**：实施的行为与其年龄、智力不相应，且未追认

**法定代理人的追认权**：
- 单方意思表示即可
- 追认前，相对人有**撤销权**（《民法典》第145条第2款）

**相对人的催告权**：
- 相对人可以催告法定代理人在30日内予以追认
- 30日内未作表示的，视为拒绝追认

## 三、无权代理人以被代理人名义订立的合同

**《民法典》第171条**：
> 行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，未经被代理人追认的，对被代理人不发生效力。

**效力未定**：待被代理人追认

**相对人的权利**：
- 催告权：30日内催告被代理人是否追认
- 撤销权：合同被追认前，善意相对人有撤销权

**善意相对人的保护**：
- 表见代理（《民法典》第172条）：相对人有理由相信行为人有代理权
- 代理权外观：持有公章、合同书、授权委托书等

**无权代理人的责任**（《民法典》第171条第3款）：
> 行为人实施的行为未被追认的，善意相对人有权请求行为人履行债务或者就其受到的损害请求行为人赔偿。但是，赔偿的范围不得超过被代理人追认时相对人所能获得的利益。

## 四、无权处分行为

**《民法典》第597条**：
> 因出卖人未取得处分权致使标的物所有权不能转移的，买受人可以解除合同并请求出卖人承担违约责任。

**无权处分的效力**：
- **债权合同**有效（不因无权处分而无效）
- **物权变动**效力待定（需权利人追认或处分人取得处分权）

**典型情形**：
- 一物数卖（同一物出卖给数人）
- 夫妻共有财产处分（未经其他共有人同意）
- 共有财产处分（未经其他共有人同意）
- 抵押物处分（未经抵押权人同意）

**善意取得制度**（《民法典》第311条）：无权处分 + 受让人善意 + 合理价格 + 登记或交付 = 取得所有权

## 第六节 合同无效、被撤销或者确定不发生效力的法律后果

## 一、返还财产

**《民法典》第157条**：
> 民事法律行为无效、被撤销或者确定不发生效力后，行为人因该行为取得的财产，应当予以返还；不能返还或者没有必要返还的，应当折价补偿。

**返还财产的性质**：
- **不当得利返还**（学说通说）
- **物上请求权**（双重要件）

**返还范围**：
- 已交付的财产
- 孳息（《民法典》第157条）

## 二、折价补偿

**适用情形**：
- 不能返还（如标的物已灭失）
- 没有必要返还（如劳务已提供）

**折价标准**：
- 一般按**取得财产时的市场价值**
- 可参照合同约定的价款

## 三、赔偿损失

**《民法典》第157条**：
> 有过错的一方应当赔偿对方由此所受到的损失；各方都有过错的，应当各自承担相应的责任。

**赔偿范围**：
- **信赖利益**损失
- 直接损失为主，间接损失视情况

## 四、部分无效及争议解决方法条款的独立性

**部分无效**（《民法典》第156条）：
> 民事法律行为部分无效，不影响其他部分效力的，其他部分仍然有效。

**争议解决方法条款的独立性**（《民法典》第507条）：
> 合同不生效、无效、被撤销或者终止的，不影响合同中有关解决争议方法的条款的效力。

**适用范围**：
- 仲裁条款
- 法院管辖约定

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **效力评价** | 合同是否符合生效要件 |
| **效力内容** | 合同有效后发生的法律效果 |
| **合同拘束力** | pacta sunt servanda；合同对当事人的约束力 |
| **有效合同** | 生效要件齐全，发生预期法律效果 |
| **无效合同** | 严重欠缺生效要件，自始无效 |
| **可撤销合同** | 存在效力瑕疵，须经撤销权行使 |
| **效力未定合同** | 效力发生取决于第三人同意或追认 |
| **虚假行为**（Scheingeschäft）| 通谋虚伪表示 |
| **隐藏行为** | 隐藏在虚假表示背后的真实行为 |
| **通谋虚伪表示** | 双方当事人相互知道非真意 |
| **真意保留** | 单方虚伪表示；原则上有效 |
| **恶意串通** | 双方通谋+故意损害他人合法权益 |
| **效力性强制性规定** | 违反导致合同无效 |
| **管理性强制性规定** | 违反不导致合同无效 |
| **公序良俗** | 公共秩序与善良风俗 |
| **重大误解** | 重大错误认识 |
| **表示错误**（Erklärungsirrtum）| 内容错误、传达错误 |
| **动机错误** | 原则上不构成重大误解 |
| **欺诈** | 虚构事实、隐瞒真相 |
| **积极欺诈** | 虚构事实、歪曲事实 |
| **消极欺诈** | 负有告知义务而故意不告知 |
| **第三人欺诈** | 第三人实施欺诈 |
| **胁迫** | 以威胁方式迫使对方 |
| **显失公平** | 利用对方困境致合同显失公平 |
| **趁人之危** | 利用对方紧迫困境 |
| **撤销权** | 形成权 |
| **除斥期间** | 撤销权行使期限 |
| **效力未定**（schwebende Unwirksamkeit）| 待第三人追认 |
| **法定代理人追认权** | 单方意思表示 |
| **无权代理** | 没有代理权、超越代理权、代理权终止后 |
| **表见代理** | 相对人有理由相信行为人有代理权 |
| **无权处分** | 无处分权而处分他人财产 |
| **善意取得** | 无权处分+善意+合理价格+公示 |
| **一物数卖** | 同一物出卖给数人 |
| **返还财产** | 合同无效后的返还义务 |
| **折价补偿** | 不能返还时的金钱补偿 |
| **信赖利益** | 因信赖合同有效所受损失 |
| **争议解决条款独立性** | 仲裁条款不因合同无效而失效 |
