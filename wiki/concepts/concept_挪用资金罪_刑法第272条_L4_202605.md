## 一、法条原文

**第二百七十二条**(1997 《刑法》制定,**2002 《刑法修正案(四)》** 修订)

「**公司、企业或者其他单位的工作人员**,**利用职务上的便利**,**挪用本单位资金归个人使用或者借贷给他人**,**数额较大**、**超过三个月未还**的,或者**虽未超过三个月**,**但数额较大、进行营利活动**的,或者**进行非法活动**的,处 **3 年以下有期徒刑或者拘役**;**挪用本单位资金数额巨大**,或者**数额较大未退还**的,处 **3 年以上 7 年以下有期徒刑**;**挪用本单位资金数额特别巨大**的,处 **7 年以上有期徒刑**。」

「**国有公司、企业或者其他国有单位中从事公务的人员和国有公司、企业或者其他国有单位委派到非国有公司、企业以及其他单位从事公务的人员**有前款行为的,**依照本法第三百八十四条的规定定罪处罚**。」

「**挪用本单位资金**的,**依照本法第二百七十二条的规定定罪处罚**。」

### 1.1 司法解释
- **最高人民法院《关于办理违反公司受贿、侵占、挪用等刑事案件适用法律若干问题的解释》**(法发〔1995〕12 号)
- **最高人民法院、最高人民检察院《关于办理挪用资金刑事案件适用法律若干问题的解释》**(2025 年新解释)

### 1.2 数额标准
| 数额档次 | 标准 |
|---|---|
| 数额较大 | 100,000 元以上 |
| 数额巨大 | 4,000,000 元以上 |
| 数额特别巨大 | 20,000,000 元以上 |

## 二、段级释解

### 2.1 客体要件

**双重客体**:①**公司、企业或其他单位的财产所有权**;②**公司、企业或其他单位的正常管理秩序**。

### 2.2 客观要件

**公司、企业或其他单位的工作人员**,**利用职务上的便利**,**挪用本单位资金归个人使用或者借贷给他人**,**数额较大**的行为。

#### (一) 主体范围

依据 2025 年新解释,**「公司、企业或者其他单位的工作人员」** 包括:
1. 公司、企业工作人员(正式员工/合同工/临时工)
2. 个体工商户雇佣人员
3. 民办非企业单位工作人员
4. 社会团体工作人员
5. 基金会工作人员
6. 其他依法成立的组织工作人员

**不包括**:**国家工作人员**(→挪用公款罪)

#### (二) 「利用职务上的便利」的认定
同职务侵占罪:① 主管/管理/经手单位财物的便利;② 保管/销售/采购/收款/付款等业务的便利;③ 其他职务便利。

#### (三) 「挪用」的认定
**「挪用」** = **暂时使用**,而非**永久占有**(区别于职务侵占罪)。
- **核心特征**:行为人主观想归还,客观上有归还可能
- **「归个人使用」**:① 个人消费;② 个人投资;③ 个人经营;④ 个人借贷给他人
- **「借贷给他人」**:① 借给亲属/朋友;② 借给关联企业;③ 借给其他单位/个人

#### (四) 3 种入罪情形

依据 2025 年新解释 + 司法解释,**3 种入罪情形**:

1. **数额较大 + 超过 3 个月未还** → 基本档入罪
2. **数额较大 + 进行营利活动**(不受 3 个月限制) → 基本档入罪
3. **进行非法活动**(不受数额/时间限制) → 基本档入罪

> **3 种情形的递进关系**:① 数额较大 + 3 个月未还 → 民事纠纷到刑事的过渡;② 营利活动 → 反映主观恶性;③ 非法活动 → 直接构罪

### 2.3 主体要件

**一般主体**,年满 16 周岁具有刑事责任能力的自然人。

### 2.4 主观要件

**故意**,**临时使用**为目的,**具有归还意图**(区别于职务侵占罪的「非法占有」目的)。
- **故意内容**:明知是单位资金,仍挪作个人使用或借贷他人
- **归还意图**:① 主观想归还;② 客观上有归还可能
- **2025 年新解释**:虚假平账/携带资金逃匿/挥霍 → 转化为职务侵占

### 2.5 量刑三档详解

| 量刑档次 | 数额/情节标准 | 刑期 |
|---|---|---|
| **基本档** | 数额较大 + 超过 3 个月未还/数额较大 + 营利活动/非法活动 | 3 年以下有期徒刑/拘役 |
| **加重档** | 数额巨大 / 数额较大未退还 | 3-7 年有期徒刑 |
| **特别加重档** | 数额特别巨大 | 7 年以上有期徒刑 |

### 2.6 与相邻罪名的界限

#### 2.6.1 挪用资金罪 vs 职务侵占罪(第271条)
- **挪用资金罪**:**临时使用**,主观想归还
- **职务侵占罪**:**非法占有**,主观不想归还
- **核心区分**:① 主观目的(临时使用 vs 非法占有);② 是否想归还
- **转化情形**:挪用资金后虚假平账/逃匿/挥霍 → 转化为职务侵占

#### 2.6.2 挪用资金罪 vs 挪用公款罪(第384条)
- **挪用资金罪**:**非国家工作人员**
- **挪用公款罪**:**国家工作人员**
- **核心区分**:行为人是否具有国家工作人员身份

#### 2.6.3 挪用资金罪 vs 侵占罪(第270条)
- **挪用资金罪**:**利用职务便利**
- **侵占罪**:将代为保管的他人财物非法占为己有
- **核心区分**:① 是否利用职务便利;② 财物对象(单位资金 vs 代为保管的他人财物)

#### 2.6.4 挪用资金罪 vs 挪用特定款物罪(第273条)
- **挪用资金罪**:**挪用本单位资金**
- **挪用特定款物罪**:挪用**救灾/抢险/防汛/优抚/扶贫/移民/救济**等特定款物
- **核心区分**:① 款物范围;② 是否本单位

### 2.7 实务争议焦点

#### 2.7.1 「营利活动」的认定
- **「营利活动」**:① 投资/经营/炒股/炒房;② 注册公司/入股;③ 提供担保/借款给他人经营;④ 其他营利活动
- **2025 年新解释**:不论营利活动是否实际盈利,只要用于营利活动即可认定

#### 2.7.2 「非法活动」的认定
- **「非法活动」**:① 赌博;② 吸毒;③ 行贿;④ 走私;⑤ 其他违法犯罪活动
- **2025 年新解释**:用于非法活动,不论数额大小均可入罪

#### 2.7.3 「超过 3 个月未还」的认定
- **「3 个月」**:从挪用之日起算
- **「未还」**:至案发时未归还
- **「归还」**:① 主动归还;② 被单位发现后归还;③ 起诉前归还
- **2025 年新解释**:案发前归还 + 未达数额巨大 → 可不追究刑事责任

#### 2.7.4 挪用资金向职务侵占的转化
依据 2025 年新解释,**下列情形转化为职务侵占**:
1. 虚假平账
2. 携带资金逃匿
3. 挥霍资金
4. 拒不归还且不说明去向
5. 其他具有非法占有目的的情形

## 三、典型案例(精选 4 件)

### 案例 1:**「3 个月未还」挪用资金案**(2024)
- **案情**:某公司财务经理甲利用职务便利,挪用公司资金 150 万元借给朋友,超过 3 个月未还
- **定性**:挪用资金罪(数额较大 + 超过 3 个月未还)
- **量刑**:有期徒刑 2 年 + 缓刑 3 年
- **典型意义**:3 个月未还的认定

### 案例 2:**「营利活动」挪用资金案**(2025)
- **案情**:某公司销售经理乙利用职务便利,挪用公司资金 300 万元用于个人投资股票
- **定性**:挪用资金罪(数额较大 + 营利活动)
- **量刑**:有期徒刑 3 年 + 罚金 10 万元
- **典型意义**:营利活动型挪用资金

### 案例 3:**「非法活动」挪用资金案**(2024)
- **案情**:某公司出纳丙利用职务便利,挪用公司资金 50 万元用于赌博
- **定性**:挪用资金罪(非法活动)
- **量刑**:有期徒刑 2 年 + 罚金 5 万元
- **典型意义**:非法活动型挪用资金;数额较小但构成犯罪

### 案例 4:**「挪用转化为职务侵占」典型案例**(2025)
- **案情**:某公司总经理丁挪用公司资金 800 万元借给亲属公司,后虚假平账/携带资金逃匿
- **定性**:职务侵占罪(数额巨大)
- **量刑**:有期徒刑 8 年 + 罚金 30 万元
- **典型意义**:挪用资金向职务侵占的转化

## 四、实务问答 FAQ

### Q1 挪用资金罪的构成要件?
A:**四要件**:① 行为人是公司/企业/其他单位工作人员;② 利用职务便利;③ 挪用本单位资金归个人使用或借贷他人;④ 数额较大/3 个月未还/营利活动/非法活动。

### Q2 挪用资金罪与职务侵占罪如何区分?
A:**核心看主观目的**:① **临时使用 + 归还意图** → 挪用资金罪;② **非法占有 + 不归还** → 职务侵占罪。

### Q3 挪用资金罪 3 种入罪情形?
A:① **数额较大 + 超过 3 个月未还**;② **数额较大 + 营利活动**(不受 3 个月限制);③ **非法活动**(不受数额/时间限制)。

### Q4 挪用资金罪与挪用公款罪如何区分?
A:**核心看身份**:① **国家工作人员** → 挪用公款罪;② **非国家工作人员** → 挪用资金罪。

### Q5 「营利活动」的具体范围?
A:① 投资/经营/炒股/炒房;② 注册公司/入股;③ 提供担保/借款给他人经营;④ 其他营利活动。

### Q6 「非法活动」的具体范围?
A:① 赌博;② 吸毒;③ 行贿;④ 走私;⑤ 其他违法犯罪活动。

### Q7 「超过 3 个月未还」的认定?
A:① 从挪用之日起算;② 至案发时未归还;③ 案发前归还 + 未达数额巨大 → 可不追究刑事责任。

### Q8 挪用资金向职务侵占的转化?
A:① 虚假平账;② 携带资金逃匿;③ 挥霍资金;④ 拒不归还且不说明去向 → 转化为职务侵占罪。

### Q9 挪用资金罪自首/立功的认定?
A:① **自首**:犯罪后自动投案,如实供述 → 从轻/减轻;② **立功**:揭发他人犯罪/提供线索 → 从轻/减轻。

### Q10 单位挪用资金的处理?
A:**双罚制**:① 对单位判处罚金;② 对直接负责的主管人员和其他直接责任人员,依照个人犯罪的定罪量刑标准处罚。

## 五、常见辩护要点(8 项)

### 5.1 主观方面辩护
- **具有归还意图**:主观想归还,非永久占有 → 挪用资金罪而非职务侵占罪
- **不具有营利目的**:仅临时周转,非用于营利 → 入罪情形可能不成立
- **不具有非法活动目的**:非用于非法活动 → 入罪情形可能不成立

### 5.2 客观行为辩护
- **未利用职务便利**:仅利用工作关系/熟悉环境 → 不构成
- **「归个人使用」不成立**:经单位授权使用 → 不构成
- **「借贷给他人」不成立**:经单位授权借贷 → 不构成

### 5.3 入罪情形辩护
- **数额未达较大**:依据本地区标准,未达较大起点 → 不构罪
- **未超过 3 个月**:挪用时间未超过 3 个月 + 已归还 → 不构罪
- **非营利活动**:挪用的具体用途非营利 → 不构罪
- **非非法活动**:挪用的具体用途非非法 → 不构罪

### 5.4 数额辩护
- **数额计算有误**:扣除已返还部分/正常业务往来
- **退赃退赔情节**:积极退赃,单位谅解 → 从轻/减轻

### 5.5 共犯辩护
- **不明知他人挪用资金**
- **帮助行为情节显著轻微**
- **被胁迫参与**

### 5.6 罪名辩护
- **构成挪用公款罪**:具有国家工作人员身份 → 适用挪用公款罪
- **构成职务侵占罪**:具有非法占有目的 → 适用职务侵占罪(更重)
- **正当行使权利**

### 5.7 量刑情节辩护
- **从轻/减轻情节**:自首/立功/坦白/积极退赃/单位谅解/初犯偶犯
- **案发前主动归还**:可不追究刑事责任
- **犯罪未遂/中止**

### 5.8 量刑辩护
- **缓刑适用**:符合缓刑条件
- **罚金辩护**
- **民事赔偿**:积极赔偿,争取谅解
