## 核心框架

### 公诉人出庭的任务

| 任务 | 说明 |
|------|------|
| 代表国家指控、揭露和证实犯罪 | 控诉职能 |
| 对法庭审判活动是否合法进行监督 | 监督职能 |
| 维护诉讼参与人的合法权利 | 保障职能 |
| 结合案情进行法治宣传和教育 | 教育职能 |

### 公诉人出庭的基本原则

| 原则 | 说明 |
|------|------|
| 系统性原则 | 出庭各环节之间的关联，证据之间的关联，证据与事实之间的关联，事实与法律之间的关联 |
| 关联性原则 | 证据之间的关联，证据与事实之间的关联 |

## 关键知识点

### 庭前会议的主要功能

根据《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》，法院在庭前会议中可以就回避、管辖、非法证据排除等事项了解情况，听取意见。公诉人应当：

1. 提前了解案件是否召开庭前会议
2. 准备应对非法证据排除等程序性问题的预案
3. 就举证方式、争议焦点等与法院沟通

### 举证质证的基本要求

| 阶段 | 要点 |
|------|------|
| 举证 | 按证据证明力大小排列分组；围绕犯罪构成要件展开 |
| 质证 | 针对证据三性（真实性、合法性、关联性）进行质疑 |
| 辩论 | 围绕定罪量刑争议焦点展开 |

### 法庭辩论的策略

1. **定罪辩论**：围绕犯罪构成要件展开，证明行为符合特定犯罪的构成要件
2. **量刑辩论**：围绕量刑情节展开，包括法定从重从轻、坦白、自首、认罪认罚等
