# 政府信息公开类案疑难法律问题（上海法院第1册）

> **源行范围**：10293–10342（第六部分 政府信息公开类案疑难法律问题）

## 一、申请内容明确与否的判断标准如何把握？

### （一）法律依据

- **2019 年《政府信息公开条例》第 29 条第 2 款第 2 项**：政府信息公开申请应包括**申请公开的政府信息的名称、文号或者便于行政机关查询的其他特征性描述**

### （二）审查标准

"**特征性描述**"的明确性要求 → **经过检索可将原告申请的信息予以特定化**

- 可以是**一项信息**，也可以是**明确的多项信息**
- **数量多少不是特定与否的判断标准**

### （三）概括性用语的处理

实践中，申请人在申请时使用"**相关**""**所有**""**全部**""**不限于**""**包括**"等概括性用语：
- 如行政机关认定为申请内容不明确的 → 法院应**审查上述用语是否导致申请内容不能指向特定政府信息**
- 兼顾申请人权利保护与行政机关工作负担
- **例外**：申请人要求公开的政府信息**属于一类特定信息**，且**材料数量巨大**，行政机关**答复申请不明确要求申请人补正**的 → **可以认定行政机关的答复合法**

## 二、非常设机构答复的效力与被告确定

### （一）规则

- 申请人向政府机关设立的**非常设机构**提出政府信息公开申请的
- **设立该非常设机构的政府机关有权作出政府信息公开答复**

### （二）非常设机构以自己名义答复

- 非常设机构**以自己名义作出答复**
- 同时**设立该机构的政府机关在诉讼中认可该答复内容**的
- 法院**可以认定非常设机构所作政府信息公开答复主体适当**

## 三、政府信息公开答复是否必须说明法律适用依据？

### （一）两种"不能"情形

政府信息公开行为具有不同于一般行政行为的特殊性，行政机关**不予提供政府信息**有 **2 种情形**：

| 情形 | 定义 | 法律适用要求 |
|------|------|--------------|
| **事实不能** | 政府信息**在客观上不存在**（如未制作获取、遗失、销毁等） | 法院**不宜强求其列明具体法律条款**；行政机关**说理充分并有证据证明**即可 |
| **法律不能** | 政府信息**客观存在且有条件提供**，但**法律规定免予公开**（如国家秘密、商业秘密、个人隐私） | **应当写明法律依据及具体条款**；**未写明**的 → **可以认定法律适用错误** |

### （二）关键差异

- **事实不能**（信息不存在）→ 法院宽容，**不强求列法条**
- **法律不能**（依法不公开）→ 法院严格，**必须列法条**

## 四、行政机关在诉讼过程中改变理由应如何处理？

### （一）3 种情形与处理

| 情形 | 处理 |
|------|------|
| ① 答复中**说明理由不全**，**诉讼中作了适当补充**，**补充理由符合法律规定的** | **判决驳回诉讼请求** |
| ② 答复时**没有说明理由** 或 诉讼中**完全改变理由**，**改变后的理由成立的** | **判决确认违法** |
| ③ 答复时**未说理或说理不全**，诉讼中**补充或改变的理由不能成立**的 | **判决撤销** |

### （二）关键规则

- **诉讼中补充理由** vs **诉讼中改变理由** 是两种不同行为
- 补充 + 合法 → 驳回；改变 + 合法 → 确认违法；改变/补充 + 不合法 → 撤销

## 五、申请信息属性未判定时直接答复"不属于本机关公开"

### （一）规则

- 行政机关处理政府信息公开申请时，**一般应先对申请的政府信息是否属于《政府信息公开条例》所指的政府信息**进行判定
- **例外**：在申请人申请公开的信息**并非政府信息**，且**被申请的行政机关未制作或者获取**的情形下
- 被告**直接答复不属于本机关公开**
- **虽没有对申请信息是否属于《政府信息公开条例》所指政府信息进行判定**
- **但也没有对原告的知情权造成实际上的侵害**
- → **可以判决驳回原告的诉讼请求**

## 六、超期邮寄答复书的程序合法性

### （一）法律依据

- **2019 年《政府信息公开条例》第 33 条**：行政机关应当**自收到申请之日起**，**在法定期限内**对申请人的政府信息公开申请予以答复

### （二）规则

- **在法定期限内答复**不仅要求**行政机关作出政府信息公开决定**
- **而且要求在法定期限内让当事人知晓政府信息公开决定的内容**

### （三）处理

- **情形 1**：行政机关在**法定期限届满前**邮寄答复书的（**以邮戳为准**）→ **可以认定答复未超法定期限**
- **情形 2**：**确因客观事由来不及寄送**：
  - 行政机关**在答复期限届满前**告知申请人答复书内容
  - **在合理期限内（一般不超过 3 个工作日）**及时邮寄答复书
  - → 法院**不宜以此为由认定行政程序违法**

## 七、撤销后行政机关公开/重新答复的期限

### （一）法律依据

- **《信息公开司法解释》第 9 条**：
  - 法院认定被告所作不予公开决定错误的
  - **能够判定原告申请公开的信息应予以公开**的 → 法院应当**判决撤销并责令被告在一定期限内公开**
  - **尚需被告调查、裁量的** → 法院应当**判决撤销并责令被告在一定期限内重新答复**

### （二）期限设置规则

| 情形 | 期限 |
|------|------|
| **一般规则** | **不应超过 2019 年《政府信息公开条例》规定的 20 个工作日的答复期限** |
| **法院裁量缩短** | **可设定少于 20 个工作日**的公开或重新答复期限 |
| **合理期限标准** | **以确保申请人能够及时获取信息或收到答复所需要的时间**作为合理期限 |
| **重新答复过程中的期限扣除** | 行政机关依《政府信息公开条例》**延期答复**或**扣除向第三方征询意见所需时间**的 → 法院**可予支持** |

## 八、关键提示

- **申请内容明确性** = 检索可特定化（数量不是标准）
- **事实不能 vs 法律不能** 是法律适用要求的分水岭
- **诉讼中改变理由的 3 种处理**是政府信息公开案件特有的裁判技术
- **超期邮寄** = 邮戳为准 + 3 个工作日宽限
- **撤销后期限** = 不超过 20 个工作日（一般）+ 可缩短

## 九、相比 L1 旧资料的核心差异

- 旧 L1 仅有"疑难问题"等概括，本节点展开**7 大疑难问题**的完整审查标准
- **事实不能 vs 法律不能** 的双轨规则首次显性化
- **诉讼中改变理由 3 种处理**的精细化规则首次出现
- **超期邮寄 3 个工作日**的"邮戳+宽限"双规则首次显性化

## 十、实务问答

> Q1: 申请人使用"所有相关"等概括性用语，是否必然属于"申请内容不明确"？
> A: **不一定**。需审查是否**能指向特定政府信息**——若属于"**一类特定信息 + 材料数量巨大**"，行政机关要求补正 → **可认定合法**。

> Q2: 信息不存在（事实不能）时，行政机关是否必须列明法律条款？
> A: **不强求**。只要**说理充分并有证据证明**即可。但**法律不能**（依法不公开）→ **必须列明法律依据及具体条款**，否则可认定法律适用错误。

> Q3: 行政机关在诉讼中改变理由，法院如何处理？
> A: **3 种情形**：
  - ① 补充 + 合法 → 驳回诉讼请求
  - ② 改变 + 合法 → 确认违法
  - ③ 改变/补充 + 不合法 → 撤销

> Q4: 行政机关在法定期限届满前 1 天邮寄答复书，程序是否合法？
> A: **合法**（以邮戳为准）。如确因客观事由来不及寄送，**答复期限届满前告知 + 3 个工作日内邮寄** → 法院**不宜认定违法**。

> Q5: 撤销政府信息公开答复后，法院设定的重新答复期限最长多久？
> A: **不超过 20 个工作日**（一般）；法院可设定**少于 20 个工作日**。依《条例》延期/扣除征询时间可获支持。
