# 民法典第十六章【担保物权一般规定】综合

## 章节目录

本章共 8 条（Articles 386-393），规定担保物权制度的一般规则，涵盖担保物权的概念、适用范围、设立方式、担保范围、物上代位性、人保物保并存、消灭原因等基础性、共同性问题。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第386条 | 担保物权的概念 | 就担保财产优先受偿的他物权 |
| 第387条 | 适用范围和反担保 | 民事活动 + 反担保制度 |
| 第388条 | 担保合同 | 担保合同是主合同的从合同；含其他具有担保功能的合同 |
| 第389条 | 担保范围 | 主债权+利息+违约金+损害赔偿金+保管费+实现费用 |
| 第390条 | 物上代位性 | 担保财产毁损灭失的代位物 |
| 第391条 | 债务转移 | 第三人担保未经书面同意转移债务的不再担保 |
| 第392条 | 人保与物保并存 | 约定优先；债务人物保先实现 |
| 第393条 | 担保物权消灭 | 主债权消灭/实现/放弃/法定其他情形 |

## 一、第386条·担保物权的概念

### 法条原文

> 第三百八十六条　担保物权人在债务人不履行到期债务或者发生当事人约定的实现担保物权的情形，依法享有就担保财产优先受偿的权利，但是法律另有规定的除外。

### 核心释义

**担保物权的概念**：为了确保债权的实现，而在债务人或者第三人的特定财产之上设定的，在债务人不履行到期债务或者发生约定的实现担保物权的情形时，债权人可就该担保财产优先受偿的**他物权**。

### 担保物权的特征

| 特征 | 要点 |
|------|------|
| **在他人财产上设定** | 债务人或者第三人的特定财产；可包括现有财产和将来财产 |
| **以担保人所有的特定财产为标的** | 担保物限于担保人所有的特定财产；标的必须特定 |
| **优先受偿效力** | 优先于普通债权；有可能优先于后顺位担保物权；但**法律另有规定的除外** |
| **以债权实现为目的** | 支配担保财产的交换价值，非使用价值；区别于用益物权 |

### 担保物权的性质

| 性质 | 内容 |
|------|------|
| **从属性** | 从属于被担保的债权；设立/转让/消灭均从属于主债权（第388、407、393条体现） |
| **不可分性** | 债权部分消灭或担保财产部分变化的，不影响担保物权整体性 |
| **物上代位性** | 担保财产毁损灭失的，代位物上担保物权继续存在 |

**⚠️ 从属性例外**：最高额抵押权、最高额质权不以被担保债权存在为前提。

### 担保物权的分类

| 分类标准 | 类型 |
|---------|------|
| 发生原因 | 法定担保物权（留置权、建设工程价款优先权、船舶优先权） vs **意定担保物权**（抵押权、质权） |
| 标的种类 | 不动产担保物权 / 动产担保物权 / 权利担保物权 |
| 是否转移占有 | **占有型**（质权、留置权） vs **非占有型**（抵押权） |
| 法律是否有规定 | **典型担保物权**（抵押权、质权、留置权） vs **非典型担保物权**（让与担保、所有权保留、融资租赁） |

### 担保物权的行使条件

- **债务人不履行到期债务**（已届清偿期，债务人未履行或仅部分履行）
- **发生当事人约定的实现担保物权的情形**（如约定加速到期事件）

① 来源：担保物权的行使条件（L113），《民法典适用大全》物权卷3 2023年 386-462.md

## 二、第387条·担保物权的适用范围和反担保

### 法条原文

> 第三百八十七条　债权人在借贷、买卖等民事活动中，为保障实现其债权，需要担保的，可以依照本法和其他法律的规定设立担保物权。
>
> 第三人为债务人向债权人提供担保的，可以要求债务人提供反担保。反担保适用本法和其他法律的规定。

### 核心释义：担保物权的适用范围

**适用范围**：**民事活动**——平等主体间的财产关系和身份关系，但身份关系不在担保物权适用范围内。

| 适用要点 | 说明 |
|---------|------|
| **平等主体** | 仅限平等主体的民事活动；行政行为、司法行为不适用 |
| **民事活动范围** | 借贷、买卖为典型；可扩展至其他产生债权债务关系的民事活动 |
| **可担保非合同之债** | 侵权行为、无因管理、不当得利等产生的债权亦可担保（但非合同债权不能**先行**设立担保） |
| **依法律规定设立** | 民事主体不得擅自设立法律没有规定的担保物权类型 |
| **其他法律特别规定** | 《海商法》《民用航空法》《农村土地承包法》对船舶抵押权、航空器抵押权、土地经营权抵押权有特别规定 |

### 核心释义：反担保

**反担保**：又称"求偿担保"，是指为保障债务人之外的担保人将来承担担保责任后对**债务人的追偿权**的实现而设定的担保。

| 反担保要点 | 说明 |
|----------|------|
| **设立前提** | 以本担保的成立为前提；本担保无效但担保人承担赔偿责任的，反担保仍可有效 |
| **提供主体** | 债务人或债务人以外的其他人 |
| **方式排除** | 反担保方式**不能为保证、留置、定金**（保证会出现债务人和保证人合一；留置为法定不可约定；定金双向性不符） |
| **方式包含** | 反担保可以**抵押、质押**方式设立（依《民法典》第387条） |

**反担保保证期间的计算**：反担保的主债权是担保人对主债权的追偿权，仅在担保人实际承担担保责任后发生。起算点为：担保人实际承担担保责任后再向主债务人追偿且"宽限期"届满之日后**6个月**（《民法典》第692条第3款类推适用）。

### 反担保合同 vs 担保合同的区别

| 区别 | 担保合同 | 反担保合同 |
|------|---------|----------|
| **担保对象** | 债权人对债务人享有的债权 | 担保人承担民事责任后对债务人的追偿权 |
| **合同性质** | 主债权债务合同的从合同 | **并非担保合同的从合同**，是独立合同 |
| **当事人** | 债权人+担保人+债务人 | 担保人+反担保人+债务人（结构可不同） |
| **责任范围** | 不超过主债务 | 不超过委托担保合同中明确的主债务 |

① 来源：反担保制度（L145-L240），《民法典适用大全》物权卷3 2023年 386-462.md

## 三、第388条·担保合同

### 法条原文

> 第三百八十八条　设立担保物权，应当依照本法和其他法律的规定订立担保合同。担保合同包括抵押合同、质押合同和其他具有担保功能的合同。担保合同是主债权债务合同的从合同。主债权债务合同无效的，担保合同无效，但是法律另有规定的除外。
>
> 担保合同被确认无效后，债务人、担保人、债权人有过错的，应当根据其过错各自承担相应的民事责任。

### 核心释义

**担保合同的扩张**："担保合同包括抵押合同、质押合同**和其他具有担保功能的合同**"——本条扩张了担保合同范围，将所有权保留、融资租赁、有追索权保理、让与担保等非典型担保纳入担保合同范畴。

### 主从合同效力

| 主合同效力 | 担保合同效力 | 法律依据 |
|----------|------------|---------|
| 主合同有效 | 担保合同原则上有效 | 第388条 + 《担保制度解释》第2条 |
| 主合同无效 | 担保合同无效（除非法律另有规定） | 第388条 |
| 担保独立约定 | **无效**（违反从属性） | 《担保制度解释》第2条 |
| 金融机构独立保函 | 适用独立保函规定（不从属） | 《担保制度解释》第2条第2款 |

### 担保合同无效后的责任承担

**第三人提供的担保合同无效**（《担保制度解释》第17条）：

| 情形 | 担保人赔偿责任 |
|------|--------------|
| 债权人、担保人均有过错 | 不超过债权人不能清偿部分的**1/2** |
| 担保人有过错，债权人无过错 | 对债务人不能清偿部分**全额** |
| 债权人有过错，担保人无过错 | **不承担**赔偿责任 |

**主合同无效导致担保合同无效**：

| 情形 | 担保人赔偿责任 |
|------|--------------|
| 担保人无过错 | **不承担**赔偿责任 |
| 担保人有过错 | 不超过债务人不能清偿部分的**1/3** |

### "无效法律行为的转换"原理（《九民纪要》第54条）

银行/非银行金融机构之外的当事人开立的独立保函 + 排除担保从属性的约定 → **独立担保无效**，但**转换为从属性担保**：
- 主合同有效 → 担保合同有效，担保人与主债务人承担**连带保证责任**
- 主合同无效 → 担保合同无效；担保人有过错承担 ≤ 1/3；无过错不承担

① 来源：担保合同无效责任分担（L422-L555），《民法典适用大全》物权卷3 2023年 386-462.md

## 四、第389条·担保范围

### 法条原文

> 第三百八十九条　担保物权的担保范围包括主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用。当事人另有约定的，按照其约定。

### 核心释义：六项法定担保范围

| 担保范围 | 内容 |
|---------|------|
| 1. 主债权 | 担保合同所担保的原本债权 |
| 2. 利息 | 主债权产生的利息，包括约定利息和法定利息 |
| 3. 违约金 | 主合同约定的违约金 |
| 4. 损害赔偿金 | 因违约产生的损害赔偿 |
| 5. 保管担保财产的费用 | **仅发生在占有型担保**（质押、留置）中；抵押不发生 |
| 6. 实现担保物权的费用 | 拍卖费、变卖费、诉讼费、执行费、评估费等 |

**约定优先**：当事人可以约定担保范围"小于"或"大于"法定范围，依其约定。

### 担保范围的从属性

担保范围的约定不得大于主债务；当事人约定的担保责任范围超过主债务的，超过部分无效（《担保制度解释》第3条）。

① 来源：担保范围（L556-L707），《民法典适用大全》物权卷3 2023年 386-462.md

## 五、第390条·物上代位性

### 法条原文

> 第三百九十条　担保期间，担保财产毁损、灭失或者被征收等，担保物权人可以就获得的保险金、赔偿金或者补偿金等优先受偿。被担保债权的履行期限未届满的，也可以提存该保险金、赔偿金或者补偿金等。

### 核心释义

**物上代位性**：担保物因毁损、灭失或被征收而获得赔偿金、补偿金或其他利益补偿时，该代位物就成为担保物的代替物，债权人有权就该代位物行使担保物权。

### 代位物的范围

| 代位物类型 | 优先受偿 |
|----------|---------|
| 保险金 | ✅ 担保物权人优先受偿 |
| 赔偿金 | ✅ 担保物权人优先受偿 |
| 补偿金（含征收补偿） | ✅ 担保物权人优先受偿 |
| 担保财产的**买卖价金** | ❌ **不属于代位物** |

**买卖价金非代位物的理由**：在质押和留置中，担保物由担保物权人占有，不可能发生担保人买卖问题。在抵押中，抵押人可转让抵押财产，但《民法典》第406条第2款仅赋予抵押权人在转让可能损害抵押权时请求提前清偿或提存的权利，**体现的是追及效力**，抵押权人不能就价款优先受偿。

### 履行期届满前的处理

被担保债权的履行期限未届满的，担保物权人可以**提存**保险金、赔偿金或补偿金，避免期间利益损失。

① 来源：物上代位性（L708-L835），《民法典适用大全》物权卷3 2023年 386-462.md

## 六、第391条·债务转移的法律后果

### 法条原文

> 第三百九十一条　第三人提供担保，未经其书面同意，债权人允许债务人转移全部或者部分债务的，担保人不再承担相应的担保责任。

### 核心释义

**适用前提**：
1. 第三人提供的担保（保证或物上担保）
2. 债务人转移**全部或部分**债务
3. **未经**担保人**书面同意**
4. 债权人**允许**债务人转移

**法律后果**：担保人**不再承担相应的担保责任**（仅就已转移的部分免责）。

**⚠️ 例外情形**：
- 担保人书面同意转移的，仍承担担保责任
- 担保人明知债务转移未表示反对的，可能视为默示同意（实务争议）

① 来源：未经担保人同意转移债务（L836-L927），《民法典适用大全》物权卷3 2023年 386-462.md

## 七、第392条·人保与物保并存

### 法条原文

> 第三百九十二条　被担保的债权既有物的担保又有人的担保的，债务人不履行到期债务或者发生当事人约定的实现担保物权的情形，债权人应当按照约定实现债权；没有约定或者约定不明确，债务人自己提供物的担保的，债权人应当先就该物的担保实现债权；第三人提供物的担保的，债权人可以就物的担保实现债权，也可以请求保证人承担保证责任。提供担保的第三人承担担保责任后，有权向债务人追偿。

### 核心释义：实现顺序

```
情形 1：当事人有约定
└─ 按约定实现债权（约定优先原则）
情形 2：没有约定或约定不明
├─ 2a. 债务人自己提供物的担保
│  └─ 债权人**应当先就物的担保**实现债权
└─ 2b. 第三人提供物的担保
   └─ 债权人**可以选择**物的担保或保证（无顺序限制）
```

### 核心规则对比

| 担保情形 | 实现顺序 |
|---------|---------|
| 仅有物的担保（债务人物保） | 直接实现担保物权 |
| 仅有人的担保 | 直接请求保证人承担保证责任 |
| 物保（债务人）+ 人保 | 约定优先；无约定**先物后人** |
| 物保（第三人）+ 人保 | 约定优先；无约定**可选择** |

### 提供担保的第三人的追偿权

- 第三人物上担保人承担担保责任后 → **向债务人追偿**（不是向保证人追偿）
- 保证人承担保证责任后 → **向债务人追偿**（不是向物上担保人追偿）
- 第三人物上担保人与保证人之间：除非另有约定，**不承担**相互追偿责任（《担保制度解释》第18条）

① 来源：人保与物保并存（L928-L937），《民法典适用大全》物权卷3 2023年 386-462.md

## 八、第393条·担保物权消灭原因

### 法条原文

> 第三百九十三条　有下列情形之一的，担保物权消灭：
> （一）主债权消灭；
> （二）担保物权实现；
> （三）债权人放弃担保物权；
> （四）法律规定担保物权消灭的其他情形。

### 四种法定消灭原因

| 消灭原因 | 要点 |
|---------|------|
| 1. 主债权消灭 | 因清偿、抵消、提存、免除、混同等原因消灭；主债权部分消灭不影响担保物权存续（不可分性） |
| 2. 担保物权实现 | 担保物权已依法变价受偿；不论债权是否全部实现，担保物权消灭 |
| 3. 债权人放弃担保物权 | 须以**明示**方式（书面表示、办理注销登记、放弃占有）；单方法律行为 |
| 4. 法律规定的其他情形 | 例如：留置权丧失占有（第457条）、抵押权未在主债权诉讼时效期间行使（第419条 + 第44条解释） |

### ⚠️ 重大争议：主债权诉讼时效届满与担保物权

**三种学说**：
| 学说 | 要点 |
|------|------|
| 学说1：胜诉权丧失说 | 抵押权不消灭，仅胜诉权丧失，抵押人自愿履行的仍有效 |
| 学说2：抗辩权发生说 | 抵押权不消灭，抵押人享有主债务人的时效抗辩权 |
| 学说3：抵押权消灭说 | 主债权诉讼时效届满 → 抵押权消灭 |

**《民法典担保制度解释》第44条规定**（采纳"抗辩权发生说"立场）：
- 主债权诉讼时效届满后，抵押权人主张行使抵押权的，**人民法院不予支持**
- 抵押人以诉讼时效届满为由主张不承担担保责任的，**应予支持**
- **登记型担保物权**（抵押权、登记型权利质权）参照适用 → **人民法院不予支持**
- **占有型担保物权**（动产质权、凭证型权利质权）参照适用 → **可以拍卖变卖代位物**

**主流结论**：主债权诉讼时效届满后，担保物权**不消灭**，但**对抵押权等的行使不予保护**。质权、留置权效力不受影响。

### 担保物权的物上代位与物权消灭的关系

| 物权消灭的情形 | 担保物权效力 |
|--------------|------------|
| 标的物灭失+有代位物（保险金、补偿金） | 担保物权不消灭，继续存在于代位物 |
| 标的物灭失+无代位物 | 担保物权消灭 |
| 因征收消灭不动产所有权/用益物权 | 担保物权不消灭（物上代位性），继续存在于代位物 |
| 因拆除等事实行为消灭物权 | 视代位物情况而定 |

① 来源：担保物权消灭原因（L1050-L1150），《民法典适用大全》物权卷3 2023年 386-462.md

## ❓ 实务问答精选

> **问**：担保物权人优先受偿权是否绝对？
>
> **答**：**不是绝对**。第386条但书规定"法律另有规定的除外"，主要包括：
> 1. 《税收征管法》第45条：纳税人欠缴税款发生在设定担保前的，税收优先于担保物权
> 2. 《企业破产法》第132条：破产人历史欠薪以特定财产优先于担保物权受偿
> 3. 《海商法》第25条：船舶优先权先于船舶留置权，船舶留置权先于船舶抵押权
> 4. 建设工程价款优先受偿权（第807条）优于抵押权

> **问**：反担保方式能为保证吗？
>
> **答**：**不能**。反担保是为保障**担保人对债务人的追偿权**而设立的；若反担保方式为保证，会出现债务人和保证人合一的情形（因为债务人本身就是担保人的债务人），保证无法起到反担保作用。实务中反担保主要为**抵押、质押**方式。

> **问**：主合同无效，担保合同一定无效吗？
>
> **答**：**原则上无效，但有例外**。第388条规定"主债权债务合同无效的，担保合同无效，但是法律另有规定的除外"。例外情形：金融机构开立的独立保函（《担保制度解释》第2条第2款）→ 适用独立保函规定，不适用从属性。

> **问**：担保合同约定"担保责任超过主债务"有效吗？
>
> **答**：**无效**。担保范围的约定不得大于主债务；超过部分无效（《担保制度解释》第3条）。这是担保从属性的体现。

> **问**：主债权诉讼时效届满后，抵押权消灭了吗？
>
> **答**：**未消灭，但不予保护**。主流观点与《担保制度解释》第44条立场：抵押权不消灭，债权人主张行使抵押权的，人民法院不予支持；抵押人以诉讼时效届满为由主张不承担担保责任的，应予支持。但抵押人自愿承担的不在此限。占有型担保物权（质权、留置权）效力不受影响。

> **问**：担保物被征收的，担保物权还有效吗？
>
> **答**：**仍然有效，但存在于代位物上**。根据第390条物上代位性，担保财产被征收的，担保物权人对补偿金优先受偿。

## 典型案例

### 案例 1：汽车合格证非典型担保案

**王某彬诉招商银行武汉支行、江苏淳通汽车销售服务公司返还原物纠纷案**
- 案号：(2016)苏01民终1624号
- 审理法院：江苏省南京市中级人民法院
- 来源：中国裁判文书网

**裁判要旨**：
1. 银行以监管方式占有汽车合格证，本质属于**担保范畴**（非典型担保）
2. 但不属于《物权法》《担保法》规定的抵押、质押、留置、定金、保证五种法定类型
3. **未经公示程序，不能产生担保物权效力**，仅可对抗合同相对人
4. 银行未向消费者披露该事实，消费者属于**善意第三人**，银行不能对抗

**意义**：本案确立了"非典型担保+未经公示不能对抗善意第三人"规则，是新类型担保司法适用的重要参考。

① 来源：物权卷3 L122-L134

### 案例 2：保险保函作为反担保案

**天津华亿凡诉苏宁公司、苏宁易购集团不当得利纠纷案**
- 案号：2020沪0120民初8143号之一、之三
- 审理法院：上海市奉贤区人民法院
- 来源：人民法院服务和保障长三角一体化发展典型案例（2021年11月2日最高人民法院发布）

**裁判要旨**：保险保函可以作为反担保手段，灵活变更保全方案，兼顾公平与效率，降低保全期间涉诉企业账户冻结、资金占用等风险。

① 来源：物权卷3 L235-L241

### 案例 3：反担保范围不超主债务案

**上海杨浦融资担保有限公司诉上海中卉生态科技股份有限公司委托担保合同纠纷案**
- 案号：(2020)沪74民终944号
- 审理法院：上海金融法院
- 来源：《人民司法·案例》2021年第11期

**裁判要旨**：
1. 担保的从属性决定担保责任范围不得大于主债务
2. 委托担保合同中的违约金条款属于当事人意思自治范围
3. 反担保合同为委托担保合同的从合同，反担保人承担的反担保责任不应当超过委托担保合同中明确的主债务

① 来源：物权卷3 L244-L255

### 案例 4：主债权诉讼时效届满抵押权效力案

**王某诉李某抵押权纠纷案**
- 案号：(2016)京03民终8680号
- 审理法院：北京市第三中级人民法院
- 来源：《最高人民法院公报》2017年第7期

**裁判要旨**：抵押权人在主债权诉讼时效期间未行使抵押权，**抵押权消灭**（公报案例采"消灭说"），而非胜诉权消灭。抵押权消灭后，抵押人请求注销抵押权登记的，人民法院应予支持。

**说明**：本公报案例采"抵押权消灭说"，与《民法典担保制度解释》第44条"抗辩权发生说"立场不同。**理解适用**：在《民法典》施行后，应以《担保制度解释》第44条为准，即主债权诉讼时效届满后抵押权**不消灭**，但**不予保护**。

① 来源：物权卷3 L1100-L1145
