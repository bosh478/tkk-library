## 一、第271条·建筑物区分所有权的概念

### 法条原文

> 第二百七十一条　业主对建筑物内的住宅、经营性用房等专有部分享有所有权，对专有部分以外的共有部分享有共有和共同管理的权利。

### 核心释义

**建筑物区分所有权的3个要素**：

| 要素 | 内容 |
|------|------|
| **专有权** | 对专有部分的所有权 |
| **共有权** | 对共有部分的共有权 |
| **共同管理权**（成员权） | 对共有部分共同管理的权利 |

**业主身份的特别规定**（《建筑物区分所有权解释》第1条）：

| 类别 | 内容 |
|------|------|
| 1. 登记业主 | 依法登记取得或依据民法典第229-231条规定取得专有部分所有权的人 |
| 2. 实际占有业主 | 基于商品房买卖民事法律行为，已经合法占有专有部分但尚未办理所有权登记的人 → **可认定为业主** |

**建筑物区分所有权的5个特点**：

| 特点 | 内容 |
|------|------|
| **复合性** | 由专有权、共有权和共同管理权构成的复合性权利 |
| **整体性** | 三项权利必须一并转让、抵押或继承 |
| **专有权的主导性** | 专有权居于主导地位，是共有权和成员权的基础 |
| **突破一物一权** | 是对传统物权法一物一权原则的突破 |
| **扩张性** | 专有权不仅延伸到共有部分，还延伸到成员权 |

## 二、第272条·专有权的行使与限制

### 法条原文

> 第二百七十二条　业主对其建筑物专有部分享有占有、使用、收益和处分的权利。业主行使权利不得危及建筑物的安全，不得损害其他业主的合法权益。

### 核心释义

**专有权的3个判断标准**（《建筑物区分所有权解释》第2条第1款）：

| 标准 | 内容 |
|------|------|
| 1. 构造上的独立性 | 能够明确区分 |
| 2. 利用上的独立性 | 可以排他使用 |
| 3. 法律上的独立性 | 能够登记成为特定业主所有权的客体 |

**专有权的行使限制**：

| 限制类型 | 内容 |
|---------|------|
| 不得危及建筑物安全 | 不当毁损建筑物（改建非承重墙、改动管道线路等） |
| 不得损害其他业主合法权益 | 不当使用（饲养动物、放置危险物品、破坏卫生和安宁等） |

**"专有部分"的具体范围**：

| 类型 | 是否构成专有部分 |
|------|----------------|
| 住宅 | 是 |
| 经营性用房 | 是 |
| 整栋建筑物 | 是（依《建筑物区分所有权解释》第2条第1款） |
| 车位、摊位等特定空间 | 是（具备3要件） |
| 露台 | 须**同时符合**规划专属于特定房屋+建设单位销售时已根据规划列入特定房屋买卖合同 |

## 三、第273条·共有权的行使

### 法条原文

> 第二百七十三条　业主对建筑物专有部分以外的共有部分，享有权利，承担义务；不得以放弃权利为由不履行义务。
>
> 业主转让建筑物内的住宅、经营性用房，其对共有部分享有的共有和共同管理的权利一并转让。

### 核心释义

**共有部分的3类**（依《建筑物区分所有权解释》第3条）：

| 类型 | 内容 |
|------|------|
| 1. 法定共有 | 建筑物的基本结构部分（基础、承重结构、外墙、屋顶）+ 公共通行部分（通道、楼梯、大堂）+ 附属设施设备（消防、公共照明）+ 避难层、设备层 |
| 2. 天然共有 | 基于建筑物特性而当然存在的楼梯间、消防设备、走廊、水塔等 |
| 3. 约定共有 | 既不属于业主专有，也不属于市政公用部分或其他权利人所有的场所及设施 |

**业主不得以放弃权利为由不履行义务的典型情形**：

| 情形 | 处理 |
|------|------|
| 业主不使用电梯 | 仍应支付电梯维修费用 |
| 业主冬季不在住宅居住 | 在集中供暖情况下仍应支付暖气费用 |
| 业主放弃共有部分权利 | 仍应承担共有部分维护义务 |

**建筑物区分所有权的"主从性"**：业主对专有部分的所有权丧失 → 对共有部分的共有权和共同管理的权利一并丧失

## 四、第274条·共有部分的具体范围

### 法条原文

> 第二百七十四条　建筑区划内的道路，属于业主共有，但是属于城镇公共道路的除外。建筑区划内的绿地，属于业主共有，但是属于城镇公共绿地或者明示属于个人的除外。建筑区划内的其他公共场所、公用设施和物业服务用房，属于业主共有。

### 核心释义

**共有部分范围一览**：

| 类型 | 属于业主共有 | 例外 |
|------|------------|------|
| 道路 | ✓ | 城镇公共道路 |
| 绿地 | ✓ | 城镇公共绿地 / 明示属于个人的绿地 |
| 其他公共场所 | ✓ | 无 |
| 公用设施 | ✓ | 无 |
| 物业服务用房 | ✓ | 无 |

**关于"绿地"的特别说明**：

| 类型 | 归属 |
|------|------|
| 小区内非城镇公共绿地 | 业主共有 |
| 一层建筑物单元窗前绿地 + 与建筑物毗邻的特定区域内绿地 | 明示属于个人的除外 |
| 城镇公共绿地 | 不属于业主共有 |

## 五、第275-276条·车位、车库

### 第275条·车位、车库的归属

#### 法条原文

> 第二百七十五条　建筑区划内，规划用于停放汽车的车位、车库的归属，由当事人通过出售、附赠或者出租等方式约定。
>
> 占用业主共有的道路或者其他场地用于停放汽车的车位，属于业主共有。

#### 核心释义

**两类车位、车库的处理规则**：

| 类型 | 归属规则 |
|------|---------|
| **规划内车位、车库** | 由当事人通过**出售、附赠或出租**约定 |
| **占用共有道路/场地的车位** | **属于业主共有**（依《建筑物区分所有权解释》第6条） |

**未约定或约定不明时的处理**：

| 情形 | 处理 |
|------|------|
| 建设成本未分摊至业主购房费用 | 归建设单位 |
| 建设成本已分摊至业主 | 归全体业主共有 |
| 建设单位无法证明 | 归全体业主共有（举证责任倒置） |

### 第276条·车位、车库应当首先满足业主的需要

#### 法条原文

> 第二百七十六条　建筑区划内，规划用于停放汽车的车位、车库应当首先满足业主的需要。

#### 核心释义

**"首先满足业主的需要"的认定**：

| 维度 | 内容 |
|------|------|
| 数量满足 | 按配置比例（车位与房屋套数） |
| 时间满足 | 任何时候业主合理需要都应得到满足 |
| **限制**：禁止"只售不租" | 建设单位出租规划车位前须依法完成规划验收，不得以"只售不租"等名义拒绝提供停车服务 |
| 例外 | 配置比例内业主合理需要得到满足后，可将多余车位出租给第三人 |

### 典型案例

#### 重庆市豪运房地产开发有限公司与重庆市九龙坡区西彭帝景豪苑业主委员会车位纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2017）最高法民申2817号 |
| 审理法院 | 最高人民法院 |
| 来源 | 《最高人民法院公报》2021年第2期 |
| 裁判要点 | 开发商建造小区时支付了建筑区划内的土地使用权出让金。小区建设完成后，随小区内房屋的出售，小区建筑区划内的土地使用权也随之转移，小区的共有部分土地使用权归小区业主共有。**不能办理产权登记**成为特定业主所有权客体的地上车位，不能成为享有专有权的专有部分，属于占用业主共有的道路或者其他场地用于停放汽车的车位，**属于业主共有** |

## 六、第277条·业主大会与业主委员会

### 法条原文

> 第二百七十七条　业主可以设立业主大会，选举业主委员会。业主大会、业主委员会成立的具体条件和程序，依照法律、法规的规定。
>
> 地方人民政府有关部门、居民委员会应当对设立业主大会和选举业主委员会给予指导和协助。

### 核心释义

**业主大会的法律地位**：

| 项目 | 内容 |
|------|------|
| 性质 | 物业管理区域内全体业主组成的自治组织 |
| 数量 | 一个物业管理区域成立一个业主大会 |
| 职责 | 代表和维护全体业主的合法权益 |
| 表决权 | 业主拥有的建筑面积 + 业主人数 |

**业主委员会的职责**（《物业管理条例》第15条）：

| 职责 | 内容 |
|------|------|
| 1 | 召集业主大会会议，报告物业管理的实施情况 |
| 2 | 代表业主与业主大会选聘的物业服务企业签订物业服务合同 |
| 3 | 及时了解业主、物业使用人的意见和建议，监督和协助物业服务企业履行物业服务合同 |
| 4 | 监督管理规约的实施 |
| 5 | 业主大会赋予的其他职责 |

## 七、第278条·业主共同决定事项与表决比例

### 法条原文

> 第二百七十八条　下列事项由业主共同决定：
>
> （一）制定和修改业主大会议事规则；
> （二）制定和修改管理规约；
> （三）选举业主委员会或者更换业主委员会成员；
> （四）选聘和解聘物业服务企业或者其他管理人；
> （五）使用建筑物及其附属设施的维修资金；
> （六）筹集建筑物及其附属设施的维修资金；
> （七）改建、重建建筑物及其附属设施；
> （八）改变共有部分的用途或者利用共有部分从事经营活动；
> （九）有关共有和共同管理权利的其他重大事项。
>
> 业主共同决定事项，应当由专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决。决定前款第六项至第八项规定的事项，应当经参与表决专有部分面积四分之三以上的业主且参与表决人数四分之三以上的业主同意。决定前款其他事项，应当经参与表决专有部分面积过半数的业主且参与表决人数过半数的业主同意。

### 核心释义

**表决的"双2/3门槛"**：

| 阶段 | 比例 |
|------|------|
| **参与表决门槛** | 专有部分面积占比**2/3以上** + 人数占比**2/3以上** |
| → 第六至八项（重大事项） | **3/4以上** |
| → 其他事项 | **过半数** |

**9项共同决定事项**：

| 类别 | 事项 | 表决比例 |
|------|------|---------|
| **一般事项**（半数通过） | 1. 制定/修改议事规则 | 2/3参与+过半数同意 |
| | 2. 制定/修改管理规约 | 同上 |
| | 3. 选举/更换业委会成员 | 同上 |
| | 4. 选聘/解聘物业服务企业 | 同上 |
| | 5. 使用维修资金 | 同上 |
| | 9. 其他重大事项 | 同上 |
| **重大事项**（3/4同意） | 6. 筹集维修资金 | 2/3参与+3/4同意 |
| | 7. 改建/重建建筑物及其附属设施 | 同上 |
| | 8. 改变共有部分用途/经营 | 同上 |

**专有部分面积的计算**（《建筑物区分所有权解释》第8条）：

| 情形 | 计算标准 |
|------|---------|
| 已进行不动产登记 | 按登记簿记载的面积计算 |
| 尚未登记但已实测 | 按测绘机构的实测面积计算 |
| 尚未实测 | 按房屋买卖合同记载的面积计算 |

## 八、第279条·住改商

### 法条原文

> 第二百七十九条　业主不得违反法律、法规以及管理规约，将住宅改变为经营性用房。业主将住宅改变为经营性用房的，除遵守法律、法规以及管理规约外，应当经有利害关系的业主一致同意。

### 核心释义

**"住改商"的2个合法性要件**：

| 要件 | 内容 |
|------|------|
| 1. 程序性要件 | 经**有利害关系的业主一致同意**（不再适用多数决） |
| 2. 实体性要件 | 遵守法律、法规以及管理规约 |

**"有利害关系的业主"的范围**（《建筑物区分所有权解释》第11条）：

| 范围 | 界定 |
|------|------|
| **本栋建筑物内的其他业主** | **当然的有利害关系的业主**（无需举证） |
| 建筑区划内本栋建筑物之外的业主 | 须举证证明房屋价值、生活质量受到或可能受到不利影响 |

**同意方式**：必须以**明示的方式**作出（书面或明确无误的口头表示），不能以沉默推定为同意。

### 典型案例

#### 张某诉郑某、D公司建筑物区分所有权纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2013）鄂武汉中民终字第01019号 |
| 审理法院 | 湖北省武汉市中级人民法院 |
| 来源 | 《最高人民法院公报》2014年第11期 |
| 裁判要点 | 即使业主对房屋的使用没有给其他区分所有权人造成噪音、污水、异味等影响，只要房屋的用途发生改变，由专供个人、家庭日常生活居住使用改变为用于商业、工业、旅游、办公等经营性活动，即可认定该行为影响了业主的安宁生活，属于将住宅改变为经营性用房 |

## 九、第280条·业主撤销权

### 法条原文

> 第二百八十条　业主大会或者业主委员会的决定，对业主具有法律约束力。
>
> 业主大会或者业主委员会作出的决定侵害业主合法权益的，受侵害的业主可以请求人民法院予以撤销。

### 核心释义

**撤销权的行使期限**（《建筑物区分所有权解释》第12条）：
- 业主应当在知道或应当知道决定之日起**1年内**行使

**撤销权的法律后果**：

| 范围 | 处理 |
|------|------|
| 仅涉及业主之间 | 撤销效力仅及于诉讼当事人及其他业主 |
| 涉及第三人 | 与业主大会/业委会实施的法律行为**应为无效** |
| 善意第三人 | 有权请求业主大会/业委会赔偿信赖利益损失 |
| 恶意第三人 | 无权请求赔偿 |

## 十、第281条·维修资金

### 法条原文

> 第二百八十一条　建筑物及其附属设施的维修资金，属于业主共有。经业主共同决定，可以用于电梯、屋顶、外墙、无障碍设施等共有部分的维修、更新和改造。建筑物及其附属设施的维修资金的筹集、使用情况应当定期公布。
>
> 紧急情况下需要维修建筑物及其附属设施的，业主大会或者业主委员会可以依法申请使用建筑物及其附属设施的维修资金。

### 核心释义

**维修资金的4个要点**：

| 要点 | 内容 |
|------|------|
| 1. 归属 | **属于业主共有**（不能处分、转让及分割为业主份额） |
| 2. 用途 | 电梯、屋顶、外墙、无障碍设施等共有部分的维修、更新和改造 |
| 3. 公开 | 筹集、使用情况应当**定期公布** |
| 4. 紧急使用 | 紧急情况下可申请使用 |

**维修资金的筹集 vs 使用的表决比例**（依第278条）：

| 事项 | 表决比例 |
|------|---------|
| 筹集维修资金 | 2/3参与+3/4同意（重大事项） |
| 使用维修资金 | 2/3参与+过半数同意（一般事项） |

### 指导案例

#### 指导案例65号·上海市虹口区久乐大厦小区业主大会诉上海环亚实业总公司业主共有权纠纷案

| 项目 | 内容 |
|------|------|
| 发布时间 | 2016年9月19日 |
| 裁判要点 | 专项维修资金是专门用于物业共用部位、共用设施设备保修期满后的维修和更新、改造的资金，属于全体业主共有。缴纳专项维修资金是业主为维护建筑物的长期安全使用而应承担的一项**法定义务**。业主拒绝缴纳专项维修资金，并以诉讼时效提出抗辩的，人民法院**不予支持** |

## 十一、第282条·共有部分收益的归属

### 法条原文

> 第二百八十二条　建设单位、物业服务企业或者其他管理人等利用业主的共有部分产生的收入，在扣除合理成本之后，属于业主共有。

### 核心释义

**共有部分收益的典型类型**：

| 类型 | 典型情形 |
|------|---------|
| 车库、车位 | 满足业主需要后剩余部分出租收益 |
| 楼顶平台/外墙面 | 设置广告位收益 |
| 走廊、楼梯、过道、电梯间 | 设置广告位收益 |

**收益归属的处理**：

| 步骤 | 内容 |
|------|------|
| 1. 扣除合理成本 | 由行为人承担举证责任 |
| 2. 归属于业主共有 | 由全体业主共有 |
| 3. 用途由业主共同决定 | 用于补充专项维修资金或业主共同决定的其他用途 |

**合理成本**：包括管理共有部分产生的合理支出。物业服务企业主张扣除合理成本的，应提供对共有部分管理的收入和支出报表等证据。

## 十二、第283条·费用分摊与收益分配

### 法条原文

> 第二百八十三条　建筑物及其附属设施的费用分摊、收益分配等事项，有约定的，按照约定；没有约定或者约定不明确的，按照业主专有部分面积所占比例确定。

### 核心释义

**费用分摊与收益分配的规则**：

| 情形 | 处理 |
|------|------|
| 有约定 | 按约定 |
| 无约定或约定不明 | 按业主**专有部分面积所占比例**确定 |
| 低楼层业主不使用电梯 | 仍应分摊电梯费用 |

## 十三、第284-285条·物业服务

### 第284条·自行管理 vs 委托管理

| 管理方式 | 内容 |
|---------|------|
| 自行管理 | 业主可以自行管理建筑物及其附属设施 |
| 委托管理 | 委托物业服务企业或其他管理人管理 |
| 更换权 | 对建设单位聘请的物业服务企业或其他管理人，业主有权依法更换 |

### 第285条·物业服务人的义务

#### 法条原文

> 第二百八十五条　物业服务企业或者其他管理人根据业主的委托依照本法第三编有关物业服务合同的规定管理建筑区划内的建筑物及其附属设施，接受业主的监督，并及时答复业主对物业服务情况提出的询问。
>
> 物业服务企业或者其他管理人应当执行政府依法实施的应急处置措施和其他管理措施，积极配合开展相关工作。

#### 核心释义

**物业服务人的4项义务**：

| 义务 | 内容 |
|------|------|
| 1 | 依照物业服务合同管理建筑物及其附属设施 |
| 2 | 接受业主的监督 |
| 3 | 及时答复业主的询问 |
| 4 | **执行政府依法实施的应急处置措施**（新增） |

## 十四、第286条·业主义务与业主大会/业委会的管理权

### 法条原文

> 第二百八十六条　业主应当遵守法律、法规以及管理规约，相关行为应当符合节约资源、保护生态环境的要求。对于物业服务企业或者其他管理人执行政府依法实施的应急处置措施和其他管理措施，业主应当依法予以配合。
>
> 业主大会或者业主委员会，对任意弃置垃圾、排放污染物或者噪声、违反规定饲养动物、违章搭建、侵占通道、拒付物业费等损害他人合法权益的行为，有权依照法律、法规以及管理规约，请求行为人停止侵害、排除妨碍、消除危险、恢复原状、赔偿损失。
>
> 业主或者其他行为人拒不履行相关义务的，有关当事人可以向有关行政主管部门报告或者投诉，有关行政主管部门应当依法处理。

### 核心释义

**业主的3项义务**：

| 义务 | 内容 |
|------|------|
| 1. 基本义务 | 遵守法律、法规以及管理规约 |
| 2. 绿色义务 | 相关行为应当符合节约资源、保护生态环境的要求 |
| 3. 配合义务 | 对物业服务企业执行政府应急处置措施应当依法予以配合 |

**业主大会/业委会的5项管理请求权**：

| 请求权 | 法律基础 |
|--------|---------|
| 停止侵害 | 《民法典》第236条 / 第1167条 |
| 排除妨碍 | 《民法典》第236条 / 第1167条 |
| 消除危险 | 《民法典》第236条 / 第1167条 |
| 恢复原状 | 《民法典》第237条 |
| 赔偿损失 | 《民法典》第238条 / 第1165条 |

**"损害他人合法权益的行为"的6种典型类型**（《建筑物区分所有权解释》第15条）：

| 行为 | 内容 |
|------|------|
| 1 | 损害房屋承重结构、违章使用电力/燃气/消防设施、放置危险物品 |
| 2 | 破坏/改变建筑物外墙面形状、颜色等损害外观 |
| 3 | 违反规定进行房屋装饰装修 |
| 4 | 违章加建、改建，侵占、挖掘公共通道、道路、场地 |
| 5 | 任意弃置垃圾、排放污染物或噪声 |
| 6 | 违反规定饲养动物、违章搭建、侵占通道、拒付物业费 |

**3重救济途径**：

| 途径 | 内容 |
|------|------|
| 1. 业主自治 | 业主大会/业委会请求行为人停止侵害等 |
| 2. 行政救济 | 拒不履行时向有关行政主管部门报告或投诉 |
| 3. 民事诉讼 | 业主个人提起诉讼请求承担民事责任 |

## 十五、第287条·业主合法权益的民事责任请求权

### 法条原文

> 第二百八十七条　业主对建设单位、物业服务企业或者其他管理人以及其他业主侵害自已合法权益的行为，有权请求其承担民事责任。

### 核心释义

**侵害业主合法权益的3类主体**：

| 主体 | 典型行为 |
|------|---------|
| **建设单位** | 违反合同约定、修改规划方案、使用不符合要求的建筑材料、侵占共有部分 |
| **物业服务企业/其他管理人** | 妨碍业主行使物权、挪用维修资金、强迫接受不需要的服务、安全保障义务违反 |
| **其他业主** | 占用共有部分、改变房屋主体结构、住改商（未经利害关系业主同意）、相邻权侵害 |

**民事责任承担方式**（《民法典》第179条）：

| 方式 | 内容 |
|------|------|
| 1 | 停止侵害 |
| 2 | 排除妨碍 |
| 3 | 消除危险 |
| 4 | 返还财产 |
| 5 | 恢复原状 |
| 6 | 修理、重作、更换 |
| 7 | 继续履行 |
| 8 | 赔偿损失 |
| 9 | 支付违约金 |
| 10 | 消除影响、恢复名誉 |
| 11 | 赔礼道歉 |

### 典型案例

#### 赵某华与沈阳皇朝万鑫酒店管理有限公司、沈阳中一万鑫物业管理有限公司财产损害赔偿纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2018）最高法民再206号 |
| 审理法院 | 最高人民法院 |
| 来源 | 《最高人民法院公报》2019年第5期 |
| 裁判要点 | 物业服务企业未尽到安全保障义务的，应在其能够预见和防范的范围内承担相应的**补充责任**。多个行为人的行为构成多因一果的，应根据各自过错承担相应责任 |

## ⚠️ 司法适用难点

### 难点一：业主身份的认定

**争议**：未办理所有权登记的买受人是否具有业主身份？

**主流观点**（依《建筑物区分所有权解释》第1条第2款）：
- **可以认定为业主**：基于与建设单位之间的商品房买卖民事法律行为，已合法占有专有部分但尚未办理所有权登记的人
- **理由**：对共有部分的利用和共同管理权的行使需求更强烈

### 难点二：第278条表决比例的计算

**争议**：如何确定"专有部分面积"和"业主人数"？

**主流观点**：

| 计算项目 | 计算标准 |
|---------|---------|
| 专有部分面积 | 依《建筑物区分所有权解释》第8条 |
| 业主人数 | 依《建筑物区分所有权解释》第9条（按专有部分数量计算，一个专有部分按一人计算） |
| 共有人 | 一个专有部分有两个以上所有权人的，应当推选一人行使表决权 |

### 难点三：车位、车库纠纷处理

**争议**：未约定或约定不明时车位、车库的归属？

**主流观点**：
- 建设成本未分摊 → 归建设单位
- 建设成本已分摊 → 归全体业主共有
- 建设单位承担举证责任
- 不能办理产权登记 → 不能成为专有部分 → 属于共有部分

### 难点四：第279条"住改商"的同意方式

**争议**：利害关系业主的"同意"是否可以是默示同意？

**主流观点**：
- **不能**以默示推定为同意
- 必须以**明示的方式**作出（书面或明确无误的口头表示）
- 业主在约定期限内未表态 → 不能认定其默认同意

### 难点五：维修资金的诉讼时效抗辩

**争议**：业主能否以诉讼时效期间经过为由抗辩不缴纳维修资金？

**主流观点**：
- **不能**（依指导案例65号）
- 缴纳维修资金是**法定义务**
- 不存在因时间经过而可以不缴的问题

### 难点六：业主大会/业委会的诉讼主体资格

**争议**：业主大会或业主委员会是否具有民事诉讼主体资格？

**主流观点**：
- 目前**不宜确定**业主大会、业委会具有民事诉讼主体资格
- 业主委员会在**部分情形下**（如物业服务合同纠纷）可以具有诉讼主体资格
- 侵害业主**共同权益**的纠纷，可依《民事诉讼法》推选代表人进行诉讼

## ❓ 实务问答

### Q1：业主对建筑物专有部分享有哪些权利？

**A**：依《民法典》第272条，业主对其建筑物专有部分享有**占有、使用、收益和处分**的权利。但行使权利不得**危及建筑物的安全**，不得**损害其他业主的合法权益**。

### Q2：第278条业主共同决定事项的表决比例？

**A**：3层结构：

| 阶段 | 比例 |
|------|------|
| **参与表决门槛** | 专有部分面积占比 **2/3以上** + 人数占比 **2/3以上** |
| → 第六至八项（重大事项） | **3/4以上**同意 |
| → 其他事项 | **过半数**同意 |

### Q3：车位、车库的归属规则？

**A**：

| 类型 | 归属规则 |
|------|---------|
| 规划内车位、车库 | 当事人通过出售、附赠或出租**约定** |
| 占用共有道路/场地的车位 | **属于业主共有** |
| 未经约定或约定不明 | 建设成本未分摊归建设单位；已分摊归全体业主共有；建设单位承担举证责任 |

### Q4：第279条"住改商"的同意条件？

**A**：必须**同时满足**2个条件：
1. 遵守法律、法规以及管理规约
2. **经有利害关系的业主一致同意**（不再适用多数决）

### Q5：第281条维修资金的归属和使用规则？

**A**：

| 项目 | 内容 |
|------|------|
| 归属 | 属于业主共有 |
| 用途 | 电梯、屋顶、外墙、无障碍设施等共有部分的维修、更新和改造 |
| 筹集 | 需专有部分面积 2/3参与+3/4同意 |
| 使用 | 需专有部分面积 2/3参与+过半数同意 |
| 公开 | 筹集、使用情况应定期公布 |
| 紧急使用 | 业主大会/业委会可依法申请使用 |

### Q6：第282条共有部分收益的归属？

**A**：建设单位、物业服务企业或其他管理人利用业主共有部分产生的收入，**扣除合理成本后**，属于**业主共有**。成本支出的合理性由行为人承担举证责任。用途由业主共同决定（用于补充专项维修资金或其他用途）。

### Q7：第287条业主请求权与诉讼时效？

**A**：业主对侵害自己合法权益的行为，有权请求其承担**民事责任**（不仅是诉讼，也包括和解、调解、仲裁等）。业主大会/业委会不具有民事诉讼主体资格的，可推选代表人进行诉讼。指导案例65号确认：**维修资金**缴纳是**法定义务**，不适用诉讼时效抗辩。

### Q8：第286条业主大会/业委会的管理权范围？

**A**：

| 项目 | 内容 |
|------|------|
| 行使主体 | 业主大会**或者**业主委员会（任一均可独立行使） |
| 请求权类型 | 停止侵害 + 排除妨碍 + 消除危险 + 恢复原状 + 赔偿损失 |
| 法律基础 | 《民法典》第236、237、238、1165、1167、577条 |
| 救济途径 | 业主自治 → 行政投诉 → 民事诉讼 |
