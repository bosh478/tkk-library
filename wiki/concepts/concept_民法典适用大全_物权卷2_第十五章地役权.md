# 民法典第十五章【地役权】综合

## 章节目录

本章共 14 条（Articles 372-385），规定利用他人不动产提高自己不动产效益的地役权制度。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第372条 | 地役权的概念 | 供役地/需役地 + 提高效益 |
| 第373条 | 地役权合同 | 书面形式 + 内容 |
| 第374条 | 地役权的设立与登记 | 合同生效时设立 + 登记对抗 |
| 第375条 | 供役地权利人的义务 | 允许利用 + 不得妨害 |
| 第376条 | 地役权人的权利义务 | 合同约定 + 最小限制 |
| 第377条 | 地役权期限 | 不得超过用益物权剩余期限 |
| 第378条 | 地役权的承继 | 用益物权人继续享有 |
| 第379条 | 在先用益物权对地役权的限制 | 用益物权人同意 |
| 第380条 | 地役权的转让 | 不得单独转让 + 一并转让 |
| 第381条 | 地役权的抵押 | 不得单独抵押 + 一并抵押 |
| 第382条 | 地役权对需役地的不可分性 | 受让人同时享有 |
| 第383条 | 地役权对供役地的不可分性 | 对受让人有约束力 |
| 第384条 | 地役权消灭 | 法定情形 |
| 第385条 | 地役权变更后登记 | 及时办理变更/注销登记 |

## 核心制度一：地役权的概念（第372条）

### 第372条 法条原文

> 地役权人有权按照合同约定，**利用他人的不动产**以提高自己的不动产的效益。
>
> 前款所称**他人的不动产**为**供役地**，**自己的不动产**为**需役地**。

### 核心特征

| 特征 | 内容 |
|------|------|
| **客体** | 供役地（他人的不动产） |
| **目的** | **提高需役地（自己的不动产）的效益** |
| **设立方式** | 合同（地役权合同） |
| **性质** | 用益物权 |
| **地役权合同内容** | ① 当事人信息；② 供役地和需役地的位置；③ 利用目的和方法；④ 利用期限；⑤ 费用及其支付方式；⑥ 解决争议的方法 |

### 地役权 vs 相邻关系

| 维度 | 地役权 | 相邻关系 |
|------|-------|---------|
| **性质** | 用益物权（意定） | 法定权利 |
| **产生基础** | 合同约定 | 法律直接规定（不动产相邻） |
| **客体** | 他人不动产 | 相邻不动产 |
| **对价** | 通常有偿（可约定） | 一般无偿 |
| **权利转移** | 不得单独转让 | 随不动产转移 |
| **登记** | 登记对抗 | 不需登记 |

## 核心制度二：地役权的设立与登记（第373-374条）

### 第373条 合同形式

> 设立地役权，当事人应当采用**书面形式**订立地役权合同。

### 第374条 设立时点

> 地役权自地役权合同生效时设立。当事人要求登记的，可以向登记机构申请地役权登记；**未经登记，不得对抗善意第三人**。

**设立时点**：**合同生效时设立**（登记对抗主义）

### 登记对抗 vs 登记生效对比

| 物权类型 | 设立时点 |
|---------|---------|
| 土地承包经营权 | 合同生效时设立 |
| 建设用地使用权 | **登记时设立** |
| 居住权 | **登记时设立** |
| **地役权** | **合同生效时设立**（**登记对抗**） |

## 核心制度三：供役地权利人的义务（第375条）

> 供役地权利人应当按照合同约定，**允许地役权人利用其不动产**，**不得妨害地役权人行使权利**。

**两大义务**：
1. 允许地役权人利用其不动产
2. 不得妨害地役权人行使权利

## 核心制度四：地役权人的权利义务（第376条）

> 地役权人应当按照合同约定的**利用目的和方法**利用供役地，**尽量减少对供役地权利人物权的限制**。

**核心要求**：最小限制原则——按约定目的和方法利用 + 尽量减少限制。

## 核心制度五：地役权期限（第377条）

> 地役权期限由当事人约定；但是，**不得超过土地承包经营权、建设用地使用权等用益物权的剩余期限**。

**关键限制**：**不得超过供役地上用益物权的剩余期限**。

## 核心制度六：地役权的承继与限制（第378-381条）

### 第378条 承继

> 土地所有权人享有地役权或者负担地役权的，设立土地承包经营权、宅基地使用权等用益物权时，**该用益物权人继续享有或者负担已经设立的地役权**。

### 第379条 在先用益物权的限制

> 土地上已经设立土地承包经营权、建设用地使用权、宅基地使用权等用益物权的，**未经用益物权人同意，土地所有权人不得设立地役权**。

**核心规则**：
- 已有用益物权 → 所有权人设立地役权须**经用益物权人同意**

### 第380条 地役权的转让

> 地役权**不得单独转让**。土地承包经营权、建设用地使用权等转让的，**地役权一并转让**，但是合同另有约定的除外。

**核心原则**：**从属性**——地役权不得单独转让，随主权利（土地承包经营权、建设用地使用权等）一并转让。

### 第381条 地役权的抵押

> 地役权**不得单独抵押**。土地经营权、建设用地使用权等抵押的，**在实现抵押权时，地役权一并转让**。

**核心原则**：**从属性**——地役权不得单独抵押，随主权利抵押。

## 核心制度七：不可分性（第382-383条）

### 第382条 对需役地的不可分性

> 需役地以及需役地上的土地承包经营权、建设用地使用权等**部分转让**时，转让部分涉及地役权的，**受让人同时享有地役权**。

### 第383条 对供役地的不可分性

> 供役地以及供役地上的土地承包经营权、建设用地使用权等**部分转让**时，转让部分涉及地役权的，**地役权对受让人具有法律约束力**。

### 不可分性的含义

**地役权不受需役地/供役地部分转让的影响**——这是地役权的从属性的延伸。

| 情形 | 不可分性规则 |
|------|------------|
| 需役地部分转让 | 受让人**同时享有**地役权 |
| 供役地部分转让 | 地役权**对受让人有约束力** |

## 核心制度八：消灭（第384-385条）

### 第384条 消灭事由

> 地役权人有下列情形之一的，供役地权利人有权**解除地役权合同**，**地役权消灭**：

1. 违反法律规定或者合同约定，滥用地役权
2. 有偿利用供役地，**约定的付款期间届满后在合理期限内经两次催告未支付费用**

### 第385条 变更后登记

> 已经登记的地役权变更、转让或者消灭的，应当**及时办理变更登记或者注销登记**。

## 适用指引综合

### 地役权登记的两种效力

| 效力 | 内容 |
|------|------|
| **权利推定效力** | 登记记载的权利人应被推定为法律上的权利人 |
| **善意保护效力（公信力）** | 善意第三人因信赖登记而进行的交易受保护 |

**公信力意义**：保护交易安全，鼓励市场交易。

## 实务问答精选

> **问**：地役权何时设立？登记起什么作用？
>
> **答**：**地役权自地役权合同生效时设立**（《民法典》第374条）。登记不是设立要件，而是**对抗善意第三人的要件**——未经登记，不得对抗善意第三人。

> **问**：地役权能否单独转让？
>
> **答**：**不能**（《民法典》第380条）。地役权具有从属性，土地承包经营权、建设用地使用权等转让时，地役权一并转让（合同另有约定的除外）。

> **问**：地役权期限有何限制？
>
> **答**：不得超过供役地上**用益物权的剩余期限**（第377条）。

> **问**：地役权人与相邻关系如何区分？
>
> **答**：地役权是**意定用益物权**（基于合同），需登记对抗；相邻关系是**法定权利**（基于相邻不动产的客观状态），无需登记。地役权一般有偿，相邻关系一般无偿。

> **问**：已有用益物权的土地上，所有权人能否再设立地役权？
>
> **答**：**未经用益物权人同意，不得设立地役权**（《民法典》第379条）。

> **问**：地役权消灭的情形有哪些？
>
> **答**：① 违反法律规定或合同约定**滥用地役权**；② 有偿利用供役地，约定的付款期间届满后在合理期限内经**两次催告未支付费用**（第384条）。供役地权利人有权**解除地役权合同**。
