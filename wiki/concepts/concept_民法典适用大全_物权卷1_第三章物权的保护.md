## 一、第233条·物权保护的救济途径

### 法条原文

> 第二百三十三条　物权受到侵害的，权利人可以通过和解、调解、仲裁、诉讼等途径解决。

### 核心释义

#### （一）救济途径的二元分类

| 类型 | 内容 | 典型方式 |
|------|------|---------|
| **公力救济** | 权利人通过向人民法院提起诉讼的方式保护自己的物权 | 民事诉讼、行政诉讼 |
| **私力救济** | 权利人通过自己的力量或者其他非国家力量来保护其受到侵害的物权 | 和解、调解、仲裁 |

#### （二）四大救济途径详解

**1. 和解**

| 要素 | 内容 |
|------|------|
| 定义 | 权利人与侵害人通过达成协议解决物权纠纷的救济方式 |
| 特点 | 当事人之间在没有第三方参加的情况下自愿协商 |
| 法律性质 | 当事人处分自己民事实体权利的民事法律行为 |
| 时机 | 诉讼前、诉讼过程中、执行中均可 |
| 法律依据 | 《民事诉讼法》第53条 |

**2. 调解**

| 类型 | 内容 |
|------|------|
| 法院调解 | 在诉讼中达成，具有强制执行力 |
| 仲裁机构调解 | 由仲裁机构作出的生效调解书具有强制执行力 |
| 人民调解 | 经人民调解委员会调解达成的协议，具有合同效力；经司法确认后具有强制执行力 |
| 其他机构调解 | 村民委员会、乡镇人民政府等 |

**法律依据**：《人民调解法》第33条规定，经人民调解委员会调解达成调解协议后，双方当事人认为有必要的，可以自调解协议生效之日起30日内共同向人民法院申请司法确认。

**3. 仲裁**

| 要素 | 内容 |
|------|------|
| 前提条件 | 当事人自愿达成有效的仲裁协议 |
| 仲裁协议的主要内容 | 仲裁事项、仲裁的意思表示和选定的仲裁机构 |
| 法律依据 | 《仲裁法》 |

**4. 诉讼**

| 要素 | 内容 |
|------|------|
| 含义 | 权利人向有管辖权的人民法院提起请求保护其利益 |
| 主要类型 | 民事诉讼（物权保护为主） |
| 辅助类型 | 行政诉讼、刑事诉讼（涉公权力侵害物权时） |

#### （三）"等途径"的开放性

**其他救济途径**（依本条"等"的开放式规定）：

| 救济途径 | 法律依据 | 适用要件 |
|---------|---------|---------|
| **正当防卫** | 《民法典》第181条 | 不法侵害+正在发生+针对侵害人+不超过必要限度 |
| **紧急避险** | 《民法典》第182条 | 现实危险+不得已+不超过必要限度 |
| **自助行为** | 《民法典》第1177条 | 公力救济不能一时到达+权利受到侵害+措施必要 |

### 适用指引

**正当防卫的4要件**：

| 要件 | 内容 |
|------|------|
| 1 | 针对不法侵害（如电力部门依据《电力法》砍伐妨碍电力设施的树木为合法行为，不得防卫） |
| 2 | 不法侵害须正在发生（不允许事前防卫或事后防卫） |
| 3 | 排除不法侵害的行为须针对不法侵害人本人 |
| 4 | 不超过必要限度（结合侵害的剧烈和紧急程度、客观环境、防卫行为对不法侵害人的损害程度判断） |

**自助行为的3要件**：

| 要件 | 内容 |
|------|------|
| 1 | 自助行为的主体应当是权利人或者是与权利人有利害关系的其他人（如近亲属、合伙人等） |
| 2 | 公力救济不能一时到达 |
| 3 | 手段上以能够保护自己的物权或者恢复权利为限 |

## 二、第234条·确认物权

### 法条原文

> 第二百三十四条　因物权的归属、内容发生争议的，利害关系人可以请求确认权利。

### 核心释义

#### （一）确认权利的对象

| 类型 | 内容 |
|------|------|
| **归属争议** | 物权属于何人的争议（即物权权利主体争议）；包括所有权、用益物权、担保物权等争议 |
| **内容争议** | 物权功能要素范围的争议（如房屋所有权的性质争议、地役权中权利范围的争议） |

#### （二）请求确认权利的主体

**利害关系人**：对特定的物有利害关系的人；利害关系人不一定是物权人，但应对物权存在确认利益，防止确认请求权的滥用。

#### （三）请求机关

| 机关 | 适用情形 |
|------|---------|
| **人民法院** | 直接提起确认之诉 |
| **仲裁机构** | 当事人达成仲裁协议 |
| **行政机关** | 行政法律法规有特别规定的（如土地所有权和使用权的确认争议，应先请求行政机关处理） |

#### （四）物权确认的依据

| 依据 | 内容 |
|------|------|
| 《民法典》第214条 | 不动产物权自记载于不动产登记簿时发生效力 |
| 《民法典》第216条 | 不动产登记簿是物权归属和内容的根据 |
| 《民法典》第224条 | 动产物权自交付时发生效力 |
| 《民法典》第229条 | 因法律文书或征收决定，自生效时发生效力 |
| 《民法典物权编解释（一）》第2条 | 真实权利人请求确认享有物权的，应予支持 |

### 适用指引

**物权确认请求权不适用诉讼时效**（《八民会纪要》第24条）：

> 已经合法占有转让标的物的受让人请求转让人办理物权变更登记，登记权利人请求无权占有人返还不动产或者动产，**利害关系人请求确认物权的归属或内容**，权利人请求排除妨害、消除危险，对方当事人以超过诉讼时效期间抗辩的，均应不予支持。

**理由**：物权确认请求权是程序上的诉权，并非实体法上的请求权；如适用诉讼时效，将导致标的物长期处于归属不清或权利真空状态。

### 典型案例

#### 宜兴市新街街道海德名园业主委员会诉宜兴市恒兴置业有限公司案

| 项目 | 内容 |
|------|------|
| 案号 | （2017）苏02民终5565号 |
| 审理法院 | 江苏省无锡市中级人民法院 |
| 来源 | 《最高人民法院公报》2018年第11期 |
| 裁判要点 | 开发商与小区业主对开发商在小区内建造的房屋发生权属争议时，应由开发商承担举证责任。如开发商无充分证据证明该房屋系其所有，且其已将该房屋建设成本分摊到出售给业主的商品房中，则该房屋应当属于小区全体业主所有。开发商在没有明确取得业主同意的情况下，自行占有使用该房屋，不能视为业主默示同意由开发商无偿使用，应认定开发商构成侵权 |

## 三、第235条·返还原物

### 法条原文

> 第二百三十五条　无权占有不动产或者动产的，权利人可以请求返还原物。

### 核心释义

#### （一）返还原物请求权的概念

权利人对无权占有或侵夺其所有物的人，有权请求其返还原物的权利。**物权追及效力**的具体体现，体现了物权的对世权、绝对权的特征。

#### （二）请求权的主体

| 主体 | 内容 |
|------|------|
| **所有权人** | 积极权能 + 消极权能（排除他人干涉、妨碍、侵害） |
| **用益物权人** | 土地承包经营权人、建设用地使用权人、宅基地使用权人、地役权人等 |
| **担保物权人** | 质权人、留置权人（占有担保财产）；抵押权人（不占有但仍可行使返还原物请求权） |
| **其他主体** | 《企业破产法》规定的取回权权利人等 |

#### （三）请求权的相对人——无权占有的类型

| 分类标准 | 类型 |
|---------|------|
| **以是否为自始无权为标准** | 1. 自始无权占有（如盗窃物）；2. 嗣后无权占有（如租赁期满不返还） |
| **以占有状态为标准** | 1. 直接占有人；2. 间接占有人（可同时或择一请求返还） |

#### （四）请求权的客体

- 原物及其物权的存在为前提
- 原物不存在 → 寻求损害赔偿等其他救济方式
- 原物毁损但仍存在 → 可同时主张修理、重作、更换等请求
- **不适用**：金钱和无记名证券（作为特定物的古钱币或盛放于特定容器内未打开的除外）

#### （五）孳息与费用的处理（依《民法典》第460条）

| 情形 | 处理 |
|------|------|
| 孳息 | 无论占有者善意或恶意，孳息应随同原物一并返还 |
| 必要费用 | 权利人应当支付善意占有人因维护该不动产或动产支出的必要费用；恶意占有人无需支付 |

### 适用指引

**举证责任分配**：

| 当事人 | 举证责任 |
|--------|---------|
| 权利人 | 须证明其为所有权人或者他物权人，但**无须证明**相对人为无权占有（消极事实） |
| 相对人 | 主张其为有权占有时承担举证责任 |

**善意取得的限制**：
- 第三人从无权占有人处取得标的物符合善意取得 → 第三人可以对抗权利人的返还原物请求权
- 权利人只能向无权占有人主张损害赔偿

**诉讼时效**（《民法典》第196条第2项）：

| 类型 | 是否适用诉讼时效 |
|------|----------------|
| **不动产物权** | **不适用** |
| **登记的动产物权** | **不适用** |
| **未登记的一般动产** | **适用** |

#### 北京市房山区霞云岭乡上石堡村村民委员会与王某先返还原物纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2014）房民初字第00975号 |
| 审理法院 | 北京市房山区人民法院 |

## 四、第236条·排除妨害、消除危险

### 法条原文

> 第二百三十六条　妨害物权或者可能妨害物权的，权利人可以请求排除妨害或者消除危险。

### 核心释义

#### （一）两类请求权

| 类型 | 内容 |
|------|------|
| **妨害排除请求权** | 权利人请求侵害人积极采取措施排除已经发生的现实的危害 |
| **妨害防止请求权（消除危险）** | 物权存在被妨害的风险，对可能的妨害人请求防止妨害、消除危险 |

#### （二）妨害的三种形态

| 形态 | 适用 |
|------|------|
| **尚未发生但必然发生的妨害** | 权利人可以请求消除危险，采取预防措施 |
| **正在发生的妨害** | 权利人可以请求排除妨害 |
| **已经发生的妨害** | 权利人可以请求排除妨害 |

#### （三）构成要件

| 要件 | 内容 |
|------|------|
| 1. 权利主体 | 所有权人 + 他物权人 + 共有人 + 财产管理人 + 代理人 |
| 2. 行使的可能性 | 被妨害的物须仍然存在；妨害须具有被排除的可能性 |
| 3. 妨害的事实 | 存在妨害物权或者可能妨害物权的事实 |
| 4. 妨害的违法性 | 以权利人无容忍义务作为判断标准（轻微的妨害按照日常生活经验应予以容忍） |

#### （四）与原《物权法》的差异

《民法典》删除"停止侵害"——理由：**排除妨害**可以吸收**停止侵害**，停止侵害仅是排除妨害的具体方式之一。

### 适用指引

**是否需要证明相对人主观过错**：**不需要**。排除妨害请求权旨在除去物权人行权的障碍或侵害，恢复物权的完满状态，只要相对人阻碍或危及物权人的权利，权利人均可以要求行为人排除妨碍。

**诉讼时效**：妨害排除请求权和妨害防止请求权**不适用诉讼时效**（《民法典》第196条第1项）。

**权利人的举证责任**：
- 排除妨害：举证证明被排除的妨害具有非法性（如超出必要限度的相邻妨害）
- 消除危险：对该危险发生的可能性承担一定的举证责任（须是现实可能的，而非权利人臆想）

**排除妨害的费用承担**：
- 原则上由妨害人承担
- 妨害人无过错时，权利人可自行承担或合理分担

### 典型案例

#### 肖某宝与萧某田、彭某珍排除妨害纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2011）淮中民终字第0295号 |
| 审理法院 | 江苏省淮安市中级人民法院 |
| 来源 | 《人民法院案例选》2011年第2辑 |
| 裁判要点 | 相邻一方因相邻法律关系的存在而负有从有利于相邻关系健康运行的角度积极注意并保证生长在自己管理范围内树木不对邻居构成妨碍的义务；如因自己的过错使树木生长对相邻另一方权利构成妨碍的，即便是野生树木，权利人亦有权要求相邻一方排除妨碍 |

## 五、第237条·修理、重作、更换、恢复原状

### 法条原文

> 第二百三十七条　造成不动产或者动产毁损的，权利人可以**依法**请求修理、重作、更换或者恢复原状。

### 核心释义

#### （一）四种补救方式

| 方式 | 内容 | 适用 |
|------|------|------|
| **修理** | 对受损的物进行修补整理，达到受损之前的面貌 | 原物修理具有可能性和合理性 |
| **重作** | 按照原物之面貌重新生产或制作 | 修理不能的情形 |
| **更换** | 以相同或相似的他物替代毁损的原物 | 修理和重作不能的情形 |
| **恢复原状** | 修复如初，使物的状态恢复到未被不法侵害之前的状态 | 各种情形均可 |

#### （二）与原《物权法》的关键差异

《民法典》本条增加"**依法**"二字——理由：

> 返还原物、排除妨害、消除危险请求权属于**物权请求权**。而修理、重作、更换或者恢复原状请求权，在性质上属于**债权请求权**。《民法典》本条吸收这一意见，增加"依法"二字，以示区分。

#### （三）请求权的性质

**修理、重作、更换、恢复原状属于债权请求权**，适用侵权责任编以及其他相关法律规范的规定。

### 适用指引

**行使请求权的可能性和必要性**：

| 情形 | 处理 |
|------|------|
| 恢复原状费用很高，不具有经济性，市场易购 | 损害赔偿可能更合理 |
| 不易在市场上找到替代物，对权利人有特殊意义 | 应当判决恢复原状 |
| 文物的毁损 | 难以采取重作的方式进行补救 |

**主观过错要件**：本条没有要求相对人在主观上须有故意或者过失，**无须证明**相对人存在主观过错。

**与其他救济方式并用**：若标的物经修理、重作、更换或者恢复原状后仍有价值贬损，权利人仍可就价值贬损部分主张损害赔偿。

**不承担责任的情形**：
- 按日常生活经验（如承租人对房屋墙面轻微污迹）
- 按合同约定（如租赁合同约定轻微毁损免予承担责任）

## 六、第238条·损害赔偿

### 法条原文

> 第二百三十八条　侵害物权，造成权利人损害的，权利人可以**依法**请求损害赔偿，也可以依法请求承担其他民事责任。

### 核心释义

#### （一）"权利人"的范围

| 权利人 | 内容 |
|--------|------|
| **所有权人** | 绝对权、对世权，受物权法、侵权法保护 |
| **他物权人** | 用益物权人、担保物权人（赔偿义务人应向全体权利人共同为给付） |
| **破产管理人** | 依《企业破产法》第25条，有权以自己名义要求侵权人赔偿损失 |
| **基于债法关系的占有人** | 不适用本章物权保护方法（一般不适用） |
| **基于人身关系的占有人** | 未设立他物权则不能以物权人名义主张 |

#### （二）"依法"的含义

《民法典》本条在原《物权法》基础上将"可以请求"修改为"可以**依法**请求"：

> 返还原物请求权、排除妨害请求权、消除危险请求权性质上属于**物权请求权**，而损害赔偿请求权性质上属于**债权请求权**。本条增加"依法"二字，旨在体现上述请求权在法律性质及法律适用方法上的差异。

#### （三）具有人身意义物的精神损害赔偿

依《民法典》第1183条第2款：

> 因故意或者重大过失侵害自然人具有**人身意义的特定物**造成严重精神损害的，被侵权人有权请求精神损害赔偿。

**要件**：
1. 该物品属于具有人身意义的特定物
2. 侵权人有故意或者重大过失
3. 造成严重精神损害

#### 陈某冰诉广州玉德堂陵园有限公司恢复原状纠纷案

## 七、第239条·物权保护方式的单独与合并适用

### 法条原文

> 第二百三十九条　本章规定的物权保护方式，可以单独适用，也可以根据权利被侵害的情形合并适用。

### 核心释义

#### （一）三种保护方式的体系

| 类型 | 内容 | 代表条文 |
|------|------|---------|
| **物权确认请求权** | 确认物权归属和内容 | 第234条 |
| **物权请求权** | 返还原物、消除危险、排除妨害 | 第235、236条 |
| **侵权请求权** | 修理、重作、更换、恢复原状、损害赔偿 | 第237、238条 |

#### （二）请求权的渐次递进

```
1. 物权确认请求权（前提：归属不清）
       ↓
2. 物权请求权（特定的物没有发生价值减损）
       ↓
3. 侵权请求权（遭受到的损害使特定的物价值贬值，无法通过行使物权请求权予以回复）
```

#### （三）请求权聚合

**请求权聚合**：当事人对于数种以不同的给付为内容的请求权，得同时主张。

**聚合示例**：
- 请求返还原物时，可同时请求消除危险或者排除妨害，直至赔偿损失
- 聚合产生的数个责任相互间并不冲突，可以相互并存，甚至可以相互吸收

#### （四）与原《物权法》的差异

原《物权法》第38条第2款规定："侵害物权，除承担民事责任外，违反行政管理规定的，依法承担行政责任；构成犯罪的，依法追究刑事责任。"

《民法典》删除该第2款——理由：刑事责任、行政责任应当在刑法或行政法律法规中规定。但删除不意味着侵害物权一定不产生刑事责任或行政责任。

### 适用指引

**物权请求权与侵权请求权的时效差异**：

| 请求权类型 | 诉讼时效 |
|-----------|---------|
| 物权请求权（停止侵害、排除妨碍、消除危险、返还不动产或登记动产） | **不适用**（依《民法典》第196条） |
| 损害赔偿请求权（侵权请求权） | **适用** |

**主观过错原则差异**：

| 请求权类型 | 归责原则 |
|-----------|---------|
| 物权请求权 | 无过错原则 |
| 损害赔偿请求权 | 过错原则 |

**行民刑交叉的处理**：
- 侵害物权的行为可能构成犯罪 → 及时将有关证据材料移送侦查机关
- 违反行政法律法规 → 建议行政机关依法审查并作出处理

## ⚠️ 司法适用难点

### 难点一：物权请求权 vs 侵权请求权的性质区分

**争议**：修理、重作、更换、恢复原状、损害赔偿请求权究竟属于物权请求权还是债权请求权？

**主流观点**：
- 物权请求权：返还原物、排除妨害、消除危险（《民法典》第196条明确不适用诉讼时效）
- 债权请求权：修理、重作、更换、恢复原状、损害赔偿（适用《民法典》总则编第179条）

### 难点二：第235条返还原物请求权对一般动产的诉讼时效适用

**争议**：未登记的一般动产返还原物请求权是否适用诉讼时效？

**主流观点**：
- 不动产 + 登记的动产 → 不适用（《民法典》第196条第2项）
- 未登记的一般动产 → 适用（保护与返还财产义务人交易的第三人的信赖利益，维护交易安全）

### 难点三：第236条妨害与容忍义务的边界

**争议**：何种程度的妨害属于权利人应当容忍的？

**主流观点**：以日常生活经验为判断标准——轻微的妨害（如楼上住户的轻微脚步声）权利人应当容忍；超出必要限度的妨害（如树木挤压墙体）权利人可主张排除。

### 难点四：第238条"依法"的理解

**争议**：本条"依法"的含义及与物权请求权的衔接？

**主流观点**：
- 损害赔偿请求权是债权请求权
- 适用《民法典》侵权责任编以及其他相关法律规范的规定
- 需要符合这些相关法律关于请求权具体要件等方面的规定

### 难点五：第239条请求权聚合与诉讼时效的关系

**争议**：物权请求权与侵权请求权合并主张时，侵权请求权超出诉讼时效的处理？

**主流观点**：
- 物权请求权通常不适用诉讼时效
- 侵权请求权超出法定时效的，权利人则不能与物权请求权同时提出侵权请求
- 应当分别适用各自的时效规则

### 难点六：自助行为的边界

**争议**：自助行为的合法边界？

**主流观点**：
- 公力救济不能一时到达
- 手段以能够保护自己的物权或者恢复权利为限
- 不得超出必要限度

## ❓ 实务问答

### Q1：物权保护途径有哪些？

**A**：依《民法典》第233条，物权保护途径包括：
1. **公力救济**：诉讼（民事、行政、刑事）
2. **私力救济**：和解、调解、仲裁
3. **私力救济的"等途径"**：正当防卫（《民法典》第181条）、紧急避险（《民法典》第182条）、自助行为（《民法典》第1177条）

### Q2：第234条确认物权请求权是否适用诉讼时效？

**A**：**不适用诉讼时效**。

依据《八民会纪要》第24条："利害关系人请求确认物权的归属或内容，对方当事人以超过诉讼时效期间抗辩的，均应不予支持。"

**理由**：物权确认请求权是程序上的诉权，并非实体法上的请求权；如适用诉讼时效，将导致标的物长期处于归属不清或权利真空状态。

### Q3：返还原物请求权是否适用诉讼时效？

**A**：**部分适用**（《民法典》第196条第2项）：

| 类型 | 是否适用诉讼时效 |
|------|----------------|
| 不动产物权 | 不适用 |
| 登记的动产物权 | 不适用 |
| 未登记的一般动产 | **适用**（保护第三人的信赖利益，维护交易安全） |

### Q4：妨害排除请求权是否适用诉讼时效？

**A**：**不适用诉讼时效**（《民法典》第196条第1项）。

> 请求停止侵害、排除妨碍、消除危险的请求权不适用诉讼时效的规定。

### Q5：物权请求权与侵权请求权能否合并主张？

**A**：**可以合并主张**（依第239条）。

但应注意：
- 物权请求权通常不适用诉讼时效；侵权请求权适用诉讼时效
- 物权请求权适用无过错原则；侵权请求权适用过错原则
- 超出诉讼时效的侵权请求权不能与物权请求权同时主张

### Q6：修理、重作、更换、恢复原状请求权的性质是什么？

**A**：**债权请求权**（《民法典》第237条增加"依法"二字的理由）。

适用《民法典》侵权责任编以及其他相关法律规范的规定。

### Q7：侵害具有人身意义的特定物能否请求精神损害赔偿？

**A**：**可以**（依《民法典》第1183条第2款）。

**要件**：
1. 该物品属于具有人身意义的特定物
2. 侵权人有故意或者重大过失
3. 造成严重精神损害

### Q8：自助行为与正当防卫、紧急避险的区别？

**A**：

| 类型 | 法律依据 | 适用条件 | 区别 |
|------|---------|---------|------|
| **正当防卫** | 《民法典》第181条 | 针对不法侵害；正在发生 | 防卫不法侵害行为本身 |
| **紧急避险** | 《民法典》第182条 | 危险正在发生；不得已 | 损害第三人的合法权益 |
| **自助行为** | 《民法典》第1177条 | 权利受到侵害后；公力救济不能一时到达 | 恢复权利的原有状态 |
