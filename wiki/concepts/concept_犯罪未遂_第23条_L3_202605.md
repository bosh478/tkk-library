# 犯罪未遂(《刑法》第 22-23 条 · L3)

> 本页定位:犯罪未遂 L3 概念页。**总则第 2 章犯罪未完成形态**的核心制度,与既遂、中止、预备紧密关联;**已经着手 + 未得逞**。

## 一、法条原文(条文要点)

《刑法》第 22 条(犯罪预备):
> 为了犯罪,准备工具、制造条件的,是犯罪预备。
> 对于预备犯,可以比照既遂犯从轻、减轻处罚或者免除处罚。

《刑法》第 23 条(犯罪未遂):
> 已经着手实行犯罪,由于犯罪分子意志以外的原因未得逞的,是犯罪未遂。
> 对于未遂犯,可以比照既遂犯从轻或者减轻处罚。

## 二、段级释解

### 1. 概念界定

犯罪未遂 = **已经着手实行犯罪**,但由于**犯罪分子意志以外的原因**而**未得逞**的犯罪形态。

犯罪未完成形态:
- **预备**:准备阶段(尚未着手)
- **未遂**:着手阶段(因意志以外原因未得逞)
- **中止**:着手阶段(自动放弃犯罪)
- **既遂**:完成阶段(全部构成要件齐备)

### 2. 犯罪未遂三构成要件

(1) **已经着手实行犯罪**:
- 着手 = 行为人**开始实施**符合构成要件客观方面的行为
- 标志:行为已**直接指向犯罪客体**,接近犯罪目标
- 与预备的边界:预备是**准备活动**,未遂是**实行行为**

(2) **犯罪未得逞**:
- 行为**未达到既遂状态**
- 即:犯罪构成的**全部要件**未齐备
- 例:故意杀人未死 / 盗窃未偷到钱 / 诈骗未骗到财物

(3) **未得逞由于犯罪分子意志以外的原因**:
- **被阻止**(被警察抓获、被害人反抗)
- **工具失败**(枪支卡壳、毒药失效)
- **对象错误**(被害人不在家)
- **客观条件不具备**(目标逃走)
- **认识错误**(误认致死物)

与中止的区别:**意志以外** vs **主动放弃**

### 3. 未遂的类型

(1) **行为未遂**(形式未遂 / 未实行终了未遂):
- 行为**尚未实行终了**,因意志以外原因停止
- 例:甲举刀杀人,被他人阻止未砍下

(2) **结果未遂**(实质未遂 / 实行终了未遂):
- 行为**已经实行终了**,但未发生预期结果
- 例:甲投毒杀人,被害人未喝下毒药 / 喝下未死

### 4. 未遂与预备的区分

| 项目 | 预备 | 未遂 |
|------|------|------|
| 时点 | 准备阶段 | 着手阶段 |
| 行为 | 准备工具 / 制造条件 | 实行行为 |
| 处罚 | 从轻 / 减轻 / 免除 | 从轻 / 减轻 |

### 5. 未遂与既遂的区分

**犯罪既遂**:构成要件全部齐备
- 结果犯:结果发生(人死亡 / 财物被占有)
- 行为犯:行为完成
- 危险犯:危险状态出现

**犯罪未遂**:构成要件**部分齐备**(行为已实施 + 结果未发生)

### 6. 不可罚的未遂

按刑法谦抑性,**部分未遂**不可罚:
- 行为根本不具有**侵害法益的危险**(如迷信犯)
- 例:用诅咒「杀死」仇人 → **不可罚**

可罚未遂:行为**实际具有**侵害法益的危险,只是因外部原因未得逞。

## 三、实务问答(FAQ)

Q1:未遂犯的处罚原则?
**可以比照既遂犯从轻或减轻处罚**(第 23 条第 2 款)。注意是「可以」,不是「应当」,法官有裁量权。

Q2:既遂与未遂的认定时点?
- **行为犯**:行为完成即既遂(如伪造货币完成)
- **结果犯**:结果发生即既遂(如故意杀人 + 死亡)
- **危险犯**:危险状态出现即既遂(如放火 + 公共安全危险)
- 未遂:行为已实施 + 结果未发生 + 因意志以外原因

Q3:对未遂犯的处罚是否一律从轻?
**不是**:
- 可以从轻或减轻(法官酌情)
- 对**严重犯罪**(故意杀人未遂、抢劫未遂):从轻幅度较小
- 对**轻微犯罪**:可能减轻到免除处罚

Q4:未遂的「着手」如何认定?
**客观说**主流:
- 行为人**开始实施**符合构成要件客观方面的行为
- 行为**直接指向**犯罪客体(客体已受威胁)
- 与预备的边界:预备是**为犯罪创造条件**,未遂是**已经侵犯客体**

Q5:行为人误把白糖当毒药杀人,是否构成故意杀人未遂?
**是**。行为人有**故意杀人的故意** + 实施了**投毒行为** + 因**对象认识错误**(白糖非毒药)未得逞,构成未遂。

Q6:预备犯与未遂犯的处罚比较?
- **预备**:从轻 / 减轻 / 免除(3 档可选)
- **未遂**:从轻 / 减轻(2 档)
- **整体**:预备处罚更轻(因为距离犯罪完成更远)

Q7:对未遂犯能否适用累犯?
**可以**。未遂也是犯罪,符合累犯要件的仍可构成累犯。

Q8:对**不能犯**(行为人意图实施的行为不具有侵害法益的危险)的处理?
- **不能犯未遂**:无侵害危险,**不可罚**(按主流观点)
- **迷信犯**(用巫术杀人):不可罚

Q9:未遂与**中止**的关键区别?
- **未遂**:**意志以外**原因停止
- **中止**:**自动放弃**犯罪(自己主动)
- 法律后果:中止**应当**减轻或免除;未遂**可以**从轻或减轻

Q10:对**未遂加重犯**(既遂的加重情形)如何处理?
**既遂 + 未遂**的差异:
- 未遂不适用既遂的**加重情节**(因为结果未发生)
- 例:抢劫致人重伤 → 抢劫罪加重档;抢劫未遂致人轻微伤 → 抢劫未遂罪基础档
