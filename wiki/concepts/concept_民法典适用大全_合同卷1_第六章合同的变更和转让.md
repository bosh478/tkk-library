# 民法典合同编第六章【合同的变更和转让】综合

## 章节目录

本章共 14 条（Articles 543-556），规定合同变更与转让制度，包括协议变更、债权转让、债务转移、合同地位概括转让。

| 节 | 法条范围 | 主题 |
|----|---------|------|
| 第一节 协议变更 | 543-544 | 协议变更合同 |
| 第二节 债权转让 | 545-550 | 债权转让规则 |
| 第三节 债务转移 | 551-554 | 债务转移规则 |
| 第四节 概括转让 | 555-556 | 合同权利义务概括转让 |

## 一、协议变更合同（第543-544条）

### 法条原文

> 第五百四十三条　当事人协商一致，可以变更合同。
>
> 第五百四十四条　当事人对合同变更的内容约定不明确的，推定为**未变更**。

### 合同变更的规则

| 规则 | 内容 |
|------|------|
| **协商一致** | 合同变更原则上需要**双方协商一致** |
| **变更方式** | 协议形式；法律要求书面形式的，依其规定 |
| **约定不明** | 推定为**未变更**（保护双方当事人） |

### 合同变更的效力

```
协议变更合同
├─ 1. 协商一致 → 变更协议
├─ 2. 变更协议生效 → 合同内容按变更后执行
└─ 3. 未达成变更协议 → 合同按原内容继续履行
```

## 二、债权转让（第545-550条）

### （一）债权转让的一般规则（第545条）

#### 法条原文

> 第五百四十五条　债权人可以将债权**全部或者部分**转让给第三人，但是有下列情形之一的除外：
> （一）根据债权性质**不得转让**；
> （二）按照当事人约定**不得转让**；
> （三）依照法律规定**不得转让**。
>
> 当事人约定非金钱债权**不得转让**的，不得对抗**善意第三人**。
>
> 当事人约定金钱债权**不得转让**的，不得对抗**第三人**。

### 债权转让的"自由转让"原则

| 原则 | 内容 |
|------|------|
| **自由转让** | 债权人可以**全部或部分**转让债权给第三人 |
| **例外禁止** | ① 债权性质不得转让；② 约定不得转让；③ 法律不得转让 |

### 三类禁止转让的债权

| 类型 | 举例 |
|------|------|
| **根据债权性质不得转让** | 人身损害赔偿请求权、抚养费请求权、以特定身份为基础的债权 |
| **按照当事人约定不得转让** | 合同约定的禁止转让条款 |
| **依照法律规定不得转让** | 法律特别规定禁止转让的债权 |

### "不得转让"约定的效力

| 债权类型 | "不得转让"约定的效力 |
|---------|------------------|
| **非金钱债权** + 约定不得转让 | **不得对抗善意第三人** |
| **金钱债权** + 约定不得转让 | **不得对抗第三人**（无善意要求） |

### （二）债权转让通知（第546条）

#### 法条原文

> 第五百四十六条　债权人转让债权，**未通知**债务人的，该转让对债务人**不发生效力**。
>
> 债权转让的通知**不得撤销**，但是经受让人同意的除外。

### 债权转让通知的效力

| 维度 | 规则 |
|------|------|
| **通知的必要性** | 未通知债务人的，转让**对债务人不发生效力** |
| **通知主体** | **债权人**作出通知（让与人） |
| **通知方式** | 一般方式（书面、口头均可） |
| **通知的不可撤销** | 通知**不得撤销**，经受让人同意的除外 |

### 通知的"不发生效力"含义

| 通知情形 | 转让效力 |
|---------|---------|
| **已通知债务人** | 转让对债务人**发生效力** |
| **未通知债务人** | 转让**仅在让与人和受让人之间有效**，对债务人**不发生效力** |
| **通知可撤销但有限制** | 不得撤销，受让人同意的除外 |

### （三）从权利随主债权转让（第547条）

#### 法条原文

> 第五百四十七条　债权人转让债权的，受让人**取得**与债权有关的**从权利**，但是该从权利专属于债权人自身的除外。
>
> 受让人取得从权利**不因该从权利未办理转移登记手续或者未转移占有而受到影响**。

### 从权利随主债权转让的规则

| 规则 | 内容 |
|------|------|
| **从随主原则** | 主债权转让，**从权利一并转让**（如利息、违约金、担保权等） |
| **专属权利除外** | 从权利专属于债权人自身的，不随主债权转让 |
| **登记/占有问题** | 受让人取得从权利，**不因未办理转移登记或未转移占有而受影响** |

### 典型从权利的随同转让

| 从权利类型 | 是否随同转让 |
|----------|------------|
| **利息债权** | ✅ 一并转让 |
| **违约金债权** | ✅ 一并转让 |
| **担保物权**（抵押权、质权） | ✅ 一并转让（登记可能需要变更） |
| **保证债权** | ✅ 一并转让 |
| **专属于债权人的人身权** | ❌ 不转让 |

### （四）债务人的抗辩权与抵销权（第548-549条）

#### 抗辩权（第548条）

> 第五百四十八条　债务人接到债权转让通知后，债务人对**让与人**的抗辩，可以向**受让人**主张。

**抗辩权随债务移转规则**：
- 债务人对让与人的抗辩（如诉讼时效抗辩、同时履行抗辩等）→ **可以向受让人主张**
- 抗辩事由在债权转让时**已经存在**的，债务人可主张
- 抗辩事由在债权转让后**新发生**的，依具体情况判断

#### 抵销权（第549条）

> 第五百四十九条　有下列情形之一的，债务人可以向受让人主张抵销：
> （一）债务人接到债权转让通知时，债务人对让与人享有债权，且**债务人的债权先于转让的债权到期**或者**同时到期**；
> （二）债务人的债权与转让的债权是基于**同一合同**产生。

**抵销权的两类情形**：

| 情形 | 内容 |
|------|------|
| **情形1** | 债务人对让与人的债权**先于或同时**到期 |
| **情形2** | 债务人的债权与转让债权**基于同一合同**产生 |

### （五）债权转让增加的履行费用（第550条）

#### 法条原文

> 第五百五十条　因债权转让增加的履行费用，由**让与人**负担。

**履行费用增加的情形**：
- 债权转让导致债务人需要向**新的履行地**（如受让人所在地）履行
- 债权转让导致**履行方式**改变（如向境外支付）
- **增加的费用**由**让与人**（原债权人）负担

## 三、债务转移（第551-554条）

### （一）债务转移的同意（第551条）

#### 法条原文

> 第五百五十一条　债务人将债务的全部或者部分**转移给第三人的**，应当**经债权人同意**。
>
> 债务人或者第三人可以催告债权人在**合理期限内**予以同意，**债权人未作表示**的，视为**不同意**。

### 债务转移的核心规则

| 维度 | 规则 |
|------|------|
| **核心要件** | 债务人转移债务应当**经债权人同意** |
| **同意程序** | 债权人应在**合理期限内**明确表示同意 |
| **未作表示的后果** | **视为不同意** |
| **催告权** | 债务人或者第三人可以催告 |

### 债务转移与债权转让的对比

| 维度 | 债权转让 | 债务转移 |
|------|---------|---------|
| **核心要件** | **通知**债务人 | **经债权人同意** |
| **对第三人的要求** | 第三人无须特别同意 | 第三人必须接受 |
| **转让自由** | 相对自由 | 相对受限 |
| **法律理由** | 债务人的履行能力 | 债权人的履行请求 |

### （二）并存的债务承担（第552条）

#### 法条原文

> 第五百五十二条　第三人与债务人约定加入债务并**通知债权人**，或者第三人向债权人**表示愿意加入债务**，债权人未在合理期限内明确拒绝的，债权人可以请求**第三人在其愿意承担的债务范围内**和**债务人承担连带债务**。

### 并存债务承担 vs 免责债务转移

| 维度 | 并存债务承担（第552条） | 免责债务转移（第551条） |
|------|----------------------|---------------------|
| **第三人地位** | 加入债务 | 替代债务人 |
| **债权人效力** | 债务人 + 第三人**连带责任** | 债务人脱离债务关系，仅第三人承担 |
| **成立要件** | 第三人加入债务 + 通知或表示愿意 | 债权人**同意** |
| **第三人责任** | 在其**愿意承担的债务范围内**承担 | 在**债务范围内**承担 |

### 并存债务承担的成立方式

```
并存债务承担成立
├─ 1. 第三人与债务人约定加入债务 + 通知债权人
└─ 2. 第三人向债权人表示愿意加入债务
    └─ 债权人未在合理期限内明确拒绝
        └─ 视为同意加入
```

### （三）新债务人的抗辩与从债务（第553-554条）

#### 抗辩权（第553条）

> 第五百五十三条　债务人转移债务的，**新债务人**可以主张**原债务人对债权人的抗辩**。

**抗辩权随债务移转规则**：
- 原债务人对债权人的抗辩（如诉讼时效抗辩、撤销抗辩等）→ 新债务人**可以主张**
- 包括原债务人享有的实体抗辩和程序抗辩

#### 从债务（第554条）

> 第五百五十四条　债务人转移债务的，**新债务人**应当承担与主债务有关的**从债务**，但是该从债务**专属于原债务人自身**的除外。

**从债务随主债务移转规则**：

| 规则 | 内容 |
|------|------|
| **从随主原则** | 主债务转移，从债务一并转移（如利息、违约金、担保等） |
| **专属从债务除外** | 专属于原债务人自身的从债务不转移（如原债务人提供的人身担保等） |

### （四）新债务人的抗辩权与从债务对比表

| 维度 | 抗辩权（第553条） | 从债务（第554条） |
|------|------------------|------------------|
| **移转对象** | 原债务人的抗辩 | 原债务的从债务 |
| **方向** | 抗辩债权人 | 承担对债权人 |
| **专属例外** | 专属于原债务人抗辩的，不移转 | 专属于原债务人自身的从债务，不移转 |
| **效果** | 新债务人主张抗辩对抗债权人 | 新债务人承担从债务 |

## 四、合同权利义务的概括转让（第555-556条）

### （一）概括转让的概念（第555条）

#### 法条原文

> 第五百五十五条　当事人一方经**对方同意**，可以将自己在合同中的**权利和义务一并转让**给第三人。

### 概括转让的规则

| 维度 | 规则 |
|------|------|
| **核心要件** | 需**对方同意** |
| **转让标的** | 合同**权利和义务一并转让**（不是单独债权或单独债务） |
| **适用规则** | 概括转让兼具债权转让和债务转移特征，**分别适用**债权转让和债务转移的规定 |

### 概括转让的法律适用

```
概括转让
├─ 债权部分 → 适用债权转让规则（第545-550条）
└─ 债务部分 → 适用债务转移规则（第551-554条）
    ├─ 债务转移需经债权人同意
    ├─ 抗辩权随债务转移
    └─ 从债务随主债务转移
```

### （二）概括转让的特殊情形（第556条）

#### 法条原文

> 第五百五十六条　合同的权利和义务一并转让的，适用第551条、第553条、第554条的规定。

**法律适用**：
- 第551条：债务转移需经债权人同意
- 第553条：新债务人的抗辩权
- 第554条：从债务随主债务转移

**注意**：第556条**没有**援引债权转让的通知规则（第546条），这是因为概括转让中对方"同意"代替了"通知"。

## 五、合同变更与转让的体系

```
合同变更与转让制度（第六章）
├── 1. 协议变更（第543-544条）
│   ├── 协商一致 → 变更
│   └── 约定不明 → 推定未变更
├── 2. 债权转让（第545-550条）
│   ├── 自由转让 + 三类禁止
│   ├── 通知债务人
│   ├── 从权利随主转让
│   ├── 债务人抗辩援用
│   ├── 抵销权两类情形
│   └── 增加费用由让与人负担
├── 3. 债务转移（第551-554条）
│   ├── 经债权人同意
│   ├── 并存债务承担
│   ├── 新债务人抗辩
│   └── 从债务随主债务
└── 4. 概括转让（第555-556条）
    ├── 经对方同意
    └── 准用债权转让+债务转移规则
```

## 六、合同变更 vs 合同转让

| 维度 | 合同变更（第543条） | 合同转让 |
|------|------------------|---------|
| **本质** | 合同**内容**变化 | 合同**主体**变化 |
| **核心要件** | 双方协商一致 | 通知/经同意 |
| **合同关系** | 同一当事人 | 主体变更 |
| **法律效果** | 合同内容按变更后执行 | 新主体替代/加入 |

## ❓ 实务问答精选

> **问**：债权转让未通知债务人的后果？
>
> **答**：依第546条，债权转让**未通知**债务人的，该转让**对债务人不发生效力**。但转让本身**在让与人和受让人之间仍然有效**。债务人向原债权人（让与人）履行的，**不免除**其债务。

> **问**：债务人能否向受让人主张抵销？
>
> **答**：依第549条，**两类情形**可以：
> 1. 债务人对让与人的债权**先于转让债权到期**或**同时到期**
> 2. 债务人的债权与转让债权**基于同一合同**产生
>
> 这两类情形外的抵销，债务人**不能向受让人主张**。

> **问**：并存债务承担与保证的区别？
>
> **答**：
> - **并存债务承担**（第552条）：第三人**加入债务**，与原债务人承担**连带债务**；第三人是**共同债务人**
> - **保证**：保证人承担**保证债务**，具有**从属性**，一般保证人享有**先诉抗辩权**
>
> 实务区别：并存的债务承担中第三人承担**主债务**地位（连带债务），保证人承担**保证债务**（从属债务）。

> **问**：合同概括转让的成立要件？
>
> **答**：依第555条，**经对方同意**。概括转让兼具债权转让和债务转移的特征，**分别适用**两者的规则——债权部分准用债权转让规则（但通知义务被对方"同意"吸收），债务部分准用债务转移规则（须经债权人同意）。

> **问**：债权转让通知能否撤销？
>
> **答**：依第546条第2款，通知**不得撤销**，**经受让人同意的除外**。这是为了保护受让人对通知的合理信赖。

> **问**：合同变更约定不明的后果？
>
> **答**：依第544条，**推定为未变更**。这是保护双方当事人的规则，避免因约定不明导致合同关系不稳定。
