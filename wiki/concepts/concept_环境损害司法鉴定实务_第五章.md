## 一句话说明

空气污染损害鉴定通过科学评估污染行为对环境和人体健康造成的损害程度，为确定污染者法律责任提供科学依据。

## 顿悟

空气污染损害鉴定的独特挑战在于污染物的扩散性和自净作用——损害行为停止后，污染物浓度会随大气扩散作用逐渐降低。虚拟治理成本法正是为解决"排放事实明确但损害事实不明确"的困境而设计，其核心是将"假设的治理成本"作为损害数额的替代指标。

## 原文完整内容

### 第一节 空气污染损害鉴定概述

#### 一、基本概念

**（一）空气污染物来源**

空气污染的来源分为自然源和人为源两大类：

- **自然源**：火山喷发、森林及森林火灾、沙尘暴、海洋表层及海浪飞沫
- **人为源**：工业生产、交通排放、农业活动、居民生活、化石燃料燃烧

常见的大气污染物：颗粒物（PM2.5、PM10）、常规气态污染物（二氧化硫、氮氧化物、一氧化碳、臭氧等）、挥发性有机物。

**（二）空气污染造成的损害**

1. **对人体健康的影响**：全球每年约700万人因室内和室外空气过早死亡
2. **对植物的影响**：氮氧化物、二氧化硫、颗粒物、臭氧、次生有机物
3. **对能见度的影响**：颗粒物污染物影响太阳辐射的散射和吸收

#### 二、鉴定对象及内容

1. 污染环境行为致环境空气损害鉴定
2. 环境空气污染致植物损害鉴定
3. 环境空气污染致动物损害鉴定
4. 室内空气污染损害鉴定
5. 室内空气污染致人体健康损害鉴定

### 第二节 鉴定依据和鉴定要点

#### 一、相关标准及规范

- 《环境空气质量标准》（GB 3095—2012）
- 《大气污染物综合排放标准》（GB16297—1996）
- 《室内空气质量标准》（GB/T18883—2022）
- 《生态环境损害鉴定评估技术指南基础方法第1部分：大气污染虚拟治理成本法》（GB/T39793.1—2020）

#### 二、司法鉴定要点

**（一）损害调查**

1. 基础信息调查：大气污染源分布、特征污染物形态、气象条件、人口分布
2. 企业违法调查：排污许可证、在线监测、运营台账
3. 突发污染调查：污染事件类型、时间、地点、气象条件

**（二）损害确认**

基线确定方法：

1. 历史数据法
2. 区域对照法
3. 参照标准法
4. 模型估算法

**（三）因果关系分析**

1. 时间关联性：大气污染行为发生在前，损害发生在后
2. 空间关联性：大气污染物从污染源迁移至评估区域的可能性

**（四）损害价值量化**

1. 人身损害：按《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》计算
2. 财产损害：采用修复费用法或重置成本法计算

### 第三节 鉴定技术和方法

#### 一、采样分析技术

**（一）直接采样法**

- 注射器采样、塑料袋采样、采气管采样、真空瓶采样
- 挥发性有机物采样常用苏玛罐（内衬惰性涂层的不锈钢罐）

**（二）富集（浓缩）采样法**

1. 溶液吸收法：气泡吸收管、冲击式吸收管、多孔筛板吸收瓶
2. 低温冷凝法：用于低沸点气态污染物
3. 自然累积法：用于自然降尘量、硫酸盐化速率、氟化物
4. 滤料阻留法：用于采集空气中的颗粒物

**（三）分析技术**

| 污染物 | 分析方法 |
|-------|---------|
| 二氧化硫 | 分光光度法、库伦滴定法、紫外脉冲荧光法、定电位电解法 |
| 氮氧化物 | 分光光度法、原电池库仑法 |
| 一氧化碳 | 气相色谱法、汞置换法 |
| 臭氧 | 分光光度法、紫外吸收法 |
| 氟化物 | 离子选择电极法 |
| 汞 | 金膜富集-冷原子吸收法、巯基棉富集-冷原子荧光法 |
| 挥发性有机物 | 冷阱-热解析色谱-MS/FID法、质子转移质谱法 |

#### 二、在线监测技术

**（一）固定源监测**

- 离线监测：手工采样和测定技术方法
- 在线监测：烟气连续排放监测系统（CEMS）

**（二）移动源监测**

机动车排放测试、烟度计、雷达等非接触式光学监测设备

#### 三、降水监测

监测降水酸度以及化学组成特征，分析酸雨成因。常用检测方法：

| 离子种类 | 常用检测方法 |
|---------|------------|
| 硫酸根 | 铬酸钡-二苯酰胺二肼分光光度法、离子色谱法 |
| 亚硝酸根和硝酸根 | 离子色谱法、盐酸萘乙二胺分光光度法 |
| 氟离子 | 离子选择电极法、离子色谱法 |
| 氯离子 | 硫氰酸汞-高铁分光光度法、离子色谱法 |
| 铵根离子 | 纳试剂分光光度法、离子色谱法 |
| 钾、钙、钠、镁离子 | 离子色谱法、原子吸收法 |

#### 四、其他监测方法

**（一）遥感监测**：利用卫星遥感技术研究气溶胶

**（二）显微技术**：偏振光显微镜、相衬显微镜、暗场或荧光显微镜、SEM、TEM

**（三）树轮生态学技术**：利用树木年轮分析生态和环境变化

#### 五、大气污染虚拟治理成本法

虚拟治理成本法公式：

$$D = E \times \gamma$$

$$\gamma = (\alpha \times \beta + \omega) \times \tau$$

**调整系数确定**：

1. **污染物危害系数α**：根据GB 30000系列标准确定
2. **受体敏感系数β**：根据污染源与人群聚集地最近距离确定
3. **超标系数τ**：根据污染物排放浓度超过标准的倍数确定
4. **环境功能系数ω**：根据排放区域环境功能区确定

**单位治理成本确定方法**：

1. 实际调查法：调查相同或相近企业的单位污染治理成本
2. 成本函数法：基于样本建立典型行业单位治理成本函数

## 核心差异

| 空气污染类型 | 监测方法 | 损害量化方法 |
|------------|---------|-------------|
| 固定源污染 | 在线监测、CEMS | 虚拟治理成本法（实测浓度法） |
| 移动源污染 | 底盘测功机、烟度计 | 里程能耗法 |
| 室内空气污染 | 直接采样法 | 修复费用法 |
| 突发污染 | 应急监测、遥感 | 实际治理成本法 |

## 内观视角

空气污染损害鉴定面临"排放扩散性"和"损害不确定性"两大挑战。采样技术从直接采样到富集采样的发展，检测技术从化学滴定到质谱分析的升级，遥感技术从卫星到无人机的应用，共同支撑了鉴定工作的开展。虚拟治理成本法的引入，通过"假设治理成本"作为损害数额的替代指标，解决了损害行为已停止、污染物已扩散情形下的鉴定难题。
