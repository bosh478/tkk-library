# 民法典适用大全·侵权责任卷（二）·第六章医疗损害责任

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》侵权责任卷2 2023年 1208-1260.md]] |
| 章节 | 第六章 医疗损害责任 |
| 条文范围 | 《民法典》第1218条～第1228条（共11条） |
| 核心主题 | 医疗过错推定、举证责任倒置情形、病历资料、产品药品输血责任、患者知情同意 |

## 条文结构

| 条文 | 主题 | 法理要点 |
|------|------|----------|
| 第1218条 | 一般医疗损害责任 | 患者在诊疗活动中受到损害，医疗机构或其医务人员有过错的，医疗机构承担赔偿责任 |
| 第1219条 | 知情同意 | 医务人员在诊疗活动中应当向患者说明病情和医疗措施；需要实施手术、特殊检查、特殊治疗的，应当及时向患者说明医疗风险、替代医疗方案等情况，并取得其明确同意 |
| 第1220条 | 紧急救治 | 因抢救生命垂危的患者等紧急情况，不能取得患者或其近亲属意见的，经医疗机构负责人或者授权的负责人批准，可以立即实施相应的医疗措施 |
| 第1221条 | 过错推定 | 医务人员在诊疗活动中未尽到与当时的医疗水平相应的诊疗义务，造成患者损害的，医疗机构应当承担赔偿责任 |
| 第1222条 | 过错推定情形 | 推定医疗机构有过错的三种情形：违反诊疗规范；隐匿或拒绝提供病历；遗失、伪造、篡改或违法销毁病历 |
| 第1223条 | 药品器械缺陷 | 因药品、消毒产品、医疗器械的缺陷造成患者损害的，患者可以向药品上市许可持有人、生产者、血液提供机构或者医疗机构请求赔偿 |
| 第1224条 | 不合格血液 | 因输入不合格的血液造成患者损害的，患者可以向血液提供机构或者医疗机构请求赔偿 |
| 第1225条 | 病历资料 | 医疗机构及其医务人员应当按照规定填写并妥善保管病历资料；患者要求查阅、复制病历资料的，医疗机构应当及时提供 |
| 第1226条 | 患者隐私 | 医疗机构及其医务人员应当对患者的隐私和个人信息保密；泄露患者隐私和个人信息或者未经患者同意公开其病历资料的，应当承担侵权责任 |
| 第1227条 | 不得违规检查 | 医疗机构及其医务人员不得违反诊疗规范实施不必要的检查 |
| 第1228条 | 医疗机构安保 | 医疗机构及其医务人员的合法权益受法律保护；干扰医疗秩序，妨害医务人员工作、生活的，应当依法承担法律责任 |

## 核心制度深度解读

### 一、医疗损害责任归责原则体系

| 情形 | 法条 | 归责原则 |
|------|------|----------|
| 一般情形 | 第1218条 | 过错责任 |
| 紧急救治 | 第1220条 | 例外（紧急情况下合理诊疗不担责） |
| 违反诊疗水平义务 | 第1221条 | 过错推定（未尽到与当时医疗水平相应的诊疗义务） |
| 违反诊疗规范 | 第1222条第（一）项 | 过错推定 |
| 隐匿或拒绝提供病历 | 第1222条第（二）项 | 过错推定 |
| 遗失、伪造、篡改、违法销毁病历 | 第1222条第（三）项 | 过错推定 |

### 二、医疗损害举证责任分配

| 举证内容 | 举证责任 |
|----------|----------|
| 医疗机构存在过错 | 原则上由患者举证；存在第1222条情形时由医疗机构举证 |
| 医疗机构存在过错且与损害有因果关系 | 推定医疗机构有过错时，由医疗机构证明无因果关系以免责 |
| 损害事实 | 患者举证 |

### 三、知情同意制度（第1219条）

**一般告知义务**：
- 病情和医疗措施。

**特殊告知义务**（需取得明确同意）：
- 手术。
- 特殊检查。
- 特殊治疗。
- 其他存在较大医疗风险的诊疗活动。

**告知对象**：
- 患者本人。
- 不能或不宜向患者说明的，向患者的近亲属说明。
- 紧急情况下的例外（第1220条）。

### 四、紧急救治（第1220条）

**适用条件**：
1. 抢救生命垂危的患者等紧急情况。
2. 不能取得患者或其近亲属意见。

**程序**：经医疗机构负责人或者授权的负责人批准。

**效果**：可以立即实施相应的医疗措施。

### 五、药品器械不合格血液责任（第1223-1224条）

| 类型 | 法条 | 请求对象 |
|------|------|----------|
| 药品、消毒产品、医疗器械缺陷 | 第1223条 | 药品上市许可持有人、生产者、血液提供机构、医疗机构（任选） |
| 输入不合格血液 | 第1224条 | 血液提供机构、医疗机构（任选） |

### 六、病历资料管理（第1225条）

**义务主体**：医疗机构及其医务人员。

**义务内容**：
- 按规定填写病历资料。
- 妥善保管病历资料。

**患者权利**：查阅、复制病历资料，医疗机构应及时提供。

### 七、患者隐私保护（第1226条）

**保护对象**：患者的隐私和个人信息。

**保护义务**：医疗机构及其医务人员保密义务。

**侵权情形**：
- 泄露患者隐私和个人信息。
- 未经患者同意公开其病历资料。

### 八、过度检查禁止（第1227条）

**禁止行为**：医疗机构及其医务人员不得违反诊疗规范实施不必要的检查。

## ❓ 常见问题

> 问：医疗损害责任的一般归责原则？
> 答：过错责任。患者需证明医疗机构或其医务人员有过错（第1218条）。

> 问：哪些情形推定医疗机构有过错？
> 答：第1222条规定3种情形：① 违反诊疗规范的；② 隐匿或者拒绝提供与纠纷有关的病历资料的；③ 遗失、伪造、篡改或者违法销毁病历资料的。

> 问：什么是紧急救治的免责？
> 答：第1220条规定，因抢救生命垂危的患者等紧急情况，不能取得患者或其近亲属意见的，经医疗机构负责人或者授权的负责人批准，可以立即实施相应的医疗措施。

> 问：药品器械缺陷如何请求赔偿？
> 答：因药品、消毒产品、医疗器械的缺陷造成患者损害的，患者可以向药品上市许可持有人、生产者、血液提供机构或者医疗机构请求赔偿（第1223条）。

> 问：什么是患者知情同意权？
> 答：第1219条规定，医务人员在诊疗活动中应向患者说明病情和医疗措施。需要实施手术、特殊检查、特殊治疗的，应及时向患者说明医疗风险、替代医疗方案等情况，并取得其明确同意。

> 问：什么是过度检查禁止？
> 答：第1227条规定，医疗机构及其医务人员不得违反诊疗规范实施不必要的检查。

## 适用指引

### 医疗损害责任纠纷处理

1. **过错认定**：通过诊疗行为是否符合医疗规范、是否符合医疗水平来判断。
2. **因果关系**：由患者举证损害与诊疗行为之间的因果关系。
3. **鉴定**：通常需要进行医疗损害鉴定以确定过错和因果关系。
4. **病历封存**：发生纠纷后应及时封存病历。

### 病历资料纠纷处理

1. **病历查阅复制权**：患者有权查阅、复制病历资料，医疗机构应及时提供。
2. **病历伪造篡改推定**：医疗机构存在伪造、篡改、隐匿、销毁病历行为的，直接推定其有过错。
3. **客观病历与主观病历**：客观病历（如检查报告）应允许复制；主观病历（如病程记录）可限制复制。

### 知情同意纠纷处理

1. **告知形式**：口头告知+书面签字确认。
2. **告知内容**：病情、医疗措施、医疗风险、替代医疗方案。
3. **紧急情况**：第1220条的紧急救治规定可作为知情同意的例外。
