# 建工合同事实查明（一）合同关系与责任主体

> 本专题深入解析建设工程施工合同纠纷中**合同关系认定**和**责任主体认定**两大核心问题。涵盖：实际施工人认定 / 转包-违法分包-借用资质区分 / 三方关系责任承担 / 多层转包责任承担。

| # | 问题 | 关键 |
|---|------|------|
| 1 | 如何认定实际施工人身份？ | 综合 3 维度 |
| 2 | 如何区分转包、违法分包、借用资质？ | 综合 5 维度 |

## 一、合同关系审查（行 140-174）

### （一）有无书面合同的审查

**有书面合同**：
- 一般可认定合同关系成立

**无书面合同**：
- 原告须证明：涉案工程**一部分或全部由其施工**
- 原告须证明：施工过程能**作出合理解释**
- 举证责任转移 → 由否认方举证

**反向规则**：原告不能证明由其施工 → 主张基本不能成立。

### （二）合同地位审查

查明当事人是以下哪种身份：
- 发包人
- 总承包人
- 分包人
- 转包人
- 实际施工人

**识别依据**：
- 合同载明的主体身份
- 施工范围
- 实际履行情况

### （三）实际施工人身份的认定

**定义**：实际施工人是指**建设工程施工合同无效情形下实际完成建设工程施工、实际投入资金、材料和劳动力违法承包的单位和个人**（行 152）。

#### 3 维度综合审查

| 维度 | 审查要点 | 具体证据 |
|------|----------|----------|
| **1. 合同签订参与** | 原告与承包人是否存在真实劳动关系 | 委托代理人身份、合同磋商记录 |
| **2. 资金投入** | 投标保证金、履约保证金来源 | 银行转账记录 + 保证金缴纳凭证 |
| **3. 合同履行** | 实际履行施工义务 + 享有对人财物支配权 | 劳务付款 + 材料采购 + 机械租赁 + 施工资料 + 进度款申报 + 实际参与结算 |

#### 4 类证据必查

- 投标保证金、履约保证金的**实际交纳凭证**
- 大量**劳务、材料、租赁机械**的付款凭证
- 多份**施工合同**（与下游供应商/分包商签订）
- **施工资料持有**情况（施工日志、隐蔽工程记录等）
- **进度款申报**和**实际参与结算**的证据

## 二、转包/违法分包/借用资质区分（行 162-174）

### 三大概念区分

| 形态 | 概念 | 责任范围 |
|------|------|----------|
| **转包** | 承包人将全部工程转给第三人 | 发包人在欠付范围内担责 |
| **违法分包** | 分包给不具备资质单位/违反规定分包 | 发包人在欠付范围内担责 |
| **借用资质** | 无资质企业借用有资质企业名义施工 | 发包人明知时承担全部付款责任 |

### 5 维度综合审查

| 维度 | 转包/违法分包 | 借用资质 |
|------|---------------|----------|
| **1. 合同签订时间** | 转分包合同**晚于**总承包合同 | 内部承包合同**早或晚于**总承包合同均可能 |
| **2. 招投标参与** | 承包人完成招投标，**实际施工人未参与** | 实际施工人参与招投标 + 交纳保证金 + 投标文件填写其姓名 |
| **3. 总承包合同签订** | 承包人签订 | 实际施工人**以承包人委托代理人身份**签订 |
| **4. 内部合同表述** | 转包/分包表述 | 借用资质表述（内部承包等） |
| **5. 施工范围** | **可能小于**总承包范围 | **与总承包一致** |

### 司法实务问题

- 部分当事人**未作区分**（在诉讼请求中笼统表述为"实际施工人")
- 部分法官**未注意两种情形对合同关系和责任范围的不同影响**
- **必须**将实际施工人的具体情形作为重要事实查明

## 三、责任承担主体（行 176-192）

### 合同相对性原则

> 建设工程施工合同纠纷的原告一般应依据合同相对性要求合同主体承担责任，部分情况下原告主张突破合同相对性要求非合同主体承担责任，**必须有法律法规的明确规定或债的加入等其他充分理由**。

**适用规则**：
- ✅ 原则：合同相对性
- ⚠️ 例外：法律法规明确规定

### （一）转包、违法分包情形下的责任承担

**两个合同关系**：
1. 发包人 ↔ 承包人（总承包合同，效力独立）
2. 承包人 ↔ 实际施工人（转分包合同，**无效**）

**总承包合同效力**：**不因**承包人是否转分包而无效

**承包人违约**：转分包行为构成违约，但**不影响总承包合同效力**

**各方责任**：

| 主体 | 责任范围 |
|------|----------|
| 承包人 → 实际施工人 | **全部付款义务**（工程款 + 利息 + 赔偿损失）— 基于合同相对性 |
| 发包人 → 实际施工人 | **欠付工程款范围内**承担付款义务（**不包括**工程款利息、损失）— 建工司法解释（一）第 43 条 |

### （二）借用资质情形下的责任承担（**关键区分**）

**发包人明知实际施工人借用资质**：
- 发包人 ↔ 实际施工人：**事实上施工合同关系**（**无效**）
- 出借资质人 ↔ 实际施工人：**借用合同关系**（**无效**）

**各方责任（与转包情形显著不同）**：

| 主体 | 责任范围 |
|------|----------|
| 发包人 → 实际施工人 | **全部付款责任**（工程款 + 利息 + 停工损失赔偿） |
| 出借资质人 → 实际施工人 | **不是**结算支付工程款义务，而是**协助结算 + 转付工程款**义务 |
| 出借资质人 | 对**截留款项**向实际施工人承担付款义务 |

**出借资质人责任承担的混乱现象**：
- 司法实践中存在**连带责任、共同责任、补充赔偿责任**等多种判决
- 应根据**出借资质人与实际施工人之间的合同约定**判定：
  - 若约定由出借资质人**收取管理费** + **协助配合结算** → 出借资质人承担**协助结算及转付**义务
  - 若约定由出借资质人**向实际施工人承担付款义务** → 出借资质人承担**付款责任**

### （三）多层转包/违法分包的责任承担

**典型链条**：发包人 A → 承包人 B → 转承包人 C → 实际施工人 D

**核心规则**：

| 当事人 | 责任 |
|--------|------|
| 实际施工人 D | 只能向其合同相对人 C 主张合同权利 |
| D → B | **不能突破合同相对性** |
| D → A | **不能要求发包人 A 承担责任** |
| 承包人 B | **不能视为发包人**（建工司法解释（一）第 43 条**仅适用三方关系**） |

**建工司法解释（一）第 43 条的适用限制**：

> "发包人在欠付工程款范围内向实际施工人承担责任" **仅适用于最简单的三方关系**（发包人/承包人/实际施工人），**不适用**多层转分包关系。

**例外情形**：表见代理

- 若 C 构成对 B 的表见代理 → **承担责任的仅是 B**，**不包括 C**

## 四、施工合同效力审查（行 194-222）

### 7 个审查要点

| # | 审查要点 | 无效情形 |
|---|----------|----------|
| 1 | 建设工程规划许可证 | 未办理 → 合同无效 |
| 2 | 建筑企业资质 | 承包人不具有所需资质 → 合同无效 |
| 3 | 招投标程序 | 未履行招投标程序（依规定必须招标的工程）→ 合同无效 |
| 4 | 招投标过程强制性规定 | 违反招标投标法强制性规定 → 中标无效 |
| 5 | 转包情形 | 存在转包 → 转包合同无效 |
| 6 | 违法分包情形 | 存在违法分包 → 分包合同无效 |
| 7 | 多份合同情形 | 黑白合同识别 → 见工程价款专题 |

## ❓ 实务高频问题

### Q1：仅有转账凭证，能否认定实际施工人？

**A**：⚠️ **不充分**。需要综合 3 维度：
- 资金投入（转账记录）
- 合同履行（劳务 + 材料 + 机械付款）
- 施工管理（持有施工资料 + 进度款申报）

仅有转账凭证 → 不足以认定实际施工人。

### Q2：内部承包合同是否构成转包？

**A**：取决于**实质内容**：
- 形式上：内部承包合同（员工 + 公司）
- 实质审查：若**无真实劳动关系** + 公司**仅收取管理费** → 构成**借用资质**

### Q3：借用资质情形，发包人承担"全部付款责任"是否包括质保金？

**A**：✅ **是的**。"全部付款责任"包括工程款、利息、停工损失等所有付款义务，质保金属于工程款范畴，应一并承担。

### Q4：多层转包中 D 能否以"发包人"身份起诉 B？

**A**：❌ **不能**。建工司法解释（一）第 43 条仅适用三方关系，多层转包中：
- 不能将 B 视为发包人
- 不能依据第 43 条要求 B 承担责任
- 除非能证明 C 对 B 构成表见代理

### Q5：借用资质情形下，发包人"明知"如何认定？

**A**：综合判断：
- 实际施工人**直接参与**工程管理
- 工程款**直接支付**给实际施工人
- 出借资质人**未实际参与**施工
- 招投标文件中**实际施工人姓名**出现
