## 章节结构

### 第一章 总则

**立法目的**（第1条）：预防和制止家庭暴力，保护家庭成员的合法权益，维护平等、和睦、文明的家庭关系，促进家庭和谐、社会稳定。✅ VERIFIED

**家庭暴力定义**（第2条）：家庭成员之间以殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓等方式实施的身体、精神等侵害行为。✅ VERIFIED

**核心原则**：
- 第3条：国家禁止任何形式的家庭暴力
- 第5条：预防为主，教育、矫治与惩处相结合；尊重受害人真实意愿，保护当事人隐私
- 特殊保护对象：未成年人、老年人、残疾人、孕期和哺乳期的妇女、重病患者

**主管机构**（第4条）：县级以上人民政府负责妇女儿童工作的机构，负责组织、协调、指导、督促有关部门做好反家庭暴力工作。

### 第二章 家庭暴力的预防

- 第6条：国家开展家庭美德宣传教育；工会、共青团、妇联、残联组织开展宣传教育；学校、幼儿园开展教育
- 第7条：预防和制止家庭暴力纳入业务培训和统计；医疗机构做好诊疗记录
- 第8条：乡镇/街道组织开展预防工作，居委会/村委会配合协助
- 第9条：政府支持社会组织开展心理健康咨询、家庭关系指导等服务
- 第10条：人民调解组织依法调解家庭纠纷
- 第11条：用人单位发现本单位人员有家庭暴力情况的，应当批评教育并做好调解
- 第12条：未成年人监护人应当以文明方式家庭教育，不得实施家庭暴力

### 第三章 家庭暴力的处置

**投诉与报案**（第13-14条）：
- 受害人及其法定代理人、近亲属可向所在单位、居委会、村委会、妇联投诉、反映或求助
- 也可向公安机关报案或向人民法院起诉
- 学校、医院等机构发现无/限制民事行为能力人遭受或疑似遭受家暴的，**应当及时向公安机关报案**

**公安机关处置**（第15-17条）：
- 接到报案后应当及时出警，制止家暴，调查取证，协助就医、鉴定伤情
- 情节较轻的：给予批评教育或出具**告诫书**（第16条）
- 告诫书内容：加害人身份信息、家暴事实陈述、禁止实施家暴
- 居委会、村委会、派出所对收到告诫书的加害人、受害人进行查访监督

**临时庇护与法律援助**（第18-19条）：
- 县级或设区的市级政府可设立临时庇护场所
- 法律援助机构应当依法提供法律援助；法院应缓收、减收或免收诉讼费用

**证据认定**（第20条）：法院可根据出警记录、告诫书、伤情鉴定意见等证据认定家暴事实。✅ VERIFIED

**监护人资格撤销**（第21条）：监护人实施家暴严重侵害被监护人合法权益的，法院可撤销其监护人资格。被撤销者仍应负担赡养、扶养、抚养费用。✅ VERIFIED

### 第四章 人身安全保护令

**申请条件**（第23条）：遭受家庭暴力或面临家暴的现实危险，可向人民法院申请。✅ VERIFIED

**代为申请**（第23条第2款）：无/限制民事行为能力人，或因强制、威吓等原因无法申请的，近亲属、公安机关、妇联、居委会、村委会、救助管理机构可代为申请。

**申请方式**（第24条）：书面方式；书面确有困难的可口头申请。

**管辖**（第25条）：申请人或被申请人居住地、家暴发生地的基层人民法院。

**裁定形式**（第26条）：由人民法院以裁定形式作出。

**审查期限**（第28条）：受理后72小时内作出；情况紧急的24小时内。✅ VERIFIED

**保护令措施**（第29条）：
1. 禁止被申请人实施家庭暴力
2. 禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属
3. 责令被申请人迁出申请人住所
4. 保护申请人人身安全的其他措施

**有效期**（第30条）：不超过六个月，自作出之日起生效。可根据申请撤销、变更或延长。✅ VERIFIED

**复议**（第31条）：对驳回申请或保护令不服的，5日内可向作出裁定的法院申请复议一次。复议期间不停止执行。

**执行**（第32条）：由人民法院执行，公安机关及居委会、村委会协助执行。

### 第五章 法律责任

- 第33条：构成违反治安管理行为的依法给予治安管理处罚；构成犯罪的依法追究刑事责任
- 第34条：违反人身安全保护令，构成犯罪的依法追究刑事责任；尚不构成犯罪的，法院给予训诫，可处1000元以下罚款、15日以下拘留
- 第35条：未按规定报案造成严重后果的，对直接负责人员依法给予处分
- 第36条：负有反家暴职责的国家工作人员玩忽职守、滥用职权、徇私舞弊的，依法给予处分；构成犯罪的追究刑事责任

### 第六章 附则

- 第37条：家庭成员以外共同生活的人之间实施的暴力行为，**参照本法规定执行** ✅ VERIFIED
- 第38条：本法自2016年3月1日起施行

## 核心制度要点

### 人身安全保护令制度

| 要素 | 内容 |
|------|------|
| 申请主体 | 受害人本人；无/限制行为能力人或因强制威吓无法申请的，由近亲属、公安、妇联、居/村委会、救助机构代为申请 |
| 管辖法院 | 居住地或家暴发生地基层法院 |
| 审查期限 | 72小时（紧急24小时） |
| 保护措施 | 禁止家暴、禁止骚扰跟踪、责令迁出、其他保护措施 |
| 有效期限 | 不超过6个月，可撤销/变更/延长 |
| 救济途径 | 5日内申请复议，复议期间不停止执行 |
| 执行主体 | 人民法院执行，公安/居/村委会协助 |

### 告诫书制度

| 要素 | 内容 |
|------|------|
| 适用条件 | 家暴情节较轻，依法不给予治安管理处罚 |
| 出具机关 | 公安机关 |
| 内容 | 加害人身份信息、家暴事实陈述、禁止实施家暴 |
| 后续监督 | 居委会/村委会/派出所查访监督 |
