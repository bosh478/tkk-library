# 侵犯公民个人信息罪·安徽量刑细则 L4(2024)

> **L4 概念页**(皖高法发〔2024〕3号):本罪在安徽省内的具体起刑点、量刑幅度、基准刑递增规则。

## 一、量刑档次三档(必须齐全 · R3 铁律)

依据《刑法》第 253 条之一 + 安徽 2024 细则:

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(情节严重)** | 三年以下有期徒刑或者拘役 + 罚金 | 视触发项在 **3 月拘役 - 1 年** 区间 |
| **第二档(情节特别严重)** | 三年以上七年以下有期徒刑 + 罚金 | **3-4 年有期徒刑** |
| **第三档(顶格)** | 7 年 | 由基准刑递增 |

## 二、第一档 · 入罪触发(11 项 · 任一)

| 触发 | 数额 | 起刑点 |
|------|------|--------|
| 出售/提供行踪轨迹 + 1 次犯罪 | — | **6 月-1 年**;每多 1 次犯罪 + **3-6 月** |
| 明知他人利用信息犯罪 + 出售提供 | — | **6 月-1 年** |
| 非法获取/出售/提供 行踪轨迹/通信内容/征信/财产信息 | **50 条** | **3 月拘役-9 月**;每多 50 条 + **3 月** |
| 非法获取/出售/提供 住宿/通信记录/健康生理/交易信息 | **500 条** | **3 月拘役-9 月**;每多 500 条 + **3 月** |
| 非法获取/出售/提供 其他信息 | **5000 条** | **3 月拘役-9 月**;每多 5000 条 + **3 月** |
| 数量未达上面 3-5 项但合计达标 | 按比例 | **3 月拘役-9 月** |
| 违法所得 | **5000 元** | **3 月拘役-9 月**;每多 5000 + **3 月** |
| 履职过程获得 + 出售提供 + 半额标准 | — | **3 月拘役-9 月**;每多半额 + **3 月** |
| 2 年内受过刑/政处罚又非法获取 | — | **6-9 月** |
| 合法经营 + 非法购买其他信息 + 获利 5 万 | **5 万** | **3 月拘役-9 月**;每多 5 万 + **3 月** |
| 合法经营 + 2 年内处罚又购买 + — | — | **3 月拘役-9 月** |

> 注:条数与违法所得**不得同时**用以增加刑罚量;二者均明确的,**以确定基准刑较重的标准计算**。

## 三、第二档 · 3-4 年起刑点(情节特别严重)

**入罪触发**(任一):
1. 造成被害人死亡、重伤、精神失常或被绑架等严重后果
2. 造成重大经济损失或恶劣社会影响
3. 数量或数额达到第一档 3-8 项规定标准 **10 倍以上**
4. 其他可以增加刑罚量的情形

**基准刑递增**:
| 增加项 | 月数规则 |
|--------|----------|
| 每多 1 名被害人死亡 | + **1-2 年** |
| 每多 1 名重伤/精神失常/被绑架 | + **6 月-1 年** |
| 行踪轨迹/通信内容/征信/财产 + 100 条 | + **1-3 月** |
| 住宿/通信记录/健康生理/交易 + 1000 条 | + **1-3 月** |
| 其他信息 + 10000 条 | + **1-3 月** |
| 违法所得 + 1 万 | + **1-3 月** |
| 履职过程 + 半额标准 | + **1-3 月** |

## 四、从重情节(4 类 · 累计不超 100%)

1. 履职过程 + 出售提供 → + **10-30%**
2. 未成年人/老年人信息 → + **20% 以下**
3. 设立专门网站/通讯群组 → + **20% 以下**
4. 其他可以从重 → + **20% 以下**

## 五、从宽情节

- 为合法经营 + 非法购买收受 → **− 30% 以下**

## 六、罚金

- 违法所得 1-5 倍罚金
- 单处罚金 / 无违法所得 / 数额无法查实:**2000-30000 元**
- 三年以下并处:**2000-50000 元**
- 三年以上:**不低于 10000 元**
- 单位犯罪 + 情节严重:**5-100 万**;情节特别严重:**≥ 20 万**

## 七、缓刑适用 — 一般不适用情形(7 类)

1. 死亡/重伤/精神失常/被绑架等严重后果
2. 2 年内刑/政处罚史
3. 行踪轨迹信息多次被用于犯罪
4. 通信内容/征信/财产 ≥ 500 条
5. 国家工作人员实施
6. 利用职业便利 / 履职过程获取 + 出售提供
7. 其他不适用情形

## 八、相比同类规范的核心差异

| 维度 | 安徽(本页) | 两高指导意见(二) |
|------|------------|------------------|
| 第一档触发条数 | 50 / 500 / 5000 | 同 |
| 第二档倍数 | 10 倍 | 同(大同小异) |
| 罚金起点 | 2000-30000 元(无违法所得) | 类似 |
| 缓刑不适用 | 7 类 | 类似 |
