# 民法典合同编第一章【一般规定】综合

## 章节目录

本章共 6 条（Articles 463-468），规定合同编的调整范围、合同概念、合同相对性、合同解释规则、无名合同适用、非合同债权债务关系适用等基础性、共同性问题。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第463条 | 合同编调整范围 | 因合同产生的民事关系 |
| 第464条 | 合同概念+身份关系协议 | 广义合同+身份关系参照适用 |
| 第465条 | 合同受法律保护+相对性 | 合同相对性原则 |
| 第466条 | 合同条款解释 | 文义+体系+目的+习惯+诚信 |
| 第467条 | 无名合同+涉外合同 | 参照最相类似合同+国际条约+惯例 |
| 第468条 | 非合同债权债务关系 | 准用合同编通则规定 |

## 一、第463条·合同编调整范围

### 法条原文

> 第四百六十三条　本编调整因合同产生的民事关系。

### 核心释义

**合同编的体例结构**：

| 分编 | 内容 |
|------|------|
| **第一分编 通则** | 合同订立、效力、履行、保全、变更转让、权利义务终止、违约责任 |
| **第二分编 典型合同** | 19 类典型合同（买卖、供用电、赠与、借款、保证、租赁、融资租赁、保理、承揽、建设施工、运输、技术、保管、仓储、委托、物业服务、中介、行纪、合伙、准合同） |
| **第三分编 准合同** | 无因管理、不当得利（《民法典》不设债法总则，将债法主要规则放到合同编） |

**合同编调整范围的理解**：

1. **调整平等民事主体之间**的合同关系
2. **因合同设立、变更、终止**民事权利义务关系的协议
3. **不调整**行政协议、身份关系协议（除非参照适用）

① 来源：合同编调整范围（L485-L650），《民法典适用大全》合同卷1 2023年 463-556.md

## 二、第464条·合同概念与身份关系协议

### 法条原文

> 第四百六十四条　合同是民事主体之间设立、变更、终止民事法律关系的协议。
>
> 婚姻、收养、监护等有关身份关系的协议，适用有关该身份关系的法律规定；没有规定的，可以根据其性质参照适用本编规定。

### 合同概念解析

| 维度 | 内容 |
|------|------|
| **主体** | 民事主体（自然人、法人、非法人组织） |
| **客体** | 民事法律关系（财产关系为主，身份关系参照） |
| **行为** | 设立、变更、终止 |
| **形式** | 协议（意思表示一致） |

### 合同与协议的区别

- **合同**：本编规定的 19 类典型合同 + 无名合同
- **协议**：包括但不限于合同，涵盖更广的合意行为

### 身份关系协议的特别规则

| 类型 | 适用规则 |
|------|---------|
| **婚姻、收养、监护等身份关系协议** | 优先适用**身份关系法律规定**（如《民法典》婚姻家庭编） |
| **身份关系法律规定没有规定的** | **可以根据其性质参照适用**合同编规定 |
| **典型情形** | 夫妻财产约定（参照合同编） |

### 合同分类

| 分类标准 | 类型 |
|---------|------|
| **是否有名** | 典型合同（有名合同） vs 非典型合同（无名合同） |
| **成立方式** | 诺成合同 vs 实践合同（要物合同） |
| **是否需对价** | 有偿合同 vs 无偿合同 |
| **标的** | 财产合同 vs 身份合同 |
| **履行期限** | 一时性合同 vs 继续性合同 |
| **成立时间** | 预约合同 vs 本约合同 |
| **当事人** | 双务合同 vs 单务合同 |
| **是否涉及第三人** | 束己合同 vs 涉他合同 |

## 三、第465条·合同受法律保护与合同相对性

### 法条原文

> 第四百六十五条　依法成立的合同，受法律保护。
>
> 依法成立的合同，仅对当事人具有法律约束力，但是法律另有规定的除外。

### 合同相对性原则

**核心含义**：依法成立的合同**仅对当事人具有法律约束力**——这是合同法的基本原则。

| 维度 | 相对性体现 |
|------|----------|
| **主体相对性** | 仅合同当事人享有权利、承担义务 |
| **内容相对性** | 合同约定的权利义务仅在当事人间发生效力 |
| **责任相对性** | 违约责任仅在当事人间承担 |
| **第三人** | 第三人不受合同约束（除非法律特别规定） |

### 合同相对性的突破（例外情形）

| 例外情形 | 法律依据 |
|---------|---------|
| **涉他合同**（向第三人履行/由第三人履行） | 第522-524条 |
| **债权人的代位权** | 第535条 |
| **债权人的撤销权** | 第538-539条 |
| **买卖不破租赁** | 第725条 |
| **建设工程价款优先受偿权** | 第807条 |
| **第三人侵害债权**（有限承认） | 司法实践 |

## 四、第466条·合同条款解释规则

### 法条原文

> 第四百六十六条　当事人对合同条款的理解有争议的，应当依据合同目的、交易习惯以及诚实信用原则，确定争议条款的含义。
>
> 合同文本采用两种以上文字订立并约定具有同等效力的，对各文本使用的词句推定具有相同含义。各文本使用的词句不一致的，应当根据合同的目的予以解释。

### 合同解释的方法

| 解释方法 | 内容 |
|---------|------|
| **文义解释** | 从词句的通常含义出发 |
| **体系解释** | 依据合同整体结构、相关条款 |
| **目的解释** | 依据合同目的 |
| **习惯解释** | 依据交易习惯 |
| **诚信解释** | 依据诚实信用原则 |

### 合同解释的适用顺序

```
合同条款理解争议
├─ 1. 合同约定明确 → 按合同约定
├─ 2. 合同约定不明确 → 文义解释
├─ 3. 文义解释不能 → 体系解释
├─ 4. 体系解释不能 → 目的解释
├─ 5. 目的解释不能 → 习惯解释
└─ 6. 习惯解释不能 → 诚信解释
```

### 两种以上文字合同的处理

| 情形 | 处理规则 |
|------|---------|
| **约定具有同等效力** | 各文本**推定具有相同含义** |
| **约定具有同等效力，但词句不一致** | **根据合同目的予以解释** |
| **未约定同等效力** | 推定**中文文本**为主要文本（实务规则） |

### 合同解释的特殊规则

- **格式条款解释**：第498条规定不利解释规则（对格式条款提供方不利）
- **合同名称与内容不一致**：以**内容**为准（《民法典》合同解释通则）
- **合同漏洞填补**：依第510-511条规定

## 五、第467条·无名合同与涉外合同

### 法条原文

> 第四百六十七条　本法或者其他法律没有明文规定的合同，适用本编通则的规定，并可以参照适用本编典型合同或者其他法律最相类似合同的规定。
>
> 在中华人民共和国境内履行的中外合资经营企业合同、中外合作经营企业合同、中外合作勘探开发自然资源合同，适用中华人民共和国法律。

### 无名合同的处理

**无名合同**：本法或者其他法律没有明文规定的合同。

**处理规则**：
1. **适用本编通则**规定（合同订立、效力、履行等共同规则）
2. **参照适用本编典型合同**中**最相类似**的合同规定
3. **参照适用其他法律**最相类似合同的规定

**实务常见无名合同**：合作开发合同、合作协议、战略合作协议、框架协议、OEM 合同等。

### 涉外合同的特别规则

**三类必须适用中国法律的合同**：
1. **中外合资经营企业合同**（中国境内履行）
2. **中外合作经营企业合同**（中国境内履行）
3. **中外合作勘探开发自然资源合同**（中国境内履行）

**涉外合同的法律适用**（依《法律适用法》及司法解释）：
- 合同当事人可以**协议选择**适用法律
- 未选择的，适用**与合同有最密切联系**的法律
- 特定类型的合同（如技术合同）适用专属规则

## 六、第468条·非合同债权债务关系

### 法条原文

> 第四百六十八条　非因合同产生的债权债务关系，适用有关该债权债务关系的法律规定；没有规定的，适用本编通则的有关规定，但是根据其性质不能适用的除外。

### 非合同债权债务关系的范围

| 类型 | 主要法律依据 |
|------|------------|
| **侵权行为** | 《民法典》侵权责任编 |
| **无因管理** | 第979-984条 |
| **不当得利** | 第985-988条 |
| **其他法定之债** | 单行法或特别规定 |

### 准用规则

**适用顺序**：
1. **优先适用**有关该债权债务关系的**专门法律规定**
2. **没有规定的**，适用**合同编通则**的有关规定
3. **根据性质不能适用**的**除外**

**典型适用情形**：
| 情形 | 适用规则 |
|------|---------|
| 侵权损害赔偿之债 | 优先《民法典》侵权责任编；没有规定的可准用合同编通则（如违约金、解除等） |
| 无因管理之债 | 适用合同编通则相关规定（如履行费用的求偿） |
| 不当得利之债 | 适用合同编通则相关规定（如利益返还的范围） |

### "根据其性质不能适用"的判断

**不能适用的典型情形**：
- 合同编通则中**专属合同**的规则（如要约承诺、合同成立时点等）
- **强行性规定**（如合同相对性原则对第三人不直接适用）

## ❓ 实务问答精选

> **问**：合同编是否调整所有合同？
>
> **答**：**不完全是**。合同编调整因合同产生的民事关系，**不调整**身份关系协议（除非参照适用）、行政协议、行政管理关系。**调整范围**：平等民事主体之间因合同设立、变更、终止民事法律关系的协议。

> **问**：身份关系协议能否适用合同编？
>
> **答**：**可以参照适用**。第464条规定"婚姻、收养、监护等有关身份关系的协议，适用有关该身份关系的法律规定；没有规定的，可以根据其性质**参照适用**本编规定"。**关键**：身份关系法律规定优先，没有规定的参照合同编。

> **问**：合同相对性的例外有哪些？
>
> **答**：合同相对性原则的**主要例外**：
> 1. 涉他合同（向第三人履行/由第三人履行，第522-524条）
> 2. 债权人的代位权（第535条）
> 3. 债权人的撤销权（第538-539条）
> 4. 买卖不破租赁（第725条）
> 5. 建设工程价款优先受偿权（第807条）
> 6. 第三人侵害债权（司法实践有限承认）

> **问**：合同解释应当遵循什么顺序？
>
> **答**：依第466条规定，应当**依据合同目的、交易习惯以及诚实信用原则**确定争议条款的含义。实务中的解释顺序：
> 1. 文义解释（通常含义）
> 2. 体系解释（合同整体结构）
> 3. 目的解释（合同目的）
> 4. 习惯解释（交易习惯）
> 5. 诚信解释（诚实信用）

> **问**：无名合同如何适用法律？
>
> **答**：依第467条规定：
> 1. 适用合同编通则规定
> 2. 可以参照适用合同编典型合同中**最相类似**的合同规定
> 3. 可以参照适用其他法律最相类似合同的规定

> **问**：涉外合同必须适用中国法律的情形？
>
> **答**：第467条第2款规定在中华人民共和国境内履行的**三类合同必须适用中国法律**：
> 1. 中外合资经营企业合同
> 2. 中外合作经营企业合同
> 3. 中外合作勘探开发自然资源合同
>
> **其他涉外合同**：可由当事人协议选择；未选择的，适用最密切联系原则。
