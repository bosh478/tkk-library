# 《侵权责任法教程》第九章 共同加害行为

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第九章 共同加害行为 |
| 行号范围 | 3272-3408（书籍）|
| 核心议题 | 共同故意/共同过失的共同侵权行为 |
| 涵盖 | 构成要件+责任承担+实务争议 |

## 🎯 核心论点

**共同加害行为 = 共同侵权 = 连带责任**

**《民法典》第1168条**：
> 二人以上共同实施侵权行为，造成他人损害的，应当承担连带责任。

**关键要件**：
- **主体** = 二人以上
- **行为** = 共同实施侵权行为
- **效果** = 连带责任

---

## 第一节 概念与特征

## 一、概念

**共同加害行为**（Mittäterschaft）= 二人以上**共同实施**侵权行为，造成他人损害。

## 二、特征

1. **二人以上**
2. **共同实施**（共同故意或共同过失）
3. **统一损害结果**（损害是共同行为的整体结果）
4. **连带责任**

---

## 第二节 共同实施侵权行为的认定

## 一、构成要件

### （一）主体复数

- 二人以上
- 法人 + 法人 / 法人 + 自然人 / 自然人 + 自然人

### （二）共同实施

**两种情形**：
1. **共同故意**（多数情形）— 意思联络
2. **共同过失**（少数情形）— 各方对损害的发生均有共同过失

### （三）造成损害

- 共同行为整体造成他人损害
- 损害是共同行为的整体结果

## 二、共同故意的认定

**意思联络** = 各加害人之间有共同的意思联络（意思沟通）

**认定标准**：
- 主观上有共同实施侵权行为的认识
- 客观上各加害人的行为相互配合
- 各加害人对损害结果均有希望或放任的态度

## 三、共同过失的认定

**典型情形**：
- 数人共同实施危险行为
- 各方对危险后果均有共同的过失
- 例：数人共同将重物推出窗外致人损害

---

## 第三节 责任承担

## 一、对外责任

**《民法典》第1168条**：**连带责任**

**被侵权人的权利**：
- 可向任一加害人请求全部赔偿
- 可向数个或全部加害人请求赔偿

## 二、内部责任分担

**求偿关系**：
- 连带责任人之间按各自责任大小确定赔偿数额
- 难以确定的，平均承担
- 实际承担超过自己份额的，可向其他连带责任人追偿

## 三、典型案例

- 数人共同殴打致人受伤
- 共同决策实施环境污染
- 共同实施网络攻击

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **共同加害行为** | 二人以上共同实施侵权行为 |
| **共同故意** | 各加害人之间有共同的意思联络 |
| **共同过失** | 各方对损害均有共同过失 |
| **意思联络** | 加害人之间关于实施侵权行为的意思沟通 |
| **连带责任** | 任一加害人承担全部责任 |
