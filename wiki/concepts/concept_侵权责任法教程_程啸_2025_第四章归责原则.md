# 《侵权责任法教程》第四章 归责原则

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第四章 归责原则 |
| 行号范围 | 2251-2591（书籍）|
| 核心议题 | 损害赔偿的归责原则体系 |
| 涵盖 | 归责事由（主观/客观）+ 过错责任 + 过错推定 + 无过错责任 + 公平责任 |

## 🎯 核心论点

**我国《民法典》中的归责原则只有两项**：过错责任与无过错责任。

- **过错推定责任** ≠ 独立归责原则（仅举证责任倒置，本质仍属过错责任）
- **公平责任** ≠ 独立归责原则（辅助性，仅适用于法律明确规定的个别情形）

**两大类归责事由**：

| 类别 | 内涵 | 我国法体现 |
|------|------|-----------|
| **主观归责事由**（意思归责）| 行为人过错（故意或过失）| 过错责任（第1165条第1款）+ 过错推定（第1165条第2款）|
| **客观归责事由**（三种）| 危险 / 控制力 / 公平 | 无过错责任（第1166条）|

## 第一节 概述

## 一、归责事由

### 损害赔偿法的基本原理

> "享有权益者自担损害" — 权益的享有者原则上应自行承担因意外而遭受的损害

**归责事由**（Zurechnung）= 令他人承担损害赔偿的理由。

**为什么需要归责事由**：
- 损害一旦发生，从社会整体看无法填补
- 损害赔偿 = 对已存在损失的再分配，过程本身有成本
- "良好的政策应当让损害停留在其所发生之处，除非有特别干预的理由存在"

### 两类归责事由

#### 1. 主观归责事由（意思归责 Zurechnung zum Willen）

**核心**：依据行为人**有无过错**确定其是否应承担赔偿责任

**体现**：
- **过错责任原则**（《民法典》第1165条第1款）
- **过错推定责任**（《民法典》第1165条第2款）

**例外情形**：
- 意外事件 → 无归责事由 → 受害人自担
- 例1（毒蛇咬死）：意外事件，无可归责性，无人负责
- 例1修正情形：组织者L知道D山多剧毒蛇却未警示 → L有过错 → 负责

#### 2. 客观归责事由（三种）

| 类型 | 内涵 | 立法例 |
|------|------|--------|
| **危险** | 行为人从事高度危险活动，因危险现实化致人损害的归责 | 高度危险物、高度危险活动责任（《民法典》第1239条）|
| **控制力** | 责任人虽无过错也要对与之有特定关系的人从事的侵权行为负责 | 监护人责任（第1188条第1款）、用人者责任 |
| **公平** | 即便无过错且不适用无过错责任，基于公平仍令行为人承担补偿 | 高空抛物掷物责任（第1254条第1款）|

### 客观归责事由详解

#### ① 危险（危险责任）

**例3**（航空公司航班坠毁）：
- 飞机失事无论有无过错，航空公司均应负责
- 民航运营本身是高度危险活动
- **归责事由 = 危险**（非过错）

**立法例**：
- 《民法典》第1239条：占有或使用易燃、易爆、剧毒、高放射性、强腐蚀性、高致病性等高度危险物
- 危险现实化造成他人损害 → 占有人或使用人承担侵权责任

#### ② 控制力（替代责任）

**理论依据**：
- 责任人虽无过错
- 但与之有特定关系的人从事的侵权行为
- 责任人因对被监护人/雇员等具有控制力而负责

**立法例**：
- 《民法典》第1188条第1款：监护人责任
- 用人者责任（第十四章）
- 雇主对雇员侵权的替代责任

#### ③ 公平（公平责任）

**理论依据**：
- 即便造成损害之人没有过错
- 亦不适用无过错责任
- 基于公平考虑，仍令行为人承担**补偿**责任（非赔偿责任）

**例2**（高空抛物）：
- 受害人甲非常无辜
- 难以确定具体侵权人
- 但基于公平 → 由可能加害的建筑物使用人给予补偿（《民法典》第1254条第1款）

## 二、归责原则的概念

**归责原则** = 被作为基本规则而被广泛适用的损害赔偿责任之归责事由

**重要限定**：
- 归责事由/归责原则**仅与损害赔偿责任**（Schadenshaftung）有关
- **不解决**停止侵害、排除妨碍、消除危险等其他侵权责任承担方式
- 归责事由 = 损害赔偿的归责事由
- 归责原则 = 损害赔偿的归责原则

### 我国《民法典》的归责原则体系

| 归责原则 | 性质 |
|---------|------|
| **过错责任原则** | **独立归责原则** |
| **无过错责任原则** | **独立归责原则** |
| 过错推定责任 | **非**独立归责原则（举证责任倒置，仍属过错责任）|
| 公平责任 | **非**独立归责原则（辅助性，仅适用于法律规定情形）|

## 第二节 过错责任

## 一、含义

**《民法典》第1165条第1款**：
> 行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。

**过错责任原则**（Verschuldensprinzien）= 任何人只有在因过错（故意或过失）侵害他人权益造成损害时，才承担侵权赔偿责任。

### 过错责任原则的价值评判

> "在法律地位的维护与行为自由这两种利益发生冲突时，行为自由优先。"

**理由**：
- 行为自由是形成人和物的价值所必需的
- 正在形成者优先于已经存在者
- 对青年人发展、个人职业活动而言，自由不可或缺

### 过错责任原则的具体内容

| 内容 | 说明 |
|------|------|
| **过错是归责事由** | "有过错，或有责任" / "无过错，必无责任" |
| **例1**（物业不扫雪）| 物业服务人员有过错 → 物业公司承担赔偿责任 |
| **共同故意连带责任** | 数人因共同故意造成他人损害时，连带赔偿 |
| **过失相抵** | 受害人对同一损害的发生或扩大有过错的，可减轻侵权人责任 |

## 二、过错推定责任

**《民法典》第1165条第2款**：
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

**内涵**：损害发生后，基于某种**客观事实**而**推定**行为人具有过错；如果行为人不能推翻该推定即证明自己没有过错，就要承担侵权责任。

**例2**（花盆坠落）：花盆坠落的事实足以推定李某有过错；李某须证明自己没有过错（《民法典》第1253条）

### 过错推定的法理依据

- **传统过失理论**：过失 = 主观可非难状态（应注意且能注意而不注意）
- **现代困境**：受害人难以证明加害人过失（机器设备、专业分工、知识壁垒）
- **过错推定的价值**：维持过错责任原则的统治地位 + 举证责任倒置保护受害人

### 适用过错推定责任的侵权行为（《民法典》列举）

| 序号 | 侵权行为 | 法条 |
|------|----------|------|
| 1 | 无民事行为能力人受害时教育机构的侵权责任 | 第1199条 |
| 2 | 动物园的动物致害责任 | 第1248条 |
| 3 | 建筑物、构筑物等及其搁置物、悬挂物脱落、坠落致害责任 | 第1253条 |
| 4 | 堆放物倒塌致害责任 | 第1255条 |
| 5 | 公共道路堆放、倾倒、遗撒妨害通行的物品致害时公共道路管理人的责任 | 第1256条 |
| 6 | 林木折断致害责任 | 第1257条 |
| 7 | 挖掘修缮地下设施致害责任 | 第1258条第1款 |
| 8 | 窨井等地下设施致害责任 | 第1258条第2款 |

### 过错推定的限制

> 《民法典》第1165条第2款属于**宣示性规定**，目的在于**限制**过错推定责任的适用范围，并非独立的请求权基础。

**适用要求**：
- 必须有**法律规定**
- 不能任意扩大适用
- 不能通过合同约定
- 不能由法官自由裁量

## 第三节 无过错责任

## 一、概念与特征

**《民法典》第1166条**：
> 行为人造成他人民事权益损害，不论行为人有无过错，法律规定应当承担侵权责任的，依照其规定。

**无过错责任**（strict liability）= 不论行为人有无过错，只要法律规定应当承担责任，行为人就应承担侵权责任。

**理论依据**：
- "**危险**" 客观存在 → 危险现实化 → 承担责任
- 控制力理论
- 损失分担理论（保险、责任池）

**例1**（高铁线路）：铁路部门修建了地下通道但村民破坏防护网横越铁路被撞死 → 高速铁路运营的危险现实化 → 铁路部门承担责任

## 二、无过错责任的特征

| 特征 | 说明 |
|------|------|
| **不以过错为要件** | 不论行为人有无过错 |
| **法定性** | 必须由法律明确规定（行政法规、地方性法规、规章、司法解释、政府规章均不得规定）|
| **举证责任倒置** | 受害人不必证明加害人过错 |
| **免责事由受限** | 通常仅在不可抗力、受害人故意等极少数情形下免责 |
| **责任范围** | 通常包括直接损失+合理间接损失 |

## 三、适用无过错责任的侵权行为（《民法典》列举）

| 序号 | 侵权行为 | 法条 |
|------|----------|------|
| 1 | 监护人责任（无民事行为能力人造成他人损害）| 第1188条 |
| 2 | 用人者责任（用人单位工作人员因执行工作任务造成他人损害）| 第1191条 |
| 3 | 提供劳务一方因劳务造成他人损害 | 第1192条 |
| 4 | 产品责任（生产者）| 第1202条 |
| 5 | 机动车交通事故责任 | 第1208条 |
| 6 | 医疗产品责任 | 第1218条 |
| 7 | 环境污染、生态破坏责任 | 第1229条 |
| 8 | 高度危险责任（民用核设施、民用航空器、占有使用高度危险物）| 第1232-1244条 |
| 9 | 饲养动物致害责任（特定动物）| 第1245-1247条 |
| 10 | 建筑物倒塌致害责任 | 第1252条 |

## 四、无过错责任的免责事由

**《民法典》一般免责事由**：
- **不可抗力**（极少数情形）
- **受害人故意**（常见免责事由）
- **第三人过错**（不当然免责，需法律规定）

**典型立法例**：
- 《民法典》第1239条高度危险物占有人或使用人：受害人故意或不可抗力 → 减轻或免除
- 《民法典》第1245条饲养动物致害：受害人故意或重大过失 → 可以减免
- 《民法典》第1237条民用核设施：战争等情形 + 受害人故意 → 不承担责任
- 《民法典》第1233条环境污染：法律规定的不承担责任或减轻责任的情形

## 第四节 公平责任

## 一、概念

**公平责任** = 即便无过错且不适用无过错责任，基于公平考虑令行为人承担**补偿**责任。

**性质**：**辅助性归责事由**，**不**是独立归责原则。

## 二、适用情形

**典型情形**（《民法典》第1254条第1款）：
> 从建筑物中抛掷物品或者从建筑物上坠落的物品造成他人损害，难以确定具体侵权人的，除能够证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿。

**其他可能情形**：
- 完全民事行为能力人暂时没有意识造成他人损害（《民法典》第1190条第1款）
- 见义勇为造成受助人损害的，救助人不承担民事责任（《民法典》第184条）

## 三、公平责任的适用限制

**重要规则**：
- 公平责任**仅适用于法律规定情形**（非独立请求权基础）
- 适用从严
- 法官无自由裁量空间（仅在法律明确规定的范围内适用）
- 通常表现为"**补偿**"而非"**赔偿**"（语义区别）

## 四、公平责任与无过错责任的区别

| 维度 | 公平责任 | 无过错责任 |
|------|----------|------------|
| **请求权基础** | 法定个别情形 | 法律规定类型 |
| **归责事由** | 公平 | 危险/控制力 |
| **法律效果** | 补偿（而非完全赔偿）| 完全赔偿 |
| **范围** | 严格限定 | 法定类型 |
| **法官裁量** | 无（仅适用法律）| 无（仅适用法律）|

| **客观归责事由** | 危险 / 控制力 / 公平 |
