# 民法典物权编第二分编第四章【一般规定(所有权)】综合

## 章节目录

本章共 6 条（Articles 240-245），是所有权编的"一般规定"，规定所有权制度的基础：所有权的积极权能与消极权能、所有权与他物权的关系、国家专有、征收制度、耕地保护和征用制度。

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第240条 | 所有权的积极权能 | 占有、使用、收益、处分 |
| 第241条 | 所有权与他物权 | 用益物权+担保物权 |
| 第242条 | 国家专有 | 禁止流通物+用益物权/准物权 |
| 第243条 | 征收 | 公共利益+补偿 |
| 第244条 | 耕地保护 | 特殊保护+总量控制 |
| 第245条 | 征用 | 抢险救灾+疫情防控+补偿 |

## 一、第240条·所有权的积极权能

### 法条原文

> 第二百四十条　所有权人对自己的不动产或者动产，依法享有占有、使用、收益和处分的权利。

### 核心释义

所有权是**完全物权**，是所有人对所有物的永久和充分的物权。

#### （一）四项积极权能

| 权能 | 内容 | 备注 |
|------|------|------|
| **占有权能** | 所有权人对标的物为事实上管领的权能 | 是权利人对标的物进行现实支配的前提和基础 |
| **使用权能** | 所有权人依标的物的性质或用途对其加以利用 | 以满足生活需要 |
| **收益权能** | 所有权人收取标的物天然孳息和法定孳息 | 非所有权人独享，也是用益物权的主要内容 |
| **处分权能** | 所有权人对标的物进行处置 | 决定标的物权属变化或物理形态变化；**所有权的核心内容** |

**处分的两种类型**：

| 类型 | 内容 |
|------|------|
| **事实上的处分** | 对物进行物理上处理（如销毁某物品、加工某物品） |
| **法律上的处分** | 使标的物的所有权发生移转、消灭（如买卖、赠与） |

#### （二）所有权的消极权能

所有权还具有消极权能——在所有权受到妨害或有妨害的危险时，权利人有排除他人干涉，以恢复对标的物的圆满支配状态的权能。详见第3章"物权的保护"。

#### （三）所有权的5个法律特征

| 特征 | 内容 |
|------|------|
| **整体性** | 所有权不是各项权能在量上的总和，而是一个整体的权利；不能在内容或时间上加以分割 |
| **社会性** | 所有权的行使应顾及社会公益；权利人行使所有权须受法律规定的限制 |
| **观念性** | 所有权系观念的存在，不以对标的物的现实支配为必要（现代社会通过设定用益物权/担保物权实现物的利用） |
| **弹力性** | 所有权的单一内容可以自由伸缩，其权能可以于一定情况下往复分出、回归 |
| **恒久性** | 所有权因标的物的存在而永久存续，不得预定其存续期间 |

### 适用指引

**所有权受限制的3种情形**：

| 限制类型 | 内容 | 典型情形 |
|---------|------|---------|
| **容忍义务** | 要求所有人容忍他人对其所有物于一定限度内为一定的"妨害"行为 | 相邻关系 |
| **不作为义务** | 要求所有人不得任意实施某种自由支配行为 | 不得擅自改变耕地的用途 |
| **积极的作为义务** | 所有人于一定情况下应负有积极作为的义务 | 及时拆除或加固危房、不能使土地撂荒 |

其他限制：物权编及其他法律上规定的征收、征用制度；诉讼时效制度。

## 二、第241条·所有权与他物权

### 法条原文

> 第二百四十一条　所有权人有权在自己的不动产或者动产上设立用益物权和担保物权。用益物权人、担保物权人行使权利，不得损害所有权人的权益。

### 核心释义

#### （一）他物权的两大类型

| 类型 | 内容 | 典型 |
|------|------|------|
| **用益物权** | 对他人所有的不动产或动产，享有的占有、使用和收益的权利；以支配物的**使用价值**为内容 | 土地承包经营权、建设用地使用权、宅基地使用权、地役权 |
| **担保物权** | 对担保财产享有优先受偿的权利；以支配标的物**交换价值**为内容 | 抵押权、质权、留置权 |

#### （二）用益物权 vs 担保物权的4点差异

| 差异维度 | 用益物权 | 担保物权 |
|---------|---------|---------|
| **权利内容** | 占有、使用、收益；支配物的使用价值 | 支配物的交换价值（价值权） |
| **权利客体** | 不动产及某些不动产权利 | 不动产+动产+债券+股权等权利（必须具有可让与性） |
| **权利实现时间** | 取得与实现同时发生，无时间间隔 | 取得与实现存在时间间隔（须待债权清偿期届满未获清偿时） |
| **是否有主从性** | 原则上为独立的物权 | 因主债权的存在而存续（从属性） |

### 适用指引

**他物权人行使权利的3项限制**：

| 限制 | 内容 |
|------|------|
| 1. 物权法定原则 | 只能在法律规定的范围内行使物权，不得超越权利范围 |
| 2. 合理利用 | 按照标的物的性质和用途合理利用，不得擅自改变用途 |
| 3. 期限届满返还 | 用益物权在期限届满或担保物权在债权实现后，应将标的物返还所有权人 |

**他物权人的物权保护**：
- 他物权与所有权一样具有排他效力、追及效力
- 所有权人非因法定事由不得收回相应土地
- 他物权受侵害时，可适用第3章物权请求权（返还原物、排除妨害、消除危险）

## 三、第242条·国家专有

### 法条原文

> 第二百四十二条　法律规定专属于国家所有的不动产和动产，任何组织或者个人不能取得所有权。

### 核心释义

#### （一）国家专有的典型客体

依《宪法》第9条等规定：

| 类型 | 内容 |
|------|------|
| **自然资源** | 矿藏、水流、森林、山岭、草原、荒地、滩涂（法律规定属于集体所有的除外） |
| **城市土地** | 城市的土地属于国家所有 |
| **海域** | 海域属于国家所有 |
| **国防资产** | 国防资产属于国家所有 |
| **无线电频谱资源** | 属于国家所有 |
| **文物** | 法律规定属于国家所有的文物 |
| **野生动物资源** | 法律规定属于国家所有的野生动物资源 |
| **水资源** | 水资源属于国家所有 |

#### （二）国家专有的法理意义

| 意义 | 内容 |
|------|------|
| 1. 落实基本经济制度 | 通过《民法典》这一调整民事法律关系的基本法，从私法角度落实《宪法》规定的我国基本经济制度 |
| 2. 民法保护国有财产 | 对国家所有权进行全面的民法保护 |
| 3. 国有财产依法参与民事活动 | 为国有财产依法参与民事活动提供基础性法律依据 |

#### （三）国家所有权行使的特殊性

| 特殊性 | 内容 |
|--------|------|
| **取得方式** | 除传统的原始取得和继受取得外，可依法采取公法方式（征税、国有化、征收、没收） |
| **行使方式** | 国家通过代表国家的相应组织机构来行使（国务院代表国家行使所有权） |
| **运营机制** | 企业或非企业组织代表国家占有、使用财产；由该组织的管理层代表该组织进行具体使用 |

| 项目 | 内容 |

| 审理法院 | 福建省高级人民法院 |

## 四、第243条·征收制度

### 法条原文

> 第二百四十三条　为了公共利益的需要，依照法律规定的权限和程序可以征收集体所有的土地和组织、个人的房屋以及其他不动产。
>
> 征收集体所有的土地，应当依法及时足额支付土地补偿费、安置补助费以及农村村民住宅、其他地上附着物和青苗等的补偿费用，并安排被征地农民的社会保障费用，保障被征地农民的生活，维护被征地农民的合法权益。
>
> 征收组织、个人的房屋以及其他不动产，应当依法给予征收补偿，维护被征收人的合法权益；征收个人住宅的，还应当保障被征收人的居住条件。
>
> 任何组织或者个人不得贪污、挪用、私分、截留、拖欠征收补偿费等费用。

### 核心释义

#### （一）征收的3项法定条件

| 条件 | 内容 |
|------|------|
| 1. 公共利益 | 基于公共利益的需要 |
| 2. 法定权限 | 法律规定的有权机关 |
| 3. 法定程序 | 依法定程序进行 |

#### （二）征收补偿的范围

| 征收对象 | 补偿内容 |
|---------|---------|
| **集体土地** | 土地补偿费 + 安置补助费 + 农村村民住宅、其他地上附着物和青苗等的补偿费用 + 社保费用 |
| **个人住宅** | 征收补偿 + 居住条件保障 |
| **其他不动产** | 依法给予征收补偿 |

**补偿标准**（《土地管理法》第48条）：
- 征收土地应当给予**公平、合理的补偿**
- 保障被征地农民**原有生活水平不降低、长远生计有保障**

#### （三）公共利益的范围（依《国有土地上房屋征收与补偿条例》第8条）

| 公共利益类型 | 内容 |
|------------|------|
| 1 | 国防和外交的需要 |
| 2 | 由政府组织实施的能源、交通、水利等基础设施建设的需要 |
| 3 | 由政府组织实施的科技、教育、文化、卫生、体育、环境和资源保护、防灾减灾、文物保护、社会福利、市政公用等公共事业的需要 |
| 4 | 由政府组织实施的保障性安居工程建设的需要 |
| 5 | 由政府依照《城乡规划法》有关规定组织实施的对危房集中、基础设施落后等地段进行旧城区改建的需要 |
| 6 | 法律、行政法规规定的其他公共利益的需要 |

**公共利益判断的4个考虑因素**：

| 因素 | 内容 |
|------|------|
| 1 | 受益人的范围、是否特定、人数多寡 |
| 2 | 政府所采取的行政措施不应当给人民造成过大的损失和不成比例的负担 |
| 3 | 公共利益的层次性（局部的财产利益可以让位于国家安全、能源安全、生态安全或社会发展等公共利益） |
| 4 | 可选择性（能通过其他办法保护公共利益的，尽量采用对私人财产损害较小的方法） |

### 适用指引

**征收权的行使主体**：只能由**国家**（由政府依法组织实施）行使。除国家之外，任何组织和个人都不享有公权力，因而也不享有征收权。

**与原《物权法》的差异**：
- 将"单位"改为"组织"
- 增加"及时"二字
- "安置补助费、地上附着物和青苗的补偿费等费用"修改为"安置补助费以及农村村民住宅、其他地上附着物和青苗等的补偿费用"
- "拆迁补偿"修改为"征收补偿"

**建设用地使用权提前收回的征收**（依《民法典》第358条）：
> 建设用地使用权期限届满前，因公共利益需要提前收回该土地的，应当依据本法第243条的规定对该土地上的房屋及其他不动产给予补偿，并退还相应的出让金。

## 五、第244条·耕地保护

### 法条原文

> 第二百四十四条　国家对耕地实行特殊保护，严格限制农用地转为建设用地，控制建设用地总量。不得违反法律规定的权限和程序征收集体所有的土地。

### 核心释义

#### （一）耕地保护5项核心制度（《土地管理法》第4章）

| 制度 | 内容 |
|------|------|
| 1. 占用耕地补偿制度 | "占多少，垦多少"原则；没有条件开垦或不符合要求的，缴纳耕地开垦费 |
| 2. 耕地总量和质量保障 | 确保本行政区域内耕地总量不减少、质量不降低 |
| 3. 永久基本农田保护制度 | 永久基本农田经依法划定后，任何单位和个人不得擅自占用或者改变其用途 |
| 4. 禁止闲置、荒芜耕地 | 1年未用→恢复耕种或组织耕种；1年以上未动工→缴纳闲置费；连续2年未使用→无偿收回 |
| 5. 鼓励依法开垦未利用土地 | 在保护和改善生态环境、防止水土流失和土地荒漠化的前提下开发未利用土地 |

#### （二）永久基本农田的保护范围

| 耕地类型 | 内容 |
|---------|------|
| 1 | 经国务院农业农村主管部门或者县级以上地方人民政府批准确定的粮、棉、油、糖等重要农产品生产基地内的耕地 |
| 2 | 有良好的水利与水土保持设施的耕地，正在实施改造计划以及可以改造的中、低产田和已建成的高标准农田 |
| 3 | 蔬菜生产基地 |
| 4 | 农业科研、教学试验田 |
| 5 | 国务院规定应当划为永久基本农田的其他耕地 |

**比例要求**：各省、自治区、直辖市划定的永久基本农田一般应当占本行政区域内耕地的**80%以上**。

## 六、第245条·征用制度

### 法条原文

> 第二百四十五条　因抢险救灾、疫情防控等紧急需要，依照法律规定的权限和程序可以征用组织、个人的不动产或者动产。被征用的不动产或者动产使用后，应当返还被征用人。组织、个人的不动产或者动产被征用或者征用后毁损、灭失的，应当给予补偿。

### 核心释义

#### （一）征收 vs 征用的4点区别

| 差异维度 | 征收 | 征用 |
|---------|------|------|
| **适用情况** | 公共利益的需要 | 抢险救灾、疫情防控等紧急需要 |
| **适用对象** | 不动产 | 不动产 + 动产 |
| **法律效果** | 国家取得财产的所有权（永久转移） | 仅取得使用权（临时使用） |
| **补偿标准** | 按标的物的价值进行及时充分的补偿 | 主要考虑被征用人所受到的损失 |

#### （二）征用的4项适用条件

| 条件 | 内容 |
|------|------|
| 1 | 必须基于抢险救灾、疫情防控等**紧急需要** |
| 2 | 必须严格按照**法定权限**进行征用 |
| 3 | 必须严格按照**法定程序**进行征用 |
| 4 | 对被征用人给予**公平合理的补偿** |

#### （三）"紧急需要"的判断

"紧急需要"应是一种**突发性的、非常状态下的需要**，也是事关公共利益保护的需要：

| 法律 | 紧急需要的情形 |
|------|--------------|
| 《宪法》+《戒严法》 | 严重危及国家统一、安全或社会公共安全的动乱、暴乱或严重骚乱 |
| 《突发事件应对法》第12条 | 应对突发事件 |
| 《传染病防治法》第45条 | 传染病暴发、流行 |
| 《人民警察法》第13条 | 因侦查犯罪需要 |
| 《防汛条例》第32条 | 紧急防汛期抢险需要 |

**关键判断**：如果突然发生的危险**仅仅涉及私人利益**的范围，则处理该事件的需要不属于"紧急需要"。

### 适用指引

**征用的救济途径**：
- 对于征用决定不服 → 可以提起**行政复议**或者**行政诉讼**
- 对于补偿标准有异议 → 同样通过行政复议或行政诉讼解决
- **不应**通过民事诉讼解决政府征用引起的纠纷

**与原《物权法》的差异**：
- 将"单位"修改为"组织"
- 增加"**疫情防控**"这一可以征用的情形（总结新冠肺炎疫情防控工作经验）

## ⚠️ 司法适用难点

### 难点一：所有权权能的可分性

**争议**：所有权是否包含全部权能？设定他物权时所有权是否减损？

**主流观点**：
- 所有权是**整体性**的权利，不是各项权能在量上的总和
- 设定用益物权或担保物权**不是**让与所有权的一部分，而是**创设一个新的、独立的物权**
- 所有权具有**弹力性**，设定限制物权后所有权"减缩"，限制解除后所有权恢复圆满状态

### 难点二：用益物权与担保物权的边界

**争议**：同一不动产上是否可以同时设定用益物权和担保物权？

**主流观点**：
- 可以并存（如建设用地使用权上设定抵押权）
- 但**不得并存数个以现实占有为要件的用益物权**（如两个土地承包经营权人不能同时占有同一块土地）
- 可以并存数个担保物权（如同一不动产上设定多个抵押权）

### 难点三：国家专有财产的可交易性

**争议**：国家专有的财产（如国有土地所有权）是否可以交易？

**主流观点**：
- 国家专有财产本身**不可交易**（土地所有权等属于禁止流通物）
- 但基于该所有权而设立的**用益物权或准物权可以依法交易**（如国有土地使用权出让、出租、抵押）
- 在不改变所有权归属的前提下，可以依法为组织或个人所使用

### 难点四：公共利益的界定

**争议**：何为"公共利益"？

**主流观点**（依《国有土地上房屋征收与补偿条例》第8条）：
- 公共利益具有**极大的不确定性**（"公共"的不确定性 + "利益"的不确定性）
- 通过立法形式细化（列举 + 兜底条款严格解释）
- 防止"公共利益"被滥用

### 难点五：征收与征用的区分

**争议**：何时适用征收？何时适用征用？

**主流观点**：

| 判断标准 | 适用征收 | 适用征用 |
|---------|---------|---------|
| 目的 | 公共利益 | 抢险救灾、疫情防控等紧急需要 |
| 期限 | 永久 | 临时 |
| 所有权 | 永久转移 | 不转移 |

## ❓ 实务问答

### Q1：所有权的4项积极权能是什么？

**A**：依《民法典》第240条：
1. **占有权能**：所有权人对标的物为事实上管领
2. **使用权能**：依标的物的性质或用途对其加以利用
3. **收益权能**：收取标的物天然孳息和法定孳息
4. **处分权能**：对标的物进行处置（事实上的处分 + 法律上的处分）

### Q2：所有权与他物权的关系？

**A**：依《民法典》第241条：
- 所有权人有权在自己的不动产或动产上设立用益物权和担保物权
- 用益物权人、担保物权人行使权利，**不得损害所有权人的权益**
- 他物权与所有权一样具有排他效力、追及效力

### Q3：国家专有的不动产和动产能否取得所有权？

**A**：**不能**。

依《民法典》第242条，法律规定专属于国家所有的不动产和动产，任何组织或者个人不能取得所有权。但国家可以通过设定用益物权或准物权使组织或个人取得使用权。

### Q4：征收的法定条件是什么？

**A**：依《民法典》第243条，征收的3项法定条件：
1. **公共利益**（依《国有土地上房屋征收与补偿条例》第8条）
2. **法定权限**（法律规定的有权机关）
3. **法定程序**（依法定程序进行）

### Q5：征收集体土地的补偿范围？

**A**：依《民法典》第243条第2款：
- 土地补偿费
- 安置补助费
- 农村村民住宅、其他地上附着物和青苗等的补偿费用
- 安排被征地农民的社会保障费用

### Q6：征收与征用的区别？

**A**：

| 维度 | 征收 | 征用 |
|------|------|------|
| 适用情况 | 公共利益 | 抢险救灾、疫情防控等紧急需要 |
| 适用对象 | 不动产 | 不动产 + 动产 |
| 法律效果 | 永久转移所有权 | 临时使用 |
| 补偿 | 按标的物价值及时充分补偿 | 返还 + 损失补偿 |

### Q7：耕地保护的核心制度有哪些？

**A**：依《土地管理法》第4章：
1. 占用耕地补偿制度（"占多少，垦多少"）
2. 耕地总量和质量保障
3. **永久基本农田保护制度**（划定后任何单位和个人不得擅自占用或改变用途；占本行政区域内耕地的80%以上）
4. 禁止闲置、荒芜耕地
5. 鼓励依法开垦未利用土地

### Q8：征用的救济途径？

**A**：依《民法典》第245条：
- 对于征用决定不服 → **行政复议**或者**行政诉讼**
- 对于补偿标准有异议 → 同样通过行政复议或行政诉讼解决
- **不应**通过民事诉讼解决政府征用引起的纠纷
