# 犯罪构成(《刑法》第 13-16 条 · L3)

> 本页定位:犯罪构成 L3 概念页。**总则第 2 章犯罪构成要件**的总论基石,与故意、过失、既遂、未遂、正当防卫等紧密关联;**罪与非罪、此罪与彼罪、轻罪与重罪**的判断标准。

## 一、法条原文(条文要点)

《刑法》第 13 条(犯罪概念):
> 一切危害国家主权、领土完整和安全……以及其他危害社会的行为,依照法律应当受刑罚处罚的,都是犯罪,但是情节显著轻微危害不大的,不认为是犯罪。

学理定义:**犯罪构成** = 刑法规定的,决定某一行为**成立犯罪所必须具备**的**全部客观和主观要件**的有机统一整体。

## 二、段级释解

### 1. 概念界定

犯罪构成 = 行为成立犯罪所必须具备的**法律规定的全部要件**的有机整体。

法律地位:**罪与非罪、此罪与彼罪、轻罪与重罪**的**唯一法律标准**。

学说分歧:
- **四要件说**(中国主流):客体 + 客观方面 + 主体 + 主观方面
- **三阶层说**(德日):构成要件该当性 + 违法性 + 有责性
- **英美双层次**:犯罪本体要件 + 责任充足要件

本 wiki 采用**四要件说**(与中国司法实践一致)。

### 2. 犯罪构成四要件

(1) **犯罪客体**:
- 刑法所**保护**的**社会关系**
- 例:故意杀人罪的客体是他人的生命权
- 盗窃罪的客体是公私财产所有权
- 受侵害的**社会关系**而非具体的人或物

(2) **犯罪客观方面**:
- **行为**(作为 / 不作为)
- **结果**(实害结果 / 危险结果 / 无需结果)
- **因果关系**(行为 → 结果)
- **特定时间、地点、方法**(部分罪名)

(3) **犯罪主体**:
- **自然人** / **单位**
- **刑事责任年龄**(已满 16 周岁 / 14-16 周岁特定 8 类犯罪)
- **刑事责任能力**(精神病人 / 醉酒人)
- **特殊身份**(国家工作人员 / 司法工作人员 / 医务人员等)

(4) **犯罪主观方面**:
- **故意**(直接故意 / 间接故意)
- **过失**(疏忽大意 / 过于自信)
- **目的 / 动机**(部分罪名)
- **认识错误**(事实认识错误 / 法律认识错误)

### 3. 犯罪构成的意义

(1) **罪与非罪的标准**:不具备任一要件 → 不构成犯罪
(2) **此罪与彼罪的区分**:要件不同 → 不同罪名
(3) **轻罪与重罪的判断**:要件不同 → 量刑轻重不同
(4) **犯罪形态的认定**:构成要件齐备 → 既遂;部分齐备 → 未完成形态
(5) **共同犯罪的认定**:共同要件 → 共同犯罪

### 4. 犯罪构成的体系地位

**犯罪构成**是连接:
- **犯罪概念**(第 13 条:何为犯罪)
- **犯罪构成要件**(具体要件)
- **具体犯罪**(分则各罪)

的核心枢纽。

### 5. 四要件说的批评与三阶层说的引入

**四要件说批评**:
- 客体要件**先于**主体,逻辑上**无法解释正当防卫**(侵害人也是犯罪客体,为何不构成犯罪?)
- **主体与主观方面**判断时混淆

**三阶层说的优势**:
- **构成要件该当性**(符合客观要件)
- **违法性**(无违法阻却事由)
- **有责性**(主观责任 + 责任能力)
- 逻辑清晰,易于处理正当防卫、紧急避险等出罪事由

中国司法实践**仍以四要件说为主**,但学界已引入三阶层说作为补充。

## 三、实务问答(FAQ)

Q1:犯罪构成与「犯罪构成要件」的区别?
- **犯罪构成**:**整体概念**(四要件的有机统一)
- **犯罪构成要件**:**单个要件**(客体/客观方面/主体/主观方面)
- 关系:构成要件是构成的「元素」,构成是元素的「整体」

Q2:犯罪客体与「犯罪对象」的区别?
- **犯罪客体**:**社会关系**(人身权、财产权等抽象法益)
- **犯罪对象**:**具体的人或物**(被害人、赃物等具体对象)
- 例:盗窃罪的客体是财产所有权,对象是具体的公私财物

Q3:犯罪主体与「刑事责任年龄」的关系?
**刑事责任年龄**是犯罪主体的**必要条件**:
- 已满 16 周岁:完全责任能力(任何犯罪)
- 已满 14 周岁不满 16 周岁:相对责任能力(8 类特定犯罪)
- 不满 14 周岁:无责任能力(不负刑事责任)

Q4:不作为犯罪是否需要四要件?
**是**。不作为犯罪同样需要四要件:
- 客体:被侵害的社会关系
- 客观方面:**不作为**行为 + 特定结果 + 因果关系(不作为 → 结果)
- 主体:**有作为义务的人**(基于法律 / 职务 / 先行行为 / 合同)
- 主观方面:故意 / 过失

Q5:意外事件是否构成犯罪?
**不构成**:
- 意外事件**不符合主观方面要件**(无故意 / 过失)
- 第 16 条:行为在客观上虽然造成了损害结果,但是不是出于故意或者过失,而是由于不能抗拒或者不能预见的原因所引起的,不是犯罪

Q6:精神病人在犯罪时无责任能力,如何认定?
**严格标准**(《刑法》第 18 条):
- **完全丧失**辨认或控制能力:**不负刑事责任**
- **尚未完全丧失**:**应当负刑事责任,但可以从轻或减轻处罚**
- **间歇性精神病**:精神正常时犯罪 → 负刑事责任

Q7:犯罪构成的「认识错误」如何处理?
**事实认识错误**:
- 具体事实认识错误:不影响犯罪构成(按实际行为认定)
- 抽象事实认识错误:影响犯罪构成(按主观意图认定)

**法律认识错误**:
- 不知法律:**不免责**(一般情况下)

Q8:四要件说与三阶层说的实务差异?
**中国司法实务**以四要件说为主:
- **入罪逻辑**:四要件同时具备 → 构成犯罪
- **出罪事由**:正当防卫 / 紧急避险等特殊规定
- **法律适用**:按四要件逐一审查

三阶层说主要在**学理研究**中使用。

Q9:犯罪构成与「犯罪未完成形态」的关系?
- **犯罪构成**:理论框架(完整的犯罪构成要件)
- **犯罪未完成形态**:**部分要件齐备**的状态
- 关系:未完成形态是「构成要件不齐备」的特殊情形

Q10:对**单位犯罪**的犯罪构成如何认定?
**单位犯罪构成要件**:
- 主体:**单位**(公司、企业、事业单位、人民团体)
- 主观:**单位集体决定**或**负责人决定**(代表单位)
- 客体:受侵害的社会关系
- 客观:**以单位名义** + **为单位利益** + **单位决策**
