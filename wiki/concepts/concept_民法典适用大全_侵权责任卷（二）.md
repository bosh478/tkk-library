## 内容定位

本卷是侵权责任卷第二册，围绕《民法典》第1208条（2021-01-01 施行 / 2021-01-01 最新修正）至第1260条，涵盖特殊侵权责任类型：机动车交通事故责任、医疗损害责任、环境污染和生态破坏责任、高度危险责任、饲养动物损害责任、建筑物和物件损害责任（含高空抛物）。这些特殊侵权责任类型各有独立的归责原则和构成要件。

## 章节结构总览

### 第五章 机动车交通事故责任（第1208-1217条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1208条 | 一般规定 | 机动车发生交通事故造成损害的，依照道路交通安全法律和本法有关规定承担赔偿责任 |
| 第1209条 | 租赁、借用 | 因租赁、借用等情形机动车所有人、管理人与使用人不是同一人时，属于该机动车一方责任的由使用人承担赔偿责任；所有人、管理人有过错的承担相应责任 |
| 第1210条 | 转让交付后登记前 | 当事人已转让并交付但未办理登记的，属于该机动车一方责任的由受让人承担赔偿责任 |
| 第1211条 | 挂靠 | 以挂靠形式从事道路运输经营活动的，属于该机动车一方责任的由挂靠人和被挂靠人承担连带责任 |
| 第1212条 | 未经允许驾驶 | 未经允许驾驶他人机动车造成损害的，由使用人承担赔偿责任；所有人、管理人有过错的承担相应责任 |
| 第1213条 | 赔偿顺序 | 先由交强险赔偿→商业保险赔偿→侵权人赔偿 |
| 第1214条 | 拼装车或报废车 | 以买卖或其他方式转让拼装或报废机动车造成损害的，由转让人和受让人承担连带责任 |
| 第1215条 | 盗抢机动车 | 盗窃、抢劫或抢夺的机动车造成损害的，由盗窃人、抢劫人或抢夺人承担赔偿责任 |
| 第1216条 | 逃逸 | 机动车驾驶人发生交通事故后逃逸的，由道路交通事故社会救助基金垫付抢救费用 |
| 第1217条 | 好意同乘 | **新增**：非营运机动车发生交通事故造成无偿搭乘人损害的，应减轻赔偿责任（故意或重大过失除外） |

### 第六章 医疗损害责任（第1218-1228条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1218条 | 诊疗过错责任 | 患者在诊疗活动中受到损害，医疗机构或其医务人员有过错的，由医疗机构承担赔偿责任 |
| 第1219条 | 知情同意 | 医务人员应向患者说明病情和医疗措施；实施手术等应取得患者或其近亲属明确同意 |
| 第1220条 | 紧急救治 | 因抢救生命垂危的患者等紧急情况不能取得患者或其近亲属意见的，经医疗机构负责人批准可立即实施相应医疗措施 |
| 第1221条 | 诊疗义务判断标准 | 医务人员在诊疗活动中未尽到与当时的医疗水平相应的诊疗义务的，医疗机构应承担赔偿责任 |
| 第1222条 | 推定过错 | 违反法律法规规章及诊疗规范；隐匿或拒绝提供病历；遗失、伪造、篡改或违法销毁病历 |
| 第1223条 | 医疗产品责任 | 因药品、消毒产品、医疗器械的缺陷或输入不合格血液造成损害的，患者可向生产者或医疗机构请求赔偿 |
| 第1224条 | 免责事由 | 患者或其近亲属不配合医疗机构进行符合诊疗规范的诊疗；医务人员在抢救生命垂危的患者等紧急情况下已尽到合理诊疗义务；限于当时的医疗水平难以诊疗 |
| 第1225条 | 病历资料 | 医疗机构应按规定填写并妥善保管病历资料；患者有权查阅、复制 |
| 第1226条 | 患者隐私权和个人信息 | 医疗机构及其医务人员应保护患者的隐私和个人信息 |
| 第1227条 | 不必要的检查 | 医疗机构及其医务人员不得违反诊疗规范实施不必要的检查 |
| 第1228条 | 医疗机构合法权益保护 | 医疗机构及其医务人员的合法权益受法律保护；干扰医疗秩序或妨害医务人员工作生活的应承担法律责任 |

### 第七章 环境污染和生态破坏责任（第1229-1235条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1229条 | 一般规定 | 因污染环境、破坏生态造成他人损害的，侵权人应承担侵权责任 |
| 第1230条 | 举证责任倒置 | 因污染环境、破坏生态发生纠纷，行为人应就法律规定的不承担责任或减轻责任的情形及行为与损害之间不存在因果关系承担举证责任 |
| 第1231条 | 数人环境侵权 | 两个以上侵权人污染环境、破坏生态的，承担责任的大小根据污染物的种类、浓度、排放量等因素确定 |
| 第1232条 | 惩罚性赔偿 | **新增**：侵权人违反法律规定故意污染环境、破坏生态造成严重后果的，被侵权人有权请求相应的惩罚性赔偿 |
| 第1233条 | 第三人过错 | 因第三人的过错污染环境、破坏生态造成损害的，被侵权人可向侵权人或第三人请求赔偿 |
| 第1234条 | 生态环境修复责任 | **新增**：违反国家规定造成生态环境损害的，国家规定的机关或法律规定的组织有权请求侵权人在合理期限内承担修复责任 |
| 第1235条 | 生态环境损害赔偿 | **新增**：违反国家规定造成生态环境损害的，国家规定的机关或法律规定的组织有权请求侵权人赔偿相关费用 |

### 第八章 高度危险责任（第1236-1244条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1236条 | 一般规定 | 从事高度危险作业造成他人损害的，应承担侵权责任 |
| 第1237条 | 民用核设施或核材料致害 | 经营者应承担侵权责任；但因战争等情形或受害人故意造成的除外 |
| 第1238条 | 民用航空器致害 | 经营者应承担侵权责任；但因受害人故意造成的除外 |
| 第1239条 | 高度危险物致害 | 占有或使用易燃、易爆、剧毒、高放射性、强腐蚀性、高致病性等高度危险物造成他人损害的，占有人或使用人应承担侵权责任 |
| 第1240条 | 高度危险活动致害 | 从事高空、高压、地下挖掘活动或使用高速轨道运输工具造成他人损害的，经营者应承担侵权责任 |
| 第1241条 | 遗失抛弃高度危险物 | 遗失、抛弃高度危险物造成他人损害的，由所有人承担侵权责任 |
| 第1242条 | 非法占有高度危险物 | 非法占有高度危险物造成他人损害的，由非法占有人承担侵权责任 |
| 第1243条 | 未经许可进入高度危险区域 | 未经许可进入高度危险活动区域或高度危险物存放区域受到损害的，管理人能证明已采取足够安全措施并尽到充分警示义务的，可减轻或不承担责任 |
| 第1244条 | 赔偿限额 | 承担高度危险责任的赔偿限额由法律规定 |

### 第九章 饲养动物损害责任（第1245-1251条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1245条 | 一般规定 | 饲养的动物造成他人损害的，动物饲养人或管理人应承担侵权责任（受害人故意或重大过失可减免） |
| 第1246条 | 违反规定未采取安全措施 | 违反管理规定未对动物采取安全措施造成他人损害的，动物饲养人或管理人应承担侵权责任 |
| 第1247条 | 禁止饲养的危险动物 | 禁止饲养的烈性犬等危险动物造成他人损害的，动物饲养人或管理人应承担侵权责任 |
| 第1248条 | 动物园动物 | 动物园的动物造成他人损害的，动物园应承担侵权责任（能证明尽到管理职责的除外） |
| 第1249条 | 遗弃逃逸动物 | 遗弃、逃逸的动物在遗弃、逃逸期间造成他人损害的，由原动物饲养人或管理人承担侵权责任 |
| 第1250条 | 第三人过错 | 因第三人的过错致使动物造成他人损害的，被侵权人可向动物饲养人或管理人请求赔偿，也可向第三人请求赔偿 |
| 第1251条 | 行为规范 | 饲养动物应遵守法律法规，尊重社会公德，不得妨碍他人生活 |

### 第十章 建筑物和物件损害责任（第1252-1258条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1252条 | 建筑物倒塌塌陷 | 建筑物、构筑物或其他设施倒塌、塌陷造成他人损害的，由建设单位与施工单位承担连带责任（能证明不存在质量缺陷的除外） |
| 第1253条 | 物件脱落坠落 | 建筑物、构筑物或其他设施及其搁置物、悬挂物发生脱落、坠落造成他人损害的，所有人、管理人或使用人不能证明自己没有过错的应承担侵权责任 |
| 第1254条 | 高空抛物 | **新增**：禁止从建筑物中抛掷物品；从建筑物中抛掷物品或从建筑物上坠落的物品造成他人损害的，由侵权人依法承担侵权责任；经调查难以确定具体侵权人的，由可能加害的建筑物使用人给予补偿 |
| 第1255条 | 堆放物倒塌 | 堆放物倒塌、滚落或滑落造成他人损害的，堆放人不能证明自己没有过错的应承担侵权责任 |
| 第1256条 | 公共道路妨碍通行 | 在公共道路上堆放、倾倒、遗撒妨碍通行的物品造成他人损害的，由行为人承担侵权责任 |
| 第1257条 | 林木折断 | 因林木折断、倾倒或果实坠落等造成他人损害的，林木的所有人或管理人不能证明自己没有过错的应承担侵权责任 |
| 第1258条 | 地面施工、地下设施 | 在公共场所或道路上挖掘、修缮安装地下设施等造成他人损害的，施工人不能证明已设置明显标志和采取安全措施的应承担侵权责任 |

## 核心制度解读

### 一、好意同乘制度（第1217条）

**制度创新**：《民法典》新增制度。非营运机动车发生交通事故造成无偿搭乘人损害的，应减轻赔偿责任，但机动车使用人有故意或重大过失的除外。

**立法意义**：鼓励互助行为，保护善意施惠人。

### 二、高空抛物责任（第1254条）

**制度完善**：《民法典》在原《侵权责任法》第87条基础上完善：
- 明确禁止从建筑物中抛掷物品
- 经调查难以确定具体侵权人的，由可能加害的建筑物使用人补偿
- 建筑物使用人补偿后有权向侵权人追偿
- 物业服务企业等建筑物管理人应采取安全保障措施防止高空抛物

### 三、生态环境损害修复责任（第1234条）

**制度创新**：《民法典》新增生态环境损害修复制度，明确侵权人应在合理期限内承担修复责任。

**惩罚性赔偿**（第1232条）：故意污染环境、破坏生态造成严重后果的，被侵权人有权请求惩罚性赔偿。

### 四、医疗损害责任（第1218-1228条）

**归责原则**：过错责任（第1218条）。患者需证明医疗机构或其医务人员有过错。

**推定过错**（第1222条）：违反诊疗规范；隐匿或拒绝提供病历；遗失、伪造、篡改或违法销毁病历的，推定医疗机构有过错。

## ❓ 常见问题

> 问：好意同乘出事故如何处理？
> 答：非营运机动车发生交通事故造成无偿搭乘人损害的，应减轻赔偿责任，但机动车使用人有故意或重大过失的除外（第1217条）。

> 问：高空抛物找不到侵权人怎么办？
> 答：经调查难以确定具体侵权人的，除能证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿（第1254条）。

> 问：医疗损害责任中谁承担举证责任？
> 答：一般由患者证明医疗机构有过错。但有三种情形推定医疗机构有过错：违反诊疗规范；隐匿或拒绝提供病历；遗失、伪造、篡改或违法销毁病历（第1222条）。

> 问：环境污染侵权的举证责任如何分配？
> 答：行为人应就法律规定的不承担责任或减轻责任的情形及行为与损害之间不存在因果关系承担举证责任（第1230条）。
