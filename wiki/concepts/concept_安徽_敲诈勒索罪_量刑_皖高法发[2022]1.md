# 敲诈勒索罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(数额较大)** | 三年以下有期徒刑、拘役或者管制 + 罚金 | **3 月拘役-1 年** |
| **第二档(数额巨大)** | 三年以上十年以下有期徒刑 + 罚金 | **3-5 年** |
| **第三档(数额特别巨大)** | 十年以上有期徒刑 | **10-12 年** |

## 二、第一档 · 3 月拘役-1 年起刑点

**入罪触发**:数额较大 + 两高解释第二、三条规定情形。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 数额每增 **1500 元** | + **1 月** |
| 轻微伤 +1 | + **1-2 月** |
| 轻伤 +1 | + **3-6 月** |
| 2 年内敲诈勒索 +1 次 | + **1-3 月** |

## 三、第二档 · 3-5 年起刑点

**入罪触发**:数额巨大 + "其他严重情节"。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 数额每增 **4500 元** | + **1 月** |
| 轻微伤 +1 | + **1-2 月** |
| 轻伤 +1 | + **3-6 月** |
| "其他严重情节"+1 种 | + **6 月-1 年** |

## 四、第三档 · 10-12 年起刑点

**入罪触发**:数额特别巨大 + "其他特别严重情节"。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 数额每增 **25000 元** | + **1 月** |
| 轻微伤 +1 | + **1-2 月** |
| 轻伤 +1 | + **3-6 月** |
| "其他特别严重情节"+1 种 | + **1-2 年** |

## 五、从重情节(6 类,累计不超 100%)

1. 两高解释第 2 条 7 种情形 → **+30% 以下**(每多 1 种 + **10% 以下**)
2. 多次敲诈勒索(分别达较大/巨大/特别巨大)→ **+20% 以下**
3. 为吸毒 / 赌博 → **+20% 以下**
4. 以非法手段获取隐私勒索 → **+20% 以下**
5. 手段残忍 + 严重后果 → **+30% 以下**
6. 其他从重情形

## 六、从宽情节(4 类)

1. 被害人有过错 → **−20% 以下**
2. 生活所迫 / 学习 / 治病急需 + 人身危险性不大 → **−10% 以下**
3. 敲诈近亲属 + 认定为犯罪 → **−10-50%**
4. 其他从轻情形

**免予刑事处罚**(任一 + 认罪悔罪 + 退赃退赔):
- 法定从宽 / 未参与分赃或获赃较少 + 非主犯 / 谅解 / 其他情节轻微危害不大

## 七、罚金

- 单处罚金:**1-2 倍**,最低 2000 元
- 三年以下:**2000-60000 元**
- 三年-十年:**10000-100000 元**
- 十年以上:**50000-500000 元**

## 八、缓刑适用

**一般可以适用**(任一):
1. 积极退赔 + 谅解
2. 共同犯罪从犯 + 未参与分赃
3. 被害人有过错
4. 敲诈近亲属 + 谅解
5. 其他可适用情形

**一般不适用**(任一):
1. 以放火 / 爆炸 / 故意杀人 / 绑架等严重犯罪相威胁
2. 以黑恶势力名义
3. 冒充国家机关工作人员 / 军人 / 新闻工作者
4. 未成年 / 残疾 / 老年 / 丧失劳动能力
5. 造成被害人自杀 / 精神失常 / 严重后果
6. 曾因敲诈勒索受过刑 / 一年内行拘
7. 其他不适用情形
