# 民法典适用大全·侵权责任卷（二）·第十章建筑物和物件损害责任

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》侵权责任卷2 2023年 1208-1260.md]] |
| 章节 | 第十章 建筑物和物件损害责任 |
| 条文范围 | 《民法典》第1252条～第1258条（共7条） |
| 核心主题 | 建筑物/构筑物倒塌、搁置物悬挂物、高空抛物、公共设施致害责任 |

## 条文结构

| 条文 | 主题 | 法理要点 |
|------|------|----------|
| 第1252条 | 建筑物倒塌塌陷致害 | 建筑物、构筑物或者其他设施倒塌、塌陷造成他人损害的，由建设单位与施工单位承担连带责任 |
| 第1253条 | 搁置物悬挂物致害 | 建筑物、构筑物或者其他设施及其搁置物、悬挂物发生脱落、坠落造成他人损害的，所有人、管理人或者使用人不能证明自己没有过错的，应当承担侵权责任 |
| 第1254条 | 高空抛物坠物（重点修改） | 经调查难以确定具体侵权人的，除能够证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿；可能加害的建筑物使用人补偿后有权向侵权人追偿 |
| 第1255条 | 堆放物倒塌致害 | 堆放物倒塌、滚落、滑落或者堆放物表面脱落造成他人损害的，堆放人不能证明自己没有过错的，应当承担侵权责任 |
| 第1256条 | 公共道路堆放倾倒遗撒 | 在公共道路上堆放、倾倒、遗撒妨碍通行的物品造成他人损害的，有关单位或者个人应当承担侵权责任 |
| 第1257条 | 树木折断果实坠落 | 因林木折断或者树木果实坠落造成他人损害的，林木的所有人或者管理人不能证明自己没有过错的，应当承担侵权责任 |
| 第1258条 | 地下设施致害 | 公共场所或者道路上的窨井等地下设施造成他人损害的，管理人不能证明尽到管理职责的，应当承担侵权责任 |

## 核心制度深度解读

### 一、建筑物倒塌塌陷责任（第1252条）

**归责原则**：无过错责任。

**责任主体**：建设单位与施工单位承担**连带责任**。

**立法变化**：原《侵权责任法》第86条规定"建设单位与施工单位承担连带责任"，但《民法典》第1252条进一步明确建设单位、施工单位的连带责任。

**其他责任人**：因其他责任人的原因造成建筑物倒塌的，建设单位、施工单位赔偿后有权向其他责任人追偿。

### 二、搁置物悬挂物致害责任（第1253条）

**归责原则**：过错推定。

**责任主体**：所有人、管理人或者使用人。

**免责条件**：能证明自己没有过错。

**实务要点**：
- "使用人"是指对建筑物实际使用的人（如承租人）。
- 共同使用时应承担连带责任。

### 三、高空抛物坠物责任（第1254条，重点修改）

**立法演进**：
- 原《侵权责任法》第87条规定了"高空抛物连坐"补偿责任（但实践中争议较大）。
- 《民法典》第1254条对规则进行优化，强调调查义务。

**新规则要点**：
1. **公安等机关的调查义务**：发生高空抛物坠物事件，公安机关应当依法及时调查，查清责任人。
2. **难以确定侵权人的**：除能证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿。
3. **追偿权**：可能加害的建筑物使用人补偿后，有权向侵权人追偿。
4. **物业责任**：物业服务企业等建筑物管理人应当采取必要的安全保障措施防止高空抛物坠物情形的发生；未采取必要的安全保障措施的，应当依法承担未履行安全保障义务的侵权责任。

**法律性质**：补偿而非赔偿（因加害人不明）。

**实务要点**：
- 建筑物使用人应提供证据证明自己不是侵权人（如当时不在家、监控可证等）。
- 证明免责的情形：不在建筑物内、有相反证据证明自己无抛物可能等。

### 四、堆放物倒塌致害（第1255条）

**归责原则**：过错推定。

**责任主体**：堆放人。

**免责条件**：能证明自己没有过错。

### 五、公共道路堆放倾倒遗撒致害（第1256条）

**归责原则**：无过错责任（基于特殊规定）。

**责任主体**：有关单位或者个人。

**实务要点**：
- 堆放物应当远离通行区域。
- 倾倒、遗撒行为也承担责任。

### 六、林木折断果实坠落致害（第1257条）

**归责原则**：过错推定。

**责任主体**：林木所有人或者管理人。

**免责条件**：能证明自己没有过错（如定期修剪、及时处理等）。

### 七、地下设施致害（第1258条）

**适用对象**：公共场所或者道路上的窨井等地下设施。

**归责原则**：过错推定。

**责任主体**：管理人。

**免责条件**：能证明尽到管理职责。

## ❓ 常见问题

> 问：建筑物倒塌塌陷致害的责任由谁承担？
> 答：由建设单位与施工单位承担连带责任（第1252条）。其他责任人原因造成的，建设单位、施工单位赔偿后有权追偿。

> 问：高空抛物找不到侵权人怎么办？
> 答：经调查难以确定具体侵权人的，除能证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿（第1254条）。可能加害的建筑物使用人补偿后有权向侵权人追偿。

> 问：搁置物悬挂物致害的举证责任如何分配？
> 答：所有人、管理人或使用人不能证明自己没有过错的，应当承担侵权责任。归责原则为过错推定。

> 问：什么是林木折断果实坠落致害责任？
> 答：第1257条规定，因林木折断或者树木果实坠落造成他人损害的，林木的所有人或者管理人不能证明自己没有过错的，应当承担侵权责任。

> 问：什么是窨井致害责任？
> 答：第1258条规定，公共场所或者道路上的窨井等地下设施造成他人损害的，管理人不能证明尽到管理职责的，应当承担侵权责任。

> 问：堆放物致害责任如何承担？
> 答：第1255条规定，堆放物倒塌、滚落、滑落或者堆放物表面脱落造成他人损害的，堆放人不能证明自己没有过错的，应当承担侵权责任。

## 适用指引

### 高空抛物纠纷处理

1. **第一时间**：保护现场、通知公安机关。
2. **证据收集**：监控视频、目击证人、建筑物使用情况等。
3. **被告确定**：能确定具体侵权人的，向其请求赔偿；不能确定的，向可能加害的建筑物使用人请求补偿。
4. **举证免责**：建筑物使用人应举证证明自己不是侵权人（如不在家、监控可证等）。
5. **物业责任**：未采取必要安全保障措施的物业服务企业应承担侵权责任。

### 建筑物倒塌塌陷纠纷

1. **责任主体**：建设单位与施工单位承担连带责任。
2. **追偿机制**：因其他责任人原因造成的，建设单位、施工单位赔偿后有权追偿。
3. **诉讼时效**：3年普通诉讼时效。

### 搁置物悬挂物致害纠纷

1. **责任主体**：所有人、管理人或使用人（按实际占有使用情况确定）。
2. **举证责任倒置**：所有人、管理人或使用人证明自己没有过错。
3. **物业管理**：物业服务企业可能因未尽管理职责而承担连带责任。

### 窨井致害纠纷

1. **责任主体**：管理人（通常是市政部门或物业公司）。
2. **举证责任倒置**：管理人证明尽到管理职责。
3. **义务范围**：定期检查、及时修复、设置警示标志等。
