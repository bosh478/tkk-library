## 监管职责分工

| 部门 | 职责 |
|------|------|
| 应急管理部门 | 安全生产监督管理、安全条件审查、安全设施设计审查、许可证核发 |
| 公安机关 | 公共安全管理、剧毒化学品购买许可、道路运输通行证 |
| 市场监管部门 | 工业产品生产许可证、营业执照 |
| 生态环境主管部门 | 废弃危险化学品处置、环境污染事故应急监测 |
| 交通运输主管部门 | 道路/水路运输许可、人员资格认定 |
| 卫生健康主管部门 | 毒性鉴定、职业健康管理 |
| 自然资源主管部门 | 国土空间规划纳入化工园区和周边安全控制距离 |
