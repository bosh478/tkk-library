## 🎯 核心论点（BLUF）

侵权责任法的核心任务 = **协调法益保护（安全）与行为自由**两大基本价值。

基本方法：
1. **过错责任原则**作为基本归责原则
2. **区分保护客体**：民事权利 vs 民事利益；绝对权 vs 相对权；给予不同程度保护

## 第一节 侵权责任法概述

### 一、侵权责任法的概念

| 分类 | 含义 | 范围 |
|------|------|------|
| **狭义侵权责任法**（形式意义）| 民法典规定侵权责任成立与承担的法律规范 | 《民法典》第七编"侵权责任"全部内容 + 总则编/合同编/物权编/人格权编相关规定 |
| **广义侵权责任法**（实质意义）| 所有规范侵权责任的法律规范总和 | 《民法典》 + 《产品质量法》《个人信息保护法》《食品安全法》《消费者权益保护法》《道路交通安全法》《民用航空法》《铁路法》《核安全法》 + 司法解释 |

### 二、侵权责任法的特征

#### 1. 属于私法

- 调整平等主体之间的民事权利与义务关系
- 保护**民事权益**，而非其他权益
- 侵权责任 = 民事责任（≠ 行政责任/刑事责任）
- 国家从事侵权行为也要承担侵权责任（无优越地位）
- 《国家赔偿法》《行政诉讼法》规范公权力侵权赔偿

#### 2. 是强行法（区别于合同法/物权法的任意性规范）

| 维度 | 合同法 | 侵权责任法 |
|------|--------|------------|
| 规范性质 | 任意性规范为主 | 强行性规范更多 |
| 当事人意思自治空间 | 大 | 小 |
| 哪些行为适用无过错/过错推定 | - | **只能由法律规定**（《民法典》第1166条、第1165条第2款） |

> 但并非完全排除意思自治：侵权人与被侵权人仍可就**赔偿范围、数额、支付方式**等协商。

### 三、侵权责任法的体系

```
侵权责任法
├── 侵权责任基本法
│   ├── 《民法典》第七编"侵权责任"
│   ├── 总则编第八章"民事责任"
│   └── 物权编/合同编/人格权编相关规定
└── 侵权责任特别法
    ├── 《个人信息保护法》
    ├── 《产品质量法》
    ├── 《消费者权益保护法》
    ├── 《道路交通安全法》
    ├── 《食品安全法》
    ├── 《铁路法》《民用航空法》
    ├── 《环境保护法》《水污染防治法》《大气污染防治法》《固体废物污染环境防治法》《放射性污染防治法》《核安全法》
    └── 全国人大及其常委会通过的单行法律40余部
```

### 四、侵权责任法的法律渊源

按立法权限和效力等级：

| 渊源 | 性质 | 侵权法适用 |
|------|------|------------|
| **宪法** | 最高法律效力 | 决定民事法律的规范空间；不能直接作为裁判依据 |
| **法律**（狭义）| 全国人大及其常委会 | **唯一可规定侵权责任**的层级（《立法法》第11条第8项：民事基本制度只能制定法律） |
| **法律解释** | 全国人大常委会 | 同法律同等效力（《立法法》第53条）；民事领域仅1件（《民法通则》第99条+《婚姻法》第22条解释，已纳入《民法典》第1015条） |
| **司法解释** | 最高人民法院 | 5种形式：**解释**、规定、规则、批复、决定；如《人身损害赔偿解释》《道路交通事故损害赔偿解释》《精神损害赔偿解释》《民法典时间效力规定》《侵犯商业秘密规定》 |
| **指导性案例** | 最高人民法院 | 截至2025-01-01已发布43批247个；审判类似案件应参照，作为裁判理由引述 |

> **关键判断**：根据《立法法》第11条第8项，"民事基本制度"只能制定法律。**行政法规不能规定侵权责任**（除非授权）。地方性法规、规章等均非侵权法渊源。

> **重要评论**（作者观点）：地方法院在无授权下制定"指导意见"无法律依据，不公开、不备案审查，违反法律和行政法规的屡见不鲜，**有损裁判统一性与权威性**。

### 五、侵权责任法在民法中的地位

#### （一）独立成编的三大理由

| 理由 | 内涵 |
|------|------|
| **1. 适应现代社会发展的客观需要** | 现代新型权益与新型侵权行为众多、形态复杂；大陆法系传统民法典侵权行为仅以一章甚至一节放在债编，严重制约侵权法发展 |
| **2. 符合民法典作为权利法的基本特征** | 新中国接受苏联民法学说，侵权责任是"民事责任"而非单纯"损害赔偿之债"；8种侵权责任承担方式（停止侵害、排除妨碍、消除危险、返还财产、恢复原状、赔偿损失、赔礼道歉、消除影响/恢复名誉）+ 惩罚性赔偿 |
| **3. 有助于完善和发展侵权法** | 现有规定原则、缺乏可操作性；分散在单行法、缺乏共性规定 |

#### （二）《民法典》侵权责任编的意义

| 意义 | 内涵 |
|------|------|
| **1. 确立共通法律规则** | 过错责任原则（第1165条第1款）+ 归责原则/多数人侵权/减责免责事由 + 损害赔偿范围/精神损害赔偿 |
| **2. 有效规制侵权责任特别法** | 防止"部门利益""行业利益"立法；如《民法典》第1244条规定高度危险责任赔偿限额只能由法律规定 |

#### （三）侵权责任编与其他编的关系

**1. 与总则编的关系**：
- 第177-178条：按份责任、连带责任
- 第179条第1款：11种民事责任方式（8种属侵权责任）
- 第179条第2款：惩罚性赔偿原则
- 第180-182条：不可抗力、正当防卫、紧急避险
- 第184条：**自愿紧急救助免责**（主要适用于侵权责任）
- 第185条：英雄烈士人格利益保护
- 第186条：违约责任与侵权责任竞合
- 第187条：民事责任优先原则

**2. 与物权编的关系**：
- 物权法 = "建构性规范"（constitutive rules）
- 侵权法 = "保护性规范"（protective rules）
- 物权请求权（返还原物、排除妨害、消除危险）与侵权赔偿请求权既有区别又有联系
- 物权编特殊规则：
  - 第290-296条：相邻关系中正当行为 vs 侵权行为
  - 第460、461条：善意占有人保护（排除过错责任在"所有人-占有人"关系的适用）

**3. 与合同编的关系**：

| 维度 | 合同编 | 侵权责任编 |
|------|--------|------------|
| 调整对象 | 特定人与特定人关系（交易成本低）| 一类人与人的关系（交易成本高）|
| 功能 | 保护未来行为的协议 | 保护既有生命、健康、财产等权益 |
| 名言 | "当事人主要是因为没把事情办好而承担责任" | "侵权行为人主要是因为把事情搞砸了而承担责任" |

- 联系：违约责任与侵权责任竞合
  - 《民法典》第186条：受害人自由选择
  - 《民法典》第996条：违约行为损害人格权造成严重精神损害，受损害方选择违约责任后仍可请求精神损害赔偿

**4. 与人格权编的关系**：
- 人格权独立成编（民法典特色）
- 第995条：人格权请求权（停止侵害等6种）**不适用诉讼时效**
- 第998条：动态系统论适用除生命权/身体权/健康权之外的人格权益
- 第994条：死者人格利益保护（限制赔偿权利人范围）

| 请求权类型 | 构成要件 | 诉讼时效 |
|----------|---------|----------|
| 人格权请求权 | 不以损害/过错为要件 | **不适用** |
| 侵权赔偿请求权 | 必须有损害，原则上需过错 | 适用 |

## 第二节 侵权责任法的目标

### 一、协调自由与安全

> "整个法律和正义的哲学都是以自由观念为核心而建构起来的。法律的目的不是要废除或限制自由，而是保护和扩大自由。" —— 哈耶克
>
> "从最低限度来说，人之幸福要求有足够的秩序以确保诸如粮食生产、住房以及孩子抚养等基本需要得到满足。" —— 博登海默

**关键洞察**：
- **稀缺性**（scarcity）：社会资源有限 → 经济活动中互相"损害"不可避免
- **并非有损害必有救济**：单纯的"损害"不一定产生侵权责任
- 例1（手机市场竞争）：乙、丙"损害"是市场正常竞争结果，无权请求赔偿
- 例2（路人袖手旁观自杀）：道德可非难，但法律不应强制增进他人福利

**侵权法的双重身份**：
1. **权利救济法** → 充分有效保护民事权益
2. **自由保障法** → 避免对合理行为自由的不当限制

### 二、协调自由与安全的方法

#### 方法1：过错责任原则作为基本归责原则

- "无过错，无责任"
- 例4（张某晕厥撞人）：张某无过错，不承担侵权责任；按经济状况适当补偿即可（《民法典》第1190条第1款）

#### 方法2：区分侵权法保护客体给予不同程度保护

**保护客体等级**：

```
民事权益
├── 民事权利
│   ├── 绝对权（生命权、身体权、健康权等高阶人格权益 + 物权）
│   │   → 因过错（或法律规定无须过错）造成损害 → 承担赔偿责任
│   └── 相对权（特定人之间的债权）
│       → 仅受特定行为方式侵害（如违背善良风俗）；第三人须有故意
└── 民事利益（纯粹经济利益、商业秘密等）
    → 仅给予一定程度保护
```

**例5**（虚假借款合同逃避债务）：
- A与C恶意串通损害B债权 → C需与A承担连带赔偿责任
- 第三人C不知道A已负债而借款给A → 不需承担侵权责任

**死者人格利益保护**（《民法典》第994条）：
- 死者的配偶、子女、父母 → 有权请求
- 无配偶/子女且父母已死亡 → 其他近亲属方能依法请求

## 第三节 侵权责任法的功能

## 一、概述

侵权责任法作为民法的重要组成部分，承担以下核心功能：
1. 民事权益的**事后救济**（损害赔偿 + 8种民事责任方式）
2. 社会行为的**规范引导**（一般预防 + 特殊预防）
3. 社会风险的**合理分配**（侵权责任 + 保险 + 救助基金）

## 二、主要侵权责任类型（预告）

### 过错责任原则（第1165条第1款）

> 行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。

### 过错推定责任（第1165条第2款）

> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

### 无过错责任（第1166条）

> 行为人造成他人民事权益损害，不论行为人有无过错，法律规定应当承担侵权责任的，依照其规定。

> **强制法定**：哪些侵权行为适用无过错责任、过错推定责任**只能由法律规定**，行政法规、地方性法规、司法解释和政府规章不得规定。

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **过错责任原则** | "无过错，无责任"；基本归责原则 |
| **过错推定责任** | 法律规定推定过错；行为人需证明无过错 |
| **无过错责任** | 不论过错，法律规定即承担责任 |
| **强行法** | 不能由当事人约定排除或改变 |
| **强制性规范** | 同上 |
| **基本法 vs 特别法** | 民法典第七编是基本法，单行法是特别法 |
| **形式意义 vs 实质意义侵权法** | 狭义 vs 广义 |
| **稀缺性（scarcity）** | 社会资源有限性，侵权法调整经济活动损害的根源 |
| **权利救济法 vs 自由保障法** | 侵权法双重身份 |
| **建构性规范 vs 保护性规范** | 物权法 vs 侵权法 |
| **保护客体的等级化** | 民事权利 > 民事利益；绝对权 > 相对权 |
| **人格权请求权 vs 侵权赔偿请求权** | 不以损害/过错为要件 vs 必须损害；不适用诉讼时效 vs 适用 |
| **动态系统论** | 综合考量多种因素确定责任范围 |
| **民事责任优先原则** | 民事责任优先于行政、刑事责任 |
