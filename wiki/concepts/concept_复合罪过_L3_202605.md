# 复合罪过(罪过形式混合情形 · L3)

> 本页定位:复合罪过 L3 概念页。**总则第 2 章罪过形式**的特殊问题,涉及故意与过失混合情形(如故意伤害致人死亡、对甲结果故意对乙结果过失),司法认定与罪数认定 + 罪名选择紧密关联。

## 一、法条原文(条文要点)

复合罪过非《刑法》独立条款,是学理概念,源自司法实践中对故意 + 过失混合情形的归纳总结。最高法相关司法解释及最高人民法院刑庭《刑法分则新释新解》均有系统阐释。

相关条文:
- 《刑法》第 14 条(故意犯罪)
- 《刑法》第 15 条(过失犯罪)
- 《刑法》第 234 条(故意伤害罪——含致人死亡加重情节)
- 《刑法》第 233 条(过失致人死亡罪)

## 二、段级释解

### 1. 概念界定

复合罪过 = 行为人对某一危害结果(通常是严重结果)同时存在故意 + 过失两种罪过形式,或对不同危害结果分别持故意 / 过失态度的情形。

两种典型形态:
- 形态 A:对同一结果持混合态度——行为人希望或放任某一结果发生,但对该结果的实现方式/范围持过失态度
- 形态 B:对不同结果持不同态度——行为人故意实施某一行为致结果 A,对额外引发的结果 B 持过失态度(经典例:故意伤害致人死亡)

### 2. 四构成要件(司法认定)

(1) 行为要件:行为人主动实施某一危害行为,该行为同时违反故意犯罪 + 过失犯罪的规范要求

(2) 罪过要件(核心):对基础行为/基础结果:故意态度;对严重结果(如死亡 / 重伤 / 重大财产损失):过失态度

(3) 结果要件:基础结果实际发生(故意内容已实现) + 严重结果实际发生(过失内容已实现)

(4) 因果关系要件:故意行为 → 基础结果 → 严重结果的完整因果链

### 3. 典型类型

类型 1:故意伤害致人死亡(最典型)
- 对伤害故意(《刑法》第 234 条前段)
- 对死亡过失(轻信不会致死)
- 法律评价:按故意伤害罪(致人死亡加重情节)定罪

类型 2:故意杀人中的复合罪过
- 行为人故意伤害致被害人抢救无效死亡(过失)
- 与故意杀人未遂区分:看行为人对死亡结果的主观态度

类型 3:滥用职权致人死亡的复合罪过
- 对滥用职权行为故意,对致人死亡结果过失
- 法律评价:按滥用职权罪(致人死亡加重情节)定罪

类型 4:医疗事故中的复合罪过
- 对违反诊疗规程故意,对患者伤害/死亡结果过失
- 法律评价:按医疗事故罪(《刑法》第 335 条)定罪

### 4. 与相邻概念的边界

与结果加重犯的区分(核心难点):
- 结果加重犯:法律明文规定的基础行为 + 重结果加重情形
- 复合罪过:学理概念,涵盖法律未明文规定的故意 + 过失混合情形
- 重叠情形:故意伤害致人死亡既是结果加重犯,也是复合罪过的典型

与间接故意的区分:
- 间接故意:行为人放任结果发生(认识 + 容忍)
- 复合罪过(过失):行为人不希望结果发生(轻信能避免)

## 三、实务问答(FAQ)

Q1:故意伤害致人死亡,定故意伤害罪还是过失致人死亡罪?
故意伤害罪(致人死亡加重情节)。理由:行为人对伤害持故意,对死亡持过失,按实际结果的发生认识态度,定故意伤害罪(致人死亡加重情节),不适用过失致人死亡罪。

Q2:如何区分故意伤害致人死亡与故意杀人(既遂)?
核心是行为人对死亡结果的主观态度:
- 故意杀人:行为人希望或放任死亡结果 → 故意杀人罪
- 故意伤害致人死亡:行为人不希望死亡结果 → 故意伤害罪致人死亡加重情节
- 区分要点:凶器种类、打击部位、打击力度、犯罪动机、事后行为

Q3:复合罪过情形下,基础故意行为未达情节严重,但过失致人死亡,如何定罪?
按结果吸收原则:过失致人死亡结果吸收基础故意行为(未达情节严重),定过失致人死亡罪。

Q4:复合罪过与想象竞合的关系是什么?
- 想象竞合:一行为触犯数罪
- 复合罪过:罪过形式混合
- 重叠情形:故意伤害致死亡既是复合罪过,也可能是想象竞合 → 但司法实践按结果加重犯处理

Q5:过失致人死亡 + 故意伤害(两个独立行为)能否数罪并罚?
可以。这是数罪并罚情形(《刑法》第 69 条),不是复合罪过

Q6:医疗事故罪(第 335 条)是复合罪过还是纯过失?
纯过失。医师对违反诊疗规程属故意,但故意违反诊疗规程 ≠ 故意伤害,医师无伤害患者的故意,只是业务过失。

Q7:复合罪过情形能否构成共同犯罪?
理论上可以。二人共同故意伤害致人死亡,二人对伤害共同故意,对死亡共同过失 → 成立共同故意伤害罪(致人死亡加重情节)。

Q8:复合罪过与危险犯/结果犯的关系?
- 复合罪过是罪过形式层面的概念
- 危险犯/结果犯是犯罪既遂标准层面的概念
- 两者可同时存在
