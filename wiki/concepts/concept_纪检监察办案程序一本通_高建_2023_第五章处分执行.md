# 《纪检监察办案程序一本通》第五章 处分执行

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第五章 处分执行 |
| 行号范围 | 5539-8787（与第4章交叉）|
| 核心议题 | 党纪政务处分的种类、程序、执行 |
| 涵盖 | 11 类处分+程序+重点疑难 |

## 🎯 核心论点

**处分执行 = 党纪处分 + 政务处分 + 四种形态 + 程序合规**

**11 种处分**：
- 党纪：警告/严重警告/撤销党内职务/留党察看/开除党籍（5种）
- 政务：警告/记过/记大过/降级/撤职/开除公职（6种）

**核心原则**：
- 党纪严于政务
- 同步适用
- 处分档次对应

---

## 第一节 处分种类

## 一、党纪处分

### （一）党员违纪处分

5种党纪处分（从轻到重）：
1. **警告**（最轻）
2. **严重警告**
3. **撤销党内职务**
4. **留党察看**
5. **开除党籍**（最重）

### （二）党组织违纪处分

- **改组**
- **解散**

## 二、政务处分

6种政务处分（从轻到重）：
1. **警告**
2. **记过**
3. **记大过**
4. **降级**
5. **撤职**
6. **开除公职**（最重）

## 三、党纪政务处分的匹配适用

**基本原则**：
- 党纪严于政务
- 同时给予党纪政务处分
- 处分档次对应

## 四、处分以外的处理方式

| 类别 | 方式 |
|------|------|
| **警示教育类** | 约谈、批评教育、责令检查、通报批评 |
| **组织处理类** | 调离岗位、改任非领导职务、责令辞职、免职、降职、停职检查、引咎辞职、责令辞职 |

## 五、精准运用监督执纪"四种形态"

| 形态 | 内涵 | 占比目标 |
|------|------|----------|
| **第一种形态** | 经常开展批评和自我批评、约谈函询 | "红红脸、出出汗"，常态化 |
| **第二种形态** | 党纪轻处分、组织调整 | 大多数 |
| **第三种形态** | 重处分、重大职务调整 | 少数 |
| **第四种形态** | 严重违纪涉嫌违法立案审查 | 极少数 |

## 第二节 处分程序和批准权限

## 一、普通程序：党支部大会讨论

- 召开支部大会讨论
- 表决作出处分决定
- 上报审批

## 二、特殊程序：县级以上纪委直接作出处分

适用于情况紧急或特殊情形

## 三、党组作出党纪处分

**依据**：《中国共产党党组工作条例》

## 四、地方各级党委委员、候补委员的处分批准程序

按干部管理权限 + 党委常委会审批

## 五、终止党代表资格的程序

按党章和有关规定办理

## 六、查处人大代表、政协委员的程序

需依法办理罢免、撤销资格等手续

## 七、给予人大、政协选举或决定任命人员重处分的程序

需先免去其职务，再给予处分

## 八、"双管"干部的处分权限

按"双管"干部管理规定办理

## 三、处分决定的执行事项

| 党纪处分 | 影响期 | 关键执行事项 |
|---------|--------|------------|
| **警告** | 1年 | 不得在党内提升职务 |
| **严重警告** | 1年半 | 不得在党内提升职务 |
| **撤销党内职务** | 2年 | 撤销党内职务 |
| **留党察看** | 1年/2年 | 期间停止党员权利；期满后视情况恢复 |
| **开除党籍** | 永久 | 终止党员权利 |

| 政务处分 | 期间 |
|---------|------|
| **警告** | 6个月 |
| **记过** | 12个月 |
| **记大过** | 18个月 |
| **降级** | 24个月 |
| **撤职** | 24个月 |
| **开除公职** | 永久 |

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **党纪处分** | 对党员违纪的纪律处分 |
| **政务处分** | 对公职人员违法的政务处分 |
| **警告** | 最轻的党纪或政务处分 |
| **记过** | 政务处分 |
| **记大过** | 政务处分 |
| **降级** | 降低级别/工资档次 |
| **撤职** | 撤销现任领导职务 |
| **留党察看** | 党员保留党籍但停止权利 |
| **开除党籍** | 最严重的党纪处分 |
| **开除公职** | 最严重的政务处分 |
| **四种形态** | 监督执纪的四种形态 |
| **"双管"干部** | 一方为主、一方协管 |
| **处分期** | 处分的执行期限 |
| **影响期** | 处分对晋升等的影响期限 |
