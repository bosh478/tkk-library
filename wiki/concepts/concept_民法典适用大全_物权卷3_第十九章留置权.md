# 民法典第十九章【留置权】综合

## 章节目录

本章共 11 条（Articles 447-457），规定留置权制度。留置权是**法定担保物权**（非意定），债权人合法占有债务人动产时，债务人不履行到期债务的，债权人可以留置该动产并就该动产优先受偿。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第447条 | 留置权的概念 | 法定担保物权 |
| 第448条 | 留置财产与债权的关系 | 同一法律关系 + 企业之间留置例外 |
| 第449条 | 不得留置的情形 | 法定/约定禁止 |
| 第450条 | 留置财产的保管 | 妥善保管义务 |
| 第451条 | 孳息收取权 | 收取+冲抵费用 |
| 第452条 | 留置权的实现 | 折价/拍卖/变卖 |
| 第453条 | 宽限期 | 60日履行期 |
| 第454条 | 变价后的处理 | 超过部分归还 |
| 第455条 | 留置权优先于抵押权/质权 | 法定超级优先权 |
| 第456条 | 留置权消灭 | 丧失占有/接受另行担保 |
| 第457条 | 法律适用 | 准用担保物权一般规定 |

## 一、留置权的概念（第447条）

### 法条原文

> 第四百四十七条　债务人不履行到期债务，债权人可以留置已经合法占有的债务人的动产，并有权就该动产优先受偿。
>
> 前款规定的债权人为留置权人，占有的动产为留置财产。

### 留置权的特征

| 特征 | 内容 |
|------|------|
| **法定担保物权** | 留置权**不是意定**的，无需合同约定，依法律规定产生 |
| **占有型担保** | 留置权以**占有**留置财产为公示方法和成立要件 |
| **动产标的** | 仅限**动产**（不动产不得留置） |
| **牵连性** | 留置财产原则上需与债权属于**同一法律关系** |
| **公示性** | 占有即公示，无需登记 |

### 留置权与质权的区别

| 维度 | 留置权 | 质权 |
|------|--------|------|
| **设立方式** | **法定**（依法律规定产生） | **意定**（依合同约定） |
| **占有来源** | 债权人**已经合法占有** | 债权人依出质人**交付**占有 |
| **牵连性** | 要求债权与占有物**同一法律关系**（企业之间除外） | 不要求牵连性 |
| **客体** | **动产** | 动产 + 权利 |
| **行业惯例** | 留置权常常基于特定的行业惯例（如修理费、保管费） | 质权一般基于融资或担保合同 |

### 留置权的产生基础（典型情形）

| 典型情形 | 法律关系 |
|---------|---------|
| 修理合同 | 修理人完成工作后，委托人未支付修理费 |
| 保管合同 | 保管人妥善保管后，寄存人未支付保管费 |
| 运输合同 | 承运人完成运送后，托运人未支付运费 |
| 加工承揽合同 | 承揽人完成工作后，定作人未支付报酬 |
| 建设工程价款 | 承包人就工程价款可留置工程（实务争议） |

## 二、留置财产与债权的关系（第448条）

### 法条原文

> 第四百四十八条　债权人留置的动产，应当与债权属于同一法律关系，但企业之间留置的除外。

### 同一法律关系原则（牵连性）

**一般规则**：债权人留置的动产**应当**与债权属于**同一法律关系**。

**举例**：
- 修理电视机 → 修理费未付 → 留置电视机 ✅ 同一法律关系
- 修理电视机 → 之前的借款未还 → 留置电视机 ❌ 不同法律关系

### 企业之间留置的例外

**企业之间留置**（包括个体工商户）→ **不受同一法律关系限制**：
- 反映商事交易的便捷性需求
- 商事留置权不要求牵连性
- 但仍需满足"合法占有"+ "债务人不履行到期债务"两个前提

### 同一法律关系的判断标准

司法实践中判断"同一法律关系"通常考虑：
1. **直接因果关系**：债权的发生与留置物的占有是基于同一交易
2. **交易连续性**：债权与占有物属于同一连续交易的不同环节
3. **商人习惯**：参照行业惯例

## 三、不得留置的情形（第449条）

### 法条原文

> 第四百四十九条　法律规定或者当事人约定不得留置的动产，不得留置。

### 不得留置的情形

| 情形 | 说明 |
|------|------|
| **法律规定不得留置** | 如涉及公益财产、人道主义物品等 |
| **当事人约定不得留置** | 债权人在占有动产时承诺不主张留置权的，依约定 |
| **占有的合法性丧失** | 占有本身非法的（如侵占所得），不构成合法占有 |
| **留置违反公序良俗** | 留置将导致明显不公或违反公序良俗的 |

**实务注意**：留置权人占有动产时作出的"不主张留置权"承诺通常有效，构成"约定不得留置"。

## 四、留置财产的保管（第450条）

### 法条原文

> 第四百五十条　留置权人负有妥善保管留置财产的义务；因保管不善致使留置财产毁损、灭失的，留置权人应当承担赔偿责任。

### 妥善保管义务

| 维度 | 内容 |
|------|------|
| **主观标准** | 善良管理人标准 |
| **保管费用** | 保管费用属于留置担保范围，可优先受偿 |
| **损害赔偿** | 因保管不善致留置财产毁损灭失的，留置权人**承担赔偿责任** |
| **减轻责任情形** | 不可抗力、被留置人过错等 |

### 与质权保管义务的对比

| 维度 | 留置权人 | 质权人 |
|------|---------|--------|
| 义务来源 | 法定 | 法定 + 合同约定 |
| 保管费用 | 担保范围内 | 担保范围内（第389条） |
| 损害赔偿 | 依第450条 | 依第431、432条 |

## 五、孳息收取权（第451条）

### 法条原文

> 第四百五十一条　留置权人有权收取留置财产的孳息。
>
> 前款规定的孳息应当先冲抵收取孳息的费用。

### 孳息处理规则

- **天然孳息 + 法定孳息**：留置权人有权收取
- **孳息优先冲抵收取孳息的费用**（如修剪费、储藏费等）
- 剩余部分按担保范围冲抵主债权

### 与质权孳息规则的对比

留置权孳息规则（第451条）与质权孳息规则（第430条）基本一致，反映占有型担保物权的共同规则。

## 六、留置权的实现（第452-454条）

### 实现方式（第452条）

> 第四百五十二条　留置权人与债务人应当约定留置财产后的债务履行期间；没有约定或者约定不明确的，留置权人应当给债务人六十日以上履行债务的期间，但是鲜活易腐等不易保管的动产除外。
>
> 债务人逾期仍未履行债务的，留置权人可以与债务人协议以留置财产折价，也可以就拍卖、变卖留置财产所得的价款优先受偿。
>
> 留置财产折价或者变卖的，应当参照市场价格。

### 宽限期（第453条）

> 第四百五十三条　债务人可以请求留置权人在债务履行期限届满后行使留置权；留置权人不行使的，债务人可以请求人民法院拍卖、变卖留置财产。

**宽限期规则**：
| 情形 | 宽限期 |
|------|--------|
| 留置权人与债务人**有约定** | 按约定 |
| 没有约定或约定**不明确** | 留置权人应给债务人**60日以上**履行期 |
| **鲜活易腐等不易保管**的动产 | **不适用60日**，留置权人可直接变价 |

### 变价后的处理（第454条）

> 第四百五十四条　留置财产折价或者拍卖、变卖后，其价款超过债权数额的部分归债务人所有，不足部分由债务人清偿。

- 超过债权数额部分 → 归**债务人**所有
- 不足债权数额部分 → 由**债务人**清偿

### 留置权人的及时行使请求权

**第437条类推适用**（虽第453条直接规定）：债务人可以请求留置权人在债务履行期限届满后及时行使留置权；留置权人**怠于行使**的，债务人可以请求人民法院拍卖、变卖留置财产。

## 七、留置权优先于抵押权、质权（第455条）

### 法条原文

> 第四百五十五条　同一动产上已经设立抵押权或者质权，该动产又被留置的，留置权人优先受偿。

### 留置权的"超级优先权"地位

**核心规则**：**留置权 > 抵押权/质权**（即使抵押权/质权设立在先）

**理由**：
1. **法定担保物权**：留置权是法律直接规定的担保物权
2. **占有公示**：留置权人占有留置财产，对外有公示效果
3. **劳动价值保护**：留置权常常基于债权人**提供劳务或服务**产生（如修理、保管、运输），是对劳动价值的保护
4. **公共政策考量**：鼓励债权人提供服务

### 实务情形

| 典型情形 | 留置权优先性 |
|---------|------------|
| 修理人留置修理物，修理物上已设定抵押 | 修理人（留置权）优先于抵押权人 |
| 保管人留置保管物，保管物上已设定质押 | 保管人（留置权）优先于质权人 |
| 承运人留置货物，货物上已设定动产抵押 | 承运人（留置权）优先于抵押权人 |

**意义**：第455条确立了留置权的"超级优先权"地位，是物权编担保物权制度中最重要的优先性规则之一。

## 八、留置权消灭（第456条）

### 法条原文

> 第四百五十六条　留置权人对留置财产丧失占有或者留置权人接受债务人另行提供担保的，留置权消灭。

### 留置权消灭的两大原因

| 消灭原因 | 要点 |
|---------|------|
| **丧失占有** | 留置权人对留置财产**丧失占有**（无论是遗失、被抢、被窃还是返还） |
| **接受另行担保** | 留置权人**接受债务人另行提供担保**（如保证、抵押、质押） |

### 留置权消灭的特别规则

| 维度 | 内容 |
|------|------|
| **占有丧失的恢复** | 占有短暂丧失后**恢复**的，留置权是否恢复？主流观点：**不恢复**（占有是留置权的公示要件） |
| **接受担保的范围** | 接受的担保可以**大于**原债权范围，依当事人约定 |
| **接受部分担保** | 接受部分担保的，留置权是否消灭？依具体约定和实际情况判断 |

## 九、法律适用（第457条）

### 法条原文

> 第四百五十七条　本章规定的留置权除适用本章规定外，适用本法第十六章担保物权一般规定的有关规定。

### 准用规则

留置权除本章特别规定外，准用第十六章担保物权一般规定，包括但不限于：
- 第386条：担保物权的概念和优先受偿性
- 第388条：担保合同（留置权为法定，无需担保合同，但其他规则可准用）
- 第389条：担保范围
- 第390条：物上代位性
- 第392条：人保与物保并存（留置权与保证的关系）
- 第393条：担保物权消灭原因（除第456条特别规定外）

### 留置权的担保范围

依第389条 + 第457条准用，留置权的担保范围包括：
1. 主债权
2. 利息
3. 违约金
4. 损害赔偿金
5. 保管留置财产的费用
6. 实现留置权的费用

## 十、留置权 vs 抵押权 vs 质权核心对比

| 维度 | 留置权 | 抵押权 | 质权 |
|------|--------|--------|------|
| **设立方式** | **法定** | 意定（合同+公示） | 意定（合同+交付） |
| **占有状态** | 占有 | 不占有 | 占有 |
| **公示方法** | 占有 | 登记 | 交付/登记 |
| **客体** | **动产** | 不动产+动产+权利 | 动产+权利 |
| **牵连性** | **要求**同一法律关系（企业间除外） | 无要求 | 无要求 |
| **优先性** | **优先于**抵押权/质权 | 依登记顺序 | 依交付/登记顺序 |
| **善意取得** | 占有脱离物不构成留置（特殊情形） | 抵押权不要求占有 | 质权要求占有 |

## ❓ 实务问答精选

> **问**：留置权是意定担保物权还是法定担保物权？
>
> **答**：**法定担保物权**。留置权无需合同约定，依据法律规定产生，只要满足"合法占有+同一法律关系（企业之间除外）+债务人不履行到期债务"即可成立。这与抵押权（意定）和质权（意定）有本质区别。

> **问**：留置权与抵押权冲突时，谁优先？
>
> **答**：**留置权优先**。第455条规定："同一动产上已经设立抵押权或者质权，该动产又被留置的，留置权人优先受偿。"即使抵押权/质权设立在先，留置权仍优先。这是留置权的"超级优先权"地位。

> **问**：企业之间留置的特殊规则是什么？
>
> **答**：第448条但书规定"企业之间留置的除外"——**企业之间留置不受同一法律关系限制**（即不要求牵连性）。但仍需满足"合法占有+债务人不履行到期债务"两个前提。这一规则反映了商事交易的便捷性需求。

> **问**：留置权人留置财产后必须立即变卖吗？
>
> **答**：**不是**。第452条规定留置权人应给债务人**60日以上**的履行宽限期（鲜活易腐等不易保管的动产除外）。宽限期届满后债务人仍未履行的，留置权人才可以变价。

> **问**：留置权消灭的原因有哪些？
>
> **答**：第456条规定两个原因：
> 1. 留置权人对留置财产**丧失占有**
> 2. 留置权人**接受债务人另行提供担保**
>
> 这两个原因都是**留置权特有的**（不同于其他担保物权）。

> **问**：留置权人能否留置第三人占有的动产？
>
> **答**：原则上不能。留置权要求留置权人**合法占有**债务人的动产；如占有的动产属于第三人所有，不构成留置权。但如第三人明知留置权存在仍接受留置物的，可能承担相应责任。

## 典型案例

### 案例 1：留置权与抵押权冲突的优先性

**典型案例**：某银行对设备设定了抵押权（已登记），后设备送至修理厂修理，修理厂因修理费未付留置该设备。修理费未付满 60 日后，修理厂主张就该设备变价优先受偿。

**裁判要旨**：依第455条，留置权优先于抵押权。修理厂作为留置权人优先于银行的抵押权受偿。

**意义**：明确留置权"超级优先权"地位，体现对劳动价值的保护。

① 来源：物权卷3 L7400-L7500

### 案例 2：企业之间留置的特殊规则

**典型案例**：A 公司与 B 公司有多次交易。B 公司欠 A 公司货款 100 万，同时 A 公司合法占有 B 公司的一批货物（非同一交易产生）。A 公司主张留置该批货物。

**裁判要旨**：依第448条但书，**企业之间留置不受同一法律关系限制**。A 公司可主张留置权。

**意义**：商事留置的特殊规则，便利企业之间的交易。

① 来源：物权卷3 L7400-L7550

### 案例 3：留置权丧失占有的消灭

**典型案例**：留置权人将留置财产交由第三方维修，后第三方未返还留置财产。

**裁判要旨**：依第456条，留置权人对留置财产**丧失占有**，留置权**消灭**。留置权人只能依其他法律关系（如保管合同、借用合同）向第三方主张权利。
