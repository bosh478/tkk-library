- 二、修改第一百三十五条（重大劳动安全事故罪）

- 四、在第一百三十九条后增加一条（不报、谎报安全事故罪）
- 五、修改第一百六十一条（违规披露、不披露重要信息罪）
- 六、在第一百六十二条之一后增加一条（虚假破产罪）
- 七、修改第一百六十三条（非国家工作人员受贿罪）
- 八、修改第一百六十四条第一款（对非国家工作人员行贿罪）
- 九、在第一百六十九条后增加一条（背信损害上市公司利益罪）
- 十、在第一百七十五条后增加一条（骗取贷款、票据承兑、金融票证罪）

## 量刑档次

### 重大责任事故罪（第134条）
- 档1：发生重大伤亡或严重后果 → 3年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 3年以上7年以下有期徒刑

### 强令他人违章冒险作业罪（第134条第2款）
- 档1： → 5年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 5年以上有期徒刑

### 重大劳动安全事故罪（第135条）
- 档1：安全生产设施或条件不符合国家规定 → 3年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 3年以上7年以下有期徒刑

### 大型群众性活动重大安全事故罪（第135条之一）
- 档1： → 3年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 3年以上7年以下有期徒刑

### 不报、谎报安全事故罪（第139条之一）
- 档1：情节严重 → 3年以下有期徒刑或拘役
- 档2：情节特别严重 → 3年以上7年以下有期徒刑

### 违规披露、不披露重要信息罪（第161条）
- 档1：严重损害股东或其他人利益/有其他严重情节 → 3年以下有期徒刑或拘役，并处或单处2万元以上20万元以下罚金

### 虚假破产罪（第162条之二）
- 档1： → 5年以下有期徒刑或拘役，并处或单处2万元以上20万元以下罚金

### 非国家工作人员受贿罪（第163条）
- 档1：数额较大 → 5年以下有期徒刑或拘役
- 档2：数额巨大 → 5年以上有期徒刑，可以并处没收财产

### 对非国家工作人员行贿罪（第164条第1款）
- 档1：数额较大 → 3年以下有期徒刑或拘役
- 档2：数额巨大 → 3年以上10年以下有期徒刑，并处罚金

### 背信损害上市公司利益罪（第169条之一）
- 档1：致使上市公司利益遭受重大损失 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：致使上市公司利益遭受特别重大损失 → 3年以上7年以下有期徒刑，并处罚金

### 骗取贷款、票据承兑、金融票证罪（第175条之一）
- 档1：给银行或其他金融机构造成重大损失 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：给银行或其他金融机构造成特别重大损失/有其他特别严重情节 → 3年以上7年以下有期徒刑，并处罚金
- 单位犯本罪：对单位判处罚金，对直接负责的主管人员和其他直接责任人员依照前款规定处罚

### 操纵证券、期货市场罪（第182条）
- 档1：情节严重 → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 5年以上10年以下有期徒刑，并处罚金
- 单位犯本罪：对单位判处罚金，对直接负责的主管人员和其他直接责任人员依照前款规定处罚

### 背信运用受托财产罪（第185条之一）
- 档1：情节严重 → 对单位判处罚金，对直接负责人员处3年以下有期徒刑或拘役，并处3万元以上30万元以下罚金
- 档2：情节特别严重 → 对直接负责人员处3年以上10年以下有期徒刑，并处5万元以上50万元以下罚金

### 违法发放贷款罪（第186条）
- 档1：数额巨大或造成重大损失 → 5年以下有期徒刑或拘役，并处1万元以上10万元以下罚金
- 档2：数额特别巨大或造成特别重大损失 → 5年以上有期徒刑，并处2万元以上20万元以下罚金

### 吸收客户资金不入账罪（第187条）
- 档1：数额巨大或造成重大损失 → 5年以下有期徒刑或拘役，并处2万元以上20万元以下罚金
- 档2：数额特别巨大或造成特别重大损失 → 5年以上有期徒刑，并处5万元以上50万元以下罚金

### 违规出具金融票证罪（第188条）
- 档1：情节严重 → 5年以下有期徒刑或拘役
- 档2：情节特别严重 → 5年以上有期徒刑

### 洗钱罪（第191条）
- 档1： → 5年以下有期徒刑或拘役，并处或单处洗钱数额5%以上20%以下罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处洗钱数额5%以上20%以下罚金

### 组织残疾人、未成年人乞讨罪（第262条之一）
- 档1：以暴力、胁迫手段组织乞讨 → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 赌博罪（第303条）
- 档1：以营利为目的，聚众赌博或以赌博为业 → 3年以下有期徒刑、拘役或管制，并处罚金

### 开设赌场罪（第303条第2款）
- 档1： → 3年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 3年以上10年以下有期徒刑，并处罚金

### 掩饰、隐瞒犯罪所得、犯罪所得收益罪（第312条）
- 档1： → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 枉法仲裁罪（第399条之一）
- 档1：情节严重 → 3年以下有期徒刑或拘役
- 档2：情节特别严重 → 3年以上7年以下有期徒刑
