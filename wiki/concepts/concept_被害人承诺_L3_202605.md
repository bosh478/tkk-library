# 被害人承诺(《刑法》总则第 2 章违法阻却 · L3)

> 本页定位:被害人承诺 L3 概念页。**总则第 2 章违法阻却事由**之一,与正当防卫、紧急避险紧密关联;**被害人有效承诺 = 阻却违法性**。

## 一、法条原文(条文要点)

《刑法》总则**无明文规定**被害人承诺制度,但通过**司法实践** + **学理**确立。

学理定义:**被害人承诺** = 法益主体**对他人侵害自己**可处分法益的行为**表示同意**的违法阻却事由。

## 二、段级释解

### 1. 概念界定

被害人承诺 = 被害人**自愿**对他人侵害自己**可处分法益**的行为**表示同意**的违法阻却事由。

**地位**:**阻却违法性**的事由(行为形式上符合构成要件,但实质上不违法)。

### 2. 被害人承诺的要件

(1) **承诺主体要件**:
- **被害人本人**(对法益有处分权的人)
- **有承诺能力**(能理解承诺的意义)
- **达到承诺年龄**(民事行为能力 + 智力状态)

(2) **承诺范围要件**:
- **个人法益**(可由个人处分)
- **非个人专属法益**:生命权 / 重大健康权不可由个人承诺
- **非国家 / 社会法益**:不可由个人承诺(如国家安全、公共安全)

(3) **承诺内容要件**:
- 承诺侵害的**范围**与**实际侵害**一致
- 超过承诺范围 → **可能构成犯罪**

(4) **承诺方式要件**:
- **明示**(口头 / 书面)
- **默示**(根据情境推定)
- 推定的承诺(无明确表示但可推定)

(5) **承诺自愿要件**:
- 承诺必须是**被害人自由意志**的真实表示
- **非因欺诈、胁迫、重大误解**

(6) **承诺时点要件**:
- 承诺**在侵害行为之前**或**侵害进行中**作出
- 侵害**结束后**的事后同意 → **不阻却违法**

### 3. 可承诺法益 vs 不可承诺法益

**可承诺法益**:
- **财产法益**(他人可处分自己的财产)
- **轻度身体伤害**(轻微伤以下)
- **隐私权 / 名誉权**(被害人同意的公开)

**不可承诺法益**:
- **生命权**(任何情况下不可承诺他人杀害自己)
- **重大健康权**(重伤 / 严重残疾)
- **人身自由权**(被害人承诺不阻却非法拘禁)
- **性自主权**(性交行为不允许以承诺方式)
- **国家 / 社会法益**(不可由个人承诺处分)

### 4. 推定的承诺

**推定的承诺** = 被害人**未明确表示**同意,但根据其**利益 / 意愿**可**推定**其会同意的情形。

要件:
- 行为人**主观上**相信被害人**会同意**
- 客观上**被害人确实会同意**(事后询问)
- 行为**为被害人利益**

**典型情形**:
- 医生紧急救治(推定的患者同意)
- 紧急情况下为被害人利益的行为

### 5. 被害人承诺的法律后果

(1) **有效承诺**:**阻却违法性** → 不构成犯罪
(2) **无效承诺**:不阻却违法性 → 按犯罪处理
(3) **超过承诺范围**:超出部分构成犯罪

## 三、实务问答(FAQ)

Q1:被害人承诺可以阻却所有犯罪吗?
**不是**。被害人承诺**仅阻却**对**可处分法益**的犯罪。对**不可处分法益**(生命、重大健康、性自主等)的犯罪,即使承诺也**不阻却违法**。

Q2:被害人承诺伤害的限度?
- **轻微伤**:可由被害人承诺
- **轻伤**:争议(主流不阻却)
- **重伤 / 死亡**:**绝对不阻却**(生命 / 重大健康不可处分)
- 例:经被害人同意的安乐死 → 中国**不合法**;经被害人同意的医疗手术 → 阻却违法(正当医疗行为)

Q3:推定的承诺与被害人真实意愿冲突时?
- 推定的承诺**基于客观**判断
- 事后被害人明确**反对** → 可能**不阻却**
- 例:医生紧急手术 → 患者清醒后**明确拒绝** → 仍可能构成故意伤害

Q4:对**未成年人**的承诺效力?
- **未成年人**(限制行为能力人):承诺**效力受限**
- 重大事项的承诺需**监护人同意**
- 例:未成年人同意捐献器官 → 需监护人同意 + 主管部门批准

Q5:对**精神病人**的承诺效力?
- 精神病人(无承诺能力):**承诺无效**
- 间歇性精神病人(正常期):有承诺能力
- 例:精神病人同意捐献器官 → 监护人代为同意

Q6:对**国家 / 社会法益**的承诺?
- 国家 / 社会法益**不可由个人承诺**处分
- 例:本人同意他人放火烧自己房屋(危害公共安全)→ 仍构成放火罪

Q7:对**亲属**的承诺效力?
- 亲属关系**不**自动产生**承诺代理权**
- 重大事项需**本人明示**或**法定代理**
- 例:丈夫同意医生切除妻子器官 → 无效(需妻子本人同意)

Q8:被害人**事先承诺**的撤回?
- 侵害行为**实施前**:被害人可**撤回承诺**
- 行为人**未停止** → 仍构成犯罪
- 例:被害人承诺参与盗窃,后**反悔**,行为人**仍继续** → 仍构成盗窃罪

Q9:被害人承诺对**未遂犯罪**的适用?
- 被害人承诺在**实施前**撤回 → 行为人**未停止** → 构成既遂(非未遂)
- 被害人承诺**全部**撤回 → 行为人**继续** → 构成犯罪

Q10:被害人**事后**同意的效力?
- 侵害**结束后**的事后同意 → **不阻却违法**(回溯无效)
- 但可作为**酌定从轻**情节(被害人谅解)
- 例:故意伤害致人轻伤 → 被害人**事后谅解** → 不阻却犯罪成立,但可**从轻**
