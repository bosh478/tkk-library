# 因果关系(《刑法》总则第 2 章客观方面 · L3)

> 本页定位:因果关系 L3 概念页。**总则第 2 章犯罪客观方面**的核心要件,行为 → 结果之间的**归责基础**;**必然因果 + 偶然因果 + 客观归责**三层理论。

## 一、法条原文(条文要点)

《刑法》总则无单独的「因果关系」定义条款,因果关系概念散见于:
- 第 14 条(故意犯罪)
- 第 15 条(过失犯罪)
- 第 16 条(意外事件)
- 分则各罪构成要件(结果犯的「结果」与「行为」之间)

学理定义:**刑法上的因果关系** = 行为人的危害行为**引起**刑法规定的**危害结果**的客观联系。

## 二、段级释解

### 1. 概念界定

刑法因果关系 = 行为人的危害行为**与**危害结果之间**引起与被引起**的客观联系。

**地位**:**犯罪客观方面**的核心要件(结果犯的必备要件)。

### 2. 因果关系判断步骤

(1) **事实因果关系**(条件说):
- 行为**事实上**引起了结果
- 假设消除该行为,结果是否会发生?
- 不发生 → 行为是结果的**条件**(因果关系存在)
- 发生 → 行为不是结果的**条件**(因果关系不存在)

(2) **法律因果关系**(相当因果关系说):
- 行为**通常**足以导致该结果
- 行为 → 结果具有**相当性**(非偶然)
- 例:拳击致人死亡 → 拳击通常足以致死 → 有因果关系

(3) **客观归责**(现代刑法理论):
- 行为**制造**了不被允许的危险
- 行为**实现**了该危险
- 结果在**规范保护范围**内
- 例:醉酒驾车致人死亡 → 制造交通危险 + 实现该危险 + 在交通安全规范保护范围内 → 归责

### 3. 必然因果 vs 偶然因果

**必然因果关系**:
- 行为**必然**导致结果(高概率)
- 例:刀刺心脏 → 死亡(必然因果)
- 通常构成刑法因果关系

**偶然因果关系**:
- 行为**偶然**导致结果(低概率)
- 例:轻微推搡 → 被害人突发心脏病死亡
- **通常不构成**刑法因果关系(除非特殊情形)

### 4. 介入因素与因果关系中断

**介入因素**:行为 → 结果之间的**其他因素**
- **被害人行为**(被害人自杀 + 被害人体质特殊)
- **第三人行为**(医生过失治疗 + 他人介入)
- **自然力**(突发地震、洪水)

**因果关系中断**:
- 介入因素**异常独立** → 行为与结果之间因果关系中断
- 行为人**不归责**

**因果关系未中断**:
- 介入因素**通常**会发生 → 因果关系未中断
- 行为人**仍归责**

### 5. 特殊情形的因果关系

(1) **一因多果**:一个行为导致多个结果(想象竞合或数罪并罚)
(2) **多因一果**:多个行为导致一个结果(共同犯罪 / 共同加害)
(3) **重叠因果**:两个行为各自足以导致结果,实际共同导致(共同正犯)
(4) **聚合因果**:两个行为共同作用导致结果(共同正犯)

### 6. 不作为犯罪的因果关系

不作为 → 结果的因果关系:
- 不作为是结果发生的**原因**(如果履行义务,结果可避免)
- 不作为具有**等价性**(与作为具有等价的原因力)

## 三、实务问答(FAQ)

Q1:行为与结果之间没有时间上的连续性,是否构成因果关系?
**视情况**:
- 若行为是结果的**必要条件**(条件说) → 有因果关系
- 若行为与结果之间有**异常介入因素** → 因果关系可能中断
- 例:甲致乙轻伤 → 乙送医院途中被车撞死 → 甲的伤害与死亡**无因果关系**(介入因素异常)

Q2:特殊体质被害人的因果关系?
**主流观点**:有因果关系
- 例:甲拳击乙,乙因**血友病**死亡 → 甲仍构成故意伤害罪(致人死亡加重)
- 理由:**特殊体质是被害人固有因素**,不中断因果关系
- 但**极端特殊体质**(概率极低) → 部分学说认为因果关系减弱

Q3:医生过失治疗介入的因果关系?
- 被害人受伤 → 医生过失治疗 → 死亡
- **医生过失**是**异常介入** → 中断原行为的因果关系
- 医生承担**医疗事故罪**,原行为人对死亡**不归责**

Q4:被害人自杀的因果关系?
- 行为人致被害人伤害 → 被害人自杀 → 因果关系中断
- 但**违法行为致被害人**失去生存意志**自杀 → 部分观点认为有因果关系
- 例:丈夫长期家暴致妻子自杀 → 司法实践可能认定为故意杀人

Q5:多因一果的责任分配?
**共同正犯**情形:
- 各行为人对结果共同负责
- 按**各自作用**分配责任
- 例:甲乙共同围殴丙致丙死亡 → 共同故意伤害罪(致人死亡加重)

Q6:对不作为犯罪,因果关系如何认定?
- 不作为**等价于**作为(具有原因力)
- 履行义务 → 结果**可以避免** → 不作为是结果的原因
- 例:母亲不喂养婴儿致其饿死 → 不作为 = 故意杀人(等价于作为)

Q7:对**危险犯**是否需要因果关系?
- 危险犯不要求**实害结果**
- 但需**危险状态**与行为的因果关系
- 例:放火罪既遂:放火行为 → 公共安全危险状态

Q8:因果关系与「**罪责**」的关系?
- **因果关系**:**客观要件**(行为与结果的联系)
- **罪责**:主观要件(故意 / 过失)
- 两者独立:有因果关系但无罪责 → 不可罚(意外事件)
- 例:甲意外撞伤乙 → 致乙死亡 → 有因果关系 + 无故意/过失 → 意外事件,不负刑责

Q9:对**介入因素**如何判断「异常性」?
- **常态**:介入因素是行为**通常**可能引发
- **异常**:介入因素与行为**无内在联系**
- 例:甲致乙受伤 → 乙到医院 → 医院失火致乙死亡 → 医院失火**异常** → 因果关系可能中断

Q10:「**客观归责**」与「**因果关系**」的区别?
- **因果关系**:行为**事实**上是否导致结果(客观事实判断)
- **客观归责**:行为是否**在法律上**可归责(规范判断)
- 关系:因果关系是**必要条件** + 客观归责是**充分条件**
