# 民法典合同编第十二章【借款合同】综合

## 章节目录与提取状态

本章共 **14 条**（Articles 667-680），是合同编第二分编"典型合同"的重要章节，规定借款合同制度。

| 节 | 法条范围 | 主题 |
|----|---------|------|
| 第一节 借款合同概念与形式 | 667-668 | 概念/形式 |
| 第二节 借款合同内容 | 669 | 条款 |
| 第三节 借款的支付 | 670-672 | 借款人交付 |
| 第四节 借款用途与利息 | 673-676 | 用途/利息 |

## 一、借款合同的概念（第667条）

### 法条原文

> 第六百六十七条　借款合同是借款人向贷款人借款，到期返还借款并支付利息的合同。

### 本条主旨

本条是关于借款合同概念的规定。

### 条文解读

借款合同具有以下法律特征：

| 特征 | 内容 |
|------|------|
| **转移金钱所有权** | 借款人将约定金额的金钱所有权转移给贷款人 |
| **要式合同** | 金融机构借款合同应当采用书面形式 |
| **有偿合同** | 借款人需要支付利息 |
| **双务合同** | 贷款人负交付借款的义务，借款人负返还借款及利息的义务 |
| **诺成性** | 金融机构借款合同为诺成性合同 |

### 借款合同的分类

| 分类 | 类型 | 性质 |
|------|------|------|
| 按贷款人 | 金融机构借款合同 | 诺成合同、要式合同 |
| | 自然人借款合同（民间借贷） | 实践合同、不要式合同 |
| 按借款用途 | 特定借款合同 | 用途专款专用 |
| | 不特定借款合同 | 借款人可自由使用 |

## 二、借款合同的形式（第668条）

### 法条原文

> 第六百六十八条　借款合同应当采用书面形式，但是自然人之间借款另有约定的除外。借款合同的内容一般包括借款种类、币种、用途、数额、利率、期限和还款方式等条款。

### 本条主旨

本条是关于借款合同形式的规定。

### 条文解读

| 主体 | 形式要求 |
|------|---------|
| 金融机构与借款人 | **应当采用书面形式** |
| 自然人之间 | 另有约定的除外——可为口头形式 |

借款合同的内容一般包括：借款种类、币种、用途、数额、利率、期限、还款方式等条款。

## 三、借款人的义务（第669条）

### 法条原文

> 第六百六十九条　订立借款合同，借款人应当按照贷款人的要求提供与借款有关的业务活动和财务状况的真实情况。贷款人按照约定可以检查、监督借款的使用情况。借款人应当按照约定向贷款人定期提供有关财务会计报表或者其他资料。

### 本条主旨

本条是关于借款人如实告知义务和接受监督义务的规定。

### 条文解读

| 借款人义务 | 内容 |
|----------|------|
| **如实告知义务** | 按照贷款人的要求提供与借款有关的业务活动和财务状况的真实情况 |
| **接受监督义务** | 贷款人按照约定可以检查、监督借款的使用情况 |
| **定期提供资料** | 按照约定向贷款人定期提供有关财务会计报表或者其他资料 |

## 四、贷款人的主要义务——交付借款（第670条）

### 法条原文

> 第六百七十条　借款的利息不得预先在本金中扣除。利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。

### 本条主旨

本条是关于借款利息不得预先扣除的规定（**禁止预扣利息/砍头息**）。

### 条文解读

**借款的利息不得预先在本金中扣除**——即禁止"砍头息"。

**违反后果**：利息预先在本金中扣除的，**应当按照实际借款数额返还借款并计算利息**。

## 五、借款人未按照约定收取借款的后果（第671条）

### 法条原文

> 第六百七十一条　贷款人未按照约定的日期、数额提供借款，造成借款人损失的，应当赔偿损失。

### 本条主旨

本条是关于贷款人未按约定提供借款的责任的规定。

### 条文解读

贷款人未按照约定的日期、数额提供借款，造成借款人损失的，应当**赔偿损失**——这是贷款人承担违约责任的体现。

## 六、借款人未按照约定用途使用借款的后果（第672条）

### 法条原文

> 第六百七十二条　贷款人按照约定检查、监督借款使用情况。借款人未按照约定的借款用途使用借款的，贷款人可以停止发放借款、提前收回借款或者解除合同。

### 本条主旨

本条是关于借款人擅自改变借款用途的法律后果的规定。

### 条文解读

借款人未按照约定的借款用途使用借款的，贷款人的救济：

| 救济措施 | 内容 |
|---------|------|
| **停止发放借款** | 尚未发放的部分停止发放 |
| **提前收回借款** | 已发放的部分提前收回 |
| **解除合同** | 解除借款合同 |

## 七、自然人借款合同的实践性（第673条）

### 法条原文

> 第六百七十三条　借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息。

### 本条主旨

本条是关于借款人逾期返还借款的违约责任的规定。

### 条文解读

借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定**支付逾期利息**——逾期利息的计算基准由当事人约定或国家规定。

### 适用指引

逾期利率标准可由当事人约定，但不得超过合同成立时一年期贷款市场报价利率四倍的限制（《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》）。

## 八、借款人支付利息的期限（第674条）

### 法条原文

> 第六百七十四条　借款人应当按照约定的期限支付利息。对支付利息的期限没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，借款期间不满一年的，应当在返还借款时一并支付；借款期间一年以上的，应当在每届满一年时支付，剩余期间不满一年的，应当在返还借款时一并支付。

### 本条主旨

本条是关于借款人支付利息期限的规定。

### 条文解读

| 借款期间 | 利息支付时间 |
|---------|------------|
| 约定支付期限 | 按约定 |
| 未约定 | 协议补充→交易习惯→ |
| 借款期间不满一年 | 在返还借款时一并支付 |
| 借款期间一年以上 | 每届满一年时支付，剩余期间不满一年的，在返还借款时一并支付 |

## 九、借款返还期限（第675条）

### 法条原文

> 第六百七十五条　借款人应当按照约定的期限返还借款。对借款期限没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，借款人可以随时返还；贷款人可以催告借款人在合理期限内返还。

### 本条主旨

本条是关于借款返还期限的规定。

### 条文解读

| 借款期限 | 返还时间 |
|---------|---------|
| 约定借款期限 | 按约定 |
| 未约定或约定不明确 | 协议补充→交易习惯→ |
| | 借款人可随时返还 |
| | 贷款人可催告在合理期限内返还 |

## 十、借款人逾期返还借款（第676条）

### 法条原文

> 第六百七十六条　借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息。

### 本条主旨

本条是关于借款人逾期返还借款的责任的规定。

### 条文解读

借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息——逾期利息可由当事人约定，但超过法律规定上限的部分不受保护。

## 十一、借款合同终止的处理（第677条）

### 法条原文

> 第六百七十七条　借款人提前返还借款的，除当事人另有约定外，应当按照实际借款的期间计算利息。

### 本条主旨

本条是关于借款人提前返还借款的规定。

### 条文解读

借款人提前返还借款的：
- **当事人另有约定的**：按约定
- **未约定**：按照实际借款的期间计算利息

## 十二、展期（第678条）

### 法条原文

> 第六百七十八条　借款人可以在还款期限届满前向贷款人申请展期。贷款人同意的，可以展期。

### 本条主旨

本条是关于借款展期的规定。

### 条文解读

| 步骤 | 内容 |
|------|------|
| 1. **申请** | 借款人可以在还款期限届满前向贷款人申请展期 |
| 2. **同意** | 贷款人同意的，可以展期 |

**注意**：展期须经贷款人同意——这是贷款人的权利，不是借款人的单方权利。

## 十三、借款人返还借款义务（第679条）

### 法条原文

> 第六百七十九条　自然人之间的借款合同，自贷款人提供借款时成立。

### 本条主旨

本条是关于自然人之间借款合同成立时间的规定。

### 条文解读

**自然人之间的借款合同，自贷款人提供借款时成立**——即自然人借款合同为**实践合同**，区别于金融机构借款合同的诺成性。

| 主体 | 合同性质 |
|------|---------|
| 金融机构与借款人 | 诺成合同（成立即生效） |
| 自然人之间 | **实践合同**（以交付为成立要件） |

## 十四、自然人借款利息的特别规定（第680条）

### 法条原文

> 第六百八十条　禁止高利放贷，借款的利息不得预先在本金中扣除。利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。

### 本条主旨

本条是关于禁止高利放贷的规定。

### 条文解读

**禁止高利放贷**——借款的利率不得违反国家有关规定。

| 规则 | 内容 |
|------|------|
| 禁止高利放贷 | 借款利率不得违反国家有关规定 |
| 禁止砍头息 | 利息不得预先在本金中扣除 |
| 违规后果 | 按实际借款数额返还借款并计算利息 |

### 适用指引

- 自然人之间的借款合同对支付利息没有约定或者约定不明确的，视为不支付利息
- 自然人之间约定利息的，利率不得超过合同成立时一年期贷款市场报价利率的四倍
- 超过部分的利息约定无效

## 章节总结（第十二章·借款合同）

本章共 14 条，规定借款合同制度：

1. **概念与形式**（第667-668条）：借款合同概念；金融机构借款合同应书面+自然人间另有约定除外
2. **借款人义务**（第669条）：如实告知+接受监督+定期提供资料
3. **贷款交付**（第670-671条）：禁止预扣利息；未按约定交付的赔偿损失
4. **借款用途**（第672条）：擅自改变用途的救济（停止发放+提前收回+解除）
5. **利息与逾期**（第673-676条）：逾期利息；支付期限；返还期限；借款人逾期返还
6. **提前还款与展期**（第677-678条）：提前还款按实际期间计算；展期须经贷款人同意
7. **自然人借款**（第679-680条）：实践合同性质；禁止高利放贷

**实务要点**：

- **金融机构借款合同为诺成合同**——双方意思表示一致即成立
- **自然人借款合同为实践合同**——以贷款人提供借款为成立要件
- **禁止砍头息**——利息不得预先在本金中扣除
- **禁止高利放贷**——超过国家规定利率上限的约定无效
- **未按用途使用的救济**——贷款人可停止发放/提前收回/解除合同
- **逾期利息**——可约定但不得超过国家规定上限
