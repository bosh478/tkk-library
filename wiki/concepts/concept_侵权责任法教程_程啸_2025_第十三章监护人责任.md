# 《侵权责任法教程》第十三章 监护人责任

| 字段 | 内容 |

| 核心议题 | 无/限制民事行为能力人致害时的监护人替代责任 |

## 🎯 核心论点

**监护人责任 = 替代责任 + 无过错责任**

**《民法典》第1188条第1款**：
> 无民事行为能力人、限制民事行为能力人造成他人损害的，由监护人承担侵权责任。监护人尽到监护职责的，可以减轻其侵权责任。

**重要规则**：
- **不能免责**——即使尽到监护职责也**只能减轻**
- **替代责任**——加害人是未成年人，责任人是监护人
- **被监护人有财产**的特殊处理

---

## 第一节 概述

## 一、概念、特征与规范目的

### 概念

**监护人责任** = 无/限制民事行为能力人造成他人损害时，**监护人**依法应当承担的侵权责任。

### 特征

**1. 无过错责任**
- 加害人致害时，无论监护人有无过错，均应承担责任
- 即使尽到监护职责，**只能减轻不能免除**
- 例外：被监护人因他人教唆、帮助而侵权时，监护人可证明尽到监护职责而不承担责任（《民法典》第1169条第2款第2句）

**2. 替代责任**
- 实施加害行为的人 = 被监护人
- 承担责任的人 = 监护人
- 被监护人有自己财产的，监护人**不能以**此为由主张补充责任
- 赔偿费用先从被监护人财产中支付（**可以**而非**必须**），不足部分由监护人支付

### 规范目的

**1. 保护被侵权人合法权益**
- 被监护人多无独立财产
- 由监护人代为承担责任可充分补偿被侵权人

**2. 预防侵权行为的发生**
- 督促监护人尽到管理和教育义务
- 减少被监护人实施侵权行为

---

## 二、归责原则

**无过错责任**（《民法典》第1188条）

**立法沿革**：
- 《民法通则》第133条：首次确立无过错责任
- 《侵权责任法》第32条：延续
- 《民法典》第1188条：再次确认

**理由**：
- 过错责任下监护人可免责 → 不利于受害人
- 《婚姻法》《治安管理处罚条例》均规定未成年人致害父母赔偿，未规定监护人尽到监护可免责
- 即使尽到监护，也只能减轻不能免除

**我国法的严苛性**：
- 不承认过错能力（责任能力）
- 被监护人有独立财产 → 法院可判从其财产中先支付
- 不足部分 → 监护人继续承担
- 即便尽到监护 → 只能减轻

## 第二节 构成要件

## 一、加害人

**无民事行为能力人**（《民法典》第20条）：
- 不满8周岁的未成年人
- 不能完全辨认自己行为的成年人
- （痴呆患者、精神病人等）

**限制民事行为能力人**（《民法典》第21条、第22条）：
- 8周岁以上不满18周岁的未成年人
- 不能完全辨认自己行为的成年人

## 二、加害行为

被监护人实施了侵害他人民事权益的行为。

**注意**：纯获益或与年龄、智力相适应的行为除外。

## 三、损害

被监护人的加害行为造成他人的人身、财产或其他民事权益损害。

## 四、因果关系

被监护人的加害行为与损害之间存在因果关系。

## 第三节 责任承担

## 一、监护人承担无过错责任

**《民法典》第1188条第1款**：
> 无民事行为能力人、限制民事行为能力人造成他人损害的，由监护人承担侵权责任。监护人尽到监护职责的，可以减轻其侵权责任。

## 二、尽到监护职责的法律效果

**可以减轻 ≠ 可以免除**

- 监护人证明自己尽到监护职责的
- 法院可以减轻其侵权责任
- 不能完全免除（除非教唆帮助情形）

## 三、被监护人有自己财产时的处理

**《民法典侵权责任编解释（一）》第5条**：

| 情形 | 处理 |
|------|------|
| 被监护人有自己财产 | 赔偿费用**可以**先从被监护人财产中支付 |
| 不足部分 | 由监护人继续承担 |
| 被监护人有自己财产 | 监护人**不得**主张只承担补充责任 |
| 法院判决 | 明确**先从被监护人财产中支付，不足部分由监护人支付** |

## 四、监护人尽到监护的举证责任

**举证责任**：监护人主张减轻责任的，应当举证证明自己尽到了监护职责。

**典型情形**：
- 进行了合理的安全教育
- 采取了必要的防护措施
- 知道侵权行为后及时制止
- 平时对被监护人管理得当

## 五、委托监护的情形

**委托监护** = 监护人将监护职责委托他人（如送孩子到亲戚家、学校）。

**委托监护的责任承担**：
- 原则上仍由监护人承担责任
- 受托人有过错的，承担相应责任
- 监护人未履行监护职责的，与受托人承担连带责任

---

## 第四节 教唆、帮助情形

## 一、行为人与责任人分离的特殊规则

**《民法典》第1169条**：

**情形1（教唆无/限制民事行为能力人）**：
> 教唆、帮助无民事行为能力人、限制民事行为能力人实施侵权行为的，由**教唆、帮助人**承担侵权责任。

**情形2（监护人尽到监护的免责）**：
> 监护人尽到监护职责的，可以减轻其侵权责任（教唆帮助情形下，可以**免除**监护人责任）。

## 二、教唆帮助的认定

| 情形 | 认定 |
|------|------|
| 教唆 | 怂恿、利诱未成年人实施侵权行为 |
| 帮助 | 提供工具、协助实施侵权行为 |

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **监护人责任** | 无/限制民事行为能力人致害时的监护人替代责任 |
| **替代责任** | 行为人与责任人分离的责任形态 |
| **尽到监护职责** | 监护人证明已尽合理教育管理义务的事实 |
| **教唆侵权** | 怂恿未成年人实施侵权 |
| **帮助侵权** | 提供工具或协助未成年人侵权 |
| **委托监护** | 监护人将监护职责委托他人 |
