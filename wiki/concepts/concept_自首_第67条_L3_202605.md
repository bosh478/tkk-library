# 自首(《刑法》第 67 条 · L3)

> 本页定位:自首 L3 概念页。**总则第 4 章量刑情节**的核心从轻/减轻制度,与立功、累犯紧密关联;**一般自首 + 特别自首 + 准自首**三类型。

## 一、法条原文(条文要点)

《刑法》第 67 条(自首):
> 犯罪以后自动投案,如实供述自己的罪行的,是自首。对于自首的犯罪分子,可以从轻或者减轻处罚。其中,犯罪较轻的,可以免除处罚。
> 被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯,如实供述司法机关还未掌握的本人其他罪行的,以自首论。
> 犯罪嫌疑人虽不具有前两款规定的自首情节,但是如实供述自己罪行的,可以从轻处罚;因其如实供述自己罪行,避免特别严重后果发生的,可以减轻处罚。

## 二、段级释解

### 1. 概念界定

自首 = 犯罪分子**犯罪后自动投案 + 如实供述自己罪行**的法定从宽情节。

三类型:
- **一般自首**(第 1 款):犯罪后自动投案
- **特别自首 / 准自首**(第 2 款):被采取强制措施后供述未掌握的其他罪行
- **坦白**(第 3 款):虽不自首,但如实供述(2020 修订新增)

### 2. 一般自首四构成要件(第 1 款)

(1) **时点要件**:犯罪**以后**(犯罪既遂后 / 犯罪未完成时)
- 犯罪中自首:也可成立(主动停止犯罪 + 投案)

(2) **自动投案要件**:
- 自动投案**+ 未被司法机关发觉**或**尚未被讯问**
- 主动投案的形式:亲自投案 / 委托他人代为投案 / 电话投案 / 投案途中被捕获等
- 视为自动投案:亲友送去投案 / 在现场等待 / 主动报案等

(3) **如实供述要件**:
- **供述自己的罪行**(不是他人)
- **如实**:与客观事实基本一致(主要事实)
- 不能隐瞒主要犯罪事实 / 作虚假供述

(4) **自愿要件**:**主动投案**(非被迫)

### 3. 特别自首 / 准自首(第 2 款)

要件:
- **被采取强制措施**(拘传、拘留、逮捕、取保候审、监视居住)
- **正在服刑**
- **如实供述司法机关还未掌握的本人其他罪行**

「其他罪行」:**与已采取强制措施的罪行不同**(罪名或事实不同)

### 4. 坦白(第 3 款,2020 修订新增)

不成立自首 + 如实供述 → 坦白
- **可以从轻处罚**
- 避免特别严重后果发生 → **可以减轻处罚**

与自首的区别:
- 自首:**主动投案**(主动) + 如实供述
- 坦白:**被动**(被抓获后) + 如实供述

### 5. 自首的法律后果

(1) **可以从轻或减轻处罚**(法官酌情裁量)
(2) **犯罪较轻可以免除处罚**(第 1 款但书)

量刑考虑因素:
- 自首的**时点**(案发前/早期/晚期)
- 自首的**动机**(真诚悔罪/迫于压力/避重就轻)
- 自首的**内容**(全部供述/部分供述)
- **如实供述**的程度

## 三、实务问答(FAQ)

Q1:犯罪后潜逃多年后投案,是否构成自首?
**构成**。投案时点不影响自首成立,只要投案时如实供述。

Q2:投案后翻供,是否影响自首?
**影响**。如实供述是自首核心要件,翻供可能导致自首不成立。但**部分翻供**(对部分事实翻供)不影响其他事实的自首。

Q3:亲友送去投案,是否构成自动投案?
**构成**。《最高人民法院关于处理自首和立功具体应用法律若干问题的解释》明确「亲友送去投案」视为自动投案。

Q4:被采取强制措施后供述同种罪行,是否构成准自首?
**不构成**。准自首要求供述「**其他罪行**」(与已采取强制措施的罪行不同)。同种罪行属坦白。

Q5:单位犯罪的自首如何认定?
- 单位自首:**单位集体决定**或**负责人决定**代表单位投案
- 单位犯罪中**直接负责的主管人员**和**直接责任人员**自动投案 + 如实供述单位犯罪事实 → 单位自首
- 但**仅部分**人员投案 → 单位是否自首视情况而定

Q6:自首后立功,如何处理?
**综合考量**:
- 自首:可以从轻/减轻
- 立功:可以从轻/减轻(重大立功应当从轻/减轻)
- 两者可以同时适用

Q7:对自首的从宽幅度?
**司法实践**:
- 一般自首:减 20-30%
- 重大自首(如揭发同案犯):减 30-50%
- 犯罪较轻自首:可免除处罚

Q8:犯罪后自杀未遂再投案,是否构成自首?
**构成**(主流观点)。自杀未遂**不影响**自动投案的事实认定。

Q9:网上发声明认罪是否构成自首?
**视情况**:
- 公开声明 + 接受公安机关讯问时如实供述 → 构成
- 仅有声明 + 不到案 → 不构成(未实际投案)

Q10:自首与立功的竞合?
两者**可同时适用**:自首(投案) + 立功(供述他人犯罪 / 揭发同案犯)。综合考量,司法实践通常**总从宽幅度更大**。
