## 核心制度深度解读

### 一、股东会的组成与性质（第36条）

**条文原文**：有限责任公司股东会由全体股东组成。股东会是公司的权力机构，依照本法行使职权。

**股东会的法律地位**：

| 维度 | 内容 |
|------|------|
| 组成 | 由全体股东组成（含原始股东和继受股东） |
| 性质 | 公司的权力机构 |
| 行权方式 | 会议形式，不采取常设机构或日常办公方式 |
| 与董事会、监事会关系 | 区别于执行机构，不执行日常业务；区别于监督机构和咨询机构 |

**股东的身份界定**：

| 类型 | 取得方式 |
|------|----------|
| 原始股东 | 公司设立时因出资筹办公司或认缴公司资本，随公司成立而成为公司股东 |
| 继受股东 | 因受让、继承、遗赠、共同财产分割、公司合并、认缴公司新增资本等方式取得原始股东的出资或向公司出资而成为公司的股东 |

**股东会行使职权的法定原则**：公司的一切重大决策和其他重大事项，必须依照法律规定，由股东会按照少数表决权服从多数表决权的原则作出决议。

### 二、股东会的十一项职权（第37条）

**条文原文**：股东会行使下列职权：（一）决定公司的经营方针和投资计划；（二）选举和更换非由职工代表担任的董事、监事，决定有关董事、监事的报酬事项；（三）审议批准董事会的报告；（四）审议批准监事会或者监事的报告；（五）审议批准公司的年度财务预算方案、决算方案；（六）审议批准公司的利润分配方案和弥补亏损方案；（七）对公司增加或者减少注册资本作出决议；（八）对发行公司债券作出决议；（九）对公司合并、分立、解散、清算或者变更公司形式作出决议；（十）修改公司章程；（十一）公司章程规定的其他职权。

对前款所列事项股东以书面形式一致表示同意的，可以不召开股东会会议，直接作出决定，并由全体股东在决定文件上签名、盖章。

**职权的六大类归纳**：

| 类别 | 内容 |
|------|------|
| 1. 投资经营决定权 | 决定公司的经营方针和投资计划 |
| 2. 人事决定权 | 选举和更换非由职工代表担任的董事、监事，决定有关董事、监事的报酬事项 |
| 3. 重大事项审批权 | 审议批准董事会、监事会或者监事的报告；审议批准年度财务预算方案、决算方案、利润分配方案和弥补亏损方案 |
| 4. 重大事项决议权 | 对公司增加或者减少注册资本、发行公司债券、合并、分立、解散、清算或者变更公司形式作出决议 |
| 5. 公司章程修改权 | 修改公司章程（须经代表2/3以上表决权的股东通过） |
| 6. 其他职权 | 公司章程规定的其他职权 |

**股东会决议不成立的五种情形**（《公司法规定（四）》第5条）：

| 情形 | 内容 |
|------|------|
| 1 | 公司未召开会议的（但依据《公司法》第37条第2款或者公司章程规定可以不召开股东会或者股东大会而直接作出决定，并由全体股东在决定文件上签名、盖章的除外） |
| 2 | 会议未对决议事项进行表决的 |
| 3 | 出席会议的人数或者股东所持表决权不符合公司法或者公司章程规定的 |
| 4 | 会议的表决结果未达到公司法或者公司章程规定的通过比例的 |
| 5 | 导致决议不成立的其他情形 |

**股东会行使职权的两种方式**：

| 方式 | 条件 |
|------|------|
| 召开股东会会议作出决定 | 一般情况 |
| 不召开会议直接作出决定 | 全体股东以书面形式一致表示同意，并由全体股东在决定文件上签名、盖章 |

### 三、首次股东会会议（第38条）

**条文原文**：首次股东会会议由出资最多的股东召集和主持，依照本法规定行使职权。

**理解要点**：

| 要点 | 内容 |
|------|------|
| 召集和主持人 | 出资最多的股东 |
| 召开会议 | 应当于首次会议召开15日以前，由出资最多的股东通知全体股东 |
| 会议记录 | 出席首次会议的股东应当在会议记录上签名 |
| 职权行使 | 决定公司经营方针和投资计划；选举董事、监事；决定董事、监事的报酬事项等 |

### 四、股东会会议的种类（第39条）

**条文原文**：股东会会议分为定期会议和临时会议。定期会议应当依照公司章程的规定按时召开。代表十分之一以上表决权的股东，三分之一以上的董事，监事会或者不设监事会的公司的监事提议召开临时会议的，应当召开临时会议。

**两类股东会会议**：

| 类型 | 内容 |
|------|------|
| 定期会议 | 依照公司章程规定在一定时期内必须召开的会议；每个营业年度终了后必须召开一次年会 |
| 临时会议 | 公司章程中没有明确规定什么时间召开的一种不定期的会议 |

**提议召开临时会议的三类主体**：

| 主体 | 提议比例 |
|------|----------|
| 股东 | 代表1/10以上表决权的股东（包括合计拥有1/10以上表决权的股东） |
| 董事 | 1/3以上董事 |
| 监督机构 | 监事会或者不设监事会的公司的监事 |

**强制性**：法定人员依法提议召开股东会临时会议的，「应当」召集临时会议，即必须召开临时会议，否则即违反法律规定。

**条文演变**：2005年将原规定修改为「提议召开临时会议的，应当召开临时会议」，明确了有法定提议权的人提议召开临时会议后，必须召开临时会议；同时将股东表决权比例从1/4以上降低到1/10以上。

### 五、股东会会议的召集与主持（第40条）

**条文原文**：有限责任公司设立董事会的，股东会会议由董事会召集，董事长主持；董事长不能履行职务或者不履行职务的，由副董事长主持；副董事长不能履行职务或者不履行职务的，由半数以上董事共同推举一名董事主持。有限责任公司不设董事会的，股东会会议由执行董事召集和主持。董事会或者执行董事不能履行或者不履行召集股东会会议职责的，由监事会或者不设监事会的公司的监事召集和主持；监事会或者监事不召集和主持的，代表十分之一以上表决权的股东可以自行召集和主持。

**召集与主持的层级顺位**：

| 顺位 | 召集 | 主持 |
|------|------|------|
| 第一 | 董事会 | 董事长 |
| 第二 | 董事会 | 副董事长（董事长不能或者不履行职务时） |
| 第三 | 董事会 | 半数以上董事共同推举一名董事（副董事长不能或者不履行职务时） |
| 第四 | 执行董事 | 执行董事（不设董事会时） |
| 第五 | 监事会或者监事 | 监事会或者监事（董事会或者执行董事不能或者不履行召集职责时） |
| 第六 | 代表1/10以上表决权的股东 | 代表1/10以上表决权的股东（监事会或者监事不召集和主持时） |

**适用指引**（《九民纪要》第29条）：公司召开股东（大）会本质上属于公司内部治理范围。股东请求判令公司召开股东（大）会的，人民法院应当告知其按照《公司法》第40条或者第101条规定的程序自行召开。股东坚持起诉的，人民法院应当裁定不予受理；已经受理的，裁定驳回起诉。

### 六、通知与会议记录（第41条）

**条文原文**：召开股东会会议，应当于会议召开十五日前通知全体股东；但是，公司章程另有规定或者全体股东另有约定的除外。股东会应当对所议事项的决定作成会议记录，出席会议的股东应当在会议记录上签名。

**通知的两项要求**：

| 要求 | 内容 |
|------|------|
| 时间 | 提前15日（章程另有规定或全体股东另有约定的除外） |
| 范围 | 必须通知全体股东，不能只通知部分股东 |

**会议记录的法律意义**：

| 意义 | 内容 |
|------|------|
| 对内 | 公司登记机关、法院以及仲裁机关处理股东间权益纠纷的依据 |
| 对外 | 上述有关机关判断公司的行为能力以及公司行为是否存在违反《公司法》规定的依据 |
| 完整性 | 连同公司其他财务会计报告、清算报告等，未逾法律规定期限，不得销毁 |

### 七、股东表决权（第42条）

**条文原文**：股东会会议由股东按照出资比例行使表决权；但是，公司章程另有规定的除外。

**表决权行使的两种依据**：

| 依据 | 内涵 |
|------|------|
| 出资比例 | 体现资本的本质，是世界各国通行的做法；以股东平等原则为基本指导思想 |
| 公司章程 | 可以作出不以出资比例行使表决权的规定（如以股东人数行使表决权等） |

**适用指引**（《九民纪要》第7条）：股东认缴的出资未届履行期限，对未缴纳部分的出资是否享有以及如何行使表决权等问题，应当根据公司章程来确定。公司章程没有规定的，应当按照认缴出资的比例确定。如果股东（大）会作出不按认缴出资比例而按实际出资比例或者其他标准确定表决权的决议，股东请求确认决议无效的，人民法院应当审查该决议是否符合修改公司章程所要求的表决程序，即必须经代表2/3以上表决权的股东通过。符合的，人民法院不予支持；反之，则依法予以支持。

### 八、议事方式与表决程序（第43条）

**条文原文**：股东会的议事方式和表决程序，除本法有规定的外，由公司章程规定。股东会会议作出修改公司章程、增加或者减少注册资本的决议，以及公司合并、分立、解散或者变更公司形式的决议，必须经代表三分之二以上表决权的股东通过。

**两类股东会决议**：

| 类型 | 通过比例 | 事项 |
|------|----------|------|
| 普通决议 | 代表1/2以上表决权的股东通过 | 公司一般事项 |
| 特别决议 | 代表2/3以上表决权的股东通过 | ① 修改公司章程；② 增加或者减少注册资本；③ 合并、分立、解散；④ 变更公司形式 |

**特别决议的强制性**：《公司法》对股东会特别决议的表决程序的规定是强制性规定，公司章程不得作出与此不一致的规定。公司章程只能重复记载此类特别决议的表决程序，否则无效。

**公司章程变更的三原则**：

| 原则 | 内容 |
|------|------|
| 不违法原则 | 公司章程变更的内容不得与法律、行政法规相抵触，不得违背公序良俗 |
| 不损害股东利益原则 | 不得违反股东平等原则和侵害股东合法权益 |
| 不损害债权人利益原则 | 如公司减资、合并分立等可能影响公司的偿债能力 |

### 九、董事会的组成（第44条）

**条文原文**：有限责任公司设董事会，其成员为三人至十三人；但是，本法第五十条另有规定的除外。两个以上的国有企业或者两个以上的其他国有投资主体投资设立的有限责任公司，其董事会成员中应当有公司职工代表；其他有限责任公司董事会成员中可以有公司职工代表。董事会中的职工代表由公司职工通过职工代表大会、职工大会或者其他形式民主选举产生。董事会设董事长一人，可以设副董事长。董事长、副董事长的产生办法由公司章程规定。

**董事会组成的三要素**：

| 要素 | 内容 |
|------|------|
| 人数 | 3-13人；通常为单数，防止决议僵局 |
| 职工董事 | 两个以上国有投资主体的公司必须有职工代表；其他公司可以有 |
| 董事长 | 设1人；可设副董事长；产生办法由公司章程规定 |

**董事长的法律地位演变**：2005年《公司法》修订时取消了原条文「董事长为公司的法定代表人」的强制性规定，确立法定代表人由公司章程规定的原则。

### 十、董事任期（第45条）

**条文原文**：董事任期由公司章程规定，但每届任期不得超过三年。董事任期届满，连选可以连任。董事任期届满未及时改选，或者董事在任期内辞职导致董事会成员低于法定人数的，在改选出的董事就任前，原董事仍应当依照法律、行政法规和公司章程的规定，履行董事职务。

**董事与公司的法律关系**：

| 观点 | 内涵 |
|------|------|
| 劳动合同关系说 | 董事履行公司与其约定的职权，接受公司的雇佣，由公司发放劳动报酬 |
| 委任关系说 | 股东会委任其为董事会成员并赋予相应职权（最高人民法院生效判决采纳的观点） |

**股东会的董事任意解除权**（《公司法规定（五）》第3条）：董事任期届满前被股东会或者股东大会有效决议解除职务，其主张解除不发生法律效力的，人民法院不予支持。董事职务被解除后，因补偿与公司发生纠纷提起诉讼的，人民法院应当依据法律、行政法规、公司章程的规定或者合同的约定，综合考虑解除的原因、剩余任期、董事薪酬等因素，确定是否补偿以及补偿的合理数额。

**职工董事的罢免**：职工董事由职工代表大会或职工大会等通过民主选举的方式产生，股东会无权任意解除职工董事的职务。若发生违反公司章程、不履行或怠于履行董事职责等情形，应当通过召开职工代表大会或职工大会等方式的罢免程序进行罢免。

### 十一、董事会的十一项职权（第46条）

**条文原文**：董事会对股东会负责，行使下列职权：（一）召集股东会会议，并向股东会报告工作；（二）执行股东会的决议；（三）决定公司的经营计划和投资方案；（四）制订公司的年度财务预算方案、决算方案；（五）制订公司的利润分配方案和弥补亏损方案；（六）制订公司增加或者减少注册资本以及发行公司债券的方案；（七）制订公司合并、分立、解散或者变更公司形式的方案；（八）决定公司内部管理机构的设置；（九）决定聘任或者解聘公司经理及其报酬事项，并根据经理的提名决定聘任或者解聘公司副经理、财务负责人及其报酬事项；（十）制定公司的基本管理制度；（十一）公司章程规定的其他职权。

**职权的五大类别**：

| 类别 | 内容 |
|------|------|
| 召集执行权 | 召集股东会会议，并向股东会报告工作；执行股东会的决议 |
| 宏观决策权 | 决定公司的经营计划和投资方案 |
| 经营管理权 | 制订年度财务预算方案、决算方案；制订利润分配方案和弥补亏损方案；制订增加或者减少注册资本以及发行公司债券的方案；制订合并、分立、解散或者变更公司形式的方案 |
| 机构与人事管理权 | 决定公司内部管理机构的设置；决定聘任或者解聘公司经理及其报酬事项，并根据经理的提名决定聘任或者解聘公司副经理、财务负责人及其报酬事项 |
| 管理制度权 | 制定公司的基本管理制度；公司章程规定的其他职权 |

**适用指引**（盈余分配原则）：公司利润分配方案的制订权在公司的董事会或不设董事会的执行董事。对于董事会或执行董事所提出的公司利润分配方案的批准权，则在公司的股东会。公司股利是否分配以及分配的数额，原则上属于公司自治和股东自治的范围，司法权不能干预股东会的这一权利，当董事会或执行董事未制订利润分配方案且未经公司股东会批准通过时，股东不能请求法院强制公司分配股利。

### 十二、董事会会议的召集与主持（第47条）

**条文原文**：董事会会议由董事长召集和主持；董事长不能履行职务或者不履行职务的，由副董事长召集和主持；副董事长不能履行职务或者不履行职务的，由半数以上董事共同推举一名董事召集和主持。

**召集和主持的顺位**：

| 顺位 | 召集和主持人 |
|------|--------------|
| 第一 | 董事长 |
| 第二 | 副董事长（董事长不能或者不履行职务时） |
| 第三 | 半数以上董事共同推举一名董事（副董事长不能或者不履行职务时） |

**「半数以上董事」的认定**：是指董事会全体成员的半数以上，并非到会董事成员的半数以上。

### 十三、董事会的议事方式与表决程序（第48条）

**条文原文**：董事会的议事方式和表决程序，除本法有规定的外，由公司章程规定。董事会应当对所议事项的决定作成会议记录，出席会议的董事应当在会议记录上签名。董事会决议的表决，实行一人一票。

**一人一票的强制性**：董事会决议的表决，实行一人一票制，即包括董事长、副董事长在内的董事会全体成员，每人只有一票的投票权，彼此之间不存在投票权大小的差别。

**会议记录的重要性**：

| 维度 | 作用 |
|------|------|
| 监督凭据 | 股东或监事查阅知情的凭据 |
| 责任依据 | 在公司受到损失或发生纠纷时，认定各董事是否出现判断错误、失职、免责等的依据 |
| 决议免责 | 决议中持异议的董事可以免责 |

### 十四、经理的设立与职权（第49条）

**条文原文**：有限责任公司可以设经理，由董事会决定聘任或者解聘。经理对董事会负责，行使下列职权：（一）主持公司的生产经营管理工作，组织实施董事会决议；（二）组织实施公司年度经营计划和投资方案；（三）拟订公司内部管理机构设置方案；（四）拟订公司的基本管理制度；（五）制定公司的具体规章；（六）提请聘任或者解聘公司副经理、财务负责人；（七）决定聘任或者解聘除应由董事会决定聘任或者解聘以外的负责管理人员；（八）董事会授予的其他职权。公司章程对经理职权另有规定的，从其规定。经理列席董事会会议。

**经理职权的四大方面**：

| 方面 | 内容 |
|------|------|
| 组织经营权 | 主持生产经营管理工作；组织实施董事会决议；组织实施年度经营计划和投资方案 |
| 公司内部规章的拟订、制定权 | 拟订公司内部管理机构设置方案；拟订基本管理制度；制定具体规章 |
| 人事任免权 | 提请聘任或解聘副经理、财务负责人；决定聘任或解聘其他负责管理人员 |
| 其他职权 | 董事会授予的其他职权；公司章程另有规定的从其规定 |

**经理的法律地位**：经理列席董事会会议，以便更好地理解董事会决议的意图，更准确地执行董事会的决议。

### 十五、执行董事（第50条）

**条文原文**：股东人数较少或者规模较小的有限责任公司，可以设一名执行董事，不设董事会。执行董事可以兼任公司经理。执行董事的职权由公司章程规定。

**执行董事的设立条件**：股东人数较少或者规模较小的有限责任公司，可以不设董事会，而只设一名执行董事。

**执行董事的法律地位**：

| 维度 | 内容 |
|------|------|
| 与董事会关系 | 法律地位相同，是公司的执行机关和业务决策机关，对股东会负责 |
| 兼任经理 | 执行董事可以兼任公司经理（业务决策机构和执行机构合并） |
| 职权来源 | 由公司章程规定，不完全相同于董事会的职权 |

### 十六、监事会的组成（第51条）

**条文原文**：有限责任公司设监事会，其成员不得少于三人。股东人数较少或者规模较小的有限责任公司，可以设一至二名监事，不设监事会。监事会应当包括股东代表和适当比例的公司职工代表，其中职工代表的比例不得低于三分之一，具体比例由公司章程规定。监事会中的职工代表由公司职工通过职工代表大会、职工大会或者其他形式民主选举产生。监事会设主席一人，由全体监事过半数选举产生。监事会主席召集和主持监事会会议；监事会主席不能履行职务或者不履行职务的，由半数以上监事共同推举一名监事召集和主持监事会会议。董事、高级管理人员不得兼任监事。

**监事会的四个核心要素**：

| 要素 | 内容 |
|------|------|
| 人数 | 监事会成员不得少于3人；股东人数较少或者规模较小的，可以设1-2名监事，不设监事会 |
| 组成结构 | 股东代表和适当比例的公司职工代表（职工代表比例不低于1/3，具体比例由公司章程规定） |
| 监事会主席 | 由全体监事过半数选举产生；召集和主持监事会会议；不能或者不履行职务时，由半数以上监事共同推举一名监事 |
| 兼任禁止 | 董事、高级管理人员不得兼任监事 |

**职工监事的产生**：监事会中的职工代表由公司职工通过职工代表大会、职工大会或者其他形式民主选举产生，不能由股东会选举产生。

**适用指引**（决议效力瑕疵）：有限责任公司监事会中的职工代表监事应当具有该公司职工的身份，职工代表监事的产生方式应符合《公司法》第51条规定的职工民主选举产生的程序，并符合该条规定的代表比例。公司股东会作出任命职工代表监事的决议，如果该被任命监事并非本公司职工，或该被任命监事的产生程序、代表比例违反《公司法》第51条规定的，该部分决议内容应属无效。

### 十七、监事任期（第52条）

**条文原文**：监事的任期每届为三年。监事任期届满，连选可以连任。监事任期届满未及时改选，或者监事在任期内辞职导致监事会成员低于法定人数的，在改选出的监事就任前，原监事仍应当依照法律、行政法规和公司章程的规定，履行监事职务。

**与董事任期的比较**：

| 主体 | 任期规定 |
|------|----------|
| 董事 | 由公司章程规定，每届不得超过3年 |
| 监事 | 每届固定为3年 |

**继续履职的两种情形**：

| 情形 | 内容 |
|------|------|
| 1 | 监事任期届满未及时改选，在改选出的监事就任前，原监事继续履职 |
| 2 | 监事在任期内辞职导致监事会成员低于法定人数的，在改选出的监事就任前，原监事继续履职 |

### 十八、监事会、监事的七项职权（第53条）

**条文原文**：监事会、不设监事会的公司的监事行使下列职权：（一）检查公司财务；（二）对董事、高级管理人员执行公司职务的行为进行监督，对违反法律、行政法规、公司章程或者股东会决议的董事、高级管理人员提出罢免的建议；（三）当董事、高级管理人员的行为损害公司的利益时，要求董事、高级管理人员予以纠正；（四）提议召开临时股东会会议，在董事会不履行本法规定的召集和主持股东会会议职责时召集和主持股东会会议；（五）向股东会会议提出提案；（六）依照本法第一百五十一条的规定，对董事、高级管理人员提起诉讼；（七）公司章程规定的其他职权。

**职权的七项内容**：

| 序号 | 职权 |
|------|------|
| 1 | 检查公司财务 |
| 2 | 对董事、高级管理人员执行公司职务的行为进行监督，对违反法律、行政法规、公司章程或者股东会决议的董事、高级管理人员提出罢免的建议 |
| 3 | 当董事、高级管理人员的行为损害公司的利益时，要求董事、高级管理人员予以纠正 |
| 4 | 提议召开临时股东会会议；在董事会不履行本法规定的召集和主持股东会会议职责时召集和主持股东会会议 |
| 5 | 向股东会会议提出提案 |
| 6 | 依照本法第一百五十一条的规定，对董事、高级管理人员提起诉讼 |
| 7 | 公司章程规定的其他职权 |

**代表诉讼的原告**（《公司法规定（四）》第23条）：监事会或者不设监事会的有限责任公司的监事依据《公司法》第151条第1款规定对董事、高级管理人员提起诉讼的，应当列公司为原告，依法由监事会主席或者不设监事会的有限责任公司的监事代表公司进行诉讼。

### 十九、监事的列席权与特别调查权（第54条）

**条文原文**：监事可以列席董事会会议，并对董事会决议事项提出质询或者建议。监事会、不设监事会的公司的监事发现公司经营情况异常，可以进行调查；必要时，可以聘请会计师事务所等协助其工作，费用由公司承担。

**监事的列席与质询权**：

| 维度 | 内容 |
|------|------|
| 列席性质 | 法律赋予监事的一项权利，董事会应当予以保障，在召开董事会会议前，应当及时通知监事列席会议 |
| 质询建议权 | 监事在列席董事会会议时，有权对董事会决议事项提出质询或者建议 |
| 不参与决策 | 监事列席董事会会议，但并不参与公司的决策决议及日常经营管理 |

**特别调查权**：

| 维度 | 内容 |
|------|------|
| 启动条件 | 发现公司经营情况异常 |
| 调查方式 | 查阅公司财务文件，对董事、高级管理人员进行询问，要求其对某一具体事项进行说明 |
| 协助机构 | 必要时，可以聘请会计师事务所等协助其工作 |
| 费用承担 | 由公司承担 |

### 二十、监事会会议制度（第55条）

**条文原文**：监事会每年度至少召开一次会议，监事可以提议召开临时监事会会议。监事会的议事方式和表决程序，除本法有规定的外，由公司章程规定。监事会决议应当经半数以上监事通过。监事会应当对所议事项的决定作成会议记录，出席会议的监事应当在会议记录上签名。

**监事会会议的四个核心规则**：

| 规则 | 内容 |
|------|------|
| 定期会议 | 每年度至少召开一次（强制性规定，公司不能通过章程等方式予以变更） |
| 临时会议 | 监事可以提议召开临时监事会会议 |
| 决议通过 | 监事会决议应当经半数以上监事通过（强制性规定，公司章程不得规定更宽松的通过比例） |
| 会议记录 | 监事会应当对所议事项的决定作成会议记录，出席会议的监事应当在会议记录上签名 |

**「半数以上监事」的认定**：是指全部监事的半数，并非出席监事会会议的监事过半数通过。

### 二十一、监事会行使职权的费用（第56条）

**条文原文**：监事会、不设监事会的公司的监事行使职权所必需的费用，由公司承担。

**费用范围的认定**：

| 必要费用 | 内容 |
|----------|------|
| 财务审计费 | 检查公司财务时聘请会计师事务所的报酬 |
| 调查费 | 行使调查权时聘请相关专业人员的报酬 |
| 会议经费 | 召集和主持股东会会议的经费 |
| 诉讼费用 | 依法对董事、高级管理人员提起诉讼的费用 |
| 律师代理费 | 聘请律师代理的费用 |

**适用指引**（律师费的承担）：公司监事代表公司提起损害公司利益诉讼，属监事行使监事的职权，履行监事职责所必需的费用，应当由公司承担。因提起诉讼所支出的律师代理费应当属于该必需的费用范围，但关于风险代理服务费超出合理、必需的限度，不应当由公司承担。

## ⚠️ 司法适用难点

### 难点一：股东会决议「不成立」与「无效」「可撤销」的区分

**三类效力瑕疵的区分**：

| 类型 | 法律依据 | 法律后果 |
|------|----------|----------|
| 不成立 | 《公司法规定（四）》第5条 | 自始不成立 |
| 无效 | 《公司法》第22条第1款（内容违反法律、行政法规） | 自始无效 |
| 可撤销 | 《公司法》第22条第2款（程序违法/违章；内容违章） | 60日内请求撤销 |

**典型情形**：
- 实际控制公司的个人股东虚构股东会议并作出股东会决议的，可认定该决议不成立（最高人民法院公报2007年第9期：张某某与江苏万华工贸发展有限公司案）
- 公司章程规定要形成董事会决议，必须不少于2/3董事表决通过方为有效，公司5名董事，只有3名投了赞成票，未达到公司章程规定的通过比例，董事会决议不能成立

### 难点二：董事职务的解除与补偿

**主流观点**（《公司法规定（五）》第3条）：

| 维度 | 内容 |
|------|------|
| 解除权 | 股东会或股东大会只要以有效的决议解除董事职务，不需要「正当理由」 |
| 董事长的解除 | 公司可以随时解除董事长的职务，董事长也可以随时辞职（公司与董事之间的合同关系产生的任意解除权） |
| 补偿 | 综合考虑解除的原因、剩余任期、董事薪酬等因素，确定是否补偿以及补偿的合理数额 |
| 职工董事 | 股东会无权任意解除职工董事的职务 |

### 难点三：股东会决议撤销之诉的60日期限与轻微瑕疵例外

**60日除斥期间**：股东自决议作出之日起60日内请求人民法院撤销，逾期撤销权消灭。

**轻微瑕疵例外**（《公司法规定（四）》第4条）：股东请求撤销股东会或者股东大会、董事会决议，符合《民法典》第85条、《公司法》第22条第2款规定的，人民法院应当予以支持，但会议召集程序或者表决方式仅有轻微瑕疵，且对决议未产生实质影响的，人民法院不予支持。

**案例**：吕某于2013年4月20日召集的股东会由于表决权达不到出资比例未形成有效的股东会决议，王某某于2013年4月21日召集的股东会已形成决议，虽然该股东会在召集程序上存在违反法律规定及公司章程之处，但吕某并未在决议作出之日起60日内申请撤销该临时股东会决议，因此该决议应为有效。

### 难点四：监事会代表诉讼的当事人确定

**主流观点**（《公司法规定（四）》第23条）：

| 诉讼类型 | 原告 | 诉讼代表人 |
|----------|------|------------|
| 监事会或监事依据第151条第1款对董事、高级管理人员提起诉讼 | 公司 | 监事会主席或者不设监事会的有限责任公司的监事 |
| 董事会或执行董事依据第151条第1款对监事提起诉讼 | 公司 | 董事长或者执行董事 |
| 董事会或执行董事依据第151条第3款对他人提起诉讼 | 公司 | 董事长或者执行董事 |

**前置程序**（《公司法》第151条）：股东可以书面请求监事会或者不设监事会的有限责任公司的监事向人民法院提起诉讼。监事会、不设监事会的有限责任公司监事收到前款规定的股东书面请求后拒绝提起诉讼，或者自收到请求之日起30日内未提起诉讼，或者情况紧急、不立即提起诉讼将会使公司利益受到难以弥补的损害的，前款规定的股东有权为了公司的利益以自己的名义直接向人民法院提起诉讼。

**例外情形**：公司执行董事、监事是公司控股股东一方所委派，与控股股东的利益趋同，不具备独立性。在公司小股东与公司的执行董事、监事及控股股东利益主张相悖的情况下，股东可以未经《公司法》规定的前置程序而直接提起股东代表诉讼。

### 难点五：未届期出资的表决权与利润分配

**主流观点**（九民纪要第7条）：

| 维度 | 内容 |
|------|------|
| 表决权 | 股东认缴的出资未届履行期限，对未缴纳部分的出资是否享有以及如何行使表决权，根据公司章程确定；章程没有规定的，按认缴出资的比例确定 |
| 决议效力审查 | 股东（大）会作出不按认缴出资比例而按实际出资比例或者其他标准确定表决权的决议，股东请求确认决议无效的，审查是否符合修改公司章程所要求的表决程序（2/3以上表决权通过） |

## ❓ 实务问答

> **Q1：股东会的性质是什么？**
>
> A：股东会由全体股东组成，是公司的权力机构。股东会是依照《公司法》和公司章程的规定设立的，由全体股东共同组成的，对公司经营管理和各种涉及公司及股东利益的事项拥有最高决策权的机构（第36条）。

> **Q2：股东会行使哪些职权？**
>
> A：股东会行使11项职权，包括：① 决定公司的经营方针和投资计划；② 选举和更换非由职工代表担任的董事、监事，决定有关董事、监事的报酬事项；③ 审议批准董事会的报告；④ 审议批准监事会或者监事的报告；⑤ 审议批准公司的年度财务预算方案、决算方案；⑥ 审议批准公司的利润分配方案和弥补亏损方案；⑦ 对公司增加或者减少注册资本作出决议；⑧ 对发行公司债券作出决议；⑨ 对公司合并、分立、解散、清算或者变更公司形式作出决议；⑩ 修改公司章程；⑪ 公司章程规定的其他职权（第37条）。

> **Q3：全体股东以书面形式一致同意的，可以不召开股东会会议吗？**
>
> A：可以。对前款所列事项股东以书面形式一致表示同意的，可以不召开股东会会议，直接作出决定，并由全体股东在决定文件上签名、盖章（第37条第2款）。

> **Q4：首次股东会会议由谁召集和主持？**
>
> A：首次股东会会议由出资最多的股东召集和主持，依照本法规定行使职权（第38条）。

> **Q5：哪些主体可以提议召开临时股东会会议？**
>
> A：代表十分之一以上表决权的股东，三分之一以上的董事，监事会或者不设监事会的公司的监事提议召开临时会议的，应当召开临时会议（第39条第2款）。

> **Q6：股东会会议的召集和主持顺位如何确定？**
>
> A：设立董事会的，由董事会召集，董事长主持；董事长不能履行职务或者不履行职务的，由副董事长主持；副董事长不能履行职务或者不履行职务的，由半数以上董事共同推举一名董事主持。不设董事会的，由执行董事召集和主持。董事会或者执行董事不能履行或者不履行召集股东会会议职责的，由监事会或者不设监事会的公司的监事召集和主持；监事会或者监事不召集和主持的，代表十分之一以上表决权的股东可以自行召集和主持（第40条）。

> **Q7：召开股东会会议的提前通知期限是多少？**
>
> A：召开股东会会议，应当于会议召开十五日前通知全体股东；但是，公司章程另有规定或者全体股东另有约定的除外（第41条第1款）。

> **Q8：股东表决权如何行使？**
>
> A：股东会会议由股东按照出资比例行使表决权；但是，公司章程另有规定的除外（第42条）。

> **Q9：哪些股东会决议必须经代表2/3以上表决权的股东通过？**
>
> A：股东会会议作出修改公司章程、增加或者减少注册资本的决议，以及公司合并、分立、解散或者变更公司形式的决议，必须经代表三分之二以上表决权的股东通过（第43条第2款）。

> **Q10：有限责任公司董事会的组成人数是多少？**
>
> A：有限责任公司设董事会，其成员为三人至十三人；但是，本法第五十条另有规定的除外。董事会设董事长一人，可以设副董事长。董事长、副董事长的产生办法由公司章程规定（第44条）。

> **Q11：哪些有限责任公司必须有职工董事？**
>
> A：两个以上的国有企业或者两个以上的其他国有投资主体投资设立的有限责任公司，其董事会成员中应当有公司职工代表；其他有限责任公司董事会成员中可以有公司职工代表。董事会中的职工代表由公司职工通过职工代表大会、职工大会或者其他形式民主选举产生（第44条第2款）。

> **Q12：董事任期是如何规定的？**
>
> A：董事任期由公司章程规定，但每届任期不得超过三年。董事任期届满，连选可以连任。董事任期届满未及时改选，或者董事在任期内辞职导致董事会成员低于法定人数的，在改选出的董事就任前，原董事仍应当依照法律、行政法规和公司章程的规定，履行董事职务（第45条）。

> **Q13：股东会可以无因解除董事职务吗？**
>
> A：根据《公司法规定（五）》第3条，董事任期届满前被股东会或者股东大会有效决议解除职务，其主张解除不发生法律效力的，人民法院不予支持。董事职务被解除后，因补偿与公司发生纠纷提起诉讼的，人民法院应当综合考虑解除的原因、剩余任期、董事薪酬等因素，确定是否补偿以及补偿的合理数额。

> **Q14：董事会有哪些职权？**
>
> A：董事会对股东会负责，行使下列11项职权：① 召集股东会会议，并向股东会报告工作；② 执行股东会的决议；③ 决定公司的经营计划和投资方案；④ 制订公司的年度财务预算方案、决算方案；⑤ 制订公司的利润分配方案和弥补亏损方案；⑥ 制订公司增加或者减少注册资本以及发行公司债券的方案；⑦ 制订公司合并、分立、解散或者变更公司形式的方案；⑧ 决定公司内部管理机构的设置；⑨ 决定聘任或者解聘公司经理及其报酬事项，并根据经理的提名决定聘任或者解聘公司副经理、财务负责人及其报酬事项；⑩ 制定公司的基本管理制度；⑪ 公司章程规定的其他职权（第46条）。

> **Q15：董事会决议如何表决？**
>
> A：董事会决议的表决，实行一人一票（第48条第3款）。

> **Q16：股东人数较少或者规模较小的有限责任公司可以不设董事会吗？**
>
> A：可以。股东人数较少或者规模较小的有限责任公司，可以设一名执行董事，不设董事会。执行董事可以兼任公司经理。执行董事的职权由公司章程规定（第50条）。

> **Q17：监事会成员的最低人数是多少？**
>
> A：有限责任公司设监事会，其成员不得少于三人。股东人数较少或者规模较小的有限责任公司，可以设一至二名监事，不设监事会（第51条第1款）。

> **Q18：监事会中的职工代表比例是多少？**
>
> A：监事会应当包括股东代表和适当比例的公司职工代表，其中职工代表的比例不得低于三分之一，具体比例由公司章程规定。监事会中的职工代表由公司职工通过职工代表大会、职工大会或者其他形式民主选举产生（第51条第2款）。

> **Q19：监事可以兼任董事吗？**
>
> A：董事、高级管理人员不得兼任监事（第51条第4款）。

> **Q20：监事任期如何规定？**
>
> A：监事的任期每届为三年。监事任期届满，连选可以连任。监事任期届满未及时改选，或者监事在任期内辞职导致监事会成员低于法定人数的，在改选出的监事就任前，原监事仍应当依照法律、行政法规和公司章程的规定，履行监事职务（第52条）。

> **Q21：监事会行使哪些职权？**
>
> A：监事会行使7项职权：① 检查公司财务；② 对董事、高级管理人员执行公司职务的行为进行监督，对违反法律、行政法规、公司章程或者股东会决议的董事、高级管理人员提出罢免的建议；③ 当董事、高级管理人员的行为损害公司的利益时，要求董事、高级管理人员予以纠正；④ 提议召开临时股东会会议，在董事会不履行本法规定的召集和主持股东会会议职责时召集和主持股东会会议；⑤ 向股东会会议提出提案；⑥ 依照本法第151条的规定，对董事、高级管理人员提起诉讼；⑦ 公司章程规定的其他职权（第53条）。

> **Q22：监事会发现公司经营情况异常可以采取什么措施？**
>
> A：监事会、不设监事会的公司的监事发现公司经营情况异常，可以进行调查；必要时，可以聘请会计师事务所等协助其工作，费用由公司承担（第54条第2款）。

> **Q23：监事会会议每年至少召开几次？**
>
> A：监事会每年度至少召开一次会议，监事可以提议召开临时监事会会议。监事会决议应当经半数以上监事通过（第55条）。

> **Q24：监事会行使职权所必需的费用由谁承担？**
>
> A：监事会、不设监事会的公司的监事行使职权所必需的费用，由公司承担（第56条）。
