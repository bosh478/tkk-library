## 第一章 问题线索管理

## 第一节 问题线索的概念

### 一、基本定义

**问题线索** = 反映公职人员涉嫌违纪违法问题的初步材料 + 案件来源起点

### 二、问题线索办理要求

- **集中管理**
- **归口受理**
- **分级负责**
- **及时办理**

## 第二节 问题线索的受理与移送

### 一、问题线索来源

| 来源方式 | 内涵 |
|---------|------|
| **信访举报** | 群众来信、来访、网络举报 |
| **工作中发现** | 监督检查、审查调查中主动发现 |
| **移交转送** | 公安、检察、审判机关行政执法机关移送 |
| **主动投案** | 涉嫌违纪违法的公职人员主动交代 |

**问题线索材料的形式**：信访举报材料、移送材料、初步核实材料等

### 二、问题线索移送

**移送途径**：
- 横向移送（同级机关之间）
- 纵向移送（上下级机关之间）
- 跨地区跨部门移送

**移送要求**：及时、规范、有据可查

### 三、几类特殊人群问题线索的管辖主体

| 特殊人群 | 管辖主体 |
|---------|----------|
| **"双管"公职人员** | 一方为主，另一方协管 |
| **国企退休人员** | 退休前所在单位对应的纪检监察机关 |
| **退役军官、军士** | 移交地方后由地方纪检监察机关管辖 |

### 四、分办程序

**基本程序**：线索登记 → 分类 → 领导审批 → 分流到具体承办部门

## 第三节 线索处理

### 一、四类主要问题线索来源方式的处理流程

| 来源方式 | 处理流程 |
|---------|----------|
| **处理信访举报** | 登记 → 阅看 → 领导批示 → 分办 |
| **处理工作中发现线索** | 报告 → 登记 → 评估 → 分办 |
| **处理移交转送线索** | 接收 → 审查 → 登记 → 分办 |
| **处理主动投案线索** | 接待 → 登记 → 评估 → 分办 |

### 二、实名检举控告的处理流程

实名检举控告 = 署真实姓名+联系方式+明确诉求的检举控告

**特殊处理**：
- 优先受理
- 及时反馈受理情况
- 优先办理
- 阶段性反馈

### 三、诬告陷害和澄清正名的处理流程

| 情形 | 处理 |
|------|------|
| **诬告陷害** | 严肃查处，依规依纪依法追究诬告人责任 |
| **澄清正名** | 为受到不实举报的干部澄清事实、消除影响 |

## 第四节 重点疑难问题

### 一、交办、转办、指定管辖、委托核实(调查)的区别

| 方式 | 内涵 |
|------|------|
| **交办** | 上级机关将问题线索交下级机关办理，要求报告结果 |
| **转办** | 将问题线索转送相关机关或部门处理 |
| **指定管辖** | 上级指定某一机关管辖本不属于其管辖的问题线索 |
| **委托核实（调查）** | 委托其他机关协助核实或调查特定事项 |

### 二、业务内外交织问题材料

在信访举报中，发现有些公职人员业务内外交织的问题材料如何处理？

**原则**：由有管辖权的纪检监察机关统一处理，业务问题与违纪违法问题同步核查

### 三、村党支部书记担任市委候补委员的管辖确定

按其最高职务确定管辖主体（市委候补委员 > 村党支部书记）

## 第二章 问题线索处置

## 第一节 处置方式和要求

### 一、处置方式

四类处置方式：
1. **谈话函询**（轻）
2. **初步核实**（中）
3. **暂存待查**（暂缓）
4. **予以了结**（终结）

### 二、处置时限要求

| 处置方式 | 时限 |
|---------|------|
| 谈话函询 | 一般30日内完成 |
| 初步核实 | 一般2个月内完成，重大复杂可延长1个月 |
| 暂存待查 | 视情况 |
| 予以了结 | 视情况 |

### 三、处置报告要求

处置结束后需形成书面报告，载明：
- 线索来源
- 处置过程
- 核查情况
- 处理建议

### 四、承办部门线索管理要求

- 建立台账
- 定期清理
- 严格保密

## 第二节 四类处置方式

### 一、谈话函询

#### (一) 启动要求

- 经领导审批
- 制定工作方案
- 谈话函询对象明确

#### (二) 谈话实施

- 承办人不得少于2人
- 告知权利义务
- 制作谈话笔录

#### (三) 函询实施

- 发函通知被反映人
- 要求在规定时间内书面回复
- 必要时可要求其到纪检监察机关说明情况

#### (四) 谈话函询后的处理

- 谈话函询材料归入个人廉政档案
- 根据谈话函询结果决定下一步处置
- 谈话函询中发现新问题 → 转入初步核实或审查调查

### 二、初步核实

#### (一) 初步核实启动要求

- 经领导审批
- 成立初核组（一般不少于2人）
- 制定初核方案

#### (二) 初步核实措施

可采取的措施（限于初核阶段）：
- 调取个人有关事项报告
- 查阅复制文件资料
- 与相关人员了解情况
- 委托审计

#### (三) 初步核实后的处理

| 情形 | 处理 |
|------|------|
| 涉嫌违纪违法需追究纪律法律责任 | 转入立案审查调查 |
| 有违纪事实但不需追究纪律法律责任 | 给予批评教育、诫勉等 |
| 反映问题失实 | 予以了结，必要时澄清正名 |

### 三、暂存待查

**适用情形**：线索有价值但短期内难以查清或条件不成熟

**管理要求**：定期评估，条件成熟时及时处置

### 四、予以了结

**适用情形**：
- 反映问题失实
- 虽有违纪事实但已过追责时效
- 情节轻微不需追究纪律法律责任

**程序**：经领导审批后予以了结

## 第三节 重点疑难问题

### 一、如何精准有效处置问题线索？

**原则**：
1. 分类处置
2. 轻重分开
3. 动态管理

### 二、在实践中如何开展诫勉工作？

**诫勉** = 谈话函询与轻处分之间的处理方式
- 谈话诫勉
- 书面诫勉
- 诫勉谈话记录归入廉政档案

### 三、反映人请求撤回检举控告是否影响问题线索的处置？

**原则**：
- 不影响正常处置程序
- 但可在处置方式上适当考虑
- 重大问题即使撤回仍需继续核查

## 第三章 审查调查

## 第一节 审查调查启动程序

### 一、立案标准

#### 党纪立案标准

《中国共产党纪律处分条例》规定的违纪行为 + 需追究纪律责任

#### 政务立案标准

《政务处分法》规定的违法行为 + 需追究政务责任

#### 职务犯罪立案标准

《监察法》规定的职务违法犯罪 + 需追究法律责任

### 二、立案模式

| 立案模式 | 适用情形 |
|---------|----------|
| **"人立案"** | 已明确涉嫌违纪违法的具体人员 |
| **"事立案"** | 暂未明确具体人员，但有明确的违纪违法行为 |

### 三、立案程序

**流程**：承办部门提出 → 部门负责人审核 → 分管领导审批 → 纪委常委会会议研究决定 → 报同级党委审批 → 立案

### 四、重点疑难问题

1. **对其他纪检监察机关监督对象采取措施的审批手续**：提级办理或商请协助
2. **"以事立案"**：先立案查事，再追查人
3. **党纪和政务双立案**：涉嫌违纪和职务违法需双立案

## 第二节 监督检查审查调查措施（13项）

### 措施清单

| 序号 | 措施 | 法规依据 | 适用对象 |
|------|------|----------|----------|
| 1 | **谈话** | 《监察法》第19条 | 监督对象 |
| 2 | **讯问** | 《监察法》第21条 | 被调查人 |
| 3 | **询问** | 《监察法》第21条 | 证人等 |
| 4 | **查询、冻结** | 《监察法》第21、23条 | 财产、账户 |
| 5 | **调取、查封、扣押** | 《监察法》第21、25条 | 财物、文件 |
| 6 | **鉴定** | 《监察法》第21、26条 | 专门性问题 |
| 7 | **勘验检查** | 《监察法》第21、26条 | 场所、物品 |
| 8 | **搜查** | 《监察法》第21、24条 | 身体、住所等 |
| 9 | **留置** | 《监察法》第22条 | 涉嫌严重职务违法/职务犯罪 |
| 10 | **技术调查** | 《监察法》第28条 | 重大复杂案件 |
| 11 | **通缉** | 《监察法》第29条 | 涉案在逃人员 |
| 12 | **限制出境** | 《监察法》第30条 | 涉案人员 |
| 13 | 其他依法可采取措施 | — | — |

### 重点措施详解

#### 9. 留置

**适用条件**：
- 涉嫌严重职务违法或职务犯罪
- 监察机关已掌握部分违法犯罪事实及证据
- 仍有重要问题需要调查
- 涉及案情重大、复杂
- 可能逃跑、自杀
- 可能串供或者伪造、隐匿、毁灭证据

**审批权限**：设区的市级以上监察机关批准

**期限**：一般3个月，可延长1次（不超过3个月），重大复杂案件经省级以上批准可再延长（不超过6个月），合计不超过12个月（待核实最新规定）

#### 10. 技术调查

**适用范围**：重大贪污贿赂等职务犯罪案件
**审批**：严格的批准程序
**种类**：记录监控、行踪监控、通信监控等

#### 11. 通缉

**适用**：涉案在逃人员
**决定机关**：县级以上监察机关
**执行机关**：公安机关

#### 12. 限制出境

**适用**：涉案人员可能逃往国（境）外
**执行机关**：国家移民管理机构
**期限**：根据办案需要确定

### 重点疑难问题

1. **如何做好讯问准备工作？** 制定讯问方案、熟悉案情、准备法律文书、心理应对预案
2. **非党员非监察对象在无法准确认定违法所得金额的情况下，能否启动主动登记上交程序？** 可以启动，主动登记上交不以金额为唯一标准
3. **如何在指定管辖案件中开展对同级党委管理的正职领导干部（证人）的询问工作？** 商请同级党委同意或提级办理

## 第三节 审查调查重点文书

### 一、审查调查报告

主要内容：
- 被审查调查人基本情况
- 审查调查依据
- 主要违纪违法事实
- 证据材料
- 涉案款物处理建议
- 移送审理建议

### 二、违纪违法事实材料

要求：
- 客观真实
- 证据充分
- 条理清晰
- 引用法律条文准确

### 三、涉案人员处理意见

分类处理建议：
- 涉嫌犯罪 → 移送司法机关
- 涉嫌违纪违法 → 给予党纪政务处分
- 涉嫌犯罪+违纪 → 同步处理

## 第四章 案件审理

## 第一节 自办案件的审理

### 一、案件受理

**受理范围**：本级纪检监察机关立案审查调查的案件

### 二、案件审理

#### (一) 提前介入审理

**适用**：重大、复杂、疑难案件
**方式**：审理部门提前介入审查调查

#### (二) 阅卷审核

仔细审阅卷宗材料：
- 程序是否合法
- 事实是否清楚
- 证据是否充分
- 定性是否准确
- 处理建议是否恰当

#### (三) 退回审查调查

**退回情形**：
- 事实不清
- 证据不足
- 程序违法
- 遗漏违纪违法事实

#### (四) 审理谈话

与被审查调查人谈话，听取其意见。

#### (五) 室务会集体审议

审理部门集体讨论案件

### 三、审议报批

#### (一) 纪委常委会会议审议

集体讨论决定

#### (二) 征求有关党组织意见

对涉及党委管理的党员，需征求其所在党组织的意见

#### (三) 党委常委会审批

需同级党委常委会审批的案件

### 四、法法衔接程序

| 环节 | 内涵 |
|------|------|
| **检察机关提前介入** | 重大复杂案件可商请检察机关提前介入 |
| **商请指定管辖** | 监察机关商请同级检察机关指定管辖 |
| **移送审查起诉** | 涉嫌职务犯罪的案件移送检察机关审查起诉 |
| **提出从宽处罚建议** | 监察机关可在移送时提出从宽处罚建议 |
| **检察机关退回补充调查** | 案件需要补充证据的退回监察机关补充调查 |

## 第二节 报批案件的审理

### 一、案件范围

下级纪检监察机关立案审查调查，但需报上级审批的案件

### 二、办理程序

下级审理 → 报上级审理 → 报同级党委审批

## 第三节 备案案件的审理

### 一、案件范围

本级纪检监察机关作出处分决定后报上级备案的案件

### 二、办理程序

审理 → 备案

## 第四节 重点疑难问题

### 一、指定管辖案件又提级办理的程序

按提级办理后的管辖权限履行立案、审理和处分程序

### 二、党委审批意见与纪委常委会审议意见不一致的处理

按党委常委会意见办理，纪委执行党委决定

### 三、互涉案件的处理

互涉案件 = 同一案件涉及不同级别或地区纪检监察机关监督对象
- 协商管辖
- 分别处理
- 移送衔接

### 四、监察机关出具从宽处罚建议的注意事项

- 以事实为依据
- 以法律为准绳
- 说明从宽事由
- 附相关证据材料

### 五、如何认定主动投案？

**主动投案的认定**：
- 主动、直接向监察机关投案
- 经监察机关电话通知后主动到案（一般可认定）
- 留置后即如实交代全部问题（可认定为主动投案）

### 六、职务犯罪案件移送审查起诉时留置措施与刑事强制措施的衔接

| 情形 | 衔接 |
|------|------|
| 移送审查起诉 | 留置措施解除，检察机关决定采取刑事强制措施 |
| 监察机关商请 | 检察机关可商请监察机关协助 |

## 第五章 处分执行

## 第一节 处分种类

### 一、党纪处分

#### (一) 党员违纪处分

5种党纪处分（从轻到重）：
1. **警告**（最轻）
2. **严重警告**
3. **撤销党内职务**
4. **留党察看**
5. **开除党籍**（最重）

#### (二) 党组织违纪处分

- 改组
- 解散

### 二、政务处分

11种政务处分（从轻到重）：
1. **警告**
2. **记过**
3. **记大过**
4. **降级**
5. **撤职**
6. **开除公职**（最重）

### 三、党纪政务处分的匹配适用

**基本原则**：
- 党纪严于政务
- 同时给予党纪政务处分
- 处分档次对应

### 四、处分以外的处理方式

| 类别 | 方式 |
|------|------|
| **警示教育类** | 约谈、批评教育、责令检查、通报批评 |
| **组织处理类** | 调离岗位、改任非领导职务、责令辞职、免职、降职、停职检查、引咎辞职、责令辞职 |

### 五、精准运用监督执纪"四种形态"

| 形态 | 内涵 |
|------|------|
| **第一种形态**（经常开展批评和自我批评、约谈函询）| "红红脸、出出汗" |
| **第二种形态**（党纪轻处分、组织调整）| 大多数 |
| **第三种形态**（重处分、重大职务调整）| 少数 |
| **第四种形态**（严重违纪涉嫌违法立案审查）| 极少数 |

## 第二节 处分程序和批准权限

### 一、普通程序：党支部大会讨论

- 召开支部大会讨论
- 表决作出处分决定
- 上报审批

### 二、特殊程序：县级以上纪委直接作出处分

适用于情况紧急或特殊情形

### 三、党组作出党纪处分

**依据**：《中国共产党党组工作条例》

### 四、地方各级党委委员、候补委员的处分批准程序

按干部管理权限 + 党委常委会审批

### 五、终止党代表资格的程序

按党章和有关规定办理

### 六、查处人大代表、政协委员的程序

需依法办理罢免、撤销资格等手续

### 七、给予人大、政协选举或决定任命人员重处分的程序

需先免去其职务，再给予处分

### 八、"双管"干部的处分权限

按"双管"干部管理规定办理

## 第三节 处分决定的执行

### 一、制作处分决定

按规定格式和内容制作

### 二、处分决定的宣布和送达

#### (一) 向本人宣布

#### (二) 向基层党组织的全体党员、班子成员宣布

#### (三) 处分决定的送达

### 三、处分决定的执行事项

| 党纪处分 | 影响期 | 关键执行事项 |
|---------|--------|------------|
| **警告** | 1年 | 不得在党内提升职务 |
| **严重警告** | 1年半 | 不得在党内提升职务 |
| **撤销党内职务** | 2年 | 撤销党内职务 |
| **留党察看** | 1年/2年 | 期间停止党员权利；期满后视情况恢复 |
| **开除党籍** | 永久 | 终止党员权利 |

| 政务处分 | 期间 |
|---------|------|
| **警告** | 6个月 |
| **记过** | 12个月 |
| **记大过** | 18个月 |
| **降级** | 24个月 |
| **撤职** | 24个月 |
| **开除公职** | 永久 |

## 第四节 重点疑难问题

### 一、降级和撤职处分的区别

**降级**：降低工资档次、级别
**撤职**：撤销现任职务

### 二、应给予撤职处分但本人没有领导职务的处分

给予**降低职级**处分

### 三、《公职人员政务处分法》出台后事业单位工作人员的处分

按"从旧兼从轻"原则确定处分种类

### 四、同时给予政务撤职和党纪重处分的职务层次降低

按较低职务层次确定

### 五、处分期内再次受到处分的处分期重新计算

按较重的处分期重新计算

### 六、退休公职人员处分执行

按原职务级别对应处分执行

### 七、国企管理人员处分执行

按其身份（党政干部/国企管理人员/普通职工）确定处分种类
