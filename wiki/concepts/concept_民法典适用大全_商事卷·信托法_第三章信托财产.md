## 一、第14条·信托财产构成

### 法条原文

> 第十四条　受托人因承诺信托而取得的财产是信托财产。
>
> 受托人因信托财产的管理运用、处分或者其他情形而取得的财产，也归入信托财产。
>
> 法律、行政法规禁止流通的财产，不得作为信托财产。
>
> 法律、行政法规限制流通的财产，依法经有关主管部门批准后，可以作为信托财产。

### 核心释义

**信托财产的2个来源**：

| 来源 | 内容 |
|------|------|
| **原始受托财产** | 受托人因承诺信托而取得的财产（设立信托时形成的初始信托财产） |
| **代位财产和收益** | 受托人因信托财产的管理运用、处分或者其他情形而取得的财产（信托存续期间因形态变化而形成的新财产） |

**代位财产和收益的典型类型**：

| 类型 | 例子 |
|------|------|
| 天然孳息 | 植物所结果实 |
| 法定孳息 | 房屋出租租金 |
| 出售对价 | 出卖信托财产而取得的价款 |
| 货物 | 支付信托财产而购买到的财物 |
| 损害赔偿请求权 | 因信托财产毁损灭失所生之损害赔偿请求权 |
| 担保物权 | 运用信托财产而取得的担保物权 |
| 利息 | 银行存款利息 |

**禁止/限制流通物的处理规则**：

| 类别 | 处理 |
|------|------|
| **禁止流通物** | 不得作为信托财产（如专属国家所有的财产、军用武器、淫秽物品等） |
| **限制流通物** | 依法经有关主管部门批准后，可以作为信托财产 |

**禁止流通物的典型类型**：

| 类别 | 内容 |
|------|------|
| 专属国家所有 | 矿藏、水流、森林、山岭等自然资源；全民所有的博物馆藏品 |
| 军用物品 | 武器、弹药 |
| 违禁物品 | 淫秽的书刊、影片、录像带、录音带、图片等 |

**限制流通物的典型类型**：

| 类别 | 内容 |
|------|------|
| 土地相关 | 城乡土地使用权 |
| 资源类 | 全民所有的水面、滩涂的使用权 |
| 专卖品 | 烟草专卖品 |
| 特殊物 | 麻醉品、探矿权、采矿权 |
| 林地类 | 用材林、经济林、薪炭林及其林地、采伐迹地、火烧迹地的林地使用权 |
| 保护类 | 国家重点保护野生动物及其产品 |

### 适用指引

**代位物与同一性原则**：

> 信托财产即使转变成新的形态，这些新的财产也构成信托财产，这被称为"信托财产的物上代位"或者"**信托财产的同一性**"。

**初始信托财产的取得方式**：
- 委托人先取得后再转交受托人
- 委托人指示某义务人将所得请求的权利直接转移给受托人（**指示交付**）

**初始受托财产的种类**：金钱、动产、不动产、有价证券、金钱债权、知识产权等可转让的财产和财产权利

## 二、第15条·信托财产与委托人财产区别

### 法条原文

> 第十五条　信托财产与委托人未设立信托的其他财产相区别。设立信托后，委托人死亡或者依法解散、被依法撤销、被宣告破产时，委托人是唯一受益人的，信托终止，信托财产作为其遗产或者清算财产；委托人不是唯一受益人的，信托存续，信托财产不作为其遗产或者清算财产；但作为共同受益人的委托人死亡或者依法解散、被依法撤销、被宣告破产时，其信托受益权作为其遗产或者清算财产。

### 核心释义

**信托财产 vs 委托人未设立信托的其他财产的5点区别**：

| 维度 | 信托财产 | 委托人其他财产 |
|------|---------|--------------|
| **权利内容** | 间接的、相对的支配权；以保护信托利益为目的的请求权 | 直接的、排他的支配权 |
| **权利主体** | 委托人、受托人、受益人 | 仅委托人本人 |
| **行使方式** | 通过受托人实现（不能直接及于信托财产） | 直接行使 |
| **收益归属** | 归属于受益人（自益信托除外） | 归属于委托人 |
| **担保的债务** | 不能作为委托人债务的担保 | 可作为委托人债务的担保 |

**委托人破产时信托财产的处理（双轨制）**：

| 委托人在信托中的地位 | 委托人破产的法律后果 |
|-------------------|--------------------|
| **唯一受益人** | 信托终止；信托财产作为委托人的遗产或清算财产 |
| **非唯一受益人** | 信托存续；信托财产不作为委托人的遗产或清算财产 |
| **作为共同受益人之一** | 信托存续；**其信托受益权**作为委托人的遗产或清算财产 |

#### 中航信托股份有限公司与夏某执行分配方案异议案

## 三、第16条·信托财产与受托人财产区别

### 法条原文

> 第十六条　信托财产与属于受托人所有的财产（以下简称固有财产）相区别，不得归入受托人的固有财产或者成为固有财产的一部分。
>
> 受托人死亡或者依法解散、被依法撤销、被宣告破产而终止，信托财产不属于其遗产或者清算财产。

### 核心释义

**信托财产独立性的3点体现**：

| 独立性 | 内容 |
|--------|------|
| 与受托人固有财产相区别 | 信托财产不归入受托人固有财产或成为其一部分 |
| 受托人破产时不属于其遗产或清算财产 | 受托人死亡/终止时，信托财产独立于其遗产或清算财产 |
| 受托人债权人不得追索 | 受托人的债权人不得对信托财产主张权利 |

**受托人管理信托财产的特别要求**（《信托法》第29条）：

| 要求 | 内容 |
|------|------|
| 1 | 信托财产与固有财产分别管理、分别记账 |
| 2 | 不同委托人的信托财产分别管理、分别记账 |
| 3 | 不得将信托财产转为其固有财产 |
| 4 | 不得利用信托财产为自己谋取利益（除法律规定的报酬外） |
| 5 | 不得将固有财产与信托财产进行交易（除信托文件另有规定/经委托人受益人同意+公平市价） |
| 6 | 不得将不同委托人的信托财产相互交易 |

**受托人破产时的处理**：

| 处理 | 内容 |
|------|------|
| 信托财产不作为受托人遗产 | 受托人死亡时，信托财产不归入其遗产，继承人不得主张 |
| 信托财产不作为受托人清算财产 | 受托人解散/撤销/破产时，信托财产不归入清算财产 |
| 选任新受托人 | 依《信托法》第40条规定选任新受托人 |
| 转移信托财产 | 将信托财产转移给新受托人 |

### 典型案例

#### 中国工商银行股份有限公司安庆分行与雨润控股集团有限公司合同纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2018）皖民初11号 |
| 审理法院 | 安徽省高级人民法院 |
| 裁判要点 | 信托公司持有的该股权作为**信托财产具有独立性**，不属于信托公司自身所负债务的责任财产，并不存在其他债权人对该股权主张权利的可能，故委托人提出优先偿付的请求并无必要 |

## 四、第17条·对信托财产不得强制执行

### 法条原文

> 第十七条　除因下列情形之一外，对信托财产不得强制执行：
>
> （一）设立信托前债权人已对该信托财产享有优先受偿的权利，并依法行使该权利的；
>
> （二）受托人处理信托事务所产生债务，债权人要求清偿该债务的；
>
> （三）信托财产本身应担负的税款；
>
> （四）法律规定的其他情形。
>
> 对于违反前款规定而强制执行信托财产，委托人、受托人或者受益人有权向人民法院提出异议。

### 核心释义

**对信托财产强制执行的4种例外情形**：

| 序号 | 例外情形 | 说明 |
|------|---------|------|
| 1 | 设立信托前债权人已对该信托财产享有优先受偿的权利，并依法行使 | 如抵押权、担保物权 |
| 2 | 受托人处理信托事务所产生债务，债权人要求清偿 | 受托人因处理信托事务所支出的费用、对第三人所负债务 |
| 3 | 信托财产本身应担负的税款 | 依《税收征收管理法》《海关法》 |
| 4 | 法律规定的其他情形 | 兜底条款 |

**违反规定的异议权**：

| 维度 | 内容 |
|------|------|
| 异议权人 | 委托人、受托人或者受益人 |
| 异议机关 | 人民法院 |
| 法律依据 | 《民事诉讼法》第234条（案外人执行异议） |
| 异议期限 | 人民法院应当自收到书面异议之日起**15日内**审查 |

### 适用指引

**《九民会议纪要》第95条的5项要点**：

1. 信托财产在信托存续期间**独立**于委托人、受托人、受益人各自的固有财产
2. 委托人将其财产委托给受托人进行管理，在信托依法设立后，该信托财产即独立于委托人未设立信托的其他固有财产
3. 受托人因承诺信托而取得的信托财产，以及通过对信托财产的管理、运用、处分等方式取得的财产，均独立于受托人的固有财产
4. 受益人对信托财产享有的权利表现为信托受益权，**信托财产并非受益人的责任财产**
5. 当事人因其与委托人、受托人或者受益人之间的纠纷申请对存管银行或者信托公司专门账户中的信托资金采取保全措施的，除符合《信托法》第17条规定的情形外，人民法院不应当准许

**《善意文明执行意见》的禁止性规定**：
> 信托财产在信托存续期间独立于委托人、受托人各自的固有财产，并且受益人对信托财产享有的权利表现为信托受益权，信托财产并非受益人的责任财产。因此，当事人因其与委托人、受托人或者受益人之间的纠纷申请对存管银行或信托公司专门账户中的信托资金采取保全或执行措施的，除符合《信托法》第17条规定的情形外，人民法院不应准许。

## 五、第18条·信托债权不得抵销

### 法条原文

> 第十八条　受托人管理运用、处分信托财产所产生的债权，不得与其固有财产产生的债务相抵销。
>
> 受托人管理运用、处分不同委托人的信托财产所产生的债权债务，不得相互抵销。

### 核心释义

**禁止抵销的2种情形**：

| 情形 | 目的 |
|------|------|
| **信托债权与受托人固有债务不得抵销** | 避免受托人以信托财产清偿自己的债务，保护信托财产安全和受益人利益 |
| **不同委托人的信托债权债务不得相互抵销** | 保护各委托人的信托财产独立性，避免相互侵蚀 |

**禁止抵销的特别要求**（《信托公司集合资金信托计划管理办法》第27条）：

| 要求 | 内容 |
|------|------|
| 1 | 不得向他人提供担保 |
| 2 | 向他人提供贷款不得超过其管理的所有信托计划实收余额的30% |
| 3 | 不得将信托资金直接或间接运用于信托公司的股东及其关联人 |
| 4 | **不得以固有财产与信托财产进行交易** |
| 5 | **不得将不同信托财产进行相互交易** |
| 6 | 不得将同一公司管理的不同信托计划投资于同一项目 |

## ⚠️ 司法适用难点

### 难点一：信托财产的独立性边界

**争议**：信托财产的独立性是否彻底？

**主流观点**：
- 信托财产独立于委托人、受托人、受益人各自的固有财产
- **但并非完全独立**：受托人的固有财产原则上并不完全隔离于信托财产对第三人的责任
- 与公司法中的经理和董事等能把其个人财产和公司财产隔离开来不同，信托受托人仍可能以固有财产承担信托债务

### 难点二：信托财产的强制执行例外

**争议**：第17条的4种例外情形如何理解？

**主流观点**：
- 设立信托前的优先受偿权：设立信托前已经成立的抵押权等
- 受托人处理信托事务的债务：依《信托法》第37条规定
- 信托财产本身应担负的税款：依税法规定
- 兜底条款：为未来立法留余地

### 难点三：第15条"双重所有权"理论

**争议**：信托财产所有权归属于受托人还是受益人？

**主流观点**：
- 英美法系：受托人享有"普通法上的所有权"，受益人享有"衡平法上的所有权"
- 大陆法系：受托人对信托财产享有不完全的所有权（管理、使用、处分的权利）
- 我国《信托法》回避信托财产所有权的归属问题
- 信托财产既不属于受托人的固有财产，也不属于委托人的未设立信托的其他财产

### 难点四：第16条第2款的适用范围

**争议**：受托人破产时，信托财产与受托人固有财产的区分是否彻底？

**主流观点**：
- 受托人死亡或终止，信托财产不属于其遗产或清算财产
- 需选任新受托人，继续管理信托财产
- 体现了信托制度的连续性、稳定性

### 难点五：禁止抵销的范围

**争议**：第18条禁止抵销的范围是否包括"集合运用"情形？

**主流观点**：
- 一般原则：禁止受托人固有财产与信托财产相互抵销
- 一般原则：禁止不同委托人的信托财产相互抵销
- 例外探讨：如果受托人将不同委托人的信托财产进行集合运用（混同管理），所产生的债权债务在一定条件下可能相互抵销

## ❓ 实务问答

### Q1：信托财产的2个来源？

**A**：依《信托法》第14条：
1. **原始受托财产**：受托人因承诺信托而取得的财产
2. **代位财产和收益**：受托人因信托财产的管理运用、处分或者其他情形而取得的财产（天然孳息、法定孳息、出售对价、损害赔偿请求权等）

### Q2：禁止/限制流通物作为信托财产的规则？

**A**：依《信托法》第14条第3、4款：
- **禁止流通物** → 不得作为信托财产
- **限制流通物** → 依法经有关主管部门批准后，可以作为信托财产

### Q3：信托财产与委托人其他财产的5点区别？

**A**：

| 维度 | 信托财产 | 委托人其他财产 |
|------|---------|--------------|
| 权利内容 | 间接、相对的支配权 | 直接、排他的支配权 |
| 权利主体 | 委托人+受托人+受益人 | 仅委托人 |
| 行使方式 | 通过受托人 | 直接行使 |
| 收益归属 | 受益人 | 委托人 |
| 担保的债务 | 不能作为委托人债务担保 | 可作为委托人债务担保 |

### Q4：委托人破产时信托财产的处理？

**A**：依《信托法》第15条：

| 委托人在信托中的地位 | 委托人破产的法律后果 |
|-------------------|--------------------|
| 唯一受益人 | 信托终止；信托财产作为遗产或清算财产 |
| 非唯一受益人 | 信托存续；信托财产不作为遗产或清算财产 |
| 作为共同受益人之一 | 信托存续；其**信托受益权**作为遗产或清算财产 |

### Q5：第17条对信托财产强制执行的4种例外？

**A**：
1. 设立信托前债权人已对该信托财产享有优先受偿的权利，并依法行使
2. 受托人处理信托事务所产生债务，债权人要求清偿
3. 信托财产本身应担负的税款
4. 法律规定的其他情形

### Q6：第18条禁止抵销的2种情形？

**A**：
1. 受托人管理运用、处分信托财产所产生的债权，不得与其**固有财产**产生的债务相抵销
2. 受托人管理运用、处分**不同委托人**的信托财产所产生的债权债务，不得相互抵销

### Q7：信托财产独立性 vs 公司财产独立性？

**A**：
- **信托财产独立性**：单向的风险隔离——信托财产免受受托人个人债权人的追索，隔离于受托人个人破产风险
- **公司财产独立性**：公司经理和董事等能把其个人财产和公司财产隔离开来
- 信托受托人地位 vs 公司经理人地位不同

### Q8：受托人管理信托财产的6项特别要求？

**A**：依《信托法》第29条 + 《集合资金信托计划管理办法》第27条：
1. 信托财产与固有财产分别管理、分别记账
2. 不同委托人的信托财产分别管理、分别记账
3. 不得将信托财产转为其固有财产
4. 不得利用信托财产为自己谋取利益
5. 不得将固有财产与信托财产进行交易（除例外）
6. 不得将不同委托人的信托财产相互交易（除例外）
