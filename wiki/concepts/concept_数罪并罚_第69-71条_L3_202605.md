# 数罪并罚(《刑法》第 69-71 条 · L3)

> 本页定位:刑法第 69-71 条 数罪并罚 L3 概念页。**总则第 4 章刑罚裁量**的核心制度,与罪数认定、吸收犯、想象竞合紧密关联;判决前发现数罪与判决后漏罪/新罪适用不同规则。

## 一、法条原文(条文要点)

《刑法》第 69 条(判决宣告前数罪并罚):
> 判决宣告以前一人犯数罪的,除判处死刑和无期徒刑的以外,应当在总和刑期以下、数刑中最高刑期以上,酌情决定执行的刑期……
> 数罪中有判处附加刑的,附加刑仍须执行。

《刑法》第 70 条(判决宣告后漏罪并罚):
> 判决宣告以后,刑罚执行完毕以前,发现被判刑的犯罪分子在判决宣告以前还有其他罪没有判决的,应当对新发现的罪作出判决,把前后两个判决所判处的刑罚,依照本法第六十九条的规定,决定执行的刑罚。

《刑法》第 71 条(判决宣告后新罪并罚):
> 判决宣告以后,刑罚执行完毕以前,被判刑的犯罪分子又犯罪的,应当对新犯的罪作出判决,把前罪没有执行的刑罚和后罪所判处的刑罚,依照本法第六十九条的规定,决定执行的刑罚。

## 二、段级释解

### 1. 概念界定

数罪并罚 = 行为人犯有数个独立罪行(实质数罪或独立数罪),法院在量刑时合并计算应执行刑罚的制度。

适用范围:
- 判决宣告前一人犯数罪 → 第 69 条
- 判决后发现漏罪 → 第 70 条「先并后减」(漏罪情形)
- 判决后犯新罪 → 第 71 条「先减后并」(新罪情形)

### 2. 四构成要件

(1) 数罪成立要件:
- 实质数罪:行为人实施数个独立犯罪行为,符合数个独立犯罪构成
- 非数罪情形(不适用数罪并罚):
  - 一行为触犯数罪(想象竞合) → 择一重罪从重,不并罚
  - 数行为触犯同一罪(连续犯/继续犯/集合犯) → 按一罪处理
  - 法条竞合 → 特别法优先 / 全面评价原则,不并罚
  - 吸收犯(重罪吸收轻罪) → 按重罪一罪处理
  - 牵连犯(手段行为与目的行为) → 一般择一重罪从重

(2) 时间要件:
- 判决宣告前发现数罪 → 一并判决,适用第 69 条
- 判决后发现漏罪 → 第 70 条「先并后减」
- 判决后犯新罪 → 第 71 条「先减后并」

(3) 刑罚计算要件(第 69 条):
- 总和刑期:数罪分别判处的刑期相加
- 数刑中最高刑期:数罪中最高一个刑期
- 执行刑期区间:总和刑期以下、数刑中最高刑期以上
- 死刑/无期徒刑吸收规则:判处死刑或无期徒刑的,吸收其他有期徒刑/拘役/管制

(4) 附加刑要件:
- 附加刑必须执行:数罪中有附加刑的,主刑合并执行时附加刑仍须执行

### 3. 三原则

**原则 1:吸收原则(重罪吸收轻罪)**
- 死刑 吸收 无期徒刑、有期徒刑、拘役、管制
- 无期徒刑 吸收 有期徒刑、拘役、管制

**原则 2:限制加重原则**
- 适用于数罪均判有期徒刑/拘役/管制的情形
- 执行刑期 = 数刑中最高刑期以上 + 总和刑期以下

**原则 3:并科原则**
- 附加刑 与 主刑 之间:并科(均须执行)
- 不同种主刑(有期徒刑 + 拘役 + 管制):转换执行

### 4. 漏罪 vs 新罪(关键区别)

**第 70 条 漏罪(先并后减)**:
- 步骤:新发现的罪先判决 → 与前罪刑罚合并 → 减去已执行部分 → 决定剩余执行刑期
- 目的:避免遗漏罪行逃避处罚

**第 71 条 新罪(先减后并)**:
- 步骤:新犯的罪先判决 → 前罪剩余未执行刑期 + 新罪刑期 → 按第 69 条合并 → 决定新执行刑期
- 目的:惩罚服刑期间再犯新罪(比漏罪更严)

## 三、实务问答(FAQ)

**Q1:数罪并罚与想象竞合的根本区别是什么?**
- 想象竞合:一行为触犯数罪(基于一个行为)
- 数罪并罚:数行为触犯数罪(基于数个独立行为)
- 法律后果不同:想象竞合 → 择一重罪从重;数罪并罚 → 合并计算刑期

**Q2:连续犯、继续犯、集合犯为什么不适用数罪并罚?**
这三类在刑法上视为一罪(不是数罪):
- 连续犯:基于同一/概括故意连续实施同种犯罪行为
- 继续犯:犯罪行为与不法状态同时持续(如非法拘禁)
- 集合犯:法律规定将数个同种行为集合为一罪
均按一罪处理,不并罚。

**Q3:有期徒刑总和刑期超过 20 年的,数罪并罚如何处理?**
按第 69 条限制加重处理:执行刑期不得超过 20 年(有期徒刑总和刑期上限)。这是有期徒刑数罪并罚的硬性上限(《刑法修正案(八)》修订)。

**Q4:无期徒刑数罪并罚时,是否可能降至有期徒刑?**
不能。无期徒刑是最高刑期,只能吸收其他刑种,不能因并罚降至有期徒刑。但单独判无期徒刑的犯罪人,符合条件可申请减刑/假释至有期徒刑。

**Q5:数罪中有判处死刑的情形,如何并罚?**
只执行死刑,其他刑种被死刑吸收(吸收原则)。但附加刑(如剥夺政治权利终身、没收财产)仍须执行。

**Q6:刑罚执行期间既发现漏罪又犯新罪,如何处理?**
分别处理:
- 对漏罪适用第 70 条「先并后减」
- 对新罪适用第 71 条「先减后并」
- 两份判决分别作出,执行刑期按各自规则计算

**Q7:数罪并罚与缓刑、假释的关系?**
数罪并罚决定执行刑期后,符合《刑法》第 72 条缓刑条件 / 第 81 条假释条件的,仍可单独适用缓刑/假释。但缓刑/假释期间发现漏罪或犯新罪,需撤销缓刑/假释,重新数罪并罚。

**Q8:数罪并罚与累犯的关系?**
不冲突,但需注意:
- 数罪并罚是刑罚裁量制度(量刑时合并)
- 累犯是量刑情节(从重处罚情节)
- 数罪并罚时,其中前罪已执行完毕 + 后罪成立 → 可能构成累犯 → 数罪并罚时从重
