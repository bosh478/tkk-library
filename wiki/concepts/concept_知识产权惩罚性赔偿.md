## 概念定义

知识产权惩罚性赔偿是指人民法院针对故意侵害知识产权且情节严重的侵权行为，在弥补实际损失之外额外判处的赔偿制度。

## 适用条件

| 条件 | 说明 |
|------|------|
| 故意 | 明知侵权而为之 |
| 情节严重 | 侵权行为性质恶劣、后果严重 |
| 须原告主张 | 法院不主动适用 |

## 计算规则

### 基数（法释〔2026〕7号第八、九条）

| 类型 | 说明 |
|------|------|
| 实际损失数额 | 首选 |
| 违法所得数额 | 次选 |
| 因侵权所获得的利益 | 次选 |
| 参照权利许可使用费 | 均难以计算时 |

**法定赔偿不能作为惩罚性赔偿的计算基数**

### 倍数

- 最高为基数的**5倍**
- 可以不是整数
- 综合考虑主观过错程度、情节严重程度

### 已受行政处罚的处理

因同一侵权行为已经被处以罚款或者罚金且执行完毕的，人民法院在确定惩罚性赔偿的倍数时应予考虑。

## 与补偿性赔偿的区别

| 区别 | 补偿性赔偿 | 惩罚性赔偿 |
|------|-----------|-----------|
| 目的 | 填补损失 | 惩罚+震慑 |
| 适用 | 一般侵权 | 故意+情节严重 |
| 数额 | 实际损失 | 实际损失×倍数 |
