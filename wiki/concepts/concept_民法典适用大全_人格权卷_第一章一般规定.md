| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第989条 | 人格权编调整范围 | 调整因人格权的享有和保护产生的民事关系 |

| 第991条 | 人格权受法律保护 | 任何组织或者个人不得侵害 |
| 第992条 | 人格权不得放弃、转让或者继承 | 人格权专属自然人享有 |
| 第993条 | 姓名、名称、肖像许可使用 | 可许可他人使用，依性质或法律规定不得许可的除外 |

| 第995条 | 人格权请求权 | 停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权不适用诉讼时效 |
| 第996条 | 违约责任与精神损害赔偿 | 违约行为损害人格权并造成严重精神损害的，不影响请求精神损害赔偿 |
| 第997条 | 预防性请求权 | 人格权侵害的预防性保护措施申请 |
| 第998条 | 认定人格权侵权的考虑因素 | 行为人和受害人的职业、影响范围、过错程度、行为目的、方式、后果 |
| 第999条 | 公共利益合理使用 | 公共利益实施新闻报道、舆论监督的，可合理使用人格权客体 |
| 第1000条 | 消除影响等责任相当 | 与行为的具体方式和造成的影响范围相当 |
| 第1001条 | 身份权利的参照适用 | 自然人因婚姻家庭关系等产生的身份权利的保护 |

### 生命权、身体权、健康权（第1002-1011条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1002条 | 生命权 | 自然人的生命安全和生命尊严受法律保护 |
| 第1003条 | 身体权 | 自然人的身体完整和行动自由受法律保护 |
| 第1004条 | 健康权 | 自然人的身心健康受法律保护 |
| 第1005条 | 法定救助义务 | 生命权、身体权、健康权受侵害或处于危难情形的，负有法定救助义务的组织或个人应及时施救 |
| 第1006条 | 人体组织捐献 | 完全民事行为能力人有权自主决定无偿捐献人体细胞、组织、器官、遗体 |
| 第1007条 | 禁止买卖人体组织 | 禁止以任何形式买卖人体细胞、组织、器官、遗体；买卖行为无效 |
| 第1008条 | 临床试验 | 进行临床试验应依法经批准并经伦理委员会审查同意，向受试者告知并书面同意 |
| 第1009条 | 人体基因、胚胎等科研活动 | 从事相关医学和科研活动应遵守法律，不得危害人体健康、违背伦理道德、损害公共利益 |
| 第1010条 | 性骚扰 | 违背他人意愿以言语、文字、图像、肢体行为等方式实施性骚扰的，应承担民事责任 |
| 第1011条 | 非法限制人身自由 | 以非法拘禁等方式剥夺、限制他人行动自由，或非法搜查他人身体的，应承担民事责任 |

## 核心制度深度解读

### 一、人格权编的体例创新（第989条）—— **民法典重大突破**

**条文原文**：本编调整因人格权的享有和保护产生的民事民事关系。

**重大意义**：
- 民法典首次将人格权独立成编
- 在世界民法史上具有里程碑意义
- 体现了以人民为中心的发展理念

**人格权编的体系**：

| 章节 | 条文 | 内容 |
|------|------|------|
| 第一章 一般规定 | 第989-1011条 | 人格权基础 + 生命权身体权健康权 |
| 第二章 生命权、身体权和健康权（部分） | 含在第一章 | 详见上述 |
| 第三章 姓名权和名称权 | 第1012-1017条 | 自然人和法人、非法人组织 |
| 第四章 肖像权 | 第1018-1023条 | 自然人肖像权 |
| 第五章 名誉权和荣誉权 | 第1024-1031条 | 民事主体名誉权、荣誉权 |
| 第六章 隐私权和个人信息保护 | 第1032-1039条 | 隐私权、个人信息保护 |

### 二、人格权定义与范围（第990条）

**条文原文**：人格权是民事主体享有的生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等权利。

**九种具体人格权**：

| 权利 | 主体 | 内容 |
|------|------|------|
| 生命权 | 自然人 | 生命安全和生命尊严 |
| 身体权 | 自然人 | 身体完整和行动自由 |
| 健康权 | 自然人 | 身心健康 |
| 姓名权 | 自然人 | 决定、使用、变更或者许可他人使用 |
| 名称权 | 法人、非法人组织 | 决定、使用、变更、转让或者许可他人使用 |
| 肖像权 | 自然人 | 制作、使用、公开、许可他人使用 |
| 名誉权 | 民事主体 | 外部社会评价 |
| 荣誉权 | 民事主体 | 获得的荣誉称号 |
| 隐私权 | 自然人 | 私密活动和私密信息 |

**"等权利"的内涵**：除明确列举的九种权利外，还包括基于人身自由、人格尊严产生的"一般人格权"。

### 三、人格权的专属性（第992条）

**条文原文**：人格权不得放弃、转让或者继承。

**理解要点**：

| 性质 | 内容 |
|------|------|
| 不得放弃 | 人格权是民事主体的基本权利，不得预先放弃 |
| 不得转让 | 人格权专属于民事主体本人，不得转让 |
| 不得继承 | 人格权随主体死亡而消灭，不发生继承 |

**例外**：第993条规定姓名、名称、肖像等人格要素的商业利用许可，以及其他人格要素的合理使用。

### 四、人格权请求权（第995条）

**条文原文**：人格权受到侵害的，受害人有权依照本法和其他法律的规定请求行为人承担民事责任。受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定。

**人格权请求权的特殊规则**：

| 请求权类型 | 是否适用诉讼时效 |
|----------|-----------------|
| 停止侵害 | 不适用 |
| 排除妨碍 | 不适用 |
| 消除危险 | 不适用 |
| 消除影响 | 不适用 |
| 恢复名誉 | 不适用 |
| 赔礼道歉 | 不适用 |
| 财产损失赔偿 | 适用（3年） |
| 精神损害赔偿 | 适用（3年） |

**意义**：人格权的防御性请求权不受时效限制，确保受害人可随时主张。

### 五、预防性保护（第997条）—— **新增条款**

**条文原文**：民事主体有证据证明行为人正在实施或者即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，有权依法向人民法院申请采取责令行为人停止有关行为的措施。

**理解要点**：
- **适用情形**：正在实施或即将实施的侵权行为
- **损害程度**：不及时制止将造成难以弥补的损害
- **措施**：人民法院责令行为人停止有关行为
- **意义**：从"事后救济"到"事前预防"

### 六、合理使用（第999条）

**条文原文**：为公共利益实施新闻报道、舆论监督等行为的，可以合理使用民事主体的姓名、名称、肖像、个人信息等；使用不合理侵害民事主体人格权的，应当依法承担民事责任。

**合理使用的构成**：

| 构成要件 | 内容 |
|----------|------|
| 1. 公共利益目的 | 新闻报道、舆论监督等 |
| 2. 合理使用 | 必要范围内使用 |
| 3. 不合理使用 | 超出合理范围，侵害人格权 |

**典型合理使用**：
- 新闻报道中不可避免的肖像使用
- 公众人物的合理报道
- 公共场所拍摄

### 七、死者人格利益保护（第994条）

**条文原文**：死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权依法请求行为人承担民事责任；死者没有配偶、子女且父母已经死亡的，其他近亲属有权依法请求行为人承担民事责任。

**请求权人顺序**：

| 顺序 | 请求权人 |
|------|----------|
| 1 | 配偶、子女、父母 |
| 2 | 其他近亲属（无配偶、子女且父母已死亡时） |

**保护客体**：
- 姓名、肖像、名誉、荣誉、隐私
- 遗体

### 八、生命权、身体权、健康权（第1002-1004条）

| 权利 | 法条 | 内涵 |
|------|------|------|
| 生命权 | 第1002条 | 自然人的生命安全和生命尊严受法律保护 |
| 身体权 | 第1003条 | 自然人的身体完整和行动自由受法律保护 |
| 健康权 | 第1004条 | 自然人的身心健康受法律保护 |

**三者的关系**：
- **生命权**：最高层次的人格权，丧失不可恢复
- **身体权**：身体完整性的保护
- **健康权**：身心健康的保护

### 九、人体组织捐献与买卖禁止（第1006-1007条）

**第1006条**：完全民事行为能力人有权依法自主决定无偿捐献其人体细胞、人体组织、人体器官、遗体。

**捐献的法定要求**：
1. 完全民事行为能力人
2. 自愿决定
3. 无偿

**禁止行为（第1007条）**：禁止以任何形式买卖人体细胞、人体组织、人体器官、遗体。违反前款规定的买卖行为无效。

**法律后果**：
- 买卖行为无效
- 买卖行为可能构成犯罪

### 十、法定救助义务（第1005条）

**条文原文**：自然人的生命权、身体权、健康权受到侵害或者处于其他危难情形的，负有法定救助义务的组织或者个人应当及时施救。

**理解要点**：
- 救助对象：生命权、身体权、健康权受侵害或处于危难情形
- 救助主体：负有法定救助义务的组织或个人
- 救助要求：及时施救

**典型场景**：
- 交通事故中的救助义务
- 医疗机构的救助义务
- 公共场所的救助义务

### 十一、性骚扰规制（第1010条）—— **新增条款**

**条文原文**：违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权依法请求行为人承担民事责任。

**性骚扰的构成**：
1. 违背他人意愿
2. 言语、文字、图像、肢体行为等方式
3. 性骚扰性质

**典型场景**：
- 工作场所的性骚扰
- 公共场所的性骚扰
- 网络性骚扰

### 十二、人身自由保护（第1011条）

**条文原文**：以非法拘禁等方式剥夺、限制他人的行动自由，或者非法搜查他人身体的，受害人有权依法请求行为人承担民事责任。

**保护对象**：
- 行动自由（人身自由）
- 身体（不受非法搜查）

## ⚠️ 司法适用难点

### 难点一：人格权请求权与侵权请求权的区别

**争议**：人格权请求权与侵权请求权的区别？

**主流观点**：

| 维度 | 人格权请求权 | 侵权请求权 |
|------|--------------|------------|
| 性质 | 绝对权请求权 | 债权请求权 |
| 适用 | 停止侵害等 | 财产损失/精神损害赔偿 |
| 时效 | 部分不适用 | 适用诉讼时效 |

### 难点二：合理使用的边界

**争议**：新闻报道、舆论监督的合理使用边界？

**主流观点**：
- **公共利益目的**：必须是公益性质
- **必要范围**：仅在必要的范围内使用
- **最小损害**：选择损害最小的方式
- **综合考量**：依社会一般观念判断

### 难点三：死者人格利益保护的边界

**争议**：死者人格利益保护的边界？

**主流观点**：
- **保护客体**：姓名、肖像、名誉、荣誉、隐私、遗体
- **保护范围**：仅在受到侵害时予以保护
- **请求权人**：依第994条规定

## ❓ 实务问答

> **Q1：人格权包括哪些具体权利？**
> 
> A：包括生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等（第990条）。

> **Q2：人格权可以放弃、转让或继承吗？**
> 
> A：人格权不得放弃、转让或者继承（第992条）。但人格要素的商业利用（如姓名、肖像许可使用）可以。

> **Q3：哪些人格权请求权不适用诉讼时效？**
> 
> A：停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定（第995条）。

> **Q4：什么是预防性人格权保护？**
> 
> A：行为人正在实施或即将实施侵害人格权的违法行为，不及时制止将造成难以弥补损害的，受害人可申请人民法院采取责令停止行为的措施（第997条）。

> **Q5：死者人格利益保护由谁主张？**
> 
> A：配偶、子女、父母有权依法请求；死者没有配偶、子女且父母已死亡的，其他近亲属有权请求（第994条）。

> **Q6：人格权的合理使用？**
> 
> A：为公共利益实施新闻报道、舆论监督等行为的，可合理使用民事主体的姓名、名称、肖像、个人信息等；使用不合理侵害人格权的，应承担民事责任（第999条）。

> **Q7：人体组织可以买卖吗？**
> 
> A：禁止以任何形式买卖人体细胞、人体组织、人体器官、遗体；违反规定的买卖行为无效（第1007条）。

> **Q8：什么是性骚扰？**
> 
> A：违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施的，受害人有权请求行为人承担民事责任（第1010条）。

> **Q9：生命权、身体权、健康权的区别？**
> 
> A：① 生命权：生命安全和生命尊严；② 身体权：身体完整和行动自由；③ 健康权：身心健康。
