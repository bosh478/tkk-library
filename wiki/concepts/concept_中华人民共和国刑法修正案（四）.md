## 章节结构
- 一、修改第一百四十五条（生产、销售不符合标准的医用器材罪）
- 二、在第一百五十二条中增加一款（走私废物罪）
- 三、修改第一百五十五条（间接走私以走私罪论处）
- 四、在第二百四十四条后增加一条（雇用童工从事危重劳动罪）
- 五、修改第三百三十九条第三款（擅自进口固体废物罪）
- 六、修改第三百四十四条（非法采伐、毁坏珍贵树木罪）
- 七、修改第三百四十五条（盗伐林木罪等）
- 八、修改第三百九十九条（徇私枉法罪等）
- 九、本修正案自公布之日起施行（2002年12月28日）

## 量刑档次

### 生产、销售不符合标准的医用器材罪（第145条）
- 档1：足以严重危害人体健康 → 3年以下有期徒刑或拘役，并处销售金额50%以上2倍以下罚金
- 档2：对人体健康造成严重危害 → 3年以上10年以下有期徒刑，并处销售金额50%以上2倍以下罚金
- 档3：后果特别严重 → 10年以上有期徒刑或无期徒刑，并处销售金额50%以上2倍以下罚金或没收财产

### 走私废物罪（第152条第2款）
- 档1：情节严重 → 5年以下有期徒刑，并处或单处罚金
- 档2：情节特别严重 → 5年以上有期徒刑，并处罚金

### 雇用童工从事危重劳动罪（第244条之一）
- 档1：雇用未满16周岁的人从事超强度体力劳动/高空/井下/危险环境劳动，情节严重 → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金
- 有前款行为造成事故构成其他犯罪 → 数罪并罚

### 非法采伐、毁坏珍贵树木罪（第344条）
- 档1：非法采伐、毁坏/非法收购、运输、加工、出售珍贵树木及其制品 → 3年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 盗伐林木罪（第345条）
- 档1：数量较大 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数量巨大 → 3年以上7年以下有期徒刑，并处罚金
- 档3：数量特别巨大 → 7年以上有期徒刑，并处罚金

### 滥伐林木罪（第345条第2款）
- 档1：数量较大 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数量巨大 → 3年以上7年以下有期徒刑，并处罚金

### 非法收购、运输盗伐、滥伐的林木罪（第345条第3款）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 徇私枉法罪（第399条）
- 档1：徇私枉法/徇情枉法，对明知无罪的人追诉/对明知有罪的人包庇不追诉/违背事实和法律裁判 → 5年以下有期徒刑或拘役
- 档2：情节严重 → 5年以上10年以下有期徒刑
- 档3：情节特别严重 → 10年以上有期徒刑

### 民事、行政枉法裁判罪（第399条第2款）
- 档1：情节严重 → 5年以下有期徒刑或拘役
- 档2：情节特别严重 → 5年以上10年以下有期徒刑

### 执行判决、裁定失职/滥用职权罪（第399条第3款）
- 档1：致使当事人利益遭受重大损失 → 5年以下有期徒刑或拘役
- 档2：致使当事人利益遭受特别重大损失 → 5年以上10年以下有期徒刑
