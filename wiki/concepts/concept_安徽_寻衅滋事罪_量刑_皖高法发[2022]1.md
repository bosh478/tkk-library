# 寻衅滋事罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(基本情节)** | 五年以下有期徒刑、拘役或者管制 | **3 月拘役-3 年**(7 种情形中的轻微) / **1 年半-3 年**(严重情形) |
| **第二档(纠集他人 3 次以上)** | 五年以上十年以下有期徒刑 + 罚金 | **5-7 年** |
| **第三档** | 数罪并罚 | — |

## 二、第一档 · 7 种情形 + 基准刑递增

### 情形 1:随意殴打 · 3 月拘役-3 年起点

"情节恶劣"(任一):
- 致 2+ 轻微伤
- 随意殴打他人达到 3 次
- 持凶器随意殴打
- 其他情节恶劣

**严重升级 → 1 年半-3 年**:
- 致 1+ 轻伤
- 引起精神失常 / 自杀等严重后果
- 随意殴打特殊人员(精神病人 / 残疾 / 流浪乞讨 / 老年 / 孕妇 / 未成年) + 严重社会影响
- 在公共场所随意殴打 + 公共场所秩序严重混乱

### 情形 2:追逐 / 拦截 / 辱骂 / 恐吓

任一:3 次以上 / 持凶器 / 其他情节恶劣 → **3 月拘役-3 年**

**严重升级 → 1 年半-3 年**:
- 上述行为针对特殊人员 + 严重社会影响
- 引起精神失常 / 自杀
- 严重影响正常工作 / 生活 / 生产 / 经营

### 情形 3:强拿硬要 / 任意损毁占用

任一:价值 ≥ 1000 元(强拿硬要)/ ≥ 2000 元(任意损毁占用)/ 3 次 + 恶劣影响 → **3 月拘役-3 年**

**严重升级 → 1 年半-3 年**:
- 上述行为针对特殊人员
- 引起精神失常 / 自杀
- 严重影响正常工作 / 生活 / 生产 / 经营

### 情形 4:公共场所起哄闹事

造成公共场所秩序严重混乱 → **1-3 年**

**基准刑递增**(以上 7 种情形通用):
| 项 | 规则 |
|----|------|
| 轻微伤 +1 | + **1-6 月** |
| 轻伤 +1 | + **6 月-1 年** |
| 精神失常 +1 | + **6 月-1 年半** |
| 自杀 / 重伤 / 死亡 +1 | + **1-2 年** |
| 殴打 / 追逐拦截 / 强拿硬要等每多 1 次(超 3 次) | + **1-2 月** |
| 强拿硬要每多 1000 元 | + **1-2 月** |
| 任意损毁占用每多 2000 元 | + **1-2 月** |
| 公共场所起哄闹事每多 1 次 | + **6 月-1 年** |
| 每多 1 项刑法 293 规定 4 种情形 | + **6 月-1 年** |

## 三、第二档 · 5-7 年起刑点(纠集他人 3 次寻衅滋事)

**入罪触发**:纠集他人 3 次寻衅滋事 + 严重破坏社会秩序。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 轻微伤 +1 | + **1-6 月** |
| 轻伤 +1 | + **6 月-1 年** |
| 精神失常 +1 | + **6 月-1 年半** |
| 自杀 / 重伤 / 死亡 +1 | + **1-2 年** |
| 纠集他人超过 3 次每多 1 次 | + **6 月-1 年** |
| 强拿硬要每多 1000 元 | + **1-2 月** |
| 任意损毁占用每多 2000 元 | + **1-2 月** |
| 每多 1 项刑法 293 规定 4 种情形 | + **6 月-1 年** |

## 四、从重情节(3 类 · +20% 以下)

1. 带有黑社会性质
2. 纠集未成年人寻衅滋事
3. 其他从重情形

## 五、罚金(仅第二档以上)

- 五年以上:**5000-50000 元**(5-7 年 5000-30000 / 7-10 年 10000-50000)

## 六、缓刑适用

**一般可以适用**(任一):
1. 日常生活偶发矛盾 + 借故生非 + 被害人有过错 + 积极赔偿 + 谅解
2. 婚恋 / 家庭 / 邻里 / 债务纠纷 + 积极赔偿 + 谅解
3. 未成年向未成年强索生活 / 学习用品 / 少量钱物 + 谅解
4. 其他可适用情形

**一般不适用**(任一):
1. 实施刑法 293 第 1 款 (一)至(四)中**两项以上**
2. 纠集未成年人
3. 黑恶势力性质
4. 曾因寻衅滋事 / 其他扰乱社会管理秩序的行为受过刑 / 一年内行拘
5. 其他不适用情形
