# 民法典适用大全·侵权责任卷（一）·第二章损害赔偿

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》侵权责任卷1 2023年 1164-1207.md]] |
| 章节 | 第二章 损害赔偿 |
| 条文范围 | 《民法典》第1179条～第1187条（共9条） |
| 核心主题 | 人身损害赔偿、精神损害赔偿、财产损害赔偿、惩罚性赔偿、公平责任 |

## 条文结构

| 条文 | 主题 | 法理要点 |
|------|------|----------|
| 第1179条 | 人身损害赔偿范围 | 医疗费、护理费、交通费、营养费、误工费；残疾赔偿金、丧葬费、死亡赔偿金 |
| 第1180条 | 同一侵权多人死亡 | 因同一侵权行为造成多人死亡的，可以以相同数额确定死亡赔偿金 |
| 第1181条 | 其他请求权主体 | 被侵权人死亡的，近亲属有权请求侵权人承担责任 |
| 第1182条 | 侵害人身权益造成财产损失 | 按被侵权人损失或侵权人获利赔偿 |
| 第1183条 | 精神损害赔偿 | 严重精神损害的，被侵权人有权请求精神损害赔偿 |
| 第1184条 | 侵害财产的赔偿 | 按损失发生时的市场价格或其他合理方式计算 |
| 第1185条 | 知识产权惩罚性赔偿 | 故意侵害知识产权情节严重的，被侵权人有权请求相应惩罚性赔偿 |
| 第1186条 | 公平责任 | 受害人和行为人对损害的发生都没有过错的，依法分担损失 |
| 第1187条 | 损害赔偿支付方式 | 协商支付方式；协商不成的应一次性支付 |

## 核心制度深度解读

### 一、人身损害赔偿范围（第1179条）

**一般费用**：医疗费、护理费、交通费、营养费、住院伙食补助费等合理费用，以及因误工减少的收入。

**造成残疾的**：辅助器具费和残疾赔偿金。

**造成死亡的**：丧葬费和死亡赔偿金。

**特别要点**：
- 医疗费：包括诊疗、住院、药品、后续治疗等费用。
- 误工费：根据受害人误工时间和收入状况确定。
- 残疾赔偿金：根据伤残等级和收入情况综合确定。

### 二、人身权益侵害的财产损失赔偿（第1182条）

侵害他人人身权益造成财产损失的，按以下方式确定赔偿数额：
1. **被侵权人因此受到的损失**。
2. **侵权人因此获得的利益**。
3. 难以确定的，由法院根据实际情况确定赔偿数额。

**适用范围**：人身权益侵害造成财产损失的情形（如侵害健康权导致误工损失、侵害名誉权导致工作机会丧失等）。

### 三、精神损害赔偿制度（第1183条）

**构成要件**：
1. 侵害自然人的人身权益。
2. 造成严重精神损害。

**赔偿请求权人**：
1. 被侵权人。
2. 因侵权行为致死的，由死者的近亲属请求。
3. 被侵权人为胎儿或婴幼儿的，由其父母或其他近亲属请求。

**严重精神损害的认定**：
- 一般认为，达到伤残等级的，应认定严重精神损害。
- 死亡、近亲属分离、名誉严重受损等也可认定。

### 四、财产损害赔偿规则（第1184条）

**赔偿方式**：
1. 按损失发生时的**市场价格**计算。
2. 其他合理方式（如折旧价、重置成本等）。

**特殊情形**：
- 能修复的：修理费。
- 不能修复的：按重置成本或折旧价。
- 灭失的：按市价或评估价。

### 五、惩罚性赔偿体系

| 类型 | 法条 | 适用条件 |
|------|------|----------|
| 知识产权惩罚性赔偿 | 第1185条 | 故意+情节严重 |
| 产品责任惩罚性赔偿 | 第1207条 | 明知缺陷+生产销售/未采取补救措施+死亡/健康严重损害 |
| 食品安全惩罚性赔偿 | 《食品安全法》第148条 | 生产销售不符合食品安全标准 |
| 生态破坏惩罚性赔偿 | 《民法典》第1232条 | 故意+严重后果 |

### 六、公平责任制度（第1186条）

**构成要件**：
1. 受害人和行为人对损害的发生都没有过错。
2. 法律有特别规定的情形。

**法律效果**：由双方按法律规定分担损失。

**适用情形举例**：
- 紧急避险造成的损害（《民法典》第182条）。
- 见义勇为受到的损害（《民法典》第183条）。
- 受益人对见义勇为者的补偿。

### 七、损害赔偿支付方式（第1187条）

| 时点 | 方式 |
|------|------|
| 损害发生后 | 协商支付方式 |
| 协商不成 | 一次性支付 |
| 持续性损害 | 可分期支付（如后续治疗费） |

## ❓ 常见问题

> 问：人身损害赔偿包括哪些费用？
> 答：医疗费、护理费、交通费、营养费、住院伙食补助费、误工费；造成残疾的还包括辅助器具费和残疾赔偿金；造成死亡的还包括丧葬费和死亡赔偿金（第1179条）。

> 问：什么是同一侵权多人死亡的赔偿？
> 答：第1180条规定，因同一侵权行为造成多人死亡的，可以以相同数额确定死亡赔偿金，避免因城乡差异、年龄差异等导致赔偿数额悬殊。

> 问：精神损害赔偿的请求权人有哪些？
> 答：被侵权人本人；被侵权人死亡的，由近亲属请求；被侵权人为胎儿/婴幼儿的，由其父母或其他近亲属请求。

> 问：什么是惩罚性赔偿？
> 答：除补偿性赔偿外，对故意或重大过失的侵权行为施加的额外赔偿。民法典侵权责任编规定了知识产权惩罚性赔偿（第1185条）、产品责任惩罚性赔偿（第1207条）、生态破坏惩罚性赔偿（第1232条）。

> 问：什么是公平责任？
> 答：第1186条规定，受害人和行为人对损害的发生都没有过错的，依照法律的规定由双方分担损失。是对过错责任和无过错责任的补充。

> 问：赔偿数额如何确定？
> 答：人身损害按实际损失和法律规定计算；精神损害综合考虑侵权情节、后果、当地生活水平等；财产损害按损失发生时的市场价格或其他合理方式计算。

## 适用指引

### 人身损害赔偿的具体计算

1. **医疗费**：根据医疗机构出具的医药费、住院费等收款凭证，结合病历和诊断证明确定。
2. **误工费**：根据受害人的误工时间和收入状况确定。
3. **护理费**：根据护理人员的收入状况和护理人数、护理期限确定。
4. **交通费**：根据受害人及其必要的陪护人员因就医或者转院治疗实际发生的费用计算。
5. **残疾赔偿金**：根据受害人丧失劳动能力程度或者伤残等级，按照受诉法院所在地上一年度城镇居民人均可支配收入标准计算。

### 精神损害赔偿的考量因素

1. 侵权人的过错程度。
2. 侵害的手段、场合、行为方式等具体情节。
3. 侵权行为所造成的后果。
4. 侵权人的获利情况。
5. 侵权人承担责任的经济能力。
6. 受诉法院所在地平均生活水平。

### 惩罚性赔偿的适用

1. **主观要件**：故意或重大过失。
2. **客观要件**：情节严重或造成严重后果。
3. **数额确定**：综合考虑被告的过错程度、侵权情节、损害后果等。
4. **请求权人**：被侵权人。
