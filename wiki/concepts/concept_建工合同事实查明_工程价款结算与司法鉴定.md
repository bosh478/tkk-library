# 建工合同事实查明（二）工程价款结算与司法鉴定

> 本专题深入解析建设工程施工合同纠纷中**工程价款结算**和**司法鉴定**两大核心问题。涵盖：黑白合同识别 / 固定价款 vs 定额 / 财政审计结论 / 7 大司法鉴定要点。

## 一、工程价款结算（行 230-260）

### （一）合同内容的审查

#### 承包人 → 发包人主张工程款

**有书面施工合同**：按合同结算
**无书面合同 + 有效招投标**：以招投标文件作为结算依据
**无书面合同 + 未招投标 + 未事后结算**：可参照以下材料
- 同一项目内其他施工人的施工合同
- 施工地定额计价标准
- 结合案件事实确定

#### 实际施工人 → 承包人主张工程款

**有书面合同**：参照二者之间的书面合同
**多层转包/违法分包下无书面合同**：
- 参照 B 与 C 之间的合同就争议工程内容结算方式
- **不能**简单按定额计价标准结算（避免价格倒挂）

### （二）实际履行合同的审查（黑白合同识别）

**核心规则**：

| 情形 | 结算依据 |
|------|----------|
| **工程未招投标** + 多份合同 | 签订时间**在后**的合同 |
| **工程招投标** + 中标有效 + 中标后又签背离中标合同的合同（黑白合同） | **中标合同** |
| **工程招投标** + **中标无效** | **实际履行**的合同 |

**判断"实际履行合同"的依据**：
- 双方往来函件
- 付款节点
- 工程进度款申请表
- 付款审批表
- 预算书、结算书
- 履约保证金支付凭证

### （三）计价方式的审查

**主流计价方式**：
- 定额计价
- 工程量清单计价
- 平方米单价
- 固定总价

**审查方法**：
1. 审查合同**协议书**中关于合同价款的表述
2. 结合合同**专用条款**中合同价款与支付、竣工结算等条款
3. 仍无法辨明 → 查招投标文件中关于结算的计价方式

### （四）固定价款合同的特殊处理

#### 工程已完工

**规则**：应适用**固定价**结算
**变更部分**：按合同约定的计价标准在合同固定价基础上**增减**工程价款

#### 工程未完工

**处理**：可委托司法鉴定
**计算方法**：
1. 鉴定机构在同一取费标准下分别计算：
   - 已完工工程部分价款
   - 整个合同约定工程总价款
2. 两者对比计算**系数**（合同优惠率或工程完成比）
3. 参照该系数认定工程价款

**特别提示**：
- ⚠️ 优惠率/完成比**仅是参照**，具体情况具体分析
- 若合同约定土建安装，但仅完成地基基础或主体结构 → **不再适用**优惠率或酌情降低
- 若合同约定土建安装，已完成绝大部分合同内容 → **适用**合同优惠率或接近合同优惠率
- 若合同约定仅是主体结构 → 即使主体结构未完成，仍**参照适用**合同优惠率

### （五）定额或综合单价计价

**核心规则**：

| 情形 | 结算依据 |
|------|----------|
| 双方达成结算协议 | 结算协议 |
| 未达成结算协议 + 争议工程价款 | 委托造价鉴定 |

**鉴定中争议项目的处理**：
- 鉴定机构将争议施工项目在报告中**单列**
- 法官审查证据（施工图纸、工程签证单、施工组织方案、图纸会审纪要、招投标文件等）
- 与鉴定机构沟通 → 合理判断

**下浮结算的约定**：
- 若合同约定在定额或综合单价基础上对总价或部分价款进行一定比例**下浮**
- 不论合同是否有效，如该约定是当事人**真实意思表示**，**一般应参照适用**

### （六）政府财政审计结论

#### 一般规则

> 合同约定以政府财政审计结论作为结算依据的，**该约定对当事人具有约束力**（行 262）。

#### 例外情形

- 因**发包人原因未进行审计**
- 发包人**怠于履行配合审计义务**
- 未能在合理期限内作出审计意见

**处理**：诉讼过程中承包人可以通过**司法鉴定**对工程价款进行结算。

## 二、已付工程款的审查（行 262-284）

### 5 种付款方式核查

| 付款方式 | 核查要点 |
|----------|----------|
| 银行汇款 | 银行流水 + 转账凭证 |
| 承兑汇票 | 票据背书 + 兑付记录 |
| 现金支付 | 收款收据 + 出纳记录 + 取款凭证 |
| 工程借款 | 借款协议 + 实际到账记录 |
| 代付材料款/分包工程款/劳务工资 | 代付协议 + 实际支付凭证 + 计入已付工程款确认 |

### 实务要点

- 已付工程款应**逐笔核查**，避免遗漏
- 注意区分**借款与工程款**（借款不计入已付工程款）
- 注意区分**代付与代垫**（代付通常计入已付工程款）

## 三、工程质量的审查（行 286-310）

### （一）是否存在质量问题

**审查内容**：
- 质量检测报告
- 监理评估报告
- 竣工验收报告
- 质量问题现场照片/视频

### （二）质量修复问题

**审查内容**：
- 修复方案
- 修复费用
- 修复工期
- 修复期间损失

### （三）质保金应否返还

**区分履约保证金与质保金**：

| 类型 | 性质 | 返还时点 |
|------|------|----------|
| 履约保证金 | 担保合同履行 | 工程竣工验收合格后 |
| 质保金 | 担保质量保修期 | 质保期满后 |

**实务要点**：
- 质保金返还应审查：质量保修期是否届满 + 质量缺陷是否修复
- 履约保证金返还应审查：合同是否完全履行 + 是否存在违约

## 四、停工损失及工期违约（行 312-356）

### （一）停工事实

**审查内容**：
- 停工通知
- 监理日志
- 施工日志
- 现场照片/视频

### （二）停工原因

**常见原因及归责**：

| 原因 | 归责 |
|------|------|
| 新冠疫情 | **不可抗力**（按比例分担） |
| 大气污染防控 | **政府行为**（按比例分担） |
| 发包人原因（图纸延误、款项不到位等） | **发包人承担** |
| 承包人原因（人员、材料、设备问题） | **承包人承担** |

### （三）停工损失数额

**分项审查**：

| 损失类型 | 审查要点 |
|----------|----------|
| 人员窝工 | 工资 + 人数 + 天数 |
| 机械闲置 | 台班费 + 设备清单 |
| 材料积压 | 采购凭证 + 损耗 |
| 现场管理费 | 现场管理人员工资 + 办公费 |

### （四）逾期交工

**审查内容**：
- 合同约定工期
- 实际开工日期
- 实际竣工日期
- 逾期天数

### （五）逾期违约金或损失数额

**审查内容**：
- 合同约定违约金条款
- 实际损失证据
- 违约金调整申请（过高/过低）

## 五、司法鉴定（行 358-388）

### 7 个关键要点

#### 1. 必要性审查

**目的**：
- 避免拖延
- 减少诉累
- 节约诉讼成本

**判断标准**：
- 争议事实是否必须通过专业鉴定才能查明
- 当事人是否具备自行举证能力
- 鉴定费用与争议金额的比例

#### 2. 举证责任分配和释明

**法院义务**：
- 明确鉴定事项由谁申请
- 释明不申请鉴定的法律后果
- 在鉴定事项不明确时予以释明

#### 3. 鉴定机构资质

**核查内容**：
- **司法鉴定许可证**
- **鉴定人执业证**
- 鉴定机构执业范围
- 鉴定人专业背景

#### 4. 法院先行确定事项

**法院必须先确定**：
- 合同效力
- 工程是否合格
- 工程范围
- 计价方式

**理由**：避免鉴定机构对法律问题作出判断。

#### 5. 鉴定事项的审查与引导

**审查内容**：
- 避免重复鉴定
- 不超出申请范围
- 与争议焦点对应
- 鉴定事项具体明确

#### 6. 鉴定材料的提供

**程序要求**：
- 双方质证
- 法院确认
- 鉴定机构不得自行收集未经质证的证据

#### 7. 工程质量鉴定事项的确定

**特殊要求**：
- **鉴定机构资质**：必须具有工程质量鉴定资质
- **现场勘验**：必要时进行现场勘验
- **取样检测**：必要时取样送检
- **鉴定人员**：具有相应专业背景

## ❓ 实务高频问题

### Q1：黑白合同以哪份为准？

**A**：依据是否招投标分两种情况：
- **未招投标** → 签订时间在后的合同
- **招投标 + 中标有效** → **中标合同**（即使双方后签了背离中标合同的合同）
- **招投标 + 中标无效** → 实际履行的合同

### Q2：固定价款合同能否改为定额结算？

**A**：❌ **一般不支持**。
- 工程已完工 → 适用固定价，变更部分按合同约定增减
- 工程未完工 → 委托司法鉴定，按合同优惠率或工程完成比计算

### Q3：财政审计结论未被采纳，能否起诉？

**A**：✅ 可以。
- 若合同约定以财政审计结论为结算依据，但发包人未审计或怠于配合
- 承包人可**通过司法鉴定**结算
- 但已作出的有效财政审计结论对当事人**有约束力**

### Q4：司法鉴定中，鉴定机构能否对法律问题作出判断？

**A**：❌ **不能**。
- 合同效力、工程是否合格、工程范围、计价方式等**法律问题**由法院决定
- 鉴定机构仅对**专业技术问题**作出鉴定意见

### Q5：合同无效时，工程价款如何结算？

**A**：⚠️ 区分情形：
- **建设工程施工合同无效，但工程经竣工验收合格** → 可参照合同约定结算
- **建设工程施工合同无效，且工程经竣工验收不合格** → 修复后合格的，参照合同约定结算；修复后仍不合格的，承包人无权主张工程价款
