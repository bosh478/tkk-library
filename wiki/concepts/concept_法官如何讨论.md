## 核心框架

### 司法决策中的集体讨论机制

本书从群体决策理论出发，系统阐述合议庭、专业法官会议、审判委员会三种案件讨论形式：

| 形式 | 定位 | 决策机制 | 适用范围 |
|------|------|----------|----------|
| 合议庭讨论 | 一线审判组织 | 群体决策（少数服从多数） | 绝大多数案件 |
| 专业法官会议 | 咨询性质 | 提供专业参考意见 | 重大疑难复杂案件 |
| 审判委员会 | 最高审判组织 | 集体讨论决定 | 重大疑难复杂案件、法律规定应提交讨论的案件 |

### 七讲内容体系

**引论：以集体讨论为基础的司法决策**
- 裁判中的"一案多解"现象
- 从合议制到审委会讨论制的制度演进
- "讨论规则"为什么重要：程序制约下的汇报技能与讨论方法
- 关注讨论能力的培养

**第一讲：讨论的品性与构成**
- 讨论的普遍性与讨论方法的重要性
  - 寻求以最短时间达成最佳结果的讨论方法
- 作为决策过程的案件讨论（发现问题→确立目标→收集信息→建构决定→选择方案）
- 案件讨论的形式与种类：合议庭讨论、专业法官会议、审判委员会

**第二讲：合议庭的讨论原理与规则**
- 群体决策：合议制的灵魂
- 合议制运行中可能存在的问题：
  - 合议庭成员缺乏全程参与
  - 部分合议庭成员作用发挥不够（"合而不议""陪而不审""一言堂"）
- 理想情境中的合议制：
  - 群体决策的心理机制（多数决策规则、有效获取决策信息、克服从众心理、防止被少数人控制、明确各成员具体责任）
  - 合议庭评议表决规则的理性构建（充分讨论、合理提炼归纳、禁止弃权规则、限定发言顺序、限制复议规则、禁止结论性简单表态、同时亮出观点）
  - 加强对合议庭的监管和建设
- 推行院庭长阅核制度

**第三讲：专业法官会议的讨论原理与规则**
- 专业法官会议的会议属性（议题提交、召开、主持）
- 专业法官会议讨论的主要步骤：汇报→讨论→表决
- 专业法官会议运行中可能存在的问题：
  - 议事程序行政化
  - 审议程序简单化
  - 缺少当事人参与
  - 责任追究有待细化
  - 会议成果转化不足
- 专业法官会议的十二项议事规则：
  - 动议中心原则、主持中立原则、机会均等原则、立场明确原则
  - 发言完整原则、面对主持原则、限时限次原则、一时一件原则
  - 遵守裁判原则、文明表达原则、充分辩论原则、多数裁决原则

**第四讲：审委会讨论案件的原理与规则**
- 审委会的历史沿革及改革历程（从"一五改革"到"四五改革"）
- 审委会的制度定位：
  - 本质是集体决策
  - 经过实践检验符合中国国情
  - 在坚持中不断发展完善
- 审委会的会议属性及议事规则：汇报→讨论→表决→固化
- 审委会与专业法官会议的异同和衔接
- 审委会运行中可能存在的问题与改革方向
- 审委会秘书的角色定位与职业规范

**第五讲：案件汇报**
- 汇报的原理：完整的双向"信息沟通"过程
- 汇报的基本要求：
  - 书面汇报（让阅卷笔录成为审查报告草稿、事实证据排列符合认知规律、站在听众立场撰写）
  - 口头汇报（开场白设定、汇报被告人基本情况、侦破及抓获经过、案件事实及证据、检辩双方争议情况、存在问题及所做工作）
  - 基本要求：简明扼要、客观全面、观点明确
- 汇报的基本方法：顺叙汇报法、倒叙汇报法、人物关系汇报法、逐罪汇报法、逐次汇报法、表格式汇报法
- 典型案件汇报技巧：命案、经济犯罪、毒品犯罪、事实证据分歧、法律适用分歧、量刑分歧案件

**第六讲：案件讨论方法**
- 一般讨论方法：
  - 提出有效问题的方法（策略性提问、开放式问题讨论、焦点问题自由讨论）
  - 积极倾听的方法（提问与反馈、重复或转述、各抒己见、接力回应）
  - 针对书面材料进行讨论的方法
  - 让讨论民主化的方法
- 合议庭评议步骤与方法：
  - 一人多次犯一罪：逐次评议法、逐段评议法
  - 一人多次犯数罪：逐罪评议法、逐次评议法
  - 多人多次犯一罪：逐人评议法、逐人逐次评议法
  - 多人多次犯数罪：分别评议法
- 典型案件讨论技巧：命案、经济犯罪、毒品犯罪、事实证据分歧、法律适用分歧案件

**第七讲：讨论能力的培养**
- 掌握能力要求：案件汇报能力、主持讨论能力、参与评议能力
- 加强实践锻炼：汇报技能、主持技能、评议技能
- 加强培训观摩：跟庭学习、参与合议庭和专业法官会议讨论、观看讨论录像或书面记录

## 关键概念

### 专业法官会议十二项议事规则

| 原则 | 核心要求 |
|------|----------|
| 动议中心原则 | 动议是讨论的前置程序，一次一个议题 |
| 主持中立原则 | 主持人不得对议题表态 |
| 机会均等原则 | 主持人准许才能发言，"双方轮流发言" |
| 立场明确原则 | 先讲态度再讲理由，"明确"意味着"确定不移" |
| 发言完整原则 | 不得打断别人正当发言 |
| 面对主持原则 | 严禁参会者直接辩论 |
| 限时限次原则 | 至少发言一次，遵循限时限次规定 |
| 一时一件原则 | 同时只讨论一个议题 |
| 遵守裁判原则 | 服从主持人的裁判 |
| 文明表达原则 | 遵守文明礼仪和议事礼节 |
| 充分辩论原则 | 真理越辩越明 |
| 多数裁决原则 | 过半数表决，复杂案件三分之二 |
