# 抢劫罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(基础)** | 三年以上十年以下有期徒刑 + 罚金 | **3-6 年** |
| **第二档(8 种情节)** | 十年以上有期徒刑 / 无期 / 死刑 | **10-13 年** |
| **第三档** | 数罪并罚 | — |

## 二、第一档 · 3-6 年起刑点

**入罪触发**:抢劫一次;或转化的抢劫罪(盗窃 / 诈骗 / 抢夺未达数额较大但当场使用暴力)。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 抢劫财物每多 1000 元 | + **1 月** |
| 抢劫 +1 次 | + **1-3 年** |
| 轻微伤 +1 | + **3-6 月** |
| 轻伤 +1 | + **6 月-1 年** |
| 10-7 级残疾 +1 级 | + **3-6 月** |

## 三、第二档 · 10-13 年起刑点

**入罪触发**(任一):
1. 入户抢劫
2. 在公共交通工具上抢劫
3. 抢劫银行或其他金融机构
4. 抢劫 3 次 或 数额达数额巨大起点
5. 抢劫致 1 人重伤
6. 冒充军警人员抢劫
7. 持枪抢劫
8. 抢劫军用物资或抢险 / 救灾 / 救济物资

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 数额达数额巨大 + 每多 5000 元 | + **1 月** |
| 超过 3 次 + 每多 1 次 | + **1-3 年** |
| 轻微伤 +1 | + **3-6 月** |
| 轻伤 +1 | + **6 月-1 年** |
| 重伤 +1 | + **1-2 年** |
| 10-7 级残疾 +1 级 | + **3-6 月** |
| 6-3 级残疾 +1 级 | + **6 月-1 年** |
| 2-1 级残疾 +1 级 | + **2-3 年** |
| 每多 1 项刑法 263 规定情形 | + **1-2 年** |

## 四、从重情节(5 类 · +20% 以下)

1. 为实施其他违法活动而抢劫
2. 流窜作案
3. 在公共场所当众抢劫
4. 持械具或其他凶器抢劫
5. 其他从重情形

## 五、从轻情节(3 类 · −10% 以下)

1. 因生活所迫 / 学习 / 治病急需 + 人身危险性不大
2. 抢劫家庭成员或近亲属财物
3. 其他从轻情形

## 六、罚金

- 3-10 年:**2000-100000 元**(分梯度:3-5 年 2000-40000 / 5-7 年 5000-50000 / 7-10 年 10000-100000)
- 10 年以上:**10000-200000 元**(10-12 年 10000-150000 / 12 年以上 30000-200000)

## 七、缓刑适用 — **从严**

**一般可以适用**(任一):
1. 生活所迫 / 学习 / 治病急需 + 初次 + 数额不大 + 未造成伤害 / 谅解
2. 共同犯罪从犯 + 未参与分赃
3. 抢劫家庭成员或近亲属 + 谅解
4. 其他可以适用情形

## 八、相比同类规范的核心差异

| 维度 | 安徽(本页) | 两高 |
|------|------------|------|
| 第一档起点 | 3-6 年 | 3 年 |
| 第二档起点 | 10-13 年 | 10 年 |
| 数额巨大递增 | 每多 5000 元 + 1 月 | 类似 |
