## 量刑档次

### 生产、销售假药罪（第141条）
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：对人体健康造成严重危害或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：致人死亡或有害特别严重情节 → 10年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产

### 生产、销售不符合安全标准的食品罪（第143条）
- 档1：足以造成严重食物中毒事故或其他严重食源性疾病 → 3年以下有期徒刑或拘役，并处罚金
- 档2：对人体健康造成严重危害或其他严重情节 → 3年以上7年以下有期徒刑，并处罚金
- 档3：后果特别严重 → 7年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 生产、销售有毒、有害食品罪（第144条）
- 档1： → 5年以下有期徒刑，并处罚金
- 档2：对人体健康造成严重危害或其他严重情节 → 5年以上10年以下有期徒刑，并处罚金
- 档3：致人死亡 → 依照第141条处罚（10年以上/无期/死刑）

### 走私武器、弹药罪（第151条第1款）
- 档1：情节较轻 → 3年以上7年以下有期徒刑，并处罚金
- 档2： → 7年以上有期徒刑，并处罚金或没收财产
- 档3：情节特别严重 → 无期徒刑，并处没收财产

### 走私文物罪、贵重金属罪（第151条第2款）
- 档1：情节较轻 → 5年以下有期徒刑，并处罚金
- 档2： → 5年以上10年以下有期徒刑，并处罚金
- 档3：情节特别严重 → 10年以上有期徒刑或无期徒刑，并处没收财产

### 走私国家禁止进出口货物罪（第151条第3款）
- 档1：情节较轻 → 5年以下有期徒刑，并处罚金
- 档2： → 5年以上有期徒刑，并处罚金

### 走私普通货物、物品罪（第153条）
- 档1：偷逃税额较大/一年内曾因走私被二次行政处罚后又走私 → 3年以下有期徒刑或拘役，并处偷逃税额1倍以上5倍以下罚金
- 档2：偷逃税额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处偷逃税额1倍以上5倍以下罚金
- 档3：偷逃税额特别巨大或有其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处偷逃税额1倍以上5倍以下罚金或没收财产

### 组织出卖人体器官罪（第234条之一）
- 档1： → 5年以下有期徒刑，并处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金或没收财产

### 强迫劳动罪（第244条）
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节严重 → 3年以上10年以下有期徒刑，并处罚金

### 盗窃罪（第264条）
- 档1：数额较大/多次盗窃/入户盗窃/携带凶器盗窃/扒窃 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 敲诈勒索罪（第274条）
- 档1：数额较大或多次敲诈勒索 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑，并处罚金

### 拒不支付劳动报酬罪（第276条之一）
- 档1：数额较大，经政府有关部门责令支付仍不支付 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：造成严重后果 → 3年以上7年以下有期徒刑，并处罚金

### 寻衅滋事罪（第293条）
- 档1： → 5年以下有期徒刑、拘役或管制
- 档2：纠集他人多次实施，严重破坏社会秩序 → 5年以上10年以下有期徒刑，可以并处罚金

### 组织、领导、参加黑社会性质组织罪（第294条）
- 档1：组织、领导 → 7年以上有期徒刑，并处没收财产
- 档2：积极参加 → 3年以上7年以下有期徒刑，可以并处罚金或没收财产
- 档3：其他参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利，可以并处罚金

### 传授犯罪方法罪（第295条）
- 档1： → 5年以下有期徒刑、拘役或管制
- 档2：情节严重 → 5年以上10年以下有期徒刑
- 档3：情节特别严重 → 10年以上有期徒刑或无期徒刑

### 盗掘古文化遗址、古墓葬罪（第328条）
- 档1：情节较轻 → 3年以下有期徒刑、拘役或管制，并处罚金
- 档2： → 3年以上10年以下有期徒刑，并处罚金
- 档3：有法定加重情形 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 污染环境罪（第338条）
- 档1：严重污染环境 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：后果特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 非法采矿罪（第343条）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 协助组织卖淫罪（第358条第3款）
- 档1： → 5年以下有期徒刑，并处罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处罚金

### 食品安全监管渎职罪（第408条之一）
- 档1：造成严重后果或恶劣影响 → 5年以下有期徒刑或拘役
- 档2：造成特别严重后果 → 5年以上10年以下有期徒刑
