# 民法典适用大全·总则卷（一）

| 字段 | 内容 |

## 内容定位

本卷是最高人民法院编著的民法典司法适用权威工具书总则卷第一册，围绕《民法典》总则编第1条至第75条，系统编辑关联规定、条文释义、适用指引、指导案例、典型案例和类案检索，形成完整的总则编司法适用参考体系。

**体例结构**：每个条文按"关联规定→条文释义→适用指引→指导案例/典型案例→类案检索"六部分组织。

## 章节结构总览

### 第一章 基本规定（第1-12条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1条 | 立法目的和依据 | 保护民事主体合法权益；调整民事关系；维护社会经济秩序；适应中国特色社会主义发展要求；弘扬社会主义核心价值观 |
| 第2条 | 调整范围 | 平等主体的自然人、法人和非法人组织之间的人身关系和财产关系 |
| 第3条 | 民事权益受法律保护 | 人身权利、财产权利及其他合法权益受法律保护，任何组织或个人不得侵犯 |
| 第4条 | 平等原则 | 民事主体法律地位一律平等 |
| 第5条 | 自愿原则 | 按照自己的意愿设立、变更、终止民事法律关系 |
| 第6条 | 公平原则 | 合理确定各方权利义务 |
| 第7条 | 诚信原则 | 秉持诚实，恪守承诺 |
| 第8条 | 合法性原则、公序良俗原则 | 不得违反法律，不得违背公序良俗 |
| 第9条 | 绿色原则 | 节约资源、保护生态环境 |
| 第10条 | 处理民事纠纷的依据 | 法律→习惯→法理 |
| 第11条 | 优先适用特别法 | 其他法律对民事关系有特别规定的，依照其规定 |
| 第12条 | 效力范围 | 在中华人民共和国领域内的民事活动，适用中华人民共和国法律 |

### 第二章 自然人（第13-56条）

#### 第一节 民事权利能力和民事行为能力（第13-25条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第13条 | 民事权利能力的起止 | 自然人从出生时起到死亡时止 |
| 第14条 | 民事权利能力平等 | 自然人的民事权利能力一律平等 |
| 第15条 | 出生和死亡时间 | 以出生证明、死亡证明记载的时间为准 |
| 第16条 | 胎儿利益保护 | 涉及遗产继承、接受赠与等，胎儿视为具有民事权利能力 |
| 第17条 | 成年人和未成年人 | 18周岁以上的自然人为成年人 |
| 第18条 | 完全民事行为能力人 | 成年人；16周岁以上以自己劳动收入为主要生活来源的 |
| 第19条 | 限制民事行为能力的未成年人 | 8周岁以上不满18周岁 |
| 第20条 | 无民事行为能力的未成年人 | 不满8周岁 |
| 第21条 | 无民事行为能力的成年人 | 不能辨认自己行为的成年人 |
| 第22条 | 限制民事行为能力的成年人 | 不能完全辨认自己行为的成年人 |
| 第23条 | 法定代理人 | 无、限制民事行为能力人的监护人是法定代理人 |
| 第24条 | 认定与恢复 | 法院可认定或恢复民事行为能力 |
| 第25条 | 自然人的住所 | 户籍登记或其他有效身份登记记载的居所为住所 |

#### 第二节 监护（第26-39条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第26条 | 父母子女法律义务 | 父母抚养、教育、保护未成年子女；成年子女赡养、扶助、保护父母 |
| 第27条 | 未成年人的监护人 | 父母→祖父母/外祖父母→兄姐→其他个人或组织 |
| 第28条 | 成年人的监护人 | 配偶→父母/子女→其他近亲属→其他个人或组织 |
| 第29条 | 遗嘱指定监护 | 被监护人的父母可通过遗嘱指定监护人 |
| 第30条 | 协议确定监护 | 有监护资格的人可协议确定监护人 |
| 第31条 | 指定监护 | 对监护人有争议的，由被监护人住所地的居委会/村委会或民政部门指定；可申请法院指定 |
| 第32条 | 公职监护人 | 没有依法具有监护资格的人的，由民政部门或居委会/村委会担任 |
| 第33条 | 意定监护 | 具有完全民事行为能力的成年人可事先协商确定监护人 |
| 第34条 | 监护职责 | 代理被监护人实施民事法律行为，保护被监护人人身权利、财产权利等 |
| 第35条 | 监护职责履行 | 最有利于被监护人的原则；尊重被监护人真实意愿 |
| 第36条 | 撤销监护人资格 | 实施严重损害被监护人身心健康行为等情形，法院可撤销 |
| 第37条 | 负担义务不免除 | 被撤销监护资格的人应继续负担抚养费、赡养费等 |
| 第38条 | 恢复监护人资格 | 确有悔改表现的，经申请可恢复 |
| 第39条 | 监护关系终止 | 被监护人取得或恢复完全民事行为能力；监护人丧失监护能力等 |

#### 第三节 宣告失踪和宣告死亡（第40-53条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第40条 | 宣告失踪的条件 | 下落不明满2年 |
| 第41条 | 下落不明的时间计算 | 从失去音讯之日起计算 |
| 第42条 | 财产代管人 | 配偶、父母、成年子女或其他愿意担任的人 |
| 第43条 | 财产代管人的职责 | 妥善管理失踪人的财产 |
| 第44条 | 财产代管人的变更 | 不履行代管职责等，利害关系人可申请变更 |
| 第45条 | 失踪宣告的撤销 | 重新出现或确知下落的，经申请撤销 |
| 第46条 | 宣告死亡的条件 | 下落不明满4年；意外事件下落不明满2年 |
| 第47条 | 宣告死亡和失踪的关系 | 符合宣告死亡条件的，可同时申请 |
| 第48条 | 死亡日期确定 | 判决作出之日视为死亡日期 |
| 第49条 | 实际生存时的行为效力 | 被宣告死亡人在实际生存地实施的民事法律行为有效 |
| 第50条 | 死亡宣告的撤销 | 重新出现或确知未死亡的，经申请撤销 |
| 第51条 | 对婚姻关系的影响 | 配偶未再婚的，婚姻关系自撤销之日起自行恢复 |
| 第52条 | 对收养关系的影响 | 被宣告死亡人的子女被他人收养的，不得主张收养无效 |
| 第53条 | 财产返还 | 撤销死亡宣告后有权请求返还财产 |

#### 第四节 个体工商户和农村承包经营户（第54-56条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第54条 | 个体工商户 | 自然人依法登记从事工商业经营 |
| 第55条 | 农村承包经营户 | 农村集体经济组织成员依法取得土地承包经营权 |
| 第56条 | 债务承担 | 个体工商户：个人经营的以个人财产承担，家庭经营的以家庭财产承担；农村承包经营户：以家庭财产承担 |

### 第三章 法人 第一节 一般规定（第57-75条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第57条 | 法人的定义 | 依法成立，有自己的名称、组织机构、住所、财产或经费 |
| 第58条 | 法人的成立条件 | 依法成立；有自己的名称、组织机构和住所；有财产或经费 |
| 第59条 | 法人的民事权利能力和行为能力 | 从成立时产生，到终止时消灭 |
| 第60条 | 法人的独立责任 | 法人以其全部财产独立承担民事责任 |
| 第61条 | 法定代表人 | 代表法人从事民事活动的负责人 |
| 第62条 | 法定代表人职务行为的责任 | 法人承担民事责任后可向有过错的法定代表人追偿 |
| 第63条 | 法人的住所 | 主要办事机构所在地 |
| 第64条 | 法人的变更登记 | 登记事项变更的，应办理变更登记 |
| 第65条 | 法人登记的对抗效力 | 实际情况与登记事项不一致的，不得对抗善意相对人 |
| 第66条 | 登记信息公示 | 登记机关应公示法人登记信息 |
| 第67条 | 法人的合并、分立 | 合并后的法人承受权利义务；分立后的法人享有连带债权、承担连带债务 |

## 核心制度解读

### 一、民法典的立法目的与核心价值（第1条）

**立法目的五重维度**：
1. **保护民事主体合法权益**：民法是私法领域落实宪法人权保障制度的基本法律，将宪法权利具体化、法治化
2. **调整民事关系**：核心是调整权利义务关系，通过规定民事责任落实对正常民事关系的保护
3. **维护社会和经济秩序**：设定法律规则厘定、维护社会秩序，是市场经济的基本法
4. **适应中国特色社会主义发展要求**：将四十多年来改革成果制度化、体系化
5. **弘扬社会主义核心价值观**：核心价值观塑造了民法典的精神灵魂

**适用指引要点**：法官应在裁判文书中加强以社会主义核心价值观为依据的分析说理工作。

### 二、民法调整范围（第2条）

**三个要件**：
1. **主体平等性**：法律地位平等、适用规则平等、权利保护平等
2. **主体类型**：自然人、法人、非法人组织三类
3. **关系类型**：人身关系和财产关系（人身关系置于财产关系之前，体现以人为本理念）

**实践要点**：行政机关履行行政职责与行政相对人形成的非平等法律关系不属于民事关系。

### 三、监护制度（第26-39条）

**制度创新**：
- **意定监护**（第33条）：完全民事行为能力的成年人可事先协商确定监护人，体现对被监护人意愿的尊重
- **最有利于被监护人原则**（第35条）：履行监护职责应最大程度尊重被监护人真实意愿
- **撤销监护人资格**（第36条）：实施严重损害被监护人身心健康行为等情形，法院可撤销

### 四、宣告失踪与宣告死亡制度（第40-53条）

**制度要点**：
- 宣告失踪：下落不明满2年，利害关系人可申请
- 宣告死亡：下落不明满4年（意外事件满2年），判决作出之日视为死亡日期
- 死亡宣告撤销后：配偶未再婚的婚姻关系自行恢复；子女被他人收养的不得主张无效

### 五、法人制度一般规定（第57-75条）

**法人独立责任**（第60条）：法人以其全部财产独立承担民事责任，出资人以出资额为限承担有限责任。

**法定代表人**（第61-62条）：法定代表人因执行职务造成他人损害的，由法人承担民事责任；法人承担后可向有过错的法定代表人追偿。

## ❓ 常见问题

> 问：胎儿是否有民事权利能力？
> 答：涉及遗产继承、接受赠与等胎儿利益保护的，胎儿视为具有民事权利能力（第16条）。但胎儿娩出时为死体的，其民事权利能力自始不存在。

> 问：8周岁以下儿童实施的民事法律行为效力如何？
> 答：不满8周岁的未成年人为无民事行为能力人，由其法定代理人代理实施民事法律行为（第20条）。

> 问：意定监护与法定监护的效力哪个优先？
> 答：意定监护优先于法定监护。具有完全民事行为能力的成年人可通过书面协议确定监护人（第33条），该协议在该成年人丧失或部分丧失民事行为能力时生效。

> 问：法人分支机构的民事责任由谁承担？
> 答：分支机构以自己的名义从事民事活动，产生的民事责任由法人承担；也可以先以该分支机构管理的财产承担，不足以承担的，由法人承担（第74条）。

> 问：法定代表人因执行职务造成他人损害，责任如何承担？
> 答：由法人承担民事责任。法人承担民事责任后，依照法律或者法人章程的规定，可以向有过错的法定代表人追偿（第62条）。
