## 一、立法目的（第1条）

1. **规范公司的组织和行为** — 提供制度设计，使公司规范设立和经营管理
2. **保护公司、股东、职工和债权人的合法权益** — 明确规定权利义务，对内规范公司与股东关系，对外规范公司与其他市场主体关系
3. **完善中国特色现代企业制度，弘扬企业家精神** — 落实党的二十大报告要求
4. **维护社会经济秩序，促进社会主义市场经济的发展** — 为基础性法律，为市场主体提供公平、诚信、有序的市场环境

## 二、公司形式与法律地位（第2-4条）

### 公司形式（第2条）

| 公司类型 | 特征 |
|----------|------|
| **有限责任公司** | 资合公司，具有较强人合性；资本不划分为等额股份；治理结构灵活；股权转让受限制 |
| **股份有限公司** | 资合公司典型；可公开发行股票筹集资本；资本划分为等额股份；治理结构健全完备 |

### 法人地位（第3条）

- **企业法人** — 营利法人，具有民事权利能力和民事行为能力
- **独立法人财产** — 自主经营、自负盈亏的物质基础，来源包括：股东出资、盈利积累、其他途径
- **以全部财产对债务承担责任** — 责任范围以全部财产为限，不追及股东个人财产

### 股东责任（第4条）

- 有限责任公司股东：以其认缴的出资额为限对公司承担责任
- 股份有限公司股东：以其认购的股份为限对公司承担责任

## 三、2023年修订核心变化

本释义对应2023年12月29日修订的《中华人民共和国公司法》，主要修订包括：

1. **完善公司资本制度** — 强化股东出资责任，完善股份有限公司授权资本制
2. **优化公司治理** — 允许选择单层制（审计委员会）或双层制（监事会）
3. **完善股权转让规则** — 简化对外转让程序，删除"同意"规则，仅保留优先购买权
4. **强化董事、监事、高级管理人员义务** — 完善忠实义务和勤勉义务的具体内容
5. **强化股东权利保护** — 完善股东知情权、股东代表诉讼制度
6. **加强债权人保护** — 完善公司法人人格否认制度

## 四、有限责任公司组织机构

### 董事会

| 要点 | 内容 |
|------|------|
| 人数 | 三人以上（规模较小或股东较少的可设一名董事） |
| 任期 | 由章程规定，每届不得超过三年，连选可以连任 |
| 职权（第67条） | 执行股东会决议、决定经营计划、制定方案等 |
| 议事规则 | 过半数董事出席方可举行；决议经全体董事过半数通过；一人一票 |
| 召集主持 | 董事长→副董事长→过半数董事共同推举一名董事 |

### 监事会

| 要点 | 内容 |
|------|------|
| 人数 | 三人以上（规模较小或股东较少的可设一名监事；经全体股东一致同意也可不设） |
| 组成 | 股东代表 + 适当比例职工代表（职工代表比例不得低于三分之一） |
| 任期 | 三年，连选可以连任 |
| 主席 | 由全体监事过半数选举产生 |
| 职权（第78条） | 检查公司财务、监督董事高管、执行职务行为、提议召开临时股东会、提案、对董事高管提起诉讼等 |

### 经理

- **设置**：由董事会决定聘任或者解聘（可设可不设）
- **职权**：由公司章程规定或董事会授予，受董事会监督
- **法律中的"经理"**：指对公司日常经营管理工作负总责的人员（相当于总经理），不同于实践中部门经理

## 五、股权转让（第四章）

### 股东之间转让

有限责任公司的股东之间可以相互转让其全部或者部分股权，无限制。

### 对外转让（第84条）

**程序简化**（2023年修订删除了"同意"规则）：
1. 书面通知其他股东（载明数量、价格、支付方式和期限）
2. 其他股东三十日内答复，逾期未答复视为放弃优先购买权
3. 两个以上股东行使优先购买权的，协商确定比例；协商不成的按转让时各自出资比例

### 特殊规定

- 公司章程对股权转让另有规定的，从其规定
- 股权强制转让、继承等情形另有规定

## 六、董事、监事、高级管理人员义务（第八章）

### 忠实义务和勤勉义务（第180条）

- **守法合规义务** — 应当遵守法律、行政法规和公司章程（第179条）
- **忠实义务** — 不得有第181条禁止的行为（挪用公司资金、违规担保、自我交易、竞业禁止等）
- **勤勉义务** — 执行职务应当为公司的最大利益尽到管理者通常应有的合理注意

### 归入权（第186条）

公司可以行使归入权，将董事、监事、高级管理人员违反忠实义务所得收入归入公司。

### 股东代表诉讼（第189条）

董事、高级管理人员损害公司利益时，股东可书面请求监事会提起诉讼。

## 七、公司法人人格否认（第23条）

公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任。
