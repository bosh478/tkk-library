# 第二十六章

一句话说明：从文书物证司法鉴定的基础理论、质量控制、历史发展到各类鉴定技术方法的系统性教材。

# 第二十六章 基於文件材料特性的文件製作时间鉴定

## 第一节概 述

文件制作时间鉴定，是对形成时间不明的或对其标称时间有争议的可疑文件进行检验，根据所获取的科学事实，对其实际形成时间所做的鉴别和判断。在检验方法上可分为“基于痕迹特征的件制作时间鉴定”和“基于材料特性的件制作时间鉴定”两类。前者在本书第六部分已有详述；后者则是指根据墨水墨迹、油墨墨迹、墨粉墨迹、印文色料、纸张等文件材料的理化特性随时间的变化规律，分析判断文件的制作时间，因此又分出了“书写时间”“盖印/捺印时间”等具体项。

件制作时间鉴定中会遇到以下个概念：

（1）“文件标称时间”与“文件实际制作时间” “件标称时间”是指件上标注的落款期；“文件实际制作时间”是指件实际的形成时间。

（2）“绝对制作时间”与“相对制作时间” “绝对制作时间”是指件客观的形成时间，般以具体的时间来描述；“相对制作时间”是指不同的件或同份件的不同部分之间形成的顺序，一般以形成先后或者是否一次、同时、相近时期制作形成来描述。

(3）“检测时间” 指可疑文件送到鉴定机构后，鉴定人员取样进行理化检测的时间。对于些根据件短期内理化特性变化来判断件是否近期形成的鉴定法，“检测时间”与“件实际制作时间”的间隔关系到法的有效性，如通过检测墨迹中挥发性溶剂的含量（或含量变化)来判断书写时间的方法。

(4）“比对样本” 大部分基于材料特性的件制作时间鉴定方法需要有“比对样本”。此类样本通常要求是与送检文件制作材料种类相同、形成时间明确，以及保存条件相同的文件样本。由于文件材料种类众多，成分复杂，只有通过与同类材料的比较，才能获知这类文件材料的历时性变化情况，从而判断送检文件的材料状态。换言之，基于材料特性的文件制作时间鉴定方法大部分是根据已知时间的样本来判断送检文件与样本之间的“相对制作时间”鉴定，因此“对样本”分重要。

用于文件材料理化检验的常用分析方法有显微分光光度法、红外光谱法、拉曼光谱法、气相谱法、薄层谱法、液相谱法、毛细管电泳法[2²]、质谱法等，其基本原理和特点参见第二十五章第一节中有关内容。借助这些仪器分析方法，鉴定人可对文件材料的状态进行检测，根据常见文件材料的历时性变化规律，通过与样本的比对或与自身的比对，来判断文件的形成时间。

## 第二节 书写墨的特征成分及历时性变化研究

随着化学工业的发展，书写工具也在不断发展：20世纪30\~40年代，我国常见的书写工具是毛笔、钢笔和铅笔；1945年圆珠笔传入我国；1980年后，中性笔出现，在20世纪90年代前后在我国逐渐推广。在这一历程中，制笔技术发展迅速，出墨系统和墨水配方都有了很大的进步。现在，快干、色牢度好、价格经济的中性笔已成了人们日常生活中最常用的书写工具，在此基础上，还出现了可擦型中性笔；而传统的圆珠笔、钢笔仍有一定的受众，因此，这三类书写墨是文件制作时间鉴定研究中的主要研究对象。无论是性的钢笔墨、油性的圆珠笔油墨还是黏度体系介于两者之间的中性笔墨水，从功能上分，其墨水成分基本分为着色剂、溶剂和其他助剂，其中，着色剂又分为不溶性的颜料和可溶性的染料两类。目前，可检测的墨水特征成分主要有铁盐和硫酸盐（钢笔）、染料和挥发性的醇类有机溶剂。

## （一）硫酸盐扩散法

## (二）溶解法

1937年，英国的米切尔（Mitchell)提出了用草酸溶解钢笔字迹来判断形成时间的方法。他发现新鲜的墨迹经草酸处理会立即溶解，而书写三四年以上的字迹笔画几乎看不到这种现象。这种法的原理：新鲜书写的鞣酸铁墨字迹中，溶性的 $\mathrm { F e } ^ { 2 + }$ 盐含量大,难溶的 $\mathrm { F e } ^ { 3 + }$ 盐含量低，因此墨迹能用草酸溶解；而形成时间久的钢笔墨迹中， $\mathrm { F e } ^ { 3 + }$ 盐相对含量高，故难以溶解。这一方法用到的主要试剂是5%草酸水溶液，通过测量溶解时间来判断墨迹的新旧程度[4]。

在此基础上，研究人员又陆续建立了“溶压-转印”、“溶解-透析”和“双溶剂溶解提取”等方法。“溶压-转印”方法是用浸润了5%草酸溶液的承印纸覆盖于待检字迹表面，在一定压力下使待检字迹中的墨水成分溶解、转印到承印纸上，再通过测定转印的墨迹含量与原字迹的墨迹含量值（灰度），来较墨待检字迹的形成先后[5]。“溶解-透析”法是特殊的透析液一步完成“溶解-透析”的过程：蓝黑钢笔墨迹被透析液溶解后，有色成分浮现于白色的透析液表面，通过测定透析液表面墨水显现的时间或者显现的墨水量（灰度值）来判断膜墨迹的新旧程度。透析液的成分有二甲基甲酰胺（DMF）、无水乙醇、表面活性剂和 $\mathrm { T i O } _ { 2 }$ [6]。“双溶剂溶解提取”法是采用弱溶解性和强溶解性的两种溶剂，依次溶解待检墨迹，然后分别测定弱溶剂和强溶剂提取液的薄层扫描信号强度，通过比较“溶解百分率”来判断墨迹的新旧程度。其理论依据是新鲜墨迹的溶解提取率高，陈旧墨迹的溶解提取率低，而合适的弱溶剂能区分不同形成时间的墨迹。根据具体的研究对象，强、弱溶剂的组成或有不同，可以采用50%乙醇溶液作为弱溶剂、醇--36%醋酸(1：2：1)混合溶液作为强溶剂7]。从后两种法来看，溶解钢笔墨迹的溶剂有所改进，但依据溶解时间长短判断墨迹形成时间的基本思路没有变。

需要注意的是，溶解法仍然受墨水种类、纸张种类和保存条件等因素的影响，在应用时应充分考虑这些因素的影响，在同类墨迹之间进行比较。

## (三) $\mathsf { F e } ^ { 2 + } / \mathsf { F e } ^ { 3 + }$ 浓度测定法

蓝黑钢笔字迹中的 $\mathrm { F e } ^ { 2 + }$ 会随时间逐渐氧化成 $\mathrm { F e } ^ { 3 + }$ ，通过比较待测墨迹中这两种离子的相对含量，可判断相同环境下同种类墨迹的形成先后。

又如， $\mathrm { F e } ^ { 2 + }$ 在弱酸性介质中与邻菲啰啉 $\displaystyle ( \mathrm { C } _ { 1 2 } \mathrm { H } _ { 8 } \mathrm { N } _ { 2 } )$ 作用，形成红色络合物 $\big [ \mathrm { F e } ( \mathrm { C } _ { 1 2 } \mathrm { H } _ { 8 } \mathrm { N } _ { 2 } ) _ { 3 } \big ] ^ { 2 + }$ ,该络合物在515nm有特征吸收，且没有 $\mathrm { F e } ^ { 3 + }$ 干扰； $\mathrm { F e } ^ { 3 + }$ 与磺基水杨酸 $\mathrm { ( ~ C _ { 7 } H _ { 1 0 } O _ { 8 } S ) }$ 作用，反应产物在460nm有特征吸收，同样，没有 $\mathrm { F e } ^ { 2 + }$ 干扰[8]。

## （四）其他方法

墨水中的染料多为芳烃化合物，在墨迹的氧化过程中，这些染料也会逐渐降解。利用合适的检测方法对染料原体和降解产物的相对含量进行分析，能反映出墨迹中染料的降解程度。由于钢笔墨水成分中含有许多酸性基团，如 $\mathrm { S O } _ { 4 } ^ { 2 - }$ ，进行液相色谱分析时，需要在流动相中加入离子对试剂（如四丁基溴化铵），中和酸性基团，使被分析物呈中性，从而在C18等常规色谱柱上得以保留[10]

钢笔墨水中还含有甘油、乙二醇等小分子醇类化合物，它们被用作润湿剂，使墨水在笔尖上保持湿润，不易结[3]。这类成分在墨迹中随时间增加逐渐减少，故可以应相谱(-质谱)法[1]来检测钢笔墨迹中的油、乙醇含量,进判断墨迹的形成时间范围或形成先后。

## 二、圆珠笔墨迹

从字面意义来说，“圆珠笔”指的是利用滚珠作为笔尖的笔，包括水性、中性、油性墨水笔。而我们现在通常所说的圆珠笔，特指使用油性墨水作为书写媒介的滚珠笔。圆珠笔油墨是由颜料/染料、树脂、有机溶剂和其他添加剂组成的黏稠状液体。圆珠笔自20世纪40年代问世，随后其笔尖、笔芯的制作技术不断改进，书写字迹的色泽鲜艳，墨迹快干。时至今日，圆珠笔仍然是人们常用的书写具之一。关于圆珠笔字迹的形成时间鉴定，国内外都开展了多年的研究，主要依据墨迹中染料的降解、有机溶剂的挥发及溶解性能的变化来判断墨迹的形成时间。

## (一)染料法

般蓝或圆珠笔油墨中常的染料包括结晶紫、甲基紫、维多利亚蓝B和碱性蓝7（结构式见图26-1)。这些染料均为芳基甲烷类染料，化学结构不稳定，尤其在光照条件下，会陆续丢失结构中的甲基或乙基。以结晶紫为例（图26-2），丢失一个甲基时，生成甲基紫；丢失两个甲基时，成TPR[12](tetramethylpara rosaniline，又称碱性品蓝）。通过在同检测条件下较这些降解产物与结晶紫的相对含量，可以测定结晶紫的降解例。在制作圆珠笔油墨时，厂家会同时使用多种染料，加之染料生产工艺中可能存在副产物，因此，即使新鲜书写的圆珠笔墨迹中也能检出含量不低的甲基紫和TPR[12]。

式中 $, A _ { i }$ 表示目标物的峰面积， $\boldsymbol { A } _ { t o t }$ 表染料原体（结晶紫）与降解产物（甲基紫、TPR及后续可测得的降解产物)的峰积之和[13\~14]。其中,结晶紫的相对含量随时间逐渐减少，但降解产物如甲基紫、TPR的相对含量可能经历个先增加后减少的过程,也可能单向减少，具体的变化取决于被测圆珠笔油墨中3种成分的初始含量与降解速度。

研究表明，避光存放的圆珠笔墨迹中碱性染料的降解速度较小，而受到光照后染料的降解速度较快[12]。因此,对于妥善保存的件上的圆珠笔字迹，染料法适于间隔时间较长（如3\~5年及以上)的墨迹之间形成时间先后的比较。此外，油墨、纸张及保存条件对墨迹中染料的降解速度都确定有影响。所以，不同种类的圆珠笔、不同类型纸张上的字迹或不同条件下保存的文件不能直接进行比较。

由于书写力度、滚珠质量等因素的影响，字迹上的圆珠笔油墨分布并不均匀。直接检测墨迹中的挥发性溶剂进含量比较不可避免地会受到墨迹分布的影响。为了减少这种影响带来的分析误差，理想的解决方案是在墨迹样品中找到稳定的成分作为内标，其次是通过多次检测与样品自身进比较。为此，研究员建了不同参数的比值法。

“双溶剂提取法”由俄罗斯的阿斯基（Aginsky）先提出,基本原理是新鲜书写墨迹中的挥发性溶剂含量高且易于被提取；而陈旧墨迹中挥发性溶剂含量少，且由于树脂固化难于被提取。该方法对同一墨迹样品用“强”“弱”两种溶剂提取两次，分别进气相色谱分析，然后用每次提取液中目标物的含量作为比值，以该比值的大小判断墨迹形成时间先后。其中，“弱溶剂”是指提取能力较弱的溶剂，合适的弱溶剂应能区分新鲜和陈旧墨迹；“强溶剂”是指提取能力较强的溶剂，理想状态下应能提取出墨迹中所有剩余挥发性溶剂[16]。

类似的法还有“次加热值法”。2008年德国的布格勒（Bügler）等提出热脱附-质联用仪（TD-GC/MS），检测同一份圆珠笔字迹样品在70℃加热20分钟后逸出的挥发性成分的含量M1和在200℃加热5分钟后逸出的挥发性成分的含量M2，建参数R%=M1/(M1+M2)×100%[17]。经过实验，布格勒等发现200℃加热5分钟的条件可以让圆珠笔墨迹中的大部分挥发性溶剂逸出;70℃加热20分钟的条件则较为温和，能区分新鲜墨迹和陈旧墨迹。此外，采用热脱附-GC/MS联用设备，加热逸出的挥发性成分在热脱附的冷阱部分富集，然后对冷阱快速升温，使富集成分次性进GC/MS进检测；完成第次加热检测后，同圆珠笔样品可以在仪器内次加热检测。动化的设备减少了操作带来的分析误差。

“溶剂-染料值法”最早也是由阿斯基提出[1⁸]，该法先四氯化碳提取圆珠笔字迹样品中的挥发性有机溶剂,提取液相谱分析,得到苯氧醇、2(2-苯氧基氧基)乙醇等挥发性物质的含量 $\mathrm { X } _ { \circ }$ 接着让样品干燥，继续添加甲基甲酰胺，用于提取圆珠笔字迹样品中的染料成分，提取液紫外-可见分光光度计计算595nm的吸光度值A。最后，值X/A对样品的书写时间作图，根据X/A的数值判断字迹形成时间先后。采这样的法，由样品量不均引的误差可以通过比值法消除一部分（无法完全消除，因为每种溶剂的提取率始终与样品量相关）。后来随着分析技术的发展，该法中于检测染料含量的紫外-可见分光光度法已被薄层扫描和液相谱所取代。为了提分析结果的准确性和重现性，使“溶剂-染料值法”和前述“双溶剂提取法”时,提取液中都应加内标以控制操作过程中的误差。

溶解法的创始人是日本的菊池（Kikutchi），在1963年，他发表了在圆珠笔字迹上滴加稀盐酸的实验结果。1980，坎图（Cantú）和布鲁内尔（Brunelle)提出：对于在同张纸上的同种圆珠笔墨迹，形成时间越早的墨迹，50%乙醇对其提取率越低、提取时间越长。他们认为该方法可于判断墨迹的相对形成时间。后来坎图和普罗夫(Prough)提取液的吸光度值来量化溶解的染料量,并引弱强双溶剂法以消除样品量的影响[16]。我国学者王世全等采双溶剂提取-薄层扫描法，测得圆珠笔墨迹中染料提取率随时间变化的曲线，用于判断墨迹的相对形成时间[19]。谢朋等研制了透析液,滴加在蓝圆珠笔字迹笔画上后,测量字迹在透析液表显现的时间显现时间与字迹形成时间呈正相关[20]。

为了解决比对样本难找的问题，2005年方邡提出“多次溶解法”，通过考察同一墨迹样品在一段时间内溶解率是否发生变化，来判断该墨迹是否近期形成。方法：取一段待测样品笔画，滴加溶剂（如50%乙醇溶液），测得起溶时间T1;剩余样品在避光条件下自然老化1\~2个月（或在35℃、相对湿度为50%\~70%的环境下加速老化10\~20天），再取一段样品笔画，同前操作，测得起溶时间T2。若T1与T2有明显变化，则样品字迹的形成时间在半年之内；反之，不作结论[21]。该法的优点在于采用身对照，克服了墨配、保存环境、纸张等因素的影响，但对每次提取的操作精度有较要求。梁鲁宁等考察了“多次溶解法”在检测圆珠笔字迹形成时间中的实践要点，发现除了检测人员的反应速度，滴加的溶剂量、滴加速度、角度对结果都有影响。他们提出两次检测的时间间隔为1个月，判断的时间阈值为0.5秒，即T1与T2的差值于0.5秒时，可判断样品字迹为年内形成[22]。 O

## 三、中性笔墨迹

1984年日本樱花公司发明中性笔，所用的中性墨水（gelink）是具有触变性的非牛顿流体：经过笔头滚珠剪切力的作用，墨水由凝胶态转变为液态，而平时保持为凝胶态。独特的黏度体系使该类墨水书写流畅、快干，墨迹不易散和褪色，可用于签署重要文件、书写档案，也被称作“签字笔”，是现在我们最常用的书写工具。这类墨水的制作关键在于黏度体系，一般选的都是大分的动植物胶类和合成树脂类。

中性笔墨水中适合检测的小分子化合物主要是有机溶剂和助剂，如醇类、醚类化合物，它们在墨水中起着润湿作用，配合其他表面活性剂、添加剂的使用，保证墨水的润滑性、流利性和间歇书写性能的实施[3]。

按所用着色剂来区分，大多为颜料型，也有染料型的，如常用的黑色中性笔多以炭黑颜料为着色剂，使得墨迹色牢度好，能长期留存。不过，从检测角度而言，炭黑颜料无法用薄层色谱、质谱等方法进行分析，只能用光谱方法来表征，而且炭黑颜料的稳定性好，因此不适宜作为研究中性笔墨迹历时性变化的目标成分。而染料成分易于溶解和检测，所以染料型中性笔可以通过检测溶解度或者染料的降解来反映墨迹的历时性变化。

除了上述的特定成分外，还有应用光谱分析，通过墨迹的整体色泽变化来研究墨迹形成时间的方法。

## (一）溶剂法

中性笔墨水中所用有机溶剂多为乙二醇、1，2-丙二醇、甘油、二甘醇、三甘醇等多元醇类化合物（表26-1），墨水书写到纸上以后，经过挥发、渗透、扩散等过程，在一段时间内，这些小分子醇类的含量逐渐减少。采用相谱（-质谱)法对同一墨迹进多次检测，能在段时期内捕捉到溶剂含量的历时性变化。

若待测中性笔墨迹中含染料，可以像圆珠笔一样使“溶剂-染料比值法”，减少样品量不同带来的分析误差。徐媛媛等用相谱-分光光度法检测中性笔中溶剂的历时性变化，先用甲醇提取挥发性溶剂，再加N，N-二甲基甲酰胺提取染料，计算气相谱上溶剂的峰面积与光谱图上染料的峰积值，发现该参数随形成时间的增加逐渐减少[25]。

## (二）染料法

与圆珠笔墨迹相似，中性笔墨迹中的染料成分亦会发生降解反应。谢孟峡等建立了离子对-液相谱法，对黑色中性笔和蓝色中性笔墨迹中染料峰的历时性变化进了研究，发现染料成分在光照条件下会发降解，谱峰的相对峰积随时间变化，然化条件下染料降解的变化趋势与光照化条件下的变化趋势相似,但速度更缓慢[26\~27]。王元凤等应细管电泳（配有极管阵列检测器）对13种蓝签字笔墨迹进分析，在214nm波长下都检出2\~3个电泳峰，它们的相对峰积值随墨迹的形成时间变化，可于同类签字笔墨迹相对形成时间的较[28]。赵鹏程等采细管电泳法，对光照化和然化的签字笔墨迹中染料峰进了历时性研究，获得了相似的结果[29]。

## (三）溶解法

李彪将“透析法”和图像灰度值相结合，建“溶解-扩散法”研究染料型黑色中性笔墨迹的形成时间。该方法在体视显微镜上安装一个注射器，其倾斜角度及与样品台的相对高度均固定。该注射器中装着白的透析液（2mL甲基甲酰胺+13mL无乙醇+13gTi0₂）。先在显微镜下对选取的中性笔墨迹拍照(显微镜所带软件的图像摄取参数固定）,测得其图像灰度值G1，然后向墨迹样品滴加1mL透析液，同时开启显微镜软件的定时动拍照功能，每10秒自动获取一幅图像。最后选取透析液表面有字迹显现的某张图，测得其图像灰度值G2及时间间隔T，获得溶解-扩散率参数 $v = ( ~ G 1 - G 2 ) / T _ { \circ }$ 李彪研究发现，随着字迹形成时间的推移，v值逐渐减小。此外，墨、纸张的种类，以及墨迹的厚度都会影响v值[30]。

## （四）其他方法

实时直接分析质谱（DART），是一种新的常温常压电离源技术，以氦气或氮气为解吸气体，经放电产生激发态高能粒子，该激发态粒子被快速加热和电场加速，在大气压下使被测样品表面的挥发性物质瞬间电离，然后进行质谱仪检测，实现了样品的实时直接分析。琼斯（Jones)等采用实时直接分析-飞时间质谱（DART-TOFMS）对中性笔墨迹进历时性变化研究，发现部分聚乙二醇（PEG）低聚物在质谱图上的峰高值虽然有一定程度的离散，但在一年有明确的下降趋势[31]。宝等DART-TOFMS对同种墨6个不同时间书写的48个样本字迹进行分析，建立不同时间墨迹样品的质谱指纹图谱，再运用主成分分析法对数据进行投影分析。经优化，DART离子源温度设为350C时，新鲜中性笔墨迹中检出的主要成分有乙二醇、异丙醇、三乙醇胺、聚乙二醇。借助化学计量学所建立的主成分分类方法，可以将在不同时间书写的墨字迹进分类,初步判定未知样本的书写时间,所得结果与已知结果致[32]。 O

## 、印泥印油的成分

## (一)印泥

印泥又称油溶性印油，主要有红色和蓝色两种。印泥品种繁多，按用途来分可以分为办公印泥、书画印泥和篆刻印泥三种，按制作原料来分，常见有朱砂印泥和仿朱砂印泥两种。红色朱砂印泥的主要原料是朱砂（硫化汞、红色无机颜料）、艾绒、脱水蓖麻油和冰片。矿质朱砂经研磨后，上层的朱砂细末颜偏黄称为朱标，以朱标作为素成分的印泥称朱标印泥，义上也属于朱砂印泥的一种。仿朱砂印泥主要成分是大红粉808、涂料黄、银珠R、金光红C、酸性大红、乙萘酚、苯酚、牛油、蓖麻油、陶土、重晶石粉、白艳华、艾绒等。蓝色印泥的主要成分是油溶性的苯胺蓝和油酸、酞菁铜、氯化液状蜡或蓖麻油等。光红C是种淀性偶氮颜料，又称色淀红C，一般以钡盐的形式存在，能溶于极性较强的或含氮的有机溶剂中。大红粉808也是一种偶氮类红颜料，与光红C相比，在弱极性的有机溶剂中溶解度较。氯化液状蜡是蜡经氯化而制得的产品，用作增塑剂。蓖麻油是从蓖麻中提炼的一种性植物油，主要成分是蓖麻酸甘油酯。

## （二）印油

印油主要分为印台油、原子印油、光敏印油，主要由色料、树脂、溶剂和助剂组成。印油的料包括颜料和染料，其中颜料分为机颜料和有机颜料，机颜料主要有铁蓝、钴绿等，有机颜料主要有光红、耐晒黄等。在印油使的料中，多数印油的料为颜料，少数为染料。

按使用稀释剂种类的不同，印油可分为油溶性印油、溶性印油和醇溶性印油。油溶性印油以植物油、矿物油、酯类及烃类溶剂为主，油脂与颜料、树脂和其他填料易于结合，制作艺简单，耐受性较好。同时，油溶性印油也存在油脂在纸张上易洇散、挥发性差等特点。溶性印油是以为主要溶剂的印油，具有环保无毒害且易挥发的特点，其遇会溶解且印油加难度较，盖印时容易使纸张变形。醇溶性印油主要溶剂为单元醇或多元醇,部分物质分量较、沸点低、易挥发，与纸张结合度较且速。使的溶剂多为醇、异丙醇、丁醇等。

根据印章的制作材料可以将印油分为原印油、光敏印油和印台印油。印台印油主要成分是染料（红、蓝、紫，多为碱性染料，也有酸性染料）、甘油、乙醇、乙二醇、和甲醛等，黏稠剂主要是油和醇。原印油是原印章专印油，有渗透型印油和热固化型印油两种。渗透型原印油的主要成分由颜料、合成树脂、性或半性植物油、矿物油及沸点溶剂等多种物质组成。颜料主要有阳离红、桃红、耐晒红BBN、红粉808、光红C、酞菁蓝、炭、永固紫RL等。合成树脂起到增黏和延伸印油的作，主要是酚醛树脂、丙烯酸树脂、聚酰胺树脂、聚氨酯及其改性树脂等。溶剂属于沸点有机溶剂，常溶剂有苯甲醇、缩醇、邻苯二甲酸二酯等。常见的植物油主要有亚麻油、桐油、蓖麻油、豆油、椰子油，矿物油有柴油、机油、锭子油等。表面活性剂主要是十二烷基苯胺，可使颜料均匀分散在树脂、油中。光敏印油是光敏印章专用印油，印油不易沉降，颜色鲜艳，色密度高，印文清晰均匀，不洇纸，渗透速度快，即印即干，耐高温、耐低温，稳定性强，与印垫和印章壳不发生不良反应，并可重复注油。光敏印油多数属于水性印油，主要以水为溶剂，色料采用水溶性较强的酸性染料和偶氮颜料等，如罗丹明B、酸性红18、酸性红87、颜料红等。

按照印油功能可以将印油分为普通印油和防伪印油，防伪印油具有防伪的功能，通常在印油里面加入特殊的化学物质，一般是荧光物质，如荧光颜料、荧光树脂等，常见的防伪印油有红外防伪印油、紫外防伪印油和光敏防伪印油等。

## 、研究印泥印油历时性变化的法

理论上，无论何种品牌型号的印泥或印油，纸张上一旦形成印章盖印的印文后，由于改变了印泥或印油存在的环境条件，直接暴露于空气中或光线下，随着时间的推移，印文墨迹都会发某些物理或化学性质的变化。这种变化的程度与盖印时间的长短相对应，同时又受到各种因素的影响。这种变化主要表现在以下几个方面：印文色料与纸张的结合越来越牢固，被溶解、转印的能力会逐渐下降；印文色料中的某些成分逐渐挥发；印文色料中的某些成分逐渐分解；印文色料中的某些成分沿纸张的扩散越来越严重；印文色料在纸张上的聚集状态和色泽逐渐发某种变化。如果能检测出上述某种变化并能掌握其随时间的变化规律，就可以利这一特性判断印文的盖印时间。

## （一）油脂成分扩散法

印泥由于成分中含有较多的蓖麻油或氯化液状蜡等调和油，这些油脂均是在常温下呈液态的高分子，很难挥发，当用印章蘸取印泥在纸张上盖印后，由于纸张纤维呈不规则的毛细管网状分布，印油成分会向纸张纤维渗透。与此同时，印文色料中的油脂便开始在表面张力的作用下沿着纸张纤维向外铺展扩散形成油痕。在一定时段内，时间越长油脂的扩散距离越大，经过一段时间后，油脂逐渐变稀薄，表面张力逐渐减小，当表面张力减小到与油脂分子间的相互吸引力平衡时，油痕的扩散距离达到最大值并稳定下来。在不同时间内通过测量印泥印文油脂成分的扩散程度，即可判定其盖印时间。鉴于油脂成分从开始扩散至达到最大值，一般需要2个月左右的时间，而此期间内，油脂成分的扩散并非匀速扩散而是一个由快到慢的过程，因此不能单纯通过测量油痕扩散的绝对值和绝对速度来推测印文的盖印时间。通常采用测量同一印文在某几个时间段的再扩散距离占原油痕宽度的百分比（差值百分比）来推断印文的盖印时间。油脂成分扩散程度测定法的操作简单方便，不需借助于复杂的仪器即可，但是该方法般仅适于盖印时间在2个左右的检材。实际检验作中，相当数量的案件是要求鉴定落款时间为一年或数年前的文件上的印文是否最近形成，所以，对油脂成分的扩散程度进行测定是一种有效的方法，能准确地判定文件是否近期形成。

油脂成分扩散法的操作：在受理案件当日，进行第一次油痕测定。在印文所在纸页的正面或反面选择3处以上油痕扩散明显和均匀处，在适当的光线下准确地用较细的工具分别在油痕分界线做几对测量点标记，用读数显微镜或其他具有测量功能的软件或工具测量油痕扩散距离并记录数据。在室内避光放置15\~60天，每15天复测次。如在第个15天即测出两个时间的扩散距离有较大差异，则可判定印文为近期盖印，盖印时间不会超过2个月。如测出两个时间的扩散距离没有明显差异，则必须继续测至第60天，再确认其是否继续扩散。如确认个时间段内油脂成分扩散距离已差异，说明印油脂已停扩散。

房晓龙等基于印泥油脂成分的扩散特征，运用油痕扩散法对印泥印文的油痕扩散现象进考察，实验中检仪对印泥印进观察并借助Photoshop具对油痕扩散距离进测量，绘制了油痕扩散差值百分比与印文形成时间的关系曲线，并考察了印文清晰度、印泥品牌型号及纸张种类等因素对实验结果的影响。研究结果表明，油痕扩散法能够判定印是2个之前盖印形成的还是两个之内盖印形成的[34]。

李开开利用365nm波长的紫外光对复印纸和票据纸上的印文油痕进观察并拍照，再通过Photoshop软件对图像进行增强处理，使印文油痕更加清晰，随后对不同扩散时间下的油痕扩散距离进行测量，建立油痕扩散距离与时间的关系曲线，发现印油盖印后15天内，印油的扩散速度较快，扩散曲线斜率大；盖印后15\~60天，印油的扩散速度逐渐趋于平缓，扩散曲线斜率较小[35] 。

## （二）显微分光光度法

纸张上印文墨迹成分的历时性变化虽然不明确，但是可以从印文墨迹的颜色上反映出来（如颜色逐渐暗淡），因此可以用显微分光光度计，对印文墨迹进行检测。这一方法必须用同类纸张上、同类印油、印泥盖印的已知时间盖印的文件作为样本，获得其历时性变化数据，然后用显微分光光度计在同一检测条件下，分别对检材印和样本印文进检测，对测得的光谱图进比较。对于检测结果，还要考虑检材和样本在保存环境上的差异，对检验数据进科学客观的分析。

## （三）拉曼光谱法

存在于载体上的印文墨迹，因为暴露在空气中，会发生一些氧化、固化、挥发等反应，从而使不同时期形成的印各的成分及含量有所不同,在拉曼光谱曲线中表现出差异,通过较这种差异来判定印的盖印时间。

韩伟等借助激光显微拉曼光谱技术，分析了10种不同品牌和型号的印油（泥)印，发现其均在 $1 ~ 2 3 5 ~ \mathrm { c m } ^ { - 1 }$ 和 $1 ~ 0 8 9 ~ \mathrm { c m } ^ { - 1 }$ 处存在特征峰，并利用该处特征峰的相对面积值探讨了温度、纸张、热化因素对印盖印时间的影响，分析了相对峰积值与印盖印时间的关系。结果表明，由于不同品牌、型号的印泥（油）中所含的溶剂成分不同、保存条件也不尽相同，因此各溶剂挥发状态各阶段表现也不同，达到平衡的时间和曲线拐点出现的时间也不同，但是可以看出印油在形成初期的变化规律较为明显[36]。 欢迎关注法律类微信公众号【善雅集】

籍康等红外激光785nm作为激发光源，利共焦显微拉曼光谱技术连续4年多跟踪检测种品牌印泥(油)的拉曼光谱图，建了印文盖印时间的数据库。研究发现，印油(泥)中均含有酯类成分，其拉曼光谱均在 $1 ~ 2 3 5 ~ \mathrm { c m } ^ { - 1 }$ 处出现特征峰，且该处特征峰的相对强度随着时间的推移不断变。因此，可通过对检材印与历时性样本印的拉曼光谱数据来判断印油(泥)的相对形成时间[37]。

## （四）相谱法

储墨印章(原印章和光敏印章)的印油料中含有类似于圆珠笔和中性笔墨中的溶剂成分，如1，2丙二醇、1，3-丙二醇等，这些溶剂都具有一定的挥发性。当储墨印章盖印于纸张上以后，印料中的这些溶剂成分便会随着盖印时间的延长逐渐挥发,其含量逐渐减少,直挥发殆尽。采相谱仪可以检测出印料中这些相关溶剂的残留量，残留量越说明盖印时间越短,残留量越说明盖印时间越长,通过与相应的样本印进对即可以测定检材印的盖印时间。

谢朋等用相谱仪对37种红的原印油和光敏印油所含有的主溶剂进分析，依据溶剂成分对印油进了分类并对主溶剂进跟踪检测。研究以1微升的苯甲酸酯和100毫升的无乙醇配制的混合液作为提取剂，以苯甲酸乙酯作为内标物，依据实验数据总结出各主溶剂随印盖印时间的变化规律，其中1,3-丙醇的挥发残留量随印盖印时间的延长减，在30天内减少最快，在30\~70天内变化较为缓慢，70天后检测不出残存的溶剂[38]。

尤伟等利相谱-质谱法对5种不同品牌光敏印油的印的形成时间进了研究，研究发现每种品牌的印油中均含有二丙二醇及其同分异构体，并采取内标法对形成时间不同的光敏印油印中的丙醇及其同分异构体的相对含量进分析。研究结果表明，形成时间在1个月内的印文，其二丙二醇及其同分异构体的相对含量较高，随着形成时间的增加，相对含量则迅速降低，并在2个之后基本变化。因此可以通过分析光敏印油印中丙醇及其同分异构体的相对含量来判断其形成时间[39]。

## （五）染料比值法

对印文色料采用薄层层析后，可将各成分分开，利用薄层扫描仪对展开后的各色料斑点进谱扫描，依据染料斑点吸收峰峰积相对于标准峰峰积值，可得出各成分的相对含量，通过检材和不同时段样本的比较可分析印泥(油)印文的盖印时间。该方法的提取剂是氯仿：乙醇(5：2），根据印染物成分的不同可调整展开剂的配方，展开剂有正己烷：乙酸乙酯（17：3）、正已烷：油醚（7：3）、油醚：乙酸乙酯（5：2）或乙酸乙酯：乙醇：水(11：1：1)。

凡等调温型电熨对印料进为加热化,并使薄层谱法对得到的染料数据进Logistic回归分析，建了不同加热温度和加热时间对印盖印时间判定的数学模型，以考察不同加热温度和加热时间两面对印盖印时间结果的影响。该模型判定印盖印时间的法为实践中印形成时间检验和为化印判断提供了新的思路[40]。

## （六）溶解提取率法和溶压转印法

盖印时间越短的印料越容易被溶解，盖印时间越长的印料越不容易被溶解，因此选择合适的弱、强两种试剂，采用双溶剂提取法，根据印文色料提取率的不同即可判断印的相对形成时间。双溶剂提取法的具体操作和测定圆珠笔油墨字迹书写时间时的操作类似。

李彪等通过双溶剂提取法确定印泥印文的盖印时间，实验确定了50%甲酸溶液为弱提取剂，N，N-二甲基甲酰胺为强提取剂，在采用双溶剂提取法溶解印泥后，利用薄层色谱仪进行扫描，薄层扫描时狭缝的为6mm×0.45mm，扫描波长为485nm，绘制了提取率随印盖印时间的变化曲线，发现在半年内印文盖印时间越短，提取率越高；反之，盖印时间越长，提取率越低，根据这规律，在有合适的样本印文的前提下，可以判定印文的盖印时间[41]。暴仁等确定的弱提取剂是环己烷，强提取剂是氯苯，扫描时狭缝大小为5mmx0.45mm，扫描波长为490nm。

张凌燕等以N，N-二甲基甲酰胺、正丁醇与二氯甲烷混合溶剂作为原子印油印文的提取剂，利用薄层色谱检测，绘制了萃取速率随盖印时间变化的校正曲线，发现盖印时间在1\~36个月以内的印文，随印文盖印时间的增加，萃取速率值降低迅速，检测下限为3个月；盖印时间在36\~66个月的陈旧印文，萃取速率值基本没有变化，表明该方法不能对陈旧性印文的形成时间进区分，但可与新鲜印进区分[42]

与提取率法原理相似的还有溶压转印法。李彪等用50%甲酸溶液为压取转印试剂，在优化的压力和保压时间等压取转印条件下，将印泥色料转印到纸张上，利用薄层扫描仪对转印前后的印文色料进行扫描并用薄层扫描仪自带软件计算印文色料吸收峰的峰面积，再利用公式计算印泥色料的转移率，绘制了转移率随印文盖印时间变化的关系曲线，发现印文盖印时间在半年内且盖印时间越短其转移率越高；相反，盖印时间越长，转移率越低。在样本满足条件的情况下，利转移率可以判定印的盖印时间[43]。

## 第四节纸张的历时性变化研究

纸张是经过特殊处理的植物纤维（除产某种特殊纸采化学纤维外）制作形成的。造纸时，植物纤维悬浮于水中，并根据使用要求加入适量的胶料、填充料、色料等，然后在网上脱，使纤维相互紧密交织在起，经过压榨和燥后形成厚薄均匀的纤维层（图26-6)。造纸术是我国的“四大发明”之一，早在西汉年间我国已出现了麻纸，到了东汉中期，蔡伦对造纸术进行了重要革新。他的研究不仅显著提高了麻纸的质量，降低了造纸成本，还开发了楮皮纸的制作技术，扩充了造纸纤维的来源。

图26-6 扫描电显微镜下的复印纸表形态(放倍率1000倍)

纸张的形成时间主要是指它的绝对制作时间，即产制作时间，它决定了件形成时间的上限，是文件材料及文件形成时间鉴定研究中重要的环。按照制作艺，纸张可以分为纸和机制纸两类。纸是指以式抄造成的纸，我国的传统纸原料主要有麻类、树、、麦稻草、叶纤维(如龙须草)等。机制纸和纸的制作原理和制作法是脉相承的。我国于清朝末年开始从西引进技术和设备产机制纸，机制纸纸成本低、产规模，已经成为社会产活的主流用纸。前，除了少数印制了生产年份或批次的机制纸外,判断纸张制作时间主要依靠显微检验（含染法）分析纸张的纤维种类和制作艺，多应于古籍、档案研究。例如，1853年后材成为造纸业的主要原料，若显微检验发现纸张中含浆纤维，就可以判断档案的形成年代不会早于19世纪中叶[4]。在造纸和档案学界有许多相关研究著作，如王菊华所著的《中国造纸原料纤维特性及显微图谱》（中国轻业出版社，1999)书，详细介绍了针叶纤维、阔叶纤维、禾草类纤维、竹纤维、韧皮棉纤维的形态和鉴别特征，以及不同纤维对纸张性质的影响。在法庭科学研究领域，张建洲等总结了中国造纸术中量使的14种草类纤维和韧类纤维的显微特征、最早出现的年代和历史性发展[45]。除了纤维鉴别定性之外,有个详尽的古籍纸张数据库也尤为重要，纸样越多，可参考比对的样品就越多，通过显微比对、仪器分析比对，能有助于提判断的准确性。

现代造纸艺中，纸张的产过程中会加各类化学品，它们的种类和用量也随着造纸技术的进步不断变化,故不同的化学品也可以看作是种时间指针[4]。

纸张中植物纤维的主要成分为纤维素、半纤维素和质素，均为天然分结构。造纸艺主要包括制浆、打浆、纸浆流送与纸页成形、纸页压榨与干燥、纸页的表面处理，以及纸页的卷曲和完成这六个步骤。其中制浆是造纸的第道序，是利化学或机械法，使植物纤维原料解离变成纸浆的产过程，对应产的纸浆被称为化学浆和机械浆。在这步骤中，需要对天然植物纤维制成的纸浆进漂，以提纸浆的度和度稳定性，改善纸浆的物理化学性质，提纸浆的洁净度。经过后几道物理制作过程，到纸页表面处理时，需要对纸页表面进施胶，以改善纸页的表面性能、空隙结构和吸收性能，以及纸页的适印性能。

在抄造过程中，引入的化学添加剂从功能上分，有增干强剂（提高纸张在干燥状态下的强度）、增湿强剂（提高纸张被浸湿后的强度）、内部施胶剂、填料、助留助滤剂、色料（染料、颜料、荧光增剂）、表施胶剂等[47]。多种纸张化学品的定性定量分析已经有相应法，可以在司法鉴定领域开展应用，如液相色谱-质谱法检测纸张中的荧光增白剂、X射线荧光光谱法检测纸张中的无机填料；另些化学品虽然尚未形成系统检测法，但主要是研究关注者少，本身检测技术难度并不。定性化学品后，最重要的是要了解该类化学品的使年代，这需要综合文献信息、样本收集、实地访等多种式，才有可能去伪存真，为判断纸张时间提供参考[46]。

虽然纸张年代鉴定还面临很多技术上的难题，但是对于纸张的历时性变化，在档案、古籍研究和造纸领域，出于延长纸张耐久性、保护古籍档案的考虑，已较早地开展了对于纸张化的研究。般纸张化在宏观上表现为纸张泛黄，机械强度下降，铜价（表纸张内解纤维素和氧化纤维素还原金属离子到低价态的能力）上升，酸度上升；微观上则是纤维素、半纤维素和质素的化学结构发了变化。纸张化的内因是纤维素、半纤维素、质素的氧化、降解反应，以及纸张内部生成过程中残留的酸、氧化剂、施胶剂、金属离子等；老化的外因是环境中的温湿度、光线、微生物等[48]。

纸张的理化性能检验有一系列的国标，如测定纸张pH的《纸、纸板和纸浆水抽提液酸度或碱度的测定》（GB/T15452008）、测定纸张度的《纸、纸板和纸浆蓝光漫反射因数D65亮度的测定（漫射/垂直法，室外光条件）》（GB/T79742013）、测定纸张物理强度的《纸和纸板抗张强度的测定恒速拉伸法（20mm/min）》（GB/T12914—2018）、《纸和纸板撕裂度的测定》（GB/T455—2002）、《纸和纸板耐折度的测定》（GB/T457—2008)等。多项研究报道了在高温、高湿、日光及紫外光照射条件下，宣纸、竹皮纸、新闻纸、档案纸等纸张在白度、耐折度、抗张强度、抗撕裂强度、pH和铜价上的变化[49\~51]。对于检实践，纸张的度变化是最直观且易于测量的，除了国标方法，通过显微分光光度计、视频光谱仪等设备，也能比较色泽不同的同种类纸张。例如，用显微分光光度计检测发现，人工或自然老化后色泽变黄的纸张，在L、a、b色度体系中，表征黄蓝色的b值会逐渐增大。

一般而，自然老化的纸张的色泽变化是从与环境接触更多的纸张边缘开始的，多为四周泛黄，而中心部位仍然呈白色；光照老化的纸张，接触光照的部位整体色泽均匀，与未接触光照的部位色差明显（如纸张正面与反面），边界清晰；加热老化的纸张则整体色泽均匀。

在化学成分分析方面，多项研究应用无损的红外光谱和拉曼光谱对老化的纸张进行研究：孙礼春等应用红外光谱检验光照老化的纸张，发现 $1 ~ 7 4 0 \sim 1 ~ 7 1 0 ~ \mathrm { c m } ^ { - 1 }$ 处红外吸收峰强度增加，峰形变宽；同时 $1 \ 2 6 5 \ \mathrm { c m } ^ { - 1 }$ 处红外吸收峰强度降低[52]。类似的，张旭等开展古籍纸张的红外光谱无损检测研究，发现经过老化的传统手工纸的红外光谱图上， $1 ~ 7 4 0 \sim 1 ~ 6 8 0 ~ \mathrm { c m } ^ { - 1 }$ 之间会产羰基吸收峰，研究人员将其解读为纤维素的聚合度降低，产生含羰基或羧基的氧化基团，并定义为纤维素的氧化度。他们发现,随着化时间的延长,纸张氧化度逐渐增[53]。泽巴·帕卢斯(ZiebaPalus)等应用红外光谱和拉曼光谱，对5种在90℃、65%RH条件下化35天的纸张进行检验，发现人工化使纸张纤维素氧化，生成羰基和羧基，老化前后的样品在以$1 ~ 8 0 0 \sim 9 0 0 ~ \mathrm { c m } ^ { - 1 }$ 范围构建的维光谱上可以区分[54]。西尔(Silva)等采ATR-红外光谱对15个年份的纸张进行检测，然后应用化学计量学方法建立了回归模型，用于预测纸张年龄。研究表明，用正交普通最二乘法（ordinary least squaremethod，OLS)滤波器建偏最小二乘（partialleastsquare method，PLS)模型的误差最，能在定程度上降低变量的影响，但机物成分对模型仍然有影响。该研究探索了化学计量学与红外光谱相结合判定纸张年代的可行性[55] O
