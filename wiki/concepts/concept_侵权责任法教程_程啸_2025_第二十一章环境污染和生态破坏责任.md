# 《侵权责任法教程》第二十一章 环境污染和生态破坏责任

## 🎯 核心论点

**环境污染和生态破坏责任 = 无过错责任 + 举证责任倒置**

**《民法典》第1229条**：
> 因污染环境、破坏生态造成他人损害的，侵权人应当承担侵权责任。

**《民法典》第1230条**：
> 因污染环境、破坏生态发生纠纷，行为人应当就法律规定的不承担责任或者减轻责任的情形及其行为与损害之间不存在因果关系承担举证责任。

**两大创新**：
1. **生态破坏责任**首次独立规定
2. **举证责任倒置**：行为人就免责事由和不存在因果关系举证

---

## 第一节 概述

## 一、环境污染的含义

**环境污染** = 由于人类的活动向环境排放了某种或某些物质或能量，超出环境的自净能力或承载能力，从而对生态环境造成不良影响的行为。

**特点**：
- 排放物质或能量
- 超出环境自净能力或承载能力
- 造成不良影响

## 二、生态破坏的含义

**生态破坏** = 人类活动对生态系统的结构和功能造成损害，导致生态系统服务功能退化或丧失。

**典型行为**：
- 砍伐森林
- 过度放牧
- 围湖造田
- 野生动植物栖息地破坏
- 矿产开采导致生态破坏

## 三、《民法典》对环境污染和生态破坏责任的体系性规定

**法律基础**：
- 《民法典》第1229条：基本规定（无过错责任）
- 《民法典》第1230条：举证责任倒置
- 《民法典》第1231条：多人侵权
- 《民法典》第1232条：惩罚性赔偿
- 《民法典》第1233条：第三人过错不免除
- 《环境保护法》《水污染防治法》《大气污染防治法》《土壤污染防治法》《固体废物污染环境防治法》《噪声污染防治法》《放射性污染防治法》等

---

## 第二节 构成要件

## 一、环境污染或生态破坏行为

**典型行为**：
- 排放废水、废气、废渣
- 排放噪声、振动、放射性物质
- 砍伐森林、破坏植被
- 排放有害物质到土壤
- 破坏野生动物栖息地

## 二、损害

**损害范围**：
- 人身损害（生命权、身体权、健康权）
- 财产损害（直接损失+间接损失）
- 生态环境损害（生态服务功能损失）

## 三、因果关系

**因果关系推定**（举证责任倒置）：
- 由侵权人就**不存在因果关系**承担举证责任
- 原告只需初步证明污染行为与损害之间存在关联性

---

## 第三节 责任主体

## 一、排污单位

**排污单位** = 排放污染物的企业、事业单位、其他生产经营者

## 二、个人

**个人排污者** = 排放污染物的个人（如个人燃放烟花、个人倾倒污染物等）

## 三、生态破坏者

**生态破坏者** = 实施砍伐森林、过度放牧、破坏栖息地等行为的单位或个人

---

## 第四节 法律后果

## 一、赔偿范围

| 损害类型 | 赔偿范围 |
|---------|----------|
| **人身损害** | 医疗费、误工费、护理费、残疾赔偿金、死亡赔偿金等 |
| **财产损害** | 直接损失 + 可得利益损失 |
| **生态环境损害** | 生态修复费用 + 生态服务功能损失 |

## 二、举证责任倒置

**《民法典》第1230条**：
> 因污染环境、破坏生态发生纠纷，行为人应当就法律规定的不承担责任或者减轻责任的情形及其行为与损害之间不存在因果关系承担举证责任。

**举证倒置的两项内容**：
1. 免责事由的存在（由行为人证明）
2. 不存在因果关系（由行为人证明）

**意义**：
- 大幅降低受害人举证负担
- 体现对环境污染受害人的特殊保护
- 推动行为人承担预防损害的激励

## 三、第三人过错不免除

**《民法典》第1233条**：
> 因第三人的过错污染环境、破坏生态造成损害的，被侵权人可以向侵权人请求赔偿，也可以向第三人请求赔偿。侵权人赔偿后，有权向第三人追偿。

**重要规则**：
- 即便完全是因第三人过错造成的污染损害
- 侵权人**也不能以第三人过错为由免责**
- 被侵权人可选择：起诉侵权人 / 起诉第三人 / 共同被告
- 侵权人赔偿后可向第三人**全部追偿**（不是部分追偿）

**理由**：
- 有效保护环境污染受害人
- 如果允许以第三人过错免责，被侵权人只能向第三人主张，而第三人往往无法查明或无赔偿能力

## 四、减责事由

**受害人重大过失**：
- 《水污染防治法》第96条第3款第2句：受害人有重大过失可减轻排污方责任
- 注意：受害人**一般过失**不能减轻侵权人责任

---

## 第五节 惩罚性赔偿

**《民法典》第1232条**：
> 侵权人违反法律规定故意污染环境、破坏生态造成严重后果的，被侵权人有权请求相应的惩罚性赔偿。

**《生态环境侵权惩罚性赔偿解释》**（最高人民法院）

## 一、构成要件

| 要件 | 内涵 |
|------|------|
| **主观故意** | 明知其行为会给他人造成损害，而依然追求或放任损害结果的发生 |
| **违反法律规定** | 行为违反法律、行政法规、地方性法规，可以参照规章 |
| **造成严重后果** | 严重污染或生态破坏 |

## 二、主观故意的认定

**《生态环境侵权惩罚性赔偿解释》第6条**：综合判断因素：
- 侵权人的**职业经历**、专业背景、经营范围
- 因**同一或同类行为**受到行政处罚或刑事追究的情况
- 污染物的种类
- 污染环境、破坏生态行为的方式

## 三、"法律"的范围

**《生态环境侵权惩罚性赔偿解释》第5条**：
- 不限于全国人大及其常委会制定的法律
- 包括**行政法规**和**地方性法规**
- 可以**参照规章**的规定

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **环境污染** | 排放物质或能量超出环境自净能力或承载能力 |
| **生态破坏** | 破坏生态系统结构或功能的行为 |
| **环境自净能力** | 环境对污染物的自然净化能力 |
| **环境承载能力** | 环境能承受的最大污染负荷 |
| **生态环境损害** | 生态服务功能损失 + 生态修复费用 |
| **生态修复费用** | 使生态恢复原状的费用 |
| **生态服务功能损失** | 生态系统服务功能的减少 |
| **举证责任倒置** | 行为人就免责事由和不存因果关系举证 |
| **第三人过错不免除** | 即便全是第三人过错，侵权人也不免责 |
| **污染者付费** | "谁污染谁付费"原则 |
| **惩罚性赔偿** | 故意污染+严重后果 |
