# 《侵权责任法教程》第七章 过错

## 📋 章节概览

| 字段 | 内容 |

## 🎯 核心论点

**过错**（fault/Verschulden）= 对行为人**主观心理状态**的评价，分为**故意**与**过失**。

**重要规则**：
- 我国法上**未区分过错与违法性**
- 过错判断**日益客观化**（合理人标准、违法视为过失）
- 过错仅是协调法律价值的**技术性手段**，不再是对个人主观的道德非难

---

## 第一节 概述

## 一、过错的概念

**例1**：甲骑电动车经过路口时未注意观察，将乙撞伤

### 过错的含义

**过错**（Verschulden）= 对行为人主观心理状态的评价，分为：
- **故意**（Vorsatz）
- **过失**（Fahrlässigkeit）

### 过错的从属性

> "过错作为主观构成要件，要求客观构成要件的存在。因为过错意味着主观责任。只有在客观上存在某种可负责的行为时，这一问题才有意义。"

**意义**：
- 须先满足客观构成要件（加害行为、损害、因果关系）
- 然后才讨论过错（主观可归责性）

## 二、过错的功能变迁

### 19世纪：道德观念在法律上的反映
- 威慑、制裁为主要功能
- "坏人就应当为他们干的坏事付出代价"
- 例：故意侵权后果不被认为过于遥远、恶意可击败特定抗辩

### 现代：补偿和预防为基本功能
- 与商业保险、责任保险、社会保障结合
- 过错判断标准日益客观化
- 过错成为协调法律价值的技术性手段

## 三、我国法上未区分过错与违法性

**例2**：A队甲争抢篮板时肘击B队乙眼眶 → 适用自甘冒险（《民法典》第1176条）

**理由**：
1. 违法性不足以明确行为规则
2. 民事行为纷繁复杂，法律无需规定具体标准
3. 现代过错判断客观化使两者交错
4. 正当防卫等可作为免责事由处理
5. 简化责任构成要件便于受害人补救

---

## 第二节 过错能力

## 一、概述

**过错能力**（Verschuldsfähigkeit）= 行为人对自己从事的加害行为是否需要负责任的**认识能力**。

**特点**：
- 又称**侵权责任能力**（Deliktsfähigkeit）或**归责能力**（Zurechnungsfähigkeit）
- 不同于**民事行为能力**（无民事行为能力人可能有过错能力）
- 故意和过失都以过错能力为前提

**例1（10岁女孩案）**：李乙虽不具备完全民事行为能力，但具有过错能力

## 二、判断标准

### 1. "一般标准+特别认定"模式（德国模式）

| 规则 | 内涵 |
|------|------|
| 未满7岁 | 绝对不具有过错能力（《德国民法典》第828条第1款）|
| 已满7岁未满10岁 | 就汽车、电车、缆车事故造成的损害不负责任（第828条第2款）|
| 已满7岁未满18岁 | 个案判断：是否具有认知责任所必要的判断力（第828条第3款）|
| 成年人丧失知觉/精神错乱 | 不具有过错能力（第827条）|

### 2. 个别认定模式（奥地利、日本模式）

- 不设一般性判断标准
- 就各行为具体认定
- 综合行为人心理、生理、人格智能发展状况判断

## 第三节 故意

## 一、故意的概念

**故意** = 行为人**预见到**自己的行为可能引起损害结果，**仍希望**或**放任**该结果发生。

**故意三要素**：
1. 行为人对损害结果有认识
2. 行为人希望或放任该结果发生
3. 行为人有意识地进行行为

## 二、故意的分类

| 类型 | 内涵 |
|------|------|
| **直接故意** | 行为人**希望**损害结果发生 |
| **间接故意**（未必故意）| 行为人**放任**损害结果发生 |

## 三、故意的意义

- 法律上对故意的评价重于过失
- 故意侵权可能涉及刑事责任（不阻却刑事违法性）
- 故意情况下免责事由较少（除受害人故意外）

---

## 第四节 过失

## 一、过失的概念

**过失** = 行为人应当预见自己的行为可能引起损害结果，**因疏忽未预见**或**虽预见但轻信能够避免**。

**过失三要素**：
1. 行为人应当预见
2. 行为人能够预见
3. 行为人未预见或轻信能够避免

## 二、过失的分类

### （一）重大过失与一般过失

| 类型 | 内涵 |
|------|------|
| **重大过失**（grobes Verschulden）| 行为人严重违反注意义务，连普通人都能注意的程度 |
| **一般过失**（einfaches Verschulden）| 行为人违反注意义务但未达到重大程度 |

**法律意义**：
- 重大过失通常导致更重的责任
- 在过错相抵中，重大过失才能减轻加害人责任（《民法典》第1233条等）

### （二）具体的过失与抽象的过失

| 类型 | 内涵 |
|------|------|
| **具体的过失** | 行为人应当预见并避免损害但未为之 |
| **抽象的过失** | 善良管理人/合理人的注意义务标准 |

### （三）业务过失

**业务过失** = 从事特定职业的人违反其职业所要求的特别注意义务。

**例**：医生、律师、会计师等专业人员的过失。

## 三、过失的判断标准

### （一）主观标准
- 行为人的具体预见能力
- 考虑行为人的年龄、智力、经验等

### （二）客观标准（通说）
- **善良管理人**（diligent paterfamilias）标准
- **合理人**（reasonable person）标准
- 同等情况下的行为人标准

### （三）违法视为过失

**违法视为过失** = 行为人违反保护他人的法律，视为有过失。

**意义**：在受害人证明加害人违反法律时，直接推定加害人有过失。

---

## 第五节 共同过错

## 一、共同过错的含义

**共同过错** = 多个主体对同一损害的发生或扩大具有过错。

## 二、共同过错与共同侵权

| 区别 | 共同过错 | 共同侵权 |
|------|----------|----------|
| 过错程度 | 各有过错 | 共同故意或共同过失 |
| 主体关系 | 不要求有意思联络 | 要求有意思联络 |
| 法律后果 | 按过错比例分担 | 承担连带责任 |

## 三、过错相抵

**《民法典》第1173条**：
> 被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。

**规则**：
- 受害人有过错 → 减轻侵权人责任
- 受害人故意 → 侵权人免责（《民法典》第1174条）
- 受害人重大过失 → 无过错责任下可减轻（《民法典》第1233条）

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **过错** | 行为人主观心理状态（故意或过失）|
| **故意** | 预见+希望或放任结果 |
| **直接故意** | 希望损害结果发生 |
| **间接故意**（未必故意）| 放任损害结果发生 |
| **过失** | 应当预见而未预见或轻信能避免 |
| **重大过失** | 严重违反注意义务 |
| **一般过失** | 违反注意义务但未达重大程度 |
| **具体的过失** | 个体化判断 |
| **抽象的过失** | 合理人标准 |
| **业务过失** | 违反职业特别义务 |
| **过错能力** | 行为人认识能力 |
| **过错相抵** | 受害人过错可减轻加害人责任 |
| **违法视为过失** | 违反法律视为有过失 |
| **结果不法说** | 违法性由结果推定（德国传统）|
| **行为不法说** | 违法性须考察行为是否违反注意义务 |
