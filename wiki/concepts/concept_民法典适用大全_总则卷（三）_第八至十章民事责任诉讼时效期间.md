### 第九章 诉讼时效（第188-199条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第188条 | 一般诉讼时效 | 向人民法院请求保护民事权利的诉讼时效期间为三年。法律另有规定的，依照其规定 |
| 第189条 | 诉讼时效起算 | 当事人约定同一债务分期履行的，诉讼时效期间自最后一期履行期限届满之日起计算 |
| 第190条 | 无民事行为能力人请求权时效起算 | 无民事行为能力人或者限制民事行为能力人对其法定代理人的请求权的诉讼时效期间，自该法定代理终止之日起计算 |
| 第191条 | 受胁迫请求权时效起算 | 未成年人遭受性侵害的损害赔偿请求权的诉讼时效期间，自受害人年满十八周岁之日起计算 |
| 第192条 | 时效届满抗辩 | 诉讼时效期间届满的，义务人可以提出不履行义务的抗辩 |
| 第193条 | 不得主动适用 | 人民法院不得主动适用诉讼时效的规定 |
| 第194条 | 时效中止 | 在诉讼时效期间的最后六个月内，因不可抗力或者其他障碍不能行使请求权，诉讼时效中止 |
| 第195条 | 时效中断 | 有下列情形之一的，诉讼时效中断，从中断、有关程序终结时起，诉讼时效期间重新计算 |
| 第196条 | 不适用时效 | 下列请求权不适用诉讼时效的规定 |
| 第197条 | 诉讼时效法定 | 诉讼时效的期间、计算方法以及中止、中断的事由由法律规定，当事人约定无效 |
| 第198条 | 仲裁时效 | 法律对仲裁时效有规定的，依照其规定；没有规定的，适用诉讼时效的规定 |
| 第199条 | 撤销权/解除权存续期间 | 法律规定或者当事人约定的撤销权、解除权等权利的存续期间，除法律另有规定外，自权利人知道或者应当知道权利产生之日起计算，不适用有关诉讼时效中止、中断和延长的规定。存续期间届满，撤销权、解除权等权利消灭 |

### 第十章 期间计算（第200-204条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第200条 | 期间单位 | 民法所称的期间按照公历年、月、日、小时计算 |
| 第201条 | 期间起算 | 按照年、月、日计算期间的，开始的当日不计入，自下一日开始计算 |
| 第202条 | 期间末日 | 按照年、月计算期间的，到期月的对应日为期间的最后一日；没有对应日的，月最后一日为期间的最后一日 |
| 第203条 | 期间末日延长 | 期间的最后一日是法定休假日的，以法定休假日结束的次日为期间的最后一日 |
| 第204条 | 期间计算方法 | 期间的计算方法依照本法的规定，但是法律另有规定或者当事人另有约定的除外 |

## 核心制度深度解读

### 一、民事责任基础（第175-176条）

**第175条**：民事主体依照法律规定或者按照当事人约定，履行民事义务，承担民事责任。

**民事责任的产生依据**：

| 依据 | 内容 |
|------|------|
| 法律规定 | 侵权责任、无因管理、不当得利等 |
| 当事人约定 | 合同违约责任、债务不履行等 |

**民事责任的特征**：

| 特征 | 内容 |
|------|------|
| 1. 强制性 | 由国家强制力保障 |
| 2. 财产性 | 主要以财产方式承担 |
| 3. 补偿性 | 旨在弥补受害人的损失 |
| 4. 法定性 | 责任范围依法律规定 |

### 二、按份责任与连带责任（第177-178条）

#### （一）按份责任（第177条）

**条文原文**：二人以上依法承担按份责任，能够确定责任大小的，各自承担相应的责任；难以确定责任大小的，平均承担责任。

**按份责任的特征**：
- 责任人各自承担特定份额
- 不就他人责任份额负责
- 责任大小可确定的依确定；难以确定的平均

**按份责任的典型情形**：
- 共同侵权中各自过错程度不同的（第1172条分别侵权按份责任）
- 多方违约中各自违约程度不同的

#### （二）连带责任（第178条）

**条文原文**：二人以上依法承担连带责任的，权利人有权请求部分或者全部连带责任人承担责任。

**连带责任的特征**：
- 权利人可选择向任一责任人主张全部责任
- 责任人不得拒绝超过其份额的请求
- 责任人内部有追偿权

**连带责任的典型情形**：
- 共同侵权（第1168条）
- 共同危险行为（第1170条）
- 教唆帮助侵权（第1169条）
- 雇员侵权中雇主与雇员（第1191条）
- 违法代理中代理人与被代理人（第167条）

#### （三）按份责任 vs 连带责任

| 维度 | 按份责任 | 连带责任 |
|------|----------|----------|
| 权利人选择 | 只能向责任人主张相应份额 | 可向任一责任人主张全部 |
| 责任人承担 | 仅承担自己份额 | 承担全部，再向其他责任人追偿 |
| 抗辩 | 可主张份额抗辩 | 不得主张份额抗辩 |

### 三、民事责任承担方式（第179条）

**条文原文**：承担民事责任的方式主要有：
1. 停止侵害
2. 排除妨碍
3. 消除危险
4. 返还财产
5. 恢复原状
6. 修理、重作、更换
7. 继续履行
8. 赔偿损失
9. 支付违约金
10. 消除影响、恢复名誉
11. 赔礼道歉

**法律规定惩罚性赔偿的，依照其规定。**

**责任方式的适用**：

| 责任方式 | 适用情形 |
|----------|----------|
| 停止侵害 | 正在进行的侵权行为 |
| 排除妨碍 | 妨碍他人行使权利 |
| 消除危险 | 存在造成损害的危险 |
| 返还财产 | 无权占有他人财产 |
| 恢复原状 | 财产被损坏或改变 |
| 修理、重作、更换 | 标的物不符合约定 |
| 继续履行 | 合同义务未履行 |
| 赔偿损失 | 造成他人财产损失 |
| 支付违约金 | 合同违约 |
| 消除影响、恢复名誉 | 人格权侵害 |
| 赔礼道歉 | 人格权侵害 |

### 四、特殊民事责任情形（第180-185条）

#### （一）不可抗力（第180条）

**条文原文**：因不可抗力不能履行民事义务的，不承担民事责任。法律另有规定的，依照其规定。不可抗力是指不能预见、不能避免且不能克服的客观情况。

**不可抗力的特征**：

| 特征 | 内容 |
|------|------|
| 1. 不能预见 | 以一般人的预见能力为标准 |
| 2. 不能避免 | 尽到充分注意仍无法避免 |
| 3. 不能克服 | 尽最大努力仍无法克服 |

**典型情形**：自然灾害（地震、台风、洪水）、政府行为（征收、征用）、社会异常事件（战争、罢工）。

#### （二）正当防卫（第181条）

**第181条第1款**：因正当防卫造成损害的，不承担民事责任。

**第181条第2款**：正当防卫超过必要的限度造成不应有的损害的，正当防卫人应当承担适当的民事责任。

**正当防卫的构成**：
1. 防卫起因：存在不法侵害
2. 防卫时间：正在进行的不法侵害
3. 防卫对象：针对不法侵害人
4. 防卫意图：保护合法权益
5. 防卫限度：没有明显超过必要限度

#### （三）紧急避险（第182条）

**条文原文**：因紧急避险造成损害的，由引起险情发生的人承担民事责任。危险由自然原因引起的，紧急避险人不承担民事责任，或者给予适当补偿。紧急避险采取措施不当或者超过必要的限度，造成不应有的损害的，紧急避险人应当承担适当的民事责任。

**紧急避险 vs 正当防卫**：

| 维度 | 正当防卫 | 紧急避险 |
|------|----------|----------|
| 起因 | 不法侵害 | 危险（包括不法侵害和自然危险） |
| 对象 | 不法侵害人 | 第三人或财产 |
| 限度 | 没有明显超过必要限度 | 没有超过必要限度 |
| 责任 | 不超过必要限度的免责；超过的适当责任 | 不超过必要限度的免责或补偿；超过的适当责任 |

#### （四）见义勇为（第183条）

**条文原文**：因保护他人民事权益使自己受到损害的，由侵权人承担民事责任，受益人可以给予适当补偿。没有侵权人、侵权人逃逸或者无力承担民事责任，受害人请求补偿的，受益人应当给予适当补偿。

**理解要点**：
- 救助人因保护他人民事权益受损的，由侵权人承担
- 受益人可给予适当补偿（道德义务）
- 没有侵权人时，受益人应当给予适当补偿（法定义务）

#### （五）紧急救助（第184条）—— **新增条款**

**条文原文**：因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。

**理解要点**：救助人自愿实施紧急救助造成受助人损害的，免责。

**立法目的**：鼓励见义勇为，避免"扶不扶"困境。

#### （六）英烈保护（第185条）

**条文原文**：侵害英雄烈士等的姓名、肖像、名誉、荣誉，损害社会公共利益的，应当承担民事责任。

**理解要点**：
- 保护对象：英雄烈士等的姓名、肖像、名誉、荣誉
- 保护方式：民事责任
- 起诉主体：检察机关或英烈近亲属

### 五、责任竞合（第186-187条）

#### （一）违约责任与侵权责任竞合（第186条）

**条文原文**：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。

**理解要点**：
- 违约行为同时侵害人身权益/财产权益的，构成责任竞合
- 受损害方有权选择请求权基础
- 一旦选定，不得再变更

#### （二）民事责任优先（第187条）

**条文原文**：民事主体因同一行为应当承担民事责任、行政责任和刑事责任的，承担行政责任或者刑事责任不影响承担民事责任；民事主体的财产不足以支付的，优先用于承担民事责任。

**理解要点**：
- 责任并行：三种责任互不影响
- 财产不足以支付时：民事责任优先

### 六、诉讼时效制度（第188-199条）

#### （一）一般诉讼时效（第188条）

**条文原文**：向人民法院请求保护民事权利的诉讼时效期间为三年。法律另有规定的，依照其规定。

**时效期间分类**：

| 类型 | 期间 | 法条 |
|------|------|------|
| 普通诉讼时效 | 3年 | 第188条 |
| 国际货物买卖合同争议 | 4年 | 《民法典》第594条 |
| 人寿保险 | 5年 | 《保险法》第26条 |
| 最长保护期 | 20年 | 第188条第2款 |

#### （二）时效起算（第189-191条）

| 情形 | 起算点 |
|------|--------|
| 一般情形 | 自权利人知道或应当知道权利受到损害以及义务人之日起计算（第188条） |
| 分期履行债务 | 最后一期履行期限届满之日（第189条） |
| 无民事行为能力人对法定代理人 | 法定代理终止之日（第190条） |
| 未成年人遭性侵 | 年满18周岁之日（第191条） |
| 最长保护期 | 自权利受到损害之日起超过20年的，人民法院不予保护 |

#### （三）时效中止（第194条）

**时效中止的情形**：在诉讼时效期间的最后六个月内，因下列障碍，不能行使请求权，诉讼时效中止：

1. 不可抗力
2. 无民事行为能力人或者限制民事行为能力人没有法定代理人，或者法定代理人死亡、丧失民事行为能力、丧失代理权
3. 继承开始后未确定继承人或者遗产管理人
4. 权利人被义务人或者其他人控制
5. 其他导致权利人不能行使请求权的障碍

**时效中止的法律后果**：自中止时效的原因消除之日起满六个月，诉讼时效期间届满。

#### （四）时效中断（第195条）

**时效中断的情形**：

| 情形 | 内容 |
|------|------|
| 1 | 权利人向义务人提出履行请求 |
| 2 | 义务人同意履行义务 |
| 3 | 权利人提起诉讼或者申请仲裁 |
| 4 | 与提起诉讼或者申请仲裁具有同等效力的其他情形 |

**时效中断的法律后果**：从中断、有关程序终结时起，诉讼时效期间重新计算。

#### （五）不适用时效的请求权（第196条）

**不适用诉讼时效的请求权**：

1. 请求停止侵害、排除妨碍、消除危险
2. 不动产物权和登记的动产物权的权利人请求返还财产
3. 请求支付抚养费、赡养费或者扶养费
4. 依法不适用诉讼时效的其他请求权

#### （六）时效届满的后果（第192条）

**条文原文**：诉讼时效期间届满的，义务人可以提出不履行义务的抗辩。诉讼时效期间届满后，义务人同意履行的，不得以诉讼时效期间届满为由抗辩；义务人已经自愿履行的，不得请求返还。

**理解要点**：
- 时效届满：义务人取得抗辩权（履行抗辩）
- 法院不得主动适用（第193条）
- 时效届满后履行：不得请求返还（自然债务）
- 时效届满后重新确认：不得以时效届满抗辩

#### （七）仲裁时效（第198条）

法律对仲裁时效有规定的，依照其规定；没有规定的，适用诉讼时效的规定。

### 七、期间计算（第200-204条）

**第200条**：民法所称的期间按照公历年、月、日、小时计算。

**期间计算规则**：

| 规则 | 内容 |
|------|------|
| 第201条 | 按照年、月、日计算期间的，开始的当日不计入，自下一日开始计算 |
| 第202条 | 按照年、月计算期间的，到期月的对应日为期间的最后一日；没有对应日的，月最后一日为期间的最后一日 |
| 第203条 | 期间的最后一日是法定休假日的，以法定休假日结束的次日为期间的最后一日 |
| 第204条 | 期间的计算方法依照本法的规定，但是法律另有规定或者当事人另有约定的除外 |

**期间计算的实务要点**：

| 情形 | 规则 |
|------|------|
| 期间为1日 | 起算当日不计入，从次日起算 |
| 期间为1月 | 到期月对应日为最后一日；无对应日的，月末日为最后一日 |
| 期间为1年 | 同月同日为最后一日；无对应日的，月末日为最后一日 |
| 最后一日为法定休假日 | 延至休假日结束次日 |
| 末日截止时间 | 24小时；有业务时间的，到停止业务活动的时间 |

## ⚠️ 司法适用难点

### 难点一：正当防卫与防卫过当的认定

**争议**：如何认定"超过必要的限度"？

**主流观点**：
- **明显超过**：防卫行为明显超过必要限度
- **重大损害**：造成不应有的重大损害
- 综合考量不法侵害的强度、紧迫性、危险程度

**典型案例**：侵害他人生命权的防卫行为，致不法侵害人重伤的，一般不认定防卫过当。

### 难点二：诉讼时效起算点的认定

**争议**：侵权责任的诉讼时效起算点？

**《民法典》第188条**：自权利人知道或者应当知道权利受到损害以及义务人之日起计算。

**实务要点**：
- "知道或应当知道"：客观标准，依一般理性人判断
- "权利受到损害"：损害结果客观发生
- "义务人"：明确知道被告是谁

### 难点三：连带责任与按份责任的区分

**争议**：同一损害涉及多个主体时，如何确定责任形式？

**判断方法**：

| 情形 | 责任形式 |
|------|----------|
| 共同故意/共同过失 | 连带责任（第1168条） |
| 教唆/帮助 | 连带责任（第1169条） |
| 共同危险行为 | 连带责任（第1170条） |
| 原因叠加 | 连带责任（第1171条） |
| 分别侵权 | 按份责任（第1172条） |

## ❓ 实务问答

> **Q1：民事责任的方式有哪些？**
> 
> A：① 停止侵害；② 排除妨碍；③ 消除危险；④ 返还财产；⑤ 恢复原状；⑥ 修理、重作、更换；⑦ 继续履行；⑧ 赔偿损失；⑨ 支付违约金；⑩ 消除影响、恢复名誉；⑪ 赔礼道歉（第179条）。

> **Q2：按份责任与连带责任的区别？**
> 
> A：① 按份责任：权利人只能向责任人主张相应份额；② 连带责任：权利人可向任一责任人主张全部责任，责任人承担后可向其他责任人追偿。

> **Q3：正当防卫与防卫过当的民事责任？**
> 
> A：正当防卫造成损害的不承担民事责任；超过必要限度造成不应有损害的，承担适当的民事责任（第181条）。

> **Q4：紧急救助的免责条款？**
> 
> A：因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任（第184条）——这是《民法典》的新增条款，鼓励见义勇为。

> **Q5：一般诉讼时效期间？**
> 
> A：3年。法律另有规定的，依照其规定（第188条）。

> **Q6：诉讼时效中止的情形？**
> 
> A：在诉讼时效期间的最后六个月内，因不可抗力等障碍不能行使请求权，诉讼时效中止（第194条）。自中止原因消除之日起满六个月，诉讼时效期间届满。

> **Q7：诉讼时效中断的情形？**
> 
> A：① 权利人向义务人提出履行请求；② 义务人同意履行义务；③ 权利人提起诉讼或申请仲裁；④ 与提起诉讼或申请仲裁具有同等效力的其他情形（第195条）。中断后，诉讼时效期间重新计算。

> **Q8：哪些请求权不适用诉讼时效？**
> 
> A：① 请求停止侵害、排除妨碍、消除危险；② 不动产物权和登记的动产物权的权利人请求返还财产；③ 请求支付抚养费、赡养费或者扶养费；④ 依法不适用诉讼时效的其他请求权（第196条）。

> **Q9：期间的最后一日为法定休假日的，如何处理？**
> 
> A：以法定休假日结束的次日为期间的最后一日（第203条）。

> **Q10：违约责任与侵权责任竞合时如何处理？**
> 
> A：受损害方有权选择请求其承担违约责任或者侵权责任。一旦选定，不得再变更（第186条）。
