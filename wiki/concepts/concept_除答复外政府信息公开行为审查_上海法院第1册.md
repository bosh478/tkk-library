# 对除答复以外的政府信息公开行为的审查（上海法院第1册）

> **源行范围**：9987–10292（第四部分 对除答复以外的政府信息公开行为的审查 + 第五部分 一般裁判指引与举证指引）

## 一、不予立案情形的进一步审查

### （一）裁定驳回起诉

**法律依据**：《行诉解释》第 69 条 10 种情形

| 序号 | 情形 |
|------|------|
| ① | 不符合行政诉讼法第 49 条规定的 |
| ② | 超过法定起诉期限且无行政诉讼法第 48 条规定情形的 |
| ③ | 错列被告且拒绝变更的 |
| ④ | 未按照法律规定由法定代理人、指定代理人、代表人为诉讼行为的 |
| ⑤ | 未按照法律、法规规定先向行政机关申请复议的 |
| ⑥ | 重复起诉的 |
| ⑦ | 撤回起诉后无正当理由再行起诉的 |
| ⑧ | 行政行为对其合法权益明显不产生实际影响的 |
| ⑨ | 诉讼标的已为生效裁判或者调解书所羁束的 |
| ⑩ | 其他不符合法定起诉条件的情形 |

**程序要点**：
- 前款所列情形**可以补正或者更正**的，人民法院应当**指定期间责令补正或者更正**
- 在指定期间已经补正或者更正的 → 应当依法审理
- 法院经过**阅卷、调查或者询问当事人**，认为不需要开庭审理的 → **可以迳行裁定驳回起诉**

### （二）准予撤诉的裁定

**法律依据**：《行政诉讼法》第 62 条

- 原告申请撤诉的，法院**应当对其撤诉意愿的真实性进行审查**
- **释明**：撤回起诉后，**不得另行提起诉讼**
- 原告坚持撤回起诉的 → 法院**可予以准许**

## 二、未经复议案件的判决方式

### （一）驳回诉讼请求

**适用情形**：
- 政府信息公开答复**职权合法、程序合法、事实认定清楚、说理和法律适用正确**
- 在其他案件中，**原告的理由不能成立**
- 注意：若适用《信息公开司法解释》作为驳回诉讼请求依据的，**注意不同情形适用的具体项不同**

**法律依据**：
- **《行政诉讼法》第 69 条**：行政行为证据确凿，适用法律、法规正确，符合法定程序的 → 判决驳回原告诉讼请求
- **《信息公开司法解释》第 12 条**：8 种应当判决驳回诉讼请求的情形：
  1. 不属于政府信息、政府信息不存在、依法属于不予公开范围或者依法不属于被告公开的
  2. 申请公开的政府信息**已经向公众公开**，被告已经**告知申请人获取该政府信息的方式和途径**的
  3. 起诉被告逾期不予答复，**理由不成立**的
  4. 以政府信息**侵犯其商业秘密、个人隐私**为由反对公开，**理由不成立**的
  5. 要求被告更正与其自身相关的政府信息记录，**理由不成立**的
  6. **不能合理说明**申请获取政府信息系**根据自身生产、生活、科研等特殊需要**，且被告据此不予提供的
  7. **无法按照申请人要求的形式提供**政府信息，且被告已通过**安排申请人查阅相关资料、提供复制件或者其他适当形式提供**的
  8. 其他应当判决驳回诉讼请求的情形

### （二）撤销答复

**适用情形**：事实认定不清、说理不适当、违反法定程序、法律适用错误等

**裁判要点**：
- 行政机关对于**是否公开的判断有裁量空间**的，**在撤销的同时责令重新答复**
- **可以判定申请公开的政府信息应当予以公开**的，**在撤销的同时责令行政机关公开**

**法律依据**：
- **《行政诉讼法》第 70 条**：行政行为有下列情形之一的，人民法院**判决撤销或者部分撤销**，并可以判决被告**重新作出行政行为**：
  - ① 主要证据不足的
  - ② 适用法律、法规错误的
  - ③ 违反法定程序的
  - ④ 超越职权的
  - ⑤ 滥用职权的
  - ⑥ 明显不当的

### （三）确认违法（针对程序轻微违法等）

**适用情形**：行政行为**程序轻微违法**但**对原告权利不产生实际影响**

**裁判要点**：
- 确认违法，但不撤销行政行为
- 适用于：答复实体合法但程序存在轻微瑕疵的情形

## 三、举证责任分配

### （一）一般规则

| 主体 | 举证内容 |
|------|----------|
| **被告（行政机关）** | 证明**作出答复的事实根据、法律依据、程序履行** |
| **原告（申请人）** | 证明**提出申请、收到答复、不服答复的事实** |

### （二）特殊规则

- **主动公开抗辩**：被告承担**主动公开的时间、方式、同一性**举证
- **信息不存在抗辩**：被告承担**尽到合理检索义务**举证
- **商业秘密/个人隐私抗辩**：被告承担**该信息确属商业秘密/个人隐私**举证
- **数量/频次超过合理范围**：被告承担**数量/频次的认定事实**举证说明

## 四、关键提示

- **驳回诉讼请求**：行政行为合法 + 原告理由不成立
- **撤销答复**：事实不清/说理不当/程序违法/法律错误 + 区分是否可同时责令公开/重新答复
- **确认违法**：程序轻微违法但实体合法
- **10 种裁定驳回起诉情形** + **8 种判决驳回诉讼请求情形** = 立案/实体审查两套驳回规则
- **举证责任** = 被告为主（事实/法律/程序）+ 原告为辅（申请/收到/不服）

## 五、相比 L1 旧资料的核心差异

- 旧 L1 仅有"判决方式"原则，本节点展开**驳回/撤销/确认违法 3 大判决方式**的完整适用情形 + 法律依据
- **10 种裁定驳回 + 8 种判决驳回**的"两套驳回规则"首次系统化
- **举证责任**作为**4 大特殊规则**（主动公开/不存在/商业秘密/数量频次）首次显性化
- **《行政诉讼法》第 70 条** 6 种撤销情形与**《行政诉讼法》第 69 条**驳回情形完整列出

## 六、实务问答

> Q1: 行政机关答复合法但程序轻微违法，如何判决？
> A: **确认违法**（不撤销）——适用于**程序轻微违法但对原告权利不产生实际影响**的情形。

> Q2: 行政机关撤销后，能否同时责令公开？
> A: **可以**——若**法院可以判定申请公开的政府信息应当予以公开**的，**在撤销的同时责令行政机关公开**。

> Q3: 裁定驳回起诉与判决驳回诉讼请求如何区分？
> A: **裁定驳回起诉** = 立案阶段不符合起诉条件（10 种情形）；**判决驳回诉讼请求** = 实体审理后行政行为合法/原告理由不成立（8 种情形）。

> Q4: 被告主动公开抗辩的举证责任？
> A: 被告承担**主动公开的时间、方式、同一性**举证——证明**答复前已主动公开 + 与申请信息同一 + 查询方式正确**。

> Q5: 数量/频次超过合理范围的举证责任？
> A: **被告**承担**数量/频次认定事实**的举证说明——需说明申请人**申请信息公开的目的已超越知情权范畴**。
