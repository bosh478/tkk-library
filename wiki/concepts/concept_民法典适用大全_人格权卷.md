# 民法典适用大全·人格权卷

## 内容定位

本卷围绕《民法典》人格权编全部51个条文，系统编辑关联规定、条文释义、适用指引、指导案例、典型案例和类案检索。人格权独立成编是《民法典》的最大亮点之一，体现了以人民为中心的立法理念，在世界民法典立法史上具有里程碑意义。

**体例结构**：每个条文按"关联规定→条文释义→适用指引→典型案例→类案检索"五部分组织。

## 章节结构总览

### 第一章 一般规定（第989-1001条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第989条 | 调整范围 | 因人格权的享有和保护产生的民事关系 |
| 第990条 | 一般人格权和具体人格权 | 生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等；自然人享有基于人身自由、人格尊严产生的其他人格权益 |
| 第991条 | 人格权受法律保护 | 民事主体的人格权受法律保护，任何组织或个人不得侵害 |
| 第992条 | 禁止性规定 | 人格权不得放弃、转让或继承 |
| 第993条 | 人格利益许可使用 | 姓名、名称、肖像等可以许可他人使用 |
| 第994条 | 死者人格利益保护 | 死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权请求承担民事责任 |
| 第995条 | 民事责任 | 人格权受到侵害的，受害人有权依法请求行为人承担民事责任；停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权不适用诉讼时效 |
| 第996条 | 精神损害赔偿 | 因当事人一方的违约行为损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响请求精神损害赔偿 |
| 第997条 | 人格权侵害禁令 | 民事主体有证据证明行为人正在或即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，可申请法院责令停止 |
| 第998条 | 责任承担考量因素 | 认定行为人承担侵害人格权的民事责任应考虑的因素 |
| 第999条 | 人格利益的合理使用 | 为公共利益实施新闻报道、舆论监督等行为的，可以合理使用民事主体的姓名、名称、肖像、个人信息等 |
| 第1000条 | 消除影响、恢复名誉、赔礼道歉 | 应与行为的具体方式和造成的影响范围相当 |
| 第1001条 | 身份权利的法律适用 | 身份权利的保护适用总则编和婚姻家庭编等的规定 |

### 第二章 生命权、身体权和健康权（第1002-1011条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1002条 | 生命权 | 自然人享有生命权；生命安全和生命尊严受法律保护 |
| 第1003条 | 身体权 | 自然人享有身体权；身体完整和行动自由受法律保护 |
| 第1004条 | 健康权 | 自然人享有健康权；身心健康受法律保护 |
| 第1005条 | 法定救助义务 | 自然人的生命权、身体权、健康权受到侵害或处于其他危难情形的，负有法定救助义务的组织或个人应当及时施救 |
| 第1006条 | 人体捐献 | 完全民事行为能力人有权依法自主决定无偿捐献其人体细胞、人体组织、人体器官、遗体 |
| 第1007条 | 禁止买卖人体 | 禁止以任何形式买卖人体细胞、人体组织、人体器官、遗体 |
| 第1008条 | 人体临床试验 | 为研制新药、医疗器械或发展新的预防和治疗方法进行临床试验的，应依法经主管部门批准并经伦理委员会审查同意 |
| 第1009条 | 基因和胚胎 | 从事与人体基因、人体胚胎等有关的医学和科研活动应遵守法律、法规和国家有关规定 |
| 第1010条 | 性骚扰 | 违背他人意愿以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权请求行为人承担民事责任 |
| 第1011条 | 侵害行动自由和非法搜查 | 以非法拘禁等方式剥夺、限制他人行动自由，或非法搜查他人身体的，受害人有权请求承担民事责任 |

### 第三章 姓名权和名称权（第1012-1017条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1012条 | 姓名权 | 自然人享有姓名权，有权依法决定、使用、变更或许可他人使用自己的姓名 |
| 第1013条 | 名称权 | 法人、非法人组织享有名称权，有权依法决定、使用、变更、转让或许可他人使用自己的名称 |
| 第1014条 | 禁止侵害姓名权、名称权 | 任何组织或个人不得以干涉、盗用、假冒等方式侵害 |
| 第1015条 | 姓氏选取规则 | 应随父姓或母姓；可在父姓和母姓之外选取姓氏的情形 |
| 第1016条 | 姓名名称变更 | 自然人决定、变更姓名或法人、非法人组织决定、变更、转让名称的，应办理变更登记 |
| 第1017条 | 笔名、艺名等保护 | 具有一定社会知名度的笔名、艺名、网名、译名、字号、姓名和名称的简称等，受法律保护 |

### 第四章 肖像权（第1018-1023条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1018条 | 肖像权 | 自然人享有肖像权，有权依法制作、使用、公开或许可他人使用自己的肖像 |
| 第1019条 | 禁止侵害肖像权 | 任何组织或个人不得以丑化、污损或利用信息技术手段伪造等方式侵害他人肖像权 |
| 第1020条 | 肖像权合理使用 | 为个人学习、艺术欣赏、课堂教学或科学研究等可合理使用 |
| 第1021条 | 肖像许可使用合同解释 | 对肖像许可使用条款有争议的，应作出有利于肖像权人的解释 |
| 第1022条 | 肖像许可使用期限 | 没有约定或约定不明确的，任何一方可随时解除 |
| 第1023条 | 姓名许可和声音保护 | 对姓名等的许可使用参照适用肖像权规定；声音保护参照适用肖像权规定 |

### 第五章 名誉权和荣誉权（第1024-1031条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1024条 | 名誉权 | 民事主体享有名誉权；任何组织或个人不得以侮辱、诽谤等方式侵害 |
| 第1025条 | 新闻报道与舆论监督 | 行为人为公共利益实施新闻报道、舆论监督等行为影响他人名誉的，不承担民事责任（有例外） |
| 第1026条 | 合理核实义务 | 认定行为人是否尽到合理核实义务应考虑的因素 |
| 第1027条 | 文学、艺术作品侵害名誉权 | 行为人发表的文学、艺术作品以真人真事或特定人为描述对象，含有侮辱、诽谤内容的应承担民事责任 |
| 第1028条 | 媒体报道失实的补救 | 媒体报道内容失实侵害名誉权的，有权请求更正或删除 |
| 第1029条 | 信用评价不当 | 民事主体可以查询自己的信用评价；发现错误有权提出异议并请求更正等 |
| 第1030条 | 信用信息保护 | 民事主体与征信机构等之间的关系适用个人信息保护规定 |
| 第1031条 | 荣誉权 | 民事主体享有荣誉权；任何组织或个人不得非法剥夺 |

### 第六章 隐私权和个人信息保护（第1032-1039条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1032条 | 隐私权 | 自然人享有隐私权；任何组织或个人不得以刺探、侵扰、泄露、公开等方式侵害 |
| 第1033条 | 侵害隐私权的典型形态 | 以电话、短信等方式侵扰私人生活安宁；进入、拍摄、窥视他人私密空间等 |
| 第1034条 | 个人信息 | 自然人的个人信息受法律保护；个人信息包括自然人的姓名、出生日期、身份证号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等 |
| 第1035条 | 处理个人信息的原则和条件 | 应遵循合法、正当、必要原则；应征得自然人或其监护人同意 |
| 第1036条 | 处理个人信息的免责事由 | 在自然人或其监护人同意范围内合理实施的行为等 |
| 第1037条 | 信息主体的权利 | 自然人可以依法向信息处理者查阅、复制、更正、删除其个人信息 |
| 第1038条 | 信息处理者的安全保护义务 | 信息处理者不得泄露或篡改其收集、存储的个人信息 |
| 第1039条 | 国家机关保密义务 | 国家机关、法定机构及其工作人员对于履行职责过程中知悉的自然人的隐私和个人信息应予以保密 |

## 核心制度解读

### 一、人格权独立成编的制度意义

**立法创新**：人格权独立成编是《民法典》最大的亮点和创新，在世界各国民法典中尚属首次。这体现了以人民为中心的发展理念，顺应了新时代人民群众对人格尊严、人格权保护的迫切需求。

**体系价值**：将人格权制度从侵权责任法中独立出来，形成完整的人格权保护体系，包括人格权的一般规定、各类具体人格权的规定。

### 二、人格权侵害禁令制度（第997条）

**制度意义**：被称为"人格权保护的端口前移"，在侵害行为发生前或正在发生时即可请求法院责令停止。

**适用条件**：有证据证明行为人正在或即将实施侵害其人格权的违法行为；不及时制止将使其合法权益受到难以弥补的损害。

### 三、性骚扰的法律规制（第1010条）

**构成要件**：违背他人意愿；以言语、文字、图像、肢体行为等方式实施。

**责任主体**：用人单位应采取措施预防和制止性骚扰。

### 四、个人信息保护（第1034-1039条）

**保护范围**：姓名、出生日期、身份证号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等。

**处理原则**：合法、正当、必要；应征得同意；不得过度处理。

**信息主体权利**：查阅、复制、更正、删除权。

## ❓ 常见问题

> 问：什么是人格权侵害禁令？
> 答：民事主体有证据证明行为人正在或即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，可依法向人民法院申请采取责令行为人停止有关行为的措施（第997条）。

> 问：声音是否受法律保护？
> 答：是。第1023条第2款规定，对自然人声音的保护，参照适用肖像权保护的有关规定。

> 问：死者的人格利益是否受保护？
> 答：是。死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权请求承担民事责任（第994条）。

> 问：处理个人信息需要满足什么条件？
> 答：应遵循合法、正当、必要原则；应征得自然人或其监护人同意；应明示处理信息的目的、方式和范围；不得过度处理（第1035条）。

> 问：新闻报道侵害名誉权是否一定承担责任？
> 答：不一定。行为人为公共利益实施新闻报道、舆论监督等行为影响他人名誉的，不承担民事责任，但有捏造歪曲事实、未尽合理核实义务等情形的除外（第1025条）。
