## 🎯 核心论点

**侵权责任的客观构成要件** = 三要件：
1. **加害行为**（行为要件）
2. **民事权益被侵害**（权益要件）
3. **因果关系** + **损害**（结果要件）

---

## 第一节 加害行为

## 一、加害行为概述

**加害行为**（Handlung）= 引起损害发生的、可归责的行为。

**加害行为的特征**：
- 是人的行为（不是自然现象）
- 是可归责的（基于行为人意志或违反义务）
- 是导致损害的原因

## 二、加害行为的分类：作为与不作为

### （一）区分标准

| 类型 | 含义 | 识别 |
|------|------|------|
| **作为**（Tun）| 行为人积极的举止动作 | 有所为 |
| **不作为**（Unterlassen）| 不做某件事情，处于消极静止状态 | 有所不为 |

**核心规则**：
- 原则上只有**作为**才构成加害行为
- 不作为只有在行为人**负有作为义务**时才构成加害行为

### （二）作为义务的产生

**1. 基于特定关系的作为义务**

| 关系类型 | 典型义务 | 法条 |
|---------|---------|------|
| 婚姻家庭关系 | 夫妻间互相扶养义务 | 《民法典》第1058、1059条 |
| | 父母对未成年子女抚养、教育、保护义务 | 《民法典》第1067条 |
| | 子女对父母赡养扶助义务 | 《民法典》第1068条 |
| 契约关系 | 当事人约定的义务 | 意思自治 |
| 运输/医疗合同 | 法律规定直接规定 | 《民法典》第822条承运人救助义务 |
| 债权债务终止后 | 通知、协助、保密、旧物回收 | 《民法典》第558条 |

**2. 基于特定身份或职业、营业活动的法定作为义务**

| 身份/职业 | 作为义务 | 法律依据 |
|----------|---------|----------|
| 法定救助义务人 | 及时施救 | 《民法典》第1005条 |
| 人民警察 | 立即救助 | 《人民警察法》第21条第1款 |
| 任何单位发生火灾 | 组织扑救 | 《消防法》第44条第3-4款 |
| 网络服务提供者 | 知道侵权后采取删除等 | 《民法典》第1195条第2款 |

**3. 在先行为引发的作为义务**

- 在先行为诱发/开启了某种危险状态
- 行为人负有消除危险状态或救助受害人的义务

**例3**：陈某在自家院内挖地窖，致小偷余某掉入坑中受伤 → 陈某无作为义务（私人财产范围内，且非正当理由进入），余某自负其责

**4. 防止/制止第三人侵权的安全保障义务**

**特定场所**：
- 经营者、管理者
- 特定活动的组织者
- 负有保障他人人身、财产安全的义务

## 第二节 民事权益被侵害

## 一、民事权益的范围

**《民法典》总则编第五章"民事权利"列举的民事权益**：
- 生命权、身体权、健康权
- 姓名权、名称权
- 肖像权、名誉权、荣誉权
- 隐私权、个人信息权益
- 婚姻自主权
- 人格尊严、人身自由
- 财产权（物权、债权、知识产权、继承权等）

**民法典侵权责任编保护范围**（第1165条）：
> 民事主体的人身权利、财产权利以及其他合法权益。

## 二、侵害的判断

**侵害** = 行为人的加害行为造成了他人合法权益的损害。

**侵害 vs 行使权利**：
- 行使权利 vs 滥用权利
- 合法行为 vs 侵权行为
- 需要利益衡量

## 三、权益侵害的分类

| 类型 | 内涵 |
|------|------|
| 人身权益侵害 | 生命、身体、健康、人格权益等 |
| 财产权益侵害 | 物权、债权、知识产权等 |
| 其他权益侵害 | 婚姻家庭权益、继承权等 |

---

## 第三节 损害

## 一、损害的概念

**损害**（Schaden）= 权利或法益受侵害时所发生的不利益后果。

**损害的要件**：
1. 是权利或法益受侵害的客观结果
2. 是法律意义上的损害（不是任何不利益）
3. 是可补救的（能恢复原状或金钱赔偿）

## 二、损害的分类

### （一）按权益分类

| 类型 | 内涵 |
|------|------|
| **人身损害** | 生命权、身体权、健康权、人格权等损害 |
| **财产损害** | 财物损失、费用支出、收入减少、可得利益损失 |

### （二）按内容分类

| 类型 | 内涵 |
|------|------|
| **所受损害**（damnum emergens）| 现有财产的减少（直接损失） |
| **所失利益**（lucrum cessans）| 可得利益的丧失（间接损失） |

### （三）按可否补救分类

| 类型 | 内涵 |
|------|------|
| **实际损害** | 真实发生的损失 |
| **象征性损害**（symbolischer Schaden）| 仅构成权利侵害但无实际损失 |

### （四）按当事人分类

| 类型 | 内涵 |
|------|------|
| **直接受害人的损害** | 加害人直接造成的损害 |
| **反射损害** | 受害人近亲属等因受害人损害而间接受到的损害 |

### （五）按时间分类

| 类型 | 内涵 |
|------|------|
| **既存损害** | 已经发生的损害 |
| **将来发生的损害**（未来损害）| 将来必然发生的损害 |

---

## 三、损害的特别情形

### （一）精神损害

**《民法典》第1183条**：
> 侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。

**精神损害赔偿的条件**：
- 自然人的人身权益受到侵害
- 造成**严重**精神损害
- 有法律依据（如第1183条）

**精神损害赔偿的法定情形**：
1. 侵害生命权、身体权、健康权
2. 侵害姓名权、肖像权、名誉权、荣誉权
3. 侵害人格权、人身自由
4. 违反社会公共利益、社会公德侵害他人隐私或个人信息
5. 因故意或重大过失侵害具有人身意义的特定物
6. 其他情形

### （二）纯粹经济损失

**纯粹经济损失**（reiner Vermögensschaden; pure economic loss）= 非因人身或财产受侵害而直接发生的经济损失。

**典型情形**：
- 律师执业过失导致当事人丧失诉讼时效
- 审计师过失导致投资人损失
- 货物运输延误导致买受人生产线中断

**赔偿规则**：原则上不予赔偿，例外情形可赔。

### （三）机会丧失

**机会丧失** = 受害人因加害人的行为丧失了某种机会。

**法律地位**：在因果关系上可能成立（须证明机会丧失与加害行为之间有因果关系）。

---

## 第四节 加害行为与权益侵害的关系

## 一、因果关系要件

加害行为与权益侵害之间须存在**因果关系**（详见第六章）。

## 二、加害行为与权益侵害的判断步骤

1. **行为** 是否存在加害行为？
2. **权益** 是否存在被侵害的民事权益？
3. **因果关系** 加害行为是否是权益侵害的原因？
4. **损害** 是否存在损害？
5. **过错** 加害人是否有过错（过错责任下）？

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **加害行为** | 引起损害发生的、可归责的行为 |
| **作为** | 行为人积极的举止动作 |
| **不作为** | 行为人消极静止状态（须有作为义务）|
| **作为义务** | 行为人应当积极实施某种行为的法律义务 |
| **特定关系的作为义务** | 基于婚姻家庭、契约等关系产生的义务 |
| **法定身份的作为义务** | 人民警察、医生、消防等的义务 |
| **在先行为义务** | 在先行为开启危险源后的消除义务 |
| **安全保障义务** | 经营者/管理者保护他人安全的义务 |
| **损害** | 权利或法益受侵害时的不利益 |
| **所受损害**（damnum emergens）| 现有财产减少 |
| **所失利益**（lucrum cessans）| 可得利益丧失 |
| **直接损害** | 加害人直接造成的损害 |
| **反射损害** | 间接受害人因受害人损害受到的损害 |
| **将来损害** | 将来必然发生的损害 |
| **精神损害** | 人身权益侵害造成的严重精神痛苦 |
| **纯粹经济损失** | 非人身/财产侵害直接导致的经济损失 |
| **机会丧失** | 因加害人行为丧失某种机会 |
