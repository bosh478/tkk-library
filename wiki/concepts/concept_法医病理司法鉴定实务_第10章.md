## 第十章 机械性损伤与致伤物推断及成伤机制分析



钝器种类繁多，从人体的掌、拳、足、牙到各种生活用品，以及生产工具等都可以作为致伤物，因此造成的损伤形态多种多样。钝器伤通常表现为擦伤、挫伤、挫裂创、骨折、内部器官破裂或者肢体离断等形态，其中以擦伤、挫伤和挫裂创多见。挫伤通常与擦伤并存，挫裂创多伴有擦伤和挫伤。钝器伤多见于他杀案件及意外事故。另外，交通事故、坠落和挤压等损伤类型易形成复合钝器伤。常见的锐器有刀、斧、匕首、剪刀等，根据使用方式不同一般分为刺器、砍器、切器、刺切器，锐器伤按其作用方式和发生的部位不同，可导致皮肤、骨骼和内脏器官不同类型的损伤。锐器伤多见于他杀案件。



致伤物推断及成伤机制分析，是命案现场勘查及司法鉴定中重要的组成部分。不同的案件中，嫌疑人对凶器的选择与凶器的获得、作案的目的和动机、案件的性质、职业特点、现场条件、个人体质状况等有关。现场提取的可疑致伤物、根据损伤推断的致伤物、知情人提供的致伤物以及从嫌疑人处搜得的致伤物等均有可能与案件存在着某种直接或间接的联系。根据推断的凶器及成伤机制分析，对以物找人、分析作案过程、判定案件性质、锁定嫌疑人起到重要的作用，也为侦查人员对调查访问的内容、询问／讯问情况及口供的真实性等的判断创造条件，同时为诉讼和审判提供证据。



机械性损伤致伤物（instruments inflicting mechanical injuries）指所有作用于人体引起组织结构破坏和（或）功能障碍的具有机械性因素的物体，包括钝器、锐器、火器（枪弹）等。机械性损伤的致伤物推断（judgement of instruments inflicting injuries）是根据机械性损伤形态特点，结合案情及现场勘查、辅助检验环节中的特征性要素，对致伤物的类型、大小、质地、重量及作用面形状等特点进行综合分析推断的过程。



成伤机制分析（analysis of mechanism inflicting injury），有时也称之为致伤方式分析，是利用法医学及相关学科，如物理学、生物力学、损伤力学、解剖学、生理学等学科知识，依据损伤的形态学，对可疑致伤物检验，结合案情及现场调查等信息，对损伤形成的过程、方式以及暴力因素和损伤结果之间关系等进行研究、判断，主要内容包括损伤形成过程与方式、致伤物作用力方向及作用过程、作用力的大小、损伤次数等分析的过程。机械性损伤成伤机制分析是认识损伤表象与致伤行为关系的重要基础，是深化对损伤本质认识的前提。脱离成伤机制分析，就难以准确鉴别各种类型致伤物形成不同形态的损伤。本章主要对钝器和锐器两种致伤物推断及成伤机制分析进行重点介绍。

## 1． 圆柱形棍棒伤



由于圆柱形棍棒致伤物表面为圆弧形，打击人体时仅有棍棒部分表面与人体接触，并且受作用的各部位压强不同，因此作用于不同组织形成的损伤有一定特征性；一般情况下常表现为



长条状皮内、皮下出血，中心部位损伤重，向两侧逐渐减轻，边界不清，出血带宽度小于棍棒直径。当木质棍棒表面不平滑时，可在打击范围内出现灶状的表皮剥脱。铁制棍棒形成的表皮剥脱较重，在打击范围内常有条状表皮剥脱。圆柱形棍棒类致伤物打击人体时，主要形成以下几种较为特征性的损伤



1）当圆柱形棍棒快速重力打击在平坦且软组织较为丰满的部位时即可出现类似“竹打中空”“铁轨样挫伤”形态的中空性挫伤（图 10 1）。



2）当圆柱形棍棒打击在头部时，易出现头皮挫裂创，两侧创缘可见对称性挫伤带，呈“镶边样”挫伤带所见。



3）头皮及皮下组织因含有大量毛囊结构及颅骨衬垫易被造成挫裂或挫碎，形成弧形挫裂创。



4）当棍棒打击头部时且力量较大时往往形成骨折，可表现为线性、舟状凹陷性甚至粉碎性骨折。

## 2． 方柱形棍棒伤



当方柱形棍棒不同面打击机体可表现为不同类型的损伤，常有以下几种：



（1）平面垂直打击 方柱形棍棒以其平面垂直打击人体时，形成均匀的带状挫伤，界线清楚，宽度与接触面宽度基本一致。快速、猛击平坦且软组织丰厚的部位，形成带状中空性挫伤。



（2）棒端打击 用棒端打击时，出现槽状中空性皮下出血，中空区宽度可反映接触面宽度，力量较大时，可形成线形骨折，或长方形凹陷性骨折、粉碎性骨折。



（3）棱边垂直打击 若以其棱边垂直打击人体软组织，可形成条状擦伤、挫伤，中心部位较重。若软组织下有骨质衬垫，则易形成条状挫裂创，创口边缘平直，创缘周围出血带不明显，创腔内常无组织间桥。致伤物为铁质、打击力量较大时，可形成颅骨沟状凹陷性骨折。



（4）倾斜打击 若以棒体倾斜打击，可形成条带状挫伤，着力重的一侧边界清楚，并常伴有擦伤，另一侧边界模糊。力量大时，形成挫裂创，在颅骨上可形成一侧骨板下陷明显的骨折。



（5）棒端戳（压）击 以棒端戳击，可形成与棍棒端形态相似的方形挫伤。端部一角打击时，可形成三角形皮内、皮下出血或挫裂创，在颅骨上可形成三角形凹陷性骨折。



## 3． 不规则形棍棒伤



不规则棍棒形态特殊，如纵轴弯曲、粗细不均、表面凹凸不平以及有分支或其他附属物，打击时形成的损伤可表现为散在、大小不等、形态不一、程度不同的擦伤、划伤、挫伤、挫裂创。

## 1． 砖头伤



砖头平面打击，打击头面部时挫伤区常伴有砖石粗糙面所致的点状擦痕。打击软组织丰满部位，可形成长方形中空性挫伤。倾斜打击形成线条状平行排列的梳齿状擦痕；砖头棱边或棱角打击，打击头部在头皮可形成条形、三角形皮内、皮下出血和表皮剥脱。当打击力度大时，在头皮可形成条状、三角形挫裂创，有时可见组织挫碎，创口周围可以留碎砖屑、灰砂等物；断砖头打击，损伤轻重不一、形态不规则，同一损伤区内可同时存在多发性、大小形状不一的擦伤、挫伤、挫裂创。



## 2． 石头伤



石头致伤的案件常发生在野外，其中以山石、鹅卵石损伤较为常见。受伤部位多位于头部。



（1）山石伤 不规则的山石一次打击，常可形成大小不等、深浅不一、形态各异的损伤，与断砖打击形成的损伤相似。山石打击头部所致的挫裂创，可表现为多种形状，但大多数为不规则形，有多个创角，创腔内可见石屑，呈现出周围着力较轻、中央着力较重的趋势，并且在创口周围伴有多种形态、轻重不一的擦伤、挫伤、挫裂创（图 10 2、图 10 3）。



（2）鹅卵石伤 鹅卵石多见于河滩和一些山区，可呈不规则圆形或椭圆形，表面较光滑，质地较坚硬致密。损伤部位多见于头部。



鹅卵石打击可在头皮上形成表皮剥脱和皮下出血，其形状多为类圆形或椭圆形，中心部位出血较严重，色泽较深，周边逐渐浅淡，边界不清。鹅卵石所致挫裂创，创口周围常伴有范围较大的表皮剥脱、皮下出血。鹅卵石打击造成的骨折，与打击力的大小和接触面有关。

徒手伤是指加害人在不使用任何器具而是用身体的某一部位造成的损伤。常见于事先无准备或无工具利用的情况下发生的案件，如纠纷斗殴、虐待、强奸等案件。徒手伤多使用手、脚或者肘、膝、牙齿以及头部等部位形成。形成的损伤轻者可致擦伤、挫伤、挫裂创，重者可形成骨折、内脏器官损伤，甚至造成死亡。



## 1． 手所致损伤



（1）抓痕 指甲掠过皮肤表面并使表皮移位，在表皮形成扇形或几条平行的沟状痕，尾端逐渐变浅变细，多见于面部、颈部和上肢等处。



（2）手指伤 手指尤其是指端以一定力量压迫身体表面一段时间特别是颈部，受伤部位皮肤形成局限性圆形或椭圆形皮下出血，前部伴有新月状表皮剥脱。



（3）掌击伤 损伤较轻，肉眼可无明显变化，重者可见较大面积皮内出血或皮下出血，典型者可检见与手掌外形相似的皮下出血。击中耳部可致鼓膜穿孔。



（4）拳击伤 拳头形态不规则，体表常见不规则形擦伤、皮内出血和皮下出血。



## 2． 足所致损伤



（1）足踢伤 损伤形状及程度主要与加害者是否穿鞋、鞋的质地、作用力大小、作用部位有关，作用于胸腹部可致骨折或者内脏损伤。



（2）足踩伤 轻者可致表皮剥脱、皮下出血，重者可致骨折、内脏破裂、穿孔；压迫颈胸腹部可导致窒息死，属于扼颈所致的机械性窒息。



## 3． 咬伤



轻微咬伤仅在皮肤留下轻微痕迹，稍重的可形成皮下出血伴有擦伤，更重的形成挫裂创，甚至组织器官缺损。其形态多为对称的半弧形构成圆形或椭圆形的咬痕，常见于面颊、肩部、乳房等。

## 1． 钝器损伤形态特征分析



钝器创的主要特点在于创口形态不一，创角钝，创缘不齐，创底不平整，创腔不整洁，创壁



间可见组织间桥。当发现钝器创时，往往提示施加的作用力较大或致伤物具有一定重量。在分析时应详细记录创位置、大小、深度、创口、创缘、创角、创底、创腔、创壁等特征。



（1）挫裂创 往往由有一定重量，质地较硬的致伤物，在较大力的作用下作用在人体上形成。



（2）撕裂创 可见于作用力较大且与人体表面呈小于 $9 0 ^ { \circ }$ 的方向作用于人体时。



（3）捅创 多见于有一定长度，粗细多较细，空心或实心的棍棒以与人体表面呈 $9 0 ^ { \circ }$ 左右作用于人体时，通常捅创在体表可见一定组织缺失，创缘、创底多不平整。



## 2． 钝器作用力大小与方向分析



（1）作用力大小分析 钝器作用力的大小会直接影响损伤的程度。影响作用力和能量的因素比较多，由牛顿第二定律可知，力等于物体质量和运动加速度的乘积 $\prime = m a )$ ），加速度是单位时间内速度的变化程度 $\left( a = { \frac { \Delta v } { \Delta t } } \right)$ ，物体的运动速度在较短时间内改变（Δv 增大），作用力会正比增大，损伤程度也会增加。另一方面，物体由于运动而具有的能量称为动能，由动能定理 $E _ { \mathrm { { } } k } = { \frac { 1 } { 2 } } m v ^ { 2 }$ 可知，质量越大、运动速度越快，动能就越大，机体所能形成的损伤就越重。



钝性外力作用于较小面积时更易发生损伤 $\left( \sigma _ { i j } = \operatorname * { l i m } _ { \Delta A _ { i } \to 0 } \frac { \Delta F _ { j } } { \Delta A _ { i } } \right)$ 。 人体形变速度（v）和压力（c）的相互关系是引起损伤的重要因素。已有用两者的乘积 $\left( v \times c \right)$ 来描述损伤的严重性。如果形变速度高，即使作用于胸部的压力极小，也会发生内部器官的损伤。器官或组织对压力和撞击速度的抵抗力可以反映为其耐受度。当对损伤的程度进行分析后与作用力大小相结合可以大致判断出作用力的大小范围。如挫裂创往往可反映作用力较大，也可提示致伤物具有一定的重量，在继续侦查时所找寻的嫌疑人至少是有一定力量，可以较轻松使用重量较大致伤物并施加较大作用力的人。



（2）作用力方向分析 作用力方向往往可以反映损伤的来源，是成伤机制的重要部分，主要包括着力点和受力方向两方面分析，以此综合判断作用力方向。



损伤着力点是指物体与组织直接接触导致损伤的位置，通常也指受力最大或起始位置。软组织损伤着力点可表现为表皮剥脱处、皮下出血处、中空性皮下出血的中空区和挫伤处等。而骨骼损伤着力点多为骨质表面缺损和压痕处、外板完整而内板骨折处、各条线状骨折分支密集处等。由于力的传导、压力的变化以及血液的扩散等原因，对于确定着力点而言，皮肤损伤比骨骼损伤更为稳定，而骨骼损伤比器官损伤更为稳定。如交通事故中，驾驶员双手紧握方向盘导致损伤时，着力点可能在手或前臂，而骨骼损伤可能发生在肱骨甚至锁骨。而当身体高坠着地时，足部首先受到压力，力的传导可能导致脊柱甚至骨盆的损伤，胸廓的变形或骨骼的移位挤压可能导致胸腹腔内任何器官的损伤。对于皮肤损伤，表皮剥脱、皮内出血和创伤是反映受力方向稳定的指标，而单纯的皮下出血有时并非受力的结果。因为在皮肤软组织较薄的位置，骨折由于传导作用引起的出血往往会扩散至皮下。确定着力点是损伤分析的基础条件，也是第一步的工作。



判断清楚受力方向后，便可根据牛顿第三定律可知作用力方向，从而通过物体接触方式推断嫌疑人与受害人相互的体位关系，并在某些情况下辅助左右利手的判断，甚至判断作案人数、死亡性质等。例如死者颅顶部凹陷性骨折，则可提示多是嫌疑人从背后在死者处于低位时打击形成；枕部出现损伤，则被害人遇害时处于俯卧位可能性较大。在皮肤表面形成的擦伤可更好地提示受力方向。在交通事故中，常发生汽车拖拽受害人的情况，而在受害人皮肤表面，可观察到一定方向性的擦伤，在擦伤末端可见游离皮瓣，提示受害人受力方向与擦伤方向相反。然而，需要注意的是，受力方向的判断并不完全符合上述规律。例如，对于夹角形状的矩形损伤，撕裂方向与车辆的拉、推、挤方向可能不一致；在判断骨折方向时需要谨慎，通常只需大致判断垂直和斜向，以及前后、左右、上下的方向，不宜轻易进行过于具体的方向判断，如右下斜向左上的判断。此外，还需要注意某些观察指标的不稳定性。



## 3． 损伤次数分析



损伤次数的分析主要依据损伤的数目、位置和组织结构特点、作用力的性质和方式等。



（1）软组织损伤的打击次数和顺序



1）距离相距较远的软组织损伤个数直接反映打击次数。



2）非同一个平面的软组织损伤个数直接反映打击次数。



3）不相邻的挫裂创的个数多提示打击次数。



4）明显重叠的挫裂创的个数直接反映打击次数。



5）皮下组织挫裂创等的个数直接反映打击次数。



6）软组织重叠挫裂创通常位于单个挫裂创之后。



（2）骨骼损伤的打击次数和顺序



1）局部变形导致的骨折线的数量直接反映打击次数。



2）凹陷骨折边缘弧度较大的数量直接反映打击次数。



3）凹陷性骨折、孔状骨折的数量直接反映打击次数。



4）两条骨折线相交，延长受阻的骨折线产生在后。



5）两条骨折线交叉，其中错位的骨折线产生在后。



6）粉碎性骨折区内板脱落较多的位置受力在前。



值得注意的是，有时候一次损伤可以导致多个或多处损伤，尤其在人体与较大平面物体接触时。因此，损伤的数量或者受影响的区域，并不总是与作用的次数直接对应。损伤发生在对侧部位，首先需要确定是否是一次打击导致的。此外，高坠尸体，力量传导和人体腔隙受到挤压可能会导致多组织和多器官的损伤。骨折线的数量有时与打击次数不一致，除了放射状骨折外，正常的骨折线可能会呈分叉状，容易被误认为是两次打击形成。在某个局部区域，若骨折线缺乏连续性，很可能是由于骨骼结构本身的原因，而不是两次或多次损伤造成的结果。

## 1． 推断致伤物的种类



根据损伤的形态特点，推断其是否为钝器形成一般不难。但是，同一种钝器的不同打击面打击人体，可形成形态不同的损伤；同一种钝器击打人体的不同部位，或是打击的力量、速度、方式等不同，所形成的损伤形态也可能不同；不同的钝器完全可以形成形态学特征相似的损伤。实际工作中，法医一般根据不同种类钝器所能形成的最具代表性的损伤，将致伤物确定为某个种类而非某一具体的钝器，如根据条状中空性挫伤推断致伤物为棍棒类。



## 2． 推断致伤物的形态



无论是擦伤、挫伤还是挫裂创，一般不会反映某一致伤物特有的形状特征，而是仅反映钝器的共同特征。只有部分钝器损伤能反映致伤物与人体接触面的形态特征。



推断擦伤致伤物的形态：细条状或梳状的擦伤，提示致伤物与人体接触面类似细砂石呈凹凸不平状；脖颈、股内侧、乳房等处的半月形擦伤，伴有或不伴有圆形或椭圆形挫伤，一般由犯罪嫌疑人的指端（指甲和手指）造成；印痕状擦伤，多见于交通事故中，其形态一般符合机动车保险杠或散热器的形态特征。



推断挫伤致伤物的形态：体表的平行条状、带状挫伤一般为棍棒类致伤物形成，若两侧挫伤带与周围皮肤分界明显，则可利用其推断致伤物的宽度，而条状或线状的挫伤可认为是棍棒的棱边造成；圆形或方形挫伤提示致伤钝器存在圆形或方形接触面，而当方形挫伤伴有成角的挫伤或挫裂创时提示具有类方形平面的金属工具（如斧背或锤背）；具有特殊纹路的挫伤系表面带有对应花纹或沟嵴的致伤物打击人体造成部分皮肤剧烈扭曲，出现皮内出血所形成（如轮胎碾压形成的印痕）；大面积的皮内出血和皮下出血应由较大的平面拍击所致，如木板、砖块或与地面接触等。



推断挫裂创致伤物的形态：挫伤和挫裂创在形成上有相似之处，均是钝性外力挫压所致。挫裂创的创口面积可能大于致伤物的打击面。条状和椭圆形的挫裂创多为圆柱形较粗的长条状物打击所致，伴随创缘的挫伤带若一侧宽一侧窄，则多为致伤物偏击所致；弧形挫裂创，沿弧缘的圆心侧常伴有皮内出血或挫伤，常为致伤物的某一端或某一侧打击所致，可以通过几何学方法推算接触面的直径；角形挫裂创系带有棱角的致伤物形成，如砖块、斧背或棍棒的棱角和棱边等。



## 3． 推断致伤物的重量



对损伤部位进行检查，发现表皮剥脱严重、一击多伤、多形式的裂创、击打部位形成皮肤挫伤、较大长度挫裂创、颅骨凹陷性骨折，则致伤物重量较重。



## 4． 推断致伤物的质地



法医学实践中最常见的钝器包括金属、砖石和木质三种质地。致伤物的质地推断，主要是需要考虑金属、非金属的区分。



推断致伤物质地的指标，在创口上主要是观察创边挫伤的特征和压痕挤压缘的特征。创边挫伤的特征要观察边缘整齐程度、轻重均匀程度、分界清楚程度，边缘是否整齐、轻重是否均匀。在压痕挤压缘的判断上，重点关注骨折的挤压缘，此类挤压缘一般见于金属质地工具作用骨骼所致。



创内的残留物或附着物反映了致伤物材料。发现及提取衣物、创口内遗留物，如木质碎屑、树皮、铁锈、碎石屑等，进行微量物证检验，确定其成分以推断致伤物质地。有学者利用 X线放大成像技术分辨铁及其氧化物颗粒与其他类型外源性颗粒。

## 1． 现场勘查资料



钝器打击可以通过分析和研究血迹的尺寸、形状、分布等特征来佐证，钝器打击产生的血迹斑块可能具有不规则的形状，这是由于钝器与人体组织的相互作用所致；血迹斑块可能呈现出扩散、撕裂或挫伤的特征；钝器打击可能导致较大范围的血污迹，因为钝器较大的撞击面积可以造成更大的溅射；钝器打击导致的血滴可能具有不规则的轨迹，与钝器在打击过程中的运动轨迹有关，血滴的轨迹可能呈现出不同方向的分散和溅射。



## 2． 案情调查资料



调查人员通过与受伤人以及目击证人交流并进行记录，可以得知关于伤害发生时的情况，如何受伤以及使用的工具的特征描述。这些的描述有助于确定伤害的力度、形状和可能造成伤害的物体。虽然受伤人陈述可能并不完全准确，但能为钝器致伤物的认定可能提供线索。



## 3． 病历及影像学资料



病历资料可以提供受害人的伤情情况，通过病历记录的诊断结果、检查结果、治疗方案，可以了解到伤害的性质、程度和可能的致伤物。能够为成伤机制分析和致伤物推断过程提供可靠的、必要的信息支撑。这些记录可以与钝器伤的特征进行比对，以确定可能的钝器类型。



影像学资料在推断钝器伤时可以提供重要的线索和信息。X 线透视可以用于检查骨折、骨裂、骨折片的位置和形状等；CT 扫描提供更详细的骨骼和软组织影像，显示骨骼结构的横断面和三维重建，有助于检测骨折、骨裂、骨片的位置和形状，并进一步推断钝器伤的性质和范围；MRI 扫描可以显示肌肉、韧带、血管和神经等组织的影像，并检测软组织损伤、挫伤和内部出血等情况；乳腺钼靶摄影常用于妇女乳房损伤的检查，帮助识别钝器伤引起的可能的组织破裂或其他损伤的等。



## 4． 视频资料



通过视频监控、执法记录仪以及周围路人拍摄的视频，可以进一步确证受害人是否遭受暴力、暴力的性质、暴力的作用点、致伤物的种类、加害人与受害人的相对位置关系等案发事实，再现犯罪轨迹。仔细观察攻击行为中施暴者的动作、持物姿势和力度。观察他们的手臂运动、作用力的方向和幅度有助于获得推断钝器类型的线索。钝器致伤通常会产生明显的疼痛、骨折或其他损伤的迹象，观察被攻击者的疼痛表情、抓握受伤部位的反应等，可以提供关于钝器使用的一些指示。观察视频监控资料中的其他可能与钝器致伤物相关的物证，如攻击后留下的物品、破碎物品或其他与攻击行为相关的痕迹，这些附加线索可能有助于推断钝器致伤物的类型。



## 5． 尸检记录



尸表检验时应仔细检查伤口的形状、大小、深度和方向等特征，测量伤口的长度、宽度和深度等尺寸。观察伤口周围的组织是否有挫伤、擦伤或瘀血等特征。钝器伤可能会导致周围组织受挫或擦伤的痕迹。检查衣物、伤口和周围组织是否有可能的异物残留，如木屑、金属碎片等，这些异物可能是钝器伤的来源。进行系统解剖时，需要仔细检查受害者的各个部位，包括头颈部、胸部、腹部、四肢等，观察是否存在骨折、骨裂、挫伤、组织损伤等。钝器引起的骨折通常呈现出压迫性或挤压性的特征。解剖过程中，可以取样进行进一步的检验和分析。

## 1． 结合组织病理学检查



通过显微镜可以观察到钝器造成组织中的断裂、撕裂、破坏等特征。钝器伤可能导致明显的出血和血肿，组织病理学检查可以显示组织中的血液积聚和血管损伤情况。钝器伤还引起周围组织的炎症反应，通过观察炎症标志物和病理学改变，推断炎症反应的存在。严重的钝器伤可能导致受伤组织的细胞变性和坏死。病理学检查还可以提供其他与钝器伤相关的病变特征，例如骨折、软组织损伤等。需要强调的是，组织病理学检查仅能提供病理学相关的诊断，而不能直接推断伤害的具体来源或作用。



## 2． 结合 DNA 检验



在确定钝器损伤时，DNA 证据的作用可能相对有限，因为钝器通常不会直接与攻击者的DNA 接触。然而在某些情况下，如被攻击者受伤并出血，血迹样本可能包含被攻击者的 DNA。如果攻击者接触了被攻击者的皮肤，例如在攻击过程中进行防卫动作，可能会留下一些含有攻击者 DNA 的皮肤细胞，这些皮肤细胞通过采样、收集，并进行 DNA 分析和比对。如果攻击者使用了棍棒或其他物品，其人体组织可能残留在器具表面上。



## 3． 运用数字化、智能化技术



（1）结合微量物证检测 受害者身体、衣物以及现场进行仔细检查，寻找微量物证，如血迹、纤维、植物残留、沙尘等。通过光学显微镜检查、红外光谱分析、电子显微镜、X 线能谱（EDS）等技术检测，确定所收集到的微量物质的性质和组成，为判断致伤物提供证据。使用显微镜检查受害者伤口和物证样本，观察微观结构和特征。钝器造成的伤口可能显示出撞击或压缩的特征，如疲劳裂纹、撞击痕迹或挫伤等。需要注意的是，这些方法仅能作为推测致伤物为钝器的线索，无法确定具体的致伤物。



（2）结合虚拟解剖技术 通过虚拟解剖技术，可以利用计算机软件将受害者身体的解剖结构进行三维重建。包括骨骼结构、软组织和内部器官等。利用影像学技术获取尸体表面及内部信息，可构建人体器官组织断面及三维图像，提供证据。基于三维解剖重建，可以使用虚拟解剖技术模拟伤害的过程。通过在计算机模型中施加钝器造成的力量和运动路径，可以推测致伤物对受害者身体的影响和可能的损伤模式。利用虚拟解剖技术，可以量化和评估虚拟钝器对受害者身体所施加的力量和压力。通过与已知类型的钝器进行比较，可以推测致伤物的特征和可能的伤害程度。通过虚拟解剖技术，可以观察并分析模拟伤口的特征。通常情况下，钝器可造成较为广泛的挤压、撞击和破裂性损伤，与锐器或其他致伤物所致损伤有所区别。将虚拟解剖技术提供的信息与其他调查数据综合分析，如目击证词、物证分析结果和现场调查等，可以为判断钝器性致伤物提供有价值的依据。



（3）结合数字化扫描技术 使用数字化扫描技术，对伤口进行高精度的三维扫描。这种扫描将伤口的形状、大小和深度转化为数字化的模型，为后续分析提供基础。将伤口的数字化模型与已知类型的钝器进行形状比对。利用数字化扫描技术提供的高精度数据，可以仔细观察伤口的损伤特征。通过数字化扫描技术仅能提供关于致伤物的推测，并不能确定具体的物品。



（4）结合计算机建模分析 通过计算机建模软件，可以模拟钝器对人体组织造成的损伤过程。基于已知的物理性质和几何特征，收集关于钝器的几何形状、材料属性和应用方式等方面的数据，建立模型来表示钝器和人体组织的相互作用，确定其材料属性，例如密度、弹性模量、应力应变曲线等。通过施加力量和运动路径，模拟钝器对组织的挤压、撞击和破裂等效应。利用计算机建模进行动力学分析，模拟钝器与人体的碰撞过程。基于钝器的形状、质量和运动轨迹，以及人体的生物力学特征和阻力，推测钝器对人体产生的力量和压力分布。在计算机模型中设置约束条件，考虑人体的解剖结构、组织物性和力学响应。通过对组织构造、骨骼韧带连接和组织强度等因素的建模，推测钝器造成的伤害模式和可能的损伤程度。将计算机模型的结果与实际数据进行对比和验证，可以帮助确认模型的准确性和可靠性，并进一步对推测致伤物进行了验证。



（5）结合损伤生物力学分析 损伤生物力学是研究人体在外部载荷（如运动冲击、直接或间接冲击、碰撞等）作用下的变形和动态响应。损伤生物力学分析可以通过计算受害者身体所承受的力量和压力来评估伤害的威力。这些数据可以与常见的钝器或工具的性能参数进行比较，从而推测可能的致伤物品。使用损伤生物力学模型和数字计算模拟，可以模拟不同类型的钝器所造成的损伤。通过比对模拟结果和实际伤害特征，可以推测致伤物的类型、形状和可能的运动路径。比如应用有限元法研究颅脑在外力作用下的应力传导、应变以及颅脑各部位组织在外力作用下的变化过程。损伤生物力学分析可以根据损伤特征、伤害的形状和受害者的相关信息，并推测可能的致伤物品。这可能涉及力量和角度的估计，结合受害者和现场的特征进行综合推断。

## 1． 检验钝器特征性损伤



特征性损伤（characteristic injury）指能反映出致伤物接触面形态、质地、大小、致伤方式等特征的损伤，如“中空性皮下出血”。钝器作用的特征性损伤主要表现为擦伤、挫伤、挫裂创、闭合性骨折及闭合性内脏损伤等。



## 2． 发现钝器特征性要素



特征性要素（characteristic element）指在机械性损伤致伤物推断流程的现场勘验、辅助检验环节中，能反映致伤物特征性（如形状、质地、理化成分、生物物证等）的因素。如衣服上遗留的鞋底花纹印迹。



（1）现场勘验 现场勘验需检查尸体的位置、姿态、衣着，现场翻动情况、破坏状况、是否有伪装，现场物品变动及损失等原始情况。观察发现尸体的位置与周围环境的关系，有无移尸迹象，并结合调查分析移尸的形成方式。



勘验现场环境，应注意是否存在就地取材的可能。对于发现的作案钝器，首先要与尸体反映的凶器类型和数量进行对比，判断犯罪嫌疑人的人数及杀人手法。此外，需关注现场遗留的物证痕迹和搏斗痕迹。一般来说钝器杀人案的现场都会留下喷溅状的血迹。勘查现场时还应对现场中物体的变动，位移，翻动和毁坏痕迹进行勘验。通过分析现场的搏斗痕迹，还原案发过程。



（2）衣着检验 除了头部、面部、手部等暴露部位，当致伤物作用于人体时，首先会受到衣物的影响。因此，在判断致伤物时，检查被害人的衣着具有重要的意义。除了观察衣物的外观和衣着的特征，特别要注意检查衣物上的附着物。例如，是否有擦痕、褶皱、变形或轮胎印痕等；是否有血迹、毛发、油渍、呕吐物或排泄物等异物。



对于衣物上的破损，应该详细检查和记录其形状。需要特别注意检查衣物破损的部位、范围、程度、数量，以及每个破损的大小、方向和特征。特别是需要检查与尸体上的损伤相对应的破损，以确定其大小、织物纤维的改变、破损边缘和两个角的情况等，并与尸体周围可能存在的衣物破损残留物进行对比，以推测出破损形成的原因及致伤物的性质（图 10 7）。任何在衣物上发现的痕迹都应妥善保存，较大的颗粒或附着物应单独包装。如果尸体已经被触摸或移动过，需要仔细了解是否改变了原始的衣物破损情况以及其变化过程。通常情况下，衣物的损坏位置应与身体损伤的部位一致。

（3）尸表检验 损伤情况检查：观察尸体上各部位损伤情况，记录损伤的位置、大小，明确损伤的种类，观察尸体各部位外形有无异常，以推测有无骨折。对擦伤用放大镜仔细观察表皮翘起的方向及形态，以分析外力的作用方向。对挫伤应注明其表面有无擦痕，如有则注明其方向、大小及颜色。对创应描述创口形状、创缘、创角、创壁、创腔及创底的情况；观察创壁间有无组织间桥，创腔内有无异物，创缘周围有无其余附着物的痕迹；用手指将两创缘合拢或用透明胶纸贴住后可观察创角及创缘的形状。



血迹形态检查：注意体表出血的来源及血迹的分布，描述血迹的形态及流注的方向，以估计出血时人体的位置及姿势以及出血后保持在该位置的时间。从血迹形态考虑是动脉或静脉出血。从体表及衣服上的血迹估计出血量。



创口内遗留物及伤痕周围附着物检查：创口内遗留物的发现，如创口内遗留木质碎屑、树皮、铁锈、碎石屑等，妥善提取后进行微量物证检验，确定其成分以推断致伤物种类、质地。伤痕周围附着物，是伤痕周围的尸体自身以外的微量物质，如毛发、纤维、泥沙等附着物。并作出相应记录、提取，妥善保存。



（4）解剖检验 系统全面的解剖检验，是对致伤物形成推断、成伤机制进行分析等的重要部分。常规尸体解剖应当剖开颅腔、胸腔和腹腔，特殊情况剖开脊髓腔或关节腔。



对头皮及颅骨解剖检验时，应注意检查头皮创伤的深度，头皮及帽状腱膜下出血的分布范围。剥下头皮观察颅骨骨折的条数、走向及交叉情况，有无凹陷或缺损，记录清楚骨折位置、类型、分布以及断端情况。并将头皮损伤与颅骨骨折进行比对，找出造成颅骨骨折的暴力在头皮上形成的损伤，分析两者的关系。锯开颅骨后还应检查颅顶骨内板骨折情况，与颅骨外板进行比较。



对于颈部受伤者，应首先解剖胸腹腔和颅腔，然后取出胸腹腔器官和大脑，最后进行颈部的解剖检查。要特别注意检查颈项部皮肤、皮下组织、肌肉是否有损伤和出血。检查喉头是否存在水肿、黏膜下出血或异物阻塞，以及舌骨、甲状软骨和环状软骨是否存在骨折或出血。还要检查颈椎是否存在脱位或骨折，以及颈部大血管是否受损。必要时，可以锯开脊椎骨取出颈部脊髓。



皮肤损伤的检查中，需要测量创口的深度，探查创口内是否有异物以及创口的方向，以确定内部器官的损伤位置、形态和程度，还需要注意出血情况。



## 3． 分析可能影响因素



影响工具推断的因素很多很杂，主要包括人体、致伤物、作用方式三个方面；其中，以人体和致伤物最为重要。



（1）人体 涉及人体的因素主要包括人体致伤的部位、致伤的组织以及致伤的状态。一般来说，平坦的部位、皮下组织丰富或者有硬物衬垫（如骨骼）的部位是反映致伤物接触面比较理想的部位。人体受伤组织反映致伤物的情况取决于推断的指标。一般来说，皮肤组织更能反映致伤工具的大致形态，而骨骼更能反映工具的质地。



人体受伤时的状态指的是人体在受致伤物作用时的活动性。当活动性较高时，工具容易产生偏击或侧击，因此造成的损伤变化较大。而当人体处于静止状态，比如侧卧且有衬垫时，工具更容易在相对稳定的状态下形成损伤，因此损伤形态的稳定性也较高。



（2）致伤物 涉及致伤物的因素主要包括致伤物的质地和接触面。前文已经提到，不同工具可以导致不同类型的人体损伤。工具的接触面形态是影响损伤形态的一个关键因素，当工具的特定形态因某些原因发生变化时，所形成的损伤形态会发生变化，容易导致错误的致伤物推断。例如，方形斧背因为长时间使用和磨损，其矩形边缘和棱角可能已经不显著，可能导致形成的损伤更类似于圆形，从而容易误判为圆形锤类工具的损伤。此外，接触面的光滑程度也会明显影响损伤的形态，即使是金属质地的工具，如果接触面非常光滑，创伤边缘的挫伤带也可能不太明显。



（3）作用方式 涉及作用方式的因素主要包括打击的方向、角度和挥动性等。当人体处于活动和变动的状态时，需要挥动工具。这种情况下，很难确保工具的接触面完全覆盖在人体上。因此，不同的打击方向、打击角度，甚至不同的挥动方式，都会影响致伤工具与人体接触的方式，从而导致复杂多样的损伤形态。

锐器损伤的成伤机制分析与钝器损伤的类似，主要从损伤形态特征、作用力大小、方向以及损伤次数等方面进行分析。



## 1． 损伤形态特征分析



锐器损伤的形态主要是创，其形态一般较为规则，主要具有创角锐、创缘齐、创壁平、创腔深、两创缘及创壁间无组织间桥，创口出血较明显等特点。



## 2． 作用力大小分析



锐器具有锋利刃缘和尖端的特点决定了较小的作用力即可造成较严重的损伤。胸腹部皮肤仅需 0．5～3 kg 的外力即可用刀刺穿，向锐器施加 2 ～ 3 kg 压力即可刺穿衣物。但实际情况中，考虑到锐器的锋利程度、捅刺速度、损伤部位组织的类型、衣着种类等因素，往往难以确定能使锐器造成损伤的外力大小。若致伤锐器的刃缘或尖端足够锋利，单个手指施加的压力就足以使锐器刺入人体。



另一方面，皮肤对于外部压力的反应是非线性的。压力较低时，皮肤形变可以恢复，恢复的时间与受压时间有关；当压力持续增大时，皮肤变硬，延展性变差；当压力足够大时皮肤失去抵抗能力从而破裂。人体皮肤是除了骨骼和钙化软骨之外对锐器抵抗能力最强的组织，锐器刺穿皮肤后进一步刺入机体所需的外力会变小。身体的不同部位对锐器穿透的抵抗能力存在差异，如肋间隙组织张力更强，比上腹部更容易被刺穿。考虑到组织器官的收缩和挤压，将致伤锐器从体内拔出时所需的力一般比刺入身体时的力更大。



## 3． 作用力方向分析



无刃刺器形成刺创依靠于其尖端的捅刺作用。对于有刃刺器，既有沿着其长轴刺入组织的作用，又有垂直于刃部的切割作用，其刺入组织的方向即为上述两力的合力方向。切器对人体的作用力包括刃部垂直向下的压力和平行于刃部的推拉力，两个力的合力指示为锐器切割组织的方向。砍器的作用力方向与刃部垂直，但若在砍击时与体表成一定倾斜角度，刃缘两侧可对皮肤施加倾斜方向的摩擦力，在砍创的创口两侧形成擦伤。剪器两刃在夹剪汇合的过程中对组织施加剪切力，组织受到大小相等、方向相反且方向不在同一平面上的两个力作用，导致组织截面发生相对滑动错位，同时还伴有剪刀刃缘的切割作用。



## 4． 损伤次数分析



一般情况下，当受害人对于第一次攻击缺少戒备时，此时使用锐器造成的损伤特征最为典型。之后，由于抵抗和搏斗，锐器在进入和拔出人体时可发生扭转、变形甚至破损，导致损伤形态常出现变化。当受害人失去抵抗能力时，锐器形成的损伤又逐渐表现出其典型特征。



在自杀和他杀案件中，单一的致命性刺创多位于死者胸部，多发性锐器伤见于自杀者的四肢，而多发离断性损伤则提示他杀。多次切割形成的切创可见较小的创瓣，创角常有多个浅表的鱼尾状小创角。对于自杀切创，常可在主要创口附近见到与其平行而不连续的较浅的切割伤，称为试切创。刺创周围也可能伴有线性尾部擦伤或较深的切创。

锐器的致伤物推断相对于钝器而言比较简单，主要是根据不同种类锐器损伤的独特形态学特征来进行。由于切创、砍创都是刃边作用所致，在推断时无特征性指标，有时候可以根据创口的深度、骨骼受损情况对致伤物的质量、大小、质地、形态等特征进行推断。



## 1． 根据损伤形态推断致伤物



（1）推断刺创的致伤物 刺创创口的形状往往反映出刺器横断面的形态特征。确定创口为刺器形成后，应尝试推断刺器的宽度与长度。根据创口长度可大致推测刺器的宽度（或无刃刺器的直径），但考虑到有刃刺器的刺切作用导致创口延长，应选择数个创口中较小的。刺创管能代表刺器刺入部分的长度，而不能反映刺器的全长，可借助其推断刺器的最小长度。对于贯通性刺创，如果刺器未拔出而反复戳刺并贯通时，可形成一个刺入口和多个刺出口。当刺器以较大的作用力刺入人体时，除了刺入口可见锐器创的特点之外，刺入口周围还可能见到护手或刀柄造成的压痕、擦伤或挫伤，可作为推断和认定致伤物的依据。



不同的组织结构可使刺创在形态上有显著差异。腹壁的皮肤较薄，脂肪层较厚，因此腹部刺创，可以较逼真地反映致伤物的横断面。若刺创的部位在皮肤厚、脂肪薄的头顶部，则刺创的形态可呈人字形。在实质器官形成的刺创，可以反映刺器前端的特征。如在肝脏形成的刺创，由于肝组织致密的特性，能够真实地反映致伤物前端的特征，解剖时应该暴露刺创的最大切面，这样可以观察致伤物刃的宽度及特征。



（2）推断切创的致伤物 切创依据其形态特征一般不难判定。但实践中往往只能推断出创口为切创，而无法确定是具体哪一种切器，因为切器在切割组织时可伴随下压、拖拉的过程，即使刃部较短的切器也可形成深而长的切创。正常情况下，皮肤、软组织具有一定的张力，能使创口哆开、变形，特别是颈部、肘窝、腹股沟等处，可形成纺锤形或梭形的断面，故测量创口长度时除测量原始状况外，还应测量合拢后的创口长度。



（3）推断砍创的致伤物 砍创的致伤物一般是有柄而便于握持、挥动的刀斧类工具。砍创的形态特征与切创类似，但由于作用力较大，损伤往往更为严重，创口哆开明显并常伴有骨折。创口较长的砍创一般为刀类形成；创口较短的一般为斧类所形成，此类砍创的创口边缘常伴有明显的擦伤或挫伤带，创角可较钝。砍器刃部全部进入人体组织时，砍创长度近似于砍器刃长；若砍击时伴有切割动作，创口长度可长于砍器刃长；砍击人体圆隆而突出的部位（如头、肩）时，创长可小于砍器刃部长度。在平坦的体表部位出现的长度一致的、两创角钝圆的砍创，系砍器刃缘全部砍入体内形成，若两创角一钝一锐说明仅部分刃缘砍入。由于作用力较大，砍器可在骨质上留下砍痕或导致骨折，骨骼砍创能较好地反映砍器刃部的宽度、厚度等形态特征。



（4）推断剪创的致伤物 剪创具有独特形态特征，与其他致伤物造成的损伤有明显不同，故从形态学上推断致伤物较为容易。典型的“V”形和“八”字形创口、大小不等的多个创角可推断系剪刀所为。若创口具有典型刺创特征，但呈双排列、瓜子形或梭形，一侧钝圆而另一侧创角尖锐，可考虑为剪刀造成的剪刺创。



（5）推断锯创的致伤物 锯创是一种极特殊的锐器创，多见于分尸案件中死者肢体断面（图10 18），罕见于一般命案中，呈现死后损伤的特征，但也有因意外事故导致的。典型的锯创，创缘呈锯齿状，可形成有尖的皮瓣；骨的锯创断面呈阶梯状，系锯齿状致伤物在人体组织上滑动形成。

除了头面部、双手等暴露部位外，锐器作用于人体时要先和衣物发生接触。一般情况下，衣着上与锐器创相对应的部位应当出现一致的损伤（图 10 20），但要注意在抵抗或搏斗过程中衣着发生位置移动的情况。对衣物进行检查时，应仔细观察破损处织物纤维断端是否整齐，有无撕裂和毛刺。锐器的刃缘一般可对衣物造成尖锐整齐的裂口，其钝端形成的则是参差不齐或呈绒毛状的裂口，据此可推断嫌疑致伤物是单刃还是双刃。若系双刃刺器造成衣服的破口，两角尖细，纤维断端整齐，毛边较少，将破口闭合，呈现出棉条状裂缝。若系单刃刺器在衣着上形成的破口，创角相应部位亦有一端钝和一端锐的特点但是应当注意致伤锐器刃缘可能存在缺损断裂卷刃的情况。

此外，在锐器刺入身体的过程中衣物碎片也会被带入创腔。需要指出的是，不同种类的衣物纤维在物理特性上存在差异，这可能导致衣着破损情况不符合嫌疑致伤物的特征，为致伤物推断带来干扰。



## 4． 根据现场情况推断致伤物



锐器往往可损伤人体深部较大的血管，故案发现场常可见大量血迹或血痕。当致伤锐器伤及人体较大的动脉时，可能造成大片的喷溅状血迹，或是形成大面积的血泊。对于自杀者，致伤锐器一般会遗留在现场，甚至握在死者手中。在进行现场勘查时需仔细寻找致伤物，对现场找到的可疑锐器要尽快包装送检，但要注意犯罪嫌疑人就地藏匿或带走作案工具的情况。一般情况下，犯罪嫌疑人在有预谋的作案过程中会倾向于使用自己事先准备好的作案工具，而在激情犯罪案件中会就地取材。因此，现场勘查时需对案发地的基本情况进行了解，如其属于居住区、办公场所、工厂企业还是其他属性的场所，并研究在案发现场哪类锐器可以存在，是否存在与现场环境不相符的可疑锐器。



## 5． 推断致伤物的质地



一般而言，绝大多数致伤锐器均为金属材质，少数可以是玻璃，或其他锐利的非金属类物品。仅从锐器伤的形态学特征上难以鉴别致伤锐器的质地。若创内遗留有来自致伤锐器的异物，可对其使用实验室仪器进行检验和分析以帮助确定致伤物的质地。

## 3． 运用数字化、智能化技术



（1）结合微量物证检测 对受害者身体、衣物以及现场进行仔细检查，寻找与锐器相关的微量物证。包括血迹、切割的纤维、外表层的涂层、皮肤上的剪刀痕迹或划痕等。使用化学试剂或技术来检测可能与锐器有关的化学物质。例如，血迹检测试剂可以用来检测微量的血迹，以确定是否存在锐器切割血迹。使用显微镜观察受害者伤口和物证样本，以观察切割的特征。



（2）结合虚拟解剖技术 利用计算机软件对受害者身体进行三维重建，包括骨骼、软组织和内部器官。从而模拟锐器对受害者身体造成的伤害过程。在计算机模型中应用锐器的切割和刺穿力量，可以观察和分析虚拟伤口的形状、深度和方向模拟切割和刺穿动作，分析受害者身体组织的反应和损伤程度，进而推测致伤物的形状、大小和可能的运动路径。经 CT 断层扫描后再进行系统尸体解剖并通过 CT 断层影像阅片观察结果，与相应尸体解剖结果进行对比。虚拟解剖技术仅能提供关于致伤物的推测，并不能确定具体的致伤物。推测致伤物为锐器需要综合考虑多个因素，并可能涉及伤害模拟、力量估计和其他调查数据的限制。



（3）结合数字化扫描技术 使用数字化扫描技术对受害者的伤口进行高精度的三维扫描。这种扫描可以捕捉伤口的形状、边缘特征和几何信息。将伤口的数字化模型与已知类型的锐器进行形状比对。通过比较伤口与锐器模型的形状、边缘特征和刃口轮廓，可以推测致伤物的形状和可能的锐利特征。结合数字化伤口模型和损伤生物力学模型，进行力学模拟实验。模拟使用不同形状和锐利度的锐器对组织进行切割，观察模拟伤口的形态和损伤特征，从而推测致伤物的类型。



（4）结合计算机建模分析 根据已知锐器的类型和材料特性，建立锐器的计算机模型。考虑到锐器的形状、刃口特征和材质硬度等因素，将其几何属性和材料性质纳入模型。利用计算机建模进行动力学仿真，模拟锐器与人体组织的相互作用过程。基于锐器的形状、质量和运动轨迹，以及人体的生物力学特性和阻力，推测锐器对组织的切割和刺穿力量分布。通过计算机建模软件，模拟锐器对人体组织造成的损伤过程。基于已知的物理性质和几何特征，建立模型来表示锐器和人体组织的相互作用，通过施加切割和刺穿力量，模拟锐器对组织的割裂和损伤效应。



（5）结合损伤生物力学分析 法医损伤生物力学是研究机械性外力与人体组织损伤之间的关系，并为法庭科学提供相应证据的学科。通过仔细观察受害者的伤口特征，可以推测可能的致伤物类型。锐器造成的伤害通常表现为清晰的切割线、割裂组织和其他与锐器相关的特征。通过分析伤害的模式和特点，可以推测致伤物为锐器。锐器造成的伤害常表现为直线、精确的切割或刺穿，与钝器或其他致伤物有所不同。使用损伤生物力学模型和数字计算模拟，可以模拟不同类型的锐器所造成的伤害。通过比对模拟结果和实际伤害特征，可以推测致伤物的形状、大小和可能的运动路径。将受害者的伤害与已知类型的锐器进行比较，评估其相似性和一致性。这可以包括比较切割线、刃口形状、深度和伤害范围等参数。

## 1． 变异型损伤分析



损伤的形态受多种因素的影响，同一个刺器，可以造成形态多样的创口，不同形态的刺器，又可出现相似的创伤，故有些刺创难以判断其刺器的种类和形态。



（1）刺器本身的影响 现实中的刺器是多种多样的，有些刺器前端呈双刃，后部却呈单刃，由此在人体形成刺创的时候，刺入较浅的位置两侧创角均锐，而刺入较深的位置两侧创角又呈一钝一锐，一些单刃刺器的钝缘甚至刃缘都被加工成齿状或者钩状（图 10 21），容易形成不规则的创口或者在创周形成附加损伤等。

图 10 21 有齿单刃刺器形成的创口



有齿单刃刺器刺入，刺入口呈菱形，创缘呈现锯齿状，无表皮剥脱及皮下出血，创角一钝一锐，锐角为刺器刃部形成，钝角为背部形成。



（2）刺创刺入部位的影响 由于人体体表组织的差异和不同特点，有时会引起刺创形态上的改变。在四肢屈曲的和皮肤皱褶或突出处，可出现一次刺击形成多个创口的现象；在同一部位由于多次刺入也会造成变异的创口。



（3）刺击方式的影响 刺者和被刺者都是相对活动的个体，刺击的过程是动态的，刺击方向、体位、角度等常常都会发生变化。



在完成刺入和抽出一次刺击行为时，刺者和被刺者在瞬间的体位变化有时直接影响刺创创口的大小及形态。体位的改变能直接改变刺器对创口内抽出时的原有状态，常表现一侧创口由内向外逐渐变浅的类似拖刀痕迹。



（4）刺入的角度、深度以及转动变化对于单刃刺器而言，可形成两创角皆钝或锐，一创角或两创角呈分支、弧形、椭圆形，甚至不规则形的刺创（图 10 22），而在法医的实际工作中，单刃刺器形成的变异创口最为常见，可形成两创角均锐、刃侧创角变钝、刃侧创角分叉、刃侧创口延长以及混合型，即既有刺创又有切创的形态所见。

损伤生物力学作为一门新兴的循证交叉学科，旨在将生物力学原理和方法应用于法医损伤学研究和实践，解释损伤成伤机制并探究普遍的损伤生物力学规律。该领域已成为法医学研究的重要分支，为各类案（事）件调查提供客观和量化的分析手段，展现出显著的发展潜力。研究人员在多刚体动力学重建、有限元损伤分析、人体材料测试、致伤条件测试、损伤标准制定以及法医学成伤机制分析方面进行了大量研究，在实践应用和法庭举证方面取得实质性进展，已得到多国司法体系的认可。



随着数字仿真技术的进步，基于数字假人的仿真分析成为研究的关键手段。数字假人需要考虑计算效率、鲁棒性和精度间的平衡，满足要求的模型以多刚体和有限元模型为主。多刚体模型的建模相对简单，以 MADYMO（mathematical dynamic models，数学动力学模型）为代表的多刚体系统以其高效和准确性而得到广泛应用，这在交通事故分析中尤为重要，通过对交通事故车辆、人员等要素进行多刚体建模，求解仿真系统内模型的运动学响应，以分析事故前、后车辆和人员运动轨迹及速度、预测涉事人员损伤致伤方式。我国法医损伤生物力学研究虽起步较晚，自2007 年司法鉴定科学研究院（司鉴院）陈忆九团队采用数字仿真技术以来，已在交通事故重建和交通行为方式鉴定方面取得显著成效，提高了案件分析的客观性，同时更深入地探索了不同事故涉事人员的一般成伤机制规律。然而，多刚体模型在模拟真实人体结构方面存在难以精确重建骨骼、关节、软组织等损伤成伤机制的局限性。近年来，有限元模型在几何建模、材料属性以及边界条件更为接近真实人体，并在近年来得到了显著的改进和完善，有利于法医损伤过程重建及成伤机制的准确分析。



人体组织材料属性是有限元法损伤重建及成伤机制研究的关键。由于人体组织具有非线性、各向异性和黏弹性特性，必须通过材料测试获取真实的应力－应变关系。为弥补人体软组织材料属性数据不足，司鉴院开发了标准化人体软组织拉伸、压缩测试方法，并系统测试了人主动脉材料属性，为有限元建模和案例分析提供了基础数据。此外，准确的致伤条件也是分析的关键，研究人员利用 VICON 三维动作捕捉系统采集成人徒手击打数据，并加载于颅脑有限元模型，系统分析拳击损伤的成伤机制及其影响因素。



随着建模技术的进步，人体有限元模型在完整性和精准度方面得到显著提升。其中，THUMS 模型和 GHBMC 模型是目前最完善的整人有限元模型，广泛应用于汽车安全、乘员防护、行人保护和事故重建等领域，为法医损伤生物力学研究提供了坚实基础。这些整人有限元模型在解析头部击打、枪弹损伤、儿童虐待和交通事故重建等问题中起到了重要作用。利用这些模型和自建模型对颅脑减速损伤、颅底环形骨折、膝关节撞击／摔跌伤、骨盆撞击／碾压伤、踝关节损伤等成伤机制进行系统研究，为法医学提供了创新的分析手段。



生物力学技术的进步为法医损伤鉴定与研究开辟了新路径，数字化生物力学证据以图像和动态效果呈现，有利于非专业人员的理解，显著提升了鉴定品质。尽管法医损伤生物力学在损伤机制评估方面具有很大优势，但由于人体解剖结构的独特性、生物材料的复杂性以及致伤环境的不确定性，这些技术仍然存在一定限制，不能替代传统法医学手段。通过将数字仿真技术与传统方法相结合，形成综合性损伤分析新模式，涵盖专家系统、数据信息系统和计算机系统，将进一步确保法医学鉴定及科学证据的严谨性、客观性和准确性。

## 1． 基本原则



（1）合法性 法医损伤生物力学分析从程序到实体、从技术到标准均应遵循国家相关法律法规规定，确保程序合法、技术合规。样本采集、实验操作等须通过科技伦理审查，必要时相关人员应依法回避。



（2）科学性 损伤生物力学重建和分析应基于案件实际，凝炼案件关键问题，科学制定分析方案和步骤。分析应基于生物力学科学原理，合理阐明人体损伤生物力学机制，避免超越科学技术规律和证据力限度，规避跳跃式推理。



（3）全面性 法医损伤生物力学分析应全面、系统，对于关键问题设计分析工况，结果尽量以量化数据呈现，并通过大样本工况数据对比分析，避免以点带面、以偏概全。应根据损伤部位选择合适的模型及重建方法，选取有效的损伤指标和阈值，避免不规范、不全面分析而影响结果。



（4）综合性 法医损伤生物力学分析结果应与损伤检验结果、案情情况（如损伤死亡过程、病历材料）、勘验资料、致伤物检验和实验室检测结果综合比对验证。分析结果作为辅助证据，避免单独依据生物力学分析作出诊断或鉴定意见。

道路交通中的行人和非机动车驾驶者常处于弱势地位，是交通事故的主要伤亡群体。在交通拥堵日益严重的大背景下，二次事故损伤，即原肇事车辆或其他车辆未能及时发现或避让而对伤者或死者造成的二次损伤，已成为交通事故中亟待解决的重要问题。此类案件损伤过程复杂、损伤叠加多发，其成伤机制往往难以厘清，对交通事故处理构成巨大挑战。



在此背景下，运用损伤生物力学技术分析二次事故的成伤机制显得尤为必要。该技术可重建损伤的生物力学过程，辅助鉴定人更准确地区分多次损伤的成因，并量化各次事故的死亡风险。本案例在交通事故重建方法、优化手段及死亡风险量化模型的研究基础上，对实际二次事故损伤案例进行分析，对比实际损伤和事故过程，应用死亡风险模型定量评估受害者死亡风险，以期为二次事故损伤鉴定提供新的思路和理论支撑，进而提升交通事故鉴定的准确性和效率。

成人头部剧烈摇晃造成的损伤极为罕见，但由于无明显外伤、致伤方式隐蔽，极易成为虐待或折磨的手段，在监管场所更容易出现。应用损伤生物力学技术重建成人摇晃综合征（Shaking Adult Syndrome，SAS）损伤过程及分析成伤机制对于理解其致伤方式至关重要。通过模拟和分析头部遭受的动力学过程，可以揭示颅内组织在没有明显外伤情况下如何产生弥漫性轴索损伤、脑挫伤等损伤。SAS 的后果可能致命，但由于缺乏明显外伤标志，其识别尤为困难，因此，对于监控录像显示死者头部遭受多次快速摇晃的情况，进行详细的生物力学分析至关重要。通过这种分析，我们可以量化头部摇晃时的加速度、速度以及脑组织的应力和应变，从而评估 SAS 的成伤风险。



本案是一起疑似 SAS 的案例，尽管未发现明显的体表损伤，但死者左颞叶脑实质挫伤、硬脑膜下少量出血以及弥漫性轴索损伤（图10 34）表明头部可能遭受了高强度的力学载荷，提示头部摇晃造成的外力作用。通过损伤生物力学仿真，能够重建快速摇晃下颅脑的生物力学响应过程，明确 SAS 的成伤机制，并为法医鉴定提供定量分析方法和科学依据，准确判断颅内损伤的成因，这对于监管场所案件的调查尤为重要。

利用损伤生物力学技术进行深入研究，不仅可以定性地展示成人摇晃综合征的成伤过程，还可以通过定量分析，精确地模拟和重建颅脑损伤的成伤机制，描述其生物力学特征，为成人摇晃综合征这种致伤方式的鉴别提供了客观的科学依据。此外，该技术还有助于发现监管场所中潜在的虐待和酷刑行为，如快速摇晃头部等，从而采取有效的预防措施，降低此类事件的发生率。



在处理疑难复杂的人体钝力性损伤案件时，法医损伤生物力学技术的应用不可或缺，它有助于法医专家科学、客观、合理地鉴别损伤成伤机制和致伤方式，区分意外伤害还是故意伤害，甚至在某些情况下，能够帮助确定损伤的时间顺序。此外，该技术在法庭上可增强案件论证的可信度，为法律判决提供强有力的支持。法医损伤生物力学还有助于法医学鉴定的科学化和精准化，对提升法律正义和保护人权也具有重要意义。
