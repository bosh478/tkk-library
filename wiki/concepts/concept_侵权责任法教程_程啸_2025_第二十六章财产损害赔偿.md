# 《侵权责任法教程》第二十六章 财产损害赔偿

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第二十六章 导论 + 第二十六章 财产损害赔偿 |
| 行号范围 | 7011-7530（书籍）|
| 核心议题 | 财产损害的赔偿范围与计算方法 |
| 涵盖 | 损害赔偿原则+直接损失+间接损失 |

## 🎯 核心论点

**财产损害赔偿 = 全部赔偿原则 + 损益相抵**

**《民法典》第1184条**：
> 侵害他人财产的，财产损失按照损失发生时的市场价格或者其他合理方式计算。

---

## 第一节 损害赔偿原则

## 一、全部赔偿原则

**全部赔偿** = 加害人应当赔偿因其侵权行为造成的**全部损失**。

**范围**：
- 直接损失
- 间接损失（可得利益损失）

## 二、损益相抵

**《民法典》第1182条**：
> 侵害他人人身权益造成财产损失的，按照被侵权人因此受到的损失或者侵权人因此获得的利益赔偿；被侵权人因此获得的利益应当在赔偿数额中扣除。

**规则**：
- 加害人获得利益的，从赔偿中扣除
- 受害人因同一损害获得利益的，相应减少赔偿

## 三、过失相抵

**《民法典》第1173条**：
> 被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。

## 四、衡平原则

- 损害赔偿不应使受害人获得超过损害的利益
- 损害赔偿不应使加害人不合理地承担

---

## 第二节 直接损失

## 一、概念

**直接损失** = 因侵权行为**直接引起**的财产减少。

## 二、典型情形

| 情形 | 赔偿 |
|------|------|
| 财物被损坏 | 维修费用或重置费用 |
| 财物被侵占 | 返还或折价赔偿 |
| 财物被毁损灭失 | 按损失发生时市场价格 |
| 身体受到伤害支出的费用 | 医疗费、护理费、交通费、误工费等 |

## 三、计算方法

**维修费用**：
- 维修到原有功能状态
- 维修费用不应超过重置费用

**重置费用**：
- 按损失发生时**市场价格**
- 折旧因素应考虑

**折价赔偿**：
- 物品已无维修价值
- 按折旧后价值赔偿

---

## 第三节 间接损失（可得利益损失）

## 一、概念

**间接损失** = 侵权行为**未直接引起**但因损害的发生**可得利益的丧失**。

**《民法典》第1182条**：
> ...侵权人因此获得的利益赔偿...

## 二、典型情形

| 情形 | 间接损失 |
|------|----------|
| 营业中断 | 正常经营可得利润 |
| 车辆损坏 | 替代交通费用或停运损失 |
| 货物毁损 | 预期转售利润 |
| 房屋损毁 | 租金损失 |
| 人身伤害 | 误工费、护理费、伤残后收入减少 |

## 三、计算方法

**限制**：
- 可得利益损失须**确定性**（不是或然性）
- 须有合理基础（证明材料）
- 须以**损失发生时的实际情况**为依据
- 不得超过合理范围

---

## 第四节 损害赔偿的具体计算

## 一、财产毁损

**《民法典》第1184条**：
> 侵害他人财产的，财产损失按照**损失发生时的市场价格**或者其他合理方式计算。

**计算方法**：
- 损失发生时市场价格
- 不能确定市场价格的，鉴定
- 按**其他合理方式**（如成本法、收益法）

## 二、财产侵占

- 返还原物
- 不能返还的，折价赔偿
- 侵占期间的使用费

## 三、营业损失

- 受害人实际营业损失
- 需证明：营业利润、因果关系
- 不得超过合理预期

## 四、特殊情形

| 情形 | 赔偿 |
|------|------|
| 抢走的现金 | 按数额 |
| 抢走的贵金属 | 按损失时市场价格 |
| 抢走的古玩字画 | 鉴定价值 |
| 抢走的有价证券 | 票面金额或损失时市场价格 |

---

## 第五节 损害赔偿的特别规定

## 一、车辆交通事故中的财产损害

**《民法典》第1213条**：
> 以买卖等方式转让拼装或者已达到报废标准的机动车，发生交通事故造成损害的，由转让人和受让人承担连带责任。

## 二、产品责任中的财产损害

**《民法典》第1207条**：
> 明知产品存在缺陷仍然生产、销售，或者没有依据前条规定采取有效补救措施，造成他人死亡或者健康严重损害的，被侵权人有权请求相应的惩罚性赔偿。

**财产损害**：可适用惩罚性赔偿。

## 三、环境污染中的财产损害

**《民法典》第1234条**：
> 违反国家规定造成生态环境损害，生态环境能够修复的，国家规定的机关或者法律规定的组织有权请求侵权人在合理期限内承担修复责任。

**生态环境损害**：可请求修复费用或生态环境损害赔偿。

---

## 第六节 损害赔偿的抵销与扣减

## 一、损益相抵的情形

| 情形 | 抵销 |
|------|------|
| 受害人因受伤获得保险金 | 仍可请求侵权人赔偿（保险除外）|
| 加害人因侵权获利 | 在赔偿中扣除 |
| 受害人获得其他赔偿 | 视情况抵销 |

## 二、过失相抵的情形

- 受害人对损害发生有过错
- 受害人对损害扩大有过错
- 减轻加害人责任

## 三、减免的特殊规则

| 情形 | 规则 |
|------|------|
| 受害人故意 | 加害人免责 |
| 受害人重大过失（无过错责任）| 减轻加害人 |
| 第三人过错 | 不影响加害人责任（一般情形）|

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **直接损失** | 侵权行为直接引起的财产减少 |
| **间接损失** | 可得利益的丧失 |
| **可得利益损失** | 若无侵权行为本可获得的利益 |
| **全部赔偿原则** | 加害人赔偿全部损失 |
| **损益相抵** | 受害人获益应从赔偿中扣除 |
| **过失相抵** | 受害人过错可减轻加害人责任 |
| **重置费用** | 按损失时市场价格重置 |
| **折价赔偿** | 折旧后价值赔偿 |
| **恢复原状** | 维修到原有功能状态 |
| **市场价格** | 损失发生时的市场交易价格 |
