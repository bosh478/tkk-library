# 《纪检监察办案程序一本通》第一章 问题线索管理

## 🎯 核心论点

**问题线索管理 = 纪检监察执纪执法的入口环节**

**核心制度**：
- **集中管理** + **归口受理** + **分级负责** + **及时办理**
- 4 大类来源（信访举报/工作发现/移交转送/主动投案）
- 实名检举控告特别处理
- 诬告陷害与澄清正名

---

## 第一节 问题线索的概念

## 一、定义

**问题线索** = 反映公职人员涉嫌违纪违法问题的**初步材料**。

**基本特征**：
- 是反映**问题**的**初步**材料
- 内容可能是违纪、违法或职务犯罪
- 来源多元
- 需要甄别和处理

## 二、办理要求

| 要求 | 内涵 |
|------|------|
| **集中管理** | 问题线索由专门部门统一管理，避免分散 |
| **归口受理** | 不同来源的线索由专门部门归口受理 |
| **分级负责** | 按干部管理权限分级处理 |
| **及时办理** | 在规定时间内完成甄别处理 |

## 第二节 问题线索的受理与移送

## 一、问题线索来源

### （一）来源方式

| 序号 | 来源 | 说明 |
|------|------|------|
| 1 | **信访举报** | 群众来信、来访、网络举报 |
| 2 | **工作中发现** | 监督检查、审查调查中主动发现 |
| 3 | **移交转送** | 公安、检察、审判机关、行政执法机关移送 |
| 4 | **主动投案** | 涉嫌违纪违法的公职人员主动交代 |

### （二）问题线索材料的形式

- 信访举报材料（信函、邮件、走访笔录）
- 移送材料（正式函件+证据材料）
- 工作中发现的内部材料
- 主动投案材料（自书材料、谈话笔录）

## 二、问题线索移送

### （一）移送途径

- 横向移送（同级机关之间）
- 纵向移送（上下级机关之间）
- 跨地区跨部门移送
- 上下联动移送

### （二）移送要求

- **及时**：发现后及时移送
- **规范**：通过正式渠道
- **有据可查**：留有移送记录
- **保持完整**：附相关证据材料

## 三、几类特殊人群问题线索的管辖主体

| 特殊人群 | 管辖主体 |
|---------|----------|
| **"双管"公职人员** | 一方为主，另一方协管 |
| **国企退休人员** | 退休前所在单位对应的纪检监察机关 |
| **退役军官、军士** | 移交地方后由地方纪检监察机关管辖 |

## 四、分办程序

**基本程序**：
1. 线索登记
2. 分类（按性质、管辖等）
3. 领导审批
4. 分流到具体承办部门

**法规依据**：
- 《中国共产党纪律检查机关监督执纪工作规则》第7条
- 《监察机关监督执法工作规定》

## 第三节 线索处理

## 一、四类主要问题线索来源方式的处理流程

### （一）处理信访举报的流程

1. 登记
2. 阅看
3. 领导批示
4. 分办

### （二）处理工作中发现线索的流程

1. 报告
2. 登记
3. 评估
4. 分办

### （三）处理移交转送线索的流程

1. 接收
2. 审查（管辖权和完整性）
3. 登记
4. 分办

### （四）处理主动投案线索的流程

1. 接待
2. 登记
3. 评估（包括真实性、主动性）
4. 分办

## 二、实名检举控告的处理流程

**实名检举控告** = 署真实姓名+联系方式+明确诉求的检举控告

**特殊处理**：
- **优先受理**
- **及时反馈受理情况**（15日内书面告知）
- **优先办理**
- **阶段性反馈**办理进展

## 三、诬告陷害和澄清正名的处理流程

| 情形 | 处理 |
|------|------|
| **诬告陷害** | 严肃查处，依规依纪依法追究诬告人责任 |
| **澄清正名** | 为受到不实举报的干部澄清事实、消除影响 |

**澄清正名的方式**：
- 书面澄清
- 当面澄清
- 公开通报
- 召开会议
