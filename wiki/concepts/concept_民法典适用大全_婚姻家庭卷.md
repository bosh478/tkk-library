## 内容定位

本卷围绕《民法典》婚姻家庭编全部79个条文，系统编辑关联规定、条文释义、适用指引、指导案例、典型案例和类案检索。婚姻家庭编是民法典的重要组成部分，调整因婚姻家庭产生的民事关系，对维护婚姻家庭关系的稳定和家庭成员的合法权益具有重要意义。

## 章节结构总览

### 第一章 一般规定（第1040-1045条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1040条 | 调整范围 | 因婚姻家庭产生的民事关系 |
| 第1041条 | 基本原则 | 婚姻自由、一夫一妻、男女平等；保护妇女、未成年人、老年人、残疾人的合法权益 |
| 第1042条 | 禁止行为 | 禁止包办买卖婚姻；禁止借婚姻索取财物；禁止重婚；禁止有配偶者与他人同居；禁止家庭暴力 |
| 第1043条 | 道德规范 | 家庭应当树立优良家风、弘扬家庭美德、重视家庭文明建设 |
| 第1044条 | 收养原则 | 收养应遵循最有利于被收养人的原则；保障被收养人和收养人的合法权益 |
| 第1045条 | 亲属、近亲属、家庭成员 | 配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女为近亲属；配偶、父母、子女和其他共同生活的近亲属为家庭成员 |

### 第二章 结婚（第1046-1054条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1046条 | 结婚自愿 | 结婚应当男女双方完全自愿 |
| 第1047条 | 法定结婚年龄 | 男不得早于22周岁，女不得早于20周岁 |
| 第1048条 | 禁止结婚 | 直系血亲或三代以内的旁系血亲禁止结婚 |
| 第1049条 | 结婚登记 | 要求结婚的男女双方应亲自到婚姻登记机关申请登记 |
| 第1050条 | 互为家庭成员 | 登记结婚后可约定成为对方家庭成员 |
| 第1051条 | 婚姻无效 | 重婚；有禁止结婚的亲属关系；未到法定婚龄 |
| 第1052条 | 胁迫婚姻 | 因胁迫结婚的，受胁迫方可向法院请求撤销婚姻 |
| 第1053条 | 隐瞒重大疾病 | 一方患有重大疾病的，应在结婚登记前如实告知；不如实告知的，另一方可请求撤销婚姻 |
| 第1054条 | 婚姻无效或撤销的后果 | 无效或被撤销的婚姻自始没有法律约束力；无过错方有权请求损害赔偿 |

### 第三章 家庭关系（第1055-1075条）

#### 第一节 夫妻关系（第1055-1071条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1055条 | 夫妻地位平等 | 夫妻在婚姻家庭关系中地位平等 |
| 第1056条 | 姓名权 | 夫妻双方都有各自使用自己姓名的权利 |
| 第1057条 | 人身自由 | 夫妻双方都有参加生产、工作、学习和社会活动的自由 |
| 第1058条 | 抚养教育子女 | 夫妻双方平等享有对未成年子女抚养、教育和保护的权利 |
| 第1059条 | 扶养义务 | 夫妻有相互扶养的义务 |
| 第1060条 | 日常家事代理权 | 夫妻一方因家庭日常生活需要实施的民事法律行为对双方发生效力 |
| 第1061条 | 继承权 | 夫妻有相互继承遗产的权利 |
| 第1062条 | 夫妻共同财产 | 婚姻关系存续期间所得的工资奖金、生产经营收益、知识产权收益、继承或赠与的财产（遗嘱或赠与合同中确定只归一方的除外）等为夫妻共同财产 |
| 第1063条 | 夫妻个人财产 | 一方的婚前财产；一方因受到人身损害获得的赔偿或补偿；遗嘱或赠与合同中确定只归一方的财产；一方专用的生活用品等 |
| 第1064条 | 夫妻共同债务 | 夫妻双方共同签名或一方事后追认等共同意思表示所负的债务，以及一方在婚姻关系存续期间以个人名义为家庭日常生活需要所负的债务 |
| 第1065条 | 夫妻财产约定 | 夫妻可约定婚姻关系存续期间所得的财产以及婚前财产归各自所有、共同所有或部分各自所有、部分共同所有 |
| 第1066条 | 婚内分割共同财产 | 一方有隐藏转移变卖毁损挥霍夫妻共同财产或伪造夫妻共同债务等严重损害夫妻共同财产利益的行为，或一方负有法定扶养义务的人患重大疾病需要医治另一方不同意支付相关医疗费用的，可请求分割 |

| 第1072条 | 继父母与继子女 | 继父母与继子女间不得虐待或歧视；适用关于父母子女关系的有关规定 |

### 第四章 离婚（第1076-1092条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1076条 | 协议离婚 | 夫妻双方自愿离婚的应签订书面离婚协议并亲自到登记机关申请 |
| 第1077条 | 离婚冷静期 | 自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方可撤回申请 |
| 第1078条 | 离婚登记 | 婚姻登记机关查明双方确实是自愿离婚并已对子女抚养、财产及债务处理等事项协商一致的，予以登记 |
| 第1079条 | 诉讼离婚 | 夫妻一方要求离婚的可向法院提起诉讼；调解无效应准予离婚的情形：重婚或与他人同居、实施家庭暴力、赌博吸毒等恶习、因感情不和分居满二年等 |
| 第1080条 | 婚姻关系解除时间 | 完成离婚登记或离婚判决书调解书生效时 |

| 第1082条 | 女方怀孕期间的限制 | 女方怀孕期间、分娩后一年内或终止妊娠后六个月内，男方不得提出离婚（女方提出或法院认为确有必要的除外） |
| 第1083条 | 复婚 | 离婚后男女双方自愿恢复婚姻关系的应到登记机关重新登记 |
| 第1084条 | 离婚后子女抚养 | 不满两周岁的子女以由母亲直接抚养为原则；已满两周岁的按最有利于未成年子女的原则判决；已满八周岁的应尊重其真实意愿 |
| 第1085条 | 抚养费 | 离婚后子女由一方直接抚养的，另一方应负担部分或全部抚养费 |
| 第1086条 | 探望权 | 离婚后不直接抚养子女的父或母有探望子女的权利 |
| 第1087条 | 离婚时财产处理 | 夫妻共同财产由双方协议处理；协议不成的由法院判决 |
| 第1088条 | 经济补偿 | 一方因抚育子女、照料老年人、协助另一方工作等负担较多义务的，离婚时有权向另一方请求补偿 |
| 第1089条 | 离婚时债务清偿 | 离婚时夫妻共同债务应共同偿还 |
| 第1090条 | 经济帮助 | 离婚时如一方生活困难，有负担能力的另一方应给予适当帮助 |
| 第1091条 | 离婚损害赔偿 | 重婚、与他人同居、实施家庭暴力、虐待遗弃家庭成员等导致离婚的，无过错方有权请求损害赔偿 |
| 第1092条 | 少分或不分财产 | 夫妻一方隐藏转移变卖毁损挥霍夫妻共同财产或伪造夫妻共同债务企图侵占另一方财产的，在离婚分割夫妻共同财产时可少分或不分 |

## 核心制度解读

### 一、离婚冷静期制度（第1077条）

**制度意义**：《民法典》新增制度，旨在减少冲动离婚，维护家庭稳定。自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方不愿意离婚的，可撤回申请。

**适用范围**：仅适用于协议离婚，不适用于诉讼离婚。

### 二、夫妻共同债务认定规则（第1064条）

**三类共同债务**：
1. 夫妻双方共同签名的债务
2. 一方事后追认的债务
3. 一方以个人名义为家庭日常生活需要所负的债务

**举证责任**：超出家庭日常生活需要的债务，债权人主张为夫妻共同债务的，应举证证明该债务用于夫妻共同生活、共同生产经营或基于夫妻双方共同意思表示。

### 三、离婚损害赔偿制度（第1091条）

**法定情形**：重婚；与他人同居；实施家庭暴力；虐待、遗弃家庭成员；有其他重大过错（新增）。

**请求权主体**：无过错方。

### 四、亲子关系异议之诉（第1073条）

**制度创新**：《民法典》新增亲子关系确认和否认之诉，父或母以及成年子女均可向法院提起诉讼。

## ❓ 常见问题

> 问：什么是离婚冷静期？
> 答：自婚姻登记机关收到离婚登记申请之日起三十日内，任何一方不愿意离婚的，可撤回申请。三十日期满后双方应亲自到登记机关申请发给离婚证（第1077条）。

> 问：哪些情形下可以诉讼离婚？
> 答：重婚或与他人同居；实施家庭暴力或虐待遗弃家庭成员；有赌博吸毒等恶习屡教不改；因感情不和分居满二年；其他导致夫妻感情破裂的情形（第1079条）。

> 问：一方隐瞒重大疾病结婚的如何处理？
> 答：一方患有重大疾病的，应在结婚登记前如实告知另一方。不如实告知的，另一方可向法院请求撤销婚姻（第1053条）。

> 问：离婚时子女抚养权如何确定？
> 答：不满两周岁以母亲直接抚养为原则；已满两周岁按最有利于未成年子女的原则判决；已满八周岁应尊重其真实意愿（第1084条）。
