## 一句话说明

本章系统阐述了电子数据现场勘验的规划与准备、现场处理流程、电子数据提取固定方法，以及实验室中数据固定与检材管理的完整规范，确保电子数据司法鉴定的原始性和有效性。

## 顿悟

电子数据现场勘验是整个鉴定工作的基石——"现场勘验工作的充分程度、科学程度，对后期电子数据分析结论将造成重大的影响"。现场勘验的核心原则是：一是防止证据被破坏（包括嫌疑人和调查人员自身）；二是遵循"不改变原始证据"的根本原则，通过硬盘复制机、只读锁等专用设备进行证据固定。

## 核心差异（相比同类旧资料）

1. **勘验规划系统化**：提出物理位置因素、现场人员因素、应用系统因素、装备规划四大考量维度
2. **易失证据固定规范**：明确区分需要固定易丢失证据的情形（犯罪行为正在发生 vs 已停止），以及不同操作系统关机方法的详细对照表
3. **现场数据固定多方法**：硬盘复制机、只读锁+软件（取证大师、WinHex）、网络方式等多种方法并列
4. **检材管理全流程**：接收→预检→备份→存放→流转→清退的完整管理体系

## 内观视角

本章构建了电子数据现场勘验与检材管理的完整体系：

1. **现场勘验规划与准备**：物理位置、场人员、应用系统、装备规划四维度
2. **现场电子数据处理**：记录现场→识别潜在证据→全面搜查→固定易失证据→关闭计算机→封存包装
3. **电子数据提取固定方法**：硬盘复制机、只读锁+软件、网络方式、应急方法
4. **实验室检材管理**：接收→预检→备份→存放→流转→清退

## 第一节 电子数据现场勘验

### 一、电子数据现场勘验的任务

发现、固定、提取与案件相关的电子数据，封存电子设备，提取传统物证及提取其他信息，对现场进行搜查，并制作和存储现场信息资料，判断案件性质，确定案件方向和范围，为诉讼工作提供线索和证据。

电子数据现场勘验工作的充分程度、科学程度，对后期电子数据分析结论将造成重大的影响。

### 二、现场勘验规划与准备

#### （一）物理位置因素

1. 充分了解现场所在的位置有助于保障人身安全
2. 证据安全决定了勘验工作的成败
3. 勘验范围可能是个人住所、公司或拥有百台计算机的网吧
4. 对于机器非常多的案件，需借助专用取证设备，预先定义要获取的特定数据
5. 对于被故意破坏的介质也应作为证物进行收集与封存，后期物理恢复可能得到关键证据

#### （二）现场人员因素

根据现场可能出现的情况，确定我方到场人员名单，一般分为两组：

1. **安全保障组**：主要负责现场人员和设备的安全，防止嫌疑人伤害调查人员或破坏设备
2. **现场勘验组**：职责主要是记录现场笔录，并收集所有与案件有关的证物。现场勘验人员必须是经过现场勘验相关的培训才能执行勘验任务

参与现场调查的人员至少要接受过计算机调查理论、方法和过程的培训。

#### （三）应用系统因素

在去现场之前必须考虑以下环节：
1. 存在什么类型的证据？
2. 搜查范围有限制吗？
3. 现场有多少台计算机？所有的计算机都在运行吗？
4. 使用什么样的操作系统？
5. 是否使用加密（如微软的EFS、PGPDisk、BestCrypt等）？
6. 是否联网？应将网络断开，防止嫌疑人或其同伙通过远程的方式进行数据删除等破坏工作
7. 服务器在什么位置？有无网络拓扑图？
8. 服务器的备份在哪里？本地备份还是远程备份？
9. 网络管理员是否需要调查？谁有根用户或者管理员的密码？
10. 有无无线网络存在？什么类型？覆盖范围？
11. 根据当前所使用的系统，如果计算机在运行，是否需要关闭？什么时间关闭？由谁来执行关闭？用什么方法关闭？
12. 谁是嫌疑人或者调查目标？会有多少嫌疑人？是个人犯罪还是属于集体犯罪？
13. 如果在获取之前，调查人员需要执行一个关键字搜索，调查人员需要使用哪一个关键字？

#### （四）装备规划与准备

赴现场常带的设备：

1. **勘查箱**：照相机或摄像机、螺丝刀、小钳子、标签、运输过程中用于保护证物的纸箱或纸袋、彩色水笔、电磁信号屏蔽袋、多功能充电器、电子证据只读锁

2. **取证专用介质复制设备**：硬盘（赴现场前应该先擦除干净）、高速硬盘复制机

3. **现场取证工具**：取证大师、EnCase、FTK、X-Ways等分析软件；关键数据获取系统；仿真系统；密码破解系统

4. **袖珍式打印机**：方便现场进行快速打印相关涉案文档

### 三、现场电子数据处理

#### （一）记录现场情况

方位草图应该包含的元素有：发案地点、发案时间、制图单位、制图人、制图时间、现场方位、中心现场位置、图例说明等信息。

进入现场后应拍摄现场概貌图，记录下现场的基本情况。应对中心现场进行拍照记录。对于涉案计算机及周边设备，应对其进行编号并拍照，然后按证据编号将其记录到现场勘验笔录当中。

#### （二）识别潜在证据

利用计算机进行违法的活动越来越多，案件现场可能出现各种各样的电子证据。计算机和相关证据的覆盖范围从大型计算机到微型掌上电脑再到软盘、CD或者最小的芯片，这些介质上的图形文件、音频文件、文本文件以及其他数据很容易改变或丢失。

#### （三）全面搜查证据

1. **检查与目标计算机互联的系统**：注意查看网络、电缆、电源等线路的连接走向；注意查看是否有无线局域网或其他无线网络连接方式；检查系统是否通过调制解调器提供拨入服务

2. **搜查数字化证据存储设备**：计算机、PDA、移动存储媒介（优盘、活动硬盘、ZIP盘、软盘、光盘、存储卡）、移动电话、电话、扫描仪、打印机、复印机、备份磁带、数码相机、数码摄像机、数码录音笔、智能卡、磁卡、嵌入式微电脑等

3. **外部设备的搜查**：注意搜查存储媒介的读写设备；注意搜查打印机使用的色带；注意搜查与设备相关的说明书、软件、配套硬件等

4. **其他证据的搜查**：嫌疑人使用的笔记本、纸张等记录信息（账号、口令、联系人信息）；计算机周边的相关物品；现场周边的相关设施（工作台、书房、床头柜、储藏室、箱包、文件柜、各种抽屉、衣柜、卫生间马桶、厨房等有下水通道的房间、窗户周边及窗户周边的室外场地）

#### （四）固定易失证据

**1. 需要固定易丢失证据的情形**

如果到达现场时犯罪行为正在发生（如系统正在对外实施攻击、群发垃圾邮件），或者犯罪嫌疑人正在使用该计算机，则应当提取易丢失证据。

如果从案发时间到调查人员抵达案发现场期间，犯罪行为已经停止并且系统曾经重新启动，则只需提取时间信息，无须提取其他易丢失证据。

**2. 时间信息的提取**

对于任何有内置时钟的设备，都必须记录该设备当前时间、该时间与北京时间的时差以及时区设置。计算机处于开机状态时可以用截图的方式；计算机处于关机状态时则可以通过进入主机BIOS提取时间信息。

**3. 系统运行状态的提取**

传统案件需要提取的计算机系统状态信息包括：系统当前运行的进程、每个进程当前打开的文件、每个进程内存中的内容、当前网络连接状态等。

计算机系统入侵案件需要提取的系统状态信息包括：当前运行的进程、每个进程当前打开的文件、每个进程内存中的内容、每个进程提供的网络服务端口、每个进程所依赖的模块列表、当前网络连接状态和网卡当前运行模式、当前登录用户以及登录的时间等。

**提取易失性数据时应遵循的原则**：
- 不得使用目标系统上的程序实施提取（可能被攻击者替换）
- 不得使用消耗大量资源的软件实施提取
- 不得将提取的信息存储在目标系统原有的存储媒介中

#### （五）关闭计算机

不同操作系统的关机方法：

| 操作系统 | 系统特征 | 关机过程 |
|----------|----------|----------|
| DOS | 全屏幕黑色背景，系统提示符 | 拍摄屏幕，拔下插头 |
| Windows 3.1/95/NT | 具有Windows标志的启动按钮 | 拍摄屏幕，拔下插头 |
| Windows 98/Me/2000/XP/2003 | 具有Windows标志的启动按钮 | 拍摄屏幕，拔下插头 |
| Linux/Unix | 有GUI查找Unix/Linux启动按钮符号或图标 | 使用正常关机处理过程，使用sync;sync;halt |
| Macintosh | 顶层左边角落有苹果标志 | 从菜单条记录系统时间，从尾部拔下插头 |

关机前应记录调查人员所有的行为以及进行相关操作的方法与原因。

#### （六）封存与包装

**标记电缆**：在每根电缆和每一个端口使用唯一的字母来进行标识，从A开始。电缆A接在端口A上，电缆B接在端口B上。

**封存的原则**：
1. 保证封条贴在正确的位置，保证除非破坏封条，否则无法使用封存设备
2. 对于可移动介质，如移动硬盘、U 盘等，可以贴上标签，然后用防静电袋装好，封条贴在封口处

**包装方法**：
1. 尽量使用大小合适的、能够吸收碰撞能量的包装材料
2. 加一些硅凝胶吸潮材料
3. 使用防静电袋，进行静电放电保护
4. 固定存储介质，防止在运输过程中损坏
5. 找一个与之大小相适的外包装箱

## 第二节 电子数据提取、固定的方法

### 一、使用硬盘复制机进行数据提取、固定

现场电子数据固定的工作流程：
1. 记录现场计算机的连接现状
2. 固定当前对象计算机的易失性数据
3. 关闭当前计算机系统
4. 拆卸当前计算机取出硬盘介质
5. 对硬盘介质进行写保护处理
6. 使用专用设备进行硬盘复制
7. 计算原始硬盘介质并封存
8. 封存硬盘介质副本
9. 现场固定结束

高速硬盘复制机是一种基于位对位复制原理的硬盘复制设备，制作的硬盘介质副本与原始硬盘介质完全一致，且可以通过MD5等散列算法进行一致性验证。

### 二、使用只读锁+软件进行数据提取、固定

只读锁设备能够阻止任何对所连接的设备的修改操作，使用只读锁是采用软件方式进行数据固定的基本前提条件。

**CyberBlock电子数据只读锁使用方法**：
1. 选择只读锁类型（IDE、SCSI、USB等）
2. 选择使用的电源
3. 连接设备电缆
4. 硬盘设置（如跳线设置为主盘模式）
5. LED灯的显示状态判断
6. 更换硬盘的步骤和方法
7. 分析结束断开硬盘

**取证分析软件固定方法**：
使用取证分析软件（如取证大师）生成硬盘的E01镜像文件。

**WinHex软件固定方法**：
使用WinHex的磁盘镜像功能，通过将磁盘制作成.dd、.e01以及.whx等扩展名的镜像文件，同时计算镜像的MD值。

**通过网络方式固定方法**：
取证分析软件EnCase中提供的基于Linux EnCase（或称LinEn）的功能，利用启动软盘或光盘启动对象计算机，通过目标计算机的网卡接入交叉网线连接到分析计算机进行预览和复制。

### 三、现场数据固定应急方法

通过修改注册表实现将USB接口设置为只读的方法：
1. 打开注册表编辑器
2. 新建HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\StorageDevicePolicies
3. 新建Dword值WriteProtect，数值1表示打开USB接口写入保护

### 四、电子数据提取、固定的后处理工作

对原始数据介质进行固定的同时，对电子数据及电子数据副本的保护也同样重要。在电子数据固定工作结束后，建议使用专用的物证袋将原始介质进行封存保护，并且对于封存后的原始介质的每次拆封和使用都需要做严格的管理和监控。

## 第三节 实验室中数据固定与检材管理

### 一、检材接收

**委托登记**：
- 委托人委托鉴定机构进行鉴定，应取得鉴定委托书或聘请书
- 鉴定委托书应至少包含委托人、委托日期、受托机构、鉴定事项、鉴定材料、案情摘要
- 鉴定机构了解委托人的实际鉴定需求后，应根据自身执业范围、技术能力、设备配置情况、检材充分情况判断是否受理委托

**检材接收**：
- 比对委托书中鉴定材料信息与实际检材是否匹配
- 填写《司法鉴定委托材料收领单》
- 文字记录、拍照和摄像相结合的方式

**检材信息记录**：
- 电子设备：外观、颜色、品牌、型号、序列号或产品号等；手机还应记录IMEI号、SIM卡的ICCID号等
- 存储介质：品牌、型号、序列号、容量、扇区数、接口类型、Hash值等

### 二、检材预检

预检的目的：
1. 保证后续鉴定能够顺利进行
2. 预检不能影响后续鉴定，要保证检材的原始性
3. 预检不必得出与鉴定要求相关的结果

**预检内容**：
1. 连接检材（通过电子数据只读锁等设备连接，硬件阻止数据写入）
2. 通电测试（查看检材通电后的运行情况）
3. 读取检材（在检材正常运转的情况下，对检材的识别、读取情况进行检查）
4. 计算Hash值

### 三、检材备份

**盘对盘复制**：将原始硬盘内的数据完整地复制到另一个硬盘上

**制作镜像文件**：将原始检材内的数据镜像成一个或多个文件

### 四、检材存放

**安全要求**：
- 环境应满足防磁、防静电、防震、防潮的要求
- 每起鉴定涉及的检材应有明显的区域分开存放
- 检材应远离高磁场、高温、灰尘、积压、潮湿、腐蚀性化学试剂等

**保密要求**：
- 检材应有专门人员（如检材管理员）管理
- 检材柜要具有保护机制，如设置密码或安装锁
- 与检材对应案件无关的人员不能接触检材

### 五、检材流转

检材在鉴定过程中使用，应全程保证原始检材的原始性和完整性：
- 原始检材必须在只读的环境下才能操作
- 使用硬盘套、硬盘盒等工具避免检材碰撞
- 鉴定人员操作检材时应佩戴防静电手套和防静电腕带
- 备份检材无特殊情况也应在只读环境下操作
- 若某些鉴定方法有要求不得不向检材中写入数据，此类鉴定必须使用备份检材

### 六、检材清退

鉴定机构退还检材时，应与委托人一起确认检材是否完整，再次计算Hash值并与收领时记录的Hash值比对，以证明检材在鉴定过程中未作过任何更改。

### 七、备份检材清理

鉴定机构结束鉴定后，原始检材已连同鉴定报告一起交给委托人，但鉴定期间使用的备份检材还留在鉴定机构（留样）。考虑到诉讼时效，若委托人无特别要求，鉴定机构将保存留样6个月。
