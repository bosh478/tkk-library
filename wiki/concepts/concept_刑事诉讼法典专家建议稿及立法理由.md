## 概述

本建议稿由中国学者陈卫东主持，中国人民大学出版社于2025年出版，系对《中华人民共和国刑事诉讼法》的全面修订建议稿。全稿分为**法典篇**和**立法理由论证篇**两大部分，共七编，条文从第一条延伸至第一千零四十五条之后，涵盖总则、证据与证明、立案侦查公诉、审判、执行、特别程序、涉外刑事诉讼程序等内容。本建议稿系统总结了我国刑事诉讼法的既有经验，借鉴域外法治成果，旨在推进以审判为中心的刑事诉讼制度改革，完善人权司法保障。

## 第一编 通则

### 一般规定（第一条至第二十五条）

本编第一章确立刑事诉讼法的**基本原则体系**，相较现行法有显著增设与完善：

| 条文 | 原则/制度 | 要点 |
|------|-----------|------|
| 第一条 | 立法目的 | 保证刑法正确实施，惩罚犯罪，规范职权，保障人权，公正高效 |
| 第三条 | 依靠群众、以事实为根据以法律为准绳、适用法律平等三原则 | 继承现行法规定 |
| 第四条 | 职权法定原则 | 明确公检法三机关职权分工 |
| 第五条 | 正当程序原则 | 未经正当程序不得对任何人适用强制措施或作出有罪判决 |
| 第六条 | 依法独立公正行使司法职权原则 | 人民法院独立行使审判权，人民检察院独立行使检察权 |
| 第七条 | 分工负责、互相配合、互相制约原则 | 坚持宪法规定，与审判中心改革并行不悖 |
| 第八条 | 检察监督原则 | 人民检察院依法对刑事诉讼实行法律监督 |
| 第九条 | 审判中心原则 | **新增原则**。所有诉讼活动以审判活动为中心 |
| 第十条 | 两审终审原则 | 保留并强化审判中心基础上的两审终审制 |
| 第十一条 | 审判公开原则 | 允许公民旁听和新闻记者采访报道 |
| 第十二条 | 控辩平等原则 | **新增原则**。控辩双方诉讼地位平等、机会平等 |
| 第十三条 | 审判中立原则 | **新增原则**。审判人员无偏倚对待控辩双方 |
| 第十四条 | 人民陪审原则 | 人民陪审员陪审制度 |
| 第十五条 | 无罪推定原则 | **重大完善**。明确"假定其无罪"、证据不足时应作无罪判决或不起诉决定 |
| 第十六条 | 不得强迫自证其罪原则 | 严禁刑讯逼供等非法方法收集证据 |
| 第十七条 | 有效辩护原则 | **新增三款规定**。明确有效辩护原则、司法机关保障义务、法律援助国家义务 |
| 第十八条 | 权利保障原则 | 强化被害人诉讼地位保障 |
| 第十九条 | 比例原则 | **新增原则**。追诉处罚须与罪行社会危害性和人身危险性成比例 |
| 第二十条 | 依法免予追究刑事责任原则 | 保留现行规定（六种情形） |
| 第二十一条 | 一事不再理原则 | **新增原则**。生效判决后不得再次审判或追诉 |
| 第二十二条 | 诉讼及时原则 | **新增原则**。刑事诉讼应在合理时间内迅速进行 |
| 第二十三条 | 外国人犯罪管辖原则 | 外国人犯罪适用本法；享有外交特权者通过外交途径解决 |
| 第二十四条 | 司法协助原则 | 根据国际条约或互惠原则进行刑事司法协助 |
| 第二十五条 | 使用我国通用语言文字进行诉讼原则 | 汉语为通用语，为不通晓者提供翻译 |

### 管辖（第二十六条至第五十五条）

本编第二章系统规定管辖制度，包括职能管辖、级别管辖、地域管辖、牵连管辖、指定管辖、管辖异议等：

**职能管辖**：
- 第二十六条：人民法院直接受理自诉案件
- 第二十七条：人民检察院立案侦查司法工作人员利用职权实施的非法拘禁、刑讯逼供、非法搜查等侵犯公民权利、损害司法公正的犯罪
- 第二十八条：公安机关及其他侦查机关的职能管辖（国家安全机关、军队保卫部门、中国海警局、监狱）

**级别管辖**：
- 第三十条：基层人民法院管辖第一审刑事案件
- 第三十一条：中级人民法院管辖危害国家安全、恐怖活动、黑社会性质组织犯罪及可能判处无期徒刑、死刑的案件
- 第三十二条：高级人民法院管辖全省性重大刑事案件
- 第三十三条：最高人民法院管辖全国性重大刑事案件

**地域管辖**（第三十七条至第四十二条）：
- 犯罪地法院管辖为主，被告人居住地法院管辖为辅
- 特殊地区管辖（内水领海、列车、国际列车、船舶、航空器、驻外使领馆、服刑期间犯罪等）
- 竞合管辖、牵连管辖（共同犯罪、一人犯数罪、关联犯罪等）

**指定管辖与管辖异议制度**（第四十五条至第五十五条）：
- 指定管辖的法定事由：管辖不明确或有争议、因回避或舆论偏见不宜行使审判权、因其他原因不能行使审判权
- 管辖异议的主体与程序：犯罪嫌疑人、被告人、被害人、自诉人及其法定代理人可提出异议
- 辩护人、诉讼代理人的程序性权利

### 回避（第五十六条至第六十六条）

- 回避适用对象：审判人员、检察人员、侦查人员、司法警察、书记员、记录人、翻译人员、鉴定人、专门性问题报告出具人
- 回避情形：利害关系、近亲属关系、担任过其他诉讼角色、与辩护人有近亲属关系等
- 办案人员违规参与程序的回避、任职回避
- 回避决定的效力：故意违法管辖导致严重后果的，先前诉讼行为无效

### 辩护与代理（第六十七条至第九十五条）

**核心制度创新**：

| 条文 | 制度 | 主要修改 |
|------|------|----------|
| 第六十七条 | 辩护人数量 | 允许委托一至四人；律师可带一名助理 |
| 第六十八条 | 辩护人范围 | 扩大禁止担任辩护人的情形 |
| 第六十九条 | 委托辩护时间 | 提前至侦查机关立案之日 |
| 第七十条 | 法律援助辩护 | 规定办案机关依职权指定辩护 |
| 第七十一条 | 法律援助范围 | **重大扩展**：增加视力听力言语残疾人、死缓期间故意犯罪等 |
| 第七十二条 | 委托辩护优先原则 | **新增**。防止"占坑式辩护" |
| 第七十三条 | 值班律师制度 | 明确值班律师职责范围 |
| 第七十四条 | 值班律师权利 | 明确了解案情、阅卷、会见权利 |
| 第七十六条 | 侦查期间辩护律师权利 | 代理申诉控告、申请变更强制措施等 |
| 第七十八条 | 会见权 | **重大完善**：看守所应立即安排会见；不被监听 |
| 第八十条 | 阅卷权 | **扩展**：增加犯罪嫌疑人本人阅卷权、审查批捕阶段阅卷权 |
| 第八十一条 | 申请调查取证权 | 增加监察机关调取证据；律师在场权 |
| 第八十二条 | 辩护律师调查取证权 | 可申请人民法院颁发调查令 |
| 第八十四条 | 辩护律师在场权 | **新增**。侦查机关讯问时律师消极在场权 |
| 第八十六条 | 辩护人豁免权 | **新增**。执业活动中人身权利不受侵犯 |
| 第八十七条 | 有效辩护与无效辩护 | **新增**。明确无效辩护的情形和救济 |

## 第二编 证据和证明

### 证据的一般规定（第一百八十三条至第二百七十六条）

**证据种类**（第一百八十三条）：
- 物证、书证、证人证言、被害人陈述、犯罪嫌疑人/被告人供述和辩解
- 鉴定意见、专门性问题报告（新增）
- 勘验/检查/辨认/侦查实验等笔录
- 视听资料、电子数据

**基本原则**：
- 证据裁判原则（第一百八十四条）：认定案件事实必须以证据为根据
- 自由心证原则（第一百八十五条）：法庭调查辩论后，审判人员依程序审查判断证据

**主要制度**：
- 监察证据的使用（第一百八十九条）：监察机关依法收集的证据材料在刑事诉讼中可作为证据使用
- 境外证据材料的移送与使用（第一百九十条）：取消"公证+双认证"限制
- 意见证据规则（第一百九十二条）：证人猜测性、评论性、推断性证言不得作为证据使用
- 相似事实证据规则（第一百九十三条）：被告人先前犯罪记录不得用以证明其品格
- 非法证据排除的阶段（第一百九十四条）：侦查、审查起诉、审判各阶段均应排除非法证据
- 供述自愿性规则（第一百九十五条）：刑讯逼供取得的供述应当排除

## 第三编 立案、侦查和公诉

### 立案（第二百七十七条至第二百九十条）

- 立案条件：发现犯罪事实或者犯罪嫌疑人
- 控告举报制度：任何单位和个人有权报案或举报
- 受案登记：当场登记、出具回执；必要时录音录像
- 调查核实：可采取询问、查询、勘验、鉴定等非强制性措施

### 侦查

本编第二章系统规定侦查程序，包括讯问、询问、勘验检查、辨认、搜查、扣押、查询冻结、技术侦查、大数据侦查、侦查终结等程序。

**技术侦查**（第十五节）：根据侦查犯罪需要，经批准可采取技术侦查措施

**大数据侦查**（第十七节）：**新增**。规范运用大数据分析等技术手段进行侦查

### 公诉

- 审查起诉：人民检察院自收到移送审查起诉材料之日起三日内告知犯罪嫌疑人有权委托辩护人
- 提起公诉：事实清楚、证据充分的应当起诉
- 不起诉：法定不起诉、酌定不起诉、证据不足不起诉
- 附条件不起诉：**新增**。适用于未成年人等特定情形
- 认罪认罚案件的特别规定：**新增专节**。明确认罪认罚从宽的程序要求
- 核准追诉：**新增**。明确最高人民检察院核准追诉的程序

## 第四编 审判

### 审判组织

- 合议庭：基层人民法院由审判员组成或审判员与人民陪审员组成
- 独任审判：基层人民法院适用简易程序、速裁程序
- 审判委员会：讨论决定重大疑难案件

### 第一审程序

**公诉案件**：
- 庭前准备程序：召开庭前会议、管辖异议处理
- 开庭审理：法庭调查、法庭辩论、被告人最后陈述
- 法庭秩序：**新增**（第一千条）：违反法庭秩序的处罚规则

**自诉案件**：
- 告诉才处理的案件、被害人有证据证明的轻微刑事案件、被害人有证据证明公安机关应当依法立案而不依法立案的案件

**简易程序**：基层人民法院审理的案件，事实清楚、证据充分，被告人认罪

**速裁程序**：基层人民法院审理的案件，可能判处三年有期徒刑以下刑罚，事实清楚，证据充分，被告人认罪认罚

### 第二审程序

- 上诉权：被告人、自诉人及其法定代理人、经被告人同意的辩护人、近亲属
- 抗诉权：人民检察院
- 二审审理方式：开庭审理为原则

### 死刑复核程序

- 被告人可能被判处死刑的案件，应当报请最高人民法院核准
- 辩护律师参与：辩护律师可以向最高人民法院提出意见

### 再审程序

- 当事人及其法定代理人、近亲属、辩护人可向人民法院或人民检察院申诉
- 重新审理：事实不清、证据不足的应当发回重审

## 第五编 执行

### 判决、裁定的执行

- 死刑（立即执行、缓期执行）的执行
- 罚金、没收财产的执行
- 资格刑的执行

### 刑罚执行中的变更

- 减刑：中级人民法院收到监狱、看守所提请减刑建议后审查
- 假释：符合条件的可以假释
- 暂予监外执行：怀孕或哺乳婴儿的妇女等情形

### 轻微犯罪记录封存

**新增制度**。犯罪记录封存，使有过轻罪记录的人在升学、就业等方面不受歧视

## 第六编 特别程序

本编规定未成年人案件、精神病人强制医疗、犯罪嫌疑人/被告人逃匿/死亡案件违法所得没收、缺席审判、刑事和解、违法所得没收、强制医疗等特别程序。

| 章节 | 主要内容 |
|------|----------|
| 违法所得没收程序 | 犯罪嫌疑人、被告人逃匿、死亡时，可申请没收违法所得 |
| 强制医疗程序 | 依法不负刑事责任的精神病人，由人民法院决定强制医疗 |
| 未成年人刑事案件诉讼程序 | 犯罪记录封存、附条件不起诉、法律援助等 |
| 缺席审判程序 | 外逃贪污贿赂等案件犯罪嫌疑人、被告人不到案可缺席审判 |
| 刑事和解程序 | 被告人真诚悔罪，通过赔偿损失、赔礼道歉获得谅解 |

## 第七编 涉外刑事诉讼程序

### 一般规定（第一千零五条至第一千零一十三条）

| 条文 | 原则/制度 |
|------|-----------|
| 第一千零五条 | 国家主权原则 |
| 第一千零六条 | 信守国际条约原则、平等互惠原则 |
| 第一千零七条 | 权利义务平等原则（国民待遇原则） |
| 第一千零八条 | 审判公开原则 |
| 第一千零九条 | 使用我国通用语言文字进行诉讼原则 |
| 第一千零一十条 | 中国律师代理诉讼原则 |
| 第一千零一十一条 | 涉外刑事案件的范围 |
| 第一千零一十二条 | 国籍认定 |
| 第一千零一十三条 | 无国籍人适用本编规定 |

### 管辖（第一千零一十四条至第一千零一十八条）

- 保护管辖：外国人对我国国家或公民犯罪，由登陆地、入境地或居住地法院管辖
- 普遍管辖：缔结或参加的国际条约规定的罪行，由被抓获地、登陆地或入境地法院管辖
- 属人管辖：中国公民在领域外犯罪，由入境地或居住地法院管辖
- 集中管辖：涉外刑事案件较多地区可指定集中管辖

### 权利保障（第一千零一十九条至第一千零二十八条）

- 委托辩护：须委托中国律师
- 探视权、会见权、通信权
- 质证权
- 通知义务与层报制度

### 国际刑事司法协助（第一千零三十二条至第一千零四十五条之后）

- 协助依据：国际条约、互惠原则
- 协助范围：调查取证、送达文书、资产追缴返还等
- 禁止性事项：政治犯罪、死刑案件等不得协助
- 边境地区变通执法合作
- 请求审查与执行程序

## 主要立法特色与创新

### 1. 基本原则体系的完善

相较现行《刑事诉讼法》，本建议稿在基本原则层面新增**审判中心原则、控辩平等原则、审判中立原则、有效辩护原则、比例原则、一事不再理原则、诉讼及时原则**等，这些原则的确立为刑事诉讼制度的现代化提供了价值指引。

### 2. 辩护制度的实质性推进

本建议稿在辩护制度方面的修改最为显著：
- 委托辩护时间提前至立案之日
- 扩大法律援助范围
- 确立值班律师制度职责
- 保障辩护人会见、阅卷、在场权利
- 创设辩护人豁免权、有效辩护与无效辩护制度

### 3. 审判中心主义的贯彻

- 确立审判中心原则为基本原则
- 完善回避制度、管辖异议制度
- 强化辩护律师在场权
- 完善非法证据排除规则

### 4. 国际化视野

本建议稿充分借鉴联合国公约、欧洲人权公约、美国宪法、俄罗斯联邦刑事诉讼法典、德国刑事诉讼法典、日本刑事诉讼法等国际规范，在正当程序、无罪推定、不得强迫自证其罪、有效辩护等领域实现与国际标准的接轨。

### 5. 新兴领域规制

- 大数据侦查的规范
