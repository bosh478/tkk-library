## 一、编纂背景与立法历程

### 三版演进

| 版本 | 时间 | 名称 | 条文数 | 特点 |
|------|------|------|--------|------|
| 第一版 | 2005年 | 《模范刑事诉讼法典》 | 662条 | 8编体例开创法典化先河 |
| 第二版 | 2011年 | 《模范刑事诉讼法典（第二版）》 | 676条 | 增加认罪认罚协商程序 |
| 第三版 | 2025年 | 《刑事诉讼法典》专家建议稿 | 1077条 | 全面法典化、精细化 |

**历史沿革**：

1. **2005年版**：2004年组建研究团队，历经两年调研（含赴欧美考察）、国际研讨会论证而成。设8编：通则、证据、审前程序、一审程序、救济程序、特别程序、执行程序、刑事司法协助。2006年获司法部第二届全国法学教材和科研成果二等奖。

2. **2011年版**：2010年启动修订，借鉴六年间理论研究与司法实践新成果。增加内容：尊重保障人权原则入法、刑事非法证据排除规则、辩诉交易和认罪认罚协商程序。2015年获钱端升法学研究优秀成果一等奖。2018年刑诉法修正案吸收了其创设的认罪认罚协商程序。

3. **2025年版**：2023年11月组建新团队，2024年6月安阳统稿会，2024年7月烟台论证会（全国学者及实务界百余人参会）。恰逢《民法典》开创法典化时代，刑事诉讼法修改列入第十四届全国人大常委会立法规划。

## 二、法典结构（七编1077条）

| 编别 | 名称 | 章节数 | 条文数 | 主要内容 |
|------|------|--------|--------|----------|
| 第一编 | 通则 | 7章 | 182条 | 一般规定、管辖、回避、辩护与代理、强制措施、附带民事诉讼、期间送达 |
| 第二编 | 证据和证明 | 3章 | 94条 | 一般规定、证据（9节）、证明 |
| 第三编 | 立案、侦查和公诉 | 3章 | 249条 | 立案（3节）、侦查（19节）、公诉（7节） |
| 第四编 | 审判 | 5章 | 241条 | 审判组织、第一审程序、第二审程序（3节）、死刑复核、再审 |
| 第五编 | 执行 | 4章 | 71条 | 一般规定、判决裁定执行、刑罚执行变更、轻微犯罪记录封存 |
| 第六编 | 特别程序 | 7章 | 167条 | 未成年人、单位犯罪、缺席审判、涉案财物处置、违法所得没收、强制医疗、在线诉讼 |
| 第七编 | 涉外刑事诉讼程序 | 5章 | 73条 | 一般规定、管辖、权利保障、通知通报、国际刑事司法协助（5节） |

**法典规模对比**：现行《刑事诉讼法》308条 → 专家建议稿1077条（增加约2.5倍）

## 三、核心特色

### 1. 体例法典化

- 编章数量从现行5编增至7编
- 证据和证明单列一编（第二编）
- 新增涉外刑事诉讼程序编（第七编）
- 整合删减：删除监视居住、公诉案件当事人和解程序
- 增设：单位犯罪诉讼程序、涉案财物处置程序、在线诉讼程序

### 2. 规范完备化

- 条文数量从308条增至1077条
- 将司法解释及规范性文件的规定上升为立法规定
- 实现立法精细化和缜密化
- 克服现行法"条文过少、规定过疏"之不足

### 3. 内容创新化

- **新技术立法**：增设大数据侦查、强制采样、在线诉讼程序
- **轻罪化治理**：扩大完善附条件不起诉制度（适用范围扩至可能判处3年以下有期徒刑之刑罚的轻罪案件）
- **涉外法治**：增设涉外刑事诉讼程序专编

## 四、主要制度创新

### 第一编 通则（182条）

| 创新点 | 内容 |
|--------|------|
| 基本原则体系重构 | 新增审判中心原则、一事不再理原则、比例原则 |
| 管辖制度完善 | 规范指定管辖，增设管辖异议制度 |
| 辩护制度扩展 | 增设辩护律师在场权、有效辩护制度 |
| 强制措施重构 | 取消监视居住，增设羁押必要性审查专节 |
| 附带民事诉讼 | 增设财产保全制度 |

### 第二编 证据和证明（94条）

| 创新点 | 内容 |
|--------|------|
| 证据裁判原则 | 增设证据裁判原则、自由心证原则 |
| 证据规则 | 增设意见证据规则、相似事实证据规则 |
| 证据种类扩展 | 增设技术调查证据、专门性问题报告等 |
| 非法证据排除 | 完善非法证据排除规则 |
| 证明制度 | 增加证明对象、免证事实等规定 |

### 第三编 立案、侦查和公诉（249条）

| 创新点 | 内容 |
|--------|------|
| 立案监督 | 公安机关立案或不立案报送同级检察院备案；被害人救济程序 |
| 侦查措施扩展 | 现行11节增至19节：调取、强制采样、辨认、侦查实验、限制出境、大数据侦查 |
| 审查起诉实质化 | 完善审查起诉实质化相关规定 |
| 附条件不起诉 | 适用范围：可能判处3年以下有期徒刑之轻罪案件 |
| 认罪认罚协商 | 审查起诉阶段特别规定专节 |

### 第四编 审判（241条）

| 创新点 | 内容 |
|--------|------|
| 第一审程序 | 增设分案和并案规定；庭前审查实质化；增设反询问、交叉询问规则 |
| 第二审程序 | 区分判决上诉与裁定上诉；一律开庭审理 |
| 死刑复核 | 强化诉讼化审理 |
| 再审程序 | 区分有利于和不利于原审被告人两类再审 |

### 第五编 执行（71条）

| 创新点 | 内容 |
|--------|------|
| 执行主体 | 明确执行主体、罪犯权利规定 |
| 刑罚执行变更 | 减刑、假释、暂予监外执行：开庭审理、公示程序、实质化审理 |
| 轻微犯罪记录封存 | 法定最高刑3年有期徒刑以下（除危害国家安全等特定案件外）适用 |

### 第六编 特别程序（167条）

| 创新点 | 内容 |
|--------|------|
| 未成年人保护 | 未成年犯罪嫌疑人/被告人/被害人信息保护；强化矫正教育；细化犯罪记录封存 |
| 单位犯罪程序 | 诉讼代表人、强制措施、检察建议；单位犯罪附条件不起诉 |
| 缺席审判 | 扩大适用范围 |
| 涉案财物处置 | 统一保管、先行处置、执行程序 |
| 在线诉讼 | 适用范围、不适用情形、效力、程序转换 |

### 第七编 涉外刑事诉讼程序（73条）

| 创新点 | 内容 |
|--------|------|
| 管辖原则 | 保护管辖、普遍管辖、属人管辖、集中管辖 |
| 权利保障 | 外籍犯罪嫌疑人辩护权、会见权、探望权 |
| 国际司法协助 | 刑事司法协助程序、证据问题、涉案财物处理、送达 |

## 五、对现行法的重大修改

### 修改要点汇总

| 领域 | 现行法问题 | 建议稿对策 |
|------|-----------|-----------|
| 体例 | 5编结构松散 | 7编体系化 |
| 证据 | 16条过于简略 | 94条完备规定 |
| 侦查 | 11节不够完善 | 19节穷尽列举 |
| 强制措施 | 监视居住存在争议 | 取消，替代措施完善 |
| 轻罪处理 | 和解程序分散 | 附条件不起诉统一规定 |
| 涉外 | 无规定 | 专编73条详尽规定 |
| 技术应用 | 滞后 | 大数据侦查、在线诉讼 |

## 六、学术价值与实践意义

1. **学术价值**：
   - 二十余年持续深耕的学术积累
   - 为刑事诉讼法从"修改"走向"法典化"提供理论支撑
   - 创设的制度和程序已成为学界研究热点

2. **实践意义**：
   - 立法机关和司法机关高度重视
   - 部分内容已被2012年、2018年刑诉法修改吸收
   - 为司法改革探索提供思路和指引

3. **法典化愿景**：
   > "为中国第一部刑事诉讼法典的制定提供参考"——陈卫东
