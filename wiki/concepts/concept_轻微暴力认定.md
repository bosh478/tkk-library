## 定义

轻微暴力是行为人实施的撕扯、推搡、掌掴、抓挠等低位暴力行为，这种暴力行为一般不会造成轻伤以上后果。

## 轻微暴力的基本特性

| 特性 | 说明 |
|------|------|
| 身体接触 | 对视、辱骂、手势威胁等不是刑法规范意义上的暴力 |
| 力度和速度 | 轻轻碰一下、摸一下、推一下对方身体等不是刑法规范意义上的暴力 |
| 身体感受 | 对方的身体感受有一定疼痛或不适，如红肿、抓痕、微出血等 |

## 与轻微暴力的区分

| 行为 | 是否属于轻微暴力 |
|------|------------------|
| 撕扯、推搡、掌掴、抓挠 | 是 |
| 使劲拉扯、猛拽衣领、向前猛推、脚踹 | 否（属于可能致伤的暴力） |
| 掌掴 | 视力度和情形而定 |
| 推一下 | 视力度、对象、环境等因素综合判断 |

## 认定要点

### 力度控制

行为人对力度进行有意识控制是判断是否具有伤害故意的关键因素。

### 情形因素

| 因素 | 影响 |
|------|------|
| 对象 | 体弱者、儿童、老年人、腿脚不便的人更容易受伤 |
| 部位 | 头部、眼部、胸部、裆部等关键部位更易构成伤害 |
| 环境 | 危险环境下更易发生意外 |
| 次数 | 连续多次比单次更可能认定为伤害 |

### 与故意伤害罪的关系

轻微暴力致人轻伤不一定构成故意伤害罪，需要结合行为人的主观故意判断：
- 如果行为人有伤害故意 → 可能构成故意伤害罪
- 如果行为人无伤害故意（过失或意外）→ 不构成故意伤害罪

## 相关案例

**朱某推搡案**：被告人拉扯、推搡致被害人摔倒受伤（轻伤二级）。法院认为朱某的行为具有节制性，通常不会直接造成轻伤以上后果，朱某主观上不具有伤害他人的故意，**不构成故意伤害罪**。

## 法律依据

- 《中华人民共和国刑法》第十四条（故意犯罪）
- 《中华人民共和国行政处罚法》第二十七条（行刑反向衔接）
