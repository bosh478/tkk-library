# 机动车交通事故责任类案 · 总体情况与统计（第1册）

> **位置**：第一部分 机动车交通事故责任类案总体情况概述（行 5843–5907）
> **核心数据**：年均 4 万件 + 占比 7% + 调撤率 60% + 小额诉讼 30% + 重新鉴定率 9%
> **关联条文**：《民法典》第一千二百零八条至第一千二百一十七条 + 上海法院智能辅助办案系统

## 一、原文逐句（L4 段级提取 · 行 5847–5907）

### 1.1 (一) 总体呈高发态势（行 5849–5850）

**审查要点**：

> 全市法院审理的机动车交通事故责任类案年均收案数量连续多年超 4 万件，在全市一审民商事收案总数中的占比超过 7%，排名前三。

**量化数据**：

| 年份 | 收案数(件) |
|------|------------|
| 2015 | 49,533 |
| 2016 | 49,436 |
| 2017 | 46,057 |
| 2018 | 40,282 |
| 2019 | 28,616 |

### 1.2 (二) 案件调撤比例超过半数（行 5853–5854）

**审查要点**：

> 近五年上海法院处理该类案件总体调撤率为 60% 左右，适用小额诉讼程序的比例达到 30%。重新鉴定比例 9% 左右，近年升高趋势明显。

### 1.3 (三) 非机动车引发的事故较多（行 5857–5858）

**审查要点**：

> 原告方交通方式占比（2017 年以来）：机动车 18.1% / 行人 16.4% / 非机动车 65.5%。

### 1.4 (四) 引入智能辅助办案系统（行 5861–5862）

**审查要点**：

> 上海市高级人民法院 2017 年 8 月启动研发智能辅助办案系统，2018 年 9 月全市推广，首批案由含机动车交通事故责任类案。2018.9–2019.12 处理总量 2571 件，自动文书生成 659 件，编目准确率 78%。

## 二、类案特征（行 5863–5892）

### 2.1 法律关系复合性（行 5865–5868）

**审查要点**：

> 复合之诉：除一般侵权问题（赔偿范围、因果关系）外，还涉及保险合同法律问题（商业三者险免责条款效力认定）。交强险与商业三者险的功能定位不同——前者侧重受害者权益保护（社会利益），后者侧重合同风险平衡（意思自治）。

### 2.2 责任主体复杂性（行 5869–5873）

**审查要点**：

> 责任主体涉及三类：
> - 车辆所有权类：所有人 / 实际管理人 / 挂靠人 / 被挂靠人 / 被套牌人
> - 侵权关系类：实际驾驶人 / 雇主 / 试乘服务提供者 / 驾驶培训机构
> - 保险责任类：投保义务人 / 保险公司 / 道路救助基金

### 2.3 程序分化特征明显（行 5875–5885）

**审查要点**：

> 简易案件走诉前调解或小额诉讼；复杂案件需第三方鉴定（事故成因 / 损害后果 / 参与度）。近年来鉴定机构问题导致重新鉴定数量增加。

### 2.4 智能辅助办案初见成效（行 5887–5892）

**审查要点**：

> 系统核心功能：文字识别转换 + 知识索引模板 + 内置智能计算器（赔偿计算与责任分配）。

## 三、指导原则（行 5887–5907）

| 原则 | 核心要求 |
|------|----------|
| 确保裁判标准统一 | 解决地区性差异，理清适法争议，规范操作流程 |
| 保障各类法益平衡 | 受害人权益 + 社会成本 + 保险制度 + 订约自由 + 裁判导向 |
| 采取繁简分流 | 简易灵活 + 复杂规范 + 鉴定流程透明 |
| 关注新型案件 | 网约车 / 网络代驾 / 平台与司机法律关系 |

## 五、实务问答（FAQ）

> **Q1: 上海法院机动车交通事故责任类案的体量级别？**
> 答：年均 4 万件 + 占比 7% + 排名前三（行 5849）。

> **Q2: 重新鉴定率近年趋势？**
> 答：9% 左右，且**升高趋势明显**（行 5853），部分鉴定机构暴露问题。

> **Q3: 交强险与商业三者险的功能区分？**
> 答：交强险**社会利益** + 受害者权益保护；商业三者险**意思自治** + 合同风险平衡（行 5867）。

> **Q4: 责任主体包含哪些？**
> 答：13 类——车辆所有权 5 类 + 侵权关系 4 类 + 保险责任 3 类 + 道路救助基金（行 5871–5873）。

> **Q5: 4 项指导原则？**
> 答：裁判标准统一 / 法益平衡 / 繁简分流 / 关注新型案件（行 5887–5907）。
