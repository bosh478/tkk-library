# 政府信息公开类案 · 不予立案 9 种情形（第1册）

> **位置**：第二部分 六 政府信息公开案件不予立案的情形（行 9605–9659）
> **核心条文**：《行政诉讼法》第四十九条 + 《信息公开司法解释》第二条 + 《行诉解释》第六十九条第八项

## 一、原文逐句（L4 段级提取）

### 1.1 (一) 一般规定（行 9607–9621）

> 4 类一般不予受理情形：
> 1. **被告不适格且拒绝变更的**；
> 2. **超过起诉期限且无正当理由的**；
> 3. **缺乏原告资格的**；
> 4. **不属于接收诉状法院管辖的**。

**规范指引**：《行政诉讼法》第四十九条（4 项起诉条件）。

### 1.2 (二) 不予立案具体情形（行 9633–9649 + 典型案例）

> **9 种不予立案情形**：

#### 1.2.1 1.补正告知对申请人权利义务不产生实际影响的（行 9633–9635）

> 《信息公开司法解释》第二条 — 因**申请内容不明确**，行政机关要求申请人**作出更改、补充且对申请人权利义务不产生实际影响的告知行为**，**法院不予受理**。
>
> **4 种情形区分**：
> 1. 补正后**又对补正告知行为提起诉讼** → **不予立案**；
> 2. **拒绝补正 / 逾期未补正** + 行政机关作出答复 → 对告知行为提起诉讼 → **不予立案**；
> 3. **未补正** + 行政机关**不再答复** + 申请人在补正期满后**对补正告知**提起诉讼 → **法院可引导**对不予答复起诉，**坚持对补正告知起诉的应当立案**；
> 4. **补正期限未届满前拒绝补正** + 对告知行为起诉 → **不予立案**。

#### 1.2.2 2.申请人要求行政机关提供公开出版物（行 9635–9637）

> 《信息公开司法解释》第二条第二项 — 申请人要求行政机关提供**政府公报 / 报纸 / 杂志 / 书籍等公开出版物** + 行政机关**拒绝** → **法院不予立案**。

#### 1.2.3 3.要求行政机关对信息加工 / 汇总（行 9637–9641）

> 《信息公开司法解释》第二条第三项 — 申请人要求行政机关**为其制作、搜集政府信息** + 或**对若干政府信息进行汇总、分析、加工** + 行政机关明确拒绝 → 法院**可裁定不予立案**。
>
> **例外**：行政机关**以其他理由作出实体答复**的 → 申请人不服起诉 → **法院应当立案受理**。经审查**充分证据和依据**证明申请确属制作/搜集/汇总/分析/加工的 → **可在理由部分说明 + 裁定驳回起诉**。

#### 1.2.4 4.以信息公开名义申请查阅案卷材料（行 9641–9643）

> 《信息公开司法解释》第二条第四项 — **行政程序中的当事人、利害关系人**以政府信息公开名义申请查阅案卷材料 + 行政机关告知**应当按照相关法律、法规的规定办理**的 → **法院不予立案**。

#### 1.2.5 5.要求获取信访信息 / 通过信息公开信访咨询（行 9643–9645）

> 行政机关对信访事项所作处理**对当事人权利义务不产生实际影响** → **一般不属于行政诉讼受案范围**。
>
> 申请人以**信息公开方式要求获取信访信息或进行信访活动**的 → 本质属于**信访活动组成部分** → 行政机关答复和处理可视为**处理信访事项的工作** → **不属于行政诉讼范围**。
>
> 法院可适用《行诉解释》第六十九条第八项作出裁定。
>
> ⚠️ **此处信访信息应当是在形式上就能够识别的信访信息**。

#### 1.2.6 6.要求获取行政复议信息（行 9645–9647）

> 《行政复议法》及其实施条例**已经对行政复议过程中形成的案卷材料的查询作出规定**，**申请者可以按照专门规定申请查阅**。
>
> 申请者以**信息公开方式申请查阅复议材料** → **不属于政府信息公开条例调整范围** → 法院**不予立案**。

#### 1.2.7 7.申请公开涉诉信息（行 9647–9651）

> 行政机关参加诉讼活动所作的行为**本身不属于行政诉讼受案范围**。行政机关对要求获取涉诉信息的政府信息公开申请进行处理 → **不等同于一般履行行政管理职责的活动** → **可视为诉讼活动的延续** → **依然不属于法院受案范围**。
>
> ⚠️ **此处"涉诉信息"= 行政机关为了参加诉讼活动专门制作的材料**（如**答辩状 / 行政强制执行申请书**等）。
>
> **例外情形**：
> - 行政机关在诉讼中提交的**其他在诉讼活动进行之前在行政管理中已经形成**的政府信息 → **不属于**此处"涉诉信息"；
> - 行政机关**依法履行法院准予执行行政裁定的行为**可视为诉讼活动的延续 → 与之相关的信息属于此处"涉诉信息"；
> - 行政机关在组织实施强制执行过程中**超越行政裁定的范围、侵害被执行人利益**的 → **相关执行行为因构成行政侵权**而**不能被视为诉讼活动的延续** → 与之相关的信息**不属于**此处"涉诉信息"。

#### 1.2.8 8.以信息公开申请形式进行信访、投诉举报等活动（行 9651–9653）

> 此类申请的**本质是信访或者投诉举报** → 申请人**目的不是获得信息** → 而是要求行政机关实施某些行政管理活动。
>
> 由于申请人**不具有《政府信息公开条例》所保护的获取信息的利益** → 法院**可以不予立案**。

#### 1.2.9 9.以信息公开名义进行咨询（行 9653–9655 + 典型案例）

> **咨询申请** = 申请中包括要求行政机关回答：
> - "**合法性依据**"
> - "**事实根据**"
> - "**办理进度**"
> - "**是否合法**"
> - "**做出某一行为的理由**"
> - 或要求行政机关进行**指导 / 解释 / 作指引**
>
> 行政机关针对**咨询申请**作出的答复以及**不予答复行为** → **不属于政府信息公开行为** → 起诉人**缺乏诉的利益 → 无原告资格** → 法院**可以不予立案**。

**典型案例**：**孙长荣诉吉林省人民政府行政复议不予受理决定案**（《最高人民法院公报》2016 年第 12 期 / 最高人民法院 / (2015)行提字第 19 号）。

> 裁判要旨：**行政机关针对咨询申请作出的答复以及不予答复行为，不属于政府信息公开行为**，**不会对咨询人的权利义务产生实际影响** → **不属于行政复议的受理范围** → 起诉人**缺乏诉的利益 → 无原告资格** → 法院可以**不予受理或裁定驳回起诉**。

## 三、实务问答（FAQ）

> **Q1: 4 类一般不予受理？**
> 答：被告不适格 / 超期 / 缺原告资格 / 不属管辖（行 9611–9613）。

> **Q2: 补正告知 4 情形？**
> 答：补正后/拒绝补正+答复/未补正+不答复+补正期满/期限未届满 4 种（行 9633–9635）。

> **Q3: 公开出版物拒绝？**
> 答：**法院不予立案**（公报/报纸/杂志/书籍等）（行 9635）。

> **Q4: 加工汇总要求？**
> 答：明确拒绝 → 法院**可裁定不予立案**；但行政机关**以其他理由作实体答复** → **应当立案**（行 9637–9639）。

> **Q5: 查阅案卷材料？**
> 答：告知**按相关法律、法规规定办理** → 法院**不予立案**（行 9641）。

> **Q6: 信访信息受理？**
> 答：法院可适用《行诉解释》第六十九条第八项**不予立案**；**形式上可识别**的信访信息（行 9643–9645）。

> **Q7: 行政复议信息？**
> 答：**不属于政府信息公开条例调整** → **不予立案**（行 9647）。

> **Q8: 涉诉信息 3 种例外？**
> 答：行政管理形成 / 准予执行 / **超越裁定侵权不视为延续**（行 9649–9651）。

> **Q9: 咨询 5 关键词？**
> 答：合法性依据/事实根据/办理进度/是否合法/行为理由（行 9653）。
