# 《纪检监察办案程序一本通》第四章 案件审理

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第四章 案件审理 |
| 行号范围 | 5539-8787（书籍）|
| 核心议题 | 自办/报批/备案案件审理+法法衔接 |
| 涵盖 | 3 类案件审理+重点疑难 |

## 🎯 核心论点

**案件审理 = 3 类案件 + 5 步流程 + 法法衔接**

**3 类案件**：
- **自办案件**：本级纪检监察机关立案审查调查
- **报批案件**：下级立案但需报上级审批
- **备案案件**：本级处分后报上级备案

**5 步审理流程**：
1. 案件受理
2. 案件审理（提前介入/阅卷/退回/谈话/审议）
3. 审议报批
4. 法法衔接（程序衔接）
5. 备案/报批

---

## 第一节 自办案件的审理

## 一、案件受理

**受理范围**：本级纪检监察机关立案审查调查的案件

**受理条件**：
- 属于本级管辖
- 立案手续完备
- 案卷材料齐全

## 二、案件审理

### （一）提前介入审理

**适用**：重大、复杂、疑难案件

**方式**：审理部门提前介入审查调查

**作用**：
- 提前发现问题
- 减少退查次数
- 提高审理效率

### （二）阅卷审核

仔细审阅卷宗材料：
- **程序是否合法**
- **事实是否清楚**
- **证据是否充分**
- **定性是否准确**
- **处理建议是否恰当**

### （三）退回审查调查

**退回情形**：
- 事实不清
- 证据不足
- 程序违法
- 遗漏违纪违法事实

### （四）审理谈话

**目的**：与被审查调查人谈话，听取其意见

**要求**：
- 认真听取陈述和申辩
- 做好记录
- 申辩合理的，采纳

### （五）室务会集体审议

审理部门集体讨论案件

## 三、审议报批

### （一）纪委常委会会议审议

**集体讨论决定**

### （二）征求有关党组织意见

对涉及党委管理的党员，需征求其所在党组织的意见

### （三）党委常委会审批

需同级党委常委会审批的案件

## 四、法法衔接程序

| 环节 | 内涵 |
|------|------|
| **检察机关提前介入** | 重大复杂案件可商请检察机关提前介入 |
| **商请指定管辖** | 监察机关商请同级检察机关指定管辖 |
| **移送审查起诉** | 涉嫌职务犯罪的案件移送检察机关审查起诉 |
| **提出从宽处罚建议** | 监察机关可在移送时提出从宽处罚建议 |
| **检察机关退回补充调查** | 案件需要补充证据的退回监察机关补充调查 |

---

## 第二节 报批案件的审理

## 一、案件范围

下级纪检监察机关立案审查调查，但需报上级审批的案件

## 二、办理程序

**三级流程**：
1. 下级审理
2. 报上级审理
3. 报同级党委审批

**重点**：
- 保留原卷宗
- 增加上级审理意见
- 按层级报批

---

## 第三节 备案案件的审理

## 一、案件范围

本级纪检监察机关作出处分决定后报上级备案的案件

## 二、办理程序

**两级流程**：
1. 审理
2. 备案

**备案审查**：
- 上级发现问题的，可以要求纠正
- 不直接改变处分决定

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **自办案件** | 本级纪检监察机关立案审查调查的案件 |
| **报批案件** | 下级立案但需报上级审批的案件 |
| **备案案件** | 本级处分后报上级备案的案件 |
| **提前介入审理** | 重大复杂案件审理部门提前介入 |
| **法法衔接** | 监察与司法的程序衔接 |
| **移送审查起诉** | 涉嫌职务犯罪案件移送检察机关 |
| **从宽处罚建议** | 监察机关可提出的量刑建议 |
| **退回补充调查** | 检察机关退回监察机关补充证据 |
| **互涉案件** | 涉及不同级别或地区监督对象的案件 |
| **指定管辖** | 上级指定某一机关管辖 |
| **室务会** | 审理部门的集体审议会议 |
