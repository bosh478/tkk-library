## 内容定位

本卷是物权卷第三册，围绕《民法典》第386条（2021-01-01 施行 / 2021-01-01 最新修正）至第462条，涵盖担保物权全部内容（抵押权、质权、留置权）和占有制度。担保物权是物权编的重要组成部分，对保障债权实现、促进资金融通具有重要意义。

## 章节结构总览

### 第四分编 担保物权

#### 第十六章 一般规定（第386-393条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第386条 | 担保物权的概念 | 担保物权人在债务人不履行到期债务或发生约定情形时，依法享有就担保财产优先受偿的权利 |
| 第387条 | 适用范围和反担保 | 债务人或第三人为担保债务履行可设定担保物权；第三人为担保的可以要求债务人提供反担保 |
| 第388条 | 担保合同 | 设立担保物权应订立担保合同；担保合同是主债权债务合同的从合同 |
| 第389条 | 担保范围 | 包括主债权及其利息、违约金、损害赔偿金、保管担保财产和实现担保物权的费用 |
| 第390条 | 物上代位性 | 担保期间担保财产毁损、灭失或被征收的，担保物权人可就保险金、赔偿金或补偿金等优先受偿 |
| 第391条 | 债务转移 | 第三人提供担保未经其书面同意转移债务的，担保人不再承担担保责任 |
| 第392条 | 人保与物保并存 | 被担保的既有物的担保又有人的担保的，债务人不履行到期债务时按约定实现债权；没有约定的，债务人自己提供物的担保的，债权人应先就该物的担保实现债权 |
| 第393条 | 担保物权消灭原因 | 主债权消灭；担保物权实现；债权人放弃担保物权等 |

#### 第十七章 抵押权（第394-427条）

**第一节 一般抵押权（第394-419条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第394条 | 抵押权的概念 | 为担保债务履行，债务人或第三人不转移财产占有，将财产抵押给债权人 |
| 第395条 | 可抵押财产 | 建筑物和其他土地附着物；建设用地使用权；海域使用权；生产设备、原材料、半成品、产品；正在建造的建筑物、船舶、航空器；交通运输工具等 |
| 第396条 | 浮动抵押 | 企业、个体工商户、农业生产经营者可将现有及将有的生产设备、原材料、半成品、产品抵押 |
| 第397条 | 建筑物与建设用地使用权同时抵押 | 以建筑物抵押的，该建筑物占用范围内的建设用地使用权一并抵押 |
| 第398条 | 乡镇、村企业建设用地使用权抵押限制 | 乡镇、村企业的建设用地使用权不得单独抵押 |
| 第399条 | 禁止抵押的财产 | 土地所有权；宅基地、自留地等集体所有土地的使用权（法律规定可以抵押的除外）；学校、幼儿园等公益设施；所有权或使用权不明或有争议的财产等 |
| 第400条 | 抵押合同 | 应采用书面形式 |
| 第401条 | 流押禁止 | 抵押权人在债务履行期限届满前，不得与抵押人约定债务人不履行到期债务时抵押财产归债权人所有 |
| 第402条 | 不动产抵押登记 | 以不动产抵押的应办理抵押登记，抵押权自登记时设立 |
| 第403条 | 动产抵押效力 | 以动产抵押的，抵押权自抵押合同生效时设立；未经登记不得对抗善意第三人 |
| 第404条 | 动产抵押权对抗效力的限制 | 以动产抵押的，不得对抗正常经营活动中已支付合理价款并取得抵押财产的买受人 |
| 第405条 | 抵押权与租赁权的关系 | 抵押前已出租并转移占有的，原租赁关系不受抵押权影响 |
| 第406条 | 抵押财产的转让 | 抵押期间抵押人可转让抵押财产；抵押权不受影响 |
| 第407条 | 抵押权的从属性 | 抵押权不得与债权分离而单独转让或作为其他债权的担保 |
| 第408条 | 抵押权的保护 | 抵押人的行为足以使抵押财产价值减少的，抵押权人有权请求恢复价值或提供相应担保 |
| 第409条 | 抵押权及其顺位的处分 | 抵押权人可以放弃抵押权或抵押权的顺位 |
| 第410条 | 抵押权的实现 | 债务人不履行到期债务或发生约定情形时，抵押权人可与抵押人协议以抵押财产折价或以拍卖、变卖所得价款优先受偿 |
| 第411条 | 浮动抵押财产的确定 | 债务履行期届满债权未实现等情形下，抵押财产确定 |
| 第412条 | 抵押权对孳息的效力 | 债务人不履行到期债务或约定情形致使抵押财产被法院扣押的，自扣押之日起抵押权人有权收取该抵押财产的天然孳息或法定孳息 |
| 第413条 | 抵押财产变价后的处理 | 超过债权数额的部分归抵押人所有，不足部分由债务人清偿 |
| 第414条 | 数个抵押权的清偿顺序 | 登记的优先于未登记的；都登记的按登记先后；都未登记的按债权比例 |
| 第415条 | 抵押权与质权的清偿顺序 | 同一财产既设立抵押权又设立质权的，拍卖、变卖所得价款按登记、交付的时间先后确定清偿顺序 |
| 第416条 | 购买价款抵押担保的优先权 | 动产抵押担保的主债权是抵押物的价款的，该抵押权人优先于其他担保物权人受偿 |
| 第417条 | 抵押权对新增建筑物的效力 | 建设用地使用权抵押后，该土地上新增的建筑物不属于抵押财产 |
| 第418条 | 集体所有土地使用权抵押权的实现 | 实现抵押权后不得改变土地所有权的性质和用途 |
| 第419条 | 抵押权存续期间 | 抵押权人应在主债权诉讼时效期间行使抵押权 |

**第二节 最高额抵押权（第420-424条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第420条 | 最高额抵押权的概念 | 为担保债务履行，债务人或第三人对一定期间内将要连续发生的债权提供担保 |
| 第421条 | 债权转让 | 最高额抵押担保的债权确定前，部分债权转让的，最高额抵押权不得转让 |
| 第422条 | 合同内容变更 | 最高额抵押担保的债权确定前，抵押权人与抵押人可协议变更债权确定的期间、债权范围等 |
| 第423条 | 债权确定 | 约定的债权确定期间届满、新的债权不可能发生、抵押财产被查封扣押等情形 |
| 第424条 | 法律适用 | 最高额抵押权除适用特别规定外，适用一般抵押权的规定 |

#### 第十八章 质权（第425-446条）

**第一节 动产质权（第425-439条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第425条 | 动产质权的概念 | 为担保债务履行，债务人或第三人将其动产出质给债权人占有 |
| 第426条 | 禁止出质的动产 | 法律、行政法规禁止转让的动产不得出质 |
| 第427条 | 质押合同 | 应采用书面形式 |
| 第428条 | 流质禁止 | 质权人在债务履行期限届满前不得与出质人约定债务人不履行到期债务时质押财产归债权人所有 |
| 第429条 | 质权的设立 | 质权自出质人交付质押财产时设立 |
| 第430条 | 孳息收取 | 质权人有权收取质押财产的孳息 |
| 第431条 | 质权人的保管义务 | 质权人应妥善保管质押财产 |
| 第432条 | 质权人的赔偿责任 | 因保管不善致使质押财产毁损灭失的应承担赔偿责任 |
| 第433条 | 质权的保护 | 质押财产毁损或价值减少的，质权人有权请求恢复价值或提供相应担保 |
| 第434条 | 转质 | 质权人在质权存续期间未经出质人同意转质的，造成质押财产毁损灭失的应承担赔偿责任 |
| 第435条 | 质权人放弃质权 | 出质人可以请求质权人返还质押财产 |
| 第436条 | 质权的实现 | 债务人不履行到期债务或约定情形时，质权人可与出质人协议以质押财产折价或拍卖变卖 |
| 第437条 | 出质人请求质权人及时行使质权 | 出质人可请求质权人在债务履行期届满后及时行使质权 |
| 第438条 | 质押财产变价后的处理 | 超过债权数额的部分归出质人所有 |
| 第439条 | 最高额质权 | 出质人与质权人可以协议设立最高额质权 |

**第二节 权利质权（第440-446条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第440条 | 可出质的权利 | 汇票、本票、支票；债券、存款单；仓单、提单；可以转让的基金份额、股权；可以转让的注册商标专用权、专利权、著作权等知识产权中的财产权；现有的以及将有的应收账款等 |
| 第441条 | 权利质权的设立 | 以汇票等出质的，质权自权利凭证交付时设立；没有权利凭证的，自办理出质登记时设立 |
| 第442条 | 基金份额、股权质权 | 以基金份额、股权出质的，质权自办理出质登记时设立 |
| 第443条 | 知识产权质权 | 以注册商标专用权、专利权等出质的，质权自办理出质登记时设立 |
| 第444条 | 应收账款质权 | 以应收账款出质的，质权自办理出质登记时设立 |
| 第445条 | 权利质权的转让限制 | 出质人不得转让已出质的权利（经质权人同意的除外） |
| 第446条 | 法律适用 | 权利质权除适用特别规定外，适用动产质权的规定 |

#### 第十九章 留置权（第447-457条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第447条 | 留置权的概念 | 债务人不履行到期债务，债权人可以留置已合法占有的债务人的动产 |
| 第448条 | 留置财产与债权的关系 | 债权人留置的动产应与债权属于同一法律关系（企业之间留置除外） |
| 第449条 | 不得留置的情形 | 法律规定或当事人约定不得留置的动产不得留置 |
| 第450条 | 留置财产的保管 | 留置权人应妥善保管留置财产 |
| 第451条 | 孳息收取 | 留置权人有权收取留置财产的孳息 |
| 第452条 | 留置权的实现 | 债务人逾期未履行的，留置权人可与债务人协议以留置财产折价或拍卖变卖 |
| 第453条 | 留置权实现的宽限期 | 应给债务人六十日以上的履行债务期间（鲜活易腐等不易保管的动产除外） |
| 第454条 | 留置财产变价后的处理 | 超过债权数额的部分归债务人所有 |
| 第455条 | 留置权优先于抵押权和质权 | 同一动产上已设立抵押权或质权，该动产又被留置的，留置权人优先受偿 |
| 第456条 | 留置权消灭 | 留置权人对留置财产丧失占有或接受债务人另行提供担保的，留置权消灭 |
| 第457条 | 法律适用 | 留置权除适用特别规定外，适用担保物权的一般规定 |

### 第五分编 占有（第458-462条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第458条 | 占有的定义 | 基于合同关系等产生的占有，有关不动产或动产的使用、收益、违约责任等按合同约定 |
| 第459条 | 占有人的损害赔偿责任 | 占有人因使用占有的不动产或动产致使该不动产或动产受到损害的，恶意占有人应承担赔偿责任 |
| 第460条 | 占有物的返还 | 不动产或动产被占有人占有的，权利人可请求返还原物及其孳息 |
| 第461条 | 占有人的费用偿还请求权 | 占有人因维护不动产或动产支出的必要费用，权利人应偿还 |
| 第462条 | 占有的保护 | 占有的不动产或动产被侵占的，占有人有权请求返还原物；对妨害占有的行为，占有人有权请求排除妨害或消除危险 |

## 核心制度解读

### 一、担保物权体系（第386-462条）

**三种担保物权**：抵押权（不转移占有）、质权（转移占有）、留置权（法定担保）。

**担保物权的从属性**（第388条）：担保合同是主债权债务合同的从合同。主债权债务合同无效的，担保合同无效（法律另有规定的除外）。

### 二、抵押权制度的重大变化

**流押禁止的放松**（第401条）：抵押权人在债务履行期限届满前，不得与抵押人约定债务人不履行到期债务时抵押财产归债权人所有。但可以在债务履行期届满后以抵押财产折价。

**抵押财产转让规则**（第406条）：抵押期间抵押人可以转让抵押财产，抵押权不受影响。这与原《物权法》第191条（需经抵押权人同意）有重大变化。

**购买价款抵押担保的超级优先权**（第416条）：动产抵押担保的主债权是抵押物的价款的，该抵押权人优先于其他担保物权人受偿。

### 三、留置权优先规则（第455条）

**优先顺序**：同一动产上已设立抵押权或质权，该动产又被留置的，留置权人优先受偿。这体现了留置权的法定担保性质和对劳动价值的保护。

## ❓ 常见问题

> 问：抵押期间抵押人能否转让抵押财产？
> 答：可以。抵押期间抵押人可以转让抵押财产，抵押权不受影响（第406条）。当事人另有约定的按约定。

> 问：留置权与抵押权、质权的优先顺序是什么？
> 答：同一动产上已设立抵押权或质权，该动产又被留置的，留置权人优先受偿（第455条）。

> 问：什么是浮动抵押？
> 答：企业、个体工商户、农业生产经营者可以将现有的以及将有的生产设备、原材料、半成品、产品抵押（第396条）。浮动抵押的特点是抵押财产在抵押期间处于变动状态。

> 问：最高额抵押权的债权何时确定？
> 答：约定的债权确定期间届满、新的债权不可能发生、抵押财产被查封扣押、债务人或抵押人被宣告破产等情形（第423条）。
