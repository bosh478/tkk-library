# 民法典合同编第二章【合同的订立】综合

## 章节目录

本章共 33 条（Articles 469-501），是合同编通则中条文最多的章节，规定合同订立的全过程：**合同订立方式（要约-承诺）+ 格式条款 + 特殊合同（预约合同、悬赏广告）+ 缔约过失责任**。

| 节 | 法条范围 | 主题 |
|----|---------|------|
| 第一节 合同订立方式 | 469-501 | 要约、承诺、合同成立 |
| 第二节 格式条款 | 496-498 | 格式条款规则 |
| 第三节 预约合同 | 495 | 预约合同效力 |
| 第四节 悬赏广告 | 499 | 悬赏广告效力 |
| 第五节 缔约过失责任 | 500-501 | 缔约过失责任 |

## 一、合同订立的形式（第469条）

### 法条原文

> 第四百六十九条　当事人订立合同，可以采用书面形式、口头形式或者其他形式。
>
> 书面形式是合同书、信件、电报、电传、传真等可以有形地表现所载内容的形式。
>
> 以电子数据交换、电子邮件等方式能够有形地表现所载内容，并可以随时调取查用的数据电文，视为书面形式。

### 合同订立的三种形式

| 形式 | 内容 | 适用 |
|------|------|------|
| **书面形式** | 合同书、信件、电报、电传、传真、数据电文 | 法律特别要求 + 重要交易 |
| **口头形式** | 当面或电话交谈 | 即时清结的小额交易 |
| **其他形式** | 默示、行为推定等 | 交易习惯允许时 |

### 书面形式的特殊规定

**数据电文视为书面形式**（第469条第3款）：
- 电子数据交换（EDI）
- 电子邮件
- 其他能够有形表现 + 随时调取查用的形式

**电子合同成立**（第491条）：当事人约定通过电子签名等方式签订合同的，**电子签名生效时合同成立**。

### 法律要求书面形式的典型情形

| 情形 | 法律依据 |
|------|---------|
| 融资租赁合同 | 第736条 |
| 建设工程合同 | 第470条 + 第789条 |
| 建设工程施工合同 | 第789条 |
| 定期租船合同 | 《海商法》 |
| 抵押合同 | 第400条 |
| 质押合同 | 第427条 |

## 二、要约制度（第472-478条）

### 要约的概念及构成要件（第472条）

> 第四百七十二条　要约是希望与他人订立合同的意思表示，该意思表示应当符合下列条件：
> （一）内容具体确定；
> （二）表明经受要约人承诺，要约人即受该意思表示约束。

### 要约 vs 要约邀请

| 维度 | 要约 | 要约邀请 |
|------|------|---------|
| **含义** | 希望与他人订立合同的意思表示 | 希望他人向自己发出要约的意思表示 |
| **法律性质** | **民事法律行为** | 事实行为/意思通知 |
| **约束力** | 受要约人承诺即受约束 | 不受承诺约束 |
| **法律效果** | 承诺到达时合同成立 | 不直接导致合同成立 |

### 典型要约邀请情形（第473条）

- 寄送的价目表
- 拍卖公告
- 招标公告
- 招股说明书
- 商业广告（**符合要约条件的除外**）

### 要约的生效、撤回、撤销、失效

| 制度 | 法条 | 核心规则 |
|------|------|---------|
| **要约生效** | 第474条 | **到达主义**（要约到达受要约人时生效） |
| **要约撤回** | 第475条 | 要约人可以撤回要约；撤回要约的通知应当在要约到达受要约人之前或者同时到达受要约人 |
| **要约撤销** | 第476条 | 要约人可以撤销要约；撤销要约的通知应当在受要约人发出承诺通知之前到达受要约人 |
| **要约失效** | 第478条 | ① 拒绝要约的通知到达要约人；② 要约人依法撤销要约；③ 承诺期限届满，受要约人未作出承诺；④ 受要约人对要约内容作出实质性变更 |

### 不可撤销的要约（第476条第2款）

下列要约**不得撤销**：
1. 要约人**确定承诺期限**或者其他形式表明要约不可撤销
2. 受要约人有理由认为要约不可撤销，并已经为履行合同作了准备工作

## 三、承诺制度（第479-489条）

### 承诺的概念（第479条）

> 第四百七十九条　承诺是受要约人同意要约的意思表示。

### 承诺的方式（第480条）

- **方式**：承诺应当以**通知**的方式作出
- **例外**：根据交易习惯或者要约表明**可以通过行为**作出承诺的除外

### 承诺的期限（第481条）

- 要约**确定承诺期限**的，承诺应当在**确定的期限内**到达要约人
- 要约**未确定承诺期限**的：
  - 对话方式作出的 → 受要约人**即时**承诺
  - 非对话方式作出的 → 在**合理期限内**承诺

### 合同成立时间（第483条）

- **承诺生效时**合同成立
- 当事人**采用合同书形式**订立合同的，**最后一方签字或盖章**时合同成立
- 当事人**采用信件、数据电文等形式**订立合同的，**最后一方履行主要义务**时合同成立（实务规则）

### 承诺的撤回（第485条）

- 承诺可以撤回
- 撤回承诺的通知**应当在承诺通知到达要约人之前或者与承诺通知同时到达**要约人

### 承诺逾期（第486-487条）

| 情形 | 处理 |
|------|------|
| 受要约人**超过承诺期限**发出承诺 | 除要约人**及时通知**受要约人该承诺有效的以外，为**新要约** |
| 受要约人在承诺期限内发出承诺，**因其他原因**逾期的 | 除要约人**及时通知**受要约人因承诺超过期限不接受该承诺的以外，该承诺**有效** |

### 承诺对要约的变更（第488-489条）

| 变更类型 | 处理 |
|---------|------|
| **实质性变更**（合同标的、数量、质量、价款、履行期限、履行地点和方式、违约责任、解决争议方法等） | 视为**新要约** |
| **非实质性变更** | 承诺有效；要约人**及时表示反对**或者要约表明承诺不得对要约内容作出任何变更的除外 |

## 四、合同成立时间与地点（第490-492条）

### 合同成立时间（第490条）

| 订立方式 | 合同成立时点 |
|---------|------------|
| 合同书形式 | **最后一方签字或盖章** |
| 信件、数据电文 | **最后一方履行主要义务**（实务规则） |
| 实际履行 | 一方**履行主要义务**，对方**接受**时 |
| 法律、行政法规要求办理批准等手续 | **手续完成时** |

### 合同成立地点（第492条）

| 订立方式 | 合同成立地点 |
|---------|------------|
| 合同书形式 | **最后一方签字或盖章**的地点 |
| 数据电文 | 收件人的**主营业地**；没有主营业地的，**经常居住地** |
| 书面合同未载明履行地点 | 不影响合同成立 |

## 五、数据电文与电子合同（第491条）

> 第四百九十一条　当事人约定采用电子数据交换、电子邮件等方式订立合同的，**电子签名生效时合同成立**。

### 电子合同的成立

| 订立方式 | 合同成立时点 |
|---------|------------|
| 电子签名约定 | **电子签名生效**时 |
| 通过电子信息网络销售商品 | 双方**主要权利义务关系建立**时 |

### 电子签名的法律效力

依《电子签名法》第13-14条：
- 可靠的电子签名与手写签名或者盖章具有同等的法律效力
- "可靠的电子签名"需满足：① 签名专属于电子签名人；② 签署时电子签名制作数据仅由电子签名人控制；③ 签署后对电子签名的任何改动能够被发现；④ 签署后对数据电文内容和形式的任何改动能够被发现

## 六、强制缔约（第494条）

### 法条原文

> 第四百九十四条　国家根据抢险救灾、疫情防控或者其他需要下达国家订货任务、指令性任务的，有关民事主体之间应当依照有关法律、行政法规规定的权利和义务订立合同。

### 强制缔约的情形

| 情形 | 法律依据 |
|------|---------|
| **国家订货任务** | 抢险救灾、疫情防控等需要 |
| **指令性任务** | 国家下达的指令性任务 |
| **公共事业服务** | 供水、供电、供气、邮政、电信等公共服务提供者（学理） |
| **医疗救治** | 医疗机构不得拒绝急救患者（法律义务） |

## 七、预约合同（第495条）

### 法条原文

> 第四百九十五条　当事人约定在将来一定期限内订立合同的认购书、订购书、预订书等，构成预约合同。
>
> 当事人一方不履行预约合同约定的订立合同义务的，对方可以请求其承担预约合同的违约责任。

### 预约合同的特征

| 特征 | 内容 |
|------|------|
| **合同标的** | **将来订立本约合同的义务** |
| **法律效力** | 违约方应承担**预约合同违约责任**（不是本约合同的违约责任） |
| **违约救济** | 守约方可以请求违约方承担违约责任（不强制订立本约） |

### 预约合同 vs 本约合同

| 维度 | 预约合同 | 本约合同 |
|------|---------|---------|
| **义务** | 订立本约的义务 | 履行本约的义务 |
| **标的** | 将来订立的本约合同 | 具体的合同权利义务 |
| **违约责任** | 预约合同违约责任 | 本约合同违约责任 |

## 八、格式条款制度（第496-498条）

### 格式条款的概念（第496条第1款）

> 格式条款是当事人为了重复使用而预先拟定，并在订立合同时未与对方协商的条款。

### 提供方的提示说明义务（第496条第2款）

> 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则**明确告知**对方免除或者减轻其责任等与对方有重大利害关系的条款，并按照对方的要求予以说明。

**提示说明义务的要点**：
- **遵循公平原则**
- **明确告知**与对方有**重大利害关系**的条款
- **按照对方要求予以说明**
- **违反后果**：对方可以主张该条款**不成为合同内容**

### 格式条款无效（第497条）

> 第四百九十七条　有下列情形之一的，该格式条款无效：
> （一）**具有本法第一编第六章第三节和本法第五百零六条规定的无效情形**；
> （二）**提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利**；
> （三）**提供格式条款一方排除对方主要权利**。

**格式条款无效的三种情形**：

| 情形 | 法律依据 |
|------|---------|
| **情形1** | 第1编第6章第3节（民事法律行为效力瑕疵）+ 第506条（免责条款无效） |
| **情形2** | 不合理地免除/减轻提供方责任、加重对方责任、限制对方主要权利 |
| **情形3** | 排除对方主要权利 |

### 格式条款解释规则（第498条）

> 第四百九十八条　对格式条款的理解发生争议的，应当**按照通常理解**予以解释。对格式条款有两种以上解释的，应当作出**不利于提供格式条款一方的解释**。
>
> 格式条款和非格式条款不一致的，应当**采用非格式条款**。

**格式条款的解释三步法**：
1. 按照**通常理解**解释（与一般合同解释相同）
2. 有两种以上解释的，作出**不利于提供方**的解释
3. 格式条款与**非格式条款不一致**的，采用**非格式条款**

## 九、悬赏广告（第499条）

### 法条原文

> 第四百九十九条　悬赏人以公开方式声明对完成特定行为的人支付报酬的，完成该行为的人可以请求其支付。

### 悬赏广告的法律性质

**学理争议**：
| 学说 | 内容 |
|------|------|
| **要约说** | 悬赏广告是**要约**，行为人完成特定行为即构成承诺 |
| **单独行为说** | 悬赏广告是**单方民事法律行为**，行为人完成特定行为即发生效力 |

**实务立场**：最高人民法院采**单独行为说**——悬赏广告是单方法律行为，**不需行为人承诺**，完成特定行为即发生效力，行为人可以请求报酬。

### 悬赏广告的成立要件

| 要件 | 内容 |
|------|------|
| **公开方式** | 公开声明（电视、报纸、网络等） |
| **特定行为** | 行为人完成特定行为 |
| **报酬支付** | 悬赏人有支付报酬的义务 |

## 十、缔约过失责任（第500-501条）

### 缔约过失责任的概念（第500条）

> 第四百条　当事人在订立合同过程中有下列情形之一，造成对方损失的，应当承担赔偿责任：
> （一）假借订立合同，恶意进行磋商；
> （二）故意隐瞒与订立合同有关的重要事实或者提供虚假情况；
> （三）有其他违背诚信原则的行为。

### 缔约过失责任的三种情形

| 情形 | 内容 |
|------|------|
| **1. 假借订立合同恶意磋商** | 没有订立合同的真实意思，恶意进行磋商 |
| **2. 故意隐瞒/提供虚假情况** | 故意隐瞒与订立合同有关的重要事实或者提供虚假情况 |
| **3. 其他违背诚信原则** | 违背诚信原则的其他行为 |

### 缔约过失责任的法律特征

| 特征 | 内容 |
|------|------|
| **发生阶段** | 合同**订立过程中**（合同未成立或无效） |
| **主观状态** | 行为人有**过错**（故意或过失） |
| **损害事实** | 对方因合同未成立/无效而**遭受损失** |
| **因果关系** | 损失由缔约过失行为引起 |
| **法律基础** | **诚实信用原则** |

### 缔约过失 vs 违约责任

| 维度 | 缔约过失责任 | 违约责任 |
|------|------------|---------|
| **发生阶段** | 合同订立过程 | 合同成立后 |
| **前提** | 合同未成立或无效 | 合同有效成立 |
| **归责原则** | 过错责任 | 严格责任（一般） |
| **赔偿范围** | 信赖利益损失 | 履行利益损失 |
| **法律基础** | 诚信原则 | 合同义务 |

### 保密义务（第501条）

> 第五百零一条　当事人在订立合同过程中知悉的商业秘密或者其他应当保密的信息，无论合同是否成立，不得泄露或者不正当地使用；泄露、不正当地使用该商业秘密或者信息，造成对方损失的，应当承担赔偿责任。

**保密义务的特征**：
- 适用于**订立合同过程**中知悉的信息
- 无论合同是否成立，**均不得泄露**或**不正当使用**
- 违反造成的损失应当**赔偿**

### 保密义务的范围

| 类型 | 是否受保护 |
|------|----------|
| **商业秘密**（不为公众知悉 + 商业价值 + 保密措施） | ✅ 受保护 |
| **其他应当保密的信息**（如对方的报价、谈判策略等） | ✅ 受保护 |
| **公开信息** | ❌ 不受保护 |

## ❓ 实务问答精选

> **问**：要约与要约邀请如何区分？
>
> **答**：**关键看内容具体确定性和约束力意思表示**。
> - **要约**：内容具体确定 + 表明受要约人承诺即受约束 → 承诺到达合同成立
> - **要约邀请**：内容不具体确定或无约束意思表示 → 不导致合同成立
>
> **典型要约邀请**：寄送价目表、拍卖公告、招标公告、招股说明书。**商业广告**：原则上是要约邀请，但**符合要约条件**的视为要约。

> **问**：要约的生效时点是什么？
>
> **答**：**到达主义**。第474条规定，要约**到达受要约人时生效**。与英美法的"发送主义"不同，**到达时**才生效，撤回通知须在要约到达前或同时到达。

> **问**：承诺对要约内容的实质性变更如何处理？
>
> **答**：视为**新要约**。第488条规定，承诺对要约内容作出**实质性变更**的（合同标的、数量、质量、价款、履行期限、履行地点和方式、违约责任、解决争议方法等），该承诺**不发生承诺的效力**，**视为新要约**。

> **问**：格式条款被认定无效后，合同其他条款是否受影响？
>
> **答**：**不影响**。第497条规定的格式条款无效情形仅涉及**该格式条款本身**无效，不影响合同其他条款的效力。合同其他部分仍然有效。

> **问**：缔约过失责任与违约责任的核心区别？
>
> **答**：
> - **缔约过失责任**：发生在**合同订立过程**，合同未成立或无效；以**过错责任**为基础；赔偿**信赖利益**损失
> - **违约责任**：发生在**合同成立后**；以**严格责任**为基础（一般）；赔偿**履行利益**损失
>
> **核心区别**：发生阶段（合同订立 vs 合同履行）+ 归责原则（过错 vs 严格）

> **问**：悬赏广告是要约还是单方行为？
>
> **答**：**单方行为说**（最高法立场）。悬赏广告是**单方民事法律行为**，不需要行为人"承诺"，完成特定行为即发生效力，行为人可以请求报酬。这与要约-承诺的合同成立机制不同。

> **问**：预约合同的违约责任如何承担？
>
> **答**：依第495条，预约合同违约方应承担**预约合同违约责任**，**不强制订立本约合同**。实务中的违约责任形式：
> - 继续履行（请求订立本约）
> - 损害赔偿（信赖利益损失）
> - 违约金（依预约合同约定）
