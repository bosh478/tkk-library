# 缓刑(《刑法》第 72-77 条 · L3)

> 本页定位:缓刑 L3 概念页。**总则第 4 章量刑制度**的核心制度,与累犯、假释、自首、立功紧密关联;**附条件不执行原判刑罚**的特殊制度。

## 一、法条原文(条文要点)

《刑法》第 72 条(缓刑适用条件):
> 对于被判处拘役、三年以下有期徒刑的犯罪分子,同时符合下列条件的,可以宣告缓刑;对其中不满十八周岁的人、怀孕的妇女和已满七十五周岁的人,应当宣告缓刑:
> (一)犯罪情节较轻;
> (二)有悔罪表现;
> (三)没有再犯罪的危险;
> (四)宣告缓刑对所居住社区没有重大不良影响。

《刑法》第 74 条(累犯不适用缓刑):
> 对于累犯和犯罪集团的首要分子,不适用缓刑。

《刑法》第 76 条(缓刑考验期满):
> 对宣告缓刑的犯罪分子,在缓刑考验期限内,依法实行社区矫正,如果没有本法第七十七条规定的情形,缓刑考验期满,原判的刑罚就不再执行,并公开予以宣告。

《刑法》第 77 条(缓刑撤销):
> 被宣告缓刑的犯罪分子,在缓刑考验期限内犯新罪或者发现判决宣告以前还有其他罪没有判决的,应当撤销缓刑,对新犯的罪或者新发现的罪作出判决,把前罪和后罪所判处的刑罚,依照本法第六十九条的规定,决定执行的刑罚。
> 被宣告缓刑的犯罪分子,在缓刑考验期限内,违反法律、行政法规或者国务院有关部门关于缓刑的监督管理规定,或者违反人民法院判决中的禁止令,情节严重的,应当撤销缓刑,执行原判刑罚。

## 二、段级释解

### 1. 概念界定

缓刑 = 对**判处 3 年以下有期徒刑或拘役**的犯罪分子,**附条件地暂缓执行原判刑罚**的制度。**核心是「不执行」而非「免除」**。

特征:
- **附条件**:必须满足法定条件 + 遵守考验期规定
- **暂缓执行**:原判刑罚**暂不执行**(不是不执行)
- **社区矫正**:考验期内依法实行社区矫正(《社区矫正法》)

### 2. 缓刑适用四构成要件(第 72 条)

(1) **刑种要件**:被判处**拘役或 3 年以下有期徒刑**(含 1 年以下 / 1-3 年)
- 3 年以上有期徒刑 → 不得缓刑
- 无期徒刑 / 死刑 → 不得缓刑

(2) **犯罪情节要件**:犯罪情节**较轻**
- 数额较小 / 后果较轻 / 主观恶性小

(3) **悔罪要件**:有**悔罪表现**
- 主动认罪 / 退赃退赔 / 赔偿损失 / 取得被害人谅解

(4) **人身危险性要件**:
- **没有再犯罪的危险**(人身危险性低)
- **宣告缓刑对所居住社区没有重大不良影响**

### 3. 应当缓刑(第 72 条第 2 款)

下列人员**应当**宣告缓刑(满足刑种 + 情节要件):
- **不满 18 周岁的人**
- **怀孕的妇女**
- **已满 75 周岁的人**

### 4. 禁止缓刑(第 74 条)

- **累犯**(无论一般累犯 + 特殊累犯)→ 不得缓刑
- **犯罪集团的首要分子** → 不得缓刑

### 5. 缓刑考验期(第 73 条)

按原判刑种确定:
- 拘役 → **2 个月以上 1 年以下**
- 有期徒刑:
  - 原判 ≤ 1 年 → **2 个月以上 1 年以下**
  - 原判 > 1 年 → **1 年以上 3 年以下**
  - 原判 = 3 年 → **1 年以上 3 年以下**(上限可至 3 年,但司法实践多为 2-3 年)

考验期**自判决确定之日起计算**。

### 6. 缓刑撤销情形(第 77 条)

(1) **再犯新罪**(考验期内犯新罪):
- 撤销缓刑 + 数罪并罚(第 69 条)
- 「新罪」:包括故意罪 + 过失罪

(2) **发现漏罪**(考验期内发现判决前未判决的罪):
- 撤销缓刑 + 数罪并罚(第 69 条)
- 与新罪区别:漏罪是判决宣告前已实施

(3) **违反监督管理规定情节严重**:
- 违反法律、行政法规或监督管理规定
- 违反人民法院判决中的**禁止令**
- 情节严重(司法认定)

### 7. 战时缓刑(第 449 条)

军人在战时:
- 适用第 72 条条件 + **战时**特定情形
- 允许戴罪立功(战时缓刑的特殊规定)

## 三、实务问答(FAQ)

Q1:缓刑与「免予刑事处罚」的区别?
- 缓刑:**判处**刑罚 + **暂不执行**(3 年以下有期徒刑/拘役)
- 免予刑事处罚:**不判处**刑罚(因犯罪情节轻微等)
- 两者均不留犯罪记录?否:**缓刑是犯罪记录**,免予刑事处罚通常不留(具体看情形)

Q2:判处 3 年以上有期徒刑能否缓刑?
**不能**。第 72 条刑种要件限定为拘役 + 3 年以下有期徒刑。

Q3:数罪并罚后决定执行刑期为 3 年,能否缓刑?
**理论上可以**,但司法实践**从严**。前提是数罪分别均符合缓刑条件 + 合并后仍在 3 年以下。

Q4:缓刑期间发现漏罪,如何处理?
撤销缓刑 + 数罪并罚(第 77 条第 1 款 + 第 69 条)。

Q5:缓刑期间再犯新罪,如何处理?
撤销缓刑 + 数罪并罚(第 77 条第 1 款 + 第 69 条)。

Q6:缓刑期满后再犯新罪,是否构成累犯?
**视情况**:
- 缓刑期满**未撤销** → 原判刑罚**不再执行**(第 76 条),等于未受刑事处罚,**不构成累犯**
- 缓刑**被撤销** → 已执行原判刑罚,**可能构成累犯**(符合累犯要件)

Q7:缓刑期内可否减刑?
**不能**。缓刑是**暂缓执行原判刑罚**,不存在「执行中」减刑问题。减刑是**假释 / 监禁执行期间**的制度。

Q8:缓刑期内能否被收监?
**可以**:
- 再犯新罪 / 发现漏罪 / 严重违反监督管理规定 → 撤销缓刑 + 收监执行原判刑罚

Q9:累犯前科能否影响缓刑?
**绝对不能**。第 74 条明确**累犯不得缓刑**,即使符合第 72 条全部要件。

Q10:战时缓刑(第 449 条)与普通缓刑的区别?
- 战时缓刑:**战时** + **军人** + **允许戴罪立功**
- 普通缓刑:平时 + 任何主体 + 不允许戴罪立功
- 战时缓刑不计入犯罪前科
