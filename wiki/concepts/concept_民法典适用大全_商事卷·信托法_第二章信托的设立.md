## 一、第6条·合法信托目的

### 法条原文

> 第六条　设立信托，必须有合法的信托目的。

### 核心释义

**信托目的的3项要求**：

| 要求 | 内容 |
|------|------|
| **确定性** | 信托目的应当明确，便于受托人清楚掌握其受托义务，也便于第三人准确无误地了解该信托的意思表示 |
| **自由性和多样性** | 在不违反法律、行政法规，不违背国家利益和社会公共利益的前提下，可为委托人所希望达到的各种目的 |
| **合法性** | 信托行为必须受到法律、行政法规的强制性规范的限制 |

**信托目的的分类**：

| 类型 | 内容 |
|------|------|
| 私益目的 - 自益信托 | 以委托人自已为唯一受益人 |
| 私益目的 - 他益信托 | 以他人为受益人或者以他人和委托人为共同受益人 |
| 公益目的 - 公益信托 | 为公众利益；只能是他益信托 |

**信托目的不合法的法律后果**（依《信托法》第11条）：

| 情形 | 后果 |
|------|------|
| 信托目的违反法律、行政法规或损害社会公共利益 | 信托无效 |
| 专以诉讼或讨债为目的设立信托 | 信托无效 |
| 设立信托损害债权人利益 | 可撤销（依第12条） |

## 二、第7条·确定、合法的信托财产

### 法条原文

> 第七条　设立信托，必须有确定的、合法的信托财产，并且该信托财产必须是委托人合法所有的财产。本法所称财产包括合法的财产权利。

### 核心释义

**信托财产的4项要求**：

| 要求 | 内容 |
|------|------|
| **确定性** | 财产应可以"确定"其金钱价值 |
| **现存性** | 委托人所确定的财产应当是其实际所有的财产；将来可能取得的财产不能作为信托财产 |
| **积极财产性** | 不能以债务等消极财产设立信托 |
| **合法性** | 委托人合法取得并占有的财产 |

**信托财产的范围**：

| 类别 | 内容 |
|------|------|
| 有形财产 | 现金、动产、不动产、有价证券 |
| 无形财产 | 商标专用权、专利权、著作权、股权、债权 |

**不得作为信托财产的范围**：

| 类别 | 内容 |
|------|------|
| 人格权 | 身份权、名誉权、姓名权（不能以金钱计算） |
| 消极财产 | 债务（不能产生积极收益） |
| 非委托人财产 | 委托人无处分权的财产（无权处分） |
| 专以诉讼权 | 委托人的诉讼权不得设定信托 |

**信托财产与委托人、受托人、受益人财产的关系**：

| 主体 | 关系 |
|------|------|
| 委托人 | 信托财产交付后，不再享有所有权 |
| 受托人 | 享有管理或处分权，但服从于信托目的 |
| 受益人 | 享有受益权（受益请求权），但无占有、使用、处分权 |

**信托财产的独立性**（依《九民会议纪要》第95条）：

> 信托财产在信托存续期间独立于委托人、受托人、受益人各自的固有财产。当事人因其与委托人、受托人或者受益人之间的纠纷申请对存管银行或者信托公司专门账户中的信托资金采取保全措施的，除符合《信托法》第17条规定的情形外，人民法院不应当准许。

### 典型案例

#### 世欣荣和投资管理股份有限公司与长安国际信托股份有限公司等信托合同纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2016）最高法民终19号 |
| 审理法院 | 最高人民法院 |
| 来源 | 《最高人民法院公报》2016年第12期 |
| 裁判要点 | （1）资金信托设立时，受托人因承诺信托而从委托人处取得的资金是信托财产；资金信托设立后，受托人管理运用、处分该资金而取得的财产也属于信托财产。（2）信托财产的确定体现为该财产明确且特定。信托财产的确定要求其从委托人的自有财产中隔离和指定出来，而且在数量和边界上应当明确。（3）当事人以信托财产上存在权利负担或者他人就该财产享有购买权益，主张信托无效的，不能成立 |

## 三、第8条·信托设立形式和成立要件

### 法条原文

> 第八条　设立信托，应当采取书面形式。
>
> 书面形式包括信托合同、遗嘱或者法律、行政法规规定的其他书面文件等。
>
> 采取信托合同形式设立信托的，信托合同签订时，信托成立。采取其他书面形式设立信托的，受托人承诺信托时，信托成立。

### 核心释义

**3种书面设立形式**：

| 形式 | 内容 | 信托成立时点 |
|------|------|------------|
| **信托合同** | 委托人与受托人签订的设立信托的协议 | 信托合同签订时 |
| **遗嘱** | 公民个人对身后各事作出的处理（包括遗嘱信托） | 受托人承诺信托时 |
| **其他书面文件** | 法律、行政法规规定的其他书面文件（如人民法院的判决等） | 受托人承诺信托时 |

**信托合同与遗嘱信托的对比**：

| 维度 | 信托合同 | 遗嘱信托 |
|------|---------|---------|
| 性质 | 双方法律行为 | 单方法律行为 |
| 受托人承诺 | 不需要（合同签订即生效） | 需要（受托人承诺时生效） |
| 设立主体的关系 | 双方协商一致 | 遗嘱人单方决定 |

**信托合同与普通合同的区别**：

| 维度 | 信托合同 | 普通合同 |
|------|---------|---------|
| 形式要求 | 要式合同（必须书面） | 一般为非要式 |
| 生效要件 | 合同签订 + 信托财产转移 | 合同成立生效 |
| 主体 | 三方（委托人、受托人、受益人） | 通常为两方 |

**信托成立的2种情况**：

| 情形 | 信托成立时点 |
|------|------------|
| 信托合同形式 | 信托合同签订时 |
| 其他书面形式 | 受托人承诺信托时 |

### 典型案例

#### 中国轻骑集团有限公司与华夏银行济南市高新支行、山东天源资产投资管理有限公司委托管理资金合同纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2003）民二终字第172号 |
| 审理法院 | 最高人民法院 |
| 裁判要点 | 华夏银行将其客户资金委托天源公司管理的行为，属于商业银行中间业务的**委托代理行为**，并不符合《信托法》关于信托目的、信托设定和信托合同等规定的要件，因此不属于从事信托投资业务的信托行为。《协议书》有效 |

## 四、第9条·信托文件必备条款

### 法条原文

> 第九条　设立信托，其书面文件应当载明下列事项：
>
> （一）信托目的；
>
> （二）委托人、受托人的姓名或者名称、住所；
>
> （三）受益人或者受益人范围；
>
> （四）信托财产的范围、种类及状况；
>
> （五）受益人取得信托利益的形式、方法。
>
> 除前款所列事项外，可以载明信托期限、信托财产的管理方法、受托人的报酬、新受托人的选任方式、信托终止事由等事项。

### 核心释义

**5项必备条款（强制性条款）**：

| 序号 | 条款 | 说明 |
|------|------|------|
| 1 | 信托目的 | 必须明确具体；决定信托当事人基本权利义务 |
| 2 | 委托人、受托人的姓名或者名称、住所 | 信托关系的重要主体 |
| 3 | 受益人或者受益人范围 | 必须指明；公益信托可以确定受益人范围 |
| 4 | 信托财产的范围、种类及状况 | 信托财产具有独立性；必须准确记载 |
| 5 | 受益人取得信托利益的形式、方法 | 实现信托目的的必要内容 |

**6项选择性条款**：

| 序号 | 条款 |
|------|------|
| 1 | 信托期限 |
| 2 | 信托财产的管理方法 |
| 3 | 受托人的报酬 |
| 4 | 新受托人的选任方式 |
| 5 | 信托终止事由 |
| 6 | 信托当事人约定的其他事项 |

**信托公司管理办法规定16项信托合同记载事项**：

| 序号 | 事项 |
|------|------|
| 1-5 | 同信托法第9条5项必备条款 |
| 6 | 信托当事人的权利义务 |
| 7 | 信托财产管理中风险的揭示和承担 |
| 8 | 信托财产的管理方式和受托人的经营权限 |
| 9 | 信托利益的计算，向受益人交付信托利益的形式、方法 |
| 10 | 信托公司报酬的计算及支付 |
| 11 | 信托财产税费的承担和其他费用的核算 |
| 12 | 信托期限和信托的终止 |
| 13 | 信托终止时信托财产的归属 |
| 14 | 信托事务的报告 |
| 15 | 信托当事人的违约责任及纠纷解决方式 |
| 16 | 新受托人的选任方式 |

## 五、第10条·信托登记

### 法条原文

> 第十条　设立信托，对于信托财产，有关法律、行政法规规定应当办理登记手续的，应当依法办理信托登记。
>
> 未依照前款规定办理信托登记的，应当补办登记手续；不补办的，该信托不产生效力。

### 核心释义

**信托登记的范围**：

| 类别 | 内容 |
|------|------|
| 应当登记的信托财产 | 法律、行政法规规定应当办理登记的（如不动产、知识产权、股权等） |
| 不需要登记的信托财产 | 货币、动产等（但需要交付） |

**未登记的法律后果**：

| 情形 | 后果 |
|------|------|
| 应当补办而补办的 | 该信托不产生效力 |
| 拒不补办的 | 该信托不产生效力 |

**信托登记的效力**：
- 信托登记是对抗第三人还是生效要件，要看具体法律、行政法规的规定
- 信托财产的登记应当遵循相关法律关于登记的规定

## 六、第11条·信托无效

### 法条原文

> 第十一条　有下列情形之一的，信托无效：
>
> （一）信托目的违反法律、行政法规或者损害社会公共利益；
>
> （二）信托财产不能确定；
>
> （三）委托人以非法的财产或者本法第七条规定不得设立信托的财产设立信托；
>
> （四）专以诉讼或者讨债为目的设立信托；
>
> （五）受益人或者受益人范围不能确定；
>
> （六）法律、行政法规规定的其他情形。

### 核心释义

**信托无效的6种情形**：

| 序号 | 情形 | 性质 |
|------|------|------|
| 1 | 信托目的违反法律、行政法规或者损害社会公共利益 | 目的违法 |
| 2 | 信托财产不能确定 | 客体不特定 |
| 3 | 委托人以非法的财产或不得设立信托的财产设立信托 | 财产违法 |
| 4 | 专以诉讼或者讨债为目的设立信托 | 目的不当 |
| 5 | 受益人或者受益人范围不能确定 | 主体不特定 |
| 6 | 法律、行政法规规定的其他情形 | 兜底条款 |

**信托无效的法律后果**：

| 后果 | 内容 |
|------|------|
| 信托自始无效 | 依《民法典》关于无效法律行为的规定 |
| 返还财产 | 信托财产应当返还 |
| 赔偿损失 | 过错方承担 |
| 折价补偿 | 不能返还或者没有必要返还的 |

### 典型案例

#### 北京天悦投资发展有限公司与安信信托股份有限公司等合同纠纷案

## 七、第12条·欺诈信托撤销

### 法条原文

> 第十二条　委托人设立信托损害其债权人利益的，债权人有权申请人民法院撤销该信托。
>
> 人民法院依照前款规定的撤销权，自债权人知道或者应当知道撤销事由之日起一年内行使。自信托发生之日起五年内没有行使撤销权的，撤销权消灭。
>
> 此款规定的五年期间为除斥期间，不适用诉讼时效中止、中断或者延长的规定。

### 核心释义

**撤销权的基本要素**：

| 要素 | 内容 |
|------|------|
| 撤销权人 | 债权人（因设立信托受到损害的） |
| 撤销对象 | 损害债权人利益的信托 |
| 撤销机关 | 人民法院（依债权人申请） |
| 撤销事由 | 委托人设立信托损害其债权人利益 |

**撤销权的双重时效**：

| 时效 | 期限 | 起算 | 性质 |
|------|------|------|------|
| **短期时效** | 1年 | 债权人知道/应当知道撤销事由之日起 | 短期时效 |
| **长期时效** | 5年 | 自信托发生之日起 | **除斥期间**，不中止/中断/延长 |

**欺诈信托的撤销与无效的区别**：

| 维度 | 欺诈信托撤销（第12条） | 信托无效（第11条） |
|------|------------------------|--------------------|
| 触发条件 | 设立信托损害债权人利益 | 多种法定无效情形 |
| 主张主体 | 债权人 | 任何利害关系人 |
| 主张方式 | 向人民法院申请 | 自动无效 / 主动主张 |
| 财产性质 | 委托人合法所有的财产 | 可能包括非法财产 |

## ⚠️ 司法适用难点

### 难点一：信托合同成立与信托成立的区分

**争议**：信托合同签订后，信托是否立即成立？

**主流观点**（依《信托法》第8条）：
- 信托合同签订时 → 信托合同成立
- 但信托的成立还需要：合法的信托目的 + 确定的、合法的信托财产
- 三者缺一不可，信托才能有效成立

### 难点二：信托财产的确定性判断

**争议**：信托财产"确定"的标准？

**主流观点**：
- 数量和边界上应当明确
- 能够从委托人的自有财产中隔离和指定出来
- 不要求必须进行登记
- 信托财产上存在权利负担或者他人就该财产享有购买权益，与信托财产的确定属不同的法律问题，也不当然影响信托财产的确定（依世欣荣和案）

### 难点三：第12条撤销权的行使主体

**争议**：哪些债权人可以行使撤销权？

**主流观点**：
- 必须是因为设立信托而**受到损害**的债权人
- 一般为委托人的普通债权人
- 信托财产的债权人不享有撤销权

### 难点四：信托合同未采用书面形式的效力

**争议**：信托合同未采用书面形式的效力？

**主流观点**：
- 信托是要式法律行为，应当采用书面形式
- 未采用书面形式的，参照《民法典》第490条（一方履行主要义务、对方接受的，合同成立）
- 不能一概认定信托不成立

### 难点五：公益信托的设立特殊要求

**争议**：公益信托的设立是否需要公益事业管理机构批准？

**主流观点**（依《信托法》第62条）：
- 公益信托的设立和确定其受托人，应当经有关公益事业的管理机构批准
- 未经批准的，不得以公益信托的名义进行活动
- 依《慈善法》第45条，还应当向民政部门备案

## ❓ 实务问答

### Q1：信托设立需要哪些必备要件？

**A**：依《信托法》第6-9条：
1. **合法的信托目的**（第6条）
2. **确定的、合法的信托财产**（第7条）
3. **书面形式**（信托合同/遗嘱/其他书面文件）（第8条）
4. **信托文件必备条款**（第9条：信托目的+当事人+受益人+信托财产+利益取得方式）

### Q2：信托法第11条信托无效的6种情形？

**A**：
1. 信托目的违反法律、行政法规或者损害社会公共利益
2. 信托财产不能确定
3. 委托人以非法的财产或不得设立信托的财产设立信托
4. 专以诉讼或者讨债为目的设立信托
5. 受益人或者受益人范围不能确定
6. 法律、行政法规规定的其他情形

### Q3：第12条撤销权的双重时效？

**A**：依《信托法》第12条第2款：
- **短期时效**：自债权人知道/应当知道撤销事由之日起**1年**
- **长期时效**：自信托发生之日起**5年**（**除斥期间**，不中止/中断/延长）

### Q4：信托财产的范围与限制？

**A**：

| 可以作为信托财产 | 不得作为信托财产 |
|---------------|---------------|
| 现金、动产、不动产 | 人格权（身份权、名誉权、姓名权） |
| 有价证券 | 债务等消极财产 |
| 商标专用权、专利权 | 委托人无处分权的财产 |
| 股权、债权 | 专以诉讼权 |

### Q5：信托文件的形式要求？

**A**：依《信托法》第8条：
- 设立信托应当采用**书面形式**（要式法律行为）
- 书面形式包括：信托合同 / 遗嘱 / 法律、行政法规规定的其他书面文件
- **信托合同签订时** → 信托成立
- **其他书面形式**：受托人**承诺信托时** → 信托成立

### Q6：信托财产的独立性？

**A**：依《九民会议纪要》第95条：
- 信托财产**独立**于委托人、受托人、受益人各自的固有财产
- 委托人的债权人不得对信托财产申请保全（除《信托法》第17条规定的情形外）
- 受托人因承诺信托而取得的信托财产，以及通过对信托财产的管理、运用、处分等方式取得的财产，均独立于受托人的固有财产
- 受益人对信托财产享有的权利表现为信托受益权，信托财产并非受益人的责任财产

### Q7：第9条5项必备条款？

**A**：依《信托法》第9条第1款：
1. 信托目的
2. 委托人、受托人的姓名或者名称、住所
3. 受益人或者受益人范围
4. 信托财产的范围、种类及状况
5. 受益人取得信托利益的形式、方法

### Q8：欺诈信托与信托无效的区别？

**A**：

| 维度 | 欺诈信托撤销（第12条） | 信托无效（第11条） |
|------|------------------------|--------------------|
| 触发条件 | 设立信托损害债权人利益 | 多种法定无效情形 |
| 主张主体 | 债权人 | 任何利害关系人 |
| 财产性质 | 委托人合法所有的财产 | 可能包括非法财产 |
| 法律后果 | 自撤销时起失效 | 自始无效 |
