## 条文结构

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1条 | 立法目的和依据 | 保护合法权益；调整民事关系；维护社会经济秩序；弘扬社会主义核心价值观；根据宪法制定 |
| 第2条 | 调整范围 | 平等主体的自然人、法人和非法人组织之间的人身关系和财产关系 |
| 第3条 | 民事权益受法律保护 | 人身权利、财产权利及其他合法权益受法律保护，任何组织或个人不得侵犯 |
| 第4条 | 平等原则 | 民事主体在民事活动中的法律地位一律平等 |
| 第5条 | 自愿原则 | 按照自己的意愿设立、变更、终止民事法律关系 |
| 第6条 | 公平原则 | 合理确定各方权利义务 |
| 第7条 | 诚信原则 | 秉持诚实，恪守承诺 |
| 第8条 | 合法性原则、公序良俗原则 | 不得违反法律，不得违背公序良俗 |
| 第9条 | 绿色原则 | 节约资源、保护生态环境 |
| 第10条 | 处理民事纠纷的依据 | 法律→习惯→法理 |
| 第11条 | 优先适用特别法 | 其他法律对民事关系有特别规定的，依照其规定 |
| 第12条 | 效力范围 | 在中华人民共和国领域内的民事活动，适用中华人民共和国法律 |

## 核心制度深度解读

### 一、立法目的五重维度（第1条）

**立法目的**：

| 维度 | 内容 |
|------|------|
| 1. 保护民事主体合法权益 | 民法是私法领域落实宪法人权保障制度的基本法律，将宪法权利具体化、法治化 |
| 2. 调整民事关系 | 核心是调整权利义务关系，通过规定民事责任落实对正常民事关系的保护 |
| 3. 维护社会和经济秩序 | 设定法律规则厘定、维护社会秩序，是市场经济的基本法 |
| 4. 适应中国特色社会主义发展要求 | 将四十多年来改革成果制度化、体系化 |
| 5. 弘扬社会主义核心价值观 | 核心价值观塑造了民法典的精神灵魂 |

**立法依据**：本条来源于原《民法总则》第1条，与原《民法总则》表述完全一致。根据《宪法》制定，宪法具有最高法律效力。

**适用指引**：法官应在裁判文书中加强以社会主义核心价值观为依据的分析说理工作。最高人民法院《关于深入推进社会主义核心价值观融入裁判文书释法说理的指导意见》（2021年1月）。

### 二、民法调整范围（第2条）

**三个要件**：

| 要件 | 内容 |
|------|------|
| 1. 主体平等性 | 法律地位平等、适用规则平等、权利保护平等 |
| 2. 主体类型 | 自然人、法人、非法人组织三类 |
| 3. 关系类型 | 人身关系和财产关系（人身关系置于财产关系之前，体现以人为本理念） |

**条文演变**：

| 立法 | 表述 |
|------|------|
| 原《民法通则》第2条 | "调整平等主体的公民之间、法人之间、公民和法人之间的财产关系和人身关系" |
| 原《民法总则》第2条 | "调整平等主体的自然人、法人和非法人组织之间的人身关系和财产关系" |
| 《民法典》第2条 | 完整保留原《民法总则》 |

**主要变化**：
- "公民" → "自然人"（含外国人/无国籍人）
- 增加"非法人组织"作为第三类主体
- "人身关系"置于"财产关系"之前

**实践要点**：行政机关履行行政职责与行政相对人形成的非平等法律关系不属于民事关系。

### 三、基本原则体系（第4-9条）

民法典构建了"六项基本原则"体系：

| 原则 | 法条 | 核心内涵 | 功能定位 |
|------|------|----------|----------|
| 平等原则 | 第4条 | 法律地位一律平等 | 民法与公法的基本界限 |
| 自愿原则 | 第5条 | 按自己意愿设立、变更、终止民事法律关系 | 意思自治 |
| 公平原则 | 第6条 | 合理确定各方权利义务 | 利益平衡 |
| 诚信原则 | 第7条 | 秉持诚实，恪守承诺 | 民法"帝王条款" |
| 合法性原则、公序良俗原则 | 第8条 | 不得违反法律，不得违背公序良俗 | 行为底线 |
| 绿色原则 | 第9条 | 节约资源、保护生态环境 | 新增原则 |

**绿色原则（第9条）**——**新增**：将生态文明纳入民法基本原则，是民法典的重大创新。该原则在物权编（用益物权、担保物权）、合同编（履行原则）、侵权责任编（环境污染责任）中均有具体体现。

**诚信原则（第7条）**——重大变化：删除原《民法通则》第4条"等价有偿"表述（与第5条自愿原则、第6条公平原则分立）。

**诚信原则的功能**：
1. 指导民事主体行为
2. 解释合同条款
3. 填补法律漏洞
4. 衡平各方利益

### 四、处理民事纠纷的依据（第10条）

**适用顺序**：
1. **法律** —— 优先适用
2. **习惯** —— 法律没有规定时，可以适用习惯（不得违背公序良俗）
3. **法理** —— 适用习惯不得违背公序良俗

**适用条件**：法律无规定 → 习惯 → 法理（依公序良俗审查）

### 五、特别法优先原则（第11条）

其他法律对民事关系有特别规定的，依照其规定。

**与第10条的关系**：第10条是法律渊源问题（法律→习惯→法理）；第11条是法律适用问题（一般法 vs 特别法）。

### 六、民法典的效力范围（第12条）

**属地原则**：在中华人民共和国领域内的民事活动，适用中华人民共和国法律。法律另有规定的，依照其规定（如涉外民事关系法律适用法、国际条约等）。

## ⚠️ 司法适用难点

### 难点一：平等原则与差别待遇的边界

**争议**：经营者对特定人群的优惠是否构成歧视？

**裁判规则**（参考源文件 line 993-1010 典型案例）：
- 餐厅对川大师生优惠 → 不构成歧视
- 物业公司对个别业主拒绝供水供电 → 违反平等原则
- 平等原则保护"法律地位平等"，而非"实际享受权利均等"

### 难点二：社会主义核心价值观的裁判运用

**适用指引**：
- 弘扬社会主义核心价值观是民法的立法宗旨
- 司法裁判对保护生态环境、维护社会公共利益的行为应当依法予以支持和鼓励
- 公民有权制止在禁止吸烟的公共场所的吸烟者吸烟（典型案例：田某菊、杨某生命权、健康权、身体权纠纷案）

### 难点三：绿色原则的适用

**创新意义**：民法典首次将绿色原则作为基本原则，对应"五位一体"总体布局中的生态文明建设。

**具体体现**：
- 物权编：用益物权应保护和合理利用资源
- 合同编：合同履行应避免浪费资源、污染环境和破坏生态
- 侵权责任编：环境污染和生态破坏责任

### 难点四：习惯作为法律渊源的边界

**适用条件**：
- 法律没有规定
- 习惯不违背公序良俗
- 习惯应具有"合理性"和"必要性"

## ❓ 实务问答

> **Q1：绿色原则在合同纠纷中如何适用？**
> 
> A：绿色原则要求合同当事人在履行合同过程中避免浪费资源、污染环境和破坏生态。违约方违反绿色原则导致环境损害的，可作为违约责任和侵权责任竞合的依据。

> **Q2：经营者对特定人群的优惠政策是否违反平等原则？**
> 
> A：不一定。司法实践中，餐厅对特定群体（如川大师生）的就餐优惠不构成歧视，理由：① 原告行为系自愿选择；② 餐厅让利促销属自主经营权；③ 未对其他群体产生不良评价；④ 未违背公序良俗。但差别待遇不得违反法律强制性规定或公序良俗。

> **Q3：法律没有规定时，能否直接适用法理？**
> 
> A：第10条规定的顺序是"法律→习惯→法理"。只有在法律没有规定且习惯不适用的情况下，才能适用法理（即学理上的法律精神、原则）。

> **Q4：第4条平等原则与第2条调整范围如何衔接？**
> 
> A：第2条调整范围决定法律关系是否适用民法（主体平等性 + 主体类型 + 关系类型）；第4条平等原则决定民法调整过程中不能差别对待。

> **Q5：外国人之间在中国发生民事纠纷，适用哪国法律？**
> 
> A：依第12条，属地原则优先。但在涉外民事关系中，应根据《涉外民事关系法律适用法》确定准据法；国际条约优先于国内法（但声明保留的条款除外）。

> **Q6：民法典第1条"弘扬社会主义核心价值观"是宣示性条款还是有裁判规范效力？**
> 
> A：两者兼具。① 立法目的角度：宣示性，体现民法典的价值取向；② 司法适用角度：具有规范效力，可作为法律解释和漏洞填补的依据。最高人民法院《关于深入推进社会主义核心价值观融入裁判文书释法说理的指导意见》要求法官在裁判文书中加强以此为依据的分析说理工作。

## 典型案例

### 案例 1：田某菊、杨某生命权、健康权、身体权纠纷案

**关键词**：弘扬社会主义核心价值观、公共利益

**裁判摘要**：公民有权制止在禁止吸烟的公共场所的吸烟者吸烟，杨某对段某在电梯内吸烟予以劝阻合法正当，是自觉维护社会公共秩序和公共利益的行为。弘扬社会主义核心价值观是民法的立法宗旨，司法裁判对保护生态环境、维护社会公共利益的行为应当依法予以支持和鼓励。

**基本案情**：段某立与杨某先后进入小区同一电梯，因段某立在电梯内吸烟发生言语争执。段某立猝死，其配偶田某菊起诉要求杨某赔偿四十余万元。一审判决杨某补偿15000元（适用公平原则）。二审法院认为杨某劝阻吸烟行为合法正当，不存在法律上的因果关系，撤销补偿责任。

**案号**：（2017）豫01民终14848号
**审理法院**：河南省郑州市中级人民法院

### 案例 2：郭某诉某餐饮公司餐饮消费服务合同纠纷案

**关键词**：平等原则、自愿原则

**裁判要旨**：餐厅对特定人群（如川大师生）的就餐优惠属合法让利行为，不构成对其他群体的歧视。平等原则保护法律地位平等，不保护实际享受权利均等。

**案号**：（2009）武侯民初字第4680号

### 案例 3：中铁一局集团某公司诉廖某物业服务合同纠纷案

**关键词**：平等原则

**裁判要旨**：物业公司对个别业主拒绝供水供电违反民法平等原则，是对物业服务合同的不当履行。

**案号**：（2018）陕03民终182号
