# 民法典物权编第一章【一般规定】综合

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》物权卷1 2023年 205-296]] |
| 章节 | 第一章 一般规定 |
| 条文范围 | 《民法典》第205条～第208条（共4条） |
| 体例定位 | 物权编第一分编"通则"第一章 |
| 核心主题 | 物权编调整范围、基本经济制度、物权平等保护、物权公示原则 |

## 章节目录

本章共 4 条（Articles 205-208），规定物权编的调整范围与四项基础性原则：物的归属与利用的调整范围、社会主义基本经济制度、国家集体私人物权的平等保护、以及物权变动的公示方法（不动产登记 / 动产交付）。这四条是物权编所有后续制度（不动产登记、动产交付、所有权、用益物权、担保物权）的总纲。

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第205条 | 物权编调整范围 | 因物的归属和利用产生的民事关系 |
| 第206条 | 社会主义基本经济制度 | 公有制为主体+两个毫不动摇+社会主义市场经济 |
| 第207条 | 物权平等保护 | 国家、集体、私人、其他权利人物权平等 |
| 第208条 | 物权公示原则 | 不动产登记 + 动产交付 |

## 一、第205条·物权编调整范围

### 法条原文

> 第二百零五条　本编调整因物的归属和利用产生的民事关系。

### 核心释义

**编纂目的**：物权编编纂目的即"**定分止争，物尽其用**"。
- "定分止争"：典出《管子·七臣七主》，意为确定名分，止息纷争
- "物尽其用"：各种东西凡有可用之处，尽量利用

#### （一）调整范围的两大维度：物的归属 + 物的利用

| 维度 | 内容 | 关系 |
|------|------|------|
| **物的归属** | 物的所有人是谁，确定财产权归属 | 利用的前提 |
| **物的利用** | 对物的占有、使用、收益、处分 | 归属的目的 |

**法律意义**：
1. **物的归属**：确定财产所有权归属 → 消弭纷争（山林纠纷、土地边界、用水纠纷等多因归属不明而起）
2. **物的利用**：通过合同/用益物权/担保物权实现"物尽其用" → 促进社会财富创造

#### （二）物权编仅调整"民事关系"

**关键限定**：本条所称"民事关系"具有如下基本内涵：

| 内涵 | 内容 |
|------|------|
| 1. 主体地位平等 | 平等主体之事，任何一方不得凌驾 |
| 2. 财产关系性质 | 平等主体之间的财产关系（非人身关系） |
| 3. 专属调整范围 | 仅调整平等主体之间因物的归属和利用而产生的财产关系 |

**例外**：因物的归属和利用而在民事主体利益与公共利益之间发生的法律关系，也可由物权编调整（典型如第243条征收、第245条征用）。依《民法典》第132条，禁止滥用民事权利损害公共利益；依第9条绿色原则，物权行使需遵循节约资源、保护生态环境。

#### （三）本条与原《物权法》的关系

| 演变 | 内容 |
|------|------|
| 原《物权法》第2条第1款 | 同本条 |
| 调整：将物权客体的规定 | 调整到总则编第115条 |
| 调整：物权概念和种类的规定 | 调整到总则编第114条第2款 |

**理由**：突出物权的基本特征，将物权与人身权、债权、知识产权等其他基本民事权利区分开来，同时科学界定调整范围。

### 适用指引

**物权编与行政法的分工**：审判实践中存在民事与行政交叉的情形，在不动产登记领域较为突出。例如，当事人因不动产登记簿存在错误，以行政机关存在登记过失为由提起行政诉讼，又针对导致该不动产登记簿存在错误的民事法律行为效力提起民事诉讼。

《民法典物权编解释（一）》第1条明确规定：
> 因不动产物权的归属，以及作为不动产物权登记基础的买卖、赠与、抵押等产生争议，当事人提起民事诉讼的，应当依法受理。当事人已经在行政诉讼中申请一并解决上述民事争议，且人民法院一并审理的除外。

**理由**：不动产登记是一种物权公示手段，是《民法典》规定的一项物权制度，其本质是反映不动产物权发生变动的事实行为而非行政管理行为。

## 二、第206条·社会主义基本经济制度

### 法条原文

> 第二百零六条　国家坚持和完善公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制等社会主义基本经济制度。
>
> 国家巩固和发展公有制经济，鼓励、支持和引导非公有制经济的发展。
>
> 国家实行社会主义市场经济，保障一切市场主体的平等法律地位和发展权利。

### 核心释义

#### （一）三个"毫不动摇"

本条包含三项社会主义基本经济制度，被概括为"**两个毫不动摇 + 一个保障**"：

| 维度 | 内容 | 政策表述 |
|------|------|---------|
| **公有制经济** | 巩固和发展 | "毫不动摇巩固和发展公有制经济" |
| **非公有制经济** | 鼓励、支持和引导 | "毫不动摇鼓励、支持和引导非公有制经济发展" |
| **市场主体平等** | 平等法律地位和发展权利 | "保障一切市场主体的平等法律地位和发展权利" |

#### （二）本条立法演变（5个关键节点）

| 节点 | 标志性事件 |
|------|----------|
| 1999年《宪法修正案》 | 增加"发展社会主义市场经济"内容；非公有制经济从"补充"升为"重要组成部分" |
| 2004年《宪法修正案》 | 增加"国家鼓励、支持和引导非公有制经济的发展" |
| 2007年原《物权法》第3条 | 首次在民事基本法中确立基本经济制度 + 平等保护 |
| 党的十六届三中全会 | 提出"保障所有市场主体的平等法律地位和发展权利" |
| 党的十九大、十九届四中全会 | "两个毫不动摇"写入新时代坚持和发展中国特色社会主义基本方略 |

**党的十九届四中全会决定**：将**公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制**都作为社会主义基本经济制度。这是本条第1款的直接政策来源。

#### （三）"平等保护"与"基本经济制度"的关系

本条与第207条"平等保护"原则的关系：

| 第206条 | 第207条 |
|---------|---------|
| 经济制度基础 | 物权平等保护 |
| 不同所有制经济在国民经济中**地位和作用不同** | 各类市场主体**法律地位平等、权利保护相同** |
| 国家宏观调控、市场准入、公共资源配置层面 | 物权保护的具体规则层面 |

### 典型案例

#### 案例一·张文中再审改判无罪案

| 项目 | 内容 |
|------|------|
| **案号** | （2018）最高法刑再3号 |
| **审理法院** | 最高人民法院 |
| **裁判要点** | 产权制度是社会主义市场经济的基石。国家平等保护各类市场主体的产权和合法权益，依法惩治侵吞、瓜分、挪用国有、集体和非公有制企业财产的犯罪 |
| **典型意义** | 再审改判无罪 + 返还已执行罚金及追缴财产，体现平等保护原则在刑事司法中的落实 |

#### 案例二·顾雏军再审案

| 项目 | 内容 |
|------|------|
| **案号** | （2018）最高法刑再4号 |
| **审理法院** | 最高人民法院 |
| **裁判要点** | 原审认定虚报注册资本事实存在，但相关法律已修改 + 行为情节显著轻微危害不大 → 不认为是犯罪 |
| **典型意义** | 体现"从旧兼从轻"原则和对各类所有制经济平等保护 |

#### 案例三·罗某明等五人与某综合行政执法局行政赔偿案

| **典型意义** | 体现对民营经济合法产权的平等保护 |

### 适用指引

**产权平等保护的三个维度**：

| 维度 | 内涵 |
|------|------|
| 1. 物权主体平等 | 不得歧视非公有物权的主体；国家、集体、私人、其他权利人物的物权都受法律平等保护 |
| 2. 物权平等 | 无论是国家、集体、私人还是其他权利人的物权，都是平等的物权，受物权法规则的约束和保护 |
| 3. 法律对不同类型物权进行平等保护 | 各种市场主体对相同的物权具有同等的权利，适用相同的市场交易规则，侵害人承担同样的民事责任 |

**配套制度**：《民法典》第268条规定："国家、集体和私人依法可以出资设立有限责任公司、股份有限公司或者其他企业。国家、集体和私人所有的不动产或者动产投到企业的，由出资人按照约定或出资比例享有收益、重大决策以及选择经营管理者等权利并履行义务。"

## 三、第207条·物权平等保护

### 法条原文

> 第二百零七条　国家、集体、私人的物权和其他权利人的物权受法律平等保护，任何组织或者个人不得侵犯。

### 核心释义

#### （一）"平等保护"的四重内涵

| 内涵 | 内容 |
|------|------|
| 1. **主体平等** | 国家、集体、私人三类主体法律地位平等 |
| 2. **规则平等** | 适用相同的物权规则 |
| 3. **救济平等** | 受到侵害时享有相同的救济途径 |
| 4. **责任平等** | 侵权人承担相同的法律责任 |

#### （二）"其他权利人"的范围

本条从所有制角度对物权主体分类规定平等保护原则，对于无法完全纳入"国家""集体""私人"的权利人（如公益性基金会等），规定为"其他权利人"。

**典型主体**：
- 法人（国有企业法人、私营企业法人、外商投资企业法人等）
- 非法人组织（个人独资企业、合伙企业等）
- 个体工商户、农村承包经营户
- 社会团体、捐助法人

#### （三）四类物权的平等保护

| 类别 | 法律依据 | 保护要点 |
|------|---------|---------|
| **国有财产** | 第246-256条 | 受法律保护，禁止任何组织或个人侵占、哄抢、私分、截留、破坏 |
| **集体财产** | 第260-265条 | 受法律保护，禁止任何组织或个人侵占、哄抢、私分、破坏；集体经济组织或负责人作出的决定侵害集体成员合法权益的，可请求人民法院撤销 |
| **私有财产** | 第266-267条 | 私人对其合法的收入、房屋、生活用品、生产工具、原材料等不动产和动产享有所有权；私人的合法财产受法律保护 |
| **其他权利人** | 第270条 | 社会团体法人、捐助法人依法所有的不动产和动产受法律保护 |

#### （四）"任何组织或者个人不得侵犯"

| 演变 | 内容 |
|------|------|
| 原《物权法》第4条 | "任何**单位**和个人不得侵犯" |
| 《民法典》本条 | "任何**组织**和个人不得侵犯" |

**理由**：《民法典》将民事主体分为自然人、法人、非法人组织。"组织"可以涵盖个人以外的一切民事主体，比"单位"更为科学准确。

**国家机关的职责**：国家机关履行职责、行使职权必须清楚自身行为和活动的范围和界限。各级党和国家机关开展工作要考虑《民法典》的规定，不能侵犯人民群众享有的合法民事权利。

### 适用指引

**物权平等保护在司法中的四个场景**：

| 场景 | 适用指引 |
|------|---------|
| 1. **征收中的产权保护** | 征收补偿的标准和范围，应当严格依照《民法典》第243条的规定；不将公共利益扩大化 |
| 2. **招商引资中的产权保护** | 对于确因政府规划调整、政策变化导致民商事合同不能履行的，依法支持当事人解除合同的请求 |
| 3. **强制执行中的产权保护** | 严禁超标的查封；以价值足以清偿生效法律文书确定的债权额为限采取执行措施 |
| 4. **刑事案件中的产权保护** | 严格区分刑民界限；严格区分企业家违法所得和合法财产；没有充分证据证明为违法所得的，不得判决追缴或者责令退赔 |

**法源支撑**：
- 《中共中央、国务院关于完善产权保护制度依法保护产权的意见》（中发〔2016〕28号）：明确"健全以公平为核心原则的产权保护制度"
- 《最高人民法院关于充分发挥审判职能作用切实加强产权司法保护的意见》（2016年11月）："坚持各种所有制经济权利平等、机会平等、规则平等"
- 《最高人民法院关于在执行工作中进一步强化善意文明执行理念的意见》（2019年12月）：严禁超标的查封

## 四、第208条·物权公示原则

### 法条原文

> 第二百零八条　不动产物权的设立、变更、转让和消灭，应当依照法律规定登记。动产物权的设立和转让，应当依照法律规定交付。

### 核心释义

物权公示原则是物权法的**基石原则**，包含两方面：
1. **公示方法**：不动产登记 / 动产交付（"确定物的归属就是不动产看登记，动产看占有"）
2. **公信效力**：公示所表彰的权利状态产生公信力

#### （一）公示方法的两大类型

| 类型 | 公示方法 | 典型适用 |
|------|---------|---------|
| **不动产登记** | 法定登记机构依法定程序进行登记 | 土地、房屋、林木等不动产 |
| **动产交付** | 出让人将动产占有移转给受让人 | 一般动产 |
| **登记对抗**（特殊动产） | 登记非生效要件，但未经登记不得对抗善意第三人 | 船舶、航空器、机动车等 |
| **其他公示方法** | 应收账款出质登记、基金份额/股权出质登记 | 权利质押 |

#### （二）不动产登记的公示功能

| 功能 | 内容 |
|------|------|
| 1. **明确物的归属** | 通过将物权设定和移转的事实对外公开，明确物权的归属 |
| 2. **维护交易安全** | 物权对世权 + 关系第三人利益，必须符合公示要件才能设立 |
| 3. **提高物的利用效率** | 公示制度使不移交占用、不影响物之利用而对物之交换价值进行利用成为可能 |

#### （三）公信原则的两方面内容

| 方面 | 内容 |
|------|------|
| 1. **权利推定** | 登记记载的权利人在法律上推定其为真正的权利人；登记簿是物权归属和内容的根据（第216条） |
| 2. **善意保护** | 信赖登记所记载的权利而与权利人进行的交易，在法律上应当受到保护；构成善意取得要件的，受到善意取得制度的保护 |

**借名协议的特别规则**：对于存在合理理由，协议借用他人名义按照公示原则取得物权的双方当事人，如借名协议不违反法律规定，登记的权利人不得以公示公信原则对抗借名人实现权利。但借名人的上述权利**不得对抗**与登记权利人就该特定物为标的进行交易或者享有抵押权的第三人。

#### （四）违反公示方法的法律后果

| 情形 | 法律后果 |
|------|---------|
| **登记要件主义** | 依法需要办理登记的，必须办理登记；未办理登记，不能发生物权设立和变动的效果 |
| **登记对抗主义** | 即使未办理登记，也可发生物权变动；但受让人取得的物权不能对抗第三人 |
| **动产物权变动** | 必须移转占有才能发生物权设立和变动的后果 |

#### （五）"一房二卖"的阻却机制

期房买卖交易中，经常出现"一房二卖"的情形。阻却第三人善意取得的方式：

| 方式 | 法律效力 | 法律依据 |
|------|---------|---------|
| **预告登记** | 效力最强；未经预告登记权利人同意，不能处分该不动产 | 《不动产登记暂行条例实施细则》第85条第1款 |
| **购房合同备案** | 防止"一房二卖"的有效途径 | 《城市商品房预售管理办法》第10条第1款 |
| **网签制度** | 行政管理手段；防止"一房多卖" | 房地产管理部门网络管理系统 |

**典型认定**（《物权法解释（一）》第16条第2项）：若不动产登记簿上存在有效的预告登记，未经预告登记的权利人同意受让该不动产的，不能认定为善意受让人。

### 适用指引

**违反公示方法的合同效力问题**：

违反公示方法并不意味着不发生任何法律效力。如果满足合同成立和生效的要件，在当事人之间仍然会发生法律效力，一方当事人不履行合同，应当承担包括完善公示方法依约登记及相应的法律责任。

**典型案例**：
- 《民商审判会议纪要》第60条：不动产抵押合同依法成立，但未办理抵押登记手续，债权人请求抵押人办理抵押登记手续的，人民法院依法予以支持。因抵押物灭失以及抵押物转让他人等原因不能办理抵押登记，债权人请求抵押人以抵押物的价值为限承担责任的，人民法院依法予以支持。
- 《民法典担保制度解释》第63条：当事人未在法定的登记机构依法进行登记，主张该担保具有物权效力的，人民法院不予支持。

**预告登记 + 网签 + 备案的关系**：

```
法律效力强度（强→弱）：
预告登记 > 购房合同备案 > 网签制度
```

预告登记是法定公示方法，具有物权效力；网签和备案多为行政管理手段。

## ⚠️ 司法适用难点

### 难点一：第207条"其他权利人"的范围界定

**争议**：公益性基金会、寺院、社会服务机构等非营利法人的物权是否属于"其他权利人"？

**主流观点**：
- **多数说**：上述主体归入"其他权利人"，适用物权平等保护
- **少数说**：应根据其财产来源（社会捐赠 vs 政府拨款）区分对待

### 难点二：物权编是否调整纵向关系

**争议**：行政机关与相对人之间因物的归属和利用产生的争议，是否属于物权编调整范围？

**主流观点**：
- 物权编**仅调整**平等主体之间因物的归属和利用而产生的财产关系
- 经济社会管理活动中管理者与被管理者之间的纵向关系，由**行政法、经济法**调整
- 例外：因物的归属和利用而在民事主体利益与公共利益之间发生的法律关系（如征收、征用），也可由物权编调整

### 难点三：登记生效主义 vs 登记对抗主义的边界

**争议**：哪些物权变动采登记生效主义？哪些采登记对抗主义？

**主流观点**（依《民法典》及相关法律）：

| 物权类型 | 公示方法 |
|---------|---------|
| 不动产物权 | 登记生效（**原则**） |
| 土地承包经营权设立 | 合同生效（特殊） |
| 土地承包经营权互换、转让 | 登记对抗 |
| 地役权设立 | 合同生效 |
| 地役权登记 | 登记对抗 |
| 宅基地使用权 | 无登记生效要件 |
| 动产物权 | 交付生效（原则） |
| 船舶、航空器、机动车 | 交付生效 + 登记对抗 |
| 应收账款出质 | 登记设立 |
| 基金份额/股权出质 | 登记设立 |

### 难点四：借名买房纠纷

**争议**：借名买房协议效力如何？借名人能否对抗第三人？

**主流观点**（结合第208条 + 民法典相关规定）：
- 借名协议不违反法律规定的 → 有效
- 登记权利人不得以公示公信原则对抗借名人实现权利
- **但借名人的权利不得对抗**：与登记权利人就该特定物为标的进行交易或者享有抵押权的第三人

### 难点五：未登记的不动产物权合同的违约责任

**争议**：房屋买卖未办理过户登记，出卖人一房二卖的法律责任？

**主流观点**：
- 第一买受人：依《民法典》第215条，未办理物权登记不影响合同效力，出卖人应承担**违约责任**
- 第二买受人：若已办理过户登记且符合善意取得条件 → 第二买受人取得房屋所有权
- 第一买受人：可向出卖人主张违约责任，但不能请求返还房屋

## ❓ 实务问答

### Q1：物权编调整哪些范围？

**A**：物权编仅调整**平等主体之间**因物的**归属和利用**而产生的财产关系。经济社会管理活动中管理者与被管理者之间的纵向关系，由行政法、经济法调整。例外：因物的归属和利用而在民事主体利益与公共利益之间发生的法律关系（如征收、征用），也可由物权编调整。

### Q2：第206条和第207条的关系是什么？

**A**：第206条规定**经济制度基础**（公有制为主体+多种所有制经济共同发展+社会主义市场经济），第207条规定**物权平等保护**（国家、集体、私人、其他权利人物的物权受法律平等保护）。
- 第206条强调：不同所有制经济在国民经济中地位和作用**不同**（公有制为主体、国有经济为主导）
- 第207条强调：各类市场主体的物权受**平等保护**（法律地位、权利救济平等）

二者是有机统一：没有前者，就会改变社会主义基本经济制度的性质；没有后者，就违背了市场经济原则，反过来又会损害社会主义基本经济制度。

### Q3：第207条"其他权利人"包括哪些主体？

**A**：包括**法人、非法人组织、个体工商户、农村承包经营户、社会团体、捐助法人**等所有无法完全纳入"国家""集体""私人"分类但依法享有物权的民事主体。例如公益性基金会、寺院、社会服务机构等。

### Q4：第208条"物权公示原则"与"公信原则"的关系？

**A**：
- **公示原则**：物权变动必须以法定的公示方法进行（不动产登记、动产交付），方发生物权变动的法律效果
- **公信原则**：通过法定公示方法公示出来的权利状态，相对人有合理理由相信其为真实，与登记权利人进行交易，对这种信赖法律应当予以保护
- 公示与公信**密切联系**：公示是公信的前提，公信是公示的效力

### Q5：第208条"未经登记，不发生效力"的例外？

**A**：主要包括以下情形：
1. **本法第229-232条规定的非依法律行为物权变动**：法律文书、征收决定、继承、事实行为（合法建造、拆除房屋）
2. **本法第209条第2款**：依法属于国家所有的自然资源，所有权可以不登记
3. **土地承包经营权**：自土地承包经营权合同生效时设立；互换、转让未经登记不得对抗善意第三人
4. **地役权**：自地役权合同生效时设立；登记对抗
5. **宅基地使用权**：不以登记为生效要件；转让或者消灭的，应当及时办理变更登记或者注销登记

### Q6：违反物权公示原则的法律后果？

**A**：
| 情形 | 后果 |
|------|------|
| 不动产物权未登记 | 不发生物权变动效力；合同效力不受影响（第215条）；违约责任 |
| 动产物权未交付 | 不发生物权变动效力；合同效力不受影响 |
| 不动产抵押未登记 | 抵押权不成立；但抵押合同有效，可要求办理抵押登记（第402条、民商审判会议纪要第60条） |
| 期房"一房二卖" | 已办理过户登记且符合善意取得 → 第二买受人取得所有权；第一买受人可主张违约责任 |

### Q7：预告登记、网签、备案三者效力比较？

**A**：法律效力（强→弱）：**预告登记 > 购房合同备案 > 网签**
- **预告登记**：法定公示方法，未经预告登记权利人同意，处分该不动产的，不发生物权效力（第221条）
- **购房合同备案**：行政管理手段，防止"一房二卖"
- **网签制度**：房地产管理部门网络管理系统，规范销售行为

### Q8：未登记的不动产物权合同是否有效？

**A**：**有效**。依《民法典》第215条，当事人之间订立有关设立、变更、转让和消灭不动产物权的合同，除法律另有规定或者当事人另有约定外，自合同成立时生效；未办理物权登记的，不影响合同效力。但未登记不发生物权变动效力，出卖人可能承担违约责任。
