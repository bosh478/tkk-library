## 核心制度深度解读

### 第一部分 有限责任公司的股权转让（第71-75条）

### 一、股东间相互转让与股东优先购买权（第71条）

**条文原文**：有限责任公司的股东之间可以相互转让其全部或者部分股权。股东向股东以外的人转让股权，应当经其他股东过半数同意。股东应就其股权转让事项书面通知其他股东征求同意，其他股东自接到书面通知之日起满三十日未答复的，视为同意转让。其他股东半数以上不同意转让的，不同意的股东应当购买该转让的股权；不购买的，视为同意转让。经股东同意转让的股权，在同等条件下，其他股东有优先购买权。两个以上股东主张行使优先购买权的，协商确定各自的购买比例；协商不成的，按照转让时各自的出资比例行使优先购买权。公司章程对股权转让另有规定的，从其规定。

**三层规则体系**：

| 层次 | 内容 |
|------|------|
| 股东间相互转让 | 自由转让，无需其他股东同意 |
| 股东对外转让 | 经其他股东过半数同意（股东多数决而非资本多数决）；书面通知征求同意；30日未答复视为同意；半数以上不同意的，不同意股东应购买否则视为同意 |
| 优先购买权 | 同等条件下其他股东有优先购买权；多人主张时协商确定比例，协商不成按出资比例行使 |

**股权的双重属性**：

| 属性 | 内容 |
|------|------|
| 财产权利属性 | 股权具有价值并可转让 |
| 人合性质 | 有限责任公司组建依赖股东之间的信任关系和共同利益关系 |

**立法目的**：法律一方面要确认并保障有限责任公司股东转让股份的权利，另一方面也要维护股东间的相互信赖及其他股东的正当利益。股东优先购买权制度的正当性主要源自有限责任公司具有资合兼人合的性质，既需要强调股东之间的信任与合作关系，也需要确保股权作为财产权利的自由流动。

**同意权与异议股东强制购买义务的实际作用有限**：本条规定将同意权制度、异议股东的强制购买义务以及股东优先购买权三项制度糅合一体。由于股东对外转让股权，只要外部有人愿意买，并且认可转让价格的，其他股东不论是否同意，股权是一定能卖出的，所以，其他股东是同意还是不同意，对于转让股东来说，可能只有程序意义，没有实质作用。因此，对于同意权而言，其本身并不产生防止股权对外转让的效力，不同意股东若无力或不愿购买，将被视为同意转让，这项权利的限制作用不大。

### 二、优先购买权的适用问题

**1. 享有优先购买权的主体**

| 主体 | 是否享有优先购买权 | 法律依据 |
|------|-------------------|----------|
| 同意转让的股东 | 不丧失优先购买权 | 《公司法规定（四）》第17条第3款 |
| 瑕疵出资股东 | 公司章程或股东会决议可对其合理限制；未限制的，享有优先购买权 | 《公司法规定（三）》第16条 |
| 继承发生时 | 原则上其他股东不享有优先购买权；章程另有规定或全体股东另有约定除外 | 《公司法规定（四）》第16条 |

**2. 同等条件的认定**（《公司法规定（四）》第18条）

| 因素 | 评判标准 |
|------|----------|
| 股权数量 | 第三人购买特定比例股权是整体购买，其他股东不得部分行使优先购买权 |
| 转让价格 | 同等价格；转让股东与第三人恶意串通虚拟高价的，其他股东有权以真实转让价格确定同等条件 |
| 支付方式 | 影响转让股东利益的实质性方式；如分期付款属于重要条件 |
| 履行期限 | 影响转让股东何时获得对价 |
| 其他因素 | 违约金条款、从给付义务等；如第三人需向公司提供关键技术的从给付义务属于同等条件内容 |

**"绝对同等说"与"相对同等说"之争**：

| 学说 | 主张 | 实务倾向 |
|------|------|----------|
| 绝对同等说 | 优先购买权人认购条件应与第三人绝对相同和完全一致 | 过于严苛，实践中难以操作 |
| 相对同等说 | 购买条件与第三人条件大致相等即为同等条件 | 司法实务采相对同等说 |

**3. 阴阳合同的处理**：转让股东与第三人订立阴阳合同，依据所载股份数量不符、交易价格高或其他条件更苛刻的"阳合同"通知其他股东，迫使其他股东放弃优先购买权后，转让股东与第三人按载有真正数量和交易价格及其他条件的"阴合同"履行，第三人因"阴合同"的履行取得了股权后，已经放弃"阳合同"购买条件下优先购买权的其他股东，仍然有权以"阴合同"的条件请求行使优先购买权。因为"阳合同"是转让股东与第三人恶意串通下的虚假意思表示，根据《民法典》第154条规定无效。

**4. 优先购买权的行使期限**（《公司法规定（四）》第19条）

| 情形 | 行使期间 |
|------|----------|
| 公司章程规定行使期间 | 按章程规定 |
| 章程未规定或规定不明 | 以通知确定的期间为准 |
| 通知期间短于30日或未明确行使期间 | 30日 |

**股东优先购买权行使期间，属于不可变期间**，不适用中止、中断或延长的相关规定。优先购买权的行使期间起算之日不应早于通知到达其他股东之日。

**5. 按照出资比例行使优先购买权的认定**：

| 情形 | 适用比例 |
|------|----------|
| 公司章程有规定 | 按章程规定 |
| 章程未规定，当事人也协商不成 | 区分情形：届满期限已至但未缴足，按实缴出资比例；出资期限尚未届满，按认缴出资比例 |

**6. 侵犯优先购买权的股权转让合同的效力**：

| 学说 | 内容 |
|------|------|
| 无效说 | 侵犯优先购买权即无效 |
| 附法定生效条件说 | 须经其他股东放弃优先购买权才生效 |
| 效力待定说 | 须经其他股东追认 |
| 可撤销说 | 其他股东可以撤销 |
| 相对无效说 | 对其他股东相对无效，对合同当事人有效 |

**主流观点**（依《民商审判会议纪要》第9条）：除转让股东和股东以外的股权受让人恶意串通损害其他股东优先购买权订立的合同无效外，一般情况下，转让股东与股东以外的股权受让人之间签订股权转让合同时即使没有履行《公司法》第71条第2款、第3款的义务，侵犯了其他股东的优先购买权，该合同也是有效的。主要理由是股东优先购买权的行使目的在于通过保障其他股东优先购买权获得拟转让股份而维护公司内部信赖关系，法律所要否定的是股东以外的股权受让人优先于公司其他股东取得公司股份的行为，而不是转让股东与股东以外的股权受让人之间签订的股权转让合同的效力。

**7. 侵害股东优先购买权的救济**（依《公司法规定（四）》第21条）

| 情形 | 救济方式 |
|------|----------|
| 未就股权转让事项征求其他股东意见 | 其他股东可主张按照同等条件购买 |
| 以欺诈、恶意串通等手段损害优先购买权 | 同上 |
| 主张按同等条件购买的期限 | 自知道或应当知道同等条件之日起30日内；或自股权变更登记之日起1年内 |
| 仅提出确认合同及股权变动效力等请求，未同时主张购买 | 不予支持；非因自身原因导致无法行使的，可请求损害赔偿 |
| 股东以外的股权受让人因股东行使优先购买权不能实现合同目的 | 可依法请求转让股东承担相应民事责任 |

**8. 股东放弃优先购买权时的处理**（依《公司法规定（四）》第20条）：在有限责任公司的其他股东主张优先购买后，转让股东又不同意转让的，对其他股东优先购买的主张，不应支持。但存在两种例外情形：公司章程规定转让股东不允许反悔；或全体股东约定转让股东不允许反悔。

### 三、股权转让生效时点的认定

**三个时点的关系**：

| 时点 | 效力 |
|------|------|
| 股权转让合同生效 | 合同生效时间早于股权变动时间；合同本身效力不受股东名册变更或工商登记影响 |
| 股东名册变更 | 受让人取得股权的标志（设权登记） |
| 公司登记机关变更登记 | 产生对抗效力（对抗善意相对人） |

**司法认定原则**（依《民商审判会议纪要》第8条）：以转让方式变动有限责任公司股权的，有限责任公司股权转让合同自签订时生效，附条件的自所附条件成就时生效，公司股东名册变更登记与公司登记机关变更登记不影响股权转让合同本身的效力；股权转让生效时点以股东名册变更为准，法律、行政法规规定应当办理批准手续才能生效的，则以股东名册变更与办理批准手续完成为准；股权变动未经公司登记机关变更登记的，不得对抗善意相对人。

**股东名册的法律效力**：

| 效力 | 内容 |
|------|------|
| 权利推定效力 | 股东名册上记载为股东的，推定为公司股东，股东可凭该记载对外主张为股东 |
| 对抗效力 | 受让人受让股权后未在股东名册上记载，不能对公司行使股权 |
| 免责效力 | 公司只将股东名册上记载的股东视为股东，即便股东名册上的股东不是真正股东，也可免除公司的责任 |

**无规范股东名册情形**：在不存在规范股东名册的情况下，有关的公司文件，如公司章程、会议纪要等，只要能够证明公司认可受让人为新股东的，都可以产生相应的效力。

### 四、对股权变更的救济问题

**公司不履行变更登记义务的救济**：

| 情形 | 救济方式 |
|------|----------|
| 转让人不履行交付股权义务 | 受让人应就股权转让合同纠纷提起诉讼，追究转让人的违约责任 |
| 公司怠于或拒绝履行变更登记义务 | 转让人、受让人均可以公司为被告起诉请求办理股东名册变更；法院可判令公司履行法律规定的义务 |

**法律依据**：《公司法规定（三）》第23条规定，当公司未履行签发出资证明书、记载于股东名册并办理工商变更登记的义务的，受让人请求公司履行上述义务的，人民法院应当予以支持。

### 五、国有股的股权转让问题

国有股权转让应遵循国有资产监督管理法律法规的诸多强制性规范：

| 特殊规定 | 内容 |
|----------|------|
| 严格的股权转让审批制度 | 《企业国有资产交易监督管理办法》第7-8条规定国资监管机构负责审核国家出资企业的产权转让事项 |
| 经资产评估确定转让价格 | 《企业国有资产法》第55条规定转让价格应以依法评估并经履行出资人职责的机构认可或报经本级人民政府核准的价格为依据 |
| 公开进场交易 | 《企业国有资产法》第54条第2款规定除按照国家规定可以直接协议转让的以外，应当在依法设立的产权交易场所公开进行 |

**国有股权转让公开进场交易方式**：

| 方式 | 适用情形 |
|------|----------|
| 非公开协议转让 | 涉及主业处于关系国家安全、国民经济命脉的重要行业和关键领域企业的重组整合，对受让方有特殊要求；同一国家出资企业及其各级控股企业或实际控制企业之间因实施内部重组整合 |
| 公开竞价（拍卖、招投标、网络竞价等） | 公开征集产生两个以上受让方时 |

### 六、瑕症出资股权转让的效力及责任承担问题

**效力认定**：

| 情形 | 效力 |
|------|------|
| 转让人隐瞒出资瑕疵事实，受让人不知亦不应知 | 属于可变更、可撤销合同，受让人可在法定期间内以欺诈为由主张变更或撤销 |
| 受让人明知或应知转让股东出资瑕疵事实 | 股权转让合同有效 |

**责任承担**（《公司法规定（三）》第18条）：

| 责任主体 | 责任 |
|----------|------|
| 转让股东 | 出资义务不得因股权转让而解除，公司仍有权请求转让股东履行出资义务 |
| 受让人（明知或应知） | 与转让股东承担连带责任 |
| 公司债权人 | 可请求转让股东在未出资本息范围内对公司债务不能清偿部分承担补充赔偿责任，受让人承担连带责任 |
| 受让人承担连带责任后 | 有权向转让股东追偿 |

### 七、强制执行中的优先购买权（第72条）

**条文原文**：人民法院依照法律规定的强制执行程序转让股东的股权时，应当通知公司及全体股东，其他股东在同等条件下有优先购买权。其他股东自人民法院通知之日起满二十日不行使优先购买权的视为放弃优先购买权。

**理解要点**：

| 要点 | 内容 |
|------|------|
| 通知义务 | 通知公司（使其协助执行）+ 通知其他股东（保障优先购买权） |
| 行使期限 | 自人民法院通知之日起20日 |
| 逾期后果 | 视为放弃优先购买权 |

**股权拍卖中优先购买权的行使方式**：

| 方式 | 内容 |
|------|------|
| 跟价法 | 优先购买权人作为竞买人参与拍卖，最高应价时优先购买权人可以表示以该最高价接受 |
| 询价法 | 由法院通知优先购买权人到拍卖现场，但不直接参与竞价，待产生最高应价者后由拍卖师询问优先购买权人 |

**拍卖通知的层级适用**：

| 规定 | 通知时间 |
|------|----------|
| 《公司法》第72条 | 自人民法院通知之日起满20日不行使视为放弃 |
| 《民事执行拍卖、变卖财产的规定》第11条 | 拍卖5日前通知 |
| 《网络司法拍卖规定》第16条 | 拍卖公告发布3日前通知 |

### 八、股权转让后的变更记载（第73条）

**条文原文**：依照本法第七十一条、第七十二条转让股权后，公司应当注销原股东的出资证明书，向新股东签发出资证明书，并相应修改公司章程和股东名册中有关股东及其出资额的记载。对公司章程的该项修改不需再由股东会表决。

**理解要点**：

| 项目 | 内容 |
|------|------|
| 注销义务 | 公司应当注销原股东的出资证明书 |
| 签发义务 | 向新股东签发出资证明书 |
| 修改义务 | 修改公司章程和股东名册中有关股东及其出资额的记载 |
| 章程修改程序 | 不需再由股东会表决 |

### 九、异议股东股份回购请求权（第74条）

**三种法定情形**：

| 情形 | 内容 |
|------|------|
| 连续5年不分配利润 | 公司连续5年不向股东分配利润，而公司该5年连续盈利，并且符合《公司法》规定的分配利润条件的 |
| 合并、分立、转让主要财产 | 公司的合并、分立、转让主要财产 |
| 营业期限届满或解散事由出现后决议存续 | 公司章程规定的营业期限届满或者章程规定的其他解散事由出现，股东会会议通过决议修改章程使公司存续的 |

**程序**：

| 阶段 | 时限 |
|------|------|
| 投反对票 | 在股东会决议时投反对票 |
| 协议收购 | 自股东会会议决议通过之日起60日内达成收购协议 |
| 提起诉讼 | 自股东会会议决议通过之日起90日内向人民法院提起诉讼 |

**异议股东回购请求权的本质**：本条是在"资本多数决"的情况下，赋予中小股东或少数股东维护自身权益的救济措施的制度设计。当公司的控股股东或代表多数表决权的股东利用股东会决议的方式，客观上造成"绑架"或"裹挟"其他股东，使其合理期待的利益落空或者蒙受额外风险的威胁时，后者可以利用本条规定的救济措施，实现退出公司的目的。

**回购股权的处理**：

| 处理方式 | 法律依据 |
|----------|----------|
| 申请减少注册资本 | 《公司法》第74条规定的处理方式 |
| 6个月内转让或注销 | 参照《公司法》第142条第3款对股份公司的规定 |
| 调解收购 | 《公司法规定（二）》第5条规定，在公司解散诉讼中调解时公司可收购股东的股份 |

**指导案例96号**（宋某某诉西安市大华餐饮有限公司股东资格确认纠纷案）：国有企业改制为有限责任公司，其初始章程对股权转让进行了限制，明确约定了公司回购条款，只要不违反公司法等法律强制性规定，可认定为有效。有限责任公司按照初始章程约定，支付合理对价回购股东股权，且通过转让给其他股东等方式进行合理处置的，人民法院应予支持。

### 十、自然人股东死亡后的股东资格继承（第75条）

**条文原文**：自然人股东死亡后，其合法继承人可以继承股东资格；但是，公司章程另有规定的除外。

**理解要点**：

| 要点 | 内容 |
|------|------|
| 一般原则 | 合法继承人可以继承股东资格 |
| 章程另设规定 | 允许章程对股东资格继承办法作出其他安排 |
| 限制性约束 | 公司章程只能限制继承人继承股东资格，不得违反《民法典》继承编的基本原则剥夺继承人获得与股权价值相适应的财产对价的权利 |

**特殊情形**：

| 情形 | 处理 |
|------|------|
| 无民事行为能力人、限制民事行为能力人 | 可以继承股东资格，其股权由法定代理人代为行使 |
| 公务员 | 不得继承股权成为公司股东，只能继承与股权相对应的财产权益 |
| 股东资格继承后公司只有1个股东 | 引导及时将部分或全部股权转出或变更为一人公司 |
| 继承导致股东人数超过50人 | 协商由部分继承人继承股东资格；协商不成的，变更组织形式为股份有限公司；协商不成且公司不愿变更的，不得同时确认各继承人的股东资格 |

**类案适用**（启东市建都房地产开发有限公司与周某1股东资格确认纠纷案）：公司曾规定自然人股东死亡后合法继承人可以继承股东资格，后删除该条款并增加规定股东应及时办理股权转让手续。结合公司高度人合性和封闭性特征以及死亡股东应及时办理股权转让手续的表述，可以认定排除股东资格继承是章程的真实意思表示。

### 第二部分 股份有限公司的设立（第76-97条）

### 十一、股份有限公司的设立条件（第76条）

**6项法定条件**：

| 序号 | 条件 |
|------|------|
| 1 | 发起人符合法定人数（2人以上200人以下） |
| 2 | 有符合公司章程规定的全体发起人认购的股本总额或者募集的实收股本总额 |
| 3 | 股份发行、筹办事项符合法律规定 |
| 4 | 发起人制订公司章程，采用募集方式设立的经创立大会通过 |
| 5 | 有公司名称，建立符合股份有限公司要求的组织机构 |
| 6 | 有公司住所 |

**股东出资最低限额的演变**：

| 时间 | 制度 |
|------|------|
| 1993年《公司法》 | 法定资本最低限额1000万元 |
| 2005年《公司法》 | 法定资本最低限额500万元；实行分期缴纳制 |
| 2013年《公司法》修正 | 取消法定资本最低限额；实行认缴制 |
| 2018年《公司法》修正 | 沿用2013年规定 |

**特殊行业的实缴要求**：现行法律、行政法规等规定了银行业金融机构、证券公司、期货公司、基金管理公司、保险公司等公司实行注册资本实缴登记制。

### 十二、股份有限公司的设立方式（第77条）

**两种设立方式对比**：

| 比较项 | 发起设立 | 募集设立 |
|--------|----------|----------|
| 定义 | 由发起人认购公司应发行的全部股份而设立公司 | 由发起人认购应发行股份的一部分，其余股份向社会公开募集或向特定对象募集 |
| 适用范围 | 任何类型公司（含有限责任公司） | 仅股份有限公司 |
| 优势 | 缩短设立时间、减少费用、增加稳定性 | 短期内筹集巨额资本、缓解发起人出资压力 |
| 不足 | 规模有限（需发起人资金充足） | 程序复杂、费用高、风险大、股权高度分散 |
| 注册资本 | 全体发起人认购的股本总额 | 实收股本总额 |

**募集设立的类型**：

| 类型 | 内容 |
|------|------|
| 公募设立 | 向不特定对象发行证券（公开发行） |
| 私募设立 | 向特定对象发行证券（累计不超过200人），如天使投资和风险投资 |

### 十三、发起人（第78条）

**条文原文**：设立股份有限公司，应当有二人以上二百人以下为发起人，其中须有半数以上的发起人在中国境内有住所。

**发起人的三大法律特征**（《公司法规定（三）》第1条）：

| 特征 | 内容 |
|------|------|
| 为设立公司而签署公司章程 | 只有公司章程的签署人才能对公司章程的制定和通过具有实质性影响 |
| 向公司认购出资或者股份 | 购股人只要作出了认购行为，无论是否实际缴纳出资，均可认定为公司发起人 |
| 履行公司设立职责 | 发起人基于其发起人身份，依照法律规定和合同约定享有权利负有义务承担责任 |

**发起人人数的演变**：

| 时间 | 制度 |
|------|------|
| 1993年《公司法》 | 5人以上，国有企业改建可少于5人 |
| 2005年《公司法》 | 2人以上200人以下（增设上限） |
| 2013年《公司法》 | 沿用2005年规定 |
| 2021年12月《公司法（修订草案）》 | 承认一人股份有限公司 |

**资格要求**：

| 要求 | 内容 |
|------|------|
| 行为能力 | 必须完全民事行为能力人；无民事行为能力及限制民事行为能力人不得作为发起人 |
| 国籍 | 自然人或法人、中国人或外国人均可作为发起人 |
| 住所 | 须有半数以上在中国境内有住所 |

**半数以上在中国境内有住所的立法理由**：

| 理由 | 内容 |
|------|------|
| 防止外国人操纵 | 防止公司被外国人操纵 |
| 负责任地履行设立职责 | 能够使发起人确实负责任，经常执行设立中公司的事务 |
| 便于监督管理 | 便于国家监督管理，防止发起人利用设立股份有限公司损害社会公众利益 |

### 十四、发起人义务（第79条）

**条文原文**：股份有限公司发起人承担公司筹办事务。发起人应当签订发起人协议，明确各自在公司设立过程中的权利和义务。

**筹办事务的内容**：制定公司章程、依法向国务院证券监督管理机构申请核准公开发行股份、依法选举董事会和监事会、依法公告招股说明书、制作认股书、与证券公司签订承销协议、与银行签订代收股款协议、依法召开公司创立大会、申请设立登记等。

**发起人协议与公司章程的关系**：

| 比较项 | 发起人协议 | 公司章程 |
|--------|------------|----------|
| 性质 | 合伙协议 | 公司自治性质的根本规则 |
| 是否必备 | 强制性文件（股份公司） | 必备性文件 |
| 要式性 | 不要式 | 要式 |
| 效力范围 | 仅在发起人之间有效 | 所有股东之间、股东与公司之间、公司管理机构与公司之间 |
| 效力期间 | 公司设立过程 | 公司成立后的整个存续过程 |

### 十五、股份有限公司的注册资本（第80条）

**两种设立方式的注册资本对比**：

| 设立方式 | 注册资本 | 是否允许分期缴纳 |
|----------|----------|------------------|
| 发起设立 | 全体发起人认购的股本总额 | 允许（缴足前不得向他人募集） |
| 募集设立 | 实收股本总额 | 不允许（一次性全部发行并募足） |

**募集设立不允许分期缴纳的原因**：通过向社会公众募集股份，可以筹资设立公司，允许发起人分期缴纳出资的意义不大。同时，募集设立的股份有限公司，其股票有可能在证券交易所上市交易，允许股东分期缴纳出资则很难保证出资到位，也不利于保护社会公众利益。

**法律对实缴资本另有规定的除外**：银行业金融机构、证券公司、期货公司、基金管理公司、保险公司等公司实行注册资本实缴登记制。

### 十六、股份有限公司章程的记载事项（第81条）

**12项绝对必要记载事项**：

| 序号 | 事项 |
|------|------|
| 1 | 公司名称和住所 |
| 2 | 公司经营范围 |
| 3 | 公司设立方式 |
| 4 | 公司股份总数、每股金额和注册资本 |
| 5 | 发起人的姓名或者名称、认购的股份数、出资方式和出资时间 |
| 6 | 董事会的组成、职权和议事规则 |
| 7 | 公司法定代表人 |
| 8 | 监事会的组成、职权和议事规则 |
| 9 | 公司利润分配办法 |
| 10 | 公司的解散事由与清算办法 |
| 11 | 公司的通知和公告办法 |
| 12 | 股东大会会议认为需要规定的其他事项 |

**任意记载事项**：在不违反法律、行政法规强行性规定和社会公共利益的前提下，经由章程制定者共同同意自愿记载于公司章程的事项。

### 十七、发起设立程序（第83条）

**四个程序步骤**：

| 步骤 | 内容 |
|------|------|
| 1 | 发起人书面认足公司章程规定其认购的股份 |
| 2 | 按照公司章程规定缴纳出资（非货币财产出资的应当依法办理财产权的转移手续） |
| 3 | 发起人认足出资后，选举董事会和监事会 |
| 4 | 由董事会向公司登记机关报送公司章程及法律、行政法规规定的其他文件，申请设立登记 |

**出资违约的法律后果**：

| 责任形式 | 内容 |
|----------|------|
| 违约责任 | 发起人不依照规定缴纳出资的，应当按照发起人协议承担违约责任 |
| 追缴出资 | 公司、守约股东可以向出资违约的股东行使追缴出资权，要求其补缴出资 |
| 损害赔偿 | 违约股东应向守约股东承担违约的损害赔偿责任 |
| 除名 | 公司可经催告后以股东会决议解除未履行出资义务股东的股东资格 |

### 十八、募集设立的特别要求（第84条）

**条文原文**：以募集设立方式设立股份有限公司的，发起人认购的股份不得少于公司股份总数的百分之三十五；但是，法律、行政法规另有规定的，从其规定。

**理解要点**：

| 要点 | 内容 |
|------|------|
| 35%基数 | 拟设立股份有限公司的股份总额 |
| 适用对象 | 仅限于募集设立方式设立的股份有限公司 |
| 出资形式 | 货币或可用货币估价并可依法转让的非货币财产 |

**35%限制的立法理由**：

| 理由 | 内容 |
|------|------|
| 防止发起人逃避出资 | 防止发起人只认购名义股份、遏制完全凭借他人资本开办公司而自己不承担财产责任的投机行为 |
| 保持一定比例的股份由社会公众认购 | 保持股份有限公司的公众性 |

### 十九、公开募集程序（第85条）

**程序要点**：

| 步骤 | 内容 |
|------|------|
| 1 | 必须公告招股说明书（要约邀请） |
| 2 | 制作认股书 |
| 3 | 认股人在认股书上填写认购股数、金额、住所，并签名、盖章 |
| 4 | 认股人按所认购股数缴纳股款 |
| 5 | 经依法设立的证券公司承销（第87条） |
| 6 | 同银行签订代收股款协议（第88条） |

**认股人未按期缴纳的法律后果**（《公司法规定（三）》第6条）：

| 情形 | 法律后果 |
|------|----------|
| 经公司发起人催缴后在合理期间内仍未缴纳 | 公司发起人对该股份另行募集有效 |
| 给公司造成损失 | 公司请求认股人承担赔偿责任 |

### 二十、招股说明书内容（第86条）

### 二十一、证券公司承销（第87条）

| 方式 | 内容 |

| 包销 | 证券公司将发行人的证券按照协议全部购入或者在承销期结束时将售后剩余证券全部自行购入的承销方式 |

**承销期限**：证券公司代销、包销期最长不得超过90日。

**承销协议应载明的事项**：

| 3 | 代销、包销的期限及起止日期 |

| 5 | 代销、包销的费用和结算办法 |
| 6 | 违约责任 |
| 7 | 国务院证券监督管理机构规定的其他事项 |

### 二十二、代收股款协议（第88条）

**条文要点**：

| 要点 | 内容 |
|------|------|
| 协议主体 | 发起人与银行 |
| 协议性质 | 委托合同 |
| 银行义务 | 按协议代收和保存股款；向缴纳股款的认股人出具收款单据；向有关部门出具收款证明 |

### 二十三、创立大会（第89-91条）

**创立大会的召开**：

| 要点 | 内容 |
|------|------|
| 召开时间 | 自股款缴足之日起30日内 |
| 通知期限 | 创立大会召开15日前通知各认股人或公告 |
| 出席要求 | 代表股份总数过半数的发起人、认股人出席，方可举行 |
| 性质 | 设立中公司的决议机关，是股东大会的前身 |

**创立大会的7项职权**：

| 序号 | 职权 |
|------|------|
| 1 | 审议发起人关于公司筹办情况的报告 |
| 2 | 通过公司章程 |
| 3 | 选举董事会成员 |
| 4 | 选举监事会成员 |
| 5 | 对公司的设立费用进行审核 |
| 6 | 对发起人用于抵作股款的财产的作价进行审核 |
| 7 | 发生不可抗力或者经营条件发生重大变化直接影响公司设立的，可以作出不设立公司的决议 |

**决议通过原则**：创立大会对所列事项作出决议，必须经出席会议的认股人所持表决权过半数通过。

**不得抽回股本的3种例外情形**（第91条）：

| 情形 | 内容 |
|------|------|
| 1 | 未按期募足股份 |
| 2 | 发起人未按期召开创立大会 |

| 序号 | 文件 |

### 二十五、资本充实责任（第93条）

**两类资本充实责任**：

| 类型 | 责任主体 |
|------|----------|
| 缴纳担保责任 | 公司成立后，发起人未按章程规定缴足出资的，应当补缴；其他发起人承担连带责任 |
| 差额填补责任 | 公司成立后，发现非货币财产实际价额显著低于章程所定价额的，由交付出资的发起人补足其差额；其他发起人承担连带责任 |

**差额填补责任的法律基础**：确立发起人承担资本充实责任，一方面是因为在公司设立过程中，发起人享有其他认股人所不能享有的权利，如以非货币财产出资的权利等，本着权利义务相对等的原则，发起人应当承担比其他股东更重的责任；另一方面，通过发起人之间建立出资担保关系，保证公司资本到位，以保护公司债权人利益。

### 二十六、发起人责任（第94条）

**三类责任**：

| 序号 | 责任 | 性质 |
|------|------|------|
| 1 | 公司不能成立时，对设立行为所产生的债务和费用负连带责任 | 对外连带责任 |
| 2 | 公司不能成立时，对认股人已缴纳的股款，负返还股款并加算银行同期存款利息的连带责任 | 对内连带责任 |
| 3 | 公司设立过程中，由于发起人的过失致使公司利益受到损害的，应当对公司承担赔偿责任 | 对公司单独责任（非连带责任） |

### 二十七、有限责任公司变更为股份有限公司（第95条）

**条文原文**：有限责任公司变更为股份有限公司时，折合的实收股本总额不得高于公司净资产额。有限责任公司变更为股份有限公司，为增加资本公开发行股份时，应当依法办理。

**理解要点**：

| 要点 | 内容 |
|------|------|
| 净资产限额 | 折合的实收股本总额不得高于公司净资产额 |
| 公开发行 | 增加资本公开发行股份的，应当向国务院证券监督管理机构递交募股申请并报送有关文件；应当聘请保荐机构；应当制作并公告招股说明书；应当制作认股书；应当与证券承销机构签订承销协议，同银行签订代收股款协议；必须经法定验资机构验资并出具证明 |

**净资产评估的必要性**：在市场价格有重大变动的情况下，公司原有资产中有些财产因贬值而使其价值额下降，有些财产因升值而使价值额增加。因此，为了准确地核定公司的净资产额，需要按照国家规定的通行的会计准则和财务通则，对公司资产的现值进行重新评估。

## ⚠️ 司法适用难点

### 难点一：股东优先购买权与股权转让合同效力的关系

**主流观点**（依《民商审判会议纪要》第9条）：

| 情形 | 合同效力 |
|------|----------|
| 转让人与第三人恶意串通损害其他股东优先购买权 | 合同无效 |
| 一般情况下未履行第71条第2、3款义务 | 合同有效 |

**主要理由**：股东优先购买权的行使目的在于通过保障其他股东优先购买权获得拟转让股份而维护公司内部信赖关系，法律所要否定的是股东以外的股权受让人优先于公司其他股东取得公司股份的行为，而不是转让股东与股东以外的股权受让人之间签订的股权转让合同的效力。

### 难点二：股权转让生效时点的认定

**三个时点**：

| 时点 | 法律效力 |
|------|----------|
| 股权转让合同生效 | 自合同签订时生效，附条件自条件成就时生效 |
| 股东名册变更 | 受让人取得股权的标志 |
| 工商变更登记 | 对抗善意相对人的效力 |

**三者的关系**：股权转让合同生效时间早于股权变动生效时间；合同效力不受股东名册变更或工商登记影响。

### 难点三：国有股权转让的特殊程序

**国有股权转让的特殊规定**：

| 特殊规定 | 法律依据 |
|----------|----------|
| 严格的股权转让审批制度 | 《企业国有资产交易监督管理办法》第7-8条 |
| 经资产评估确定转让价格 | 《企业国有资产法》第55条 |
| 公开进场交易 | 《企业国有资产法》第54条第2款 |

**违反程序的效力**：未按规定进场交易导致损害国家利益的，国有资产监督管理机构或者企业国有产权转让相关批准机构有权要求转让方终止股权转让活动，必要时可依法向人民法院提起诉讼，确认股权转让行为无效。

### 难点四：异议股东回购请求权的行使期限

**90日法定期间的法律性质**（依《公司法规定（一）》第3条）：超过公司法规定期限的，人民法院不予受理。此时股东丧失的是诉权，其丧失的是进入到诉讼程序的权利，而不是胜诉权利的消灭，也不是实体权利的消灭。可见，此处的期限并不是诉讼时效，也不是除斥期间，应当被称为商法上特殊的起诉期限。

**决议通过之日的确定**：

| 情形 | 决议通过之日 |
|------|--------------|
| 以召开股东会会议形式 | 法定比例的股东表决同意提案之日 |
| 传签书面文件通过决议 | 最后一个应当参加表决的股东在传签文件上签章的日期 |

### 难点五：发起人责任与公司设立失败的处理

**公司不能成立时的处理**：

| 责任 | 内容 |
|------|------|
| 对外债务和费用 | 发起人承担连带责任 |
| 认股人已缴股款 | 发起人负返还股款并加算银行同期存款利息的连带责任 |
| 设立过程中发起人过失致公司利益受损 | 过错发起人对公司承担赔偿责任（非连带责任） |

**发起人责任与普通合伙人责任的关系**：发起人是基于以设立公司为目的的合伙协议来进行公司的筹划和设立活动的。发起人之间是一种合伙关系，各发起人都是权利义务的主体。

### 难点六：股份公司设立与募集设立中35%比例的适用

**适用要点**：

| 要点 | 内容 |
|------|------|
| 适用对象 | 仅募集设立的股份有限公司 |
| 35%基数 | 拟设立股份有限公司的股份总额 |
| 法律适用 | 法律、行政法规另有规定从其规定 |

**违反35%规定的效力**（张某某、黄某1合同纠纷案）：发起人认缴的股份未达"不得少于公司股份总数的百分之三十五"要求，发起人协议书违反法律强制性规定，依法无效。

## ❓ 实务问答

> **Q1：有限责任公司股东之间是否可以相互转让股权？**
>
> A：有限责任公司的股东之间可以相互转让其全部或者部分股权，无需其他股东同意（第71条第1款）。

> **Q2：股东向股东以外的人转让股权需要哪些程序？**
>
> A：① 经其他股东过半数同意（股东多数决而非资本多数决）；② 书面通知其他股东征求同意；③ 其他股东自接到书面通知之日起满30日未答复的，视为同意；④ 半数以上不同意转让的，不同意的股东应当购买，否则视为同意；⑤ 经股东同意转让的股权，在同等条件下，其他股东有优先购买权（第71条）。

> **Q3：股东优先购买权的"同等条件"如何认定？**
>
> A：根据《公司法规定（四）》第18条，应当考虑转让股权的数量、价格、支付方式及期限等因素。司法实务采"相对同等说"，而非"绝对同等说"。

> **Q4：侵犯优先购买权的股权转让合同效力如何？**
>
> A：依《民商审判会议纪要》第9条，除转让股东和股东以外的股权受让人恶意串通损害其他股东优先购买权订立的合同无效外，一般情况下，即使未履行《公司法》第71条第2款、第3款的义务侵犯了其他股东的优先购买权，该合同也是有效的。

> **Q5：股权转让合同何时生效？股权何时转移？**
>
> A：股权转让合同自签订时生效；股权变动以股东名册变更为标志；未经工商变更登记的，不得对抗善意相对人（《民商审判会议纪要》第8条）。

> **Q6：异议股东在什么情形下可以请求公司收购股权？**
>
> A：① 公司连续5年不向股东分配利润，而公司该5年连续盈利，并且符合分配利润条件的；② 公司合并、分立、转让主要财产的；③ 公司章程规定的营业期限届满或者章程规定的其他解散事由出现，股东会会议通过决议修改章程使公司存续的。决议通过之日起60日内协议，90日内诉讼（第74条）。

> **Q7：自然人股东死亡后股东资格如何继承？**
>
> A：合法继承人可以继承股东资格；但是，公司章程另有规定的除外（第75条）。继承人如为无民事行为能力人或限制民事行为能力人，其股权可由法定代理人代为行使；公务员不得继承股东资格，只能继承与股权相对应的财产权益。

> **Q8：股份有限公司设立的6项法定条件是什么？**
>
> A：① 发起人符合法定人数（2人以上200人以下，半数以上在中国境内有住所）；② 有符合公司章程规定的全体发起人认购的股本总额或者募集的实收股本总额；③ 股份发行、筹办事项符合法律规定；④ 发起人制订公司章程，采用募集方式设立的经创立大会通过；⑤ 有公司名称，建立符合股份有限公司要求的组织机构；⑥ 有公司住所（第76条）。

> **Q9：股份有限公司设立的方式有哪些？**
>
> A：① 发起设立（由发起人认购公司应发行的全部股份）；② 募集设立（由发起人认购应发行股份的一部分，其余股份向社会公开募集或向特定对象募集）（第77条）。

> **Q10：股份有限公司发起人的人数和资格要求是什么？**
>
> A：2人以上200人以下为发起人，其中须有半数以上的发起人在中国境内有住所。发起人必须具有完全民事行为能力，自然人或法人、中国人或外国人均可作为发起人（第78条）。

> **Q11：发起设立和募集设立在注册资本上有什么区别？**
>
> A：发起设立的注册资本为全体发起人认购的股本总额（允许分期缴纳）；募集设立的注册资本为实收股本总额（不允许分期缴纳，必须一次性全部发行并募足）（第80条）。

> **Q12：募集设立时发起人认购股份的下限是多少？**
>
> A：发起人认购的股份不得少于公司股份总数的35%；法律、行政法规另有规定的，从其规定（第84条）。

> **Q13：发起人向社会公开募集股份应当履行哪些程序？**
>
> A：① 公告招股说明书；② 制作认股书；③ 由依法设立的证券公司承销并签订承销协议；④ 同银行签订代收股款协议；⑤ 股款缴足后必须经依法设立的验资机构验资并出具证明；⑥ 自股款缴足之日起30日内主持召开公司创立大会（第85-89条）。

> **Q14：创立大会有哪些职权？**
>
> A：① 审议发起人关于公司筹办情况的报告；② 通过公司章程；③ 选举董事会成员；④ 选举监事会成员；⑤ 对公司的设立费用进行审核；⑥ 对发起人用于抵作股款的财产的作价进行审核；⑦ 发生不可抗力或者经营条件发生重大变化直接影响公司设立的，可以作出不设立公司的决议（第90条）。

> **Q15：发起人对公司不能成立承担哪些责任？**
>
> A：① 对设立行为所产生的债务和费用负连带责任；② 对认股人已缴纳的股款，负返还股款并加算银行同期存款利息的连带责任；③ 在公司设立过程中，由于发起人的过失致使公司利益受到损害的，应当对公司承担赔偿责任（第94条）。

> **Q16：股份有限公司的资本充实责任是什么？**
>
> A：① 缴纳担保责任：公司成立后发起人未按章程规定缴足出资的，应当补缴，其他发起人承担连带责任；② 差额填补责任：公司成立后，发现非货币财产实际价额显著低于章程所定价额的，由交付出资的发起人补足差额，其他发起人承担连带责任（第93条）。

> **Q17：有限责任公司变更为股份有限公司应当注意什么？**
>
> A：① 折合的实收股本总额不得高于公司净资产额；② 必须对公司资产进行评估和验资；③ 增加资本公开发行股份的，应当依法向国务院证券监督管理机构递交募股申请并报送有关文件等（第95条）。

> **Q18：股份有限公司应当置备哪些文件？**
>
> A：公司应当将公司章程、股东名册、公司债券存根、股东大会会议记录、董事会会议记录、监事会会议记录、财务会计报告置备于本公司（第96条）。

> **Q19：股份有限公司股东享有哪些查阅权和质询权？**
>
> A：股东有权查阅公司章程、股东名册、公司债券存根、股东大会会议记录、董事会会议决议、监事会会议决议、财务会计报告，对公司的经营提出建议或者质询（第97条）。但与有限责任公司股东不同，股份有限公司股东没有查阅会计账簿的权利，也没有复制权。

> **Q20：发起人协议与公司章程有什么不同？**
>
> A：发起人协议在性质上属于合伙协议，调整发起人之间的关系，仅在发起人之间具有法律约束力，调整公司设立过程；公司章程是公司自治性质的根本规则，调整所有股东之间、股东与公司之间、公司管理机构与公司之间的法律关系，效力及于公司成立后的整个存续过程。
