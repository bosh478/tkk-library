# 《侵权责任法教程》第二十二章 高度危险责任

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第二十二章 高度危险责任 |
| 行号范围 | 6032-6535（书籍）|
| 核心议题 | 高度危险责任的范围、各类高度危险行为的归责 |
| 涵盖 | 7 节内容（民用核设施、民用航空器、高度危险物、高度危险活动等）|

## 🎯 核心论点

**高度危险责任 = 无过错责任 + 有限免责**

**《民法典》第1236条**：
> 从事高度危险作业造成他人损害的，应当承担侵权责任。

**理论依据**：
- **危险开启理论**（开启危险源者应承担危险现实化的责任）
- **报偿理论**（从危险活动中获益者应承担损失）
- **损失分担理论**（通过保险、价格分散风险）

**两类免责情形**（极其有限）：
1. 不可抗力（特定情形）
2. 受害人故意

---

## 第一节 概述

## 一、高度危险责任的归责原则

**无过错责任原则**（《民法典》第1236条）

**理由**：
- 高度危险活动对周围环境具有潜在的高度危险性
- 一旦危险现实化，损害通常巨大
- 受害人难以证明加害人过错
- 加害人可通过保险、价格分散风险

## 二、高度危险责任的范围

**《民法典》第八章"高度危险责任"**（第1236-1244条）：

| 类型 | 法条 |
|------|------|
| **高度危险作业的一般规定** | 第1236条 |
| **民用核设施** | 第1237条 |
| **民用航空器** | 第1238条 |
| **高度危险物（占有、使用）**| 第1239-1241条 |
| **高度危险活动（高空、高压、地下挖掘等）**| 第1242条 |
| **遗失、抛弃高度危险物** | 第1243条 |
| **赔偿限额** | 第1244条 |

## 三、免责事由（极其有限）

| 免责事由 | 适用范围 |
|---------|----------|
| **不可抗力** | 特定情形（《民法典》第1237条民用核设施、第1238条民用航空器）|
| **受害人故意** | 通用免责事由 |
| **战争** | 民用核设施特有 |

**注意**：民法典颁布后，原侵权责任法中关于"受害人对损害的发生有重大过失"作为免责事由的规定**已被删除**。

---

## 第二节 民用核设施损害责任

**《民法典》第1237条**：
> 民用核设施或者运入运出核设施的核燃料、核废料发生核事故造成他人损害的，民用核设施的营运单位应当承担侵权责任。但是，能够证明损害是因战争等情形或者受害人故意造成的，不承担责任。

**核心要素**：

| 要素 | 内容 |
|------|------|
| **责任主体** | 民用核设施的营运单位 |
| **归责原则** | 无过错责任（绝对责任）|
| **免责事由** | 战争等情形 + 受害人故意 |
| **赔偿限额** | 依法有最高赔偿限额规定的，依其规定，但行为人有故意或重大过失的除外 |

**国际公约参照**：
- 1960年《核能领域第三方责任公约》（巴黎公约）
- 1963年《维也纳核损害民事责任公约》
- 1997年《补充赔偿公约》

---

## 第三节 民用航空器损害责任

**《民法典》第1238条**：
> 民用航空器造成他人损害的，民用航空器的经营者应当承担侵权责任。但是，能够证明损害是因受害人故意造成的，不承担责任。

**核心要素**：

| 要素 | 内容 |
|------|------|
| **责任主体** | 民用航空器的经营者 |
| **归责原则** | 无过错责任 |
| **免责事由** | 受害人故意 |
| **不可抗力** | 不一定免责（依具体情形）|

**适用范围**：
- 民用航空器对地面第三人造成损害
- 飞行中航空器与其他航空器碰撞
- 航空器坠毁造成地面损害

## 第四节 高度危险物损害责任

**《民法典》第1239条**：
> 占有或者使用易燃、易爆、剧毒、高放射性、强腐蚀性、高致病性等高度危险物造成他人损害的，由占有人或者使用人承担侵权责任。能够证明损害是因受害人故意或者不可抗力造成的，不承担责任。能够证明受害人对损害的发生有重大过失的，可以减轻经营者的责任。

## 一、适用范围

**"高度危险物"的种类**（法律列举）：
- 易燃物（如汽油、酒精）
- 易爆物（如炸药、烟花爆竹）
- 剧毒物（如氰化物、农药）
- 高放射性物质（如核废料、铀矿石）
- 强腐蚀性物质（如硫酸、盐酸）
- 高致病性物质（如传染病病原体）

## 二、责任承担

| 情形 | 责任 |
|------|------|
| 一般情形 | 占有人/使用人承担责任 |
| 受害人故意 | 不承担责任 |
| 不可抗力 | 不承担责任 |
| 受害人重大过失 | 可以减轻责任 |

## 三、占有 vs 使用

| 概念 | 内涵 |
|------|------|
| **占有人** | 实际控制高度危险物者（不一定是所有人）|
| **使用人** | 正在使用高度危险物者（可能临时借用）|

---

## 第五节 高度危险活动损害责任

**《民法典》第1242条**：
> 从事高空、高压、地下挖掘活动，使用高速轨道运输工具造成他人损害的，经营者应当承担侵权责任。但是，能够证明损害是因受害人故意或者不可抗力造成的，不承担责任。

## 一、高度危险活动的种类

| 活动类型 | 典型情形 |
|---------|----------|
| **高空活动** | 高空作业、高空建筑、高空运输 |
| **高压活动** | 高压电、高压气体、高压液体 |
| **地下挖掘活动** | 地下采矿、地下隧道、地下管道施工 |
| **高速轨道运输工具** | 高速铁路、地铁、城市轻轨 |

## 二、责任承担

- 经营者承担侵权责任
- 免责：受害人故意、不可抗力

---

## 第六节 遗失、抛弃高度危险物

**《民法典》第1243条**：
> 遗失、抛弃高度危险物造成他人损害的，由所有人承担侵权责任。所有人将高度危险物交由他人管理的，由管理人和所有人承担连带责任。

**核心规则**：
- 遗失、抛弃高度危险物 → 所有人承担责任
- 所有人将高度危险物交他人管理 → 管理人与所有人连带责任

**典型情形**：
- 核废料桶遗失、被偷
- 工业废料非法倾倒
- 危险化学品运输中遗失

---

## 第七节 赔偿限额

**《民法典》第1244条**：
> 承担高度危险责任，法律规定赔偿限额的，依照其规定，但是行为人有故意或者重大过失的除外。

**重要规则**：
- 一般情形：可适用法定赔偿限额
- 例外情形：行为人有**故意或者重大过失** → **不得**适用赔偿限额

**理论依据**：
- 限额设计旨在保护高度危险行业的稳定发展
- 但行为人有可责性（故意/重大过失）时，不应享受限额保护
- 体现对受害人的倾斜保护
