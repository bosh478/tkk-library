# 案件调撤难度较大

> **数据基础**：第 1 册"案件特点五"（行 455–458）
> **关键数据**：2014–2019 判决率 74.74%，调撤率总体呈下降趋势

## 一、原文逐句（L4 段级提取）

### 1.1 调撤障碍成因（行 456）

> 由于送达、承租人经营状况恶化等原因，甚至出现承租人、担保人出逃等现象，直接阻碍了法院开展案件调解工作。

**三大障碍**：
1. 送达问题（关联"缺席审判普遍存在"）
2. 承租人经营状况恶化
3. 承租人/担保人**出逃**

### 1.2 判决率数据（行 456）

> 故2014年至2019年间上海法院此类纠纷仍以判决方式为主，占总结案数的74.74%。

**关键数据点**：

| 指标 | 数值 |
|------|------|
| 6 年判决率 | 74.74% |
| 隐含调撤率 | 25.26% |

### 1.3 调撤率趋势（行 456）

> 调撤案件数量虽逐年增多，但调撤率总体上呈现下降趋势。

**趋势定性**：
- 调撤案件**绝对数** ↑（逐年增多）
- 调撤率 ↓（总体下降）

### 1.4 调撤率下降的深层原因（行 456–457）

> 这除了公告送达等原因外，主要还因承租人经营恶化、负债严重，出租人对承租人已缺乏信心，很难接受承租人提出的宽限还款期限的调解方案，希望依法判决后尽快申请执行。

**两层原因**：

| 层级 | 原因 |
|------|------|
| 表层 | 公告送达（关联"缺席审判"） |
| **深层** | 承租人经营恶化、负债严重 → 出租人**对承租人已缺乏信心** |
| 行为表现 | 不接受宽限还款 → 依法判决 → 尽快执行 |

## 二、相比同类旧资料的核心差异

| 维度 | 本指南（行 455–458） | 旧 L1 synthesis |

| 判决率 | 74.74%（行 456） | 无 |
| 调撤率趋势 | 数量↑ / 比率↓ | 泛述"调撤难度大" |
| 深层原因 | 出租人**对承租人已缺乏信心**（行 457） | 未列 |

## 三、实务问答（FAQ）

> **Q1: 2014–2019 年上海法院融资租赁合同纠纷的判决率是多少？**
> 答：74.74%（行 456）。

> **Q2: 调撤率为何下降？**
> 答：调撤案件**绝对数**虽增多但**比率**下降；主要因承租人经营恶化、负债严重，出租人对承租人**缺乏信心**，倾向判决后申请执行（行 456–457）。

> **Q3: 出租人倾向依法判决而非调解的根本原因？**
> 答：希望依法判决后**尽快申请执行**（行 457），这是出租人利益最大化的程序选择。
