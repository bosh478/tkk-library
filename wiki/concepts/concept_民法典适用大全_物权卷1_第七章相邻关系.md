## 一、第288条·处理相邻关系的基本原则

### 法条原文

> 第二百八十八条　不动产的相邻权利人应当按照有利生产、方便生活、团结互助、公平合理的原则，正确处理相邻关系。

### 核心释义

**处理相邻关系的4项基本原则**：

| 原则 | 内容 |
|------|------|
| **有利生产** | 减少生产给对方造成的妨碍；既要定分止争，又要把对生产的影响降到最低限度 |
| **方便生活** | 以人为本，充分考虑相邻权利人的生活方便；保护相邻权利人的生存权 |
| **团结互助** | 与邻为善，互利共赢；换位思考；保持忍让和克制；遇事先友好协商 |
| **公平合理** | 权利义务平等；行使权利应在合理限度内；尊重历史形成的客观状况和先后顺序 |

**相邻关系的6个特征**：

| 特征 | 内容 |
|------|------|
| 1 | **客体不是不动产本身**，而是相邻权利人之间的权利义务关系 |
| 2 | 主体包括**所有权人、用益物权人和占有人**（自然人/法人/非法人组织之间） |
| 3 | 内容丰富：通行、引水、排水、临时占用邻地等 |
| 4 | **依附于不动产**；不动产灭失，相邻关系消灭；不因权属变更而变更 |
| 5 | 不动产**相互相邻**（地理位置毗邻） |
| 6 | 相邻权的行使以**必要便利**为限度，不得借口行使相邻权损害相邻权利人 |

**相邻关系 vs 地役权的区别**：

| 维度 | 相邻关系 | 地役权 |
|------|---------|--------|
| **不动产是否相邻** | 必须相邻 | 不要求相邻 |
| **必需性** | 维持正常生产生活的必备条件（最低标准） | 提高不动产的效益（更高标准） |
| **设立方式** | 法定，无须登记 | 书面合同设立，登记可对抗善意第三人 |

## 二、第289条·处理相邻关系的依据

### 法条原文

> 第二百八十九条　法律、法规对处理相邻关系有规定的，依照其规定；法律、法规没有规定的，可以按照当地习惯。

### 核心释义

**处理相邻关系的依据体系**：

| 层级 | 适用规则 |
|------|---------|
| 1. 法律、法规 | 有规定依规定 |
| 2. 当地习惯 | 无法可依时，按当地习惯（不得违背公序良俗） |
| 3. 基本原则（第288条） | 找不到当地习惯时，适用基本原则 |

**适用规范的方法**：

| 步骤 | 内容 |
|------|------|
| 1 | 法律、法规、司法解释有规定的，适用其规定 |
| 2 | 法律没有规定但法规有规定的，适用法规 |
| 3 | 法律、法规没有规定但司法解释有规定的，可单独适用司法解释 |
| 4 | 有效行政规章可作为参考和说理依据，但不能作为裁判依据 |
| 5 | 法律、法规、司法解释均无规定的，才可适用当地习惯 |
| 6 | 没有习惯的，按基本原则处理 |

**法律解释的适用**：

| 解释类型 | 说明 |
|---------|------|
| 法律解释 | 法律条文的延伸和具体化；效力高于行政法规 |
| 司法解释 | 最高人民法院就审判工作中具体适用法律问题作出；具普遍拘束力 |
| 部门规章 | 不与法律法规相抵触时可参照适用 |
| 地方政府规章 | 同上 |

**当地习惯的证明**：

| 原则 | 内容 |
|------|------|
| 主张方承担举证责任 | "谁主张，谁举证" |
| 法官可依职权调查 | 必要时主动调查 |
| 不得违背公序良俗 | 违反法律禁止性规定的"恶俗"不得适用 |

## 三、第290条·用水、排水相邻关系

### 法条原文

> 第二百九十条　不动产权利人应当为相邻权利人用水、排水提供必要的便利。
>
> 对自然流水的利用，应当在不动产的相邻权利人之间合理分配。对自然流水的排放，应当尊重自然流向。

### 核心释义

**用水、排水相邻关系的4项规则**：

| 规则 | 内容 |
|------|------|
| 1 | 必须提供便利（若有地理优势能够制约相邻权利人用水、排水） |
| 2 | 负有补救或补偿义务（影响相邻权利人利益） |
| 3 | "必要"便利（不提供则影响正常生产/生活；不应超过自身能力） |
| 4 | 损害的，应承担排除妨碍、赔偿损失等民事责任 |

**自然流水的利用和排放**：

| 项目 | 规则 |
|------|------|
| **自然流水的利用** | 在相邻权利人之间合理分配 |
| **自然流水的排放** | 尊重自然流向 |

**自然流水利用的4项要求**：

| 要求 | 内容 |
|------|------|
| 1 | 兼顾相邻各方的利益 |
| 2 | **生活用水优先**（《水法》第21条） |
| 3 | 顺流原则（"先近后远，由高到低"） |
| 4 | 擅自堵截或独占自然流水的，他方有权请求排除妨碍 |

### 典型案例

#### 李某敏与李某建、胡某丽、新疆生产建设兵团第五师中心团场八十三团相邻用水纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2015）民提字第144号 |
| 审理法院 | 最高人民法院 |
| 裁判要点 | 相邻用水人对于自然流水的利用应**合理分配**。在上游用水人恢复水源原状系维护自身合法权益的情况下，下游用水人未与上游草原用水人协商即挖深水渠，使得原本漫向草原的自然流水集中流向其养殖区，**并非合理利用**讼争自然水源的行为 |

## 四、第291条·通行相邻关系

### 法条原文

> 第二百九十一条　不动产权利人对相邻权利人因通行等必须利用其土地的，应当提供必要的便利。

### 核心释义

**"必须"的含义**：

| 含义 | 内容 |
|------|------|
| 必要性 | 一方权利的行使须以利用相邻一方的土地为条件 |
| 不利用的影响 | 若不利用相邻一方的土地，就无法行使自己的民事权利 |
| 范围 | 包括土地和建筑物（城镇用地、农田、农村宅基地、林地、草地等） |
| 必要便利 | 留出能够正常出入的通道；不得设置障碍或封堵 |

**邻地通行权的3个特点**：

| 特点 | 内容 |
|------|------|
| 1. 长期性 | 长期路过性质，不发生固定、全面占有 |
| 2. 无需合同 | 一般不用订立合同 |
| 3. 一般无偿 | 除造成损失外，行使邻地通行权一般是无偿的 |

**对邻地通行权的4项限制**：

| 限制 | 内容 |
|------|------|
| 1 | 选择最为经济合理的路线（走老路；季节性通行可不留固定道路） |
| 2 | 注意保护邻地上的财产（不得践踏青苗或毁损附着物） |
| 3 | 客观变化时改由其他路线通行 |
| 4 | 因通行造成损失的，应予赔偿 |

## 五、第292条·利用相邻土地、建筑物

### 法条原文

> 第二百九十二条　不动产权利人因建造、修缮建筑物以及铺设电线、电缆、水管、暖气和燃气管线等必须利用相邻土地、建筑物的，该土地、建筑物的权利人应当提供必要的便利。

### 核心释义

**本条规定的2种使用邻地情形**：

| 情形 | 典型情形 |
|------|---------|
| 1. 因建造、修缮建筑物而临时使用邻地 | 临时搭建脚手架、工棚、工作平台；堆放建筑材料；挖掘管线地沟 |
| 2. 在邻地上铺设管线 | 电线、电缆、水管、暖气和燃气管线 |

**"临时利用"vs"邻地通行权"的区别**：

| 维度 | 临时利用邻地 | 邻地通行权 |
|------|--------------|------------|
| 时间 | 临时（施工期间） | 长期 |
| 是否订立合同 | 往往需要约定 | 一般不需要 |
| 有偿/无偿 | 因造成损害需补偿 | 一般无偿 |

**使用邻地需满足的4个条件**：

| 条件 | 内容 |
|------|------|
| 1 | 确有需要（提供便利过程中未遭受损失的，通常不应是有偿的） |
| 2 | 谨慎行使相邻权（优选修建施工方案，减少给相邻权利人造成影响） |
| 3 | 注意保护相邻权利人的利益（双方可约定利用范围、用途和期限） |
| 4 | 施工完毕后及时清理现场，恢复原状 |

### 典型案例

#### 陈某平与广东广佛轨道交通有限公司相邻关系纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2016）粤01民终9号 |
| 审理法院 | 广东省广州市中级人民法院 |
| 来源 | 《人民法院案例选》2018年第5辑 |
| 裁判要点 | 地铁施工属于涉及社会公共利益的重大工程，相邻关系一方对公共利益工程建设造成的个人利益受损害负有**必要容忍义务**，不应支持其损失分担主张 |

## 六、第293条·通风、采光和日照

### 法条原文

> 第二百九十三条　建造建筑物，不得违反国家有关工程建设标准，不得妨碍相邻建筑物的通风、采光和日照。

### 核心释义

**判断妨碍通风、采光和日照的标准**：

| 标准 | 内容 |
|------|------|
| **违反国家工程建设标准** | 超出社会一般人的容忍限度，受害人可主张排除妨碍和损害赔偿 |
| **符合国家建设标准** | 即使造成一定程度的妨碍，相邻建筑物所有人或利用人负有容忍义务 |

**判断标准的类型化**：

| 妨碍程度 | 是否构成妨碍 |
|---------|------------|
| 超出社会一般人的容忍限度 | **构成妨碍**（排除妨碍、损害赔偿） |
| 未超出一般人容忍限度 | **不构成妨碍**（容忍义务） |

**国家工程建设标准示例**（《城市居住区规划设计标准》）：

| 情形 | 日照标准 |
|------|---------|
| 老年人居住建筑 | 不应低于冬至日日照时数2小时 |
| 在原设计建筑外增加任何设施 | 不应使相邻住宅原有日照标准降低（既有住宅无障碍改造加装电梯除外） |
| 旧区改建项目内新建住宅建筑 | 不应低于大寒日日照时数1小时 |

### 典型案例

#### 南京国资绿地金融中心有限公司与陈某生相邻关系纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2016）苏01民终20号 |
| 审理法院 | 江苏省南京市中级人民法院 |
| 裁判要点 | 房屋在大厦建成后日照时间明显减少，低于国家标准（大寒日累计日照时间大于等于2小时）。阳光之于生命非常重要，陈某生作为房屋产权人，其**日照权应受法律保护** |

## 七、第294条·不可量物侵害

### 法条原文

> 第二百九十四条　不动产权利人不得违反国家规定弃置固体废物，排放大气污染物、水污染物、土壤污染物、噪声、光辐射、电磁辐射等有害物质。

### 核心释义

**不可量物侵害的7类形式**：

| 类别 | 内容 |
|------|------|
| 1. 固体废物 | 丧失利用价值或被抛弃的固态/半固态物品 |
| 2. 大气污染物 | 煤烟、废气、粉尘、恶臭等 |
| 3. 水污染物 | 超过水污染物排放标准的排放 |
| 4. 土壤污染物 | 引起土壤化学、物理、生物等方面特性改变的物质 |
| 5. 噪声 | 干扰周围生活环境的声音 |
| 6. 光辐射 | 强光、眩光等（如LED显示屏） |
| 7. 电磁辐射 | 电磁波等 |

**不可量物侵害的特征**：

| 特征 | 内容 |
|------|------|
| 难以衡量性 | 没有一定形态，不能用传统方式计量 |
| 一定程度的危害性 | 对相邻不动产造成干扰性妨害或损害 |
| 从物性 | 罗马法即有规定 |

**相邻关系 vs 环境侵权的区分**：

| 维度 | 相邻污染侵害（第294条） | 环境侵权 |
|------|------------------------|----------|
| 归责原则 | 违反国家规定为前提（违法性要件） | 无过错责任 |
| 适用范围 | 个人/家庭生活排放污染物 | 法人、非法人组织及自然人生产经营过程中排放污染物 |
| 是否合规排放 | 合规可能免责 | 合规不能免责（违法性要件被排除） |

**判断"相邻污染侵害"的容忍限度**：

| 因素 | 内容 |
|------|------|
| 被侵害利益的种类、性质 | 基本生存权 vs 一般利益 |
| 被侵害程度 | 现实紧迫的危险 vs 抽象可能性 |
| 加害行为样态 | 持续性 vs 一次性 |
| 加害方和受害方具体情况 | 经济地位、影响范围 |
| 不动产利用的先后关系 | 先建后建 / 历史形成 |
| 污染者所从事行为的社会价值和必要性 | 公共利益 vs 私人利益 |

### 指导案例

#### 指导案例128号·李劲诉华润置地（重庆）有限公司环境污染责任纠纷案

| 项目 | 内容 |
|------|------|
| 发布时间 | 2019年12月26日 |
| 关键词 | 光污染损害认定+可容忍度 |
| 裁判要点 | 由于光污染对人身的伤害具有潜在性、隐蔽性和个体差异性等特点，人民法院认定光污染损害，应当依据国家标准、地方标准、行业标准，是否干扰他人正常生活、工作和学习，以及是否超出**公众可容忍度**等进行综合认定。对于公众可容忍度，可以根据周边居民的反应情况、现场的实际感受及专家意见等判断 |

## 八、第295条·维护相邻不动产安全

### 法条原文

> 第二百九十五条　不动产权利人挖掘土地、建造建筑物、铺设管线以及安装设备等，不得危及相邻不动产的安全。

### 核心释义

**危及相邻不动产安全的6种典型情形**：

| 情形 | 内容 |
|------|------|
| 1 | 挖掘土地时避免使相邻土地的地基发生动摇或动摇的危险 |
| 2 | 在疆界线附近埋设管道、电缆、电线等时预防土沙崩溃、渗漏 |
| 3 | 种植的竹木根枝伸延，危及另一方建筑物的安全和正常使用 |
| 4 | 建筑物有倒塌的危险，威胁到邻居的生命财产安全 |
| 5 | 堆放易燃、易爆、剧毒、放射、恶臭物品时保持安全距离或采取预防措施 |
| 6 | 因管线安设关系产生的纠纷（如水管渗漏等） |

**"危及"程度的三种类型**：

| 类型 | 处理 |
|------|------|
| 现实损害 | 赔偿经济损失 |
| 现实紧迫危险 | 消除危险 |
| 抽象可能性 | 不构成"危及"相邻不动产的安全 |

## 九、第296条·利用相邻不动产时尽量避免损害

### 法条原文

> 第二百九十六条　不动产权利人因用水、排水、通行、铺设管线等利用相邻不动产的，应当尽量避免对相邻的不动产权利人造成损害。

### 核心释义

**"尽量避免"必须满足的4个条件**：

| 条件 | 内容 |
|------|------|
| 1. 必要性 | 无其他方式能够避免损害 |
| 2. 有效性 | 造成损害能够有效实现相邻权 |
| 3. 手段的轻微性 | 最小损害原则（考虑必要性、有效性等） |
| 4. 相邻权的优越性 | 行使相邻权所保护的合法权益明显大于所损害的合法权益 |

**利益衡量方法**：

| 因素 | 内容 |
|------|------|
| 1. 合法权益的定性比较 | 位阶高的合法权益优于位阶低的合法权益 |
| 2. 合法权益的量化比较 | 位阶相同时，量大的利益优于量小的利益 |
| 3. 实现相邻权的难易程度 | 与保护相邻不动产权利的难易程度综合比较 |
| 4. 社会习惯或社会观念的要求 | 当地习惯+社会政策 |

**造成损害的民事责任**（依《民法典》第179条）：

| 责任方式 | 内容 |
|---------|------|
| 停止侵害 | 行为人停止其侵害行为 |
| 排除妨碍 | 排除对相邻不动产权利人造成的不当妨碍 |
| 消除危险 | 消除可能造成损害的危险 |
| 恢复原状 | 恢复到损害发生前的状态 |
| 赔偿损失 | 金钱赔偿实际损失 |

#### 万通公司与新源公司、瑞达公司相邻排水及相邻损害防免关系纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2019）最高法民申3209号 |
| 审理法院 | 最高人民法院 |
| 来源 | 《民事审判指导与参考》2019年第4辑 |
| 裁判要点 | 负有容忍义务一方对于轻微的不利影响不能主张赔偿，必须具有"**异常性**"和"**过度性**"。相邻关系中通过限制对方不动产权能而受益的一方，对限制物权一方的牺牲无须承担责任而享有利益，并不可以认为理所当然；受限一方因此在所有类型的损失上均承担全面的赔偿责任，亦不可取 |

## ⚠️ 司法适用难点

### 难点一：相邻关系与地役权的边界

**争议**：相邻通行权与地役权的区分？

**主流观点**：
- 相邻通行权基于**法定相邻关系**，无需合同
- 地役权基于**合同**设立，需书面形式
- 同一纠纷可能同时涉及两者（混合状态），需要根据具体情形选择适用法律

### 难点二：第290条"自然流向"的认定

**争议**：能否改变自然流水的流向？

**主流观点**：
- 原则上**尊重自然流向**
- 确需改变的，应当与他方协商，达成排水协议
- 协议涉及社会公共利益的，应报请水行政主管部门同意
- 擅自改变自然流向造成损害的，承担赔偿责任

### 难点三：第293条"通风、采光、日照"的判断标准

**争议**：符合国家标准的建筑是否一定不构成妨碍？

**主流观点**：
- **符合国家标准** → 推定不构成妨碍
- **不符合国家标准** → 推定构成妨碍
- 国家标准缺失时，可参考地方标准、行业标准，或结合当地习惯和具体情况判断
- 是否超出"社会一般人的容忍限度"是核心判断标准

### 难点四：第294条"违反国家规定"的判断

**争议**：达标排放是否构成相邻污染侵害？

**主流观点**：
- 形式上：达标排放应不构成相邻污染侵害
- 但司法实践中应借鉴容忍限度理论，做好利益衡量
- 即使达标但明显超出一般人容忍限度，仍可能构成相邻污染侵害

### 难点五：第296条"尽量避免"的判断

**争议**：相邻权人如何证明自己已"尽量避免"？

**主流观点**：
- 举证责任分配：原则上相邻权人举证证明已"尽量避免"
- 判断标准：必要性 + 有效性 + 手段的轻微性 + 相邻权的优越性
- 综合考量：合法利益 + 利益大小 + 社会影响 + 当地习惯

## ❓ 实务问答

### Q1：第288条处理相邻关系的4项原则？

**A**：依《民法典》第288条：
1. **有利生产**
2. **方便生活**
3. **团结互助**
4. **公平合理**

### Q2：第289条处理相邻关系的依据？

**A**：
- 有法依法（法律+法规+司法解释）
- 无法依当地习惯（不得违背公序良俗）
- 找不到习惯时，适用第288条基本原则

### Q3：第290条自然流水的利用规则？

**A**：
- **合理分配**（相邻权利人之间）
- 尊重**自然流向**
- 擅自堵截或独占自然流水影响他方正常生产生活的，他方有权请求排除妨碍
- 生活用水优先

### Q4：邻地通行权的特点？

**A**：依《民法典》第291条：
- **长期性**（路过性质）
- **无需合同**
- **一般无偿**（造成损失的，应当给予适当补偿）

### Q5：第293条判断妨碍通风、采光、日照的标准？

**A**：
- **违反国家有关工程建设标准** → 构成妨碍
- **符合国家标准** → 不构成妨碍（容忍义务）
- 国家标准缺失时，可参考地方标准、行业标准、当地习惯判断
- 核心标准：是否超出"社会一般人的容忍限度"

### Q6：第294条不可量物侵害的责任构成？

**A**：
- 必须**违反国家规定**为前提（违法性要件）
- 适用范围：**个人/家庭生活**排放污染物
- **生产经营**排放适用环境侵权（无过错责任）
- 容忍义务：达标不一定免责，应结合容忍限度理论综合判断

### Q7：第295条"危及"的类型化处理？

**A**：

| 类型 | 处理 |
|------|------|
| 现实损害 | 赔偿经济损失 |
| 现实紧迫危险 | 消除危险 |
| 抽象可能性 | 不构成"危及" |

### Q8：第296条"尽量避免"必须满足的4个条件？

**A**：
1. **必要性**（无其他方式能避免损害）
2. **有效性**（造成损害能有效实现相邻权）
3. **手段的轻微性**（最小损害原则）
4. **相邻权的优越性**（所保护权益明显大于所损害权益）
