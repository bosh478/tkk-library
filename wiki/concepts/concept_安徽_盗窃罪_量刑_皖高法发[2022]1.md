# 盗窃罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(数额较大)** | 三年以下有期徒刑、拘役或者管制 + 罚金 | **3 月拘役-6 月**(基础) / **9 月-1 年**(国有馆藏一般文物) |
| **第二档(数额巨大)** | 三年以上十年以下有期徒刑 + 罚金 | **3-4 年** |
| **第三档(数额特别巨大)** | 十年以上有期徒刑 / 无期 | **10-12 年** |

## 二、第一档 · 3 月拘役-6 月起刑点

**入罪触发**(任一):
- 数额较大起点
- 入户盗窃 / 携带凶器盗窃 / 扒窃
- 二年内三次盗窃
- 数额较大起点 50% + 9 种情形之一(曾因盗窃受过刑罚 / 组织控制未成年人 / 突发事件期间 / 弱势人员财物 / 医院病人财物 / 抢险救济款物 / 严重后果)
- **国有馆藏一般文物 2 件** → **9 月-1 年**

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 犯罪数额每增 **1500 元** | + **1 月** |
| 每多 1 次作案 或 1 种情形 | + **2-3 月** |
| 国有馆藏一般文物 +1 件 | + **9 月-1 年** |

## 三、第二档 · 3-4 年起刑点

**入罪触发**:数额巨大 + 数额巨大 50% + 上述 8 种情形;**国有馆藏一般文物 3 件 / 三级文物 1 件**。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 犯罪数额每增 **5000 元** | + **1 月** |
| "其他严重情节"每多 1 种 | + **6 月-1 年** |
| 国有馆藏一般文物 +1 件 | + **9 月-1 年**;三级文物 +2 件 → + **2.5-3 年** |

## 四、第三档 · 10-12 年起刑点

**入罪触发**:数额特别巨大 / 其他特别严重情节 / 国有馆藏三级文物 3 件 / 二级文物 1 件。

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 犯罪数额每增 **25000 元** | + **1 月** |
| "其他特别严重情节"+1 | + **1-2 年** |
| 三级文物 +1 / 二级文物 +1 件 | + **9 月-1 年** / + **1-2 年**;含一般文物每件 → + **3-4 月** |

## 五、从重情节(6 类)

1. 多次 / 扒窃 / "其他严重情节" 等 9 种情形 → **+30% 以下**,每多 1 种 → 再 + **10% 以下**
2. 破坏性手段 + 财物损毁 → **+10-30%**
3. 为吸毒 / 赌博等违法活动而盗窃 → **+20% 以下**
4. 流窜作案 → **+20% 以下**
5. 给失主造成的损失 > 盗窃数额 → **+10% 以下**

## 六、从宽情节(4 类)

1. 生活所迫 / 学习 / 治病急需 → **−10% 以下**
2. 案发前主动放回 / 归还 → **−30% 以下**
3. 盗窃家庭成员或近亲属 + 谅解 → **−20-50%**(不作犯罪处理除外)
4. 其他从轻情形

## 七、罚金

- 单处罚金:**1-2 倍**,最低 2000 元
- 三年以下:**1000-60000 元**
- 三年-十年:**5000-200000 元**
- 十年以上:**50000-500000 元**

## 八、缓刑适用

**一般可以适用**(任一):
1. 生活所迫 / 学习 / 治病急需
2. 案发前主动归还
3. 未参与分赃 / 获赃较少
4. 积极退赔 + 谅解
5. 家庭成员 / 近亲属财物
6. 在校学生初犯 / 偶犯

**一般不适用**(任一):
1. 多次 / 入户 / 携带凶器 / 扒窃 + 数额较大以上
2. 教唆 / 组织 / 控制未成年人、残疾人盗窃
3. 为吸毒 / 赌博等违法活动盗窃
4. 医院盗窃病人或亲友财物
5. 曾因盗窃受刑罚 / 一年内行拘
6. 有能力但拒不退赃 / 赔偿
