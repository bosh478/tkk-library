# 网络犯罪(《刑法》第 285-287 条 · L3)

> 本页定位:网络犯罪 L3 概念页。**第 6 章妨害社会管理罪**下,2015《刑法修正案(九)》增设的**网络犯罪体系**;涉及计算机信息系统安全 + 网络帮助行为。

## 一、法条原文(条文要点)

《刑法》第 285 条(非法侵入计算机信息系统罪):
> 违反国家规定,侵入国家事务、国防建设、尖端科学技术领域的计算机信息系统的,处三年以下有期徒刑或者拘役。
> 违反国家规定,侵入前款规定以外的计算机信息系统或者采用其他技术手段,获取该计算机信息系统中存储、处理或者传输的数据,情节严重的,处三年以下有期徒刑或者拘役,并处或者单处罚金;情节特别严重的,三年以上七年以下有期徒刑,并处罚金。
> 提供专门用于侵入、非法控制计算机信息系统的程序、工具,情节严重的,依照前款的规定处罚。

《刑法》第 286 条(破坏计算机信息系统罪):
> 违反国家规定,对计算机信息系统功能进行删除、修改、增加、干扰,造成计算机信息系统不能正常运行,后果严重的,处五年以下有期徒刑或者拘役……
> 违反国家规定,对计算机信息系统中存储、处理或者传输的数据和应用程序进行删除、修改、增加的操作,后果严重的,依照前款的规定处罚。
> 故意制作、传播计算机病毒等破坏性程序,影响计算机系统正常运行,后果严重的,依照第一款的规定处罚。

《刑法》第 286 条之一(拒不履行信息网络安全管理义务罪):
> 网络服务提供者不履行法律、行政法规规定的信息网络安全管理义务,经监管部门责令采取改正措施而拒不改正,有下列情形之一的,处三年以下有期徒刑、拘役或者管制,并处或者单处罚金:
> (一)致使违法信息大量传播的;
> (二)致使用户信息泄露,造成严重后果的;
> (三)致使刑事案件证据灭失,情节严重的;
> (四)有其他严重情节的。

《刑法》第 287 条之一(利用计算机实施犯罪):
> 利用计算机实施金融诈骗、盗窃、贪污、挪用公款、窃取国家秘密或者其他犯罪的,依照本法有关规定定罪处罚。

《刑法》第 287 条之二(帮助信息网络犯罪活动罪):
> 明知他人利用信息网络实施犯罪,为其犯罪提供互联网接入、服务器托管、网络存储、通讯传输等技术支持,或者提供广告推广、支付结算等帮助,情节严重的,处三年以下有期徒刑或者拘役,并处或者单处罚金。
> 单位犯前款罪的,对单位判处罚金,并对其直接负责的主管人员和其他直接责任人员,依照第一款的规定处罚。

## 二、段级释解

### 1. 概念界定

网络犯罪 = **以计算机网络 / 信息系统**为**工具 / 对象 / 场所**的犯罪。

**分类**:
- **网络工具型犯罪**:以网络为**工具**实施的传统犯罪(网络诈骗、网络盗窃)
- **网络对象型犯罪**:以网络信息系统为**对象**的犯罪(非法侵入、破坏系统)
- **网络帮助型犯罪**:为网络犯罪提供**帮助**的犯罪(帮信罪)
- **网络平台犯罪**:网络服务提供者**不履行义务**的犯罪(拒不履行信息网络安全管理义务罪)

### 2. 核心罪名构成要件

(1) **非法侵入计算机信息系统罪**(第 285 条第 1 款):
- 对象:**特定**计算机信息系统(国家事务 / 国防建设 / 尖端科技)
- 行为:违反国家规定 + **侵入**
- 主观:**故意**

(2) **非法获取计算机信息系统数据罪**(第 285 条第 2 款):
- 对象:**一般**计算机信息系统
- 行为:侵入 + **获取数据** + **情节严重**
- 主观:故意

(3) **提供侵入计算机信息系统程序工具罪**(第 285 条第 3 款):
- 行为:**提供**专门用于侵入 / 非法控制系统的**程序、工具**
- 情节严重

(4) **破坏计算机信息系统罪**(第 286 条):
- 对象:计算机信息系统 / 数据 / 应用程序
- 行为:**删除、修改、增加、干扰** / 制作传播**计算机病毒**
- 后果:**后果严重**
- 三档刑罚:5 年以下 / 5 年以上

(5) **拒不履行信息网络安全管理义务罪**(第 286 条之一):
- 主体:**网络服务提供者**
- 行为:**不履行**信息网络安全义务 + **监管部门责令改正拒不改正**
- 后果:4 类情形之一

(6) **帮助信息网络犯罪活动罪**(第 287 条之二,2015 增设):
- 主体:**自然人 / 单位**
- 行为:**明知**他人利用信息网络实施犯罪 + **提供**技术支持或帮助
- 客观:**情节严重**
- 主观:**明知**他人利用信息网络实施犯罪
- 刑罚:3 年以下

### 3. 网络犯罪的共同特征

(1) **以网络为媒介**:以网络作为**工具 / 对象 / 场所**
(2) **数据化**:行为以**数据 / 信息**为载体
(3) **跨地域性**:可跨**国境**实施
(4) **技术性**:需**专业计算机技术**
(5) **隐蔽性**:行为人**身份隐蔽**

### 4. 帮信罪(帮助信息网络犯罪活动罪)与共同犯罪的边界

| 项目 | 帮信罪(第 287 条之二) | 共同犯罪(第 25-29 条) |
|------|------------------------|------------------------|
| 主体 | 帮助人 | 共犯 |
| 主观 | **明知**他人利用信息网络实施犯罪 | **共谋**实施犯罪 |
| 行为 | 提供**技术支持或帮助** | 实施构成要件行为 |
| 定性 | **独立罪名** | 共犯 |
| 关系 | 非共犯 | 共犯 |

**关键区分**:
- 帮信罪:**单向**提供帮助 + 明知 + 不参与
- 共同犯罪:**共谋** + 共同实施

### 5. 拒不履行信息网络安全管理义务罪(第 286 条之一)

**主体**:**网络服务提供者**(ISP / 平台 / 应用程序提供者等)

**入罪情形**(4 类):
- 致使**违法信息大量传播**
- 致使用户**信息泄露** + 严重后果
- 致使**刑事案件证据灭失** + 情节严重
- 其他严重情节

**出罪情形**:
- 履行义务 + 已采取改正措施
- 责令改正后改正

## 三、实务问答(FAQ)

Q1:网络诈骗按什么罪定罪?
**诈骗罪**(传统罪名)+ **网络工具**:
- 第 266 条诈骗罪
- 数额较大 / 巨大 / 特别巨大 → 3 个档次
- 网络是**工具**,不影响定性

Q2:帮信罪与诈骗罪共犯的边界?
- **帮信罪**:提供**技术支持**(建站、维护、推广、支付)
- **诈骗罪共犯**:参与**共谋 + 实施**诈骗
- **关键**:是否**共谋**(帮信罪:无共谋,只单向帮助)

Q3:非法侵入计算机信息系统罪与非法获取数据罪的区别?
- 第 285 条 1 款:**特定**系统(国家事务 / 国防 / 尖端科技)
- 第 285 条 2 款:**一般**系统 + 情节严重
- 前者无情节要求,后者需情节严重

Q4:对单位网络犯罪的处罚?
- **双罚制**(第 287 条之二第 2 款):
  - **对单位**判处罚金
  - 对**直接负责的主管人员**和**其他直接责任人员**判处刑罚

Q5:网络服务提供者的范围?
- 互联网服务提供商(ISP)
- 平台服务提供者(电商 / 社交 / 视频)
- 应用程序(App)提供者
- 内容服务提供者
- 云计算服务提供者

Q6:「明知」他人利用信息网络实施犯罪的认定?
- **知道**他人实施犯罪 + 提供帮助
- **应当知道** + 客观上可推断(司法解释)
- 不要求知道**具体**犯罪

Q7:破坏计算机信息系统罪与非法获取数据罪的边界?
- **破坏**:对系统功能 / 数据 / 应用程序**造成损害**(删除、修改、干扰)
- **获取数据**:**获取**数据(可能不破坏系统)
- 两者可能**竞合**(获取 + 破坏数据)

Q8:网络犯罪管辖?
- 犯罪地:**服务器所在地 + 被害人所在地 + 行为人所在地**
- 跨地域:**最先受理**的公安机关立案
- 跨境:**国际刑事司法协助** + **引渡**

Q9:对**深度链接**等新型网络行为如何定罪?
- 主流:**侵犯著作权罪**(信息网络传播权)
- 视具体情形可能涉及**非法经营罪**等

Q10:网络犯罪与**传统犯罪**的衔接?
- 利用网络实施**传统犯罪** → 按传统罪名(诈骗、盗窃、敲诈勒索等)
- 利用网络实施**新型犯罪** → 按网络专门罪名(帮信罪、拒不履行安全管理义务罪等)
- **法条竞合**时按重罪从重
