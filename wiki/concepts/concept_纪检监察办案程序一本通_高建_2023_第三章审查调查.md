# 《纪检监察办案程序一本通》第三章 审查调查

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第三章 审查调查 |
| 行号范围 | 2079-5538（书籍）|
| 核心议题 | 审查调查启动+13项措施+重点文书+证据标准 |
| 涵盖 | 启动+措施+文书+重点疑难 |

## 🎯 核心论点

**审查调查 = 立案 + 13项措施 + 重点文书**

**核心制度**：
- 立案标准（3 种案件 3 种标准）
- 13 项监督检查审查调查措施
- 3 种证据标准
- 重点文书（审查调查报告/违纪违法事实材料/涉案人员处理意见）

---

## 第一节 审查调查启动程序

## 一、立案标准

### （一）党纪立案标准

- 党员涉嫌违纪
- 需追究纪律责任
- 具备初步证据

### （二）政务立案标准

- 公职人员涉嫌职务违法
- 需追究政务责任
- 具备初步证据

### （三）职务犯罪立案标准

- 公职人员涉嫌职务犯罪
- 需追究法律责任
- 具备初步证据

## 二、立案模式

| 立案模式 | 适用情形 |
|---------|----------|
| **"人立案"** | 已明确涉嫌违纪违法的具体人员 |
| **"事立案"** | 暂未明确具体人员，但有明确的违纪违法行为 |

## 三、立案程序

**流程**：
1. 承办部门提出
2. 部门负责人审核
3. 分管领导审批
4. 纪委常委会会议研究决定
5. 报同级党委审批
6. 立案

## 四、立案三种证据标准

| 案件类型 | 证据标准 | 内涵 |
|---------|---------|------|
| **违纪案件** | 明确合理可信 | 违纪构成要件标准低于违法犯罪，证据量较少 |
| **职务违法案件** | 清晰且令人信服 | 通过证据推理形成高确信度 |
| **职务犯罪案件** | 排除合理怀疑 | 刑事诉讼标准，定罪量刑证据确凿充分 |

## 第二节 监督检查审查调查措施（13项）

## 一、措施清单

| 序号 | 措施 | 法规依据 |
|------|------|----------|
| 1 | **谈话** | 《监察法》第19条 |
| 2 | **讯问** | 《监察法》第21条 |
| 3 | **询问** | 《监察法》第21条 |
| 4 | **查询、冻结** | 《监察法》第21、23条 |
| 5 | **调取、查封、扣押**（暂扣、封存）| 《监察法》第21、25条 |
| 6 | **鉴定** | 《监察法》第21、26条 |
| 7 | **勘验检查** | 《监察法》第21、26条 |
| 8 | **搜查** | 《监察法》第21、24条 |
| 9 | **留置** | 《监察法》第22条 |
| 10 | **技术调查** | 《监察法》第28条 |
| 11 | **通缉** | 《监察法》第29条 |
| 12 | **限制出境** | 《监察法》第30条 |
| 13 | 其他依法可采取措施 | — |

## 二、关键措施详解

### （一）谈话 vs 讯问 vs 询问

| 维度 | 谈话 | 讯问 | 询问 |
|------|------|------|------|
| 对象 | 监督对象 | 被调查人 | 证人等 |
| 性质 | 了解情况 | 调查取证 | 调查取证 |
| 措施强度 | 轻 | 重 | 中 |
| 法条 | 第19条 | 第21条 | 第21条 |

### （二）留置

**《监察法》第22条**：
> 被调查人涉嫌贪污贿赂、失职渎职等严重职务违法或者职务犯罪，监察机关已经掌握其部分违法犯罪事实及证据，仍有重要问题需要进一步调查，并有下列情形之一的，经监察机关依法审批，可以将其留置在特定场所：
> 1. 涉及案情重大、复杂的；
> 2. 可能逃跑、自杀的；
> 3. 可能串供或者伪造、隐匿、毁灭证据的；
> 4. 可能有其他妨碍调查行为的。

**留置条件**：
- 涉嫌严重职务违法/职务犯罪
- 已掌握部分违法犯罪事实及证据
- 仍有重要问题需要调查
- 具备 4 种法定情形之一

**审批权限**：设区的市级以上监察机关

**期限**：一般3个月，可延长1次（不超过3个月），合计可延长情形（不超过12个月）

### （三）技术调查

**《监察法》第28条**：
> 监察机关调查涉嫌重大贪污贿赂等职务犯罪，根据需要，经过严格的批准手续，可以采取技术调查措施，按照规定交有关机关执行。

**种类**：记录监控、行踪监控、通信监控等

**审批**：严格的批准程序

### （四）通缉

**《监察法》第29条**：
> 依法应当留置的被调查人如果在逃，监察机关可以决定在本行政区域内通缉，由公安机关发布通缉令，追捕归案。

**适用**：涉案在逃人员

### （五）限制出境

**《监察法》第30条**：
> 监察机关为防止被调查人及相关人员逃匿境外，经省级以上监察机关批准，可以对被调查人及相关人员采取限制出境措施。

## 第三节 审查调查重点文书

## 一、审查调查报告

**主要内容**：
- 被审查调查人基本情况
- 审查调查依据
- 主要违纪违法事实
- 证据材料
- 涉案款物处理建议
- 移送审理建议

## 二、违纪违法事实材料

**要求**：
- 客观真实
- 证据充分
- 条理清晰
- 引用法律条文准确

## 三、涉案人员处理意见

**分类处理建议**：
- 涉嫌犯罪 → 移送司法机关
- 涉嫌违纪违法 → 给予党纪政务处分
- 涉嫌犯罪+违纪 → 同步处理

---

## 第四节 重点疑难问题

## 一、三种证据标准的具体应用

| 标准 | 适用案件 | 证明要求 |
|------|----------|----------|
| 明确合理可信 | 违纪案件 | 违纪事实的证明 + 违纪构成要件 |
| 清晰且令人信服 | 职务违法案件 | 调查人员对证据综合考量后形成确信 |
| 排除合理怀疑 | 职务犯罪案件 | 经庭审质证 + 排除合理怀疑 |

## 二、立案疑难问题

1. **对其他纪检监察机关监督对象采取措施的审批**：提级办理或商请协助
2. **"以事立案"**：先立案查事，再追查人
3. **被审查调查人涉嫌违纪违法问题是否必须党纪和政务双立案**：应当双立案

## 三、措施适用疑难

1. **如何做好讯问准备工作**：制定方案+熟悉案情+法律文书+心理应对预案
2. **非党员非监察对象主动登记上交**：可以启动
3. **指定管辖案件对同级党委管理正职领导干部询问**：商请同级党委同意+提级办理

## 四、主动投案认定

| 情形 | 是否认定 |
|------|---------|
| 主动、直接向监察机关投案 | 是 |
| 经监察机关电话通知后主动到案 | 一般可认定 |
| 留置后即如实交代全部问题 | 可认定 |
| 亲友规劝陪同投案 | 可认定 |
| 投案时机的早晚+主动性+如实性 | 关键判断 |

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **审查调查** | 立案后对涉嫌违纪违法案件的调查核实 |
| **13项措施** | 监督检查审查调查的13项法定措施 |
| **"人立案"** | 已明确涉嫌违纪违法的具体人员 |
| **"事立案"** | 先立案查事，再追查人 |
| **双立案** | 党纪+政务同时立案 |
| **三种证据标准** | 明确合理可信/清晰且令人信服/排除合理怀疑 |
| **主动投案** | 自动性+如实交代+投案时机 |
| **留置** | 监察机关法定的强制措施 |
| **技术调查** | 重大贪污贿赂案件的特殊调查措施 |
| **指定管辖** | 上级指定某一机关管辖 |
