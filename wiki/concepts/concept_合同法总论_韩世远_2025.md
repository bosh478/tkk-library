## 🎯 核心论点（BLUF）

中国民法上的**合同**＝"平等民事主体之间以设立、变更、终止民事权利义务关系为目的具有**法律约束力**的**合意**"。

其三要素缺一不可：
1. **协议**（合意）— 双方意思表示一致
2. **法律约束力** — 依法成立方有约束力
3. **狭义解释** — 原则上应回归债权合同（《民法典》第118条第2款明定合同为债权发生原因之一）

## 第一章 合同与合同法概述

## 第一节 合同、合意与契约

### 一、"合同"的语义

《民法典》第**464条第1款**规定："**合同是民事主体之间设立、变更、终止民事法律关系的协议**"。第463条："本编调整因合同产生的民事关系"。

#### 三层语义限定

| 限定维度 | 内涵 | 反例 |
|---------|------|------|
| **主体限定** | 平等主体之间 | 行政协议（《行政诉讼法》第12条第1款第11项）→ 参照适用而非适用 |
| **内容限定** | 财产关系 | 身份关系协议（婚姻/收养/监护）→ 参照适用合同编 |
| **范围限定** | **狭义合同**（原则上回归债权合同） | 人格权客体许可使用协议、捐献协议 → 多数可归属于合同编典型合同或通则 |

> **重要解释论**：《民法典》第464条第1款中的"民事法律关系"宜**限制解释**为**债权债务关系**。着眼点在体系位置（合同编+分则中物权、亲属、继承之外），将讨论对象限定于狭义合同是切合实际的做法。

### 二、"合同"两大法系比较

| 法系 | 合同定义 | 代表立法 |
|------|----------|----------|
| **大陆法系传统（法国）** | 合同为一种**合意**（an agreement）| 《法国民法典》新第1101条：合同是两人或多人之间旨在创设、变更、转让或消灭债之关系的合意 |
| **英美法系** | 合同是一种**允诺**（a promise）| 美国《合同法重述》（第2版）第1条 |
| **德国法（潘德克顿模式）** | **广义合同**（Vertrag）— 一切意思合致 | 《德国民法典》：合同成立规定在总则编，债务关系法/物权法/亲属法/继承法均可适用 |

> **萨维尼**（1779-1861）最早系统主张广义合同概念，后为《德国民法典》采纳。其思想基础：18世纪以来德国盛行体系化与抽象化，确立抽象法律行为概念。

### 三、"合同 = 合意"公式的挑战

"合同 = 合意" 公式反映意思理论，但有三大挑战：

1. **"事实合同关系"论**（豪普特 1941）：在若干情形中，合同关系可根据事实过程而成立，当事人意思如何不必过问。
2. **附随义务论**：以诚信原则为基础（《民法典》第509条第2款），无论当事人是否特别约定都被作为合同应有内容，并非因合意而发生。
3. **关系合同论**（麦克尼尔 1929-2010）：合同不过是一组规划未来交换的**关系**，当事人之间的允诺只是其中一个组成部分；社会习俗、身份、习惯等**非允诺性机制**对规划未来交换至关重要。

> **中国民法典的回应**：合同编本着促进交易的精神，关于合同成立只要求就**合同最低限度内容**达成合意即可，其他内容通过合同解释或立法补充性规定加以补充。

### 四、"合同"与"契约"的区别

| 概念 | 含义 | 当代用法 |
|------|------|----------|
| **契约**（Vertrag, contract）| 两个交互意思表示一致而成立 | 已基本被"合同"取代 |
| **合同行为**（Gesamtakt）| 同方向平行的两个以上意思表示一致而成立 | 共同行为，如社团法人设立、合伙开除 |

> **关键事实**：1949年中华人民共和国成立后，"契约"逐渐被"合同"替代。我国台湾地区仍使用"契约"。经典用语仍有"契约自由""契约神圣""契约严守"等遗迹。

## 第二节 合同行为、合同过程与合同关系

### 一、合同过程论

传统理论以**一时性合同**为模型构筑体系；现代学说倾向从**过程侧面**把握合同，认为现实合同是**从合同缔结前阶段到履行完毕后的连续过程**（process）。

**重要新概念**：

| 概念 | 内涵 |
|------|------|
| **合同成熟度** | 日本早稻田大学镰田薰教授提出。出卖人转卖标的物，依合同成熟度可能：无责任/信赖利益赔偿/履行利益赔偿/背信恶意者排除论 |
| **中间性合意理论** | 1986年后发展，对缔约过程分阶段划分相应责任（阶段责任论） |
| **框架合同**（framework agreement; Rahmenvertrag）| 经销商协议中长期继续性合同的开放性框架 |

**我国民法典的体现**：
- 第**500条**：合同订立过程中的过失责任
- 第**501条**：合同订立过程中的保密义务
- 第**558条**：合同终了后的义务

### 二、合同关系的构成

合同关系 = 主体 + 客体 + 内容

| 构成 | 内涵 |
|------|------|
| **主体**（合同当事人）| 债权人/债务人；可为自然人/法人/非法人组织；本国人/外国人；不以行为能力为限 |
| **客体**（合同的标的）| 给付行为（债务人为或不为一定行为）；可为作为/不作为；不以财产价值为限 |
| **内容**（合同债权债务）| 债权（请求力+受领力+保持力+执行力）+ 债务（主给付义务+附随义务）|

> **继续性合同的挑战**：合同内容于成立时即全部确定固然理想（"把将来转化为现在"），但在长期继续性合同场合难以实现，需借由**框架合同**概念解决。

### 三、合同关系的相对性

《民法典》第**465条第2款**："依法成立的合同，仅对当事人具有法律约束力，但是法律另有规定的除外"。

**两大法系对应**：
- 英国普通法：**合同的相对性**（the privity of contract）
- 大陆法系：**债的相对性**（Relativität des Schuldverhältnisses）

**近现代对相对性的突破**：
1. **买卖不破租赁**（债权物权化）
2. **债权人代位权 + 撤销权**（债权保全效力）
3. **第三人侵害债权**（债权对外效力）
4. 法国法"**直接诉权**"制度
5. 德国法"**附保护第三人作用的合同**"制度

## 第三节 合同法的历史

### 一、古代合同法

中国早在**西周后期及春秋时期**便已有相当发达的契约制度。"合同"本是契约形式之一种（验证契约的标记，犹如今天的押缝标记），本身不是当事人之间的协议。

### 二、近代合同法

罗马法上债权无追及性、属于对人权 → 法国法 + 德国法继承 → 形成"债权相对性"与"物权绝对性"基本格局。

### 三、现代合同法

20世纪以来，附随义务理论、积极侵害债权理论逐步发展，突破传统合同法理。

### 四、现代中国合同法

1999年《合同法》→ 2020年《民法典》合同编。合同编变化体现了从"意思理论"向"过程理论"+"关系理论"的演进。

## 第四节 合同法的原则（十项）

### 一、合同法原则概述

合同法原则是合同法规范之基础性原理，是理解、解释、适用合同法的根本依据。

### 二、十项原则清单

| 序号 | 原则 | 内涵 |
|------|------|------|
| 1 | **法律地位平等原则** | 合同当事人法律地位一律平等（《民法典》第2条） |
| 2 | **合同自由原则** | 当事人依法享有自愿订立合同的权利 |
| 3 | **公平原则** | 当事人应当遵循公平原则确定各方权利义务（第6条） |
| 4 | **诚信原则** | 当事人行使权利、履行义务应当遵循诚信原则（第7条） |
| 5 | **不得违法和公序良俗原则** | 民事主体从事民事活动不得违反法律、不得违背公序良俗 |
| 6 | **合同约束力原则** | 依法成立的合同对当事人具有法律约束力（第119条） |
| 7 | **合同相对性原则** | 依法成立的合同仅对当事人具有法律约束力（第465条） |

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **合意** | 当事人意思表示的一致 |
| **允诺**（promise）| 英美法上合同概念的核心 |
| **Gesamtakt**（共同行为）| 同方向平行意思表示一致而成立 |
| **事实合同关系** | 根据事实过程而成立的合同关系（豪普特 1941）|
| **附随义务** | 以诚信原则为基础、并非因合意发生的合同义务 |
| **关系合同** | 一组规划未来交换的关系（麦克尼尔）|
| **合同成熟度** | 合同从开端到履行终了的阶段性成熟（镰田薰）|
| **中间性合意** | 1986年后发展的阶段责任论基础 |
| **框架合同** | 长期继续性合同的开放性框架 |
| **狭义合同** | 仅指债权合同（《民法典》第118条第2款）|
| **广义合同** | 一切意思合致（德国法潘德克顿模式）|
| **合同相对性** | 合同仅对当事人具有法律约束力 |
| **合同的参照适用** | 行政协议参照适用民事合同相关规定 |
| **身份到契约** | 梅因"古代法"著名论断 |
