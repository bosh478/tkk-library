# 民法典适用大全·企业破产法一

## 概述

本卷收录《中华人民共和国企业破产法》及相关司法解释的理解与适用，内容涵盖破产申请受理、管理人制度、债务人财产、债权申报、债权人会议等核心制度。企业破产法是规范企业法人不能清偿到期债务时进入破产程序的法律，对于公平清理债权债务、保护债权人和债务人的合法权益、维护社会主义市场经济秩序具有重要意义。

---

## 第一章 总则

### 第1条【立法宗旨和本法调整范围】

**法条原文：**
> 为规范企业破产程序，公平清理债权债务，保护债权人和债务人的合法权益，维护社会主义市场经济秩序，制定本法。

**条文释义：**
本条规定了企业破产法的四大立法目的：
1. **规范企业破产程序** — 建立完善的破产法律程序
2. **公平清理债权债务** — 使全体债权人获得公平受偿的机会
3. **保护债权人和债务人的合法权益** — 既保护债权人利益，也保护债务人利益
4. **维护社会主义市场经济秩序** — 使丧失经营能力的市场主体有序退出

**调整范围：** 本法调整范围以企业法人为限，暂不涉及其他主体的破产问题。

### 第2条【破产原因和重整条件】

**法条原文：**
> 企业法人不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力的，依照本法规定清理债务。
>
> 企业法人有前款规定情形，或者有明显丧失清偿能力可能的，可以依照本法规定进行重整。

**破产原因（满足其一即可）：**
| 类型 | 条件 |
|------|------|
| 情形一 | 不能清偿到期债务 + 资产不足以清偿全部债务 |
| 情形二 | 不能清偿到期债务 + 明显缺乏清偿能力 |

**重整原因：**
1. 具备破产原因（不能清偿到期债务 + 资产不足或明显缺乏清偿能力）
2. 有明显丧失清偿能力可能（即使尚未达到破产原因）

**关联规定：**
- 《民事诉讼法解释》第511条：执行中符合破产法第2条第1款情形的，应中止执行并移送破产审查
- 《企业破产法规定(一)》第1-4条：详细规定了破产原因的认定标准

### 第3条【破产案件管辖】

**法条原文：**
> 破产案件由债务人住所地人民法院管辖。

**要点：** 债务人主要办事机构所在地为住所地人民法院管辖。

### 第5条【破产法域外效力】

**要点：** 我国破产法采取有限的普及主义，破产效力可以及于债务人在国外的财产，但需要通过双边或多边条约安排。

### 第6条【保障破产企业职工合法权益】

**要点：** 破产程序中应依法保护职工的工资、社会保险费用等合法权益，在财产分配中予以优先考虑。

---

## 第二章 申请和受理

### 第一节 破产申请

### 第7条【破产申请主体】

**破产申请主体：**
| 主体 | 条件 |
|------|------|
| 债权人 | 债务人不能清偿到期债务 |
| 债务人 | 资产不足以清偿全部债务或明显缺乏清偿能力 |
| 清算责任人 | 企业法人已解散但未清算或未清算完毕 |

### 第8条【破产申请书及有关证据】

**要点：** 申请人应提交破产申请书及有关证据，载明申请人基本情况、申请目的、申请理由等。

### 第二节 破产受理

### 第10条【人民法院受理破产申请时限】

**要点：** 人民法院应在收到破产申请后法定期限内决定是否受理。

### 第13条【指定管理人】

**要点：** 人民法院裁定受理破产申请的，应当同时指定管理人。

### 第14条【受理破产申请的通知及公告】

**要点：** 人民法院应自裁定受理破产申请之日起法定期限内通知已知债权人并公告。

### 第15条【人民法院受理破产申请后债务人的有关人员承担义务】

**要点：** 债务人的有关人员应承担妥善保管财产、账簿、文书等义务。

### 第16条【破产申请受理后，债务人的个别清偿无效】

**要点：** 破产申请受理后，债务人对个别债权人的清偿无效。

### 第18条【破产申请受理前成立而债务人和对方当事人均未履行完毕合同的处理】

**法条原文：**
> 管理人有权决定解除或者继续履行双方均未履行完毕的合同。

**适用指引：**
- 管理人自破产申请受理之日起二个月内未通知对方当事人，或自收到对方当事人催告之日起三十日内未答复的，视为解除合同
- 对方当事人以合同解除产生损害赔偿请求权申报债权

**典型案例：通州建总集团有限公司诉安徽天宇化工有限公司别除权纠纷案**
- 关键词：别除权、建设工程价款优先受偿权、合同解除
- 裁判要点：符合《破产法》第18条规定情形，建设工程施工合同视为解除的，承包人行使优先受偿权的期限应自合同解除之日起计算

### 第19条【人民法院受理破产申请对有关债务人财产的保全措施和执行程序的效力】

**法条原文：**
> 有关债务人财产的保全措施应当解除，执行程序应当中止。

**要点：**
- 保全措施解除是破产申请受理的当然效力
- 执行程序中止，已开始的执行措施应当停止
- 依据《企业破产法规定(二)》第5-8条执行回转的财产应认定为债务人财产

### 第20条【人民法院受理破产申请后，有关债务人的民事诉讼或者仲裁应当中止】

**要点：** 诉讼或仲裁在管理人接管债务人财产后继续进行。

## 第三章 管理人

### 第22条【管理人的任命及解任】

**管理人的指定：**
- 由人民法院指定
- 债权人会议认为管理人不能依法、公正执行职务或有其他不能胜任情形的，可申请人民法院更换

**管理人指定方式（《指定管理人规定》）：**
| 方式 | 适用情形 |
|------|----------|
| 随机指定 | 一般案件（轮候、抽签、摇号） |
| 竞争指定 | 金融机构、全国有重大影响、复杂案件 |
| 清算组 | 行政清算、强制清算、金融机构清算 |

### 第24条【管理人的组成及任职资格】

**管理人资格：**
1. 有关部门、机构组成的清算组
2. 依法设立的律师事务所、会计师事务所、破产清算事务所
3. 个人担任：需具备专业知识并取得执业资格

**消极资格（不得担任）：**
- 因故意犯罪受过刑事处罚
- 曾被吊销相关专业执业证书
- 与本案有利害关系
- 人民法院认为不宜担任的其他情形

### 第25条【管理人职责】

**管理人职责清单：**
| 序号 | 职责 | 说明 |
|------|------|------|
| 1 | 接管财产、印章、账簿、文书 | 全面接管债务人企业 |
| 2 | 调查财产状况 | 制作财产状况报告 |
| 3 | 决定内部管理事务 | 财务管理、资产管理、人事管理 |
| 4 | 决定日常开支 | 日常运转必要费用 |
| 5 | 决定继续或停止营业 | 第一次债权人会议前需经法院许可 |
| 6 | 管理和处分财产 | 核心职责：管理、估价、变现、分配 |
| 7 | 代表参加诉讼 | 代表债务人参加诉讼仲裁 |
| 8 | 提议召开债权人会议 | 履行程序性职责 |
| 9 | 其他职责 | 兜底条款 |

### 第26条【管理人行使职权的限制】

**需经人民法院许可的行为（第一次债权人会议前）：**
- 决定继续或停止债务人营业
- 《破产法》第69条规定的重大财产处分行为（土地房屋转让、知识产权转让、全部库存或营业转让、借款、设定担保、债权转让、放弃权利等）

### 第27条【管理人的勤勉忠实义务】

**法条原文：**
> 管理人应当勤勉尽责，忠实执行职务。

**违反后果：**
- 罚款（《破产法》第130条）
- 赔偿责任：给债权人、债务人或第三人造成损失的，承担赔偿责任
- 情节严重构成犯罪的，依法追究刑事责任

### 第28条【管理人聘用工作人员和管理人报酬】

**管理人报酬规定（《确定管理人报酬规定》）：**
| 财产价值总额 | 报酬比例上限 |
|--------------|--------------|
| ≤100万元 | 12% |
| 100-500万元部分 | 10% |
| 500-1000万元部分 | 8% |
| 1000-5000万元部分 | 6% |
| 5000万-1亿元部分 | 3% |
| 1亿-5亿元部分 | 1% |
| >5亿元部分 | 0.5% |

**注：** 担保物价值不计入报酬计算基数。

### 第29条【管理人辞去职务】

**要点：**
- 管理人没有正当理由不得辞去职务
- 辞去职务应经人民法院许可
- 无正当理由辞去职务未获许可的，可被罚款、从管理人名册除名

## 第四章 债务人财产

### 第30条【债务人财产范围】

**法条原文：**
> 破产申请受理时属于债务人的全部财产，以及破产申请受理后至破产程序终结前债务人取得的财产，为债务人财产。

**债务人财产构成：**
| 时间节点 | 财产范围 |
|----------|----------|
| 破产申请受理时 | 属于债务人的全部财产（包括已设定担保的财产） |
| 受理后至程序终结前 | 债务人取得的财产（膨胀主义） |

**不应认定为债务人财产的（《企业破产法规定(二)》第2条）：**
- 基于仓储、保管、承揽、代销等合同占有使用的他人财产
- 所有权保留买卖中尚未取得所有权的财产
- 所有权专属于国家且不得转让的财产
- 其他不属于债务人的财产

### 第31条【人民法院受理破产申请前1年内可撤销行为】

**可撤销行为类型：**
| 类型 | 行为特征 |
|------|----------|
| 无偿转让财产 | 无代价或实质无代价让渡财产 |
| 明显不合理价格交易 | 高价买入或低价卖出 |
| 对无财产担保债务提供担保 | 原本无担保的债务设定担保 |
| 对未到期债务提前清偿 | 债务未届清偿期而清偿 |
| 放弃债权 | 放弃债权权利 |

**时间要件：** 行为须发生在破产申请受理前1年内

### 第32条【破产申请受理前六个月内可撤销的个别清偿】

**法条原文：**
> 人民法院受理破产申请前六个月内，债务人有本法第二条第一款规定的情形，仍对个别债权人进行清偿的，管理人有权请求撤销。但是，个别清偿使债务人财产受益的除外。

**不予撤销的个别清偿情形（《企业破产法规定(二)》第14-16条）：**
- 债务人为维系基本生产需要支付水电费
- 债务人支付劳动报酬、人身损害赔偿金
- 使债务人财产受益的其他个别清偿
- 经诉讼、仲裁、执行程序的个别清偿（恶意串通除外）
- 债务人对自有财产设定担保物权的债权进行的个别清偿（担保财产价值低于债权额除外）

### 第33条【破产程序中无效行为】

**无效行为：**
- 为逃避债务而隐匿、转移财产
- 虚构债务或承认不真实债务
- 上述行为取得的财产应收归债务人财产

### 第38条【取回权】

**法条原文：**
> 人民法院受理破产申请后，债务人占有的不属于债务人的财产，该财产的权利人可以通过管理人取回。

**取回权分类：**
| 类型 | 依据 | 要件 |
|------|------|------|
| 一般取回权 | 第38条 | 财产被债务人合法占有 |
| 出卖人取回权 | 第39条 | 在运途中标的物、买受人未付清价款 |

**适用指引：**
- 取回权标的物毁损灭失的，权利人只能申报债权
- 权利人行使取回权应向管理人主张
- 重整期间取回需符合事先约定条件（第76条）

### 第40条【抵销权】

**法条原文：**
> 债权人在破产申请受理前对债务人负有债务的，可以向管理人主张抵销。

**不得抵销的情形：**
| 情形 | 说明 |
|------|------|
| 情形一 | 债务人的债务人在破产申请受理后取得他人对债务人的债权 |
| 情形二 | 债权人已知债务人不能清偿或破产申请的事实而负担债务（破产申请1年前因法律规定或发生的原因除外） |
| 情形三 | 债务人的债务人已知上述事实而取得债权（1年前原因除外） |

## 第五章 破产费用和共益债务

### 第41条【破产费用】

**破产费用范围：**
| 类型 | 内容 |
|------|------|
| 诉讼费用 | 破产案件的诉讼费用 |
| 管理变价分配费用 | 管理、变价和分配债务人财产的费用 |
| 执行职务费用 | 管理人执行职务的费用、报酬和聘用工作人员的费用 |

### 第42条【共益债务】

**共益债务类型：**
| 类型 | 产生情形 |
|------|----------|
| 履行双务合同 | 管理人或债务人请求对方履行未履行完毕合同产生的债务 |
| 无因管理 | 债务人财产受无因管理产生的债务 |
| 不当得利 | 因债务人不当得利产生的债务 |
| 继续营业 | 为债务人继续营业支付的劳动报酬和社会保险费用 |
| 执行职务致害 | 管理人或相关人员执行职务致人损害 |
| 财产致害 | 因债务人财产致人损害 |

### 第43条【破产费用和共益债务的清偿】

**清偿规则：**
1. 由债务人财产**随时清偿**
2. 不足清偿时，**优先清偿破产费用**
3. 不足清偿同一顺序的，**按比例清偿**
4. 财产不足支付破产费用的，**终结破产程序**

## 第六章 债权申报

### 第44条【破产债权人】

**法条原文：**
> 人民法院受理破产申请时对债务人享有债权的债权人，依照本法规定的程序行使权利。

**破产债权成立时点：** 破产申请受理时

### 第45条【债权申报期限】

**法条原文：**
> 债权申报期限自人民法院发布受理破产申请公告之日起计算，最短不得少于三十日，最长不得超过三个月。

### 第46条【未到期债权和附利息债权】

**规则：**
| 类型 | 处理方式 |
|------|----------|
| 未到期债权 | 视为到期（减去未到期利息） |
| 附利息债权 | 自破产申请受理时起停止计息 |

**"破产止息"的效力：**
- 担保人可以主张担保债务自破产受理之日起停止计息（《担保制度解释》第22条）
- 保证人可以主张保证债务适用"破产止息"

### 第47条【附条件、附期限债权和诉讼仲裁未决债权】

**要点：**
- 附条件、附期限债权可以申报
- 诉讼、仲裁未决债权可以申报
- 管理人应将分配额提存

### 第48条【债权申报方式】

**职工债权（不必申报）：**
| 债权类型 | 说明 |
|----------|------|
| 工资 | 拖欠的劳动报酬 |
| 医疗、伤残补助、抚恤费用 | 社会保险相关 |
| 基本养老保险、基本医疗保险 | 应划入职工个人账户的费用 |
| 补偿金 | 法律行政法规规定应支付的 |

**注：** 职工债权由管理人调查后列出清单并公示，职工有异议可要求更正或提起诉讼。

### 第49条【债权申报要求】

**申报内容：**
- 债权数额
- 有无财产担保
- 相关证据
- 连带债权的说明

### 第56条【补充申报债权】

**要点：**
- 债权人在确定的申报期限届满后可以补充申报
- 补充申报的费用承担：由此增加的费用由补充申报人承担
- 补充申报前已进行的分配，不再补充分配

### 第57条【管理人审查债权和编制债权表】

**要点：**
- 管理人对债权进行登记造册
- 管理人编制债权表
- 债权表应提交债权人会议核查

### 第58条【破产债权核查程序】

**债权确认程序：**
1. 管理人编制债权表
2. 债权人会议核查
3. 债务人、债权人对债权表有异议的，可向人民法院提起债权确认之诉

## 第七章 债权人会议

### 第59条【债权人会议的组成及表决权】

**债权人会议成员：**
| 类型 | 表决权 |
|------|--------|
| 有财产担保的债权人 | 有表决权（担保物变现前除外） |
| 放弃优先受偿权的债权人 | 有表决权 |
| 连带债权人 | 可推选一人或共同申报 |
| 债务人职工 | 列席（无表决权） |

**表决权计算：**
- 债权人按债权金额计算表决权
- 债权尚未确定的，原则上不得行使表决权

### 第60条【债权人会议主席】

**要点：**
- 人民法院可以指定有财产担保的债权人为债权人会议主席
- 主席负责召集和主持债权人会议

### 第61条【债权人会议职权】

**主要职权：**
| 职权 | 说明 |
|------|------|
| 核查债权 | 审查债权表 |
| 申请更换管理人 | 认为管理人不能胜任时 |
| 监督管理人 | 监督管理人执行职务 |
| 通过财产管理方案 | 债务人财产管理 |
| 通过变价方案 | 财产变现 |
| 通过分配方案 | 财产分配 |
| 选任债权人委员会 | 日常监督机构 |

### 第62条【召开债权人会议】

**召开条件：**
- 第一次债权人会议由人民法院召集
- 之后的会议可由债权人会议主席或管理人召集

### 第64条【债权人会议的决议规则】

**决议生效条件：**
| 事项类型 | 表决通过条件 |
|----------|--------------|
| 一般决议 | 出席会议有表决权债权人过半数通过，且其所代表的债权额占无财产担保债权总额半数以上 |
| 重整计划草案分组表决 | 同一表决组过半数通过，且所代表债权额占该组债权总额的三分之二以上 |
| 和解协议 | 由出席债权人会议的有表决权债权人过半数同意，且其所代表的债权额占无财产担保债权总额的三分之二以上 |

**效力：** 债权人会议的决议对全体债权人具有约束力。

### 第68条【债权人委员会】

**债权人委员会职权：**
| 职权 | 说明 |
|------|------|
| 监督财产管理 | 监督债务人财产管理和处分 |
| 监督分配 | 监督破产财产分配 |
| 提议召开债权人会议 | 提议召开临时会议 |
| 其他职权 | 债权人会议委托 |

## 典型案例

### 指导案例163号：江苏省纺织工业（集团）进出口有限公司等实质合并破产重整案

**关键词：** 实质合并破产、关联企业、债转股、预表决

**裁判要点：**
1. 关联企业成员破产以适用单个破产程序为原则
2. 法人人格高度混同时可例外适用实质合并破产
3. 实质合并后各关联企业债权债务归于消灭，财产统一分配
4. 可通过"现金+债转股"等方式灵活设计清偿方案

### 指导案例164号：江苏苏醇酒业有限公司实质合并破产重整案

**关键词：** 投资人试生产、破产保护、利益衡平

**裁判要点：**
1. 破产重整中可准许投资人在接管前先行投入部分资金进行试生产
2. 试生产有利于恢复企业持续经营能力
3. 试生产应接受法院、管理人及债权人监督

### 指导案例165号：重庆金江印染有限公司实质合并破产清算案

**关键词：** 实质合并破产清算、听证程序

**裁判要点：**
1. 关联企业破产清算应单独审查破产原因
2. 法人人格高度混同时可申请实质合并破产清算
3. 人民法院应组织听证，综合考量混同程度、利益关系等因素
