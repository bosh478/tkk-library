## 上篇：刑法总则

### 第一编 总则（刑法典全文）

本部分对刑法总则进行了全面释解，内容涵盖刑法的任务、基本原则、适用范围、犯罪、刑罚、刑罚的具体运用等核心内容。

#### 第一章 刑法的任务、基本原则和适用范围

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1条 | 立法目的和根据 | 惩罚犯罪、保护人民；宪法根据+实践根据 |
| 第2条 | 刑法任务 | 保卫国家安全；保护国有/集体/私有财产；保护公民权利；维护社会秩序经济秩序 |
| 第3条 | 罪刑法定原则 | 法无规定不为罪、法无规定不处罚；禁止类推；明确性要求 |
| 第4条 | 法律面前人人平等 | 定罪公正、量刑公正、行刑公正；反对特权 |
| 第5条 | 罪责刑相适应 | 罪重则刑重、罪轻则刑轻；重罪重判、轻罪轻判、罚当其罪 |
| 第6条 | 属地管辖 | 领域内犯罪（含船舶航空器）；行为或结果有一项在领域内即适用 |
| 第7条 | 属人管辖 | 中国公民领域外犯罪（三年以下可不追究）；国家工作人员/军人无条件适用 |
| 第8条 | 保护管辖 | 外国人领域外对国家/公民犯罪（三年以上、可双重犯罪例外） |
| 第9条 | 普遍管辖 | 缔约义务范围内的国际犯罪 |
| 第10条 | 外交豁免 | 外交途径解决 |

#### 第二章 犯罪

##### 第一节 犯罪和刑事责任

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第14条 | 故意犯罪 | 明知+希望/放任 |
| 第15条 | 过失犯罪 | 应知+轻信避免/疏忽大意 |
| 第16条 | 不可抗力/意外事件 | 无罪过不承担刑事责任 |
| 第17条 | 刑事责任年龄 | 16+完全；14-16八类重罪负责；12-14两档情节需核准 |
| 第17条之一 | 老年人犯罪 | 75+故意犯罪可从轻；过失犯罪应当从轻 |
| 第18条 | 精神病人犯罪 | 精神病发作时无责任能力不负责；间歇性精神病的清醒时需负责 |
| 第19条 | 又聋又哑/盲人 | 可从轻/减轻/免除 |
| 第20条 | 正当防卫 | 不负刑责；明显超过必要限度造成重大损害属防卫过当，应负刑责但应减轻/免除 |
| 第21条 | 紧急避险 | 不得已采取；超过必要限度应负刑责但应减轻/免除 |
| 第22条 | 犯罪预备 | 可比照既遂犯从轻/减轻/免除 |
| 第23条 | 犯罪未遂 | 比照既遂犯从轻/减轻 |
| 第24条 | 犯罪中止 | 没有造成损害的应免除；造成损害的应减轻 |
| 第25条 | 共同犯罪 | 二人以上共同故意犯罪 |
| 第26条 | 主犯 | 组织、领导犯罪集团或起主要作用 |
| 第27条 | 从犯 | 次要或辅助作用，应从轻/减轻/免除 |
| 第28条 | 胁从犯 | 被胁迫参加，可减轻/免除 |
| 第29条 | 教唆犯 | 教唆不满18周岁从重；被教唆人未犯可从轻/减轻 |
| 第30条 | 单位犯罪 | 机关/团体/企业/事业单位为本单位谋取非法利益 |
| 第31条 | 单位犯罪的处罚 | 双罚制（单位+直接责任人） |

##### 第二节 犯罪的预备、未遂和中止

- **第22条**：为犯罪准备工具、制造条件 → 预备犯
- **第23条**：已着手实行但未得逞 → 未遂犯（意志以外原因）
- **第24条**：自动放弃或有效防止结果 → 中止犯

##### 第三节 共同犯罪

- **组织、领导犯罪集团** → 主犯（首要分子）
- **在共同犯罪中起次要/辅助作用** → 从犯
- **被胁迫参加** → 胁从犯
- **教唆不满18周岁犯罪** → 从重处罚

##### 第四节 单位犯罪

- 公司、企业、事业单位、机关、团体实施危害社会行为
- 法律明文规定为犯罪才负刑事责任
- 双罚制：单位+直接责任人员

#### 第三章 刑罚

##### 第一节 刑罚的种类

| 刑种 | 条文 | 要点 |
|------|------|------|
| 主刑 | 第32-34条 | 管制、拘役、有期徒刑、无期徒刑、死刑 |
| 附加刑 | 第34-35条 | 罚金、剥夺政治权利、没收财产；驱逐出境（外国人） |

##### 死刑

- **第48条**：死刑只适用于罪行极其严重的犯罪分子
- **死缓制度**：判处死刑同时宣告缓期二年执行（2015年修正案九后累犯+八类重罪限制减刑）
- **第50条**：死缓期满后处理（减无期/有期25年/执行死刑）
- **第51条**：死缓期间刑期计算

##### 剥夺政治权利

- 第54条：四项政治权利（选举/被选举权、言论等自由、担任公职、担任国企领导）
- 第55条：期限1-5年（管制附加时与管制同期）
- 第57条：死刑/无期应剥夺政治权利终身

#### 第四章 刑罚的具体运用

##### 量刑原则（第61条）

根据犯罪的事实、性质、情节和危害程度，依照本法规定判处。

**法定/酌定从重情节**、**法定/酌定从轻情节**

##### 累犯（第65-66条）

| 类型 | 条件 | 后果 |
|------|------|------|
| 一般累犯 | 5年内+有期徒刑以上+故意 | 从重处罚 |
| 特殊累犯 | 国安/恐怖/黑社会组织犯罪+任何时间 | 以累犯论 |

**不满18周岁的人犯罪不构成累犯**

##### 自首和立功（第67-68条）

| 情形 | 处理 |
|------|------|
| 自首 | 可从轻/减轻；犯罪较轻可免除 |
| 坦白 | 可从轻；避免特别严重后果可减轻 |
| 立功 | 可从轻/减轻；重大立功可减轻/免除 |

**自首认定**：自动投案+如实供述

##### 数罪并罚（第69-77条）

- **原则**：在总和刑期以下、最高刑期以上酌情决定
- **限制**：管制最高3年、拘役最高1年、有期徒刑20年/25年（35年以上）
- **先并后减**（第70条）：发现漏罪
- **先减后并**（第71条）：又犯新罪

##### 缓刑（第72-77条）

| 条件 | 禁止 |
|------|------|
| 拘役/三年以下；悔改+无再犯危险+社区无重大不良影响 | 累犯+犯罪集团首要分子 |

**三类应当宣告缓刑**：不满18周岁、怀孕妇女、已满75周岁

##### 减刑（第78-80条）

- 认真遵守监规+接受教育改造+确有悔改/立功 → 可减
- 重大立功 → 应当减
- **最低实际执行刑期**：有期/管制/拘役不少原判1/2；无期不少于13年

##### 假释（第81-86条）

| 条件 | 禁止 |
|------|------|
| 有期执行1/2以上；无期执行13年以上；确有悔改+无再犯危险 | 累犯+十年以上八类重罪 |

**假释考验期**：有期为未执行完毕刑期；无期为10年

##### 时效（第87-89条）

| 法定最高刑 | 追诉期限 |
|------------|----------|
| 不满5年 | 5年 |
| 5-10年 | 10年 |
| 10年以上 | 15年 |
| 无期/死刑 | 20年（最高检核准可追诉） |

**不受追诉限制**：立案后逃避侦查/审判；应当立案而不立案
