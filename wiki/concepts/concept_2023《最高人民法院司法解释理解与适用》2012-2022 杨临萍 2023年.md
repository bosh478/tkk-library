## 书籍结构

本书结集刊发了《人民司法》杂志2012年至2022年间刊发的重要司法解释的理解与适用文章，按部门法分为九大篇：

| 篇名 | 主要内容 |
|------|----------|
| **一、综合篇** | 总类、审判管理、审判组织、统一法律适用 |
| **二、民事篇** | 劳动争议、疫情案件、婚姻家庭、继承、担保、人格权 |
| **三、商事篇** | 破产重整、证券纠纷、外商投资、民间借贷 |
| **四、刑事篇** | 危害生产安全、金融犯罪、毒品犯罪、环境污染、知识产权犯罪 |
| **五、行政篇** | 行政协议、行政诉讼、国家赔偿 |
| **六、知识产权篇** | 专利、商标、著作权、技术调查官 |
| **七、国家赔偿篇** | 赔偿程序、精神损害赔偿 |
| **八、执行篇** | 执行异议、破产执行、网络执行 |
| **九、程序篇** | 立案、审判监督、仲裁、在线诉讼 |

## 核心内容领域

### 一、综合篇

#### (一) 总类
- **司法为民理念**：要求人民法院切实践行司法为民宗旨

| 数额/情节 | 贪污罪 | 受贿罪 |
|-----------|--------|--------|

| 数额巨大 | 20万元以上不满300万元 |  |
| 数额特别巨大 | 300万元以上 |  |
| 其他情节 | 特定情形下调档 |  |

### 帮信罪定罪标准
- 明知他人利用信息网络犯罪
- 提供支付结算帮助
- 情节严重

### 知识产权惩罚性赔偿
- 故意侵权 + 情节严重
- 倍数：1-5倍
- 基数：实际损失/违法所得/合理倍数
