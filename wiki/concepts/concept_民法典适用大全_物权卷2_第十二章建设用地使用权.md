# 民法典第十二章【建设用地使用权】综合

## 章节目录

本章共 18 条（Articles 344-361），是**用益物权编中条文最多的章节**，规定国有土地上的建设用地使用权制度——出让、划拨双轨制、设立登记、流转、续期、收回等。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第344条 | 建设用地使用权的概念 | 国家所有土地 + 占有、使用、收益 + 建造建筑物 |
| 第345条 | 分层设立 | 地表、地上或地下分别设立 |
| 第346条 | 设立原则 | 节约资源 + 保护生态 + 遵守用途 |
| 第347条 | 设立方式 | 出让 / 划拨 |
| 第348条 | 出让合同 | 招标、拍卖、协议等 + 书面形式 |
| 第349条 | 设立登记 | 登记时设立 |
| 第350条 | 土地用途 | 不得擅自改变 |
| 第351条 | 出让金等费用 | 依法 + 依约支付 |
| 第352条 | 建筑物等设施权属 | 属于建设用地使用权人（相反证据除外） |
| 第353条 | 流转方式 | 转让、互换、出资、赠与、抵押 |
| 第354条 | 流转合同形式和期限 | 书面 + 不得超过剩余期限 |
| 第355条 | 流转后变更登记 | 应向登记机构申请 |
| 第356-357条 | 房随地走 / 地随房走 | 一并处分原则 |
| 第358条 | 提前收回及补偿 | 公共利益 + 第243条 |
| 第359条 | 续期 | 住宅自动续期；非住宅依法律 |
| 第360条 | 注销登记 | 出让人及时办理 |
| 第361条 | 集体土地作为建设用地 | 依土地管理法律规定办理 |

## 核心制度一：建设用地使用权的概念与设立

### 第344条 法条原文

> 建设用地使用权人依法对国家所有的土地享有占有、使用和收益的权利，有权利用该土地建造建筑物、构筑物及其附属设施。

**核心要点**：
1. **客体**：**国家所有的土地**（不含集体土地——集体土地作为建设用地依第361条 + 土地管理法）
2. **权能**：占有、使用、收益 + 建造建筑物、构筑物及其附属设施
3. **派生**：从国家土地所有权派生

### 第345条 分层设立

> 建设用地使用权可以在土地的地表、地上或者地下分别设立。

**意义**：承认**空间权**——地上、地下空间可以单独设立使用权（适应立体化土地利用）。

### 第346条 设立原则

> 设立建设用地使用权，应当符合**节约资源、保护生态环境**的要求，遵守法律、行政法规关于**土地用途**的规定，不得损害已经设立的用益物权。

**三原则**：
1. 节约资源
2. 保护生态环境
3. 遵守土地用途 + 不得损害已设立的用益物权

## 核心制度二：出让/划拨双轨制（第347条）

### 第347条 法条原文

> 设立建设用地使用权，可以采取出让或者划拨等方式。

**双轨制沿革**：

| 阶段 | 制度 | 内容 |
|------|------|------|
| 计划经济时期 | 无偿划拨 | 国家所有权人地位虚置，国有土地收益流失 |
| 1988年《土地管理法》修正 | **有偿使用制度** | 国家依法实行国有土地有偿使用制度 |
| 1994年《城市房地产管理法》 | 有偿 + 划拨双轨 | 国家依法实行国有土地有偿、有限期使用制度；同时可划拨 |
| 现行（民法典） | 出让 / 划拨 双轨并存 | 出让为主导，划拨为例外 |

| 方式 | 性质 | 适用 |
|------|------|------|
| **出让** | **有偿**（支付出让金） | 经营性用地 |
| **划拨** | **无偿**（特定情形） | 国家机关用地、军事用地、城市基础设施、公益事业等 |

### 第348条 出让合同

> 通过招标、拍卖、协议等出让方式设立建设用地使用权的，当事人应当采用书面形式订立建设用地使用权出让合同。

**出让方式**：
- 招标
- 拍卖
- 协议（限制使用）

**形式要求**：**书面形式**（要式合同）

### 第349条 设立登记

> 设立建设用地使用权的，应当向登记机构申请建设用地使用权登记。**建设用地使用权自登记时设立**。

**设立时点**：**登记时设立**（与土地承包经营权的"合同生效时设立"形成对比）。

## 核心制度三：用途管制与费用支付（第350-351条）

### 第350条 土地用途

> 建设用地使用权人应当合理利用土地，**不得改变土地用途**；需要改变土地用途的，应当依法经有关行政主管部门批准。

**核心原则**：**不得擅自改变土地用途**。

### 第351条 出让金等费用

> 建设用地使用权人应当依照法律规定以及合同约定支付出让金等费用。

**出让金含义**：建设用地使用权人依照法律规定以及合同约定向国家缴纳的出让价款及其他应当支付的税费等，是其取得建设用地使用权的**对价**。

## 核心制度四：建筑物权属与房随地走原则（第352条）

### 第352条 法条原文

> 建设用地使用权人建造的建筑物、构筑物及其附属设施的所有权属于建设用地使用权人，但是有相反证据证明的除外。

**基本原则**：**房随地走**——建筑物等设施的所有权属于建设用地使用权人（"相反证据"除外）。

## 核心制度五：流转（第353-357条）

### 第353条 流转方式

> 建设用地使用权人有权将建设用地使用权转让、互换、出资、赠与或者抵押，但是法律另有规定的除外。

**五种流转方式**：转让、互换、出资、赠与、抵押。

### 第354条 流转合同形式和期限

> 建设用地使用权转让、互换、出资、赠与或者抵押的，当事人应当采用书面形式订立相应的合同。**使用期限由当事人约定，但是不得超过建设用地使用权的剩余期限**。

**关键限制**：流转期限**不得超过原建设用地使用权的剩余期限**。

### 第355条 流转后变更登记

> 建设用地使用权转让、互换、出资或者赠与的，应当向登记机构申请变更登记。

### 第356-357条 房随地走 / 地随房走（一并处分原则）

| 条款 | 规则 |
|------|------|
| 第356条 | 建设用地使用权转让、互换、出资或者赠与的，**附着于该土地上的建筑物、构筑物及其附属设施一并处分** |
| 第357条 | 建筑物、构筑物及其附属设施转让、互换、出资或者赠与的，**该建筑物、构筑物及其附属设施占用范围内的建设用地使用权一并处分** |

**核心原则**：**房随地走 + 地随房走 = 一并处分**（避免权属分离）。

## 核心制度六：提前收回与续期（第358-360条）

### 第358条 提前收回及补偿

> 建设用地使用权期限届满前，因公共利益需要提前收回该土地的，应当依据本法第二百四十三条的规定对该土地上的房屋以及其他不动产给予补偿，并退还相应的出让金。

**收回条件**：
1. **公共利益需要**
2. 提前收回
3. 给予**补偿**（房屋 + 其他不动产）
4. **退还相应出让金**

### 第359条 续期

> **住宅建设用地使用权期限届满的，自动续期**。续期费用的缴纳或者减免，依照法律、行政法规的规定办理。
>
> 非住宅建设用地使用权续期依法律、行政法规规定办理。

**核心规则**：

| 用地类型 | 续期规则 |
|---------|---------|
| **住宅** | **自动续期** |
| **非住宅** | 依法律、行政法规办理 |

**注意**：住宅续期**费用的缴纳或减免**仍需依法律、行政法规——目前尚无统一规定（《民法典适用大全》释义）。

### 第360条 注销登记

> 建设用地使用权消灭的，出让人应当及时办理注销登记。登记机构应当收回权属证书。

## 核心制度七：集体土地作为建设用地（第361条）

> 集体所有的土地作为建设用地的，应当依照土地管理的法律规定办理。

**含义**：集体土地作为建设用地（不同于国有土地）须依《土地管理法》等法律规定办理（如集体经营性建设用地入市）。

## 适用指引综合

### 审判核心要点

1. **设立时点**：登记时设立（与土地承包经营权不同）
2. **双轨制**：出让 + 划拨
3. **用途管制**：不得擅自改变土地用途
4. **一并处分**：房随地走 + 地随房走
5. **续期**：住宅自动续期；非住宅依规定
6. **提前收回**：公共利益 + 补偿 + 退还出让金

## 实务问答精选

> **问**：建设用地使用权何时设立？
>
> **答**：**登记时设立**（《民法典》第349条）。与土地承包经营权"合同生效时设立"形成对比。

> **问**：建设用地使用权的设立方式有哪些？
>
> **答**：**出让**（有偿、主导）和**划拨**（无偿、例外）。双轨制起源于 1988 年《土地管理法》修正和 1994 年《城市房地产管理法》。

> **问**：住宅建设用地使用权期满后是否自动续期？
>
> **答**：**自动续期**（《民法典》第359条）。但续期费用的缴纳或减免仍需依法律、行政法规规定办理（目前尚无统一规定）。

> **问**：建筑物与建设用地使用权流转时如何处理？
>
> **答**：**一并处分原则**——房随地走（第356条）+ 地随房走（第357条）。建筑物/构筑物/附属设施的所有权属于建设用地使用权人（第352条，但有相反证据的除外）。

> **问**：集体土地可以作为建设用地吗？
>
> **答**：可以，但须**依《土地管理法》等法律规定办理**（《民法典》第361条）。如集体经营性建设用地入市。
