# 《纪检监察办案程序一本通》第二章 问题线索处置

## 🎯 核心论点

**问题线索处置 = 4 种处置方式（依线索性质分流）**

**《中国共产党纪律检查机关监督执纪工作规则》规定的 4 种处置方式**：

| 处置方式 | 性质 | 时限 |
|---------|------|------|
| **谈话函询** | 轻 | 30日内 |
| **初步核实** | 中 | 2个月内（可延长1个月）|
| **暂存待查** | 暂缓 | 视情况 |
| **予以了结** | 终结 | 视情况 |

---

## 第一节 处置方式和要求

## 一、4 种处置方式概述

### （一）谈话函询

**性质**：最轻的处置方式

**适用情形**：
- 反映问题**具有一般性**
- 查清了只能给予轻处分或批评教育
- 反映问题**不实**而予以澄清

**特点**：
- 不进入正式审查调查程序
- 通过谈话或书面函询了解情况
- 处理结果影响后续处置

### （二）初步核实

**性质**：中等处置方式

**适用情形**：
- 涉嫌违纪或职务违法、职务犯罪问题线索**比较具体**
- 具有**可查性**
- **需要追究**纪律和法律责任

**特点**：
- 进入初步核实程序
- 可采取部分调查措施
- 不采取限制人身自由措施

### （三）暂存待查

**性质**：暂缓处置方式

**适用情形**：
- 反映的问题线索因**时机、现有条件、涉案人一时难以找到**等原因
- 暂**不具备核查的条件**

**特点**：
- 存放备查
- 定期评估
- 条件成熟时及时处置

### （四）予以了结

**性质**：终结处置方式

**适用情形**：
- 反映的问题线索**失实**
- 没有可能开展核查工作

**特点**：
- 终结处理
- 不再跟进
- 但应留有记录

## 二、处置时限要求

| 处置方式 | 时限 |
|---------|------|
| 谈话函询 | 一般30日内完成 |
| 初步核实 | 一般2个月内完成，重大复杂可延长1个月 |
| 暂存待查 | 视情况 |
| 予以了结 | 视情况 |

## 三、处置报告要求

处置结束后需形成书面报告，载明：
- 线索来源
- 处置过程
- 核查情况
- 处理建议

## 四、承办部门线索管理要求

- 建立台账
- 定期清理
- 严格保密

## 第二节 四类处置方式详解

## 一、谈话函询

### （一）启动要求

- 经**领导审批**
- 制定工作方案
- 谈话函询对象明确

### （二）谈话实施

- 承办人**不得少于2人**
- 告知权利义务
- 制作谈话笔录
- 谈话笔录由被谈话人签字确认

### （三）函询实施

- 发函通知被反映人
- 要求在规定时间内**书面回复**
- 必要时可要求其到纪检监察机关说明情况

### （四）谈话函询后的处理

- 谈话函询材料归入个人廉政档案
- 根据谈话函询结果决定下一步处置
- 谈话函询中发现新问题 → 转入初步核实或审查调查

## 二、初步核实

### （一）初步核实启动要求

- 经领导审批
- 成立初核组（一般不少于2人）
- 制定初核方案

### （二）初步核实措施

可采取的措施（限于初核阶段）：
- 调取个人有关事项报告
- 查阅复制文件资料
- 与相关人员了解情况
- 委托审计

**不能采取的措施**：
- 限制人身自由措施
- 查封、扣押、冻结大额财产
- 留置等强制措施

### （三）初步核实后的处理

| 情形 | 处理 |
|------|------|
| 涉嫌违纪违法需追究纪律法律责任 | 转入立案审查调查 |
| 有违纪事实但不需追究纪律法律责任 | 给予批评教育、诫勉等 |
| 反映问题失实 | 予以了结，必要时澄清正名 |

## 三、暂存待查

**适用情形**：线索有价值但短期内难以查清或条件不成熟

**管理要求**：
- 定期评估
- 条件成熟时及时处置
- 重大变化时及时调整

## 四、予以了结

**适用情形**：
- 反映问题失实
- 虽有违纪事实但已过追责时效
- 情节轻微不需追究纪律法律责任

**程序**：经领导审批后予以了结

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **谈话函询** | 通过谈话或函询了解情况的轻处置 |
| **初步核实** | 对具体线索进行核查的中等处置 |
| **暂存待查** | 暂不具备核查条件时的暂缓处置 |
| **予以了结** | 反映问题失实或无需核查的终结处置 |
| **诫勉** | 谈话诫勉或书面诫勉，6个月影响期 |
| **四种形态** | 监督执纪的四种形态 |
| **廉政档案** | 领导干部廉政情况档案 |
