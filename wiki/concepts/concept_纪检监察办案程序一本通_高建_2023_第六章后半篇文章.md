| 字段 | 内容 |

## 🎯 核心论点

**"后半篇文章"= 案件查办后的延伸治理工作**

**核心理念**：
- 案件查办不是终点
- 治标与治本结合
- 监督执纪+审查调查+后半篇文章 三位一体

**5 大延伸工作**：
1. 案件剖析与整改
2. 制度建设和完善
3. 警示教育
4. 思想政治工作
5. 监督执纪"第一种形态"的运用

---

## 第一节 "后半篇文章"的内涵

## 一、概念

**"后半篇文章"** = 案件查办之后，为实现**政治效果、纪法效果、社会效果相统一**而开展的延伸治理工作。

**重要意义**：
- 治标与治本相结合
- 个案查办与系统治理相结合
- 惩治与教育相结合
- 监督执纪"四种形态"贯通运用

## 二、工作理念

**"三不腐"一体推进**：
- **不敢腐**（惩治威慑）
- **不能腐**（制度约束）
- **不想腐**（思想自觉）

**贯通运用"四种形态"**：
- 从第一种形态（教育提醒）到第四种形态（严重违纪违法立案审查）
- 把"后半篇文章"作为运用第一种形态的重要载体

---

## 第二节 5 大延伸工作

## 一、案件剖析与整改

### （一）案件剖析

**重点**：
- 案件发生的**制度原因**
- 案件发生的**管理原因**
- 案件发生的**监督原因**
- 案件发生的**思想原因**

**剖析方法**：
- 个案剖析（针对具体案件）
- 类案剖析（针对同类型案件）
- 系统剖析（针对系统性问题）

### （二）整改

**整改要求**：
- **明确整改责任**（单位+个人）
- **明确整改时限**
- **明确整改措施**
- **跟踪整改落实**

**整改机制**：
- 整改台账管理
- 整改销号制度
- 整改"回头看"

## 二、制度建设和完善

### （一）建章立制

**重点领域**：
- 决策制度
- 审批制度
- 监督制度
- 风险防控制度

### （二）制度执行

- 制度宣传教育
- 制度执行检查
- 制度执行考核

### （三）制度清理

- 与时俱进修订
- 废止过时制度
- 整合零散制度

## 三、警示教育

### （一）警示教育方式

| 方式 | 内涵 |
|------|------|
| **警示教育大会** | 集中通报+以案促改 |
| **警示教育片** | 制作案例视频 |
| **警示教育基地** | 现场教学 |
| **案例汇编** | 文字材料学习 |
| **专题民主生活会/组织生活会** | 对照检查 |

### （二）警示教育内容

- 案件事实
- 案件原因
- 案件教训
- 整改要求

- 重塑政治生态
- 巩固监督执纪成效

### （二）思想政治工作方法

## 五、监督执纪"第一种形态"的运用

### （一）第一种形态的内涵

**第一种形态** = 经常开展**批评和自我批评、约谈函询**。

**意义**：
- 抓早抓小
- 防微杜渐
- 源头治理

### （二）第一种形态的运用方式

| 方式 | 内涵 |
|------|------|
| 谈心谈话 | 经常性谈心谈话 |
| 约谈函询 | 针对轻微问题 |
| 提醒谈话 | 及时提醒 |
| 批评教育 | 严肃批评教育 |
| 责令检查 | 要求书面检查 |
| 通报批评 | 公开通报 |
| 民主生活会批评 | 党内批评 |

### （三）"后半篇文章"与第一种形态的衔接

- "后半篇文章"是第一种形态的**重要载体**
- 在案件查办后开展第一种形态 → 巩固成效
- 案件查办 + 第一种形态 → 形成**完整闭环**

## 第四节 典型经验

## 一、'一案双查'

**一案双查** = 查办违纪违法案件的同时，倒查**主体责任**和**监督责任**。

**目的**：推动"两个责任"落实

## 二、'三个区分开来'

**三个区分开来**：
1. 把因缺乏经验、先行先试出现的失误与明知故犯行为区分开来
2. 把国家尚无明确规定时的探索性试验与国家明令禁止后有规不依的行为区分开来
3. 把为推动发展的无意过失与为谋取私利的故意行为区分开来

**目的**：保护干部干事创业积极性

## 三、'四种形态'贯通运用

- 第一种形态：教育提醒
- 第二种形态：党纪轻处分
- 第三种形态：重处分
- 第四种形态：立案审查

四种形态**贯通运用** + **后半篇文章** → 完整监督执纪体系
