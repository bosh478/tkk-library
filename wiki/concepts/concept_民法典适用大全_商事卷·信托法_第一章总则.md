| 法条 | 主题 | 核心制度 |
|------|------|---------|

| 第9条 | 信托文件必备条款 | 必备条款 + 选择性条款 |
| 第10条 | 信托登记 | 法定需办理登记的信托财产 |
| 第11条 | 信托无效 | 信托目的违反法律/行政法规/损害社会公共利益 |
| 第12条 | 欺诈信托撤销 | 设立信托损害债权人利益的，债权人可申请撤销 |

## 一、第1条·信托法立法宗旨

### 法条原文

> 第一条　为了调整信托关系，规范信托行为，保护信托当事人的合法权益，促进信托事业的健康发展，制定本法。

### 核心释义

**4项立法宗旨**：

| 立法宗旨 | 内容 |
|---------|------|
| **调整信托关系** | 解决信托基本关系问题（信托活动中产生的财产转移、管理处分及受益所形成的财产信赖关系） |
| **规范信托行为** | 解决信托业市场定位、业务范围、风险控制等 |
| **保护信托当事人的合法权益** | 委托人是创设信托的人 + 受托人是基于信托而持有财产的人 + 受益人享有信托财产利益的人 |
| **促进信托事业的健康发展** | 在法治环境中规范信托业发展 |

**信托的5个特点**：

| 特点 | 内容 |
|------|------|
| 1 | **信任为基础**（受人之托，忠人之事） |
| 2 | **委托人将财产权转移给受托人**（含物权、债权、知识产权及其他无形财产权） |
| 3 | **信托财产独立性**（从委托人/受托人/受益人自有财产中分离） |
| 4 | **受托人谨慎义务**（忠诚、谨慎、尽职） |
| 5 | **存续连贯性**（不因受托人死亡、解散、辞任等终止） |

## 二、第2条·信托定义

### 法条原文

> 第二条　本法所称信托，是指委托人基于对受托人的信任，将其财产权委托给受托人，由受托人按委托人的意愿以自己的名义，为受益人的利益或者特定目的，进行管理或者处分的行为。

### 核心释义

**信托定义的4层含义**：

| 含义 | 内容 |
|------|------|
| 1. 委托人信任受托人 | 信托关系成立的基础；受托人须忠诚、谨慎、尽职 |
| 2. 委托人将财产权委托给受托人 | 信托财产是成立信托的第一要素；原则上除身份权、名誉权、姓名权外，其他权利均可设立信托 |
| 3. 受托人以自己的名义管理、处分信托财产 | 信托的重要特征；不需要借助于委托人、受益人的名义 |
| 4. 受托人为受益人的最大利益管理信托事务 | 按照委托人意愿 + 为受益人利益（不能为自己或第三人利益） |

**信托关系的3个特征**：

| 特征 | 内容 |
|------|------|
| 三方法律关系 | 委托人 + 受托人 + 受益人（典型信托） |
| 受托人以自己名义 | 与委托代理的区别之一 |
| 独立财产 | 信托财产独立于三方当事人的自有财产 |

**信托的多种分类**：

| 分类标准 | 类型 |
|---------|------|
| 意思表示形式 | 明示信托 / 默示信托 |
| 法律是否有明文规定 | 法定信托 / 推定信托 |
| 信托目的 | 私益信托 / 公益信托 |
| 是否以金钱为标的 | 金钱信托 / 非金钱信托 |
| 委托人与受益人是否同一 | 自益信托 / 他益信托 |
| 信托生效时间 | 生前信托 / 死后信托（遗嘱信托） |
| 委托人是否保留撤销权 | 可撤销信托 / 不可撤销信托 |
| 信托行为设立形态 | 契约信托 / 遗嘱信托 |
| 受托人行为性质 | 营业性信托 / 非营业性信托 |
| 信托财产管理方式 | 个别信托 / 集团信托 |
| 受益人是否确定 | 固定信托 / 自由裁量信托 |
| 信托设立依据 | 意定信托 / 法定信托 |

**信托 vs 委托代理的6点区别**：

| 维度 | 信托 | 委托代理 |
|------|------|---------|
| 行动名义 | 受托人以自己名义对外 | 代理人对外以显名为原则（隐名为例外） |
| 财产所有权 | 信托财产所有权转移至受托人名下 | 财产仍属委托人 |
| 委托人权限 | 受托人享有充分自主权 | 委托人可随时发出指示甚至改变主意 |
| 成立条件 | 必须有确定的信托财产 | 不以财产为前提 |
| 行为效果归属 | 不直接归属于委托人/受益人 | 直接归属于被代理人 |
| 意思表示 | 当事人建立关系时的意思为准 | 同 |

**信托 vs 行纪的5点区别**：

| 维度 | 信托 | 行纪 |
|------|------|------|
| 业务范围 | 财产的管理、处分、投资、收益分配 | 主要是贸易活动 |
| 受托人地位 | 以自己意志处理，享有自主权 | 须服从委托人的指示 |
| 有偿性 | 可有偿可无偿 | 通常有偿 |
| 适用范围 | 各种财产 | 主要适用于动产 |
| 财产性质 | 信托财产具有独立性 | 行纪财产所有权属委托人 |

### 典型案例

#### 北京星河世界集团有限公司与渤海国际信托股份有限公司金融借款合同纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2020）最高法民终142号 |
| 审理法院 | 最高人民法院 |
| 裁判要点 | 案涉《资金信托合同》形成于银监发〔2018〕4号文件之前，按"新老划断"政策属于存量业务。渤海信托提起本案诉讼属于对存量业务的消化行为，故案涉《信托贷款合同》项下贷款系受托人渤海信托收取的信托财产，与委托人未设立信托的其他财产以及受托人的财产均相区别。案涉《信托贷款合同》应属有效合同 |

## 三、第3条·信托法适用范围

### 法条原文

> 第三条　委托人、受托人、受益人（以下统称信托当事人）在中华人民共和国境内进行民事、营业、公益信托活动，适用本法。

### 核心释义

**3类信托的区分**：

| 类型 | 特点 | 典型代表 |
|------|------|---------|
| **民事信托**（非营业性信托） | 以个人财产为抚养、赡养、处理遗产等目的；受托人为自然人；不以营利为目的 | 家庭信托、遗嘱信托、遗产管理 |
| **营业信托**（商事信托 / 信托营业） | 以营利为目的；以信托方式从事的商事行为；受《信托法》第4条监管 | 信托公司、证券投资基金管理公司 |
| **公益信托**（慈善信托） | 为促进慈善事业和学术及其他公益事业；只能是他益信托 | 公益基金会、慈善信托 |

**民事信托 vs 营业信托的3种学说**：

| 学说 | 内容 |
|------|------|
| 目的说 | 出于个人/家人目的为民事信托；以从事商行为为目的为商事信托 |
| 行为说 | 接受信托之行为是否具有营业性；主流学说 |
| 受托人身份说 | 受托人是否专门经营信托业务；委托普通自然人为民事信托；委托专门机构为商事信托 |

**营业信托的3个特点**：

| 特点 | 内容 |
|------|------|
| 营利性 | 通过受托人的管理活动获得相应的利益 |
| 营业性 | 往往通过信托公司经营 |
| 商品性 | 受益权凭证化或证券化 |

**营业信托的10类业务**：

| 序号 | 业务 |
|------|------|
| 1 | 资金信托 |
| 2 | 动产信托 |
| 3 | 不动产信托 |
| 4 | 有价证券信托 |
| 5 | 其他财产或财产权信托 |
| 6 | 作为投资基金或基金管理公司的发起人从事投资基金业务 |
| 7 | 经营企业资产的重组、并购以及项目融资、公司理财、财务顾问 |
| 8 | 受托经营国务院有关部门批准的证券承销业务 |
| 9 | 办理中介、咨询、资信调查 |
| 10 | 代保管保管箱业务 |

**遗嘱信托的依据**（《民法典》第1133条第4款）：
> 自然人可以依法设立遗嘱信托。

## 四、第4条·营业信托机构监管

### 法条原文

> 第四条　受托人采取信托机构形式从事信托活动，其组织和管理由国务院制定具体办法。

### 核心释义

**营业信托的监管体系**：

| 监管层级 | 内容 |
|---------|------|
| 法律层 | 《信托法》（基础法律） |
| 行政法规层 | 《信托机构管理条例》（国务院制定中） |
| 部门规章层 | 《信托公司管理办法》《信托公司集合资金信托计划管理办法》（银保监会） |
| 监管机构 | 中国人民银行 → 中国银保监会 |

**信托机构的设立条件**（《信托公司管理办法》第7条）：
- 须经中国银保监会批准
- 领取金融许可证
- 未经批准，任何单位和个人不得经营信托业务

**保险资金投资信托的特殊要求**（银保监办发〔2019〕144号）：

| 要求 | 内容 |
|------|------|
| 净资产门槛 | 上年末经审计的净资产不低于30亿元 |
| 合规要求 | 近一年公司及高级管理人员未发生重大刑事案件，未受监管机构重大行政处罚 |
| 禁止通道业务 | 不得将资金信托作为通道；不得投资单一资金信托；不得投资结构化集合资金信托的劣后级受益权 |

### 典型案例

#### 姜某某与洪范基金管理有限公司吉林省分公司等信托纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2019）吉01民终1371号 |
| 审理法院 | 吉林省长春市中级人民法院 |
| 裁判要点 | 设立有效信托的生效法律要件中包含关于信托当事人主体资格的生效要件，**营业信托的受托人必须是持有金融许可证的信托机构**。洪范基金吉林分公司未取得金融许可证，不具备从事一般信托业务的受托人资格，与姜某某之间**并未形成有效的信托法律关系** |

## 五、第5条·信托活动基本原则

### 法条原文

> 第五条　信托当事人进行信托活动，必须遵守法律、行政法规，遵循自愿、公平和诚实信用原则，不得损害国家利益和社会公共利益。

### 核心释义

**3项基本原则**：

| 原则 | 内容 |
|------|------|
| **合法原则** | 遵守法律、行政法规；对信托财产范围、受托人资格等有限制 |
| **自愿、公平和诚实信用原则** | 自愿原则 + 公平原则 + 诚信原则（帝王条款） |
| **不得损害国家利益和社会公共利益** | 不得违反公共政策，不得损害公序良俗 |

**自愿原则的4层含义**：

| 含义 | 内容 |
|------|------|
| 1 | 民事主体自愿从事民事活动 |
| 2 | 自主决定民事法律关系的内容 |
| 3 | 自主决定民事法律关系的变动 |
| 4 | 自己行为 + 自己责任 |

**公平原则的3层含义**：

| 含义 | 内容 |
|------|------|
| 1 | 民法规范应体现公平原则，兼顾各方利益 |
| 2 | 民事主体应本着公平的观念进行民事活动 |
| 3 | 民事行为的结果不能显失公平 |

**诚实信用原则的3项功能**：

| 功能 | 内容 |
|------|------|
| 指导功能 | 指导当事人依法正确行使权利、履行义务 |
| 弥补成文法局限 | 克服成文法的不完全性，授予法官自由裁量权 |
| 利益平衡 | 为利益关系平衡提供依据和法理支持 |

## 六、第6条·信托设立目的

### 法条原文

> 第六条　设立信托，必须有合法的信托目的。

### 核心释义

**信托目的合法性要求**：
- 信托目的不得违反法律、行政法规
- 信托目的不得损害社会公共利益
- 信托目的不得损害债权人利益（违反者依第12条可被撤销）

## 七、第7条·确定、合法的信托财产

### 法条原文

> 第七条　设立信托，必须有确定的、合法的信托财产。
>
> 前款所称财产包括合法的财产权利。

### 核心释义

**信托财产的2个必备条件**：

| 条件 | 内容 |
|------|------|
| **确定性** | 财产是确定的、特定的，可以是特定的物或财产权利 |
| **合法性** | 财产必须是合法的，不能是违法所得 |

**可以作为信托财产的范围**：
- 物权（如房屋、土地使用权）
- 债权（如金钱债权）
- 知识产权（如专利权、商标权、著作权）
- 其他无形财产权

**不得作为信托财产的范围**：
- 身份权、名誉权、姓名权
- 消极财产权
- 委托人及其赡养人的生活必需品

## 八、第8条·信托设立形式和成立要件

### 法条原文

> 第八条　设立信托，应当采取书面形式。
>
> 书面形式包括信托合同、遗嘱或者法律、行政法规规定的其他书面文件等。
>
> 采取信托合同形式设立信托的，信托合同签订时，信托成立。采取其他书面形式设立信托的，受托人承诺信托时，信托成立。

### 核心释义

**信托设立形式（要式性）**：

| 形式 | 信托成立时点 |
|------|------------|
| 信托合同 | 信托合同签订时 |
| 遗嘱 | 受托人承诺信托时 |
| 法律、行政法规规定的其他书面文件 | 受托人承诺信托时 |

**信托合同vs委托合同**：
- 信托合同：要式合同（必须书面）
- 委托合同：非要式合同（可口头）

## 九、第9条·信托文件必备条款

### 法条原文

> 第九条　设立信托，其信托文件应当载明下列事项：
>
> （一）信托目的；
>
> （二）委托人、受托人的姓名或者名称、住所；
>
> （三）受益人或者受益人范围；
>
> （四）信托财产的范围、种类及状况；
>
> （五）受益人取得信托利益的形式、方法。
>
> 前款所列信托文件载明的事项，依照信托目的、信托财产管理或者处分方法等不同情形，有的可以省略。

### 核心释义

**5项必备条款**（可省略的为选择性条款）：

| 序号 | 必备条款 |
|------|---------|
| 1 | 信托目的 |
| 2 | 委托人、受托人的姓名或者名称、住所 |
| 3 | 受益人或者受益人范围 |
| 4 | 信托财产的范围、种类及状况 |
| 5 | 受益人取得信托利益的形式、方法 |

## 十、第10条·信托登记

### 法条原文

> 第十条　设立信托，对于信托财产，有关法律、行政法规规定应当办理登记手续的，应当依法办理信托登记。未依照前款规定办理信托登记的，应当补办登记手续。

### 核心释义

**信托登记的对象**：
- 仅限于法定需办理登记的信托财产
- 例：不动产、知识产权、股权等

**未登记的法律后果**：
- 应当补办登记手续
- 不补办的，可能影响信托财产的对抗效力

## 十一、第11条·信托无效

### 法条原文

> 第十一条　有下列情形之一的，信托无效：
>
> （一）信托目的违反法律、行政法规或者损害社会公共利益；
>
> （二）信托财产不能确定；
>
> （三）委托人以非法的财产或者本法第七条规定不得设立信托的财产设立信托；
>
> （四）专以诉讼或者讨债为目的设立信托；
>
> （五）受益人或者受益人范围不能确定；
>
> （六）法律、行政法规规定的其他情形。

### 核心释义

**信托无效的6种情形**：

| 序号 | 情形 |
|------|------|
| 1 | 信托目的违反法律、行政法规或损害社会公共利益 |
| 2 | 信托财产不能确定 |
| 3 | 委托人用非法的财产或不得设立信托的财产 |
| 4 | 专以诉讼或讨债为目的设立信托 |
| 5 | 受益人/受益人范围不能确定 |
| 6 | 法律、行政法规规定的其他情形 |

## 十二、第12条·欺诈信托撤销

### 法条原文

> 第十二条　委托人设立信托损害其债权人利益的，债权人有权申请人民法院撤销该信托。
>
> 人民法院依照前款规定的撤销权，自债权人知道或者应当知道撤销事由之日起一年内行使。自信托发生之日起五年内没有行使撤销权的，撤销权消灭。
>
> 此款规定的五年期间为除斥期间，不适用诉讼时效中止、中断或者延长的规定。

### 核心释义

**撤销权的行使**：

| 维度 | 内容 |
|------|------|
| 撤销权人 | 债权人（因设立信托受到损害的） |
| 撤销对象 | 损害债权人利益的信托 |
| 撤销机关 | 人民法院（依债权人申请） |
| 短期时效 | 自债权人知道/应当知道撤销事由之日起**1年** |
| 长期时效 | 自信托发生之日起**5年**（除斥期间，不中止/中断/延长） |

## 十三、第13条·遗嘱信托

### 法条原文

> 第十三条　设立遗嘱信托，应当遵守继承法关于遗嘱的规定。
>
> 遗嘱指定受托人或者其他遗嘱信托的财产归属的，效力依照继承法有关规定。
>
> （依《民法典》第1133条第4款规定：自然人可以依法设立遗嘱信托）

### 核心释义

**遗嘱信托的特别要求**：
- 须遵守《民法典》继承编关于遗嘱的规定（形式、内容）
- 遗嘱信托只能是他益信托
- 遗嘱指定受托人或财产归属的，效力依《民法典》继承编

## ⚠️ 司法适用难点

### 难点一：信托与委托代理的区分

**争议**：商业银行理财产品、资管产品究竟属于信托关系还是委托代理关系？

**主流观点**（依《九民会议纪要》第88条）：
- 信托公司等受托人开展的营业信托 → 信托关系
- 商业银行理财业务 → 多构成信托关系（但形式上可能采用委托代理合同）
- 证券公司、基金子公司的资管产品 → 区分认定

### 难点二：通道业务与主动管理信托的区分

**争议**：通道业务是否构成信托关系？

**主流观点**（依《九民会议纪要》第93条）：
- 通道业务中受托人仅提供事务协助 → 仍属于信托业务
- 但"新老划断"原则：过渡期内（截至2020年底）存量业务有效
- 委托人和受托人之间的权利义务 → 依据信托文件约定

### 难点三：信托公司未尽管理义务的侵权责任

**争议**：被动管理型信托中信托公司是否承担侵权责任？

**主流观点**（依吴某与华澳国际信托案）：
- 即使是通道业务，受托人在以自己名义独立从事信托管理事务时，仍应尽到**合理注意义务**
- 信托公司过错行为客观上促成犯罪分子集资诈骗的，应当根据其过错程度承担相应的侵权损害赔偿责任
- 例：华澳信托承担20%的补充赔偿责任

### 难点四：营业信托机构的认定

**争议**：未取得金融许可证的机构开展资产管理业务，是否构成信托关系？

**主流观点**：
- 受托人必须**持有金融许可证**，否则不能构成有效的营业信托关系（依姜某某与洪范基金案）
- 自然人违规以受托理财为业的，委托理财合同无效

### 难点五：第12条撤销权的双重时效

**争议**：1年和5年时效的适用？

**主流观点**：
- 1年：短期时效，自知道/应当知道撤销事由之日起算
- 5年：长期时效，**除斥期间**，自信托发生之日起算
- 不适用诉讼时效中止、中断、延长的规定

## ❓ 实务问答

### Q1：信托的5个特点是什么？

**A**：依《信托法》第2条释义：
1. **信任为基础**
2. **委托人将财产权转移给受托人**（含物权、债权、知识产权等）
3. **信托财产独立性**（独立于委托人/受托人/受益人）
4. **受托人谨慎义务**（忠诚、谨慎、尽职）
5. **存续连贯性**（不因受托人死亡/解散/辞任等终止）

### Q2：信托与委托代理的区别？

**A**：

| 维度 | 信托 | 委托代理 |
|------|------|---------|
| 行动名义 | 受托人以自己名义 | 代理人对外以显名为原则 |
| 财产所有权 | 转移至受托人名下 | 仍属委托人 |
| 委托人权限 | 受托人充分自主 | 委托人可随时指示 |
| 成立条件 | 必须有确定的信托财产 | 不以财产为前提 |
| 行为效果归属 | 不直接归属 | 直接归属于被代理人 |

### Q3：营业信托、民事信托、公益信托的区别？

**A**：

| 类型 | 受托人 | 目的 | 典型代表 |
|------|--------|------|---------|
| **营业信托** | 信托机构（需金融许可证） | 营利 | 信托公司 |
| **民事信托** | 自然人 | 个人/家庭（抚养、赡养、遗产） | 家庭信托、遗嘱信托 |
| **公益信托** | 信托机构或公益法人 | 公共利益 | 公益基金会、慈善信托 |

### Q4：信托法第12条撤销权的时效？

**A**：依《信托法》第12条第2款：
- **短期时效**：自债权人知道/应当知道撤销事由之日起**1年**
- **长期时效**：自信托发生之日起**5年**（**除斥期间**，不中止/中断/延长）

### Q5：信托无效的6种情形？

**A**：依《信托法》第11条：
1. 信托目的违反法律、行政法规或损害社会公共利益
2. 信托财产不能确定
3. 委托人用非法的财产或不得设立信托的财产
4. 专以诉讼或讨债为目的设立信托
5. 受益人/受益人范围不能确定
6. 法律、行政法规规定的其他情形

### Q6：信托设立的形式要件？

**A**：依《信托法》第8条：
- 设立信托应当采取**书面形式**
- 书面形式包括：**信托合同**、**遗嘱**或法律、行政法规规定的其他书面文件
- 信托合同签订时，信托成立
- 其他书面形式 → 受托人**承诺信托时**，信托成立

### Q7：信托文件的5项必备条款？

**A**：依《信托法》第9条：
1. 信托目的
2. 委托人、受托人的姓名或者名称、住所
3. 受益人或者受益人范围
4. 信托财产的范围、种类及状况
5. 受益人取得信托利益的形式、方法

### Q8：营业信托机构必须取得什么许可？

**A**：依《信托法》第4条 + 《信托公司管理办法》第7条：
- 须经中国银保监会批准
- 领取**金融许可证**
- 未经批准，任何单位和个人不得经营信托业务
