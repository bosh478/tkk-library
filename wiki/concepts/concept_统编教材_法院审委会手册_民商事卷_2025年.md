# 统编教材·法院审委会手册·民商事卷（2025年）

## 书籍概述

**全称**：《人民法院审判委员会审判手册·民商事卷》
**编写**：最高人民法院审判管理办公室
**出版**：人民法院出版社，2025年10月
**篇幅**：约385万字

## 内容结构

本手册包含**民法编**和**民事诉讼编**两大部分。

### 民法编

| 领域 | 主要内容 |
|------|----------|
| 一、综合 | 《民法典》总则编及相关司法解释 |
| 二、物权 | 所有权、用益物权、担保物权 |
| 三、合同 | 合同编通则、典型合同（买卖、租赁、借款、建设工程等） |
| 四、知识产权和竞争法 | 著作权、专利权、商标权、竞争法 |
| 五、劳动保障 | 劳动法、社会保险法、劳动争议 |
| 六、环境资源 | 环境保护、自然资源 |
| 七、公司（企业）、破产 | 公司法、企业破产法 |
| 八、证券、期货、保险、票据、信托 | 金融领域法律 |

#### 《民法典》结构（7编）
| 编 | 内容 |
|----|------|
| 第一编 总则 | 基本规定、自然人、法人、非法人组织、民事权利、法律行为、代理、民事责任、诉讼时效 |
| 第二编 物权 | 通则、所有权、用益物权、担保物权、占有 |
| 第三编 合同 | 通则、典型合同、准合同（无因管理、不当得利） |
| 第四编 人格权 | 生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权、个人信息保护 |
| 第五编 婚姻家庭 | 结婚、家庭关系、离婚、收养 |
| 第六编 继承 | 法定继承、遗嘱继承、遗产处理 |
| 第七编 侵权责任 | 一般规定、损害赔偿、产品责任、机动车交通事故、医疗损害、环境污染、饲养动物、建筑物 |

### 民事诉讼编

| 章节 | 主要内容 |
|------|----------|
| 一、综合 | 《民事诉讼法》全文及司法解释 |
| 二、公益诉讼 | 环境公益诉讼、消费公益诉讼 |
| 三、证据 | 证据规则、举证责任 |
| 四、调解 | 诉调对接 |
| 五、保全 | 诉前保全、诉讼保全 |
| 六、审判监督程序 | 再审程序 |
| 七、执行 | 执行程序、执行异议 |
| 八、涉港澳台 | 区际司法协助 |
| 九、涉外、海事海商 | 涉外民事诉讼、海事诉讼 |

## 重要司法解释

### 民法典适用
- 法释〔2020〕28号：关于适用《民法典》时间效力的若干规定
- 法释〔2020〕17号：关于适用《民法典》总则编若干问题的解释
- 《全国法院贯彻实施民法典工作会议纪要》

### 合同纠纷
- 《全国法院民商事审判工作会议纪要》（九民纪要）
  - 对赌协议效力与履行
  - 股东出资加速到期
  - 股权转让
  - 公司人格否认
  - 公司为他人提供担保
  - 金融消费者权益保护
  - 证券虚假陈述

### 公司纠纷
- 公司法司法解释系列
- 有限责任公司清算义务人责任
- 股东代表诉讼

### 担保纠纷
- 不动产担保物权
- 动产担保物权
- 非典型担保

## 实务要点

1. **民法典时间效力**：溯及适用的具体规定和衔接适用规则
2. **公司纠纷**：对赌协议、股东出资加速到期、股权转让等重点问题
3. **担保物权**：不动产和动产担保物权的区分适用
4. **金融消费者保护**：适当性义务和损失赔偿规则
5. **证券纠纷**：虚假陈述民事赔偿
