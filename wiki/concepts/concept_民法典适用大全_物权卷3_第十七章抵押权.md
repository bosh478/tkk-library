# 民法典第十七章【抵押权】综合

## 章节目录

本章共 31 条（Articles 394-424），分两节：第一节一般抵押权（26 条，394-419）+ 第二节最高额抵押权（5 条，420-424）。抵押权是不转移财产占有的担保物权，是物权编担保物权分编中条文最多、内容最丰富的章节。

| 节 | 法条范围 | 主题 |
|----|---------|------|
| 第一节 一般抵押权 | 394-419 | 抵押权基本制度 |
| 第二节 最高额抵押权 | 420-424 | 预定期内连续发生债权的特殊抵押 |

## 一、第一节 一般抵押权

### （一）抵押权的概念与特征（第394条）

#### 法条原文

> 第三百九十四条　为担保债务的履行，债务人或者第三人不转移财产的占有，将该财产抵押给债权人的，债务人不履行到期债务或者发生当事人约定的实现抵押权的情形，债权人有权就该财产优先受偿。
>
> 前款规定的债务人或者第三人为抵押人，债权人为抵押权人，提供担保的财产为抵押财产。

#### 抵押权的三大特点

| 特点 | 内容 |
|------|------|
| **抵押财产的广泛性** | 涵盖不动产、不动产权利、动产；现有+将有的集合财产 |
| **公示方法的唯一性** | 登记是抵押权物权变动的**唯一**公示方法 |
| **物权变动模式的二元性** | 不动产/不动产权利：登记**生效要件**；动产：登记**对抗要件** |

#### 抵押权的性质

| 性质 | 内容 |
|------|------|
| **从属性** | 成立上、转移上、消灭上均从属于主债权 |
| **特定性** | 抵押财产必须特定；浮动抵押在确定时特定化 |
| **不可分性** | 债权部分变化或抵押财产部分变化的，不影响抵押权整体性 |
| **物上代位性** | 抵押财产毁损灭失的，抵押权存在于代位物 |

**⚠️ 从属性从宽解释**：附生效条件未成就的未生效债权可设立抵押权；最高额抵押设立时被担保债权尚未产生的不违反从属性。

### （二）抵押财产的范围（第395-399条）

#### 可以抵押的财产（第395条）

| 类别 | 具体财产 |
|------|---------|
| **不动产** | 建筑物、其他土地附着物 |
| **不动产权利** | 建设用地使用权、海域使用权；通过招拍挂取得并经依法登记的土地承包经营权 |
| **动产** | 生产设备、原材料、半成品、产品；交通运输工具；正在建造的船舶、航空器 |
| **集合动产/将来财产** | 浮动抵押（第396条） |
| **兜底** | 法律、行政法规未禁止抵押的其他财产 |

#### 建筑物与建设用地使用权"房随地走、地随房走"原则（第397条）

| 情形 | 规则 |
|------|------|
| 以建筑物抵押 | 该建筑物占用范围内的建设用地使用权**一并抵押** |
| 以建设用地使用权抵押 | 该土地上的建筑物**一并抵押** |
| 例外 | 当事人另有约定的，从其约定（但不得违反法律强制性规定） |

**乡镇、村企业的建设用地使用权不得单独抵押**（第398条）；但以厂房等建筑物抵押的，其占用范围内的建设用地使用权一并抵押。

#### 禁止抵押的财产（第399条）

| 禁止类型 | 说明 |
|---------|------|
| 土地所有权 | 国有和集体所有土地所有权均不得抵押 |
| 集体土地使用权 | 宅基地、自留地、自留山等集体所有土地的使用权（**法律另有规定可以抵押的除外**） |
| 公益设施 | 学校、幼儿园、医院等以公益为目的的事业单位、社会团体的教育设施、医疗卫生设施和其他公益设施 |
| 所有权/使用权不明或有争议的财产 | — |
| 依法被查封、扣押、监管的财产 | — |
| 兜底条款 | 法律、行政法规规定不得抵押的其他财产 |

### （三）浮动抵押（第396条）

#### 法条原文

> 第三百九十六条　企业、个体工商户、农业生产经营者可以将现有的以及将有的生产设备、原材料、半成品、产品抵押，债务人不履行到期债务或者发生当事人约定的实现抵押物权的情形，债权人有权就抵押财产确定时的动产优先受偿。

#### 浮动抵押的特点

| 特点 | 内容 |
|------|------|
| **主体特定** | 仅限企业、个体工商户、农业生产经营者 |
| **客体浮动** | 现有的以及将有的生产设备、原材料、半成品、产品 |
| **公示对抗** | 抵押登记为对抗要件（不登记不得对抗善意第三人） |
| **抵押期间可处分** | 抵押人在抵押期间对抵押财产仍有处分权 |
| **抵押财产确定时优先受偿** | 抵押权人就确定时的动产优先受偿 |

#### 浮动抵押财产的确定（第411条）

下列情形之一发生时，浮动抵押财产确定：
1. 债务履行期届满，债权未实现
2. 抵押人被宣告破产或者解散
3. 当事人约定的实现抵押权的情形
4. 严重影响债权实现的其他情形

#### 浮动抵押 vs 流动质押

| 区别 | 浮动抵押 | 流动质押（动态质押） |
|------|---------|--------------------|
| 客体确定性 | 确定前抵押财产范围**不确定** | 抵押财产价值/数量**恒定** |
| 法律关系 | 抵押人+抵押权人两方 | 出质人+质权人+监管人三方 |
| 法律性质 | 动产抵押 | 动产质押 |
| 公示方法 | **登记**（登记对抗主义） | **交付**（实际占有+第三方监管） |

① 来源：浮动抵押与流动质押（L1614-L1720），《民法典适用大全》物权卷3 2023年 386-462.md

### （四）抵押合同与流押禁止（第400-401条）

#### 抵押合同（第400条）

- **形式**：应采用**书面形式**（第400条）
- **内容**：被担保债权的种类、数额；债务人履行债务的期限；抵押财产的名称、数量、质量、状况、所在地、所有权归属或使用权归属；担保范围

#### 流押禁止（第401条）

> 第四百零一条　抵押权人在债务履行期限届满前，不得与抵押人约定债务人不履行到期债务时抵押财产归债权人所有。

**流押禁止的规则**：
- **禁止期内约定**：债务履行期届满前约定"不履行则归债权人" → **无效**
- **届满后折价**：债务履行期届满后可以协议以抵押财产折价
- **效力独立的转换**：流押条款无效，**不影响**抵押合同其他条款的效力
- **与流质禁止对比**：第401条（流押）+ 第428条（流质）共同构成流押流质禁止规则

### （五）抵押设立与公示（第402-405条）

#### 不动产抵押登记（第402条）

> 第四百零二条　以不动产抵押的，应当办理抵押登记。抵押权自登记时设立。

**登记生效主义**：不动产抵押**未经登记**，抵押权**不设立**（但抵押合同仍然有效）。

#### 动产抵押的效力（第403条）

> 第四百零三条　以动产抵押的，抵押权自抵押合同生效时设立；未经登记，不得对抗善意第三人。

**登记对抗主义**：动产抵押**合同生效时**抵押权即设立，但**未经登记**不能对抗善意第三人。

#### 动产抵押权对抗效力的限制（第404条）

> 第四百零四条　以动产抵押的，不得对抗正常经营活动中已支付合理价款并取得抵押财产的买受人。

**正常经营活动买受人规则**：即使动产抵押已经登记，也不得对抗在**正常经营活动中**已支付合理价款并取得抵押财产的买受人（《担保制度解释》第56条明确"正常经营活动"标准）。

#### 抵押权与租赁权的关系（第405条）

> 第四百零五条　抵押权设立前抵押财产已经出租并转移占有的，原租赁关系不受该抵押权的影响。

**先租后抵 vs 先抵后租**：
- **先租后抵**（租赁在先）：原租赁关系**不受**抵押权影响（租赁>抵押，买受人取得时租赁合同继续）
- **先抵后租**：抵押权设立后出租的，租赁关系**不得对抗**已登记的抵押权（抵押>租赁）

### （六）抵押权的效力（第406-413条）

#### 抵押财产的转让（第406条）

**⚠️ 重大变化**（与原《物权法》第191条对比）：

| 旧规则（《物权法》191） | 新规则（《民法典》406） |
|------------------------|----------------------|
| 抵押期间转让抵押财产**需经抵押权人同意** | 抵押期间抵押人**可以转让**抵押财产，抵押权不受影响 |
| 未经同意转让的，转让无效 | 抵押人转让抵押财产的，**应当及时通知抵押权人** |
| — | 抵押权人能够证明转让可能损害抵押权的，可请求抵押人将转让所得价款**提前清偿**或**提存** |

**意义**：第406条回归了抵押权的**追及效力**——抵押权随物走，抵押财产受让人取得的财产仍负担抵押权。

#### 抵押权的从属性（第407条）

> 第四百零七条　抵押权不得与债权分离而单独转让或者作为其他债权的担保。债权转让的，担保该债权的抵押权一并转让，但是法律另有规定或者当事人另有约定的除外。

#### 抵押权的保护（第408条）

抵押人的行为**足以使抵押财产价值减少**的，抵押权人有权：
1. 请求抵押人**停止**该行为
2. 请求抵押人**恢复抵押财产的价值**
3. 要求抵押人**提供与减少的价值相应的担保**
4. 抵押财产价值减少的，抵押权人有权请求**提前清偿**债务

#### 抵押权及其顺位的处分（第409条）

抵押权人可以：
- **放弃抵押权**：单方民事法律行为，明示方式
- **放弃抵押权顺位**：可能损害其他抵押权人的利益，需注意
- **协议变更抵押权顺位及被担保债权数额**：未经其他抵押权人**书面同意**的，不得对其他抵押权人产生不利影响

#### 抵押权的实现（第410条）

> 第四百一十条　债务人不履行到期债务或者发生当事人约定的实现抵押权的情形，抵押权人可以与抵押人协议以抵押财产折价或者以拍卖、变卖该抵押财产所得的价款优先受偿……

**实现方式**：
1. **协议折价**：抵押权人与抵押人协议以抵押财产折价
2. **拍卖**：依《民事诉讼法》规定的拍卖程序
3. **变卖**：以一般买卖方式变卖

**协议损害其他债权人利益**：其他债权人可以请求**撤销**该协议（《民法典》第538-539条债权人撤销权）。

#### 抵押权对孳息的效力（第412条）

**抵押财产被扣押**之日起，抵押权人有权收取抵押财产的天然孳息和法定孳息（但需通知清偿法定孳息义务人）。孳息优先用于冲抵收取孳息的费用。

#### 抵押财产变价后的处理（第413条）

- 拍卖、变卖所得价款 **超过债权数额** 部分 → 归**抵押人**所有
- 拍卖、变卖所得价款 **不足债权数额** 部分 → 由**债务人**清偿

### （七）数个抵押权的清偿顺序（第414-418条）

#### 数个抵押权的清偿顺序（第414条）

| 情形 | 顺序规则 |
|------|---------|
| 抵押权均已登记 | 按**登记时间**先后 |
| 抵押权均未登记 | 按**债权比例**清偿 |
| 已登记 vs 未登记 | **已登记的优先于未登记的** |

#### 抵押权与质权的清偿顺序（第415条）

> 第四百一十五条　同一财产既设立抵押权又设立质权的，拍卖、变卖该财产所得的价款按照登记、交付的时间先后确定清偿顺序。

**规则**：先登记/先交付的优先于后登记/后交付的。

#### 购买价款抵押担保的超级优先权（第416条）

> 第四百一十六条　动产抵押担保的主债权是抵押物的价款的，该抵押权人优先于其他担保物权人受偿。

**超级优先权规则**：
- **构成要件**：
  1. 抵押物为动产
  2. 担保的主债权是抵押物的**价款**
  3. 抵押权在**标的物交付后10日内**办理登记
- **效力**：购买价款抵押权人**优先于**其他担保物权人受偿（包括先设立的担保物权）
- **意义**：保护动产融资交易中出卖人的利益，类似美国 UCC 的 PMSI（Purchase Money Security Interest）

#### 抵押权对新增建筑物的效力（第417条）

- 建设用地使用权抵押后，该土地上**新增的建筑物不属于抵押财产**
- 抵押权实现时，可以**一并处分**新增建筑物，但**抵押权人无优先受偿权**（就新增建筑物部分）

#### 集体所有土地使用权抵押权的实现效果（第418条）

实现抵押权后**不得改变土地所有权的性质和用途**。

### （八）抵押权存续期间（第419条）

> 第四百一十九条　抵押权人应当在主债权诉讼时效期间行使抵押权；未行使的，人民法院不予保护。

**主债权诉讼时效届满的法律后果**（详见第十六章综合页 + 《担保制度解释》第44条）：
- 抵押权**不消灭**
- 抵押权人主张行使抵押权的，**人民法院不予支持**
- 抵押人以诉讼时效届满为由主张不承担担保责任的，**应予支持**

## 二、第二节 最高额抵押权（第420-424条）

### 法条原文

> 第四百二十条　为担保债务的履行，债务人或者第三人对一定期间内将要连续发生的债权提供担保财产的，债务人不履行到期债务或者发生当事人约定的实现抵押权的情形，抵押权人有权在最高债权额限度内就该担保财产优先受偿。

### 最高额抵押权的特殊性

| 特征 | 内容 |
|------|------|
| **预决债权额** | 在"最高债权额限度内"优先受偿 |
| **担保未来债权** | 担保的是一定期间内将要**连续发生**的债权 |
| **不违反从属性** | 设立时被担保债权尚未存在的，不违反从属性 |
| **基础关系** | 借款合同 + 特定连续交易关系（《担保制度解释》第1条） |

### 债权转让（第421条）

> 第四百二十一条　最高额抵押担保的债权确定前，部分债权转让的，最高额抵押权**不得转让**，但是当事人另有约定的除外。

**⚠️ 关键规则**：最高额抵押权在**债权确定前**原则上**不随部分债权转让而转让**——因为最高额抵押权担保的是"一定期间内连续发生的债权"，其本身具有独立性，不从属于任一具体债权。

### 合同内容变更（第422条）

最高额抵押担保的债权确定前，抵押权人与抵押人可以协议**变更债权确定的期间、债权范围、最高债权额**，但不得对其他抵押权人产生不利影响。

### 债权确定（第423条）

下列情形之一的，**最高额抵押权所担保的债权确定**：
1. 约定的债权确定期间届满
2. **新的债权不可能**再发生
3. 抵押财产被**查封、扣押**
4. 债务人、抵押人被**宣告破产**或者解散
5. **法律规定**债权确定的其他情形

### 法律适用（第424条）

最高额抵押权除适用本节特别规定外，**适用一般抵押权的规定**。

## 三、抵押权 vs 质权对比

| 维度 | 抵押权 | 质权 |
|------|--------|------|
| 占有状态 | **不转移**占有 | **转移**占有 |
| 公示方法 | 登记（生效/对抗） | 交付（动产）/ 登记（权利） |
| 标的 | 不动产+动产+不动产权利 | 动产+权利 |

| 实现方式 | 折价/拍卖/变卖 | 同左 |

## ❓ 实务问答精选

> **问**：抵押财产被转让后，抵押权是否受影响？
>
> **答**：**不影响**。第406条改变了原《物权法》第191条规则，确立"抵押期间抵押人可转让抵押财产，抵押权不受影响"原则。但抵押人**应当及时通知**抵押权人；抵押权人能够证明转让可能损害抵押权的，可请求抵押人将转让所得价款提前清偿或提存。

> **问**：动产抵押未登记，能否对抗正常经营活动中的买受人？
>
> **答**：**不能**。第404条规定，以动产抵押的，**不得对抗正常经营活动中已支付合理价款并取得抵押财产的买受人**。即使已经登记，正常经营活动买受人规则优先保护买受人利益（《担保制度解释》第56条）。

> **问**：购买价款抵押权为什么是"超级优先权"？
>
> **答**：第416条赋予购买价款抵押担保以"超级优先权"——在动产抵押担保的主债权是抵押物价款的，**该抵押权人优先于其他担保物权人受偿**（包括先设立的担保物权）。这是为了保护动产融资交易中的出卖人利益，平衡融资安全与交易便利。**适用条件**：在标的物交付后**10日内**办理登记。

> **问**：最高额抵押权转让的特殊规则是什么？
>
> **答**：最高额抵押权担保的是"一定期间内将要连续发生的债权"，**债权确定前**部分债权转让的，**最高额抵押权不得转让**（第421条）。这是最高额抵押权与一般抵押权最重要的区别之一。

> **问**：主债权诉讼时效届满，抵押权消灭吗？
>
> **答**：**不消灭，但不予保护**。详见第十六章综合页第393条释义。主流立场（依《担保制度解释》第44条）：主债权诉讼时效届满后，抵押权人主张行使抵押权的，人民法院不予支持。

> **问**：浮动抵押与流动质押如何区分？
>
> **答**：详见本综合页"浮动抵押 vs 流动质押"对比表。**核心区别**：
> - 浮动抵押：客体在确定前**不确定**；仅抵押人+抵押权人两方；登记公示
> - 流动质押：客体价值/数量**恒定**；出质人+质权人+监管人三方；交付公示

## 典型案例

### 案例 1：正常经营活动买受人保护案

**某农业发展银行吉林市分行营业部诉京顺公司抵押权纠纷案**

**裁判要旨**：动产抵押担保的主债权是抵押物价款的，即使已经登记，也不得对抗在正常经营活动中已支付合理价款并取得抵押财产的买受人。粮食购销企业的玉米销售属于正常经营活动。

**意义**：第404条"正常经营活动买受人规则"的典型适用，明确粮食购销企业的玉米销售属于正常经营活动。

① 来源：物权卷3 L2718-L2730

### 案例 2：抵押权与租赁权冲突案

抵押权设立前抵押财产已经出租并转移占有的，原租赁关系不受抵押权影响（第405条）。先租后抵，买受人取得的财产上仍存在原租赁合同，租赁>抵押。

① 来源：物权卷3 L2730-L2760

### 案例 3：抵押物转让与抵押权追及案

抵押人转让抵押财产的，抵押权不受影响；抵押权人可以就转让后的抵押财产继续行使抵押权。但能够证明转让可能损害抵押权的，可请求提前清偿或提存。

① 来源：物权卷3 L2588-L2600
