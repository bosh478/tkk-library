# 监察法与刑事追诉的衔接(《监察法》第 4 章 + 《刑诉法》第 3 编 · L3)

> 本页定位:监察法与刑事追诉衔接 L3 概念页。**监察体制改革(2018)**后形成的监察调查 → 刑事追诉程序衔接机制,涉及《监察法》、《刑事诉讼法》、《政务处分法》、《刑法》多法源的协调;主要适用于第 8 章贪污贿赂罪 + 第 9 章渎职罪的公职人员犯罪。

## 一、法条原文(条文要点)

《监察法》第 4 章 监察权限:
- 第 18 条:监察机关收集证据规则
- 第 19-22 条:谈话、讯问、询问、留置等调查措施
- 第 31-34 条:从宽处罚建议
- 第 45 条:监察机关对涉嫌职务犯罪移送检察机关审查起诉

《刑事诉讼法》相关条款:
- 第 3 编第 2 章 提起公诉
- 第 170 条:监察机关移送案件,人民检察院作出不起诉决定应经上一级检察院批准
- 第 171 条:不起诉案件的处置
- 第 170-176 条:认罪认罚从宽制度

《政务处分法》(2020):政务处分 vs 刑事处罚的双轨制

## 二、段级释解

### 1. 概念界定

监察法与刑事追诉的衔接 = 监察机关对公职人员涉嫌职务违法 / 职务犯罪的调查,与检察机关对刑事犯罪的审查起诉、法院的刑事审判之间的程序衔接 + 证据转化 + 处罚协调机制。

监察体制改革(2018)的核心变化:
- 监察委员会整合原行政监察 + 预防腐败 + 检察机关反贪反渎职能
- 形成集中统一、权威高效的反腐败体制
- 政务处分取代原行政监察的「行政处分」

### 2. 四构成要件

(1) 主体要件:监察对象(《监察法》第 3 条 + 第 15 条):
- 公务员 + 参公管理人员
- 法律、法规授权或者依法受委托管理公共事务的组织中从事公务的人员
- 国有企业管理人员
- 公办教育、科研、文化、医疗卫生、体育等单位中从事管理的人员
- 基层群众性自治组织中从事管理的人员
- 其他依法履行公职的人员

(2) 行为要件:
- 职务违法:违反《政务处分法》等行政法规(政务处分处理)
- 职务犯罪:涉嫌《刑法》分则第 8 章贪污贿赂罪 + 第 9 章渎职罪(刑事追诉)

(3) 程序要件:
- 监察调查(《监察法》第 4 章)
- 移送审查起诉(《监察法》第 45 条)
- 审查起诉(《刑诉法》第 170-176 条)
- 审判(《刑诉法》第 3 编第 3 章)

(4) 证据要件:
- 监察证据与刑事证据的转化(《监察法》第 33 条)
- 监察机关收集的物证、书证、证人证言、被调查人供述等,经审查符合法定要求的,可作为刑事证据使用
- 非法证据排除规则仍适用

### 3. 程序衔接流程

完整流程:
1. 问题线索(信访举报 / 巡视巡察 / 审计移送 / 上级交办)
2. 监察立案(《监察法》第 39 条)
3. 监察调查(《监察法》第 4 章)
4. 调查终结:职务违法 → 政务处分;职务犯罪 → 移送检察机关审查起诉
5. 检察院审查起诉(《刑诉法》第 170-176 条)
6. 法院审判:定罪免刑 + 政务处分,或判处刑罚

### 4. 留置 vs 逮捕的衔接

留置(《监察法》第 22 条):
- 适用对象:涉嫌严重职务违法 / 职务犯罪的监察对象
- 决定机关:设区的市级以上监察机关
- 期限:不超过 3 个月,特殊情况下可延长 1 次,延长期限不得超过 3 个月(最长 6 个月)

逮捕(《刑诉法》第 81 条):
- 适用对象:可能判处有期徒刑以上刑罚的犯罪嫌疑人
- 决定机关:检察院批准 / 法院决定
- 期限:2 个月(可延长至 7 个月)

衔接:
- 监察机关对被调查人采取留置措施的,案件移送起诉前,留置自动解除
- 检察机关审查起诉时重新决定是否逮捕 / 取保候审 / 监视居住

## 三、实务问答(FAQ)

Q1:监察机关可以「留置」所有公职人员吗?
不是。《监察法》第 22 条限制为涉嫌严重职务违法 / 职务犯罪的监察对象,一般职务违法仅给予政务处分。

Q2:监察证据在刑事审判中的证据效力如何?
按《监察法》第 33 条 + 《刑诉法》第 56-60 条:
- 物证、书证、证人证言等客观证据:一般可转化使用
- 被调查人供述 / 辩解:经审查合法取得的,可作为证据
- 非法证据排除规则仍适用

Q3:同一行为是否可以同时给予政务处分和刑事处罚?
可以。双轨制:政务处分(《政务处分法》)不等同于刑事处罚,同一行为违反行政法规 + 刑法时,既可政务处分,又可刑事处罚。

Q4:监察机关调查终结后,检察院能否作出不起诉决定?
可以但有限制:《刑诉法》第 170 条要求监察机关移送案件的不起诉决定应经上一级检察院批准,防止地方检察院与监察机关协调轻纵职务犯罪。

Q5:监察法中的「从宽处罚建议」与刑事诉讼法的「认罪认罚从宽」是何关系?
关联但有区别:
- 监察法从宽建议:监察调查阶段的主动认罪认罚 + 重大立功
- 刑事诉讼法认罪认罚从宽:审查起诉 + 审判阶段的认罪认罚从宽制度
- 关系:监察阶段的从宽建议影响后续检察 + 审判的从宽幅度

Q6:巨额财产来源不明罪(第 395 条)与监察调查的衔接?
直接关联:监察机关调查公职人员巨额财产来源不明时,可适用第 395 条,举证责任由被告人说明来源。

Q7:监察机关是否可以调查「军事人员」?
有限管辖:军队监察机构适用《中国人民解放军纪律条令》+ 军队监察规定;地方监察机关不直接管辖军事人员。

Q8:监察法实施前(2018 年前)已立案的职务犯罪案件如何处理?
程序转化:2018 年 3 月前已由检察机关立案侦查的职务犯罪案件,由检察机关继续办理;2018 年 3 月后新发现的职务犯罪线索,由监察机关调查。
