# 民法典适用大全·侵权责任卷（一）

## 内容定位

本卷是侵权责任卷第一册，围绕《民法典》第1164条（2021-01-01 施行 / 2021-01-01 最新修正）至第1207条，涵盖侵权责任编一般规定（归责原则、共同侵权、减责免责事由）、损害赔偿、责任主体的特殊规定（监护人责任、用人单位责任、网络侵权、安全保障义务等）和产品责任。侵权责任编是民法典保护民事权益的最后一道防线。

## 章节结构总览

### 第一章 一般规定（第1164-1178条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1164条 | 调整范围 | 因侵害民事权益产生的民事关系 |
| 第1165条 | 过错责任原则 | 行为人因过错侵害他人民事权益造成损害的，应承担侵权责任；过错推定 |
| 第1166条 | 无过错责任 | 行为人造成他人民事权益损害，不论有无过错，法律规定应承担侵权责任的，从其规定 |
| 第1167条 | 危及人身财产安全的责任 | 侵权行为危及他人人身、财产安全的，被侵权人有权请求停止侵害、排除妨碍、消除危险 |
| 第1168条 | 共同侵权 | 二人以上共同实施侵权行为造成他人损害的，承担连带责任 |
| 第1169条 | 教唆帮助侵权 | 教唆、帮助他人实施侵权行为的，与行为人承担连带责任 |
| 第1170条 | 共同危险行为 | 二人以上实施危及他人人身、财产安全的行为，其中一人或数人的行为造成他人损害，不能确定具体侵权人的，行为人承担连带责任 |
| 第1171条 | 原因叠加的连带责任 | 二人以上分别实施侵权行为造成同一损害，每个人的侵权行为都足以造成全部损害的，行为人承担连带责任 |
| 第1172条 | 分别侵权的按份责任 | 二人以上分别实施侵权行为造成同一损害，能够确定责任大小的各自承担；难以确定的平均承担 |
| 第1173条 | 过失相抵 | 被侵权人对同一损害的发生或扩大有过错的，可减轻侵权人的责任 |
| 第1174条 | 受害人故意 | 损害是因受害人故意造成的，行为人不承担责任 |
| 第1175条 | 第三人过错 | 损害是因第三人造成的，第三人应承担侵权责任 |
| 第1176条 | 自甘冒险 | **新增**：自愿参加具有一定风险的文体活动，因其他参加者的行为受到损害的，受害人不得请求其他参加者承担侵权责任（故意或重大过失除外） |
| 第1177条 | 自助行为 | **新增**：合法权益受到侵害，情况紧迫且不能及时获得国家机关保护的，可在必要范围内采取扣留侵权人财物等合理措施 |
| 第1178条 | 减责免责事由的法律衔接 | 本法和其他法律对不承担责任或减轻责任的情形另有规定的，从其规定 |

### 第二章 损害赔偿（第1179-1187条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1179条 | 人身损害赔偿范围 | 医疗费、护理费、交通费、营养费、住院伙食补助费等合理费用，以及因误工减少的收入；造成残疾的还包括辅助器具费和残疾赔偿金；造成死亡的还包括丧葬费和死亡赔偿金 |
| 第1180条 | 同一侵权多人死亡 | 因同一侵权行为造成多人死亡的，可以以相同数额确定死亡赔偿金 |
| 第1181条 | 其他请求权主体 | 被侵权人死亡的，其近亲属有权请求侵权人承担侵权责任 |
| 第1182条 | 侵害人身权益造成财产损失 | 侵害他人人身权益造成财产损失的，按被侵权人因此受到的损失或侵权人因此获得的利益赔偿 |
| 第1183条 | 精神损害赔偿 | 侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿 |
| 第1184条 | 侵害财产的赔偿 | 侵害他人财产的，财产损失按损失发生时的市场价格或其他合理方式计算 |
| 第1185条 | 故意侵害知识产权的惩罚性赔偿 | 故意侵害他人知识产权，情节严重的，被侵权人有权请求相应的惩罚性赔偿 |
| 第1186条 | 公平责任 | 受害人和行为人对损害的发生都没有过错的，依照法律的规定由双方分担损失 |
| 第1187 | 损害发生后费用支付方式 | 损害发生后可协商支付方式；协商不一致的应一次性支付 |

### 第三章 责任主体的特殊规定（第1188-1201条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1188条 | 监护人责任 | 无民事行为能力人、限制民事行为能力人造成他人损害的，由监护人承担侵权责任 |
| 第1189条 | 委托监护时的责任 | 监护人将监护职责委托给他人的，监护人应承担侵权责任；受托人有过错的承担相应责任 |
| 第1190条 | 暂时丧失意识 | 完全民事行为能力人暂时丧失意识造成他人损害的，有过错的承担侵权责任；没有过错的根据经济状况适当补偿 |
| 第1191条 | 用人单位责任 | 用人单位的工作人员因执行工作任务造成他人损害的，由用人单位承担侵权责任 |
| 第1192条 | 个人劳务关系责任 | 个人之间形成劳务关系，提供劳务一方因劳务造成他人损害的，由接受劳务一方承担侵权责任 |
| 第1193条 | 承揽人责任 | 承揽人在完成工作过程中造成第三人或自身损害的，定作人不承担侵权责任（定作人有过错的除外） |
| 第1194条 | 网络侵权责任 | 网络用户、网络服务提供者利用网络侵害他人民事权益的，应承担侵权责任 |
| 第1195条 | 通知删除规则 | 权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施 |
| 第1196条 | 反通知规则 | 网络用户接到转送的通知后可提交不存在侵权行为的声明 |
| 第1197条 | 网络服务提供者的连带责任 | 网络服务提供者知道或应当知道网络用户利用其网络服务侵害他人民事权益未采取必要措施的，承担连带责任 |
| 第1198条 | 安全保障义务 | 经营场所、公共场所的经营者、管理者或群众性活动的组织者未尽到安全保障义务造成他人损害的，应承担侵权责任 |
| 第1199条 | 教育机构责任（无民事行为能力人） | 无民事行为能力人在幼儿园、学校等学习生活期间受到人身损害的，教育机构应承担侵权责任（能证明尽到教育管理职责的除外） |
| 第1200条 | 教育机构责任（限制民事行为能力人） | 限制民事行为能力人在学校等学习生活期间受到人身损害的，教育机构未尽到教育管理职责的应承担侵权责任 |
| 第1201条 | 第三人侵害时教育机构的补充责任 | 无民事行为能力人或限制民事行为能力人受到教育机构以外的第三人人身损害的，由第三人承担侵权责任；教育机构未尽到管理职责的承担补充责任 |

### 第四章 产品责任（第1202-1207条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第1202条 | 生产者责任 | 因产品存在缺陷造成他人损害的，生产者应承担侵权责任 |
| 第1203条 | 生产者与销售者的责任 | 因产品存在缺陷造成损害的，被侵权人可向生产者或销售者请求赔偿 |
| 第1204条 | 第三人过错 | 因运输者、仓储者等第三人的过错使产品存在缺陷造成他人损害的，产品的生产者、销售者赔偿后有权向第三人追偿 |
| 第1205条 | 缺陷产品排除妨碍、消除危险 | 因产品缺陷危及他人人身、财产安全的，被侵权人有权请求生产者、销售者承担停止侵害、排除妨碍、消除危险等侵权责任 |
| 第1206条 | 产品召回 | 产品投入流通后发现存在缺陷的，生产者、销售者应及时采取停止销售、警示、召回等补救措施 |
| 第1207条 | 惩罚性赔偿 | **新增**：明知产品存在缺陷仍然生产、销售或未采取有效补救措施造成他人死亡或健康严重损害的，被侵权人有权请求相应的惩罚性赔偿 |

## 核心制度解读

### 一、归责原则体系（第1165-1166条）

**过错责任原则**（第1165条）：一般侵权适用过错责任，被侵权人需证明行为人有过错。

**过错推定**：法律规定推定行为人有过错的，行为人不能证明自己没有过错的应承担侵权责任。

**无过错责任**（第1166条）：法律规定不论有无过错均应承担责任的，从其规定（如产品责任、高度危险责任等）。

### 二、自甘冒险制度（第1176条）

**制度创新**：《民法典》新增制度。自愿参加具有一定风险的文体活动，因其他参加者的行为受到损害的，受害人不得请求其他参加者承担侵权责任（故意或重大过失除外）。

**适用范围**：具有一定风险的文体活动（如足球、篮球、拳击等）。

### 三、自助行为制度（第1177条）

**制度创新**：《民法典》新增制度。合法权益受到侵害，情况紧迫且不能及时获得国家机关保护的，可在必要范围内采取合理措施。

**限制条件**：应立即请求国家机关处理；措施不当造成不应有的损害的应承担侵权责任。

### 四、网络侵权责任（第1194-1197条）

**通知删除规则**（第1195条）：权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施。

**连带责任**（第1197条）：网络服务提供者知道或应当知道网络用户利用其网络服务侵害他人民事权益未采取必要措施的，承担连带责任。

### 五、产品责任惩罚性赔偿（第1207条）

**适用条件**：明知产品存在缺陷仍然生产、销售或未采取有效补救措施；造成他人死亡或健康严重损害。

**制度意义**：加大对恶意侵权行为的惩罚力度，保护消费者权益。

## ❓ 常见问题

> 问：什么是自甘冒险？
> 答：自愿参加具有一定风险的文体活动，因其他参加者的行为受到损害的，受害人不得请求其他参加者承担侵权责任。但其他参加者对损害的发生有故意或者重大过失的除外（第1176条）。

> 问：网络侵权如何维权？
> 答：权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施。网络服务提供者接到通知后未及时采取必要措施的，对损害的扩大部分与侵权人承担连带责任（第1195条）。

> 问：产品责任中谁可以作为被告？
> 答：被侵权人可以向产品的生产者请求赔偿，也可以向产品的销售者请求赔偿（第1203条）。

> 问：安全保障义务的适用范围？
> 答：宾馆、商场、银行、车站、机场、体育场馆、娱乐场所等经营场所、公共场所的经营者、管理者或群众性活动的组织者，未尽到安全保障义务造成他人损害的应承担侵权责任（第1198条）。
