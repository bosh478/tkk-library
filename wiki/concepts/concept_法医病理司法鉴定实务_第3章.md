# 第三章 死亡的法医学鉴定理论



随着人类认识和科技水平的提高，对生命和死亡的认识亦不断深入。因此，不同的生死观反映人们的不同认识水平和思维理念。目前，从生物医学和法医学角度看，生与死两者既对立又统一，人的生命中始终伴随着死亡的发生，如生理状态下细胞的程序性死亡。



死亡（death）指一切生命特征的丧失且永久性不可逆转地终止，最终变成无生命特征的生物体，是生命个体自然进化的必然结果。死亡原因（cause of death）是指导致死亡发生的疾病、暴力或衰老等因素。



死亡原因鉴定是法医病理学的主要研究内容之一，常常关系着当事人的罪与非罪问题。正确判定死亡原因、方式，熟练掌握死因鉴定技术、死因分析理论在某些复杂案件的检案中显得十分重要。死亡机制分析对于说明死亡原因具有清晰的因果关系，也是体现鉴定人掌握知识的广度、深度及逻辑分析的能力之一。本章将重点介绍生命与死亡的基本理论、死亡的分类及诊断标准、脑死亡、死亡的发生过程与假死、死因分析等内容。

哲学领域中，研究与死亡相关的行为、思想、情感以及现象的学科称为死亡学（thanatology），它探讨与死亡相关的现象及行为。



目前，世界各国仍普遍沿用《布莱克法律词典》的死亡定义：“死亡（death）是指生物个体的生命和存在的终止，表现为循环、呼吸、脉搏等生命功能的丧失。”死亡概念反映出人们对生命本质的科学认知及其哲学概念。随着科学技术进步，特别是临床救治的对有死亡征象患者的复苏、器官移植和人工器官、人工生殖，以及生物医学工程等医学技术的进展，引发了人类生死观，乃至世界观的社会学、哲学、伦理学关于生命问题的反思和争论。



为保护人类生命健康权，防止危害人们生命行为或事件的发生，国内外法医学者认为，有必要发展一门研究死亡案件相关法律问题，既要依据自然科学的生物医学理论知识和技术手段，又要遵从人文科学的社会法学的法律思维和证据规范的法医死亡学（forensic thanatology），它是根据法医学的观点，应用医学、法学、哲学、精神心理学及伦理学的理论与技术，科学地研究、确定死亡及有关理论的一门学科。主要研究内容包括死亡标志、死亡原因、死亡机制、死因分析、死亡过程、死亡性质、死亡方式、死亡证明，以及死亡概念和安乐死的相关立法等理论问题。这些研究内容应成为法医病理学死亡鉴定问题的重要知识体系。因此，要对死亡进行科学准确的分析和鉴定，必须具备一定的医学、法医学和法学知识，才能加强对法医死亡学的认识和研究。

维持人体的生命有赖于呼吸及心跳。呼吸运动将氧吸入肺并排出二氧化碳；心跳将氧输送至全身细胞并将细胞代谢产生的二氧化碳带到肺排出体外。早在战国时期，《黄帝内经》中《素问·玉版论要篇》里便提到“脉短，气绝，死”。人个体死亡的传统概念是呼吸和心跳的停止，并按照呼吸和心跳停止的先后顺序而分为呼吸性死亡和心脏性死亡。由于现代科学技术的发展、临床抢救技术的有效运用、器官移植和人工器官技术的进展，脑死亡（brain death）的概念开始冲击着传统概念，并日益受到重视。

呼吸性死亡（respiratory death）又称肺死亡（pulmonary death），是指源于呼吸系统，尤其是肺的疾病或损伤而致呼吸功能严重障碍或衰竭所引起的死亡。人体为维持其生命活动正常进行，需要由呼吸系统从外界吸入氧，并将体内代谢所产生的二氧化碳排出体外，这一过程的实现需肺和心血管系统功能的协调与配合。一旦功能发生失衡，就会造成一系列危害健康乃至危及生命的后果，甚至死亡。



肺的呼吸功能主要是保证肺部血液和外界大气间进行有效的气体交换，使血液气体分压保持在正常范围以内。正常人的动脉血氧分压 $\left( \mathrm { P a O } _ { 2 } \right)$ ）为 $1 0 . 4 \sim 1 3 \mathrm { \ k P a } ( 8 0 \sim 1 0 0 \mathrm { \ m m H g } )$ ），二氧化碳分压 $\mathbf { \Pi } ^ { ' } ( \mathrm { P a C O } _ { 2 } )$ ）为4．3～6．4 kPa（36～44 mmHg）。呼吸性死亡特点在于低氧血症、高碳酸血症、酸碱平衡紊乱、组织缺氧和酸中毒，由于缺氧导致血液中还原血红蛋白增多，进而致肤色青紫发绀。动脉血氧分压在3．2 kPa 以下是诊断呼吸功能障碍或呼吸性死亡的依据。



由于体内血液和组织液都有缓冲二氧化碳的碱储备，只有在代谢失常的情况下， ${ \mathrm { P a C O } } _ { 2 }$ 才缓慢上升。从正常水平上升到致死的高度需要 10～15 min，而在此前，组织缺氧已可达到致死的程度，特别是脑缺氧及由此所引起的脑功能障碍，在呼吸性死亡的发生上起着关键作用。这是因为脑组织的耗氧量居各组织耗氧量之首，对缺氧的耐受性最差。脑的重量虽仅占体重的2％，但在正常安静情况下血流量却占心输出量的 15％，加之脑组织的能量储备和无氧代谢能力极小，所需能量几乎都来自葡萄糖的有氧氧化，而脑的葡萄糖和糖原的储备又极其有限，只能维持数分钟，因此脑组织一旦缺氧就易遭受严重损害。



法医学实践中，呼吸性死亡最常见于呼吸道阻塞包括口鼻的堵塞、呼吸道内异物阻塞、外压（缢、扼、勒等）颈胸腹所致的机械性窒息，也见于肺出血、肺水肿、休克肺、大叶性肺炎、支气管肺炎、肺栓塞、气胸、胸腔积液、呼吸肌麻痹及影响呼吸功能的毒物中毒等。呼吸停止后，心脏常能短时间内跳动，继之出现心室纤维颤动，无效的室性自搏，最终心跳停止。呼吸性死亡的关键机制在于呼吸功能障碍或停止引起的脑缺氧致脑的结构或功能的严重损害。

心脏性死亡（cardiac death）是指源于心脏疾病或损伤而致其功能严重障碍或衰竭所引起的死亡。主要由原发性心脏病变、功能障碍及暴力损伤所引起，包括心外膜、心肌、心内膜、心冠状动脉系统和传导系统的各种病变和心脏的严重损伤等。



原发性心跳停止（primary cardiac arrest）是指源于心脏的有效搏动的突然停止，主要表现为心搏骤停，包括心室纤颤、心脏无收缩、室性濒死节律（agonal rhythm）等。心室纤颤在心电图上表现为频速而不规则的室性颤动波，心跳完全停止则心电活动完全消失，室性濒死节律在【善雅集】公众号资料来源于公开网络，本书的版权及著作权等部归于出版社及作者等。心电图上呈现宽大畸形、主波和 T 波相反的图形，但不伴有心肌收缩，又称为电 机械分离现象。



虽然原发性心跳停止的心电及节律表现形式不一样，但共同点是心脏不能有效地将血液搏出以供生命活动所需的能量代谢需求，且由于脑的血液供应需求量最大，特别是皮质神经元对缺氧的敏感性高，故其临床表现都是突然意识丧失和颈动脉或股动脉搏动消失。其发生机制颇为复杂，与自主神经功能变化、缺氧、二氧化碳蓄积和酸中毒、电解质紊乱、麻醉、低温、心脏本身的严重损伤或病变有关，不同因素所致的原发性心跳停止机制有所不同。



## 1． 自主神经功能变化



迷走神经过度刺激可致心脏骤停，交感神经过度刺激可致心室颤动。迷走神经兴奋可直接抑制窦房结及其他室上起搏点，同时可导致心率减慢，心缩减弱，心输出量减少和血压降低而致冠脉血流量减少，又可促进心脏骤停的发生；交感神经兴奋能增加心肌耗氧量和降低心室颤动阈值，还可使静脉收缩而增加回心血量和肺循环量，从而增大了心脏的负荷。许多疾病和损伤（包括心脏以外部位）都可引起心脏自主神经功能的变化。



## 2． 缺氧



缺氧可引起迷走神经兴奋；促进儿茶酚胺的释放而降低心室颤动阈值；心肌代谢障碍，产能不足，ATP、磷酸肌酸含量减少或消失，导致心肌收缩能量匮乏；无氧酵解增强，氧化不全和酸性代谢产物堆积引起酸中毒；心肌释放钾离子，影响心肌的自律性和传导性；直接抑制心传导系统。



## 3． 酸中毒和二氧化碳蓄积



酸中毒及二氧化碳蓄积可降低室颤阈；使心肌细胞内钾离子增多，影响钙运转；直接抑制窦房结和房室结的正常传导及心肌收缩；可促使细胞内钾离子释放，改变膜电位；抑制线粒体酶活性，导致氧化障碍和产能减少。



## 4． 电解质紊乱



电解质紊乱所引起的心跳停止不仅取决于各电解质绝对浓度的改变程度和速度，还取决于各电解质之间的比例关系以及心肌细胞内外电解质的浓度差。



（1）血钾 轻度升高（5～7 mmol ／ L）可致心肌兴奋性和传导性升高；但血钾浓度过度升高（7～9 mmol ／ L）则因静息电位过小，动作电位过低而致兴奋性和传导性降低甚至丧失而出现心脏骤停和心室纤颤。



（2）血钙 高血钙可致室性心动过速或心室颤动，甚至突然死亡。这可能是由于心肌传导减慢，不应期缩短而发生折返现象的结果。单纯的低血钙常引起早搏而很少引起心脏骤停，但低血钙合并高血压时则容易出现心室颤动和传导阻滞。



（3）血镁 血镁浓度高（2．5 ～ 5 mmol ／ L）可出现心动过缓、传导阻滞（P R 间期延长、QRS 波增宽）；血镁升高到12．5～22 mmol ／ L 时可致心跳停止在舒张期。镁对心跳的这种抑制作用可能是其直接对心的毒性作用，或抑制了心肌能量产生的结果。



## 5． 麻醉



麻醉引起的心跳停止既与麻醉剂的种类、剂量、用法有关，也与患者原来心功能状态有关。麻醉引起心跳停止的因素有：抑制呼吸、导致呼吸性酸中毒和缺氧；深度麻醉促进酸中毒的发生；直接抑制心脏活动；麻醉早期促进儿茶酚胺释放而增加心肌耗氧量，并降低室颤阈；增强迷走神经兴奋性，反射性地引起心脏抑制和冠脉血流量减少。药物麻醉对原有心脏病的患者最易引起心脏骤停。 【善雅集】 请勿商用。



## 6． 低温



低温可致心室颤动和心肌收缩无力，温度愈低，引起室颤的危险性愈大，其原因与以下因



素有关：交感 儿茶酚胺系统的兴奋性增高；抑制呼吸，导致缺氧和酸中毒；电解质紊乱和高钾血症；低温抑制窦房结起搏和刺激心室异位节律点。但低温可降低脑耗氧量而起保护性抑制作用，因此复温后停跳的心脏可以复苏。



## 7． 心脏本身严重损伤或病变



是心跳停止的最常见的直接原因，尤以急性心肌缺血或梗死最为重要。由于心肌梗死常可引起心力衰竭或同时伴有心源性休克，因此发生心跳停止的形式主要为心脏骤停和心室颤动。两者发生多在大面积心肌梗死后，但也可见于小灶性梗死。心搏骤停并非都是心脏器质性损伤或病变发展的终极，往往是功能性的；有些情况下，通过及时有效除颤或起搏，停跳的心脏可能复跳。因此，心跳停止并不表示人的个体必然死亡而不能复苏。

随着现代医学的发展，起搏器和人工呼吸机用于抢救复苏已使众多危重患者转危为安。对脑功能活动已经完全丧失的人来说，这些抢救虽然能人工地维持心、肺功能，但不能挽回其生命。撤去呼吸机就意味着死亡。因此，抢救的时限成为医学上的一个难题。医学界日益主张将全脑功能活动不可逆转的丧失作为个体死亡的指标，即称为脑死亡（brain death）。全脑功能不可逆转地丧失而脑外体循环继续存在的原发性脑死亡者，其捐献的器官用作器官移植较为适宜。由于决定人的个体生命与死亡的中枢器官是脑，而不是心或其他脑外器官，如法律承认以脑死亡作为个体死亡的标准，对推动现代医学科学发展特别是器官移植有极其重要的意义。



1968 年，美国哈佛大学医学院特设委员会对死亡的定义和标准提出了新观点，把死亡规定为不可逆转地昏迷或脑死亡，即不可逆性的全脑功能丧失。这一概念的提出使个体死亡的定义发生了重大的转变，除了传统的临床死亡诊断的心、肺标准，又增加了脑标准。目前，世界上已有多个国家承认了脑死亡的合法性，在很大程度上节约了医疗资源，并为器官移植工作的开展创造了良好条件。



脑死亡是指大脑、小脑和脑干等全脑功能不可逆转地永久性丧失。此时，不管心跳、呼吸、脑外体循环以及脊髓功能是否存在，均可宣告人的个体死亡。脑死亡分原发性脑死亡（primarybrain death）和继发性脑死亡（secondary brain death）。原发性脑死亡是由原发性脑疾病或损伤所致，其脑外器官适宜供器官移植之用；继发性脑死亡是由心、肺等脑外器官的原发性疾病或损伤致脑缺血缺氧或代谢障碍等所致。随着临床诊治水平的提高，抢救复苏以及器官移植和人工脏器的开展，继发性脑死亡可能将越来越少而原发性脑死亡将相对增多。临床医学实践中，也常见在人工心肺支持系统维持下处于脑死亡的病例。虽然此类患者在呼吸机维持下仍具有循环功能，但全脑已经处于不可逆转的死亡状态，甚至因颅内脑组织水肿、肿胀，缺少血流灌注，脑组织已经发生广泛软化，甚至部分液化等死后变化，将此种脑死亡状态下的脑称为“呼吸机脑”（respirator brain）。法医病理鉴定实践中，也常见存在呼吸机脑的案例，呼吸机脑的主要病理形态学所见属于脑组织的死后变化，且可以严重破坏或影响颅内原发性疾病或损伤的病理形态学所见。因此，应尽量通过宏观和组织病理学检查辨识原发性病变。

有些情况下，当人体受到暴力因素作用或在某些疾病状态下，可使机体呼吸、循环和脑等器官的重要生命功能活动处于极度微弱状态，用一般的体检方法查不出生命体征，从外表上看好像已经死亡，但实际上人还活着，这种情况称为假死（apparent death）。实际上，假死状态的心跳、呼吸和循环等生命机能是处于类似于“冬眠式”的维持机体最基本组织细胞代谢功能活动的状态。生活中或临床上，有时将尚可救治复苏的假死状态错误地判断为死亡。因此，对于具有潜在假死可能的情况，需要认真进行甄别，以免引起误判和纠纷。引发假死的原因主要有机械性窒息、电击、大失血、镇静安眠药中毒、高温或低温损伤、癫痫、尿毒症、严重脱水、一氧化碳中毒、糖尿病昏迷、严重营养不良，以及强烈精神刺激等疾病或损伤，早产儿更易发生假死。从发生机制和临床表现方面，假死者主要是由于某些中枢神经系统功能性抑制引起的濒死期的特殊情况，若得到及时救治可复苏，有些假死者经过一段时间亦可自然复苏。但是，患者即使得到暂时复苏，如果导致假死的原因未去除，大部分仍会在短时间内死亡。曾有报道，临床医师诊查不慎，错将假死状态诊断为死亡，而开具死亡证明。因此，在临床医师和法医鉴定工作中，应注意鉴别死亡和假死，一般只要通过认真细致的检查，可识别假死：



1）心脏活动：用听诊器在心前区听诊心脏搏动；心电图检查存在心电活动；通过 X 线透视观察心脏搏动。



2）呼吸活动：仔细听诊颈部支气管呼吸音；做气管插管时候存在咽反射。



3）血液循环：眼底镜观察视网膜血管搏动和血流，以及动静脉血氧饱和度的色差；眼球张力和眼压正常；瞳孔变形试验，压迫眼球致瞳孔变形，解除压迫后，瞳孔很快恢复正常；1％荧光色素钠滴眼，2～5 min 结膜黄染褪色等，均提示存在血液循环。

从现代医学研究积累的大量医学基础研究和临床治疗的实验资料来看，个体的死亡，并不是瞬时的事件，而是一个连续发展的过程。生命的主导器官脑组织主宰整个生物的机体。人类脑组织对缺氧的耐受性非常低，大脑皮质完全缺氧 6～ 8 min，就可以使脑皮质坏死到不可逆转的程度。广泛脑细胞坏死一经形成，自主呼吸就不能恢复，即使心跳、血压仍可维持，但患者实际已经进入一种死亡状态。从病理生理学角度来讲，在脑死亡的过程中，机体的新陈代谢分解要大于合成，组织细胞的破坏要大于修复。一旦脑死亡确定，那么人的机体便处于整体死亡阶段，作为人的特征性的东西完全消失，即自主活动，信息交流不能实现，那这个人存在的社会意义也就不复存在。因此，脑死亡的概念的提出，成为必然。



## 1． 脑死亡的诊断标准



目前，由于各国立法不同，脑死亡的诊断标准也不尽相同。迄今，已提出 30 余种，其中以1968 年美国哈佛大学医学院特设委员会提出诊断脑死亡的标准（简称哈佛标准）最具代表性，具体标准如下：① 昏迷不可逆转，对刺激完全无反应，即使剧痛刺激（压眶）也不引起反应。② 无自主性呼吸，观察1 h，撤去人工呼吸机仍无自动呼吸。③ 无反射，瞳孔散大、固定，对光反射消失；转动患者头部或向其耳内灌注冰水无眼球运动反应；无眨眼运动；无姿势性活动（去大脑现象）；无吞咽、咀嚼、发声；无角膜反射和咽反射；通常无腱反射。④ 平直脑电图，即等电位脑电图，记录至少持续 10 min。



上述各试验在 24 h 后还需重复一次，但必须排除低温（32．2℃以下），中枢神经抑制剂如巴比妥酸盐中毒等才有意义。后来该委员会又增加了还应排除代谢性神经肌肉阻滞剂中毒、休克和 5岁以下的小儿。同时，检测方法又增加了脑血管造影和放射核素检查以证明脑血流的停止。



## 2． 脑死亡的立法



随着现代医学的进展，以脑死亡作为个体死亡的标准和观念正在冲击着对人死亡的传统诊断标准，即临床医学所沿用的“呼吸、循环停止”作为个体死亡的判断依据。因为人的个体死亡涉及遗嘱争执、保险的索赔、职工的抚恤金、器官移植的开展、医疗纠纷或事故以及刑事诉讼案件所涉及的是否杀人等问题。因此，在法律上也必须考虑到脑死亡的立法问题。目前，我国尚未对脑死亡进行立法，因此不能以脑死亡作为判定个体死亡的标准或依据。



## 3． 脑死亡与植物人



脑死亡与植物人并非同一概念，两者不能混淆。脑死亡是指大脑、小脑、脑干等全脑功能不可逆转地丧失，是人的个体死亡新概念。



植物人，又称持续性植物状态（persistent vegetative state）是指脑中枢的高级部位（大脑皮质）功能丧失，患者呈意识障碍或永久性昏迷状态，而脑中枢的中心部位（皮质下核和脑干）所管理的呼吸、体温调节、消化吸收、分泌排泄、新陈代谢以及心脏循环等自主功能依然存在。这样的患者，只要护理得当就能长期生存。按以下各点可以做出植物人的诊断：



1）不能自行活动或变换体位，只能躺在床上，必须别人护理和照料。



2）思想、意志、智能、情感以及其他有目的的活动均已丧失，如能发出声音也是吐字不清，含意不明。



3）在指示和命令下，虽有睁眼、握手等简单动作，但不能做复杂动作。



4）即使能注视目标，也不能辨认。



5）不能自行摄取食物，不能诉说饥饱。



6）二便失禁。



总之，不可将植物人状态当作脑死亡。因为植物人还有自主呼吸、心跳等自主功能存在，而脑死亡这些自主功能永久全部消失，只有靠机器来维持这些功能。

脑死亡作为个体死亡的诊断标准之一，不是完全取代传统心肺死亡的诊断标准，两者是相互补充的关系。一般情况下，心搏呼吸停止 5 ～ 6 min 即可导致脑生命中枢不可逆性丧失的脑死亡，现代医疗水平几乎难以在如此短时间内有效地抢救复苏。因而，临床上有心脏性猝死“黄金 4 分钟”的有效救治时限之说。在临床实践中，多数脑外器官伤病者，仍可沿用传统的心搏呼吸功能停止作为诊断死亡的标准或确定死亡的标志，此时引起的脑死亡属于继发性脑死亡诊断。只有原发性脑干或全脑严重伤病时，心肺等脑外器官功能可在医疗辅助下长期维持，才适用脑死亡诊断，即原发性脑死亡诊断。现代医学和法律上死亡的确定，不论心肺死亡，还是脑死亡，均属于死亡诊断标准。



## 四、死亡过程



从各种死因引发的致死性病理生理过程开始，到个体死亡的时间历程称为死亡过程（death process）。一般情况下，死亡过程可分为濒死期、临床死亡期、生物学死亡期，但其发展情况取决于个体的死因、体质和救治等诸多影响因素，其各阶段的表现和持续时间不尽相同；有时，暴力因素或疾病导致的急性死亡可不经过濒死期，而直接进入临床死亡状态。 【善雅集】公众号资料来源于公开网络，本书的版权及著作权等部归于出版社及作者等。



## 1． 濒死期（agonal stage）



又称临终状态，为死亡过程的开始阶段。其主要为各种原因导致机体各器官系统功能整合机制紊乱、失调的病理生理过程的终末阶段。患者主要表现为不同程度的意识障碍，各种中枢神经反射减弱或消失，瞳孔大小、心率、血压、呼吸等生命体征不稳定，呈波动性，如各种病理性呼吸。濒死期持续时间长短不一，可从数分钟至数小时，甚至更长。一般情况下，青壮年、体质强健者较长，衰老体弱者较短。此期的生命功能尚处于可逆性阶段，若得到及时有效的治疗，可以复苏；反之，当呼吸、心搏停止后则进入临床死亡期。



## 2． 临床死亡期（clinical death stage）



指人的躯体或个体死亡，是与细胞性死亡相对而言的。按照传统的概念是呼吸、心跳停止。此时各生命中枢器官功能丧失，如脑的功能丧失，呼吸和心跳停止；但全身各器官组织的细胞并未全部死亡，有些还可以存活一定的时间，随后功能逐渐衰退直至全部死亡。



若在生命中枢不可逆性损害时限内及时有效救治，此期仍可复苏。但是，由于临床死亡期持续时间较短，约持续 5～6 min，即发生继发性脑死亡前脑能够耐受缺血缺氧的时限；在大多数情况下，均难以获得及时救治，进而转入不可救治的生物学死亡期。

是死亡过程的最后阶段，也称细胞性死亡。此期脑干生命中枢乃至全脑均发生不可逆的损害和功能丧失，机体其他器官组织随之相继进入细胞死亡。生物学死亡期的早期阶段脑外器官组织细胞仍可保持一定的生命功能和对外界刺激的低级原始性反应，此种现象称超生反应（supravital reaction）。如机械性或电刺激骨骼肌、心肌、肠道平滑肌的收缩蠕动反应等，可用于推断死亡时间。但目前有关生物学死亡期的时限及其生物学特征尚不清楚，是法医病理学领域需要研究和解决的基础科学问题之一。

在临床和法医实践中，引起死亡的原因种类繁多，但这些原因作用于机体引发的致死性病理生理机制及过程不同，主要集中于脑、心、肺等生命重要器官的功能失代偿，即原发性疾病、中毒或损伤等因素引起的个体死亡的病理生理过程，称之为死亡机制（mechanism of death）。



一个完整的医学和法医学死因诊断至少都要包含符合医学原理的死因和死因机制两部分内容，体现对于死者的死因及其死亡机制的科学理解。合乎医学理论和逻辑的分析死亡机制，对于解释和印证死因引起的一系列致死性病理生理变化及其相应的临床表现、指导解决相关医疗纠纷及其死亡案件的法医学鉴定等，均必不可少。



传统的法医学教材中，往往把死亡概念分类为心脏死、肺脏死和脑死亡三种。但是基于WHO 提出的死亡定义，心、肺、脑分别为三个重要生命器官，其各自发生致命性功能紊乱的表现分别为循环衰竭、呼吸衰竭、中枢衰竭以及同时出现不同组合的多器官功能衰竭。这种基于病理生理机制的死亡分类可能更有利于死亡机制的阐述。



死亡机制是各种不同的死因通向死亡终点的几条共同通道，常见的死亡机制有心脏停搏、反射性心脏抑制、严重代谢性酸中毒或碱中毒、呼吸抑制或麻痹、心肺功能衰竭、肝肾衰竭、延髓生命中枢麻痹等。所有这些机制最后都会导致心、肺、脑的生命活动停止而死亡。死亡发生的速度不尽相同，而死亡速度的快慢与死因及死亡机制密切相关。

急性死亡（acute death）指损伤或疾病发作后几小时至 24 h 内发生的死亡，其机制主要是心、肺或脑机能的急性衰竭。



1）急性心力衰竭 由于心输出量急剧减少，机体尚来不及发挥代偿作用，多伴有心源性休克。主要表现为快速发生意识障碍，心脏节律紊乱，因急性肺水肿，口鼻可有泡沫性液体流出。除常见于心脏和大血管的严重损伤外，还见于各种重度心脏疾病，如心脏破裂、重度心肌炎、心肌病、二尖瓣脱垂等。



2）中枢神经系统机能障碍 多见于中枢神经系统某些损伤或疾病及其急性并发症。如外伤性或病理性脑大片出血、急性硬脑膜外或硬脑膜下血肿、重度蛛网膜下腔出血、脑室积血，各种原因的颅内高压继发的脑疝、脑干损伤、脑脊液循环的急性障碍等。



3）急性循环衰竭 如创伤性、急性失血或失液性、过敏性、感染中毒性休克等。病理学上主要表现为微循环障碍引起的组织灌流不足，临床上主要表现为血压的显著下降。



4）急性呼吸衰竭 见于各种机械性、病理性或中毒性窒息。



5）中枢性及心源性功能障碍 重度日射病、热射病引起的中枢神经系统急性功能障碍和心脏节律紊乱，低温引起的心脏传导阻滞伴发心室纤颤。

3）外伤后非感染性并发症 如挤压综合征导致的急性肾功能衰竭，血栓栓塞等引起的急性呼吸功能衰竭或急性心脏功能衰竭、中枢神经系统功能障碍。



4）水电解质和酸碱平衡紊乱 因缺氧、中毒、损伤或某些疾病等引起体内水电解质紊乱、酸或碱中毒。

慢性死亡（chronic death）指损伤3 周以后发生的死亡。有的可能在几个月、几年，甚至更长的时间后才发生的死亡。与法医鉴定有关且较常见的如下：



1）颅脑外伤后迟发性脑出血，死后中枢神经系统功能障碍。



2）下丘脑、垂体的损伤或疾病引起了代谢紊乱性疾病（如糖尿病、尿崩症），多死于多器官功能衰竭。



3）心包或胸膜广泛粘连致心包腔或胸腔闭塞，引起心脏或呼吸衰竭。



4）外伤性胰腺炎、肝胆损伤、胃肠道狭窄或梗阻等引起水电解质紊乱。



5）慢性中毒和多次小剂量投毒导致重要器官功能的逐渐衰竭。



在分析死亡机制时，以往多集中于单个生命重要器官和系统的功能衰竭，分别进行死因及其死亡机制分析。但是，近年来，随着医疗救治技术不断发展和完善，各种伤病引发的单器官功能衰竭死亡率已明显下降。而严重的创伤和疾病等危重患者，特别是多发伤和复合伤，往往继发多器官功能障碍综合征（multiple organ dysfunction syndrome，MODS）的并发症导致死亡。据统计，目前医疗救治水平情况下，单个器官功能衰竭的病死率为15％～30％，2 个以上器官功能衰竭的病死率为 40％ ～ 60％，3 个器官功能衰竭的病死率可达 80％，4 个及 4 个以上器官功能衰竭的病死率几乎为100％。因此，多器官功能衰竭已成为不容忽视的一类死亡机制。



上述分类是为了便于法医工作者在实际工作中进行死因及死亡机制分析时参考，引起死亡的机制可有多种，因而分类与临床上传统的分类方法不尽相同。且有些死亡机制可在不同的情况下表现为急性、亚急性或慢性死亡，受损伤或疾病的程度、治疗措施等多种因素影响。作为一名法医学鉴定人员，应当不断总结实际检案工作经验。

在法医学上，将不同原因所引起的人体死亡性质分为自然性死亡与非自然性死亡两大类。

自然性死亡又称非暴力性死亡（nonviolent death），指符合生命和疾病自然发展的规律，没有暴力因素干预时发生的死亡，理论上又可以分为生理性死亡和病理性死亡。



## 1． 生理性死亡（physiological death）



也称衰老死（death over aging），指由于机体自然衰老，体内各组织、器官的生理功能逐渐减退直至衰竭，尤其是脑、心、肺功能的自然衰竭以至不能维持生命功能而导致的死亡。实际上，生理性死亡是极罕见的。在目前条件下活到 100 岁以上的人并不少见，绝大多数人属于病死，真正“无疾而终”的衰老死几乎见不到。这是因为随着年龄增长至老年阶段，全身各器官的功能都已严重退化，抵抗力严重减退，最后还是由于疾病的侵袭而导致死亡，所以生理性死亡更多的只是理论上的意义，但是，人类追求长寿的努力从古至今一直没有停歇过。



## 2． 病理性死亡（pathological death）



指由于各种疾病的发生、发展、恶化而引起的死亡，习惯上称为病死。大多数病死者在死亡前接受过一定的临床检查、诊断、治疗和预后估计，死亡经医生证明，一般不会引起纠纷和诉讼，法医学所受理的病理性死亡案件主要为出乎人们意料之外的猝死或医疗纠纷。

非自然死亡又称暴力性死亡（violent death），是由某种或几种外来的作用力或有害因素导致的非病理性死亡。是指由于生命或疾病自然发展规律以外的因素干预而提前发生的死亡。所谓“暴力”完全是一种习惯性的叫法，它具有广泛的含义，指疾病以外的所有因素。这种干预因素可以是外界的（他人的，环境的），也可以是死者本人的；可以是故意的，也可以是非故意的。它们是法医学研究的主要的和不同于其他学科的内容。造成暴力性死亡的因素种类繁

包括钝器、锐器、火器、交通工具损伤；缢、勒、扼、捂死等；雷击、电击死、烧死、冻死和其他物理因素致死等。

死亡方式（manner of death）通常是指暴力性死亡以何种方式得以实现。有学者习惯上也称其为案情性质。死亡方式的鉴定是法医病理鉴定中的重要工作之一，是制定刑事侦查方案、司法审判定罪与非罪的重要依据，对民事调解和灾害赔偿同样也具有重要意义。死亡方式分为自杀、他杀、意外死亡、死亡方式不确定四种。



## 1． 自杀（suicide）



是指自己用某种暴力手段伤害自己，故意终结（剥夺）自己生命而导致死亡的行为。自杀引起的死亡称自杀死（death from suicide）。据 WHO 统计，全世界每年自杀死者达数十万人；其中，日本人的自杀率最高。我国每年自杀死高达 28 万人，约占整个死亡人群的 3．6％，构成第五大死因。每年自杀未遂者约 200 万，自杀率农村高于城市，女性高于男性。自杀现象已成为不容忽视的一类社会问题。



## 2． 他杀（homicide）



指违背他人意愿故意使用暴力手段造成他人死亡的行为。由他杀造成的死亡称为他杀死（homicide death）。法律上还可进一步区别三种不同司法审判量刑的他杀情况：谋杀（murder）、过失杀人（manslaughter）、正当防卫致死（legitimate homicide）。如果死因明确，委托方提供的案情确实可靠，特别是产生根本死因的案情清楚无误，法医病理鉴定中可以做出他杀的死亡方式判断，但对于具体是否为谋杀、过失杀人、正当防卫致死的死亡方式，则属于司法审判量刑过程中法官（或陪审团）之法律因果关系判断。



## 3． 意外死亡（accidental death）



指意料之外、非故意的行为所造成的死亡。其核心是意料之外，即没有预见所做的行为在一般情况下会导致死亡；非故意指其行为不是以结束他人或自己生命为目的。但其他的目的有时可能是故意的，如为了避免撞车紧急刹车或转向而造成的交通事故，这种意料之外和非故意的行为所造成的死亡受害者可能是他人，也可能是行为者本人。由社会或人为因素造成的死亡称为意外事故死（death from an accident），包括交通事故（traffic accident）、工伤事故（industrial accident）、医疗事故（medical accident 或 medical negligence）。而由风暴潮、洪水、地震、火山爆发等自然灾害造成的死亡称为灾害死（disaster death）。



## 4． 死亡方式不确定（undetermined manner of death）



指由于受到各种原因的影响，而无法通过法医病理学鉴定，包括案情调查、现场勘查等明确死因或死亡方式的情况。世界卫生组织《国际疾病分类》（WHO ICD）第 11 版中将死亡方式不确定又分为三种情况，可以为法医病理鉴定实践提供借鉴：



（1）不能确定（could not determined） 指死因不明的情况，如高度腐败、尸体火化等尸体严重毁损而不能确定死因。尽管相关案情可能清楚，因不能确定各类死因情况而不能确定其死亡方式。例如，某人因交通事故致条件性致命伤而死亡，因尸体严重腐败或未经系统尸体解剖检验而火化，不能确定死者是否存在除交通损伤之外可能与导致其死亡有关的潜在疾病或其他因素等，难以进行相应因素在引起死亡中的因果关系及其原因力分析，特别是不能确定根本死因。由此也表明仅通过尸表检验进行死亡原因鉴定，在很大程度上并不能客观、科学地做出死因鉴定意见，也不能对死亡方式做出正确判断。因此，一旦发生死因不明或死因争议案件，应通过系统尸体解剖检验及其他相关检查等明确死因，进行死亡方式鉴定。



（2）待调查（pending investigation） 指事件情况不明的情况。虽然尸体检验能够明确死因，但造成死亡的相关事件情况不明，特别是根本死因的案情不清或尚未调查清楚，仍不具备确定死亡方式的条件。例如，通过法医学尸体解剖等检验确定了根本死因为高坠伤，但案情不明确和现场被破坏，自杀、他杀、意外坠楼均有可能，尸检所见没有优势证据确定其是如何发生高坠的；法医病理鉴定意见书的分析说明中，只表述相关死因的事实因果关系及各种与死亡相关因素在引起死亡中的作用分析，而不予判断死亡方式。但有时可能对确定死亡方式具有提示作用。



（3）未知（unknown） 指死因和案情均不明确的情况。这种情况下，法医通过系统全面尸检排除已知伤病导致死亡的可能，但无法确定其根本死因，且案情事实不清，则难以判断死亡方式。



死亡方式既是司法、医疗及保险机关审理或裁决死亡案件的一项重要内容，又是判断案件性质的主要依据。新版 WHO ICD 11 死亡证明表中专设死亡方式一栏，明确了三类不确定的死亡方式，提示临床医师填写死亡证明时需更加审慎。同时，也提醒法医病理鉴定人，应充分利用法律赋予的案件知情权，依据尸体检验所见的客观证据，特别具有诊断价值的特征性损伤、病变，结合证据资料，综合尸体检验所见、实验室检验结果，结合明确的案情调查、现场勘验等信息资料，掌握相关案例的充分必要判断条件后，进行死亡方式的分析、判断，做出相应的鉴定意见。

死亡原因，简称“死因”，是指导致死亡发生的暴力、疾病或衰老等因素。WHO ICD 将死亡原因（cause of death）定义为：“所有导致或间接促进死亡的疾病、病态情况或损伤，以及造成任何这类损伤的事故或暴力的情况。”WHO ICD 的死因概念涉及两方面，一是所有导致或间接促进死亡的疾病或损伤；二是造成疾病或损伤的事故或暴力的情况。其包含了所有与死亡相关的因素，既有具体的疾病和损伤及其并发症，又有产生致死性疾病和损伤的原发事件或者暴力情况。该死因定义科学、全面、系统地涵盖了所有与死亡相关的自然的、社会的、法律的因素，对于法医病理学进行死亡原因、死亡机制、死亡方式和死亡性质的鉴定和判断具有指导作用。



自 1979 年 WHO ICD 第 4 版至 2019 年第11 版中，一直将死因概括为4 种类型：根本死因、直接死因、中介死因、辅助死因。但是，在法医学死因分析中，仅依据 4 种死因分类难以满足死亡原因鉴定的需求，还应该包括死亡诱因、协同死因、联合死因等。需要说明的是，死亡诱因其本质上不属于死因，但由于在死因鉴定或分析中常需要对其在引发死亡中的作用予以说明，在此一并表述。



## 1． 根本死因（primary cause of death）



法医病理学领域，根本死因是指导致死亡的原发性疾病、损伤或暴力性因素。世界卫生组织将根本死因定义为：启动一系列病态事件而直接导致死亡的疾病或损伤，或产生致命性损伤的事故或暴力情况，以及没有中间环节的单一死因，有时也称为原发性死因。例如，交通事故，车辆撞伤行人致多发性骨折→创伤性休克→循环衰竭→死亡；胰头癌→胆管梗阻→肝功能衰竭→死亡。两个事件中，交通事故所致多发性骨折、原发性疾病胰头癌分别为根本死因。分析、确定根本死因的意义在于溯源性，既包括具体的原发性疾病或损伤，又包括造成伤病的最初事故或暴力情况，如交通事故、工伤事故、医疗事故等，并指向相关事件的责任者。



## 2． 直接死因（immediate cause of death）



系直接导致死亡的原因，常是疾病、损伤、中毒引起的致死性并发症。例如，失血性休克、心肌梗死、脑出血、肺水肿等。直接死因不是独立的原发性疾病或病变，是直接导致死亡的疾病或病变，是死亡机制的启动因素。有时，根本死因即是直接死因，如氰化物中毒、全颅崩裂等导致的死亡。



## 3． 中介死因（intervening cause of death）



法医病理鉴定实践中，常可见在根本死因与直接死因间存在加重或促进继发性病变进展的因素，起到承上启下或转向不利发展的“中介因素”的作用，也将其称为“中介死因”。例如，颅脑损伤后发生继发性支气管肺炎，而又发生了误吸，进一步加重了支气管肺炎的病变程度，因颅脑损伤并诱发继发性支气管肺炎而死亡；其中，“误吸”可被视为“中介因素”或“中介死因”。有时，中介因素也可能是人为因素，如“护理不当”“手术过失”等。因此，“中介死因”更适用于医疗损害相关的司法鉴定。



## 4． 辅助死因（contributory cause of death）



系指独立于根本死因或直接死因之外的疾病、损伤或其他暴力因素，其本身单独不会致命，但在死亡过程中起到辅助或促进作用。一般而言，同时存在的与直接死因方面无关的病理情况及其他外部介入因素，可一定程度地降低机体抵抗力或代偿力的伤病，或对致命性损伤或疾病进展具有促进作用的伤病等因素，均属于辅助死因。如慢性支气管炎转变为急性支气管炎而死亡；其中，基于医学理论，慢性支气管炎可以引起继发性急性支气管炎或有利于其发生，继之可以导致严重的肺水肿等而死亡，即慢性支气管炎与急性支气管炎之间存在转归的因果关系，故慢性支气管炎应为辅助死因。又如，患有血友病或晚期肝硬化的患者，因存在凝血机制功能障碍，在损伤后更易发生大量失血、失血性休克而死亡；其所患血友病或肝硬化对外伤所致大量失血具有辅助作用，应作为辅助死因。



## 5． 联合死因（combined causes of death）



系指同时存在两种或两种以上致命性原因，或共同作用导致死亡的非致命性原因，包括疾病、损伤或其他暴力因素的联合。其各种疾病、损伤及其他暴力因素情况相互独立，仅为时空上的偶合或伴发，无明显的相互作用或联系，故亦称为并列死因。联合死因可有多种联合形式：① 伤与伤联合。如心脏刺创和脑干挫裂伤；② 伤与病联合，如脑干挫裂伤和胃溃疡上消化道大出血；③ 病与病联合，如高血压性脑出血和冠心病心肌梗死。亦可有损伤、疾病与中毒三种死因或多种不同因素组合导致死亡的情况。尽管联合死因是指疾病、损伤或其他暴力因素等多种原因共同作用导致死亡的情形，但实践中往往各类疾病、损伤等并非对引起死亡起到同等作用，也存在主次作用。多种因素参与导致死亡的复杂死因鉴定及其死因分析一直是法医病理学实践中的难题，需要深入研究、阐明各类因素在导致死亡中的病理生理机制才能解决这一难点问题。



## 6． 死亡诱因（induced factor of death）



系指引起体内潜在疾病发作或病情恶化致死的轻微伤痛和（或）引发生理性应激反应的因素，简称诱因。在法医实践中，常常遇到这类情况，而为司法审判量刑所需要。理论上，诱因情况仅引起一过性生理性应激反应，如躯体疼痛、血压升高、心率加快、情绪波动等，对于一般健康人不能单独导致较为严重的伤病损害或致死。例如：“扇耳光”引发脑血管畸形破裂导致病理性蛛网膜下腔出血而死亡。甚至，没有直接外力打击，仅是“与人争吵”就引发了冠心病患者的心源性猝死，或者高血压患者的脑干出血死亡。这类情况的死因分析：脑血管畸形、冠心病或高血压均应属于根本死因，而“扇耳光”或与人争吵等均应属于诱因，病理性蛛网膜下腔出血或脑干出血均应属于直接死因。



在死因分析中，常常需要区别诱因和辅助死因。一般而言，诱因应是在原发性疾病基础上，临时介入而引发机体生理性反应的轻微的、短暂的或一过性身心刺激的情况。而辅助死因，既可以在死者身体早已存在，又可以是临时介入的较重的、持续性的身心病痛或应激反应。

如前所述，直接死因指直接引起死亡的疾病或损伤，它常是疾病、损伤、中毒、窒息所引起的直接致命的并发症或继发症。常见的如感染、出血、栓塞、肺水肿、内源性的毒素吸收中毒等，也有如各类休克，脑疝，肺、心、脑的（脂肪、空气、血栓）栓塞，严重的心律失常、酸或碱中毒等。而根本死因指导致上述直接死因的原发性疾病、损伤、中毒、窒息等或暴力性因素，如电击。如冠心病是一种常见的根本死因，它的直接死因可以是急性心脏压塞，还可能是冠心病急性发作后引起的交通事故损伤、高坠损伤、溺水等。其他常见的根本死因如主动脉夹层破裂出血致死；在暴力性或中毒死亡案例中机械性损伤、机械性窒息、雷电击伤、外源性毒物中毒等引起的死亡，根本死因即是指该项暴力或中毒。



根本死因与直接死因之间通常有一段时间间隔，短者只有几十分钟、几小时，长者可有几天、几周、几个月，甚至更长的时间。也可能根本死因也是直接死因，两者合二为一。此时，根本死因直接导致了死亡，如严重的颅脑损伤、重度窒息、急性重度中毒、心或脑部位的高压电击等。其特点是这种死亡均发生得很快。



根本死因和直接死因不是主次关系，而是因果关系。根本死因是直接死因的原因，而直接死因还是死亡机制的启动因素。如果是死于继发病理后果或并发症，在填写诊断时，要把继发病理后果或并发症写在“直接死因”项内，而把原发性损伤、疾病或中毒写在“根本死因”项内。这样既符合国际死因统计的要求，又符合法医学死因分析的要求。

检验鉴定是法医学专业人员在检案实践中以科学的观点为指导，用客观、恰当的方法观察未知事物，并通过科学的逻辑思维正确反映其本质和得出结论的过程。要完成这一过程，法医除要全面掌握专业理论和技术方法外，还要熟悉哲学方法和逻辑学方法。确定死亡原因具有十分重要的意义，直接影响着各类涉及法律问题的案件或事件的准确定性、公正审判或处理。在法医病理鉴定工作中，科学、合理并具有逻辑性的死亡原因分析、论证是做出死亡相关事项鉴定意见的重要依据。



分析、论证死因的过程如同临床医生看病诊断，应有分析思考的方向。合格的法医病理鉴定人应做到在尸检前尽可能多地了解有关死亡发生的信息，如死者的年龄、性别、职业、既往病史；死亡发生的时间、地点、死前的表现；死者的家庭及社会状况，夫妻关系等，就像临床医生在体检前采集病史一样，从而在头脑中形成有关死因和死亡方式的几种可能或假设，使法医尸检能做到有的放矢、重点突出。其次，全面、系统的尸体解剖检验、组织病理学检查及其他实验室检验结果等是死因分析的核心依据；同时，需要综合现场勘查及案情情况才能得出符合或接近客观事实的死亡原因鉴定意见。



在检验鉴定中，牢记唯物辩证法是检验鉴定的指导思想。唯物辩证法认为，物质世界有着自己的辩证运动规律，任何事物都是处在普遍联系和相互作用之中；任何事物都有它产生、发展和灭亡的过程；事物发展的根本原因在于事物内部的矛盾性，矛盾者的对立面既统一又斗争，由此推动事物的运动和变化。唯物辩证法是当代最科学的哲学认识论和方法论。因此，在死因分析及检验鉴定的全过程中，必须始终用唯物辩证法指导我们去发现、认识、研究和解决问题，不能孤立地、静止地、表面地和片面地看问题，而要深入细致地做好调查研究。

一切结论都是产生于调查研究的结尾，没有调查就没有发言权。所以，在分析鉴定案例时，既不能凭自己主观想象办事，也不能受他人的诱导而盲从，除全面了解案情和现场勘查信息等，还应注重以下工作：



## 1． 全面仔细地检验尸体



尸体检验就是运用法医病理学的理论和技术以及检案实践经验，通过系统尸体检验进行调查研究。需要认识到人与人之间的个体差异大，即或是同样一种损伤或疾病，在不同人身上的表现和后果也不完全一样。因此，在检验鉴定中，要结合案情、现场和全部调查材料以及实验室检验的结果，综合辩证地分析损伤、疾病或其他因素与死因的关系。



## 2． 客观准确的实验室检查



死亡原因鉴定离不开相关实验室的检验工作，其检验结果既可以是认定死因的关键依据或作为参与死因的因素之一，也可能是分析、判断死因的排除性因素。很多情况下，如果未做毒物检验，则不能排除中毒死亡或存在中毒的可能。应根据案情及尸体检验发现等，进行有助于说明死因的相应实验室检验。

通过实事求是的调查研究可以获得正确反映客观事实的第一手材料，但要进一步研究这些感性材料，还必须通过分析、归纳、推理，将其升华到理性认识阶段。分析时应注意以下几点：



## 1． 整体与局部的关系



整体是由若干局部构成的统一体，局部是整体的组成部分，两者既有区别又不可分割。疾病或暴力可在机体局部有明显的表现，如颈部缢沟、扼痕，但作为窒息死亡的根本原因，还必须在死者全身有窒息死的征象。或相反，当发现死者全身有窒息征象时，又必须尽全力在尸体的某一局部找到引起窒息的原因。在法医实践中，发现较大的局部病变，特别是局限性实变病灶较容易，要认识宏观的整体病变则难，如急性心功能障碍、窒息、休克、代谢性酸（碱）中毒等全身性变化，如没有扎实的病理解剖学理论基础和形态学认知能力以及丰富的实践经验，就很难发现、认识。只注意局部变化而忽略整体的情况，也时有发生。例如，疑为细菌感染所致败血症而死亡的案例，如果仅注意局部创口感染，而没有检查最能反映全身感染情况的脾、淋巴结等网状内皮系统改变，也未检查各组织器官有无炎症反应所见，甚至未做细菌培养、鉴定的实验室检验，就难以分析认为系因败血症致死。其他情况还包括不能仅从死者胃内容物中检出某种毒物就认定是中毒死。



## 2． 一般与特殊的关系



人对事物的认识是由特殊到一般，又由一般到特殊的过程。只有在认识了若干个别事物的特殊本质以后，才有可能通过概括，从特殊的个性中抽出一般的共性，使之成为一种共性认识，然后再用共性认识，去揭示未知事物个性的特殊本质。实践中，始终是借鉴前人总结的共性和个性知识，并结合自己的实践经验，去认识被检验的对象。如根据锐器伤的形态学一般共性，可以确认锐器伤；根据损伤的具体特殊形态还可以推断致伤物。一般性特征解决共性认识，特殊性特征解决个性认识，所以说，要认识每个事物，必须注意它的个性特殊点，注意它与其他事物的本质区别。在法医学，一般共同具有的所见称之为征象或一般征象，仅个别具有的特殊所见的才能称之为特征。如缢死尸体的所见中，缢沟是缢死的特征，而尸斑出现早且显著、各器官淤血以及浆膜、黏膜瘀点性出血点等只是窒息死的一般共性所见。总之，在检验鉴定中，必须正确地处理一般与特殊、个性和共性的关系，只有两者相辅相成才是一个完整的认识过程。



## 3． 形态变化与功能变化的关系



人体的形态结构是功能活动的物质基础，功能是形态结构的物质运动形式，两者对立统一，互相联系。形态结构发生病变，功能也会出现相应异常，如心脏因传导系统有病变或心肌有缺血性病变，心功能出现失常；此时，我们可以用形态结构的病变解释心功能障碍，甚至解释心源性猝死。同样，功能有异常改变也可以反映存在组织器官形态结构的病变。因此，一般情况下可以根据形态变化解释并认定因功能障碍而导致的死亡。但是，有些由于基因突变引起蛋白质结构异常而引起致命性功能障碍导致的死亡，如长 QT 综合征、短 QT 综合征、Brugada综合征等离子通道病死亡的病例，心脏并无病理形态学所见。



## 4． 内因与外因的关系



唯物辩证法认为外因是变化的条件，内因是变化的根据，外因通过内因而起作用。也就是说，事物发展的根本原因不是在事物的外部而是在事物的内部，在于事物内部的矛盾性。法医病理鉴定中，当涉及损伤与疾病在导致死亡的相互作用关系时，就必须用内因与外因关系的观点予以论证。如某人在殴斗中，当场倒地死亡，尸体解剖中虽然检见体表存在钝力性损伤，但均非致命伤，而确有严重的冠状动脉粥样硬化性心脏病，可见陈旧性梗死灶，也有急性缺血性心肌病变，显然本例的根本死因是冠心病（内因），殴斗和钝性外力作用只是诱发冠心病发作的因素（外部的条件）。即使是心脏刺创，因心脏破裂而死，其死亡也是源于内因（心脏破裂出血），只是心脏破裂是由被刺造成的，故鉴定其死因为心脏刺创（根本死因）导致心脏破裂、出血（直接死因）而死亡。以上两例，虽然死亡都取决于心脏这个内因，但是这内因的性质不同，前者是自身的疾病，后者是心脏刺创，一个是疾病致死，一个是损伤致死。



总之，死因分析是一个由实践到认识的辩证思维过程。当掌握的实践材料越多，实践经验越丰富，作为分析思考基础的理论知识越广博，其最后的鉴定意见的科学性和客观性就越强。因此，实践中需要具体问题具体分析。

法医病理学工作者在进行死亡原因鉴定时，应注意遵循全面细致、科学客观的鉴定原则，准确客观地提供检验结果和鉴定意见，不受外来的因素影响。鉴定意见应具备实事求是、客观公正、规范性、合理性的原则。鉴定意见表述方式常有认定性、符合性、不排除性。



法医病理学有关死因的鉴定意见可分为认定性鉴定意见、符合性鉴定意见、倾向性鉴定意见、不排除性鉴定意见和不能得出结论性鉴定意见。



当鉴定意见使用“系”作为谓语时，尸体检验工作应建立在解剖检验的基础上，具备其他充分必要的死因证据支持，如组织病理学检查、毒物检验等，并能够与案件事实相印证；



当鉴定意见使用“符合”作为谓语时，尸体检验工作应至少建立在解剖检验的基础上，表示具备基本的死因证据支持；



当鉴定意见使用“不排除”作为谓语时，表示依据现有的各项检验结果可以排除其他死因，但不能排除某种死因的可能；



当鉴定意见使用“无法认定”作为谓语时，表示依据现有的条件及各种检验结果不具备支持某些死因的证据，且无法排除任何死因的可能性。
