# 民法典物权编第二分编第五章【国家所有权和集体所有权、私人所有权】综合

## 第一部分 国家所有权（Articles 246-259）

### 一、第246条·国家所有权总括与国务院代表行使

#### 法条原文

> 第二百四十六条　法律规定属于国家所有的财产，属于国家所有即全民所有。
>
> 国有财产由国务院代表国家行使所有权。法律另有规定的，依照其规定。

#### 核心释义

**国家所有权的6个特殊性**：

| 特殊性 | 内容 |
|--------|------|
| 1. 全民所有 | 国家所有即全民所有，由国家代表全民行使所有权 |
| 2. 公私法交融 | 与国家公权力有关联，又应严格区分 |
| 3. 内容法定 | 国家所有权的产生、内容、运作程序都是法定的 |
| 4. 客体广泛性 | 既包括经营性财产，也包括行政公益性财产 |
| 5. 取得方法专属性 | 征收、没收、税收等只能产生国家所有权 |
| 6. 行使特殊性 | 由代表国家的专门机关或单位行使，不直接由国家行使 |

### 二、第247-254条·国家专有的具体客体

| 条文 | 客体类型 | 核心要点 |
|------|---------|---------|
| 第247条 | 矿藏、水流、海域 | 矿产资源、水资源、海域属于国家所有；国务院代表国家行使 |
| 第248条 | 无居民海岛 | 属于国家所有；国务院代表国家行使无居民海岛所有权 |
| 第249条 | 城市的土地 + 法律规定属于国家所有的农村和城市郊区的土地 | 城市市区土地属于国家所有 |
| 第250条 | 森林、山岭、草原、荒地、滩涂 | 可国家所有或集体所有（法律规定属于集体所有的除外） |
| 第251条 | 野生动植物资源 | 法律规定属于国家所有的野生动植物资源属于国家所有 |
| 第252条 | 无线电频谱资源 | 国家实行统一规划、合理开发、有偿使用 |
| 第253条 | 文物 | 中华人民共和国境内地下、内水和领海中遗存的一切文物属于国家所有 |
| 第254条 | 国防资产 + 铁路、公路、电力设施、电信设施和油气管道等基础设施 | 国防资产属于国家所有；基础设施依照法律规定为国家所有的，属于国家所有 |

**野生动植物资源的归属**：

| 类型 | 归属 |
|------|------|
| 野生动物资源 | 只能成为国家所有权的客体（依《野生动物保护法》第3条） |
| 野生植物资源 | 国家重点保护野生植物和地方重点保护野生植物；属于国家所有 |

**国家文物所有权的5类情形**（依《文物保护法》第5条）：

| 情形 | 内容 |
|------|------|
| 1 | 中华人民共和国境内地下、内水和领海中遗存的一切文物 |
| 2 | 古文化遗址、古墓葬、石窟寺 |
| 3 | 国家指定保护的纪念建筑物、古建筑、石刻、壁画、近代现代代表性建筑等不可移动文物（除国家另有规定的以外） |
| 4 | 中国境内出土的文物（国家另有规定的除外） |
| 5 | 国有文物收藏单位以及其他国家机关、部队和国有企业、事业组织等收藏、保管的文物；国家征集、购买的文物；公民、法人和其他组织捐赠给国家的文物 |

### 三、第255-257条·国家所有权的行使主体

| 条文 | 行使主体 | 权利内容 |
|------|---------|---------|
| 第255条 | 国家机关 | 对其直接支配的不动产和动产，享有占有、使用以及依照法律和国务院的有关规定处分的权利 |
| 第256条 | 国家举办的事业单位 | 对其直接支配的不动产和动产，享有占有、使用以及依照法律和国务院的有关规定**收益、处分**的权利 |
| 第257条 | 国家出资的企业 | 由国务院、地方人民政府依照法律、行政法规规定分别代表国家履行**出资人职责**，享有出资人权益 |

**国家出资企业的6类范围**：

| 类型 | 内容 |
|------|------|
| 1 | 资产完全归国家所有、不具有公司形态的企业法人 |
| 2 | 国有独资公司 |
| 3 | 国有控股企业 |
| 4 | 国有参股企业 |
| 5 | 中外合资经营企业 |
| 6 | 中外合作经营企业 |

### 四、第258-259条·国有财产的保护与监管责任

#### 第258条·国家财产的保护

**禁止行为**（5类）：

| 行为 | 含义 |
|------|------|
| **侵占** | 以非法占有为目的，将其经营、管理的国有财产非法占为己有 |
| **哄抢** | 以非法占有为目的，组织、参与多人一起强行抢夺国有财产 |
| **私分** | 违反国家关于国有财产分配管理规定，以单位名义将国有财产按人头分配给单位全部或部分职工 |
| **截留** | 违反国家关于国有资金等国有财产拨付、流转的决定，擅自将经手的有关国有财产据为己有或挪作他用 |
| **破坏** | 故意毁坏国有财产，影响其发挥正常功效 |

#### 第259条·国有财产管理监督责任

**机构及其工作人员的职责**：
- 依法加强对国有财产的管理、监督
- 促进国有财产保值增值
- 防止国有财产损失
- 滥用职权、玩忽职守造成损失的，依法承担法律责任

**多发性违法违规行为**（违反国有财产管理规定）：

| 情形 | 内容 |
|------|------|
| 企业改制、合并分立、关联交易等过程中 | 低价转让、合谋私分、擅自担保 |
| 其他方式 | 造成国有财产损失 |

**法律责任体系**：

| 责任类型 | 法律依据 |
|---------|---------|
| 民事责任 | 《企业国有资产法》第70、72条；相关民事行为无效 |
| 行政责任 | 《企业国有资产法》第69、71条；依法给予处分 |
| 刑事责任 | 《刑法》第165-169条、第396-397条 |

## 第二部分 集体所有权（Articles 260-265）

### 一、第260条·集体财产的范围

#### 法条原文

> 第二百六十条　集体所有的不动产和动产包括：
> （一）法律规定属于集体所有的土地和森林、山岭、草原、荒地、滩涂；
> （二）集体所有的建筑物、生产设施、农田水利设施；
> （三）集体所有的教育、科学、文化、卫生、体育等设施；
> （四）集体所有的其他不动产和动产。

#### 核心释义

**集体财产4大类**：

| 类型 | 内容 | 来源 |
|------|------|------|
| 1. 自然资源 | 土地和森林、山岭、草原、荒地、滩涂 | 集体自己出资兴建 + 国家拨给或捐赠 |
| 2. 生产设施 | 集体所有的建筑物、生产设施、农田水利设施 | 同上 |
| 3. 公益设施 | 教育、科学、文化、卫生、体育等设施 | 同上 |
| 4. 其他 | 集体所有的其他不动产和动产 | 同上 |

**集体所有权主体的特殊性**：

| 维度 | 集体所有权 | 共有的区别 |
|------|----------|----------|
| 性质 | 公有制 | 私有制 |
| 主体 | 集体成员集体 | 共有人（按份或共同） |
| 处分 | 不可分割 | 可分割共有财产 |
| 行使 | 通过成员权 | 直接行使 |

**集体所有 vs 国家所有的差异**：

| 标的 | 一般原则 | 例外 |
|------|---------|------|
| **土地**（农村和城市郊区） | 农民集体所有 | 法律规定属于国家所有的除外 |
| **森林、草原** | 国家所有 | 法律规定属于集体所有的除外 |

### 二、第261条·农民集体所有 + 5项法定议定事项

#### 法条原文

> 第二百六十一条　农民集体所有的不动产和动产，属于本集体成员集体所有。
>
> 下列事项应当依照法定程序经本集体成员决定：
> （一）土地承包方案以及将土地发包给本集体以外的组织或者个人承包；
> （二）个别土地承包经营权人之间承包地的调整；
> （三）土地补偿费等费用的使用、分配办法；
> （四）集体出资的企业的所有权变动等事项；
> （五）法律规定的其他事项。

#### 核心释义

**"本集体成员集体所有"的4个特征**：

| 特征 | 内容 |
|------|------|
| 1 | 本集体的成员享有对本集体财产的集体所有权，不是每一个集体成员单独享有的所有权 |
| 2 | 本集体的成员享有依法定程序对本集体事务的集体管理权 |
| 3 | 本集体的成员享有依法定程序对本集体利益的集体分享权 |
| 4 | 本集体的成员享有的集体所有权不等于本集体成员共同共有 |

**民主议定程序**：
- 村民会议**2/3 以上成员**或**2/3 以上村民代表**同意
- 特殊情形（承包地调整）还需报乡（镇）人民政府和县级人民政府农业农村、林业和草原等主管部门批准

### 三、第262条·集体所有权的行使主体

| 集体类型 | 行使主体 |
|---------|---------|
| 村农民集体所有 | 村集体经济组织或者村民委员会 |
| 村内两个以上农民集体所有 | 村内各该集体经济组织或者村民小组 |
| 乡镇农民集体所有 | 乡镇集体经济组织 |

### 四、第263-265条·城镇集体所有 + 集体财产公开 + 集体财产保护

**第263条**：城镇集体所有的不动产和动产，依照法律、行政法规的规定由本集体享有占有、使用、收益和处分的权利。

**第264条·集体财产公开制度**：

| 要素 | 内容 |
|------|------|
| 公布义务主体 | 农村集体经济组织或者村民委员会、村民小组 |
| 公布内容 | 本集体的财产状况（收支状况、债权债务、所有权变动、使用情况、分配情况） |
| 公布要求 | 依照法律、行政法规、章程和村规民约；内容简洁明了；及时；真实 |
| 集体成员权利 | 有权**查阅、复制相关资料**（《民法典》新增） |

**第265条·集体财产保护与撤销权**：

| 制度 | 内容 |
|------|------|
| **5类禁止行为** | 侵占、哄抢、私分、破坏、非法查封扣押冻结没收 |
| **撤销权** | 农村集体经济组织、村民委员会或者其负责人作出的决定侵害集体成员合法权益的，受侵害的集体成员可以请求人民法院予以撤销 |

### 典型案例

#### 马某与甘肃省天水市秦州区某居民委员会等侵害集体经济组织成员权益纠纷案

| 项目 | 内容 |
|------|------|
| 案号 | （2022）甘05民终22号 |
| 审理法院 | 甘肃省天水市中级人民法院 |
| 裁判要点 | 集体经济组织所有的财产属本集体成员集体所有，由集体经济组织或由村民委员会、居民委员会代表集体行使所有权。居民委员会代表集体经济组织行使对集体财产的处分权，其决策程序符合法律规定，工作流程透明公开，未侵害集体经济组织成员的合法权利 |

## 第三部分 私人所有权（Articles 266-267）

### 一、第266条·私人所有权的范围

#### 法条原文

> 第二百六十六条　私人对其合法的收入、房屋、生活用品、生产工具、原材料等不动产和动产享有所有权。

#### 核心释义

**私人所有权的主体**：

| 类别 | 典型主体 |
|------|---------|
| 自然人 | 不论是否成年、是否具有行为能力 |
| 个体工商户 | 个体经济 |
| 个人独资企业 | 私营经济 |
| 合伙 | 私营经济 |
| 公司 | 中外合资经营企业、中外合作经营企业、股份有限公司、有限责任公司 |

**私有财产4大类范围**：

| 类型 | 内容 |
|------|------|
| 1. 合法收入 | 工资、稿费、专利转让费、利息、股息、红利、出租所得、转让所得、偶然所得等 |
| 2. 私人房屋 | 城镇住宅、农村宅基地上住宅、商铺、厂房等 |
| 3. 生活用品 | 家用电器、私人汽车、家具等 |
| 4. 生产工具和原材料 | 机器设备、运输工具、矿石、木材、钢铁等 |

### 二、第267条·私有财产的保护

**禁止行为**（3类）：

| 行为 | 含义 |
|------|------|
| **侵占** | 以非法占有为目的，将其保管、管理的私人财产非法占为己有 |
| **哄抢** | 以非法占有为目的，组织、参与多人一起强行抢夺他人财产 |
| **破坏** | 故意毁坏他人所有的合法财产，致使其不能发挥正常功效 |

**保护的三项基本原则**：

| 原则 | 内容 |
|------|------|
| **平等保护** | 国有企业还是民营企业、内资企业还是外资企业、大企业还是小微企业，一律平等对待 |
| **全面保护** | 保护物权、债权、股权、知识产权和其他无形财产权；保护财产权 + 人身权；保护实体权利 + 程序权利 |
| **依法保护** | 严格执行法律和司法解释；防止将经济纠纷当作刑事犯罪 |

## 第四部分 企业出资与法人财产权（Articles 268-270）

### 一、第268条·企业出资与出资人权利

#### 法条原文

> 第二百六十八条　国家、集体和私人依法可以出资设立有限责任公司、股份有限公司或者其他企业。国家、集体和私人所有的不动产或者动产投到企业的，由出资人按照约定或者出资比例享有资产收益、重大决策以及选择经营管理者等权利并履行义务。

#### 核心释义

**出资人的3项主要权利**：

| 权利 | 内容 |
|------|------|
| **资产收益权** | 通过企业盈余分配从企业获得红利；按照实缴出资比例或约定分取红利 |
| **参与重大决策** | 通过股东会/股东大会作出决议决定企业的重大行为（增加/减少注册资本、合并/分立/解散、修改章程等） |
| **选择经营管理者** | 选举/更换董事或监事，决定其薪酬；通过董事会聘任/解聘经理等高级管理人员 |

**特殊决议的表决比例**（《公司法》）：

| 事项类型 | 表决比例 |
|---------|---------|
| 一般事项 | 出席股东所持表决权过半数通过 |
| 修改章程、增加/减少注册资本、合并/分立/解散、变更公司形式 | 出席股东所持表决权**2/3 以上**通过 |

**出资人的义务**：

| 义务 | 内容 |
|------|------|
| 1 | 按期、足额缴纳出资 |
| 2 | 不得滥用股东权利损害公司或其他股东的利益 |
| 3 | 不得滥用公司法人独立地位和股东有限责任损害公司债权人的利益 |
| 4 | 不得利用关联关系损害公司利益 |
| 5 | 公司成立后，不得抽逃出资 |

### 二、第269条·法人财产权

#### 法条原文

> 第二百六十九条　营利法人对其不动产和动产依照法律、行政法规以及章程享有占有、使用、收益和处分的权利。
>
> 营利法人以外的法人，对其不动产和动产的权利，适用有关法律、行政法规以及章程的规定。

#### 核心释义

**营利法人 vs 非营利法人的区别**：

| 维度 | 营利法人 | 非营利法人 |
|------|---------|-----------|
| 目的 | 取得利润并分配给股东 | 公益或其他非营利目的 |
| 利润分配 | 分配给股东 | 不得向出资人、设立人或会员分配 |
| 设立原则 | 准则主义 | 许可主义 |
| 终止时剩余财产 | 按章程分配 | 用于公益目的或转给宗旨相同/相近法人 |

**营利法人**（依《民法典》第76条）：
- 有限责任公司
- 股份有限公司
- 其他企业法人

**营利法人以外的法人**（非营利法人，依《民法典》第87条）：
- 事业单位
- 社会团体
- 基金会
- 社会服务机构
- **特别法人**（机关法人、农村集体经济组织法人、城镇农村的合作经济组织法人、基层群众性自治组织法人）

### 三、第270条·社会团体法人、捐助法人财产保护

#### 法条原文

> 第二百七十条　社会团体法人、捐助法人依法所有的不动产和动产，受法律保护。

#### 核心释义

**捐助法人财产的3个特征**：

| 特征 | 内容 |
|------|------|
| 1. 捐助来源不受限制 | 捐助人可以是国家、一般自然人和法人；可以捐助实物或货币 |
| 2. 非生产资料性质 | 公益目的所要推进的是不能直接用货币衡量的非经济福利 |
| 3. 需要专门管理人 | 捐助法人没有成员，捐助人不能对财产行使任何权利；必须有专门的管理人 |

**捐助法人终止时的剩余财产处理**（依《民法典》第95条）：
1. 不得向出资人、设立人或会员分配
2. 按照章程或权力机构决议用于公益目的
3. 无法处理的，由主管机关主持转给宗旨相同或相近的法人
4. 向社会公告

## ⚠️ 司法适用难点

### 难点一：集体成员资格的认定

**争议**：农村集体经济组织成员资格的认定标准？

**主流观点**：
- 户籍规则（在被征地农村集体经济组织所在地具有长期、固定的生产生活 + 依法登记为常住户口）
- 经常居住规则
- 综合考量（户籍 + 生产生活 + 土地利益依赖）
- **审判实践**：综合考量，**审判经验**一般认为同时符合户籍 + 长期生产生活 + 以集体土地作为社会保障基础

### 难点二：第265条撤销权的行使

**争议**：受侵害集体成员撤销权与村民自治的关系？

**主流观点**：
- 撤销权的行使主体是**受侵害的集体成员**
- 撤销对象是农村集体经济组织、村民委员会或者其**负责人**作出的决定
- 撤销权的行使应当依据《民法典》第265条第2款
- 撤销权应在合理期限内行使

### 难点三：第258条私分国有财产的认定

**争议**：私分国有财产的主体是否仅限单位？

**主流观点**：
- **私分的主体只是单位**，一般指负有经营、管理国有财产的国家机关、国有公司、企业、事业单位、人民团体等单位
- 个人侵占、哄抢、截留国有财产的，按相应的规定处理

### 难点四：第269条法人财产权的范围

**争议**：非营利法人是否享有完整的法人财产权？

**主流观点**：
- 非营利法人也依法享有相应的法人财产权
- 但其行使受法律和章程的限制（如不得向成员分配利润）
- 终止时剩余财产的处理有特殊规则（用于公益目的）

### 难点五：野生动植物资源的归属

**争议**：野生植物资源是否一律属于国家所有？

**主流观点**：
- **不是**一律属于国家所有
- 法律规定属于国家所有的野生动植物资源属于国家所有
- 通常以列入国家保护范围为限
- 个人不能成为自然资源的所有权主体

## ❓ 实务问答

### Q1：哪些财产属于国家专有（禁止流通物）？

**A**：依《民法典》第247-254条规定：
- 第247条：矿藏、水流、海域
- 第248条：无居民海岛
- 第249条：城市的土地
- 第251条：野生动植物资源（法律规定属于国家所有的）
- 第252条：无线电频谱资源
- 第253条：文物（法律规定属于国家所有的）
- 第254条：国防资产

### Q2：集体财产保护与国有财产保护的区别？

**A**：

| 维度 | 集体财产 | 国有财产 |
|------|---------|---------|
| 禁止行为 | 侵占、哄抢、私分、破坏 | 侵占、哄抢、私分、截留、破坏 |
| 责任人员 | 未单设监管机构责任条款 | 单设第259条监管机构及工作人员责任 |
| 特殊保护 | 第265条第2款撤销权（成员对集体组织决定） | 第257条出资人权益 |

### Q3：第261条5项法定议定事项的程序？

**A**：依《民法典》第261条 + 《土地管理法》《农村土地承包法》《村民委员会组织法》：

| 步骤 | 内容 |
|------|------|
| 1 | 集体经济组织成员的村民会议**2/3 以上成员**或**2/3 以上村民代表**同意 |
| 2 | 特殊情形（如承包地调整）报乡（镇）人民政府和县级人民政府农业农村、林业和草原等主管部门批准 |
| 3 | 签订承包合同或作出决议 |

### Q4：国家出资企业的出资人职责由谁行使？

**A**：依《民法典》第257条 + 《企业国有资产监督管理暂行条例》：

| 层级 | 主体 |
|------|------|
| 中央 | 国务院代表国家履行出资人职责（关系国民经济命脉和国家安全的大型国有及国有控股、国有参股企业，重要基础设施和重要自然资源等领域） |
| 地方 | 省、自治区、直辖市人民政府和设区的市、自治州级人民政府分别代表国家对其他国有及国有控股、国有参股企业履行出资人职责 |

### Q5：私人所有权的范围与国家、集体所有权有何区别？

**A**：私人所有权的主体最为广泛，包括自然人、个体工商户、个人独资企业、合伙、中外合资经营企业、中外合作经营企业、股份有限公司、有限责任公司等。私人财产范围以**合法**为前提（非法取得的财产不受法律保护），私人所有权与国家、集体所有权受法律平等保护。

### Q6：法人财产权与股东权利的关系？

**A**：依《民法典》第268-269条：

| 维度 | 法人财产权 | 股东权利 |
|------|----------|---------|
| 主体 | 营利法人（公司） | 股东（出资人） |
| 内容 | 占有、使用、收益、处分 | 资产收益、参与重大决策、选择经营管理者 |
| 行使 | 法人机关（股东会、董事会、监事会） | 股东会/股东大会 |
| 关系 | 公司以其全部财产独立承担民事责任；股东以其出资额/股份为限承担责任 |

### Q7：第270条捐助法人终止时剩余财产如何处理？

**A**：依《民法典》第95条：
1. **不得**向出资人、设立人或会员分配
2. 按照章程或权力机构决议用于公益目的
3. 无法处理的，由**主管机关**主持转给宗旨相同或相近的法人
4. 向社会公告

### Q8：第264条集体成员查阅复制权的边界？

**A**：依《民法典》第264条 + 《村民委员会组织法》：

| 边界 | 内容 |
|------|------|
| **可查阅内容** | 集体财产状况（收支、债权债务、所有权变动、使用、分配情况） |
| **权利行使方式** | 查阅、复制相关资料 |
| **行使限制** | 仅限具有集体经济组织成员资格的人 |
| **成员资格考量** | 户籍 + 长期生产生活 + 以集体土地利益作为社会保障基础 |
