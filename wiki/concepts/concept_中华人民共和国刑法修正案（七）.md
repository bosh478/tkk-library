## 章节结构
- 一、修改第一百五十一条第三款（走私国家禁止进出口货物罪）
- 二、修改第一百八十条（内幕交易罪、利用未公开信息交易罪）
- 三、修改第二百零一条（逃税罪）
- 四、在第二百二十四条后增加一条（组织、领导传销活动罪）
- 五、修改第二百二十五条第三项（非法经营罪）
- 六、修改第二百三十九条（绑架罪）
- 七、在第二百五十三条后增加一条（侵犯公民个人信息罪）
- 八、在第二百六十二条之一后增加一条（组织未成年人进行违反治安管理活动罪）
- 九、在第二百八十五条中增加两款（非法获取计算机信息系统数据罪、非法控制计算机信息系统罪、提供侵入、非法控制计算机信息系统程序工具罪）
- 十、在第三百一十二条中增加一款（单位犯掩饰、隐瞒犯罪所得罪）
- 十一、修改第三百三十七条第一款（妨害动植物防疫检疫罪）
- 十二、修改第三百七十五条（非法生产、买卖武装部队制式服装罪，伪造盗窃买卖非法提供使用武装部队专用标志罪）
- 十三、在第三百八十八条后增加一条（利用影响力受贿罪）
- 十四、修改第三百九十五条第一款（巨额财产来源不明罪）
- 十五、本修正案自公布之日起施行（2009年2月28日）

## 量刑档次

### 走私国家禁止进出口货物罪（第151条第3款）
- 档1：走私珍稀植物及其制品/其他禁止进出口货物、物品 → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金

### 内幕交易、泄露内幕信息罪（第180条）
- 档1：情节严重 → 5年以下有期徒刑或拘役，并处或单处违法所得1倍以上5倍以下罚金
- 档2：情节特别严重 → 5年以上10年以下有期徒刑，并处违法所得1倍以上5倍以下罚金

### 利用未公开信息交易罪（第180条第4款）
- 档1：情节严重 → 依照第一款的规定处罚（5年以下/5年以上10年以下）

### 逃税罪（第201条）
- 档1：数额较大并且占应纳税额10%以上 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大并且占应纳税额30%以上 → 3年以上7年以下有期徒刑，并处罚金

### 组织、领导传销活动罪（第224条之一）
- 档1： → 5年以下有期徒刑或拘役，并处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金

### 非法经营罪（第225条第3项）
- 档1：未经批准非法经营证券、期货、保险业务/非法从事资金支付结算业务 → 5年以下有期徒刑或拘役，并处或单处违法所得1倍以上5倍以下罚金
- 档2：情节特别严重 → 5年以上有期徒刑，并处违法所得1倍以上5倍以下罚金

### 绑架罪（第239条）
- 档1：勒索财物或绑架人质 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产
- 档2：情节较轻 → 5年以上10年以下有期徒刑，并处罚金
- 档3：致使被绑架人死亡/杀害被绑架人 → 死刑，并处没收财产

### 侵犯公民个人信息罪（第253条之一）
- 档1：出售或非法提供公民个人信息，情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：窃取或非法获取，按前款处罚

### 组织未成年人进行违反治安管理活动罪（第262条之二）
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 非法获取计算机信息系统数据、非法控制计算机信息系统罪（第285条第2款、第3款）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 提供侵入、非法控制计算机信息系统程序、工具罪（第285条第3款）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 妨害动植物防疫检疫罪（第337条）
- 档1：引起重大动植物疫情/有引起疫情危险，情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金

### 非法生产、买卖武装部队制式服装罪（第375条第2款）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金

### 伪造、盗窃、买卖、非法提供、使用武装部队专用标志罪（第375条第3款）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 利用影响力受贿罪（第388条之一）
- 档1：数额较大或有其他较重情节 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大或有其他严重情节 → 3年以上7年以下有期徒刑，并处罚金
- 档3：数额特别巨大或有其他特别严重情节 → 7年以上有期徒刑，并处罚金或没收财产

### 巨额财产来源不明罪（第395条第1款）
- 档1：差额巨大 → 5年以下有期徒刑或拘役
- 档2：差额特别巨大 → 5年以上10年以下有期徒刑
