# 机动车交通事故 · 被告抗辩·车辆所有人与保险公司（第1册）

> **位置**：第四部分 二 车辆所有人 + 三 保险公司的抗辩审查（行 6233–6385）
> **核心条文**：《民法典》第一千二百零九条至第一千二百一十七条 + 《保险法》第十七条（免责条款提示说明）

## 一、原文逐句（L4 段级提取）

### 1.1 二 车辆所有人的抗辩（行 6235–6287）

**1.1.1 (一) 对责任主体的抗辩（7 种情形）**

| 情形 | 处理 |
|------|------|
| 租用/借用 | 审查所有人/管理人**是否有过错**（行 6237–6241） |
| 未经允许使用 | 同上（行 6243–6245） |
| 盗窃/抢劫/抢夺 | 所有人**不承担责任**（行 6247–6251） |
| 挂靠 | 挂靠人 + 被挂靠人**连带责任**（行 6253–6257） |
| 转让 | **最后一次转让并交付的受让人**承担；重点审查转让真实性，避免**顶包**（行 6259–6263） |
| 被套牌 | 套牌方承担；**被套牌方同意套牌的**承担**连带责任**（行 6265–6269） |
| 拼装/报废 | **所有转让人和受让人连带责任**（行 6271–6275） |

**1.1.2 (二) 对责任构成的抗辩**（行 6277–6281）：

> 同侵权人对责任构成的抗辩。

**1.1.3 (三) 对赔偿项目的抗辩**（行 6283–6287）：

> 详见原告诉请的审查。

### 1.2 三 保险公司的抗辩（行 6289–6385）

**1.2.1 (一) 交强险对于事故的抗辩**（行 6291–6309）

- **事故真实性、因果关系异议**（行 6293–6297）：审查事故是否真实 + 因果关系 + **举证责任的分配**。
- **已赔偿被保险人**（行 6299–6303）：**抗辩无效**。被保险人未赔偿第三者情况下，保险人即使已先行赔付被保险人，仍应赔偿第三者，**嗣后可向被保险人追偿**。
- **被保险人放弃索赔**（行 6305–6309）：**抗辩无效**，保险公司**不能免除**赔偿责任。

**1.2.2 (二) 交强险对于被保险人（驾驶人）的抗辩**（行 6311–6327）

- **驾驶资格受限**（行 6313–6317）：无证 / 未取得相应资格 / 酒驾 / 毒驾 / 驾驶员故意——交强险范围内**先行赔付 + 赔付后追偿权**。
- **故意制造交通事故**（行 6319–6321）：同驾驶资格受限审查要点。
- **驶离现场**（行 6323–6327）：未及时报案驶离或逃逸 → 交强险**仍应当赔偿**。

**1.2.3 (三) 交强险对于被保险车辆的抗辩**（行 6329–6359）

- **被盗抢期间事故**（行 6331–6335）：交强险**先赔 + 追偿**。
- **送修期间事故**（行 6337–6341）：交强险**应当赔偿**。
- **超载/改装/改变使用性质**（行 6343–6347）：交强险**应当赔偿**，但可要求被保险人**补足差额保费**。
- **所有权变动**（行 6349–6353）：交强险**应当赔偿**。
- **临时牌照过期**（行 6355–6359）：交强险**应当赔偿**。

**1.2.4 (四) 交强险对于受害人的抗辩**（行 6361–6379）

- **被侵权人是车上人员**（行 6363–6367）：**含上下车过程**，不是交强险第三者范畴 → **不予赔偿**。
- **被侵权人是投保人**（行 6369–6373）：投保人允许的驾驶人致害 → 交强险**应予赔偿**。
- **单方委托鉴定评估**（行 6375–6379）：属一方举证内容，由法院结合双方证据综合确定是否采信。**疑点** → 重新委托司法鉴定。

**1.2.5 (五) 商业三者险对于免责条款的抗辩**（行 6381–6385）

> 依据为商业三者险合同。原则：先审查**免责条款是否生效**（满足**提示与说明**要求才生效）→ 再审查**免责事实是否成立**（详见第五部分"商业三者险责任的认定"）。

## 三、实务问答（FAQ）

> **Q1: 车辆被盗抢期间发生事故责任？**
> 答：车辆所有人不承担责任（行 6251）。保险公司交强险**先赔 + 追偿**（行 6335）。

> **Q2: 套牌车致害责任？**
> 答：套牌方承担；**被套牌方同意套牌的**承担**连带责任**（行 6269）。

> **Q3: 已赔付被保险人后还能拒赔第三者吗？**
> 答：不能。**抗辩无效**，仍应赔偿第三者，**嗣后可向被保险人追偿**（行 6301–6303）。

> **Q4: 驶离现场/逃逸交强险赔不赔？**
> 答：**仍应当赔偿**（行 6327）。

> **Q5: 车上人员（含上下车）能否请求交强险？**
> 答：**不能**，不是交强险第三者的范畴（行 6367）。

> **Q6: 商业三者险免责审查 2 步？**
> 答：(1) 免责条款**提示与说明**生效；(2) 免责**事实成立**（行 6385）。
