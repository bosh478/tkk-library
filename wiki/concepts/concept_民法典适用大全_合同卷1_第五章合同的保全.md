# 民法典合同编第五章【合同的保全】综合

## 章节目录

本章共 8 条（Articles 535-542），规定合同保全的两大制度：**债权人代位权**（第535-537条）+ **债权人撤销权**（第538-542条）。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第535条 | 债权人代位权 | 怠于行使到期债权 |
| 第536条 | 代位保存权 | 保存行为 |
| 第537条 | 代位权行使效果 | 直接受偿规则 |
| 第538条 | 撤销权·无偿行为 | 放弃/无偿转让 |
| 第539条 | 撤销权·有偿行为 | 明显不合理低价/高价 |
| 第540条 | 撤销权行使范围 | 必要费用负担 |
| 第541条 | 撤销权除斥期间 | 1年/5年 |
| 第542条 | 撤销权行使效果 | 财产返还 |

## 一、债权人代位权（第535条）

### 法条原文

> 第五百三十五条　因债务人**怠于行使其债权**或者与该债权有关的**从权利**，影响债权人的到期债权实现的，债权人可以向人民法院请求**以自己的名义代位行使**债务人对相对人的权利，但是该权利专属于债务人自身的除外。
>
> 代位权的行使范围以债权人的到期债权为限。债权人行使代位权的必要费用，由债务人负担。
>
> 代位权成立的，由次债务人向债权人履行。

### 代位权的构成要件

| 要件 | 内容 |
|------|------|
| **1. 债权合法有效** | 债权人对债务人的债权合法有效 |
| **2. 债权已到期** | 债权人的债权已**到期** |
| **3. 债务人怠于行使权利** | 债务人**怠于行使**其对相对人的债权或从权利 |
| **4. 影响债权人到期债权实现** | 怠于行使权利**影响**债权人到期债权的实现 |
| **5. 权利非专属** | 该权利**不专属于**债务人自身 |

### "怠于行使"的判断

"怠于行使"是指债务人**应当行使**其权利且**能够行使**而**不行使**。

**判断标准**：
- 客观上有行使权利的可能性
- 主观上无正当理由不行使
- **不以诉讼/仲裁为限**：第535条第1款扩张解释为"以诉讼或者仲裁的方式"（《合同编通则解释》第33条对怠于行使的扩张规定）

### 代位权行使的禁止

**专属权利不得代位**：
- **人身权利**：抚养费、赡养费、抚养费请求权、人格权请求权等
- **劳动权利**：劳动报酬请求权（虽非绝对，但有限制）
- **公法权利**：行政诉讼权、选举权等

### 代位权行使的范围

- 范围以**债权人的到期债权**为限
- **必要费用**（诉讼费、律师费、差旅费等）由**债务人**负担

### 代位权的程序

```
代位权行使
├─ 1. 债权人对**相对人**提起代位权诉讼（被告为相对人，次债务人）
├─ 2. 法院审理代位权是否成立
├─ 3. 代位权成立的：
│   ├─ 3a. **次债务人向债权人履行**（直接受偿规则）
│   └─ 3b. 债权人在代位权范围内受偿
└─ 4. 超出部分归属于债务人
```

## 二、代位保存权（第536条）

### 法条原文

> 第五百三十六条　债权人的债权**到期前**，债务人的权利可能因**未及时行使**而**消灭**或者**受影响**的，债权人可以代位向债务人的相对人请求**履行**，或者向人民法院请求**采取保全措施**。

### 代位保存权与代位权的区别

| 维度 | 代位权（第535条） | 代位保存权（第536条） |
|------|------------------|---------------------|
| **债权是否到期** | 债权人的债权**已到期** | 债权人的债权**未到期** |
| **情形** | 影响债权人到期债权实现 | 债务人的权利可能因未及时行使而**消灭或受影响** |
| **行使方式** | 代位行使 | **请求履行** 或 **请求保全** |

### 代位保存权的典型情形

| 情形 | 适用 |
|------|------|
| 债务人对相对人的**诉讼时效即将届满** | 债权人可代位向相对人请求履行或起诉 |
| 债务人对相对人的权利**可能因时效经过而消灭** | 同上 |
| 债务人对相对人的权利**可能被转移、毁损** | 债权人可请求保全 |

## 三、代位权行使效果（第537条）

### 法条原文

> 第五百三十七条　人民法院认定代位权成立的，由**次债务人**向**债权人**履行**清偿义务**，债权人接受履行后，债权人与债务人、债务人与相对人之间相应的权利义务**终止**。

### "直接受偿规则"（入库规则突破）

**核心规则**：代位权成立的，**次债务人直接向债权人履行**——这是**入库规则**的重大突破。

**实务意义**：
- 原《合同法》采"入库规则"——次债务人向债务人履行
- 《民法典》第537条改为"**直接受偿规则**"——次债务人直接向债权人履行
- **保护债权人利益**，避免债务人再次处分财产

### 代位权成立后的多重法律关系

```
代位权成立的法律效果
├─ 1. 次债务人 → 债权人履行（清偿义务）
├─ 2. 债权人在代位权范围内受偿
├─ 3. 债权人接受履行后：
│   ├─ 债权人与债务人之间的债权债务关系相应消灭
│   └─ 债务人与相对人之间的权利义务相应消灭
└─ 4. 超出代位权范围的部分，债务人仍可向相对人主张
```

## 四、债权人撤销权——无偿行为（第538条）

### 法条原文

> 第五百三十八条　债务人以**放弃债权**、**无偿转让财产**等方式**无偿处分**财产权益，影响债权人的债权实现的，债权人可以请求人民法院**撤销**债务人的行为。

### 无偿行为撤销权的构成要件

| 要件 | 内容 |
|------|------|
| **1. 债权合法有效** | 债权人对债务人的债权合法有效 |
| **2. 债务人有处分行为** | 债务人实施了处分财产权益的行为 |
| **3. 行为无偿** | 放弃债权 / 无偿转让财产 等 |
| **4. 影响债权实现** | 无偿处分行为**影响**债权人的债权实现 |

### 无偿处分行为的类型

| 行为类型 | 是否属于无偿处分 |
|---------|---------------|
| **放弃债权** | ✅ 属于 |
| **放弃债权担保** | ✅ 属于 |
| **放弃债权时效抗辩** | ❌ 不一定（看情形） |
| **无偿转让财产** | ✅ 属于 |
| **明显不合理的低价转让** | ❌ 不属于无偿（属第539条有偿行为） |
| **为他人债务提供担保** | ❌ 不属于无偿（看具体情形） |

### 无偿行为撤销权 vs 有偿行为撤销权

| 维度 | 无偿行为（第538条） | 有偿行为（第539条） |
|------|------------------|------------------|
| **行为性质** | 无偿 | 有偿（但价格明显不合理） |
| **主观要件** | 无需证明相对人恶意 | 需证明相对人**知道或应当知道** |
| **构成要件** | 仅需客观上影响债权实现 | 需"影响债权实现"+ "相对人恶意" |

## 五、债权人撤销权——有偿行为（第539条）

### 法条原文

> 第五百三十九条　债务人以**明显不合理的低价**转让财产、**明显不合理的高价**受让他人财产或者**为他人的债务提供担保**，影响债权人的债权实现，**相对人知道或者应当知道**该情形的，债权人可以请求人民法院撤销债务人的行为。

### 有偿行为撤销权的构成要件

| 要件 | 内容 |
|------|------|
| **1. 债权合法有效** | 债权人对债务人的债权合法有效 |
| **2. 行为类型** | 明显不合理低价转让 / 明显不合理高价受让 / 为他人债务提供担保 |
| **3. 影响债权实现** | 该行为**影响**债权人的债权实现 |
| **4. 相对人恶意** | 相对人**知道或应当知道**该情形 |

### "明显不合理"的判断

**判断标准**：依《合同编通则解释》第42条：
- **明显不合理的低价**：转让价格**低于市场价格的70%**
- **明显不合理的高价**：受让价格**高于市场价格的130%**
- 参考市场价格：政府指导价 / 市场参考价 / 中介机构评估价 / 同类标的同期价格

### "为他人债务提供担保"的特别规则

依第539条第2句，债务人为他人债务提供担保，影响债权人的债权实现，相对人知道或应当知道的，可以撤销。

**例外情形**（依《合同编通则解释》第43条）：
- 为自己债务提供担保不影响债权人实现
- 担保金额**显著低于**主债务金额
- 担保设定后剩余责任财产仍足以清偿债务

## 六、撤销权行使范围（第540条）

### 法条原文

> 第五百四十条　撤销权的行使范围以**债权人的债权**为限。债权人行使撤销权的**必要费用**，由**债务人**负担。

### 撤销权行使的范围限制

| 维度 | 规则 |
|------|------|
| **行使范围** | 以**债权人的债权**为限 |
| **必要费用** | 律师费、诉讼费、差旅费、评估费等，由**债务人**负担 |
| **第三人受益** | 受益人已支付合理价款的，不能撤销 |

## 七、撤销权除斥期间（第541条）

### 法条原文

> 第五百四十一条　撤销权**自债权人知道或者应当知道**撤销事由之日起**一年内**行使。**自债务人的行为发生之日起五年内**没有行使撤销权的，撤销权消灭。

### 除斥期间的双重限制

| 期限类型 | 起算点 | 长度 |
|---------|--------|------|
| **1年**（相对除斥期间） | 自债权人**知道或应当知道**撤销事由之日起 | **1年** |
| **5年**（绝对除斥期间） | 自债务人的**行为发生之日起** | **5年** |

**法律效果**：除斥期间届满，**撤销权绝对消灭**（不中止、中断、延长）。

### 撤销权期间的适用

```
撤销权行使期间
├─ 1. 债权人知道或应当知道撤销事由 → 1年内行使
└─ 2. 任何情形 → 行为发生后 5年内必须行使
```

**举例**：
- 2020年1月1日债务人实施处分行为
- 2020年6月1日债权人知道撤销事由
- 撤销权期间：**至2021年6月1日（1年）** AND **至2025年1月1日（5年）**——两者取**先到**者

## 八、撤销权行使效果（第542条）

### 法条原文

> 第五百四十二条　债务人影响债权人的债权实现的行为被撤销的，**自始无效**。
>
> 债务人、相对人及受益人因此取得的财产，应当**返还**；不能返还或者没有必要返还的，**折价补偿**。
>
> 债务人行使撤销权所支付的必要费用，由债务人和相对人或者受益人**分担**。

### 撤销权效果的三层含义

| 层面 | 内容 |
|------|------|
| **1. 行为效力** | 撤销后**自始无效**（溯及既往） |
| **2. 财产返还** | 取得的财产应当**返还**；不能返还或没必要返还的**折价补偿** |
| **3. 必要费用** | 行使撤销权的必要费用，由**债务人和相对人或受益人分担** |

### 自始无效的具体表现

- 债务人与相对人之间的**转让行为自始无效**
- 财产应当**恢复原状**
- **多重转让**情形：债务人将财产转让给 A，A 又转让给 B，债权人撤销后，A 与 B 之间的转让是否撤销？
  - 主流观点：依具体情况判断善意取得规则
  - B 善意取得的，撤销对 B 不发生效力，债权人只能向 A 主张损害赔偿

## 九、代位权与撤销权的对比

| 维度 | 代位权（第535条） | 撤销权（第538-539条） |
|------|------------------|------------------|
| **标的** | 债务人对相对人的**权利** | 债务人对相对人的**行为** |
| **目的** | 保全**责任财产** | 恢复**责任财产** |
| **行使条件** | 债务人怠于行使 | 债务人不当处分 |
| **程序** | 以自己的名义代位行使 | 请求法院撤销 |
| **直接受偿** | ✅ 直接受偿 | ❌ 入库规则（向债务人返还） |
| **除斥期间** | 一般诉讼时效（5年） | 1年/5年 |

## ❓ 实务问答精选

> **问**：代位权与撤销权的核心区别？
>
> **答**：
> - **代位权**：债务人**怠于行使**权利 → 代位行使 → **直接受偿**
> - **撤销权**：债务人**不当处分**财产 → 撤销行为 → **入库规则**（向债务人返还）

> **问**：代位权成立时，谁向谁履行？
>
> **答**：依第537条"**直接受偿规则**"：**次债务人直接向债权人履行**。这是《民法典》对原《合同法》"入库规则"（次债务人向债务人履行）的重大修改。

> **问**：撤销权的双重除斥期间是什么？
>
> **答**：依第541条：
> - **1 年**：自债权人**知道或应当知道**撤销事由之日起
> - **5 年**：自债务人的**行为发生之日起**
>
> **两者取先到者**。除斥期间届满，撤销权**绝对消灭**。

> **问**：债权人撤销权与破产撤销权的区别？
>
> **答**：
> - **债权人撤销权**（第538-539条）：普通民事程序中的撤销权，依民法典合同编规定
> - **破产撤销权**（《企业破产法》第31-32条）：破产程序中的撤销权，**管理人**行使，**6 个月/1 年**期间
>
> **重叠情形**：债务人进入破产程序的，依《企业破产法》处理。

> **问**：代位保存权与代位权的区别？
>
> **答**：
> - **代位权**：债权人对债务人的债权**已到期** + 债务人怠于行使影响债权实现
> - **代位保存权**：债权人对债务人的债权**未到期** + 债务人的权利可能因未及时行使而**消灭或受影响**

> **问**：明显不合理低价的标准是什么？
>
> **答**：依《合同编通则解释》第42条，**明显不合理的低价**指**低于市场价格70%**；**明显不合理的高价**指**高于市场价格130%**。参考市场价格：政府指导价 / 中介评估价 / 同类标的同期价格。
