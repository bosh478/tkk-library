# 民法典适用大全·物权卷（一）

## 内容定位

本卷是物权卷第一册，围绕《民法典》第205条（2021-01-01 施行 / 2021-01-01 最新修正）至第296条，涵盖物权编通则（一般规定、物权的设立变更转让消灭、物权的保护）和所有权前半部分（一般规定、国家所有权和集体所有权、私人所有权、建筑物区分所有权）。物权编是民法典的重要组成部分，确立了物权法定原则、公示公信原则等基本制度。

## 章节结构总览

### 第一分编 通则

#### 第一章 一般规定（第205-208条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第205条 | 物权编的调整范围 | 因物的归属和利用产生的民事关系 |
| 第206条 | 基本经济制度 | 坚持公有制为主体、多种所有制经济共同发展；保障一切市场主体的平等法律地位和发展权利 |
| 第207条 | 物权平等保护 | 国家、集体、私人的物权受法律平等保护 |
| 第208条 | 物权公示原则 | 不动产物权的设立、变更、转让和消灭，应当依照法律规定登记；动产物权的设立和转让，应当依照法律规定交付 |

#### 第二章 物权的设立、变更、转让和消灭（第209-232条）

**第一节 不动产登记（第209-223条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第209条 | 不动产物权登记生效 | 不动产物权的设立、变更、转让和消灭，经依法登记，发生效力；未经登记，不发生效力 |
| 第210条 | 不动产登记机构 | 由不动产所在地的登记机构办理 |
| 第211条 | 登记申请材料 | 当事人应提供权属证明和不动产界址、面积等必要材料 |
| 第212条 | 登记机构职责 | 查验权属证明、询问申请人、如实及时登记等 |
| 第213条 | 登记机构禁止行为 | 不得要求对不动产进行评估、不得以年检等名义进行重复登记等 |
| 第214条 | 物权变动时间 | 不动产物权的设立、变更、转让和消灭，依照法律规定应当登记的，自记载于不动产登记簿时发生效力 |
| 第215条 | 合同效力与物权变动区分 | 当事人之间订立的不动产物权合同，自合同成立时生效；未办理物权登记的，不影响合同效力 |
| 第216条 | 不动产登记簿 | 不动产登记簿是物权归属和内容的根据 |
| 第217条 | 不动产权属证书 | 不动产权属证书是权利人享有该不动产物权的证明 |
| 第218条 | 登记资料查询 | 权利人、利害关系人可以查询、复制不动产登记资料 |
| 第219条 | 登记资料保密 | 不动产登记机构不得泄露、非法使用不动产登记资料 |
| 第220条 | 更正登记和异议登记 | 权利人、利害关系人可申请更正登记；利害关系人可申请异议登记 |
| 第221条 | 预告登记 | 当事人签订买卖房屋或其他不动产物权的协议，可申请预告登记 |
| 第222条 | 登记错误赔偿 | 因登记错误造成他人损害的，登记机构应承担赔偿责任 |
| 第223条 | 登记收费 | 不动产登记费按件收取，不得按照不动产面积、体积等比例收取 |

**第二节 动产交付（第224-228条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第224条 | 动产交付生效 | 动产物权的设立和转让，自交付时发生效力 |
| 第225条 | 特殊动产登记对抗 | 船舶、航空器和机动车等的物权变动，未经登记不得对抗善意第三人 |
| 第226条 | 简易交付 | 动产物权设立和转让前，权利人已经占有该动产的，物权自民事法律行为生效时发生效力 |
| 第227条 | 指示交付 | 动产物权设立和转让前，第三人占有该动产的，负有交付义务的人可以通过转让请求第三人返还原物的权利代替交付 |
| 第228条 | 占有改定 | 动产物权转让时，双方又约定由出让人继续占有该动产的，物权自该约定生效时发生效力 |

**第三节 其他规定（第229-232条）**

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第229条 | 法律文书、征收决定的物权变动 | 因人民法院、仲裁机构的法律文书或人民政府的征收决定等导致的物权变动，自法律文书或征收决定等生效时发生效力 |
| 第230条 | 继承取得物权 | 因继承取得物权的，自继承开始时发生效力 |
| 第231条 | 事实行为取得物权 | 因合法建造、拆除房屋等事实行为设立或消灭物权的，自事实行为成就时发生效力 |
| 第232条 | 非依法律行为取得物权的处分 | 处分前述不动产物权，依照法律规定需要办理登记的，未经登记，不发生物权效力 |

#### 第三章 物权的保护（第233-239条）

| 条文 | 主题 | 核心要点 |
|------|------|----------|
| 第233条 | 物权保护途径 | 和解、调解、仲裁、诉讼等 |
| 第234条 | 确认物权 | 因物权的归属、内容发生争议的，利害关系人可以请求确认权利 |
| 第235条 | 返还原物 | 无权占有不动产或动产的，权利人可以请求返还原物 |
| 第236条 | 排除妨碍、消除危险 | 妨害物权或可能妨害物权的，权利人可以请求排除妨碍或消除危险 |
| 第237条 | 修理、重作、更换或恢复原状 | 造成不动产或动产毁损的，权利人可以请求修理、重作、更换或恢复原状 |
| 第238条 | 损害赔偿 | 侵害物权造成损害的，权利人可以请求损害赔偿 |
| 第239条 | 物权保护方式的适用 | 可以单独适用，也可以根据权利被侵害的情形合并适用 |

|------|------|----------|

## 核心制度解读

### 一、物权平等保护原则（第207条）

**制度意义**：国家、集体、私人的物权受法律平等保护，任何组织或者个人不得侵犯。这是民法典物权编的核心原则之一，体现了对各类市场主体财产权的平等保护。

### 二、不动产登记制度（第209-223条）

**登记生效主义**：不动产物权的设立、变更、转让和消灭，经依法登记发生效力；未经登记不发生效力（第209条）。

**合同效力与物权变动区分**（第215条）：当事人之间订立的不动产物权合同自合同成立时生效，未办理物权登记不影响合同效力。这是物权行为与债权行为区分原则的体现。

**预告登记**（第221条）：当事人签订买卖房屋或其他不动产物权的协议，为保障将来实现物权，可申请预告登记。预告登记后，未经预告登记权利人同意处分该不动产的，不发生物权效力。

### 三、征收征用制度（第243-245条）

**征收**（第243条）：为了公共利益需要，依照法律规定的权限和程序可以征收集体所有的土地和组织、个人的房屋及其他不动产。应依法给予征收补偿，维护被征收人的合法权益。

**征用**（第245条）：因抢险救灾、疫情防控等紧急需要，可征用组织、个人的不动产或动产。使用后应返还被征用物；毁损、灭失的应给予补偿。

### 四、建筑物区分所有权（第271-287条）

**三元结构**：专有部分所有权 + 共有部分共有权 + 共同管理权。

**业主共同决定事项**（第278条）：筹集建筑物及其附属设施的维修资金、改建重建建筑物等重大事项需经参与表决专有部分面积四分之三以上的业主且参与表决人数四分之三以上的业主同意。

## ❓ 常见问题

> 问：未办理不动产登记的物权合同是否有效？
> 答：有效。当事人之间订立的不动产物权合同自合同成立时生效，未办理物权登记不影响合同效力（第215条）。但未登记不发生物权变动效力。

> 问：业主如何决定小区重大事项？
> 答：业主共同决定事项应当由专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决。筹集维修资金、改建重建等重大事项需经参与表决的四分之三以上同意（第278条）。

> 问：车位、车库归谁所有？
> 答：建筑区划内规划用于停放汽车的车位、车库的归属，由当事人通过出售、附赠或出租等方式约定。但应首先满足业主的需要（第275-276条）。

> 问：征收补偿标准是什么？
> 征收集体所有的土地，应依法及时足额支付土地补偿费、安置补助费等费用；征收组织、个人的房屋及其他不动产，应依法给予征收补偿（第243条）。
