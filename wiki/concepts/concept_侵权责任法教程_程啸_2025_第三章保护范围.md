# 《侵权责任法教程》第三章 保护范围

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第三章 保护范围 |
| 行号范围 | 1581-2250（书籍）|
| 核心议题 | 侵权责任法所保护的民事权益范围 |
| 涵盖 | 民事权利+民事利益+不受保护的范围 |

## 🎯 核心论点

**侵权责任法的保护范围 = 民事权益 = 民事权利 + 民事利益**

**《民法典》第1165条**：
> 行为人因过错侵害他人民事权益造成损害的...

**保护范围分类**：
- 绝对权（人格权、物权、知识产权等）
- 相对权（债权）的有限保护
- 民事权利 vs 民事利益的差别保护

---

## 第一节 民事权利

## 一、人格权

### （一）物质性人格权

| 类型 | 法条 | 内容 |
|------|------|------|
| 生命权 | 第1102条 | 生命安全和生命尊严 |
| 身体权 | 第1102条 | 身体完整和行动自由 |
| 健康权 | 第1102条 | 生理心理健康 |

### （二）精神性人格权

| 类型 | 法条 |
|------|------|
| 姓名权 | 第1012、1014条 |
| 名称权 | 第1013、1014条 |
| 肖像权 | 第1018条 |
| 名誉权 | 第1024条 |
| 荣誉权 | 第1031条 |
| 隐私权 | 第1032条 |
| 个人信息权益 | 第1034条 |
| 人格尊严 | 第1091条 |
| 人身自由 | 第1091条 |

## 二、身份权

- 婚姻自主权
- 监护权
- 亲属权
- 继承权

## 三、财产权

### （一）物权

- 所有权
- 用益物权
- 担保物权
- 占有

### （二）债权

**保护限制**：
- 债权仅在特定情形下受侵权法保护
- 第三人故意侵害债权的（如恶意串通逃避债务）→ 受保护
- 第三人过失侵害债权的 → **不**受保护

### （三）知识产权

- 著作权
- 专利权
- 商标权
- 商业秘密权

---

## 第二节 民事利益

## 一、概念

**民事利益** = 尚未上升为民事权利但受法律保护的利益。

**与民事权利的区别**：

| 维度 | 民事权利 | 民事利益 |
|------|---------|----------|
| 法定性 | 法定明确 | 范围较广 |
| 位阶 | 较高 | 较低 |
| 受保护程度 | 强 | 较弱 |
| 构成要件 | 较宽 | 较严 |

## 二、典型民事利益

- 死者人格利益
- 胎儿利益（涉及遗产继承、接受赠与等）
- 占有利益
- 商业机会
- 经济利益（间接经济利益）

---

## 第三节 绝对权与相对权

## 一、绝对权的保护

**绝对权**（对世权）= 可以对抗任何第三人的权利。

**类型**：
- 物权（所有权、用益物权、担保物权、占有）
- 人格权
- 知识产权

**保护方式**：
- 任何第三人不得侵害
- 受到侵害时，绝对权人可直接请求侵权责任

## 二、相对权的有限保护

**相对权**（对人权）= 仅能对抗特定人的权利。

**典型**：债权

**保护限制**：
- 原则上**不**受侵权法保护（基于合同相对性）
- 例外：第三人故意以违背善良风俗的方式损害债权
- 第三人过失损害债权 → 不承担侵权责任

**典型情形**：
- 恶意串通逃避债务
- 故意诱使违约
- 商业秘密侵权

---

## 第四节 区分保护的实务意义

## 一、民事权利 vs 民事利益的差别保护

| 维度 | 民事权利 | 民事利益 |
|------|---------|----------|
| 范围 | 较窄 | 较广 |
| 证明责任 | 受害人证明权利受侵害 | 受害人证明利益受侵害+违法性 |
| 抗辩 | 加害人证明合法行使 | 加害人证明无过错等 |
| 赔偿 | 较广 | 较窄（仅在故意或重大过失时）|

## 二、典型案例

### （一）死者人格利益保护

**《民法典》第994条**：
> 死者的姓名、肖像、名誉、荣誉、隐私、遗体等受到侵害的，其配偶、子女、父母有权依法请求行为人承担民事责任；没有配偶、子女且父母已经死亡的，其他近亲属有权依法请求行为人承担民事责任。

### （二）商业秘密

**商业秘密** = 不为公众所知悉、能为权利人带来经济利益、具有实用性并经权利人采取保密措施的技术信息和经营信息。

**保护要件**：
- 秘密性
- 价值性
- 保密性

---

## 第五节 不在侵权责任法保护范围的对象

## 一、超出民事权益范围

- 国家利益（通过行政法/刑法保护）
- 社会公共利益（通过经济法/行政法/刑法保护）
- 宗教信仰（部分通过其他法律保护）

## 二、不予保护的情形

- 行使权利的行为
- 正当防卫
- 紧急避险
- 自愿救助他人
- 自甘冒险
- 自助行为
- 受害人故意
- 第三人行为

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **民事权益** | 民事权利+民事利益 |
| **民事权利** | 法定明确的民事权益 |
| **民事利益** | 尚未上升为权利的合法权益 |
| **绝对权**（对世权）| 可对抗任何第三人的权利 |
| **相对权**（对人权）| 仅能对抗特定人的权利 |
| **死者人格利益** | 死者姓名、肖像、名誉等 |
| **商业秘密** | 秘密性+价值性+保密性 |
