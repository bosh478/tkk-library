# 案件数量与标的金额均呈增长态势

> **数据来源**：上海法院 2014–2019 年统计（行 437–442）
> **总览节点**：行 437 标题；行 438 案件数据；行 440 标的额数据；行 441 排名表述

## 一、原文逐句（L4 段级提取）

### 1.1 案件数量（行 438）

> 2014年至2019年，上海法院共受理融资租赁合同纠纷一审案件27047件，审结25384件，同期结案率为93.85%。

**关键数据点**：

| 指标 | 数值 |
|------|------|
| 6 年累计受理 | 27,047 件 |
| 6 年累计审结 | 25,384 件 |
| 同期结案率 | 93.85% |

### 1.2 收案年度分布（行 438）

| 年份 | 收案数 |
|------|--------|
| 2014 | 952 |
| 2015 | 2,593 |
| 2016 | 2,975 |
| 2017 | 4,319 |
| 2018 | 5,216 |
| 2019 | 10,992 |

**趋势观察**：6 年间收案数增长 11.5 倍（952 → 10,992），2019 年单年收案数是 2014 年的 11.55 倍。

### 1.3 案件标的额（行 440）

> 从案件标的额看，收案标的总金额高达人民币577.72亿元。

| 指标 | 数值 |
|------|------|
| 6 年累计标的额 | 577.72 亿元 |
| 单年最大 | 2019 年 236.04 亿元 |
| 单年最小 | 2014 年 37.85 亿元 |

**年度标的额分布（行 440）**：

| 年份 | 标的额（亿元） |
|------|----------------|
| 2014 | 37.85 |
| 2015 | 50.45 |
| 2016 | 74.99 |
| 2017 | 63.64 |
| 2018 | 114.75 |
| 2019 | 236.04 |

### 1.4 排名（行 441）

> 案件数量与标的总金额均位居上海法院受理的一审金融商事案件第三。

**裁判要点**：融资租赁合同纠纷是上海法院 2014–2019 年一审金融商事案件中**数量第三**、**标的额第三**的双第三类案。

## 三、实务问答（FAQ）

> **Q1: 2014–2019 年上海法院融资租赁合同纠纷 6 年累计多少件？**
> 答：27,047 件一审案件（行 438），审结 25,384 件，结案率 93.85%。

> **Q2: 2019 年单年收案数是 2014 年的多少倍？**
> 答：约 11.55 倍（10,992 / 952）。

> **Q3: 融资租赁合同纠纷在上海法院金融商事案件中的排名？**
> 答：案件数量与标的总金额均位居**第三**（行 441）。
