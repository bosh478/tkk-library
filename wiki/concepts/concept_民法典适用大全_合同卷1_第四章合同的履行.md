# 民法典合同编第四章【合同的履行】综合

## 章节目录

本章共 26 条（Articles 509-534），规定合同履行制度，涵盖履行原则、履行规则、涉他合同、抗辩权体系、情势变更等核心内容。

| 节 | 法条范围 | 主题 |
|----|---------|------|
| 第一节 履行原则 | 509 | 全面履行+诚信原则+绿色原则 |
| 第二节 履行规则 | 510-524 | 内容填补、涉他合同、多数人之债 |
| 第三节 抗辩权体系 | 525-528 | 同时/先履行/不安抗辩权 |
| 第四节 履行特殊情形 | 529-532 | 履行困难、提前、部分、变化 |
| 第五节 情势变更 | 533 | 情势变更 |
| 第六节 合同监管 | 534 | 行政机关对合同的监督管理 |

## 一、合同履行原则（第509条）

### 法条原文

> 第五百零九条　当事人应当按照约定全面履行自己的义务。
>
> 当事人应当遵循诚信原则，根据合同的性质、目的和交易习惯履行通知、协助、保密等义务。
>
> 当事人在履行合同过程中，应当避免浪费资源、污染环境和破坏生态。

### 合同履行的三大原则

| 原则 | 内容 | 法条依据 |
|------|------|---------|
| **全面履行原则** | 按约定**全面**履行义务 | 第509条第1款 |
| **诚信原则** | 依合同性质、目的、交易习惯履行附随义务 | 第509条第2款 |
| **绿色原则** | 避免浪费资源、污染环境、破坏生态 | 第509条第3款 |

### 诚信原则下的附随义务

| 附随义务 | 内容 |
|---------|------|
| **通知义务** | 重要事项告知对方 |
| **协助义务** | 协助对方履行 |
| **保密义务** | 保守对方商业秘密 |
| **其他义务** | 依合同性质、目的、交易习惯确定 |

### 绿色原则的意义

**新增原则**（与原《合同法》对比）：第509条第3款新增绿色原则，要求当事人在履行合同过程中**避免浪费资源、污染环境和破坏生态**。

**意义**：将生态文明理念融入合同法，体现民事立法的时代特征。

## 二、合同内容约定不明的履行（第510-511条）

### 法条原文

> 第五百一十条　合同生效后，当事人就质量、价款或者报酬、履行地点等内容没有约定或者约定不明确的，可以协议补充；不能达成补充协议的，按照合同相关条款或者交易习惯确定。
>
> 第五百一十一条　当事人就有关合同内容约定不明确，依照前条规定仍不能确定的，适用下列规定：
> （一）质量要求不明确的，按照强制性国家标准履行；没有强制性国家标准的，按照推荐性国家标准履行；没有推荐性国家标准的，按照行业标准履行；没有国家标准、行业标准的，按照通常标准或者符合合同目的的特定标准履行。
> （二）价款或者报酬不明确的，按照订立合同时履行地的市场价格履行；依法应当执行政府定价或者政府指导价的，依照规定履行。
> （三）履行地点不明确，给付货币的，在接受货币一方所在地履行；交付不动产的，在不动产所在地履行；其他标的，在履行义务一方所在地履行。
> （四）履行期限不明确的，债务人可以随时履行，债权人也可以随时请求履行，但是应当给对方必要的准备时间。
> （五）履行方式不明确的，按照有利于实现合同目的的方式履行。
> （六）履行费用的负担不明确的，由履行义务一方负担；因债权人原因增加的履行费用，由债权人负担。

### 合同漏洞的填补规则

```
合同约定不明
├─ 1. 协议补充
├─ 2. 按合同相关条款或交易习惯确定
└─ 3. 依第511条法定规则确定（按质量/价款/地点/期限/方式/费用）
```

### 法定填补规则的要点

| 不明事项 | 法定规则 |
|---------|---------|
| **质量** | 国家标准 → 行业标准 → 通常标准/合同目的标准 |
| **价款/报酬** | 订立合同时履行地市场价格 |
| **履行地点** | 货币→接受货币方所在地；不动产→不动产所在地；其他→履行义务方所在地 |
| **履行期限** | 随时履行/随时请求+必要准备时间 |
| **履行方式** | 有利于实现合同目的的方式 |
| **履行费用** | 履行义务方负担；因债权人原因增加的由债权人负担 |

## 三、电子合同与特殊履行（第512-514条）

### 电子合同履行（第512条）

> 第五百一十二条　通过互联网等信息网络订立的电子合同的标的为交付商品并采用快递物流方式交付的，**收货人的签收时间为交付时间**。

### 政府定价、政府指导价（第513条）

> 第五百一十三条　执行政府定价或者政府指导价的，在合同约定的交付期限内政府价格调整时，按照交付时的价格计价。逾期交付标的物的，遇到价格上涨时，按照原价格执行；价格下降时，按照新价格执行。逾期提取标的物或者逾期付款的，遇到价格上涨时，按照新价格执行；价格下降时，按照原价格执行。

**逾期履行的价格规则**：

| 情形 | 价格上涨 | 价格下降 |
|------|---------|---------|
| **逾期交付**（卖方） | 按**原价格**（不利违约方） | 按**新价格**（不利违约方） |
| **逾期提取/付款**（买方） | 按**新价格**（不利违约方） | 按**原价格**（不利违约方） |

## 四、选择之债（第515-516条）

### 选择之债的概念（第515条）

> 第五百一十五条　标的有多项而债务人只需履行其中一项的，债务人享有选择权；但是，法律另有规定、当事人另有约定或者另有交易习惯的除外。

### 选择权的行使（第516条）

- 选择权**归属**：原则上**债务人**享有选择权
- 选择权的**转移**：选择权**经对方同意**可以转移
- 选择权的**行使**：选择一经作出，**不得撤销**
- 选择权的**行使期限**：无约定或不明时，**对方可以催告**债务人在合理期限内作出选择
- 选择权**不行使的后果**：选择权转移给对方（《合同编通则解释》）

## 五、按份之债与连带之债（第517-521条）

### 按份之债（第517条）

> 第五百一十七条　债权人为二人以上，标的可分，按照份额各自享有债权的，为按份债权；债务人为二人以上，标的可分，按照份额各自承担债务的，为按份债务。
>
> 按份债权人或者按份债务人的份额难以确定的，视为份额相同。

### 连带之债（第518条）

> 第五百一十八条　债权人为二人以上，部分或者全部债权人均可以请求债务人履行债务的，为连带债权；债务人为二人以上，债权人可以请求部分或者全部债务人履行全部债务的，为连带债务。

### 按份之债 vs 连带之债

| 维度 | 按份之债 | 连带之债 |
|------|---------|---------|
| **标的** | 可分 | 可分或不可分 |
| **权利/义务范围** | 各自份额内 | 任一债权人/债务人可主张/承担全部 |
| **效力独立性** | 各债权人/债务人独立 | 相互间连带 |
| **诉讼** | 各自单独诉讼 | 可任选一人或全部诉讼 |

### 连带债务的内外部关系

| 关系 | 规则 |
|------|------|
| **外部关系（债权人vs债务人）** | 债权人可向任一连带债务人请求全部履行 |
| **内部关系（债务人之间）** | 实际承担债务超过自己份额的，有权向其他连带债务人**追偿** |
| **份额确定** | 难以确定的，**视为份额相同** |

## 六、涉他合同（第522-524条）

### 向第三人履行（第522条）

> 第五百二十二条　当事人约定由债务人向第三人履行债务，债务人未向第三人履行债务或者履行债务不符合约定的，应当向债权人承担违约责任。
>
> 法律规定或者当事人约定第三人可以直接请求债务人向其履行债务，第三人未在合理期限内明确拒绝，债务人不履行债务或者履行债务不符合约定的，第三人可以请求债务人承担违约责任；债务人可以向第三人主张其对债权人的抗辩。

### 由第三人履行（第523条）

> 第五百二十三条　当事人约定由第三人向债权人履行债务，第三人不履行债务或者履行债务不符合约定的，债务人应当向债权人承担违约责任。

### 第三人代为履行（第524条）

> 第五百二十四条　债务人不履行债务，第三人对履行该债务具有合法利益的，第三人有权代为履行；但是，根据债务性质、按照当事人约定或者依照法律规定只能由债务人本人履行的除外。
>
> 第三人代为履行后，取得代位权，可以向债务人追偿。

### 涉他合同三类对比

| 类型 | 法条 | 内容 | 不履行的责任 |
|------|------|------|------------|
| **向第三人履行（不真正第三人利益合同）** | 第522条第1款 | 债务人向第三人履行 | **债务人对债权人**承担违约责任 |
| **真正的第三人利益合同** | 第522条第2款 | 第三人有履行请求权 | 第三人可请求债务人承担违约责任 |
| **由第三人履行** | 第523条 | 第三人代债务人履行 | **债务人对债权人**承担违约责任 |
| **第三人代为履行** | 第524条 | 第三人主动履行 | **第三人对债务人**有追偿权 |

## 七、抗辩权体系（第525-528条）

### 同时履行抗辩权（第525条）

> 第五百二十五条　当事人互负债务，没有先后履行顺序的，应当同时履行。一方在对方未履行之前有权拒绝其履行请求。一方在对方履行债务不符合约定时，有权拒绝其相应的履行请求。

### 先履行抗辩权（第526条）

> 第五百二十六条　当事人互负债务，有先后履行顺序，先履行一方未履行的，后履行一方有权拒绝其履行请求。先履行一方履行债务不符合约定的，后履行一方有权拒绝其相应的履行请求。

### 不安抗辩权（第527-528条）

> 第五百二十七条　应当先履行债务的当事人，有确切证据证明对方有下列情形之一的，可以中止履行：
> （一）经营状况严重恶化；
> （二）转移财产、抽逃资金，以逃避债务；
> （三）丧失商业信誉；
> （四）有丧失或者可能丧失履行债务能力的其他情形。
>
> 当事人没有确切证据中止履行的，应当承担违约责任。

> 第五百二十八条　当事人依据前条规定中止履行的，应当及时通知对方。对方提供适当担保的，应当恢复履行。中止履行后，对方在合理期限内未恢复履行能力且未提供适当担保的，视为以自己的行为表明不履行主要债务，中止履行的一方可以解除合同并可以请求对方承担违约责任。

### 三大抗辩权对比

| 抗辩权 | 行使条件 | 法律效果 |
|--------|---------|---------|
| **同时履行抗辩权** | 互负债务+无先后顺序 | 对方未履行/不完全履行时拒绝其请求 |
| **先履行抗辩权** | 互负债务+有先后顺序 | 先履行方未履行/不完全履行时拒绝 |
| **不安抗辩权** | 互负债务+有先后顺序+后履行方丧失/可能丧失履行能力 | 中止履行；通知；对方提供担保则恢复；对方不恢复则可解除 |

### 不安抗辩权的行使程序

```
不安抗辩权行使
├─ 1. 有确切证据证明对方有第527条规定情形之一
├─ 2. 中止履行
├─ 3. 及时通知对方
├─ 4. 对方在合理期限内：
│   ├─ 4a. 提供适当担保 → 恢复履行
│   └─ 4b. 未恢复履行能力 + 未提供担保 → 视为预期违约
│       └─ 中止方可以解除合同 + 请求违约责任
└─ 注意：无确切证据中止履行的，承担违约责任
```

## 八、合同履行的特殊情形（第529-532条）

### 履行困难（第529条）

- 因债权人原因**致使履行困难**的，债务人可以**主张**其后果
- 例如：标的物特定化后，因债权人原因致债务人无法履行的，债务人可主张合同目的不能实现

### 提前履行（第530条）

- 债务人**可以提前履行**，但**不损害债权人利益**的除外
- 提前履行不损害债权人利益的，债权人**不得拒绝**
- 提前履行给债权人增加的费用，由**债务人**负担

### 部分履行（第531条）

- 债务人**部分履行**的，债权人可以**拒绝**
- 但部分履行**不损害债权人利益**的，债权人**不得拒绝**
- 部分履行给债权人增加的费用，由**债务人**负担

### 当事人变化（第532条）

- 合同生效后，**当事人不得**因姓名、名称的变更或者法定代表人、负责人、承办人的变动而**不履行合同义务**——这是合同严守原则的体现。

## 九、情势变更（第533条）

### 法条原文

> 第五百三十三条　合同成立后，合同的基础条件发生了当事人在订立合同时无法预见的、不属于商业风险的重大变化，继续履行合同对于当事人一方明显不公平的，受不利影响的当事人可以与对方重新协商；在合理期限内协商不成的，当事人可以请求人民法院或者仲裁机构变更或者解除合同。
>
> 人民法院或者仲裁机构应当结合案件的实际情况，根据公平原则变更或者解除合同。

### 情势变更的构成要件

| 要件 | 内容 |
|------|------|
| **1. 时间要件** | 合同**成立后** |
| **2. 客观要件** | 合同**基础条件**发生重大变化 |
| **3. 主观要件** | 当事人**无法预见** |
| **4. 风险要件** | **不属于商业风险** |
| **5. 后果要件** | 继续履行对一方**明显不公平** |
| **6. 程序要件** | **重新协商**前置；合理期限内协商不成可请求司法变更/解除 |

### 情势变更 vs 商业风险

| 维度 | 情势变更 | 商业风险 |
|------|---------|---------|
| **可预见性** | 无法预见 | 可以预见 |
| **发生概率** | 异常变化 | 一般商业波动 |
| **继续履行后果** | 明显不公平 | 正常商业损失 |
| **法律救济** | 可以变更/解除 | 自行承担 |

### 情势变更 vs 不可抗力

| 维度 | 情势变更 | 不可抗力（第590条） |
|------|---------|-------------------|
| **客观情况** | 重大变化 | 不能预见、不能避免、不能克服 |
| **履行状态** | 可以履行但明显不公平 | 可能部分/全部不能履行 |
| **法律效果** | 变更/解除合同 | 全部/部分免责 |
| **程序** | 重新协商前置 | 通知+证明 |
| **适用范围** | 长期合同重大失衡 | 任何合同 |

### 情势变更的法律效果

| 程序 | 结果 |
|------|------|
| 1. 受不利影响方与对方**重新协商** | — |
| 2. 合理期限内协商**不成** | 请求法院/仲裁机构**变更或解除合同** |
| 3. 法院/仲裁机构依据**公平原则**裁判 | 变更合同 / 解除合同 |

**变更合同**：调整价款、履行方式、履行期限等
**解除合同**：解除合同+损害赔偿（依公平原则确定）

## 十、合同监管（第534条）

### 法条原文

> 第五百三十四条　对当事人利用合同实施危害国家利益、社会公共利益行为的，市场监督管理和其他有关行政主管部门依照法律、行政法规的规定负责监督处理。

### 合同监管的机关

| 机关 | 监管范围 |
|------|---------|
| **市场监督管理部门** | 一般合同监管、反不正当竞争、消费者权益保护 |
| **行业主管部门** | 行业特殊合同监管 |
| **金融监管部门** | 金融合同监管 |
| **税务机关** | 税务合同监管 |
| **其他行政主管部门** | 各自职责范围内的合同监管 |

### 合同监管的行为

- 利用合同实施**危害国家利益**的行为
- 利用合同实施**危害社会公共利益**的行为
- 违反**法律、行政法规**的强制性规定

## 十一、合同履行的核心制度框架

```
合同履行制度
├── 1. 履行原则
```

## ❓ 实务问答精选

> **问**：合同履行的三大原则是什么？
>
> **答**：依第509条：
> 1. **全面履行原则**：按约定全面履行义务
> 2. **诚信原则**：附随义务（通知、协助、保密）
> 3. **绿色原则**：避免浪费资源、污染环境、破坏生态（**新增**）

> **问**：合同约定不明如何处理？
>
> **答**：三步走：
> 1. 协议补充
> 2. 按合同相关条款或交易习惯确定
> 3. 仍不能确定的，依第511条法定规则（按质量/价款/地点/期限/方式/费用）

> **问**：不安抗辩权如何行使？
>
> **答**：
> 1. 有**确切证据**证明对方有第527条情形之一
> 2. **中止履行** + **及时通知**对方
> 3. 对方提供适当担保 → **恢复履行**
> 4. 对方在合理期限内未恢复履行能力且未提供担保 → 视为预期违约 → 可**解除合同** + 请求违约责任

> **问**：情势变更与商业风险、不可抗力的区别？
>
> **答**：
> - **情势变更**：合同基础条件的重大变化，**不属于商业风险**，无法预见，继续履行明显不公平 → **变更/解除**
> - **商业风险**：正常商业波动，应自行承担
> - **不可抗力**：不能预见、不能避免、不能克服 → **全部/部分免责**

> **问**：连带债务人的内部追偿规则？
>
> **答**：实际承担债务超过自己份额的连带债务人，有权就超过部分向其他连带债务人**追偿**（第519条）。份额难以确定的，**视为份额相同**（第517条）。

> **问**：情势变更的协商前置程序？
>
> **答**：第533条规定**重新协商前置**：受不利影响的当事人**应先与对方重新协商**；在合理期限内协商不成的，可以请求人民法院或仲裁机构变更或解除合同。法院/仲裁机构依**公平原则**裁判。
