## 第一部分：婚姻家庭编解释（二）的核心规则

## 一、亲子关系

### 1. 亲子关系确认与否认

**核心规则**：
- 父或母**可**向法院起诉**确认**亲子关系
- 父或母**可**向法院起诉**否认**亲子关系
- **成年子女**可独立请求确认/否认亲子关系

### 2. 亲子关系诉讼时效

**限制**：
- 否认亲子关系 → **自知道或应当知道**之日起**1 年内**行使
- 超过 1 年 → 丧失**否认权**（但**确认权**不限制）

## 二、夫妻共同财产

### 1. 夫妻共同财产范围

**《民法典》第1062条**：
> 夫妻在婚姻关系存续期间所得的下列财产，为夫妻的共同财产，归夫妻共同所有：
> （一）工资、奖金、劳务报酬；
> （二）生产、经营、投资的收益；
> （三）知识产权的收益；
> （四）继承或者受赠的财产，但是本法第一千零六十三条第三项规定的除外；
> （五）其他应当归共同所有的财产。

### 2. 夫妻共同财产的认定

**司法解释（二）的细化**：
- **职业**所得（律师、医生等执业收入）→ 共同财产
- **知识产权**收益 → 共同财产
- **股票、基金**等投资收益 → 共同财产
- **继承或受赠**（除明确表示赠与一方外）→ 共同财产

### 3. 夫妻共同财产的分割

**司法解释（二）的细化**：
- **照顾子女、女方和无过错方**原则
- **全职主妇/夫**的家务劳动贡献
- **生产、经营**的贡献
- **知识产权**的特殊分割

## 三、离婚损害赔偿

### 1. 法定情形（《民法典》第1091条）

**5 种情形**：
- 重婚
- 与他人同居
- 实施家庭暴力
- 虐待、遗弃家庭成员
- 有其他重大过错

### 2. 司法解释（二）的细化

**重大过错**的认定：
- 赌博、吸毒等恶习屡教不改
- 与他人发生不正当性关系
- 对家庭成员实施精神虐待
- 其他严重损害婚姻关系的行为

**损害赔偿范围**：
- 物质损害赔偿
- 精神损害赔偿（**可单独主张**）

## 四、家务劳动补偿

### 1. 法定依据（《民法典》第1088条）

> 夫妻一方因抚育子女、照料老年人、协助另一方工作等负担较多义务的，离婚时有权向另一方请求补偿，具体办法由双方协议；协议不成的，由人民法院判决。

### 2. 司法解释（二）的细化

**补偿考量因素**：
- 婚姻关系存续时间
- 家务劳动的具体内容
- 家务劳动对另一方工作的协助程度
- 婚姻关系存续期间的生活水平
- 离婚时双方的财产状况

**补偿方式**：
- **一次性**补偿（**不**分期）
- **实物**或**金钱**补偿

## 五、夫妻共同债务

### 1. 共同债务的认定（《民法典》第1064条）

**基于共同意思表示**：
- 双方**共同签字**或**事后追认** → 共同债务

**基于家庭日常生活需要**：
- 夫妻一方在婚姻关系存续期间以**个人名义**为家庭日常生活需要所负的债务 → 共同债务

**超出家庭日常生活需要**：
- 夫妻一方以**个人名义**超出家庭日常生活需要所负的债务 → **债权人**须证明用于夫妻共同生活、共同生产经营或者基于夫妻双方共同意思表示，否则**个人债务**

### 2. 司法解释（二）的细化

**"家庭日常生活需要"**的判断：
- 家庭**正常生活消费**的需要
- 子女**教育**支出
- 家庭成员**医疗**支出
- **合理**的住房支出
- 其他**必要**的家庭支出

**举证责任分配**：
- 债权人**初步举证**（债务真实存在）
- 主张不属于共同债务的**非举债方**须**反证**

## 第二部分：涉彩礼纠纷解释的核心规则

## 一、适用范围

**第一条**：
> 本解释所称彩礼，是指**男方**以**结婚为目的**给付给女方的**财物**。

**核心要件**：
- **给付方** = 男方（或其家庭）
- **接受方** = 女方（或其家庭）
- **目的** = **结婚**（**非**其他）
- **财物** = 价值较高的财产

## 二、彩礼返还规则

### 1. 应当返还彩礼的情形

**第三条**：
> 双方未办理结婚登记手续，**可以**请求返还按照习俗给付的彩礼。
> 双方办理结婚登记但确未共同生活，**可以**请求返还按照习俗给付的彩礼。
> 婚前给付并导致给付人生活困难，**可以**请求返还按照习俗给付的彩礼。

**3 种返还情形**：
1. **未办理结婚登记**
2. **办理结婚登记但未共同生活**
3. **婚前给付导致生活困难**

### 2. 返还数额的考量因素

**第四条**：
> 人民法院在审理涉彩礼纠纷案件中，可以根据一方给付财物的目的，综合考虑**双方共同生活的时间**、**彩礼数额**、**是否生育子女**、**离婚过错**、**当地习俗**等因素，确定是否返还以及返还的具体数额。

**5 大考量因素**：
1. **共同生活时间**（越长，返还越少）
2. **彩礼数额**（越大，返还越多）
3. **是否生育子女**（生育 → 返还减少或不予返还）
4. **离婚过错**（有过错方 → 返还减少或不予返还）
5. **当地习俗**（按当地习俗认定）

### 3. 不予返还的情形

**第五条**：
> 有下列情形之一的，人民法院可以**不予返还**彩礼：
> （一）已经办理结婚登记且**已经共同生活**的；
> （二）已经办理结婚登记且**已经生育子女**的；
> （三）双方**已经共同生活**且**彩礼已经用于共同生活**的。

## 三、彩礼与一般赠与的区分

**判断规则**：
- **以结婚为目的** → 彩礼
- **不附条件**的赠与 → 一般赠与

**重大误解的处理**：
- 误以为需支付彩礼而支付 → **可**请求返还
- 但**已共同生活**或**已生育子女** → 返还受限

## 四、彩礼范围认定

**第七条**：
> 一方主张以**习俗**给付的**财物**属于彩礼的，人民法院应当**结合给付财物的目的**、**当地习俗**、**给付财物**的价值等因素综合判断。

**典型属于彩礼的**：
- 现金（数额较大）
- 金银首饰
- 房屋、车辆等价值较高财物
- 其他以结婚为目的的财物

**不视为彩礼的**：
- 价值较小的赠与（如"见面礼"小额红包）
- 节日的礼尚往来
- 一般的人情往来

## 第三部分：实务操作要点

## 一、彩礼的认定

**证据规则**：
- 双方**书面约定**（婚约、彩礼协议等）
- 双方**聊天记录**（微信、短信等）
- **证人证言**（媒人、亲属等）
- **转账记录**（银行流水、微信转账等）
- 当地**习俗**（村委证明、邻居证言等）

## 二、共同债务与个人债务的区分

**核心判断**：
1. 债务是否**用于家庭日常生活**？
2. 是否有**夫妻共同意思表示**？
3. 是否**用于夫妻共同生活/共同生产经营**？

**举证责任**：
- 债权人承担**初步**举证责任
- 非举债方**反证**可免除共同债务

## 三、家务劳动补偿的请求

**适用情形**：
- 离婚时
- 负担较多**家庭义务**的一方
- 包括抚育子女、照料老人、协助另一方工作等

**请求时点**：
- **离婚**时一并提出
- **不**支持**婚内**主张
- **协议离婚**中可约定

**补偿数额**：
- 法院**酌情**确定
- 考量因素：婚姻时长、家务劳动量、协助程度等

## 第四部分：相关法律问题

## 一、亲子关系确认

**适用情形**：
- 父母**均**可主张
- 成年子女**独立**主张权
- **举证规则**：
  - 必要证据（出生证明、亲子鉴定等）
  - 必要鉴定（法院**可**依职权委托鉴定）
  - 亲子鉴定的**证据效力**（一般**应当**作为定案依据）

## 二、离婚损害赔偿

**请求时点**：
- 离婚**时**或离婚**后**1 年内
- **不**支持**婚内**主张

**请求主体**：
- **无过错**方
- 不能是**双方均有过错**的情形

**赔偿范围**：
- 物质损害（医疗费、误工费等）
- 精神损害（**单独**主张）

## 三、探望权

**适用情形**：
- 离婚后**不直接抚养**子女的一方
- **定期**探望
- 法院可对**拒绝协助**探望的**直接抚养方**进行罚款、拘留

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **彩礼** | 男方以结婚为目的给付女方的财物 |
| **夫妻共同财产** | 婚姻关系存续期间所得的财产 |
| **夫妻个人财产** | 一方婚前专属或婚后专属的财产 |
| **夫妻共同债务** | 共同意思表示或家庭日常生活所负债务 |
| **家务劳动补偿** | 离婚时负担较多家庭义务一方的补偿请求权 |
| **离婚损害赔偿** | 离婚时无过错方对有过错方的损害赔偿请求权 |
| **探望权** | 离婚后不直接抚养子女方的探望权利 |
| **亲子关系** | 父母与子女之间的法律关系 |
| **亲子关系确认** | 通过诉讼确定亲子关系 |
| **亲子关系否认** | 通过诉讼否认亲子关系 |
| **彩礼返还** | 解除婚约时返还彩礼的权利 |
| **家庭日常生活需要** | 夫妻共同债务的判断标准 |
