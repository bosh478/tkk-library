# 政府信息公开类案 · 疑难法律问题（第1册）

> **位置**：第六部分 政府信息公开类案疑难法律问题（行 10293–10323）
> **核心条文**：《政府信息公开条例》（2019）第二十九/三十三条 + 《信息公开司法解释》第九条

## 一、原文逐句（L4 段级提取 · 7 大疑难问题）

### 1.1 一 申请内容明确与否的判断标准（行 10295–10301）

> 2019 年《政府信息公开条例》第二十九条第二款第二项 — 申请应当包括**名称、文号或便于行政机关查询的其他特征性描述**。
>
> **"特征描述"明确性要求** = **经过检索可将原告申请的信息予以特定化**，可以是一项信息，也可以是**明确的多项信息**，**数量多少不是特定与否的判断标准**。

**概括性用语审查**（行 10301）：

> 对于申请人在申请时使用"**相关**""**所有**""**全部**""**不限于**""**包括**"等概括性用语：
> - 如行政机关认定为申请内容不明确的 → 法院应审查**上述用语是否导致申请内容不能指向特定政府信息**；
> - 实践中考虑到**兼顾申请人权利保护与行政机关工作负担** → 如果申请人要求公开的政府信息**属于一类特定信息 + 材料数量巨大** → 行政机关答复申请不明确要求申请人补正的 → **可认定行政机关的答复合法**。

### 1.2 二 非常设机构答复效力与被告确定（行 10301–10305）

> 申请人向政府机关设立的非常设机构提出申请的：
> - **设立该非常设机构的政府机关**有权作出答复；
> - 如果非常设机构**以自己名义**作出答复 + **设立该政府机关在诉讼中认可**该答复内容 → 法院可以认定**非常设机构所作答复主体适当**。

### 1.3 三 答复是否必须说明法律适用依据（行 10303–10307）

> **特殊性** = 政府信息公开行为具有不同于一般行政行为的特殊性。**不予提供**有 2 种情况：
>
> 1. **事实不能** — 政府在**客观上不存在**（未制作获取 / 遗失 / 销毁等），《政府信息公开条例》不可能穷尽所有事实上不能提供的情形。**在客观上不能提供又无对应法律条文的情形下**，只要行政机关**说理充分并有证据证明**，**法院不宜强求列明具体法律条款**，**亦不宜否定其适用法律的合法性**。
> 2. **法律不能** — 政府信息**客观存在且有条件提供**，只是由于**法律规定免予公开**才不予提供（涉国家秘密 / 商业秘密 / 个人隐私）。**在此情形下，应当写明法律依据及具体条款**，**如果未写明法律依据**，**可以认定被诉行政行为法律适用错误**。

### 1.4 四 行政机关诉讼中改变理由的处理（行 10307–10317）

> 经常发生的情况：行政机关认为答复书说理不明/不全，**在诉讼中补充说理或重新说理**。
>
> 法院审查 → 如果被诉行政行为**实体处理合法** → 视情况分别处理：
>
> 1. **答复中说明理由不全 + 诉讼中适当补充 + 补充理由符合法律** → **判决驳回诉讼请求**；
> 2. **答复时未说明理由 / 诉讼中完全改变理由 + 改变后理由成立** → **判决确认违法**；
> 3. **答复时未说理或说理不全 + 诉讼中补充/改变的理由不能成立** → **判决撤销**。

### 1.5 五 "非条例所指政府信息"的处理（行 10317–10319）

> 行政机关处理申请时，**一般应先**对申请的政府信息**是否属于《政府信息公开条例》所指的政府信息**进行判定。
>
> 例外：申请人申请公开的信息**并非政府信息** + **被申请行政机关未制作或获取** → 被告**直接答复不属于本机关公开**（**未对是否属于条例所指政府信息进行判定**）→ **没有对原告的知情权造成实际侵害** → **可以判决驳回原告的诉讼请求**。

### 1.6 六 法定期限内决定 + 超期邮寄答复书的合法性（行 10319–10323）

> 2019 年条例第三十三条 — 行政机关应当**自收到申请之日起，在法定期限内**对申请人的政府信息公开申请予以答复。
>
> **法定期限内答复的实质要求** = 行政机关在该期限内**作出政府信息公开决定 + 在法定期限内让当事人知晓决定内容**。
>
> **平衡原则**：对于行政机关**在法定期限届满前邮寄答复书的**（**以邮戳为准**）→ **可认定为行政机关的答复未超法定期限**。
>
> **例外**：因客观事由来不及寄送 → 行政机关在**答复期限届满前告知**申请人答复书内容 + **合理期限内（一般不超过 3 个工作日）及时邮寄** → **法院不宜以此为由认定行政程序违法**。

### 1.7 七 撤销答复后行政机关公开/重新答复的期限设定（行 10323–10323）

> 《信息公开司法解释》第九条：
> - 法院认定**不予公开决定错误**的：
>   - **能够判定原告申请公开的信息应予以公开** → **判决撤销 + 责令被告在一定期限内公开**；
>   - **尚需被告调查、裁量** → **判决撤销 + 责令被告在一定期限内重新答复**。
>
> **期限设置原则**：
> - **政府信息公开工作具有及时性要求** → 法院责令的公开/重新答复期限**不应超过 20 个工作日**；
> - **法院经过审理**认为行政机关可以在**更短时间内**完成 → 也可**设定少于 20 个工作日**的期限；
> - **原则上以确保申请人能够及时获取信息或者收到答复所需要的时间**作为合理期限；
> - **重新答复过程中**，行政机关依《政府信息公开条例》规定**延期答复**或**扣除向第三方征询意见所需时间**的，法院**可予支持**。

## 三、实务问答（FAQ）

> **Q1: 申请内容明确的判断？**
> 答：**经过检索可特定化**（一项或多项），**数量多少不是判断标准**（行 10299）。

> **Q2: 概括性用语的处理？**
> 答：使用"相关/所有/全部/不限于/包括"等用语 → 审查**是否导致不能指向特定信息**（行 10301）。

> **Q3: 大量材料申请不明确补正？**
> 答：可认定**行政机关答复合法**（行 10301）。

> **Q4: 事实不能 vs 法律不能？**
> 答：事实不能 → 法院**不宜强求列明法律条款**；法律不能 → **应写明法律依据**，**未写明 = 法律适用错误**（行 10305–10307）。

> **Q5: 诉讼中改变理由 3 种处理？**
> 答：补充合法 → **驳回**；完全改变且成立 → **确认违法**；补充/改变不成立 → **撤销**（行 10313–10315）。

> **Q6: 邮戳认定？**
> 答：**以邮戳为准**，**法定期限届满前邮寄** → 未超期（行 10321）。

> **Q7: 重新答复期限？**
> 答：**≤ 20 个工作日**；可更短；扣除第三方征询时间可支持（行 10323）。
