## 核心制度深度解读

### 一、公司法立法目的（第1条）

**条文原文**：为了规范公司的组织和行为，保护公司、股东和债权人的合法权益，维护社会经济秩序，促进社会主义市场经济的发展，制定本法。

**立法目的四项**：

| 项目 | 内容 |
|------|------|
| 1. 规范公司的组织和行为 | 公司法是组织法+行为法：通过确立公司的设立、变更、终止、章程、权利能力、行为能力、内部组织机构及其相互关系等作出明确规定 |
| 2. 保护公司、股东和债权人的合法权益 | 公司财产权、股东股权、债权人债权均受保护 |
| 3. 维护社会经济秩序 | 通过规范公司行为促进良好经济秩序的形成和稳定 |
| 4. 促进社会主义市场经济的发展 | 公司发展→市场经济健康发展 |

**条文演变**：本条源于1993年《公司法》第1条；2005年修订时删除"适应建立现代企业制度的需要"和"根据宪法"等内容。

### 二、公司法调整对象（第2条）

**条文原文**：本法所称公司是指依照本法在中国境内设立的有限责任公司和股份有限公司。

**公司法调整的两类公司**：

| 类型 | 股东责任 |
|------|----------|
| 有限责任公司 | 股东以其认缴的出资额为限对公司承担责任 |
| 股份有限公司 | 股东以其认购的股份为限对公司承担责任 |

**公司法不调整的经济组织**：
- 无限公司
- 两合公司
- 个人独资企业
- 合伙企业
- 个体工商户

### 三、公司法人格与股东责任形式（第3条）

**条文原文**：公司是企业法人，有独立的法人财产，享有法人财产权。公司以其全部财产对公司的债务承担责任。

有限责任公司的股东以其认缴的出资额为限对公司承担责任；股份有限公司的股东以其认购的股份为限对公司承担责任。

**两大基本原则**：

| 原则 | 内容 |
|------|------|
| 公司法人格 | 公司是企业法人；独立享有法人财产权 |
| 股东有限责任 | 股东以出资/股份为限承担责任 |

**法人财产权的内涵**：
- 股东出资形成的财产和公司经营积累的财产 → 属于公司
- 公司依法占有、使用、收益、处分
- 股东不得以个人名义独立支配、任意分割

### 四、股东权利（第4条）

**条文原文**：公司股东依法享有资产收益、参与重大决策和选择管理者等权利。

**股东三大权利**：

| 权利 | 内容 |
|------|------|
| 1. 资产收益权 | 按投入公司的资本额享有所有者的资产受益 |
| 2. 参与重大决策权 | 参与公司生产经营以及利润分配等重大问题的决策 |
| 3. 选择管理者权 | 选举公司董事、监事等管理者的权利 |

**典型案例**：庆阳市太一热力有限公司、李某某与甘肃居立门业有限责任公司盈余分配纠纷案（最高人民法院公报 2018年第8期）—— 强制盈余分配的适用条件与举证责任。

### 五、公司经营活动基本原则（第5条）

**条文原文**：公司从事经营活动，必须遵守法律、行政法规，遵守社会公德、商业道德，诚实守信，接受政府和社会公众的监督，承担社会责任。公司的合法权益受法律保护，不受侵犯。

**五项经营原则**：

| 原则 | 内涵 |
|------|------|
| 1. 守法 | 遵守法律、行政法规 |
| 2. 遵守公德 | 遵守社会公德、商业道德 |
| 3. 诚实守信 | 市场经济既是法治经济也是信用经济 |
| 4. 接受监督 | 接受政府和社会公众的监督 |
| 5. 承担社会责任 | 劳动就业、经济秩序、依法纳税、依法办社保、保护环境等 |

### 六、设立登记（第6-9条）

**第6条**：设立公司，应当依法向公司登记机关申请设立登记。符合本法规定的设立条件的，由公司登记机关分别登记为有限责任公司或者股份有限公司；不符合本法规定的设立条件的，不得登记为有限责任公司或者股份有限公司。法律、行政法规规定设立公司必须报经批准的，应当在公司登记前依法办理批准手续。

**第7条**：公司营业执照签发日期为公司成立日期。

**第8条**：依照本法设立的有限责任公司，必须在公司名称中标明有限责任公司或者有限公司字样。依照本法设立的股份有限公司，必须在公司名称中标明股份有限公司或者股份公司字样。

**第9条**：有限责任公司变更为股份有限公司，应当符合本法规定的股份有限公司的条件。股份有限公司变更为有限责任公司，应当符合本法规定的有限责任公司的条件。有限责任公司变更为股份有限公司的，或者股份有限公司变更为有限责任公司的，公司变更前的债权、债务由变更后的公司承继。

### 七、公司章程（第11条）

**条文原文**：设立公司必须依法制定公司章程。公司章程对公司、股东、董事、监事、高级管理人员具有约束力。

**章程约束力范围**：

| 主体 | 约束内容 |
|------|----------|
| 公司 | 章程是公司组织与行为的基本准则 |
| 股东 | 章程对全体股东具有约束力 |
| 董事 | 章程对董事具有约束力 |
| 监事 | 章程对监事具有约束力 |
| 高级管理人员 | 章程对高级管理人员具有约束力 |

### 八、法定代表人（第13条）

**条文原文**：公司法定代表人依照公司章程的规定，由董事长、执行董事或者经理担任，并依法登记。公司法定代表人变更，应当办理变更登记。

**法定代表人选任规则**：

| 公司类型 | 法定代表人 |
|----------|------------|
| 设有董事会的 | 董事长 |
| 不设董事会设执行董事的 | 执行董事 |
| 任何公司 | 经理（依章程） |

### 九、对外投资与担保的程序（第15-16条）

#### （一）公司对外投资责任的限制（第15条）

**条文原文**：公司向其他企业投资或者为他人提供担保，依照公司章程的规定，由董事会或者股东会、股东大会决议；公司章程对投资或者担保的总额及单项投资或者担保的数额有限额规定的，不得超过规定的限额。

公司为公司股东或者实际控制人提供担保的，必须经股东会或者股东大会决议。

前款规定的股东或者受前款规定的实际控制人支配的股东，不得参加前款规定事项的表决。该项表决由出席会议的其他股东所持表决权的过半数通过。

#### （二）对外投资及担保程序（第16条）

**理解要点**：
- 公司章程可对投资/担保总额及单项数额规定限额
- 超过限额 → 该投资/担保无效（《公司法规定（一）》相关）
- 对股东或实控制人担保 → 必须经股东会/股东大会决议；该股东不得参加表决；由其他股东所持表决权过半数通过

### 十、保护职工权益与工会（第17-18条）

**第17条**：公司必须保护职工的合法权益，依法与职工签订劳动合同，参加社会保险，加强劳动保护，实现安全生产。

公司应当采用多种形式，加强公司职工的职业教育和岗位培训，提高职工素质。

**第18条**：公司职工依照《中华人民共和国工会法》组织工会，开展工会活动，维护职工合法权益。公司应当为本公司工会提供必要的活动条件。公司工会代表职工就职工的劳动报酬、工作时间、福利、保险和劳动安全卫生等事项依法与公司签订集体合同。

### 十一、党的基层组织（第19条）

**条文原文**：在公司中，根据中国共产党章程的规定，设立中国共产党的组织，开展党的活动。公司应当为党组织的活动提供必要条件。

**理解要点**：
- 公司中根据党章设立党组织
- 党组织开展活动
- 公司应当为党组织活动提供必要条件

### 十二、股东权利禁止滥用与法人格否认（第20条）

**条文原文**：公司股东应当遵守法律、行政法规和公司章程，依法行使股东权利，不得滥用股东权利损害公司或者其他股东的利益；不得滥用公司法人独立地位和股东有限责任损害公司债权人的利益。

公司股东滥用股东权利给公司或者其他股东造成损失的，应当依法承担赔偿责任。

公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任。

**法人格否认（揭开公司面纱）的构成要件**：

| 要件 | 内容 |
|------|------|
| 1. 主体 | 公司股东（滥用法人格） |
| 2. 行为 | 滥用公司法人独立地位和股东有限责任 |
| 3. 目的 | 逃避债务 |
| 4. 后果 | 严重损害公司债权人利益 |
| 5. 法律后果 | 股东对公司债务承担连带责任 |

**典型案例**：海南碧桂园房地产开发有限公司与三亚凯利投资有限公司、张某某等确认合同效力纠纷案（最高人民法院公报 2021年第2期）—— 单笔转移公司资金的法人格否认判断。

### 十三、禁止关联交易（第21条）

**条文原文**：公司的控股股东、实际控制人、董事、监事、高级管理人员不得利用其关联关系损害公司利益。

违反前款规定，给公司造成损失的，应当承担赔偿责任。

**关联关系**（《公司法》第216条释义）：
- 公司控股股东、实际控制人、董监高与其直接或间接控制的企业之间的关系
- 可能导致公司利益转移的其他关系

**理解要点**：
- 关联方不得利用关联关系损害公司利益
- 违反规定造成损失的，承担赔偿责任

### 十四、公司决议效力（第22条）

**条文原文**：公司股东会或者股东大会、董事会的决议内容违反法律、行政法规的无效。

股东会或者股东大会、董事会的会议召集程序、表决方式违反法律、行政法规或者公司章程，或者决议内容违反公司章程的，股东可以自决议作出之日起六十日内，请求人民法院撤销。

股东依照前款规定提起诉讼的，人民法院可以应公司的请求，要求股东提供相应担保。

公司根据股东会或者股东大会、董事会决议已办理变更登记的，人民法院宣告该决议无效或者撤销该决议后，公司应当向公司登记机关申请撤销变更登记。

**决议效力二元结构**：

| 类型 | 事由 | 救济 |
|------|------|------|
| 无效 | 决议内容违反法律、行政法规 | 自始无效；任何人均可主张 |
| 可撤销 | 召集程序、表决方式违反法律、行政法规或公司章程；决议内容违反公司章程 | 股东自决议作出之日起60日内请求法院撤销 |

## ⚠️ 司法适用难点

### 难点一：公司法人格否认的适用边界

**争议**：法人格否认（揭开公司面纱）的边界？

**主流观点**（依《公司法规定（一）》）：
- 主体：滥用法人格的股东
- 行为：人格混同、财产混同、业务混同
- 后果：严重损害债权人利益
- 责任：连带责任

**实务要点**：
- 单一违法行为不必然否认法人格
- 需综合判断股东是否有滥用行为
- "举重以明轻"原则的适用（如《公司法规定（三）》第14条参照适用）

### 难点二：公司决议无效与可撤销的区分

**争议**：决议无效与可撤销如何区分？

**主流观点**：

| 维度 | 无效 | 可撤销 |
|------|------|--------|
| 事由 | 内容违反法律、行政法规 | 程序违法/违章；内容违章 |
| 主张主体 | 任何人 | 股东 |
| 主张期限 | 无 | 60日 |
| 法律效果 | 自始无效 | 撤销后自始无效 |

### 难点三：对股东、实控人担保的程序要求

**争议**：对股东或实控制人提供担保的程序？

**主流观点**：
- 必须经股东会或股东大会决议
- 该股东/受实控人支配的股东不得参加表决
- 由出席会议的其他股东所持表决权的过半数通过
- 违反程序的担保，公司不承担担保责任（实务争议）

## ❓ 实务问答

> **Q1：公司法的立法目的是什么？**
>
> A：① 规范公司的组织和行为；② 保护公司、股东和债权人的合法权益；③ 维护社会经济秩序；④ 促进社会主义市场经济的发展（第1条）。

> **Q2：公司法调整哪些公司？**
>
> A：本法所称公司是指依照本法在中国境内设立的有限责任公司和股份有限公司（第2条）。

> **Q3：公司的法人财产权的内涵？**
>
> A：股东出资形成的财产和公司经营过程中积累的财产→属于公司，由公司依法占有、使用、收益和处分；股东不得以个人名义独立支配、任意分割（第3条）。

> **Q4：股东享有哪些权利？**
>
> A：① 资产收益权；② 参与重大决策权；③ 选择管理者权（第4条）。

> **Q5：公司经营活动应遵守哪些原则？**
>
> A：① 守法；② 遵守社会公德、商业道德；③ 诚实守信；④ 接受政府和社会公众的监督；⑤ 承担社会责任（第5条）。

> **Q6：公司成立日期如何确定？**
>
> A：公司营业执照签发日期为公司成立日期（第7条）。

> **Q9：公司章程对谁有约束力？**
>
> A：公司章程对公司、股东、董事、监事、高级管理人员具有约束力（第11条）。

> **Q10：公司法定代表人如何担任？**
>
> A：依照公司章程的规定，由董事长、执行董事或者经理担任，并依法登记（第13条）。

> **Q11：公司对外投资或为他人提供担保的程序？**
>
> A：① 依公司章程由董事会或股东会决议；② 公司章程对总额及单项数额有限额的，不得超过；③ 对股东或实控人提供担保的，必须经股东会决议，该股东不得参加表决，由其他股东所持表决权过半数通过（第15-16条）。

> **Q12：公司法人格否认的构成？**
>
> A：公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任（第20条）。

> **Q13：关联交易给公司造成损失的责任？**
>
> A：公司的控股股东、实际控制人、董事、监事、高级管理人员不得利用其关联关系损害公司利益。违反规定给公司造成损失的，应当承担赔偿责任（第21条）。

> **Q14：公司决议无效的情形？**
>
> A：公司股东会或者股东大会、董事会的决议内容违反法律、行政法规的无效（第22条第1款）。

> **Q15：公司决议可撤销的情形及期限？**
>
> A：股东会或者股东大会、董事会的会议召集程序、表决方式违反法律、行政法规或者公司章程，或者决议内容违反公司章程的，股东可以自决议作出之日起60日内，请求人民法院撤销（第22条第2款）。
