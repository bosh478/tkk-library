## 量刑档次

### 组织、领导、参加恐怖组织罪（第120条）
- 档1：组织、领导恐怖活动组织 → 10年以上有期徒刑或无期徒刑，并处没收财产
- 档2：积极参加 → 3年以上10年以下有期徒刑，并处罚金
- 档3：其他参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利，可以并处罚金

### 资助恐怖活动罪（第120条之一）
- 档1： → 5年以下有期徒刑、拘役、管制或剥夺政治权利，并处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金或没收财产

### 准备实施恐怖活动罪（第120条之二）
- 档1： → 5年以下有期徒刑、拘役、管制或剥夺政治权利，并处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金或没收财产

### 宣扬恐怖主义、极端主义、煽动实施恐怖活动罪（第120条之三）
- 档1： → 5年以下有期徒刑、拘役、管制或剥夺政治权利，并处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金或没收财产

### 利用极端主义破坏法律实施罪（第120条之四）
- 档1： → 3年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金
- 档3：情节特别严重 → 7年以上有期徒刑，并处罚金或没收财产

### 强制穿戴宣扬恐怖主义、极端主义服饰标志罪（第120条之五）
- 档1： → 3年以下有期徒刑、拘役或管制，并处罚金

### 非法持有宣扬恐怖主义物品罪（第120条之六）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金

### 危险驾驶罪（第133条之一）
- 档1：追逐竞驶（情节恶劣）/醉酒驾驶/严重超员/严重超速/违反危险化学品安全管理规定运输 → 拘役，并处罚金

### 走私武器、弹药罪（第151条第1款）
- 档1：情节较轻 → 3年以上7年以下有期徒刑，并处罚金
- 档2： → 7年以上有期徒刑，并处罚金或没收财产
- 档3：情节特别严重 → 无期徒刑，并处没收财产

### 伪造货币罪（第170条）
- 档1： → 3年以上10年以下有期徒刑，并处罚金
- 档2：伪造货币集团首要分子/数额特别巨大/其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 强制猥亵、侮辱罪（第237条）
- 档1： → 5年以下有期徒刑或拘役
- 档2：聚众或当众/其他恶劣情节 → 5年以上有期徒刑

### 猥亵儿童罪（第237条第3款）
- 档1： → 依照前两款规定从重处罚

### 绑架罪（第239条第2款）
- 档1：杀害被绑架人/故意伤害致人重伤死亡 → 无期徒刑或死刑，并处没收财产

### 收买被拐卖的妇女罪（第241条第6款）
- 档1：对被买儿童没有虐待/不阻碍解救 → 可以从轻处罚
- 档2：按照被买妇女意愿不阻碍返回 → 可以从轻或减轻处罚

### 侮辱罪、诽谤罪（第246条）
- 档1： → 3年以下有期徒刑、拘役、管制或剥夺政治权利
- 告诉才处理，但严重危害社会秩序和国家利益的除外

### 侵犯公民个人信息罪（第253条之一）
- 档1： → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 虐待罪（第260条）
- 告诉才处理，但被害人没有能力告诉/因强制威吓无法告诉的除外

### 虐待被监护、看护人罪（第260条之一）
- 档1：情节恶劣 → 3年以下有期徒刑或拘役
- 单位犯本罪：对单位判处罚金，对直接负责的主管人员和其他直接责任人员依照前款规定处罚

### 抢夺罪（第267条）
- 档1：数额较大/多次抢夺 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 袭警罪（第277条第5款）
- 档1：暴力袭击正在依法执行职务的人民警察 → 依照第277条第1款规定从重处罚（3年以下有期徒刑、拘役、管制或罚金）

### 伪造、变造、买卖国家机关公文证件印章罪（第280条）
- 档1： → 3年以下有期徒刑、拘役、管制或剥夺政治权利，并处罚金
- 档2：情节严重 → 3年以上10年以下有期徒刑，并处罚金

### 使用虚假身份证件罪（第280条之一）
- 档1：情节严重 → 拘役或管制，并处或单处罚金

### 非法生产、销售专用间谍器材罪（第283条）
- 档1： → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 组织考试作弊罪（第284条之一）
- 档1： → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 非法利用信息网络罪（第287条之一）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金

### 帮助信息网络犯罪活动罪（第287条之二）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金

### 扰乱无线电通讯管理秩序罪（第288条）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 聚众扰乱社会秩序罪（第290条）
- 档1：情节严重 → 3年以上7年以下有期徒刑
- 档2：积极参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利

### 编造、故意传播虚假信息罪（第291条之一第2款）
- 档1：严重扰乱社会秩序 → 3年以下有期徒刑、拘役或管制
- 档2：造成严重后果 → 3年以上7年以下有期徒刑

### 组织、利用会道门、邪教组织罪（第300条）
- 档1：情节较轻 → 3年以下有期徒刑、拘役、管制或剥夺政治权利，并处或单处罚金
- 档2：情节特别严重 → 7年以上有期徒刑或无期徒刑，并处罚金或没收财产
- 档3：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 盗窃、侮辱尸体罪（第302条）
- 档1： → 3年以下有期徒刑、拘役或管制

### 虚假诉讼罪（第307条之一）
- 档1：妨害司法秩序或侵害他人合法权益 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金

### 泄露不公开审理案件信息罪（第308条之一）
- 档1：造成信息公开传播或其他严重后果 → 3年以下有期徒刑、拘役或管制，并处或单处罚金

### 扰乱法庭秩序罪（第309条）
- 档1： → 3年以下有期徒刑、拘役、管制或罚金

### 拒绝提供间谍犯罪证据罪（第311条）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制

### 拒不执行判决、裁定罪（第313条）
- 档1：情节严重 → 3年以下有期徒刑、拘役或罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 偷越国（边）境罪（第322条）
- 档1： → 1年以下有期徒刑、拘役或管制，并处罚金
- 档2：为参加恐怖活动组织/接受恐怖活动培训/实施恐怖活动 → 1年以上3年以下有期徒刑，并处罚金

### 非法生产、买卖、运输制毒物品罪（第350条）
- 档1：情节较重 → 3年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金
- 档3：情节特别严重 → 7年以上有期徒刑，并处罚金或没收财产

### 组织、强迫卖淫罪（第358条）
- 档1： → 5年以上10年以下有期徒刑，并处罚金
- 档2：情节严重 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 贪污罪（第383条）
- 档1：数额较大或有其他较重情节 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金或没收财产
- 档3：数额特别巨大或有其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产；使国家和人民利益遭受特别重大损失 → 无期徒刑或死刑，并处没收财产

### 行贿罪（第390条）

- 档2：情节严重/使国家利益遭受重大损失 → 5年以上10年以下有期徒刑，并处罚金
- 档3：情节特别严重/使国家利益遭受特别重大损失 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 对有影响力的人行贿罪（第390条之一）

### 对单位行贿罪（第391条）
