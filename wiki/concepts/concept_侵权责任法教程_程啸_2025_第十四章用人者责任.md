# 《侵权责任法教程》第十四章 用人者责任

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | 第十四章 用人者责任 |
| 行号范围 | 3944-4180+（书籍）|
| 核心议题 | 用人单位/雇主对其工作人员/雇员侵权的替代责任 |
| 涵盖 | 4 节内容（概述/用人单位/接受劳务方/特殊情形）|

## 🎯 核心论点

**用人者责任 = 替代责任 + 无过错责任**

**《民法典》第1191条第1款**：
> 用人单位的工作人员因执行工作任务造成他人损害的，由用人单位承担侵权责任。用人单位承担侵权责任后，可以向有故意或者重大过失的工作人员追偿。

**两类型**：
1. **用人单位责任**（第1191条）：劳动关系
2. **接受劳务方责任**（第1192条）：劳务关系/劳务派遣

---

## 第一节 概述

## 一、概念

**用人者责任** = 被使用者（工作人员/提供劳务一方）因执行工作任务或提供劳务造成他人损害时，用人者（用人单位/接受劳务方）应承担的侵权责任。

**别称**：雇主责任、辅助人责任、使用人责任。

## 二、广义 vs 狭义

| 类型 | 范围 |
|------|------|
| **狭义** | 被使用人致害时用人者的责任 |
| **广义** | 狭义 + 被使用人自身受害时用人者的责任 |

## 三、特征

1. **替代责任**（行为人与责任人分离）
2. **无过错责任**（用人者承担责任不以过错为要件）
3. **追偿权**（用人者可向有故意或重大过失的工作人员追偿）

---

## 第二节 用人单位责任

## 一、构成要件

### （一）用人单位与工作人员存在劳动关系

**劳动关系** = 劳动者与用人单位之间依法确立的劳动权利义务关系。

**特征**：
- 用人单位招用劳动者
- 劳动者从事用人单位安排的工作
- 用人单位支付劳动报酬
- 受劳动法调整

### （二）工作人员因执行工作任务造成他人损害

**执行工作任务** = 工作人员在职权范围内从事的与用人单位利益相关的活动。

**判断标准**：
- 是否在工作时间
- 是否在工作场所
- 是否属于职权范围
- 行为是否与用人单位利益相关

### （三）工作人员主观上有过错（过错推定）

**用人者责任的内部关系**：
- 用人单位对受害人承担无过错责任
- 用人单位对工作人员的追偿以工作人员**故意或重大过失**为限

## 二、责任承担

**用人单位承担无过错责任**（《民法典》第1191条第1款）

**追偿权**：
- 用人单位可向有故意或重大过失的工作人员追偿
- 仅有一般过失或无过失的，不追偿

**劳务派遣的特殊规则**（第1191条第2款）：
> 劳务派遣期间，被派遣的工作人员因执行工作任务造成他人损害的，由**接受劳务派遣的用工单位**承担侵权责任；**劳务派遣单位有过错的，承担相应的责任**。

---

## 第三节 接受劳务方责任

## 一、构成要件

### （一）接受劳务方与提供劳务方存在劳务关系

**劳务关系** ≠ 劳动关系

**区别**：

| 维度 | 劳动关系 | 劳务关系 |
|------|----------|----------|
| 法律依据 | 《劳动法》《劳动合同法》 | 《民法典》 |
| 主体 | 用人单位+劳动者 | 平等主体 |
| 待遇 | 劳动保护、社保等 | 无 |
| 纠纷处理 | 劳动仲裁前置 | 法院直接受理 |
| 用工形式 | 较稳定 | 临时性、阶段性 |

### （二）提供劳务方因劳务造成他人损害

**提供劳务** = 从事约定的劳务活动。

## 二、责任承担

**《民法典》第1192条第1款**：
> 个人之间形成劳务关系，提供劳务一方因劳务造成他人损害的，由**接受劳务一方**承担侵权责任。接受劳务一方承担侵权责任后，可以向有故意或者重大过失的提供劳务一方追偿。

**特殊情形**（第1192条第2款）：
> 劳务派遣中劳务派遣单位与接受劳务派遣方（即用工单位）的责任承担，与第1191条第2款相同。

---

## 第四节 特殊情形

## 一、工作人员被借调的情形

**借调** = 工作人员在借用单位工作，但劳动关系仍属原单位。

**责任承担**：
- 由**借用单位**承担侵权责任
- 原单位有过错的，承担相应的责任

## 二、工作人员在工作时间外的行为

**判断标准**：是否与执行工作任务有关
- **属于执行工作任务**：用人单位承担责任
- **不属于执行工作任务**：行为人自己承担责任
- **与执行工作任务有内在联系**：用人单位可能承担责任

## 三、违反劳动纪律的行为

**情形**：
- 一般违纪：用人单位仍要承担责任
- 严重违反劳动纪律但仍在工作时间：用人单位承担责任
- 私自离岗从事与工作无关的活动：用人单位可能不承担责任

## 四、用人单位未尽合理注意义务

**用人单位选任、监督、教育工作人员**：
- 选任不当：工作人员明显不胜任工作
- 监督不力：未进行必要的安全管理
- 教育缺失：未进行必要的职业培训

**此类情形下，用人单位仍要承担无过错责任**（但可以向有故意或重大过失的工作人员追偿）。

## 重要概念节点

| 概念 | 定义 |
|------|------|
| **用人者责任** | 用人者对被使用人侵权的替代责任 |
| **雇主责任**（employer's liability）| 用人者责任的别称 |
| **辅助人责任**（Gehilfenhaftung）| 用人者责任的别称 |
| **替代责任** | 行为人与责任人分离 |
| **执行工作任务** | 工作人员在职权范围内的活动 |
| **劳动关系** | 劳动者与用人单位的关系 |
| **劳务关系** | 平等主体之间的劳务关系 |
| **劳务派遣** | 派遣单位+用工单位的用工形式 |
| **借调** | 工作人员在借用单位工作的情形 |
| **追偿权** | 用人者向有故意/重大过失的工作人员追偿 |
