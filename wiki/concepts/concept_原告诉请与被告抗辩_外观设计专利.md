# 诉辩主张的整理与固定（外观设计专利）

> **源行范围**：7829–8067（第二部分 诉辩主张的整理与固定）

## 一、原告诉请的审查（原告主体资格）

### （一）专利权人

- 须提交主体资格证明 + 《外观设计专利证书》
- 主体资格证明（营业执照/身份证）应与专利证书上的专利权人相一致
- 被诉侵权行为应发生在**专利权有效期内**

### （二）独占实施被许可人

- 须提交：外观设计专利证书 + 专利实施许可合同 + 备案证明
- 实施许可合同系原告与专利权人签订，许可方式**应系独占许可**
- 被诉侵权行为一般应发生在许可合同**有效期内**

### （三）排他实施被许可人

- 须额外提交**专利权人不起诉的证据**
- 同上 + 排他许可方式

### （四）普通实施被许可人

- 一般**无单独诉权**——只有在专利权人**明确授权起诉**时才能起诉
- 须提交**专利权人授权起诉的证明文件**

## 二、原告主体审查的核心要点

| 主体类型 | 是否可单独起诉 | 关键证据 |
|----------|----------------|----------|
| 专利权人 | ✅ 单独 | 主体证明 + 专利证书 |
| 独占被许可人 | ✅ 单独 | + 独占许可合同 + 备案 |
| 排他被许可人 | ✅ 专利权人不起诉时单独 | + 排他许可合同 + 备案 + 不起诉证据 |
| 普通被许可人 | ⚠️ 须有授权 | + 专利权人授权起诉文件 |

## 三、被告抗辩的审查（10 大抗辩）

| 抗辩类型 | 审查要点 | 抗辩依据 |
|----------|----------|----------|
| （一）**不侵权抗辩** | 设计特征对比；相同/相近种类产品认定 | 被诉设计与授权设计比对 |
| （二）**专利权效力抗辩** | 应提交无效宣告请求审查决定书或生效行政判决书 | 专利权不符合授权条件的评价报告 |
| （三）**不落入保护范围抗辩** | ① 不属于相同/相近种类产品 ② 不相同不相近似 | 比对意见 |
| （四）**未实施抗辩** | ① 原告无证据证明被告实施 ② 实施主体非被告 ③ 经其他共有人授权 | 采购合同/授权文件 |
| （五）**抗辩权（5 类）** | 非生产经营目的 / 现有设计 / 抵触申请 / 权利用尽 / 先用权 | 各类证据见下 |
| （六）**不承担停止侵权抗辩** | 国家利益/公共利益考量；替代性支付合理费用 | 公共利益证据 |
| （七）**不承担赔偿抗辩** | 无损失/无获利/合法来源/赔偿金额过高 | 进货凭证/销售数据 |
| （八）**不承担消除影响抗辩** | 不应承担消除影响/方式不当 | 反证 |
| （九）**合理费用抗辩** | 不应承担/费用过高 | 费用支出与必要性证据 |
| （十）**超过诉讼时效抗辩** | 3 年时效（民法典 188 条）；中止/中断 | 时效证据 |

### 抗辩权 5 类详解

1. **现有设计抗辩**——提供专利申请日前的现有设计文件 + 被诉设计与现有设计比对意见
2. **抵触申请抗辩**——提供抵触申请文件 + 比对意见
3. **权利用尽抗辩**——提供被诉侵权产品**合法来源于权利人**的证据
4. **先用权抗辩**——提供专利申请日前已制造相同产品/已做好必要准备 + 仅在**原有范围内**继续制造的证据
5. **非生产经营目的抗辩**——个人消费/科研使用等

## 四、关键提示

- **被告以专利权不符合授权条件抗辩**的，应向其释明：无效宣告请求应向**国家知识产权局专利局复审和无效审理部**提出；**审理侵权诉讼的法院仅就现有设计抗辩进行审理**
- 诉讼时效：**3 年**（民法典 188 条，旧规定 2 年已调整为 3 年）
- 即使权利人超过 3 年起诉，**侵权行为在起诉时仍在继续且专利有效期内**，仍应**判决停止侵权**；**赔偿数额向前推算 3 年**计算
- 知识产权请求权（停止侵权、消除影响）**不适用时效抗辩**；**损害赔偿请求权适用时效抗辩**
- 外观设计专利侵权**不包括使用侵权**（区别于发明/实用新型）

## 五、相比 L1 旧资料的核心差异

- 旧 L1 仅泛指"被告抗辩"，本节点列出 **10 类抗辩 + 5 类抗辩权** 完整分类
- **专利权效力抗辩**与**现有设计抗辩**的法院/行政程序分流首次显性化
- 诉讼时效从旧 2 年调整为 3 年的过渡说明首次出现

## 六、实务问答

> Q1: 普通实施被许可人能否单独起诉？
> A: 不能。除非有**专利权人明确授权**（书面授权书），否则无单独诉权。

> Q2: 被告主张专利权无效应向谁提出？
> A: **国家知识产权局专利局复审和无效审理部**。**审理侵权诉讼的法院不审理专利效力**，仅审理现有设计抗辩。

> Q3: 超过 3 年诉讼时效起诉，还能获得什么救济？
> A: ① 若侵权行为**仍在继续**且**专利有效期内**，可获**停止侵权判决**；② 损害赔偿**向前推算 3 年**（旧规则为 2 年）；③ 知识产权请求权本身**不适用时效**。

> Q4: 外观设计专利侵权的"使用侵权"如何认定？
> A: 外观设计专利**不存在使用侵权**——只有制造/许诺销售/销售/进口 4 类；这与发明/实用新型专利不同。
