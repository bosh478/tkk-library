# 海量电子数据审查

## 一、电子数据"取"的问题已经基本解决

经过十余年发展，我国电子数据取证领域已取得长足进步：

- **市场成熟**：国产取证产品从跟随模仿发展到向国外输出产品、技术、培训和理念
- **标准完善**：截至2021年，共发布电子数据取证鉴定领域各项标准与技术规范百余项
- **立法体系**：电子数据增列为证据种类之一，相关司法解释陆续出台
- **实践丰富**：以杭州市检察机关为例，2019-2021年办理电子数据专业技术案件6947件

作者认为，电子数据"取"的问题已经基本解决。

## 二、电子数据"用"的问题凸显

### 六大困难（整体工作面）

1. **装备落后**：检察官缺少审查电子数据的必要科技装备，无法直接打开蓝光光盘和移动硬盘
2. **审限紧张**：海量电子数据审查与7天逮捕审查期限矛盾突出，如某案件社交软件记录达近1000万条
3. **缺乏指引**：检察官缺乏电子数据审查操作指引
4. **敏感度低**：检察官审查判断电子数据的技能还跟不上
5. **专业薄弱**：检察机关专业技术人员配备薄弱、水平参差不齐
6. **标准不一**：公检法三家在电子数据认知上存在差异

### 三个困境（技术层面）

| 困境 | 表现 |
|------|------|
| **看不到** | 基层检察院对侦查部门移送的电子数据束手无策，审查流于形式 |
| **搜不着** | 取证报告通常为网页格式，关键词搜索效率极低，缺乏智能化工具 |
| **用不好** | 海量电子数据中蕴藏的违法犯罪线索挖掘利用远远不够 |

### 业务层面痛点

- 检察官难以提出针对性的引导侦查意见
- 电子数据未及时收集提取（如未扣押电脑、未获取密码密钥）
- 远程跨境获取电子数据合法性存疑

## 三、精准运用电子数据的路径

### 五个步骤

**步骤一：引导培育办理案件运用电子数据的良好生态**

- 完善电子数据取证报告的浏览、过滤、搜索、统计、标记功能
- 浏览是应用第一步，涉及组合过滤浏览需求
- 统计功能：分析主账号的群组活跃度、好友联系紧密程度等

**步骤二：了解检察办案电子数据分析精准需求**

从犯罪构成角度入手，明确审查要点：

- 哪些电子数据能证明相关人员**主体身份**？（通讯簿、第三方App注册信息、聊天记录中的称呼等）
- 哪些电子数据能直接证明**明知或主观故意**？（聊天记录中的炫耀内容可推定明知）
- 哪些电子数据能表示**犯罪行为的危害后果**？
- 哪些电子数据能延伸证明**潜在的受害对象**？
- 哪些电子数据能证明**上下游勾连或团伙组织架构**？

**步骤三：设计科学合理的人工智能技术框架**

#### 人工智能辅助审查模型

```
输入 → 处理（算法分析） → 输出
```

**输入层**：
- 手机取证报告等电子数据

**处理层**：
- **基本属性**：人、物、地址、时间
- **扩展属性**：行为识别、实体识别、情绪识别
- 匹配规则库和案由库

**输出层**（检察办案所需项目）：
- 是否有团伙
- 主观故意情况
- 表示危害后果的证据
- 潜在的受害对象
- 取证规范性判断

**模型验证路径**：
- 提供真实案件电子数据包给高校、科研院所、公司企业
- 各参与方创建人工智能算法并竞争
- 依据已决案件结果验证效果

**步骤四：实现案件电子数据审查的必要功能**

在浏览、过滤、搜索、标记、统计等基础功能上融合人工智能经典算法。

**自然语言处理需求示例**：
- "检索聊天记录中出现的所有安徽省的地址"
- "检索'闪电'组织的其他成员"
- "张三与李四2020年10月3日下午去了哪里"
- "王五2020年11月10日的情绪怎么样"

这些需求突破了精准匹配和模式匹配概念，需要以自然语言处理、机器学习为基础。

**步骤五：构建案件电子数据的科学表达**

- 对海量电子数据进行可视化表达
- 以组织架构图等形式呈现传销等组织的层级关系和总体规模
- 数据可视化是充分实现庭审效果的有效手段

## 四、核心观点

> "电子数据中有天使，电子数据中也有魔鬼"

海量电子数据中挖掘诉讼价值，极有可能成为第一个在司法机关真正落地的人工智能应用场景。只要有广泛的参与者，检察机关一定能最大程度地利用好这些电子数据，履行好追诉犯罪和法律监督职能。
