# 信托法第四章【信托当事人】综合

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》商事卷·信托法 2023]] |
| 章节 | 第四章 信托当事人 |
| 条文范围 | 《信托法》第19条～第48条（共30条） |
| 体例定位 | 信托法第四章 |
| 核心主题 | 委托人(第一节)+ 受托人(第二节)+ 受益人(第三节)三方的权利义务体系 |

## 章节目录

本章共 30 条（Articles 19-48），分三节规定信托三方当事人的权利义务：

| 节 | 法条范围 | 核心制度 |
|----|---------|---------|
| **第一节 委托人** | 19-23（5条） | 委托人资格 + 知情权 + 调整管理方法权 + 撤销权 + 解任权 |
| **第二节 受托人** | 24-40（17条） | 受托人资格 + 忠实/注意义务 + 利益冲突禁止 + 自我交易禁止 + 分别管理 + 共同受托人 + 费用承担 + 辞任 + 职责终止 + 新受托人选任 |
| **第三节 受益人** | 41-48（8条） | 受益人范围 + 受益权 + 放弃受益权 + 受益人大会 + 撤销权类推 + 受益权转让/继承 + 受益权清偿 + 受益人终止 |

## 第一节 委托人（Articles 19-23）

### 一、第19条·委托人资格

#### 法条原文

> 第十九条　委托人应当是具有完全民事行为能力的自然人、法人或者依法成立的其他组织。

#### 核心释义

**委托人的3个条件**：

| 条件 | 内容 |
|------|------|
| 1. 具有完全民事行为能力 | 依《民法典》第17、18条（年满18周岁+精神能力正常） |
| 2. 应拥有一定数量的财产 | 委托人对该财产享有所有权 |
| 3. 未处于资不抵债的境地 | 委托人无须用设立信托的财产清偿债务 |

**委托人的3类范围**：

| 类别 | 内容 |
|------|------|
| 1. 具有完全民事行为能力的自然人 | 18周岁以上+精神能力正常 |
| 2. 法人 | 依法核准登记的法人+特别法人 |
| 3. 依法成立的其他组织 | 非法人组织（个人独资企业、合伙企业等） |

**特别委托人的特殊要求**：

| 类别 | 要求 |
|------|------|
| 集合资金信托计划委托人 | 合格投资者+唯一受益人+50人以下（300万以上不受限） |
| 信贷资产支持证券委托人 | 银行业金融机构 |
| 企业年金信托委托人 | 经济负担能力+集体协商机制 |
| 保险资金间接投资基础设施信托委托人 | 保险公司+保监会批准+内部风控机制等7项条件 |

### 二、第20条·委托人知情权

#### 法条原文

> 第二十条　委托人有权了解其信托财产的管理运用、处分及收支情况，并有权要求受托人作出说明。
>
> 委托人有权查阅、抄录或者复制与其信托财产有关的信托帐目以及处理信托事务的其他文件。

#### 核心释义

**委托人的2项权利**：

| 权利 | 内容 |
|------|------|
| **了解情况权** | 了解信托财产的管理运用、处分及收支情况，要求受托人说明 |
| **查阅复制权** | 查阅、抄录、复制与其信托财产有关的信托账目和处理信托事务的其他文件 |

**知情权的行使边界**：
- 仅限于与"信托财产"有关的情况
- 查阅复制权的范围限于"与信托财产有关"的账目和文件
- 不得损害他方利益（损害可能性）

### 三、第21条·调整信托财产管理方法权

#### 法条原文

> 第二十一条　因设立信托时未能预见的特别事由，致使信托财产的管理方法不利于实现信托目的或者不符合受益人的利益时，委托人有权要求受托人调整该信托财产的管理方法。

#### 核心释义

**行使条件**：
1. "设立信托时**未能预见**的特别事由"
2. "管理方法**不利于**实现信托目的"
3. "或**不符合**受益人的利益"

**行使方式**：
- 委托人可以直接向受托人行使
- 也可以通过法院作出裁定行使

### 四、第22条·委托人的撤销权

#### 法条原文

> 第二十二条　受托人违反信托目的处分信托财产或者因违背管理职责、处理信托事务不当致使信托财产受到损失的，委托人有权申请人民法院撤销该处分行为，并有权要求受托人恢复信托财产的原状或者予以赔偿；该信托财产的受让人明知是违反信托目的而接受该财产的，应当予以返还或者予以赔偿。
>
> 前款规定的申请权，自委托人知道或者应当知道撤销原因之日起一年内不行使的，归于消灭。

#### 核心释义

**撤销权的行使条件**：

| 条件 | 内容 |
|------|------|
| 1. 行为 | 违反信托目的处分信托财产或违背管理职责、处理信托事务不当 |
| 2. 后果 | 信托财产受到损失 |
| 3. 因果关系 | 损失由上述行为引起 |

**撤销权的行使方式**：
- 撤销权+恢复原状+赔偿损失（可单独或合并适用）
- 受让人明知违反信托目的而接受财产的，应当**返还或赔偿**

**撤销权的时效**（1年除斥期间）：
- 自知道或应当知道撤销原因之日起**1年**
- 不中止、中断、延长

**善意取得制度的适用**（依《民法典》第311条）：
- 受让人善意+合理价格+登记/交付 → 受让人取得所有权
- 否则所有权人可追回

### 五、第23条·委托人的解任权

#### 法条原文

> 第二十三条　受托人违反信托目的处分信托财产或者管理运用、处分信托财产有重大过失的，委托人有权依照信托文件的规定解任受托人，或者申请人民法院解任受托人。

#### 核心释义

**解任权的行使条件**（严格模式）：
- 受托人**违反信托目的处分信托财产**，或
- 受托人**管理运用、处分信托财产有重大过失**
- 受托人管理业绩平平 + 一般过失 → 不构成解任事由

**解任权的行使途径**：
- 信托文件有规定的，按规定解任
- 信托文件无规定的，申请人民法院解任
- 集合资金信托计划 → 通过受益人大会集体决议

## 第二节 受托人（Articles 24-40）

### 一、第24条·受托人资格

#### 法条原文

> 第二十四条　受托人应当是具有完全民事行为能力的自然人、法人。
>
> 法律、行政法规对受托人的条件另有规定的，从其规定。

#### 核心释义

**受托人的2类**：
- 具有完全民事行为能力的自然人
- 法人

**受托人的2个条件**：
- 具有行为能力（认识、预期、判断能力）
- 未处于资不抵债的境地

**注意**：与第19条相比，**不包括"依法成立的其他组织"**（如合伙企业不能作为受托人）

### 二、第25条·受托人忠实义务与注意义务

#### 法条原文

> 第二十五条　受托人应当遵守信托文件的规定，为受益人的最大利益处理信托事务。
>
> 受托人管理信托财产，必须恪尽职守，履行诚实、信用、谨慎、有效管理的义务。

#### 核心释义

**受托人的2类义务**：

| 义务 | 内容 |
|------|------|
| **忠实义务** | 为受益人的最大利益处理信托事务（禁止性规范） |
| **注意义务** | 恪尽职守+诚实+信用+谨慎+有效管理（作为性规范） |

**忠实义务与注意义务的区分**：

| 维度 | 忠实义务 | 注意义务 |
|------|---------|---------|
| 性质 | 禁止性规范（不得） | 作为性规范（应当） |
| 救济 | 利得吐出（归入权） | 损害赔偿 |
| 举证责任 | 受益人 | 受益人（举证损害+因果关系） |
| 主体范围 | 包括家庭、子公司等 | 客观标准 |

**营业信托纠纷的举证责任**（依《民商审判会议纪要》第94条）：
> 资产管理产品的委托人以受托人未履行勤勉尽责、公平对待客户等义务损害其合法权益为由，请求受托人承担损害赔偿责任的，**应当由受托人举证证明其已经履行了义务**。受托人不能举证证明，委托人请求其承担相应赔偿责任的，人民法院依法予以支持。

### 三、第26条·受托人不得利用信托财产为自己谋取利益

#### 法条原文

> 第二十六条　受托人除依照本法规定取得报酬外，不得利用信托财产为自己谋取利益。
>
> 受托人违反前款规定，利用信托财产为自己谋取利益的，所得利益归入信托财产。

#### 核心释义

**归入权（秘密获利禁止）**：
- 受托人不得利用信托财产为自己谋取利益
- 违反规定的，所得利益**归入信托财产**

**严格责任原则**：受托人承担严格责任——不得获得秘密利益

### 四、第27条·受托人不得将信托财产转为其固有财产

#### 法条原文

> 第二十七条　受托人不得将信托财产转为其固有财产。受托人将信托财产转为其固有财产的，必须恢复该信托财产的原状；造成信托财产损失的，应当承担赔偿责任。

### 五、第28条·受托人不得自我交易

#### 法条原文

> 第二十八条　受托人不得将其固有财产与信托财产进行交易或者将不同委托人的信托财产进行相互交易，但信托文件另有规定或者经委托人或者受益人同意，并以公平的市场价格进行交易的除外。
>
> 受托人违反前款规定，造成信托财产损失的，应当承担赔偿责任。

### 六、第29条·分别管理、分别记账

#### 法条原文

> 第二十九条　受托人必须将信托财产与其固有财产分别管理、分别记帐，并将不同委托人的信托财产分别管理、分别记帐。

### 七、第30-32条·亲自处理 + 共同受托人

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第30条 | 受托人应当亲自处理信托事务 | 原则上亲自处理；信托文件另有规定或不得已事由可委托他人代为处理 |
| 第31条 | 共同受托人对信托事务的处理 | 两个以上受托人共同处理；意见不一致时依信托文件规定；无规定的按多数意见或咨询委托人/受益人 |
| 第32条 | 共同受托人共同处理信托事务应承担的责任 | 共同处理的行为对委托人/受益人承担连带责任（除非信托文件另有规定） |

### 八、第33-34条·受托人报告与支付

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第33条 | 受托人的保管、报告及保密义务 | 妥善保管+定期报告+对受益人等保守秘密 |
| 第34条 | 受托人向受益人支付信托利益 | 依信托文件按时支付 |

### 九、第35-37条·受托人报酬与费用

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第35条 | 受托人的取得报酬权 | 依信托文件约定；未约定的经协商补充约定；不得未经同意变更报酬数额 |
| 第36条 | 受托人请求给付报酬权的限制 | 受托人违反信托目的或重大过失 → 不得请求给付报酬 |
| 第37条 | 受托人处理信托事务支出的费用 | 费用+对第三人所负债务 → 以信托财产承担；受托人固有财产先行支付的，对信托财产享有**优先受偿权** |

### 十、第38-40条·受托人的辞任、终止与新受托人

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第38条 | 受托人辞任 | 须经委托人和受益人同意；公益信托受托人未经公益事业管理机构批准不得辞任 |
| 第39条 | 受托人职责终止的6种情形 | 死亡/宣告死亡+宣告无/限制民事行为能力+撤销/破产+解散/丧失资格+辞任/解任+法律规定的其他情形 |
| 第40条 | 新受托人的产生办法 | 信托文件规定 → 委托人/受益人指定 → 法院指定 |

## 第三节 受益人（Articles 41-48）

### 第41条·受益人范围

> 第四十一条　受益人是在信托中享有信托受益权的人。受益人可以是自然人、法人或者依法成立的其他组织。
>
> 委托人可以是受益人，也可以是同一信托的唯一受益人。
>
> 受托人可以是受益人，但不得是同一信托的唯一受益人。

**核心规则**：
- 受益人可以是自然人、法人、其他组织
- 委托人**可以**是受益人（自益信托）
- 受托人**可以是**受益人，但**不得是同一信托的唯一受益人**

### 第42-43条·受益人的权利

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第42条 | 受益人的权利 | 享有信托受益权；受益人可以行使第20-23条规定的委托人权利；与委托人意见不一致时可申请人民法院裁定 |
| 第43条 | 受益人大会 | 受益人大会由全体受益人组成；依照信托文件或法律规定的程序和规则行使职权 |

**依第42条，类推适用委托人的5项权利**：
- 知情权（第20条）
- 调整管理方法权（第21条）
- 撤销权（第22条）
- 解任权（第23条）
- 申请人民法院作出裁定的权利

### 第44-48条·受益权的其他规定

| 法条 | 主题 | 核心制度 |
|------|------|---------|
| 第44条 | 受益人放弃信托受益权 | 可放弃；放弃后在受益权范围内以自有财产承担责任 |
| 第45条 | 共同受益人的信托利益分配 | 依信托文件规定；无规定的按等额分配 |
| 第46条 | 受益人不能清偿到期债务 | 可以其信托受益权清偿；清偿后受益人地位由受托人或委托人指定的其他人承受 |
| 第47条 | 受益权的转让和继承 | 受益人取得的信托受益权可以依法转让和继承（信托文件有限制性规定的除外） |
| 第48条 | 受益人的终止 | 受益人死亡/丧失民事行为能力/被宣告破产/法人终止/信托文件规定的其他情形 |

## ⚠️ 司法适用难点

### 难点一：委托人 vs 受益人行使权利的冲突

**争议**：受益人行使第20-23条权利时与委托人意见不一致？

**主流观点**（依第42条）：
- 受益人可行使上述权利
- 与委托人意见不一致时，**可以申请人民法院作出裁定**
- 依《九民会议纪要》第94条，营业信托中受托人承担举证责任

### 难点二：忠实义务与注意义务的区分

**争议**：如何区分忠实义务与注意义务？

**主流观点**：
- 忠实义务 → 禁止性规范 → 利得吐出 → 不需证明损害
- 注意义务 → 作为性规范 → 损害赔偿 → 需证明损害+因果关系

### 难点三：共同受托人责任

**争议**：共同受托人如何承担责任？

**主流观点**（依第32条）：
- 共同处理的行为 → 承担连带责任
- 信托文件另有规定的，从其规定
- 内部追偿依第32条第2款

### 难点四：第26条受托人利用信托财产谋利的边界

**争议**：何为"利用信托财产为自己谋取利益"？

**主流观点**：
- 形式上未给信托财产带来损害，但利用受托人身份、机会、信息、地位谋取利益的，也构成违反
- 包括受托人本人+家庭+子公司等
- 受托人从第三人处取得贿赂、回扣或其他利益 → 也构成违反

### 难点五：第22条撤销权1年时效的性质

**争议**：1年时效是诉讼时效还是除斥期间？

**主流观点**：
- **1年是除斥期间**，不中止、中断、延长
- 依《民法典》第152条第2款，5年内未行使的撤销权消灭

## ❓ 实务问答

### Q1：委托人的3项条件？

**A**：
1. 具有完全民事行为能力
2. 应拥有一定数量的财产（对该财产享有所有权）
3. 未处于资不抵债的境地

### Q2：委托人的5项权利？

**A**：
1. 知情权（第20条）
2. 调整管理方法权（第21条）
3. 撤销权（第22条）
4. 解任权（第23条）
5. 监督权（与受益人共同行使）

### Q3：受托人的2项核心义务？

**A**：
1. **忠实义务**：为受益人的最大利益处理信托事务；不得利用信托财产为自己谋取利益
2. **注意义务**：恪尽职守+诚实+信用+谨慎+有效管理

### Q4：受托人的6条禁止行为（依第26-29条）？

**A**：
1. 不得利用信托财产为自己谋取利益（第26条）
2. 不得将信托财产转为其固有财产（第27条）
3. 不得自我交易或不同委托人信托财产相互交易（第28条）
4. 必须将信托财产与固有财产分别管理、分别记账（第29条）
5. 不得将不同委托人的信托财产混同管理
6. 不得擅自辞任（公益信托）（第38条）

### Q5：第22条撤销权的行使条件？

**A**：
1. 行为：违反信托目的处分信托财产或违背管理职责、处理信托事务不当
2. 后果：信托财产受到损失
3. 因果关系：损失由上述行为引起
4. 时效：自知道/应当知道撤销原因之日起1年（除斥期间）

### Q6：第23条解任权的行使条件？

**A**（严格模式）：
- 受托人违反信托目的处分信托财产，或
- 管理运用、处分信托财产有重大过失
- （**不包括**：受托人管理业绩平平 + 一般过失）

### Q7：受托人资格与委托人的区别？

**A**：
- **委托人**：具有完全民事行为能力的**自然人、法人或者依法成立的其他组织**（第19条）
- **受托人**：具有完全民事行为能力的**自然人、法人**（第24条）
- 注意：受托人**不包括"依法成立的其他组织"**（如合伙企业不能作为受托人）

### Q8：受托人报酬权的限制？

**A**：依《信托法》第35、36条：
- 报酬的取得：依信托文件约定 → 协商补充 → 不得未经同意变更
- **不得请求给付报酬**的情形：受托人违反信托目的处分信托财产或管理运用、处分信托财产有重大过失的，在恢复原状或赔偿前不得请求给付报酬
