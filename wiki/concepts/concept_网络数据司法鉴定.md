# 网络数据司法鉴定

## 概述

网络数据司法鉴定是电子数据司法鉴定的重要分支，是指运用计算机科学理论和技术以及其他相关专门知识和经验，对涉及诉讼的网络数据有关内容进行判断、鉴别并出具鉴定意见的活动。网络取证（network forensics）是针对涉及民事、刑事和管理事件而进行的对网络流量的研究，目的是保护用户和资源，防范由于持续膨胀的网络连接而产生的被非法利用、入ior及其他犯罪行为。

## 网络数据来源

### 主机日志文件

存在于被入侵的主机上，主要有操作系统的日志功能生成。通过对主机日志进行审查，分析被攻击过程的历史记录，可以发现许多证据信息。但入侵者获得 Root 权限后可以轻易修改、删除操作系统所保存的日志记录，甚至伪造现场。建议使用第三方的日志工具，生成被隔离保护、格式信息不易被攻击者理解的日志。

### 防火墙日志

当防火墙系统被配置为所有内部网络与外部网络连接均需经过的安全系统时，防火墙就能够对所有的访问做出日志记录，包括有关连接的信息、服务器的通信量以及试图闯入者的任何企图事件，从而为网络取证提供重要的依据。

### DHCP 服务器日志

DHCP 服务器根据需要为网络上的主机分配 IP 地址，保留分配的日志，记录 MAC 地址、分配给某个 MAC 地址的 IP 地址及分配的时间等信息。

### ISP 记录

作为日常工作的一部分或者调查异常活动时，ISP 要收集网络通信相关数据。ISP 的记录不会保留很长时间，通常几天或几小时，但执法机关依照程序，可以要求他们保留更长的时间。

### 网络监测日志

包括入侵检测日志、蜜罐日志、认证系统、DHCP 等。入侵检测能对网络进行监听，提供对内部攻击、外部攻击的实时保护。

### 其他网络设备日志

如路由器、交换机等网络设备的日志。

### 数据类型

| 类型 | 说明 |
|------|------|
| 报警数据 | 来自入侵检测系统，是对异常行为的监测数据 |
| 全文数据 | 来自对网络连接的记载，包括所有的数据报细节甚至应用层 |
| 会话数据 | 系统之间会话的概要，通常是与传递的内容无关的紧凑数据 |
| 统计数据 | 描述性的、时间聚合的高度视图 |

## 网络数据收集方法

### 一般取证方式

1. **打印**：对网络犯罪案件在文字内容上有证明意义的情况下，直接将有关内容打印在纸张上
2. **拷贝**：将计算机文件拷贝到软盘、活动硬盘或光盘中
3. **拍照摄像**：采用拍照摄像的方法进行证据的提取和固定
4. **制作司法文书**：包括检查笔录和鉴定，具有专门性、特定性的特点
5. **查封扣押**：对于涉及案件的证据材料物件，为防止有关当事人进行损毁、破坏而采取的方式
6. **公证**：通过公证机构将有关证据进行公证固定

### 复杂取证方式

1. **解密**：对密码进行解译，使用相应的解除密码口令软件
2. **恢复**：通过计算机系统组织数据的链指针进入小块磁盘空间，从中发现数据备份或修改后的剩余数据
3. **测试**：由司法会计专家对提取的资料进行现场验证

## 网络数据的保护和保存

1. **形成监护链**：在证据收集后立即对其作 Hash 值，并在安全的媒介上保存，防止交叉污染
2. **理解证据形式**：最好的证据是调查人员可以得到的网络证据的原始形态
3. **拷贝原始证据**：拷贝原始证据到只读的媒介，不直接在原始证据上进行取证
4. **创建衍生证据**：对原始证据文件的副本做 Hash 运算，并与先前保存的 Hash 值匹配确认
5. **跟踪证据链**：确保网络证据处理的每一个环节具有可验证的一致性和完整性

## 网络数据关联分析

### 关联方法

1. **用户名关联**：特定对象在选取用户名时，可能会采用与自己有直接关系的词，不同用户名间可能有相同或相似之处
2. **密码关联**：对于特定对象的多个密码之间，可能会具有一些相同或相似的特征
3. **时间关联**：确定事件发生的时间段，在此时间段内访问的文件、使用的各种网上账号都属于同一人所有
4. **关系人关联**：在聊天工具中存在好友列表，多个账号中存在相同的与案件有关的关系人

### 分析方法

1. **规范化**：给出一致性的说明，在证据链中建立规范化的描述
2. **消除冲突**：注意不要遗漏在攻击现场的每个步骤
3. **排除假象**：注意区分和鉴别"良性"事件和攻击
4. **创建证据链和事件时间线**：将证据链制成事件时间线，关联连接的事件形成现场
5. **用证据证明每一个假设**：结合使用取证和传统的调查方法以强化证据

## IP 地址追踪技术

### IP 地址问题

1. **假冒的 IP 地址**：许多攻击使用假冒的 IP 地址，对于需要建立连接的攻击，假冒很难成功
2. **大量的源 IP 地址**：有些攻击试图用成百上千个不同的源 IP 地址
3. **IP 地址的合法性**：IP 地址常常是动态地分配的，以前被攻击过的系统所用的 IP 地址现在可能是另一个系统在使用

### 证实可疑主机身份的方法

1. **联系 IP 地址的所有者**：通过 RIR（ARIN、APNIC、RIPE NCC、LACNIC）提供 WHOIS 查询
2. **给 IP 地址发送网络通信**：不应向一个明显正在进行攻击的 IP 地址发送网络通信
3. **寻求 ISP 的帮助**：ISP 通常需要法律手续才提供可疑网络事件的信息
4. **调查 IP 地址的历史**：查找用过相同 IP 地址或 IP 地址块的以前的可疑活动
5. **在应用程序内容中找寻线索**：攻击有关的应用程序数据包可能包含了攻击者身份的线索

## 网络数据司法鉴定技术手段

### IP 地址获取技术

1. 使用 ping 或 traceroute 命令判断主机是否在线
2. 混乱地址的恢复：将十进制整数转换为十六进制再转为 IP 地址格式
3. 使用 IP 扫描工具程序
4. 由 DNS 获取 IP 地址，使用 nslookup 进行正向和逆向查询
5. MAC 地址的获取：通过 ARP 表实现 IP 和 MAC 地址的转化
6. 在 ISP 的支持下获取 IP：通过 RADIUS 协议支持身份认证和记账

### 电子邮件取证技术

电子邮件头信息中包含了从发送者到接收者之间的路径，可以对信息发送路径上的痕迹进行分析以获取证据。跟踪伪造的电子邮件的主要方法是请求 ISP 的帮助，取证人员必须学会解读邮件的头文件。

### 网络入侵跟踪技术

1. **IP 报文入侵追踪技术**：包括连接检测、日志记录、ICMP 追踪法、标记报文法等
2. **基于主机的入侵追踪技术**：身份识别系统（CISIE），向处于"扩展连接"的主机报警，提供前若干跳的连接信息
3. **指纹技术**：网络入侵源点的安全管理框架（DecIDuous 系统）
4. **协同的入侵追踪和响应框架**（CITRA）
5. **基于主动网络的入侵检测框架**（SWT）

### IDS 取证技术

在检测到非法入侵或恶意行为时利用入侵检测系统（IDS）收集电子证据。1999 年 Yuill 等人详细阐述了同时作为取证和研究工具的入侵检测系统的使用。将网络取证结合到入侵检测等网络安全工具和网络体系结构中进行动态取证，可使整个取证过程更加系统并具有智能性和实时性。

### 蜜阱取证技术

蜜阱（Honeytrap）包括蜜罐（Honeypot）和蜜网（Honeynet），以诱骗技术为核心，当黑客攻击时能够监视攻击者的行径、策略、工具和目标，从而自动收集相关的电子证据，实现实时网络取证。

### 恶意程序技术

恶意代码指能够长期潜伏、秘密窃取敏感信息的有害代码程序，应用同样的原理可以设计用来进行取证。

### 入侵容忍技术

入侵容忍系统的目标包括保证服务器上数据的真实性、完整性、秘密性，保证服务的可用性和保护系统的安全运行。处理那些防火墙和 IDS 不能有效阻挡的、已渗入系统的攻击。

### 网络监控和传感器技术

网络监控系统可包括主机传感器、网络传感器、网络摄像机等部件以及专家系统和知识库，能够进行数据采集与分析、网络传播内容监控、网页监督、实时屏幕信息监视、击键分析等。

### 网络透视技术

网络透视（Network Tomography）通过发送多种探测包给指定的接收器，观察并分析接收器所获得的信息，最后通过统计和推断来获得各种网络信息。可用来获取网络中一些不能直接观察到的信息，目前已应用于网络安全领域，如可从一些观察点发现 DDoS 的踪迹。

### Agent 技术

基于 Agent 的分布式主动实时网络取证系统可以对网络入侵进行主动实时的调查，并提供对网络流量的自适应包获取，以及日志系统、网络流量、扫描调查等数据的数据融合功能。

### SVM 取证技术

应用 SVM 对数据包进行特征选择，并进而取证的技术。Mukkamala 和 Sung 的研究表明 SVM 的性能优于 ANN，且 SVM 具有良好的伸缩性。

## 相关工具

### Sniffer Infinistream

Network General 公司产品，集成网络流量监控和解码分析能力以及专家系统，具备大容量存储能力：

- 千兆位网络流量数据捕获和存储（高达 1800Mbps）
- 大容量存储（高达 TB 级）
- 方便快速的数据检索
- 历史统计分析

### eTrust Network Forensics

CA 公司产品，整合式的安全与网络监控解决方案：

- 记录目标网络的原始数据
- 进行识别、保存、分析和提交数字证据
- 重现网络活动过程
- 运用先进的审计分析技术来找出网络使用、内部资料窃取、企业政策违规等状况

### NetDetector

美国 Niksun 公司产品，核心是比特级的网络流量记录和分析：

- 实时发现网络流量中的异常状况
- 可以在应用层上重组网络中的各个进程
- 倡导网络安全第二级防护的概念
- 具有入侵检测功能（内置 Snort）

### NetMonitor

网络信息监控与取证系统：

- 能够记录网络上的全部底层报文
- 提供 WWW、TELNET、FTP、SMTP、POP 和 UDP 等应用的报文重组
- 可监控基于 TCP 协议的 FTP、HTTP、SMTP、POP3、TELNET 应用服务和 UDP 协议

## 攻击者分类

| 级别 | 描述 | 注释 |
|------|------|------|
| 低级 | 试图成为黑客，将来有一天可能成为黑客 | 不可低估 |
| 初级 | 使用现成的有效攻击技术和手段进行攻击 | 用户的进程或程序可以自由使用 |
| 高级 | 经验丰富，知识渊博 | 攻击结束后会把证据清理干净 |
| 超级 | 掌握大量的有关操作系统和互联网的知识，能熟练操纵各种硬件和软件 | 本质上是难以寻找的，具体攻击行为可能都无法被注意到 |
