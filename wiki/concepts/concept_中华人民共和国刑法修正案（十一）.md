## 量刑档次

### 刑事责任年龄（第17条）
- 档1：已满16周岁 → 应当负刑事责任
- 档2：已满14周岁不满16周岁 → 犯故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质罪 → 应当负刑事责任
- 档3：已满12周岁不满14周岁 → 犯故意杀人、故意伤害罪，致人死亡或以特别残忍手段致人重伤造成严重残疾，情节恶劣，经最高检核准 → 应当负刑事责任

### 妨害安全驾驶罪（第133条之二）
- 档1：对行驶中公共交通工具驾驶人员使用暴力或抢控驾驶装置 → 1年以下有期徒刑、拘役或管制，并处或单处罚金

### 强令他人违章冒险作业罪（第134条第2款）
- 档1： → 5年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 5年以上有期徒刑

### 危险作业罪（第134条之一）
- 档1：关闭破坏安全设备/拒不执行整改/擅自从事高危作业 → 1年以下有期徒刑、拘役或管制

### 生产、销售假药罪（第141条）
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：对人体健康造成严重危害或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：致人死亡或有害特别严重情节 → 10年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产

### 生产、销售劣药罪（第142条）
- 档1：对人体健康造成严重危害 → 3年以上10年以下有期徒刑，并处罚金
- 档2：后果特别严重 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 妨害药品管理罪（第142条之一）
- 档1：足以严重危害人体健康 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：对人体健康造成严重危害或有其他严重情节 → 3年以上7年以下有期徒刑，并处罚金

### 欺诈发行证券罪（第160条）
- 档1：数额巨大、后果严重或有其他严重情节 → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：数额特别巨大、后果特别严重或有其他特别严重情节 → 5年以上有期徒刑，并处罚金

### 违规披露、不披露重要信息罪（第161条）
- 档1：严重损害或情节严重 → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 5年以上10年以下有期徒刑，并处罚金

### 非国家工作人员受贿罪（第163条）
- 档1：数额较大 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或有其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金

### 骗取贷款罪（第175条之一）
- 档1：给银行造成重大损失 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：给银行造成特别重大损失或有其他特别严重情节 → 3年以上7年以下有期徒刑，并处罚金

### 非法吸收公众存款罪（第176条）
- 档1：扰乱金融秩序 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：数额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或有其他特别严重情节 → 10年以上有期徒刑，并处罚金

### 操纵证券、期货市场罪（第182条）
- 档1：情节严重 → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节特别严重 → 5年以上10年以下有期徒刑，并处罚金

### 洗钱罪（第191条）
- 档1： → 5年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处罚金

### 集资诈骗罪（第192条）
- 档1：数额较大 → 3年以上7年以下有期徒刑，并处罚金
- 档2：数额巨大或有其他严重情节 → 7年以上有期徒刑或无期徒刑，并处罚金或没收财产

### 假冒注册商标罪（第213条）
- 档1：情节严重 → 3年以下有期徒刑，并处或单处罚金
- 档2：情节特别严重 → 3年以上10年以下有期徒刑，并处罚金

### 销售假冒注册商标的商品罪（第214条）
- 档1：违法所得数额较大或有其他严重情节 → 3年以下有期徒刑，并处或单处罚金
- 档2：违法所得数额巨大或有其他特别严重情节 → 3年以上10年以下有期徒刑，并处罚金

### 非法制造、销售非法制造的注册商标标识罪（第215条）
- 档1：情节严重 → 3年以下有期徒刑，并处或单处罚金
- 档2：情节特别严重 → 3年以上10年以下有期徒刑，并处罚金

### 侵犯著作权罪（第217条）
- 档1：违法所得数额较大或有其他严重情节 → 3年以下有期徒刑，并处或单处罚金
- 档2：违法所得数额巨大或有其他特别严重情节 → 3年以上10年以下有期徒刑，并处罚金

### 销售侵权复制品罪（第218条）
- 档1：违法所得数额巨大或有其他严重情节 → 5年以下有期徒刑，并处或单处罚金

### 侵犯商业秘密罪（第219条）
- 档1：情节严重 → 3年以下有期徒刑，并处或单处罚金
- 档2：情节特别严重 → 3年以上10年以下有期徒刑，并处罚金

### 为境外窃取商业秘密罪（第219条之一）
- 档1： → 5年以下有期徒刑，并处或单处罚金
- 档2：情节严重 → 5年以上有期徒刑，并处罚金

### 提供虚假证明文件罪（第229条）
- 档1：情节严重 → 5年以下有期徒刑或拘役，并处罚金
- 档2：有法定加重情形之一 → 5年以上10年以下有期徒刑，并处罚金
- 档3：出具证明文件有重大失实，造成严重后果 → 3年以下有期徒刑或拘役，并处或单处罚金

### 强奸罪（第236条）
- 档1： → 3年以上10年以下有期徒刑
- 档2：奸淫不满14周岁幼女 → 从重处罚
- 档3：情节恶劣/多人/当众/轮奸/致重伤死亡 → 10年以上有期徒刑、无期徒刑或死刑

### 负有照护职责人员性侵罪（第236条之一）
- 档1： → 3年以下有期徒刑
- 档2：情节恶劣 → 3年以上10年以下有期徒刑

### 猥亵儿童罪（第237条第3款）
- 档1： → 5年以下有期徒刑
- 档2：多人多次/聚众当众/造成伤害/手段恶劣 → 5年以上有期徒刑

### 职务侵占罪（第271条）
- 档1：数额较大 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大 → 10年以上有期徒刑或无期徒刑，并处罚金

### 挪用资金罪（第272条）
- 档1：归个人使用/借贷，数额较大超3个月/进行营利活动/非法活动 → 3年以下有期徒刑或拘役
- 档2：数额巨大 → 3年以上7年以下有期徒刑
- 档3：数额特别巨大 → 7年以上有期徒刑

### 袭警罪（第277条第5款）
- 档1： → 3年以下有期徒刑、拘役或管制
- 档2：使用枪支、管制刀具或驾驶机动车撞击 → 3年以上7年以下有期徒刑

### 冒名顶替罪（第280条之二）
- 档1：盗用冒用他人身份顶替入学、录用、就业待遇 → 3年以下有期徒刑、拘役或管制，并处罚金

### 高空抛物罪（第291条之二）
- 档1：情节严重 → 1年以下有期徒刑、拘役或管制，并处或单处罚金

### 催收非法债务罪（第293条之一）
- 档1：使用暴力胁迫/限制人身自由/恐吓跟踪骚扰 → 3年以下有期徒刑、拘役或管制，并处或单处罚金

### 侵害英雄烈士名誉、荣誉罪（第299条之一）
- 档1：情节严重 → 3年以下有期徒刑、拘役、管制或剥夺政治权利

### 赌博罪（第303条）
- 档1：以营利为目的，聚众赌博或以赌博为业 → 3年以下有期徒刑、拘役或管制，并处罚金

### 开设赌场罪（第303条第2款）
- 档1： → 5年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处罚金

### 妨害传染病防治罪（第330条）
- 档1：引起甲类传染病传播或有传播严重危险 → 3年以下有期徒刑或拘役
- 档2：后果特别严重 → 3年以上7年以下有期徒刑

### 非法采集人类遗传资源罪（第334条之一）
- 档1：情节严重 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 非法植入基因编辑、克隆胚胎罪（第336条之一）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节特别严重 → 3年以上7年以下有期徒刑，并处罚金

### 污染环境罪（第338条）
- 档1：严重污染环境 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：情节严重 → 3年以上7年以下有期徒刑，并处罚金
- 档3：有法定加重情形之一 → 7年以上有期徒刑，并处罚金

### 非法猎捕陆生野生动物罪（第341条第3款）
- 档1：情节严重 → 依照第1款处罚（5年以下有期徒刑或拘役，并处罚金；情节特别严重，5年以上有期徒刑，并处罚金）

### 破坏自然保护地罪（第342条之一）
- 档1： → 5年以下有期徒刑或拘役，并处或单处罚金

### 非法引进、释放、丢弃外来入侵物种罪（第344条之一）
- 档1：情节严重 → 3年以下有期徒刑或拘役，并处或单处罚金

### 妨害兴奋剂管理罪（第355条之一）
- 档1： → 3年以下有期徒刑或拘役，并处罚金

### 食品、药品监管渎职罪（第408条之一）
- 档1：造成严重后果或恶劣影响 → 5年以下有期徒刑或拘役
- 档2：造成特别严重后果或恶劣影响 → 5年以上10年以下有期徒刑
