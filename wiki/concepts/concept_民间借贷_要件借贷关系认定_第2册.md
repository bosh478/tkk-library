# 民间借贷类案 · 要件·借贷关系认定（第2册）

> **位置**：第五部分 一 民间借贷关系的认定和审查要点（行 1306–1573）
> **核心条文**：《民法典》第一百七十二/五百四十八条 + 《合同法》第一百九十七条 + 《民间借贷规定》第一/二/五/十五/十六/十七条

## 一、原文逐句（L4 段级提取）

### 1.1 (一) 借贷主体的认定（行 1310–1414）

**1.1.1 1. 出借人身份的认定**（行 1312–1321）：

> 2 项规则：
> 1. 借条所载出借人与借条持有人不一致时，**借条所载出借人为债权人**，但**持有人有充分证据证明债权人身份的除外**。
> 2. **未记载出借人**的借条一般可推定借条持有人为权利人，借款人抗辩**由借款人负举证责任**。
>    ⚠️ **未记载出借人的借条系出借人制作的格式模板的 → 不能推定借条持有人为权利人**。借款人抗辩的，**由借条持有人举证**。

**1.1.2 2. 借款人身份的认定**（行 1322–1341）：

> 5 项规则：
> 1. 借条上借款人的签字、捺印并非本人 → **综合考虑出具借条时的具体情形及行为合理性、借款实际由谁取得及其用途、各当事人关系及对相关情况是否知情**。
> 2. **行为人以他人名义借款** + 实际收取款项后**未将款项交付给借条上记载的名义借款人** + **不存在其他委托代理关系** → **可认定该行为人为实际借款人**。
> 3. **法定代表人/授权的人在合同上加盖法人公章** → **除《公司法》第十六条等特别规定**外 → **由法人承担相应法律后果**。法人以**法定代表人事后已无代表权 / 加盖的是假章 / 所盖之章与备案公章不一致**为由否定合同效力的 → **一般不予支持**。
> 4. **家庭成员代签**是否构成**表见代理** → 出借人**应当承担举证责任**（不仅**代理行为存在诸如委托书/合同书/印章等有权代理的客观表象**，而且**证明其善意且无过失地相信行为人具有代理权**）。
> 5. **向中间人还款**是否构成履行 → 在出借人**未约定由他人代为收款**的情况下，**借款人向中间人还款的 → 不构成已履行还款义务**。若主张中间人表见代理，按表见代理规则审查。

**1.1.3 3. 网络平台是否构成借贷或担保主体**（行 1342–1414）：

> 3 项规则：
> 1. **网络贷款平台仅提供贷款平台或信息中介服务**，且**未受让债权或承担债务**的 → **一般不构成借贷主体**。
> 2. **网络贷款平台并未承诺对贷款提供担保** → **平台提供者不承担担保责任**。
> 3. **网络贷款平台提供者通过网页/广告/其他媒介明示或他证证明为借贷提供担保** → **该网络贷款平台提供者具有担保人身份**，**应承担担保责任**。**具体担保形式** → 视**网络贷款平台提供的承诺或宣传内容**确定。

**规范指引**：
- 《民法典》第一百七十二条（**表见代理**：相对人有理由相信行为人有代理权的，代理行为有效）。
- 《民法典》第五百四十八条（**债权转让抗辩**：债务人对让与人的抗辩可向受让人主张）。
- 《民间借贷规定》第一条（**民间借贷定义** + 金融机构不适用本规定）。
- 《民间借贷规定》第二条（**借据/收据/欠条等债权凭证** + **未载明债权人**的受理与驳回）。
- 《民间借贷规定》第五条（**非法集资等犯罪 → 裁定驳回起诉 + 移送公安/检察机关**）。

### 1.2 (二) 借贷合意的认定（行 1438–1500）

> 2 项规则：
> 1. **是否已形成借贷合意**；
> 2. **意思表示瑕疵的认定**。

### 1.3 (三) 借贷合同成立与生效的认定（行 1502–1546）

> 2 项：
> 1. **自然人之间的借贷合同**（要式性 / 实践性 / 推定规则）；
> 2. **除自然人之间以外的其他民间借贷合同**（书面形式 / 内容条款）。

**规范指引**：
- 《民法典》第六百七十九条（自然人借款合同自交付时生效 / **自然人之间借款另有约定的除外**）。
- 《合同法》第一百九十七条（**借款合同采用书面形式** + 借款合同内容 7 项：种类/币种/用途/数额/利率/期限/还款方式）。
- 《民间借贷规定》第二条（借据等债权凭证）。
- 《民间借贷规定》第十五条（**基础法律关系**审理）。
- 《民间借贷规定》第十六条（**已偿还借款的举证** + **借贷行为尚未实际发生的综合判断**）。
- 《民间借贷规定》第十七条（**仅依据转账凭证 → 被告抗辩 + 原告仍应就借贷关系成立举证**）。

**典型案例 3 件**：
1. **赵俊诉项会敏、何雪琴民间借贷纠纷案**（**最高人民法院公报案例** / 上海市长宁区人民法院 / (2012)长民四(民)初字第 1136 号）。
   > 裁判要旨：**夫妻一方具有和第三人恶意串通、通过虚假诉讼虚构婚内债务嫌疑**的，该夫妻一方**单方自认债务** → **并不必然免除"出借人"对借贷关系成立并生效的事实应承担的举证责任**。**借款人配偶未参加诉讼** + **出借人及借款人均未明确表示放弃该配偶可能承担的债务份额** → **应依法追加与案件审理结果具有利害关系的借款人配偶作为第三人**。出借人**仅提供借据**佐证借贷关系的 → **应深入调查辅助性事实以判断借贷合意的真实性**（举债必要性/款项用途合理性）。**大额借款仅有借据无任何交付凭证** + **陈述有重大疑点或矛盾** → **应依据证据规则认定"出借人"未完成举证义务，判决驳回**。
2. **赖芳华诉张一飞民间借贷纠纷案**（人民法院案例选 / 广东省深圳市中级人民法院 / (2017)粤 03 民终 2559 号）。
   > 裁判要旨：《民间借贷规定》第十七条所规定的原告和被告应承担的**举证责任**，是**行为意义上的举证责任**，**不是结果意义上的举证责任**。**如双方均不能完成各自的行为意义上的举证责任**导致款项性质这一事实**真伪无法查清**时 → **仍应由原告承担结果意义上的举证责任即败诉风险**。
3. **张某某与余某某、刘某某民间借贷纠纷案**（人民法院案例选 / 浙江省宁波市中级人民法院 / (2011)浙甬商终字第 613 号）。
   > 裁判要旨：出借人在庭审中承认已经收到了借款人归还的本金和利息 → 但认为该本金和利息系用于归还**另一笔借款** → 借款人则**否认存在另一笔借款** → 此时**应当由出借人对其诉讼主张存在两笔借款的事实承担举证责任**，如不能举证证明 → **应根据谁主张谁举证的原则，承担未能举证的法律后果**。

### 1.4 (四) 其他法律关系的识别认定（行 1548–1571 + 典型案例）

> 识别借贷关系还是其他法律关系（如买卖/委托/合伙等）。

## 三、实务问答（FAQ）

> **Q1: 出借人身份 3 情形？**
> 答：载明 / 未载明推定 / **格式模板不推定**（行 1313–1320）。

> **Q2: 借款人身份 5 项？**
> 答：签印 / **实际收款人** / **公章假章一般不支持** / **家庭表见代理** / **中间人还款不构成履行**（行 1323–1340）。

> **Q3: 网络平台 3 项？**
> 答：**信息中介不构成借贷** / **不承诺不担保** / **承诺即担保**（行 1343–1351）。

> **Q4: 民间借贷定义？**
> 答：自然人/法人/非法人组织之间资金融通；**金融机构不适用**（民间借贷规定第 1 条）。

> **Q5: 非法集资？**
> 答：**裁定驳回 + 移送公安/检察**（民间借贷规定第 5 条）。

> **Q6: 已偿还借款举证？**
> 答：被告举证 + **原告仍应就借贷关系存续举证**（行 1533–1535）。

> **Q7: 借贷未实际发生综合判断 6 因素？**
> 答：金额/交付/经济能力/交易方式/交易习惯/财产变动（行 1537–1539）。

> **Q8: 行为意义 vs 结果意义举证？**
> 答：行为意义 + 双方均不能 + **结果意义原告败诉**（赖芳华案，行 1500–1502 区段）。

> **Q9: 夫妻恶意串通 + 虚假诉讼？**
> 答：单方自认不免除举证 + **追加配偶为第三人**（赵俊案 / 最高法公报）。
