# 民法典适用大全·侵权责任卷（一）·第三章责任主体的特殊规定

## 📋 章节概览

| 字段 | 内容 |
|------|------|
| 来源 | [[《民法典适用大全》侵权责任卷1 2023年 1164-1207.md]] |
| 章节 | 第三章 责任主体的特殊规定 |
| 条文范围 | 《民法典》第1188条～第1201条（共14条） |
| 核心主题 | 特殊主体责任（监护、用工、网络侵权、安全保障、教育机构） |

## 条文结构

| 条文 | 主题 | 法理要点 |
|------|------|----------|
| 第1188条 | 监护人责任 | 无/限制民事行为能力人致害由监护人承担责任 |
| 第1189条 | 委托监护时的责任 | 监护人委托他人监护的，由监护人承担责任；受托人有过错的承担相应责任 |
| 第1190条 | 暂时丧失意识 | 完全民事行为能力人暂时丧失意识致害的，过错责任；无过错根据经济状况适当补偿 |
| 第1191条 | 用人单位责任 | 用人单位的工作人员因执行工作任务致害的，由用人单位承担责任 |
| 第1192条 | 个人劳务关系责任 | 提供劳务一方因劳务致害的，由接受劳务一方承担责任 |
| 第1193条 | 承揽人责任 | 承揽人在完成工作过程中致害的，定作人不承担侵权责任（定作人有过错的除外） |
| 第1194条 | 网络侵权责任 | 网络用户、网络服务提供者利用网络致害的应承担责任 |
| 第1195条 | 通知删除规则 | 权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等措施 |
| 第1196条 | 反通知规则 | 网络用户接到转送通知后可提交不存在侵权行为的声明 |
| 第1197条 | 网络服务提供者连带责任 | 知道或应当知道网络侵权未采取必要措施的，承担连带责任 |
| 第1198条 | 安全保障义务 | 经营场所、公共场所的经营者、管理者或群众性活动的组织者未尽到安全保障义务致害的应承担责任 |
| 第1199条 | 教育机构责任（无民事行为能力人） | 无民事行为能力人在教育机构学习生活期间受到人身损害，教育机构承担责任 |
| 第1200条 | 教育机构责任（限制民事行为能力人） | 限制民事行为能力人在教育机构学习生活期间受到人身损害，教育机构未尽到教育管理职责的应承担责任 |
| 第1201条 | 第三人侵害时教育机构的补充责任 | 第三人承担侵权责任；教育机构未尽到管理职责的承担补充责任 |

## 核心制度深度解读

### 一、监护人责任体系（第1188-1190条）

| 情形 | 法条 | 责任承担 |
|------|------|----------|
| 监护人责任 | 第1188条 | 监护人承担侵权责任；尽到监护职责的可减轻责任 |
| 委托监护 | 第1189条 | 监护人承担侵权责任；受托人有过错的承担相应责任 |
| 暂时丧失意识 | 第1190条 | 完全民事行为能力人有过错的承担侵权责任；无过错的根据经济状况适当补偿 |

**关键要点**：
- 监护人责任是无民事行为能力人/限制民事行为能力人致害的核心救济。
- 单位担任监护人的，参照适用。
- "尽到监护职责"是减轻责任的关键，由监护人举证证明。

### 二、用工责任体系（第1191-1193条）

| 类型 | 法条 | 责任承担 |
|------|------|----------|
| 用人单位责任 | 第1191条 | 用人单位承担侵权责任；工作人员有故意或重大过失的，用人单位可追偿 |
| 个人劳务责任 | 第1192条 | 接受劳务一方承担侵权责任；提供劳务方有故意或重大过失的，接受劳务方可追偿 |
| 承揽人责任 | 第1193条 | 承揽人致害的，定作人不承担责任；定作人对定作、指示或选任有过错的，承担相应责任 |

**承揽关系 vs 劳务关系 区分**：
- 劳务关系：雇员从事雇主安排的工作。
- 承揽关系：定作人交付工作成果，承揽人独立完成。

### 三、网络侵权责任体系（第1194-1197条）

| 规则 | 法条 | 内容 |
|------|------|------|
| 一般规则 | 第1194条 | 网络用户、网络服务提供者利用网络致害的应承担责任 |
| 通知删除 | 第1195条 | 权利人通知→网络服务提供者及时采取必要措施 |
| 反通知 | 第1196条 | 网络用户提交不存在侵权行为的声明→转送权利人→权利人15日内未起诉的可恢复 |
| 知道规则 | 第1197条 | 网络服务提供者知道或应当知道网络侵权未采取必要措施的，承担连带责任 |

**实务要点**：
- 通知删除规则是"避风港原则"的中国化表达。
- "知道"包括"明知"和"应知"。
- 网络服务提供者未及时采取必要措施的，对损害扩大部分与侵权人承担连带责任。

### 四、安全保障义务（第1198条）

**义务主体**：经营场所、公共场所的经营者、管理者或群众性活动的组织者。

**典型场所**：宾馆、商场、银行、车站、机场、体育场馆、娱乐场所等。

**义务内容**：合理限度范围内的安全保障义务。

**责任承担**：
- 未尽到安全保障义务致害的，承担侵权责任。
- 第三人侵权时，安全保障义务人未尽到安全保障义务的，承担相应的补充责任。

### 五、教育机构责任体系（第1199-1201条）

| 受害人年龄 | 法条 | 归责原则 |
|------------|------|----------|
| 无民事行为能力人 | 第1199条 | 过错推定（教育机构能证明尽到教育管理职责的除外） |
| 限制民事行为能力人 | 第1200条 | 过错责任（教育机构未尽到教育管理职责的承担责任） |
| 第三人侵害 | 第1201条 | 第三人承担侵权责任；教育机构未尽到管理职责的承担补充责任 |

**关键区别**：
- 对无民事行为能力人：教育机构举证免责（过错推定）。
- 对限制民事行为能力人：受害人举证教育机构未尽职责。

## ❓ 常见问题

> 问：监护人责任如何承担？
> 答：无/限制民事行为能力人致害的，由监护人承担侵权责任。监护人尽到监护职责的可减轻责任。委托他人监护的，由监护人承担；受托人有过错的承担相应责任（第1188-1189条）。

> 问：用人单位责任如何承担？
> 答：用人单位的工作人员因执行工作任务致害的，由用人单位承担侵权责任。工作人员有故意或重大过失的，用人单位可向其追偿（第1191条）。

> 问：什么是"通知删除"规则？
> 答：第1195条规定，权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施。网络服务提供者接到通知后应及时采取必要措施；未及时采取的，对损害扩大部分与侵权人承担连带责任。

> 问：什么是反通知规则？
> 答：第1196条规定，网络用户接到转送的通知后可提交不存在侵权行为的声明。声明应转送权利人；权利人15日内未向有关部门投诉或起诉的，网络服务提供者可以恢复相关内容。

> 问：什么是安全保障义务？
> 答：经营场所、公共场所的经营者、管理者或群众性活动的组织者负有的合理限度范围内的安全保障义务。未尽到该义务致害的，应承担侵权责任（第1198条）。

> 问：教育机构责任如何区分受害人年龄？
> 答：无民事行为能力人受到人身损害的，教育机构承担过错推定责任；限制民事行为能力人受到人身损害的，教育机构承担过错责任。第三人侵权时，教育机构未尽到管理职责的承担补充责任。

> 问：劳务关系与承揽关系的责任区别？
> 答：劳务关系中，提供劳务一方因劳务致害的，由接受劳务一方承担责任。承揽关系中，承揽人在完成工作过程中致害的，定作人不承担责任，但定作人对定作、指示或选任有过错的，承担相应责任。

## 适用指引

### 网络侵权维权实务

1. **取证**：及时通过公证、可信时间戳等方式固定侵权证据。
2. **通知**：向网络服务提供者发出书面通知（包含权利人信息、侵权内容、要求采取的措施等）。
3. **等待处理**：网络服务提供者应在合理期限内采取必要措施。
4. **未处理时**：可起诉网络服务提供者要求其承担连带责任。
5. **反通知应对**：如遇反通知，应在15日内向有关部门投诉或起诉。

### 安全保障义务人责任

1. **场所范围**：经营场所、公共场所、群众性活动场所。
2. **义务内容**：危险预防义务、危险消除义务、救助义务。
3. **第三人侵权**：安全保障义务人未尽到义务的，承担相应的补充责任。
4. **追偿权**：承担补充责任后可向第三人追偿。

### 教育机构责任实务

1. **归责原则区分**：根据受害人年龄确定归责原则。
2. **免责事由**：教育机构应举证证明已尽到教育管理职责。
3. **第三人侵权**：明确教育机构的补充责任性质。
