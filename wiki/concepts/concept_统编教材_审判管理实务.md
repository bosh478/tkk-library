# 审判管理实务

## 基本信息

- **图书名称**：审判管理实务
- **出版来源**：全国法官培训统编教材
- **组织编写**：最高人民法院
- **主编**：邓修明
- **出版社**：人民法院出版社
- **出版时间**：2025年8月
- **ISBN**：978-7-5109-4587-8

## 内容概述

《审判管理实务》是全国法官培训统编教材之一，由最高人民法院组织编写，主编邓修明。本书立足于新时代审判管理工作，从审判管理的内涵、原则、理念，到上级法院对下监督、院庭长管理、审判委员会运行，再到审判质量管理指标体系、数字化建设、司法数据分析应用和司法数据管理等多个维度，系统阐述了审判管理的理论框架和实践路径。

## 第一章 新时代审判管理的基本内涵、主要原则和总体理念

### 一、审判管理的演进历程

| 阶段 | 时间 | 主要标志 |
|------|------|----------|
| 探索阶段 | 1999年起 | 《人民法院五年改革纲要》首次提出"审判管理"概念 |
| 发展阶段 | 2009-2011年 | 审判管理办公室设立，《关于加强人民法院审判管理工作的若干意见》印发 |
| 创新阶段 | 2015年后 | 司法责任制改革，审判权运行机制改革 |
| 深化阶段 | 2023年后 | 审判管理现代化，"大审判管理观" |

### 二、新时代审判管理的必要性

1. **维护国家法律统一的必然要求**：我国3500多家法院、每年4500多万起案件，需统一程序管理规范、审判质量评价标准、裁判尺度
2. **提高审判工作水平、实现科学发展的重要举措**：统一标准才能形成比较，推动经验推广
3. **引领社会舆论对法院工作作出正确评价的重要途径**：科学方法规制审判管理，建立规范统一的评价标准

### 三、审判管理的主要原则

1. **坚持依法管理**：严格遵守宪法、法院组织法、三大诉讼法
2. **坚持科学管理**：遵循司法规律与现代管理理念相结合
3. **坚持主动管理**：主动发现和掌握审判质效，有针对性研究提出管理举措
4. **坚持系统管理**：形成全员参与、上下联动、分工协作、齐抓共管的工作格局
5. **坚持效果管理**：将提升案件办理质效作为出发点和落脚点
6. **坚持数字管理**：向科学技术要生产力，数字化赋能审判管理

### 四、新时代审判管理的总体理念

#### （一）树立全院全条线抓审判管理念

- **各部门协同抓**：审判管理专职部门发挥枢纽作用，政务管理、队伍建设等部门协同配合
- **各层级联动抓**：上级人民法院加强对下指导，上下级法院之间业务联动
- **各条线贯通抓**：立案、审判、执行等各条线建立有效工作配合机制

#### （二）树立全案全周期抓审判管理念

- **各案件类型统筹抓**：各种类型案件及一审、二审、再审统筹纳入管理
- **各审判管理主体合力抓**："上级院统筹抓、院庭长带头抓、业务庭重点抓、承办人自觉抓、审管办专职抓"
- **各办案环节闭环抓**：从前端矛盾纠纷源头化解、中端审判执行，到后端社会治理一体推进

## 第二章 上级人民法院对下审判监督管理工作机制

### 一、对下审判监督管理必须依法开展

1. **二审程序监督**：依据《刑事诉讼法》第233条、《民事诉讼法》第175条、《行政诉讼法》第87条进行全面审查
2. **审判监督程序监督**：对生效裁判的再审监督，依据各诉讼法规定的14种（民事）、5种（刑事）等情形
3. **死刑复核监督**：最高人民法院依法复核死刑案件

### 二、对下审判监督管理的路径

#### （一）落实审级监督指导

**提级管辖的类型**（依据《最高人民法院关于加强和规范案件提级管辖和再审提审工作的指导意见》法发〔2023〕13号）：
- 涉及重大国家利益、社会公共利益的案件
- 新类型且案情疑难复杂的案件
- 具有示范引领价值的案件
- 具有法律适用指导意义的案件
- 近3年裁判生效的同类案件存在重大法律适用分歧的案件
- 由上一级人民法院一审更有利于公正审理的案件

**再审提审**：中级以上人民法院对符合条件的再审案件一般应当提审，最高人民法院可提审具有普遍法律适用指导意义的案件

#### （二）法律适用问题请示答复

依据《最高人民法院关于法律适用问题请示答复的规定》（法〔2023〕88号），以下情形可提出请示：
- 法律、法规、司法解释、规范性文件等没有明确规定，适用法律存在重大争议的
- 对法律规定具体含义的理解存在重大争议的
- 司法解释制定时所依据的客观情况发生重大变化的
- 类似案件裁判规则明显不统一的

#### （三）加强条线审判业务指导

1. **用好人民法院案例库**：截至2025年7月，库案例达5040余件，实现常见罪名、多发案由全覆盖
2. **加强指导性案例工作**：符合社会广泛关注、法律规定比较原则、具有典型性、疑难复杂或新类型等标准
3. **用足用好法答网**：最高人民法院、高级人民法院选任专家负责答疑，一般15个工作日内发布意见

## 第三章 院庭长监督管理工作机制

### 一、院庭长的监督管理职权

**主要内容包括**：
1. 配置审判资源
2. 部署综合工作
3. 审批程序性事项
4. 监管审判质效
5. 监督"四类案件"
6. 阅核案件
7. 进行业务指导
8. 作出综合评价
9. 检查监督纪律作风

**工作原则**：
- 依职权履责：在权责清单范围内履行
- 边界内监督：充分尊重审判组织办案主体地位
- 组织化行权：院庭长不得对未参加审理的案件发表倾向性意见
- 全过程留痕：在办案平台全程记录
- 循规律担责：故意或重大过失才承担责任

### 二、案件阅核机制

**阅核方式**：以裁判文书为抓手，重点审核程序、文书说理、法律适用、裁判尺度、利于执行、政治效果、法律效果、社会效果

**阅核范围**：

| 类型 | 范围 |
|------|------|
| 刚性阅核 | "四类案件"、审判委员会讨论决定的案件、死刑案件、抗诉案件等 |
| 弹性阅核 | 随机抽核+可不提请阅核的案件（常见多发案件、尺度已统一案件等） |

**六类可不提请阅核的案件**：
1. 常见多发、已有典型案例可供参考的
2. 裁判尺度已相对统一、争议不大的
3. 存在示范性判决可参照办理的
4. 适用特别程序、督促程序或公示催告程序的
5. 以撤诉方式结案的
6. 根据审判实际可以不提请阅核的

### 三、对"四类案件"的监督管理

**"四类案件"范围**：
1. 重大、疑难、复杂、敏感的案件
2. 涉及群体性纠纷或者引发社会广泛关注，可能影响社会稳定的案件
3. 与本院或者上级人民法院的类案裁判可能发生冲突的案件
4. 有关单位或者个人反映法官有违法审判行为的案件

**监督管理方式**：
- 调整分案
- 要求合议庭报告案件进展、评议结果
- 要求提供类案裁判文书或制作类案检索报告
- 审阅案件庭审提纲、审理报告
- 调阅卷宗、旁听庭审
- 要求复议（一般不超过两次）
- 决定提交专业法官会议、审判委员会讨论

### 四、专业法官会议

**制度定位**：为审判组织和院庭长提供咨询意见的内部工作机制，具有专业把关、审判监督、业务培训和人才培养等功能

**讨论范围**：
- 独任庭认为需要提交讨论的
- 合议庭内部无法形成多数意见的
- 有必要统一法律适用的
- 属于"四类案件"范围的
- 其他需要提交讨论的

**讨论规则**：按汇报→询问→发言→讨论→主持人总结的次序进行，主持人最后发表意见

## 第四章 审判委员会工作机制

### 一、审判委员会的职能定位

依据《人民法院组织法》第37条第1款：
1. 总结审判工作经验
2. 讨论决定重大、疑难、复杂案件的法律适用
3. 讨论决定本院已经发生法律效力的判决、裁定、调解书是否应当再审
4. 讨论决定其他有关审判工作的重大问题

### 二、审判委员会的运行机制

**会议形式**：全体会议和专业委员会会议（中级以上人民法院）

**议题提交机制**：
- **应当提交审判委员会讨论的案件**：涉及国家安全外交社会稳定等敏感案件、本院已生效裁判确有错误需再审的案件、人民检察院依照审判监督程序提出抗诉的刑事案件、法律适用规则不明的新类型案件、拟宣告被告人无罪的案件等
- **可以提交审判委员会讨论的案件**：合议庭对法律适用问题意见分歧较大经专业法官会议难以作出决定的案件、拟作出的裁判与类案裁判可能发生冲突的案件等

**议事规则**：遵循民主集中制，委员按法官等级和资历由低到高顺序发表意见，主持人最后发表意见，按全体组成人员过半数多数意见作出决定

**列席机制**：检察长依照《最高人民法院、最高人民检察院关于人民检察院检察长列席人民法院审判委员会会议的实施意见》列席

## 第五章 审判质量与流程管理

### 一、审判质量管理

**价值目标**：
- 法治层面：保障、促进与规范审判权、审判监督管理权依法行使
- 队伍建设层面：让担当履职的法官有获得感、成就感

**管理作用**：
- 事前引导：通过明确的质量评价标准引导审判权主体
- 事中保障：减少实体差错、程序瑕疵发生
- 事后评价：量化开展数据统计汇总，有机衔接奖惩机制
- 全面监督：为建立健全司法监督管理制约机制奠定基础

### 二、审判流程管理

**主要内容**：从立案到执行所有与案件审理相关的程序和环节的管理

**价值目标**：
- 促进程序公正
- 保障司法公正
- 规范诉讼程序
- 提升审判质效
- 实现审判资源优化配置

### 三、案件评查

**评查结果等级划分**：
- **一类案件**：审理程序合法、认定事实清楚、适用法律和裁判结论正确、文书制作规范
- **二类案件**：裁判结论正确，但存在程序、文书瑕疵
- **三类案件**：实体裁判错误或严重违反法律、司法解释规定

**评查方式**：
- 常规评查：定期开展的常态化评查
- 专项评查：针对特定范围案件或特定事项
- 重点评查：对重点案件或事项开展的评查

**评查结果运用**：
- 通报公示
- 质量讲评
- 决策参考
- 考核评价
- 责任追究

### 四、审限管理（以民事案件审限制度为视角）

**审限的剔除情形**：
- 因当事人申请新证人到庭、调取新证据、申请重新鉴定导致延期审理的期间
- 公告、鉴定期间
- 审理管辖权异议和处理管辖争议的期间
- 中止审理至恢复审理的期间
- 庭外和解期间

**超审限原因**：
1. "重实体，轻程序"问题依然存在
2. 人案矛盾迫使法官被动超审限
3. 规则不明晰给"隐性超审限"留下弹性空间

## 第六章 审判质量管理指标体系

### 一、指标体系的构建

**基本原则**：
1. 以人民为中心原则
2. 科学合理原则
3. 系统完善原则
4. 简便易行原则
5. 精准务实原则

### 二、指标体系的基本内容

**指标类型**：

| 类型 | 说明 |
|------|------|
| 综合指标 | 案-件比（唯一综合指标，也是核心指标） |
| 质量指标 | 聚焦司法办案的规范性与精准度，如上诉率、申诉申请再审率等 |
| 效率指标 | 追踪影响审判效率的关键因素，如审限内结案率、平均结案时间等 |
| 效果指标 | 评估司法活动在治理效能方面的作用，如纠纷多元化解情况等 |

**案-件比**：通过"案"数与经历的所有审判执行程序"件"数的比值，全面衡量办案的质量、效率、效果

### 三、指标体系的运用

**正确理念**：
- 关键少数要树立正确的政绩观
- 把握好共性和个性的关系
- 科学看待指标短期波动
- 坚持服务审判的功能定位

**加强"反管理"治理**：坚决纠治"数据注水""美化数据"等行为

## 第七章 审判管理数字化建设和应用

### 一、推进审判管理数字化的必要性

1. 更好服务国家和社会治理
2. 更好破解审判管理难题
3. 更好规范司法权力运行
4. 更好支撑和服务审判工作

### 二、审判管理数字化建设的基本理念

1. 注重系统集成
2. 注重业务主导
3. 注重数据驱动
4. 注重智能赋能
5. 注重动态开放
6. 注重安全规范

### 三、数字技术的应用实践

**"一张网"建设**：
- 统一办案办公平台
- 人民法院在线服务两端应用
- 业务中台、数据中台、智能中台三中台
- 采取"一级部署、双活架构"方式

**大数据融通**：贯通四级法院的司法大数据库，实现数据实时同步汇聚

**司法人工智能应用**：
- 庭审记录
- 多种诉讼语音支持
- 类案检索
- 证据要点提取
- 文书写作辅助

## 第八章 司法审判数据分析和应用

### 一、司法审判数据分析基础

**统计指标类型**：
- **总量指标**：反映总体规模或水平，如收案数、结案数
- **相对数指标**：两个有联系指标的比较，如案件增长率
- **平均数指标**：说明总体一般水平，如法官人均结案数

### 二、司法审判数据分析的具体应用

1. **强化办案流程管理**：疏通具体流程堵点、全面优化办案流程
2. **深化案件质量管理**：促进法律适用统一、优化审级监督效果
3. **辅助队伍管理**：激发队伍活力、加强廉政风险防控
4. **提供决策参考**：服务于法律规范体系完善、评估改革成效、优化资源配置
5. **服务国家和社会治理**：形成司法建议、预警风险隐患、助力新业态治理

### 三、司法审判数据分析研判会商机制

**数据会商机制**：在院主要领导主持下，由审判管理部门牵头，各审判业务部门定期围绕业务数据集中"把脉会诊""对症下药"

**会商内容**：
- 数据收集与初步分析
- 撰写司法审判数据分析报告
- 会议组织
- 决议督办落实
- 成果转化

## 第九章 司法数据管理

### 一、司法数据的分类分级

**数据分类**：
- 刑事案件数据
- 民事案件数据
- 行政案件数据
- 执行案件数据

**数据分级**：
| 级别 | 判断标准 |
|------|----------|
| 核心数据 | 直接影响国家安全、经济运行、社会秩序、公共利益 |
| 重要数据 | 对上述领域产生严重影响 |
| 一般数据 | 公开数据、敏感数据 |

### 二、司法数据全流程管理体系

**录入原则**：
- 合法性原则：采集范围限定于审判执行必要信息
- 真实性原则：准确反映案件客观事实
- 完整性原则：全部如实填报必填字段
- 及时性原则：按时效要求及时录入

**"四位一体"责任体系**：
- 承办法官：承担数据真实性主体责任
- 书记员：履行录入操作责任
- 法官助理：承担数据规范性审核责任
- 技术部门：承担系统保障责任

### 三、司法数据公开

**面向公众的公开**：
1. 互联网公布裁判文书（中国裁判文书网）
2. 互联网庭审公开
3. 司法统计数据公开
4. 互联网执行信息公开
5. 司法案例公开（人民法院案例库）
