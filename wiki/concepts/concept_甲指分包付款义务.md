## 概念定义

**甲指分包**（发包方指定分包）是指建设工程施工中，在总承包框架下，发包方指定特定的专业分包方，并要求总包方与指定分包方签订专业分包合同或三方共同签订专业分包合同的特殊项目管理与承包模式。

## 合同效力

- **不直接认定为无效**：基于意思自治原则，未违反效力强制性规范（如资质问题、违法招标等）的，一般有效
- 部门规章《房屋建筑和市政基础设施工程施工分包管理办法》第7条"不得直接指定分包"非司法认定无效依据

## 付款主体类型

### 总包方付款责任

| 情形 | 结论 |
|------|------|
| 认定总包方是分包合同相对方 | 总包方为付款义务主体（除非明确约定发包方付款） |
| 实质合同在分包方与发包方之间，总包方有转付款义务 | 总包方未及时转付的，承担付款责任 |

### 发包方付款责任

| 情形 | 结论 |
|------|------|
| 认定发包方是实际施工合同相对方 | 发包方为付款义务主体 |
| 违法分包情形 | 分包方可主张发包方在欠付工程款范围内承担责任（《建工司法解释一》第43条） |
| 发包方直接付款承诺 | 合法有效，非债务加入 |

### 责任承担原则

- 一般情况下，发包方和总包方**不承担共同付款责任或连带付款责任**
- 需谨慎认定债务加入

## 概念区分

| 区分项 | 说明 |
|--------|------|
| 付款义务主体 ≠ 工程管理主体 | 总包方参与施工管理 ≠ 总包方是付款主体 |
| 付款义务 ≠ 付款流程 | 总包付款模式（发→总→分）是对流程的约定，非义务的约定 |
| 付款义务主体 ≠ 质量责任主体 | 依据《建工司法解释一》第13条，发包方是质量缺陷责任承担人 |

## 审查理念

**"尊重约定、探求真意、权责相当"**

1. **以书面条款为起点**：合同有明确约定的从约定
2. **参考"履行治愈规则"**：实际履行行为证明实质合同关系
3. **考察交易背景**：磋商过程、交易习惯、行业惯例
4. **权责相当**：分包工程的实际控制主体同时承担相应付款义务

## 审查要点

### 三方协议重要条款

| 条款 | 审查要点 |
|------|----------|
| 签约主体列明方式 | 不同列明方式反映发包方地位差异 |
| 价款支付方式 | 发包方直接付款 vs 总包付款模式 |
| 进度款/结算款决定主体 | 有控制权和决定权者可能是实际合同相对方 |
| 总包方权利义务 | 权利义务简单（仅管理协调、转付款）→ 可能非付款主体 |
| 违约责任条款 | 直接体现付款权义相对方 |
| 索赔条款 | 谁有权向谁主张/不得向谁主张 |

### "背靠背"条款

仅影响总包方付款**条件**是否成就，**不影响**付款主体认定
