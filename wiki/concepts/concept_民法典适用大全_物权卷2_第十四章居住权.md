# 民法典第十四章【居住权】综合

## 章节目录

本章共 6 条（Articles 366-371），是**民法典新设立的用益物权类型**——居住权（应对老龄化、以房养老等社会需求）。

| 法条 | 主题 | 关键制度 |
|------|------|---------|
| 第366条 | 居住权的概念 | 他人住宅 + 占有使用 + 生活居住需要 |
| 第367条 | 居住权合同 | 书面形式 + 内容 |
| 第368条 | 居住权的设立 | 无偿设立（约定除外）+ 登记 |
| 第369条 | 居住权的限制 | 不得转让、继承 + 不得出租（约定除外） |
| 第370条 | 居住权的消灭 | 期满或死亡 + 注销登记 |
| 第371条 | 遗嘱设立居住权 | 参照适用 |

## 核心制度一：居住权的概念（第366条）

### 第366条 法条原文

> 居住权人有权按照合同约定，**对他人的住宅**享有占有、使用的用益物权，以**满足生活居住**的需要。

**核心特征**：

| 特征 | 内容 |
|------|------|
| **客体** | **他人的住宅** |
| **权能** | 占有、使用（**无收益、无处分**） |
| **目的** | **满足生活居住**需要（不能用于经营） |
| **性质** | **用益物权**（物权编新设） |
| **设立方式** | 合同 / 遗嘱（参第367、371条） |

**立法意义**：
- 应对人口老龄化（以房养老）
- 离婚后居住问题
- 公租房等社会保障性住房

## 核心制度二：居住权合同（第367条）

### 第367条 法条原文

> 设立居住权，当事人应当采用**书面形式**订立居住权合同。

**形式要求**：**书面形式**（要式合同）。

**合同一般内容**（《民法典适用大全》释义）：

1. 当事人的姓名或者名称和住所
2. 住宅的位置
3. 居住的条件和要求
4. 居住期限
5. 解决争议的方法

## 核心制度三：居住权的设立（第368条）

### 第368条 法条原文

> 居住权**无偿设立**，但是当事人另有约定的除外。设立居住权的，应当向登记机构申请居住权登记。**居住权自登记时设立**。

### 三大要点

| 要点 | 规则 |
|------|------|
| **无偿设立** | 默认**无偿**（福利性质）；**当事人另有约定的除外**（可约定有偿） |
| **登记生效** | **登记时设立**（不是合同生效时） |
| **登记机构** | 向登记机构申请居住权登记 |

**设立时点对比**：

| 物权类型 | 设立时点 |
|---------|---------|
| 土地承包经营权 | 合同生效时设立 |
| 建设用地使用权 | **登记时设立** |
| 居住权 | **登记时设立** |
| 地役权 | 合同生效时设立（登记对抗） |

## 核心制度四：居住权的限制（第369条）

### 第369条 法条原文

> 居住权**不得转让、继承**。设立居住权的住宅**不得出租**，但是当事人另有约定的除外。

### 三大禁止+一个例外

| 禁止 | 例外 |
|------|------|
| **不得转让** | 无 |
| **不得继承** | 无 |
| 不得出租 | 当事人**另有约定的除外** |

**立法理由**：
- 居住权是**人役权性质**（为特定人的生存需要而设）
- 不能脱离人身属性独立存在
- 因此不得转让、继承

## 核心制度五：居住权的消灭（第370条）

### 第370条 法条原文

> 居住权期限届满或者居住权人死亡的，居住权消灭。居住权消灭的，应当及时办理注销登记。

### 消灭事由

1. **期限届满**（合同约定）
2. **居住权人死亡**（人身属性消灭）

### 注销登记义务

居住权消灭的，**应当及时办理注销登记**。

## 核心制度六：遗嘱设立居住权（第371条）

### 第371条 法条原文

> 以**遗嘱方式**设立居住权的，**参照适用本章的有关规定**。

**遗嘱设立的特殊性**：
- 通过遗嘱方式设立（合同方式以外的另一种设立方式）
- 参照适用本章规定
- 涉及继承法的相关规定

## 适用指引综合

### 居住权 vs 类似权利对比

| 维度 | 居住权 | 租赁权 | 地役权 |
|------|-------|-------|-------|
| **性质** | 用益物权 | 债权 | 用益物权 |
| **客体** | 他人住宅 | 他人住宅 | 他人不动产 |
| **权能** | 占有、使用 | 占有、使用 | 按约定利用 |
| **期限** | 合同约定（一般长期） | 合同约定（一般短期） | 合同约定 |
| **转让** | 不得 | 可以 | 不得单独转让 |
| **继承** | 不得 | 可以 | 不得单独转让 |
| **消灭** | 期满或死亡 | 期满或解除 | 期满或法定事由 |

### 审判核心要点

1. **无偿设立**：默认无偿；可约定有偿
2. **登记设立**：登记时设立（不是合同生效）
3. **禁止转让继承**：人役权性质，不可转让继承
4. **不得出租**：默认禁止；可约定出租
5. **期限届满或死亡**：消灭事由

## 实务问答精选

> **问**：居住权能否转让？
>
> **答**：**不能**（《民法典》第369条）。居住权是人役权性质的用益物权，**不得转让、继承**。

> **问**：居住权能否出租？
>
> **答**：**默认不得出租**（《民法典》第369条）。当事人另有约定的除外（如以房养老中可约定使用权人将房屋出租以养老）。

> **问**：居住权何时设立？
>
> **答**：**登记时设立**（《民法典》第368条）。不是合同生效时，而是登记时。

> **问**：居住权是否必须有偿？
>
> **答**：**默认无偿设立**（《民法典》第368条）。当事人另有约定的除外。

> **问**：居住权因什么原因消灭？
>
> **答**：① 居住权期限届满；② 居住权人死亡（《民法典》第370条）。消灭后应当及时办理注销登记。

> **问**：遗嘱能否设立居住权？
>
> **答**：**可以**（《民法典》第371条）。以遗嘱方式设立居住权的，参照适用本章有关规定。
