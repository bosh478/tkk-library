## 核心制度深度解读

### 一、有限责任公司设立条件（第23条）

**条文原文**：设立有限责任公司，应当具备下列条件：（一）股东符合法定人数；（二）有符合公司章程规定的全体股东认缴的出资额；（三）股东共同制定公司章程；（四）有公司名称，建立符合有限责任公司要求的组织机构；（五）有公司住所。

**五项设立条件的体系性理解**：

| 条件 | 立法本意 | 实务要点 |
|------|----------|----------|
| 1. 股东符合法定人数 | 有限责任公司兼具资合与人合属性，股东以信任为基础，股东过多不利于决策和经营 | 不超过50人；包括国有独资公司和一人公司在内的所有有限责任公司；既包括设立时原始股东，也包括设立后因增资、转让、合并新增的股东 |
| 2. 符合章程规定的认缴出资额 | 2013年《公司法》修正时彻底废除最低注册资本制度，将注册资本事项完全交由股东自治 | 认缴出资的股东是否履行出资义务不再构成评判股东地位的条件；股东地位的取得仅以股东认缴出资的生效意思表示为必要 |
| 3. 股东共同制定公司章程 | 公司章程是公司设立必备文件；体现全体股东意志 | 必备事项与任意事项的区分；共同制定指股东协商一致，有共同的意思表示 |
| 4. 公司名称与组织机构 | 公司以自己的名义开展活动；组织机构是公司运行的基础 | 必须确定公司名称；必须建立股东会、董事会（或执行董事）、监事会（或监事）等符合有限责任公司要求的组织机构 |
| 5. 公司住所 | 没有住所的公司不得设立；便于政府监管和司法管辖 | 公司以其主要办事机构所在地为住所 |

**条文演变**：

| 年份 | 修改内容 |
|------|----------|
| 2005年 | 将1993年《公司法》第19条第5项「有固定的生产经营场所和必要的生产经营条件」修改为「有公司住所」，是考虑到公司设立之前要求具备营业准备是不现实的 |
| 2013年 | 彻底取消最低注册资本制度，将「股东出资达到法定资本最低限额」修改为「有符合公司章程规定的全体股东认缴的出资额」 |
| 2018年 | 未作修改 |

### 二、股东人数限制（第24条）

**条文原文**：有限责任公司由五十个以下股东出资设立。

**三层含义**：

| 含义 | 内容 |
|------|------|
| 1. 数量上限 | 50个以下股东可以设立有限责任公司 |
| 2. 出资义务 | 50个以下的股东必须都要出资；不出资不能成为股东 |
| 3. 主体类型 | 50个以下股东，既可以是自然人，也可以是法人 |

**条文演变**：本条源于1993年《公司法》第20条。2005年《公司法》增加了一人有限责任公司特别规定后，删除原第2款关于「国家授权投资的机构或者国家授权的部门可以单独投资设立国有独资的有限责任公司」的规定，将有限责任公司股东人数修改为「由五十个以下股东出资设立」，保留至今。

### 三、公司章程的法定记载事项（第25条）

**条文原文**：有限责任公司章程应当载明下列事项：（一）公司名称和住所；（二）公司经营范围；（三）公司注册资本；（四）股东的姓名或者名称；（五）股东的出资方式、出资额和出资时间；（六）公司的机构及其产生办法、职权、议事规则；（七）公司法定代表人；（八）股东会会议认为需要规定的其他事项。股东应当在公司章程上签名、盖章。

**八项法定记载事项的理解**：

| 事项 | 内涵 |
|------|------|
| 公司名称和住所 | 标识公司，确认权利义务归属的依据 |
| 公司经营范围 | 明确公司开展业务活动的界限，便于政府监管 |
| 公司注册资本 | 以货币表示的各股东认缴出资额的总和 |
| 股东姓名或者名称 | 确定公司的投资人；自然人载明姓名，法人载明名称 |
| 出资方式、出资额和出资时间 | 出资方式指出资的种类；出资额以货币表示；出资时间包括首次出资时间及分期缴足时间 |
| 公司机构及其产生办法、职权、议事规则 | 如董事会组成人数、董事长产生、董事任期、议事程序等 |
| 公司法定代表人 | 应是具有完全民事行为能力的自然人 |
| 股东会会议认为需要规定的其他事项 | 兜底条款 |

**必备事项与任意事项的区分**：

| 类型 | 含义 |
|------|------|
| 必备事项 | 法律规定必须记载的事项，包括本条第1款前7项 |
| 任意事项 | 公司自行决定是否记载的事项，包括第8项兜底条款所列事项 |

**签名盖章要求**：公司章程由公司股东共同制定。共同制定是指参与制定公司章程的股东经过协商取得一致意见，并有共同的意思表示。股东签名盖章一般情况下应当由股东本人亲自为之；委托他人代为签名盖章的，应当签署授权委托书。

### 四、注册资本认缴登记制（第26条）

**条文原文**：有限责任公司的注册资本为在公司登记机关登记的全体股东认缴的出资额。法律、行政法规以及国务院决定对有限责任公司注册资本实缴、注册资本最低限额另有规定的，从其规定。

**注册资本的双轨制**：

| 类别 | 适用情形 |
|------|----------|
| 一般认缴制 | 除法律、行政法规、国务院决定另有规定外，注册资本完全可由股东认缴，出资期限、出资类别由股东自由约定 |
| 特殊实缴制 | 法律、行政法规以及国务院决定对有限责任公司注册资本实缴、注册资本最低限额另有规定的，从其规定 |

**特殊行业实缴最低限额举例**（按源文件整理）：

| 行业 | 注册资本最低限额 | 依据 |
|------|----------------|------|

**注册资本的功能**：

| 功能 | 内容 |
|------|------|
| 1. 经营资本 | 提供公司生产经营所需要的部分资本 |
| 2. 权利义务标准 | 股东权利大小、义务多少通常由出资占注册资本的比例确定 |
| 3. 亏损风险担保 | 从债权人角度看，注册资本一经公司成立即为公司财产，可作为债权清偿担保 |

**条文演变**：本条历经1993年入法、2005年大修改、2013年第二次大修改。2013年12月28日第十二届全国人大常委会第六次会议彻底取消最低注册资本额，公司注册资本可由股东完全认缴，出资期限、出资类别由股东自由约定，标志着从严格法定资本制走向资本完全认缴制。

### 五、股东出资方式（第27条）

**条文原文**：股东可以用货币出资，也可以用实物、知识产权、土地使用权等可以用货币估价并可以依法转让的非货币财产作价出资；但是，法律、行政法规规定不得作为出资的财产除外。对作为出资的非货币财产应当评估作价，核实财产，不得高估或者低估作价。法律、行政法规对评估作价有规定的，从其规定。

**两类出资方式**：

| 方式 | 内容 | 实务要求 |
|------|------|----------|
| 货币出资 | 我国的法定货币为人民币；也可以用外币 | 足额存入有限责任公司在银行开设的账户 |
| 非货币财产出资 | 实物、知识产权、土地使用权等「可以用货币估价并可以依法转让」的非货币财产 | 必须评估作价，核实财产，不得高估或低估；依法办理财产权的转移手续 |

**非货币财产出资的具体类型**：

| 类型 | 内涵 |
|------|------|
| 实物 | 房屋、机器设备、工具、原材料、零部件等有形财产 |
| 知识产权 | 包括工业产权（专利权、商标专用权）、植物新品种权和非专利技术 |
| 土地使用权 | 国有土地和农民集体所有的土地依法明确给单位或者给个人使用的权利 |
| 其他可估价可依法转让的非货币财产 | 股权、债权、探矿权、采矿权、林权等 |

**不得作为出资的财产**（《市场主体登记管理条例》第13条）：

| 禁止类型 |
|----------|
| 劳务 |
| 信用 |
| 自然人姓名 |
| 商誉 |
| 特许经营权 |
| 设定担保的财产 |

**条文演变**：

| 年份 | 修改内容 |
|------|----------|
| 2005年 | 不再限制非货币出资形式为「实物、工业产权、非专利技术、土地使用权」四种，扩展为「可以用货币估价并可以依法转让的非货币财产」；货币出资金额不得低于注册资本30% |
| 2013年 | 删除货币出资金额不得低于注册资本30%的规定，配合资本认缴制度改革 |
| 2018年 | 未作修改 |

### 六、按期足额缴纳出资（第28条）

**条文原文**：股东应当按期足额缴纳公司章程中规定的各自所认缴的出资额。股东以货币出资的，应当将货币出资足额存入有限责任公司在银行开设的账户；以非货币财产出资的，应当依法办理其财产权的转移手续。股东不按照前款规定缴纳出资的，除应当向公司足额缴纳外，还应当向已按期足额缴纳出资的股东承担违约责任。

**两类出资的履行方式**：

| 方式 | 履行要求 |
|------|----------|
| 货币出资 | 按公司章程规定的时间和金额，将货币出资足额存入有限责任公司在银行开设的账户 |
| 非货币财产出资 | 进行作价评估；依法办理财产权的转移手续（即过户手续） |

**不按期缴纳出资的两层责任**：

| 责任类型 | 内容 |
|----------|------|
| 1. 向公司承担继续履行责任 | 股东不按期缴纳出资的，不能因此免除或减轻其按照公司章程规定应当履行的缴纳出资义务 |
| 2. 向其他股东承担违约责任 | 股东未按公司章程规定的时间、金额缴纳出资，违反公司章程规定的出资义务，构成对其他已履行缴纳出资义务股东的违约 |

### 七、设立登记申请（第29条）

**条文原文**：股东认足公司章程规定的出资后，由全体股东指定的代表或者共同委托的代理人向公司登记机关报送公司登记申请书、公司章程等文件，申请设立登记。

**设立登记的三要素**：

| 要素 | 内容 |
|------|------|
| 1. 申请时间 | 「股东认足公司章程规定的出资后」 |
| 2. 申请的具体提出人 | 全体股东指定的代表，或者全体股东共同委托的代理人 |
| 3. 申请应提交的文件 | 公司登记申请书、公司章程等文件（依《市场主体登记管理条例》第16条） |

**设立登记申请材料清单**（《市场主体登记管理条例》第16条）：

| 序号 | 材料 |
|------|------|
| 1 | 申请书 |
| 2 | 申请人资格文件、自然人身份证明 |
| 3 | 住所或者主要经营场所相关文件 |
| 4 | 公司、非公司企业法人、农民专业合作社（联合社）章程或者合伙企业合伙协议 |
| 5 | 法律、行政法规和国务院市场监督管理部门规定提交的其他材料 |

**条文演变**：2013年《公司法》修正时，删除原「股东的首次出资经依法设立的验资机构验资后」规定，将申请时间修改为「股东认足公司章程规定的出资后」，配合资本认缴制度改革。

### 八、非货币财产出资不实的差额补足（第30条）

**条文原文**：有限责任公司成立后，发现作为设立公司出资的非货币财产的实际价额显著低于公司章程所定价额的，应当由交付该出资的股东补足其差额；公司设立时的其他股东承担连带责任。

**责任构成要件**：

| 要件 | 内容 |
|------|------|
| 1. 确定时间 | 有限责任公司成立后 |
| 2. 责任主体 | 设立公司时的股东，不及于公司成立后增资时加入的股东 |
| 3. 构成条件 | 作为设立公司出资的非货币财产的实际价额「显著低于」公司章程所定价额 |
| 4. 责任形式 | 交付该出资的股东补足差额；公司设立时的其他股东承担连带责任 |

**「显著低于」的判断标准**：非货币财产的实际价额明显地少于公司章程所定价额，两者之间的差额过大，已经到了无法忽视的程度。从各国的法律实践看，实物、知识产权或者土地使用权等非货币财产的实际价额，应根据公司成立前后一定时间内对该出资标的价值的综合评估额，并按照资本充实的原则来考察。

**连带责任的法理基础**：足额缴付认缴的出资，保证公司资本充足，既是每一个股东的法定义务，也是全体股东的共同责任。当股东出资不足时，该股东必须承担补足差额的责任；如果该股东已无力承担补足差额的责任，则由公司设立时的其他股东承担连带责任，代为补足，并向该股东追偿，以确保公司资本的充足。

**辅助责任**：股东出资不足，除了补足差额外，还必须向其他已经足额出资的股东承担违约责任。

### 九、出资证明书（第31条）

**条文原文**：有限责任公司成立后，应当向股东签发出资证明书。出资证明书应当载明下列事项：（一）公司名称；（二）公司成立日期；（三）公司注册资本；（四）股东的姓名或者名称、缴纳的出资额和出资日期；（五）出资证明书的编号和核发日期。出资证明书由公司盖章。

**出资证明书的法律性质**：

| 性质 | 内容 |
|------|------|
| 1. 非设权证券 | 股东所享有的股东权并非由出资证明书所创设，来源于股东的出资；出资证明书只是记载和反映股东出资的客观状况 |
| 2. 要式证券 | 制作和记载事项必须按照法定的方式和要求进行 |
| 3. 有价证券 | 股东享有股东权的重要法律凭证；与股票不同，为不流通的有价证券 |
| 4. 有限责任公司所特有 | 相对于股份有限公司的股票 |

**出资证明书的法定记载事项**：

| 事项 | 作用 |
|------|------|
| 公司名称 | 保障股东依法行使股东权，主张股东权益 |
| 公司成立日期 | 确定股东从何时起可以依法行使股东权 |
| 公司注册资本 | 确定股东的出资额在公司注册资本中所占的比例 |
| 股东姓名/名称、缴纳出资额和出资日期 | 确定股东之间权利的大小 |
| 出资证明书编号和核发日期 | 便于保管、查阅、核对 |

**形式要件**：出资证明书应当由公司盖章。没有公司盖章的出资证明书因不具备法定的形式要件，不能发生效力。

### 十、股东名册（第32条）

**条文原文**：有限责任公司应当置备股东名册，记载下列事项：（一）股东的姓名或者名称及住所；（二）股东的出资额；（三）出资证明书编号。记载于股东名册的股东，可以依股东名册主张行使股东权利。公司应当将股东的姓名或者名称向公司登记机关登记；登记事项发生变更的，应当办理变更登记。未经登记或者变更登记的，不得对抗第三人。

**股东名册的法定记载事项**：

| 事项 | 记载要求 |
|------|----------|
| 股东的姓名或者名称及住所 | 自然人：户口簿或身份证件登记的姓名、住址；法人：营业执照登记的名称、地址 |
| 股东的出资额 | 与公司章程规定的股东出资额相一致 |
| 出资证明书编号 | 公司成立后签发给股东的出资证明书编号 |

**股东名册的双重效力**：

| 效力 | 内容 |
|------|------|
| 1. 权利推定效力（对内） | 记载于股东名册的股东，可以依股东名册主张行使股东权利；公司只以股东名册上记载的股东为本公司的股东；股权转让从变更股东名册时开始生效 |
| 2. 对抗效力（对外） | 未在公司登记机关登记或者变更登记的，不得对抗第三人 |

**与公司登记的关系**：股东名册记载的事项，应当与公司登记的事项保持一致。在出现股东转让出资等情形下，应当及时办理变更登记。如果没有经过登记或者没有及时办理变更登记，则不得对抗第三人。

**适用指引**（《九民纪要》第8条）：当事人之间转让有限责任公司股权，受让人以其姓名或者名称已记载于股东名册为由主张其已经取得股权的，人民法院依法予以支持，但法律、行政法规规定应当办理批准手续生效的股权转让除外。未向公司登记机关办理股权变更登记的，不得对抗善意相对人。

### 十一、股东知情权（第33条）

**条文原文**：股东有权查阅、复制公司章程、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告。股东可以要求查阅公司会计账簿。股东要求查阅公司会计账簿的，应当向公司提出书面请求，说明目的。公司有合理根据认为股东查阅会计账簿有不正当目的，可能损害公司合法利益的，可以拒绝提供查阅，并应当自股东提出书面请求之日起十五日内书面答复股东并说明理由。公司拒绝提供查阅的，股东可以请求人民法院要求公司提供查阅。

**股东知情权的两个层次**：

| 层次 | 范围 | 程序 |
|------|------|------|
| 1. 无条件查阅、复制 | 公司章程、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告 | 不需要公司批准，法定权利 |
| 2. 有条件查阅 | 公司会计账簿 | 须书面请求并说明目的；公司有合理根据认为不正当目的可拒绝；15日内书面答复 |

**「不正当目的」的四种情形**（《公司法规定（四）》第8条）：

| 情形 | 内容 |
|------|------|
| 1 | 股东自营或者为他人经营与公司主营业务有实质性竞争关系业务的（章程另有规定或全体股东另有约定的除外） |
| 2 | 股东为了向他人通报有关信息查阅公司会计账簿，可能损害公司合法利益的 |
| 3 | 股东在向公司提出查阅请求之日前的三年内，曾通过查阅公司会计账簿，向他人通报有关信息损害公司合法利益的 |
| 4 | 股东有不正当目的的其他情形 |

**适用指引五要点**：

| 要点 | 内容 |
|------|------|
| 1. 法定权利保障 | 查阅复制股东会会议记录、董事会会议决议、监事会会议决议便于股东了解各类会议情况并行使监督权利 |
| 2. 会计账簿的特别规定 | 股东虽有查阅权但必须取得公司批准；股东即使取得批准可查阅会计账簿，但无权复制会计账簿 |
| 3. 「不正当目的」严格限制 | 内涵应当限于股东行使知情权的实质目的为可能泄露公司商业秘密、可能与公司存在恶意竞争等利用通过行使股东知情权获知的信息对公司利益造成损害的情形；不宜作扩大理解 |
| 4. 双重身份不阻却知情权 | 同时具有公司行政职务与公司股东双重身份，当职务行为的结果与行使股东知情权结果相重叠时，不得以此阻却股东知情权的行使 |
| 5. 查阅范围及于会计凭证 | 股东知情权查阅的范围应当及于与会计账簿记载内容有关的会计凭证（记账凭证、相关原始凭证及作为原始凭证附件入账备查的有关资料） |

### 十二、收益权与优先认缴权（第34条）

**条文原文**：股东按照实缴的出资比例分取红利；公司新增资本时，股东有权优先按照实缴的出资比例认缴出资。但是，全体股东约定不按照出资比例分取红利或者不按照出资比例优先认缴出资的除外。

**股东两大权利**：

| 权利 | 内容 |
|------|------|
| 1. 收益权（分红权） | 股东按照实缴的出资比例分取红利；全体股东约定不按照出资比例分取红利的除外 |
| 2. 优先认缴权 | 公司新增资本时，股东有权优先按照实缴的出资比例认缴出资；全体股东约定不按照出资比例优先认缴出资的除外 |

**按「实缴出资比例」的立法理由**：

| 理由 | 内容 |
|------|------|
| 1. 体现股东真实出资 | 已实际缴纳的出资才形成对公司的真实贡献 |
| 2. 公平合理 | 未实缴出资的股东不应按认缴比例享受分红权利 |
| 3. 与2005年修改的衔接 | 配合股东可以分期缴纳出资的新规定作出修改 |

**优先认缴权的行使条件**：

| 条件 | 内容 |
|------|------|
| 1. 公司决定新增注册资本 | 公司设立后因经营业务发展需要增加公司资本 |
| 2. 有外部投资者也想认缴 | 仅在原股东之外的投资者也想认缴时才存在优先认缴问题 |
| 3. 原股东优先 | 在同等条件下，原股东可以优先于原股东之外的投资者认缴出资 |

**优先认购权的立法理由**：一是增加资本时原股东出资在公司全部出资中所占比例降低，影响原股东的经济利益和经营管理权利；二是原股东对公司的生产经营和该行业比较熟悉；三是有限责任公司具有人合因素。

### 十三、禁止抽逃出资（第35条）

**条文原文**：公司成立后，股东不得抽逃出资。

**抽逃出资的四种情形**（《公司法规定（三）》第12条）：

| 情形 | 内容 |
|------|------|
| 1 | 制作虚假财务会计报表虚增利润进行分配 |
| 2 | 通过虚构债权债务关系将其出资转出 |
| 3 | 利用关联交易将出资转出 |
| 4 | 其他未经法定程序将出资抽回的行为 |

**资本维持原则**：股东的出资是公司设立并从事生产经营活动的物质基础。公司一旦成立，股东的出资就成为公司的财产，即股东的出资形成公司的全部法人财产，而公司以其全部财产对外承担责任。股东按照公司章程的规定出资到位，是维护公司正常生产经营活动以及促进公司发展、保证公司必要的偿债能力、维护债权人利益的必要条件。

**抽逃出资的责任承担**：

| 责任主体 | 责任内容 |
|----------|----------|
| 抽逃出资的股东 | 向公司返还出资本息；在抽逃出资本息范围内对公司债务不能清偿的部分承担补充赔偿责任 |
| 协助抽逃出资的其他股东、董事、高级管理人员或者实际控制人 | 对返还出资、补充赔偿责任承担连带责任 |

**适用指引**（《九民纪要》第5条）：投资方与目标公司订立的「对赌协议」在不存在法定无效事由的情况下，目标公司仅以存在股权回购或者金钱补偿约定为由，主张「对赌协议」无效的，人民法院不予支持，但投资方主张实际履行的，人民法院应当审查是否符合公司法关于「股东不得抽逃出资」及股份回购的强制性规定。投资方请求目标公司回购股权的，目标公司未完成减资程序的，人民法院应当驳回其诉讼请求。投资方请求目标公司承担金钱补偿义务的，目标公司没有利润或者虽有利润但不足以补偿投资方的，人民法院应当驳回或者部分支持其诉讼请求。

## ⚠️ 司法适用难点

### 难点一：注册资本认缴制下股东出资义务的加速到期

**争议**：在注册资本认缴制下，股东出资期限未届满时，公司不能清偿到期债务，债权人能否请求未届期出资的股东承担补充赔偿责任？

**主流观点**：
- 一般情况下，债权人只能要求已届期未出资股东承担补充赔偿责任
- 例外情形：公司具备破产原因但不申请破产的，或在公司债务产生后股东会决议延长出资期限的，债权人可请求未届期股东承担补充赔偿责任
- 适用《九民纪要》第6条精神

### 难点二：抽逃出资与合法减资的区分

**争议**：股东收回出资的行为构成抽逃出资还是合法减资？

**判断要点**：

| 维度 | 抽逃出资 | 合法减资 |
|------|----------|----------|
| 程序 | 未经法定程序 | 编制资产负债表及财产清单；通知债权人；报纸公告；办理变更登记 |
| 资金实质 | 资金循环回到原股东 | 资金实际来源于公司经营积累 |
| 工商登记 | 未作变更登记 | 在国家企业信用信息公示系统作变更登记 |
| 责任 | 抽逃出资股东返还本息；协助者连带责任 | 合法减资，无责任 |

### 难点三：股东知情权与公司商业秘密保护的平衡

**争议**：股东查阅会计账簿的范围是否包括会计凭证？

**主流观点**：
- 股东知情权查阅的范围应当及于与会计账簿记载内容有关的会计凭证
- 会计凭证包含记账凭证、相关原始凭证及作为原始凭证附件入账备查的有关资料
- 查阅限定在与会计账簿记载内容有关的会计原始凭证和记账凭证，实现股东权利与公司财务资料保密的均衡保护

**「不正当目的」的举证责任分配**：

| 主体 | 举证责任 |
|------|----------|
| 股东 | 证明存在说明目的的行为，且该目的从字面上理解不具有明显不正当性即可 |
| 公司 | 证明股东行使知情权的实质目的具有不正当性 |

### 难点四：对赌协议中目标公司回购股权的履行

**争议**：投资方请求目标公司回购股权的，能否得到支持？

**主流观点**（《九民纪要》第5条）：
- 投资方与目标公司订立的「对赌协议」在不存在法定无效事由的情况下，目标公司仅以存在股权回购或者金钱补偿约定为由，主张「对赌协议」无效的，人民法院不予支持
- 投资方主张实际履行的，人民法院应当审查是否符合公司法关于「股东不得抽逃出资」及股份回购的强制性规定
- 目标公司未完成减资程序的，人民法院应当驳回其诉讼请求

## ❓ 实务问答

> **Q1：设立有限责任公司应当具备哪些条件？**
>
> A：根据《公司法》第23条，应当具备五项条件：股东符合法定人数；有符合公司章程规定的全体股东认缴的出资额；股东共同制定公司章程；有公司名称，建立符合有限责任公司要求的组织机构；有公司住所。

> **Q2：有限责任公司股东人数上限是多少？**
>
> A：有限责任公司由50个以下股东出资设立，包括自然人和法人（第24条）。

> **Q3：有限责任公司章程应当载明哪些事项？**
>
> A：根据《公司法》第25条，应当载明八项事项：① 公司名称和住所；② 公司经营范围；③ 公司注册资本；④ 股东的姓名或者名称；⑤ 股东的出资方式、出资额和出资时间；⑥ 公司的机构及其产生办法、职权、议事规则；⑦ 公司法定代表人；⑧ 股东会会议认为需要规定的其他事项。股东应当在公司章程上签名、盖章。

> **Q4：有限责任公司注册资本实行何种登记制度？**
>
> A：除法律、行政法规以及国务院决定另有规定外，实行认缴登记制；股东认缴的出资总额在公司登记机关登记；公司股东对其认缴出资额、出资方式、出资期限等自主约定并记载于公司章程（第26条）。

> **Q5：股东可以用哪些非货币财产出资？**
>
> A：根据《公司法》第27条，股东可以用实物、知识产权、土地使用权等可以用货币估价并可以依法转让的非货币财产作价出资；但是法律、行政法规规定不得作为出资的财产除外。不得作为出资的财产包括：劳务、信用、自然人姓名、商誉、特许经营权、设定担保的财产。

> **Q6：股东不按期缴纳出资应当承担什么责任？**
>
> A：股东不按期缴纳出资的，除应当向公司足额缴纳外，还应当向已按期足额缴纳出资的股东承担违约责任（第28条）。

> **Q7：设立登记申请应当由谁提出？**
>
> A：股东认足公司章程规定的出资后，由全体股东指定的代表或者共同委托的代理人向公司登记机关报送公司登记申请书、公司章程等文件，申请设立登记（第29条）。

> **Q8：非货币财产出资不实的，其他股东是否承担责任？**
>
> A：有限责任公司成立后，发现作为设立公司出资的非货币财产的实际价额显著低于公司章程所定价额的，应当由交付该出资的股东补足其差额；公司设立时的其他股东承担连带责任（第30条）。

> **Q9：出资证明书应当载明哪些事项？**
>
> A：出资证明书应当载明五项事项：① 公司名称；② 公司成立日期；③ 公司注册资本；④ 股东的姓名或者名称、缴纳的出资额和出资日期；⑤ 出资证明书的编号和核发日期。出资证明书由公司盖章（第31条）。

> **Q10：股东名册的法律效力是什么？**
>
> A：股东名册具有双重效力：① 权利推定效力，记载于股东名册的股东可以依股东名册主张行使股东权利；② 对抗效力，公司应当将股东的姓名或者名称向公司登记机关登记，未经登记或者变更登记的，不得对抗第三人（第32条）。

> **Q11：股东知情权包括哪些内容？**
>
> A：股东有权查阅、复制公司章程、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告；股东可以要求查阅公司会计账簿（须书面请求并说明目的）。股东行使知情权后泄露公司商业秘密导致公司合法利益受到损害的，公司有权请求该股东赔偿相关损失（第33条）。

> **Q12：公司拒绝股东查阅会计账簿的理由有哪些？**
>
> A：根据《公司法规定（四）》第8条，公司有合理根据认为股东查阅会计账簿有下列不正当目的之一的，可以拒绝：① 股东自营或者为他人经营与公司主营业务有实质性竞争关系业务（章程另有规定或全体股东另有约定的除外）；② 股东为了向他人通报有关信息查阅公司会计账簿，可能损害公司合法利益；③ 股东在向公司提出查阅请求之日前的三年内，曾通过查阅公司会计账簿向他人通报有关信息损害公司合法利益；④ 股东有不正当目的的其他情形。

> **Q13：股东按照什么比例分取红利？**
>
> A：股东按照实缴的出资比例分取红利。但是，全体股东约定不按照出资比例分取红利的除外（第34条）。

> **Q14：公司新增资本时股东有什么权利？**
>
> A：公司新增资本时，股东有权优先按照实缴的出资比例认缴出资。但是，全体股东约定不按照出资比例优先认缴出资的除外（第34条）。

> **Q15：股东抽逃出资的，应当承担什么责任？**
>
> A：公司成立后，股东不得抽逃出资。抽逃出资的股东应当向公司返还出资本息；公司债权人请求抽逃出资的股东在抽逃出资本息范围内对公司债务不能清偿的部分承担补充赔偿责任的，应予支持；协助抽逃出资的其他股东、董事、高级管理人员或者实际控制人对此承担连带责任（第35条、《公司法规定（三）》第14条）。

> **Q16：抽逃出资的常见情形有哪些？**
>
> A：根据《公司法规定（三）》第12条，抽逃出资的情形包括：① 制作虚假财务会计报表虚增利润进行分配；② 通过虚构债权债务关系将其出资转出；③ 利用关联交易将出资转出；④ 其他未经法定程序将出资抽回的行为。

> **Q17：对赌协议中目标公司回购股权有何限制？**
>
> A：根据《九民纪要》第5条，投资方与目标公司订立的「对赌协议」在不存在法定无效事由的情况下，原则上有效；但投资方主张实际履行的，人民法院应当审查是否符合公司法关于「股东不得抽逃出资」及股份回购的强制性规定。目标公司未完成减资程序的，人民法院应当驳回其诉讼请求。
