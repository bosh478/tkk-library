# 政府信息公开类案 · 8 种不予公开情形（第1册）

> **位置**：第三部分 四 答复理由和法律适用审查·(二) 国家秘密 + (三) 三安全一稳定 + (四) 第三方权益 + (五) 内部事务 + (六) 不存在 + (七) 非本机关 + (八) 重复 + (九) 不动产 + (十) 非条例所指（行 9735–9903）
> **核心条文**：《政府信息公开条例》第二条/第十四条/第十五条/第十六条/第十七条 + 《保守国家秘密法》第十三/十九条 + 《信息公开司法解释》第五条/第十一条

## 一、原文逐句（L4 段级提取 · 8 种不予公开情形）

### 1.1 (二) 涉及国家秘密（行 9735–9755）

> **审查性质** = **程序审和形式审**：仅审查**定密职权 / 定密标识 / 定密程序 / 保密期限**。**定密实体内容的正当与否不属于法院审查范围**。**法院对定密争议不予处理**。

**3 项审查内容**：

1. **定密职权** — 《保守国家秘密法》第十三条：
   - **中央国家机关 / 省级机关**及其授权机关、单位 → **绝密/机密/秘密级**；
   - **设区的市、自治州一级**机关及其授权机关、单位 → **机密/秘密级**。
2. **定密程序和形式** — 2019 年条例第十七条第二款：行政机关**公开前**应**保密审查**。**原告提出申请后**启动定密程序**可以**。定密方式只要能**反映定密意思**即可，**形式不具体界定**。
3. **保密期限** — 计算**自定密之日起**。**保密期内可提前解密**；**保密期满自行解密**。**超过保密期限未延长**的 → **已经解密**，不能以国家秘密为由不予公开。**法院不予支持**行政机关将超过保密期限的信息作国家秘密答复。**裁判方式** = 不直接判决公开，**撤销原答复 + 责令重新答复**。

**⚠️ 质证方式**：

> - 仅就**保密标识 / 定密目录 / 定密决定**等**真实性**进行质证；
> - **避免就实体内容质证**（防泄露）；
> - 《信息公开司法解释》第五条第四款：被告能证明涉国家秘密**请求在诉讼中不予提交**的，**应当准许**；提供**定密清单**等材料足以证明的，可准许。

### 1.2 (三) 涉及"三安全一稳定"（行 9757–9771 + 典型案例）

> 2019 年条例规定：公开后可能危及**国家安全 / 公共安全 / 经济安全 / 社会稳定**的政府信息，**不予公开**。
>
> **性质** = **不确定法律概念**，解释难度大：解释过宽 → 行政机关限缩公开范围；解释过严 → 可能引起其他社会负面效应。
>
> **审查角度** = **理由 + 程序**双角度。

### 1.3 (四) 涉及对第三方合法权益造成损害（行 9773–9825 + 典型案例）

> **5 子小节**：

1. **关于商业秘密的判断**（行 9779–9787）；
2. **关于个人隐私的判断**（行 9789–9793）；
3. **其他对第三方合法权益造成损害的政府信息**（行 9795–9797）；
4. **权利人同意公开的判定程序和司法审查内容**（行 9799–9807）；
5. **利益平衡后决定公开**（行 9809–9825）。

### 1.4 (五) 涉及内部事务信息、过程性信息、行政执法案卷信息（行 9827–9845）

> 2019 年条例新增 **"行政执法案卷"**不予公开。**3 类信息**界定：
> 1. **内部事务信息**（行 9833–9835）；
> 2. **过程性信息**（行 9837–9839）；
> 3. **行政执法案卷信息**（行 9841–9845，**2019 年新规定**）。

### 1.5 (六) 政府信息不存在（行 9847–9861 + 典型案例）

> 法院审查答复是否合法。

### 1.6 (七) 非本机关负责公开（行 9863–9877 + 注意事项）

> **判断标准**：
> 1. **被告行政管理范围** — 信息**不在被告行政管理范围**内（信息内容与被告行政管理职能不相关），可答复**非本机关负责公开**。
> 2. **被告客观上未制作或获取** — 信息虽不属于被告行政管理范围，但被告**客观制作或获取过**的，**不能答复**非本机关负责公开。

**⚠️ 关键：牵头机关判断**

> 共同制作的政府信息由**牵头制作机关**负责公开。**2 角度**：
> 1. **文号机关** — 多机关共同制作一个文件时使用**唯一文号**，该文号机关 = 牵头机关；
> 2. **无文号时** — 共同制作机关以**不属于牵头机关**为由不提供政府信息的，应当**对其不属于牵头机关进行举证**；**不能举证的** → **不予支持**该答复。

**未正确告知公开义务机关名称、联系方式的处理**：

> **法院可作为行政瑕疵指出**，**不宜直接判决撤销或确认违法**，**可判决驳回诉讼请求**。**理由**：(1) 庭审中查明被告在原告申请时**已知道/能确定**公开义务主体较难（除非被告自认）；(2) 若被告因自认能够确定公开义务机关而败诉 → 会导致被告在今后**一概不承认能够确定**，**有违条例立法宗旨**。**法院判决应导向行政机关更好地履行公开义务和便民服务**。

### 1.7 (八) 申请人重复申请不予处理（行 9879–9885）

> **"相同"标准** ≠ 文字表述一致，而是**实质上同一内容**。
>
> **注意制度环境或事实变化**：
> - **制度变化** — 第一次申请时法律规定不予公开，第二次申请时法律制度**已改变** → 对不再重复处理的告知**不予支持**；
> - **事实变化** — 子女申请父母收入信息（第一次以父母**个人隐私**不予公开，第二次父母**已死亡**） → **不予支持**不重复处理告知（父母死亡后，财产收入对**继承人不再属于个人隐私**，应公开）。

### 1.8 (九) 不动产登记 / 工商登记等资料的另行查询告知（行 9887–9891）

> **不动产登记资料 / 工商登记等资料**有**专门查询制度规定**，**不适用《政府信息公开条例》**，**由其他特别法规定**。**行政机关答复当事人依照特定规定查询的**，**法院应予以支持**。

### 1.9 (十) 申请"非条例所指政府信息"（行 9893–9903 + 典型案例）

> 2019 年条例第二条：**政府信息** = 行政机关在履行**行政管理职能**过程中制作或获取的，以**一定形式记录、保存**的信息。**关键** = **行政管理职能**过程中形成的信息（2019 年修订**明确**）。
>
> **不属于条例所指政府信息的**：
> - 行政机关**非履行行政管理职能**信息（如作为**民事主体**形成的信息）；
> - **公安机关在履行刑事侦查职能**过程中产生的信息。

**典型案例**：**奚明强诉中华人民共和国公安部案**（**2013 年度政府信息公开十大案例之二** / 北京市高级人民法院 / (2014)高行终字第 221 号）。

> 典型意义：**公安机关具有行政机关和刑事司法机关的双重职能**，其在**履行刑事司法职能**时制作的信息**不属于《政府信息公开条例》第二条所规定的政府信息**。

## 三、实务问答（FAQ）

> **Q1: 国家秘密审查性质？**
> 答：**程序审和形式审**（定密职权/标识/程序/期限）。**实体内容正当与否不属于法院审查范围**（行 9735）。

> **Q2: 涉密信息诉讼中能否不提交？**
> 答：能。**《信息公开司法解释》第五条第四款** + **定密清单**等证明可准许（行 9755）。

> **Q3: "三安全一稳定"审查角度？**
> 答：**理由 + 程序**双角度（行 9767）。

> **Q4: 内部事务 / 过程性 / 行政执法案卷？**
> 答：**3 类**不予公开信息（**行政执法案卷为 2019 年新增**）（行 9827–9845）。

> **Q5: 牵头机关判断 2 角度？**
> 答：(1) **文号机关**（唯一文号）；(2) **无文号时举证**（不能举证不予支持答复）（行 9869–9871）。

> **Q6: 重复申请"相同"标准？**
> 答：实质上同一内容（**非文字一致**）（行 9881）。

> **Q7: 父母死亡后子女再申请父母收入信息？**
> 答：父母死亡后对**继承人不再属于个人隐私**，**应公开**（行 9885）。

> **Q8: 不动产/工商登记资料适用？**
> 答：**不适用《政府信息公开条例》**，**由其他特别法规定**（行 9891）。

> **Q9: 非条例所指政府信息？**
> 答：非履行**行政管理职能**信息（如民事主体信息 + 公安刑事侦查信息）（行 9897）。
