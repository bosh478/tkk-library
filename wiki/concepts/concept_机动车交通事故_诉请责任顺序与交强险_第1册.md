# 机动车交通事故 · 诉请责任顺序与交强险范围（第1册）

> **位置**：第三部分 原告诉请的审查·一 事故责任 + 二 赔偿顺序 + 三 赔偿费用类型 + 四 交强险（行 6025–6082）
> **核心条文**：《民法典》第一千一百七十九条（人身损害赔偿清单）+ 第一千一百八十条（财产损害赔偿清单）+ 第一千一百八十三条（精神损害）+ 《道交法》第七十六条

## 一、原文逐句（L4 段级提取）

### 1.1 一 事故责任类型（行 6027–6031）

> 事故责任主要分为：全部责任 / 主要责任 / 次要责任 / 同等责任 / 无责任，一般情况下根据不同责任类型来确定不同责任比例。另外存在事故责任无法认定的情况（详见第五部分"侵权行为的认定"）。

### 1.2 二 赔偿顺序（行 6033–6043）

**3 步赔偿规则**：

1. **先由承保交强险的保险公司在责任限额范围内予以赔偿**；
2. 不足部分，由承保商业三者险的保险公司根据保险合同予以赔偿；
3. 仍有不足的，依照《道交法》和《民法典》/《侵权责任法》由侵权人予以赔偿。

**精神损害优先**：

> 被侵权人或者其近亲属请求承保交强险的保险公司**优先赔偿精神损害**的，人民法院应予支持。

### 1.3 三 各项赔偿费用类型（行 6045–6057）

**1.3.1 (一) 人身损害**（行 6047–6051）：

> 医疗费、护理费、交通费、住宿费、住院伙食补助费、必要的营养费（治疗和康复）+ 误工减少的收入。造成残疾的：残疾生活辅助器具费 + 残疾赔偿金。造成死亡的：丧葬费 + 被扶养人生活费 + 死亡赔偿金。精神损害：精神损害抚慰金。此外还包括：鉴定费 + 评估费 + 律师费。

**1.3.2 (二) 财产损害**（行 6053–6057）：

> 修复车辆费用 + 车辆所载物品损失 + 车辆施救费用；车辆灭失或无法修复的重置费用；经营性车辆停运损失；非经营性车辆通常替代性交通工具合理费用。

### 1.4 四 交强险（行 6059–6081）

**1.4.1 (一) 赔偿范围**（行 6061–6065）：

| 项目 | 包含 |
|------|------|
| 医疗费用 | 医疗费 / 住院伙食补助费 / 营养费 / 后续治疗费 |
| 死亡伤残费用 | 护理费 / 误工费 / 残疾赔偿金 / 死亡赔偿金 / 丧葬费 / 被扶养人生活费 / 精神损害抚慰金 / 残疾辅助器具费 / 交通费 / 住宿费 |
| 财产损失费用 | 衣物损失 / 修理费 / 重置费用 |

**1.4.2 (二) 赔偿限额**（行 6067–6075）：

> 全国统一限额：
> - 医疗费用赔偿限额：**1 万元**
> - 死亡伤残费用赔偿限额：**11 万元**
> - 财产损失费用赔偿限额：**2 千元**

**注意事项**：交强险责任限额根据国务院相关部门规定调整。

**1.4.3 (三) 交强险无责赔偿**（行 6077–6081）：

> 机动车一方没有过错的，由保险公司在交强险**无责限额**内承担赔偿责任：
> - 医疗费用赔偿限额：**1 千元**
> - 死亡伤残费用赔偿限额：**1.1 万元**
> - 财产损失费用赔偿限额：**100 元**
>
> 具体损害费用超过各项限额的，以限额为准；损害费用未超过限额的，与各责任方根据限额所占比例分担。

## 三、实务问答（FAQ）

> **Q1: 交强险、商业三者险、侵权人的赔偿顺序？**
> 答：3 步——交强险（限额内）→ 商业三者险（按合同）→ 侵权人（道交法 + 民法典）（行 6035–6039）。

> **Q2: 精神损害赔偿能否交强险优先？**
> 答：能。被侵权人或近亲属请求**交强险优先**的，应予支持（行 6041）。

> **Q3: 交强险有责死亡伤残赔偿限额？**
> 答：**11 万元**（行 6071）。

> **Q4: 交强险无责医疗费用赔偿限额？**
> 答：**1 千元**（行 6081）。

> **Q5: 财产损害赔偿范围？**
> 答：6 类——修复 / 物品 / 施救 / 重置 / 停运 / 替代交通（行 6055–6057）。
