# 故意伤害罪·安徽量刑细则 L4(2022)

## 一、量刑档次三档(必须齐全 · R3 铁律)

| 档次 | 法定刑幅度 | 起刑点 |
|------|-----------|--------|
| **第一档(轻伤)** | 三年以下有期徒刑、拘役或者管制 | **轻伤二级 6 月拘役-1 年** / **轻伤一级 1-2 年** |
| **第二档(重伤)** | 三年以上十年以下有期徒刑 | **重伤二级 3-4 年** / **重伤一级 5 年** |
| **第三档(致人重伤 + 特别残忍 + 6 级残疾)** | 十年以上有期徒刑 / 无期 / 死刑 | **10-13 年** |

## 二、第一档 · 1-2 年起刑点(轻伤)

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 轻微伤 +1 | + **1-2 月** |
| 轻伤 +1 | + **3-6 月** |

## 三、第二档 · 3-5 年起刑点(重伤)

**基准刑递增**:
| 项 | 规则 |
|----|------|
| 轻微伤 +1 | + **1-2 月** |
| 轻伤 +1 | + **3-6 月** |
| 重伤 +1 | + **1-2 年** |
| 10-7 级残疾 +1 级 | + **1-3 月** |
| 6-3 级残疾 +1 级 | + **6 月-1 年** |
| 2-1 级残疾 +1 级 | + **2-3 年** |

## 四、第三档 · 10-13 年起刑点(特别残忍 + 6 级残疾)

**入罪触发**:以特别残忍手段致人重伤 + 6 级严重残疾。

**基准刑递增**:同第二档(轻微伤 +1-2 月,轻伤 +3-6 月,重伤 +1-2 年,残疾分级类推)。

## 五、从重情节(4 类 · +20-30% 以下,累计不超 100%)

1. 报复伤害 → **+30% 以下**
2. 雇用他人伤害 → **+20% 以下**
3. 因实施其他违法活动而伤害 → **+20% 以下**
4. 使用枪支 / 管制刀具 / 其他凶器 → **+30% 以下**

## 六、从轻情节(3 类 · −20% 以下)

1. 因婚姻家庭 / 邻里纠纷等民间矛盾激化 + 被害人有过错
2. 犯罪后积极抢救被害人
3. 其他从轻情形

## 七、罚金

- 三年以下:单处或并处 **1000-30000 元**
- 三年以上十年以下:**5000-100000 元**
- 十年以上:**50000-300000 元**

## 八、缓刑适用

**一般可以适用**(任一):
1. 婚姻家庭情感矛盾 + 认罪悔罪 + 积极赔偿
2. 双方刑事和解
3. 防卫过当 / 避险过当
4. 被害人有过错 / 主要责任
5. 在校学生初犯 / 偶犯
6. 共同犯罪 → 三年以下从犯
7. 重伤 + 从轻情节 + 谅解

**一般不适用**(任一):
1. 弱势人员(未成年 / 老年 / 残疾 / 孕妇)
2. 致多人轻伤
3. 黑恶势力犯罪
