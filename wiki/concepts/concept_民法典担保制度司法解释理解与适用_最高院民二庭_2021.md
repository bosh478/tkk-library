## 一、一般规定核心要点

### 1. 适用范围（第1条）

- 典型担保（抵押、质押、留置、保证）适用本解释
- 所有权保留买卖、融资租赁、保理等涉及担保功能的纠纷，适用本解释的有关规定
- 定金由合同编司法解释规定，本解释未作规定

### 2. 担保从属性（第2-3条）

**效力从属性**：
- 担保合同中约定担保独立性的条款无效
- 主合同有效则该约定无效不影响担保合同效力
- 主合同无效则担保合同无效（法律另有规定除外）

**范围从属性**：
- 担保责任超出主债务范围的，担保人对超出部分不承担责任
- ① 来源：《民法典担保制度解释》第3条

### 3. 公司对外担保（第7-12条）

**越权代表规则（第7条）**：
- 法定代表人违反《公司法》第16条规定超越权限代表公司提供担保，构成越权代表
- 相对人善意的，担保合同对公司发生效力
- 相对人非善意的，担保合同对公司不发生效力，但公司需承担赔偿责任
- 善意认定：相对人对公司决议进行了合理审查

**无须决议的例外情形（第8条）**：
- 金融机构开立保函或担保公司提供担保
- 公司为其全资子公司开展经营活动提供担保
- 担保合同由持有公司2/3以上表决权的股东签字同意

**上市公司特别规定（第9条）**：
- 上市公司对外担保必须依据决议公开披露
- 债权人根据披露信息签订担保合同 → 担保有效
- 债权人未根据披露信息签订担保合同 → 担保对上市公司不发生效力，且不承担任何责任

### 4. 共同担保（第13-14条）

**追偿规则**：
- 担保人之间约定相互追偿及分担份额 → 按约定分担
- 约定连带共同担保或约定相互追偿但未约定分担份额 → 各担保人按比例分担
- 未约定相互追偿且未在同一合同书上签字 → 原则上不能相互追偿
- ① 来源：《民法典担保制度解释》第13条

**担保人受让债权（第14条）**：
- 担保人受让债权的行为系承担担保责任
- 不能请求其他担保人承担担保责任，但可请求分担相应份额

### 5. 借新还旧（第16条）

- 旧贷担保人：不承担担保责任
- 新贷担保人：
  - 与旧贷担保人相同 → 支持
  - 与旧贷担保人不同或旧贷无担保新贷有担保 → 不支持，但明知借新还旧的除外

### 6. 担保与破产衔接（第22-24条）

- 担保债务自人民法院受理破产申请之日起停止计息
- 担保人清偿全部债权后可代替债权人在破产程序中受偿
- 债权人未申报债权也未通知担保人 → 担保人在破产程序中可能受偿范围内免除担保责任

## 二、保证合同核心要点

### 1. 保证类型识别（第25条）

**一般保证推定**：约定"债务人不能履行债务时才承担保证责任"等类似内容
**连带责任保证**：约定"债务人不履行债务即承担保证责任"、"无条件承担保证责任"等类似内容

**注意**：推定规则与解释规则的区别——如果可以通过意思表示解释规则确定当事人真实意思，则不能简单适用推定规则。

### 2. 先诉抗辩权（第26-28条）

- 一般保证中，债权人必须先起诉债务人
- 债权人未起诉债务人仅起诉一般保证人 → 驳回起诉
- 一并起诉债务人和保证人 → 判决明确保证人仅对债务人财产强制执行后仍不能履行的部分承担保证责任
- 保证债务诉讼时效起算：终结执行裁定送达债权人之日，或收到申请执行书满一年之日

### 3. 保证期间（第29-34条）

- 债权人向部分保证人行使权利的行为，对其他保证人不发生效力
- 保证人之间有追偿权，债权人未在保证期间内向部分保证人行使权利 → 其他保证人丧失追偿权
- "直至主债务本息还清为止"的约定 → 保证期间为6个月
- 保证合同无效，债权人未在保证期间内行使权利 → 保证人不承担赔偿责任

### 4. 增信措施性质（第36条）

- 差额补足、流动性支持等类似承诺文件
- 具有担保意思表示 → 按保证处理
- 具有加入债务或共同承担债务意思表示 → 认定为债务加入
- 难以确定是保证还是债务加入 → 认定为保证

## 三、担保物权核心要点

### 1. 不动产抵押

**未办理抵押登记（第46条）**：
- 债权人可请求抵押人办理抵押登记
- 因不可归责于抵押人原因导致不能办理 → 抵押人在担保范围内不承担责任
- 因可归责于抵押人原因导致不能办理 → 抵押人在约定范围内承担责任（不超过抵押权能够设立时的责任范围）

**预告登记效力（第52条）**：
- 具备办理抵押登记条件的 → 抵押权自预告登记之日起设立
- 不具备办理抵押登记条件的 → 不享有优先受偿效力

### 2. 动产抵押

**未登记动产抵押权效力（第54条）**：
- 抵押人转让抵押财产并交付 → 抵押权人不能向受让人行使抵押权（除非受让人知道已订立抵押合同）
- 抵押人将抵押财产出租 → 租赁关系不受影响（除非抵押权人证明承租人知道已订立抵押合同）
- 抵押人的其他债权人申请保全或执行 → 不享有优先受偿权
- 抵押人破产 → 不享有优先受偿权

### 3. 价款超级优先权（第57条）

担保人在设立动产浮动抵押后又购入新动产，为担保价款债权而订立担保合同并在交付后10日内登记 → 享有优先于在先设立的浮动抵押权的权利。

### 4. 仓单质押（第59条）

- 仓单质押以背书记载"质押"字样并经保管人签章为要件
- 交付仓单 → 质权设立
- 无权利凭证但可办理出质登记 → 质权自办理出质登记时设立

### 5. 应收账款质押（第61条）

- 应收账款债务人确认真实性后，不得以不存在或已消灭为由主张不承担责任
- 债务人未确认真实性 → 质权人需举证证明出质时应收账款真实存在
- 将有应收账款设立特定账户 → 质权人可就账户内款项优先受偿

## 四、非典型担保核心要点

### 1. 新类型担保（第63条）

- 法律、行政法规尚未规定可以担保的财产权利，可以设立担保
- 合同效力：当事人主张合同无效的，人民法院不予支持
- 物权效力：未在法定登记机构依法进行登记的，不具有物权效力

### 2. 所有权保留（第64条）

- 出卖人有权取回标的物
- 协商不成时，可请求参照实现担保物权案件程序拍卖、变卖标的物

### 3. 融资租赁（第65条）

- 承租人未按约定支付租金，经催告后仍不支付 → 出租人可请求支付全部剩余租金并以拍卖、变卖租赁物所得价款受偿

### 4. 让与担保（第68条）

- 约定将财产形式上转移至债权人名下，债务人不履行时债权人有权折价或拍卖、变卖受偿 → 约定有效
- 已完成财产权利变动公示 → 债权人可请求就该财产优先受偿
- 约定财产归债权人所有 → 该约定无效，但不影响提供担保的意思表示效力

### 5. 保证金质押（第70条）

- 设立专门的保证金账户并由债权人实际控制 → 债权人可主张就账户内款项优先受偿
- 账户内款项浮动不影响债权人优先受偿权

## 优化营商环境核心体现

《民法典担保制度解释》在营商环境优化方面的九大举措：

| 举措 | 对应条文 | 主要内容 |
|------|----------|----------|
| 动产担保统一公示 | 第38-42、54条 | 建立统一清晰、可预测的优先权规则 |
| 概括描述担保财产 | 第53条 | 允许对担保物和担保债务进行概括描述 |
| 高效执行程序 | 第45条 | 支持庭外执行，建立高效的担保权执行程序 |
| 担保权延及收益产品替代品 | 第38-42条 | 抵押权效力及于从物、添附物、物上代位 |
| 功能主义担保 | 第63-70条 | 所有权保留、融资租赁、保理、让与担保 |
| 价款优先权 | 第57条 | 动产浮动抵押场景下的价款超级优先权 |
| 抵押预告登记 | 第52条 | 明确预告登记在一定条件下具有顺位优先性 |
| 上市公司特别规定 | 第9条 | 强化信息披露要求，严格担保效力认定 |
| 动产统一登记 | 第54条 | 明确未登记动产抵押权不能对抗第三人 |

## 与旧制度的主要变化

| 旧制度（担保法） | 新制度（民法典担保制度解释） |
|------------------|------------------------------|
| 流押、流质条款有效 | 流押、流质条款无效，但不影响担保意思表示效力 |
| 保证方式推定为连带责任保证 | 保证方式推定为一般保证 |
| 担保人之间原则上可相互追偿 | 担保人之间原则上不能相互追偿 |
| 未登记动产抵押权仍可对抗部分第三人 | 未登记动产抵押权在破产程序中不享有优先权 |
| 公司对外担保无需决议 | 公司对外担保须依《公司法》第16条决议 |
| 上市公司担保适用一般规则 | 上市公司担保须公开披露，否则不承担任何责任 |
