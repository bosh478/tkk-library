## 刑事责任年龄
- 档1：已满16周岁 → 应当负刑事责任
- 档2：已满14周岁不满16周岁 → 犯故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质罪 → 应当负刑事责任
- 档3：已满12周岁不满14周岁 → 犯故意杀人、故意伤害罪，致人死亡或以特别残忍手段致人重伤造成严重残疾，情节恶劣，经最高人民检察院核准追诉 → 应当负刑事责任
- 档4：已满75周岁的人故意犯罪 → 可以从轻或减轻处罚；过失犯罪 → 应当从轻或减轻处罚

## 典型罪名量刑档次（摘要）

### 危害国家安全罪

#### 背叛国家罪
- 档1：勾结外国，危害主权、领土完整和安全 → 无期徒刑或10年以上有期徒刑

#### 分裂国家罪
- 档1：首要分子或罪行重大 → 无期徒刑或10年以上有期徒刑
- 档2：积极参加 → 3年以上10年以下有期徒刑
- 档3：其他参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利

#### 颠覆国家政权罪
- 档1：首要分子或罪行重大 → 无期徒刑或10年以上有期徒刑
- 档2：积极参加 → 3年以上10年以下有期徒刑
- 档3：其他参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利

#### 间谍罪
- 档1：参加间谍组织或接受任务/为敌人指示攻击目标 → 10年以上有期徒刑或无期徒刑
- 档2：情节较轻 → 3年以上10年以下有期徒刑

### 危害公共安全罪

#### 放火罪、决水罪、爆炸罪、投放危险物质罪、以危险方法危害公共安全罪（第114条）
- 档1：尚未造成严重后果 → 3年以上10年以下有期徒刑
- 档2：致人重伤、死亡或重大财产损失 → 10年以上有期徒刑、无期徒刑或死刑

#### 交通肇事罪
- 档1：重大事故，致人重伤、死亡或重大财产损失 → 3年以下有期徒刑或拘役
- 档2：交通运输肇事后逃逸或其他特别恶劣情节 → 3年以上7年以下有期徒刑
- 档3：因逃逸致人死亡 → 7年以上有期徒刑

#### 危险驾驶罪
- 档1：追逐竞驶（情节恶劣）、醉酒驾驶、严重超员超速、违规运输危险化学品 → 拘役，并处罚金

#### 妨害安全驾驶罪（新增）
- 档1：对行驶中公共交通工具驾驶人员使用暴力或抢控驾驶装置 → 1年以下有期徒刑、拘役或管制，并处或单处罚金

#### 重大责任事故罪
- 档1：违反安全管理规定，发生重大伤亡或严重后果 → 3年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 3年以上7年以下有期徒刑

#### 强令、组织他人违章冒险作业罪
- 档1：强令违章冒险作业或明知重大隐患不排除 → 5年以下有期徒刑或拘役
- 档2：情节特别恶劣 → 5年以上有期徒刑

#### 危险作业罪（新增）
- 档1：关闭破坏安全设备、拒不执行整改、擅自从事高危作业 → 1年以下有期徒刑、拘役或管制

### 破坏社会主义市场经济秩序罪

#### 生产、销售假药罪
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：对人体健康造成严重危害或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：致人死亡或其他特别严重情节 → 10年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产

#### 走私武器、弹药罪
- 档1：情节较轻 → 3年以上7年以下有期徒刑，并处罚金
- 档2： → 7年以上有期徒刑，并处罚金或没收财产
- 档3：情节特别严重 → 无期徒刑，并处没收财产

#### 伪造货币罪
- 档1： → 3年以上10年以下有期徒刑，并处罚金
- 档2：伪造货币集团首要分子/数额特别巨大/其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

#### 非法吸收公众存款罪
- 档1：扰乱金融秩序 → 3年以下有期徒刑或拘役，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑，并处罚金

#### 集资诈骗罪
- 档1：数额较大 → 3年以上7年以下有期徒刑，并处罚金
- 档2：数额巨大或其他严重情节 → 7年以上有期徒刑或无期徒刑，并处罚金或没收财产

#### 洗钱罪
- 档1： → 5年以下有期徒刑或拘役，并处或单处洗钱数额5%以上20%以下罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处洗钱数额5%以上20%以下罚金

### 侵犯公民人身权利、民主权利罪

#### 故意杀人罪
- 档1： → 死刑、无期徒刑或10年以上有期徒刑
- 档2：情节较轻 → 3年以上10年以下有期徒刑

#### 强奸罪
- 档1： → 3年以上10年以下有期徒刑
- 档2：奸淫不满14周岁幼女 → 以强奸论，从重处罚
- 档3：情节恶劣/多人/当众/轮奸/致重伤死亡 → 10年以上有期徒刑、无期徒刑或死刑

#### 负有照护职责人员性侵罪（新增）
- 档1：对已满14周岁不满16周岁未成年女性负有监护等职责人员与其发生性关系 → 3年以下有期徒刑
- 档2：情节恶劣 → 3年以上10年以下有期徒刑

#### 猥亵儿童罪
- 档1： → 5年以下有期徒刑
- 档2：多人多次/聚众当众/造成伤害/手段恶劣 → 5年以上有期徒刑

#### 绑架罪
- 档1： → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产
- 档2：情节较轻 → 5年以上10年以下有期徒刑，并处罚金
- 档3：杀害被绑架人或故意伤害致重伤死亡 → 死刑，并处没收财产

### 侵犯财产罪

#### 抢劫罪
- 档1： → 3年以上10年以下有期徒刑，并处罚金
- 档2：入户/公共交通工具/银行/多次/数额巨大/致人重伤死亡/冒充军警/持枪/军用物资 → 10年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产

#### 盗窃罪
- 档1：数额较大/多次/入户/携带凶器/扒窃 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

#### 诈骗罪
- 档1：数额较大 → 3年以下有期徒刑、拘役或管制，并处或单处罚金
- 档2：数额巨大或其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

#### 职务侵占罪
- 档1：数额较大 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大 → 10年以上有期徒刑或无期徒刑，并处罚金

#### 挪用资金罪
- 档1：归个人使用/借贷他人，数额较大超3个月未还/进行营利活动/非法活动 → 3年以下有期徒刑或拘役
- 档2：数额巨大 → 3年以上7年以下有期徒刑
- 档3：数额特别巨大 → 7年以上有期徒刑

### 妨害社会管理秩序罪

#### 袭警罪
- 档1：暴力袭击正在依法执行职务的人民警察 → 3年以下有期徒刑、拘役或管制
- 档2：使用枪支、管制刀具或驾驶机动车撞击 → 3年以上7年以下有期徒刑

#### 寻衅滋事罪
- 档1： → 5年以下有期徒刑、拘役或管制
- 档2：纠集他人多次实施，严重破坏社会秩序 → 5年以上10年以下有期徒刑，可以并处罚金

#### 高空抛物罪（新增）
- 档1：情节严重 → 1年以下有期徒刑、拘役或管制，并处或单处罚金

#### 催收非法债务罪（新增）
- 档1：使用暴力胁迫/限制人身自由/恐吓跟踪骚扰 → 3年以下有期徒刑、拘役或管制，并处或单处罚金

#### 组织、领导、参加黑社会性质组织罪
- 档1：组织领导 → 7年以上有期徒刑，并处没收财产
- 档2：积极参加 → 3年以上7年以下有期徒刑，可以并处罚金或没收财产
- 档3：其他参加 → 3年以下有期徒刑、拘役、管制或剥夺政治权利，可以并处罚金

#### 赌博罪
- 档1：聚众赌博或以赌博为业 → 3年以下有期徒刑、拘役或管制，并处罚金

#### 开设赌场罪
- 档1： → 5年以下有期徒刑、拘役或管制，并处罚金
- 档2：情节严重 → 5年以上10年以下有期徒刑，并处罚金

### 贪污贿赂罪

#### 贪污罪
- 档1：数额较大或有其他较重情节 → 3年以下有期徒刑或拘役，并处罚金
- 档2：数额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金或没收财产
- 档3：数额特别巨大或有其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产；使国家和人民利益遭受特别重大损失 → 无期徒刑或死刑，并处没收财产

#### 受贿罪
- 档1： → 3年以下有期徒刑或拘役
- 档2：数额巨大或有其他严重情节 → 3年以上10年以下有期徒刑，并处罚金
- 档3：数额特别巨大或有其他特别严重情节 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产

#### 行贿罪
- 档1： → 3年以下有期徒刑或拘役，并处罚金
- 档2：情节严重或使国家利益遭受重大损失 → 3年以上10年以下有期徒刑，并处罚金
- 档3：情节特别严重或使国家利益遭受特别重大损失 → 10年以上有期徒刑或无期徒刑，并处罚金或没收财产
