## 概念定义

**欺诈**（民法典第148条、149条；《民法典总则编解释》第21条）：
- 一方当事人故意告知对方虚假情况，或故意隐瞒真实情况
- 致使当事人基于错误认识作出意思表示

**医疗美容欺诈**：医疗美容机构或相关人员在提供医疗美容服务过程中，故意虚构事实、隐瞒真相，诱使消费者作出错误消费决策的行为。

## 欺诈四要件

| 要件 | 说明 |
|------|------|
| 欺诈故意 | 明知虚假仍故意告知或隐瞒 |
| 欺诈行为 | 虚构、夸大、虚假承诺等 |
| 消费者陷入错误 | 消费者基于错误认识作出意思表示 |
| 误导消费者进行消费 | 错误认识与消费决策之间有因果关系 |

## 四种欺诈类型

### 1. 虚假宣传

**表现形式**：
- 虚构、夸大美容机构的地位、市场影响力、行业认可度
- 虚构医生专业资质、执业经历、职务职称
- 夸大产品特征或手术效果

### 2. 虚构资质

**违规情形**：
- 无《医疗机构执业许可证》
- 无执业医师资格
- 擅自更换无资质操作人员
- 夸大资质等级

### 3. 虚假承诺

- 虚假承诺医疗产品、医疗服务效果
- 过分夸大医疗技术水平和能达到的结果

### 4. 过度治疗

**定义**：为患者提供远超治疗疾病所需的医疗服务

**构成要件**：
1. 主观上存在恶意
2. 违反医疗管理制度、违背职业道德
3. 医疗行为是过度的、多余的甚至有害的

## 归责规则

### 职务代理

- 机构、工作人员欺诈 → 机构承担赔偿责任
- 基于职务产生的代理权，承诺效果及于机构

### 表见代理（渠道人员）

| 要件 | 说明 |
|------|------|
| 以机构名义活动 | 推介时以医疗美容机构名义 |
| 收取服务费 | 实际收取消费者费用 |
| 促成交易 | 促成交易实现 |
| 足以令人信赖 | 消费者相信是机构人员 |
| 善意无过失 | 消费者善意且无过失 |

**效果**：代理行为有效，后果拘束医疗美容机构

## 惩罚性赔偿

### 认定标准

- 三倍赔偿（《消费者权益保护法》第55条）
- 信息对购买行为有实质性影响

### 赔偿范围计算

| 情形 | 计算基数 |
|------|----------|
| 部分欺诈（单一性/可分性） | 该部分服务价款 |
| 整体欺诈或不可分 | 整体服务价款 |
