## 背景

贯彻落实《中共中央关于加强新时代审判工作的意见》，根据《中华人民共和国国民经济和社会发展第十五个五年规划纲要》、《知识产权强国建设纲要（2021—2035年）》制定。

## 总体要求

### 指导思想

坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平法治思想，聚焦新兴领域知识产权司法保护，助力新质生产力加快发展。

### 基本原则

| 原则 | 说明 |
|------|------|
| 党的绝对领导 | 把党的领导贯穿各方面全过程 |
| 人民至上 | 满足人民群众对知识产权公正高效保护的需求 |
| 改革创新 | 聚焦重点领域和关键环节，持续深化体制机制改革 |
| 开放共赢 | 深化国际交流合作，服务高水平对外开放 |

### 主要目标（2030年）

- 知识产权司法规则体系进一步完善
- 符合知识产权案件特点的诉讼制度进一步健全
- 审判体制机制进一步优化
- 审判队伍能力进一步提升
- 知识产权案件审理**专门化、管辖集中化、程序集约化、人员专业化**显著提升

## 重点工作（二十二条）

### 一、发挥审判职能作用（四至十一条）

| 条目 | 内容 |
|------|------|
| 第四条 | 加强科技创新保护，服务高水平科技自立自强（集成电路、工业母机、高端仪器、基础软件等） |
| 第五条 | 加强著作权保护（盗版图书、音视频、软件，聚合盗链，网盘侵权） |
| 第六条 | 加强商业标志保护（商标恶意注册、傍名牌、地理标志） |
| 第七条 | 加强反垄断反不正当竞争审判（整治内卷式竞争、商业秘密保护） |
| 第八条 | 加强数据权益司法保护（数据产权、数字经济） |
| 第九条 | 妥善审理涉人工智能案件（生成内容权属、大模型训练语料） |
| 第十条 | 强化涉外知识产权审判（跨境诉讼、平行诉讼） |
| 第十一条 | 加大对侵权行为惩治力度（惩罚性赔偿、刑事打击） |

### 二、健全审判体制机制（十二至十五条）

| 条目 | 内容 |
|------|------|
| 第十二条 | 加强审判专门化建设（国家层面知识产权案件上诉审理机制改革） |
| 第十三条 | 优化案件诉讼程序（民事、行政和刑事诉讼衔接，刑事附带民事诉讼） |
| 第十四条 | 推动研究制定知识产权诉讼特别程序法 |
| 第十五条 | 完善技术事实查明机制（技术调查官、专家辅助人、鉴定人） |

### 三、完善保护工作机制（十六至二十条）

| 条目 | 内容 |
|------|------|
| 第十六条 | 健全法律适用规则体系（指导性案例、人民法院案例库、"一张网"、"法答网"） |
| 第十七条 | 加强非正常批量诉讼、虚假诉讼、恶意诉讼综合治理 |
| 第十八条 | 完善司法权运行机制（院庭长阅核制度） |
| 第十九条 | 强化行政执法与司法衔接机制 |
| 第二十条 | 健全多元化纠纷解决机制（枫桥经验、"总对总"机制） |

### 四、强化审判保障（二十一至二十二条）

| 条目 | 内容 |
|------|------|
| 第二十一条 | 加强政治和组织保障（防止干预司法"三个规定"） |
| 第二十二条 | 加强队伍和人才保障（"知识产权专业审判人才平台"） |

## 核心关键词

- **新质生产力**：助力关键核心技术与新兴产业领域创新
- **专门化**：案件审理专门化、管辖集中化、程序集约化、人员专业化
- **全链条保护**：民事司法保护、行政执法、刑事打击协同
- **国际化**：深化知识产权司法国际交流合作
