# 民法典适用大全·知识产权与竞争卷 综合

## 概述

《中国民法典适用大全（知识产权与竞争卷）》由最高人民法院民法典贯彻实施工作领导小组编著，人民法院出版社2022年12月出版。全卷涵盖《专利法》《著作权法》《商标法》《反不正当竞争法》《反垄断法》《计算机软件保护条例》《集成电路布图设计保护条例》《种子法》及《植物新品种保护条例》等法律规范。

---

## 一、著作权法核心要点

### 1. 作品定义与特征

**《著作权法》第3条**规定了作品的定义：文学、艺术和科学领域内具有独创性并能以一定形式表现的智力成果。

作品三大特征：
- **独创性**：作品是作者独立完成的智力劳动成果，不同于专利法的创造性
- **一定形式表现**：能够以某种有形形式复制（非仅存在于脑海中）
- 属于智力创造成果

**九类作品**：文字作品、口述作品、音乐/戏剧/曲艺/舞蹈/杂技艺术作品、美术/建筑作品、摄影作品、视听作品、工程设计图/产品设计图等图形作品和模型作品、计算机软件、符合作品特征的其他智力成果。

### 2. 著作权主体与归属

**《著作权法》第9-21条**规定了著作权主体及归属规则：

| 情形 | 权利归属 |
|------|----------|
| 作者创作 | 作者享有 |
| 职务作品 | 单位享有（主要利用单位物质条件） |
| 合作作品 | 合作作者共同享有 |
| 演绎作品 | 演绎人享有（不影响原作品权利） |
| 汇编作品 | 汇编人享有（不损害原作品权利） |
| 视听作品 | 制作者享有（作者保留署名权） |
| 委托作品 | 约定优先，无约定归受托人 |

### 3. 著作权保护期限

- **人身权利（署名权、修改权、保护作品完整权）**：不受限制
- **发表权、财产权**：自然人终身+死后50年；法人/非法人组织作品：发表后50年

### 4. 合理使用与法定许可

**《著作权法》第24条**合理使用情形：
- 为个人学习、研究欣赏使用
- 为介绍、评论作品适当引用
- 为报道新闻引用
- 用于课堂教学或科学研究
- 图书馆等公共场所陈列或保存版本

合理使用需注明作者姓名、作品名称，不得影响正常使用。

### 5. 著作权侵权认定

**"接触+实质性相似"原则**：判断侵权的基本原则
- 接触：在先作品是否公开发表、被控侵权人是否有接触可能
- 实质性相似：作品在表达上是否构成实质性相似

典型案例：**刘福平与内蒙古阿儿含只文化公司案**（2019内民终156号）——电影剧本《母亲》vs《诺日吉玛》著作权侵权

## 二、专利法核心要点

### 1. 受保护的发明创造

**《专利法》第2条**定义三种专利：
- **发明**：对产品、方法或者其改进提出的新技术方案
- **实用新型**：对产品形状、构造提出的适于实用的新技术方案
- **外观设计**：对产品整体或局部的形状、图案等作出的富有美感的新设计

### 2. 职务发明创造

**《专利法》第6条**核心规则：

| 类型 | 情形 | 权利归属 |
|------|------|----------|
| 本职工作发明 | 在本职工作中作出的 | 单位 |
| 任务发明 | 履行本单位交付的任务所作出的 | 单位 |
| 离职后发明 | 离职后1年内作出的，与原单位任务有关的 | 原单位 |
| 主要利用单位物质条件 | 利用本单位资金、设备等 | 单位（约定优先） |

**《专利法实施细则》第12条**明确：
- "本单位"包括临时工作单位
- 物质技术条件指：本单位资金、设备、零部件、原材料、不对外公开的技术资料

典型案例：**深圳市卫邦科技有限公司诉李坚毅案**（指导案例158号）——离职员工专利权权属纠纷，判断是否"有关的发明创造"需综合考量四点因素

### 3. 专利侵权与保护

**《专利法》第64条**规定了专利权保护范围以权利要求内容为准。

**现有技术抗辩**（第67条）：在专利侵权纠纷中，被诉侵权人以现有技术进行抗辩的，可以参照适用。

**合法来源抗辩**（第77条）：不知道是侵权产品而购买、使用或销售，能证明合法来源的，不承担赔偿责任。

## 三、商标法核心要点

### 1. 商标注册条件

**《商标法》第9条**：申请注册的商标应有显著特征，便于识别

**《商标法》第11条**缺乏显著特征的标志：
- 仅有商品通用名称、图形、型号
- 仅直接表示商品质量、主要原料、功能等
- 其他缺乏显著特征

**显著性分类**：
- **固有显著特征**：臆造性标志、任意性标志、暗示性标志
- **获得显著特征**：经过使用取得"第二含义"

### 2. 禁止注册/使用情形

**《商标法》第10条**禁用标志：
- 同中华人民共和国的国家名称等相同或近似的
- 同外国国家名称等相同或近似的
- 同政府间国际组织名称相同或近似的
- 县级以上行政区划名称（有其他含义除外）
- 带有欺骗性、有害社会主义道德风尚的

### 3. 驰名商标保护

**《商标法》第13条**确立驰名商标保护制度：

| 类型 | 保护范围 | 适用条件 |
|------|----------|----------|
| 未注册驰名商标 | 相同/类似商品 | 容易导致混淆 |
| 已注册驰名商标 | 不相同/不类似商品 | 误导公众，损害利益 |

**认定考虑因素**（《商标法》第14条）：
1. 相关公众知晓程度
2. 使用持续时间
3. 宣传工作的持续时间、程度、地理范围
4. 作为驰名商标受保护的记录
5. 其他因素

典型案例：
- **克里斯蒂昂迪奥尔香料公司案**（2018最高法行再26号）——立体商标显著特征判断
- **"新华字典"案**（2016京73民初277号）——未注册驰名商标保护
- **腾讯"滴滴滴滴滴滴"声音商标案**——声音商标显著特征

### 4. 商标侵权赔偿

**《商标法》第63条**确定赔偿顺序：
1. 实际损失
2. 侵权获利
3. 参照许可使用费合理倍数
4. 法定赔偿（500万元以下）

**惩罚性赔偿**：故意侵权、情节严重的，可按上述数额1-5倍赔偿。

## 四、反不正当竞争法核心要点

### 1. 不正当竞争行为类型

**《反不正当竞争法》第6条**禁止混淆行为：
- 擅自使用他人有一定影响的企业名称、网站名称等
- 擅自使用他人有一定影响的域名主体等

**《反不正当竞争法》第9条**禁止侵犯商业秘密：
- 以盗窃、贿赂等不正当手段获取
- 披露、使用允许他人使用的商业秘密
- 第三人明知仍获取、披露

### 2. 互联网不正当竞争

**《反不正当竞争法》第12条**规制网络不正当竞争：
- 未经同意插入链接或强制跳转
- 恶意不兼容
- 其他影响网络用户选择的行为

## 五、反垄断法核心要点

### 1. 垄断行为类型

**《反垄断法》**规定三类垄断行为：
- **垄断协议**：横向协议（固定价格、划分市场）、纵向协议（转售价格维持）
- **滥用市场支配地位**：不公平价格、拒绝交易、限定交易等
- **经营者集中**：合并、收购等导致竞争影响

### 2. 知识产权与反垄断

**《反垄断法》第68条**明确：经营者依照有关知识产权的法律、行政法规规定行使知识产权的行为，不适用本法；但经营者达成垄断协议、滥用市场支配地位的除外。

## 八、法律适用注意事项

1. **知识产权与民法典的关系**：《民法典》第123条确认知识产权为民事权利，知识产权法适用以民法为底蕴，需形成民法思维和意识。

2. **特别法与一般法**：知识产权专门法（《专利法》《商标法》《著作权法》）有专门规定时适用专门法；无规定时适用民法典一般规则。

3. **惩罚性赔偿适用**：故意侵权+情节严重是适用惩罚性赔偿的双要件。

4. **证据规则**：知识产权侵权诉讼中，权利人举证困难时可适用举证责任转移（举证责任转移规则）。
