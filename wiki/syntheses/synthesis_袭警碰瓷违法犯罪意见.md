## 一、袭警违法犯罪

### （一）暴力袭警的认定

根据《关于依法惩治袭警违法犯罪行为的指导意见》（2020年1月10日发布），对正在依法执行职务的民警实施下列行为的，属于《刑法》第二百七十七条第五款规定的"暴力袭击正在依法执行职务的人民警察"：

| 行为类型 | 具体表现 | 定罪 |
|----------|----------|------|
| 直接人身攻击 | 撕咬、踢打、抱摔、投掷等 | 妨害公务罪（从重处罚） |
| 警用装备攻击 | 打砸、毁坏、抢夺民警正在使用的警用车辆、警械等 | 妨害公务罪（从重处罚） |
| 暴力威胁 | 以实施暴力相威胁（未实际暴力袭击） | 妨害公务罪 |

**特殊规定**：
- 醉酒的人实施袭警犯罪行为，应当负刑事责任
- 教唆、煽动他人实施袭警犯罪行为或者提供工具、帮助的，以共同犯罪论处

### （二）从重处罚情节

具有下列情形之一的，酌情从重处罚：

1. 使用凶器或者危险物品袭警、驾驶机动车袭警的
2. 造成民警轻微伤或者警用装备严重毁损的
3. 妨害民警依法执行职务，造成他人伤亡、公私财产损失或者造成犯罪嫌疑人脱逃、毁灭证据等严重后果的
4. 造成多人围观、交通堵塞等恶劣社会影响的
5. 纠集多人袭警或者袭击民警二人以上的
6. 曾因袭警受过处罚，再次袭警的
7. 实施其他严重袭警行为的

**缓刑限制**：实施上述行为构成犯罪的，一般不得适用缓刑。

### （三）升格处罚情形

| 情形 | 定罪 | 法定刑 |
|------|------|--------|
| 驾车冲撞、碾轧、拖拽、剐蹭民警，或挤别、碰撞正在执行职务的警用车辆，危害公共安全或民警生命、健康安全 | 以危险方法危害公共安全罪 | 《刑法》第114条、第115条 |
| 上述行为致民警重伤、死亡 | 故意伤害罪、故意杀人罪 | 《刑法》第232条、第234条 |
| 暴力袭警致使民警重伤、死亡 | 故意伤害罪、故意杀人罪 | 《刑法》第232条、第234条 |
| 抢劫、抢夺民警枪支 | 抢劫枪支罪、抢夺枪支罪 | 《刑法》第127条第二款 |

### （四）职务认定

- **执行职务认定**：民警在非工作时间，依照《人民警察法》等法律履行职责的，应当视为执行职务
- **非执行职务期间**：因职务行为对民警实施暴力袭击、拦截、恐吓等行为，以故意伤害罪、故意杀人罪、寻衅滋事罪等定罪，酌情从重处罚

## 二、碰瓷违法犯罪

### （一）"碰瓷"定义

根据《关于依法办理"碰瓷"违法犯罪案件的指导意见》（公通字〔2020〕12号），"碰瓷"是指行为人通过故意制造或者编造其被害假象，采取诈骗、敲诈勒索等方式非法索取财物的行为。

**常见实施方式**：
- "设局"制造或者捏造他人对其人身、财产造成损害
- 自伤、造成同伙受伤或者利用自身原有损伤，诬告系被害人所致
- 故意制造交通事故，利用被害人违法违规行为，通过害怕被查处的心理实施
- 在"碰瓷"行为被识破后，直接对被害人实施抢劫、抢夺、故意伤害等违法犯罪活动

### （二）罪名认定汇总

| 罪名 | 行为表现 | 法条依据 |
|------|----------|----------|
| **诈骗罪** | 虚构事实、隐瞒真相，骗取赔偿 | 《刑法》第266条 |
| **保险诈骗罪** | 骗取保险金 | 《刑法》第198条 |
| **虚假诉讼罪** | 捏造人身、财产权益受到侵害的事实，虚构民事纠纷，提起民事诉讼 | 《刑法》第307条之一 |
| **敲诈勒索罪** | 撕扯、推搡等轻微暴力或软暴力；故意制造交通事故要挟；揭露隐私要挟；扬言实施侵害 | 《刑法》第274条 |
| **抢劫罪** | 当场使用暴力、胁迫或者其他方法，当场劫取他人财物 | 《刑法》第263条 |
| **盗窃罪** | 采取转移注意力、趁人不备等方式窃取他人财物 | 《刑法》第264条 |
| **抢夺罪** | 采取转移注意力、趁人不备等方式夺取他人财物 | 《刑法》第267条 |
| **故意毁坏财物罪** | 故意造成他人财物毁坏 | 《刑法》第275条 |
| **交通肇事罪** | 驾驶机动车追逐、冲撞、挤别、拦截等，发生重大事故致人重伤、死亡或重大财产损失 | 《刑法》第133条 |
| **故意杀人罪** | 为实施"碰瓷"而故意杀害他人 | 《刑法》第232条 |
| **故意伤害罪** | 为实施"碰瓷"而故意伤害他人 | 《刑法》第234条 |
| **过失致人死亡罪** | 过失致人死亡 | 《刑法》第233条 |
| **过失致人重伤罪** | 过失致人重伤 | 《刑法》第235条 |
| **非法拘禁罪** | 非法剥夺他人人身自由 | 《刑法》第238条 |
| **非法搜查罪** | 非法搜查他人身体 | 《刑法》第245条 |

### （三）共同犯罪处理

- 起主要作用的认定为主犯，对参与或者组织、指挥的全部犯罪承担刑事责任
- 起次要或者辅助作用的认定为从犯，依法从轻、减轻处罚或者免除处罚
- 三人以上为共同故意实施"碰瓷"犯罪而组成的较为固定的犯罪组织，认定为犯罪集团，对首要分子按集团所犯全部罪行处罚
- 符合黑恶势力认定标准的，按照黑社会性质组织、恶势力或者恶势力犯罪集团处理

### （四）治安处罚

对实施"碰瓷"，尚不构成犯罪，但构成违反治安管理行为的，依法给予治安管理处罚。

## 三、适用要点汇总表

| 案件类型 | 违法行为 | 涉及罪名 | 法定刑档次 | 加重/从重情节 |
|----------|----------|----------|------------|---------------|
| **袭警类** | 暴力袭击正在执行职务的民警 | 妨害公务罪 | 从重处罚（三年以下有期徒刑、拘役或者管制；致人重伤的，处三年以上十年以下有期徒刑） | 使用凶器/机动车袭警；致民警轻微伤/装备严重毁损；造成恶劣社会影响；纠集多人袭警；再犯 |
| | 驾车冲撞警车、危害公共安全 | 以危险方法危害公共安全罪 | 《刑法》第114条（三年以上十年以下）；第115条（十年以上有期徒刑、无期徒刑或者死刑） | 酌情从重处罚 |
| | 暴力袭警致民警重伤、死亡 | 故意伤害罪/故意杀人罪 | 致人重伤三年以上十年以下；致人死亡十年以上、无期、死刑 | 酌情从重处罚 |
| | 抢劫、抢夺民警枪支 | 抢劫枪支罪/抢夺枪支罪 | 《刑法》第127条第二款 | 从重处罚 |
| **碰瓷类** | 虚构事实骗取赔偿 | 诈骗罪 | 《刑法》第266条（三档：三年以下；三年以上十年以下；十年以上或无期） | 从重处罚 |
| | 捏造事实提起民事诉讼 | 虚假诉讼罪 | 《刑法》第307条之一（三档） | 从重处罚 |
| | 软暴力/要挟索取财物 | 敲诈勒索罪 | 《刑法》第274条（三档：三年以下；三年以上十年以下；十年以上） | 从重处罚 |
| | 当场使用暴力劫取财物 | 抢劫罪 | 《刑法》第263条（多档：三年以上十年以下；十年以上、无期、死刑） | 从严惩处 |
| | 趁人不备窃取/夺取 | 盗窃罪/抢夺罪 | 《刑法》第264条/第267条 | 视情节 |

| | 为碰瓷故意伤害/杀人 | 故意伤害罪/故意杀人罪 | 《刑法》第232条/第234条 | 依法严惩 |

## 四、程序要点

### （一）办理要求
- 公安机关：接到报案、控告、举报后应当立即赶到现场，及时制止违法犯罪，妥善保护案发现场，控制行为人
- 人民检察院：对于符合逮捕、起诉条件的，应当依法尽快予以批捕、起诉；从严掌握不捕不诉情形
- 人民法院：依法及时审判，严格依法追究犯罪分子刑事责任

### （二）证据收集
- 民警现场执法记录仪和周边监控等视听资料
- 在场人员证人证言
- 伤情鉴定、财产损失鉴定

### （三）政策把握
- **袭警案件**：依法不适用刑事和解和治安调解
- **碰瓷案件**：落实认罪认罚从宽制度，区分"碰瓷"违法犯罪同普通民事纠纷、行政违法的界限
- 对犯罪性质和危害后果特别严重、犯罪手段特别残忍、社会影响特别恶劣的，虽有酌定从宽情节但不足以从轻处罚的，依法不予从宽处罚
