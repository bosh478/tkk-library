## 一、保险法核心要点

### 1.1 保险合同基本规则

**保险定义**（第2条）：投保人向保险人支付保险费，保险人承担赔偿或给付保险金责任的的商业保险行为。

**基本原则**：
- 自愿原则：除法律、行政法规规定必须保险的外，保险合同自愿订立（第11条）
- 诚实信用原则：保险活动当事人行使权利、履行义务应遵循诚实信用原则（第5条）
- 利益原则：人身保险在订立时对被保险人应有保险利益；财产保险在事故发生时对保险标的应有保险利益（第12条）

### 1.2 如实告知义务（第16条）

| 情形 | 后果 |
|------|------|
| 故意不履行告知义务 | 保险人有权解除合同，不承担赔偿或给付责任，且不退还保险费 |
| 因重大过失未履行告知义务 | 保险人有权解除合同，不承担赔偿或给付责任，但应退还保险费 |
| 合同成立超过二年 | 保险人不得解除合同，发生事故应承担赔偿责任（不可抗辩条款） |
| 保险人已知未告知仍承保 | 不得解除合同，应承担赔偿责任 |

### 1.3 人身保险特殊规则

**保险利益范围**（第31条）：
1. 本人
2. 配偶、子女、父母
3. 与投保人有抚养、赡养或扶养关系的家庭成员、近亲属
4. 与投保人有劳动关系的劳动者
5. 被保险人同意投保人为其订立合同的

**死亡保险限制**（第33-34条）：
- 不得为无民事行为能力人投保以死亡为给付条件的保险
- 以死亡为给付条件的合同须经被保险人同意并认可保险金额
- 父母为未成年子女投保不受此限，但死亡给付保险金不得超过规定限额

**受益人指定**（第39-42条）：
- 受益人由被保险人或投保人指定，投保人指定须经被保险人同意
- 受益人为数人的，可确定受益顺序和份额
- 未确定份额的，按相等份额享有受益权

### 1.4 财产保险核心制度

**代位求偿权**（第60条）：因第三者对保险标的损害造成保险事故，保险人在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利。但被保险人已从第三者取得损害赔偿的，保险人可相应扣减。

**重复保险**（第56条）：
- 重复保险的投保人应将有关情况通知各保险人
- 各保险人按保险金额与保险金额总和的比例承担赔偿责任

### 1.5 保险公司经营规则

**注册资本**（第69条）：最低限额为人民币二亿元，必须为实缴货币资本。

**资金运用**（第106条）：
- 银行存款
- 买卖债券、股票、证券投资基金份额等有价证券
- 投资不动产
- 国务院规定的其他资金运用形式

**分业经营**（第8条）：保险业与银行业、证券业、信托业分业经营、分业管理。

### 1.6 保险业监督管理

**偿付能力监管**（第137-139条）：
- 建立健全偿付能力监管体系
- 对偿付能力不足的保险公司可采取：责令增加资本金、限制业务范围、限制向股东分红、停止接受新业务等措施

**接管制度**（第144-147条）：
- 情形：偿付能力严重不足；违反本法规定损害社会公共利益
- 接管期限最长不超过二年

## 二、中国人民银行法核心要点

### 2.1 中央银行地位与货币政策目标

**法律地位**（第2条）：中国人民银行是中华人民共和国的中央银行，在国务院领导下制定和执行货币政策，防范和化解金融风险，维护金融稳定。

**货币政策目标**（第3条）：保持货币币值的稳定，并以此促进经济增长。

### 2.2 中国人民银行职责（第4条）

| 类别 | 具体职责 |
|------|----------|
| 货币发行 | 发布命令规章；发行人民币，管理人民币流通 |
| 市场监管 | 监督管理银行间同业拆借市场、债券市场；外汇管理，监督外汇市场；监督管理黄金市场 |
| 储备管理 | 持有、管理、经营国家外汇储备、黄金储备 |
| 金融服务 | 经理国库；维护支付、清算系统正常运行；金融业统计、调查、分析和预测 |
| 反洗钱 | 指导、部署金融业反洗钱工作，负责反洗钱资金监测 |

### 2.3 货币政策工具（第23条）

1. 要求银行业金融机构按照规定比例交存存款准备金
2. 确定中央银行基准利率
3. 为在人民银行开立账户的银行业金融机构办理再贴现
4. 向商业银行提供贷款
5. 在公开市场上买卖国债、其他政府债券和金融债券及外汇
6. 国务院确定的其他货币政策工具

### 2.4 业务限制（负面清单）

**绝对禁止**（第29-30条）：
- 不得对政府财政透支
- 不得直接认购、包销国债和其他政府债券
- 不得向地方政府、各级政府部门提供贷款
- 不得向非银行金融机构以及其他单位和个人提供贷款（国务院决定除外）
- 不得向任何单位和个人提供担保

### 2.5 金融监督管理权

**检查监督范围**（第32条）：
- 执行有关存款准备金管理规定的行为
- 执行有关人民币管理规定的行为
- 执行有关银行间同业拆借市场、银行间债券市场管理规定的行为
- 执行有关外汇管理规定的行为
- 执行有关黄金管理规定的行为
- 执行有关清算管理规定的行为
- 执行有关反洗钱规定的行为

## 三、证券法核心要点

### 3.1 证券发行制度

**注册制**（第9条）：公开发行证券须依法报经国务院证券监督管理机构或国务院授权部门注册。证券公开发行注册的具体范围、实施步骤由国务院规定。

**公开发行认定**（第9条）：
1. 向不特定对象发行证券
2. 向特定对象发行证券累计超过二百人（员工持股计划除外）
3. 法律、行政法规规定的其他发行行为

**发行条件**（第12条 公司首次公开发行新股）：
1. 具备健全且运行良好的组织机构
2. 具有持续经营能力
3. 最近三年财务会计报告被出具无保留意见审计报告
4. 发行人及其控股股东、实际控制人最近三年不存在贪污、贿赂、侵占财产、挪用财产或破坏社会主义市场经济秩序的刑事犯罪

### 3.2 证券交易基本规则

**三公原则**（第3条）：公开、公平、公正。

**交易场所**（第37条）：
- 公开发行证券：在依法设立的证券交易所上市交易或国务院批准的其他全国性证券交易场所
- 非公开发行的证券：可在证券交易所、国务院批准的其他全国性证券交易场所、区域性股权市场转让

### 3.3 禁止的交易行为

**内幕交易**（第50-53条）：
- 禁止内幕信息的知情人利用内幕信息从事证券交易活动
- 内幕信息知情人范围：发行人董监高、持股5%以上股东及其董监高、收购人及其董监高、因职务可获取内幕信息的人员、监管机构工作人员等

**操纵市场**（第55条）：禁止以资金优势、持股优势、信息优势联合或连续买卖；禁止串通交易；禁止在自己实际控制的账户之间交易；禁止虚假申报等。

**短线交易**（第44条）：持有5%以上股份的股东、董监高在买入后六个月内卖出或卖出后六个月内买入，收益归公司所有。

### 3.4 上市公司收购

**权益变动披露**（第63条）：
- 达到5%时：三日内报告和公告，期间不得再买卖
- 5%之后每增减5%：三日内报告和公告，期间不得再买卖
- 每增减1%：次日通知并公告

**要约收购**（第65-70条）：
- 持股达到30%时继续收购应发出要约
- 收购期限不得少于30日，不得超过60日
- 收购条件适用于所有股东

### 3.5 信息披露制度

**定期报告**（第79条）：
- 年度报告：每一会计年度结束之日起四个月内
- 中期报告：每一会计年度上半年结束之日起二个月内

**临时报告**（第80条）：重大事件发生后立即报告并公告。

### 3.6 投资者保护

**投资者适当性**（第88条）：证券公司向投资者销售证券、提供服务时应充分了解投资者基本情况、财产状况、投资知识和经验等。

**先行赔付**（第93条）：发行人因欺诈发行、虚假陈述给投资者造成损失的，发行人的控股股东、实际控制人、相关证券公司可委托投资者保护机构与投资者达成协议先行赔付。

## 四、证券投资基金法核心要点

### 4.1 基金当事人

**基金管理人**（第12条）：由依法设立的公司或合伙企业担任。公开募集基金的基金管理人须为基金管理公司或经国务院证券监督管理机构核准的其他机构。

**基金托管人**（第32条）：由依法设立的商业银行或其他金融机构担任。基金托管人与基金管理人不得为同一机构，不得相互出资或持有股份。

### 4.2 基金分类

| 类型 | 特征 |
|------|------|
| 公开募集基金 | 向不特定对象募集资金或向特定对象超过200人募集资金 |
| 非公开募集基金 | 向合格投资者募集，不超过200人 |

### 4.3 公开募集基金

**设立审批**（第50条）：须经国务院证券监督管理机构注册。

**基金合同应载明事项**（第52条）：
- 募集基金的目的和基金名称
- 基金管理人、基金托管人的名称和住所
- 基金的运作方式
- 封闭式基金的总额和期限，或开放式基金的最低募集份额总额
- 基金份额发售日期、价格和费用
- 权利义务、收益分配、风险承担
- 投资方向和投资限制

**上市交易条件**（第62条）：
1. 基金募集符合规定
2. 基金合同期限五年以上
3. 基金募集金额不低于二亿元人民币
4. 基金份额持有人不少于一千人

### 4.4 基金投资限制（第73条）

**禁止行为**：
1. 承销证券
2. 违反规定向他人贷款或提供担保
3. 从事承担无限责任的投资
4. 买卖其他基金份额（国务院另有规定除外）
5. 向基金管理人、基金托管人出资
6. 从事内幕交易、操纵证券交易价格及其他不正当证券交易活动

### 4.5 非公开募集基金

**合格投资者标准**（第87条）：达到规定资产规模或收入水平，具备相应的风险识别能力和风险承担能力，认购金额不低于规定限额。

**登记备案**（第94条）：
- 基金管理人应向基金行业协会履行登记手续
- 募集完毕应向基金行业协会备案

### 4.6 基金服务机构

**基金销售机构**（第98条）：应向投资人充分揭示投资风险，并根据风险承担能力销售不同风险等级的基金产品。

**份额登记机构**（第102条）：以电子介质登记的数据是基金份额持有人权利归属的根据。

## 五、适用要点汇总表

### 5.1 金融监管体制对比

| 项目 | 保险法 | 人民银行法 | 证券法 | 证券投资基金法 |
|------|--------|------------|--------|----------------|
| 监管机构 | 国务院保险监督管理机构（银保监会） | 中国人民银行（中央银行） | 国务院证券监督管理机构（证监会） | 国务院证券监督管理机构 |
| 核心监管目标 | 保护投保人、被保险人、受益人合法权益 | 维护金融稳定，币值稳定 | 保护投资者合法权益 | 保护投资人及相关当事人合法权益 |
| 分业经营 | 保险业与银行、证券、信托分业经营 | 不适用 | 证券业与银行、信托、保险分业经营 | 纳入证券业监管 |

### 5.2 重要时限汇总

| 法律 | 事项 | 时限 |
|------|------|------|
| 保险法 | 保险人解除合同权（知道解除事由起） | 30日 |
| 保险法 | 不可抗辩条款（合同成立起） | 2年 |
| 保险法 | 人寿保险诉讼时效（知道事故起） | 5年 |
| 保险法 | 其他保险诉讼时效（知道事故起） | 2年 |
| 证券法 | 权益变动达到5%报告公告 | 3日内 |
| 证券法 | 发行注册审查 | 3个月内 |
| 证券法 | 短线交易限制 | 6个月内 |
| 基金法 | 基金托管人职责终止选任新托管人 | 6个月内 |

### 5.3 违规处罚对比

| 违法行为 | 保险法罚款标准 | 证券法罚款标准 |
|----------|----------------|----------------|
| 擅自设立机构经营 | 违法所得1-5倍；无违法所得20-100万 | 违法所得1-10倍；无违法所得100-1000万 |
| 虚假陈述 | 30-100万（机构）；10-50万（责任人员） | 100-1000万；50-500万（责任人员） |
| 内幕交易 | — | 违法所得1-10倍；无违法所得50-500万 |
| 操纵市场 | — | 违法所得1-10倍；无违法所得100-1000万 |

### 5.4 跨法条适用要点

1. **保险资金投资证券**：依据《保险法》第106条，保险资金可投资股票、证券投资基金份额等有价证券，须遵守证监会相关规定。

2. **证券公司承销保险**：证券法规定承销证券，但保险产品销售适用保险法规定，须取得保险代理业务资格。

3. **基金财产独立性**：基金财产独立于基金管理人、托管人固有财产，不得强制执行（第5-7条）。

4. **金融消费者保护**：证券法确立投资者适当性制度（第88条），保险法要求如实告知（第16条），均体现对金融消费者保护原则。

5. **自律组织**：保险业有保险行业协会，证券业有证券业协会，基金业有基金行业协会，均发挥自律管理作用。

## 六、法律衔接要点

### 6.1 保险法与证券法衔接

保险公司设立保险资产管理公司从事证券投资活动，须同时遵守《保险法》第107条和《证券法》相关规定。保险资产管理公司管理保险资金时，既是保险监管对象，又是证券监管对象。

### 6.2 证券法与基金法衔接

证券投资基金属于证券范畴，基金的投资、交易、信息披露等须同时遵守《证券法》和《证券投资基金法》。《证券投资基金法》未规定的，适用《信托法》《证券法》和其他法律、行政法规（第2条）。

### 6.3 金融稳定协调机制

根据《中国人民银行法》第9条，国务院建立金融监督管理协调机制。银保监会、证监会、人民银行之间建立监督管理信息共享机制（第157条保险法、第175条证券法）。
