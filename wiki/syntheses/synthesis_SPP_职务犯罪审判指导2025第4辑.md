# 职务犯罪审判指导2025第4辑

> **来源**：最高人民法院刑事审判第二庭编《职务犯罪审判指导》第4辑，法律出版社2025年版

## 裁判要旨汇总

### 案例1：查缉走私过程中非法侵吞赃物的行为定性 [^1]

| 项目 | 内容 |
|------|------|
| **案号** | [编号045] |
| **法院** | 广东省高级人民法院（二审） |
| **裁判要旨** | 国家工作人员在履行职务过程中擅自联合非身份人员，滥用执法职权实现对赃物的即时控制，侵吞该财物的，应以贪污罪论处。非身份人员明知国家工作人员利用职权侵吞公共财物，仍提供帮助参与财物转移、隐匿或变卖的，构成贪污罪共犯。职务行为程序违法性不影响"利用职务便利"的认定。 |

**裁判理由摘要**：
- 国家工作人员冒充警察执法与真正警察执法的区别：后者具有公务性
- 走私货物属于在国家机关管理中的私人财产，以公共财产论
- 非身份犯可构成贪污罪共犯（依据《刑法》第三百八十二条第三款）
- 程序违法性不阻断"利用职务便利"要件的认定

### 案例2：国家工作人员提供发票要求下级单位负责人报销个人费用的行为定性 [^2]

| 项目 | 内容 |
|------|------|
| **案号** | [编号046] |
| **法院** | 一审法院 |
| **裁判要旨** | 国家工作人员提供发票要求下级单位负责人报销个人费用，既有贪污中饱私囊的本质，也有受贿权钱交易的实质，具体认定贪污罪还是受贿罪不能一概而论。应当考量国家工作人员对报销款项来源的具体认知、下级单位负责人对行为性质的认识以及利益损失等因素，遵循主客观相一致的原则，结合具体案件情况进行判断。 |

**裁判理由摘要**：
- 合谋贪污：国家工作人员与下级单位负责人具体商量、合谋用公共资金报销发票 → 贪污
- 受贿合意：下级单位负责人出于感谢或请托继续关照而报销 → 受贿
- 判断要点：国家工作人员对报销款项来源的认知、下级单位负责人的主观认识、利益损害等因素

[^2]: 来源：韦宗昆、梁月苹撰稿，刘琳琳审编，载《职务犯罪审判指导2025》第4辑第20-39页

### 案例3：国有融资平台公司融资领域受贿犯罪的认定 [^3]

| 项目 | 内容 |
|------|------|
| **案号** | [编号047] |
| **法院** | 一审法院 |
| **裁判要旨** | 国家工作人员利用职务上的便利或职权地位形成的便利条件，在明知国有融资平台公司无资金使用需求、不需要融资，更不需要融资中介服务的情况下，要求国有融资平台公司与融资租赁公司开展融资业务，收取"融资中介服务费""融资利息费"的，构成受贿罪。 |

**裁判理由摘要**：
- 以"融资中介服务费"为名收受财物的行为认定：
  1. 融资业务的开展系基于国家工作人员的职权影响
  2. 国有融资平台公司无实际融资需求
  3. 融资交易条件不符合市场规律
  4. 无实际市场经营投入，不承担风险
- 以"融资利息费"为名收受财物的行为认定

[^3]: 来源：凌霄、王天奇、陈红媛撰稿，段凰审编，载《职务犯罪审判指导2025》第4辑第40-73页

### 案例4：以委托投资理财为名进行利益输送行为及数额的认定 [^4]

| 项目 | 内容 |
|------|------|
| **案号** | [编号048] |
| **法院** | — |
| **裁判要旨** | 国家工作人员利用职务上的便利为请托人谋取利益，委托请托人投资理财获取高额收益，虽实际出资却不承担投资风险，不属于正常投资理财的，可认定为受贿。认定受贿数额时需遵循主客观相一致原则，准确判断是否扣除国家工作人员的出资应得收益。 |

**裁判理由摘要**：
- 正常委托投资理财与以委托投资理财为名受贿的区别：
  1. 判断投资人与资产管理人是否具备平等的主体地位
  2. 判断请托人是否有真实的融资、用资需求以及是否实际进行投资理财
  3. 判断国家工作人员是否实际承担投资风险
  4. 根据主客观一致原则准确判断国家工作人员的认知情况
- 受贿数额认定：双方假借投资理财名义进行利益输送 → 全额认定为受贿数额

[^4]: 来源：段凰、于书生撰稿，于同志审编，载《职务犯罪审判指导2025》第4辑第74-111页

### 案例5："代持原始股"及"借贷收息"受贿的数额认定 [^5]

| 项目 | 内容 |
|------|------|
| **案号** | [编号049] |
| **裁判要旨** | "代持原始股"受贿在未出售形态下，可以以案发日股价作为犯罪数额基准；"借贷收息"受贿的数额认定应重点把握：是否存在真实借贷关系、资金使用的合理成本应予扣除、扣除标准与借贷关键要素的相当性。 |

**裁判理由摘要**：
- "代持原始股"型受贿数额认定：
  1. 以案发日最低价作为犯罪数额基准
  2. 不以上市日或解禁日价格作为基准（存在不确定性）
- "借贷收息"型受贿数额认定：
  1. 扣除资金使用成本
  2. 参考同期借款利率确定扣除标准

### 案例6：投资次级信托产品获利的行为性质及犯罪数额认定 [^6]

| 项目 | 内容 |
|------|------|
| **案号** | [编号050] |
| **裁判要旨** | 认定国家工作人员投资次级信托产品获利的行为性质，应以请托双方有无权钱交易关系为基础，再结合投资产品的稀缺性、风险性及回报率等因素综合判断。如果构成受贿，犯罪金额应以国家工作人员投资本金所获的全部收益计算。 |

**裁判理由摘要**：
- 收受次级信托产品认购份额的性质审查判断标准：
  1. 以存在权钱交易行为为基础
  2. 获取无风险收益是本质目的
  3. 次级信托产品属于刑法规定的财产性利益
- 犯罪数额认定：投资次级信托产品以全部本金投入为获利基础，分配投资收益的行为属于对受贿赃款的事后处置

[^6]: 来源：范凯、陈鹏撰稿，赵卫东审编，载《职务犯罪审判指导2025》第4辑第134-168页

### 案例7：国家工作人员为他人骗补提供帮助的定性 [^7]

| 项目 | 内容 |
|------|------|
| **案号** | [编号051] |
| **裁判要旨** | 国家工作人员利用职务上的便利为他人骗取国家补助提供帮助，具有非法占有公共财产的故意和行为的，应以贪污罪处罚；若该帮助行为与国家工作人员的职务行为无关，构成诈骗罪共犯。仅利用职权为他人骗补提供帮助，不具有非法占有公共财产的故意和行为，造成公共财产重大损失的，构成滥用职权罪。 |

**裁判理由摘要**：
- 为他人骗补提供帮助的定性：
  1. 具有非法占有目的 + 利用职务便利 → 贪污罪
  2. 帮助行为与职务行为无关 → 诈骗罪共犯
  3. 仅利用职权，无非法占有目的，造成重大损失 → 滥用职权罪
  4. 利用职权为他人谋取利益并收受财物 → 数罪并罚

[^7]: 来源：蒋佳芸撰稿，高洪江审编，载《职务犯罪审判指导2025》第4辑第169-203页

### 案例8：金融机构理财管理行为与挪用公款行为之界分 [^8]

| 项目 | 内容 |
|------|------|
| **案号** | [编号052] |
| **裁判要旨** | 对于个人假借单位名义，以集体讨论、研究为幌子，违规使用单位资金，谋取个人利益的行为，本质上属于公款私用，可以挪用公款罪论处。 |

**裁判理由摘要**：
- 挪用公款罪的本质特征是公款私用
- 金融理财管理行为与挪用公款犯罪的区别：
  1. 行为发起的背景和原因
  2. 决策程序是否真实有效
  3. 获益主体是谁
- 以集体研究为幌子，个人决定使用单位资金谋取个人利益 → 挪用公款罪

[^8]: 来源：凌霄、王天奇、段凰撰稿，方文军审编，载《职务犯罪审判指导2025》第4辑第204-242页

### 案例10：伪造虚假立功证据包庇他人的行为定性 [^10]

| 项目 | 内容 |
|------|------|
| **案号** | [编号054] |
| **裁判要旨** | 司法工作人员利用职权伪造虚假立功证据材料包庇他人从轻处罚的，该行为不同于包庇罪的包庇行为，应以徇私枉法罪定罪处罚。徇私枉法的枉法目的未能实现不影响犯罪既遂的认定。 |

**裁判理由摘要**：
- 徇私枉法罪的犯罪主体是利用职权实施徇私、徇情枉法行为的司法工作人员

  1. 徇私枉法罪与包庇罪：是否利用职务、职权
  2. 徇私枉法罪与帮助毁灭、伪造证据罪：是否利用职权实施
- 枉法目的或结果未能实现不影响犯罪既遂的认定

### 案例11：被勒索情况下索贿款的处理 [^11]

| 项目 | 内容 |
|------|------|
| **案号** | [编号055] |
| **裁判要旨** | 国家工作人员利用职权便利，在无借款需求的情况下向受其权力制约的相对方提出借款要求，且在相对方多次催要、其有能力偿还的情况下拒不还款，应当认定为索贿。对于相对方系被勒索而交付财物的，相关财物应当归还被害人。 |

**裁判理由摘要**：
- 索贿的认定标准：
  1. 利用职权便利，无合理借款事由
  2. 相对方被权力制约
  3. 有能力偿还却拒不还款
- 被勒索交付财物者的地位：属于被害人，不是行贿者
- 被勒索财物应当返还被害人

### 案例12：基于行贿等严重不法目的被骗后的财物追缴问题 [^12]

| 项目 | 内容 |
|------|------|
| **案号** | [编号056] |
| **裁判要旨** | 在诈骗犯罪中，被告人骗取的财物被追缴后，一般应返还被害人。但行为人基于行贿等严重不法目的导致被他人诈骗财物的，被骗财物被追缴后，应当上缴国库，不予以发还被害人。 |

**裁判理由摘要**：
- 法律对不法目的行为应进行否定性评价："法不保护不法"
- 刑法与民法应保持法秩序统一
- 认定诈骗罪与没收被骗财物之间并不矛盾：
  - 诈骗罪是对诈骗不法行为本身的法律处置
  - 没收被骗财物是对"行贿目的"这一源头不法行为的法律处置

## 案例01：查缉走私过程中非法侵吞赃物的行为定性

**案号/法院**：广东省高级人民法院

**问题意识**：查缉走私过程中非法侵吞赃物的行为应当如何定性？

**裁判要旨**：

国家工作人员在履行职务过程中擅自联合非身份人员，滥用执法职权实现对赃物的即时控制，侵吞该财物的，应以**贪污罪**论处。

### 核心规则

1. **非身份人员可构成贪污罪共犯**：非身份人员明知国家工作人员利用职权侵吞公共财物，仍提供帮助参与财物转移、隐匿或变卖的，构成贪污罪共犯

2. **职务行为程序违法性不影响"利用职务便利"的认定**：行为人是否实际利用了其职务所赋予的权力、地位或形成的便利条件来实现非法占有目的，而非职务行为本身的程序合法性

3. **处于国家机关职权管控下的违法财物应视为公共财产**：根据《刑法》第九十一条（1997-10-01 施行 / 2024-12-27 最新修正）第二款的规定，"在国家机关、国有公司、企业、集体企业和人民团体管理、使用或者运输中的私人财产，以公共财产论"

### 本案分析

| 要件 | 认定 |
|------|------|
| 主体 | 苗某系缉私民警，属于国家工作人员 |
| 职务便利 | 利用侦查权、执法权以及对涉案走私货物的临时控制、处置权 |
| 客观行为 | 伙同吴某斌等人将走私货物予以侵吞、销售分赃 |
| 侵犯对象 | 走私货物被查获并置于其职权管控之下时转化为公共财物 |

**原文引用**：
> "苗某作为国家工作人员，在履行缉私职责过程中，利用职务便利，伙同吴某斌、王某钦、王某欣共同侵吞本应上交国库的公共财物(走私货物),其行为符合贪污罪的构成要件。" ①来源：L243

## 案例02：国家工作人员提供发票要求下级单位负责人报销个人费用的行为定性

**案号/法院**：广西壮族自治区高级人民法院

**问题意识**：国家工作人员提供发票要求下级单位负责人报销个人费用的行为如何定性？

**裁判要旨**：

国家工作人员提供发票要求下级单位负责人报销个人费用，既有贪污中饱私囊的本质，也有受贿权钱交易的实质，具体认定贪污罪还是受贿罪不能一概而论。

### 区分标准

| 情形 | 定性 |
|------|------|
| 国家工作人员明确要求下属单位负责人从公共资金中报销个人款项 | 贪污 |
| 国家工作人员不问报销款项来源，以下级单位负责人的关照作为报销条件 | 受贿 |
| 无法区分时 | 从一重罪处断 |

### 本案结论

唐某某的行为构成**受贿罪**，理由：
1. 唐某某选择曾关照过的下级单位负责人作为报销对象
2. 下级单位负责人出于感谢或请托继续关照而帮唐某某报销发票
3. 唐某某的行为侵犯了国家工作人员职务上的廉洁性

**原文引用**：
> "国家工作人员提供发票要求下级单位负责人报销个人费用的行为，既有贪污中饱私囊的本质，也有受贿权钱交易的实质，定一罪似不符合全面评价的要求，定两罪则违反禁止重复评价的原则。" ①来源：L287

## 案例03：国有融资平台公司融资领域受贿犯罪的认定

**案号/法院**：一审法院（受贿7609.6813万元）

**问题意识**：
1. 国家工作人员以实际控制的公司促成国有融资平台公司与融资租赁公司开展融资租赁业务，向国有融资平台公司收取"融资中介服务费",其行为系违法违纪还是构成犯罪？
2. 国家工作人员以实际控制的公司向国有融资平台公司提供资金，收取"手续费及租金",其行为如何定性？

**裁判要旨**：

国家工作人员利用职务上的便利或职权地位形成的便利条件，通过其他国家工作人员职务上的行为，在明知国有融资平台公司无资金使用需求、不需要融资，更不需要融资中介服务的情况下，以"融资中介服务费""融资利息费"的名义收受财物，该行为构成**受贿罪**。

### 两种行为模式

| 模式 | 方式 | 实质 |
|------|------|------|
| 中介方 | 要求国有融资平台公司与祁某乙实际控制的公司开展融资业务 | 以"中介费"名义收受财物 |
| 资金方 | 要求国有融资平台公司与祁某乙实际控制的公司开展融资租赁业务 | 以"手续费及租金"名义收受财物 |

### 核心要点

1. **"不需要融资"的认定**：明知国有融资平台公司无资金使用需求、不需要融资
2. **"不需要融资中介服务"的认定**：有直接融资渠道，不需要第三方中介联系资金
3. **犯罪数额**：祁某甲以这两种方式收受财物共计7609.6813万元

**原文引用**：
> "国家工作人员利用职务上的便利或职权地位形成的便利条件，通过其他国家工作人员职务上的行为，在明知国有融资平台公司无资金使用需求、不需要融资，更不需要融资中介服务的情况下，以'融资中介服务费''融资利息费'的名义收受财物，该行为构成受贿罪。" ①来源：L117

## 案例04：以委托投资理财为名进行利益输送行为及数额的认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：国家工作人员委托请托人投资理财获取高额收益，是否构成受贿？数额如何认定？

**裁判要旨**：

国家工作人员利用职务上的便利为请托人谋取利益，委托请托人投资理财获取高额收益，虽实际出资却不承担投资风险，不属于正常投资理财的，可认定为**受贿**。

### 数额认定规则

| 情形 | 受贿数额 |
|------|----------|
| 请托人未将出资款实际用于投资理财，国家工作人员明知 | 出资获取的"收益"全额认定为受贿数额 |
| 国家工作人员有合理理由认为其出资能够产生收益 | 出资应得的合理收益予以扣除 |

### 核心判断标准

遵循主客观相一致原则：
1. 实际出资却不承担投资风险 → 权钱交易
2. 受贿数额需准确判断是否扣除国家工作人员的出资应得收益

**原文引用**：
> "国家工作人员利用职务上的便利为请托人谋取利益，委托请托人投资理财获取高额收益，虽实际出资却不承担投资风险，不属于正常投资理财的，可认定为受贿。" ①来源：L123

## 案例05："代持原始股"及"借贷收息"受贿的数额认定

**案号/法院**：最高人民法院刑二庭

**问题意识**："代持原始股"受贿和"借贷收息"受贿的数额如何认定？

**裁判要旨**：

### "代持原始股"受贿数额认定

"代持原始股"受贿在未出售形态下，可以以**案发日股价**作为犯罪数额基准。

### "借贷收息"受贿数额认定

| 步骤 | 内容 |
|------|------|
| 第一步 | 判断行受贿双方是否存在真实借贷关系 |
| 第二步 | 存在真实借贷关系时，资金使用的合理成本应予扣除 |
| 第三步 | 扣除标准的选择应与借贷关键要素具有相当性 |

### 核心原则

借贷收息型受贿的数额认定应重点把握：
1. 真实借贷关系的判断
2. 合理成本的扣除
3. 扣除标准与借贷关键要素的相当性

**原文引用**：
> "'代持原始股'受贿在未出售形态下，可以以案发日股价作为犯罪数额基准；'借贷收息'受贿的数额认定应重点把握以下几个方面：一是判断行受贿双方是否存在真实借贷关系；二是存在真实借贷关系时，资金使用的合理成本应予扣除；三是扣除标准的选择应与借贷关键要素具有相当性。" ①来源：L127

## 案例06：投资次级信托产品获利的行为性质及犯罪数额认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：国家工作人员投资次级信托产品获利的行为如何定性？犯罪数额如何计算？

**裁判要旨**：

认定国家工作人员投资次级信托产品获利的行为性质，应以**请托双方有无权钱交易关系**为基础，再结合投资产品的稀缺性、风险性及回报率等因素综合判断。

### 犯罪数额计算

如果构成受贿，犯罪金额应以国家工作人员投资本金所获的**全部收益**计算，与本金来源及收益事后分配情况无直接关联。

### 判断因素

| 因素 | 说明 |
|------|------|
| 权钱交易关系 | 是否有请托谋利关系 |
| 投资产品的稀缺性 | 是否有市场溢价 |
| 风险性 | 是否承担实际风险 |
| 回报率 | 是否明显异常 |

**原文引用**：
> "认定国家工作人员投资次级信托产品获利的行为性质，应以请托双方有无权钱交易关系为基础，再结合投资产品的稀缺性、风险性及回报率等因素综合判断。如果构成受贿，犯罪金额应以国家工作人员投资本金所获的全部收益计算。" ①来源：L131

## 案例07：国家工作人员为他人骗补提供帮助的定性

**案号/法院**：最高人民法院刑二庭

**问题意识**：国家工作人员为他人骗取国家补助提供帮助，如何定性？

**裁判要旨**：

| 情形 | 定性 |
|------|------|
| 具有非法占有公共财产的故意和行为 | 贪污罪 |
| 帮助行为与国家工作人员的职务行为无关 | 诈骗罪共犯 |
| 不具有非法占有公共财产的故意和行为，仅利用职权为他人骗取国家补助提供帮助 | 滥用职权罪 |
| 利用职权为他人谋利而收受财物 | 受贿罪（数罪并罚） |

### 核心规则

1. **贪污罪**：国家工作人员利用职务上的便利为他人骗取国家补助提供帮助，具有非法占有公共财产的故意和行为的，应以贪污罪处罚

2. **诈骗罪共犯**：若该帮助行为与国家工作人员的职务行为无关，构成诈骗罪共犯

3. **滥用职权罪**：国家工作人员不具有非法占有公共财产的故意和行为，仅利用职权为他人骗取国家补助提供帮助，符合滥用职权立案标准的，构成滥用职权罪

4. **数罪并罚**：同时基于职权为他人谋利而收受财物，构成受贿罪的，应当数罪并罚

**原文引用**：
> "国家工作人员利用职务上的便利为他人骗取国家补助提供帮助，具有非法占有公共财产的故意和行为的，应以贪污罪处罚；若该帮助行为与国家工作人员的职务行为无关，构成诈骗罪共犯。" ①来源：L135

## 案例08：金融机构理财管理行为与挪用公款行为之界分

**案号/法院**：最高人民法院刑二庭

**问题意识**：金融机构内部人员利用职务便利以理财、融资管理等为名非法使用单位资金，如何定性？

**裁判要旨**：

金融领域的职务犯罪隐蔽性较高，犯罪过程中职权因素、市场变化、专业因素相互交织。对于该类行为的性质认定，要在纷繁复杂的金融行为中准确把握**挪用公款罪公款私用的本质特征**。

### 实质判断标准

紧扣挪用公款罪的构成要件，从以下方面综合判断：

| 考量因素 | 说明 |
|----------|------|
| 行为发起的背景 | 是否基于单位业务需要 |
| 发起原因 | 是否为个人利益 |
| 决策程序 | 是否经过单位正常审批 |
| 获益主体 | 利益归属是个人还是单位 |

### 核心结论

对于个人假借单位名义，以集体讨论、研究为幌子，违规使用单位资金，谋取个人利益的行为，本质上属于**公款私用**，可以挪用公款罪论处。

**原文引用**：
> "金融领域的职务犯罪隐蔽性较高，犯罪过程中职权因素、市场变化、专业因素相互交织...对于个人假借单位名义，以集体讨论、研究为幌子，违规使用单位资金，谋取个人利益的行为，本质上属于公款私用，可以挪用公款罪论处。" ①来源：L141

## 案例09：受贿线索与准自首的审查认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：调查机关仅掌握少部分受贿线索，被告人到案后主动供述同种类其他受贿犯罪事实，能否认定为准自首？

**裁判要旨**：

在被动到案的情况下，被告人主动供述同种类其他受贿犯罪事实能否认定为准自首，需要结合以下因素综合判断：

| 因素 | 说明 |
|------|------|
| 受贿线索是否相对准确且有初步证据 | 线索的可靠性 |
| 最终是否被查实 | 事实认定 |
| 查实数额是否超过追诉时效 | 量刑考量 |
| 查实的线索部分是否超过追诉时效 | 时效判断 |

### 认定规则

| 情形 | 认定 |
|------|------|
| 受贿线索具有未被查实、查实数额不满追诉标准或者已过追诉时效等情况 | 被告人对主动交代的犯罪具有**准自首**情节 |
| 受贿线索最终被查实且未超过追诉时效 | 被告人具有**坦白**情节 |

**原文引用**：
> "在被动到案的情况下，这种主动交代能否认定为准自首，需要结合调查机关掌握的受贿线索是否相对准确且有初步证据、最终是否被查实、查实数额以及查实的线索部分是否超过追诉时效等因素综合判断。" ①来源：L145

## 案例10：伪造虚假立功证据包庇他人的行为定性

**案号/法院**：最高人民法院刑二庭

**问题意识**：司法工作人员利用职权伪造虚假立功证据包庇他人，如何定性？

**裁判要旨**：

司法工作人员利用职权伪造虚假立功证据材料包庇他人从轻处罚的，该行为不同于包庇罪的包庇行为，应以**徇私枉法罪**定罪处罚。

### 核心要点

1. **徇私枉法罪与包庇罪的区别**：利用职权伪造虚假立功证据材料包庇他人，不同于一般的包庇行为

2. **枉法目的未能实现不影响犯罪既遂的认定**：徇私枉法罪中"不受追诉"既包括对需要追究刑事责任的人不立案、不侦查、不起诉或不审判，也包括使罪重的人受到较轻处罚或使罪轻的人受到较重的处罚

3. **既遂认定**：枉法目的未能实现不影响犯罪既遂的认定

**原文引用**：
> "司法工作人员利用职权伪造虚假立功证据材料包庇他人从轻处罚的，该行为不同于包庇罪的包庇行为，应以徇私枉法罪定罪处罚。徇私枉法的枉法目的未能实现不影响犯罪既遂的认定。" ①来源：L149
