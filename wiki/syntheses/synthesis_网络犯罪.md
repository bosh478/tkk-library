## 一、人民检察院办理网络犯罪案件规定

### 1.1 网络犯罪定义

网络犯罪包括：
- 针对信息网络实施的犯罪
- 利用信息网络实施的犯罪
- 其他上下游关联犯罪

### 1.2 办案原则

- **全链条惩治**：注重审查和发现上下游关联犯罪线索
- **捕诉监防一体**：加强以案释法，促进预防和治理
- **检察一体化**：加强跨区域协作办案
- **综合运用证据**：电子数据与其他证据相互印证

### 1.3 引导取证重点

检察官介入重大网络犯罪案件侦查时，就以下事项提出引导取证意见：
1. 案件的侦查方向及可能适用的罪名
2. 证据的收集、提取、保全、固定、检验、分析
3. 关联犯罪线索
4. 追赃挽损工作

### 1.4 电子数据审查

#### 电子数据范围

- 网页、社交平台、论坛等网络平台发布的信息
- 手机短信、电子邮件、即时通信、通讯群组等网络通讯信息
- 用户注册信息、身份认证信息、数字签名、生物识别信息
- 电子交易记录、通信记录、浏览记录、操作记录
- 恶意程序、工具软件、网站源代码、运行脚本
- 系统日志、应用程序日志、安全日志、数据库日志
- 文档、图片、音频、视频、数字证书等电子文件

#### 电子数据取证方式

| 方式 | 适用情形 |
|------|----------|
| 扣押、封存原始存储介质 | 原始介质可获取时 |
| 现场提取电子数据 | 实时提取动态数据 |
| 在线提取电子数据 | 远程服务器数据 |
| 冻结电子数据 | 防止被远程破坏 |
| 调取电子数据 | 已存储于第三方 |

#### 电子数据审查要点

| 审查维度 | 重点内容 |
|----------|----------|
| 客观性 | 完整性校验值、数字签名、是否篡改 |
| 合法性 | 法律手续、取证人员、见证人、同步录音录像 |
| 关联性 | 与案件事实、当事人之间的关联 |

### 1.5 跨区域协作

- 上级人民检察院统一指挥和统筹协调
- 统一调用辖区检察人员参与办案
- 相互申请查阅卷宗材料
- 远程视频询问异地证人、被害人

### 1.6 跨国（边）境司法协作

- 依照《国际刑事司法协助法》及相关条约
- 地方检察院需向外国请求刑事司法协助，报最高人民检察院批准
- 境外证据移交需全程录音录像

## 二、新时代检察机关网络法治工作意见

### 2.1 总体要求

- 推进网络空间法治化
- 保障数字经济健康发展
- 维护国家网络安全
- 保护公民合法权益

### 2.2 重点任务

- 依法惩治网络犯罪
- 加强网络犯罪预防
- 完善网络犯罪案件办理机制
- 强化网络空间治理
- 参与网络法治体系建设

### 2.3 网络犯罪惩治重点

- 电信网络诈骗
- 侵犯公民个人信息
- 非法利用信息网络
- 帮助信息网络犯罪活动
- 网络赌博
- 网络传播淫秽物品
- 网络黑客攻击
- 网络洗钱

### 2.4 检察职能发挥

- 强化立案监督
- 强化侦查活动监督
- 强化审判活动监督
- 强化执行活动监督
- 参与网络空间综合治理

## 三、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 网络犯罪定义 | 针对信息网络、利用信息网络、上下游关联犯罪 |
| 电子数据取证 | 扣押封存、现场提取、在线提取、冻结、调取 |
| 证据审查三性 | 客观性、合法性、关联性 |
| 跨区域协作 | 上级统筹、调用、远程询问 |
| 跨境协作 | 依照国际刑事司法协助法，报最高检批准 |
