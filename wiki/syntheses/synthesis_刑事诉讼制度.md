## 一、人民检察院刑事诉讼规则（2019）

### 1.1 立案监督

人民检察院依法对公安机关的立案活动进行监督：
- 应当重点审查公安机关是否立案侦查的案件
- 发现应当立案而不立案的，要求公安机关说明理由
- 认为理由不能成立的，依法通知公安机关立案

### 1.2 侦查监督

人民检察院依法对公安机关的侦查活动进行监督：
- 讯问犯罪嫌疑人
- 询问证人、被害人
- 勘验、检查、搜查
- 查封、扣押物证、书证
- 鉴定
- 技术侦查措施

### 1.3 审查逮捕

| 情形 | 要求 |
|------|------|
| 一般案件 | 事实清楚、证据充分 |
| 重大案件 | 应当讯问犯罪嫌疑人 |
| 有疑问 | 必须讯问 |

**社会危险性审查**：
- 可能实施新的犯罪
- 危害国家安全、公共安全或社会秩序
- 可能毁灭、伪造证据，干扰证人作证或串供
- 可能对被害人、举报人、控告人实施打击报复
- 企图自杀或逃跑

### 1.4 审查起诉

人民检察院审查起诉应当查明：
- 犯罪事实是否清楚
- 证据是否确实、充分
- 犯罪性质和罪名的认定是否正确
- 有无遗漏罪行和其他应当追究刑事责任的人
- 是否属于不应追究刑事责任的情形
- 侦查活动是否合法

### 1.5 审判监督

- 对人民法院刑事判决、裁定进行审查
- 对审判活动是否合法进行监督
- 对生效判决、裁定的执行是否合法进行监督

## 二、办理延长侦查羁押期限案件规定

### 2.1 羁押必要性审查

犯罪嫌疑人、被告人被逮捕后，人民检察院应当对羁押必要性进行审查：

**审查内容**：
- 证据是否发生变化
- 案件事实是否清楚
- 社会危险性是否仍然存在
- 是否有继续羁押的必要

**审查方式**：
- 书面审查
- 听取意见
- 调查核实

### 2.2 延长羁押期限

| 情形 | 批准机关 | 期限 |
|------|----------|------|
| 案情复杂 | 上一级人民检察院 | 1个月 |
| 重特大案件 | 省级人民检察院 | 2个月 |
| 可能判处十年以上 | 省级人民检察院 | 延长期限 |

### 2.3 羁押期限计算

- 羁押期限从逮捕之日起计算
- 节假日计入羁押期限
- 指定居所监视居住的期限折抵

## 三、犯罪嫌疑人、被告人身份审查工作机制

### 3.1 审查目的

确保准确认定犯罪嫌疑人、被告人身份，防止：
- 冒名顶替
- 虚假身份
- 错误追诉

### 3.2 审查内容

- 身份信息核实
- 前科劣迹调查
- 真实身份与涉案身份比对
- 特殊人群（未成年人、精神病人等）特别审查

### 3.3 审查方式

- 核查身份证件
- 比对指纹、DNA等生物信息
- 询问家属、亲友
- 调查走访

## 四、社区矫正法实施办法

### 4.1 社区矫正对象

| 对象类型 | 说明 |
|----------|------|
| 管制 | 刑法管制的矫正 |
| 宣告缓刑 | 缓刑考验期的矫正 |
| 假释 | 假释考验期的矫正 |
| 暂予监外执行 | 监外执行期间的矫正 |

### 4.2 矫正内容

- 监督管理
- 教育帮扶
- 社会力量参与
- 解除矫正

### 4.3 人民检察院监督

人民检察院对社区矫正活动进行法律监督：
- 交付执行是否合法
- 监督管理活动是否合法
- 解除矫正是否合法
- 发现违法提出纠正意见

## 五、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 立案监督 | 重点审查应立未立、违法立案 |
| 侦查监督 | 讯问、勘验、搜查、扣押等合法合规 |
| 逮捕条件 | 事实清楚+证据充分+社会危险性 |
| 羁押必要性 | 逮捕后持续审查，及时变更 |
| 社区矫正 | 管制、缓刑、假释、暂予监外执行 |
| 身份审查 | 防止冒名顶替、虚假身份 |
