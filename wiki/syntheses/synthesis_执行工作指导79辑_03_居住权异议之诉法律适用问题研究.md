## 核心观点

民法典首次规定了居住权这种用益物权模式。执行过程中，当执行行为遭遇居住权时，需要运用与租赁权、抵押权、物权期待权、以物抵债等既有裁判规则相类似的法理，对各类居住权异议之诉进行审查。

## 一、居住权及其分类

### （一）合同居住权、遗嘱居住权与判决居住权

根据民法典第366条、第371条，居住权可通过合同和遗嘱两种方式设立。此外，法院通过判决形式也可以设立居住权（形成之诉中对案涉标的物分割确认物权）。据此，居住权可分为：
- **合同居住权**：依当事人合同设立
- **遗嘱居住权**：依遗嘱方式设立
- **判决居住权**：依法院判决设立

### （二）登记居住权与未登记居住权（居住权期待权）

民法典第368条规定居住权自登记时设立。但依据《执行异议和复议规定》第28条，在具备四个条件时，未登记居住权可成立物权期待权，具有排除执行的效力。

### （三）有偿居住权与无偿居住权

民法典第368条规定居住权无偿设立，但当事人另有约定的除外。

## 二、居住权异议之诉审理的理论基础

民事诉讼法第234条规定了案外人提出执行异议的程序性审查，《民事诉讼法解释》第310条规定了案外人提起执行异议之诉时的实体审理规则。

居住权排除执行的理论基础在于：居住权是一种物权，具有排他性；对其背后居住权人生存权的考量是排除执行正当性基础的更高价值所在。

**重要提示**：居住权排除执行是指在拍卖时要负担此居住权进行带居拍卖，而非阻止法院对房屋处分。

## 三、居住权异议之诉的裁判规则

### （一）合同居住权异议之诉

合同居住权排除执行需满足九个要件：

| 要件 | 内容 |
|------|------|
| 内容要件 | 根据民法典第367条对合同内容进行形式审查 |
| 主体要件 | 居住权主体只能是被限制为具有生活居住需求的自然人，不包括法人和非法人组织 |
| 目的要件 | 核心目的是保障特定群体的居住权利，而非商业目的 |
| 客体要件 | 居住权客体只能为住宅，不包括商业网点 |
| 期限要件 | 居住权人死亡、超过约定期限、居住权人放弃等情形下消灭 |
| 占有要件 | 登记不是合同居住权设立的要件，但未登记居住权期待权需审查占有 |
| 登记要件 | 登记后具有物权效力，实现排除执行的终极目标 |
| 价款要件 | 有偿居住权和无偿居住权的裁判规则不同 |
| 过错要件 | 居住权人未进行登记有无过错影响排除执行效力 |

### （二）遗嘱居住权异议之诉

1. **民法典第230条适用**：以遗嘱方式设立的居住权，系非法律行为方式引起的物权变动，权利设立时间适用继承开始时起算，不以登记时间为准。
2. **民法典第1159条适用**：分割遗产应清偿被继承人依法应当缴纳的税款和债务，债务清偿优先于遗产继承。

### （三）判决居住权异议之诉

通过裁判方式设立的居住权（尤其离婚诉讼中对配偶一方的居住权安排），属于民法典第229条规定的非法律行为方式引起的物权变动。即便未登记，居住权人持生效法律文书也可排除执行。

### （四）登记居住权异议之诉

已登记居住权是完全标准的居住权，可排除执行。但需注意登记时间必须在法院查封之前（"先居后封"），"先封后居"不能排除执行。

### （五）未登记居住权（居住权期待权）排除执行

参照《异议复议规定》第28条物权期待权的四个判断标准：

| 标准 | 内容 |
|------|------|
| 时间标准 | 居住权合同在法院查封之前签订 |
| 占有标准 | 在法院查封之前已合法占有房屋（核心标准） |
| 价款标准 | 有偿居住权已支付全部或部分价款；无偿居住权无此问题 |
| 过错标准 | 非因居住权人自身原因未办理登记，但考量过错时应适当弱化 |

### （六）无偿居住权异议之诉

无偿居住权可比照赠与合同规则处理。已登记的无偿居住权可排除执行，但要注意：
1. 房屋所有权人出现生活困难、不当使用房屋等情形时可撤销
2. 道德义务性质的赠与（如对鳏寡老人的居住权安置）不得撤销

### （七）有偿居住权异议之诉（"以居抵债"）

"以居抵债"指被执行人为抵债在房屋上为案外人设立有偿居住权。比照"以物抵债"裁判规则判断：
1. 已登记的居住权可排除执行
2. 未登记的：
   - 普通债权不能排除执行
   - 特殊债权（如照料多年的保姆服务费）可基于"生存权优于债权"排除执行
3. 居住权人尚有其他住宅可居住的，不能排除执行

## 四、其他"居住权"问题

### （一）"租赁权居住权化"

当事人通过合同约定设立有偿居住权（实为租赁费），使租赁权"上升"为物权，规避20年租赁期限限制。此为虚假行为，根据民法典第146条，居住权合同（虚假行为）无效，隐藏的租赁法律关系按租赁规定处理。

### （二）"继受居住权"

民法典第369条规定居住权不得转让、继承。案外人以转让、继承方式获取的"继受居住权"不能排除执行。

### （三）居住权与其他权利竞合

| 竞合类型 | 裁判规则 |
|----------|----------|
| 居住权与抵押权 | "先居后抵"——居住权排除执行；"先抵后居"——不能排除执行 |
| 居住权与查封权 | "先居后封"——带居拍卖；"先封后居"——不能排除执行 |
| 居住权与租赁权 | 物权优于债权；但"先租后居"时，居住权不能排除对租赁权的执行 |
| 多重权利竞合 | 按时间先后顺序确定 |
| 居住权之间竞合 | 依据民法典第414条处理（登记时间先后、已登记优先于未登记） |
