## 一、涉案企业合规第三方监督评估机制

### 1.1 机制概述

建立并不断完善涉案企业合规第三方监督评估机制，是一项集刑事合规、行政合规、企业合规于一体的综合性制度。该机制通过引入独立的第三方监督评估机构，对涉案企业的合规整改情况进行监督和评估。

### 1.2 第三方监督评估组织

**组成结构：**
- 由专业人员组成
- 具有独立性和专业性
- 负责对涉案企业的合规整改情况进行监督和评估

**评估内容：**
- 企业合规计划的制定情况
- 合规整改措施的执行情况
- 合规管理体系的建立和完善情况
- 防范类似违法行为再次发生的制度建设情况

### 1.3 适用范围

适用于各类涉案企业，特别是涉及：
- 经济犯罪案件
- 破坏市场经济秩序犯罪案件
- 危害公共安全犯罪案件
- 其他可以适用企业合规的案件

### 1.4 合规整改要求

**基本要求：**
- 制定切实可行的合规整改计划
- 建立完善的内控管理制度
- 加强合规培训和文化建设
- 定期报告整改进展情况

## 二、财务造假犯罪案件有关问题解答

### 2.1 总体问题

#### 信息披露义务认定

**证券发行阶段的信息披露义务**依据：
- 《公司法》《证券法》
- 《首次公开发行股票并上市管理办法》
- 《上市公司证券发行管理办法》
- 《公司债券发行与交易管理办法》

**持续经营阶段的信息披露义务**依据：
- 上市公司、非上市公众公司对经营情况、财务情况、重大事件的定期披露和临时披露义务

#### 罪数问题

1. **欺诈发行证券罪与违规披露、不披露重要信息罪**：利用相同虚假财务数据，先后实施两个违法行为的，应当同时以两罪追究刑事责任
2. **欺诈发行证券罪与行贿犯罪**：为欺诈发行向负有金融监管职责的单位或人员行贿，构成犯罪的，应当**数罪并罚**

#### 直接经济损失认定

- 参照虚假陈述侵权民事赔偿案件的生效判决认定
- 难以准确计算的，委托专门机构出具测算报告

### 2.2 欺诈发行证券罪

#### 证券类型

公司、企业依照法定程序发行、约定在一定期限还本付息的有价证券：
- 交易所市场发行的债券
- 银行间市场发行的债券

#### 重大事项违规比例计算

- **分子**：隐瞒或编造的重大诉讼、仲裁、担保、关联交易等数额（采用"先并后合"方法）
- **分母**：最近一期披露的净资产

### 2.3 违规披露、不披露重要信息罪

#### 临时披露与定期披露

根据《证券法》规定，对重大诉讼、仲裁、担保、关联交易等重大事项，负有**临时报告、定期报告双重信息披露义务**。

临时披露违规比例与定期披露违规比例应当**分别计算**，其中一个比例达到标准即应立案追诉。

#### 追诉时效起算

1. 伪造财务数据后又实施虚假平账行为的，从虚假平账行为终了之日起计算
2. 违规不披露重要信息，违法行为有继续状态的，从继续状态结束之日起计算

### 2.4 中介组织犯罪

#### 定罪问题

| 行为 | 罪名 |
|------|------|
| 故意提供虚假证明文件，情节严重 | 提供虚假证明文件罪 |
| 参与财务造假构成共犯 | 依照处罚较重的规定定罪处罚 |
| 严重不负责任，出具证明文件重大失实 | 出具证明文件重大失实罪 |

#### 严重不负责任认定

以会计师事务所审计人员为例：
- 未按审计准则履行必需的审计程序
- 一般审计人员能够正常发现的问题而未发现
- 未开展审计工作而直接签字确认审计结论

### 2.5 涉案人员处理

| 人员类型 | 处理方式 |
|----------|----------|
| 控股股东、实际控制人、董监高实施或组织财务造假 | 以欺诈发行证券罪或违规披露、不披露重要信息罪追究 |
| 中层负责人或一般工作人员积极参与起较大作用 | 以欺诈发行证券罪或违规披露、不披露重要信息罪追究 |
| 受单位领导指派参与实施一定犯罪行为，作用不大 | 不宜作为直接责任人员追究 |
| 配合财务造假的单位或个人 | 构成相关犯罪共犯的，从一重处 |

## 三、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 企业合规评估 | 合规计划制定、执行、管理体系建立 |
| 欺诈发行证券 | 欺诈发行+行贿 → 数罪并罚 |
| 违规披露 | 临时披露与定期披露分别计算 |
| 中介犯罪 | 故意→提供虚假证明文件罪；过失→重大失实罪 |
| 人员分层 | 董监高→主犯；一般人员→视作用大小 |
