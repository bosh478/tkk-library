## 一、知识产权协同保护意见（最高法/国家知识产权局 2023年）

### （一）总体要求

**指导思想**：坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平法治思想，全面贯彻党的二十大精神。

**工作格局**：构建知识产权"严保护、大保护、快保护、同保护"工作格局。

### （二）常态化联络机制

**联络机构**：
- 最高人民法院民事审判第三庭、知识产权法庭
- 国家知识产权局知识产权保护司

**会商机制**：
- 建立知识产权保护协调会商机制
- 定期召开会议
- 邀请检察院、公安机关等参加
- 重点研究知识产权保护普遍性、趋势性问题

### （三）信息共享

**主要内容**：
- 推动知识产权行政授权确权和司法审判信息交流
- 健全完善最高人民法院与国家知识产权局现有专线
- 促进行政、司法业务协同和数据共享
- 加强知识产权民事一审案件服判息诉率
- 知识产权行政案件一二审维持率统计信息共享
- 推广专利司法查控平台

### （四）业务协作

**推动协同保护法律政策完善**：
- 推进专利权评价报告在侵权诉讼中的使用
- 统筹推进数据知识产权保护制度
- 健全数据要素权益保护制度

**促进行政标准与司法标准统一**：
- 建立专利、商标授权确权标准、司法和行政执法证据标准反馈沟通机制
- 促进药品专利纠纷早期解决机制行政裁决与司法裁判标准统一
- 推进知识产权行政执法和刑事司法立案标准衔接

**专业技术支撑**：
- 健全完善专家咨询库和技术调查人才库
- 推进知识产权鉴定机构专业化、规范化建设
- 建立知识产权鉴定机构从业情况反馈机制

### （五）跨区域协作共建

**重点推进区域**：环渤海、长三角、珠三角/泛珠三角、成渝、海西、粤港澳大湾区。

**国际合作**：深度参与全球知识产权治理。

## 二、新时代知识产权检察工作意见（最高检 2022年）

### （一）总体要求

**基本原则**：
- 坚持党的领导
- 坚持服务大局
- 坚持激励、保护创新
- 坚持系统观念
- 坚持法治思维
- 坚持强基导向

**主要目标**：
- 知识产权检察体制机制进一步健全
- 知识产权检察机构专门化建设取得积极进展
- 知识产权检察综合履职模式日臻成熟

### （二）刑事检察提质增效

**打击重点**：
- 涉农领域产品侵权假冒
- 生命健康产品侵权假冒
- 环境保护产品侵权假冒
- 地理标志产品侵权假冒
- 文化体育产品侵权假冒
- 互联网领域侵权假冒
- 新业态新领域、关键核心技术侵犯知识产权

**监督职能**：
- 刑事立案监督：防止以刑事手段插手民事纠纷
- 侦查活动监督：介入侦查引导取证、自行补充侦查
- 落实少捕慎诉慎押刑事司法政策
- 推进企业合规

### （三）民事检察精准履职

- 构建知识产权民事诉讼多元化监督格局
- 加大对虚假诉讼法律监督力度
- 注重对"纠偏、创新、引领"价值的典型案件提出抗诉
- 深化民事执行监督

### （四）行政检察走深走实

- 强化商标、专利、植物新品种等授权确权行政案件类案研究
- 加大反不正当竞争、反垄断执法问题研究
- 穿透式监督促进依法行政

### （五）公益诉讼

**重点领域**：
- 国家地理标志产品生态环境和资源保护
- 种业知识产权保护（粮食安全）
- 英烈权益保护（商标权、著作权）
- 文物和文化遗产（传统文化、民间文艺、传统知识）

### （六）商业秘密保护

**打击重点**：
- 盗窃、利诱、欺诈、胁迫、电子侵入等手段侵犯商业秘密
- 为境外机构、组织、人员窃取、刺探、收买、非法提供商业秘密

### （七）体制机制创新

**跨行政区划检察**：
- 探索推进跨行政区划知识产权检察机制
- 依托跨行政区划检察工作改革

**司法协作**：
- 完善行政执法和刑事司法衔接
- 依托"3+N"机制
- 推动知识产权司法保护走深走实

## 三、关联犯罪追诉标准

### （一）侵犯著作权罪（刑法第217条）

| 情节 | 标准 |
|------|------|
| 违法所得数额较大 | 3万元以上 |
| 非法经营数额 | 5万元以上 |
| 其他严重情节 | 复制品数量合计500份以上 |

### （二）销售侵权复制品罪（刑法第218条）

| 情节 | 标准 |
|------|------|
| 违法所得数额巨大 | 10万元以上 |

### （三）侵犯商业秘密罪（刑法第219条）

| 情节 | 标准 |
|------|------|
| 给商业秘密权利人造成重大损失 | 损失数额50万元以上 |
| 情节特别严重 | 损失数额250万元以上 |

### （四）假冒注册商标罪（刑法第213条）

| 情节 | 标准 |
|------|------|
| 情节严重 | 非法经营数额5万元以上或违法所得数额3万元以上 |
| 情节特别严重 | 非法经营数额25万元以上或违法所得数额15万元以上 |

### （五）销售假冒注册商标的商品罪（刑法第214条）

| 情节 | 标准 |
|------|------|
| 销售金额数额较大 | 5万元以上 |
| 销售金额数额巨大 | 25万元以上 |

### （六）非法制造、销售非法制造的注册商标标识罪（刑法第215条）

| 情节 | 标准 |
|------|------|
| 情节严重 | 伪造、擅自制造或者销售伪造、擅自制造的注册商标标识数量在2万件以上或非法经营数额3万元以上 |
| 情节特别严重 | 标识数量在10万件以上或非法经营数额10万元以上 |

### （七）假冒专利罪（刑法第216条）

| 情节 | 标准 |
|------|------|
| 情节严重 | 违法所得数额较大或有其他严重情节 |

## 四、要点汇总表

### （一）知识产权保护体系

| 保护类型 | 主要内容 | 责任部门 |
|----------|----------|----------|
| 刑事检察 | 打击侵权犯罪、立案监督、侦查监督 | 检察机关 |
| 民事检察 | 裁判结果监督、审判违法监督、执行监督 | 检察机关 |
| 行政检察 | 授权确权案件监督、反垄断/不正当竞争监督 | 检察机关 |
| 公益诉讼 | 地理标志、种业、英烈权益、文物文化遗产 | 检察机关 |
| 行政执法与司法衔接 | 案件移送、证据共享、标准统一 | 两法衔接 |

### （二）知识产权案件类型

| 案件类型 | 管辖部门 | 监督方式 |
|----------|----------|----------|
| 专利侵权 | 法院/知识产权局 | 民事诉讼/行政裁决 |
| 商标侵权 | 法院/知识产权局 | 民事诉讼/行政裁决 |
| 著作权侵权 | 法院 | 民事诉讼 |
| 商业秘密侵权 | 法院/公安机关 | 民事诉讼/刑事追诉 |
| 知识产权刑事案件 | 公安机关/检察机关 | 刑事诉讼 |

### （三）知识产权犯罪数额标准

| 罪名 | 数额较大/情节严重 | 数额巨大/情节特别严重 |
|------|---------------------|----------------------|
| 侵犯著作权罪 | 违法所得3万/经营额5万/500份 | - |
| 销售侵权复制品罪 | 违法所得10万 | - |
| 侵犯商业秘密罪 | 损失50万 | 损失250万 |
| 假冒注册商标罪 | 经营额5万/违法所得3万 | 经营额25万/违法所得15万 |
| 销售假冒注册商标商品罪 | 销售金额5万 | 销售金额25万 |
| 非法制造注册商标标识罪 | 2万件/经营额3万 | 10万件/经营额10万 |
| 假冒专利罪 | 违法所得较大 | - |
