# 统编教材民商事审判实务核心要点

## 导论：金融审判的理念与方法

### 五大审判理念

| 理念 | 核心内涵 |
|------|----------|
| **金融服务实体经济** | 保障直接融资、支持科技创新；落实《民法典》拓宽融资渠道、提高融资能力的精神；禁止高利放贷 |
| **金融治理协同** | 统一思想观念、落实中央金融政策、加强重大案件协同、处理金融司法职能定位 |
| **守住风险底线** | 强化系统观念；坚持持牌经营、落实全面监管；坚持实质重于形式、强化交易模式和风险识别 |
| **倾斜保护金融消费者和中小投资者** | 信息不对称需倾斜保护；运用格式条款、欺诈、重大误解等规定；"卖者尽责、买者自负" |
| **服务金融市场发展** | 强化金融债权保护；坚持"过责相当"原则 |

### 金融审判的工作机制

1. 推动建立金融司法与金融监管的常态化协同机制
2. 完善金融纠纷多元化解机制
3. 推动司法机关之间及人民法院刑事、民事、行政各专业审判庭之间的协调工作机制
4. 完善集中管辖等金融纠纷案件集约化审理机制

## 第一编 民法典总则编

### 一、法典化背景下的民事法律适用规则

#### （一）《民法典》总则编与各分编的法律适用关系

- **总则统辖分则原则**：《民法典》总则编集中体现立法指导思想，在整个《民法典》中居于统率地位，对各分编具有统辖效力
- **分编适用原则**：各分编主要围绕具体权利展开，相对于总则编的民事权利一章属于具体规定，应当适用各分编规定
- **合同编通则的债法总则功能**：《民法典》第468条规定，非因合同产生的债权债务关系适用合同编通则的有关规定

#### （二）《民法典》与其他民事法律的适用关系

- **一般法与特别法**：特别法优先于一般法
- **《民法典》与民商事单行法**：其他法律对民事关系有特别规定的，依照其规定
- **《民法典总则编解释》第1条第2款**：其他民事法律的规定属于对民法典相应规定细化的，应当适用该民事法律的规定

#### （三）《民法典》的时间效力

| 情形 | 适用规则 |
|------|----------|
| 法律事实发生在《民法典》施行后 | 适用《民法典》 |
| 法律事实发生在《民法典》施行前 | 适用当时的法律、司法解释 |
| 持续性法律事实跨越《民法典》施行前后 | 一般适用《民法典》 |

**有利溯及标准**（三个"更有利于"）：
1. 更利于保护民事主体合法权益
2. 更有利于维护社会和经济秩序
3. 更有利于弘扬社会主义核心价值观

### 二、民法基本原则的适用

#### （一）基本原则援引规则

- **适用前提**：法律、行政法规对民事关系没有具体规定
- **谦抑态度**：避免向一般条款逃逸，影响法律适用效果
- **强制性**：一旦应当适用基本原则而未适用，构成适用法律错误

#### （二）诚信原则的适用

1. 当法律有具体规定时，应优先适用该具体规定
2. 虽无具体规定，但能够以类推适用等漏洞补充方法予以补充，亦不得适用诚信原则
3. 只有在以类推适用等漏洞补充法仍不能解决时，才能适用诚信原则

#### （三）民事习惯的适用

- **习惯认定**：《民法典总则编解释》第2条第1款：在一定地域、行业范围内长期为一般人从事民事活动时普遍遵守的民间习俗、惯常做法等
- **两个条件**：①长期性、恒定性、内心确信性；②具有具体行为规则属性
- **审查标准**：不得违背公序良俗，不得违背社会主义核心价值观

### 三、自然人制度的重点问题

#### （一）胎儿利益保护

《民法典》第16条采用**个别保护主义立法模式**：
- 涉及遗产继承、接受赠与等胎儿利益保护的，胎儿视为具有民事权利能力
- **胎儿娩出时为死体的，其民事权利能力自始不存在**
- 父母可以法定代理人身份主张相应权利

#### （二）监护制度

| 监护类型 | 要点 |
|----------|------|
| 遗嘱指定监护 | 尊重被监护人真实意愿；指定监护人的遗嘱成立与生效要件 |
| 协议监护 | 不受监护顺序限制；区分协议监护与委托监护 |
| 指定监护 | 综合考量与被监护人生活情感联系密切程度、监护顺序、是否有不利履行监护职责的违法犯罪情形等 |
| 意定监护 | 协议解除规则；监督问题 |

#### （三）宣告失踪与宣告死亡

- **失踪人的财产代管人**：诉讼地位、财产代管原则
- **利害关系人范围**：宣告失踪与宣告死亡不同

### 四、法人与非法人组织

#### （一）不同阶段法人的责任承担

| 阶段 | 责任承担 |
|------|----------|
| 设立中的法人 | 设立中的法人产生的权利义务由成立后的法人承继 |
| 清算中的法人 | 以其财产为限承担民事责任 |

#### （二）法定代表人

- **性质**：法定代表人是法人的机关
- **代表权限制**：法定代表人以法人名义从事的民事活动的后果由法人承担
- **越权担保**：根据《民法典》第61条、第504条确定效力与责任

#### （三）非法人组织

- **民事责任**：非法人组织的民事责任由设立人或者出资人承担无限连带责任
- **破产清算**：非法人组织不可以进行破产清算

### 五、民事权利制度

#### （一）新类型民事权益的保护

| 类型 | 要点 |
|------|------|
| **数据权益** | 网络平台经营者持有数据的经营性利益可依法整体保护；数据处理者采集、利用原始数据生产数据产品的认定 |
| **网络虚拟财产** | 具有人为稀缺性、单边价值性、有限可支配性；法律属性认定 |
| **NFT数字藏品** | 法律属性认定；不属于著作权法意义上的发行 |
| **虚拟货币** | 金融管制与刑法保护；以虚拟货币为支付对价纠纷、委托投资纠纷的处理 |

#### （二）禁止权利滥用规则

**构成要件**：
1. 需有正当权利的存在
2. 需有滥用行为
3. 滥用行为有损害他人合法权益的危险

### 六、民事法律行为与代理

#### （一）强制性规定的识别

| 规范类型 | 识别标准 |
|----------|----------|
| "应当"、"必须" | 强制性规定的标识 |
| "不得"、"禁止" | 强制性规定的标识 |

**不导致民事法律行为无效的情形**：《民法典》第153条第1款但书

#### （二）重大误解、欺诈、胁迫

| 情形 | 要点 |
|------|------|
| **重大误解** | 行为人产生错误认识 + 错误认识具有重大性 |
| **欺诈** | 欺诈故意 + 欺诈行为 + 因果关系；区分相对人欺诈和第三人欺诈 |
| **胁迫** | 胁迫行为 + 胁迫故意 + 胁迫具有非法性 + 因果关系 |

#### （三）表见代理

- **"有理由相信"的认定**：《民法典》第172条
- **举证责任分配**
- **涉刑民交叉问题的处理**

### 七、民事责任制度

#### （一）免责事由

| 免责事由 | 要点 |
|----------|------|
| 不可抗力 | 不能预见、不能避免且不能克服的客观情况 |
| 正当防卫 | 损害不负刑事责任；防卫过当时的责任承担 |
| 紧急避险 | 紧急避险与正当防卫的区别；必要限度的把握 |
| 见义勇为 | 与无因管理的区别；受益人适当补偿范围 |
| 紧急救助 | 紧急救助规则的适用 |

#### （二）请求权竞合

- **规则演变**：从"选择主义"到"请求权自由竞合"
- **违约责任与侵权责任的主要区别**
- **精神损害赔偿**：违约精神损害赔偿需要体系化适用《民法典》第1183条

### 八、诉讼时效制度

| 问题 | 要点 |
|------|------|
| 中止 | 条件、事由、法律效果、补足规则 |
| 中断 | 事由（提出履行请求、同意履行、提起诉讼或仲裁）、重新起算点 |
| 延长 | 特殊主体权利受侵害时诉讼时效的起算 |

**特殊起算规则**：
- 无民事行为能力人、限制民事行为能力人遭受法定代理人以外的人侵害
- 无民事行为能力人、限制民事行为能力人的权利受到原法定代理人损害
- 未成年人遭受性侵害

## 第二编 物权编

### 一、物权编基础关系

#### （一）公有制经济和非公有制经济

- 平等保护原则：《民法典》第113条
- 公有制经济和非公有制经济的地位认识

#### （二）物权法定与自愿原则

- **物权法定**：物权种类和公示方法法定
- **区分原则**：合同效力与物权变动相区分

#### （三）合同效力与物权变动

| 情形 | 效力认定 |
|------|----------|
| 合同有效 | 动产交付或不动产登记时物权变动 |
| 合同不成立、无效、被撤销 | 不能发生物权变动效力 |
| 物权更正登记 | 返还原物请求权的实现 |

#### （四）物权公示与真实物权

- **公示是物权对世的必然要求**
- **真实物权的判断标准**：公示机制应与基础事实一致
- **《民法典》第352条但书**的例外情形

### 二、不动产登记纠纷

| 情形 | 责任承担 |
|------|----------|
| 当事人故意提供虚假材料导致登记错误 | 当事人承担赔偿责任 |
| 登记机构原因导致登记错误 | 登记机构承担赔偿责任 |
| 登记机构不承担责任 | 不可归责于登记机构的情形 |

### 三、物权保护纠纷

| 纠纷类型 | 要点 |
|----------|------|
| 物权确认纠纷 | 不适用诉讼时效；具体分析诉求可能性 |
| 返还原物纠纷 | 权利人范围、举证责任分配、不适用诉讼时效 |
| 排除妨害、消除危险 | 费用承担 |
| 财产损害赔偿 | 具有人身意义的物的损害赔偿 |

### 四、所有权纠纷

#### （一）建筑物区分所有权

| 类型 | 要点 |
|------|------|
| 业主专有权 | 摊位、整栋建筑物、露台 |
| 业主共有权 | 人防工程、物业服务用房、维修资金、共有部分收益 |
| 车位、车库 | 规划内与非规划内权属认定；"首先满足业主需要"的理解 |

#### （二）业主撤销权、业主知情权

- 业主撤销权的行使条件与法律后果
- 举证责任分配

#### （三）相邻关系

- 相邻关系的范围
- 规范适用

#### （四）共有纠纷

- 共有权确认
- 共有物分割
- 按份共有人优先购买权

### 五、善意取得

| 要件 | 内容 |
|------|------|
| 无权处分 | 处分人不享有处分权 |
| 受让人善意 | 善意且无重大过失 |
| 合理价格 | 以合理价格转让 |
| 公示 | 不动产登记或动产交付 |

**赃款、赃物问题**：
- 盗赃不适用善意取得
- 赃款或违法所得的善意取得需区分赃款和违法所得

### 六、建设用地使用权

#### （一）出让合同纠纷

| 问题 | 要点 |
|------|------|
| 合同性质 | 民事合同 |
| 效力认定 | 开发区管理委员会订立出让合同的效力；出让集体土地的合同效力 |
| 解除问题 | 出让未办理批准手续、受让方改变用途、未支付出让金等 |

#### （二）转让合同纠纷

- 未取得土地使用权证的转让合同效力
- 划拨建设用地使用权转让合同的效力
- 未达开发条件的转让合同效力
- 以股权转让形式转让建设用地使用权

#### （三）农村土地承包纠纷

- 土地承包经营权流转
- 侵害集体经济组织成员权益
- "外嫁女"权益保护

## 第三编 担保制度

### 一、担保制度概述

#### （一）担保从属性

| 方面 | 内容 |
|------|------|
| 效力从属 | 主合同无效，担保合同无效（另有约定除外） |
| 范围从属 | 担保责任不超过主债务范围 |
| 变更、转让、消灭从属 | 从权利一并转移 |

#### （二）担保的独立性

- **独立保函**：《民法典担保制度解释》关于独立保函的规定
- **排除从属性的约定无效**，但不影响担保合同的效力

### 二、保证合同

#### （一）保证方式

| 方式 | 规则 |
|------|------|
| 一般保证 | 债务人不能履行时承担保证责任；先诉抗辩权 |
| 连带责任保证 | 债务人不履行到期债务时债权人可请求保证人承担责任 |

**《民法典》变化**：约定不明时按一般保证（原《担保法》规定为连带责任保证）

#### （二）保证期间

- **计算**：《民法典》第692条
- **与诉讼时效的关系**：保证期间不发生中止、中断和延长
- **效力**：保证期间届满，保证人不再承担保证责任

#### （三）最高额保证

- 保证期间的起算：视债权确定时被担保债权的履行期限是否已经届满

### 三、担保物权

#### （一）抵押权

| 要点 | 内容 |
|------|------|
| 不动产抵押 | 登记生效主义 |
| 动产抵押 | 登记对抗主义 |
| 抵押财产转让 | 允许转让，但不得对抗已登记的抵押权 |
| 最高额抵押 | 确定债权的方法 |

#### （二）动产与权利担保统一登记

- **登记系统**：中国人民银行征信中心动产融资统一登记公示系统
- **登记对抗**：已登记优先于未登记；登记在先优先于登记在后

#### （三）价款优先权（超级优先权）

《民法典》第416条：抵押人新购机器设备等动产作为抵押财产为价款设定抵押，在标的物交付后10日内办理抵押登记的，优先于在先的浮动抵押

#### （四）流押、流质条款的柔化

- **禁止流押、流质条款的效力**：条款无效，但不影响抵押合同/质押合同其他条款的效力
- **允许当事人约定**：依法清算

### 四、非典型担保

| 类型 | 要点 |
|------|------|
| 所有权保留 | 《民法典》第641条；未登记不得对抗善意第三人 |
| 融资租赁 | 《民法典》第745条；出租人对租赁物的所有权 |
| 保理 | 《民法典》第768条；多重保理的顺位规则 |
| 让与担保 | 合同效力认定；流担保条款无效 |

### 五、公司对外担保

#### （一）越权担保的效力

| 情形 | 效力 |
|------|------|
| 相对人善意 | 构成表见代表，担保合同对公司发生效力 |
| 相对人非善意 | 不构成表见代表，担保合同对公司不发生效力 |

#### （二）无须决议的例外情形

- 公司为其全资子公司开展经营活动提供担保
- 担保合同系由单独或者共同持有公司三分之二以上对担保事项有表决权的股东签字同意

#### （三）上市公司对外担保

- 须依据《公司法》第15条由董事会或股东会决议
- 须对决议公开披露
- 债权人根据披露的信息与上市公司签订担保合同的，担保有效

### 六、共同担保

- **担保人之间的追偿**：担保人之间不能相互追偿
- **担保人承担责任后的追偿**：可向债务人追偿

## 第四编 合同编

### 一、合同的成立

#### （一）要约与承诺

| 要件 | 内容 |
|------|------|
| 要约 | 内容具体确定；表明经受要约人承诺即受约束 |
| 要约邀请 | 希望他人向自己发出要约的表示 |

#### （二）格式条款

**认定标准**：预先拟定 + 订立合同时未与对方协商

**效力规则**：
- 提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利的，格式条款无效
- 理解发生争议的，按照通常理解予以解释；有两种以上解释的，作出不利于提供格式条款方的解释

#### （三）预约合同

- **认定**：当事人约定在将来一定期限内订立本约的合同
- **违约责任**：可以请求承担预约合同的违约责任

### 二、合同效力

#### （一）无效合同

| 情形 | 法条依据 |
|------|----------|
| 违反法律、行政法规的强制性规定 | 《民法典》第153条第1款 |
| 违背公序良俗 | 《民法典》第153条第2款 |
| 恶意串通，损害他人合法权益 | 《民法典》第154条 |
| 通谋虚伪表示 | 《民法典》第146条 |

#### （二）可撤销合同

| 情形 | 要点 |
|------|------|
| 重大误解 | 错误认识 + 重大性 |
| 欺诈 | 故意隐瞒真实情况；须有告知义务 |
| 胁迫 | 非法性；恐惧心理 |
| 显失公平 | 一方利用对方缺乏判断能力 |

#### （三）效力待定合同

| 类型 | 要点 |
|------|------|
| 限制民事行为能力人实施的超出其年龄、智力、精神健康状况的行为 | 经法定代理人同意或追认后有效 |
| 无权代理 | 经被代理人追认后对被代理人发生效力 |

### 三、合同履行

#### （一）合同履行原则

- **全面履行原则**
- **诚实信用原则**：合同漏洞的填补、情势变更

#### （二）双务合同中的抗辩权

| 抗辩权 | 要件 |
|--------|------|
| 同时履行抗辩权 | 对方未履行 |
| 先履行抗辩权 | 对方履行不符合约定 |
| 不安抗辩权 | 对方有丧失或可能丧失履行能力的情形 |

#### （三）情势变更

**构成要件**：
1. 合同的基础条件发生重大变化
2. 变化发生在合同成立之后、履行完毕之前
3. 当事人在订立合同时无法预见
4. 不属于商业风险
5. 继续履行对当事人明显不公平

### 四、合同保全

#### （一）债权人代位权

- **要件**：债权人对债务人享有到期债权 + 债务人怠于行使其债权或与该债权有关的从权利 + 影响债权人的债权实现
- **范围**：与该债权有关的从权利

#### （二）债权人撤销权

**可撤销的行为**：
1. 债务人无偿处分财产权益的行为
2. 债务人以明显不合理的低价转让财产
3. 债务人以明显不合理的高价受让他人财产
4. 债务人为他人的债务提供担保

### 五、合同权利义务终止

#### （一）协商解除

- 当事人协商一致，可以解除合同
- 解除合同应当通知对方

#### （二）法定解除

| 情形 | 要点 |
|------|------|
| 不可抗力 | 不能实现合同目的 |
| 拒绝履行 | 明确表示或以行为表明不履行主要债务 |
| 迟延履行 | 经催告后在合理期限内仍未履行 |
| 根本违约 | 致使不能实现合同目的 |

#### （三）抵销

- **法定抵销**：按照法律规定清偿到期债务
- **约定抵销**：按照当事人约定

### 六、违约责任

| 责任形式 | 要点 |
|----------|------|
| 继续履行 | 可能的情况下 |
| 采取补救措施 | 修理、重作、更换等 |
| 赔偿损失 | 可得利益损失的计算 |
| 违约金 | 司法调整（过高或过低） |
| 定金 | 《民法典》第586-588条 |

**可得利益损失的计算方法**：
1. 差额法
2. 类比法
3. 综合裁量法

### 四、用人者责任

| 个人劳务 | 提供劳务一方因劳务造成他人损害 |

### 五、监护人责任

- 归责原则：无过错责任

### 六、产品责任

|------|------|

| 惩罚性赔偿 | 明知产品存在缺陷仍生产、销售 |

### 七、机动车交通事故责任

- 交强险：保险公司在责任限额范围内赔偿
- 商业险：按保险合同约定赔偿
- 责任承担：侵权人承担

### 八、医疗损害责任

|------|------|

### 九、饲养动物损害责任

|------|------|

#### （二）横向人格否认

《公司法》第23条第2款：股东利用其控制的两个以上公司不当转移风险和利益，损害公司债权人利益的，各公司相互之间对债务承担连带责任

#### （三）一人公司人格否认

《公司法》第23条第3款：一人有限责任公司的股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任

#### （二）保险利益

| 类型 | 主体 |
|------|------|
| 人身保险 | 投保人对本人、配偶、子女、父母等具有保险利益 |
| 财产保险 | 享有保险利益 |

#### （三）保险代位求偿权

- 保险人自向被保险人赔偿保险金之日起，在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利
- 不得损害被保险人的利益
