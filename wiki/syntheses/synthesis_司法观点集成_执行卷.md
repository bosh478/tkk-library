# 司法观点集成（执行卷）

本页面汇总《最高人民法院司法观点集成》第四版执行卷的核心司法观点，涵盖执行工作政策与精神、执行工作一般规范、执行审查案件办理规范等内容。

---

## 一、执行工作政策与精神

### 1.1 民事执行的基本原则

| 原则 | 内容 | 法律依据 |
|------|------|----------|
| 依法执行原则 | 严格按照执行依据执行 | 《民事诉讼法》第230条 |
| 及时执行原则 | 立即采取执行措施 | 最高法司法解释 |
| 全面执行原则 | 不得遗漏执行标的 | 执行工作规定 |
| 适度执行原则 | 选择对被执行人损害最小的方式 | 善意文明执行意见 |

### 1.2 善意文明执行理念

**核心要求**
- 能动司法，服务大局
- 依法保障胜诉当事人权益
- 最大限度减少对被执行人权益影响
- 营造法治化营商环境

**具体措施**
1. 严禁超标的查封
2. 合理选择执行时机
3. 活用执行和解
4. 慎用强制措施

---

## 二、执行工作一般规范

### 2.1 执行管辖

**级别管辖**
| 案件类型 | 管辖法院 |
|----------|----------|
| 法院判决 | 一审法院或被执行人住所地法院 |
| 仲裁裁决 | 被执行人住所地或财产所在地法院 |
| 公证债权文书 | 被执行人住所地或财产所在地法院 |

**管辖权异议**
- 被执行人可在收到执行通知书后提出管辖权异议
- 异议成立的，移送有管辖权的法院
- 异议不成立的，驳回异议

### 2.2 执行的申请和受理

**申请执行的条件**
1. 生效法律文书确定的义务
2. 申请执行人在法定期限内提出
3. 属于受申请法院管辖

**申请执行时效**
| 申请类型 | 时效期限 | 起算点 |
|----------|----------|--------|
| 一般执行 | 2年 | 法律文书规定履行期间的最后一日 |
| 未规定履行期间 | 2年 | 法律文书生效之日 |
| 分期履行 | 2年 | 每次履行期间最后一日 |

**时效中断**
- 申请执行
- 被执行人同意履行
- 达成和解协议

### 2.3 执行当事人及其变更、追加

#### 当事人变更

| 情形 | 变更方式 | 法律依据 |
|------|----------|----------|
| 公民死亡 | 继承人承继 | 《执行规定》 |
| 法人合并分立 | 承继主体承继 | 《执行规定》 |
| 法人注销 | 清算主体或承诺人 | 司法解释 |

#### 当事人追加

**追加被执行人的法定情形**
1. 被执行人为个人独资企业
2. 被执行人为合伙企业
3. 被执行人为分支机构
4. 被执行人为一人有限责任公司
5. 被执行人无偿接受执行标的
6. 其他法定情形

**追加程序**
1. 法院依申请或依职权审查
2. 举行听证
3. 作出追加或驳回裁定
4. 当事人可申请复议

### 2.4 执行担保

**担保成立条件**
| 条件 | 内容 |
|------|------|
| 担保人适格 | 有执行能力的企业或个人 |
| 担保物或保证 | 合法有效的财产或保证 |
| 担保期限 | 约定或法定期限 |
| 担保意思表示 | 书面形式 |

**担保效力**
- 担保成立后，暂缓执行
- 被执行人不履行时，担保人承担担保责任
- 担保人可申请执行担保财产

### 2.5 执行和解

**和解协议的特征**
1. 当事人自愿达成
2. 变更执行依据确定的义务
3. 不影响执行程序的进行
4. 履行完毕后终结执行

**和解协议的效力**
| 情形 | 效力 |
|------|------|
| 全部履行 | 执行终结 |
| 部分履行 | 可申请恢复执行 |
| 申请执行人认可 | 可阻却执行 |

**恢复执行的条件**
1. 和解协议未全部履行
2. 被执行人不履行或不完全履行
3. 申请执行人在法定期限内申请
4. 原执行依据未消灭

### 2.6 暂缓执行与中止执行

#### 暂缓执行

**适用情形**
1. 执行和解担保
2. 审查异议复议期间
3. 检察院建议
4. 其他法定情形

**暂缓期限**
- 一般不超过3个月
- 确有必要的可延长
- 累计不超过1年

#### 中止执行

**适用情形**
| 情形 | 说明 |
|------|------|
| 申请执行人表示可以延期 | 撤回申请或表示谅解 |
| 被执行人确无可供执行财产 | 暂时无法执行 |
| 案件涉及仲裁或公证 | 需要等待确权 |
| 其他情形 | 法律规定的暂时停止执行 |

**中止执行效力**
- 暂时停止执行程序
- 中止情形消失后恢复执行
- 中止执行期间不计算执行期限

### 2.7 终结本次执行程序与终结执行

#### 终结本次执行程序（终本）

**适用条件**
1. 已穷尽执行措施
2. 未发现可供执行的财产
3. 已对被执行人采取限制消费、纳入失信
4. 申请执行人同意或经解释后同意

**终本后的管理**
1. 纳入终本案件库管理
2. 定期财产查控
3. 发现财产立即恢复执行
4. 申请执行人提供财产线索可恢复

#### 终结执行

**适用情形**
| 情形 | 说明 |
|------|------|
| 执行完毕 | 全部执行标的执行完毕 |
| 和解并履行完毕 | 和解协议全部履行 |
| 申请执行人撤回申请 | 申请执行人自愿撤回 |
| 被执行人消亡 | 无遗产也无义务承担人 |
| 法院认为应当终结 | 其他法定情形 |

### 2.8 执行程序和破产程序的衔接

**执行转破产的条件**
1. 被执行人为企业法人
2. 不能清偿到期债务
3. 资产不足以清偿全部债务或明显缺乏清偿能力
4. 经申请执行人或被执行人同意

**执行转破产程序**
1. 法院征询申请执行人或被执行人意见
2. 决定移送破产审查
3. 破产法院审查受理
4. 执行程序终结或中止

### 2.9 迟延履行期间债务利息和迟延履行金

#### 迟延履行期间债务利息

**计算标准**
| 期间 | 计算标准 |
|------|----------|
| 2014年8月1日前 | 最高法院司法解释 |
| 2014年8月1日后 | 《迟延履行利息司法解释》 |
| 一般债务利息 | 按原判决确定利率 |
| 加倍部分债务利息 | 日万分之一点七五 |

**计算公式**
```
加倍部分债务利息 = 债务人尚未清偿的生效法律文书确定的除一般债务利息之外的金钱债务 × 日万分之一点七五 × 迟延履行期间
```

#### 迟延履行金

**适用情形**
1. 非金钱给付义务的执行
2. 被执行人迟延履行
3. 给申请执行人造成损失

### 2.10 强制措施和间接执行措施

#### 限制消费

**适用对象**
- 被执行人为单位的：单位及其法定代表人、主要负责人
- 被执行人为个人的：本人

**限制内容**
| 限制项目 | 内容 |
|----------|------|
| 出行 | 飞机、列车软卧、船舶 |
| 住宿 | 高星级酒店 |
| 消费 | 购车、购房、旅游、度假 |
| 任职 | 设立公司、担任董事监事 |
| 其他 | 子女就读高收费私立学校 |

**解除条件**
1. 被执行人履行完毕
2. 提供有效担保
3. 申请执行人同意

#### 纳入失信被执行人名单

**纳入条件**
1. 有履行能力而不履行
2. 以伪造证据、暴力等方法妨碍执行
3. 违反财产报告制度
4. 违反限制消费令
5. 无正当理由拒不履行和解协议

**失信惩戒措施**
- 向社会公开失信信息
- 政府采购、招标投标受限
- 融资贷款受限
- 任职资格受限

### 2.11 刑事处罚

**拒执罪**
《刑法》第313条规定：有能力执行而拒不执行，情节严重的，处三年以下有期徒刑、拘役或者罚金；情节特别严重的，处三年以上七年以下有期徒刑，并处罚金。

**构成要件**
| 要件 | 内容 |
|------|------|
| 主体 | 被执行人、担保人、协助执行人 |
| 主观 | 故意 |
| 客观 | 有能力执行而拒不执行 |
| 情节 | 严重 |

**典型情形**
1. 隐藏、转移、故意毁损财产
2. 虚假报告财产、违反限制消费令
3. 以暴力、威胁方法妨碍执行
4. 拒不交付财物、迁出房屋

## 三、执行实施案件基本流程

### 3.1 财产调查

**调查手段**
| 手段 | 内容 |
|------|------|
| 网络查控 | 银行存款、车辆、证券、婚姻信息 |
| 传统调查 | 不动产、股权、到期债权 |
| 悬赏执行 | 社会公众举报财产线索 |
| 审计调查 | 被执行人财务状况 |

**财产线索核查**
1. 申请执行人提供线索
2. 被执行人申报财产
3. 法院依职权调查
4. 利害关系人提供线索

### 3.2 财产控制

**控制措施**
1. 冻结（存款、股权、债权）
2. 查封（不动产、车辆、船舶）
3. 扣押（动产）
4. 限制出境
5. 冻结支付宝、微信账户

**财产控制的效力**
| 财产类型 | 冻结/查封效力 |
|----------|---------------|
| 银行存款 | 冻结即生效 |
| 不动产 | 查封后登记生效 |
| 动产 | 扣押占有生效 |
| 股权 | 冻结须通知公司登记机关 |

**轮候查封**
- 在先查封解除后，轮候查封自动生效
- 查封财产处置时，轮候查封优先顺位在后

### 3.3 财产变价

**变价方式**
| 方式 | 适用条件 |
|------|----------|
| 网络拍卖 | 原则上优先采用 |
| 委托拍卖 | 网络拍卖不成或不宜 |
| 变卖 | 财产无法拍卖或当事人同意 |

**网络拍卖程序**
1. 确定拍卖保留价
2. 发布拍卖公告
3. 接受竞买报名
4. 举行拍卖
5. 确认拍卖结果

**一拍、二拍、变卖**
| 拍卖阶段 | 保留价 | 说明 |
|----------|--------|------|
| 一拍 | 评估价或市场价 | 首次拍卖 |
| 二拍 | 一拍保留价的80% | 流拍后再次拍卖 |
| 变卖 | 二拍保留价 | 仍无法成交 |

### 3.4 参与分配

**参与分配的条件**
1. 被执行人为公民或其他组织
2. 被执行人的财产不能清偿所有债权
3. 债权人取得执行依据
4. 债权已到期

**分配顺序**
| 顺位 | 债权类型 | 分配规则 |
|------|----------|----------|
| 担保债权 | 优先受偿权 | 就特定财产优先受偿 |
| 优先债权 | 职工债权、税收 | 按法定顺位 |
| 普通债权 | 一般债权 | 按比例受偿 |

### 3.5 款物的发放与保管

**发放程序**
1. 制作分配方案
2. 通知债权人
3. 债权人确认或异议
4. 发放款项
5. 交付财产

**保管责任**
- 法院对查封、扣押的财产负有保管责任
- 财产毁损、灭失的，承担赔偿责任
- 委托第三方保管的，监督指导

## 四、金钱给付请求权的执行

### 4.1 对银行存款的执行

**冻结存款**
1. 法院通过网络执行查控系统冻结
2. 冻结时即生效
3. 冻结期限不超过1年

**扣划存款**
1. 冻结后进行扣划
2. 扣划到法院执行款专户
3. 通知申请执行人领取

**存款执行的特殊问题**
| 问题 | 处理规则 |
|------|----------|
| 冻结后存入 | 不冻结，后存入的资金 |
| 浮动质押 | 需审查质押效力 |
| 保证金 | 需审查保证金性质 |

### 4.2 对不动产的执行

**查封程序**
1. 发出查封裁定
2. 送达被执行人
3. 通知不动产登记机关
4. 现场张贴封条或公告

**拍卖程序**
1. 委托评估
2. 确定拍卖保留价
3. 发布拍卖公告
4. 举行拍卖
5. 确认拍卖结果

**涤除租赁**
- 拍卖前审查租赁真实性
- 租赁权不能对抗申请执行人
- 拍卖成交后交付

### 4.3 对股权的执行

**冻结程序**
1. 法院作出冻结裁定
2. 送达公司登记机关
3. 通知被执行人
4. 办理冻结登记

**评估程序**
1. 委托评估机构
2. 评估机构评估
3. 通知当事人
4. 当事人有异议可申请复核

**拍卖程序**
1. 发布拍卖公告
2. 通知公司及其他股东
3. 股东享有优先购买权
4. 拍卖成交后办理变更登记

### 4.4 对证券及其交易结算资金的执行

**执行范围**
1. 证券账户中的股票、债券
2. 证券交易结算资金
3. 基金、理财产品

**执行程序**
1. 冻结证券账户
2. 扣划资金
3. 变价证券
4. 分配执行款项

## 五、非金钱给付请求权的执行

### 5.1 行为请求权的执行

**行为请求权类型**
| 类型 | 内容 |
|------|------|
| 作为 | 交付财产、迁出房屋、办理过户 |
| 不作为 | 停止侵害、排除妨碍 |

**执行方式**
| 情形 | 方式 |
|------|------|
| 可替代行为 | 委托他人代为完成，费用被执行人承担 |
| 不可替代行为 | 被执行人亲自履行，可罚款、拘留 |
| 不作为请求权 | 持续的，可再次执行 |

### 5.2 交付特定物的执行

**特定物执行规则**
1. 查封特定物
2. 命令被执行人交付
3. 被执行人不交付的，强制交付
4. 无法交付的，赔偿损失

---

## 六、特殊案件的执行

### 6.1 财产保全与先予执行案件的执行

**财产保全执行**
1. 保全裁定的执行
2. 续行保全
3. 保全解除
4. 保全财产的处置

**先予执行**
1. 判决前执行
2. 需胜诉可能性高
3. 情况紧急
4. 裁定先予执行

### 6.2 仲裁裁决的执行

**申请执行条件**
1. 仲裁裁决已生效
2. 裁决内容明确
3. 属于执行法院管辖
4. 在申请执行时效内

**不予执行情形**
1. 当事人在合同中未订有仲裁条款
2. 裁决的事项不属于仲裁范围
3. 仲裁庭的组成或程序违法
4. 伪造证据、隐瞒证据
5. 枉法裁决

### 6.3 公证债权文书的执行

**申请执行条件**
1. 公证债权文书已生效
2. 债权债务关系明确
3. 债务人不履行或不适当履行
4. 属于执行法院管辖

**不予执行情形**
1. 公证债权文书违反公证程序
2. 债权债务关系不明确
3. 债务人提出异议
4. 其他法定情形

### 6.4 刑事裁判涉财产部分的执行

**执行范围**
1. 罚金
2. 没收财产
3. 责令退赔
4. 追缴违法所得

**执行程序**
1. 法院刑事审判庭移送执行
2. 立案执行
3. 采取执行措施
4. 执行完毕
