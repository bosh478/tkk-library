## 三、核心定义：以证据为中心的刑事指控体系四要素

### 指控主体
**检察机关**。根据宪法和《人民检察院组织法》，检察机关是国家的法律监督机关，履行刑事公诉职能。在"以审判为中心"的改革背景下，侦查中心主义逐步转向审判中心主义，检察机关指控职能对侦查职能的监督制约作用和协作配合作用均得到强化，推动形成"大控方"新格局。

### 指控对象
**犯罪嫌疑人、被告人**。公诉案件中存在于侦查/审查起诉阶段（犯罪嫌疑人）和审判阶段（被告人）。检察机关应当秉持客观公正立场，尊重和保障人权，既追诉犯罪，也保障无罪的人不受刑事追究。

### 指控内容
1. **定罪指控**：指控犯罪嫌疑人、被告人构成犯罪
2. **量刑建议**：提出量刑请求权
3. **涉案财物处置意见**：对涉案财物提出处置请求（由传统的"对人之诉"发展为"对人之诉"与"对物之诉"并行）

### 指控依据
刑事指控的法律渊源，包括：
- **刑事实体法**：定罪、量刑、涉案财物处置的实体依据
- **刑事程序法**：证明责任、证明对象、证明标准、证据规则
- **司法证明**：证明责任由人民检察院承担（公诉案件被告人有罪举证责任）

## 四、常见误解澄清

> **误解**：刑事指控只关注庭审阶段
>
> **澄清**：刑事指控体系贯穿刑事诉讼全过程（侦查→审查起诉→审判），检察机关在审前程序中承担审前过滤把关职责，在庭审中承担指控证明犯罪职责。构建以证据为中心的刑事指控体系，是"高质效办好每一个案件"的基础保障。

## 五、核心内涵：四个"善于"

"高质效办好每一个案件"实践要求做到"三个善于"：

1. 善于从纷繁复杂的法律事实中准确把握实质法律关系
2. 善于从具体法律条文中深刻领悟法治精神
3. 善于在法理情的有机统一中实现公平正义

## 六、证明标准体系

| 事项 | 证明标准 |
|------|----------|
| 定罪 | 犯罪事实清楚，证据确实、充分 |
| 量刑 | 事实清楚，证据确实、充分 |
| 涉案财物 | 有证据证明，且达到高度可能性 |
| 程序性事项 | 应当有证据予以证明，且相关证据已查证属实 |
| 逮捕 | 有证据证明有犯罪事实，可能判处徒刑以上刑罚；有社会危险性 |
| 核准追诉 | 有证据证明存在犯罪事实，且犯罪事实是犯罪嫌疑人所实施 |
| 没收违法所得 | 有证据证明有犯罪事实，申请没收的财产具有高度可能属于违法所得 |

## 七、证据审查运用方法

| 方法 | 要点 |
|------|------|
| 主客观相统一 | 主观性证据与客观性证据相互印证 |
| 证据印证 | 证据之间相互验证，形成证据链条 |
| 合理性审查 | 逻辑法则、生活经验判断证据可靠性 |
| 大数据技术 | 借助技术手段发现和固定证据 |
| 专业力量 | 检察技术人员或有专门知识的人的辅助作用 |

## 八、改革背景与意义

### 改革历程

| 时间 | 事件 |
|------|------|
| 2014年10月 | 党的十八届四中全会提出"推进以审判为中心的诉讼制度改革" |
| 2015年6月 | 最高检提出"构建以证据为核心的刑事指控体系" |
| 2018年11月 | 最高检《"十三五"时期检察工作发展规划纲要》明确构建目标 |
| 2023年8月 | 最高检《2023—2027年检察改革工作规划》提出协同推进 |
| 2024年11月 | 最高检《关于全面深化检察改革的意见》进一步明确完善刑事指控体系 |

### 改革意义

1. **贯彻证据裁判原则**：保障被告人基本权利，维护司法公正——非法证据排除在刑事诉讼证据体系之外，有效完成证据审前过滤
2. **凸显证据核心地位**：夯实刑事指控基础，提高办案质效——证据审查能力是检察官最基础、最基本的能力
3. **强化证据规则规范**：强化刑事诉讼监督制约体系——树立刑法、刑事诉讼法、证据法一体化适用思维

### 以证据为中心与以审判为中心的关系

以审判为中心的实质是以庭审为中心，以庭审为中心的实质是以证据为中心。构建以证据为中心的刑事指控体系，就牵住了刑事诉讼活动的"牛鼻子"。

## 九、证据审查运用的办案模式

1. **客观性证据主导模式**：注重引导侦查机关加强对客观性证据的收集，推动侦查活动由"突破口供"向"证明犯罪"转变
2. **全面性审查模式**：全面审查各类证据，既审查客观性证据也审查主观性证据，既审查有罪/罪重证据也审查无罪/罪轻证据
3. **亲历性办案模式**：变"静态"审查为"动态"审查——复勘现场、疑点证据走访核实、调取侦查内卷、接触当事人和证人、听取辩护律师意见
