## 一、人身安全保护令制度贯彻实施意见

### 1.1 保护对象

家庭成员中的**妇女、未成年人、老年人、残疾人**等弱势群体

### 1.2 基本原则

| 原则 | 内容 |
|------|------|
| 依法保护 | 依法、及时、有效保护受害人 |
| 尊重意愿 | 尊重受害人真实意愿 |
| 保护隐私 | 保护当事人尤其是未成年人的隐私 |

### 1.3 部门职责

| 部门 | 职责 |
|------|------|
| 人民法院 | 建立"绿色通道"，依法及时作出保护令，送达并协助执行 |
| 公安机关 | 强化干预家庭暴力，依法出具告诫书，配合调查取证 |
| 民政部门 | 加强庇护场所建设，提供转介安置、法律援助 |
| 司法行政部门 | 提供法律援助，加强法治宣传 |
| 医疗机构 | 详细记录伤情，建立医警联动机制 |
| 学校、幼儿园 | 及时报告侵害，发现问题立即报警 |
| 居民委员会、村民委员会 | 协助执行保护令，定期回访 |

### 1.4 保护令内容

**人身安全保护令**可以包括：
- 禁止被申请人实施家庭暴力
- 禁止被申请人骚扰、跟踪、接触申请人
- 责令被申请人迁出申请人住所
- 禁止实施与家庭暴力相关的其他行为

### 1.5 申请与作出

**申请主体**：
- 受害人本人
- 受害人的近亲属
- 受害人所在单位
- 民政部门
- 妇女联合会

**受理"绿色通道"**：
- 基层人民法院立案大厅或诉讼服务中心提供导诉服务
- 24小时内向当事人送达

### 1.6 协助执行

送达保护令时，应当送达：
- 当地公安派出所
- 居民委员会、村民委员会
- 妇女联合会
- 学校、未成年人保护组织等

**公安机关协助执行**：
- 督促被申请人遵守保护令
- 接警后及时出警，制止违法行为
- 搜集、固定证据

## 二、依法严惩利用未成年人实施黑恶势力犯罪的意见

### 2.1 "利用未成年人实施黑恶势力犯罪"认定

具有下列行为之一的，应当认定为"利用未成年人实施黑恶势力犯罪"：
1. 胁迫、教唆未成年人参加黑社会性质组织、恶势力犯罪集团、恶势力
2. 拉拢、引诱、欺骗未成年人参加黑社会性质组织、恶势力犯罪集团、恶势力
3. 招募、吸收、介绍未成年人参加上述组织
4. 雇佣未成年人实施黑恶势力违法犯罪活动
5. 其他利用未成年人实施黑恶势力犯罪的情形

### 2.2 从重处罚情节

利用未成年人实施黑恶势力犯罪，具有下列情形之一的，从重处罚：
1. 组织、指挥未成年人实施故意杀人、故意伤害致人重伤或死亡、强奸、绑架、抢劫等严重暴力犯罪
2. 向未成年人传授实施黑恶势力犯罪的方法、技能、经验
3. 利用未达到刑事责任年龄的未成年人实施犯罪
4. 为逃避法律追究，让未成年人自首、做虚假供述顶罪
5. 利用留守儿童、在校学生实施犯罪
6. 利用多人或者多次利用未成年人实施犯罪
7. 针对未成年人实施违法犯罪
8. 对未成年人负有监护、教育、照料等特殊职责的人员利用未成年人实施犯罪

### 2.3 处罚原则

| 情形 | 处罚原则 |
|------|----------|
| 首要分子 | 按照集团所犯的全部罪行，从重处罚 |
| 骨干成员 | 按照其组织、指挥的犯罪，从重处罚 |
| 直接利用成员 | 从重处罚 |
| 虽有自首、立功、坦白，但利用未成年人的 | 一般不予从轻或减轻处罚 |

### 2.4 未成年人保护例外

被黑社会性质组织、恶势力利用，**偶尔参与**黑恶势力犯罪活动的未成年人：
- 按其所实施的具体犯罪行为定性
- **一般不认定为**黑恶势力犯罪组织成员

## 三、宽严相济政策

### 3.1 对利用者的从严

- 依法从重追究刑事责任
- 从严掌握取保候审、监视居住
- 从严掌握缓刑、减刑、假释
- 依法运用财产刑、资格刑

### 3.2 对被利用未成年人的从宽

- 参与轻微犯罪的未成年人，以教育、挽救为主
- 封存犯罪记录
- 提供社会化帮教
- 配合有关部门及早发现、及时挽救
