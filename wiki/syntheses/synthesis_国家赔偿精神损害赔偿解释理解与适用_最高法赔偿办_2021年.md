## ❓ 常见问题

> 问：国家赔偿中精神损害抚慰金的支付标准是多少？
> 答：造成严重后果的，一般在人身自由赔偿金、生命健康赔偿金总额的50%以下（含本数）酌定；后果特别严重的，可在50%以上酌定。

> 问：哪些情形可以认定为"造成严重后果"？
> 答：（1）无罪或终止追究刑事责任的人被羁押六个月以上；（2）受害人经鉴定为轻伤以上或残疾；（3）受害人经诊断、鉴定为精神障碍或精神残疾；（4）受害人名誉、荣誉、家庭、职业、教育等方面遭受严重损害。

> 问：法人能否请求精神损害赔偿？
> 答：不能。法人或非法人组织请求精神损害赔偿的，人民法院不予受理。

## 正文

### 一、解释的核心内容

《解释》共14条，重点明确以下内容：

**1. 精神损害赔偿请求的申请与受理**
- 公民以人身权受到侵犯为由提出国家赔偿申请，依照《国家赔偿法》第35条请求精神损害赔偿的，适用本解释
- 法人或非法人组织请求精神损害赔偿的，不予受理
- 申请人身权赔偿时应一并申请精神损害赔偿，经释明后不变更请求的，案件审结后又基于同一侵权事实另行申请的，不予受理

**2. 致人精神损害的认定**
- 赔偿义务机关有《国家赔偿法》第3条、第17条规定情形之一，依法应当承担国家赔偿责任的，可以同时认定该侵权行为致人精神损害
- 例外：赔偿义务机关有证据证明该公民不存在精神损害，或认定精神损害违背公序良俗的

**3. 造成严重后果的认定标准（第7条）**

| 情形 | 认定等级 |
|------|----------|
| 无罪或终止追究刑事责任的人被羁押六个月以上 | 严重后果 |
| 受害人经鉴定为轻伤以上或残疾 | 严重后果 |
| 受害人经诊断、鉴定为精神障碍或精神残疾 | 严重后果 |
| 受害人名誉、荣誉、家庭、职业、教育等方面遭受严重损害 | 严重后果 |
| 无罪被羁押十年以上 | 后果特别严重 |
| 受害人死亡 | 后果特别严重 |
| 受害人重伤或残疾一至四级，生活不能自理 | 后果特别严重 |
| 严重精神障碍或精神残疾一至二级，生活不能自理 | 后果特别严重 |

**4. 精神损害抚慰金标准（第8条）**

```
严重后果 → 人身自由赔偿金、生命健康赔偿金总额的50%以下（含本数）
后果特别严重 → 50%以上酌定
```

**5. 抚慰金参考因素（第9条）**
- 精神受到损害以及造成严重后果的情况
- 侵权行为的目的、手段、方式等具体情节
- 侵权机关及其工作人员的违法、过错程度、原因力比例
- 原错判罪名、刑罚轻重、羁押时间
- 受害人的职业、影响范围
- 纠错的事由以及过程
- 其他应当考虑的因素

**6. 责任方式的适用规则（第4-6条）**
- 致人精神损害：消除影响、恢复名誉或赔礼道歉
- 致人精神损害并造成严重后果：支付精神损害抚慰金的同时，消除影响、恢复名誉或赔礼道歉
- 消除影响、恢复名誉与赔礼道歉可以单独适用，也可以合并适用

### 二、精神损害赔偿制度的比较法考察

**德国**：采取限定主义立法模式，《德国民法典》第253条、第823条规定精神损害赔偿的基本规则。1973年《德国国家赔偿法》明确将精神损害作为国家赔偿对象。

**法国**：采取概括主义立法模式，通过行政法院大量判例实现精神损害赔偿的广泛承认。可赔偿精神损害分为：因人身受侵害引发的精神损害和因人格权受侵犯遭受的精神损害两大类。

**日本**：《日本民法典》第710条创造性地拓展了精神损害赔偿范围，将人身、自由、名誉和财产权一并涵盖。1964年最高裁判所承认了法人的精神损害赔偿。

**英国**：精神损害赔偿规则主要依靠判例确认，包括疼痛与痛苦、安乐生活的丧失、丧亲之痛、精神打击等类型。

**美国**：精神损害赔偿请求既可以附带于人身损害赔偿提出，也可以作为独立诉因提起。

### 三、典型案例

**呼格吉勒图再审无罪国家赔偿案**：该案是推动《解释》出台的重要案件之一，涉及冤错案件的精神损害赔偿标准问题。

**聂树斌再审无罪国家赔偿案**：在全国范围内有重大影响的刑事冤错案件，精神损害赔偿问题受到广泛关注。

**张辉、张高平再审无罪国家赔偿案**：涉及长期羁押后改判无罪的精神损害赔偿认定。

### 四、核心规则总结

```
国家赔偿精神损害赔偿适用规则：

┌─ 申请条件：公民人身权受到侵犯
├─ 认定标准：法定侵权行为 → 推定致人精神损害
├─ 后果分级：
│  ├─ 致人精神损害 → 消除影响/恢复名誉/赔礼道歉
│  ├─ 造成严重后果 → 抚慰金（≤50%）+ 非财产责任
│  └─ 后果特别严重 → 抚慰金（>50%）+ 非财产责任
├─ 参考因素：7项综合考量
└─ 最低限额：不少于1000元
```
