## 一、公务员法（2019年6月1日施行）

### 1. 公务员定义
- 依法履行公职、纳入国家行政编制、由国家财政负担工资福利的工作人员
- 是干部队伍的重要组成部分，社会主义事业的中坚力量，人民的公仆

### 2. 应当具备的条件
- 中华人民共和国国籍
- 年满十八周岁
- 拥护宪法，拥护中国共产党领导和社会主义制度
- 具有良好的政治素质和道德品行
- 具有正常履行职责的身体条件和心理素质
- 具有符合职位要求的文化程度和工作能力

### 3. 应当履行的义务
- 忠于宪法，模范遵守、自觉维护宪法和法律，自觉接受中国共产党领导
- 忠于国家，维护国家的安全、荣誉和利益
- 忠于人民，全心全意为人民服务，接受人民监督
- 忠于职守，勤勉尽责，服从和执行上级依法作出的决定和命令
- 保守国家秘密和工作秘密
- 清正廉洁，公道正派

### 4. 享有的权利
- 获得履行职责应当具有的工作条件
- 非因法定事由、非经法定程序，不被免职、降职、辞退或者处分
- 获得工资报酬，享受福利、保险待遇
- 参加培训
- 对机关工作和领导人员提出批评和建议
- 提出申诉和控告

### 5. 职务与职级并行制度
- **领导职务层次**：国家级正职、国家级副职、省部级正职、省部级副职、厅局级正职、厅局级副职、县处级正职、县处级副职、乡科级正职、乡科级副职
- **职级序列**（厅局级以下）：一级巡视员至二级科员

### 6. 录用制度
- 采取公开考试、严格考察、平等竞争、择优录取的办法
- 不得录用：曾因犯罪受过刑事处罚、被开除中国共产党党籍、被开除公职、被依法列为失信联合惩戒对象

### 7. 处分种类
警告（六个月）、记过（十二个月）、记大过（十八个月）、降级（二十四个月）、撤职（二十四个月）、开除

### 8. 回避制度
- 夫妻关系、直系血亲关系、三代以内旁系血亲关系以及近姻亲关系
- 不得在同一机关双方直接隶属于同一领导人员的职位或者有直接上下级领导关系的职位工作

### 9. 禁止行为
- 散布有损宪法权威、中国共产党和国家声誉的言论
- 组织或者参加旨在反对宪法、中国共产党领导和国家的集会、游行、示威等活动
- 玩忽职守，贻误工作
- 拒绝执行上级依法作出的决定和命令
- 贪污贿赂，利用职务之便为自己或者他人谋取私利
- 泄露国家秘密或者工作秘密
- 违反有关规定从事或者参与营利性活动

## 二、人民法院组织法（2019年1月1日施行）

### 1. 法院性质与职责
- 人民法院是国家的审判机关
- 通过审判刑事、民事、行政案件以及法律规定的其他案件，惩罚犯罪，保障无罪的人不受刑事追究，解决民事、行政纠纷，保护个人和组织的合法权益，监督行政机关依法行使职权

### 2. 法院设置体系
| 层级 | 范围 |
|------|------|
| 最高人民法院 | 全国最高审判机关，可设巡回法庭 |
| 高级人民法院 | 省、自治区、直辖市高级人民法院 |
| 中级人民法院 | 省、自治区辖市的中级人民法院；直辖市内设立的中级人民法院；自治州中级人民法院；省、自治区内按地区设立的中级人民法院 |
| 基层人民法院 | 县、自治县人民法院；不设区的市人民法院；市辖区人民法院 |
| 专门人民法院 | 军事法院、海事法院、知识产权法院、金融法院等 |

### 3. 审判组织
- **合议庭**：由法官组成，或者由法官和人民陪审员组成，成员为三人以上单数
- **独任审理**：法官一人独任审理案件范围由法律规定
- **审判委员会**：总结审判工作经验，讨论决定重大、疑难、复杂案件的法律适用等

### 4. 审判原则
- 依照法律规定独立行使审判权，不受行政机关、社会团体和个人的干涉
- 审判案件在适用法律上一律平等
- 司法公正，以事实为根据，以法律为准绳
- 司法公开（法律另有规定除外）
- 司法责任制

### 5. 法官制度
- 法官实行员额制
- 法官从取得法律职业资格并且具备法律规定的其他条件的人员中选任
- 初任法官应当由法官遴选委员会进行专业能力审核
- 上级人民法院的法官一般从下级人民法院的法官中择优遴选

### 6. 死刑复核
- 死刑除依法由最高人民法院判决的以外，应当报请最高人民法院核准

## 三、人民检察院组织法（2019年1月1日施行）

### 1. 检察院性质与职责
- 人民检察院是国家的法律监督机关
- 通过行使检察权，追诉犯罪，维护国家安全和社会秩序，维护个人和组织的合法权益，维护国家利益和社会公共利益，保障法律正确实施，维护社会公平正义

### 2. 检察院设置体系
| 层级 | 范围 |
|------|------|
| 最高人民检察院 | 最高检察机关 |
| 省级人民检察院 | 省、自治区、直辖市人民检察院 |
| 设区的市级人民检察院 | 省、自治区辖市人民检察院，自治州人民检察院，省、自治区、直辖市人民检察院分院 |
| 基层人民检察院 | 县、自治县、不设区的市、市辖区人民检察院 |
| 专门人民检察院 | 军事检察院等 |

### 3. 检察职权
- 依照法律规定对有关刑事案件行使侦查权
- 对刑事案件进行审查，批准或者决定是否逮捕犯罪嫌疑人
- 对刑事案件进行审查，决定是否提起公诉，对决定提起公诉的案件支持公诉
- 依照法律规定提起公益诉讼
- 对诉讼活动实行法律监督
- 对判决、裁定等生效法律文书的执行工作实行法律监督
- 对监狱、看守所的执法活动实行法律监督
- 最高人民检察院对最高人民法院的死刑复核活动实行监督

### 4. 办案组织
- 检察官独任办理或组成办案组办理
- 检察官办案组：检察长指定一名检察官担任主办检察官
- 检察委员会：总结检察工作经验，讨论决定重大、疑难、复杂案件

### 5. 检察官制度
- 检察官实行员额制
- 检察官从取得法律职业资格的人员中选任
- 初任检察官应当由检察官遴选委员会进行专业能力审核

### 6. 人民监督员制度
- 人民监督员依照规定对人民检察院的办案活动实行监督

## 四、人民警察法（2013年1月1日施行）

### 1. 警察范围与任务
- 人民警察包括：公安机关、国家安全机关、监狱、劳动教养管理机关的人民警察和人民法院、人民检察院的司法警察
- 任务：维护国家安全，维护社会治安秩序，保护公民的人身安全、人身自由和合法财产，保护公共财产，预防、制止和惩治违法犯罪活动

### 2. 公安机关人民警察职责
- 预防、制止和侦查违法犯罪活动
- 维护社会治安秩序，制止危害社会治安秩序的行为
- 维护交通安全和交通秩序，处理交通事故
- 组织、实施消防工作，实行消防监督
- 管理枪支弹药、管制刀具和易燃易爆、剧毒、放射性等危险物品
- 警卫国家规定的特定人员，守卫重要的场所和设施
- 管理集会、游行、示威活动
- 管理户政、国籍、入境出境事务和外国人在中国境内居留、旅行的有关事务
- 维护国（边）境地区的治安秩序
- 对被判处拘役、剥夺政治权利的罪犯执行刑罚
- 监督管理计算机信息系统的安全保护工作

### 3. 盘问检查权
- 对有违法犯罪嫌疑的人员，经出示相应证件，可以当场盘问、检查
- 留置时间自带至公安机关之时起不超过二十四小时
- 特殊情况下，经县级以上公安机关批准，可以延长至四十八小时

### 4. 警衔制度
- 警衔分五级：总警监、副总警监、警监、警督、警司

### 5. 担任警察的条件
- 年满十八岁的公民
- 拥护中华人民共和国宪法
- 有良好的政治、业务素质和良好的品行
- 身体健康
- 具有高中毕业以上文化程度
- 自愿从事人民警察工作
- 不得担任警察：曾因犯罪受过刑事处罚、曾被开除公职

### 6. 禁止行为
- 散布有损国家声誉的言论，参加非法组织，参加罢工
- 泄露国家秘密、警务工作秘密
- 弄虚作假，隐瞒案情，包庇、纵容违法犯罪活动
- 刑讯逼供或者体罚、虐待人犯
- 非法剥夺、限制他人人身自由，非法搜查他人的身体、物品、住所或者场所
- 敲诈勒索或者索取、收受贿赂
- 殴打他人或者唆使他人打人
- 从事营利性的经营活动或者受雇于任何个人或者组织

### 7. 执法保障
- 人民警察依法执行职务，受法律保护
- 拒绝或者阻碍人民警察依法执行职务的处理：治安管理处罚；构成犯罪的，依法追究刑事责任

## 五、保守国家秘密法（2024年5月1日施行）

### 1. 国家秘密定义
- 关系国家安全和利益，依照法定程序确定，在一定时间内只限一定范围的人员知悉的事项

### 2. 保密工作原则
- 坚持中国共产党对保密工作的领导
- 坚持总体国家安全观
- 遵循：党管保密、依法管理，积极防范、突出重点，技管并重、创新发展

### 3. 密级分类
| 密级 | 定义 | 保密期限 |
|------|------|----------|
| 绝密 | 最重要的国家秘密，泄露会使国家安全和利益遭受特别严重的损害 | 不超过三十年 |
| 机密 | 重要的国家秘密，泄露会使国家安全和利益遭受严重的损害 | 不超过二十年 |
| 秘密 | 一般的国家秘密，泄露会使国家安全和利益遭受损害 | 不超过十年 |

### 4. 定密权限
| 机关级别 | 可确定密级 |
|----------|------------|
| 中央国家机关、省级机关及其授权的机关、单位 | 绝密级、机密级和秘密级 |
| 设区的市级机关及其授权的机关、单位 | 机密级和秘密级 |

### 5. 知悉范围
- 应当根据工作需要限定在最小范围
- 能够限定到具体人员的，限定到具体人员
- 不能限定到具体人员的，限定到机关、单位

### 6. 涉密信息系统保护
- 按照涉密程度实行分级保护
- 保密设施、设备应当与涉密信息系统同步规划、同步建设、同步运行
- 涉密信息系统应当按照规定，经检查合格后方可投入使用

### 7. 涉密人员管理
- 分类：核心涉密人员、重要涉密人员、一般涉密人员
- 实行分类管理
- 涉密人员出境应当经有关部门批准
- 离岗离职实行脱密期管理

### 8. 法律责任
- 非法获取、持有国家秘密载体
- 买卖、转送或者私自销毁国家秘密载体
- 通过普通邮政、快递等无保密措施的渠道传递国家秘密载体
- 在私人交往和通信中涉及国家秘密
- 未按照国家保密规定和标准采取有效保密措施，在互联网及其他公共信息网络传递国家秘密
- 将涉密信息系统、涉密信息设备接入互联网及其他公共信息网络
- 使用非涉密信息系统、非涉密信息设备存储、处理国家秘密

## 六、中华人民共和国审计法（2021年修正）

**生效日期：** 2022年1月1日

**审计监督范围：**
| 类型 | 审计对象 |
|------|----------|
| 财政收支 | 本级各部门（含直属单位）和下级政府预算执行和决算 |
| 财务收支 | 国有金融机构、国有企业事业组织的财务收支 |
| 投资审计 | 政府投资和以政府投资为主的建设项目 |
| 资源审计 | 国有资源、国有资产 |
| 社保审计 | 社会保险基金、全国社会保障基金等公共资金 |

**审计机关权限：**
- 检查财务、会计资料以及与财政收支有关的业务、管理等资料
- 查询被审计单位在金融机构的账户
- 查询有关单位、个人在金融机构的存款
- 封存有关资料和违反国家规定取得的资产

**审计结果运用：**
- 审计结果以及整改情况作为考核、任免、领导干部和制定政策、完善制度的重要参考
- 拒不整改或者整改时弄虚作假的，依法追究法律责任

## 七、中华人民共和国海关法（2021年修正）

**生效日期：** 2021年1月1日

**海关职权：**
- 进出境运输工具、货物、物品的监督管理
- 征收关税和其他税费
- 查缉走私
- 编制海关统计

**进出境货物监管：**
| 货物类型 | 监管要求 |
|----------|----------|
| 一般货物 | 如实申报、接受查验、缴纳税费 |
| 减免税货物 | 按批准用途使用，未经海关许可不得处置 |
| 保税货物 | 加工、装配后复运出境 |

**关税征收：**
- 从价税、从量税、复合税、滑准税
- 关税配额税率、协定税率、最惠国税率、普通税率

**法律责任：**
- 走私行为：没收走私货物及违法所得，可并处罚款
- 逃避海关监管：处以货物物品等值以下罚款
- 抗拒、阻碍海关执行职务：治安管理处罚

## 八、中华人民共和国消防法（2021年修正）

**生效日期：** 2021年4月29日

**消防责任：**
- 各级人民政府负责本行政区域内的消防工作
- 应急管理部门负责指导监督消防工作
- 单位负责本单位的消防安全

**火灾预防：**
- 建设工程须依法进行消防设计审核/备案
- 公众聚集场所须取得消防安全检查合格证
- 定期检测维护消防设施器材
- 禁止在公共场所违规用火用电

**消防组织：**
- 国家综合性消防救援队
- 专职消防队
- 志愿消防队

**灭火救援：**
- 消防救援机构统一组织和指挥
- 火灾现场总指挥有权决定紧急措施
- 任何单位和个人应当为报警提供便利

**法律责任：**
- 公共场所违规用火：警告或500元以下罚款
- 过失引起火灾：十日至十五日拘留，可并处500元以下罚款
- 擅自拆封或使用消防设施：责令改正并处罚款

## 九、中华人民共和国行政处罚法（2021年修订）

**生效日期：** 2021年7月15日

**行政处罚种类：**
| 类型 | 举例 |
|------|------|
| 警告、通报批评 | 声誉罚 |
| 罚款、没收违法所得、没收非法财物 | 财产罚 |
| 暂扣许可证件、降低资质等级、吊销许可证件 | 行为罚 |
| 责令停产停业、责令关闭、限制从业 | 能力罚 |
| 行政拘留 | 人身自由罚 |

**行政处罚程序：**
| 程序 | 适用条件 |
|------|----------|
| 简易程序 | 违法事实确凿，公民200元以下、法人3000元以下罚款或警告 |
| 普通程序 | 一般程序，须调查取证、告知、听取陈述申辩 |
| 听证程序 | 较大数额罚款、没收较大违法所得、责令停产停业等 |

**时效：** 违法行为在两年内未被发现的，不再给予行政处罚（法律另有规定除外）

**一事不再罚：** 对当事人的同一个违法行为，不得给予两次以上罚款的行政处罚

## 十、中华人民共和国行政复议法（2023年修订）

**生效日期：** 2024年1月1日

**行政复议范围：**
- 行政处罚决定
- 行政强制决定
- 行政许可决定
- 征收征用决定
- 赔偿决定
- 其他行政行为

**行政复议管辖：**
| 情形 | 管辖机关 |
|------|----------|
| 地方各级政府 | 上一级地方政府 |
| 政府部门 | 本级政府或上一级主管部门 |
| 海关、国安 | 上一级主管部门 |
| 垂直领导机关 | 上一级主管部门 |

**申请期限：** 知道具体行政行为之日起60日内（法律规定的期限长于60日的除外）

**审理程序：**
- 书面审查为主
- 重大复杂案件可以听证
- 调解适用于行政赔偿、补偿、自由裁量权案件

**决定类型：**

- 撤销、变更或确认违法
- 责令履行
- 驳回申请

## 十一、中华人民共和国行政强制法

**生效日期：** 2012年1月1日

**行政强制种类：**
| 类型 | 举例 |
|------|------|
| 行政强制措施 | 限制公民人身自由；查封场所、设施；扣押财物；冻结存款汇款 |
| 行政强制执行 | 加处罚款或滞纳金；划拨存款；拍卖或依法处理查封扣押的财物 |

**强制措施程序：**
- 须有法定依据
- 须在法定权限内
- 须按法定程序进行
- 听取当事人陈述申辩
- 重大决定须经机关负责人集体讨论

**强制执行程序：**
- 催告（当事人自觉履行）
- 强制执行决定
- 执行（可执行和解）

**法律责任：**
- 暴力、非法剥夺公民人身自由
- 损毁查封扣押的财物
- 利用职务便利牟取利益

|----------|------------|

| 行政法规 | 可设定应当由法律设定的许可 |
| 地方性法规 | 地方性事务 |
| 省级政府规章 | 临时性许可（一年） |

**行政许可程序：**
| 程序 | 要点 |
|------|------|

| 受理 | 5日内决定是否受理 |
| 审查 | 材料审核、实地核查 |
| 决定 | 20日内决定，可延10日 |
| 听证 | 涉及公共利益的重大许可须公告听证 |

**便民原则：**
- 一个窗口受理
- 一次性告知
- 限时办结
- 网上办理

**法律责任：**
- 违规许可：责令撤销
- 工作人员违法：处分
- 中介机构违规：没收违法所得、罚款

## 十三、中华人民共和国数据安全法

**生效日期：** 2021年9月1日

**数据分类分级保护：**
| 类型 | 定义 |
|------|------|
| 国家核心数据 | 关系国家安全、国民经济命脉、重要民生、重大公共利益 |
| 重要数据 | 按照数据分类分级保护制度确定 |

**数据安全制度：**
- 数据分类分级保护制度
- 数据安全风险评估、报告、信息共享、监测预警机制
- 数据安全审查制度
- 数据出口管制

**数据处理者义务：**
- 建立全流程数据安全管理制度
- 明确数据安全负责人和管理机构
- 定期开展风险评估

**法律责任：**
- 不履行数据安全保护义务：5万-50万罚款
- 向境外提供重要数据：10万-100万罚款
- 情节严重：50万-200万罚款，责令停业整顿、吊销执照

## 十四、中华人民共和国网络安全法（2025年修正）

**生效日期：** 2025年1月1日

**网络安全等级保护：**
| 等级 | 适用场景 |
|------|----------|
| 第一级 | 基础网络 |
| 第二级 | 重要系统 |
| 第三级 | 关键信息基础设施 |
| 第四级 | 极端重要系统 |
| 第五级 | 国防、极端重要系统 |

**关键信息基础设施保护：**
- 认定：公共通信和信息服务、能源、交通、水利、金融、公共服务、电子政务、国防科技工业等
- 保护：网络安全监测、应急响应、风险评估
- 采购审查：可能影响国家安全的须通过安全审查

**网络运营者义务：**
- 实名制
- 制定应急预案
- 安全技术措施
- 用户信息保护

**法律责任：**
- 网络运营者不履行安全保护义务：1万-100万罚款
- 关键信息基础设施运营者违规：10万-100万罚款
- 情节严重：100万-1000万罚款，责令停业整顿
