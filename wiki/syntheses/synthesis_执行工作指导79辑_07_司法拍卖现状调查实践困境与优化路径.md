## 核心观点

执行实践中，因为对拍品现状调查不充分而导致司法拍卖被撤销的案例时有发生，严重影响执行公信力。现状调查法律规定的制度供给不足、参照标准缺乏是造成困境的主要原因。应当从现状调查的困境入手，把握现状调查特征，探索集约化、专业化、清单式、条目式的现状调查方式方法。

## 一、现状调查环节的难点及原因

### （一）三大难点

1. **现状调查查什么**：规定过于原则，缺乏统一标准和规范性要求
2. **现状调查怎么查**：缺乏对如何进一步调查财产权属的明确规定
3. **查不到怎么办**：实践中面临的最大问题

### （二）原因分析

1. **权利登记信息管理不到位**：早期不动产信息未信息化管理、档案信息不一致、查询结果不全不准确
2. **权利登记信息混乱**：查封顺序混乱、抵押登记管理混乱
3. **未登记不动产控制情况混乱**：查封顺序难以确定、通知管理人难度大
4. **现状与登记状态差异**：买卖、租赁可能存在虚假情形；添附、结构变动难以判断
5. **欠缴税费情况查明难**：水电气非过户必须变更事项、税费缺乏统一公示查询制度

## 二、现状调查的具体事项

### （一）财产权属事项

**已办理登记财产的调查**：
- 不动产权属证书与不动产登记簿不一致的，以登记簿为准
- 不动产登记簿推定力只及于权利，不及于事实
- 应查明财产现状与登记簿记载内容是否一致

**未办理登记财产的调查**：
- 向发改、规划、建设等部门查询相关申报材料
- 结合土地使用权审批文件、规划许可、建设许可等确定权属

### （二）财产性质事项

1. 国有划拨用地使用权
2. 农村集体土地使用权（农用地、农村集体建设用地、未利用土地）
3. 农村集体建设土地上的不动产（农村宅基地、乡镇村企业建设用地、交通水利建设用地）
4. 农村土地承包经营权
5. "四荒"集体用地使用权
6. 违章建筑

### （三）权利负担事项

1. **建筑工程优先受偿权**
   - 权利主体：勘察人和设计人、转包分包承包人不享有；代建合同承包人享有
   - 优先效力排序：购房者债权>建设工程价款优先受偿权>抵押权>普通债权>发包人所有权
   - 行使条件：建设工程质量合格，无须合同有效、须建设工程宜折价拍卖

2. **国家税收优先权**：契税、印花税优先扣除；增值税、营业税由税务部门征缴

3. **土地使用权出让金优先权**：处置前须经批准，保证国家对土地出让金的优先受偿权

4. **不动产拆迁优先权**：可排除强制执行的权利

5. **抵押权调查**：查明登记的担保范围与合同约定的担保范围，依据相关规定认定

6. **租赁权调查**：确定是带租拍卖还是涤除租赁权拍卖

### （四）财产现状事项

| 事项 | 内容 |
|------|------|
| 位置结构情况 | 不动产的位置、面积、结构等 |
| 占有使用情况 | 实际占有使用主体、占有原因 |
| 装修装饰情况 | 装修状态、装饰状况 |
| 附属设施情况 | 设施配备情况 |
| 瑕疵情况 | 外观瑕疵、使用瑕疵、权利瑕疵 |

**重要建议**：现状调查应提前到财产调查控制阶段，建立现场查封制度，锁定查封时财产状态。

### （五）财产控制事项

1. 是否为首轮查封
2. 轮候查封的，首轮查封情况、在前轮候查封的单位名称及查封期间、查封范围
3. 动产实际占有使用主体及占有原因
4. 不动产占有使用主体及占有原因

**重要提示**：处置前应再次调查财产控制情况，确定是否有权处置。

## 三、破解路径

### （一）清单式现状调查事项表

将现状调查具体事项通过固定模板以表格形式呈现，由现场调查人员"照单办理"，既节省时间又不会遗漏。

### （二）全方位、专业化现状调查团队

1. **财产查控前的现状调查组**：
   - 坚持边进行财产查控、边进行现场调查
   - 有登记财产：调查登记档案信息和现场信息
   - 未登记财产：向管理人、保管人等了解情况

2. **财产处置专业化执行团队**：
   - 不动产处置团队：1名员额法官+x名执行员+x名司法辅助人员
   - 动产处置团队
   - 其他财产处置团队

### （三）现状调查事项部分外包

**外包事项**：
1. 拍卖标的视频或VR制作、照片拍摄、文字说明
2. 拍卖标的上传网络司法拍卖平台
3. 相关拍卖咨询
4. 引领现场看样及登记看样信息
5. 拍卖标的整理、清洁与保管

**外包要求**：
- 照片：单一小件每件不少于3张；不动产、汽车或船舶不少于10张
- 视频：无法用照片展示全貌的，时长不少于2分钟
- 资料应与案件执行过程形成的文书材料一并立卷归档

### （四）基层综治网格员协助机制

充分发挥基层综治网格员熟悉社情民意的优势，将协助执行工作纳入基层社会治安综合治理网格化管理，建立培训、监督、激励机制。

## 四、附件

附件包含四类财产的调查说明书模板：
1. 动产情况调查说明书（登记机动车）
2. 不动产情况调查说明书（工业厂房、土地）
3. 不动产情况调查说明书（住宅、商铺）
4. 动产情况调查说明书（无登记的动产）
