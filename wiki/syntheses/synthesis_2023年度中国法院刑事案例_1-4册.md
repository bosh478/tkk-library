## 汇编结构

本汇编共4册，按犯罪类型和专题分类：

### 第一册：犯罪、刑罚、证据、程序
- **一、犯罪**：罪与非罪的界分（含虐待致人死亡与故意伤害致人死亡的界分、拒执罪情节严重认定、套路贷认定等）
- **二、刑罚的具体运用**：量刑、数罪并罚、减刑
- **三、刑事证据**：零口供案件审查、间接证据运用
- **四、程序**：认罪认罚从宽、死刑案件程序

### 第二册：危害公共安全罪、破坏社会主义市场经济秩序罪
- **一、危害公共安全罪**：以危险方法危害公共安全罪与危险驾驶罪区分、醉驾、高速公路逆行追逐竞驶
- **二、破坏社会主义市场经济秩序罪**：
  - （三）妨害对公司、企业的管理秩序罪：非国家工作人员受贿、非法经营同类营业
  - （四）破坏金融管理秩序罪：高利转贷、骗取贷款、非法吸收公众存款
  - （五）金融诈骗罪：集资诈骗、信用卡诈骗、保险诈骗
  - （六）危害税收征管罪
  - （七）侵犯知识产权罪：假冒注册商标、侵犯著作权、侵犯商业秘密
  - （八）扰乱市场秩序罪：串通投标、合同诈骗、非法经营

### 第三册：侵犯公民人身权利民主权利罪、侵犯财产罪
- **一、侵犯公民人身权利、民主权利罪**：
  - 故意杀人罪（被害人对亲属实施暴力时杀害被害人可认定情节较轻）
  - 强奸罪（奸淫幼女采接触说、轮流奸淫的认定）
  - 猥亵儿童罪（公共场所当众猥亵情节恶劣认定）
  - 非法拘禁罪、虐待罪（严重的语言恐吓是否构成虐待）
- **二、侵犯财产罪**：
  - （一）抢劫罪（冒充军警抢劫加重情节认定、转化型抢劫既遂标准）
  - （二）盗窃罪（职务侵占与盗窃区分、盗窃文物后主动归还的处罚）
  - （三）诈骗罪（刑民交叉、套路贷、电信网络诈骗协助转账认定）

### 第四册：延续第三册财产犯罪及后续章节
- 敲诈勒索罪、故意毁坏财物罪等

## 核心司法观点摘录

### 一、罪与非罪界分

| 典型问题 | 裁判要旨 |
|----------|----------|
| 虐待致人死亡与故意伤害致人死亡的界分 | 对共同生活的家庭成员进行身体和精神上的伤害，致使家庭成员自杀，情节恶劣且属加重处罚情节，应以虐待罪从重处罚 |
| 拒执罪"情节严重"的司法认定 | 从执行标的种类、"有能力执行"的认定标准、"情节严重"的判定三方面综合判断 |
| 民间借贷纠纷与诈骗罪的界分 | 从欺骗内容、欺骗程度、欺骗结果三个维度分析被害人被骗行为与被告人虚构事实的因果联系 |
| 合同诈骗罪与民事欺诈的界分 | 行为人本身无履约能力且在签订合同时明知房屋已经被查封无法过户，仍欺骗被害人收取款项，可以认定具有非法占有故意 |

### 二、刑罚的具体运用

| 典型问题 | 裁判要旨 |
|----------|----------|
| 附条件不起诉被撤销后"新发现的罪"的认定 | 撤销附条件不起诉决定提起公诉处于行为人前罪缓刑考验期内的，应当撤销缓刑数罪并罚 |
| "套路贷"行为及金额的认定 | 应从整体上予以否定评价；犯罪成本和既、未遂诈骗金额分别确定 |
| 自首的认定 | 自动投案应当体现犯罪嫌疑人投案的主动性和自愿性；自首后未对其采取强制措施，刑事立案后逃避侦查的不能认定自首 |
| 累犯、漏罪、撤销缓刑与数罪并罚 | 缓刑考验期的意义及撤销；同种数罪应当并罚 |

### 三、刑事证据运用

| 典型问题 | 裁判要旨 |
|----------|----------|
| "零口供"案件审查要点 | 一是审查要点；二是运用间接证据构建证据体系 |
| "零口供"猥亵儿童案件 | 应实行宽松的印证规则 |
| 精神病人刑事责任能力认定 | 法官有对精神疾病司法鉴定意见进行审查、评判、取舍的职权；以证据为依据，综合判断 |

### 四、程序规则

| 典型问题 | 裁判要旨 |
|----------|----------|
| 认罪认罚从宽的实质审查 | 对事实证据的实质审查；对认罪认罚真实性的实质审查；对量刑建议的实质审查 |
| 死刑案件可适用认罪认罚 | 死刑案件可适用认罪认罚 |
| 程序违法发回重审 | 未经法庭调查和法庭辩论在判决书中超出指控范围增加从重量刑事实有违程序正当要求，二审宜发回重审 |

### 五、具体罪名认定要点

| 罪名 | 认定要点 |
|------|----------|
| 强奸罪（幼女） | 幼女为被害人时，强奸罪的认定应采接触说；年满七十五岁并非从轻或减轻处罚的当然理由 |
| 猥亵儿童罪 | "在公共场所当众猥亵儿童"不应轻易认定为"情节恶劣"；性侵未成年人案件中对证据及情节的认定 |
| 抢劫罪与敲诈勒索罪 | 抢劫罪的实质在于暴力行为使被害人彻底丧失财产处分意志自由，而非"两个当场"标准 |
| 非法吸收公众存款罪 | 自动投案时间应在行为人被司法管控之前；用资方的资金来源审查义务及帮助犯性质认定 |
| 侵犯公民个人信息罪 | 公民个人信息具备公共利益的属性；公益诉讼中"损害社会公共利益"应进行合理扩张解释 |
| 信用卡诈骗罪 | 窃取信用卡信息后用云闪付转走借贷资金定信用卡诈骗罪；冒用他人信用卡套现，被害人偿还后又透支产生的利息不应责令被告人退赔 |
| 帮助信息网络犯罪活动罪 | 与诈骗罪帮助犯的区分：明知程度判断 |
