## 一、电信网络诈骗犯罪司法解释体系

### （一）2016年意见（法发〔2016〕32号）核心要点

#### 1. 数额标准

| 量刑档次 | 诈骗数额 | 备注 |
|----------|----------|------|
| 数额较大 | 3000元以上 | 电信网络诈骗专属标准，全国统一无地域差别 |
| 数额巨大 | 3万元以上 | — |
| 数额特别巨大 | 50万元以上 | — |

二年内多次实施电信网络诈骗未经处理，诈骗数额累计计算。

#### 2. 酌情从重处罚情形（10种）

1. 造成被害人或其近亲属自杀、死亡或精神失常等严重后果
2. 冒充司法机关等国家机关工作人员实施诈骗
3. 组织、指挥电信网络诈骗犯罪团伙
4. 在境外实施电信网络诈骗
5. 曾因电信网络诈骗犯罪受过刑事处罚或二年内曾因电信网络诈骗受过行政处罚
6. 诈骗残疾人、老年人、未成年人、在校学生、丧失劳动能力人的财物，或诈骗重病患者及其亲属财物
7. 诈骗救灾、抢险、防汛、优抚、扶贫、移民、救济、医疗等款物
8. 以赈灾、募捐等社会公益、慈善名义实施诈骗
9. 利用电话追呼系统等技术手段严重干扰公安机关等部门工作
10. 利用"钓鱼网站"链接、"木马"程序链接、网络渗透等隐蔽技术手段实施诈骗

#### 3. "其他严重情节"/"其他特别严重情节"认定

诈骗数额接近"数额巨大""数额特别巨大"标准（80%以上），且具有上述10种情形之一的，分别认定为"其他严重情节"或"其他特别严重情节"。

#### 4. 犯罪未遂认定

发送诈骗信息5000条以上，或拨打诈骗电话500人次以上，或互联网发布诈骗信息页面浏览量累计5000次以上，认定为"其他严重情节"，以诈骗罪（未遂）定罪处罚。

数量达到相应标准10倍以上的，认定为"其他特别严重情节"。

#### 5. 关联犯罪全面惩处

- 非法使用"伪基站""黑广播"：扰乱无线电通讯管理秩序罪
- 出售、提供公民个人信息：侵犯公民个人信息罪
- 冒充国家机关工作人员：招摇撞骗罪，从一重处
- 非法持有他人信用卡：妨害信用卡管理罪
- 掩饰、隐瞒犯罪所得及其收益：掩饰、隐瞒犯罪所得、犯罪所得收益罪
- 网络服务提供者拒不履行信息网络安全管理义务：拒不履行信息网络安全管理义务罪
- 非法利用信息网络、帮助信息网络犯罪活动罪

#### 6. 共同犯罪认定

明知他人实施电信网络诈骗犯罪，提供下列帮助的，以共同犯罪论处：
- 信用卡、资金支付结算账户、手机卡、通讯工具
- 公民个人信息
- "木马"程序和"钓鱼软件"等恶意程序
- "伪基站"设备或相关服务
- 互联网接入、服务器托管、网络存储、通讯传输等技术支持
- 支付结算等帮助
- 改号软件、通话线路等服务（发现主叫号码被修改仍提供服务）
- 资金、场所、交通、生活保障等帮助
- 帮助转移诈骗犯罪所得及其产生的收益，套现、取现

#### 7. 案件管辖

- 一般由犯罪地公安机关立案侦查
- 犯罪地：犯罪行为发生地（包括网站服务器所在地、网站建立者管理者所在地、被侵害计算机信息系统所在地、犯罪嫌疑人被害人使用的计算机信息系统所在地、诈骗电话短信息电子邮件的拨打地发送地到达地接受地等）和犯罪结果发生地（包括被害人被骗时所在地、诈骗所得财物的实际取得地藏匿地转移地使用地销售地等）
- 最初发现地公安机关可以立案侦查
- 争议时由共同上级公安机关指定

### （二）2018年检察机关办案指引（高检发侦监字〔2018〕12号）核心要点

#### 1. 电信网络诈骗犯罪界定

以非法占有为目的，利用电话、短信、互联网等电信网络技术手段，虚构事实，设置骗局，实施远程、非接触式诈骗，骗取公私财物的犯罪行为。

**追诉标准低于普通诈骗犯罪，且无地域差别**：电信网络诈骗3000元以上即构成"数额较大"，而普通诈骗为3000元至10000元以上。

#### 2. 犯罪形态审查

- **既遂标准**：以被害人失去对被骗钱款的实际控制为既遂认定标准
- **特殊情形**：通过自助设备、第三方支付平台"延时到账""撤销转账"功能转账的，被害人并未完全失去控制，犯罪嫌疑人亦未取得实际控制，应认定为未遂

#### 3. 诈骗数额认定规则

1. 根据犯罪集团诈骗账目登记表、犯罪嫌疑人提成表等书证，结合言词证据认定
2. 结合被害人陈述认定被害人人数及诈骗资金数额
3. 不能简单将账户内款项全部推定为犯罪数额，须证明"违法所得"的排他性
4. **犯罪成本不能扣除**：购买作案工具、伪装道具、租用场地、交通工具、雇佣他人等诈骗成本不能从诈骗数额中扣除
5. **例外**：向被害人交付一定货币进而骗取信任并实施诈骗的，该部分货币可以从诈骗数额中扣除

#### 4. 发送信息、拨打电话次数认定

1. 拨出诈骗电话和接听被害人回拨电话均计入
2. 反复拨打、接听同一电话号码，以及反复向同一被害人发送诈骗信息的，累计计算
3. 被害人是否接听、接收不影响次数计算
4. 通过语音包发送的诈骗录音或通过网络工具辅助拨出的电话，认定为拨打电话
5. 发送信息条数和拨打电话次数不宜换算累加

#### 5. 主从犯认定

| 情形 | 认定 |
|------|------|
| 三人以上固定的犯罪组织 | 认定为犯罪集团 |
| 犯罪集团首要分子 | 按照集团所犯全部犯罪处罚 |
| 其余主犯 | 按照其所参与或组织指挥的全部犯罪处罚 |
| 被招募发送信息、拨打电话的人员 | 可认定为从犯，从宽处理 |
| 专门取款人 | 按其在共同犯罪中的具体作用认定，不宜一律认定为从犯 |

#### 6. 电子数据审查

**可采信的瑕疵电子数据**（经补正或合理解释）：
- 未以封存状态移送
- 笔录或清单上无签名或盖章
- 电子数据名称、类别、格式注明不清

**不能采信的电子数据**：
- 篡改、伪造或无法确定真伪
- 有增加、删除、修改等情形影响真实性

#### 7. 境外证据审查

- 来源：外交文件（国际条约、互助协议）、司法协助、警务合作
- 境外证据须经转换和固定才能作为证据使用
- 须附有来源、提取人、提取时间、提供人、提供时间等说明

### （三）2024年跨境电信网络诈骗意见核心要点

#### 1. 总体要求

- 坚持以人民为中心，坚持系统治理、依法治理、源头治理
- 依法重点打击：犯罪集团及其组织者、策划者、指挥者和骨干成员；为跨境电信网络诈骗等犯罪活动提供庇护的组织；犯罪集团实施的故意杀人、故意伤害、绑架、强奸、强迫卖淫、非法拘禁等犯罪行为；为招募成员而实施组织、运送他人偷越国（边）境的犯罪行为

#### 2. 犯罪集团认定

通过提供犯罪场所、条件保障、武装庇护、人员管理等方式管理控制犯罪团伙实施跨境电信网络诈骗、敲诈勒索等犯罪活动，抽成分红或收取相关费用，有明确的组织者、领导者，骨干成员基本固定，符合刑法第二十六条第二款规定的，认定为犯罪集团。

#### 3. 犯罪数额认定新规

- 确因客观条件限制无法查明被害人时，可依据账户交易记录、通讯群组聊天记录等证据，结合犯罪嫌疑人、被告人供述，综合认定犯罪数额
- 犯罪集团的犯罪数额，可根据其从管理控制的犯罪团伙抽成分红或收取费用的数额和方式折算

#### 4. 出境赴境外犯罪窝点的特殊认定

犯罪嫌疑人、被告人参加境外诈骗犯罪集团或犯罪团伙，犯罪数额均难以查证，但**一年内出境赴境外犯罪窝点累计时间30日以上或者多次出境赴境外犯罪窝点的**，认定为"其他严重情节"，以诈骗罪依法追究刑事责任。

**"犯罪窝点"认定**：实施电信网络诈骗犯罪活动的作案场所，以及为招募电信网络诈骗犯罪团伙而建设或入驻的主要是电信网络诈骗犯罪团伙的整栋建筑物、企业园区、产业园区、开发区等。

#### 5. 偷越国（边）境认定

以旅游、探亲、求学、务工、经商等为由申领出入境证件，但出境后即前往电信网络诈骗、敲诈勒索等犯罪窝点的，属于使用以虚假的出入境事由骗取的出入境证件出入国（边）境情形，应当认定为偷越国（边）境行为。

#### 6. 胁从犯认定

在境外受胁迫实施电信网络诈骗、敲诈勒索等犯罪活动的人员：
- 能够与外界保持自由联络，或被胁迫后又积极主动实施犯罪的，一般不认定为胁从犯
- 需要结合线索或材料进行调查核实，综合认定

#### 7. 自首从宽

主动或经亲友劝说后回国投案，并如实供述自己罪行的，认定为自首，依法可以从轻或减轻处罚。犯罪较轻的，可以免除处罚。

#### 8. 追赃挽损

- 全面调查、审查犯罪集团、犯罪团伙及其成员的财产状况
- 依法及时查询、查封、扣押、冻结涉案账户资金、房产、车辆、贵金属等涉案财物
- 犯罪嫌疑人、被告人逃匿境外或死亡，且通缉一年后不能到案或死亡的，依法没收违法所得及其他涉案财产

## 二、拐卖妇女儿童犯罪司法解释（法释〔2016〕28号）核心要点

### 1. "偷盗婴幼儿"认定

对婴幼儿采取欺骗、利诱等手段使其脱离监护人或者看护人的，视为《刑法》第二百四十条第一款第（六）项规定的"偷盗婴幼儿"。

### 2. 医疗机构等单位工作人员出卖儿童

医疗机构、社会福利机构等单位的工作人员以非法获利为目的，将所诊疗、护理、抚养的儿童出卖给他人的，以拐卖儿童罪论处。

### 3. 以介绍婚姻为名拐卖妇女

采取非法扣押身份证件、限制人身自由等方式，或者利用妇女人地生疏、语言不通、孤立无援等境况，违背妇女意志，将其出卖给他人的，以拐卖妇女罪追究刑事责任。

**注意区分**：以介绍婚姻为名，与被介绍妇女串通骗取他人钱财，数额较大的，以诈骗罪追究刑事责任。

### 4. 收买被拐卖妇女、儿童后的处理

- 收买被拐卖的妇女、儿童后又组织、强迫卖淫或组织乞讨、进行违反治安管理活动等构成其他犯罪的，数罪并罚
- 收买后又以暴力、威胁方法阻碍国家机关工作人员解救，或聚众阻碍解救的，构成妨害公务罪、聚众阻碍解救被收买的妇女、儿童罪，数罪并罚

### 5. 收买妇女"不阻碍返回"的认定

收买被拐卖的妇女，业已形成稳定的婚姻家庭关系，解救时被买妇女自愿继续留在当地共同生活的，可以视为"按照被买妇女的意愿，不阻碍其返回原居住地"。

### 6. 儿童年龄界定

《刑法》第二百四十条、第二百四十一条规定的"儿童"是指不满十四周岁的人。其中：
- 不满一周岁的为婴儿
- 一周岁以上不满六周岁的为幼儿

## 三、妇女权益保障司法保护（2023年最高检通知）核心要点

### 1. 检察职能全覆盖

- **支持起诉**：为受侵害妇女起诉提供帮助
- **行政检察监督**：涉及妇女合法权益的行政诉讼、行政非诉执行案件
- **公益诉讼检察**：妇女权益保护领域的检察公益诉讼（首次以列举方式列明监督具体情形）
- **惩治犯罪**：依法从严惩处侵犯妇女生命健康、人身自由、人格尊严等犯罪
- **司法救助**：为因案致困妇女提供救助帮扶

### 2. 打击重点

- 拐卖妇女儿童犯罪及收买犯罪
- 收买后发生的强奸、故意伤害、非法拘禁、侮辱、虐待等犯罪
- 强奸，强制猥亵、侮辱等性侵犯罪（性侵未成年人犯罪依法严惩）
- 涉家庭暴力或婚恋因素的虐待、故意伤害、故意杀人等犯罪
- 利用信息网络侮辱、诽谤妇女（符合刑法第二百四十六条第二款"严重危害社会秩序和国家利益"的，按公诉程序追诉）

### （三）拐卖妇女儿童犯罪认定要点

| 情形 | 认定 |
|------|------|
| 欺骗、利诱婴幼儿脱离监护人 | "偷盗婴幼儿"，适用《刑法》第240条第(六)项 |
| 医疗机构等单位工作人员以非法获利为目的出卖儿童 | 拐卖儿童罪 |
| 以介绍婚姻为名扣押证件、限制自由、违背妇女意志出卖 | 拐卖妇女罪 |
| 以介绍婚姻为名串通骗取钱财 | 诈骗罪 |
| 收买后组织强迫卖淫、组织乞讨等 | 数罪并罚 |
| 收买后阻碍解救 | 妨害公务罪/聚众阻碍解救被收买的妇女、儿童罪，数罪并罚 |
| 收买后形成稳定婚姻家庭关系，被买妇女自愿留下 | "不阻碍返回原居住地" |

## 五、侵犯公民个人信息刑事案件指引（2018）

### 5.1 "公民个人信息"认定

以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人身份或反映特定自然人活动情况的各种信息，包括：
- 姓名、身份证件号码
- 通信通讯联系方式
- 住址、账号密码
- 财产状况、行踪轨迹等

**企业工商登记信息**：手机、电话号码等由公司购买、使用的，不属于个人信息

### 5.2 "违反国家有关规定"认定

"国家有关规定"范围比"国家规定"更广，包括：
- 全国人大及其常委会制定的法律和决定
- 国务院制定的行政法规
- **部门规章**（金融、电信、交通、教育、医疗、统计、邮政等领域）

### 5.3 "非法获取"认定

"其他方法"包括：
- 购买（最常见）
- 收受
- 交换
- 履行职责/提供服务过程中违反国家规定收集

### 5.4 "情节严重"认定标准

| 信息类型 | 数量标准 |
|----------|----------|
| 行踪轨迹、通信内容、征信信息、财产信息（与人身财产安全直接相关） | 50条以上 |
| 住宿信息、通信记录、健康生理信息、交易信息等 | 500条以上 |
| 其他个人信息 | 5000条以上 |

**其他情节**：
- 违法所得5000元以上
- 曾因侵犯公民个人信息受过刑事处罚/2年内受过行政处罚
- 用于违法犯罪活动

### 5.5 "情节特别严重"认定

- 造成被害人死亡、重伤、轻伤
- 违法所得25万元以上
- 信息数量/违法所得达到"情节严重"标准的10倍以上

### 5.6 关联犯罪

| 罪名 | 适用情形 |
|------|----------|
| 诈骗罪共犯 | 事前通谋 |
| 非法利用信息网络罪 | 设立用于实施侵犯个人信息违法犯罪活动的网站、通讯群组 |
| 非法获取计算机信息系统数据罪 | 采用技术手段侵入合法数据库窃取信息 |

## 六、涉互联网金融犯罪案件座谈会纪要（2017）

### 6.1 非法吸收公众存款罪认定

**非法性认定**：未经有关部门依法批准

**变相自融情形**：
- 拆分融资项目期限
- 实行债权转让
- 为自己吸收资金

**主观故意认定**：
- 具有涉金融活动相关从业经历、专业背景可认定明知
- 规避监管的证据：签订虚假亲友关系确认书、更换宣传用语、夸大兑付能力等

### 6.2 集资诈骗罪认定

**非法占有目的认定**：
- 大部分资金未用于生产经营
- 资金使用成本过高
- 肆意挥霍造成资金缺口
- 归还本息靠借新还旧

### 6.3 资金支付结算犯罪

**非法经营罪**（刑法第225条第3项）：
- 无证经营网络支付业务
- 无证经营多用途预付卡

### 6.4 单位犯罪处理

- 分支机构犯罪：违法所得归分支机构所有并支配的，追究分支机构
- 上级单位追究：无法证明实际控制关系的，补充起诉

### 6.5 追赃挽损

最大限度减少投资人实际损失是办理涉互联网金融犯罪案件的重要工作。

## 七、性侵害未成年人刑事案件意见（2023）

### 5.1 性侵害未成年人犯罪范围

包括《刑法》规定的针对未成年人实施的：
- 强奸罪
- 负有照护职责人员性侵罪
- 强制猥亵、侮辱罪
- 猥亵儿童罪
- 组织卖淫罪、强迫卖淫罪
- 协助组织卖淫罪
- 引诱、容留、介绍卖淫罪
- 引诱幼女卖淫罪

### 5.2 "明知"认定

- 对不满12周岁的被害人实施性侵害 → 认定"明知"对方是幼女
- 对12-14周岁的被害人：从身体发育状况、言谈举止、衣着特征、生活作息规律等观察可能是幼女的 → 认定"明知"

### 5.3 "当众"认定

在校园、游泳馆、儿童游乐场、学生集体宿舍等公共场所对未成年人实施强奸、猥亵犯罪，只要有其他多人在场，不论在场人员是否实际看到 → 认定为"当众"强奸、猥亵

### 5.4 证据收集与审查

**一次询问原则**：尽可能避免多次反复询问，造成次生伤害

**同步录音录像**：询问未成年被害人应当进行全程不间断录音录像

**陈述采信**：未成年被害人陈述了非亲历不可知的细节，并且可以排除指证、诱证、诬告、陷害可能的 → 一般应当采信

### 5.5 未成年人保护措施

- **一站式办案救助机制**：设立专门场所，一次性完成询问、人身检查、生物样本采集、侦查辨认等取证工作
- **强制报告制度**：密切接触未成年人相关行业及其工作人员发现侵害须报告
- **准入查询制度**：建立性侵害违法犯罪人员信息库，协助开展信息查询

### 5.6 从严惩处情节

- 严格把握减刑、假释、暂予监外执行适用条件
- 纳入社区矫正的，应当严管严控
- 外国人在境内实施性侵害未成年人犯罪，可以附加驱逐出境
