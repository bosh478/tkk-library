## 一、专利纠纷案件司法解释

### 1.1 专利侵权判定

**等同特征认定：**
- 以基本相同的手段，实现基本相同的功能，达到基本相同的效果
- 手段是本领域普通技术人员无需经过创造性劳动就能够联想到的

**不视为侵权的情形：**
- 专利产品或者依照专利方法直接获得的产品，由专利权人或者经其许可的单位、个人售出后，使用、许诺销售、销售、进口该产品
- 在专利申请日前已经制造相同产品、使用相同方法或者已经作好制造、使用的必要准备，并且仅在原有范围内继续制造、使用
- 临时通过中国领土、领水、领空的外国运输工具，为运输工具自身需要而在其装置和设备中使用有关专利
- 专为科学研究和实验而使用有关专利
- 为提供行政审批所需要的信息而使用专利

### 1.2 赔偿数额计算

| 计算方式 | 适用情形 |
|----------|----------|
| 权利人实际损失 | 侵权人获利可以确定 |
| 侵权人获利 | 实际损失难以确定 |
| 参照许可费倍数 | 前两者难以确定 |
| 法定赔偿 | 权利人的损失、侵权人获利、许可费均难以确定 |

**法定赔偿限额：**
- 3万元以上500万元以下
- 赔偿数额应包括权利人为制止侵权所支付的合理开支

### 1.3 临时保护期费用

- 发明专利申请公布后至专利权授予前使用该发明未支付适当使用费的，专利权人可要求支付
- 专利权人可在专利权授予后请求支付

## 二、商标纠纷案件司法解释

### 2.1 商标侵权行为

**相同/近似商标认定：**
- 以相关公众的一般注意力为标准
- 既要进行对商标的整体比对，又要进行对商标主要部分的比对
- 判断时考虑请求保护注册商标的显著性和知名度

**类似商品/服务认定：**
- 以相关公众对商品或服务的一般认识综合判断
- 《类似商品和服务区分表》作为参考

### 2.2 在先权利保护

**在先权利类型：**
- 字号权
- 著作权
- 外观设计专利权
- 姓名权
- 肖像权
- 商品化权益

**恶意注册处理：**
- 损害他人在先权利
- 以不正当手段抢先注册他人已经使用并有一定影响的商标
- 代理人/代表人抢注
- 损害他人利益的其他情形

### 2.3 商标授权确权

**商标法第十条禁用条款：**
- 同中华人民共和国的国家名称、国旗、国徽、国歌、军旗、军徽、军歌、勋章等相同或者近似的
- 同外国的国家名称、国旗、国徽、军旗等相同或者近似的
- 同政府间国际组织的名称、旗帜、徽记等相同或者近似的
- 与表明实施控制、予以保证的官方标志、检验印记相同或者近似的
- 同"红十字"、"红新月"的名称、标志相同或者近似的
- 带有民族歧视性的
- 带有欺骗性，容易使公众对商品的质量等特点或者产地产生误认的
- 有害于社会主义道德风尚或者有其他不良影响的

**显著性和功能性：**
- 仅以商品自身形状、仅为获得技术效果而需有商品形状、使商品具有实质性价值的形状，不得注册

## 三、著作权纠纷案件司法解释

### 3.1 著作权侵权认定

**复制权控制范围：**
- 以印刷、复印、拓印、录音、录像、翻录、翻拍等方式将作品制作一份或者多份
- 不要求作品内容完全一致，只要实质性相似

**信息网络传播权：**
- 以有线或者无线方式向公众提供作品，使公众可以在其个人选定的时间和地点获得作品

### 3.2 著作权归属

**特殊作品归属：**
| 作品类型 | 著作权人 |
|----------|----------|
| 委托作品 | 有约定从约定；无约定归受托人 |
| 合作作品 | 合作开发者共同享有 |
| 影视作品 | 制片者享有著作权 |
| 职务作品 | 一般归作者；单位优先使用 |

### 3.3 赔偿数额

**计算顺序：**
1. 权利人实际损失
2. 侵权人违法所得
3. 权利使用费的合理倍数
4. 法定赔偿（500元至500万元）

## 四、商业秘密纠纷案件司法解释

### 4.1 商业秘密构成要件

**秘密性：**
- 不为所属领域知悉
- 不为普遍知悉和容易获得

**价值性：**
- 因具有商业价值
- 现实的或潜在的商业价值

**保密措施：**
- 签订保密协议
- 保密培训
- 设置保密区域
- 限制接触范围

### 4.2 侵权行为类型

**直接侵权：**
- 以盗窃、贿赂、欺诈、胁迫、电子侵入等方式获取
- 披露、使用、允许他人使用

**间接侵权：**
- 明知或应知商业秘密权利人的员工、前员工或其他单位、个人实施侵权行为，仍获取、披露、使用或者允许他人使用

### 4.3 赔偿数额

- 参照专利法赔偿计算方式
- 可适用惩罚性赔偿（故意侵权、情节严重）
- 赔偿数额应包括权利人为制止侵权所支付的合理开支

## 五、植物新品种权纠纷案件司法解释

### 5.1 保护范围

**授权品种保护：**
- 授权品种的繁殖材料
- 收获材料

**侵权认定：**
- 生产品种繁殖材料
- 为繁殖而进行处理
- 销售、许诺销售、进口、出口繁殖材料

### 5.2 侵权例外

- 科研活动
- 农民自繁自用（家庭联产承包责任制）
- 农民专业合作社

### 5.3 赔偿数额

- 实际损失
- 侵权所得
- 参照许可费
- 法定赔偿（50万元以下）
- 惩罚性赔偿（故意侵权、情节严重）

## 六、知识产权惩罚性赔偿

### 6.1 适用条件

**主观要件：**
- 故意侵权
- 情节严重

**客观要件：**
- 侵害多个知识产权
- 持续时间长
- 后果严重

### 6.2 赔偿倍数

- 一般为1-2倍
- 情节严重的，可达到3-5倍

### 6.3 计算基数

**依次按照下列顺序确定：**
1. 权利人实际损失
2. 侵权人获利
3. 权利使用费
4. 法定赔偿（500万元以下）

## 七、知识产权法庭裁判要旨

### 7.1 专利案件要点

**权利要求解释：**
- 主题名称对权利要求保护范围具有限定作用
- 封闭式权利要求通常不能适用等同侵权

**侵权认定：**
- 全面覆盖原则
- 等同侵权的判断标准
- 许诺销售侵权认定

### 7.2 商标案件要点

**混淆可能性：**
- 商品/服务类似程度
- 商标近似程度
- 原告商标显著性/知名度
- 实际混淆证据

### 7.3 著作权案件要点

**思想/表达二分：**
- 著作权不保护思想
- 只保护表达方式

**实质性相似：**
- 接触加实质性相似
- 整体观感法/抽象过滤法

## 八、适用要点汇总表

### 8.1 知识产权侵权赔偿计算顺序

| 顺序 | 计算方式 | 备注 |
|------|----------|------|
| 1 | 权利人实际损失 | 首选 |
| 2 | 侵权人获利 | 次选 |
| 3 | 参照许可费倍数 | 参考 |
| 4 | 法定赔偿 | 最后 |

### 8.2 惩罚性赔偿适用对照

| 要件 | 内容 |
|------|------|
| 主观 | 故意 + 情节严重 |
| 倍数 | 1-5倍 |
| 基数 | 实际损失/侵权获利/许可费/法定赔偿 |

### 8.3 知识产权案件管辖

| 案件类型 | 管辖法院 |
|----------|----------|
| 专利民事案件 | 知识产权法院/中级法院 |
| 专利行政案件 | 知识产权法庭（最高法院） |
| 商标民事案件 | 知识产权法院/中级法院 |
| 商标授权确权行政案件 | 北京知识产权法院 |
| 著作权案件 | 知识产权法院/中级法院 |
