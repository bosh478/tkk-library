## 一、人民检察院司法责任追究条例

### 1.1 责任追究范围

**应当追究司法责任的情形**：
- 故意违反法律法规
- 重大过失导致案件错误
- 严重侵犯当事人合法权益
- 造成恶劣社会影响

### 1.2 责任类型

| 责任类型 | 适用情形 |
|----------|----------|
| 纪律责任 | 违反纪律规定，情节较轻 |
| 政务责任 | 违反政务纪律 |
| 刑事责任 | 构成犯罪 |

### 1.3 责任追究程序

| 阶段 | 内容 |
|------|------|
| 受理 | 受理反映司法责任问题的举报、控告、申诉 |
| 调查 | 调查核实有关情况 |
| 认定 | 认定是否属于司法责任 |
| 处理 | 作出责任追究决定 |
| 救济 | 当事人可以申诉、复核 |

### 1.4 从轻、减轻情形

- 主动发现并纠正错误
- 有效避免损害后果发生
- 主动赔偿损失
- 其他可以从轻、减轻的情形

### 1.5 从重情形

- 故意违反法律法规
- 造成严重后果
- 毁灭、伪造证据
- 打击报复举报人、控告人

## 二、人民检察院听证员库建设管理指导意见

### 2.1 听证员库建立

**听证员库**是人民检察院组织听证活动的专业人才库，为检察听证提供专业支撑。

### 2.2 听证员条件

| 条件类型 | 具体要求 |
|----------|----------|
| 基本条件 | 品行良好、公道正派、热心公益 |
| 专业条件 | 具有相关专业知识或实践经验 |
| 其他条件 | 具有完全民事行为能力 |

### 2.3 听证员职责

- 参加听证会
- 发表听证意见
- 提供专业咨询
- 保守秘密

### 2.4 听证员管理

| 管理内容 | 说明 |
|----------|------|
| 选任程序 | 个人申请或组织推荐，检察院审核 |
| 聘期 | 一般为三年 |
| 考核 | 定期考核，动态管理 |
| 退出 | 违反规定可以取消资格 |

## 三、检察听证

### 3.1 听证案件范围

**应当组织听证的案件**：
- 羁押必要性审查案件
- 拟不批准逮捕案件
- 拟不起诉案件
- 刑事申诉案件
- 国家司法救助案件
- 民事、行政诉讼监督案件
- 其他需要听证的案件

### 3.2 听证程序

| 阶段 | 内容 |
|------|------|
| 公告 | 发布听证公告 |
| 选定 | 确定听证员 |
| 准备 | 告知当事人、准备材料 |
| 听证 | 听取各方意见 |
| 评议 | 听证员发表意见 |
| 决定 | 综合意见作出决定 |

### 3.3 听证意见效力

- 听证意见作为办案参考
- 人民检察院应当认真研究听证意见
- 采纳听证意见应当说明理由

## 四、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 司法责任追究 | 故意违反、重大过失→纪律/政务/刑事责任 |
| 听证员库 | 品行良好、公道正派、具有专业知识 |
| 听证范围 | 羁押必要性、不捕、不诉、申诉、司法救助 |
| 听证意见 | 作为办案参考，认真研究 |
