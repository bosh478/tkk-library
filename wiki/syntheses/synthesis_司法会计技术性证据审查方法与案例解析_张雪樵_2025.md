## 核心定义

**司法会计技术性证据审查**：对诉讼中司法会计鉴定文书、审计鉴证报告类文书证据进行程序性、实体性审查的方法论体系。

**常见误解**：司法会计鉴定只是财务审计。实际上，审计与司法会计鉴定在机构与人员资质、适用范围、工作程序、技术方法、意见类型等方面均有很大不同，不能等同视之。

## 七章结构与审查方法论

### 第一章 程序性审查

| 审查要点 | 内容 |
|----------|------|
| 委托主体适格性 | 启动鉴定的主体必须为司法机关、监察机关或有侦查权的部门 |
| 委托手续合法性 | 必须出具书面委托鉴定手续（鉴定聘请书/委托书） |
| 鉴定主体资质 | 鉴定机构资质（三大类管理模式）+ 鉴定人资质 |
| 鉴定主体资格审查 | 检察机关内设机构 vs 社会中介机构（会计师事务所） |
| 鉴定人参与程序 | 鉴定人必须亲自参与鉴定程序 |
| 鉴定文书形式要件 | 七项形式要件完整性 |
| 鉴定时限 | 审查是否在规定时限内完成 |

## 核心要点

### 1. "以审代鉴"问题

审计报告代替司法会计鉴定的情况大量存在，但两者存在本质差异：

| 差异维度 | 审计 | 司法会计鉴定 |
|----------|------|--------------|
| 机构资质 | 财政部门批准即可 | 需司法鉴定资质 |
| 人员资质 | 注册会计师 | 司法鉴定人资格 |
| 适用范围 | 经济管理活动 | 诉讼活动 |
| 工作程序 | 审计准则 | 司法鉴定程序通则 |
| 技术方法 | 允许询问、函证、抽样 | 不允许上述方法 |
| 意见类型 | 审计意见 | 鉴定意见 |

### 2. 委托主体适格性

根据《刑事诉讼法》第146条（1979-07-01 施行 / 2018-10-26 最新修正）、第148条，《人民检察院刑事诉讼规则》第332条、第334条，启动司法鉴定的主体必须是司法机关、监察机关或有侦查权的部门。

**典型案例**：某会计师事务所受涉案公司委托出具的审计报告，因委托主体不适格（温泉公司不是司法机关），不能作为定案证据。

### 3. 证据资格排除规则

根据最高人民法院《关于适用〈中华人民共和国刑事诉讼法〉的解释》第98条：
- 鉴定机构不具备法定资质 → **强制排除**
- 鉴定人不具备法定资质 → **强制排除**
- 鉴定程序违反规定 → **不得作为定案根据**

### 4. 四大类外鉴定管理模式

司法会计属于四大类（法医类、物证类、声像资料类、环境损害类）之外的鉴定门类，实行两种管理模式：
- 检察机关内设鉴定机构（最高检/省级检察院分级管理）
- 社会中介机构（会计师事务所、司法会计鉴定中心）

## 序言要点

司法会计专业正逐步实现两个转变：
1. 从传统的司法会计鉴定为主向以技术性证据审查并重转变
2. 从辅助侦查为主向以辅助审查起诉并重转变

**核心问题**：以审计报告代替司法会计鉴定（"以审代鉴"）——审计准则允许采用询问、函证、抽样等技术方法，允许采用证人证言、书面声明等非财务会计资料，而司法会计鉴定不允许采用上述方法或资料，两者结论可能完全不同。
