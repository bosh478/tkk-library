## 一、"套路贷"刑事案件意见核心要点

### （一）"套路贷"定义

"套路贷"是对以非法占有为目的，假借民间借贷之名，诱使或迫使被害人签订"借贷"或变相"借贷""抵押""担保"等相关协议，通过虚增借贷金额、恶意制造违约、肆意认定违约、毁匿还款证据等方式形成虚假债权债务，并借助诉讼、仲裁、公证或者采用暴力、威胁以及其他手段非法占有被害人财物的相关违法犯罪活动的概括性称谓。

### （二）常见犯罪手法

| 手法类型 | 具体表现 |
|----------|----------|
| 制造民间借贷假象 | 以"小额贷款公司""投资公司""咨询公司""担保公司""网络借贷平台"等名义对外宣传，以低息、无抵押、无担保、快速放款等为诱饵吸引被害人借款，以"保证金""行规"等虚假理由诱使被害人基于错误认识签订金额虚高的"借贷"协议 |
| 制造资金走账流水等虚假给付事实 | 故意制造银行转账痕迹或全部现金交付，刻意造成被害人已经取得合同所显示的全部款项的假象 |
| 故意制造违约或肆意认定违约 | 以设置违约陷阱、制造还款障碍等方式，或者肆意认定违约，造成被害人违约，或在还款后故意制造违约事由，恶意垒高借款金额 |
| 恶意垒高借款金额 | 在被害人无力支付"借款"时，介绍其他小额贷款公司或组织人员向被害人提供更高金额的"借款"，"以贷还贷"，层层转让 |
| 软硬兼施"索债" | 凭借诉讼地位优势，或通过暴力、威胁及其滋扰、纠缠等"软暴力"手段，向被害人或者被害人的特定关系人索取"债务" |

### （三）罪名认定

| 情形 | 定罪 |
|------|------|
| 未采用明显暴力或暴力威胁，主要靠虚构事实、隐瞒真相请求被害人交付财物 | 诈骗罪 |
| 采用暴力、威胁及其滋扰、纠缠等"软暴力"手段索取"债务" | 敲诈勒索罪 |
| 为强索"债务"而采用暴力、威胁等手段，符合抢劫罪构成要件 | 抢劫罪 |
| 三人以上为实施"套路贷"而组成的较为固定的犯罪组织 | 犯罪集团（首要分子按集团所犯全部罪行处罚） |

### （四）数额认定

"套路贷"的犯罪数额一般按照被害人实际收到的借款金额计算。制造资金走账流水等虚假给付事实的，按照犯罪数额认定。

## 二、"软暴力"刑事案件意见核心要点

### （一）"软暴力"定义

"软暴力"是指行为人为谋取不法利益或形成非法影响，对他人或者在有关场所进行滋扰、纠缠、哄闹、聚众造势等，足以使他人产生恐惧、恐慌进而形成心理强制，或者足以影响、限制人身自由、危及人身财产安全，影响正常生活、工作、生产、经营的违法犯罪手段。

### （二）"软暴力"典型表现形式

| 类别 | 具体表现 |
|------|----------|
| 滋扰 | 以吹哨子、跺地板、砸桌子、使用高频刺耳警报器等方法制造噪音干扰正常生活 |
| 纠缠 | 贴身紧跟、阻拦出行、纠缠不放 |
| 哄闹 | 在有关场所起哄闹事、强拿硬要 |
| 聚众造势 | 聚集多人壮大声势、以暴力方式震慑 |
| 其他 | 强占房屋、车辆，设置灵堂，披露隐私，跟踪滋扰等 |

### （三）"软暴力"罪名认定

| 罪名 | 适用情形 |
|------|----------|
| 寻衅滋事罪 | 追逐、拦截、辱骂、恐吓他人，或者强拿硬要、任意损毁、占用公私财物，严重破坏社会秩序 |
| 强迫交易罪 | 以暴力、威胁手段强迫他人接受服务或购买商品，情节严重 |
| 非法拘禁罪 | 限制他人人身自由 |
| 故意毁坏财物罪 | 故意毁损公私财物 |
| 敲诈勒索罪 | 以非法占有为目的，采用软暴力威胁索取财物 |

### （四）黑恶势力"软暴力"特征

1. **暴力程度隐蔽化**：不直接使用可见的暴力，而以"软暴力"方式规避法律
2. **组织化特征**：由黑恶势力组织实施或雇佣他人实施
3. **多次实施**：在一定区域或行业内多次实施
4. **造成心理强制**：足以使他人产生恐惧、恐慌进而形成心理强制

## 三、恶势力刑事案件意见核心要点

### （一）恶势力定义

恶势力是指经常纠集在一起，以暴力、威胁或者其他手段，在一定区域或者行业内多次实施违法犯罪活动，为非作恶，欺压百姓，扰乱经济、社会生活秩序，造成较为恶劣的社会影响，但尚未形成黑社会性质组织的违法犯罪组织。

### （二）恶势力认定标准

| 要素 | 具体要求 |
|------|----------|
| 人数 | 一般为3人以上，纠集者相对固定 |
| 时间 | 2年之内多次实施违法犯罪活动 |
| 手段 | 暴力、威胁或者其他手段 |
| 范围 | 一定区域或者行业内 |
| 次数 | 至少包括1次犯罪活动（可包含多次违法） |
| 后果 | 扰乱经济、社会生活秩序，造成较为恶劣的社会影响 |

### （三）不应认定为恶军团伙的情形

1. **单纯为牟取不法经济利益**而实施的"黄、赌、毒、盗、抢、骗"等违法犯罪活动，不具有为非作恶、欺压百姓特征的
2. 因本人及近亲属的**婚恋纠纷、家庭纠纷、邻里纠纷、劳动纠纷、合法债务纠纷**而引发的违法犯罪活动
3. **临时雇佣或被雇佣、利用或被利用以及受蒙蔽**参与少量恶势力违法犯罪活动的
4. 纠集时间明显较短，实施违法犯罪活动刚刚达到"多次"标准，尚不足以造成较为恶劣影响的

### （四）恶势力犯罪集团

恶势力犯罪集团是指符合恶势力全部认定条件，同时又符合犯罪集团法定条件的犯罪组织。

- **首要分子**：在恶势力犯罪集团中起组织、策划、指挥作用的犯罪分子
- **其他成员**：知道或者应当知道是为共同实施犯罪而组成的较为固定的犯罪组织，仍接受首要分子领导、管理、指挥，并参与该组织犯罪活动的犯罪分子

### （五）恶势力主要犯罪类型

**主要违法犯罪活动**：
- 强迫交易
- 故意伤害
- 非法拘禁
- 敲诈勒索
- 故意毁坏财物
- 聚众斗殴
- 寻衅滋事

**伴随实施的违法犯罪活动**：
- 开设赌场、组织卖淫、强迫卖淫
- 贩卖毒品、运输毒品、制造毒品
- 抢劫、抢夺
- 聚众扰乱社会秩序
- 聚众扰乱公共场所秩序、交通秩序
- 聚众"打砸抢"

## 四、黑恶势力刑事案件财产处置意见核心要点

### （一）总体要求

1. 在查明黑恶势力组织违法犯罪事实并对黑恶势力成员依法定罪量刑的同时，**全面调查**黑恶势力组织及其成员的财产状况
2. 依法对涉案财产采取**查询、查封、扣押、冻结**等措施
3. **彻底摧毁**黑社会性质组织的经济基础，防止其死灰复燃

### （二）涉案财产范围

| 类别 | 内容 |
|------|------|
| 黑恶势力组织的财产 | 组织全部财产 |
| 犯罪嫌疑人个人所有的财产 | 个人名下财产 |
| 犯罪嫌疑人实际控制的财产 | 实际支配的财产 |
| 犯罪嫌疑人出资购买的财产 | 以组织或个人名义购买的 |
| 犯罪嫌疑人转移至他人名下的财产 | 隐匿、转移的财产 |
| 洗钱及掩饰、隐瞒犯罪所得涉及的财产 | 关联犯罪财产 |
| 其他与黑恶势力组织及其违法犯罪活动有关的财产 | 资助财产等 |

### （三）财产处置方式

| 方式 | 适用情形 |
|------|----------|
| **追缴、没收** | 违法所得、违禁品、供犯罪所用的本人财物及其他等值财产 |
| **返还** | 被害人的合法财产 |
| **并处没收个人全部财产** | 组织者、领导者；确属骨干成员或为该组织转移、隐匿资产的积极参加者 |
| **依法决定财产刑** | 其他组织成员（根据参与次数、性质、地位、作用、违法所得数额、造成损失数额等） |

### （四）应当依法追缴、没收的财产

1. 黑恶势力组织及其成员通过违法犯罪活动或其他不正当手段聚敛的财产及其孳息、收益
2. 黑恶势力组织成员通过个人实施违法犯罪活动聚敛的财产及其孳息、收益
3. 其他单位、组织、个人为支持该黑恶势力组织活动资助或主动提供的财产
4. 黑恶势力组织及其成员通过合法的生产、经营活动获取的财产或者组织成员个人、家庭合法财产中，实际用于支持该组织活动的部分
5. 黑恶势力组织成员非法持有的违禁品以及供犯罪所用的本人财物
6. 其他单位、组织、个人利用黑恶势力组织及其成员违法犯罪活动获取的财产及其孳息、收益

### （五）恶意取得财产的追缴

应当依法追缴的情形：
- 第三人**明知**是违法犯罪所得而接受的
- 第三人**无偿**或者以**明显低于市场**的价格取得涉案财物的
- 第三人通过**非法债务清偿**或者**违法犯罪活动**取得涉案财物的
- 第三人通过**其他方式恶意取得**涉案财物的

### （六）等值财产追缴

有证据证明依法应当追缴、没收的涉案财产存在以下情形的，可以追缴、没收**其他等值财产**：
- 无法找到
- 被他人善意取得
- 价值灭失
- 与其他合法财产混合且不可分割

## 五、宽严相济刑事政策适用

### （一）总体政策

| 政策取向 | 适用对象 |
|----------|----------|
| **从严** | 恶势力的纠集者、恶势力犯罪集团的首要分子、重要成员、罪责严重的主犯 |
| **从宽** | 罪责相对较小、人身危险性相对不大、具有自首、立功、坦白、初犯等情节的其他成员 |

### （二）从严惩处措施

1. 严格掌握取保候审
2. 严格掌握不起诉
3. 严格掌握缓刑、减刑、假释
4. 严格掌握保外就医适用条件
5. 充分利用资格刑、财产刑等法律手段全方位从严惩处
6. 符合刑法第三十七条之一规定的，可以依法禁止其从事相关职业

### （三）从宽处理条件

- 共同犯罪中罪责相对较小
- 人身危险性、主观恶性相对不大
- 具有自首、立功、坦白、初犯等法定或酌定从宽处罚情节
- 认罪认罚或者仅参与实施少量的犯罪活动且只起次要、辅助作用
- 符合缓刑条件的，可以适用缓刑

## 六、虚假诉讼犯罪惩治意见（2021）

### 6.1 虚假诉讼罪认定

**行为方式**（刑法第307条之一）：

| 捏造事实类型 | 具体情形 |
|--------------|----------|
| 无中生有型 | 伪造证据、虚假陈述等手段捏造民事案件基本事实 |
| 恶意串通型 | 与他人恶意串通，捏造民事案件基本事实 |

**提起民事诉讼方式**：
- 提出民事起诉
- 申请宣告失踪/死亡、认定公民无民事行为能力/限制民事行为能力、认定财产无主、确认调解协议、实现担保物权、申请支付令、公示催告
- 增加独立诉讼请求、提出反诉
- 申请民事再审
- 申请执行仲裁裁决、公证债权文书
- 在民事执行中参与财产分配

### 6.2 "捏造事实"认定

**虚假诉讼罪与民事欺诈的区分**：
- 虚假诉讼罪：以捏造的基本事实提起诉讼
- 民事欺诈：隐瞒真相，使对方陷入错误认识

### 6.3 从重情节

- 多次实施虚假诉讼
- 严重损害他人合法权益
- 严重扰乱司法秩序
- 国家工作人员参与

### 6.4 罪名认定

| 行为 | 罪名 |
|------|------|
| 捏造事实提起民事诉讼 | 虚假诉讼罪 |
| 非法占有他人财产 | 诈骗罪（择一重处） |
| 逃避合法债务 | 诈骗罪（择一重处） |
| 非法干预他人生产经营 | 敲诈勒索罪（择一重处） |

### 6.5 程序规定

**管辖**：由虚假民事诉讼案件的受理法院所在地或执行法院所在地法院管辖

**证据标准**：除当事人陈述、证人证言外，一般应有物证、书证等证据印证

## 七、适用要点汇总表

### （一）概念区分

| 概念 | 特征 | 暴力程度 |
|------|------|----------|
| **套路贷** | 以借贷为名行诈骗之实，虚增金额、恶意垒高、软硬兼施索债 | 可软可硬 |
| **软暴力** | 滋扰、纠缠、哄闹、聚众造势等无形强制手段 | 隐蔽化、非直接 |
| **恶势力** | 3人以上、多次违法犯罪、为非作恶 | 暴力或软暴力 |
| **黑社会性质组织** | 较严密的组织、经济基础、控制影响 | 系统性暴力 |

### （二）罪名认定汇总

| 犯罪行为 | 定罪 |
|----------|------|
| 套路贷+虚构事实、隐瞒真相 | 诈骗罪 |
| 套路贷+软暴力索债 | 敲诈勒索罪 |
| 套路贷+暴力威胁索债 | 抢劫罪 |
| 软暴力+强拿硬要、任意损毁 | 寻衅滋事罪 |
| 软暴力+强迫交易 | 强迫交易罪 |
| 恶势力+3人以上固定组织 | 恶势力犯罪集团 |

### （三）财产处置要点

| 要点 | 内容 |
|------|------|
| 处置原则 | 与定罪量刑同时进行，全面调查财产状况 |
| 处置方式 | 追缴、没收、返还、财产刑 |
| 重点对象 | 组织者、领导者应并处没收个人全部财产 |
| 关联打击 | 深挖洗钱、掩饰隐瞒犯罪所得等关联犯罪 |

## 七、利用信息网络实施黑恶势力犯罪意见（2019）

### 7.1 网络黑恶势力犯罪认定

**利用信息网络威胁他人的处理**：
- 强迫交易，情节严重 → 强迫交易罪
- 索取公私财物，数额较大，或多次实施 → 敲诈勒索罪
- 辱骂、恐吓他人，情节恶劣，破坏社会秩序 → 寻衅滋事罪
- 编造虚假信息在信息网络散布，起哄闹事，造成公共秩序严重混乱 → 寻衅滋事罪

### 7.2 网络黑恶势力组织特征认定

**组织特征**：
- 违法犯罪的起因、目的
- 组织、策划、指挥、参与人员是否相对固定
- 组织形成后是否持续进行犯罪活动
- 有无明确的职责分工、利益分配机制
- 成员之间通过即时通讯工具、通讯群组、电子邮件、网盘等联络

**经济特征**：
- 有组织地通过实施违法犯罪活动或者其他手段获取一定数量的经济利益
- 用于违法犯罪活动或者支持该组织生存、发展

**行为特征**：
- 通过线上线下相结合的方式，有组织地多次利用信息网络实施违法犯罪活动
- 侵犯不特定多人的人身权利、民主权利、财产权利，破坏经济秩序、社会秩序

**危害特征（"一定区域或行业"）**：
- 危害行为发生地或者危害行业的相对集中程度
- 犯罪组织在网络空间和现实社会中的控制和影响程度

### 7.3 网络黑恶势力案件管辖

- 一般由犯罪地公安机关管辖（犯罪地管辖为主、被告人居住地管辖为辅）
- 公安机关可以依法并案侦查或指定下级公安机关管辖
- 跨国境犯罪案件管辖依照相关规定办理
