## 一、认罪认罚听取意见同步录音录像规定

### 1.1 适用范围

人民检察院办理认罪认罚案件，对于检察官围绕量刑建议、程序适用等事项听取犯罪嫌疑人、被告人、辩护人或者值班律师意见、签署具结书活动，**应当同步录音录像**。

### 1.2 录音录像内容

同步录音录像一般应当包含：
1. 告知犯罪嫌疑人、被告人、辩护人或者值班律师对听取意见过程进行同步录音录像的情况
2. 告知诉讼权利义务和认罪认罚法律规定，释明认罪认罚的法律性质和法律后果
3. 告知无正当理由反悔的法律后果
4. 告知认定的犯罪事实、罪名、处理意见，提出的量刑建议、程序适用建议并进行说明
5. 检察官听取意见，犯罪嫌疑人、被告人听取辩护人或者值班律师意见
6. 开示证据情况（如需要）
7. 签署具结书及辩护人或者值班律师见证情况
8. 其他需要录制的情况

### 1.3 录音录像要求

- 应当客观、全面反映参与人员、听取意见过程
- 画面完整、端正，声音和影像清晰可辨
- 保持完整、连续，不得选择性录制，不得篡改、删改
- 保存期限：**十年**

### 1.4 调取使用

- 因人民法院、犯罪嫌疑人、被告人、辩护人或者值班律师对认罪认罚自愿性、真实性、合法性提出异议或疑问，可以查阅
- 因案件质量评查、复查、检务督察等需要查阅，应当履行审批手续

## 二、认罪认罚案件量刑建议工作指导意见

### 2.1 量刑建议原则

- **宽严相济**：该宽则宽，当严则严
- **依法建议**：依照刑法、刑事诉讼法及司法解释
- **客观公正**：全面收集、审查各类证据
- **罪责刑相适应**：罚当其罪
- **量刑均衡**：同类案件量刑建议基本均衡

### 2.2 量刑建议条件

1. 犯罪事实清楚，证据确实、充分
2. 法定从重、从轻、减轻或者免除处罚等量刑情节已查清
3. 酌定从重、从轻处罚等量刑情节已查清

### 2.3 确定刑与幅度刑

| 类型 | 适用情形 |
|------|----------|
| **一般应当提出确定刑量刑建议** | 大多数案件 |
| **可以提出幅度刑量刑建议** | 新类型、不常见犯罪案件；量刑情节复杂的重罪案件 |

**幅度限制**：
- 6个月以上不满1年：不超过2个月
- 1年以上不满3年：不超过6个月
- 3年以上不满10年：不超过1年
- 10年以上：不超过2年
- 管制：不超过3个月

### 2.4 从宽幅度

认罪认罚从宽幅度的一般规则：

| 认罪认罚阶段 | 从宽幅度 |
|--------------|----------|
| 主动认罪认罚 | 优于被动认罪认罚 |
| 早认罪认罚 | 优于晚认罪认罚 |
| 彻底认罪认罚 | 优于不彻底认罪认罚 |
| 稳定认罪认罚 | 优于不稳定认罪认罚 |

认罪认罚从宽幅度一般**大于仅有坦白**，或者虽认罪但不认罚的从宽幅度。

### 2.5 从严情形

犯罪嫌疑人虽然认罪认罚，但具有下列情形之一的，从严把握从宽幅度或不予从宽：
- 危害国家安全、恐怖活动、黑社会性质组织犯罪的首要分子、主犯
- 犯罪性质和危害后果特别严重、犯罪手段特别残忍、社会影响特别恶劣
- 罪行较轻但具有累犯、惯犯等恶劣情节
- 性侵等严重侵害未成年人
- 其他应当从严的情形

### 2.6 量刑建议调整

**法院建议调整**：
- 人民法院认为量刑建议明显不当或认为异议合理，建议调整的
- 人民检察院应当认真审查，认为合理的应当调整

**被告人反悔**：
- 被告人签署具结书后反悔不再认罪认罚
- 人民检察院应当建议法院不再适用认罪认罚从宽制度，撤回从宽量刑建议

### 2.7 审判监督

- 法院违反规定未告知调整量刑建议而直接作出判决 → **应当以违反法定程序为由依法提出抗诉**
- 被告人仅以量刑过重为由上诉，因反悔致从宽量刑明显不当 → **应当依法提出抗诉**

## 三、认罪认罚案件监督管理办法

### 3.1 监督内容

- 量刑建议是否规范、适当
- 程序是否合法
- 听取意见是否充分
- 具结书签署是否自愿

### 3.2 监督方式

- 检察官联席会议会商咨询
- 部门负责人审核
- 检察长、检察委员会把关
- 人民监督员监督

### 3.3 责任追究

- 检察官故意违反法律或有关规定，导致量刑建议明显不当的，依规依纪追究责任
- 重大争议案件应当提交检委会讨论决定

```
侦查阶段 → 审查起诉阶段 → 审判阶段
   ↓            ↓              ↓
认罪认罚    提出量刑建议    法院采纳量刑建议
  听取意见    签署具结书     判决
             ↓
        同步录音录像
```

## 五、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 录音录像 | 全程记录听取意见和签署具结书，保存10年 |
| 量刑建议 | 一般为确定刑，幅度刑需严格控制 |
| 从宽幅度 | 主动>被动；早>晚；彻底>不彻底 |
| 具结书效力 | 无新事实新证据不得撤销 |
| 抗诉情形 | 未告知调整直接判决；被告人反悔上诉 |
