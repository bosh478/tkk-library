## 一、羁押必要性审查、评估工作规定

### 1.1 羁押必要性审查

人民检察院应当对羁押必要性进行审查：
- 犯罪嫌疑人、被告人被逮捕后
- 应当对羁押必要性进行审查
- 经审查不需要继续羁押的，应当建议有关机关予以释放或者变更强制措施

### 1.2 审查内容

| 审查因素 | 具体内容 |
|----------|----------|
| 案件情况 | 事实证据是否发生变化 |
| 社会危险性 | 是否仍然存在社会危险性 |
| 保障诉讼 | 能否保证诉讼顺利进行 |
| 健康状况 | 身体健康状况 |

### 1.3 评估程序

**启动方式**：
- 依职权主动审查
- 依申请审查

**审查方式**：
- 书面审查
- 听取意见
- 调查核实

### 1.4 审查结论

| 情形 | 处理方式 |
|------|----------|
| 不需要继续羁押 | 建议释放或变更强制措施 |
| 需要继续羁押 | 继续羁押，定期复查 |
| 案件情况变化 | 及时重新评估 |

## 二、国家司法救助工作细则

### 2.1 救助对象

**救助申请人**：
- 刑事案件被害人
- 被害人死亡或丧失行为能力的，其近亲属可以申请
- 举报人、证人、鉴定人因履行作证义务而遭受侵害的

### 2.2 救助条件

**应当予以救助**：
- 犯罪行为造成重伤、死亡的
- 犯罪行为造成重大财产损失且无法获得赔偿
- 刑事附带民事诉讼中无法获得赔偿
- 因举报、作证受到打击报复的

### 2.3 救助方式

| 方式 | 内容 |
|------|------|
| 支付救助金 | 主要救助方式 |
| 心理疏导 | 缓解心理创伤 |
| 法律援助 | 提供法律帮助 |
| 社会救助 | 协调社会救助 |

### 2.4 救助标准

- 根据当地经济社会发展水平确定
- 参照当地最低生活保障标准
- 综合考虑案件情况、救助对象实际需要

### 2.5 救助程序

| 阶段 | 内容 |
|------|------|
| 申请 | 救助申请人提出申请 |
| 审查 | 人民检察院审查 |
| 决定 | 作出是否救助决定 |
| 发放 | 发放救助金 |

### 2.6 救助监督

- 上级人民检察院监督下级人民检察院司法救助工作
- 审计部门审计
- 社会监督

| 要点 | 内容 |
|------|------|
| 羁押必要性审查 | 逮捕后持续审查，不需要的建议释放或变更 |
| 司法救助对象 | 被害人及近亲属、证人、鉴定人 |
| 救助条件 | 重伤死亡、财产损失无法赔偿、打击报复 |
| 救助方式 | 支付救助金、心理疏导、法律援助、社会救助 |
