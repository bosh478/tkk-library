# 执行工作指导

本页面汇总《执行工作指导》总第78辑（2021年第2辑）、总第79辑（2021年第3辑）的核心裁判观点与实务要点。

---

## 一、司法解释理解与适用

### 1.1 《最高人民法院关于人民法院强制执行股权若干问题的规定》的理解与适用

**股权执行四大难点**：冻结规则不明确、评估难、拍卖难、反规避执行难。

**股权冻结规则**：
- 冻结依据：公司章程、股东名册、公司登记机关登记信息、国家企业信用信息公示系统公示信息之一载明的股权均可冻结
- 冻结生效：向公司登记机关送达冻结裁定和协助执行通知书，在国家企业信用信息公示系统公示时发生法律效力
- 冻结顺位：多个法院冻结同一股权的，以公示系统先办理公示的为在先冻结

**股权处置参考价确定**：
- 应当委托评估机构评估
- 评估机构因缺少材料无法出具评估报告的，经申请执行人书面申请，可以进行"无底价拍卖"
- 无底价拍卖起拍价要适当高于执行费用，避免"无益拍卖"
- 公司经营严重异常、股权明显没有价值的（如空壳公司），不能适用无底价拍卖

**股权拍卖特殊情形**：
- 瑕疵出资、未届出资期限股权可以拍卖，拍卖后相关主体依照有关规定履行出资义务
- 自行转让受限的股权（如董监高持股）可以强制拍卖，但买受人仍须遵守限制转让规定
- 前置审批类股权：买受人在竞买成功后办理审批手续，未获审批的参照悔拍处理

**股权收益执行**：冻结股权并不当然及于股息、红利等收益。对收益的执行应当向股权所在公司送达冻结裁定，按债权执行规则处理。

## 二、最高人民法院案例与解析

### 2.1 债务人受让执行债权的抵销审查

**案件**：陈某玲、陈某峰、福建省丰泉环保集团有限公司与黄某民间借贷纠纷案（（2019）最高法民终218号）

**裁判要旨**：当债权人同时为多起执行案件的被执行人且资产状况陷入困难时，债务人以受让某一申请执行人对债权人享有的执行债权而主张抵销的，人民法院应采取审慎的态度审查抵销主张是否成立。

**核心规则**：
1. 诉讼中的抵销主张法院应予审查，不宜简单以"不属于同一法律关系"不予处理
2. 抵销权的行使不应损害第三人的合法权益
3. 抵销担保清偿目的的实现，应以确保债权平等、不损害其他平等主体合法利益为限
4. 债务人在明知债权人缺乏可供执行财产的情形下，受让债权并主张抵销的行为违反诚实信用原则
5. 通过参与分配程序实现债权，不能直接抵销

### 2.2 抵押权是否及于抵押财产被保全查封后租金的认定问题

**案件**：上海汉中皇国际物业管理有限公司与平安银行股份有限公司上海分行等执行复议案（（2020）最高法执复169号）

**裁判要旨**：抵押权人因债务人不履行到期债务而提起诉讼，在诉讼阶段申请保全查封了债务人之外的抵押人的抵押财产，之后又申请保全抵押财产自查封之日起的租金的，人民法院应予支持。

**核心规则**：
1. 《民法典》第412条的"扣押"包括对不动产的"查封"
2. 《民法典》第412条的"扣押"包括诉讼保全阶段的"扣押"
3. 抵押权作为一种非占有的担保，法定孳息的归属应在保护抵押权人和保护所有权人、占有人之间实现平衡
4. 抵押财产被法院保全扣押后，将抵押财产的租金收归抵押权人所有，有利于充分发挥抵押财产担保功能

## 三、地方法院案例与解析

### 3.1 对申请执行时效期间进行审查时应通知利害关系人参加审查程序

**案件**：北京百润世家贸易有限公司与保利龙马（天津）有限公司债权转让纠纷执行案

**裁判要旨**：判断执行时效是否存在中断的情形，不应简单地以执行依据确定的权利人是否行使了权利来判断。在"债权转让"情形下，债务人对债务承认，以及权利人主张权利等均构成时效中断。如果债权继受人未参加执行时效问题的审查，会直接影响对是否存在时效中断情形的审查判断，则应通知债权继受人作为利害关系人参加审查程序。

**核心规则**：
1. 执行时效中断的事由发生在当事人之间，具有相对性和特定性
2. 债权转让后，原权利人对债务承认构成时效中断
3. 权利继受人未能参加执行时效审查的，法院应依法追加其作为利害关系人参加审查
4. 将实际权利人引入执行程序，依据不同时段的实际债权人与债务人之间是否存在时效中断情形来判断

### 3.2 执行外和解协议部分履行能否阻却执行问题解析

**案件**：中国能源建设集团黑龙江省火电第一工程有限公司与新疆神火煤电有限公司承揽合同执行监督案

**裁判要旨**：执行依据发生法律效力后、尚未进入执行程序前，当事人签订的协议书属双方自行约定，不能当然发生阻却执行的效果。债务人未按协议约定履行全部付款义务，债权人有权按照执行依据确定的债务数额申请执行剩余案款本息。

**核心规则**：
1. 执行外和解协议不能当然发生阻却执行的效果
2. 执行外和解协议在性质上属于私法主体之间关于民事权利义务的安排，仅具有民事合同效力
3. 合法有效的执行外和解协议是双方当事人真实意思表示，债务人已履行部分的金钱债务应当作相应扣除
4. 债务人主张执行外和解协议已全部履行完毕从而阻却执行的，应当另行提起执行异议

### 3.3 "解冻+监管"善意执行支持企业复工复产

**案件**：华融资产管理公司与燕江国际大酒店执行异议案

**裁判要旨**：执行法院在保障申请人权益的前提下，可以对企业采取"活查封"等善意执行措施，支持企业复工复产。

**核心规则**：
1. 善意执行理念：在不影响债权实现的前提下，最大限度降低执行措施对企业正常经营的影响
2. "活查封"：对抵押的经营性房产交由企业继续使用，暂不进行评估拍卖处置
3. "解冻+监管"：有条件解除企业银行账户冻结，要求企业接受监管确保资金用于正常生产经营
4. 复工复产保障：对于有运营价值的企业，通过灵活的执行措施保障企业继续经营和员工就业

## 四、理论与争鸣

### 4.1 居住权异议之诉法律适用问题研究

**居住权分类**：
- 合同居住权、遗嘱居住权、判决居住权
- 登记居住权、未登记居住权（居住权期待权）
- 有偿居住权、无偿居住权

**居住权排除执行的裁判规则**：
| 类型 | 排除执行条件 |
|------|-------------|
| 合同居住权 | 已登记、设立在查封之前、主体为自然人、用于生活居住需要、期限未届满 |
| 遗嘱居住权 | 被继承人已死亡（不以登记为设立时间）、无未清偿债务 |
| 判决居住权 | 生效法律文书确认（未登记也可排除执行） |
| 居住权期待权 | 参照《异议复议规定》第28条物权期待权四要件 |

**与其他权利竞合**：
- 居住权与抵押权：先居后抵可以排除执行
- 居住权与查封权：先居后封应"带居拍卖"
- 居住权与租赁权：物权优于债权，但先租后居时不能排除对租赁权的执行

### 4.2 终本案件管理由混同到分类的实践转向

**核心观点**：
1. 现有混同管理模式导致终本结案标准把握不一、后续管理随意粗放、管理效能低下
2. 对终本案件进行分类管理是必要且可行的
3. 应厘清执行不能的概念，明确其构成要件，构建差异化的退出路径
4. 通过分类管理为终本库"瘦身""减负"，提升切实解决执行难的针对性与实效性
