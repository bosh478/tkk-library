## 一、核心概念框架：标准与非标准形态

本书以"标准与非标准"为界分标准，将受贿犯罪分为标准形态和非标准形态两类：

| 构成要件要素 | 标准形态 | 非标准形态 |
|------------|---------|-----------|
| **国家工作人员** | 国家工作人员本人直接收受 | 特定关系人收受、指定交付、共同犯罪 |
| **职务便利** | 本人职权（主管、负责、经手公共事务） | 利用隶属/制约的其他国家工作人员职权、利用职权地位形成的便利条件 |
| **谋取利益** | 实际为他人谋取利益 | 承诺谋取、明知他人有请托事项、感情投资型 |
| **收受财物** | 传统财物 | 财产性利益、商业机会、预期利益 |

**核心观点**：非标准形态是标准形态的变异，处于受贿罪构成要件的边缘区域，其认定需要在"穿透式功能主义"与"罪刑法定原则"之间保持平衡。

## 二、新型腐败和隐性腐败的四大特征

### 1. 腐败主体隐身化
国家工作人员躲在幕后，通过特定关系人（亲属、朋友、情妇等）作为"代理人"实施腐败，形成"办事的不收钱，收钱的不办事"模式。例如：通过妻子实际控制的公司进行权钱交易，通过多层代持人操控影子公司。

### 2. 行使职权间接化
不直接利用本人职权，而是利用职务影响力，通过打招呼、暗示等方式间接为请托人谋利，使职权与谋利之间的关联更加模糊。

### 3. 谋取利益主观化
请托人以"培养感情"为名赠送礼金，与官员建立"小圈子"，讲究心照不宣、心领神会；或离职后迅速进入相关企业担任高管，利用原有权力资源继续谋利（"期权腐败"）。

### 4. 收受财物隐蔽化
将利益输送与民事行为、市场经营行为混杂，通过借贷、合作经营、投资入股等手段掩盖腐败本质；贿赂从实物向虚拟货币、知识产权、数据信息等新型利益转变。

## 三、惩治难题

| 难题 | 表现 |
|------|------|
| **立案查处难** | 隐蔽性和伪装性强，犯罪呈非标准不典型特征，被告人辩解空间大，证据收集固定困难 |
| **司法认定难** | 民事行为与市场交易并存，违法和违纪界限不清；商业机会、股票基金、虚拟货币等价值"浮动"，性质认定和价值评估缺乏统一标准 |
| **法律适用难** | 现有法律多基于传统腐败模式设计，2007年"两高"出台司法解释后近20年未更新，新型隐性腐败行为未被明确纳入法律范畴 |

## 四、受贿犯罪主体非标准形态

### 特定关系人收财型受贿

**特定关系人范围**（《关于办理受贿刑事案件适用法律若干问题的意见》2007年）：
- 近亲属：夫、妻、父、母、子、女、同胞兄弟姊妹
- 情妇（夫）
- 其他共同利益关系人

**规制原理**：
1. 直接谋利、间接收财：国家工作人员与行贿人直接对接谋利事项，特定关系人收受财物
2. 间接谋利、间接收财：通过特定关系人居间转请托谋利并收受财物

**推定证明**：特定关系人收财型受贿犯罪的证明采用推定规则，国家工作人员"知道后未退还或者上交的"，应当认定具有受贿故意。

### 近亲属认定难点
- 近亲属范围严格按照《刑事诉讼法》和《监察法》认定（夫、妻、父、母、子、女、同胞兄弟姊妹）
- 儿媳、女婿、岳父母等特殊亲属需证明存在共同利益关系方可认定为特定关系人
- 近亲属以外的亲属认定特定关系人须证明经济利益和情感利益的共同依附

### 情妇（夫）认定标准
1. **关系的不正当性**：一方有配偶，双方建立非婚姻关系的男女亲密关系
2. **性和情感的二重关系**：有性关系为前提，同时有情感交流和依赖
3. **长期性和稳定性**：定期见面、密切联系、生活相互依赖
4. **经济利益关联**：有经济上的相互支持或依附

**关键判断**：情人关系隐蔽不公开不影响特定关系人认定；发生性关系次数少、联系少则不宜认定。

### 指定交付型受贿
- **指定交付第三人**：国家工作人员为他人谋取利益后，授意/安排行贿人将财物送给第三人
- **指定捐赠**：要求请托人向基金会、公益组织捐款
- **指定支付"公务"费用**：要求请托人支付所谓"公务费用"

**认定规则**：
1. 直接给予财物的，按《全国法院审理经济犯罪案件工作座谈会纪要》认定
2. 非直接给予财物、交付给特定关系人的，授意程度不需要很深
3. 非直接给予财物、交付给特定关系人以外第三人的，须权钱交易特征明显且国家工作人员具有明确受贿主观故意

## 五、职务便利非标准形态

### 1. 利用隶属、制约关系的其他国家工作人员职权
- **隶属关系**：直接隶属（上下级单位）、间接隶属
- **制约关系**：基于法律规定、基于职能分工、基于实质影响力

### 2. 利用"职权或者地位"形成的便利条件
- **下级对上级斡旋**：下级能否基于职权、地位影响认定斡旋受贿
- **关系密切的人斡旋**：近亲属、同学、朋友等密切关系人员之间
- **陌生人斡旋**：无工作联系的国家工作人员之间能否形成斡旋关系
- **承诺斡旋**：承诺未实施或被拒绝能否构成斡旋受贿
- **层层斡旋**：多名人员转请托情形

### 3. 利用非国家工作人员的职权
国家工作人员与行政管理对象之间制约关系的认定，第三方介入情形下利用私人关系的认定。

## 六、谋取利益非标准形态

### 感情投资型受贿
- **法律拟制**：《刑法》将超过一定数额的感情投资拟制为受贿
- **认定要件**：具有行政管理关系、"可能影响职权行使"、受请托前感情投资超过1万元、累计达到3万元

### 离职后收受财物
- "事先约定"的认定是难点
- 离职前后连续谋利且连续收受财物的行为评价

### "站台"行为
"站台"是否属于"利用职务便利谋取利益"须结合具体情形分析，谋利具有间接性。

## 七、收受财物非标准形态

| 类型 | 具体形式 |
|------|---------|
| **房屋** | 低买高卖、房产置换、虚假交易、定金定房、拖延付款、获取购房指标、购房返租 |
| **汽车** | 收受对象是车还是购车款、案发前主动还车 |
| **股份** | 干股（认缴制下价值认定）、分红型、以股票分红名义 |
| **虚拟货币** | 价值认定、数额认定、证据收集固定 |
| **以借为名** | 借房、借车、借钱 |
| **放贷收息** | 直接放贷、先借后贷、担保借贷 |
| **财物代持** | 钱款代持、股份代持、房产代持 |
| **合作投资** | 收受出资型、收受利润型、超额分红 |
| **挂名领薪** | 超额领薪、领取奖金、突击入职 |
| **赌博型受贿** | 与赌博活动的区分、审查认定 |
| **炒股型受贿** | 让他人代炒股、自己代他人炒股、向他人推荐股票 |
| **财产性利益** | 代币卡（券）、免费服务、债权免除、无息借款、提供信息 |
| **商业机会** | 收受商业机会入罪的原理与条件（权力对价性、高预期性、价值可量化性） |
| **预期利益** | 涉上市公司原始股、预期分红、承诺高收益理财；须从权力对价性、可预期性、利益确定性、高收益性、低风险性五个方面把握 |

## 八、财产性利益扩张的谦抑性要求

作者主张在肯定贿赂范围扩张到财产性利益的同时，要**谨慎适度谦抑**，对远期性利益（预期利益）从以下五个方面把握：
1. 权力对价性
2. 可预期性
3. 利益确定性
4. 高收益性
5. 低风险性

防止财产性利益的过度扩张，避免"虚置受贿罪的构成要素而完全架空刑法条文"，导致"没有边际的司法犯罪化结果"。
