# 2024《公司法释义》王翔·法工委

## 概述

本书是全国人大常委会法制工作委员会组织编写的公司法释义，由王翔主编，中国法制出版社2024年3月出版，是《公司法》（2023年12月29日修订）权威释义。

全书共266条（第一章至第十三章），涵盖：公司设立与登记、组织机构、股权转让、股份发行转让、国家出资公司、董事监事高级管理人员义务、公司债券、财务会计、合并分立增资减资、解散清算、外国公司分支机构、法律责任、附则。

---

## 核心修订要点

### 一、立法目的与适用范围（第1-2条）

**立法目的**（第1条）：
1. 规范公司的组织和行为
2. 保护公司、股东、职工和债权人的合法权益
3. 完善中国特色现代企业制度，弘扬企业家精神
4. 维护社会经济秩序，促进社会主义市场经济的发展

**公司形式**（第2条）：仅规定有限责任公司和股份有限公司两种形式

### 二、公司法人资格与股东责任（第3-4条）

- 公司是企业法人，有独立的法人财产，享有法人财产权
- 公司以其全部财产对公司的债务承担责任
- **股东有限责任**：有限责任公司股东以认缴出资额为限；股份有限公司股东以认购股份为限
- 股东对公司依法享有资产收益、参与重大决策和选择管理者等权利

### 三、法定代表人制度改革（第10-11条）

**重大变化**：
1. **扩大可担任法定代表人的人员范围**：由"董事长、执行董事或经理"扩展为"代表公司执行公司事务的董事或经理"
2. **取消执行董事概念**：法定代表人不再限于董事长或执行董事
3. **明确辞任后果**：担任法定代表人的董事或经理辞任的，视为同时辞去法定代表人
4. **30日选任期限**：法定代表人辞任的，公司应在30日内确定新的法定代表人
5. **职权限制**：公司章程或股东会对法定代表人职权的限制，不得对抗善意相对人

### 四、公司法人人格否认制度（第23条）

**三种情形**：
1. 股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的 → 承担连带责任
2. 股东利用其控制的两个以上公司实施上述行为的 → 各公司对任一公司的债务承担连带责任
3. 只有一个股东的公司，股东不能证明公司财产独立于股东自己的财产的 → 承担连带责任

### 五、公司治理结构改革（第67-69条）

**审计委员会与监事会选择设置**：
- 有限责任公司可以设审计委员会（由董事组成）代替监事会
- 股份有限公司可选择设审计委员会代替监事会
- 审计委员会成员不得少于3人
- 职工人数300人以上的，董事会成员中应有职工董事

### 六、股权转让规则（第84-90条）

**有限责任公司**：
- 股权自愿转让：股东之间可以自由转让；向股东以外的人转让，应当经其他股东过半数同意（其他股东有优先购买权）
- 强制转让：人民法院强制执行股权时，其他股东有优先购买权
- 出资责任：转让股权后，转让股东仍有义务承担未届期出资责任

### 七、股份公司类别股制度（第143-146条）

| 类别 | 内容 |
|------|------|
| 面额股/无面额股 | 可选择发行面额股或无面额股 |
| 类别股权利 | 类别股股东权利可差异化设计（如优先分配利润、优先分配剩余财产） |
| 章程记载 | 发行类别股的公司章程应载明类别股股份数及其权利义务 |
| 分类表决 | 特定事项须经类别股股东分类表决 |

### 八、股份回购制度（第162条）

**允许回购的情形**：
1. 减少公司注册资本
2. 与持有本公司股份的其他公司合并
3. 将股份用于员工持股计划或者股权激励
4. 股东因对股东会作出的公司合并、分立决议持异议，要求公司收购其股份
5. 将股份用于转换上市公司发行的可转换为股票的公司债券
6. 上市公司为维护公司价值及股东权益所必需

**限制**：不得超过已发行股份总额的10%，三年内转让或注销

### 九、公司社会责任（第20条）

公司应当充分考虑公司职工、消费者等利益相关者的利益以及生态环境保护等社会公共利益，承担社会责任。国家鼓励公司参与社会公益活动，公布社会责任报告。

### 十、简易注销与强制注销制度（第240-241条）

**简易注销**：对未开业或无债权债务的公司实行简易注销程序（提交全体股东承诺书+公告）

**强制注销**：对成立后无正当理由超过6个月未开业的，或开业后自行停业连续6个月以上的公司，可强制注销公司登记

### 十一、控股股东、实际控制人责任（第192条）

**控股股东、实际控制人指示责任**：公司的控股股东、实际控制人指示董事、监事、高级管理人员从事损害公司或股东利益的，与该董事、监事、高级管理人员承担连带责任。

### 十二、上市公司特别规定（第134-141条）

- 上市公司须设独立董事
- 上市公司董事会可设审计委员会
- 披露股东和实际控制人信息，禁止股票代持
- 上市公司与控股子公司不得交叉持股

### 十三、国家出资公司特别规定（第168-179条）

| 要点 | 内容 |
|------|------|
| 适用范围 | 国家出资的国有独资公司和国有资本控股公司 |
| 党的领导 | 坚持党的领导，写入公司章程 |
| 出资人职责 | 由履行出资人职责的机构履行 |
| 组织机构 | 国有独资公司不设股东会，由履行出资人职责的机构行使股东会职权 |
