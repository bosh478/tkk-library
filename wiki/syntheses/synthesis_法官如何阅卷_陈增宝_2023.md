## ❓ 常见问题

> 问：阅卷的主要功能是什么？
> 答：四大功能——掌握证据熟悉案情、简化卷宗方便办案、发现疑点精准审查、确定思路明确方向。

> 问：阅卷的主要任务是什么？
> 答：三大任务——逐一审读吃透案情、既审事实又审法律、立足案情延伸案外。

> 问：如何选择阅卷形式？
> 答：根据案件类型选择——承办法官单独阅卷（庭前/庭上/庭后）、合议庭成员共同阅卷（分工/交叉）、全面阅卷与重点阅卷相结合。

## 章节结构

### 引论：以认知为基础的司法裁判

**从法律形式主义到法律现实主义**：
- 认知因素否定论：法律形式主义的主张
- 认知因素肯定论：法律现实主义的观点
- 法官如何认知案件事实：法律心理学视角
- 司法过程中的阅卷："输入"案件事实信息的重要渠道

### 第一讲：案卷的品性与构成

**专题一：案卷的唯一性与裁判的稳定性**
- 侦查机关、检察机关向法院全面移送案卷材料的重要性
- 一审法院向二审法院全面移送案卷材料的重要性
- 公诉人及法官向辩护律师全面移送案卷材料的重要性

**专题二：案卷材料的构成**

| 类别 | 内容 |
|------|------|
| 证据材料 | 物证、书证、证人证言、被告人供述等 |
| 法律文书 | 起诉书、判决书、裁定书等 |
| 控辩双方意见 | 辩护词、公诉意见、专家意见书等 |
| 其他材料 | 补查补证材料等 |

**专题三：司法认知的不同指向**
- **事实指向**：对案卷的认知、对现场的认知、对庭审的认知、对证言的认知
- **法律指向**：不同人对同一法条有不同认知结果
- **社会指向**：法官对社会的认知

**专题四：案卷的认知特点**
- 案卷材料的多少影响认知范围
- 案卷材料的装订排列影响认知效率
- 案卷材料的建构性影响认知真实性

### 第二讲：阅卷的功能与任务

**专题一：阅卷的功能**

**四大功能**：

| 功能 | 说明 |
|------|------|
| 掌握证据熟悉案情 | 了解证据物理状况、定案证据状况、量刑证据状况 |
| 简化卷宗方便办案 | 为提讯、庭审、汇报提供依据 |
| 发现疑点精准审查 | 发现身份疑点、侦破疑点、证据疑点、量刑疑点 |
| 确定思路明确方向 | 为庭前准备、庭审质证、案件审理指明方向 |

**专题二：阅卷的主要任务**

**任务一：逐一审读、吃透案情**
- 审查核实被告人基本情况（户籍、强制措施、受审能力、辩护人、赔偿能力）
- 审查核实案件侦破情况及抓获经过
- 审查核实案件管辖（犯罪地、居住地、共同管辖）
- 审查把握控辩双方主要意见
- 审查核实犯罪事实及认定依据

**任务二：既审事实、又审法律**
- 以事实为重心：在事实指引下寻找规范
- 以规范为重心：在规范指引下认定事实（"建构"事实、"筛选"事实）
- 彼此互为重心：事实建构与规范发现交错进行（设证、类比、解释）

**任务三：立足案情、延伸案外**
- 了解被告人方面的信息
- 了解被害人方面的信息
- 了解诉讼原因与动机
- 了解有无调解可能
- 了解是否存在外部干预
- 了解案件处理的社会效果

### 第三讲：阅卷的形式与种类

**专题一：承办法官单独阅卷**

| 阶段 | 特点 | 重点 |
|------|------|------|
| 庭前阅卷 | 全面了解案情 | 形成初步"阅卷看法" |
| 庭上阅卷 | 以必要为条件 | 突出重点，不影响听审 |
| 庭后阅卷 | 全面性+精准性 | 针对疑点、争点、重点 |

**专题二：合议庭成员共同阅卷**

**分工阅卷**：
- 按罪名分工
- 按犯罪事实分工
- 按被告人分工

**交叉阅卷**：
- 打破承办法官对案情信息的垄断
- 全面准确落实司法责任制
- 防止案件决策"一言堂"
- 适用案件：死刑案件、证据存疑案件、争议较大案件

**专题三：全面阅卷与重点阅卷**

**按顺序逐一阅卷**：
- 逐卷阅读和审查
- 逐份阅读和审查
- 逐罪阅读和审查

**按内容重点阅卷**：
- 围绕定案根据确定重点
- 围绕犯罪构成要件确定重点
- 围绕争议焦点确定重点

**按任务补充阅卷**

**按疑点反复阅卷**：
- 被告人身份疑点
- 案件侦破疑点
- 定罪量刑证据疑点

**专题四：程序性审查与实质性审查**

**程序性问题审查**：
- 案件来源状况
- 被告人自然状况
- 时间及强制措施状况
- 证据收集状况

**实体性问题审查**：
- 主观性证据的实质性审查
- 客观性证据的程序性审查

### 第四讲：阅卷的技巧与方法

**专题一：全貌意识——如何坚持全面阅卷**
- 审阅全部卷宗材料，不遗漏每一页
- 增强宏观意识，尽量恢复案件原貌
- 善于整体性考虑，遵循逐一审查与综合判断相结合
- 透过现象看本质，不被表象迷惑

**专题二：关键行为决定定性**
- 主干行为决定定性
- 目的行为决定定性
- 关键手段决定定性

- 直接证据与间接证据的印证关系

- 证据链的完整性审查

## 核心内容

### 一、案卷的认知规律

**认知特点**：
1. 案卷材料的多少影响认知范围——材料越多，认知越全面
2. 装订排列影响认知效率——合理排列提高效率
3. 建构性影响认知真实性——法官不是被动接收，而是主动建构

**认知指向**：
- 事实指向：对案件事实的认知
- 法律指向：对法律规范的认知
- 社会指向：对社会背景的认知

### 二、阅卷的核心方法

**"三审"法**：
1. **审事实**：逐一审读，吃透案情
   - 核实被告人基本情况
   - 核实侦破及抓获经过
   - 核实犯罪事实及证据
2. **审法律**：既审事实又审法律
   - 以事实为重心寻找规范
   - 以规范为重心认定事实
   - 事实与规范交错进行
3. **审案外**：立足案情延伸案外
   - 了解当事人背景
   - 了解诉讼原因动机
   - 了解社会效果

**证据审查要点**：

| 证据类型 | 审查重点 |
|----------|----------|
| 被告人供述 | 变化情况、与在案证据印证 |
| 证人证言 | 与客观性证据印证、证人关系 |
| 物证书证 | 来源合法性、保管链条 |
| 鉴定意见 | 鉴定资质、程序合法性 |
| 电子数据 | 提取方法、完整性验证 |

### 三、阅卷笔录的制作

**功能**：
- 固定阅卷成果
- 作为审查报告草稿
- 为庭审质证做准备

**制作方法**：
- 按证据种类分类摘录
- 标注证据页码便于查找
- 记录疑点和问题
- 形成初步分析意见

### 四、特殊案件的阅卷要点

**死刑案件**：
- 必须交叉阅卷
- 重点审查证据确实充分性
- 排除一切合理怀疑

**经济犯罪案件**：
- 关注资金流向
- 审查电子数据
- 核实审计报告

**多人多罪案件**：
- 按被告人分工阅卷
- 逐罪审查证据
- 注意共犯供述的印证
