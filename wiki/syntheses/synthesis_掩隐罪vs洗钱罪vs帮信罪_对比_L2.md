# 掩隐罪 vs 洗钱罪 vs 帮信罪·三罪对比 L2

> **适用版本**：2025 年最高人民法院《掩饰、隐瞒犯罪所得、犯罪所得收益刑事案件具体应用法律若干问题的解释》+ 2024 年《帮信意见》+ 2024 年《医保骗保指导意见》+ 2024 年《洗钱刑事案件解释》
> **对比来源**：罗国良庭长 2025-09-17 前沿法评（人民法院报）+ 刑事审判参考第 132 辑第 1488 号林友谊案 + 安徽 2024 帮信罪量刑细则

## 一、对比概览（核心速查表）

| 维度 | **掩隐罪**（《刑法》第 312 条） | **洗钱罪**（《刑法》第 191 条） | **帮信罪**（《刑法》第 287 条之二） |
|------|--------------------------------|--------------------------------|----------------------------------|
| **章节归属** | 第六章第二节（妨害司法罪）· 赃物犯罪 | 第三章第四节（破坏金融管理秩序罪）· 特别法 | 第六章第一节（扰乱公共秩序罪）· 帮助信息网络犯罪 |
| **上游犯罪范围** | **任何犯罪类型**的所得 | 仅限 **7 类上游**（毒品 / 黑社会组织 / 恐怖活动 / 走私 / 贪污贿赂 / 破坏金融管理秩序 / 金融诈骗）的所得及其收益 | 网络犯罪（被帮对象的实施对象是网络犯罪） |
| **主观明知内容** | **明确具体**——明知是他人实施犯罪后获得的**赃款 / 赃物** | **明确具体**——明知是 7 类上游犯罪**所得及其产生收益的来源和性质** | **相对概括**——知道或应当知道**他人利用信息网络实施犯罪**，对资金与上游犯罪关联性的认知是**笼统的、不甚明确** |
| **主观恶性梯度** | 中性偏重 | 严重（金融领域） | 较轻（边缘 / 片面帮助） |
| **典型行为方式** | 窝藏 / 转移 / 收购 / 代为销售 / 转账 / 取现 / 套现 / 提供资金账户 | 提供资金账户 / 财产转换 / 转账 / 跨境转移 / 其他掩饰方法 | 提供互联网接入 / 服务器托管 / 网络存储 / 通讯传输 / 广告推广 / 支付结算 / 其他技术支持 / 帮忙办卡 / 拉人头等 |
| **罪名性质** | 一般赃物犯罪（下游犯罪） | 特别法 / 特别罪名 / 涉外洗钱 | 边缘 / 片面帮助（既不构成上游共犯，也不属于洗钱） |
| **罪名核心特征** | "**事后掩饰赃物 / 赃款**" | "**为 7 类上游犯罪**特定漂白" | "**为网络犯罪**提供**工具性帮助**" |

## 二、量刑对比

| 罪名 | 第一档（基本刑） | 第二档（情节严重） |
|------|------------------|--------------------|
| **掩隐罪（第 312 条）** | 三年以下有期徒刑 / 拘役 / 管制，并或单处罚金 | **三年以上七年以下**有期徒刑，并处罚金（数额标准：上游非法采矿等 500 万 / 其他犯罪 50 万 + 情节） |
| **洗钱罪（第 191 条）** | 三年以下有期徒刑 / 拘役 / 管制，并或单处罚金 | **三年以上七年以下**有期徒刑，并处罚金（数额标准：500 万 / 多次实施 / 拒不配合追缴 / 造成损失 250 万以上） |
| **帮信罪（第 287 条之二 安徽细则）** | 三年以下有期徒刑 / 拘役，并或单处罚金（10 项入罪触发项） | 视具体罪与数罪并罚 |

**量刑梯度共识**：三罪基本刑相当（三年以下），但认定范围和主观门槛不同。

## 三、定性核心：三句话分流

### 3.1 第一句分流——上游范围决定罪名适用优先级

```
      上游属于 191 条 7 类之一？
                │
       ┌────────┴────────┐
       │YES              │NO
       ↓                 ↓
   洗钱罪           （进入第二层分流）
   （特别法）           │
                       ↓
                行为针对赃款赃物？
                并明知是犯罪所得？
                       │
                ┌──────┴──────┐
                │YES          │NO
                ↓             ↓
            掩隐罪       （进入第三层分流）
            （赃物罪）       │
                              ↓
                       是否提供网络工具帮助
                       而明知他人利用信息网络实施犯罪？
                              │
                       ┌──────┴──────┐
                       │YES          │NO
                       ↓             ↓
                   帮信罪        不构罪 / 其他
                   （片面帮助）
```

### 3.2 第二句分流——"明知"内容性质决定掩隐 / 帮信

**掩隐罪"明知"要素**：
- ✅ **明确具体**：知道是"赃款 / 赃物"
- ✅ **特定对象认知**：知道是他人实施**特定犯罪**所获
- ✅ **核心环节**：行为人在赃款转移 / 掩饰环节起核心作用

**帮信罪"明知"要素**：
- ⚠️ **概括认知**：知道"可能被用于涉犯罪资金"，但对资金与上游犯罪关联性认识**笼统、不甚明确**
- ⚠️ **边缘 / 片面帮助**：既不构成上游犯罪共犯，也不属于洗钱犯罪
- ⚠️ **底端地位**："卡农" / "卡商" / 技术工具提供人

> 实务陷阱："有些案件行为人是否符合帮信罪的'明知'都存疑，却因为达不到帮信罪入罪所要求的'情节严重'，而被拔高认定为掩隐罪的'明知'，造成'**出了轻罪入了重罪**'的反常现象。"——罗国良庭长 2025-09-17

### 3.3 第三句分流——"卡农"底端从宽 + 罪刑梯度

> "对位于犯罪链条底端的'卡农'受人指使实施的转账、套现、取现行为，认定掩隐罪要**特别慎重**。"
> ① 来源：罗国良庭长前沿法评（人民法院报 2025-09-17）

**审查顺序（罗国良庭长建议）**：
1. **先审查行为是否"明知是犯罪所得"** → 判断是否构成**掩隐罪**
2. **不构成掩隐罪的** → 再判断是否构成**帮信罪**
3. **既不构成掩隐罪也不构成帮信罪** → 行政违法或其他处理

## 四、典型行为类型分流（实务速查）

| 行为现象 | 主观状态 | 罪名分流 |
|----------|----------|----------|
| 明知是**电信诈骗**赃款，仍提供本人银行卡帮助转移 | 明知是电信诈骗赃款（明确具体） | **掩隐罪**（若达到入罪标准） |
| 明知朋友让他办卡"可能用于转账赚钱"，对资金性质不甚明确 | 概括知道"可能涉犯罪资金" | **帮信罪**（若达到入罪标准） |
| 明知是**毒品犯罪所得**而帮助洗钱转化 | 明知 7 类上游之毒品犯罪所得 | **洗钱罪**（特殊法优于一般法） |
| 仅为网络诈骗团伙提供**互联网接入 / 服务器托管** | 知道被用于信息网络犯罪 | **帮信罪**（如不知是赃款） |
| 收购骗保药品，知道是医保诈骗所购 | 明知是医保诈骗所购（明确具体） | **掩隐罪**（第 9 条）〔参考 [[concept_医保骗保犯罪]]〕 |
| 对陌生客户大额现金"代为提取 / 转账"，按比例抽成 | 对资金性质笼统不甚明确 | **帮信罪** → 慎重 → 难以入掩隐罪（除非达到入罪标准 + 明知） |
| 与上游诈骗分子**事前通谋**参与犯罪分工 | 通谋 + 实施 | **上游犯罪共犯**（如诈骗罪共犯，**不构成掩隐罪**） |

## 五、2025 年新《解释》三大调整的影响

| 调整点 | 旧解释（2015） | 新解释（2025） | 实务影响 |
|--------|----------------|----------------|----------|
| **入罪判断** | 以数额论（3000-10000 元） | **综合性入罪**（结合上游 / 情节 / 后果） | 破除机械司法；数额较小但实际危害大可入罪；数额较大但实际危害小可出罪 |
| **加重标准** | 单一数额（10 万元） | **两档数额**（上游非法采矿等 500 万 / 其他 50 万） | 解决上下游量刑倒挂问题（如江苏浙江海砂案） |
| **"明知"认定** | 推定宽松 → 易拔高 | **慎用推定** + 严格依法认定 | 防"轻罪拔高入重罪" |

## 六、辩护要点分流（实务盲区）

### 6.1 掩隐罪无罪 / 罪轻辩护（核心切入点）

1. **"明知"无据**：行为人未认识到资金是"特定犯罪所得"，仅笼统知道"可能涉犯罪" → 不构成掩隐罪
2. **底端从宽**："卡农"地位 + 受人指使 + 获利少 → 即使涉案资金达标准，亦应区别于"一对一"普通掩隐
3. **数额争议**：行为人实际接触 / 转移的金额 vs 涉案流转总额（如银行流水 ≠ 实际经手）
4. **上游不成立**：上游犯罪数额未达入罪标准 → 下游不能单独入罪
5. **综合入罪**：数额较大但与上游犯罪关联松散、情节轻微、实际危害较小 → 可不起诉 / 免罚
6. **来源合法**：行为人能说明财物合法来源 → 排除明知

### 6.2 帮信罪 vs 掩隐罪辩护分流

- 当事人被指控**掩隐罪**，主张"不明知是犯罪所得，仅笼统知道银行卡可能被用于涉犯罪资金" → 争取改判**帮信罪**（轻罪）
- 当事人被指控**帮信罪**，但有证据证明**明知是特定犯罪所得** → 难逃掩隐罪（不能反向降格）

### 6.3 洗钱罪 vs 掩隐罪辩护分流

- 当事人被指控**洗钱罪**，但上游不属于 7 类之一 → 争取改判**掩隐罪**或**无罪**
- 当事人被指控**掩隐罪**，上游属 7 类之一 → 不能反向升格洗钱罪

## 七、共性原则（三罪共同适用）

1. **上游犯罪成立先于下游犯罪认定**（掩隐 / 洗钱均要求上游犯罪成立）
2. **"明知"严格认定，慎用推定**（2025 年新《解释》核心精神）
3. **罪刑相适应**（上下游人罪梯度 + 客观行为梯度）
4. **行刑衔接**（不构成犯罪可移送行政处罚）
5. **认罪认罚从宽**（初犯、偶犯、退赃挽损可获从宽处理）

## 九、章节小结

掩隐罪 vs 洗钱罪 vs 帮信罪——核心是**上游犯罪范围 + 主观明知内容 + 行为在犯罪链中的地位**三维分流：

| 维度 | 掩隐罪 | 洗钱罪 | 帮信罪 |
|------|--------|--------|--------|
| **上游** | 不限 | 仅限 7 类 | 网络犯罪 |
| **明知** | 明确具体 | 明确具体（7 类） | 概括笼统 |
| **地位** | 赃物处置环节 | 金融洗白环节 | 工具性帮助 |
| **典型** | 收赃 / 转账 / 套现 | 漂白 / 跨境 | 办卡 / 技术 |
| **政策导向** | 限缩适用 / 慎用推定 | 重刑打击 | 区别对待 / 防止拔高 |

> **核心精神（2025 年《解释》）**：
> "**出的不让人轻罪，重的不让人重罪，罪责相当公平**。"
> —— 严格依法认定"明知"，三罪界分清晰，罪刑相适应。
