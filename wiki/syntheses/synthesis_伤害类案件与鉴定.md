## 一、办理伤害类案件技术性证据实质审查工作规定

### 1.1 技术性证据审查范围

伤害类案件中的技术性证据包括：
- 人体损伤程度鉴定意见
- 伤情鉴定
- 医学诊断证明
- 影像学资料
- 其他技术性证据

### 1.2 实质审查要求

**审查原则**：
- 全面审查
- 客观公正
- 科学判断

**审查内容**：
| 审查要点 | 具体内容 |
|----------|----------|
| 鉴定主体 | 鉴定机构资质、鉴定人资格 |
| 鉴定程序 | 鉴定程序是否合法合规 |
| 鉴定依据 | 鉴定标准是否正确适用 |
| 鉴定结论 | 结论是否明确、有无矛盾 |

### 1.3 实质审查方式

- 听取当事人意见
- 咨询专业技术人员
- 委托重新鉴定
- 专家论证

### 1.4 审查结论处理

| 情形 | 处理方式 |
|------|----------|
| 鉴定意见正确 | 予以采信 |
| 鉴定意见存在瑕疵 | 要求补正或说明 |
| 鉴定意见错误 | 不予采信，申请重新鉴定 |

## 二、伤害类案件人体损伤程度鉴定意见专门审查指引

### 2.1 鉴定标准

人体损伤程度鉴定依据：
- 《人体损伤程度鉴定标准》
- 最高人民法院、最高人民检察院、公安部、国家安全部、司法部联合发布的鉴定标准

### 2.2 损伤等级

| 损伤等级 | 标准 |
|----------|------|
| 重伤 | 使人肢体残废、毁人容貌、丧失听觉、丧失视觉、丧失其他器官功能或者其他对于人身健康有重大伤害的损伤 |
| 轻伤 | 使人肢体或者容貌损害，听觉、视觉或者其他器官功能部分障碍或者其他对于人身健康有中度伤害的损伤 |
| 轻微伤 | 造成人体组织、器官结构轻微损害或者轻微功能障碍 |

### 2.3 专门审查要点

**伤情审查**：
- 原发性损伤审查
- 继发性损伤审查
- 功能障碍审查
- 容貌损害审查

**时限审查**：
- 鉴定时机是否合适
- 是否需要复查鉴定

**因果关系审查**：
- 损伤与结果的因果关系
- 损伤参与度

### 2.4 审查标准

| 审查内容 | 标准 |
|----------|------|
| 鉴定机构 | 省级人民政府指定的医院或有资质的司法鉴定机构 |
| 鉴定人 | 具有相关专业知识的鉴定人员 |
| 鉴定程序 | 符合法定程序 |
| 鉴定标准 | 正确适用鉴定标准 |

## 三、常见问题处理

### 3.1 鉴定时机问题

- 伤情尚未稳定 → 应当待伤情稳定后鉴定
- 存在争议 → 可以进行复查鉴定

### 3.2 多处损伤问题

- 分别鉴定，综合评定
- 主要损伤为主要依据
- 其他损伤作为参考

### 3.3 伤病关系问题

- 原发性损伤为主要原因 → 据实鉴定
- 自身疾病为主要原因 → 相应降低等级
- 损伤与疾病共同作用 → 综合评定

## 四、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 鉴定标准 | 国家统一标准（重伤、轻伤、轻微伤） |
| 鉴定机构 | 省级人民政府指定医院或司法鉴定机构 |
| 审查方式 | 听取意见、咨询专家、委托重鉴、专家论证 |
| 常见问题 | 鉴定时机、多处损伤、病伤关系 |
