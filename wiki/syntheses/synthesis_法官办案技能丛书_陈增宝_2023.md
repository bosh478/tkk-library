## 概述

本 synthesis 整合陈增宝著"法官办案经验与技能丛书"（人民法院出版社 2023 年），含《法官如何庭审》《法官如何讨论》《法官如何阅卷》三册，系统阐述刑事审判核心技能。

**作者：陈增宝** - 浙江三门人，杭州互联网法院院长，国家法官学院浙江分院兼职教授，第三届全国审判业务专家，长期从事经济犯罪和职务犯罪审判工作。

## 一、庭审技能（《法官如何庭审》）

### 1.1 庭审的品性与构成

**庭审本质**：法庭是维护社会公平正义的舞台，具有法律物理空间、追求公平正义的法律舞台、激发法律信仰的仪式感三重属性。

**庭审过程特点**：
- 系统性：各环节紧密衔接
- 互动性：庭审主体之间密切互动
- 即时性和语境依赖性：信息处理需当场判断

**庭审活动基本构成**：
1. 庭前准备阶段
2. 法庭调查阶段（公诉人宣读起诉书→听取证人证言和鉴定意见→出示核实证据）
3. 法庭辩论阶段
4. 被告人作最后陈述阶段
5. 评议案件与宣告判决阶段

### 1.2 庭审的功能与价值

**五大功能**：
1. 发现事实真相与建构案件事实
2. 发现法律规范与阐明法律原理
3. 增强司法透明度与主动接受监督
4. 解决矛盾纠纷与打造司法公信力
5. 宣传法治和教育民众

**庭审价值**：
- 客观、公正
- 司法效率（诉讼经济、诉讼及时）

### 1.3 庭审的结构与原则

**两大法系对比**：
- 当事人主义庭审结构
- 职权主义庭审结构（我国混合模式）

**基本构造**：等腰正三角结构
- 原告（公诉人）- 被告（辩护人）- 裁判者（法官）
- 蕴含诉讼程序的基本法理，体现程序公正要求

**庭审基本原则**：
1. 依法独立行使审判权
2. 法官中立
3. 认真倾听
4. 善于决断
5. 安全有序

### 1.4 庭审准备与预案

**庭前准备六要点**：
1. 全面熟悉案情
2. 拟制庭审提纲
3. 拟制庭审预案
4. 制定庭审工作方案
5. 开好预备庭和庭前会议
6. 指导书记员做好庭前准备工作

**庭审提纲内容**：
- 案件审理的总体范围和庭审分工
- 法庭调查的重点和步骤
- 预测庭审中可能出现的问题及应对措施
- 认证及庭审小结的预案

### 1.5 庭审驾驭技能

**驾驭四手段**：
1. **指挥**：推动庭审、调度人员、控制节奏、创设条件、保障庭审
2. **引导**：耐心倾听、察言观色、争点归纳、疑点指示
3. **干预**：重在预防、及时劝阻、有效处置
4. **决断**：程序性决断、实体性决断

**庭审驾驭技巧**：
- 合理分配和把握各方陈述、辩论时间
- 善于把握庭审主动权，适时引导控辩双方形成交锋
- 准确归纳争议焦点，及时确定庭审方向
- 休庭前进行庭审小结
- 高度重视被告人的最后陈述

### 1.6 庭审心理学技术

**四大技术**：
1. **倾听技术**：克服自以为是、急躁情绪、庭审走神
2. **提问技术**：封闭型提问、开放型提问
3. **释明技术**
4. **影响技术**：对质、情绪平复或控制、指导和建议

## 二、案件讨论技能（《法官如何讨论》）

### 2.1 讨论的制度基础

**集体讨论的司法决策意义**：
- 从案件合议制到审判委员会讨论
- 解决"一案多解"问题
- 引入集体智慧的重要性

**三种讨论形式**：
1. **合议庭讨论**：最基本的集体决策形式
2. **专业法官会议讨论**：法官职业共同体咨询机制
3. **审判委员会讨论**：重大疑难复杂案件的最高决策层

### 2.2 合议庭讨论原理

**群体决策的优势**：
- 集合多人的知识和经验
- 减少个人偏见和判断失误
- 提高决策的可接受性

**合议制运行问题**：
- 部分合议庭成员缺乏全程参与（"合而不议"）
- 部分成员作用发挥不够（"陪而不审"）
- "一言堂"现象

**理想合议制要求**：
- 遵循多数决策规则
- 保证个体有效获取决策信息
- 促进个体成员克服从众心理
- 防止被少数人控制与多数人服从
- 明确各成员的具体责任

**评议表决规则**：
1. 充分的讨论
2. 合理的提炼和归纳
3. 禁止弃权规则
4. 限定发言顺序
5. 限制复议规则
6. 禁止结论性的简单表态
7. 同时亮出观点（投票）规则

### 2.3 专业法官会议讨论

**会议属性**：咨询性、程序性、民主性

**讨论案件十二项原则**：
1. 动议中心原则
2. 主持中立原则
3. 机会均等原则
4. 立场明确原则
5. 发言完整原则
6. 面对主持原则
7. 限时限次原则
8. 一时一件原则
9. 遵守裁判原则
10. 文明表达原则
11. 充分辩论原则
12. 多数裁决原则

### 2.4 审委会讨论

**历史沿革**：经历"一五改革"至"四五改革"的不断完善

**制度定位**：
- 审委会制度的本质是集体决策
- 经过实践检验证明符合中国国情
- 在坚持中不断发展完善

**议事规则**：
1. 汇报（详细案情的介绍与问答）
2. 讨论（处理意见的审议与辩论）
3. 表决（民主集中制的运用）
4. 固化（会议纪要、笔录的制作）

### 2.5 案件汇报技能

**汇报原理**：
- 完整的双向"信息沟通"过程
- 承办法官是信息发送者
- 合议庭成员和审委会委员是信息接收者

**书面汇报要点**：
- 让阅卷笔录成为审查报告的草稿
- 事实证据的排列要符合主体的认知规律
- 站在"听众"的立场撰写报告

**口头汇报方法**：
1. 顺叙汇报法
2. 倒叙汇报法
3. 人物关系汇报法
4. 逐罪汇报法
5. 逐次汇报法
6. 表格式汇报法

## 三、阅卷技能（《法官如何阅卷》）

### 3.1 案卷的品性与构成

**案卷材料构成**：
1. 证据材料
2. 法律文书
3. 控辩双方提交的意见材料
4. 其他材料

**司法认知指向**：
- 事实指向：法官对案件事实的认知
- 法律指向：法官对法条的认知
- 社会指向：法官对社会的认知

### 3.2 阅卷的功能与任务

**四大功能**：
1. 掌握证据、熟悉案情
2. 简化卷宗、方便办案
3. 发现疑点、精准审查
4. 确定思路、明确方向

**主要任务**：
- 逐一审读、吃透案情
- 既审事实、又审法律
- 立足案情、延伸案外

### 3.3 阅卷的形式与种类

**承办法官单独阅卷**：
- 庭前阅卷
- 庭上阅卷（以必要为条件、突出重点、不影响听审）
- 庭后阅卷（全面性、精准性、针对性）

**合议庭成员共同阅卷**：
- 分工阅卷（按罪名、犯罪事实、被告人分工）
- 交叉阅卷

**全面阅卷与重点阅卷**：
- 逐一阅卷
- 重点阅卷
- 补充阅卷
- 反复阅卷

### 3.4 阅卷技巧与方法

**通读、精读、深读**：
1. 初入卷面：总揽全局（审查案卷数、案号、基本情况）
2. 通读案卷：搭建框架（了解整体结构、基本案情、控辩双方意见、证据体系）
3. 精读案卷：填充细节（全面与重点结合、证据"三性"审查）
4. 深读案卷：发现矛盾
5. 掩卷沉思：形成判断

**关键行为定性与阅卷方法**：
- 主干行为决定定性
- 目的行为决定定性
- 关键手段决定定性
- 重行为决定定性

### 3.5 典型案件阅卷要点

**命案审查**：
- 案件线索来源是否清楚
- 被害人身份是否清楚
- 被告人身份是否清楚
- 犯罪事实是否清楚
- 量刑情节是否清楚

**毒品犯罪案件**：
- 被告人主体身份
- 主观上是否具有毒品犯罪故意
- 客观方面（供述、书证、物证、鉴定意见、电子数据）

**职务犯罪案件**：
- 主体要件（受委派从事公务、其他依照法律从事公务、受委托管理国有财产）
- 客观方面
- 主观方面
- 言词证据审查（逐一审查法、同一认定法、比较印证法）

## 四、丛书核心方法论

### 4.1 司法决策的群体智慧

| 机制 | 特点 | 适用场景 |
|------|------|----------|
| 合议庭讨论 | 三人决策 | 一般案件 |
| 专业法官会议 | 咨询性质 | 疑难复杂案件 |
| 审判委员会 | 最高决策 | 重大案件 |

### 4.2 庭审为中心的改革

**从卷宗主义到庭审中心主义**：
- 以审判程序为中心
- 以庭审为中心
- 以证据裁判为落脚点

### 4.3 认知心理学视角

**法官认知的影响因素**：
- 已有图式的影响
- 知识、经验的影响
- 其他因素

**应对策略**：
- 全面阅卷，防止信息遗漏
- 增强宏观意识，恢复案件原貌
- 整体性考虑，证据审查与综合判断结合
- 透过现象看本质
