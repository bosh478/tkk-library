## 裁判要旨

被告人殷雯瑄对人民法院的生效判决、裁定有能力执行而拒不执行，情节严重；被告人李志萍、殷健程明知负有执行义务的人有能力执行而拒不执行人民法院的判决、裁定，与执行义务的人通谋，协助实施隐藏、转移财产等拒不执行行为，情节严重，其行为均构成拒不执行判决、裁定罪。

**律师参与拒执罪的特殊性**：执业律师李志萍明知健程公司账户被法院冻结，仍接受委托并协助转移财产，利用律师身份和律所账户帮助规避执行，构成共同犯罪。

## 案件事实

### 起因

长城公司（后更名安徽长城仪表线缆有限公司）与健程公司买卖合同纠纷一案，天长市人民法院于2021年12月17日作出(2021)皖1181民初5472号民事调解书，健程公司应支付长城公司货款110万元（第一期60万元于2022年1月20日前偿还，第二期50万元于2022年5月30日前偿还）。

健程公司未按期履行，长城公司于2022年3月申请强制执行，天长市人民法院裁定冻结健程公司账户。

### 李志萍的具体行为

| 时间 | 行为 | 性质 |
|-----|------|------|
| **2023年12月** | 殷雯瑄委托李志萍作为健程公司与毅毅公司执行案件的诉讼代理人，**并告知健程公司因被长城公司申请强制执行，对公账户已被法院冻结** | 接受委托时明知 |
| **2024年2月8日** | 殷雯瑄与李志萍商议重新开设对公账户接收执行款，以规避法院冻结 | 共谋规避执行 |
| **2024年2月** | 李志萍**介绍**天长市农村商业银行安乐支行工作人员杨建军，协助健程公司开设新一般账户 | 利用关系提供便利 |
| **2024年3月13日** | 新账户收到执行款37万元后，其中**10万元根据李志萍要求**转至李志萍律师事务所对公账户 | 账户过渡 |
| **2024年3月15日** | 李志萍通过其律师事务所对公账户向殷健程账户转账**6万元** | 协助转移 |

## 核心争点

### 1. 李志萍是否构成拒执罪

**控方观点**：李志萍明知健程公司账户被冻结，仍与殷雯瑄通谋，协助实施隐藏、转移财产，构成共犯。

**辩方观点**：
- 李志萍不知晓健程公司处于被执行状态
- 开设新账户并非拒执行为
- 执行款到账后未参与转移，不知晓后续处理
- 系孤证，不能认定犯罪

**法院认定**：李志萍构成拒不执行判决、裁定罪（共同犯罪）。

### 2. 李志萍的帮助行为

| 行为 | 法院认定 |
|-----|---------|
| 接受委托时明知 | ✓ 明知故犯 |
| 商议开设新账户 | ✓ 通谋 |
| 介绍银行人员 | ✓ 提供帮助 |
| 10万元转至律所账户 | ✓ 账户过渡 |
| 6万元从律所转出 | ✓ 协助转移 |

## 裁判要旨总结

1. **律师可成为拒执罪共犯**：律师虽非被执行人，但明知被执行人有执行义务仍提供帮助，构成共同犯罪
2. **"通谋"的认定**：接受委托时明知+商议对策+提供帮助=通谋
3. **账户过渡行为的定性**：利用律所账户过渡资金，构成帮助转移财产
4. **律师身份从重**：律师具有专业知识和执业便利，社会危害性更大
