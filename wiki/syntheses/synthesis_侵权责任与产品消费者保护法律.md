## 一、侵权责任法基本体系

### 1.1 归责原则

**过错责任原则**（民法典第1165条）：行为人因故意或过失侵害他人民事权益造成损害的，承担侵权责任。

**过错推定责任**（民法典第1165条第二款）：依照法律规定推定行为人有过错，行为人不能证明自己没有过错的，承担侵权责任。

**无过错责任**（民法典第1166条）：行为人造成他人民事权益损害，不论行为人有无过错，法律规定应当承担侵权责任的，依照其规定。

### 1.2 连带责任类型

| 法条 | 情形 | 法律后果 |
|------|------|----------|
| 民法典第1168条 | 二人以上共同实施侵权行为 | 承担连带责任 |
| 民法典第1169条 | 教唆、帮助他人实施侵权行为 | 与行为人承担连带责任 |
| 民法典第1171条 | 二人以上分别实施侵权行为，每一行为都足以造成全部损害 | 承担连带责任 |
| 民法典第1172条 | 二人以上分别实施侵权行为，每一行为都不足以造成全部损害 | 承担相应责任（非连带） |
| 产品质量法第43条 | 产品缺陷造成人身、他人财产损害 | 生产者与销售者连带责任 |

### 1.3 监护人责任（民法典第1188条、第1189条）

- 无/限制民事行为能力人造成他人损害，监护人承担侵权责任
- 监护人尽到监护职责的，可以减轻其侵权责任
- 被监护人财产先支付赔偿费用，不足部分由监护人支付
- 监护人责任为补充责任：法释〔2024〕12号第5条明确监护人承担侵权人应承担的全部责任，而非补充责任

### 1.4 用人单位责任（民法典第1191条）

- 工作人员因执行工作任务造成他人损害，用人单位承担侵权责任
- 工作人员故意或重大过失的，用人单位承担侵权责任后可以向工作人员追偿
- 劳务派遣单位与接受派遣用工单位责任分担：用工单位承担全部责任，派遣单位在过错范围内共同承担责任（法释〔2024〕12号第16条）

## 二、产品责任

### 2.1 生产者责任（产品质量法第41条）

因产品存在缺陷造成人身、缺陷产品以外的其他财产损害的，生产者应当承担赔偿责任。

**生产者免责事由**（产品质量法第41条但书）：
1. 未将产品投入流通的
2. 产品投入流通时，引起损害的缺陷尚不存在的
3. 将产品投入流通时的科学技术水平尚不能发现缺陷存在的

### 2.2 销售者责任（产品质量法第42条）

- 由于销售者的过错使产品存在缺陷，造成人身、他人财产损害的，销售者承担赔偿责任
- 销售者不能指明缺陷产品的生产者也不能指明供货者的，销售者承担赔偿责任

### 2.3 缺陷定义（产品质量法第46条）

产品存在危及人身、他人财产安全的不合理的危险；产品有保障人体健康和人身、财产安全的国家标准、行业标准的，是指不符合该标准。

### 2.4 惩罚性赔偿

- **一般产品欺诈**（消费者权益保护法第55条第1款）：购买商品价款或服务费用的三倍；不足五百元的为五百元
- **明知缺陷仍提供造成死亡或健康严重损害**（消费者权益保护法第55条第2款）：受害人有权要求损失二倍以下的惩罚性赔偿
- **食品安全民事纠纷**（最高人民法院关于审理食品安全民事纠纷案件适用法律若干问题的解释（一））：经营者明知食品不符合食品安全标准仍销售的，可能适用十倍赔偿

## 三、消费者权益保护

### 3.1 消费者权利（消费者权益保护法第7-15条）

| 权利类型 | 内容 |
|----------|------|
| 人身财产安全权 | 购买、使用商品或接受服务时人身财产安全不受损害 |
| 知悉真情权 | 要求经营者提供商品的价格、产地、生产者、用途、性能、规格、等级、主要成份、生产日期、有效期限、检验合格证明、使用方法说明书、售后服务等 |
| 自主选择权 | 自主选择提供商品或服务的经营者、商品品种或服务方式 |
| 公平交易权 | 获得质量保障、价格合理、计量正确等公平交易条件 |
| 求偿权 | 因购买、使用商品或接受服务受到人身、财产损害的，依法获得赔偿 |
| 人格尊严权 | 人格尊严、民族风俗习惯得到尊重，个人信息依法得到保护 |
| 监督权 | 对商品和服务以及保护消费者权益工作进行监督 |

### 3.2 经营者义务（消费者权益保护法第16-29条）

**安全保障义务**（第18条）：
- 经营者应当保证其提供的商品或服务符合保障人身、财产安全的要求
- 对可能危及人身、财产安全的商品和服务，应当向消费者作出真实的说明和明确的警示
- 宾馆、商场、餐馆、银行、机场、车站、港口、影剧院等经营场所的经营者，应当对消费者尽到安全保障义务

**缺陷产品召回义务**（第19条）：经营者发现其提供的商品或服务存在缺陷，有危及人身、财产安全危险的，应当立即向有关行政部门报告和告知消费者，并采取停止销售、警示、召回、无害化处理、销毁、停止生产或服务等措施。

**举证责任倒置**（第23条第3款）：机动车、计算机、电视机、电冰箱、空调器、洗衣机等耐用商品或者装饰装修等服务，消费者自接受商品或服务之日起六个月内发现瑕疵，发生争议的，由经营者承担有关瑕疵的举证责任。

### 3.3 无理由退货（消费者权益保护法第25条）

- 网络、电视、电话、邮购等方式销售商品，消费者有权自收到商品之日起七日内退货，且无需说明理由
- **例外商品**：
  1. 消费者定作的
  2. 鲜活易腐的
  3. 在线下载或消费者拆封的音像制品、计算机软件等数字化商品
  4. 交付的报纸、期刊
- 消费者退货的商品应当完好，经营者应当自收到退回商品之日起七日内返还消费者支付的商品价款

### 3.4 消费者组织（消费者权益保护法第36-38条）

- 消费者协会履行公益性职责：向消费者提供消费信息和咨询服务、参与制定相关法律法规、参与监督检察、受理投诉、支持起诉、揭露批评损害消费者合法权益的行为
- 消费者组织不得从事商品经营和营利性服务，不得以收取费用或其他牟取利益的方式向消费者推荐商品和服务

## 四、生态环境侵权

### 4.1 适用范围（法释〔2023〕5号第1-3条）

**侵权行为类型**：
1. 排放废气、废水、废渣、医疗废物、粉尘、恶臭气体、放射性物质等污染环境
2. 排放噪声、振动、光辐射、电磁辐射等污染环境
3. 不合理开发利用自然资源
4. 违反国家规定，未经批准，擅自引进、释放、丢弃外来物种
5. 其他污染环境、破坏生态的行为

**不作为生态环境侵权案件处理的情形**：
1. 未经由大气、水、土壤等生态环境介质，直接造成损害的
2. 在室内、车内等封闭空间内造成损害的
3. 不动产权利人在日常生活中造成相邻不动产权利人损害的
4. 劳动者在职业活动中受到损害的

### 4.2 归责原则（法释〔2023〕5号第4条）

- **无过错责任**：污染环境、破坏生态造成他人损害，行为人不论有无过错，都应当承担侵权责任
- 行为人以外的其他责任人对损害发生有过错的，应当承担侵权责任

### 4.3 惩罚性赔偿（法释〔2022〕1号）

**适用条件**（第4条）：
1. 侵权人污染环境、破坏生态的行为违反法律规定
2. 侵权人具有污染环境、破坏生态的故意
3. 侵权人污染环境、破坏生态的行为造成严重后果

**认定故意的情形**（第7条）：
- 因同一行为已被认定构成破坏环境资源保护犯罪的
- 建设项目未依法进行环境影响评价或提供虚假材料被责令停止建设后拒不执行的
- 未取得排污许可证排放污染物被责令停止排污后拒不执行，或超标排放经处罚后仍不改正的
- 生产、使用国家明令禁止的农药被责令改正后拒不改正的
- 无危险废物经营许可证从事危险废物经营活动
- 将未经处理的废水、废气、废渣直接排放或倾倒的
- 通过暗管、渗井、渗坑、灌注，篡改、伪造监测数据，或者以不正常运行防治污染设施等逃避监管的方式违法排放污染物

**赔偿限额**（第10条）：一般不超过人身损害赔偿金、财产损失数额的二倍

### 4.4 第三方治理责任（法释〔2023〕5号第12-14条）

| 情形 | 责任承担 |
|------|----------|
| 排污单位委托第三方治理机构运营环保设施，第三方造成他人损害 | 排污单位承担侵权责任，可向第三方追偿 |
| 排污单位将污染物交由第三方集中处置，第三方造成他人损害 | 第三方承担侵权责任；排污单位在选任、指示中有过错的，承担相应责任 |
| 第三方按照排污单位指示违反污染防治规定排污 | 排污单位与第三方承担连带责任 |
| 排污单位将明显存在缺陷的环保设施交由第三方运营 | 排污单位与第三方承担连带责任 |
| 排污单位以明显不合理价格将污染物交由第三方处置 | 排污单位与第三方承担连带责任 |

### 4.5 证据规则（法释〔2023〕6号）

**举证责任分配**：
- **原告（被侵权人）举证**：被告实施了污染环境或破坏生态的行为；原告人身、财产受到损害或有遭受损害的危险
- **被告举证**：其行为与损害之间不存在因果关系；法律规定的不承担责任或减轻责任的情形

**因果关系认定**（第5条）：人民法院应当根据当事人提交的证据，结合污染环境、破坏生态的行为方式、污染物的性质、环境介质的类型、生态因素的特征、时间顺序、空间距离等因素，综合判断被告行为与损害之间的关联性是否成立。

## 五、适用要点汇总表

### 5.1 侵权责任类型与管辖

| 案由/纠纷类型 | 适用法条/解释 | 管辖法院 | 备注 |
|---------------|---------------|----------|------|
| 产品责任纠纷（买卖、使用） | 产品质量法第40-46条、民法典第1202-1203条 | 被告住所地或侵权行为地法院 | 缺陷产品造成损害 |
| 消费者权益保护纠纷 | 消费者权益保护法第7-60条 | 被告住所地、侵权行为地、合同履行地法院 | 保护为生活消费需要购买商品的消费者 |
| 生态环境侵权责任纠纷 | 民法典第1229-1235条、法释〔2023〕5号、法释〔2022〕1号 | 侵权行为地或损害结果发生地法院 | 污染环境、破坏生态 |
| 网络消费纠纷 | 最高人民法院关于审理网络消费纠纷案件适用法律若干问题的规定（一） | 被告住所地或合同履行地法院 | 网络购物 |
| 食品安全民事纠纷 | 最高人民法院关于审理食品安全民事纠纷案件适用法律若干问题的解释（一） | 被告住所地或侵权行为地法院 | 十倍赔偿 |
| 预付式消费纠纷 | 最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释 | 被告住所地或合同履行地法院 | 卷款跑路 |

### 5.2 赔偿范围对照

| 损害类型 | 赔偿项目 | 法律依据 |
|----------|----------|----------|
| 人身损害（一般） | 医疗费、护理费、交通费、误工收入；残疾者生活自助具费、生活补助费、残疾赔偿金；死者丧葬费、死亡赔偿金、被扶养人生活费 | 民法典第1179条、产品质量法第44条、消费者权益保护法第49条 |
| 财产损害 | 恢复原状或折价赔偿；其他重大损失 | 民法典第1184条、产品质量法第44条 |
| 精神损害 | 严重精神损害赔偿 | 民法典第1183条 |
| 惩罚性赔偿（产品欺诈） | 价款的三倍（不足500元为500元） | 消费者权益保护法第55条 |
| 惩罚性赔偿（缺陷产品致死/健康严重损害） | 所受损失二倍以下 | 消费者权益保护法第55条 |
| 惩罚性赔偿（环境侵权） | 不超过人身+财产损害的二倍 | 法释〔2022〕1号第10条 |
| 生态环境损害 | 生态环境修复费用、服务功能丧失损失、功能永久性损害损失、清除污染费用、防止损害发生费用 | 民法典第1235条 |

### 5.3 诉讼时效

| 纠纷类型 | 诉讼时效 | 起算点 | 法律依据 |
|----------|----------|--------|----------|

| 消费者权益纠纷 | 3年 | 知道或应当知道权利受到损害以及经营者时 | 民法典第188条 |
| 生态环境侵权 | 3年 | 知道或应当知道权利受到损害以及侵权人时；行为仍持续的，自行为结束之日起计算 | 法释〔2023〕5号第27条 |
