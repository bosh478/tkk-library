## 一、涉案企业合规第三方监督评估机制

### 1.1 机制概述

建立并完善涉案企业合规第三方监督评估机制，是推进企业合规改革试点的重要举措。该机制通过对涉案企业的合规整改情况进行独立监督评估，确保企业真正落实合规管理要求。

### 1.2 第三方监督评估组织

**组成**：
- 由专业人员组成
- 具有独立性和专业性
- 负责对涉案企业合规整改情况进行监督和评估

**职责**：
- 审查企业合规计划的制定
- 监督合规整改措施的执行
- 评估合规管理体系的建立
- 考核防范类似违法行为的效果

### 1.3 适用范围

适用于各类涉案企业，特别是：
- 涉及经济犯罪的企业
- 涉及破坏市场经济秩序犯罪的企业
- 涉及公共安全犯罪的企业
- 其他可以适用企业合规的案件

### 1.4 合规整改要求

**基本要求**：
- 制定切实可行的合规整改计划
- 建立完善的内控管理制度
- 加强合规培训和企业文化建设
- 定期报告整改进展情况

**重点领域**：
- 财务管理合规
- 经营决策合规
- 知识产权保护
- 环境保护责任
- 劳动者权益保护

## 二、办理财务造假犯罪案件有关问题解答

### 2.1 财务造假犯罪类型

财务造假犯罪主要涉及：
1. **欺诈发行证券罪**
2. **违规披露、不披露重要信息罪**
3. **提供虚假证明文件罪**
4. **出具证明文件重大失实罪**

### 2.2 信息披露义务认定

#### 证券发行阶段

- 依据《公司法》《证券法》及部门规章认定
- 发行股票：首次公开发行、上市后公开发行（增股、配股）
- 发行债券：上市公司、非上市公司；公开发行、非公开发行
- 发行存托凭证：境外公司在境内发行、境内公司在境外发行

#### 持续经营阶段

- 上市公司、非上市公众公司对经营情况、财务情况、重大事件负有定期和临时披露义务
- 债券发行人在债券存续期内负有披露义务

### 2.3 欺诈发行证券罪认定

**债券范围**：
- 公司、企业依照法定程序发行
- 约定在一定期限还本付息的有价证券
- 包括交易所市场和银行间市场

**立案追诉标准**：
| 情形 | 标准 |
|------|------|
| 虚增或虚减资产、营业收入、利润占比 | 达到当期相应指标总额的50%以上 |
| 隐瞒或编造重大诉讼、仲裁、担保、关联交易 | 涉及数额达到净资产50%以上 |
| 发行文件造假 | 隐瞒或编造事项涉及金额达到净资产50%以上 |

### 2.4 违规披露、不披露重要信息罪认定

**信息披露义务主体**：
- 上市公司、非上市公众公司
- 债券发行人
- 境外基础证券发行人

**重大事项**：
- 重大诉讼、仲裁
- 担保
- 关联交易
- 其他重大事件

**追诉标准**：
- 未按照规定披露的重大事项涉及的数额或连续12个月累计数额达到最近一期披露的净资产50%以上

### 2.5 直接经济损失认定

- 已有生效民事判决的，参照民事判决认定
- 难以准确计算的，委托专门机构出具测算报告

### 2.6 涉案人员分层分类处理

| 人员类型 | 处理原则 |
|----------|----------|
| 控股股东、实际控制人、董事、监事、高管 | 组织实施或签字确认明知虚假 → 依法追究 |
| 中层负责人、一般工作人员 | 负有组织责任或积极参与 → 依法追究 |
| 受单位领导指派参与人员 | 作用不大 → 一般不宜作为直接责任人追究 |

### 2.7 中介组织及其人员犯罪

**定罪**：
- 故意提供虚假证明文件，情节严重 → **提供虚假证明文件罪**
- 严重不负责任，出具证明文件重大失实 → **出具证明文件重大失实罪**

**严重不负责任认定**：
- 未按审计准则履行必需的审计程序
- 一般审计人员能够发现的问题而未发现
- 未开展审计工作而直接签字确认审计结论

**与其他犯罪竞合**：依照处罚较重的规定定罪处罚

## 三、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 企业合规 | 第三方监督评估、整改计划、内控管理 |
| 财务造假犯罪 | 欺诈发行证券、违规披露、提供虚假证明文件 |
| 信息披露主体 | 发行人、上市公司、债券发行人 |
| 追诉标准 | 净资产50%或金额100万元以上 |
| 人员处理 | 分层分类：高管→中层→一般人员 |
