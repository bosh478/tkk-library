## 概述

电子数据司法鉴定是运用计算机科学理论和技术，以及其他相关专门知识和经验，对涉及诉讼的电子数据有关内容进行判断、鉴别并出具鉴定意见的活动。电子数据是指由信息技术形成的、用以证明案件事实的数据信息，包括电子邮件、电子交易记录、计算机文件、数码相机中的图片或视频资料等。

## 一、电子数据司法鉴定的类别

### （一）应用层鉴定事项

| 鉴定事项 | 说明 |
|----------|------|
| 信息存在性认定 | 认定特定存储媒介上存储有特定信息 |
| 信息量认定 | 认定淫秽信息数量、点击数量等 |
| 信息同一性/相似性认定 | 通过比对分析认定两个信息是否同一或相似 |
| 信息来源认定 | 认定信息的最初源头 |
| 程序功能认定 | 认定程序具有特定功能（如恶意代码、木马） |
| 程序同一性/相似性认定 | 认定两个程序是否同一或相似 |
| 犯罪事件重构 | 认定犯罪嫌疑人特征、主观方面、客观方面 |

### （二）技术层鉴定类别

**基于单机和设备的鉴定：**
- 证据保全：使用克隆数据而非原始检材进行分析
- 数据恢复：还原被删除或覆盖的数据
- 口令和密码破解：操作系统、数据库、加密文件的解密
- 隐藏数据的再现：信息隐藏检测与算法还原
- 证据搜索、过滤及挖掘：快速定位电子证据

**基于网络的鉴定：**
- 网络环境下的证据保全：实时保全、Hash值校验
- 日志分析：CPU负荷、IP来源、恶意访问、系统异常等
- 数据捕获：截获网络数据包分析攻击源
- 现场重建：建立模拟试验环境分析原理

## 二、电子数据司法鉴定的基础

### （一）法律基础

- 2012年《刑事诉讼法》第二次修正正式将"电子数据"列为第八大类证据
- 《关于办理死刑案件审查判断证据若干问题的规定》确立电子证据审查五点内容
- 《公安机关电子数据鉴定规则》《计算机犯罪现场勘验与电子证据检查规则》等

### （二）技术基础

| 技术 | 说明 |
|------|------|
| 只读技术 | 通过软件或硬件实现，只允许读不允许写 |
| 克隆技术 | 位对位复制检材硬盘，完整保留被删除文件、碎片等 |
| 数字指纹（Hash） | 散列算法验证电子证据完整性，MD5/SHA1 |

## 三、电子数据现场勘验

### （一）现场勘验任务

1. 发现、固定、提取与案件相关的电子数据
2. 封存电子设备
3. 提取其他信息
4. 对现场进行搜查
5. 制作和存储现场信息资料
6. 判断案件性质，确定方向和范围

### （二）现场勘验规划

**物理位置因素：**
- 确定勘验范围（个人住所、公司、网吧等）
- 存储介质可能从窗户丢弃
- 针对机器众多的案件需借助专用取证设备

**现场人员因素：**
- 安全保障组：负责人员和设备安全
- 现场勘验组：记录笔录、收集证物、处理计算机

**应用系统因素：**
- 确定证据类型（经济类侧重文档、软件著作权类侧重源代码）
- 搜查范围限制、联网状态、加密情况

**装备规划：**
- 勘查箱（相机、螺丝刀、标签、电磁信号屏蔽袋等）
- 取证专用介质复制设备
- 现场取证工具（取证大师、EnCase、FTK等）
- 袖珍式打印机

### （三）现场电子数据处理

**记录现场情况：**
- 绘制方位草图（包含发案地点、时间、制图单位等）
- 拍照记录现场概貌、中心现场
- 对涉案计算机及周边设备编号

**识别潜在证据：**
- 各种电子设备（计算机、PDA、软盘、CD等）
- 存储媒介（优盘、活动硬盘、SD卡等）
- 外部设备（打印机、扫描仪等）

**固定易失证据：**
- 时间信息提取：开机状态截图，关机状态通过BIOS提取
- 系统运行状态提取：进程、打开文件、内存内容、网络连接
- 不得使用目标系统上的程序实施提取
- 提取信息存储到调查人员自带的存储媒介

**关闭计算机原则：**

| 操作系统 | 关机方式 |
|----------|----------|
| Windows系统 | 拍摄屏幕后拔掉电源插头 |
| Linux/Unix | 正常关机，需根目录权限 |
| Macintosh | 从菜单选择关机 |

**封存与包装：**
- 电缆编号标识并拍照
- 防静电袋包装
- 贴标签注明日期、位置、时间、案件、机构
- 现场勘验笔录、封存清单、照片记录、固定清单

## 四、电子数据提取与固定方法

### （一）硬盘复制机复制

高速硬盘复制机基于位对位复制原理，制作与原始硬盘完全一致的副本，可通过MD5等散列算法验证。

**操作流程：**
1. 识别硬盘接口，设置主盘模式
2. 准备容量不小于原始硬盘的空白硬盘
3. 连接原始硬盘与目标硬盘
4. 检查连接后启动设备
5. 选择复制功能开始复制

### （二）只读锁+软件方式

在无硬盘复制机时使用只读锁防止对原始数据修改，通过软件制作数据文件。

**CyberBlock只读锁类型：**
- CyberBlock-SATA/IDE只读锁
- CyberBlock-SCSI只读锁
- CyberBlock-USB只读锁
- CyberBlock-Card只读读卡器

## 五、电子证据的法律制度

### （一）电子证据的采纳标准

**关联性：** 电子证据必须在逻辑上与待证事实之间具有证明关系

**合法性：**
- 通过窃录方式获得的电子证据，不予采纳
- 通过非法搜查、扣押等方式获得的电子证据，情节严重的不予采纳
- 通过非核证程序得来的电子证据，在电子商务纠纷案件中不予采纳
- 通过非法软件得来的电子证据，在民事诉讼中一般不予采纳

**真实性认定方式：**
1. 自认方式：诉讼当事人双方均认可
2. 证人具结方式：适格证人通过具结证明
3. 推定方式：证明计算机系统在关键时刻处于正常状态
4. 电子签名方式：附有电子签名或适当安全程序保障
5. 鉴定方式：由适格专家鉴定未遭修改

### （二）电子证据的采信原则

**平等对待原则：** 给电子证据同传统证据平等的待遇

**综合采信原则（印证原则）：**
- 孤证不能定案
- 单一电子证据定案不存在
- 必须构成证据体系或证据锁链

### （三）电子证据的印证体系

| 体系 | 说明 |
|------|------|
| 物理空间证据体系 | 电子证据与传统证据相结合 |
| 虚拟空间证据体系 | 若干电子证据相印证构成证据锁链 |

## 六、电子证据的审查判断

### （一）真实性认定

审查内容：
- 是否移送原始存储介质
- 是否有数字签名、数字证书等特殊标识
- 收集、提取过程是否可以重现
- 是否有增加、删除、修改等情形及说明
- 完整性校验值是否匹配

### （二）完整性认定

审查方法：
- 原始存储介质的扣押、封存状态
- 电子数据的收集、提取过程查看录像
- 比对电子数据完整性校验值
- 与备份的电子数据进行比较
- 审查冻结后的访问操作日志

### （三）合法性认定

审查内容：
- 是否由2名以上侦查人员进行
- 取证方法是否符合相关技术标准
- 是否附有笔录、清单，并经相关人员签名
- 是否依照规定由符合条件的人员担任见证人
- 电子数据检查是否通过写保护设备接入

### （四）关联性认定

- 认定网络身份与现实身份的同一性：IP 地址、网络活动记录、上网终端归属、证人证言、被告人供述等
- 认定被告人与存储介质的关联性

## 七、电子数据鉴定基本原则

| 原则 | 说明 |
|------|------|
| 及时性原则 | 尽快提取证据，防止证据变更和丢失 |
| 依法原则 | 确保鉴定主体、客体和程序的合法性 |
| 备份原则 | 制作副本或镜像，原始介质专人保管 |
| 证据原始性原则 | 不能改变其原始性 |
| 环境安全原则 | 防止环境或人为原因损毁数据 |
| 监督原则 | 全过程受监督和控制 |

## 八、电子数据取证与鉴定基本步骤

1. **电子数据证据的发现**：通过侦查和现场勘察收集最原始的证据
2. **电子数据的获取和固定**：确定鉴定对象，选用适当设备获取证据数据
3. **电子数据的检验分析**：关联分析证实信息的存在、来源及传播途径
4. **电子数据证据的表达**：鉴定结论和意见应对委托事项直接答复

## 适用要点汇总表

| 环节 | 核心要点 | 注意事项 |
|------|----------|----------|
| **现场勘验** | 发现、固定、提取电子数据；封存设备；制作现场资料 | 全程记录；防止证据被破坏或修改 |
| **证据固定** | 使用克隆数据而非原始检材；Hash值校验 | 只读技术保护；完整记录操作过程 |
| **数据提取** | 硬盘复制机位对位复制；只读锁+软件方式 | 选对接口类型；避免对原始数据修改 |
| **易失数据** | 时间信息、系统状态、网络连接 | 不得使用目标系统程序；存储到自带介质 |
| **证据审查** | 真实性、完整性、合法性、关联性 | 综合印证；孤证不能定案 |
| **鉴定结论** | 直接答复委托事项；客观准确 | 逻辑规范；文字简练；符合科学原则 |

### 关键鉴定技术清单

- **证据保全**：克隆技术、Hash校验、数字签名
- **数据恢复**：删除文件恢复、深度信号还原
- **密码破解**：密码字典、暴力穷举
- **隐藏数据再现**：信息隐藏检测与算法还原
- **网络鉴定**：日志分析、数据捕获、现场重建

### 法律依据要点

- 《刑事诉讼法》第50条：电子数据作为第八大类证据
- 《关于办理刑事案件收集提取和审查判断电子数据若干问题的规定》（法发〔2016〕22号）
- 《公安机关电子数据鉴定规则》
- 《计算机犯罪现场勘验与电子证据检查规则》
- ISO/IEC 27037:2012《电子证据识别、收集、获取和保存指南》
