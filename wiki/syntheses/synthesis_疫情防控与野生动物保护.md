## 一、依法惩治妨害疫情防控违法犯罪意见

### （一）抗拒疫情防控措施犯罪

**以危险方法危害公共安全罪定罪处罚**（刑法第114条、第115条第1款）：

| 情形 | 构成要件 |
|------|----------|
| 已经确诊的病人、病原携带者 | 拒绝隔离治疗或隔离期未满擅自脱离隔离治疗，并进入公共场所或公共交通工具 |
| 疑似病人 | 拒绝隔离治疗或隔离期未满擅自脱离隔离治疗，进入公共场所或公共交通工具，造成病毒传播 |

**妨害传染病防治罪**（刑法第330条）：
其他拒绝执行卫生防疫机构依照传染病防治法提出的防控措施，引起病毒传播或传播严重危险的。

**妨害公务罪**（刑法第277条第1款、第3款）：
以暴力、威胁方法阻碍国家机关工作人员依法履行为防控疫情而采取的防疫、检疫、强制隔离、隔离治疗等措施。
- 暴力袭击正在依法执行职务的人民警察：从重处罚

### （二）暴力伤医犯罪

| 罪名 | 情形 |
|------|------|
| 故意伤害罪（刑法第234条） | 故意伤害医务人员造成轻伤以上严重后果，或致使医务人员感染新冠病毒 |
| 寻衅滋事罪（刑法第293条） | 随意殴打医务人员，情节恶劣 |
| 侮辱罪/寻衅滋事罪（刑法第246条、第293条） | 以暴力或其他方法公然侮辱、恐吓医务人员 |
| 非法拘禁罪（刑法第238条） | 以不准离开工作场所等方式非法限制医务人员人身自由 |

### （三）制假售假犯罪

| 罪名 | 情形 |
|------|------|
| 生产、销售伪劣产品罪/假药罪/劣药罪（刑法第140条、第141条、第142条） | 生产、销售伪劣的防治/防护产品、物资，或用于防治疫情的假药、劣药 |
| 生产、销售不符合标准的医用器材罪（刑法第145条） | 生产不符合保障人体健康的国家标准/行业标准的医用口罩、护目镜、防护服等，或明知是上述医用器材而销售 |

### （四）哄抬物价犯罪

**非法经营罪**（刑法第225条第4项）：
违反国家有关市场经营、价格管理规定，囤积居奇，哄抬疫情防控急需的口罩、护目镜、防护服、消毒液等防护用品、药品或其他涉及民生的物品价格，牟取暴利，违法所得数额较大或有其他严重情节。

### （五）诈骗、聚众哄抢犯罪

| 罪名 | 情形 |
|------|------|
| 诈骗罪（刑法第266条） | 假借研制、生产/销售用于疫情防控物品的名义骗取公私财物，或捏造事实骗取公众捐赠款物 |
| 虚假广告罪（刑法第222条） | 假借疫情防控的名义，利用广告对商品或服务作虚假宣传，致使多人上当受骗 |
| 聚众哄抢罪（刑法第268条） | 聚众哄抢公私财物特别是疫情防控和保障物资 |

### （六）造谣传谣犯罪

| 罪名 | 情形 |
|------|------|
| 编造、故意传播虚假信息罪（刑法第291条之一第2款） | 编造虚假疫情信息，在信息网络或其他媒体上传播，或明知是虚假疫情信息而传播 |
| 寻衅滋事罪（刑法第293条第1款第4项） | 编造虚假信息或明知是编造的虚假信息，在信息网络上散布，起哄闹事，造成公共秩序严重混乱 |
| 煽动分裂国家罪/煽动颠覆国家政权罪（刑法第103条第2款、第105条第2款） | 利用疫情制造、传播谣言，煽动分裂国家、破坏国家统一，或煽动颠覆国家政权、推翻社会主义制度 |
| 拒不履行信息网络安全管理义务罪（刑法第286条之一） | 网络服务提供者不履行信息网络安全管理义务，致使虚假疫情信息或其他违法信息大量传播 |

### （七）疫情防控失职渎职、贪污挪用犯罪

| 罪名 | 情形 |
|------|------|
| 滥用职权罪/玩忽职守罪（刑法第397条） | 负有疫情防控职责的国家机关工作人员滥用职权或玩忽职守，致使公共财产、国家和人民利益遭受重大损失 |
| 传染病防治失职罪（刑法第409条） | 卫生行政部门工作人员严重不负责任，不履行或不认真履行防治监管职责，导致疫情传播或流行 |
| 传染病毒种扩散罪（刑法第331条） | 从事实验、保藏、携带、运输传染病菌种、毒种的人员违反规定，造成病毒扩散 |
| 贪污罪/职务侵占罪/挪用公款罪/挪用资金罪（刑法第382条、第271条、第384条、第272条） | 国家工作人员/受委托管理国有财产的人员/公司企业人员侵吞、截留、挪用防控疫情的款物 |
| 挪用特定款物罪（刑法第273条） | 挪用用于防控疫情的救灾、优抚、救济等款物 |

### （八）破坏交通设施犯罪

**破坏交通设施罪**（刑法第117条、第119条第1款）：
破坏轨道、桥梁、隧道、公路、机场、航道、灯塔、标志或进行其他破坏活动，足以使火车、汽车、电车、船只、航空器发生倾覆、毁坏危险。

注意：为了防止疫情蔓延，未经批准擅自封路阻碍交通，未造成严重后果的，一般不以犯罪论处。

### （九）破坏野生动物资源犯罪

| 罪名 | 情形 |
|------|------|
| 非法猎捕、杀害珍贵、濒危野生动物罪/非法收购、运输、出售珍贵、濒危野生动物、珍贵、濒危野生动物制品罪（刑法第341条第1款） | 非法猎捕、杀害国家重点保护的珍贵、濒危野生动物，或非法收购、运输、出售其制品 |
| 非法狩猎罪（刑法第341条第2款） | 违反狩猎法规，在禁猎区、禁猎期或使用禁用的工具、方法进行狩猎，破坏野生动物资源 |
| 非法经营罪（刑法第225条第4项） | 非法经营非国家重点保护野生动物及其制品，扰乱市场秩序 |
| 非法收购珍贵、濒危野生动物、珍贵、濒危野生动物制品罪（刑法第341条第1款） | 知道或应当知道是珍贵、濒危野生动物及其制品，为食用或其他目的而非法购买 |
| 掩饰、隐瞒犯罪所得罪（刑法第312条） | 知道或应当知道是非法狩猎的野生动物而购买 |

## 二、依法惩治非法野生动物交易犯罪指导意见

### （一）严厉打击非法野生动物交易

**非法猎捕、买卖、运输、杀害野生动物类犯罪**：

| 罪名 | 法律依据 |
|------|----------|
| 非法猎捕、杀害陆生野生动物罪 | 全国人民代表大会常务委员会《关于全面禁止非法野生动物交易、革除滥食野生动物陋习、切实保障人民群众生命健康安全的决定》 |
| 非法收购、运输、出售陆生野生动物罪 | 同上 |

### （二）依法严厉惩治非法野生动物交易行为

- 全面禁止非法野生动物交易
- 革除滥食野生动物陋习
- 切实保障人民群众生命健康安全

### （三）相关罪名适用

参照刑法第341条及相关司法解释，从严追究刑事责任。

## 三、加强国境卫生检疫工作惩治妨害国境卫生检疫违法犯罪意见

### （一）妨害国境卫生检疫罪（刑法第332条）

**犯罪情形**：

| 行为类型 | 具体表现 |
|----------|----------|
| 逃避检疫 | 逃避卫生检疫，弄虚作假，隐瞒真实情况 |
| 拒绝检疫 | 拒绝接受检疫、强制卫生检疫 |
| 非法入境 | 入境不如实申报健康状况 |
| 传播风险 | 引起鼠疫、霍乱、黄热病以及新冠肺炎等国务院确定和公布的其他检疫传染病传播或有传播严重危险 |

### （二）相关犯罪并罚

同时构成妨害传染病防治罪、妨害国境卫生检疫罪的，择一重处。

| 妨害传染病防治罪 | 第330条 | 拒绝执行防控措施引起传播 | 三年以下或三年以上七年以下 |
| 妨害公务罪 | 第277条 | 阻碍防疫人员依法履职 | 三年以下 |

| 任何野生动物（非法交易） | 非法经营罪 | 第225条第4项 |

### （三）疫情防控从重情节

- 在疫情防控期间实施相关犯罪的
- 防控期间限制：作为从重情节考量
- 针对医务人员实施犯罪的
- 利用疫情煽动颠覆国家政权的
