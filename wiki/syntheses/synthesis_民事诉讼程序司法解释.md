## 一、民事诉讼证据规定

### 1.1 举证责任分配

**一般规则：**
- 谁主张，谁举证
- 主张法律关系存在的当事人，应当对产生该法律关系的基本事实承担举证责任
- 主张法律关系变更、消灭或者权利受到妨害的当事人，应当对该法律关系变更、消灭或者权利受到妨害的基本事实承担举证责任

**特殊情形：**
| 情形 | 举证责任分配 |
|------|--------------|
| 专利侵权 | 权利人举证侵权行为；被侵权人举证不侵权抗辩 |
| 环境污染 | 加害方举证无害化处理 |
| 医疗损害 | 医疗机构举证无过错 |

### 1.2 电子数据

**电子数据范围：**
- 网页、博客、微博等网络平台发布的信息
- 手机短信、电子邮件、即时通信记录
- 用户注册信息、身份认证信息、电子交易记录
- 文档、图片、音频、视频等电子文件
- 其他以数字化形式存储、处理、传输的信息

**真实性认定：**
- 提取、复制的完整性
- 来源是否可靠
- 形成、存储、传输过程是否完整

### 1.3 证人作证

**证人资格：**
- 了解案件情况
- 能正确表达意志
- 与当事人无利害关系

**出庭要求：**
- 证人应当出庭作证
- 确有困难不能出庭的，可以提交书面证言
- 证人费用由败诉方承担

### 1.4 鉴定意见

**申请鉴定：**
- 当事人申请鉴定，应当在人民法院指定期限内提出
- 逾期且无正当理由，不予准许

**重新鉴定：**
- 当事人对鉴定意见有异议，可申请重新鉴定
- 原鉴定意见程序/实体违法的，应重新鉴定

## 二、诉讼时效制度

### 2.1 普通诉讼时效

**期间：**
- 3年（民法典施行后）
- 向人民法院请求保护民事权利的诉讼时效期间为三年

**起算：**
- 自权利人知道或者应当知道权利受到损害以及义务人之日起计算
- 权利人知道具体义务人的，自知道义务人之日起计算

### 2.2 最长权利保护期间

- 20年（自权利受到损害之日起计算）
- 特殊情况下，人民法院可以根据权利人的申请决定延长

### 2.3 时效中止/中断

**中止事由：**
- 不可抗力
- 权利人被义务人或者其他人控制
- 其他障碍（无民事行为能力人/限制民事行为能力人无法定代理人等）

**中断事由：**
- 权利人向义务人提出履行请求
- 义务人同意履行义务
- 权利人提起诉讼或者申请仲裁
- 与提起诉讼或者申请仲裁具有同等效力的其他情形

### 2.4 特殊时效规定

| 情形 | 时效期间 |
|------|----------|
| 人身损害赔偿 | 1年（知道或应当知道） |
| 环境污染损害 | 3年（知道或应当知道） |
| 船舶工程合同 | 2年 |
| 海上货物运输 | 1年 |

## 三、民事诉讼程序

### 3.1 管辖

**级别管辖：**
- 基层法院：第一审民事案件
- 中级法院：重大涉外案件、在本辖区有重大影响的案件、最高法院确定由中级法院管辖的案件

**地域管辖：**
- 被告住所地法院管辖
- 合同/侵权纠纷可由合同履行地/侵权行为地法院管辖

**专属管辖：**
- 不动产纠纷：不动产所在地法院
- 港口作业纠纷：港口所在地法院
- 继承遗产纠纷：被继承人死亡时住所地或主要遗产所在地法院

### 3.2 保全

**财产保全：**
- 诉前保全：利害关系人可在紧急情况下申请
- 诉中保全：当事人可申请或法院可依职权裁定

**行为保全：**
- 责令作出一定行为或禁止作出一定行为

### 3.3 送达

**送达方式：**
- 直接送达
- 留置送达
- 电子送达（经受送达人同意）
- 委托送达
- 邮寄送达
- 公告送达

**电子送达：**
- 以送达日期为准
- 判决书、裁定书、调解书不适用电子送达

### 3.4 调解

**调解原则：**
- 当事人自愿
- 合法合规
- 不损害第三人利益

**调解协议效力：**
- 经法院确认的调解协议，具有执行力
- 一方不履行，另一方可申请强制执行

## 四、执行程序

### 4.1 执行依据

**可执行依据：**
- 法院判决、裁定、调解书
- 仲裁裁决
- 公证债权文书
- 支付令

### 4.2 执行和解

**和解协议效力：**
- 不自动终结执行程序
- 一方不履行，对方可申请恢复执行原生效法律文书
- 也可就履行和解协议起诉

**恢复执行：**
- 申请恢复执行原生效法律文书
- 适用申请执行时效的规定

### 4.3 执行担保

**担保条件：**
- 担保人向法院承诺
- 明确担保方式、范围
- 暂缓执行期限不超过一年

**担保效力：**
- 担保期满后不履行的，可执行担保财产

### 4.4 执行异议

**异议主体：**
- 案外人
- 当事人

**异议类型：**
- 对执行标的的异议
- 对执行行为的异议

**异议审查：**
- 法院应在15日内审查
- 异议成立的，裁定撤销/改正
- 异议不成立的，裁定驳回

### 4.5 财产调查

**财产申报：**
- 被执行人应当报告当前及收到执行通知之日前一年的财产状况
- 报告财产后有变动，自变动之日起10日内补充报告

**搜查措施：**
- 被执行人不履行义务且隐匿财产
- 可对住所/财产隐匿地实施搜查

**审计措施：**
- 被执行人拒绝报告/虚假报告财产
- 可委托审计

## 五、仲裁司法审查

### 5.1 仲裁协议效力

**有效仲裁协议：**
- 请求仲裁的意思表示明确
- 仲裁事项明确
- 选定了仲裁委员会

**仲裁协议无效：**
- 约定的仲裁事项超出法律规定的仲裁范围
- 无民事行为能力人或限制民事行为能力人订立
- 一方采取胁迫手段

### 5.2 申请撤销仲裁裁决

**理由：**
- 没有仲裁协议
- 仲裁的事项不属于仲裁协议的范围
- 仲裁庭的组成或者仲裁的程序违反法定程序
- 裁决所依据的证据是伪造的
- 对方当事人隐瞒了足以影响公正裁决的证据

### 5.3 承认和执行外国仲裁裁决

**申请条件：**
- 裁决系外国仲裁机构作出
- 被申请人住所地/财产所在地在中国

**审查标准：**
- 公共利益
- 自然公正

## 六、涉港澳台司法协助

### 6.1 认可台湾地区判决

**申请条件：**
- 判决已生效
- 判决不违反一个中国原则
- 不违反大陆法律的基本原则

**不予认可情形：**
- 违反一个中国原则
- 违反大陆法律的基本原则
- 存在虚假诉讼

## 七、适用要点汇总表

### 7.1 证据认定标准

| 证据类型 | 认定标准 |
|----------|----------|
| 书证 | 原件/副本/节录本；复制件的真实性 |
| 物证 | 原物；复制品需说明 |
| 证人证言 | 出庭作证；经质证 |
| 鉴定意见 | 资质；程序合法；结论明确 |
| 电子数据 | 完整性；来源可靠 |

### 7.2 诉讼时效期间

| 类型 | 期间 | 起算 |
|------|------|------|
| 普通 | 3年 | 知道或应当知道 |
| 最长 | 20年 | 权利受损之日 |
| 人身损害 | 1年/3年 | 知道或应当知道 |

### 7.3 执行措施类型

| 措施类型 | 具体内容 |
|----------|----------|
| 查询 | 存款、证券、车辆等 |
| 冻结 | 银行存款、股权 |
| 划拨 | 存款、收入 |
| 查封 | 不动产、车辆 |
| 扣押 | 动产 |
| 拍卖/变卖 | 查封扣押财产 |
| 搜查 | 隐匿财产 |
| 限制高消费 | 高消费行为 |
| 纳入失信名单 | 失信被执行人 |
