# 裁判要旨精选（上中册）民商事篇

本页面汇总《最高人民法院裁判要旨精选》上册和中册民商事篇的核心裁判要旨，涵盖法人、民事行为效力、代表、物权、抵押、质押、公司担保、保证合同、合同订立与效力、合同履行、违约责任、买卖合同、借款合同、建设工程合同、合伙、股权转让、公司决议等专题。

---

## 一、民法总则与民事行为效力

### 1.1 法人

#### 法人的基本分类

| 分类标准 | 类型 | 举例 |
|----------|------|------|
| 目的 | 营利法人、非营利法人、特别法人 | 公司、基金会、机关法人 |
| 组织形式 | 社团法人、财团法人 | 公司法人、基金会 |
| 责任 | 有限、无限、连带 | 有限责任公司、合伙企业 |

#### 法定代表人

**《民法典》第61条**
依照法律或法人章程规定，代表法人从事民事活动的负责人，为法人的法定代表人。

**法定代表人的行为的效力**
| 情形 | 效力归属 |
|------|----------|
| 以法人名义实施的行为 | 法人承担责任 |
| 超越权限（善意相对人） | 法人不能对抗 |
| 违反内部限制（恶意相对人） | 法人可对抗 |

#### 法人分支机构

| 类型 | 签约能力 | 责任承担 |
|------|----------|----------|
| 有独立财产的分支机构 | 可独立签约 | 分支机构先承担责任，不足由法人承担 |
| 无法人分支机构的 | 无签约能力 | 法人直接承担责任 |

### 1.2 民事行为效力

#### 有效民事法律行为的要件

| 要件 | 内容 | 缺后果 |
|------|------|--------|
| 行为人具有相应民事行为能力 | 完全民事行为能力 | 限制行为能力人超能力行为效力待定 |
| 意思表示真实 | 不存在欺诈、胁迫、重大误解 | 可撤销 |
| 不违反法律、行政法规强制性规定 | 强制性规定不限于效力性规定 | 无效 |
| 不违背公序良俗 | 社会公共利益、道德准则 | 无效 |

#### 无效民事行为的类型

**《民法典》第154条**
行为人与相对人恶意串通，损害他人合法权益的民事法律行为无效。

**典型无效情形**
| 情形 | 说明 |
|------|------|
| 恶意串通 | 通谋实施，损害第三人利益 |
| 违反强制性规定 | 效力性强制性规定 |
| 违背公序良俗 | 违背公共秩序、善良风俗 |
| 虚假表示 | 双方虚假行为无效 |

#### 可撤销民事行为的类型

| 类型 | 撤销权人 | 除斥期间 |
|------|----------|----------|
| 欺诈 | 受欺诈方 | 知道或应当知道之日起1年 |
| 胁迫 | 受胁迫方 | 胁迫行为终止之日起1年 |
| 重大误解 | 误解方 | 知道或应当知道之日起3个月 |
| 显失公平 | 受不利方 | 知道或应当知道之日起1年 |

### 1.3 代理

#### 代理的基本类型

| 类型 | 特征 | 责任 |
|------|------|------|
| 委托代理 | 基于被代理人授权 | 被代理人对代理行为负责 |
| 法定代理 | 基于法律规定 | 法定代理人对代理行为负责 |

#### 表见代理

**《民法典》第172条**
行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效。

**构成要件**
| 要件 | 内容 |
|------|------|
| 外观要件 | 存在代理权的外观 |
| 主观要件 | 相对人善意且无过失 |
| 时间要件 | 代理行为在外观存续期间 |

## 二、物权

### 2.1 物权保护的基本原则

#### 物权公示原则

| 财产类型 | 公示方式 | 效力 |
|----------|----------|------|
| 动产 | 交付 | 交付生效 |
| 不动产 | 登记 | 登记生效 |
| 船舶、航空器、机动车 | 登记 | 登记对抗 |

#### 物权优先效力

| 优先类型 | 适用情形 |
|----------|----------|
| 物权优先于债权 | 特定物上既有物权又有债权时 |
| 后设立物权优先于先设立物权 | 抵押权顺位 |
| 公示的物权优先于未公示的物权 | 动产抵押登记与否 |

### 2.2 所有权

#### 所有权取得

| 方式 | 要件 | 效力 |
|------|------|------|
| 买卖 | 交付+移转登记 | 继受取得 |
| 赠与 | 交付或登记 | 继受取得 |
| 建造 | 建造完成 | 原始取得 |
| 拾得遗失物 | 公告期满无人认领 | 国家取得 |

#### 善意取得

**《民法典》第311条**
无处分权人将不动产或者动产转让给受让人的，受让人取得该财产的所有权。

**善意取得的要件**
| 要件 | 内容 |
|------|------|
| 无权处分 | 出让人无处分权 |
| 合理价格 | 以合理价格转让 |
| 公示 | 已交付或登记 |
| 善意 | 受让人善意且无过失 |

### 2.3 共有

#### 按份共有

| 权利 | 内容 |
|------|------|
| 份额权 | 按份额享有所有权 |
| 分割请求权 | 可随时请求分割 |
| 处分权 | 可转让份额 |
| 优先购买权 | 其他共有人出售份额时 |

#### 共同共有

| 类型 | 说明 |
|------|------|
| 夫妻共有 | 婚姻关系存续期间所得 |
| 家庭共有 | 家庭成员共同生活形成 |
| 遗产分割前共有 | 继承人共同继承 |

## 三、抵押

### 3.1 抵押权的设立

#### 可抵押财产范围

**可以抵押的财产**
1. 建筑物和其他土地附着物
2. 建设用地使用权
3. 土地承包经营权
4. 生产设备、原材料、半成品、产品
5. 正在建造的建筑物、船舶、航空器
6. 交通运输工具

**不得抵押的财产**
1. 土地所有权
2. 宅基地、自留地、自留山使用权
3. 学校、幼儿园、医疗机构等公益设施
4. 所有权不明或有争议的财产
5. 被查封、扣押、监管的财产

### 3.2 抵押权的效力

#### 抵押担保的范围

| 项目 | 是否包含 |
|------|----------|
| 本金 | 是 |
| 利息 | 是 |
| 违约金 | 是 |
| 损害赔偿金 | 是 |
| 实现抵押权的费用 | 是 |

#### 抵押权顺位

| 顺位确定规则 | 说明 |
|--------------|------|
| 登记先后 | 已登记的优先于未登记 |
| 同日登记 | 按债权比例清偿 |
| 均未登记 | 按债权比例清偿 |

### 3.3 最高额抵押

**《民法典》第420条**
为担保债务的履行，债务人或者第三人对一定期间内将要连续发生的债权提供担保财产的，债务人不履行到期债务或者发生当事人约定的实现抵押权的情形，抵押权人有权在最高债权额限度内就该担保财产优先受偿。

## 四、质押

### 4.1 动产质押

#### 质权的设立

**设立条件**
| 条件 | 内容 |
|------|------|
| 质押合同 | 书面形式 |
| 交付 | 现实交付或指示交付 |

**质权的效力**
| 效力 | 内容 |
|------|------|
| 优先受偿 | 就质物变价款优先受偿 |
| 孳息收取 | 质权人可收取孳息（扣除费用后） |
| 质物保全 | 质物价值减少时可要求恢复或提供担保 |

### 4.2 权利质押

| 权利类型 | 设立方式 |
|----------|----------|
| 汇票、本票、支票 | 交付权利凭证 |
| 债券、存款单 | 交付或登记 |
| 股票、股份 | 证券登记结算机构登记或工商登记 |
| 知识产权 | 主管部门登记 |

## 五、保证合同

### 5.1 保证的方式

| 方式 | 特征 | 保证人权利 |
|------|------|------------|
| 一般保证 | 债务人不能履行时承担责任 | 先诉抗辩权 |
| 连带保证 | 与债务人连带承担责任 | 无先诉抗辩权 |

### 5.2 保证期间

| 类型 | 期限 | 起算 |
|------|------|------|
| 未约定 | 6个月 | 主债务履行期限届满 |
| 约定不明 | 2年 | 主债务履行期限届满 |
| 约定明确 | 按约定 | 主债务履行期限届满 |

### 5.3 保证人的权利

| 权利 | 内容 |
|------|------|
| 主债务抗辩权 | 保证人可主张债务人对债权人的抗辩 |
| 追偿权 | 代为清偿后可向债务人追偿 |
| 抗辩独立权 | 保证人可主张一般债务人的抗辩 |

## 六、合同订立与效力

### 6.1 合同订立的程序

#### 要约与承诺

| 要素 | 要约 | 承诺 |
|------|------|------|
| 定义 | 向特定人发出的订立合同的意思表示 | 受要约人同意要约的意思表示 |
| 效力 | 可撤回、撤销（受要约人未承诺前） | 生效后合同成立 |
| 失效 | 拒绝、超期未答复、实质性变更 | 新要约 |

#### 合同成立的认定

| 情形 | 认定规则 |
|------|----------|
| 签字或盖章 | 当事人签字或盖章时成立 |
| 实际履行 | 主要义务已履行且对方接受 |
| 确认书 | 双方签订确认书时成立 |

### 6.2 合同效力

#### 效力待定合同

| 类型 | 情形 | 追认 |
|------|------|------|
| 限制行为能力人实施 | 超能力范围的合同 | 法定代理人追认 |
| 无权代理人实施 | 无代理权、超越权限、代理权终止 | 被代理人追认 |

#### 合同无效的后果

| 后果 | 内容 |
|------|------|
| 返还财产 | 依据无效合同取得的财产应返还 |
| 赔偿损失 | 有过错方赔偿对方损失 |
| 收缴 | 恶意串通损害国家利益予以收缴 |

## 七、合同履行

### 7.1 合同履行的原则

| 原则 | 内容 | 法律依据 |
|------|------|----------|
| 全面履行 | 按约定全面履行 | 《民法典》第509条 |
| 诚实信用 | 保密、协助、通知 | 《民法典》第509条 |
| 绿色履行 | 节约资源、保护环境 | 《民法典》第509条 |

### 7.2 合同履行的抗辩权

| 抗辩权 | 适用条件 | 效力 |
|--------|----------|------|
| 同时履行抗辩权 | 双务合同、对方未履行 | 一时性阻却 |
| 先履行抗辩权 | 有先后顺序、先履行方未履行 | 一时性阻却 |
| 不安抗辩权 | 后履行方有经营恶化等 | 一时性阻却 |

### 7.3 情势变更

**《民法典》第533条**
合同成立后，合同的基础条件发生了当事人在订立合同时无法预见的、不属于商业风险的重大变化，继续履行合同对于当事人一方明显不公平的，受不利影响的当事人可以与对方重新协商；在合理期限内协商不成的，当事人可以请求人民法院或者仲裁机构变更或者解除合同。

## 八、违约责任

### 8.1 违约责任的承担方式

| 方式 | 内容 | 适用条件 |
|------|------|----------|
| 继续履行 | 按合同约定履行 | 能够履行 |
|采取补救措施 | 修理、更换、重作 | 可以补救 |
| 赔偿损失 | 赔偿实际损失 | 造成损失 |
| 支付违约金 | 按约定支付违约金 | 约定违约金 |

### 8.2 损失赔偿的范围

**完全赔偿原则**
- 直接损失：现有财产的减少
- 间接损失：可得利益的损失
- 不得超过违约方订立合同时预见到或应当预见到的损失

### 8.3 违约金

| 类型 | 规则 |
|------|------|
| 约定违约金 | 当事人约定 |
| 过高调整 | 超过损失的30%可申请减少 |
| 过低调整 | 低于实际损失可申请增加 |

### 9.1 买卖合同的基本规则

#### 出卖人的义务

| 转移所有权 | 动产交付、不动产登记 |

|------|--------------|

## 十一、建设工程合同

### 11.1 建设工程合同的效力

#### 合同无效情形

| 情形 | 后果 |
|------|------|
| 承包人无资质 | 无效 |
| 借用资质 | 无效 |
| 违法分包 | 无效 |
| 转包 | 无效 |
| 未招标或虚假招标（大型工程） | 无效 |

### 11.2 工程价款优先受偿权

**《民法典》第807条**
发包人未按约定支付工程价款的，承包人可以催告发包人在合理期限内支付。发包人逾期不支付的，承包人可以与发包人协议将该工程折价，也可以请求法院将该工程依法拍卖。

**优先受偿的范围**
- 工程价款本金
- 承包人实际支出的人工费、材料费等
- 不包括利息、违约金、损害赔偿金

## 十二、合伙

### 12.1 合伙的基本类型

| 类型 | 特征 | 责任 |
|------|------|------|
| 普通合伙 | 全体合伙人无限连带责任 | 无限连带责任 |
| 有限合伙 | 至少一个有限合伙人 | 有限合伙人以其认缴出资为限 |

### 12.2 合伙事务执行

| 类型 | 执行方式 |
|------|----------|
| 共同执行 | 全体合伙人共同执行 |
| 委托执行 | 委托一个或数个合伙人执行 |
| 约定执行 | 按合伙协议约定执行 |

## 十三、股权转让

### 13.1 股权转让的基本规则

#### 转让限制

| 公司类型 | 限制规则 |
|----------|----------|
| 有限责任公司 | 其他股东过半数同意+优先购买权 |
| 股份有限公司 | 一般无限制（发起人股份有限制） |

#### 股权转让的效力

| 要件 | 效力 |
|------|------|
| 股权转让协议生效 | 约束协议双方 |
| 变更登记 | 对抗第三人 |

### 13.2 股权优先购买权

**行使条件**
1. 有限责任公司股东向外转让股权
2. 其他股东在同等条件下优先
3. 应在通知期限内行使

---

## 十四、公司决议

### 14.1 公司决议的效力类型

| 类型 | 情形 | 法律后果 |
|------|------|----------|
| 有效 | 符合法律规定和章程 | 决议有效 |
| 无效 | 内容违反法律、行政法规 | 自始无效 |
| 可撤销 | 程序违法、内容违章、超越权限 | 可撤销 |

### 14.2 无效或可撤销的情形

**无效情形**
1. 内容违反法律、行政法规强制性规定
2. 侵害股东合法权益

**可撤销情形**
1. 会议召集程序、表决方式违反法律、行政法规
2. 内容违反公司章程
3. 决议超越权限
