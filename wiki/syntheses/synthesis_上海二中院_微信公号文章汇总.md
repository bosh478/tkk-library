## 一、至正法律研究专栏

### 1.1 刑法修正案（十二）专题

**重点内容**：贪污贿赂犯罪修改

**修正要点**：
- 加大对行贿犯罪的惩处力度
- 完善受贿犯罪构成要件
- 强化腐败犯罪资产追缴

### 1.2 贪污贿赂犯罪常见认识误区

**误区一**：占有公共财物后用于公务或社会公益，不算贪污
- **纠正**：贪污罪构成不取决于赃款去向，即使用于公务或社会捐赠，仍构成贪污
- **依据**：《关于办理贪污贿赂刑事案件适用法律若干问题的解释》第十六条第一款

**误区二**：临时工不是国家工作人员，不能构成贪污受贿罪
- **纠正**：认定国家工作人员以是否从事公务为根据，不取决于身份编制
- **依据**：《全国法院审理经济犯罪案件工作座谈会纪要》

**误区三**：收了钱事没办成把钱退了，不算受贿
- **纠正**：受贿罪不以实际谋取利益为必要，承诺为他人谋取利益并收受财物即构成既遂

**误区四**：节假日收受礼金礼卡是人情往来
- **纠正**：收受下属或管理服务对象财物累计超3万元，可能影响职权行使的，视为承诺为他人谋取利益

**误区五**：打个借条就没事，大不了还上
- **纠正**：以借为名索取或收受财物为他人谋取利益的，可能被认定为受贿

**误区六**：事后收点感谢费不算受贿
- **纠正**：事后基于履职事由收受他人财物，构成"事后受贿"

**误区七**：离退休后收受财物不算受贿
- **纠正**：约定离职后收受财物以受贿论处；退休后利用原职权为他人谋取不正当利益，构成利用影响力受贿罪

**误区八**：别人打着旗号收钱，不参与就没事
- **纠正**：特定关系人收受财物，国家工作人员知情后未退还或上交的，认定国家工作人员具有受贿故意

**误区九**：没谈事情收了钱没承诺，不算受贿
- **纠正**：明知他人有具体请托事项而收受财物的，视为承诺为他人谋取利益

**误区十**：受贿后上交就不再追究
- **纠正**：受贿后上交是退赃表现，不影响受贿罪成立，但可作为从轻情节

|------|----------|
| 票据诈骗罪 | 票据签发、取得、使用中的欺骗行为 |
| 挪用公款罪 | 公款归个人使用的认定 |
| 徇私枉法罪 | 司法工作人员徇私枉法行为 |
| 寻衅滋事罪 | 与故意毁坏财物罪的区分 |
| 敲诈勒索罪 | 恐吓行为的认定 |
| 污染环境罪 | 行为与结果的因果关系 |
