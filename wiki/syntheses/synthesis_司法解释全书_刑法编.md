# 司法解释全书_刑法编核心要点

本页面汇总《新编最高人民法院最高人民检察院司法解释全书》（2023年）刑法编核心司法解释要点，按刑法分则章节分类整理。

---

## 一、危害国家安全罪

### 司法解释要点

**《最高人民法院关于审理为境外窃取、刺探、收买、非法提供国家秘密、情报案件具体应用法律若干问题的解释》**（法释〔2001〕4号）

| 情形 | 法定刑 |
|------|--------|
| 窃取机密级国家秘密/三项以上秘密级国家秘密/造成其他特别严重损害 | 五年以上十年以下有期徒刑，可以并处没收财产 |
| 窃取绝密级国家秘密/三项以上机密级国家秘密/造成其他特别严重损害 | 十年以上有期徒刑、无期徒刑，可以并处没收财产 |
| 危害特别严重、情节特别恶劣 | 死刑，可以并处没收财产 |
| 窃取秘密级国家秘密或情报，情节较轻 | 五年以下有期徒刑、拘役、管制或剥夺政治权利，可以并处没收财产 |

**关键概念界定**：
- "国家秘密"：依照《保守国家秘密法》确定
- "情报"：关系国家安全和利益、尚未公开或依规定不应公开的事项
- 通过互联网将国家秘密非法发送给境外机构的，以境外窃取国家秘密罪定罪

## 二、危害公共安全罪

### 司法解释要点

#### 1. 交通肇事罪

**《最高人民法院关于审理交通肇事刑事案件具体应用法律若干问题的解释》**（法释〔2000〕33号）

**基本量刑标准**：

| 档次 | 情形 |
|------|------|
| 三年以下有期徒刑或拘役 | 死亡一人/重伤三人以上，负事故全部或主要责任；死亡三人以上，负事故同等责任；无能力赔偿30万元以上 |
| 三年以上七年以下有期徒刑 | 死亡二人以上/重伤五人以上，负事故全部或主要责任；死亡六人以上，负事故同等责任；无能力赔偿60万元以上 |

**加重情形**：
- 交通肇事后逃逸：行为人具有上述情形，为逃避法律追究而逃跑
- 因逃逸致人死亡：被害人因得不到救助而死亡
- 单位主管人员指使、强令他人违章驾驶造成重大交通事故，以交通肇事罪论

#### 2. 危险物质犯罪

**《最高人民法院、最高人民检察院关于办理非法制造、买卖、运输、储存毒鼠强等禁用剧毒化学品刑事案件具体应用法律若干问题的解释》**（法释〔2003〕14号）

- 50克以上/饵料2千克以上，或致人重伤、死亡/造成财产损失万元以上：三年以上十年以下有期徒刑
- 500克以上/饵料20千克以上，或致人重伤、死亡/造成财产损失20万元以上：十年以上有期徒刑、无期徒刑或死刑

#### 3. 破坏电信设施罪

**《最高人民法院关于审理破坏公用电信设施刑事案件具体应用法律若干问题的解释》**（法释〔2004〕21号）

- 危害公共安全：三年以上七年以下有期徒刑
- 严重后果：七年以上有期徒刑

#### 4. 枪支弹药爆炸物犯罪

**《最高人民法院、最高人民检察院关于办理涉以压缩气体为动力的枪支、气枪铅弹刑事案件定罪量刑问题的批复》**（法释〔2018〕8号）

综合考虑涉案枪支的外观、材质、发射物、购买场所和渠道、价格、用途、致伤力大小、是否易于改制提升致伤力，以及行为人的主观认知、动机目的、一贯表现、违法所得、是否规避调查等情节。

## 三、破坏社会主义市场经济秩序罪

### 司法解释要点

#### 1. 走私犯罪

**《最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释》**

| 罪名 | 数额标准 |
|------|----------|
| 走私武器、弹药罪 | 走私军用子弹十发以上、军用枪支二支以上等 |
| 走私假币罪 | 走私伪造的货币总面额二千元以上/币量二百张以上 |
| 走私文物罪 | 走私国家禁止出口二级文物二件以下等 |

#### 2. 危害食品安全犯罪

**《最高人民法院、最高人民检察院关于办理危害食品安全刑事案件适用法律若干问题的解释》**

| 情形 | 定罪量刑 |
|------|----------|
| 生产、销售病死、死因不明畜类肉制品等 | 三年以下有期徒刑或拘役 |
| 婴幼儿食品/等特定产品 | 加重处罚 |
| 致人死亡/特别严重情节 | 死刑 |

#### 3. 药品安全犯罪

**《最高人民法院、最高人民检察院关于办理危害药品安全刑事案件适用法律若干问题的解释》**

- 生产、销售假药：三年以下有期徒刑或拘役
- 生产、销售劣药：三年以上十年以下有期徒刑
- 致人死亡/特别严重情节：十年以上有期徒刑、无期徒刑或死刑

#### 4. 侵犯知识产权犯罪

**《最高人民法院、最高人民检察院关于办理侵犯知识产权刑事案件具体应用法律若干问题的解释（三）》**

| 违法所得 | 定罪 |
|----------|------|
| 数额较大（个人2万以上/单位10万以上） | 三年以下有期徒刑 |
| 数额巨大（个人25万以上/单位100万以上） | 三年以上十年以下有期徒刑 |

#### 5. 非法经营犯罪

**《最高人民法院、最高人民检察院关于办理非法从事资金支付结算业务、非法买卖外汇刑事案件适用法律若干问题的解释》**

- 非法从事资金支付结算/非法买卖外汇：非法经营罪
- 数额500万元以上/违法所得10万元以上：五年以下有期徒刑
- 数额2500万元以上/违法所得50万元以上：五年以上有期徒刑

## 四、侵犯公民人身权利、民主权利罪

### 司法解释要点

#### 1. 拐卖妇女、儿童罪

**《最高人民法院关于审理拐卖妇女儿童犯罪案件具体应用法律若干问题的解释》**（法释〔2016〕28号）

- 采取欺骗、利诱等手段使婴幼儿脱离监护人，视为"偷盗婴幼儿"
- 医疗机构工作人员以非法获利为目的出卖儿童，以拐卖儿童罪论
- 以介绍婚姻为名采取非法扣押证件、限制人身自由等方式出卖妇女，以拐卖妇女罪追究
- "儿童"指不满十四周岁（不满一周岁为婴儿，一周岁以上不满六周岁为幼儿）

#### 2. 网络诽谤犯罪

**《最高人民法院、最高人民检察院关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》**（法释〔2013〕21号）

"情节严重"认定标准：
- 实际被点击浏览次数达五千次以上或被转发五百次以上
- 造成被害人精神失常、自残、自杀等严重后果
- 二年内曾因诽谤受过行政处罚又诽谤他人

"严重危害社会秩序和国家利益"情形：
- 引发群体性事件/公共秩序混乱/民族宗教冲突
- 诽谤多人造成恶劣影响/损害国家形象/造成恶劣国际影响

#### 3. 侵犯公民个人信息罪

**《最高人民法院、最高人民检察院关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》**

| 信息类型 | "情节严重"标准 |
|----------|----------------|
| 行踪轨迹信息、通信内容、征信信息、财产信息 | 50条以上 |
| 住宿信息、通信记录、健康生理信息、交易信息等 | 500条以上 |
| 其他个人信息 | 5000条以上 |

## 五、侵犯财产罪

### 司法解释要点

#### 1. 诈骗罪

**《最高人民法院、最高人民检察院关于办理诈骗刑事案件具体应用法律若干问题的解释》**

| 数额 | 量刑 |
|------|------|
| 三千元至一万元以上（各地不同） | 三年以下有期徒刑、拘役或管制 |

| 五十万元以上 | 十年以上有期徒刑或无期徒刑 |

**情节加重**：发送诈骗信息/拨打诈骗电话500人次以上/诈骗残疾人、老年人、孕产妇等

#### 2. 盗窃罪

**《最高人民法院、最高人民检察院关于办理盗窃刑事案件适用法律若干问题的解释》**

| 数额 | 量刑 |
|------|------|
| 一千元至三千元以上（各地不同） | 三年以下有期徒刑、拘役或管制 |
| 三万元至十万元以上（各地不同） | 三年以上十年以下有期徒刑 |
| 三十万元至五十万元以上（各地不同） | 十年以上有期徒刑或无期徒刑 |

**"多次盗窃"**：二年内盗窃三次以上

#### 3. 敲诈勒索罪

**《最高人民法院、最高人民检察院关于办理敲诈勒索刑事案件具体应用法律若干问题的解释》**

| 数额 | 量刑 |
|------|------|
| 二千元至五千元以上（各地不同） | 三年以下有期徒刑、拘役或管制 |
| 三万元至十万元以上（各地不同） | 三年以上十年以下有期徒刑 |
| 三十万元至五十万元以上（各地不同） | 十年以上有期徒刑 |

#### 4. 非法放贷犯罪

**《最高人民法院、最高人民检察院、最高人民检察院、公安部、司法部关于办理非法放贷刑事案件若干问题的意见》**（2019）

- 情节严重：年利率超过36%非法放贷，违法所得8万元以上/个人非法放贷累计200万元以上
- 黑恶势力非法放贷，可按相应数额标准的50%确定

## 六、妨害社会管理秩序罪

### 司法解释要点

#### 1. 邪教组织犯罪

**《最高人民法院、最高人民检察院关于办理组织、利用邪教组织破坏法律实施等刑事案件适用法律若干问题的解释》**（法释〔2017〕3号）

| 情形 | 量刑 |
|------|------|
| 建立邪教组织/聚众围冲国家机关/发展成员50人以上/敛财100万元以上等 | 三年以上七年以下有期徒刑 |
| 数量或数额达到上述标准五倍以上/造成特别严重后果 | 七年以上有期徒刑或无期徒刑 |
| 社会危害较轻/数量数额达到五分之一以上 | 三年以下有期徒刑 |

**"情节较轻"情形**：行为人真诚悔罪、明确退出邪教组织

#### 2. 毒品犯罪

**《最高人民法院关于审理毒品犯罪案件适用法律若干问题的解释》**

| 毒品类型 | 数量标准 |
|----------|----------|
| 海洛因/甲基苯丙胺 | 10克以上不满100克：三年以下；100克以上：七年以上 |
| 鸦片 | 200克以上不满1000克：三年以下；1000克以上：十五年 |

#### 3. 扰乱法庭秩序罪

**《最高人民法院关于进一步推进案件繁简分流优化司法资源配置的若干意见》**

依法维护法庭秩序，保障庭审活动正常进行。

#### 4. 组织考试作弊罪

**《最高人民法院、最高人民检察院关于办理组织考试作弊等刑事案件适用法律若干问题的解释》**

| 情形 | 定罪 |
|------|------|
| 公务员录用考试/专业技术资格考试等 | 三年以下有期徒刑或拘役 |
| 造成严重后果/涉及三十人以上 | 三年以上七年以下有期徒刑 |

#### 5. 传染病防治犯罪

**《最高人民法院、最高人民检察院关于办理妨害预防、控制突发传染病疫情等灾害的刑事案件具体应用法律若干问题的解释》**（法释〔2003〕8号）

- 故意传播突发传染病病原体：以危险方法危害公共安全罪
- 拒绝检疫、强制隔离，过失传播传染病：过失以危险方法危害公共安全罪

## 八、贪污贿赂罪

### 司法解释要点

#### 1. 贪污罪、受贿罪

**《最高人民法院、最高人民检察院关于办理贪污贿赂刑事案件适用法律若干问题的解释》**（法释〔2016〕9号）

| 数额/情节 | 量刑 |
|------------|------|
| 3万元以上不满20万元 | 三年以下有期徒刑或拘役，并处罚金 |
| 20万元以上不满300万元 | 三年以上十年以下有期徒刑，并处罚金或没收财产 |
| 300万元以上 | 十年以上有期徒刑、无期徒刑或死刑，并处罚金或没收财产 |

**特别严重情节**：
- 贪污1万元以上不满3万元：救灾抢险/曾受处分/曾受刑事追究/赃款用于非法活动/拒不配合追缴
- 受贿1万元以上不满3万元：多次索贿/造成损失/为他人谋取职务提拔调整

**终身监禁**：贪污受贿数额特别巨大、情节特别严重、社会影响特别恶劣、给国家和人民利益造成特别重大损失，可以判处死刑缓期二年执行，同时裁判决定终身监禁

#### 2. 挪用公款罪

| 情形 | 数额标准 |
|------|----------|
| 进行非法活动 | 3万元以上：追究刑事责任 |
| 进行营利活动/超过三个月未还 | 5万元以上：数额较大；500万元以上：数额巨大 |
| 进行非法活动情节严重 | 300万元以上 |

**"挪用公款归个人使用"**：包括本人使用或给他人使用；私有公司、私有企业使用的属于归个人使用

#### 3. 行贿罪

| 情形 | 数额 |
|------|------|
| 基本定罪 | 3万元以上 |
| 情节严重 | 100万元以上/50万以上+向三人以上行贿等 |
| 情节特别严重 | 500万元以上 |

**不适用缓刑和免予刑事处罚**：向三人以上行贿/因行贿受过处罚/为实施违法犯罪活动而行贿/造成严重危害后果

#### 4. 利用影响力受贿罪

定罪量刑标准参照受贿罪规定执行。对有影响力的人行贿罪参照行贿罪规定执行。

#### 5. 罚金标准

| 量刑档次 | 罚金 |
|----------|------|
| 三年以下有期徒刑或拘役 | 10万元以上50万元以下 |
| 三年以上十年以下有期徒刑 | 20万元以上犯罪数额二倍以下 |
| 十年以上有期徒刑或无期徒刑 | 50万元以上犯罪数额二倍以下 |

## 九、渎职罪

### 司法解释要点

**《最高人民法院、最高人民检察院关于办理渎职刑事案件适用法律若干问题的解释（一）》**（法释〔2012〕18号）

**定罪量刑标准**：

| 情形 | 标准 |
|------|------|
| 致使公共财产、国家和人民利益遭受重大损失 | 造成死亡1人以上/重伤3人以上/轻伤9人以上/经济损失30万元以上等 |
| 情节特别严重 | 造成死亡5人以上/重伤10人以上/经济损失100万元以上等 |

**主体范围**：
- 国家机关工作人员
- 依法或受委托行使国家行政管理职权的公司、企业、事业单位工作人员

**数罪并罚**：受贿并徇私舞弊构成犯罪的，除刑法另有规定外，以受贿罪和渎职犯罪数罪并罚

**食品安全监管渎职**：
- 同时构成食品监管渎职罪和其他渎职犯罪，依照处罚较重的规定定罪
- 不构成食品监管渎职罪但构成其他渎职犯罪，依照该其他犯罪定罪

## 十、军人违反职责罪

### 立案标准要点

**《军人违反职责罪案件立案标准的规定》**（2013年）

| 罪名 | 立案标准 |
|------|----------|
| 战时违抗命令罪 | 扰乱作战部署/贻误战机/造成人员伤亡/武器装备损毁影响作战任务 |
| 投降罪 | 战场上自动放下武器投降敌人 |
| 战时临阵脱逃罪 | 战斗中逃离战斗岗位 |
| 擅离、玩忽军事职守罪 | 造成重大任务不能完成/死亡1人或重伤3人以上/武器装备丢失被盗 |
| 阻碍执行军事职务罪 | 以暴力、威胁方法阻碍执行职务 |

### 二、共同犯罪认定要点

1. **贪污共犯**：与国家工作人员勾结，利用其职务便利，共同侵吞、窃取、骗取公共财物，以贪污罪共犯论处
2. **职务侵占共犯**：与公司企业人员勾结，利用其职务便利，共同将单位财物非法占为己有，以职务侵占罪共犯论处
3. **主从犯认定**：分别利用各自职务便利共同侵占，按照主犯的犯罪性质定罪

### 三、单位犯罪要点

1. 国有、集体所有的公司、企业、事业单位以及具有法人资格的合资、合作、独资、私营公司、企业，均可成为单位犯罪主体
2. 为进行违法犯罪活动而设立的公司、企业实施犯罪，不以单位犯罪论处
3. 盗用单位名义实施犯罪，违法所得由个人私分，依照自然人犯罪规定定罪处罚

### 四、缓刑适用限制

**不适用缓刑**：
- 行贿犯罪中向三人以上行贿/因行贿受过处罚/为实施违法犯罪活动而行贿/造成严重危害后果
- 拒不认罪悔罪或不履行财产性判项的贪污贿赂罪犯，一般不予假释

### 五、从重处罚情节

1. 索取未成年人、在校学生、老年人、残疾人财物
2. 挪用救灾、抢险、防汛、优抚、扶贫、移民、救济特定款物
3. 拒不交代赃款赃物去向或拒不配合追缴
4. 造成恶劣影响或其他严重后果
