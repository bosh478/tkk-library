## 一、案件信息公开工作规定

### 1.1 信息公开范围

**应当公开的案件信息**：
- 案件程序性信息
- 重要案件信息
- 法律文书
- 重要案件信息

### 1.2 信息公开平台

人民检察院案件信息公开平台：
- 案件信息公开网
- 人民检察院案件信息公开微信平台
- 其他便民服务平台

### 1.3 信息公开内容

| 类型 | 内容 |
|------|------|
| 程序性信息 | 案件受理、办理进展 |
| 重要案件信息 | 重大案件信息 |
| 法律文书 | 起诉书、抗诉书、不起诉决定书 |
| 工作文书 | 纠正违法通知书等 |

### 1.4 保密规定

- 涉及国家秘密的案件信息不得公开
- 涉及未成年人案件信息不得公开
- 涉及当事人隐私的案件信息不得公开

## 二、案件流程监控工作规定

### 2.1 流程监控范围

人民检察院对本院办理的各类案件进行流程监控：
- 侦查活动
- 审查逮捕
- 审查起诉
- 审判监督
- 执行监督

### 2.2 监控内容

| 监控环节 | 监控要点 |
|----------|----------|
| 受理环节 | 是否超期受理 |
| 审查环节 | 是否超期审查 |
| 审批环节 | 审批程序是否规范 |
| 文书环节 | 文书制作是否规范 |
| 送达环节 | 是否及时送达 |

### 2.3 监控方式

- 日常巡查
- 预警提醒
- 专项检查
- 案件质量评查

### 2.4 问题处理

| 问题类型 | 处理方式 |
|----------|----------|
| 程序瑕疵 | 口头提示 |
| 程序违规 | 发出流程监控通知书 |
| 违法违纪 | 移交相关部门处理 |

## 三、行刑反向衔接工作指引

### 3.1 行刑反向衔接概念

行刑反向衔接是指人民检察院在办理刑事案件过程中，发现被不起诉人应当给予行政处罚、行政强制等行政处理，依法移送有关行政机关处理的工作机制。

### 3.2 移送情形

**应当移送行政机关处理的情形**：
- 被不起诉人的行为应当给予行政处罚
- 被不起诉人的行为应当给予行政强制
- 其他应当移送行政机关处理的情形

### 3.3 移送程序

| 阶段 | 内容 |
|------|------|
| 审查 | 审查是否需要移送 |
| 提出建议 | 依法提出检察意见 |
| 送达 | 送达行政机关 |
| 跟踪 | 跟踪了解处理结果 |

### 3.4 跟踪监督

- 跟踪行政机关处理情况
- 发现问题及时纠正
- 确保行政处罚落实到位

## 四、诉讼档案管理办法

### 4.1 档案范围

诉讼档案包括：
- 案件材料
- 法律文书
- 证据材料
- 其他诉讼文书

### 4.2 立卷要求

| 要求类型 | 具体内容 |
|----------|----------|
| 材料收集 | 全面收集、及时归档 |
| 整理装订 | 规范整理、整齐装订 |
| 保管期限 | 根据案件性质确定保管期限 |
| 移交 | 按规定移交档案部门 |

### 4.3 档案利用

- 因工作需要查阅
- 依规办理借阅手续
- 不得遗失、涂改、伪造
