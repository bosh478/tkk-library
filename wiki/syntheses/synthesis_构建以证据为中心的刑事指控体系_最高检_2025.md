## 概述

最高人民检察院重大犯罪检察厅编著，中国检察出版社 2025 年出版。系最高人民检察院检察理论研究重点课题成果，系统阐述构建以证据为中心的刑事指控体系的基本内涵、基本原则、原理方法。

**编委会**：
- 主任：元明
- 副主任：张建忠、张庆彬、郭竹梅
- 主编：肖先华

**核心理念**：
- "努力让人民群众在每一个司法案件中感受到公平正义"
- "高质效办好每一个案件"
- "三个善于"：善于从纷繁复杂的法律事实中准确把握实质法律关系，善于从具体法律条文中深刻领悟法治精神，善于在法理情的有机统一中实现公平正义

---

## 一、背景及意义

### 1.1 改革背景

**习近平法治思想在刑事检察工作中的落实**：
- 检察机关的"四个定位"：法律监督机关、司法机关、保护国家利益和社会公共利益的重要力量，国家监督体系的重要组成部分
- 党的二十大报告强调"加强检察机关法律监督工作"
- 党的二十届三中全会提出"法治是中国式现代化的重要保障"

**以审判为中心的刑事诉讼制度改革的深化**：
- 2014年：党的十八届四中全会提出"推进以审判为中心的诉讼制度改革"
- 2015年：最高检提出"构建以证据为核心的刑事指控体系"
- 2018年："十三五"规划明确构建以证据为核心的刑事犯罪指控体系
- 2023年：《2023-2027年检察改革工作规划》提出健全以证据为核心的刑事指控体系

**高质效办好每一个刑事案件的价值追求**：
- 实体上确保实现公平正义
- 程序上让公平正义更好更快实现
- 效果上让人民群众可感受、能感受、感受到公平正义

### 1.2 改革意义

1. **贯彻证据裁判原则**：保障被告人基本权利，维护司法公正
2. **凸显证据核心地位**：夯实刑事指控基础，提高办案质效
3. **规范证据规则运用**：强化刑事诉讼监督制约体系

---

## 二、主要内涵

### 2.1 刑事指控体系

**概念**：人民检察院在刑事诉讼过程中，以依法追究犯罪嫌疑人、被告人刑事责任为目的，围绕刑事追诉涉及的证明责任、证明对象、证明标准、证据的收集审查运用、出庭指控犯罪、监督配合制约等方面组成的有机整体。

**体系要素**：

| 要素 | 内容 |
|------|------|
| 指控主体 | 检察机关 |
| 指控对象 | 犯罪嫌疑人、被告人 |
| 指控内容 | 定罪指控、量刑建议、涉案财物处置意见 |
| 指控依据 | 实体法、程序法及有关规定 |

### 2.2 以证据为中心

**核心要义**：
- 以审判为中心的实质是以庭审为中心
- 以庭审为中心的实质是以证据为中心
- 证据是构建刑事指控体系的基石

**与刑事检察职能的关系**：

| 环节 | 证据要求 |
|------|----------|
| 程序性事实 | 有证据证明，相关证据已查证属实 |
| 检察侦查 | 全面客观收集证据，严禁刑讯逼供 |
| 审查逮捕 | 有证据证明有犯罪事实，可能判处徒刑以上刑罚 |
| 审查起诉 | 犯罪事实清楚，证据确实充分 |
| 出席法庭 | 以证据为中心开展诉讼活动 |
| 特别程序 | 遵循相应的证明标准 |
| 核准追诉 | 有证据证明存在犯罪事实 |

## 三、基本原则和要求

### 3.1 基本原则

| 原则 | 内容 | 要求 |
|------|------|------|
| 客观公正原则 | 秉持客观公正立场，尊重和保障人权 | 既要追诉犯罪，也要保障无罪的人不受刑事追究 |
| 配合制约原则 | 健全与监察机关、侦查机关、审判机关的配合制约机制 | 形成"大控方"新格局 |
| 证据裁判原则 | 以证据作为认定案件事实的依据 | 突出证据的基础、中心地位 |

### 3.2 基本要求

1. **坚持"三个善于"的办案理念**
2. **系统构建刑事指控体系**
3. **聚焦证据收集审查运用**
4. **强化诉讼监督保障刑事指控**

## 四、证明责任、证明对象和证明标准

### 4.1 证明责任

| 类型 | 责任主体 | 内容 |
|------|----------|------|
| 定罪举证责任 | 检察机关 | 证明被告人有罪 |
| 证据收集合法性举证责任 | 侦查机关 | 证明取证程序合法 |

### 4.2 证明对象

**需要证明的事实**：
1. 定罪事实
2. 量刑事实
3. 涉案财物处理事实
4. 程序性事实

**免证事实**：
- 常识性事实
- 法院生效判决确认的事实
- 仲裁机构生效裁决确认的事实
- 公证机构有效公证文书证明的事实

### 4.3 证明标准

| 类型 | 证明标准 |
|------|----------|
| 定罪证明标准 | 证据确实、充分（排除合理怀疑） |
| 量刑证明标准 | 证据确实、充分 |
| 涉案财物证明标准 | 高度可能性 |
| 程序性事实证明标准 | 有证据证明，相关证据已查证属实 |
| 逮捕证明标准 | 有证据证明有犯罪事实，可能判处徒刑以上刑罚 |
| 核准追诉证明标准 | 有证据证明存在犯罪事实 |

**排除合理怀疑的双重属性**：
- 主观属性：被告人的合理怀疑
- 客观属性：证据间的矛盾和疑点

## 五、证据审查运用

### 5.1 证据审查判断方法

| 方法 | 内容 |
|------|------|
| 主客观相统一 | 既审查客观性证据，也审查主观性证据 |
| 证据印证 | 证据间的相互验证 |
| 合理性审查 | 逻辑法则、生活经验判断 |
| 大数据技术 | 借助现代科技发现证据关联 |
| 专业力量 | 借助有专门知识的人 |

### 5.2 证据的收集

**一般要求**：
- 全面、客观、及时
- 依法收集、固定

**检察职责**：
- 引导侦查
- 补查补正
- 排除非法证据

### 5.3 证据的审查

| 审查内容 | 要点 |
|----------|------|
| 真实性审查 | 证据是否真实，有无伪造、变造 |
| 关联性审查 | 证据与待证事实的关系 |
| 合法性审查 | 收集程序是否合法，有无非法取证 |

### 5.4 证据的运用

**步骤**：
1. 证据出示
2. 质证认证
3. 综合判断
4. 事实认定

**言词证据运用**：
- 印证方法
- 合理性分析
- 经验法则判断

**客观性证据运用**：
- 关联性分析
- 与言词证据相互印证

## 六、出庭指控犯罪

### 6.1 庭前准备

**主要内容**：
1. 熟悉案情，掌握证据
2. 研究法律政策问题
3. 充实专业知识
4. 拟定讯问、询问计划
5. 制定举证质证方案
6. 准备公诉意见

### 6.2 法庭讯问

**目标**：核实案件事实，完善证据体系

**原则**：
- 针对性
- 合法性
- 有效性

### 6.3 举证质证

**基本原则**：
- 合法性
- 关联性
- 系统性
- 有效性

**方法**：
- 分组示证
- 重点质证
- 逻辑论证

### 6.4 法庭辩论

**内容**：
- 发表公诉意见
- 开展法庭辩论
- 应对突发情况
