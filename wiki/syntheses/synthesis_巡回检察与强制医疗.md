## 一、巡回检察工作规定

### 1.1 巡回检察概念

巡回检察是人民检察院对监狱、看守所等监管场所依法履行法律监督职责的重要方式，通过定期或不定期的巡回检察，强化监督实效。

### 1.2 巡回检察内容

| 检察内容 | 具体事项 |
|----------|----------|
| 监管活动 | 羁押、管理、教育等活动是否合法 |
| 安全防范 | 监管场所安全防范措施是否到位 |
| 卫生防疫 | 在押人员卫生防疫是否合规 |
| 权益保障 | 在押人员合法权益是否得到保障 |
| 职务犯罪 | 监管人员职务犯罪线索 |

### 1.3 巡回检察方式

- **常规巡回**：定期全面检察
- **专项巡回**：针对特定问题重点检察
- **机动巡回**：临时机动检察

### 1.4 发现问题处理

| 问题类型 | 处理方式 |
|----------|----------|
| 一般问题 | 提出口头纠正意见 |
| 违法问题 | 发出纠正违法通知书 |
| 职务犯罪 | 依法立案侦查 |
| 重大问题 | 报告上级检察院 |

## 二、强制医疗执行检察办法

### 2.1 强制医疗对象

强制医疗适用于：
- 精神病人
- 无刑事责任能力或限制刑事责任能力
- 有继续危害社会可能

### 2.2 强制医疗执行检察内容

| 检察内容 | 具体事项 |
|----------|----------|
| 收治情况 | 收治程序是否合法 |
| 治疗情况 | 治疗方案是否合理 |
| 日常管理 | 管理活动是否规范 |
| 解除条件 | 是否符合解除强制医疗条件 |

### 2.3 检察监督方式

- 日常检察
- 专项检察
- 巡视检察

### 2.4 强制医疗解除

**解除条件**：
- 经治疗后病情痊愈或好转
- 不再具有人身危险性
- 有合法监护人或近亲属

**解除程序**：
- 强制医疗机构提出解除意见
- 人民检察院审查
- 人民法院决定

## 三、羁押听证办法

### 3.1 羁押听证范围

**可以组织羁押听证的情形**：
- 羁押必要性审查存在重大争议
- 犯罪嫌疑人、被告人对羁押必要性有异议
- 其他需要听证的情形

### 3.2 听证参加人

| 参加人 | 职责 |
|--------|------|
| 主持人 | 主持听证活动 |
| 侦查机关 | 说明羁押理由和依据 |
| 犯罪嫌疑人/被告人 | 表达意见 |
| 辩护人 | 发表辩护意见 |
| 听证员 | 参加听证并发表意见 |

### 3.3 听证程序

| 阶段 | 内容 |
|------|------|
| 准备 | 确定听证参加人、时间和地点 |
| 开始 | 主持人宣布听证纪律和议题 |
| 事实调查 | 侦查机关说明理由 |
| 申辩 | 犯罪嫌疑人/被告人申辩 |
| 辩论 | 各方发表意见 |
| 听证员评议 | 听证员发表意见 |
| 结束 | 宣布听证结束 |

### 3.4 听证意见效力

- 听证意见作为羁押必要性审查的参考
- 人民检察院应当认真研究听证意见
