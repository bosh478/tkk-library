## 一、道路交通事故损害赔偿

### 1.1 责任主体认定

**机动车所有人/管理人：**
- 租赁、借用机动车：使用人为赔偿责任主体
- 实际支配车辆并享有运行利益：实际支配人为赔偿责任主体
- 挂靠经营：被挂靠单位在收取管理费范围内承担连带责任

**特殊情形：**
| 情形 | 责任主体 |
|------|----------|
| 租赁、借用 | 使用人 |
| 转让并交付但未办登记 | 受让人 |
| 挂靠 | 被挂靠单位（连带责任） |
| 套牌 | 出借/套牌双方（连带责任） |
| 拼装/报废车 | 出卖人/使用人（连带责任） |
| 教练车 | 教练员/学员（驾校承担赔偿责任） |

### 1.2 赔偿范围

**人身损害赔偿：**
| 项目 | 计算方式 |
|------|----------|
| 医疗费 | 实际支出 |
| 误工费 | 误工收入 × 误工时间 |
| 护理费 | 护理人员收入 × 护理期限 |
| 残疾赔偿金 | 伤残等级系数 × 年限 × 标准 |
| 死亡赔偿金 | 标准 × 20年（60岁以上每增一岁减一年） |
| 被扶养人生活费 | 扶养年限 × 标准 ÷ 扶养人数 |
| 丧葬费 | 标准 × 6个月 |
| 精神损害抚慰金 | 根据伤残等级确定 |

**财产损失：**
- 车辆维修费
- 车辆所载物品损失
- 车辆施救费
- 停运损失
- 替代性交通工具费

### 1.3 交强险赔偿

**交强险责任限额：**
| 项目 | 限额 |
|------|------|
| 死亡伤残赔偿限额 | 180,000元 |
| 医疗费用赔偿限额 | 18,000元 |
| 财产损失赔偿限额 | 2,000元 |

**赔偿顺序：**
1. 交强险在限额内先行赔偿
2. 超出限额部分，由第三者责任险赔偿
3. 仍有不足，由侵权人赔偿

### 1.4 第三者责任险

**赔偿范围：**
- 被保险人/允许的驾驶人造成的人身/财产损失
- 不赔偿被保险人/驾驶人/本车人员损失

**免赔情形：**
- 故意/违法行为
- 酒驾、毒驾、无证驾驶
- 车辆未年检
- 保险免赔条款约定的情形

**赔偿计算：**
- 总损失 - 交强险赔偿 = 第三者责任险赔偿基数
- 赔偿基数 × 责任比例 × (1 - 免赔率)

## 二、铁路运输人身损害赔偿

### 2.1 责任主体

**铁路运输企业：**
- 铁路旅客伤亡：铁路运输企业赔偿责任
- 路人/其他人员伤亡：视情况认定

**特殊情形：**
| 情形 | 责任认定 |
|------|----------|
| 伤亡人员自身原因 | 铁路运输企业可减轻/免除责任 |
| 不可抗力 | 铁路运输企业不承担责任（但应尽到安全防护义务） |
| 受害人故意 | 铁路运输企业不承担责任 |

### 2.2 赔偿范围

**人身伤亡：**
- 医疗费
- 护理费
- 误工费
- 残疾赔偿金
- 死亡赔偿金
- 被扶养人生活费
- 精神损害抚慰金

**赔偿标准：**
- 适用人身损害赔偿司法解释标准
- 城镇/农村居民标准

### 2.3 限额赔偿

**部分情形适用限额：**
- 限额标准根据法院所在地标准确定
- 限额以下按实际损失赔偿
- 超过限额按限额赔偿

## 三、交通肇事刑事案件

### 3.1 入罪标准

**基本标准：**
| 情形 | 责任要求 | 后果要求 |
|------|----------|----------|
| 死亡1人或重伤3人以上 | 全部/主要责任 | - |
| 死亡3人以上 | 同等责任 | - |
| 财产损失 | 全部/主要责任 | 无力赔偿30万元以上 |

**致人重伤的特殊情形：**
1. 酒后、吸毒后驾驶
2. 无驾驶资格
3. 安全装置不全/失灵
4. 无牌证/报废车辆
5. 严重超载
6. 逃逸

### 3.2 逃逸情节

**交通运输肇事后逃逸：**
- 法定刑：3-7年有期徒刑
- 情节：发生事故后为逃避法律追究而逃跑

**因逃逸致人死亡：**
- 法定刑：7年以上有期徒刑
- 认定：逃逸致被害人死亡

### 3.3 共犯认定

**指使逃逸：**
- 单位主管人员、机动车辆所有人、承包人、乘车人指使肇事人逃逸
- 致使被害人因得不到救助而死亡
- 以交通肇事罪共犯论处

**指使违章：**
- 指使、强令他人违章驾驶造成重大交通事故
- 以交通肇事罪定罪处罚

### 3.4 特别恶劣情节

| 情节 | 标准 |
|------|------|
| 死亡2人以上或重伤5人以上 | 全部/主要责任 |
| 死亡6人以上 | 同等责任 |
| 无力赔偿60万元以上 | 全部/主要责任 |

## 四、保险法司法解释（二）

### 4.1 保险合同成立

**格式条款：**
- 保险人提供的格式合同
- 投保单/保险单等

**说明义务：**
- 保险人应当向投保人说明合同内容
- 对免责条款应当明确说明

**举证责任：**
- 保险人举证已尽说明义务
- 投保人签字/盖章确认

### 4.2 免责条款

**无效情形：**
- 保险人未对免责条款提示/说明
- 免责条款违反法律强制性规定

**免责条款认定：**
- 以足以引起注意的文字、符号、字体提示
- 明确说明内容及法律后果

### 4.3 投保人如实告知

**告知范围：**
- 足以影响保险人决定是否承保/提高保费的重要事实

**故意/重大过失：**
- 故意不告知：不赔+不退保费
- 重大过失不告知：不赔+退还保费

**不可抗辩条款：**
- 超过2年保险人不得解除合同
- 适用前提：合同成立超过2年

## 五、保险法司法解释（三）

### 5.1 人身保险

**死亡保险：**
- 以死亡为给付保险金条件
- 未经被保险人同意，不生效

**受益人：**
- 受益人指定/变更需经被保险人同意
- 未指定受益人：法定继承

**保险金请求权：**
- 被保险人死亡：受益人享有
- 无受益人/受益人先于被保险人死亡：被保险人继承人享有

### 5.2 医疗费用保险

**费用补偿：**
- 适用损失补偿原则
- 不得获利

**保险金计算：**
- 实际医疗费用
- 扣除已从其他途径获得的部分

### 5.3 保险金继承

**遗产认定：**
- 没有指定受益人/受益人丧失/放弃
- 保险金作为遗产

**继承程序：**
- 适用继承法规定
- 清偿被保险人债务

## 六、保险法司法解释（四）

### 6.1 责任保险

**第三人直接请求权：**
- 第三者可要求保险人直接赔偿
- 保险人不得以对被保险人的抗辩对抗第三人

**赔偿范围：**
- 被保险人对第三者依法应负的赔偿责任
- 合理必要的费用

### 6.2 代位求偿

**保险人代位权：**
- 赔偿保险金后代位行使被保险人对第三者请求权
- 范围不超过已赔偿保险金

**被保险人权利：**
- 保险人未赔偿前，可向第三者主张
- 保险人赔偿后，未经保险人同意放弃对第三者权利，无效

### 6.3 保险标的转让

**转让通知：**
- 保险标的转让应当通知保险人
- 经保险人同意继续承保，可变更

**未通知：**
- 保险人不知情，可拒绝赔偿
- 危险程度增加可增加保费/解除合同

## 七、涉执行司法赔偿

### 7.1 执行错误赔偿

**错误执行：**
- 错误查封、扣押、冻结
- 错误拍卖、变卖
- 错误执行财产

**赔偿范围：**
- 本金
- 利息（直接损失）

### 7.2 赔偿程序

**赔偿请求人：**
- 受害人

**赔偿义务机关：**
- 实施错误执行的法院

**程序：**
- 向赔偿义务机关申请
- 不服可向上一级法院申请复议
- 不服可向上一级法院赔偿委员会申请作出赔偿决定

## 八、适用要点汇总表

### 8.1 交通事故责任划分

| 责任 | 比例 |
|------|------|
| 全部责任 | 100% |
| 主要责任 | 70% |
| 同等责任 | 50% |
| 次要责任 | 30% |
| 无责任 | 0% |

### 8.2 交强险赔偿限额

| 情形 | 有责任限额 | 无责任限额 |
|------|------------|------------|
| 死亡伤残 | 180,000元 | 18,000元 |
| 医疗费用 | 18,000元 | 1,800元 |
| 财产损失 | 2,000元 | 100元 |

### 8.3 交通肇事罪量刑档次

| 档次 | 情节 | 法定刑 |
|------|------|--------|
| 基本犯 | 死1人+主责/重伤3人+主责/死3人+同等责/财产损失30万+主责 | 3年以下 |
| 逃逸 | 交通运输肇事后逃逸 | 3-7年 |
| 因逃逸致人死亡 | 逃逸致被害人死亡 | 7年以上 |
