## 一、图书概述

### 1.1 编辑宗旨

《新编最高人民法院司法观点集成（第二版）》是一部可以通览最高人民法院各类司法观点的权威司法实务指导用书。

**三大特点**：

1. **以司法解释为核心**：书中编入的司法观点首先注重从现行有效的司法解释中提炼，突出观点来源的权威性
2. **全面梳理、立体呈现**：全面收集最高人民法院各种政策文件、指导性案例、裁判文书等，形成对司法观点多维度、多层面的立体支撑
3. **去旧选新、强调现行有效**：对最高人民法院公布的各项司法解释、司法文件、指导性案例、裁判文书等进行仔细甄选，对失效内容加以排除，只选取现行有效的文件和资料

- 《最高人民法院公报》

## 三、核心司法观点摘录

### 3.1 《民法典合同编通则解释》的起草思路（001）

**四个工作思路**：

1. **尊重立法原意**：严格依照立法法赋予的司法解释制定权限，坚守不创设新规则的基本立场
2. **坚持问题导向**：以问题为导向，致力于解决实际问题，所提出的方案要具有可操作性
3. **保持司法政策的延续性**：对原《合同法解释一》《合同法解释二》《担保法解释》中与民法典并无冲突且仍然行之有效的规定，尽可能保留
4. **坚持系统观念和辩证思维**：重视制度之间的联系，做到全面解决问题

### 3.2 合同成立的条件（011）

**司法解释规定**（《民法典合同编通则解释》第3条）：
> 当事人对合同是否成立存在争议，人民法院能够确定当事人姓名或者名称、标的和数量的，一般应当认定合同成立。

**必备要件**：当事人姓名或名称 + 标的 + 数量

**编者说明**：合同成立的三要件是最低限度要件，除此之外的内容可以通过合同解释规则或推定规则补充。但价款或报酬作为合同的个别性要素，通常会影响合同的成立。

### 3.3 合同成立与合同生效的区分（012）

| 区别 | 合同成立 | 合同生效 |
|------|----------|----------|
| 解决问题 | 合同是否存在、何时成立的事实问题 | 合同是否合法、是否受法律保护的法律问题 |
| 判断性质 | 事实判断问题 | 法律评价问题 |
| 体现原则 | 合同自由原则 | 国家干预原则 |
| 阶段 | 合同订立阶段 | 合同履行阶段 |

**核心观点**：合同无效、可撤销或者效力待定，都是与合同有效相对应的概念，但合同不生效，则是指合同有效但却未生效的状态（如须经批准的合同在批准前）。

### 3.4 预约合同的认定标准（019）

**司法观点**：预约合同是当事人约定未来订立本约合同的合同。预约合同与本约合同的区别在于：预约合同的标的为订立本约合同的行为，而非本约合同的具体权利义务。

**裁判要旨**（最高法参考案例）：
- 预约合同与本约合同的主要区别在于：预约合同签订的目的是为了将来签订本约合同，而不是立即实现本约合同的权利义务
- 违反预约合同的，不能请求法院强制履行预约合同，但可以请求承担违反预约合同的违约责任

### 3.5 格式条款的认定与效力（029-038）

**关键司法观点**：

1. **格式条款的认定**：提供格式条款的一方履行了提示义务、说明义务的认定
2. **网络消费格式条款**：与消费者有重大利害关系内容存在例外情形，应以显著方式进行提示
3. **最低充值金额限制**：经营者作出的最低充值金额限制条款无效
4. **不利解释规则**：按照通常理解对格式条款有两种以上解释的，才可以适用不利解释规则

### 3.6 违反强制性规定的合同效力（044）

**核心观点**（最高法司法解释）：
- 违反强制性规定并不必然导致合同无效
- 应当区分效力性强制性规定和管理性强制性规定
- 只有违反效力性强制性规定才导致合同无效

**编者注**：《民法典》第153条（2021-01-01 施行 / 2021-01-01 最新修正）第1款规定，违反强制性规定（仅限效力性强制性规定）的民事法律行为无效。

### 3.7 以物抵债协议的效力与履行（090-099）

**司法观点集成**：

| 情形 | 协议性质 | 效力认定 |
|------|----------|----------|
| 履行期限届满后达成以物抵债协议 | 实践合同 | 经意思表示一致并实际交付或办理过户时成立 |
| 履行期限届满前达成以物抵债协议 | 诺成合同 | 参照流押/流质条款规定处理 |
| 债务人逾期交付抵债物 | — | 债权人可请求债务人履行原债务或履行以物抵债协议 |

### 3.8 情势变更与商业风险的区分（105-109）

**核心观点**：
- **情势变更**：合同基础条件发生了当事人在订立合同时无法预见的、不属于商业风险的重大变化
- **商业风险**：市场供求变化、价格波动等正常的商业风险不属于情势变更
- **适用规则**：发生情势变更情形的，法院根据公平原则决定变更合同还是解除合同
- **特别规定**：个案适用情势变更制度不再由高级人民法院审核

### 3.9 代位权诉讼与撤销权诉讼（111-128）

**《民法典合同编通则解释》对合同保全制度的完善**：

| 要点 | 内容 |
|------|------|
| 代位权诉讼的管辖 | 债权人提起代位权诉讼，不受债务人与相对人之间管辖协议的约束 |
| 代位权的行使条件 | 债务人怠于行使其权利（未诉讼/仲裁） |
| 撤销权的行使范围 | 债务人处分行为导致债权人的债权无法清偿 |
| 明显不合理低价的认定 | 转让价格达不到交易时交易地的指导价或者市场交易价70% |
| 撤销权的行使期限 | 知道或者应当知道撤销事由之日起一年内 |

### 3.10 违约方合同解除权（191-195）

**核心司法观点**（合同僵局处理）：

1. **违约方起诉解除**：合同陷入僵局时，违约方在承担违约责任的情况下可以起诉终止合同权利义务关系
2. **适用条件**：
   - 合同已经丧失继续履行的现实可行性
   - 违约方无履行合同的善意
   - 金钱债务合同形成僵局的
3. **排除情形**：不属于合同僵局且违约方无履行合同的善意，人民法院不予支持

### 3.11 违约损害赔偿的计算（196-201）

**《民法典合同编通则解释》规定的违约损害赔偿计算规则**：

| 规则 | 内容 |
|------|------|
| 可得利益损失计算 | 持续性定期合同中可得利益损失计算的特别规则 |
| 可预见性规则 | 违约损失赔偿的可预见性判定规则（不得超过违约方订立合同时预见到或应当预见到的损失） |
| 减损规则 | 守约方应当采取适当措施防止损失扩大 |
| 酌情确定 | 综合考虑可预见性、减损规则、必要的交易成本等因素 |

### 3.12 违约金调整规则（202-210）

**司法观点**：

1. **请求调整违约金的方式**：当事人请求调整违约金的方式和举证责任
2. **计算基准**：违约金数额司法调整的计算基准
3. **逾期付款违约金**：应计算至债务实际清偿之日
4. **恶意违约**：当事人恶意违约不履行和解协议的，法院可不调整违约金
5. **无权主张**：当事人无权依据无效合同中的违约金条款请求支付违约金

### 3.13 定金罚则（211-220）

**定金类型与适用规则**：

| 定金类型 | 适用规则 |
|----------|----------|
| 立约定金 | 为担保正式合同的订立而交付的定金 |
| 成约定金 | 合同以定金交付为生效条件 |
| 解约定金 | 以定金换取合同解除权 |
| 违约定金 | 最常见的定金类型，违约时适用定金罚则 |

**重要规则**：
- 定金超出主合同标的额20%部分无效
- 当事人不能同时主张定金罚则与合同继续履行
- 原合同被新合同更替而终止，定金合同相应消灭

## 四、重要制度解析

### 4.1 合同效力瑕疵

| 类型 | 法律后果 |
|------|----------|
| 合同不成立 | 不能产生当事人追求的法律效力 |
| 合同无效 | 法律对已成立合同评价后的否定性结论 |
| 合同可撤销 | 效力取决于有撤销权的一方当事人是否行使撤销权 |
| 合同效力待定 | 待条件出现或经同意/追认后可以生效 |

### 4.2 经批准生效的合同

**司法观点**（《民法典合同编通则解释》第5-6条）：

1. **未经批准的合同为未生效合同，而非无效合同**
2. **报批义务及相关违约条款独立生效**
3. **一方不履行报批义务，另一方有权主张解除合同并请求赔偿损失**
4. **成立未生效合同可以解除**

### 4.3 债权转让规则

**核心规则**（《民法典合同编通则解释》第42-56条）：

| 规则 | 内容 |
|------|------|
| 通知效力 | 债权转让通知到达债务人后，对债务人产生约束力 |
| 多重转让 | 债权多重转让中债务人已经履行的，债务人与多个受让人之间的关系认定 |
| 债务人抗辩 | 债务人向受让人确认债权真实存在后，原则上不得再主张债权不存在的抗辩 |
| 善意取得 | 当事人约定不得转让的金钱债权，转让非金钱债权则善意受让人取得债权 |

### 4.4 债务加入与债务转移

| 类型 | 认定标准 | 责任承担 |
|------|----------|----------|
| 债务加入 | 第三人作出愿意承担债务的意思表示 | 加入人承担债务人同等责任 |
| 债务转移 | 债务人脱离债的关系 | 由新债务人承担 |
| 第三人代为履行 | 不承担债务人责任 | 仅在债务人不履行时由第三人履行 |

## 五、裁判案例精选

### 5.1 陆永芳诉中国人寿保险股份有限公司太仓支公司保险合同纠纷案

**裁判摘要**：人寿保险合同未约定具体的保费缴纳方式，投保人与保险人之间长期以来形成了较为固定的保费缴纳方式的，应视为双方成就了特定的交易习惯。保险公司单方改变交易习惯，违反最大诚信原则，致使投保人未能及时缴纳保费的，不应据此认定保单失效。

**案例来源**：《最高人民法院公报》2013年第11期

### 5.2 李占江、朱丽敏与贝洪峰、沈阳东昊地产有限公司民间借贷纠纷案

**裁判摘要**（最高法(2014)民一终字第38号）：判断贝洪峰是否具有违约行为，应当按照合同所使用的词句、合同的目的、交易习惯以及诚实信用原则，确定该条款的真实意思。借款人在借款期间从未向出借人提供相关材料和报表，属于违约。

**案例来源**：《最高人民法院公报》2015年第9期

### 5.3 天津某房地产经营有限公司诉天津某房地产集团有限公司商品房委托代理销售合同纠纷案

**裁判要旨**（入库编号：2024-08-2-119-001）：在当事人对合同条款的理解有争议时，应当结合具体案情确定条款的真实意思。开盘的含义是指"取得销售资格并开始进行实际销售"。

**案例来源**：人民法院案例库
