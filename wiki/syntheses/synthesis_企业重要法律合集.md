## 一、公司法核心要点（2023修订，2024年7月1日施行）

### 1.1 公司设立制度

**有限责任公司设立条件**：
- 由一个以上五十个以下股东出资设立
- 注册资本为全体股东认缴的出资额，股东应按公司章程规定自公司成立之日起五年内缴足
- 股东可用货币、实物、知识产权、土地使用权、股权、债权等可估价可转让的非货币财产出资

**股份有限公司设立条件**：
- 应当有一人以上二百人以下为发起人，其中半数以上发起人在中华人民共和国境内有住所
- 注册资本为已发行股份的股本总额
- 发起人认购的股份不得少于公司章程规定的公司设立时应发行股份总数的百分之三十五

**公司登记事项**：名称、住所、注册资本、经营范围、法定代表人姓名、股东或发起人信息

### 1.2 公司法人治理结构

**股东会职权**：
- 选举和更换董事、监事，决定报酬事项
- 审议批准董事会、监事会报告
- 审议批准利润分配和弥补亏损方案
- 对增加或减少注册资本、发行公司债券、合并分立解散、修改章程作出决议

**董事会职权**：
- 召集股东会并报告工作，执行股东会决议
- 决定经营计划和投资方案
- 制订利润分配方案、增减注册资本方案、合并分立方案
- 决定内部管理机构设置，聘任或解聘经理及报酬事项

**监事会职权**：
- 检查公司财务
- 监督董事、高级管理人员执行职务的行为
- 要求董事、高级管理人员纠正损害公司的行为
- 提议召开临时股东会会议

**一人公司特别规定**：
- 只有一个股东的有限责任公司不设股东会
- 只有一个股东的公司，股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任

### 1.3 股东权利保护

**股东知情权**：
- 有权查阅、复制公司章程、股东名册、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告
- 可以要求查阅公司会计账簿、会计凭证
- 查阅公司全资子公司相关材料的权利同样受保护

**股东诉讼权**：
- 公司董事、监事、高级管理人员执行职务违反法律、行政法规或公司章程给公司造成损失的，应当承担赔偿责任
- 股东可书面请求监事会或董事会向人民法院提起诉讼
- 情况紧急时，股东可以自己的名义直接向人民法院提起诉讼

### 1.4 股权转让

**有限责任公司股权转让**：
- 股东之间可以相互转让全部或部分股权
- 向股东以外的人转让股权的，应当书面通知其他股东，其他股东有优先购买权
- 股东自接到书面通知之日起三十日内未答复的，视为放弃优先购买权

**股份有限公司股份转让**：
- 股份可以向其他股东转让，也可以向股东以外的人转让
- 公司董事、监事、高级管理人员任职期间每年转让的股份不得超过其所持有本公司股份总数的百分之二十五

**股份回购**：
- 公司可以收购本公司股份的情形包括：减少注册资本、与持有本公司股份的其他公司合并、将股份用于员工持股计划或股权激励、股东因对合并分立决议持异议要求收购等

### 1.5 公司合并、分立、减资

**合并程序**：
- 签订合并协议，编制资产负债表及财产清单
- 十日内通知债权人，三十日内在报纸或国家企业信用信息公示系统公告
- 债权人可在接到通知之日起三十日内要求公司清偿债务或提供担保

**债务承继**：
- 公司合并时，合并各方的债权、债务由合并后存续的公司或新设的公司承继
- 公司分立前的债务由分立后的公司承担连带责任，但另有书面协议的除外

## 二、企业破产法核心要点（2007年6月1日施行）

### 2.1 破产申请与受理

**破产原因**：
- 不能清偿到期债务，并且资产不足以清偿全部债务或明显缺乏清偿能力
- 有明显丧失清偿能力可能的，可以进行重整

**申请主体**：
- 债务人可提出重整、和解或破产清算申请
- 债权人可提出对债务人进行重整或破产清算申请
- 依法负有清算责任的人在企业法人已解散但未清算或未清算完毕、资产不足以清偿债务时，应申请破产清算

**受理程序**：
- 债权人提出申请的，法院五日内通知债务人，债务人七日内可提出异议
- 法院应在收到申请之日起十五日内裁定是否受理
- 裁定受理的，同时指定管理人

### 2.2 管理人制度

**管理人选任**：
- 由人民法院指定
- 可以由有关部门、机构的人员组成的清算组或律师事务所、会计师事务所、破产清算事务所等社会中介机构担任

**管理人职责**：
- 接管债务人的财产、印章、账簿、文书等资料
- 调查债务人财产状况，制作财产状况报告
- 决定债务人的内部管理事务
- 管理和处分债务人的财产
- 代表债务人参加诉讼、仲裁或其他法律程序

### 2.3 债务人财产

**撤销权**：
- 法院受理破产申请前一年内，涉及债务人财产的下列行为可撤销：无偿转让财产、以明显不合理价格交易、对没有财产担保的债务提供担保、对未到期债务提前清偿、放弃债权
- 受理前六个月内，债务人仍对个别债权人进行清偿的（个别清偿使债务人财产受益的除外），管理人有权撤销

**追回权**：
- 债务人的董事、监事、高级管理人员利用职权获取的非正常收入和侵占的企业财产，管理人应当追回
- 出资人尚未完全履行出资义务的，管理人应当要求缴纳所认缴的出资，不受出资期限限制

### 2.4 债权申报与债权人会议

**债权申报期限**：最短不少于三十日，最长不超过三个月

**破产财产清偿顺序**：
1. 破产人所欠职工的工资和医疗、伤残补助、抚恤费用，所欠的应当划入职工个人账户的基本养老保险、基本医疗保险费用，以及法律、行政法规规定应当支付给职工的补偿金
2. 破产人欠缴的除前项规定以外的社会保险费用和破产人所欠税款
3. 普通破产债权

### 2.5 重整制度

**重整申请**：
- 债务人或债权人可以直接向人民法院申请对债务人进行重整
- 债权人申请破产清算的，在法院受理后、宣告破产前，债务人或出资额占注册资本十分之一以上的出资人可申请重整

**重整计划**：
- 债务人或管理人应自法院裁定重整之日起六个月内提交重整计划草案
- 各表决组均通过时，重整计划通过
- 经法院批准的重整计划对债务人和全体债权人具有约束力

### 2.6 和解制度

**和解协议**：
- 债务人可以依照本法规定，直接向人民法院申请和解
- 债权人会议通过和解协议的决议，由出席会议的有表决权的债权人过半数同意，并且其所代表的债权额占无财产担保债权总额的三分之二以上

## 三、企业国有资产法核心要点（2009年5月1日施行）

### 3.1 国有资产定义与出资人职责

**国有资产定义**：国家对企业各种形式的出资所形成的权益

**国家出资企业类型**：国有独资企业、国有独资公司、国有资本控股公司、国有资本参股公司

**履行出资人职责的机构**：
- 国务院和地方人民政府依照法律、行政法规的规定，分别代表国家对国家出资企业履行出资人职责
- 国务院国有资产监督管理机构和地方人民政府设立的国有资产监督管理机构，根据本级人民政府的授权，代表本级人民政府对国家出资企业履行出资人职责

**出资人权利**：资产收益、参与重大决策和选择管理者

### 3.2 国家出资企业管理者的选任与考核

**管理者任免范围**：
- 国有独资企业：任免经理、副经理、财务负责人和其他高级管理人员
- 国有独资公司：任免董事长、副董事长、董事、监事会主席和监事
- 国有资本控股公司、参股公司：向股东会、股东大会提出董事、监事人选

**管理者任职条件**：
- 有良好的品行
- 有符合职位要求的专业知识和工作能力
- 有能够正常履行职责的身体条件

**经营业绩考核**：
- 国家建立国家出资企业管理者经营业绩考核制度
- 依据考核结果决定对企业管理者的奖惩
- 国有独资企业、国有独资公司和国有资本控股公司的主要负责人，应当接受依法进行的任期经济责任审计

### 3.3 重大事项管理

**重大事项范围**：
- 合并、分立、改制、上市
- 增加或减少注册资本
- 发行债券
- 进行重大投资
- 为他人提供大额担保
- 转让重大财产
- 进行大额捐赠
- 分配利润
- 解散、申请破产

**审批程序**：
- 重要的国有独资企业、国有独资公司、国有资本控股公司的合并、分立、解散、申请破产以及法律、行政法规和本级人民政府规定应当报经本级人民政府批准的重大事项，应当报请本级人民政府批准

### 3.4 企业改制

**企业改制类型**：
- 国有独资企业改为国有独资公司
- 国有独资企业、国有独资公司改为国有资本控股公司或者非国有资本控股公司
- 国有资本控股公司改为非国有资本控股公司

**改制程序要求**：
- 制定改制方案，载明企业组织形式、资产和债权债务处理方案、股权变动方案、改制的操作程序、资产评估和财务审计等
- 涉及重新安置企业职工的，应当制定职工安置方案，并经职工代表大会或者职工大会审议通过

### 3.5 关联交易规制

**关联方定义**：本企业的董事、监事、高级管理人员及其近亲属，以及这些人员所有或者实际控制的企业

**禁止行为**：
- 不得无偿向关联方提供资金、商品、服务或者其他资产
- 不得以不公平的价格与关联方进行交易
- 未经履行出资人职责的机构同意，国有独资企业、国有独资公司不得与关联方订立财产转让、借款的协议，不得为关联方提供担保，不得与关联方共同出资设立企业

### 3.6 国有资产转让

**转让原则**：等价有偿和公开、公平、公正原则

**转让方式**：
- 除可以直接协议转让的外，应当在依法设立的产权交易场所公开进行
- 征集产生的受让方为两个以上的，转让应当采用公开竞价的交易方式

**转让批准**：
- 转让全部国有资产或者转让部分国有资产致使国家对该企业不再具有控股地位的，应当报请本级人民政府批准

## 四、个人独资企业法核心要点（2000年1月1日施行）

### 4.1 企业设立

**定义**：依照本法在中国境内设立，由一个自然人投资，财产为投资人个人所有，投资人以其个人财产对企业债务承担无限责任的经营实体

**设立条件**：
- 投资人为一个自然人
- 有合法的企业名称
- 有投资人申报的出资
- 有固定的生产经营场所和必要的生产经营条件
- 有必要的从业人员

**企业名称要求**：应当与其责任形式及从事的营业相符合

### 4.2 投资人权利与责任

**财产权利**：
- 投资人对本企业的财产依法享有所有权
- 有关权利可以依法进行转让或继承

**无限责任**：
- 投资人以其个人财产对企业债务承担无限责任
- 投资人在申请企业设立登记时明确以其家庭共有财产作为个人出资的，应当依法以家庭共有财产对企业债务承担无限责任

### 4.3 事务管理

**自行管理或委托管理**：
- 投资人可以自行管理企业事务
- 也可以委托或者聘用其他具有民事行为能力的人负责企业的事务管理

**受托人义务**：
- 应当履行诚信、勤勉义务
- 投资人对其职权的限制，不得对抗善意第三人

**禁止行为**（受托人或聘用人员不得有）：
- 利用职务上的便利，索取或者收受贿赂
- 利用职务或者工作上的便利侵占企业财产
- 挪用企业的资金归个人使用或者借贷给他人
- 擅自以企业财产提供担保
- 未经投资人同意，从事与本企业相竞争的业务
- 未经投资人同意，同本企业订立合同或者进行交易
- 泄露本企业的商业秘密

### 4.4 企业解散与清算

**解散情形**：
- 投资人决定解散
- 投资人死亡或者被宣告死亡，无继承人或者继承人决定放弃继承
- 被依法吊销营业执照
- 法律、行政法规规定的其他情形

**清算程序**：
- 投资人自行清算的，应当在清算前十五日内书面通知债权人
- 债权人应当在接到通知之日起三十日内，未接到通知的应当在公告之日起六十日内，向投资人申报其债权

**债务清偿顺序**：
1. 所欠职工工资和社会保险费用
2. 所欠税款
3. 其他债务

**特别时效**：个人独资企业解散后，原投资人对个人独资企业存续期间的债务仍应承担偿还责任，但债权人在五年内未向债务人提出偿债请求的，该责任消灭

## 五、中小企业促进法核心要点（2018年1月1日施行）

### 5.1 中小企业定义与支持方针

**中小企业定义**：在中华人民共和国境内依法设立的，人员规模、经营规模相对较小的企业，包括中型企业、小型企业和微型企业

**支持方针**：
- 积极扶持、加强引导、完善服务、依法规范、保障权益
- 坚持各类企业权利平等、机会平等、规则平等

**促进措施**：
- 中央财政在本级预算中设立中小企业科目，安排中小企业发展专项资金
- 国家设立中小企业发展基金
- 实行有利于小型微型企业发展的税收政策

### 5.2 融资促进

**货币政策工具**：中国人民银行综合运用货币政策工具，鼓励和引导金融机构加大对小型微型企业的信贷支持

**金融机构的差异化监管**：
- 合理提高小型微型企业不良贷款容忍度
- 引导金融机构增加小型微型企业融资规模和比重

**多层次资本市场**：
- 健全多层次资本市场体系
- 多渠道推动股权融资
- 发展并规范债券市场
- 促进中小企业利用多种方式直接融资

**担保融资**：
- 完善担保融资制度
- 支持以应收账款、知识产权、存货、机器设备等为担保品的担保融资

### 5.3 创业扶持

**税收优惠**：高等学校毕业生、退役军人和失业人员、残疾人员等创办小型微型企业，按照国家规定享受税收优惠和收费减免

**创业基地**：国家鼓励建设和创办小型微型企业创业基地、孵化基地，为小型微型企业提供生产经营场地和服务

**注销便利化**：国家简化中小企业注销登记程序，实现中小企业市场退出便利化

### 5.4 创新支持

**技术创新鼓励**：
- 鼓励中小企业推进技术、产品、管理模式、商业模式等创新
- 完善中小企业研究开发费用加计扣除政策
- 支持中小企业在研发设计、生产制造、运营管理等环节应用现代技术手段

**知识产权保护**：
- 鼓励中小企业研究开发拥有自主知识产权的技术和产品
- 鼓励中小企业投保知识产权保险

### 5.5 市场开拓

**政府采购支持**：
- 向中小企业预留的采购份额应当占本部门年度政府采购项目预算总额的百分之三十以上
- 预留给小型微型企业的比例不低于百分之六十

**公平竞争环境**：
- 反对垄断和不正当竞争
- 政府采购不得对中小企业实行差别待遇或歧视待遇

### 5.6 权益保护

**财产权保护**：国家保护中小企业及其出资人的财产权和其他合法权益

**禁止拖欠**：
- 国家机关、事业单位和大型企业不得违约拖欠中小企业的货物、工程、服务款项
- 中小企业有权要求拖欠方支付拖欠款并要求对拖欠造成的损失进行赔偿

**乱收费禁止**：
- 任何单位不得违反法律、法规向中小企业收取费用
- 不得实施没有法律、法规依据的罚款
- 不得向中小企业摊派财物

## 六、适用要点汇总表

### 6.1 企业类型与适用法律

| 企业类型 | 适用法律 | 出资人责任 | 组织机构 |
|----------|----------|------------|----------|
| 有限责任公司 | 公司法（2023修订） | 认缴出资额为限 | 股东会、董事会、监事会 |
| 股份有限公司 | 公司法（2023修订） | 认购股份为限 | 股东会、董事会、监事会 |
| 国有独资企业 | 企业国有资产法、公司法 | 无限责任 | 董事会、监事会（履行出资人职责的机构行使股东会职权） |
| 国有资本控股/参股公司 | 企业国有资产法、公司法 | 按持股比例 | 股东会、董事会、监事会 |
| 个人独资企业 | 个人独资企业法 | 无限责任（个人或家庭财产） | 投资人自行管理或委托管理 |
| 中小企业 | 中小企业促进法 | 视企业类型 | 视企业类型 |

### 6.2 公司设立关键时限

| 事项 | 时限要求 | 法律依据 |
|------|----------|----------|
| 有限责任公司股东出资缴足期限 | 公司成立之日起五年内 | 公司法第47条 |
| 股份有限公司发起人缴纳股款 | 公司成立前 | 公司法第98条 |
| 公司登记机关核发营业执照 | 材料齐全后 | 公司法第33条 |
| 股东会会议通知（定期会议） | 召开十五日前 | 公司法第64条 |
| 股份有限公司股东大会会议通知 | 召开二十日前 | 公司法第115条 |
| 董事会会议通知 | 召开十日前 | 公司法第73、123条 |

### 6.3 破产程序关键时限

| 事项 | 时限要求 | 法律依据 |
|------|----------|----------|
| 债权人提出破产申请后法院通知债务人 | 收到申请之日起五日内 | 破产法第10条 |
| 法院裁定是否受理 | 收到申请之日起十五日内 | 破产法第10条 |
| 法院受理后通知已知债权人 | 二十五日内 | 破产法第14条 |
| 债权申报期限 | 最短三十日，最长三个月 | 破产法第45条 |
| 管理人接管债务人财产 | 裁定受理同时指定 | 破产法第13条 |
| 债务人提交财产状况说明等 | 裁定送达之日起十五日内 | 破产法第11条 |

### 6.4 出资人权益保护要点

| 权利类型 | 有限责任公司 | 股份有限公司 | 救济途径 |
|----------|--------------|---------------|----------|
| 知情权 | 查阅复制公司章程、股东名册、会议记录、财务报告；可查阅会计账簿凭证 | 查阅复制公司章程、股东名册、会议记录、财务报告；持股180日且3%以上可查账簿凭证 | 向法院提起诉讼 |
| 表决权 | 按出资比例行使，公司章程另有规定除外 | 每一股份一表决权 | 股东会决议撤销之诉 |
| 利润分配权 | 按实缴出资比例分配，全体股东另有约定除外 | 按持股比例分配，公司章程另有规定除外 | 请求公司收购股权、诉讼 |
| 优先购买权 | 对外转让时其他股东有优先购买权 | 无优先购买权 | 请求撤销转让 |
| 退出权 | 请求公司收购股权（特定情形） | 请求公司收购股份（特定情形） | 向法院提起诉讼 |

### 6.5 国有资产特别规制

| 事项 | 规制要点 | 违规后果 |
|------|----------|----------|
| 管理者兼职 | 未经同意，国有独资企业、国有独资公司董事高级管理人员不得在其他企业兼职 | 行为无效 |
| 关联交易 | 不得无偿向关联方提供资金、商品、服务；不得以不公平价格交易 | 行为无效，造成损失承担赔偿责任 |
| 资产转让 | 原则上应公开进行，涉及控股地位变更须报批 | 可撤销交易，追回财产 |
| 担保 | 为他人提供大额担保需按程序审批 | 追究相关人员责任 |
| 资产评估 | 应委托依法设立的资产评估机构 | 出具虚假报告承担法律责任 |

### 6.6 中小企业扶持政策要点

| 支持类型 | 具体措施 | 适用对象 |
|----------|----------|----------|
| 财税支持 | 设立中小企业发展专项资金；设立中小企业发展基金；税收优惠 | 各类中小企业 |
| 融资促进 | 差异化监管；开发适合中小企业特点的金融产品；完善担保融资制度 | 小型微型企业 |
| 创业扶持 | 税收优惠和收费减免；创业基地、孵化基地；简易注销程序 | 初创期中小企业 |
| 创新支持 | 研究开发费用加计扣除；现代技术手段应用支持；知识产权保护 | 各类中小企业 |
| 市场开拓 | 政府采购预留份额不低于30%（小型微型企业不低于60%） | 小型微型企业 |
| 权益保护 | 禁止拖欠款项；禁止乱收费；建立投诉举报渠道 | 各类中小企业 |

### 6.7 法律责任对比

| 违法行为 | 公司法处罚 | 破产法处罚 | 国资法处罚 |
|----------|------------|------------|------------|
| 虚报注册资本 | 虚报金额5%-15%罚款；情节严重吊销执照 | - | - |
| 抽逃出资 | 抽逃金额5%-15%罚款 | - | - |
| 违规合并分立减资 | 责令改正，1万-10万元罚款 | - | - |
| 损害债权人利益 | 股东承担赔偿责任 | 撤销行为，追回财产 | - |
| 侵占国有资产 | - | - | 赔偿损失，处分或刑事责任 |
| 违规为关联方交易 | - | - | 行为无效，赔偿损失 |
| 破产程序中欺诈 | - | 行为无效，追究刑事责任 | - |
