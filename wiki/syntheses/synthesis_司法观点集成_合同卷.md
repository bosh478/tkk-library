# 司法观点集成（合同卷）

本页面汇总《新编最高人民法院司法观点集成（第二版）》合同卷的核心司法观点，涵盖合同法基本理论、买卖合同、借款合同、建设工程合同、担保合同等各类合同纠纷的裁判规则。

---

## 一、合同法基本理论

### 1.1 合同的成立

#### 合同成立要件

| 要件 | 内容 | 说明 |
|------|------|------|
| 当事人 | 订立合同的双方或多方 | 具有民事行为能力 |
| 意思表示 | 要约与承诺 | 意思表示真实 |
| 内容 | 合同的主要条款 | 标的、数量、质量等 |
| 形式 | 书面、口头或其他 | 法律另有规定除外 |

#### 合同订立的方式

| 方式 | 特征 | 效力 |
|------|------|------|
| 口头合同 | 当事人对话形式 | 即时成立 |
| 书面合同 | 书面文件形式 | 签字盖章成立 |
| 数据电文 | 电子合同 | 收件人指定系统接收时生效 |

#### 合同的主要条款

**实质性条款**（合同成立必须具备）
- 标的
- 数量
- 质量
- 价款或报酬
- 履行期限、地点和方式
- 违约责任
- 争议解决方法

### 1.2 合同的效力

#### 合同效力的类型体系

| 效力类型 | 生效要件 | 法律后果 |
|----------|----------|----------|
| 有效合同 | 主体适格、意思表示真实、内容合法 | 依约履行 |
| 无效合同 | 违反法律强制性规定、违背公序良俗 | 返还财产、赔偿损失 |
| 可撤销合同 | 欺诈、胁迫、重大误解、显失公平 | 撤销权人选择 |
| 效力待定合同 | 限制行为能力人、无权代理 | 经追认生效 |

#### 无效合同的典型情形

**《民法典》第153条规定：**
1. 违反法律、行政法规强制性规定的民事法律行为无效
2. 违背公序良俗的民事法律行为无效
3. 行为人与相对人恶意串通，损害他人合法权益的民事法律行为无效

#### 可撤销合同的情形

| 情形 | 撤销权人 | 除斥期间 |
|------|----------|----------|
| 欺诈 | 受欺诈方 | 1年 |
| 胁迫 | 受胁迫方 | 1年 |
| 重大误解 | 误解方 | 3个月 |
| 显失公平 | 受不利方 | 1年 |

### 1.3 合同的履行

#### 合同履行的原则

| 原则 | 内容 | 法律依据 |
|------|------|----------|
| 全面履行 | 按照约定全面履行义务 | 《民法典》第509条 |
| 诚实信用 | 保密、协助、通知义务 | 《民法典》第509条 |
| 情势变更 | 合同基础发生重大变化可变更或解除 | 《民法典》第533条 |

#### 合同履行抗辩权

| 抗辩权类型 | 适用条件 | 效力 |
|------------|----------|------|
| 同时履行抗辩权 | 双务合同，对方未履行 | 一时性阻却履行 |
| 先履行抗辩权 | 约定先后履行， 先履行方未履行 | 一时性阻却履行 |
| 不安抗辩权 | 后履行方有经营恶化转移财产行为 | 一时性阻却履行 |

### 1.4 合同的保全

#### 代位权

**构成要件**
1. 债权人对债务人的债权到期
2. 债务人怠于行使其债权或相关权利
3. 债务人债权已到期
4. 债务人债权非专属于债务人

**行使方式**
- 向法院起诉
- 债权人为原告
- 债务人为被告
- 次债务人为第三人

#### 撤销权

**可撤销的行为类型**
| 行为类型 | 情形 |
|----------|------|
| 放弃债权 | 债务人放弃到期债权 |
| 放弃担保 | 债务人放弃担保物权 |
| 无偿转让 | 债务人无偿转让财产 |
| 低价转让 | 债务人以明显不合理低价转让财产 |
| 恶意延长 | 债务人恶意延长到期债权期限 |

**撤销权的行使期限**
- 知道或应当知道撤销事由之日起1年
- 行为发生之日起5年

### 1.5 合同的变更和转让

#### 债权转让

**转让条件**
1. 债权具有可转让性
2. 转让人与受让人达成协议
3. 通知债务人

**转让效力**
- 转让通知到达债务人时生效
- 债务人向原债权人履行无效
- 债务人对原债权人的抗辩可向受让人主张

#### 债务承担

**免责的债务承担**
1. 经债权人同意
2. 第三人与债务人达成协议
3. 原债务人脱离债的关系

**并存的债务承担**
1. 第三人加入债务
2. 原债务人不免除
3. 第三人与原债务人连带责任

### 1.6 合同权利义务的终止

#### 合同解除的类型

| 类型 | 方式 | 条件 |
|------|------|------|
| 协议解除 | 双方协商一致 | 达成解除协议 |
| 约定解除 | 合同约定解除条件 | 条件成就 |
| 法定解除 | 法定事由 | 根本违约、不可抗力等 |

#### 法定解除权的情形

**《民法典》第563条：**
1. 因不可抗力致使不能实现合同目的
2. 履行期限届满前，一方明确表示或以行为表明不履行主要债务
3. 一方迟延履行主要债务，经催告后在合理期限内仍未履行
4. 一方迟延履行或其他违约致使不能实现合同目的
5. 法律规定的其他情形

#### 合同终止后的义务

| 义务 | 内容 |
|------|------|
| 保密义务 | 保守在合同订立履行中知悉的商业秘密 |
| 通知义务 | 重要事项及时通知对方 |
| 协助义务 | 协助对方处理遗留问题 |
| 忠实义务 | 不诋毁对方声誉 |

### 1.7 违约责任

#### 违约责任的承担方式

| 方式 | 内容 | 适用条件 |
|------|------|----------|
| 继续履行 | 按合同约定履行 | 能够履行 |
| 采取补救措施 | 修理、更换、重作 | 可以补救 |
| 赔偿损失 | 赔偿实际损失 | 造成损失 |
| 支付违约金 | 按约定支付违约金 | 约定违约金 |

#### 损失赔偿的范围

**完全赔偿原则**
- 直接损失：现有财产的减少
- 间接损失：可得利益的损失
- 不得超过违约方订立合同时预见到或应当预见到的损失

**可预见性规则**
- 损失赔偿额 = 合同履行后可以获得的利益
- 扣除未履行部分的利益
- 扣除违约方不可预见的损失

#### 违约金

| 类型 | 规定 |
|------|------|
| 约定违约金 | 当事人约定 |
| 法定违约金 | 法律直接规定 |
| 过高调整 | 超过损失的30%可申请减少 |
| 过低调整 | 低于实际损失可申请增加 |

## 二、买卖合同

### 2.1 买卖合同的基本规则

#### 当事人的权利义务

**出卖人的义务**
| 义务 | 内容 |
|------|------|
| 交付标的物 | 按约定时间地点方式交付 |
| 转移所有权 | 交付时转移，动产登记生效 |
| 瑕疵担保 | 质量瑕疵担保、权利瑕疵担保 |

**买受人的义务**
| 义务 | 内容 |
|------|------|
| 支付价款 | 按约定数额时间地点支付 |
| 验收 | 及时检验 |
| 受领 | 接受标的物 |

### 2.2 标的物的交付

#### 交付方式

| 方式 | 所有权转移时间 | 说明 |
|------|----------------|------|
| 现实交付 | 交付时 | 实际交付标的物 |
| 指示交付 | 通知占有人时 | 返还请求权让与 |
| 占有改定 | 约定生效时 | 继续占有但所有权转让 |

#### 交付地点

| 情形 | 交付地点 | 法律依据 |
|------|----------|----------|
| 约定地点 | 按约定 | 当事人约定 |
| 标的物需要运输 | 货交第一承运人 | 出卖人将货交承运人 |
| 标的物不需要运输 | 出卖人住所地 | 合同成立时 |

### 2.3 标的物的风险负担

#### 风险转移规则

| 情形 | 风险转移时间 | 说明 |
|------|--------------|------|
| 标的物交付 | 交付时转移 | 一般规则 |
| 在途标的物 | 合同订立时 | 路货买卖 |
| 需要运输 | 货交第一承运人 | 标的物需要运输 |
| 买受人迟延受领 | 买受人违约时 | 买受人原因 |

#### 风险转移与所有权转移

**原则**
- 风险转移与所有权转移不挂钩
- 风险随交付转移

**例外**
- 出卖人违约时，买受人可以拒绝接受标的物或解除合同

### 2.4 标的物的质量与检验

#### 质量标准

| 标准 | 适用顺序 | 说明 |
|------|----------|------|
| 约定标准 | 第一 | 当事人约定 |
| 国家标准 | 第二 | 国家强制性标准 |
| 行业标准 | 第三 | 推荐性行业标准 |
| 通常标准 | 最后 | 合同目的特定标准 |

#### 检验期限

| 情形 | 检验期限 | 起算点 |
|------|----------|--------|
| 约定期限 | 按约定 | 收到标的物时 |
| 未约定期限 | 合理期限内 | 收到标的物时 |
| 最长合理期限 | 2年 | 收到标的物时（隐蔽瑕疵） |

### 2.5 买卖合同的特殊类型

#### 所有权保留买卖

**《民法典》第641条**
当事人可以在买卖合同中约定买受人未履行支付价款或者其他义务的，标的物的所有权属于出卖人。

**出卖人取回权**
1. 买受人未按约定支付价款
2. 买受人未按约定完成特定条件
3. 买受人将标的物出卖、出质给第三人

#### 试用买卖

**《民法典》第637条**
试用买卖的买受人在试用期内可以购买标的物，也可以拒绝购买。试用期限届满，买受人对是否购买标的物未作表示的，视为购买。

## 三、借款合同

### 3.1 金融借款合同

#### 借款合同的基本要素

| 要素 | 内容 |
|------|------|
| 借款种类 | 流动资金贷款、固定资金贷款等 |
| 借款用途 | 按约定用途使用 |
| 借款金额 | 合同约定的本金数额 |
| 借款利率 | 按央行规定和合同约定 |
| 借款期限 | 约定的还款时间 |
| 还款方式 | 到期一次性、分期等 |

#### 借款利息的计算

| 类型 | 计算方式 | 上限 |
|------|----------|------|
| 期内利息 | 本金×利率×期限 | 不超过合同成立时LPR4倍 |
| 逾期利息 | 本金×利率×逾期期间 | 可高于期内利率 |
| 违约金 | 按约定 | 过分高于实际损失可调减 |

### 3.2 民间借贷

#### 民间借贷的效力

**有效的情形**
1. 借贷双方具有相应民事行为能力
2. 意思表示真实
3. 资金来源合法
4. 不违反法律强制性规定

**无效的情形**
1. 套取金融机构贷款转贷
2. 以向公众非法吸收存款所得资金转贷
3. 未依法取得放贷资格的经常性放贷
4. 其他违反法律强制性规定

#### 民间借贷利率

| 时间节点 | 利率上限 | 说明 |
|----------|----------|------|
| 2020年8月20日前 | 24%/36% | 两线三区 |
| 2020年8月20日后 | 合同成立时LPR4倍 | 浮动利率 |

### 3.3 借款合同的担保

#### 保证担保

**一般保证**
- 债务人不能履行时保证人承担保证责任
- 保证人享有先诉抗辩权

**连带保证**
- 债权人可向债务人或保证人主张债权
- 保证人不享有先诉抗辩权

#### 抵押担保

**抵押物范围**
1. 建筑物和其他土地附着物
2. 建设用地使用权
3. 正在建造的建筑物
4. 法律允许抵押的其他财产

## 四、建设工程合同

### 4.1 建设工程合同的效力

#### 合同无效的情形

| 情形 | 法律后果 |
|------|----------|
| 承包人无资质 | 合同无效 |
| 借用资质 | 合同无效 |
| 违法分包 | 合同无效 |
| 转包 | 合同无效 |
| 未招标或虚假招标 | 合同无效（大型基础设施、公用事业） |

#### 合同无效的处理

| 情形 | 处理方式 |
|------|----------|
| 已完工且验收合格 | 参照合同约定支付工程款 |
| 已完工但验收不合格 | 修复后验收合格的参照约定支付，验收不合格不支付 |
| 未完工 | 按已完成工程量折价补偿 |

### 4.2 建设工程价款的结算

#### 工程价款的组成

| 项目 | 内容 |
|------|------|
| 直接费 | 人工费、材料费、施工机械费 |
| 间接费 | 管理费、规费 |
| 利润 | 企业利润 |
| 税金 | 增值税等 |

#### 工程结算方式

| 方式 | 适用情形 |
|------|----------|
| 固定价格 | 工期短、技术简单 |
| 可调价格 | 工期长、技术复杂 |
| 成本加酬金 | 特殊工程 |

#### 工程款优先受偿权

**《民法典》第807条**
发包人未按约定支付工程价款的，承包人可以催告发包人在合理期限内支付。发包人逾期不支付的，承包人可以与发包人协议将该工程折价，也可以请求法院将该工程依法拍卖。

**优先受偿的范围**
- 工程价款
- 承包人实际支出的人工费、材料费等
- 不包括利息、违约金、损害赔偿金

**优先受偿的期限**
- 18个月（自工程竣工之日或合同约定竣工之日起）

### 4.3 建设工程质量

#### 质量责任主体

| 主体 | 责任 |
|------|------|
| 建设单位 | 选任责任、提供符合标准的材料 |
| 勘察设计单位 | 勘察设计责任 |
| 施工单位 | 施工质量责任 |
| 监理单位 | 监理责任 |

#### 质量保修

| 工程类型 | 保修期限 |
|----------|----------|
| 基础设施工程、房屋建筑 | 设计文件规定的该工程合理使用年限 |
| 防水工程 | 5年 |
| 电气管线、给排水管道 | 2年 |
| 装修工程 | 2年 |

## 五、担保合同

### 5.1 保证合同

#### 保证的方式

| 方式 | 特征 | 保证人责任 |
|------|------|------------|
| 一般保证 | 债务人不能履行时承担责任 | 享有先诉抗辩权 |
| 连带保证 | 与债务人连带承担责任 | 无先诉抗辩权 |

#### 保证期间

| 类型 | 期限 | 起算点 |
|------|------|--------|
| 未约定 | 6个月 | 主债务履行期限届满 |
| 约定不明 | 2年 | 主债务履行期限届满 |
| 约定明确 | 按约定 | 主债务履行期限届满 |

### 5.2 抵押合同

#### 抵押财产的范围

**可以抵押的财产**
1. 建筑物和其他土地附着物
2. 建设用地使用权
3. 以招标、拍卖、公开协商等方式取得的荒地等土地承包经营权
4. 生产设备、原材料、半成品、产品
5. 正在建造的建筑物、船舶、航空器
6. 交通运输工具
7. 法律、行政法规未禁止抵押的其他财产

**不得抵押的财产**
1. 土地所有权
2. 宅基地、自留地、自留山等集体所有土地使用权
3. 学校、幼儿园、医疗机构等公益为目的的事业单位、社会团体的教育设施、医疗卫生设施
4. 所有权、使用权不明或有争议的财产
5. 依法被查封、扣押、监管的财产
6. 法律、行政法规规定不得抵押的其他财产

### 5.3 质押合同

#### 动产质押

**质权的设立**
- 交付占有时设立
- 交付方式：现实交付、指示交付、简易交付

**质权的效力**
- 优先受偿
- 孳息收取（扣除费用后）
- 质物价值减少时的救济

#### 权利质押

| 权利类型 | 质押设立方式 |
|----------|--------------|
| 汇票、本票、支票 | 交付权利凭证即设立 |
| 债券、存款单 | 交付或登记 |
| 股权 | 证券登记结算机构登记或工商登记 |
| 知识产权 | 主管部门登记 |

## 六、融资租赁合同

### 6.1 融资租赁的基本规则

#### 当事人权利义务

**出租人的义务**
| 义务 | 内容 |
|------|------|
| 购买租赁物 | 按承租人要求购买 |
| 交付租赁物 | 将租赁物交付承租人使用 |
| 权属保证 | 保证承租人平静占有使用 |

**承租人的义务**
| 义务 | 内容 |
|------|------|
| 支付租金 | 按约定支付租金 |
| 妥善保管 | 妥善保管使用租赁物 |
| 维修 | 承担维修义务 |
| 返还 | 租赁期满返还租赁物 |

### 6.2 融资租赁的特别规则

#### 租赁物的所有权

**归属规则**
- 融资租赁中，租赁物所有权归出租人
- 租赁期间届满后，可约定归属
- 未约定的，租赁物所有权归出租人

#### 融资租赁合同的解除

| 解除情形 | 解除后果 |
|----------|----------|
| 出租人解除 | 取回租赁物，承租人赔偿损失 |
| 承租人解除 | 支付全部租金及损失 |

## 七、保理合同

### 7.1 保理的基本概念

| 概念 | 内容 |
|------|------|
| 保理 | 应收账款债权人将应收账款转让给保理人 |
| 有追索权保理 | 保理人不承担债务人信用风险 |
| 无追索权保理 | 保理人承担债务人信用风险 |

### 7.2 保理合同的效力

#### 应收账款转让的效力

| 效力 | 内容 |
|------|------|
| 转移效力 | 应收账款债权转移给保理人 |
| 抗辩效力 | 债务人可向保理人主张对原债权人的抗辩 |
| 抵销效力 | 债务人可向保理人主张对原债权人的抵销 |

## 八、租赁合同

### 8.1 租赁合同的基本规则

#### 租赁期限

| 期限 | 规则 |
|------|------|
| 定期租赁 | 不超过20年 |
| 不定期租赁 | 可随时解除但应给予合理期限 |
| 续租 | 届满续租需重新订立合同 |

#### 租赁物的维修

| 维修义务 | 规则 |
|----------|------|
| 出租人维修 | 出租人承担维修义务 |
| 承租人维修 | 承租人自行维修后可减少租金 |
| 紧急维修 | 承租人可自行维修后追偿 |

### 8.2 房屋租赁的特殊规则

#### 优先购买权

**承租人优先购买权**
1. 房屋出售时承租人有优先购买权
2. 出租人应提前通知承租人
3. 同等条件下承租人优先

**优先购买权的例外**
1. 房屋共有人优先购买
2. 出租人将房屋卖给近亲属
3. 承租人未在15日内明确表示购买
