## 第一编 公司

### 第一章《公司法》总则中的法律适用疑难问题

#### 一、公司类纠纷案件的审理原则

**五大审理原则**：

1. **交易效率、安全与公平并重**：区分公司内外部法律关系，内部关系重实质公平（保护中小股东），外部关系重权利外观（保护善意第三人）
2. **尊重公司意思自治**：司法介入限缩于必要范围，竭尽公司内部救济后方可司法介入
3. **全面系统平衡利益**：维护公司社团关系稳定，不轻易否定公司法人人格
4. **股东有限责任原则**：不能轻易突破，由债权人越过公司直接向股东主张权利
5. **体系思维**：以公司治理规范化促推法治化营商环境

#### 二、公司法人人格否认

《公司法》第23条确立三层体系：
- **纵向否认**（第1款）：股东滥用公司法人独立地位和股东有限责任 → 连带责任
- **横向否认**（第2款）：利用控制的两个以上公司转移风险和利益 → 相互承担连带责任
- **一人公司举证责任倒置**（第3款）：财产混同时股东不能证明财产独立 → 连带责任

> 典型案例：关联公司人格混同，人员、业务、财务交叉混同导致各自财产无法区分 → 相互承担连带责任

#### 三、公司会议决议之诉

| 诉讼类型 | 原告主体 | 要件 |
|----------|----------|------|
| 决议无效之诉 | 股东、董事、监事等 | 决议内容违法 |
| 决议撤销之诉 | 股东（起诉时须具备股东资格） | 程序/内容瑕疵 |
| 决议不成立之诉 | 股东、董事、监事等 | 未开会/未表决/不足数 |

**部分撤销**：决议内容可分、撤销原因仅及于部分内容时可部分撤销（如利润分配时间超过章程规定）

### 第二章 公司登记

#### 瑕疵设立公司的法律效力

我国立法态度：**原则上设立有效，例外可撤销**（《公司法》第39条）。

| 效力模式 | 适用情况 |
|----------|----------|
| 瑕疵设立原则无效 | 大陆法系（德日韩），但设严格限制（判决不溯及、裁量补正） |
| 瑕疵设立原则有效 | 英美法系（结论性书证规则），但保留政府无效撤销权 |

**瑕疵补正路径**：
- 私法途径：民事诉讼（补缴责任、违约金、股东失权）
- 公法途径：公司登记机关责令改正、撤销登记

**撤销登记溯及力**：原则上不溯及既往，撤销前与善意相对人形成的民事法律关系不受影响

### 第三章 公司设立

#### 设立协议与公司章程冲突处理原则

| 情形 | 适用文件 |
|------|----------|
| 涉及公司、其他股东或债权人利益 | 公司章程为准 |
| 仅涉及设立人之间利益 | 真实意思表示为准（设立协议） |

#### 设立人以自己名义对外签订合同的责任

《民法典》第75条（2021-01-01 施行 / 2021-01-01 最新修正）第2款：相对人有权选择请求设立人或成立后的公司承担责任（择一行使，不能连带）

#### 公司设立失败时设立人的责任

- **对外**：全体设立人承担连带责任（基于共同行为理论）
- **对内**：有约定按约定 → 无约定按出资比例 → 无约定则平均分担
- **过错责任**：因部分设立人过错导致未成立的，其他设立人可向其追偿

### 第四章 出资责任

#### 出资不实责任体系

股东出资不实时公司可选择（轻重有序）：
1. 请求出资不实股东补足 + 发起人/董事/高级管理人员连带责任
2. 协商延长出资期限或减资
3. 限制利润分配请求权、新股优先认购权等股东权利
4. 解除股东资格（严重违反出资义务时）

#### 出资加速到期

**触发条件**：债务人不能清偿到期债务 + 明显缺乏清偿能力
- 债权人可以直接要求出资加速到期的股东清偿
- 不以诉讼为必要，可直接在执行程序中申请追加

#### 抽逃出资认定

- 抽逃出资后转让股权：受让人可免责（需证明不知情且不应知）
- 协助抽逃出资：董事、监事、高级管理人员承担连带责任

### 第五章 股权转让

#### 股权变动的核心规则

1. **有限责任公司**：记载于股东名册时发生效力，登记仅产生对抗效力
2. **一股二卖**：办理变更登记前已先行支付合理价款并实际参与公司经营的受让人，可主张善意取得
3. **优先购买权**：未依法通知其他股东 → 其他股东可主张按同等条件购买（双重保障）

#### 瑕疵股权转让的出资责任

- **认缴加速到期**：股权转让合同成立时即触发，不因转让而免除
- **受让人免责抗辩**：证明不知道且不应知道出让方未履行出资义务
- **2023年《公司法》修订前**：以是否完成变更登记为判断节点

### 第六章 股份有限责任公司发起人责任

#### 认股股份缴纳规则

| 设立方式 | 发起人认购要求 |
|----------|----------------|
| 发起设立 | 认足全部股份，公司成立前全额缴纳 |
| 募集设立 | 发起人认购不少于设立时应发行股份总数的35% |

**违法后果**：发起人未缴足前不得向他人募集股份，募集行为无效（不因事后补缴而改变）

### 第七章 董事、监事、高级管理人员责任

#### 三大责任体系

| 责任类型 | 请求权基础 | 核心要件 |
|----------|-----------|----------|
| 对公司责任 | 《公司法》第188条 | 违反忠实/勤勉义务 + 给公司造成损失 |
| 对股东责任 | 股东代表诉讼 | 持股+前置程序（情况紧急除外） |
| 对债权人责任 | 协助抽逃出资/出资不实 | 存在协助行为或未尽勤勉义务 |

#### 忠实义务的主要类型

1. **自我交易与关联交易**（第182条）：须向董事会/股东会报告并经决议，关联人回避
2. **谋取公司商业机会**（第183条）：原则上归公司，除非公司不能利用（法律/章程限制）
3. **竞业禁止**（第184条）：不得自营或为他人经营同类业务（含子公司）
4. **归入权**（第186条）：公司可主张董事、高管因违信义务获得的收入

#### 勤勉义务的判断标准

**商业判断规则**三要件：
- 无利害关系（客观性）
- 获取了适当信息（充分性）
- 理性相信有利于公司利益最大化（善意性）

#### 事实董事与影子董事（2023年修订新增）

| 类型 | 主体 | 义务 | 责任 |
|------|------|------|------|
| 事实董事 | 控股股东/实控人不任董事但实际执行公司事务 | 适用董事忠实勤勉义务 | 违反时承担董事责任 |
| 影子董事 | 控股股东/实控人指示董事、高管从事损害行为 | 与被指示人承担连带责任 | 连带责任 |

### 第八章 公司财务、会计

#### 公积金弥补亏损

股东会决议将公积金用于弥补亏损 → **有效**（前提：法定公积金弥补后仍有亏损）

#### 利润分配请求权

- 无载明具体分配方案的股东会决议 → **不予支持**分配请求
- 但大股东滥用权利导致不分配（如给关联人发过高薪酬）→ **可介入审查**

### 第九章 公司解散与清算

#### 司法解散的构成要件

1. **经营管理严重困难**：僵局状态（持续2年以上）
2. **继续存续会使股东利益受到重大损失**
3. **通过其他途径不能解决**

#### 清算义务人责任

| 主体 | 责任类型 |
|------|----------|
| 董事 | 清算组成员，负有忠实勤勉义务 |
| 怠于清算 | 给公司造成损失 → 赔偿责任 |
| 故意/重大过失 | 给债权人造成损失 → 赔偿责任 |
| 拒不配合清算 | 可追缴/追索，未依法清算可申请追加分配 |

## 第二编 破产

### 第十章 破产申请和受理

#### 破产原因

| 主体 | 破产原因 |
|------|----------|
| 债务人申请 | 不能清偿到期债务 + 资产不足以清偿全部债务**或者**明显缺乏清偿能力 |
| 债权人申请 | 不能清偿到期债务（债务人举证反驳） |
| 重整原因 | 具备破产原因 **或者** 有明显丧失清偿能力可能 |

#### 破产申请主体

- **债权人**：享有财产给付内容的请求权、已到期、无诉讼时效抗辩
- **债务人**：具有破产能力（金融等特殊行业有限制）
- **清算责任人**：公司解散后资产不足以清偿债务时 **强制义务**

#### 强制清算与破产清算的竞合

债务人同时符合两种条件时 → **应当适用破产清算程序**（债权人坚持申请强制清算的，法院裁定不予受理）

#### 破产申请的审查与监督

| 审查内容 | 要件 |
|----------|------|
| 实质审查 | 破产能力 + 破产原因 |
| 形式审查 | 申请人资格 + 材料齐备 + 管辖权 |

**举证责任分配**：
- 债权人申请 → 仅需证明债务人不能清偿到期债务
- 债务人反驳 → 须证明不存在"资产不足以清偿"或"明显缺乏清偿能力"

#### 破产受理的效力

1. **债务人**：提交财产状况说明等材料；个别清偿无效；有关人员承担移交财产、印章账簿等义务
2. **债权人**：只能通过破产程序申报债权受偿
3. **第三人**：须向管理人清偿/交付财产
4. **保全/执行**：保全措施解除，执行程序中止
5. **诉讼/仲裁**：已开始的应中止，管理人接管后继续

### 第十一章 破产管理人

#### 管理人的法律地位

破产财团代表说（理论解释）→ 法定专门机构说（立法主导观点）
- 独立执行职务
- 中立履职
- 接受法院和债权人监督

#### 管理人的选任与职责

**选任**：法院指定为主，债权人会议可申请更换

**职责**：
- 接管债务人财产、印章账簿
- 调查债务人财产状况
- 制作财产报告
- 回收债务人财产
- 决定债务人内部管理事务
- 处分债务人财产（变现）
- 参加诉讼/仲裁

**未尽职责的法律后果**：
- 对债权人/债务人/第三人造成损失 → 赔偿责任
- 勤勉尽责义务 → 忠实义务

### 第十二章 债务人财产

#### 取回权

权利人可通过管理人取回不属于债务人的财产，包括：
- 所有权保留买卖中的出卖人取回权
- 融资租赁中出租人取回权

#### 破产撤销权

管理人可撤销的行为：
- 放弃债权（撤销前1年内）
- 无偿转让财产（撤销前1年内）
- 以明显不合理价格交易（撤销前1年内）
- 对无财产担保债务提供担保（撤销前1年内）
- 提前清偿债务（撤销前1年内）
- 抵销（禁止破产抵销的情形除外）

#### 破产抵销权

禁止抵销情形：
1. 债务人的债务人在破产申请受理后取得他人债权
2. 债权人已知有不能清偿到期债务或者破产申请的事实时对债务人负担债务
3. 债务人的债务人已知有不能清偿到期债务或者破产申请的事实时从债权人取得债权

### 第十三章 破产费用和共益债务

| 类型 | 范围 | 负担方式 |
|------|------|----------|
| 破产费用 | 管理变价分配费用、公告费用、诉讼费用等 | 从债务人财产中优先拨付 |
| 共益债务 | 管理人执行职务、债务人财产致损、无因管理、不当得利 | 随时清偿，从债务人财产优先拨付 |

### 第十四章 债权申报与债权会议

#### 债权申报

| 要件 | 内容 |
|------|------|
| 申报期限 | 最短30日，最长3个月（法院确定） |
| 未按期申报 | 可以在破产财产最后分配前补充申报（但已分配的不再追加） |
| 诉讼未决债权 | 分配额提存 |

#### 债权人会议

- **表决权**：无财产担保债权人 + 有财产担保但放弃优先受偿的债权人
- **决议效力**：对全体债权人具有约束力（须法院许可的除外）
- **救济**：不服决议15日内可请求法院裁定撤销

### 第十五章 重整程序

#### 重整申请与受理

| 申请主体 | 条件 |
|----------|------|
| 债务人/债权人 | 破产原因 |
| 债权人 | 明显丧失清偿能力可能 |

#### 重整计划

| 期限 | 内容 |
|------|------|
| 6个月内提交 | 债务人/管理人制定并提交 |
| 3个月延长期 | 确有正当理由可申请 |
| 法院收到后30日内召开债权人会议表决 |  |

**批准条件**：各表决组均通过；符合法律规定（公平对待、绝对优先）

#### 上市公司重整

特殊要求：
- 须经金融监管部门批准
- 须提交重整计划草案

#### 庭外重组与庭内重整衔接

鼓励困境企业先庭外重组，再申请司法重整

### 第十六章 和解与破产清算

#### 和解程序

- 债务人可申请
- 和解协议经债权人会议表决通过 → 法院裁定认可
- 和解失败 → 法院宣告破产

#### 破产宣告

- 裁定作出之日起5日内送达债务人和管理人
- 10日内通知已知债权人并公告
- 债务人财产成为破产财产

#### 破产财产变价与分配

| 分配顺序 | 内容 |
|----------|------|
| 第一顺位 | 破产费用 |
| 第二顺位 | 共益债务 |
| 第三顺位 | 职工债权 |
| 第四顺位 | 社会保险费用 |
| 第五顺位 | 税款 |
| 第六顺位 | 普通债权 |

### 第十七章 关联企业合并破产

#### 实质合并原则

**适用条件**：关联企业法人人格高度混同（财产混同、利益输送等）
**法律后果**：各关联企业视为单一主体，债权债务统一清偿

#### 程序要求

- 应当组织听证（实质合并重整申请）
- 及时通知相关利害关系人
- 允许提出异议和复议

### 第十八章 金融机构破产

#### 特殊规则

1. **监管机构申请**：国务院金融监督管理机构可向法院提出重整或破产清算申请
2. **特殊处置措施**：接管、托管 → 可申请中止诉讼/执行
3. **客户财产保护**：自有资产与客户财产分别处理
4. **人数众多**：启动须经监管部门批准

### 第十九章 跨境破产制度

#### 制度框架

- 破产程序的域外效力
- 跨境破产司法协助
- 跨境破产示范法（联合国国际贸易法委员会）

#### 实务操作

1. 承认与执行域外破产程序
2. 主要债权人间待遇平等
3. 法院之间信息共享与协调

### 第二十章 自然人破产制度

#### 目标与特征

- 给"诚实但不幸"的债务人重新开始的机会
- 建立个人债务清理机制
- 与企业破产制度相协调

#### 程序框架

| 程序类型 | 适用情形 |
|----------|----------|
| 个人重整 | 有挽救价值的困境债务人 |
| 个人和解 | 债务人与债权人协商债务清偿方案 |
| 破产清算 | 无法挽救的债务人清算其全部财产 |

### 第二十一章 法律责任

#### 债务人相关人员责任

| 主体 | 责任类型 |
|------|----------|
| 法定代表人和债务人有关人员 | 拒绝移交财产/账簿 → 罚款、拘留 |
| 债务人有关人员 | 拒不陈述/虚假陈述 → 罚款 |
| 清算义务人 | 怠于履行义务导致无法清算 → 连带责任 |
| 实际控制人 | 恶意逃债 → 连带责任 |

#### 管理人责任

- 未勤勉尽责 → 警告、罚款、取消任职资格
- 给债权人/债务人/第三人造成损失 → 赔偿责任

#### 破产犯罪

| 罪名 | 行为类型 |
|------|----------|
| 虚假破产罪 | 隐匿财产、虚构债务、转移财产 |
| 妨害清算罪 | 隐匿财产、虚假说明、不当分配 |
| 欺诈发行股票债券罪 | 欺诈发行债券 |
| 提供虚假财务报告罪 | 提供虚假财务报告 |
