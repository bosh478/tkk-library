## 核心特点（王晓东自述）

### 1. 法治性
- 对国家工作人员离职时间节点的界定不是在免职后，而是在实际退休后
- 对于国有控股、参股企业中的国家工作人员和非国家工作人员、对单位实际控制人的理解，除了按照法律逻辑进行推理，还应注重探究内在的逻辑和国情形成的制度特色

### 2. 系统性
- 将坚持受贿行贿一起查，完善定罪量刑与追赃挽损中的相关问题推进纪法衔接、法法贯通
- 通过专章分析行贿案件，明确单位犯罪与个人犯罪的界限、行贿与渎职行为数罪是否并罚原则
- 实现《刑法》与《监察法》的贯通

### 3. 完整性
职务犯罪三大类：
- **贪污类犯罪**（6个罪名）：贪污罪、挪用公款罪、巨额财产来源不明罪、隐瞒境外存款罪、私分国有资产罪、私分罚没财物罪
- **贿赂类犯罪**（8个罪名）：受贿罪、单位受贿罪、利用影响力受贿罪、斡旋受贿罪、行贿罪、对单位行贿罪、介绍贿赂罪、单位行贿罪
- **渎职类犯罪**（44个罪名）：滥用职权类18个、玩忽职守类11个、徇私舞弊类15个

### 4. 前瞻性
- 针对国家工作人员利用职务本身还是职权地位形成的便利条件，区分直接受贿与斡旋受贿
- 明确需综合判断、实质判断，结合任职单位性质、职能、所任职务及法律规定、国情形成的制度安排等具体认定
- 针对珠宝、字画、艺术品、手表等特定财物是否必须进行真伪鉴定与价格认定的问题予以明确

### 5. 适用性
- 从综合、贪污、受贿、行贿、渎职、程序、量刑、证据及赃款赃物的追缴等9个方面
- 对百余份裁判文书进行系统剖析
- 每个问题细化为案情、分歧意见、释义三部分集中解读

## 核心裁判规则摘要

### 一、主体认定规则

#### 1. 国家工作人员认定

| 情形 | 认定规则 |
|------|----------|
| 国有控股企业 | 综合持股比例、职责范围、经营决策权等因素判断 |
| 受委派到社会团体 | 形式要件（任命、指派等）+ 实质要件（从事公务） |
| 离职时间节点 | 实际退休后，不是免除职务后 |
| 中外合资企业 | 依实际情况判断是否"代表国有投资主体" |

#### 2. 单位实际控制人认定

通过以下四个方面综合判断：
1. 企业重大事项的决策程序
2. 企业资金流向
3. 企业主要负责人与国家工作人员的关系
4. 企业主营业务与国家工作人员职权的关系

### 二、犯罪数额认定规则

| 情形 | 认定规则 |
|------|----------|
| 贪污税款 | 税款部分应计入犯罪总额 |
| 受贿税款 | 受贿犯罪中的税款应计入犯罪数额 |
| 股票/股权预期收益 | 以案发日股价作为犯罪数额基准 |
| 代持原始股（未出售） | 以案发日股价作为犯罪数额基准 |
| 共同受贿 | 个人分得赃款与受贿数额的关系需综合判断 |
| 行贿人支付的税费 | 应计入受贿数额 |

### 三、既未遂认定规则

| 情形 | 既遂标准 |
|------|----------|
| 贿赂款留在托管人账户 | 案发时仍留在托管人账户的，认定未遂 |
| 房产 | 以实际控制为标准，不以过户登记为标准 |
| 车辆 | 实际交付并办理过户登记 |
| 货币 | 实际控制并可支配 |

### 四、自首立功认定规则

| 情形 | 认定规则 |
|------|----------|
| 监察机关电话传唤后主动到案 | 需结合是否已掌握犯罪线索等具体判断 |
| 准自首 | 监察机关"掌握"的被调查人贪污贿赂行为未达"数额较大"、不构成犯罪为前提 |
| 提出系统完善建议被有关机关认可 | 不构成立功（不属于协助抓捕或其他立功表现） |

## 相比《贪污贿赂解释(一)》的核心变更

| 变更维度 | 旧解释（法释〔2016〕9号） | 新解释（法释〔2026〕6号二） |
|----------|--------------------------|----------------------------|
| 受贿罪数额标准 | 3万/20万/300万 | 维持不变 |
| 单位受贿罪 | 未明确规定 | 20万元以上，"情节严重"；200万元以上，"情节特别严重" |
| 对单位行贿罪 | 未明确规定 | 个人20万元以上、单位40万元以上 |
| 介绍贿赂罪 | 未明确规定 | 个人10万元以上、单位50万元以上 |
| 巨额财产来源不明 | 差额巨大30万以上，特别巨大300万以上 | 差额巨大300万元以上，特别巨大1000万元以上 |
| 斡旋受贿 | 未明确规定承诺说 | 明确承诺即为"为他人谋取不正当利益" |
