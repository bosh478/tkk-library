## 核心法律问题

减肥产品中含有禁止添加的西药成分，案件如何定性？如何把握情节轻微和情节显著轻微？

## 答疑结论

### 一、定性规则——区分食品与药品

| 产品性质 | 对应罪名 | 法条依据 |
|----------|----------|----------|
| 食品（保健食品） | 生产、销售有毒、有害食品罪 | 《刑法》第144条 |
| 药品 | 生产、销售、提供假药罪 | 《刑法》第141条 |

### 二、食品与药品的区分标准

| 判断维度 | 具体方法 |
|----------|----------|
| 核心标准 | 是否有"疾病预防、治疗功能"——标签、说明书是否涉及疾病预防、治疗功能，是否规定有适应症或功能主治 |
| 外观标识 | 产品审批文号、产品说明是否规定有适应症或功能主治、用法和用量 |
| 对外宣传 | 经营者以何种名义对外宣传、销售 |
| 标识与宣传一致 | 直接按标识确定产品属性 |
| 标识不明或冲突 | 按行为人对外宣传的产品性能，结合购买者购买、使用目的确定 |

**参考案例**：《刑事审判参考》第1531号"钟某本销售有毒、有害食品案"——产品以"壮阳补肾"名义销售，未宣传治疗功能，消费者基于"性保健"目的购买，认定为保健食品；检出西地那非，定销售有毒、有害食品罪。

### 三、情节轻重的把握

| 考量因素 | 说明 |
|----------|------|
| 销售数量 | 数量越小情节越轻 |
| 销售金额 | 金额越小情节越轻 |
| 销售时间长短 | 时间越短情节越轻 |
| 前科情况 | 是否曾因同类行为受过行政处罚或刑事处罚 |
| 综合认定 | 结合主客观情况综合判断 |

## 实务要点

1. 减肥产品定性不能一概而论，必须先行区分产品属于食品还是药品——这是定罪的前提
2. 产品标识不明或标识与宣传冲突时，以**行为人的对外宣传**及**消费者的购买目的**为最终判断依据
3. 保健食品检出禁止添加的西药成分，按生产、销售有毒、有害食品罪处理；若产品被认定为药品，则按假药罪处理
4. 情节显著轻微的认定需综合考量多因素，单一因素不足以决定
