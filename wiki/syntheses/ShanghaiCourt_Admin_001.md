## 背景

当前涉税争议案件**专业技术性强、事实认定复杂**，已成为法治化营商环境建设中的重点难点。上海三中院在行政审判庭加挂税务审判庭两周年之际召开新闻发布会，通报税务行政审判工作情况并发布5起典型案例。

## 数据概览

| 指标 | 数据 |
|------|------|
| 两年来受理税务行政案件 | 86件 |
| 其中二审 | 73件 |
| 一审 | 12件 |
| 再审 | 1件 |
| 已审结 | 80件 |
| 协调化解案件（2025年） | 11件 |
| 协调化解率 | 21% |

## 八项机制

上海三中院构建的**八项机制**包括：

| 机制 | 内容 |
|------|------|
| **便利诉讼** | 在虹口北外滩等地设立巡回审判点，就地开庭、就地协调化解涉税行政争议，切实减少当事人诉累 |
| **专业调解** | 组建由审判业务专家、业务骨干等组成的专业审判团队 |
| **专项审判** | 加挂税务审判庭，专注税务行政案件审理 |
| **实质解纷** | 坚持实质解纷导向，2025年协调化解率达21% |
| **精品调研** | 发布税务案件司法审查白皮书，完成多项重点调研课题 |
| **协同治理** | 坚持依法监督和支持税务部门执法与维护纳税人合法权益并重 |
| **数字赋能** | 依托数字化手段提升审判效率 |
| **法治宣传** | 发布典型案例，明晰税务案件裁判规则 |

## 府院联动

- **税务机关负责人出庭应诉率达100%** ✅
- 坚持依法监督和支持税务部门执法与维护纳税人合法权益**并重**
- 聘请高校财税法专家组建**司法智库**，为税务审判专业化提供智力支撑

## 典型案例涉及情形

发布的5起典型案例涉及：

| 类型 | 说明 |
|------|------|
| **隐匿收入逃避个人所得税** | 依法打击偷逃税行为 |
| **企业购置房屋未申报纳税** | 保护纳税人合法权益 |

## 裁判规则导向

> "这些案例明晰了税务案件裁判规则，体现了**依法打击偷逃税行为与保护纳税人合法权益并重**的导向。" —— 上海三中院行政审判庭（赔偿委员会办公室、税务审判庭）庭长丁晓华

## 典型意义

### 一、税务行政案件的专业化审判

1. **审判专业化**：组建专业审判团队，提高审理复杂涉税案件的能力
2. **裁判规则化**：通过典型案例明确裁判标准
3. **执纪协同化**：税务部门执法与法院司法审查形成合力

### 二、优化法治化营商环境

- **平等保护**：既打击违法行为，又保护纳税人合法权益
- **实质解纷**：减少当事人诉累，提高纠纷化解效率
- **府院联动**：形成行政与司法的良性互动
