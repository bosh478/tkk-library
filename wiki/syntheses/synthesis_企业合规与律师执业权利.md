# 企业合规与律师执业权利司法解释核心要点

## 一、涉案企业合规第三方监督评估机制

### 1.1 机制定位与组织架构

涉案企业合规第三方监督评估机制是指检察机关在办理涉企犯罪案件时，对符合条件的企业，由第三方监督评估组织（以下简称第三方组织）对其合规承诺及完成情况进行调查、评估、监督和考察的工作机制。

**第三方机制管委会**是承担宏观指导、具体管理、日常监督、统筹协调职责的议事协调机构，由最高人民检察院、司法部、财政部、生态环境部、国务院国资委、税务总局、市场监管总局、全国工商联、中国贸促会等部门组成。

管委会下设办公室（设在全国工商联），负责日常工作，包括组建国家层面专业人员名录库、组织巡回检查、协调指导等工作。

### 1.2 联席会议机制

联席会议由最高人民检察院、国务院国资委、财政部、全国工商联有关负责同志担任召集人，管委会其他成员单位有关负责同志担任成员。联席会议原则上每半年召开一次，也可根据工作需要临时召开。

- 涉及企业合规改革试点及重大法律政策议题的，由最高人民检察院召集
- 涉及民营企业议题的，由全国工商联召集
- 涉及国有企业议题的，由国务院国资委、财政部召集

### 1.3 第三方组织的组成

第三方组织是由第三方机制管委会从专业人员名录库中分类随机抽取人员组成的临时性组织，负责对涉案企业的合规承诺及完成情况进行调查、评估、监督和考察。

- **组成规模**：一般由3至7名专业人员组成；针对小微企业的可由2名专业人员组成
- **产生方式**：从专业人员名录库中分类随机抽取；无相关领域专业人员的，可采取协商邀请方式
- **公示要求**：选任组成人员名单需向社会公示，公示期不少于5个工作日
- **利益回避**：第三方组织组成人员在履职期间不得接受可能有利益关系的业务；履职结束后二年以内，其本人及所在中介组织不得接受涉案企业或有利益关系单位的业务

### 1.4 适用条件与启动程序

检察机关在办理涉企犯罪案件时，应当注意审查是否符合企业合规试点及第三方机制的适用条件：

- **启动方式**：检察机关经审查认为符合适用条件的，商请本地区第三方机制管委会启动第三方机制
- **申请来源**：涉案企业、人员及其辩护人、诉讼代理人可提出申请；公安机关、纪检监察机关可提出适用建议
- **组织选定**：管委会综合考虑案件涉嫌罪名、复杂程度及涉案企业类型、规模、经营范围等因素，选取专业人员组成第三方组织

### 1.5 合规计划的制定与审查

涉案企业提交的合规计划，应当以全面合规为目标、专项合规为重点，主要针对以下方面：

1. 企业内部治理结构问题
2. 规章制度问题
3. 人员管理问题
4. 业务管理流程漏洞
5. 合规风险防范报告机制缺失

第三方组织审查合规计划的重点内容：

- 涉案企业完成合规计划的可能性及合规计划本身的可操作性
- 合规计划对预防治理涉嫌犯罪行为或类似违法犯罪行为的实效性
- 合规计划是否覆盖涉案企业在合规领域的薄弱环节和明显漏洞

### 1.6 监督评估方法

第三方组织在合规考察期内采用的监督评估方法包括：

1. **观察、访谈、文本审阅、问卷调查、知识测试**
2. **抽样检查**：对相关业务与管理事项，结合业务发生频率、重要性及合规风险高低进行抽样
3. **穿透式检查**：对业务处理流程，结合原始文件、业务处理踪迹、操作管理流程等进行穿透式检查
4. **系统数据比对检查**：对相关系统及数据，结合交易数据、业务凭证、工作记录及权限、参数设置等进行比对检查

### 1.7 合规考察程序

- **考察期限**：由第三方组织根据案件具体情况和企业承诺履行期限合理确定
- **定期监督**：第三方组织定期或不定地对涉案企业合规计划履行情况进行监督和评估，可要求企业定期书面报告
- **纠偏职责**：发现企业执行合规计划存在明显偏差或错误的，及时进行指导、提出纠正意见，并报告检察机关
- **报告出具**：考察期届满后，第三方组织制作合规考察书面报告，报送第三方机制管委会和检察机关

## 二、律师执业权利保障

### 2.1 保障平台与接待机制

**12309检察服务平台**统一接收律师提交的案件材料，集中受理律师提出的阅卷、约见案件承办人、调取证据、查询等事项。

律师可通过以下方式提出事项：

- 拨打12309检察服务热线
- 登陆12309中国检察网
- 到12309检察服务中心现场办理

检察机关应当及时办理，并将办理情况或结果告知律师，做到"件件有回复"。

### 2.2 知情权保障

检察机关受理公安机关提请批准逮捕，作出退回补充侦查、改变管辖、提起公诉等重要程序性决定的，应当通过电话、短信、手机App信息推送等方式及时告知辩护律师。办案人员的姓名及联系方式也应向辩护律师提供。

### 2.3 阅卷权保障

- 律师提出阅卷申请后，一般应当提供**电子卷宗**，便于查阅、复制
- 律师提出调阅纸质卷宗的，检察机关了解原因后认为应予支持的，应当及时安排
- 进一步规范电子卷宗制作标准，确保完整、清晰、准确
- 符合互联网阅卷要求的，应当在**三日内**完成律师互联网阅卷申请的办理和答复

### 2.4 听取律师意见

检察机关听取律师意见应当坚持**"能见尽见、应听尽听"**原则：

- 拟决定或批准逮捕犯罪嫌疑人的，应当在作出决定前**征询辩护律师意见**
- 拟当面听取律师意见的，由检察官或检察官助理在专门律师会见室进行，配备记录人员，完整记录
- 当面听取有困难的，可通过书面、电话、视频等方式进行并记录在案

### 2.5 意见采纳反馈

- 检察机关应当全面审查律师就办案工作提出的意见，有事实和法律依据的意见应当吸收
- 在案件办结前，通过约见、书面、电话、视频等方式向律师反馈意见采纳情况及不予采纳的理由，并记录在案
- 制作法律文书时，应当写明律师相关信息，并载明律师意见、检察机关采纳情况及不予采纳的理由

### 2.6 认罪认罚案件律师参与

- 办理认罪认罚案件，应当认真听取辩护律师或值班律师的意见
- 已委托辩护律师的，应当提前通知辩护律师，确保犯罪嫌疑人在辩护律师在场时有明确意见
- **不得绕开辩护律师安排值班律师代为见证具结**
- 辩护律师确因客观原因无法到场的，可通过远程视频方式见证具结
- 确有不便的，经辩护律师同意，可安排值班律师在场履职

### 2.7 会见权监督保障

- 检察机关应当在看守所、监狱等律师会见场所公布派驻检察人员姓名及办公电话
- 律师提出会见申请认为受到阻碍的，可向检察机关提出控告申诉
- 派驻检察人员能当场处理的，应当及时监督相关部门依法保障律师会见权
- 不能当场处理的，应当在**五个工作日内**审查办理完毕
- 派驻检察室应当与看守所、监狱建立及时畅通的沟通交流机制

### 2.8 权利救济渠道

| 救济途径 | 具体方式 |
|----------|----------|
| 控告申诉 | 向该检察院或上一级检察院提出控告申诉 |
| 协会反映 | 向所属律师协会反映，律师协会及时将问题线索转交检察机关 |
| 快速联动 | 检察机关收到控告申诉或问题线索后，作为阻碍律师执业权利监督案件优先受理 |
| 办理时限 | 一般控告申诉：十日内办结并书面答复；情况紧急：三个工作日内办理并答复 |

### 2.9 责任落实机制

- 将依法保障律师执业权利工作情况**纳入检察人员业绩考评体系**
- 调查核实律师控告申诉情况属实的，及时通知本院有关部门、下级检察院予以纠正
- 本院有关部门、下级检察院未予纠正或纠正不到位的，及时通报或移送相关线索
- 检察人员违反职责阻碍律师依法执业需要追究司法责任的，严格依照《人民检察院司法责任追究条例》处理

### 2.10 沟通协调机制

- 检察机关、司法行政机关和律师协会加强沟通协调，发挥维护律师执业权利快速联动处置机制作用
- **每半年召开一次联席会议**，相互通报保障律师依法执业工作情况
- 建立健全**检律同堂培训机制**，常态化组织开展检律同堂培训
- 围绕律师执业权利保障、检律互动亲清有度，联合开展专项调研

## 三、适用要点汇总表

### 3.1 企业合规第三方监督评估机制适用要点

| 项目 | 要点内容 |
|------|----------|
| **适用条件** | 检察机关办理涉企犯罪案件，认为符合适用条件的 |
| **启动主体** | 检察机关（商请管委会启动）；涉案企业、人员及其辩护人、诉讼代理人（可申请） |
| **组织规模** | 一般3-7名专业人员；小微企业可2名 |
| **公示要求** | 组成人员名单向社会公示，公示期不少于5个工作日 |
| **考察期限** | 由第三方组织合理确定 |
| **利益回避** | 履职期间不得接受可能有利益关系的业务；结束后二年以内不得接受涉案企业或有利害关系单位的业务 |
| **报告时限** | 检察机关收到合规考察书面报告后及时审查，第三方组织完成监督评估工作的，由管委会宣告解散 |
| **弄虚作假后果** | 及时向有关主管机关、协会提出惩戒建议，涉嫌违法犯罪的向有关机关报案或举报，并列入禁入名单 |

### 3.2 律师执业权利保障要点

| 权利类型 | 核心要点 | 办理时限 |
|----------|----------|----------|
| **接待平台** | 12309检察服务平台统一接收，"件件有回复" | — |
| **知情权** | 重要程序性决定及时告知（电话/短信/App推送） | — |
| **阅卷权** | 一般提供电子卷宗；符合互联网阅卷条件 | 三日内完成互联网阅卷申请答复 |
| **听取意见** | "能见尽见、应听尽听"原则；逮捕前征询辩护律师意见 | — |
| **意见反馈** | 案件办结前反馈意见采纳情况及理由 | — |
| **认罪认罚** | 不得绕开辩护律师安排值班律师代为见证具结 | — |
| **会见权** | 看守所、监狱公布派驻检察人员信息；阻碍会见可向检察机关控告 | 五个工作日内审查办理 |
| **权利救济** | 向检察院或律师协会提出；情况紧急 | 一般十日；紧急三日 |

### 3.3 检律沟通协调机制

| 机制 | 频次/内容 |
|------|-----------|
| **联席会议** | 检察机关、司法行政机关、律师协会每半年召开一次 |
| **检律同堂培训** | 常态化组织开展 |
| **专项调研** | 围绕律师执业权利保障、检律互动亲清有度联合开展 |
| **快速联动** | 维护律师执业权利快速联动处置机制 |
| **业绩考评** | 保障律师执业权利工作情况纳入检察人员业绩考评体系 |
