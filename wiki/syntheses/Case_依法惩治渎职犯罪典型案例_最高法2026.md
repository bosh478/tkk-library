# 依法惩治渎职犯罪典型案例（2026年6月）

**发布机关**：最高人民法院  
**发布时间**：2026年6月18日  
**发布背景**：为充分发挥典型案例的教育、警示和震慑作用，推动树立和践行正确政绩观学习教育走深走实

## 发布特点

| 特点 | 内容 |
|------|------|
| 突出惩治重点 | 4件案例涵盖国家机关和国有公司、企业、事业单位工作人员渎职犯罪，涉及高质量发展、国有资产保护、生态环境保护、道路工程建设等重点领域 |
| 坚持依法严惩 | 对受贿并滥用职权，以及渎职行为造成公共财产、国家和人民利益重大损失的，坚持依法从严惩治 |
| 深化促改促治 | 通过以案释法、制发司法建议等方式，会同有关部门强化警示教育、加强监督管理、完善制度机制、促推源头治理 |

## 案例一：曹某受贿、滥用职权案

**关键词**：市委书记、违规举债、隐性债务、烂尾工程

**定罪量刑**：
| 罪名 | 量刑 |
|------|------|
| 受贿罪 | 有期徒刑十一年六个月，并处罚金二百万元 |
| 滥用职权罪 | 有期徒刑四年六个月 |
| 决定执行 | 有期徒刑十三年，并处罚金二百万元 |

**核心事实**：2016年至2021年，曹某担任湖南省某市市委书记期间，明知当地财力不足、政府债务已风险预警，仍违规推动融资举债实施大型项目建设，导致财政新增巨额隐性债务，政府总体债务严重超出债务风险红色预警线，形成烂尾工程33个，造成特别重大经济损失，并引发多起债务纠纷、群体性信访事件。曹某还收受贿赂2495万余元。

**典型意义**：依法依规是党员领导干部履职的前提和底线。曹某对中央防范化解地方债务风险的要求置若罔闻，造成特别恶劣社会影响。法院认定曹某滥用职权情节特别严重，依法予以惩处。

## 案例二：李某受贿、滥用职权案

**关键词**：交通运输局局长、高速公路建设、BOT模式、索贿

**定罪量刑**：
| 罪名 | 量刑 |
|------|------|
| 受贿罪 | 死刑，缓期二年执行，剥夺政治权利终身，并处没收个人全部财产 |
| 滥用职权罪 | 有期徒刑九年 |
| 决定执行 | 死刑，缓期二年执行，剥夺政治权利终身，并处没收个人全部财产 |

**核心事实**：2012年，四川省某市计划采用BOT模式修建两条高速公路。被告人李某时任市交通运输局局长，接受请托帮助章某获得工程，虚报伊某集团已汇款30亿元到监管账户，误导拨付补贴款，擅自同意将征地拆迁资金挪为补贴资金，未履行监管职责致章某大量挪用资金。最终高速公路全面停工，造成国有资金直接损失7.61亿元。李某还向章某索贿1.3亿元。

**典型意义**：道路工程质量直接影响社会经济发展和人民群众生命财产安全，发生在道路工程领域的职务犯罪危害性远超一般刑事犯罪，应依法从严惩治。

## 案例三：鲁某受贿、滥用职权案

**关键词**：水利局局长、泥炭资源、黑土地保护、非法采矿

**定罪量刑**：
| 罪名 | 量刑 |
|------|------|
| 受贿罪 | 有期徒刑三年，并处罚金二十万元 |
| 滥用职权罪 | 有期徒刑三年六个月 |
| 决定执行 | 有期徒刑四年六个月，并处罚金二十万元 |
| 另案处理张某 | 非法采矿罪，有期徒刑七年 |

**核心事实**：2021年至2023年1月，鲁某担任吉林省某县镇党委书记、县水利局局长期间，超越职权范围违规批复水库清淤项目，明知张某等人非法盗采泥炭仍放任不管，导致县域内三个水库被非法开采泥炭27万余立方米，价值1126万余元。鲁某还收受贿赂61万余元。

**典型意义**：黑土地是珍贵且稀缺的农业资源，泥炭是维持黑土地肥力的重要组成部分。法院对鲁某依法定罪处罚，彰显国家对环境资源保护领域职务犯罪严惩不贷的鲜明态度。

## 案例四：刘某贪污、受贿、国有公司人员滥用职权案

**关键词**：国有公司、农业产业基金、司法建议、三重一大制度

**定罪量刑**：
| 罪名 | 量刑 |
|------|------|
| 国有公司人员滥用职权罪 | 有期徒刑六年 |
| 受贿罪 | 有期徒刑三年，并处罚金二十万元 |
| 贪污罪 | 有期徒刑六个月，并处罚金十万元 |
| 决定执行 | 有期徒刑七年六个月，并处罚金三十万元 |

**核心事实**：2016年至2021年，刘某任某通公司（农业股权投资基金公司）董事长兼总经理期间，未经董事会必要程序擅自决定拟投资企业名单，未核实被尽调企业材料的真实性和合法性，发现风险后未采取有效措施，为掩盖问题擅自修改投资协议内容，导致1.9亿余元投资资金及收益无法追回。刘某还侵吞公款6万余元、收受贿赂55万余元。

**典型意义**：审理法院发现案涉国有公司"三重一大"制度流于形式、董事会监督职能未能有效发挥、投后管理风险预警机制形同虚设，遂制发司法建议，促推完善内部治理结构，并定期跟踪回访，推动重构全链条监督机制。
