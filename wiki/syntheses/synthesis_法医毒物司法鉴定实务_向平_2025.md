## 章节结构

### 第一章 法医毒物司法鉴定概论（第1-26页）

**毒物概述**

毒物（poison）是指在一定条件下，以较小剂量进入机体后，通过化学或物理化学作用，引起机体功能性或器质性损害，甚至导致死亡的化学物质。毒物概念三要素：
- 剂量：任何物质达到一定剂量都可能产生危害（"The dose makes the poison"）
- 外源性：通过各种途径进入机体发挥毒作用
- 作用方式：通过化学或物理化学作用导致损害

毒物与毒品的区别：
- 毒物：化学物质在特定条件下的毒性表现
- 毒品：法学范畴概念，《刑法》第357条规定的国家管制的麻醉药品和精神药品
- 截至2023年6月，我国已列管456种麻醉品和精神物质

**毒物分类（综合分类法）**

| 种类 | 代表毒物 |
|------|----------|
| 气体毒物 | 一氧化碳、硫化氢、一氧化二氮、液化石油气、氦气等 |
| 挥发性毒物 | 乙醇、甲醇、氰化物、苯及其同系物等 |
| 合成药毒物 | 苯二氮卓类、巴比妥类、抗抑郁药、抗精神病药、抗生素等 |
| 天然药毒物 | 乌头生物碱、士的宁、马钱子、钩吻、河鲀毒素等 |
| 毒品 | 阿片类、苯丙胺类、大麻类、可卡因、新精神活性物质等 |
| 易制毒化学品 | 麻黄碱、1-苯基-2-溴-1-丙酮、羟亚胺等 |
| 杀虫剂 | 有机磷类、氨基甲酸酯类、拟除虫菊酯类等 |
| 除草剂 | 百草枯、敌草快、草甘膦等 |
| 杀鼠剂 | 毒鼠强、氟乙酰胺、抗凝血类等 |
| 金属毒物 | 砷、汞、铊、铬、铅等 |
| 水溶性无机毒物 | 亚硝酸盐、强酸、强碱等 |

**中毒及中毒症状**
- 急性中毒：一次接触大剂量毒物，短时间内出现严重症状
- 慢性中毒：多次或长期接触小剂量毒物
- 亚急性中毒：介于两者之间
- 中毒量、致死量、中毒血浓度、致死血浓度的概念

**中毒症状与毒物对应关系**

| 中毒症状 | 可能毒物 |
|----------|----------|
| 颜面樱红 | 氰化物、一氧化碳 |
| 特殊气味（杏仁味） | 氰化物、硝基苯 |
| 瞳孔散大 | 阿托品、莨菪烷类生物碱、乌头碱 |
| 瞳孔缩小 | 有机磷、氨基甲酸酯类、阿片类 |
| 抽搐 | 氟乙酰胺、毒鼠强、有机磷、士的宁 |
| 凝血功能障碍 | 抗凝血杀鼠剂 |

**影响毒物作用的因素**

毒物本身因素：
- 理化性质：气态>液态>固态的吸收速度
- 剂量-效应关系：进入机体的吸收量而非口服量
- 毒物相互作用：独立作用、相加作用、协同作用、增毒作用、拮抗作用

机体因素：
- 个体状况：儿童、老人、妇女特殊时期更敏感
- 遗传因素：CYP450酶基因多态性导致个体差异（15%-30%由基因决定）
- 习惯性/耐受性：长期使用可耐受常人中毒剂量
- 过敏性：特异质和变态反应

**毒物的体内过程**
- 吸收：消化道、呼吸道、皮肤黏膜、注射等途径
- 分布：取决于组织血流速率、生理性屏障、毒物与组织亲和力
- 代谢：Ⅰ相代谢（氧化、还原、水解）和Ⅱ相代谢（结合反应）
- 排泄：肾脏排泄、胆汁排泄、肺排泄、唾液及汗液排泄

**毒物死后再分布及死后产生**
- 死后再分布：毒物从高浓度器官向邻近组织扩散，导致死后浓度变化
- 毒物死后产生：腐败过程中产生醇类、硫化氢或氰化物等非生前服用毒物

**法医毒物鉴定的任务**
1. 法医中毒鉴定：判定有无毒物、确定中毒物质、估计中毒程度、推断中毒性质
2. 体内滥用物质鉴定：摄毒鉴定、行为能力判定、药物辅助犯罪鉴定
3. 毒品鉴定：对可疑物品的定性定量分析

**法医毒物鉴定的特点**
- 分析目标物的不定性：探查性和验证性
- 检验材料的复杂性：多样性、一次性、有限性
- 鉴定方法的综合性
- 鉴定工作的严谨性

**法医毒物学发展简史**
- 古代：《洗冤集录》中已有毒物中毒鉴别方法
- 1932年：林几教授创建司法行政部法医研究所
- 黄鸣驹教授：《毒物分析化学》（1932年）
- 新中国成立后：逐步建立专业法医毒物检验机构

### 第三章 法医毒物司法鉴定方法（第37-53页）

**生物检材类型与应用价值**

| 检材类型 | 特点与应用 |
|----------|------------|
| 血液 | 最常用，反映近期毒物暴露 |
| 尿液 | 检测时限较长，含代谢物 |
| 头发、指甲 | 反映长期暴露史 |
| 唾液 | 非侵入性采集 |
| 肝脏等组织 | 死后毒物分布分析 |
| 胆汁 | 某些毒物的主要排泄途径 |
| 玻璃体液 | 受环境影响小，腐败尸体的替代检材 |
| 胃内容物 | 口服毒物的直接证据 |

**检材处理**
- 检材保存原则
- 前处理方法：预处理、萃取分离与富集
- 常用萃取方法：液液萃取、固相萃取、固相微萃取等

**毒物鉴定技术方法**

| 技术类型 | 原理 | 常用方法 |
|----------|------|----------|
| 免疫分析 | 抗原抗体反应 | ELISA、胶体金免疫层析 |
| 光谱分析 | 特征吸收光谱 | 紫外可见分光光度法、原子吸收光谱 |
| 色谱分析 | 分离分析 | GC、HPLC |
| 质谱分析 | 质荷比 | GC-MS、LC-MS/MS |
| 联用技术 | 色谱分离+质谱检测 | GC-MS、LC-MS/MS、ICP-MS |

### 第五章 气体毒物鉴定（第73-96页）

**气体毒物分类**
- 影响氧的供给：氮气、氦气、天然气、液化石油气
- 影响血液摄取或运输氧：一氧化碳、一氧化氮
- 影响氧的利用（组织细胞性缺氧）：硫化氢、氰化氢

**一氧化碳（CO）**
- 特性：无色无味，与血红蛋白结合生成COHb
- 中毒机制：CO与血红蛋白亲和力为氧气的250-300倍
- COHb饱和度与症状：10-20%轻微头痛，>50%可致死
- 检测方法：单波长法、双波长法、还原双波长法（分光光度法）
- 鉴定要点：COHb>50%通常与死亡相符

**硫化氢（H₂S）**
- 特性：无色、臭鸡蛋味，细胞色素氧化酶抑制剂
- 中毒机制：抑制细胞中电子传递，引起细胞内窒息
- "电击样"中毒：1000-2000ppm可致闪电型死亡
- 检测方法：硫离子衍生化法、硫代硫酸根离子衍生化法、酸化后顶空GC-MS
- 尸斑特征：紫绿色或暗绿色

**液化石油气（LPG）**
- 主要成分：丙烷、丁烷等烃类
- 中毒机制：缺氧窒息+中枢神经系统麻醉
- 检测方法：顶空气相色谱法、顶空GC-MS
- 案例特点：多见于滥用或自杀

**氦气等惰性气体**
- 特性：无色无臭不可燃，本身无毒但导致缺氧
- 自杀方式：塑料袋套头+氦气罐
- 检材选择：肺组织首选，其次心血、脑组织
- 检测难点：需改变载气（因氦气常作载气）

**一氧化二氮（"笑气"）**
- 特性：无色有甜味，轻微麻醉作用
- 滥用现状：英国仅次于大麻的第二大娱乐性毒品
- 中毒机制：抑制NMDA受体，影响维生素B₁₂代谢
- 检测方法：顶空GC-MS

### 第六章 挥发性毒物鉴定（第97-117页）

**乙醇、甲醇**
- 乙醇：最常见挥发性毒物，与交通事故密切相关
- 甲醇：代谢产生甲酸，可致失明和死亡
- 检测方法：顶空气相色谱法

**氰化物**
- 剧毒，抑制细胞色素氧化酶
- 苦杏仁味特征
- 检测方法：顶空GC-MS

**苯及其同系物**
- 工业毒物，致癌物
- 检测方法：顶空GC-MS

### 第七章 合成药毒物鉴定（第118-154页）

**苯二氮卓类药物**
- 代表药物：地西泮、咪达唑仑、三唑仑等
- 镇静催眠作用，常用于药物辅助犯罪
- 检测方法：LC-MS/MS

**巴比妥类药物**
- 代表药物：苯巴比妥、戊巴比妥等
- 中枢神经系统抑制剂
- 检测方法：GC-MS、LC-MS/MS

**抗抑郁药物**
- 三环类抗抑郁药（阿米替林等）
- 选择性5-HT再摄取抑制剂（氟西汀等）
- 高Vd值，死后再分布明显

**抗精神病药物**
- 氯丙嗪、氯氮平、奥氮平等
- 检测方法：LC-MS/MS

**麻醉药物**
- 利多卡因、布比卡因等局部麻醉药
- 丙泊酚等全身麻醉药

### 第八章 天然药毒物鉴定（第155-176页）

**乌头生物碱**
- 乌头、附子中的主要毒性成分
- 钠通道阻滞剂，可致心律失常
- 检测方法：LC-MS/MS

**士的宁和马钱子碱**
- 神经毒物，甘氨酸受体拮抗剂
- 致强直性痉挛
- 检测方法：GC-MS、LC-MS/MS

**莨菪烷类生物碱**
- 阿托品、东莨菪碱等
- 抗胆碱能作用，瞳孔散大
- 检测方法：GC-MS、LC-MS/MS

**钩吻生物碱**
- 钩吻（断肠草）中的毒性成分
- 极毒，可致呼吸衰竭
- 检测方法：LC-MS/MS

**烟碱**
- 烟草中的主要生物碱
- 烟碱型乙酰胆碱受体激动剂

**河鲀毒素**
- 河鲀鱼中的毒素
- 钠通道阻滞剂
- 检测方法：LC-MS/MS

### 第十章 体内毒品鉴定（第193-247页）

**阿片类物质**
- 海洛因、吗啡、可待因等
- 代谢途径：海洛因→6-MAM→吗啡→吗啡葡萄糖醛酸苷
- 检材选择：尿液（首选）、血液、毛发
- 检测方法：LC-MS/MS

**苯丙胺类物质**
- 甲基苯丙胺（冰毒）、MDMA（摇头丸）等
- 代谢途径和特征代谢物
- 检测方法：GC-MS、LC-MS/MS

**大麻**
- THC、CBD、CBN等大麻素
- THC-COOH为长期使用标志物
- 毛发检测可反映使用史

**可卡因**
- 苯甲酰爱康宁为特征代谢物
- 检测方法：GC-MS、LC-MS/MS

**致幻剂**
- LSD、麦司卡林、PCP等
- 检测方法：LC-MS/MS

**GHB**
- 中枢神经系统抑制剂
- 内源性物质，判定阈值需谨慎
- 检测方法：GC-MS、LC-MS/MS

**新精神活性物质**
- 合成大麻素、合成卡西酮类、苯乙胺类等
- 种类繁多，更新迅速
- 检测方法：LC-MS/MS

### 第十一章 易制毒化学品鉴定（第248-256页）

**麻黄碱、伪麻黄碱**
- 冰毒前体物质
- 检测方法：GC-MS、LC-MS/MS

**1-苯基-2-溴-1-丙酮**
- 新型冰毒前体
- 检测方法：GC-MS

**羟亚胺**
- 氯胺酮前体物质
- 检测方法：GC-MS、LC-MS/MS

### 第十二章 杀虫剂鉴定（第257-280页）

**有机磷类杀虫剂**
- 代表毒物：敌敌畏、甲胺磷、对硫磷等
- 中毒机制：抑制胆碱酯酶活性
- 特征症状：瞳孔缩小、大汗、肌束震颤
- 检测方法：GC-FPD、GC-MS

**氨基甲酸酯类杀虫剂**
- 代表毒物：克百威、涕灭威等
- 中毒机制：可逆性胆碱酯酶抑制
- 检测方法：GC-MS、LC-MS/MS

**拟除虫菊酯类杀虫剂**
- 代表毒物：溴氰菊酯、氯氰菊酯等
- 中毒机制：钠通道延迟关闭
- 检测方法：GC-MS、LC-MS/MS

**沙蚕毒素类杀虫剂**
- 代表毒物：杀虫双、杀虫单等
- 中毒机制：胆碱能受体阻滞
- 检测方法：GC-MS、LC-MS/MS

### 第十三章 除草剂鉴定（第281-295页）

**草甘膦、草铵膦**
- 广谱除草剂
- 检测方法：LC-MS/MS

**百草枯、敌草快**
- 剧毒除草剂，无特效解毒剂
- 中毒机制：产生氧自由基，导致多器官损伤
- 肺纤维化为特征性病变
- 检测方法：LC-MS/MS

**2,4-D等苯氧羧酸类除草剂**
- 检测方法：GC-MS、LC-MS/MS

**磺酰脲类除草剂**
- 检测方法：LC-MS/MS

### 第十四章 杀鼠剂鉴定（第296-311页）

**毒鼠强**
- 剧毒，GABA受体拮抗剂
- 致强直性痉挛，无特效解毒剂
- 检测方法：GC-MS、LC-MS/MS

**氟乙酰胺及氟乙酸钠**
- 中毒机制：干扰三羧酸循环
- 检测方法：GC-MS、LC-MS/MS

**抗凝血类杀鼠剂**
- 代表毒物：溴敌隆、溴鼠灵等
- 中毒机制：抑制维生素K环氧化物还原酶
- 特征：凝血功能障碍，出血倾向
- 检测方法：LC-MS/MS

**无机磷化物杀鼠剂**
- 磷化锌、磷化铝等
- 中毒机制：产生磷化氢气体
- 检测方法：顶空气相色谱法

### 第十五章 金属毒物鉴定（第312-332页）

**概述**
- 金属毒物的特点：蓄积性、慢性中毒多见
- 检测方法：原子吸收光谱法、ICP-MS

**砷及其化合物**
- 三氧化二砷（砒霜）：剧毒
- 中毒机制：抑制含巯基酶
- 检测方法：原子荧光光谱法、ICP-MS

**汞及其化合物**
- 无机汞和有机汞
- 甲基汞：神经毒性，可通过胎盘屏障
- 检测方法：原子荧光光谱法、ICP-MS

**铅及其化合物**
- 慢性中毒为主
- 影响血红蛋白合成
- 检测方法：原子吸收光谱法、ICP-MS

**铊及其化合物**
- 剧毒，无色无味
- 中毒机制：干扰钾离子通道
- 检测方法：ICP-MS

### 第十六章 水溶性无机毒物鉴定（第333-340页）

**亚硝酸盐**
- 中毒机制：将血红蛋白氧化为高铁血红蛋白
- 特征：皮肤黏膜发绀
- 检测方法：分光光度法、离子色谱法

**强酸**
- 硫酸、盐酸、硝酸等
- 腐蚀性损伤
- 检测方法：酸碱滴定法

**强碱**
- 氢氧化钠、氢氧化钾等
- 腐蚀性损伤
- 检测方法：酸碱滴定法

### 毒物代谢动力学参数

| 参数 | 含义 | 法医学意义 |
|------|------|------------|
| Cmax | 峰浓度 | 评价吸收速度 |
| Tmax | 达峰时间 | 推断毒物入体时间 |
| Vd | 表观分布容积 | 反映分布广泛程度 |
| t1/2 | 消除半衰期 | 确定检出时限 |

### 毒物死后再分布

| 现象 | 机制 | 鉴定影响 |
|------|------|----------|
| 心血浓度升高 | 毒物从富集器官扩散 | 心血浓度≠死亡时浓度 |
| 周围组织浓度变化 | 顺浓度梯度扩散 | 需综合多组织分析 |
| 超大剂量中毒 | 再分布不影响结论 | 仍以心血为主要检材 |

## 案例分析要点

### 气体毒物中毒案例特点

| 毒物 | 现场特征 | 尸检特征 | 毒物分析 |
|------|----------|----------|----------|
| CO | 煤气源、密闭空间 | 樱桃红色尸斑 | COHb饱和度测定 |
| H₂S | 臭鸡蛋味、工业场所 | 暗绿色尸斑 | 硫离子/硫代硫酸盐检测 |
| LPG | 液化气罐 | 鲜红色尸斑 | 顶空GC-MS |
| 惰性气体 | 塑料袋、气罐 | 缺氧征象 | 顶空GC-MS（改载气） |
| 笑气 | 气弹、气罐 | 缺氧征象 | 顶空GC-MS |

### 常见中毒案件鉴定策略

1. **疑似中毒死亡**：系统毒物筛查→定性确认→定量分析→结果评价
2. **药物辅助犯罪**：尿液/毛发筛查→目标物确认→行为能力评价
3. **涉毒案件**：体外毒品定性定量→体内毒品代谢物分析
4. **气体毒物中毒**：现场勘查→特殊检材采集→顶空GC-MS分析

## 法律实务要点

1. **鉴定意见的科学性**：毒物鉴定结果是证明客观事实的科学证据，涉及公民合法权益和司法公正
2. **检材管理**：检材一次性、有限性，必须妥善保存以供复核
3. **结果解释**：定量分析是科学评价中毒程度的基础，定性结果需结合案情综合分析
4. **死后再分布**：中毒鉴定应同时采集外周血、玻璃体液及其他组织等多种检材
5. **毒物死后产生**：醇类、硫化氢、氰化物需区分生前服毒还是死后产生
6. **新精神活性物质**：种类繁多、更新迅速，需持续关注管制目录变化
