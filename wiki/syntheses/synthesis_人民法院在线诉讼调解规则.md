## 一、规则体系概述

| 规则名称 | 文号 | 发布日期 | 生效日期 | 效力状态 |
|----------|------|----------|----------|----------|
| 人民法院在线诉讼规则 | 法释〔2021〕12号 | 2021.06.16 | 2021.08.01 | 现行有效 |
| 人民法院在线调解规则 | 法释〔2021〕23号 | 2021.12.30 | 2022.01.01 | 现行有效 |

两个规则共同构建了人民法院在线诉讼活动的完整规范体系，《人民法院在线诉讼规则》规范在线立案、庭审、执行等诉讼活动；《人民法院在线调解规则》规范立案前及诉讼中的在线调解活动。

## 二、《人民法院在线诉讼规则》核心要点

### （一）基本原则（第二条）

1. **公正高效原则**：严格依法开展在线诉讼，完善审判流程，健全工作机制，加强技术保障
2. **合法自愿原则**：尊重当事人诉讼方式选择权，未经同意不得强制适用
3. **权利保障原则**：充分保障诉讼权利，不得随意减少诉讼环节和减损权益
4. **便民利民原则**：优化在线诉讼服务，降低诉讼成本，统筹兼顾不同群体需求
5. **安全可靠原则**：维护国家安全，保护国家秘密、商业秘密、个人隐私，确保技术中立

### （二）适用范围（第三条）

以下案件可以适用在线诉讼：
- 民事、行政诉讼案件
- 刑事速裁程序案件，减刑、假释案件，因特殊原因不宜线下审理的刑事案件
- 民事特别程序、督促程序、破产程序和非诉执行审查案件
- 民事、行政执行案件和刑事附带民事诉讼执行案件
- 其他适宜采取在线方式审理的案件

### （三）同意规则（第四条）

| 情形 | 处理方式 |
|------|----------|
| 当事人主动选择适用 | 不另行征得同意，相应环节直接在线进行 |
| 各方均同意 | 相应环节在线进行 |
| 部分同意 | 同意方线上、不同意方线下 |
| 仅选择部分环节 | 不推定对其他环节同意 |

### （四）转为线下的情形（第五条）

1. 当事人欠缺在线诉讼能力、不具备在线诉讼条件
2. 相应诉讼环节不宜在线办理
3. 当事人在合理期限内反悔（经审查不存在故意拖延）
4. 一方当事人要求线下参与并提出具体理由（案件疑难复杂、需证人现场作证、有必要线下举证质证、陈述辩论等）

### （五）身份认证（第七条）

- 诉讼主体先行在诉讼平台完成实名注册
- 通过证件证照在线比对、身份认证平台认证等方式核实
- 确认身份后取得登录诉讼平台的专用账号
- 账号被盗用或系统错误除外，使用专用账号所作行为视为本人行为
- 在线调解、证据交换、庭审等活动应当再次验证身份

### （六）在线立案（第九条）

| 情形 | 处理方式 |
|------|----------|
| 符合起诉条件 | 登记立案，送达受理通知书、缴费通知书、举证通知书 |
| 材料不符合要求 | 一次性告知补正内容和期限，收到补正材料后次日重新起算 |
| 不符合条件或补正后仍不符合 | 裁定不予受理或不予立案 |

### （七）电子材料规则（第十一条至第十三条）

**提交方式**：
- 直接在诉讼平台填写录入起诉状、答辩状、反诉状、代理意见
- 扫描、翻拍、转录等方式电子化处理后上传
- 电子数据可直接提交（平台已对接情况下）

**原件、原物提交要求**（第十二条）：
1. 对方当事人提出不一致并提出合理理由
2. 电子化材料呈现不完整、内容不清晰、格式不规范
3. 卷宗档案管理要求提供原件、原物
4. 人民法院认为有必要提交原件、原物

**符合原件形式要求的情形**（第十三条）：
1. 对方当事人未提出异议
2. 已经过公证机构公证
3. 已在之前诉讼中提交并经确认
4. 已通过在线或线下方式与原件、原物比对一致
5. 有其他证据证明一致

### （八）在线证据交换（第十四条）

| 方式 | 具体做法 |
|------|----------|
| 同步交换 | 在指定时间登录诉讼平台，集中发表质证意见 |
| 非同步交换 | 在确定期限内分别登录诉讼平台查看证据并发表意见 |
| 均同意但无法达成一致 | 适用同步在线证据交换 |

### （九）区块链存证认定（第十六条至第十八条）

**认定规则（第十六条）**：
电子数据系通过区块链技术存储，并经技术核验一致的，可以认定上链后未经篡改，但有相反证据足以推翻的除外。

**真实性异议审查因素（第十七条）**：
1. 存证平台是否符合国家有关规定
2. 当事人与存证平台是否存在利害关系
3. 信息系统是否符合国家标准或行业标准
4. 存证技术和过程是否符合相关标准

**上链前真实性（第十八条）**：
当事人提出电子数据上链前已不具备真实性并提供证据或说明理由的，人民法院应当审查。可要求提交方提供证据证明，并结合上链前数据具体来源、生成机制、存储过程、公证情况、第三方见证、关联印证数据等综合判断。

### （十）在线庭审规则（第二十条至第二十七条）

**适用范围决定因素**：当事人意愿、案件情况、社会影响、技术条件

**禁止适用在线庭审的情形（第二十一条）**：
1. 各方均明确表示不同意，或一方不同意且有正当理由
2. 各方均不具备在线庭审技术条件
3. 需要通过庭审现场查明身份、核对原件、查验实物
4. 案件疑难复杂、证据繁多，在线审理不利于查明事实
5. 涉及国家安全、国家秘密
6. 案件具有重大社会影响，受到广泛关注
7. 人民法院认为存在其他不宜适用在线庭审情形

**在线法庭环境要求（第二十四条）**：
- 环境要素齐全，保持国徽显著位置
- 审判人员及席位名称在视频画面合理区域
- 出庭人员选择安静、无干扰、光线适宜、网络信号良好、相对封闭的场所
- 不得在可能影响效果或有损严肃性的场所参加

**庭审纪律（第二十五条）**：
- 应当尊重司法礼仪，遵守法庭纪律
- 无正当理由不参加在线庭审视为"拒不到庭"
- 擅自退出经提示警告后仍不改正视为"中途退庭"

**证人在线出庭（第二十六条）**：
- 通过指定在线出庭场所、设置在线作证室等方式保证不旁听、不受干扰
- 当事人有异议且有合理理由，或人民法院认为必要的，应当线下出庭

### （十一）电子送达规则（第二十九条至第三十二条）

**视为同意电子送达的情形**：
1. 受送达人明确表示同意
2. 诉讼前对适用电子送达已作出约定或承诺
3. 在起诉状、上诉状、申请书、答辩状中主动提供电子地址
4. 通过回复收悉、参加诉讼等方式接受已完成电子送达且未明确表示不同意

**送达生效时间**：
- 向受送达人主动提供或确认的电子地址送达的，到达电子地址所在系统时即为送达
- 向能够确认为受送达人本人的电子地址送达的：
  - 回复已收悉或已作出相应诉讼行为的，完成有效送达
  - 系统反馈已阅知或有其他证据证明已收悉的，推定完成有效送达（但能证明系统错误、地址非本人使用或非本人阅知的除外）

### （十二）执行案件在线处理（第三十六条）

- 执行裁决案件的在线立案、电子材料提交、执行和解、询问当事人、电子送达等环节适用本规则
- 可在线完成：财产查明、查封、扣押、冻结、划扣、变价和惩戒等执行实施环节

## 三、《人民法院在线调解规则》核心要点

### （一）调解范围与原则

**可在线调解的纠纷类型（第三条）**：
- 民事、行政、执行案件
- 刑事自诉案件
- 被告人、罪犯未被羁押的刑事附带民事诉讼
- 法律规定可以调解或和解的纠纷

**适用原则（第四条）**：
人民法院采用在线调解方式应当征得当事人同意，并综合考虑案件具体情况、技术条件等因素。

### （二）调解主体（第五条至第六条）

**可开展在线调解的人员**：
- 人民法院审判人员
- 专职或兼职调解员
- 特邀调解组织和特邀调解员
- 人民法院邀请的其他单位或个人

**公布信息**（第五条第二款）：
调解组织、调解员的基本情况、纠纷受理范围、擅长领域、是否收费、邀请法院等信息应当在人民法院调解平台公布。

**涉外调解（第六条）**：
- 符合条件的外国人可入驻平台，参与当事人一方或双方为外国人、无国籍人、外国企业或组织的民商事纠纷
- 符合条件的港澳地区居民可参与当事人一方或双方为港澳居民、法人、非法人组织以及大陆港资澳资企业的民商事纠纷
- 符合条件的台湾地区居民可参与当事人一方或双方为台湾地区居民、法人、非法人组织以及大陆台资企业的民商事纠纷

### （三）调解申请与委派（第八条至第十条）

**当事人申请材料（第八条）**：
- 身份信息
- 纠纷简要情况
- 有效联系电话
- 接收诉讼文书电子送达地址
- 电子化起诉申请材料

**退回申请的处理（第九条）**：
1. 不属于法院受案范围：告知其他纠纷解决方式
2. 法院无管辖权：告知选择有管辖权法院邀请的调解组织或调解员
3. 不适宜在线调解：告知到法院诉讼服务大厅现场办理

**委派指定规则（第十条）**：
- 一方申请：征求对方意见后指定调解组织或调解员
- 双方申请：可在管辖法院确认的调解组织和调解员中共同选择；无法在两个工作日内共同选择的，由法院指定
- 法院应在收到申请后三个工作日内指定

### （四）调解员选定与披露（第十一条至第十四条）

**调解员数量（第十一条）**：
- 一般由一名调解员进行
- 重大、疑难复杂或具有较强专业性的案件，可由两名以上调解员调解
- 当事人共同选定主持人；无法共同选定的，由法院指定

**披露义务（第十三条）**：
主持或参与调解的人员应当披露：
1. 是纠纷当事人或当事人、诉讼代理人近亲属
2. 与纠纷有利害关系
3. 与当事人、诉讼代理人有其他可能影响公正调解关系

当事人明知或披露后仍同意的，由该调解员继续调解。

### （五）调解参与方式（第十六条）

| 情形 | 处理方式 |
|------|----------|
| 各方均具备音视频技术条件 | 指定同一时间登录平台；无法同一时间登录的，分别指定时间 |
| 部分当事人不具备条件 | 在法院诉讼服务中心、调解组织所在地或其他便利地点为其提供场所和设备 |
| 各方均不具备条件或拒绝音视频 | 确定现场调解的时间、地点 |

### （六）调解协议效力（第十八条至第二十条）

**事实认定的特殊保护（第十八条）**：
当事人为达成调解协议作出妥协而认可的事实、证据等，不得在诉讼程序中作为对其不利的依据或证据，但法律另有规定或当事人均同意的除外。

**调解协议生效（第十九条）**：
- 应当在线制作或上传调解协议
- 当事人和调解员在调解协议上进行电子签章
- 调解组织主持达成的，加盖调解组织电子印章
- 各方当事人均完成电子签章之时起发生法律效力
- 有给付内容的，当事人应当主动履行

**调解结案方式（第二十条）**：
| 阶段 | 达成调解协议后的处理 |
|------|---------------------|
| 立案前 | 记入调解笔录，诉外调解结案；可申请司法确认 |
| 立案后 | 可请求法院制作调解书或申请撤诉 |

### （七）调解不成的处理（第二十一条）

| 情形 | 处理方式 |
|------|----------|
| 当事人在立案前申请调解 | 可建议在线立案或其他途径；选择在线立案的，推送电子化调解材料 |
| 立案前委派调解 | 法院应当依法登记立案 |
| 立案后委托调解 | 法院应当恢复审理 |
| 审判人员主持调解 | 及时审判 |

### （八）调解期限（第二十四条）

| 阶段 | 期限 |
|------|------|
| 立案前 | 三十日（各方同意延长的不受此限） |
| 立案后（普通程序） | 十五日 |
| 立案后（简易程序） | 七日 |

立案后延长的调解期限不计入审理期限。

### （九）调解终结情形（第二十五条）

1. 当事人达成调解协议
2. 当事人自行和解，撤回调解申请
3. 在调解期限内无法联系到当事人
4. 当事人一方明确表示不愿意继续调解
5. 当事人分歧较大且难以达成调解协议
6. 调解期限届满，未达成调解协议，且各方未达成延长合意
7. 当事人一方拒绝在调解协议上签章
8. 其他导致调解无法进行的情形

### （十）虚假调解审查（第二十三条）

人民法院在审查司法确认申请或出具调解书过程中，发现当事人可能采取恶意串通、伪造证据、捏造事实、虚构法律关系等手段实施虚假调解行为的：
- 可以要求当事人提供相关证据
- 当事人不提供的，不予确认调解协议效力或出具调解书
- 构成虚假调解的，依照《民事诉讼法》处理
- 涉嫌刑事犯罪的，移送有管辖权的机关

## 四、适用要点汇总表

### （一）在线诉讼与在线调解的关系

| 对比维度 | 在线诉讼 | 在线调解 |
|----------|----------|----------|
| 调整对象 | 立案、审理、执行等诉讼活动 | 立案前及诉讼中的调解活动 |
| 文号 | 法释〔2021〕12号 | 法释〔2021〕23号 |
| 生效日期 | 2021年8月1日 | 2022年1月1日 |
| 适用前提 | 征得当事人同意 | 征得当事人同意 |

### （二）在线诉讼各环节要点

| 环节 | 核心要点 |
|------|----------|
| **立案** | 符合条件登记立案；材料不全一次性告知补正；不得要求已在线提交符合要求的起诉状再提供纸质件 |
| **身份认证** | 先行实名注册；通过证件比对确认身份；取得专用账号；账号行为视为本人行为 |
| **证据交换** | 同步或非同步方式；均可要求原件；区块链存证可认定未经篡改 |
| **庭审** | 不得强制适用；需证人现场作证等情形应线下；证人在线出庭需保证不旁听 |
| **送达** | 到达电子地址系统即为送达；回复收悉或系统反馈已阅知推定送达 |
| **执行** | 可在线完成财产查控、拍卖、信用惩戒等 |

### （三）在线调解各环节要点

| 环节 | 核心要点 |
|------|----------|
| **申请** | 填写身份信息、纠纷简要情况、联系电话、电子送达地址 |
| **委派指定** | 法院收到申请后三个工作日内指定；一方申请需征询对方意愿 |
| **调解员** | 一般一名，复杂案件可多名；需披露利害关系 |
| **调解方式** | 各方均具备条件则视频调解；部分不具备可提供场所；均不具备则现场调解 |
| **协议效力** | 各方电子签章完成时生效；有给付内容应主动履行 |
| **调解期限** | 立案前30日；立案后普通程序15日、简易程序7日 |
| **虚假调解** | 可要求提供证据；不提供不予确认效力；涉嫌犯罪移送 |

### （四）电子数据认定规则对比

| 情形 | 认定规则 |
|------|----------|
| 普通电子数据 | 经举证质证后依法认定真实性、合法性和关联性 |
| 区块链存证电子数据 | 经技术核验一致的，认定上链后未经篡改（有相反证据除外） |
| 对方未提异议的电子化材料 | 可认定符合原件形式要求 |
| 经公证的电子化材料 | 可认定与原件一致 |

### （五）线下转在线的禁止情形

**在线庭审禁止情形**：
1. 各方均不同意（一方不同意且有正当理由）
2. 各方均不具备技术条件
3. 需现场查明身份、核对原件、查验实物
4. 疑难复杂案件在线审理不利于查明事实
5. 涉及国家安全、国家秘密
6. 重大社会影响，受到广泛关注

**可要求转为线下的情形**：
1. 当事人欠缺在线诉讼能力
2. 当事人反悔且不存在故意拖延
3. 一方要求线下并提出具体理由（案件疑难、需证人现场、有必要线下举证质证等）
