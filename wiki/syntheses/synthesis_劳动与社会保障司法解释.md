## 一、劳动争议司法解释（一）

### 1.1 劳动争议范围

**属于劳动争议：**
- 建立劳动关系发生的争议
- 订立、履行、变更、解除、终止劳动合同发生的争议
- 归属、裁减人员发生的争议
- 劳动报酬、福利、培训等发生的争议
- 休息休假、社会保险等发生的争议

**不属于劳动争议：**
- 劳动者请求社会保险经办机构发放社会保险金的
- 劳动者与用人单位因住房制度改革产生的公有住房转让纠纷
- 劳动者对劳动能力鉴定委员会的伤残等级鉴定结论/职业病诊断鉴定委员会的职业病诊断鉴定结论有异议的

### 1.2 管辖

**地域管辖：**
- 被告住所地法院
- 劳动合同履行地法院

**优先管辖：**
- 劳动合同履行地法院优先
- 多个法院都有管辖权的，由最先立案的法院管辖

### 1.3 仲裁前置

**仲裁前置：**
- 劳动争议必须先经劳动仲裁
- 对仲裁裁决不服，方可向法院起诉

**仲裁时效：**
- 一年（劳动关系存续期间因拖欠劳动报酬发生争议除外）
- 仲裁时效期间从当事人知道或应当知道权利被侵害之日起计算

### 1.4 劳动关系认定

**劳动关系特征：**
- 用人单位依法制定的各项劳动规章制度适用于劳动者
- 劳动者受用人单位的劳动管理
- 劳动者从事用人单位安排的有报酬的劳动
- 劳动者提供的劳动是用人单位业务的组成部分

**特殊劳动关系：**
- 用人单位与其招用的已达到法定退休年龄的人员发生用工争议，按劳务关系处理
- 企业停薪留职人员、内退人员、下岗待岗人员、企业经营性停产放长假人员发生用工争议，按劳动关系处理

## 二、劳动争议司法解释（二）

### 2.1 劳动合同效力

**无效情形：**
- 以欺诈、胁迫的手段或乘人之危，使对方在违背真实意思的情况下订立
- 用人单位免除自己的法定责任、排除劳动者权利
- 违反法律、行政法规强制性规定

**无效后果：**
- 合同无效，但劳动者已付出劳动的，用人单位应支付劳动报酬
- 合同无效不影响工资、社保等

### 2.2 二倍工资

**应支付二倍工资情形：**
- 用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同
- 用人单位应当订立无固定期限劳动合同而不订立

**计算方式：**
- 首月后第2个月起算
- 最长计算11个月（未签合同）
- 最长计算12个月（应签无固定期限合同而不签）

### 2.3 经济补偿

**应当支付经济补偿情形：**
- 劳动者因用人单位过错解除劳动合同
- 用人单位依法解除劳动合同
- 劳动合同期满（除用人单位维持或提高条件续订，劳动者不同意）
- 用人单位经济性裁员
- 劳动合同终止（除维持或提高条件续订，劳动者不同意）

**经济补偿计算：**
- 每满一年支付一个月工资
- 六个月以上不满一年按一年计算
- 不满六个月支付半个月工资
- 月工资高于平均工资3倍，按3倍支付，最高不超过12年

### 2.4 违法解除赔偿金

**违法解除情形：**
- 规章制度违法
- 合同无效
- 强制劳动
- 违约解除

**赔偿金计算：**
- 经济补偿的2倍

## 三、工伤保险条例适用

### 3.1 工伤认定范围

**应当认定工伤：**
- 在工作时间和工作场所内，因工作原因受到事故伤害
- 工作时间前后在工作场所内，从事与工作有关的预备性/收尾性工作受到事故伤害
- 在工作时间和工作场所内，因履行工作职责受到暴力等意外伤害
- 患职业病
- 因工外出期间，由于工作原因受到伤害
- 上下班途中，受到非本人主要责任的交通事故

**视同工伤：**
- 在工作时间和工作岗位，突发疾病死亡或在48小时内经抢救无效死亡
- 在抢险救灾等维护国家利益、公共利益活动中受到伤害
- 职工原在军队服役，因战、因公负伤致残，已取得革命伤残军人证，到用人单位后旧伤复发

### 3.2 工伤认定程序

**申请时限：**
- 用人单位：事故伤害发生后30日内
- 劳动者/近亲属：1年内

**工伤认定材料：**
- 工伤认定申请表
- 与用人单位存在劳动关系（包括事实劳动关系）的证明材料
- 医疗诊断证明/职业病诊断证明书

### 3.3 工亡待遇

**工亡补助金：**
- 上一年度全国城镇居民人均可支配收入的20倍

**丧葬补助金：**
- 6个月统筹地区上年度职工月平均工资

**供养亲属抚恤金：**
- 按职工本人工资的一定比例
- 配偶40%，其他亲属30%
- 孤寡老人/孤儿增加10%

## 四、人身损害赔偿司法解释

### 4.1 赔偿范围

**人身损害赔偿项目：**
| 项目 | 计算方式 |
|------|----------|
| 医疗费 | 实际支出 |
| 误工费 | 误工时间 × 日收入 |
| 护理费 | 护理期限 × 护理人员收入 |
| 交通费 | 实际支出 |
| 住院伙食补助费 | 住院天数 × 标准 |
| 营养费 | 伤残情况确定 |
| 残疾赔偿金 | 伤残等级 × 年限 × 标准 |
| 死亡赔偿金 | 标准 × 20年（60岁以上每增一岁减一年） |
| 丧葬费 | 标准 × 6个月 |
| 被扶养人生活费 | 扶养年限 × 标准 ÷ 扶养人数 |

### 4.2 责任划分

**过错责任：**
- 根据行为人的过错程度划分责任
- 被侵权人对损害有过错的，可以减轻侵权人责任

**过失相抵：**
- 损害是因受害人故意造成的，侵权人不承担责任
- 被侵权人对同一损害的发生/扩大有过错的，可以减轻侵权人责任

### 4.3 赔偿计算标准

**城镇居民人均可支配收入：**
- 省级行政区分别统计
- 可支配收入逐年调整

**农村居民人均纯收入：**
- 与城镇居民标准存在差异
- 逐步实现同命同价

**特殊主体：**
- 同一起事故中多人死亡，可按相同数额确定死亡赔偿金

## 五、精神损害赔偿

### 5.1 精神损害赔偿范围

**应当赔偿精神损害：**
- 生命权、身体权、健康权遭受侵害
- 姓名权、肖像权、名誉权、荣誉权、隐私权等人格权遭受侵害
- 人格尊严、人身自由权遭受侵害
- 因侵权导致胎儿健康受损
- 死者的姓名、肖像、名誉、荣誉、隐私等人格利益遭受侵害
- 近亲属遭受精神痛苦

### 5.2 精神损害赔偿标准

**数额确定因素：**
- 侵权人的过错程度（法律另有规定的除外）
- 侵权行为的目的、方式、场合等具体情节
- 侵权行为的后果
- 侵权人的获利情况
- 侵权人承担责任的经济能力
- 受理诉讼法院所在地的平均生活水平

**最高限额：**
- 无固定限额
- 根据上述因素综合确定

## 六、医疗损害责任

### 6.1 医疗损害责任认定

**过错认定：**
- 违反医疗卫生管理法律、行政法规、规章
- 违反诊疗护理规范、常规
- 隐匿或拒绝提供与纠纷有关的病历资料
- 伪造、篡改、销毁病历资料

**推定过错：**
- 医疗机构违反法律、行政法规、规章等有关诊疗义务的规定
- 隐匿或拒绝提供与纠纷有关的病历资料
- 伪造、篡改、销毁病历资料

### 6.2 因果关系认定

**参与度划分：**
- 完全责任：100%
- 主要责任：50%-90%
- 同等责任：50%
- 次要责任：10%-40%
- 轻微责任：10%以下
- 无因果关系：0%

### 6.3 赔偿范围

**医疗费：**
- 诊疗费、医药费、手术费等
- 以实际发生为准

**误工费：**
- 有固定收入：按实际减少计算
- 无固定收入：按最近三年平均收入计算
- 无法证明：按相同/相近行业上一年度职工平均工资计算

**死亡/残疾赔偿金：**
- 同人身损害赔偿标准

## 七、劳动人事争议在线诉调对接

### 7.1 调解机制

**总对总对接：**
- 最高人民法院与人力资源社会保障部建立在线诉调对接机制
- 劳动人事争议案件委托调解

**调解范围：**
- 追索劳动报酬
- 确认劳动关系
- 经济补偿/赔偿金
- 社会保险待遇

### 7.2 调解效力

**调解协议效力：**
- 经法院司法确认的调解协议，具有执行力
- 一方不履行，另一方可申请强制执行

| 情形 | 认定 |
|------|------|

| 工作时间突发疾病48小时内死亡 | 视同工伤 |
| 职业病 | 认定工伤 |
| 因工外出受伤 | 认定工伤 |
| 抢险救灾受伤 | 视同工伤 |
