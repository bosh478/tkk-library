## ❓ 常见问题

> 问：以审判为中心的诉讼制度改革的核心是什么？
> 答：核心是"庭审中心主义"——使庭审成为解决案件问题的主要场所。首要含义是以审判程序为中心，核心含义是以庭审为中心，落脚点是全面贯彻证据裁判规则。

> 问：庭审的基本构成是什么？
> 答：五个阶段——庭前准备、法庭调查、法庭辩论、被告人最后陈述、评议与宣判。

> 问：法官在庭审中的角色定位是什么？
> 答："居于其间、踞于其上"的裁判者，形成等腰正三角结构，体现程序公正的基本要求。

## 章节结构

### 引论：以审判为中心的诉讼制度

**从卷宗主义到庭审中心主义**：
- 传统审判模式：卷宗主义
- "以审判为中心"的诉讼制度改革：
  1. 坚持严格司法原则，树立依法裁判理念
  2. 规范庭前准备程序，确保法庭集中审理
  3. 规范普通审理程序，确保依法公正审判
  4. 完善证据认定规则，切实防范冤假错案
  5. 完善繁简分流机制，优化司法资源配置
- 庭审为中心的科学内涵：
  - 首要含义：以审判程序为中心
  - 核心含义：以庭审为中心
  - 落脚点：全面贯彻证据裁判规则

**专题一：作为剧场的庭审**
- 庭审作为法律物理空间
- 庭审作为追求公平正义的法律舞台
- 庭审的仪式感能激发对法律的信仰

**专题二：庭审过程的动态性**
- 庭审过程的系统性
- 庭审主体之间的互动性
- 庭审信息处理的即时性和语境依赖性

**专题三：庭审活动的基本构成**

| 阶段 | 主要内容 |
|------|----------|
| 庭前准备 | 全面熟悉案情、拟制庭审提纲/预案、开好庭前会议 |

| 最后陈述 | 被告人最后陈述 |

### 第二讲：庭审的功能与价值

**专题一：庭审的功能**
1. 发现事实真相与建构案件事实
2. 发现法律规范与阐明法律原理
3. 增强司法透明度与主动接受监督
4. 解决矛盾纠纷与打造司法公信力
5. 宣传法治和教育民众

**庭审的核心功能**：
- 查明事实
- 认定证据
- 保证诉权
- 公正裁判

**专题二：庭审的价值**
- **客观、公正**：树立科学合理的司法公正观
- **司法效率**：
  - 诉讼经济：以最小成本实现最大正义
  - 诉讼及时：在合理期限内结案

**延伸阅读**：
- 认知视野中的司法公正及其庭审实现
- 量刑纳入庭审范围的程序化改造

### 第三讲：庭审的结构与原则

**专题一：庭审的结构**

**两大法系的不同结构**：
- 对抗式：当事人主义庭审结构
- 审问式：职权主义庭审结构

**庭审的基本构造——"三方组合"式**：
- 控辩审三方构成等腰正三角结构
- 被告人诉讼权利：
  1. 陈述权
  2. 辩论权
  3. 选任辩护人权
  4. 调查证据申请权
  5. 对质权

**法官的诉讼角色**：
- "居于其间、踞于其上"的裁判者
- 形成等腰正三角结构
- 蕴含诉讼程序基本法理
- 体现程序公正基本要求：
  1. 任何人不能作为有关自己案件的法官
  2. 结果中不应包含纠纷解决者个人的利益
  3. 纠纷解决者不应有支持或反对某一方的偏见
  4. 对各方当事人的意见均给予公平的关注
  5. 纠纷解决者应听取双方的辩论和证据
  6. 纠纷解决者只应在另一方当事人在场的情况下听取对方的意见
  7. 解决的诸项内容应以理性推演为依据
  8. 分析推理应建立于当事人作出的辩论和提出的证据之上

**专题二：庭审的原则**

**支撑"等腰三角形"构造的基本原则**：
1. **依法独立行使审判权**
2. **法官中立**：
   - 法官同争议的事实和利益没有关联性
   - 法官不得对任何一方当事人存有歧视或偏私
3. **诉辩平等**：诉讼手段对等
4. **兼听则明**
5. **善于决断**
6. **安全有序**

**延伸阅读**：
- 司法方法论视野下的裁判逻辑与庭审经验
- 司法裁判中的情感因素及其庭审调控

### 第四讲：庭审的准备与预案

**专题一：全面熟悉案情**

**庭前阅卷形成"阅卷看法"**：
- 掌握案件证据材料的物理状况
- 掌握定案的证据状况
- 掌握量刑情节的证据状况

**审查被告人羁押情况**：
- 有无羁押
- 羁押何处
- 羁押时间长短

**了解当事人反应**：
- 被害人及其亲属的反应
- 被告人及其亲属的反应
- 预测旁听情况

**专题二：拟制庭审提纲**

**庭审提纲内容**：
1. 明确案件审理总体范围和庭审分工
2. 明确法庭调查重点和步骤
3. 预测庭审中可能出现的问题及应对措施
4. 拟出认证及庭审小结预案
5. 明确需要注意的其他问题

**参考范例——刑事一审庭审提纲**：
- 开庭前的准备
- 法庭调查前的准备
- 法庭调查（定罪事实+量刑事实）
- 法庭辩论（定罪辩论+量刑辩论）
- 被告人最后陈述
- 休庭评议
- 宣判程序

**专题三：庭审的基本要求——法官行为规范**
1. **耐心听讼**
2. **指挥得当**：有效控制庭审节奏
3. **重点突出**
4. **善于决断**：冷静果断应对突发事件
5. **安全有序**

## 核心内容

### 一、庭审中心主义的核心要义

**从卷宗主义到庭审中心主义的转变**：
- 传统模式：以案卷笔录为中心，庭审流于形式
- 改革方向：以庭审为中心，使庭审成为解决案件问题的主要场所

**三个层次**：
1. 以审判程序为中心（审前程序服务于审判程序）
2. 以庭审为中心（庭审是审判的核心）
3. 全面贯彻证据裁判规则（证据必须经过庭审质证）

### 二、庭审的"等腰三角形"结构

```
        法官（裁判者）
       /      \
      /        \
   控方 -------- 辩方
```

**结构要求**：
- 法官居于中间位置，保持中立
- 控辩双方地位平等，手段对等
- 法官"踞于其上"，掌控庭审进程

**程序公正的八项标准**（自然正义）：
1. 任何人不能作为自己案件的法官
2. 结果中不应包含裁判者个人利益
3. 不应有支持或反对某方的偏见
4. 对各方意见给予公平关注
5. 应听取双方辩论和证据
6. 在另一方在场时听取对方意见
7. 以理性推演为依据
8. 建立于当事人辩论和证据之上

### 三、庭前准备的核心要素

**阅卷形成"阅卷看法"**：
- 证据材料物理状况（数量、装订、完整性）
- 定案证据状况（直接证据、间接证据的印证关系）
- 量刑情节证据状况（法定、酌定情节）

**拟制庭审提纲**：
- 总体范围与分工
- 调查重点与步骤
- 问题预测与应对
- 认证预案

### 四、法官庭审行为规范

| 规范 | 要求 |
|------|------|
| 耐心听讼 | 认真听取各方陈述，不随意打断 |
| 指挥得当 | 有效控制庭审节奏，引导程序进行 |
| 重点突出 | 抓住争议焦点，集中审理核心问题 |
| 善于决断 | 冷静果断应对，有效处置突发事件 |
| 安全有序 | 确保庭审安全，维护法庭秩序 |

### 五、证据裁判规则的贯彻

**直接言词原则**：
- 证人应当庭作证
- 证据应当庭质证
- 法官应当庭听取各方意见

**证据审查方法**：
- 单个证据审查：三性（真实性、合法性、关联性）
- 证据综合审查：印证关系、证明力判断
- 疑点排除：发现矛盾、查明原因
