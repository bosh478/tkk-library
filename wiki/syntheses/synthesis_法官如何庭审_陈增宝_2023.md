## ❓ 常见问题

> 问：以审判为中心的诉讼制度改革的核心是什么？
> 答：核心是"庭审中心主义"——使庭审成为解决案件问题的主要场所。首要含义是以审判程序为中心，核心含义是以庭审为中心，落脚点是全面贯彻证据裁判规则。

> 问：庭审的基本构成是什么？
> 答：五个阶段——庭前准备、法庭调查、法庭辩论、被告人最后陈述、评议与宣判。

> 问：法官在庭审中的角色定位是什么？
> 答："居于其间、踞于其上"的裁判者，形成等腰正三角结构，体现程序公正的基本要求。

## 章节结构

### 引论：以审判为中心的诉讼制度

**从卷宗主义到庭审中心主义**：
- 传统审判模式：卷宗主义
- "以审判为中心"的诉讼制度改革：
  1. 坚持严格司法原则，树立依法裁判理念
  2. 规范庭前准备程序，确保法庭集中审理
  3. 规范普通审理程序，确保依法公正审判
  4. 完善证据认定规则，切实防范冤假错案
  5. 完善繁简分流机制，优化司法资源配置
- 庭审为中心的科学内涵：
  - 首要含义：以审判程序为中心
  - 核心含义：以庭审为中心
  - 落脚点：全面贯彻证据裁判规则

### 第三讲：庭审的结构与原则

**专题一：庭审的结构**

**两大法系的不同结构**：
- 对抗式：当事人主义庭审结构
- 审问式：职权主义庭审结构

**庭审的基本构造——"三方组合"式**：
- 控辩审三方构成等腰正三角结构
- 被告人诉讼权利：
  1. 陈述权
  2. 辩论权
  3. 选任辩护人权
  4. 调查证据申请权
  5. 对质权

**法官的诉讼角色**：
- "居于其间、踞于其上"的裁判者
- 形成等腰正三角结构
- 蕴含诉讼程序基本法理
- 体现程序公正基本要求：
  1. 任何人不能作为有关自己案件的法官
  2. 结果中不应包含纠纷解决者个人的利益
  3. 纠纷解决者不应有支持或反对某一方的偏见
  4. 对各方当事人的意见均给予公平的关注
  5. 纠纷解决者应听取双方的辩论和证据
  6. 纠纷解决者只应在另一方当事人在场的情况下听取对方的意见
  7. 解决的诸项内容应以理性推演为依据
  8. 分析推理应建立于当事人作出的辩论和提出的证据之上

**专题二：庭审的原则**

**支撑"等腰三角形"构造的基本原则**：
1. **依法独立行使审判权**
2. **法官中立**：
   - 法官同争议的事实和利益没有关联性
   - 法官不得对任何一方当事人存有歧视或偏私
3. **诉辩平等**：诉讼手段对等
4. **兼听则明**
5. **善于决断**
6. **安全有序**

**延伸阅读**：
- 司法方法论视野下的裁判逻辑与庭审经验
- 司法裁判中的情感因素及其庭审调控

## 核心内容

### 一、庭审中心主义的核心要义

**从卷宗主义到庭审中心主义的转变**：
- 传统模式：以案卷笔录为中心，庭审流于形式
- 改革方向：以庭审为中心，使庭审成为解决案件问题的主要场所

**三个层次**：
1. 以审判程序为中心（审前程序服务于审判程序）
2. 以庭审为中心（庭审是审判的核心）
3. 全面贯彻证据裁判规则（证据必须经过庭审质证）

### 二、庭审的"等腰三角形"结构

```
        法官（裁判者）
       /      \
      /        \
   控方 -------- 辩方
```

**结构要求**：
- 法官居于中间位置，保持中立
- 控辩双方地位平等，手段对等
- 法官"踞于其上"，掌控庭审进程

**程序公正的八项标准**（自然正义）：
1. 任何人不能作为自己案件的法官
2. 结果中不应包含裁判者个人利益
3. 不应有支持或反对某方的偏见
4. 对各方意见给予公平关注
5. 应听取双方辩论和证据
6. 在另一方在场时听取对方意见
7. 以理性推演为依据
8. 建立于当事人辩论和证据之上

### 三、庭前准备的核心要素

**阅卷形成"阅卷看法"**：
- 证据材料物理状况（数量、装订、完整性）
- 定案证据状况（直接证据、间接证据的印证关系）
- 量刑情节证据状况（法定、酌定情节）

**拟制庭审提纲**：
- 总体范围与分工
- 调查重点与步骤
- 问题预测与应对
- 认证预案

### 四、法官庭审行为规范

| 规范 | 要求 |
|------|------|
| 耐心听讼 | 认真听取各方陈述，不随意打断 |
| 指挥得当 | 有效控制庭审节奏，引导程序进行 |
| 重点突出 | 抓住争议焦点，集中审理核心问题 |
| 善于决断 | 冷静果断应对，有效处置突发事件 |
| 安全有序 | 确保庭审安全，维护法庭秩序 |

### 五、证据裁判规则的贯彻

**直接言词原则**：
- 证人应当庭作证
- 证据应当庭质证
- 法官应当庭听取各方意见

**证据审查方法**：
- 单个证据审查：三性（真实性、合法性、关联性）
- 证据综合审查：印证关系、证明力判断
- 疑点排除：发现矛盾、查明原因

## 实务问答(L4 必填·12 条·4 段式)

> 4 段式:问题 / 答复 / 类案指引 / 法律依据

### Q1. 以审判为中心的诉讼制度改革的核心要义是什么？

**答复**:核心是「庭审中心主义」,即让庭审成为解决案件问题的主要场所。三个层次:①首要含义是以审判程序为中心;②核心含义是以庭审为中心;③落脚点是全面贯彻证据裁判规则。

**类案指引**:最高人民法院指导案例强调,刑事庭审必须贯彻直接言词、证据裁判、疑罪从无、程序公正四大原则,发挥庭审在查明事实、认定证据中的决定性作用。

**法律依据**:①党的十八届四中全会《决定》②法发〔2016〕18号《关于推进以审判为中心的刑事诉讼制度改革的意见》③《刑事诉讼法》第50条、第五十五条

### Q2. 何为「卷宗主义」?其与「庭审中心主义」的根本区别是什么?

**答复**:卷宗主义也称案卷中心主义,属于传统审判模式,特点是通过宣读案卷笔录主导法庭调查,证人、鉴定人、侦查人员不出庭成为常态。庭审中心主义则要求直接言辞审理,证人出庭、证据当庭质证、法官当庭形成心证。

**类案指引**:念斌案、张氏叔侄案等冤错案件均暴露卷宗主义弊端,推动改革必须实现「诉讼证据出示在法庭、案件事实查明在法庭、诉辩意见发表在法庭、裁判结果形成在法庭」。

**法律依据**:①法发〔2016〕18号②《刑事诉讼法》第192条(直接言词原则)

### Q3. 庭审结构中的「等腰正三角」是什么含义?

**答复**:指控辩审三方的诉讼结构。法官居于三角形的顶点(裁判者位置),控辩双方位于底边两端,等距分布。这一结构蕴含程序公正基本法理:法官中立、控辩平等、审判独立。

**类案指引**:在辛普森案等对抗制审判中,法官严格保持中立,控辩双方交叉询问,庭审结构即等腰正三角。

**法律依据**:①《刑事诉讼法》第14条(法院独立审判)②《法官法》第三条(法官依法独立审判)

### Q4. 程序公正的八项标准是什么?

**答复**:①任何人不能作为自己案件的法官;②结果中不应包含纠纷解决者个人利益;③纠纷解决者不应有支持或反对某一方的偏见;④对各方意见均给予公平关注;⑤应听取双方的辩论和证据;⑥只应在另一方在场时听取对方意见;⑦解决内容应以理性推演为依据;⑧分析推理应建立于当事人作出的辩论和证据之上。

**类案指引**:自然正义原则起源于英国1215年《大宪章》,是英美法系程序公正的核心,亦被我国《刑事诉讼法》吸收。

**法律依据**:①《刑事诉讼法》第14条②自然正义(Natural Justice)原则

### Q5. 庭审的五个基本阶段是什么?

**答复**:①庭前准备(阅卷、提纲、庭前会议);②法庭调查(举证、质证、证据核实);③法庭辩论(控辩双方就定罪量刑发表意见);④被告人最后陈述;⑤评议与宣判(合议庭评议、宣告判决)。

**类案指引**:陈增宝法官强调,五个阶段不能颠倒,法庭调查是核心决定性环节,法庭辩论是关键展开环节,最后陈述是被告人不可剥夺的权利。

**法律依据**:①《刑事诉讼法》第186-204条

### Q6. 何为「庭审驾驭的四种方式」?

**答复**:①指挥(推动+调度+控制+创设条件+保障庭审);②引导(耐心倾听+察言观色+争点归纳+疑点指示);③干预(重在预防+及时劝阻+有效处置);④决断(程序性决断+实体性决断)。

**类案指引**:在重大敏感案件中,法官需综合运用四种方式。预防性干预优于事后处置,程序性决断应先于实体性决断。

**法律依据**:①《刑事诉讼法》第189条(法庭调查指挥权)

### Q7. 阅卷应当形成怎样的「阅卷看法」?

**答复**:三层面——①掌握案件证据材料的物理状况(数量、装订、完整性);②掌握定案证据的证据状况(直接证据、间接证据的印证关系);③掌握量刑情节的证据状况(法定、酌定情节)。

**类案指引**:最高人民法院强调,阅卷是庭审准备的核心环节,阅卷看法决定庭审提纲质量。

**法律依据**:①《最高人民法院关于全面深化人民法院改革的意见》

### Q8. 庭审提纲应包含哪些要素?

**答复**:五要素:①明确案件审理的总体范围和庭审分工;②明确法庭调查的重点和步骤以及庭审的基本流程;③预测庭审中可能出现的问题及拟采取的应对措施;④拟出认证及庭审小结的预案;⑤明确庭审中需要注意的其他问题。

**类案指引**:陈增宝法官提供的「刑事一审庭审提纲」参考范本被广泛采用,涵盖开庭前、法庭调查、法庭辩论、最后陈述、休庭评议、宣判程序六大环节。

**法律依据**:①《最高人民法院关于适用<中华人民共和国刑事诉讼法>的解释》第307条

### Q9. 法官庭审行为规范五项是什么?

**答复**:①耐心听讼(认真听取各方陈述,不随意打断);②指挥得当(有效控制庭审节奏,引导程序进行);③重点突出(抓住争议焦点,集中审理核心问题);④善于决断(冷静果断应对,有效处置突发事件);⑤安全有序(确保庭审安全,维护法庭秩序)。

**类案指引**:陈增宝法官强调,法官的「负面表现」包括喋喋不休、不耐烦、急于查清事实、缺少知识、缺乏智慧、与当事人辩论,均应避免。

**法律依据**:①《法官行为规范》②《人民法院法庭规则》

### Q10. 如何处理被告人翻供?

**答复**:①仔细审查翻供理由(是否合理、是否有新证据支持);②通知证人/鉴定人出庭质证;③对翻供前的供述进行合法性审查(是否系刑讯逼供);④综合全案证据判断翻供是否成立;⑤必要时宣布休庭核实。

**类案指引**:念斌案、呼格吉勒图案等案件均涉及翻供处理,法院最终以全案证据综合判断。

**法律依据**:①《刑事诉讼法》第56条(非法证据排除)②《最高人民法院关于适用<刑事诉讼法>的解释》

### Q11. 法庭辩论偏离焦点时如何处理?

**答复**:①及时提醒双方围绕焦点辩论;②归纳争议焦点(对争议焦点列表确认);③必要时限制辩论时间;④宣告恢复法庭调查(对辩论中提出的新证据);⑤休庭合议。

**类案指引**:陈增宝法官强调,「归纳争议焦点」是法官庭审驾驭的核心能力,直接影响庭审效率与公正。

**法律依据**:①《刑事诉讼法》第198条②《最高人民法院关于适用<刑事诉讼法>的解释》

### Q12. 庭审突发事件的处置原则是什么?

**答复**:①依法处置(依照《法庭规则》《刑事诉讼法》);②安全第一(确保法庭秩序与人员安全);③及时果断(防止事态扩大);④分别情形处理(被告人情绪失控、旁听人员扰乱、自伤自残等分别处理);⑤记录在案(详细记录事件过程与处置)。

**类案指引**:陈增宝法官提出「处置预案」应在庭前准备阶段制定,包括回避、证人出庭、辩护委托、问答、检举揭发等。

**法律依据**:①《人民法院法庭规则》第9-20条②《刑事诉讼法》第194条
