## 一、刑事申诉案件规定

**来源**：《人民检察院办理刑事申诉案件规定》（高检发办字〔2020〕55号，2020年9月22日施行）

### 1. 基本原则

| 原则 | 内容 |
|------|------|
| 原案办理与申诉办理相分离 | 申诉审查与原案办理由不同部门负责 |
| 全案复查，公开公正 | 全面审查事实、证据、法律适用 |
| 实事求是，依法纠错 | 有错必纠，维护正确决定 |
| 释法说理，化解矛盾 | 做好息诉息访工作 |

### 2. 管辖规则

**申诉类型与管辖对应**：

| 申诉类型 | 管辖检察院 |
|----------|------------|
| 不服检察院诉讼终结的刑事处理决定 | 作出决定的检察院 |
| 不服法院生效刑事判决、裁定 | 作出生效裁判法院的同级检察院 |
| 不服上一级检察院审查/复查结论 | 上一级检察院 |

### 3. 受理条件

申诉符合下列条件的应当受理：
- 属于刑事申诉范围（不服检察院诉讼终结的处理决定，或不服法院生效裁判）
- 符合管辖规定
- 申诉人是原案当事人及其法定代理人、近亲属
- 申诉材料符合要求

### 4. 审查与复查程序

**审查结案情形**（第18条）：
- 原判决、裁定或处理决定认定事实清楚、证据确实充分、处理适当的
- 原案有瑕疵但不足以影响结论的
- 其他经审查认为正确的

**移送刑事检察部门情形**（第19条）：
- 原判决、裁定或处理决定存在错误可能的
- 不服检察院诉讼终结的处理决定首次提出申诉的
- 被害人等不服不起诉决定七日内提出申诉的

**复查终结处理**（第43条）：

| 情形 | 处理方式 |
|------|----------|
| 原处理决定正确 | 予以维持 |
| 原处理决定正确，但部分事实或适用法律错误 | 纠正错误部分，维持原决定 |
| 原处理决定错误 | 予以撤销；需要重新进入诉讼程序的，移送有管辖权的检察院或本院有关部门办理 |

### 5. 办案期限

| 阶段 | 期限 |
|------|------|
| 控告申诉检察部门审查 | 受理之日起3个月以内 |
| 刑事检察部门复查 | 收到案件之日起3个月以内 |
| 重大疑难复杂案件 | 可延长3个月 |
| 调卷期间 | 不计入办案期限 |

### 6. 抗诉条件（第45条）

对法院生效裁判提出抗诉的情形：

- 原判决、裁定认定事实、适用法律确有错误致裁判不公
- 认定罪名错误且明显影响量刑
- 量刑明显不当
- 证据不确实、不充分或主要证据之间存在矛盾
- 有新的证据证明原判决、裁定认定事实确有错误
- 违反法律关于追诉时效的规定
- 违反法律规定的诉讼程序，可能影响公正审判
- 审判人员有贪污受贿、徇私舞弊、枉法裁判行为

## 二、网络犯罪案件规定

**来源**：《人民检察院办理网络犯罪案件规定》（2021年1月22日施行）

### 1. 网络犯罪范围（第2条）

- 针对信息网络实施的犯罪
- 利用信息网络实施的犯罪
- 其他上下游关联犯罪

### 2. 办案机制特点

| 特点 | 内容 |
|------|------|
| 全链条惩治 | 注重审查和发现上下游关联犯罪线索 |
| 捕诉监防一体 | 惩治犯罪与预防犯罪并举 |
| 检察一体化 | 加强跨区域协作办案 |

### 3. 电子数据审查要点

**电子数据形式**（第27条）：
- 网页、社交平台、论坛等网络平台发布的信息
- 手机短信、电子邮件、即时通信、通讯群组等网络通讯信息
- 用户注册信息、身份认证信息、数字签名、生物识别信息等用户身份信息
- 电子交易记录、通信记录、浏览记录、操作记录等用户行为信息
- 恶意程序、工具软件、网站源代码、运行脚本等行为工具信息
- 系统日志、应用程序日志、安全日志等系统运行信息
- 文档、图片、音频、视频、数字证书、数据库文件等电子文件

**审查三性要求**（第29条）：

| 审查内容 | 关键点 |
|----------|--------|
| 客观性 | 原始存储介质移送情况、数字签名/证书、提取过程可重现性、完整性校验 |
| 合法性 | 取证方法和过程规范、法律手续齐全、取证记录完备、见证人签名 |
| 关联性 | 电子数据与案件事实的关联、与案件当事人的关联 |

### 4. 引导取证重点（第12条）

检察院介入重大疑难复杂网络犯罪案件侦查，引导取证意见包括：
- 案件侦查方向及可能适用的罪名
- 证据的收集、提取、保全、固定、检验、分析
- 关联犯罪线索
- 追赃挽损工作

### 5. 主体身份同一性认定（第17条）

结合全案证据，围绕犯罪嫌疑人与原始存储介质、电子数据的关联性审查：
- 原始存储介质是否为犯罪嫌疑人所有、持有或使用
- 社交、支付结算、网络游戏、电子商务、物流等平台的账户信息是否与犯罪嫌疑人身份关联
- 通话记录、短信、聊天信息等是否能够反映犯罪嫌疑人身份
- 域名、IP地址、终端MAC地址等是否反映电子设备为犯罪嫌疑人所使用

### 6. 主观方面认定（第19条）

结合认知能力、专业水平、既往经历、人员关系、行为次数、获利情况等综合认定：
- 反映主观故意的聊天记录、发布内容、浏览记录
- 行为是否明显违背系统提示要求、正常操作流程
- 制作、使用的软件程序是否主要用于违法犯罪活动
- 支付结算对象、频次、数额是否明显违反正常交易习惯
- 是否频繁采用隐蔽上网、加密通信、销毁数据等措施或使用虚假身份

### 7. 自行侦查情形（第24条）

- 公安机关未能收集的证据，特别是存在灭失、增加、删除、修改风险的电子数据
- 经退回补充侦查未达到补充侦查要求的
- 其他需要自行侦查的情形

## 三、认罪认罚案件听取意见同录规定

**来源**：《人民检察院办理认罪认罚案件听取意见同步录音录像规定》（2021年12月2日发布，2022年3月1日实施）

### 1. 适用范围（第2-3条）

检察官围绕量刑建议、程序适用等事项听取意见、签署具结书活动，均应同步录音录像。适用于所有认罪认罚案件。

### 2. 录制内容（第4条）

同步录音录像一般包含：

| 环节 | 内容 |
|------|------|
| 告知环节 | 告知对听取意见过程进行同步录音录像的情况 |
| 权利告知 | 告知诉讼权利义务和认罪认罚法律规定，释明法律性质和法律后果 |
| 后果告知 | 告知无正当理由反悔的法律后果 |
| 建议说明 | 告知认定的犯罪事实、罪名、处理意见，释明量刑建议、程序适用建议 |
| 听取意见 | 检察官听取意见，犯罪嫌疑人、被告人听取辩护人意见 |
| 开示证据 | 根据需要开示证据 |
| 签署具结 | 犯罪嫌疑人、被告人签署具结书及辩护人/值班律师见证 |

### 3. 录制要求（第6-10条）

| 要求 | 内容 |
|------|------|
| 录制场所 | 羁押场所或检察机关办案区，有条件的可设置单独听取意见室 |
| 录制人员 | 检察技术人员或其他检察辅助人员 |
| 画面要求 | 客观、全面，画面完整、端正，声音和影像清晰可辨 |
| 完整性 | 保持完整、连续，不得选择性录制，不得篡改、删改 |
| 起止 | 由检察官宣布起始和结束，开始录像前告知参与人员 |

### 4. 中止与补录（第10条）

| 情形 | 处理方式 |
|------|----------|
| 发现可能影响定罪量刑的新情况 | 中止听取意见和同录，核实完毕后视情决定重新或继续 |
| 技术故障无法录制 | 中止听取意见，待故障排除后再行录制 |
| 技术故障一时难以排除 | 征得犯罪嫌疑人、辩护人/值班律师同意，可继续听取意见并记录在案 |

### 5. 保存与调取（第11-12条）

- **保存期限**：十年
- **调取条件**：人民法院、犯罪嫌疑人、辩护人/值班律师对认罪认罚自愿性、真实性、合法性提出异议或疑问
- **审批调取**：案件质量评查、复查、检务督察等需查阅、调取、复制、出示的，应履行审批手续

## 四、羁押必要性审查、评估工作规定

**来源**：《人民检察院 公安机关羁押必要性审查、评估工作规定》（2023年11月30日施行）

### 1. 职责分工

| 机关 | 职责 |
|------|------|
| 检察院捕诉部门 | 负责羁押必要性审查 |
| 公安机关办案部门 | 负责羁押必要性评估，法制部门统一审核 |
| 看守所 | 发现在押人员不适宜继续羁押的，及时提请办案机关变更 |

### 2. 启动方式

| 方式 | 说明 |
|------|------|
| 检察院依职权主动审查 | 刑事诉讼过程中可对被逮捕的犯罪嫌疑人、被告人主动进行 |
| 检察院依职权审查（审查起诉阶段） | 对可能判处三年有期徒刑以下刑罚的在押嫌疑人，提起公诉前应依职权开展一次审查 |
| 申请人申请 | 犯罪嫌疑人、被告人及其法定代理人、近亲属、辩护人、值班律师可申请 |
| 看守所建议 | 看守所以书面形式提出，并附证明在押人员身体状况的证据材料 |

### 3. 应当立即审查/评估的情形（第7条）

- 患有严重疾病、生活不能自理等原因不适宜继续羁押
- 怀孕或者正在哺乳自己婴儿的妇女
- 系未成年人的唯一抚养人
- 系生活不能自理的人的唯一扶养人
- 继续羁押将超过依法可能判处的刑期
- 案件事实、情节或法律、司法解释发生变化，可能导致被判拘役、管制、免予刑事处罚或判决无罪
- 案件证据发生重大变化，可能导致没有证据证明有犯罪事实
- 存在其他羁押强制措施不当情形

### 4. 审查/评估内容（第12条）

| 因素类别 | 具体内容 |
|----------|----------|
| 基本情况 | 涉嫌罪名、犯罪性质、情节，可能判处的刑罚 |
| 案件进展 | 诉讼阶段，侦查取证进展，犯罪事实是否基本查清，证据是否收集固定，认罪情况，供述是否稳定 |
| 主观恶性 | 是否有前科劣迹、累犯等从严情节；到案方式，是否被通缉或因违反取保候审、监视居住规定被逮捕 |
| 共犯情况 | 是否有不在案的共犯，是否存在串供可能 |
| 从宽情节 | 认罪认罚、自首、坦白、立功、积极退赃、获得谅解、达成和解协议、积极赔偿或提供担保 |
| 身体状况 | 健康状况 |
| 羁押表现 | 在押期间的表现情况 |
| 替代措施 | 是否具备取保候审、监视居住条件 |
| 羁押期限 | 是否即将超过依法可能判处的刑期 |
| 处理可能 | 是否存在撤销案件、不起诉、缓刑、免予刑事处罚、判决无罪的可能 |

### 5. 应当建议释放或变更的情形（第16条）

- 案件证据发生重大变化，没有证据证明有犯罪事实或者犯罪行为系犯罪嫌疑人、被告人所为
- 案件事实、情节或法律、司法解释发生变化，可能被判拘役、管制、独立适用附加刑、免予刑事处罚或判决无罪
- 继续羁押将超过依法可能判处的刑期
- 案件事实基本查清，证据已收集固定，符合取保候审或监视居住条件
- 其他羁押强制措施不当

### 6. 可以释放或变更的情形（第17条）

| 情形 | 说明 |
|------|------|
| 预备犯、中止犯 | |
| 主观恶性较小的初犯 | |
| 共同犯罪中的从犯或胁从犯 | |
| 过失犯罪 | |
| 防卫过当或避险过当 | |
| 认罪认罚 | |
| 与被害方达成和解协议或获得谅解 | |
| 已部分履行赔偿义务或提供担保 | |
| 患有严重疾病、生活不能自理 | |
| 怀孕或正在哺乳自己婴儿的妇女 | |
| 未成年人或已满75周岁的人 | |
| 未成年人的唯一抚养人 | |
| 生活不能自理的人的唯一扶养人 | |
| 可能被判一年以下有期徒刑 | |
| 可能宣告缓刑 | |

### 7. 一般不予释放或变更的情形（第18条）

| 情形 | 说明 |
|------|------|
| 危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织犯罪、重大毒品犯罪 | |
| 故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、绑架、放火、爆炸、投放危险物质 | 严重暴力犯罪 |
| 性侵未成年人犯罪 | |
| 重大贪污、贿赂犯罪，或利用职权实施的严重侵犯公民人身权利的犯罪 | |
| 可能判处十年有期徒刑以上刑罚 | |
| 因违反取保候审、监视居住规定而被逮捕 | |
| 可能毁灭、伪造证据，干扰证人作证或串供 | |
| 可能对被害人、举报人、控告人实施打击报复 | |
| 企图自杀或者逃跑 | |

**但书**：有上述情形之一，但因患有严重疾病或其他不适宜继续羁押的特殊情形，不予羁押不致发生社会危险性的，可以依法变更强制措施为监视居住、取保候审。

### 8. 办案期限（第19条）

| 阶段 | 期限 |
|------|------|
| 侦查、审判阶段收到申请 | 10日以内决定 |
| 审查起诉阶段、公安机关侦查阶段收到申请 | 3日以内作出决定 |

**不计入期限的情形**：病情鉴定等专业知识委托鉴定、专门性问题出具报告、技术性证据审查、组织听证审查。

### 9. 跟踪监督（第22、24条）

- 检察院发出建议书后，应当跟踪公安机关、人民法院处理情况
- 公安机关、人民法院应在收到建议书10日以内将处理情况通知检察院
- 变更强制措施后，公安机关应加强对取保候审、监视居住人的监督管理
- 发现严重违反取保候审、监视居住规定需要予以逮捕的，依法重新提请批准逮捕

## 五、适用要点汇总表

### 1. 各规定核心要点对比

| 规定 | 发布/施行日期 | 文号 | 核心要点 |
|------|---------------|------|----------|
| 刑事申诉案件规定 | 2020.09.22 | 高检发办字〔2020〕55号 | 原案办理与申诉办理分离；全案复查；三级审查（控申审查→刑检移送→复查）；抗诉/再审检察建议 |
| 网络犯罪案件规定 | 2021.01.22 | — | 全链条惩治；电子数据审查三性（客观性、合法性、关联性）；跨区域协作；检察技术人员参与办案 |
| 认罪认罚同录规定 | 2022.03.01 | — | 适用于所有认罪认罚案件；听取意见全程录制；保存期限10年；保障辩护权 |
| 羁押必要性审查规定 | 2023.11.30 | — | 捕诉部门审查；公安机关评估；七类应当立即审查情形；三类不予变更情形 |

### 2. 办案期限汇总

| 程序 | 期限 | 不计入情形 |
|------|------|------------|
| 刑事申诉控申审查 | 3个月 | 调卷期间 |
| 刑事申诉复查 | 3个月，可延长3个月 | — |
| 羁押必要性审查（侦查/审判阶段） | 10日 | 鉴定、技术性审查、听证 |
| 羁押必要性审查（审查起诉/公安侦查阶段） | 3日 | 鉴定、技术性审查、听证 |
| 抗诉审查（上级检察院） | 3个月 | — |
