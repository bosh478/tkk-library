## 一、刑事申诉案件异地审查规定

### 1.1 异地审查情形

**可以异地审查的情形**：
- 原处理决定可能存在错误
- 原办案单位可能存在不当利益
- 当地社会反映强烈
- 其他需要异地审查的情形

### 1.2 异地审查程序

| 阶段 | 内容 |
|------|------|
| 申请 | 申诉人提出异地审查申请 |
| 审批 | 省级以上人民检察院审批 |
| 交办 | 交由异地人民检察院审查 |
| 审查 | 异地检察院进行审查 |
| 结论 | 提出审查意见 |

### 1.3 异地审查要求

- 客观公正
- 依法独立进行
- 保障申诉人权利

## 二、办理刑事申诉案件规定

### 2.1 申诉范围

刑事申诉包括：
- 被害人及其法定代理人、近亲属对人民检察院不起诉决定不服
- 当事人对人民法院生效判决、裁定不服
- 其他依法可以申诉的情形

### 2.2 申诉材料

申诉人提出申诉，应当提交以下材料：
- 申诉书
- 身份证明
- 原处理决定、判决、裁定
- 相关证据材料

### 2.3 审查程序

| 阶段 | 内容 |
|------|------|
| 受理 | 审查申诉材料是否齐全 |
| 审查 | 审查原处理决定、判决、裁定是否正确 |
| 复查 | 必要时进行复查 |
| 决定 | 作出维持、撤销或变更决定 |

### 2.4 复查程序

**复查内容**：
- 原认定事实是否清楚
- 原适用法律是否正确
- 办案程序是否合法
- 处理是否适当

**复查方式**：
- 调阅原案卷宗
- 询问相关人员
- 调查核实证据

### 2.5 决定与送达

复查结束后：
- 制作复查决定书
- 送达申诉人
- 送达原作出决定的机关

## 三、办案活动接受人民监督员监督的规定

### 3.1 监督范围

**应当接受人民监督员监督的事项**：
- 拟不起诉案件
- 拟不批准逮捕案件
- 重大复杂敏感案件
- 检察建议
- 巡回检察
- 其他需要监督的办案活动

### 3.2 监督方式

| 方式 | 内容 |
|------|------|
| 案件评查 | 对案件办理质量进行评查 |
| 公开听证 | 公开听证，听取意见 |
| 跟踪回访 | 对案件处理结果进行跟踪回访 |
| 参与讨论 | 参与案件讨论 |

### 3.3 人民监督员职责

- 依法、独立进行监督
- 提出监督意见
- 保守秘密
- 遵守回避规定

### 3.4 监督意见处理

- 人民检察院应当认真研究人民监督员的监督意见
- 采纳监督意见应当说明理由
- 不采纳监督意见应当向人民监督员作出解释说明

## 四、适用要点汇总表

| 要点 | 内容 |
|------|------|
| 刑事申诉异地审查 | 省级以上院审批，交由异地院审查 |
| 申诉材料 | 申诉书、身份证明、原处理决定、证据 |
| 复查内容 | 事实认定、法律适用、程序合法性、处理适当性 |
| 人民监督员监督 | 不起诉、不批捕、重大复杂敏感案件 |
