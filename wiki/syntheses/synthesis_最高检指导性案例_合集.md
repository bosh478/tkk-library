# 最高人民检察院指导性案例合集

本文档收录最高人民检察院第一批至第六十二批指导性案例（检例第1号至第192号），按批次分类整理案例标题与核心裁判要旨。

## 适用要点汇总表

| 类别 | 适用要点 |
|------|----------|
| **正当防卫** | 防卫行为未明显超过必要限度不属于防卫过当；行凶等严重暴力犯罪可特殊防卫 |
| **核准追诉** | 严重危害社会治安经20年追诉期限社会影响未消失的应追诉；获得被害人谅解可不追诉 |
| **公益诉讼** | 诉前程序是前置程序；违法行为是否停止是判断履职到位的标准 |
| **虚假诉讼** | 恶意串通虚构债务骗取法律文书构成虚假诉讼；检察院应依法监督 |
| **未成年人保护** | 性侵未成年人案件证据审查按不同于成年人标准；无法告诉的由公诉 |
| **金融犯罪** | 金融领域职务犯罪手段专业隐蔽；期货交易型贪污数额按实际获利认定 |
| **食品安全** | 用地沟油瘦肉精等有毒有害物质加工食品构成生产销售有毒有害食品罪 |
| **冤错案件** | 坚持防止冤假错案底线；事实不清证据不足应依法监督纠正 |
