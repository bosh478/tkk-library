## 一、行政诉讼法司法解释

### 1.1 受案范围

**可诉行政行为：**
- 行政处罚
- 行政强制
- 行政许可
- 行政确认
- 征收征用
- 不作为（应申请而不作为）
- 侵犯经营自主权/土地承包经营权/宅基地使用权
- 滥用行政权力排除/限制竞争
- 违法集资/摊派费用
- 违法要求履行义务
- 不依法支付低保/社会保险待遇

**不可诉行为：**
- 国防外交行为
- 内部行政行为
- 刑事司法行为
- 行政调解/仲裁
- 指导行为（无强制性）
- 信访处理

### 1.2 管辖

**级别管辖：**
| 案件类型 | 管辖法院 |
|----------|----------|
| 国务院部门/省级政府 | 中级法院 |
| 海关、金融、外汇等 | 中级法院 |
| 重大复杂案件 | 中级法院 |
| 其他 | 基层法院 |

**地域管辖：**
- 被告所在地法院
- 不动产案件：不动产所在地法院

### 1.3 原告资格

**利害关系人：**
- 行政行为的相对人
- 行政行为的利害关系人

**具体情形：**
| 类型 | 原告资格 |
|------|----------|
| 相邻权人 | 采光、通风、排水等受影响 |
| 公平竞争权人 | 竞争关系受影响 |
| 受害人 | 被处罚人/受害人均可 |
| 投资人 | 投资权益受影响 |
| 合伙组织 | 合伙企业/联营企业 |

### 1.4 被告资格

**被告确定规则：**
- 谁主体谁被告
- 行政机关授权的组织为被告
- 委托行为由委托机关为被告
- 共同行为：共同被告
- 上级机关批准：批准机关为被告

**特殊情况：**
| 情形 | 被告 |
|------|------|
| 组建机构 | 组建该机构的政府 |
|  内设机构 | 行政机关（独立执法除外） |
| 限期拆除决定 | 作出决定的机关 |
| 强制拆除行为 | 作出强制执行决定的机关 |

### 1.5 起诉期限

**一般期限：**
- 知道/应当知道行为内容：6个月
- 不知道行为内容：最长20年（不动产）/5年（其他）

**特殊期限：**
| 情形 | 期限 |
|------|------|
| 复议后起诉 | 15日 |
| 生命健康/不动产 | 1年（可延长） |
| 未告知诉权/起诉期限 | 1年（从知道诉权起算） |

### 1.6 审理程序

**一审：**
- 开庭审理
- 合议庭
- 公开审理（涉及国家秘密/个人隐私/法律另有规定除外）

**二审：**
- 上诉期限：判决15日/裁定10日
- 全面审查原则

**再审：**
- 当事人申请
- 法院/检察院提起

## 二、行政协议案件

### 2.1 行政协议范围

**政府与社会资本合作：**
- PPP协议
- 特许经营协议

**国有土地/房屋征收补偿：**
- 征收补偿协议
- 搬迁协议

**其他政府与社会资本合作协议：**
- 招商引资协议
- 政府采购合同

### 2.2 协议效力

**有效协议：**
- 协议主体适格
- 意思表示真实
- 不违反法律强制性规定
- 不违背公序良俗

**无效情形：**
- 行政主体无权限
- 违反法律强制性规定
- 违背公序良俗
- 程序违法严重

**可撤销情形：**
- 重大误解
- 欺诈、胁迫
- 显失公平

### 2.3 审理规则

**法律适用：**
- 适用行政诉讼法
- 参照民事合同法相关规定

**违约责任：**
- 行政主体违约：继续履行/采取补救措施/赔偿损失
- 相对人违约：行政优益权/赔偿损失

**补偿问题：**
- 公共利益需要变更/解除协议
- 给予合理补偿

## 三、行政赔偿案件

### 3.1 赔偿范围

**人身权损害：**
| 类型 | 赔偿项目 |
|------|----------|
| 人身自由权 | 限制人身自由期间工资 |
| 生命健康权 | 医疗费/误工费/残疾赔偿金/死亡赔偿金/丧葬费 |
| 名誉权 | 精神损害抚慰金 |

**财产权损害：**
- 查封/扣押/冻结财产
- 违法征收/征用
- 违法强制拆除

### 3.2 赔偿标准

**人身自由赔偿：**
- 每日284.74元（2024年标准）
- 实际限制人身自由天数 × 每日赔偿金

**生命健康赔偿：**
- 医疗费：按实际支出
- 误工费：日平均工资 × 误工天数
- 残疾赔偿金：职工年平均工资 × 年限 × 伤残等级系数
- 死亡赔偿金：职工年平均工资 × 20年

**财产赔偿：**
- 返还财产/恢复原状
- 财产损失按损失发生时市场价格或其他方式计算

### 3.3 赔偿程序

**单独提起：**
- 先向赔偿义务机关申请
- 赔偿义务机关2个月内不赔偿/不作决定
- 可向法院提起诉讼

**一并提起：**
- 在复议/诉讼时一并提出赔偿请求

## 四、司法赔偿

### 4.1 赔偿范围

**刑事司法赔偿：**
| 情形 | 赔偿范围 |
|------|----------|
| 错误拘留 | 限制人身自由期间 |
| 错误逮捕 | 限制人身自由期间 |
| 错误判决 | 刑罚执行期间/假释考验期 |
| 刑讯逼供 | 身体伤害/财产损失 |
| 违法扣押/冻结 | 财产损失 |

**非刑事司法赔偿：**
| 侵权行为 | 赔偿范围 |
|----------|----------|
| 违法拘留/罚款 | 财产损失/精神损害 |
| 违法查封/扣押/冻结 | 财产损失 |
| 违法执行 | 实际损失 |
| 错误执行 | 本金+利息 |

### 4.2 请求时效

**时效起算：**
- 知道/应当知道侵权行为：2年
- 不知/难以知道：2年从知道之日起算
- 最长5年（侵权行为持续不计算）

**时效期间：**
- 两年请求时效
- 特殊情形可申请延长

### 4.3 赔偿决定程序

**赔偿义务机关：**
- 侵权机关为赔偿义务机关
- 复议机关改变的，由复议机关赔偿

**决定程序：**
1. 赔偿请求人向赔偿义务机关申请
2. 赔偿义务机关2个月内作出决定
3. 不服，向上一级机关申请复议
4. 不服，向中级法院赔偿委员会申请作出决定

## 五、行政诉讼被告确定

### 5.1 被告确定规则

**基本原则：**
- 谁盖章谁被告
- 行为主体为被告

**限期拆除案件：**
- 强制拆除决定作出机关为被告
- 实施强制拆除行为的机关不一定为被告

**强制拆除案件：**
| 情形 | 被告 |
|------|------|
| 有强制执行决定 | 作出决定的机关 |
| 无决定，乡镇/街道实施 | 乡镇政府/街道办 |
| 多个机关实施 | 作出决定的机关 |

### 5.2 起诉期限起算

**一般起算：**
- 知道/应当知道行政行为之日起

**特殊情形：**
| 情形 | 起算规则 |
|------|----------|
| 未告知诉权 | 知道诉权之日起，但不超过1年 |
| 未告知内容 | 知道内容之日起，最长20年/5年 |

## 六、适用要点汇总表

### 6.1 行政诉讼时效

| 情形 | 时效 |
|------|------|
| 知道行为内容 | 6个月 |
| 复议后起诉 | 15日 |
| 不知道行为内容 | 5年（其他）/20年（不动产） |
| 未告知诉权 | 1年（从知道诉权起算） |

### 6.2 行政赔偿计算标准

| 项目 | 标准 |
|------|------|
| 人身自由赔偿（2024） | 284.74元/日 |
| 死亡赔偿金 | 职工年平均工资 × 20年 |
| 残疾赔偿金 | 职工年平均工资 × 年限 × 伤残系数 |

### 6.3 司法赔偿程序

| 阶段 | 机关 | 期限 |
|------|------|------|
| 申请赔偿 | 赔偿义务机关 | 2个月 |
| 复议 | 上一级机关 | 30日 |
| 申请决定 | 中级法院赔偿委员会 | - |
