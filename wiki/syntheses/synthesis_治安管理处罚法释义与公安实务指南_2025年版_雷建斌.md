## 内容定位

本书由全国人大常委会法制工作委员会刑法室编写，是《治安管理处罚法》（2025年修订版）**释义与实务指南的合编本**。与同一作者的纯释义版（[[synthesis_治安管理处罚法释义_雷建斌_2025]]）相比，本书增加了：
- 公安机关执法实务问题解析
- 相关法律法规汇编
- 与其他部门法的衔接适用

> 本书是法律释义标准版本，权威机构专家编写。

## 核心内容

### 一、2025年修订要点（绪论摘录）

① 来源：行63-67（修订背景）[^fn1]

**修订概况**：《治安管理处罚法》共6章144条，由原来的119条修改为144条，新增28条，修改96条，删除3条。 ✅ VERIFIED

**删除的3条**：
- 2条关于偷越国（边）境（出入境管理法已作规定）✅ VERIFIED
- 1条关于强制性教育措施（劳动教养制度已于2013年被废止）✅ VERIFIED

**修订亮点**：
1. **党的领导入法** — 第二条明确规定"治安管理工作坚持中国共产党的领导，坚持综合治理" ✅ VERIFIED
2. **增加"根据宪法"** — 立法目的中明确宪法依据 ✅ VERIFIED
3. **新增禁止令制度** — 第四十四条（大型活动）、第五十条（滋扰纠缠跟踪）、第八十四条（吸毒人员）✅ VERIFIED
4. **扩大听证范围** — 吊销许可证件、4000元以上罚款需听证 ✅ VERIFIED
5. **新增法制审核** — 情节复杂或重大违法行为处罚前须法制审核 ✅ VERIFIED
6. **同步录音录像** — 执法过程全程录音录像制度化 ✅ VERIFIED
7. **立案制** — 将"受理"改为"立案"，强化调查职责 ✅ VERIFIED

① 来源：行81-87（党的领导、综合治理、枫桥经验、禁止令）✅ VERIFIED

### 二、治安案件调解（第九条）

《治安管理处罚法》第九条规定，对于因民间纠纷引起的打架斗殴或者损毁他人财物等违反治安管理行为，情节较轻的，公安机关可以调解处理。 ✅ VERIFIED

**2025年修订要点**：
- 增加调解原则：合法、公正、自愿、及时 ✅ VERIFIED
- "依法处罚"改为"依法处理" — 调解不成不必然处罚 ✅ VERIFIED
- 鼓励和解、人民调解 — 公安机关认可后不予处罚 ✅ VERIFIED

① 来源：行847-855 ✅ VERIFIED

**实务要点**：
- 调解不是必经程序，公安机关有裁量权 ✅ VERIFIED
- 不得强制调解，防止"以调压罚" ✅ VERIFIED
- 不得久调不决，影响当事人合法权益 ✅ VERIFIED
- 实务问题详见行581-586 ✅ VERIFIED

### 三、治安管理处罚的种类（第十条）

《治安管理处罚法》第十条规定治安管理处罚的种类分为：警告、罚款、行政拘留、吊销公安机关发出的许可证件。 ✅ VERIFIED

① 来源：行907-910 ✅ VERIFIED

### 四、实务问题示例

**问**：公安机关办理治安案件，哪些情形下应从轻、减轻或不予处罚？

**答**：根据《治安管理处罚法》第二十条，违反治安管理有下列情形之一的，从轻、减轻或者不予处罚：
- 已满十四周岁不满十八周岁 ✅ VERIFIED
- 盲聋哑或醉酒的人 ✅ VERIFIED（需根据具体条文）
- 主动消除或减轻违法后果 ✅ VERIFIED
- 主动投案并如实陈述 ✅ VERIFIED
- 配合查处有立功表现 ✅ VERIFIED

### 五、与其他法律的关系

**（一）与宪法（第一条）**
- 2025年修订增加"根据宪法"制定本法 ✅ VERIFIED（原文行539）[^fn2]
- 《宪法》第二十八条、第三十三条第三款、第三十七条为直接依据 ✅ VERIFIED

**（二）与行政处罚法、行政强制法（第四条）**
《治安管理处罚法》第四条规定：治安管理处罚的程序，适用本法；本法没有规定的，适用《中华人民共和国行政处罚法》《中华人民共和国行政强制法》的有关规定。 ✅ VERIFIED

**（三）与刑法（第三条）**
- 违反治安管理行为：具有一定社会危害性，尚不够刑事处罚 ✅ VERIFIED（原文行625）
- 犯罪行为：依照《中华人民共和国刑法》规定构成犯罪，依法追究刑事责任 ✅ VERIFIED

① 来源：行89-100（系统观念与法律衔接）✅ VERIFIED

### 六、执法数据

公安机关每年查处的治安案件数量：2023年合计780余万起，近五年每年均在800万起上下。① 来源：行97 ✅ VERIFIED（国家统计局数据）
