# 公司法释义核心要点

## 一、立法目的与公司定义

### （一）立法目的（第1条）

公司法的立法目的包括四个层面：

1. **规范公司的组织和行为**：提供制度设计，规范公司设立和经营管理
2. **保护合法权益**：保护公司、股东、职工和债权人的合法权益
3. **完善现代企业制度**：完善中国特色现代企业制度，弘扬企业家精神
4. **维护社会经济秩序**：促进社会主义市场经济的发展

### （二）公司形式（第2-4条）

| 公司类型 | 特征 | 股东责任 |
|----------|------|----------|
| 有限责任公司 | 资合性+人合性；资本不划分为等额股份；治理结构灵活 | 以认缴出资额为限 |
| 股份有限公司 | 资合公司典型；资本划分为等额股份；股权可自由转让 | 以认购股份为限 |

## 二、公司设立制度

### （一）设立条件

**有限责任公司**：
- 股东人数：1人以上50人以下
- 股东资格：可以是自然人或法人
- 注册资本：全体股东认缴，**5年内缴足**（第47条）

**股份有限公司**：
- 发起人：2人以上200人以下，半数以上在境内有住所
- 注册资本：已发行股份的股本总额

### （二）公司章程（第5、45-46、94-95条）

公司章程应当载明的事项：

| 有限责任公司 | 股份有限公司 |
|--------------|--------------|
| 公司名称和住所 | 公司名称和住所 |
| 公司经营范围 | 公司经营范围 |
| 公司注册资本 | 公司设立方式 |
| 股东姓名或名称 | 公司注册资本 |
| 股东出资额、方式和日期 | **面额股每股金额/无面额股** |
| 机构产生办法、职权、议事规则 | 类别股的股份数及权利义务 |
| 法定代表人产生办法 | 发起人姓名/名称、认购股份数、出资方式 |
| | 董事会组成、职权、议事规则 |
| | 法定代表人产生办法 |
| | 监事会组成、职权、议事规则 |
| | 利润分配办法 |
| | 解散事由与清算办法 |

### （三）出资方式（第48条）

| 出资类型 | 具体形式 |
|----------|----------|
| 货币出资 | 资金存入公司账户 |
| 非货币出资 | 实物、知识产权、土地使用权、**股权**、**债权**等 |

> 股权、债权出资是2024年修订新增的出资形式。

### （四）出资责任

**1. 按期缴纳义务（第49条）**
- 货币出资：存入公司账户
- 非货币财产：办理财产权转移手续
- 未按期足额缴纳：继续履行+赔偿损失

**2. 资本充实责任（第50条）**
- 设立时股东未缴纳或非货币财产实际价额显著低于认缴出资额的，其他设立时股东在出资不足范围内承担连带责任

**3. 失权制度（第52条）**
- 董事会核查出资情况→书面催缴（宽限期≥60日）→董事会决议→失权通知
- 丧失股权应当依法转让或减资注销
- 6个月内未转让或注销的，由其他股东按出资比例足额缴纳

**4. 抽逃出资禁止（第53条）**
- 形式：制作虚假财务会计报表虚增利润分配、虚构债权债务关系转出、利用关联交易转出
- 责任：返还抽逃出资+董事、监事、高管的连带责任

**5. 出资加速到期（第54条）**
- **公司不能清偿到期债务的**，公司或已到期债权人有权要求已认缴出资但未届出资期限的股东提前缴纳出资

## 三、公司治理结构

### （一）股东会

**1. 组成与职权（第58-59条）**

股东会职权：
- 选举和更换董事、监事
- 审议批准董事会、监事会报告
- 审议批准利润分配方案和弥补亏损方案
- 对增加或减少注册资本作出决议
- 对发行公司债券作出决议
- 对公司合并、分立、解散、清算或变更公司形式作出决议
- 修改公司章程
- 公司章程规定的其他职权

> 删除了"决定公司的经营方针和投资计划"、"审议批准年度财务预算方案、决算方案"等经营类事项。

**2. 一人公司不设股东会（第60条）**
- 单一股东决定事项采用书面形式，置备于公司

**3. 表决规则（第65-66条）**

| 事项 | 表决要求 |
|------|----------|
| 普通决议 | 全体股东过半数表决权通过 |
| 特别决议（修改章程、增减资本、合并分立解散、变更形式） | 全体股东2/3以上表决权通过 |

**4. 电子通信开会（第24条）**
- 股东会、董事会、监事会可以采用电子通信方式开会和表决

### （二）董事会

**1. 组成（第68条）**
- 成员：3人以上
- 可设职工代表（职工300人以上的必须有职工代表）
- 董事长、副董事长由公司章程规定产生办法

**2. 职权（第67条）**
- 召集股东会并报告工作
- 执行股东会决议
- 决定经营计划和投资方案
- 制订利润分配方案、弥补亏损方案
- 制订增减注册资本、发行债券方案
- 制订合并分立解散变更形式方案
- 决定内部管理机构设置
- 聘任或解聘经理及报酬
- 制定基本管理制度

**3. 董事任期与辞任（第70-71条）**
- 任期由章程规定，每届不超过3年
- 辞任采用书面形式，通知到达公司时生效
- 董事辞任导致董事会低于法定人数的，继续履职

**4. 董事无正当理由被解任的赔偿请求权（第71条）**

### （三）监事会/审计委员会选择制（第69、76条）

| 双层制（传统） | 单层制（选择） |
|----------------|----------------|
| 设监事会 | 在董事会中设审计委员会 |
| 成员≥3人 | 行使监事会职权 |
| 职工代表≥1/3 | 不设监事会 |

### （四）经理（第74条）

- 有限责任公司可以设经理
- 经理职权由章程或董事会授权
- 删除了法定职权的列举

### （五）上市公司特别规定

**1. 独立董事（第136条）**
- 具体管理办法由证监会规定

**2. 审计委员会（第137条）**
- 上市公司设审计委员会的，特定事项须经审计委员会通过：
  - 聘用、解聘会计师事务所
  - 聘任、解聘财务负责人
  - 披露财务会计报告

**3. 董事会秘书（第138条）**
- 负责股东会、董事会会议筹备
- 文件保管
- 股东资料管理
- 信息披露事务

**4. 关联交易回避（第139条）**
- 董事与决议事项有关联关系的，应当书面报告
- 关联方不得行使表决权
- 无关联董事过半数通过
- 无关联董事不足3人的，提交股东会审议

## 四、股份有限公司特别制度

### （一）授权资本制（第96-98条）

**股份有限公司**适用授权资本制：

| 制度内容 | 说明 |
|----------|------|
| 注册资本 | 已发行股份的股本总额 |
| 出资要求 | 发起人在公司成立前全额缴纳股款 |
| 授权发行 | 章程或股东会授权董事会发行剩余股份 |

### （二）面额股与无面额股（第142条）

| 类型 | 特征 |
|------|------|
| 面额股 | 每股票面记载金额，每股金额相等 |
| 无面额股 | 股票不记载金额，只记载股份数；发行所得股款1/2以上计入注册资本 |

> 无面额股可将已发行面额股全部转换为无面额股，反之亦可。

### （三）类别股（第144-146条）

| 类别 | 权利特征 |
|------|----------|
| 优先股/劣后股 | 利润分配/剩余财产分配顺序优先或劣后 |
| 复数表决权股 | 每股享有数个表决权 |
| 限制表决权股 | 特定事项无表决权或受限 |
| 董事提名权股/选任权股 | 类别股东选举董事 |
| 可回赎股 | 约定期限/条件下可回赎 |
| 可转换股 | 可转换为普通股或其他类别股 |

**公开发行股份的公司**不得发行复数表决权股、限制表决权股（公开发行前已发行的除外）。

### （四）股份转让

| 转让限制 | 内容 |
|----------|------|
| 发起人股份 | 公司成立前不得转让 |
| 公开发行前股份 | 上市交易起1年内不得转让 |
| 董监高股份 | 任职期间每年转让不超过25%，离职后半年内不得转让 |

## 五、股权转让

### （一）有限责任公司股权外部转让（第84条）

**程序**：书面通知其他股东（数量、价格、支付方式和期限）→ 其他股东30日内答复 → 视为放弃优先购买权

**优先购买权行使**：
- 两个以上股东行使的，协商比例；协商不成按出资比例

**章程另有规定的从其规定**

### （二）未届期股权转让（第88条）

| 情形 | 责任承担 |
|------|----------|
| 已认缴但未届出资期 | 受让人承担缴纳义务；受让人未按期缴纳的，转让人承担补充责任 |
| 已届期未缴纳或出资不实 | 转让人与受让人在出资不足范围内承担连带责任；受让人不知情的，由转让人承担 |

### （三）异议股东回购请求权（第89条）

**情形**：
1. 公司连续5年盈利且符合分配条件但不分红
2. 公司合并、分立、转让主要财产
3. 营业期限届满章程规定解散事由出现但决议存续
4. **控股股东滥用股东权利严重损害公司或其他股东利益的**

## 六、公司合并、分立、增资、减资

### （一）公司合并（第218-221条）

| 类型 | 说明 |
|------|------|
| 吸收合并 | A公司+B公司=A公司存续 |
| 新设合并 | A公司+B公司=新公司设立 |

**债权人异议权**：接到通知30日内/公告45日内可要求清偿或担保

### （二）简易合并（第219条）

**适用情形**：母公司吸收合并全资子公司

**程序简化**：免除债权人异议程序

### （三）公司分立（第222-223条）

- 分立前的债务由分立后的公司承担连带责任（分立前与债权人有约定的除外）

### （四）减资（第224-226条）

| 类型 | 说明 |
|------|------|
| 实质减资 | 减少资本同时向股东返还资金 |
| **形式减资** | 只减少会计账面所有者权益，不向股东返还资金/免除出资义务 |

**程序**：
1. 董事会制订方案
2. 股东会特别决议（2/3以上表决权）
3. 通知债权人（30日）或公告（45日）
4. 债权人可要求清偿或担保

**违法减资责任**：股东须返还违法减资获得的资金+利息；责任董事赔偿损失

### （五）股东优先认缴权（第227条）

公司增资时，现有股东有权优先认缴，按照实缴出资比例认缴

## 七、股东权利保护

### （一）股东知情权（第57、110条）

| 公司类型 | 查阅范围 |
|----------|----------|
| 有限责任公司 | 章程、股东名册、股东会/董事会/监事会决议、财务会计报告、会计账簿、会计凭证 |
| 股份有限公司 | 章程、股东名册、股东会/董事会/监事会决议、财务会计报告；持股3%以上可查阅会计账簿、会计凭证 |
| 全资子公司 | 股东可一并查阅、复制 |

**限制**：
- 查阅会计账簿须书面说明目的
- 公司有理由认为目的不正当可能损害公司利益的，可拒绝
- 15日内书面答复
- 拒绝查阅可起诉

**委托中介机构**：可委托会计师事务所、律师事务所查阅

### （二）关联交易规制（第22条）

**控股股东、实际控制人、董事、监事、高管不得利用关联关系损害公司利益**

**关联交易定义**：控股股东、实际控制人、董事、监事、高管与直接或间接控制的企业之间的关系，以及可能导致利益转移的其他关系

### （三）公司法人格否认（第23条）

| 情形 | 责任 |
|------|------|
| 股东滥用公司法人独立地位和有限责任 | 股东对公司债务承担连带责任 |
| 股东控制两个以上公司滥用 | 各公司对任一公司债务承担连带责任 |
| 一人公司股东不能证明财产独立 | 股东对公司债务承担连带责任 |

## 八、控股股东、实际控制人规范

### （一）定义（第265条）

**控股股东**：出资额≥50%**或虽<50%但表决权足以影响股东会决议的股东

**实际控制人**：通过投资关系、协议或其他安排，能够实际支配公司行为的人

> 删除了"虽不是公司股东"的限定

### （二）实际控制人指示责任（第192条）

**公司的控股股东、实际控制人不担任公司董事但实际执行公司事务的**，适用董事对公司负有忠实义务和勤勉义务的规定。

**控股股东、实际控制人指示董事、高管从事损害公司或股东利益行为的**，与该董事、高管承担连带责任。

---

## 九、公司财务会计

### （一）利润分配（第210-212条）

| 要点 | 内容 |
|------|------|
| 分配顺序 | 弥补亏损→提取公积金→税后利润 |
| 期限 | 股东会决议作出之日起6个月内 |
| 违法分配 | 返还违法分配的利润+利息 |
| 公积金弥补亏损 | 任意公积金→法定公积金→资本公积金 |

### （二）资本公积金（第213条）

资本公积金来源：
- 股份发行溢价
- **发行无面额股所得股款未计入注册资本的金额**
- 国务院财政部门规定列入的其他项目

---

## 十、公司解散和清算

### （一）解散事由（第229条）

1. 营业期限届满或章程规定解散事由出现
2. 股东会决议解散
3. 因合并或分立需要解散
4. 依法被吊销营业执照、责令关闭或撤销
5. **法院判决解散**（持股10%以上股东请求）

### （二）清算组职权（第234条）

- 清理公司财产
- 清理债权债务
- 清缴税款
- 处理与清算有关的公司未了结业务
- 分配清偿债务后的剩余财产

### （三）简易注销（第240条）

**适用条件**：未发生债权债务或债权债务已清偿完结

**程序**：
1. 全体股东承诺真实性
2. 公示系统公示20日
3. 无异议的，准予注销

### （四）强制注销（第241条）

登记机关可依职权注销以下公司：
- 依法被吊销营业执照、责令关闭、撤销的公司
- 成立后无正当理由超过6个月未开业或连续停业6个月以上的公司
- 歇业后未办理注销登记的公司

---

## 十一、国家出资公司特别规定

### （一）适用范围（第168条）

- 国有独资公司
- 国有资本控股公司

### （二）党组织领导（第170条）

国家出资公司须坚持党的领导

### （三）治理结构（第171-176条）

- 国有独资公司不设股东会
- 董事会中须有职工代表
- 董事、高级管理人员未经同意不得兼职

## 十二、法律责任

### （一）股东责任

| 违法行为 | 责任 |
|----------|------|
| 抽逃出资 | 返还+利息；董事、监事、高管连带责任 |
| 虚假出资/未出资 | 责令改正+5%-15%罚款 |

### （二）公司责任

| 违法行为 | 责任 |
|----------|------|
| 虚报注册资本 | 5%-15%罚款 |
| 虚假公示信息 | 责令改正+罚款 |
| 妨害清算 | 罚款+拘留 |
| 冒用公司名义 | 责令改正+罚款 |

### （三）董监高责任

| 违法行为 | 责任 |
|----------|------|
| 违反忠实勤勉义务 | 收入归入公司+赔偿责任 |
| 关联交易损害公司 | 收入归入公司+赔偿责任 |
| 违反竞业禁止 | 收入归入公司+赔偿责任 |

### （四）董事责任保险（第193条）

公司可以向保险公司投保董事、监事、高管责任保险

## 修订核心变化总结

### 一、资本制度改革

| 修订前 | 修订后 |
|--------|--------|
| 认缴制无期限限制 | **有限责任公司5年缴足** |
| 无面额股未规定 | **引入无面额股制度** |
| 法定资本制 | **股份有限公司引入授权资本制** |

### 二、公司治理改革

| 修订前 | 修订后 |
|--------|--------|
| 监事会必设 | **可选择设审计委员会替代** |
| 董事会至少5人（股份公司） | **规模较小的可设1名董事** |
| 经理法定职权 | **职权由章程或董事会授权** |
| 无失权制度 | **新增股东失权制度** |

### 三、债权人保护强化

| 修订前 | 修订后 |
|--------|--------|
| 无加速到期规定 | **新增出资加速到期** |
| 无法人格否认横向穿透 | **新增横向穿透** |
| 无简易注销 | **新增简易注销、强制注销** |

### 四、信息披露与监管

| 修订前 | 修订后 |
|--------|--------|
| 发起人信息登记 | **实缴出资信息公示** |
| 无股权变更公示 | **股权变更信息公示** |
| 无类别股规定 | **完善类别股制度** |
