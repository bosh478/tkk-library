## 一、证券市场虚假陈述

### 1.1 虚假陈述类型

**虚假记载：**
- 信息披露义务人披露的信息存在虚假记载

**误导性陈述：**
- 披露的信息中存在误导性陈述

**重大遗漏：**
- 信息披露义务人在信息披露文件中未按照规定披露应当披露的重要信息

**不正当陈述：**
- 应当披露的信息未及时披露

### 1.2 重大性认定

**重大事件：**
- 公司章程、注册资本等变更
- 公司的重大投资行为、重大财产的处分
- 公司的重大诉仲裁事项
- 重大关联交易
- 董事长、1/3以上董事变动
- 利润分配/增资/合并分立决定
- 会计政策/会计估计的重大变更

### 1.3 交易因果关系

**推定因果关系：**
- 投资者在虚假陈述实施日及以后，至揭露日/更正日之前买入
- 在揭露日/更正日及以后，因卖出/持续持有而发生亏损

**推翻推定：**
- 被告举证证明原告明知存在虚假陈述仍买入
- 被告举证证明原告的交易受到虚假陈述以外因素影响

### 1.4 损失计算

**损失范围：**
- 投资差额损失
- 佣金
- 印花税
- 利息（如有）

**计算方式：**
- 买入平均价格 × 卖出/持有数量 - 卖出收入/到期前收盘价

## 二、证券纠纷代表人诉讼

### 2.1 诉讼代表

**推选代表：**
- 原告方在法院登记的权利人范围内推选
- 推选不出代表，可由法院提出建议人选

**代表资格：**
- 必须是原告
- 具备诉讼能力
- 能够履行代表职责

### 2.2 程序适用

**普通代表人诉讼：**
- 10人以上共同原告
- 推选代表人进行诉讼

**特别代表人诉讼：**
- 投资者保护机构受50名以上投资者委托
- 依据诉讼法代表全体投资者诉讼

### 2.3 效力扩张

**判决效力：**
- 对登记的投资者生效
- 对未登记的投资者不生效

**退出：**
- 投资者可以在一定期间内声明退出

## 三、银行卡纠纷

### 3.1 银行卡盗刷

**责任认定：**
- 借记卡：发卡行承担责任（未尽到安全保障义务）
- 信用卡：发卡行承担责任（未尽到安全保障义务）
- 持卡人对损失有过错的，承担相应责任

**赔偿范围：**
- 本金
- 利息（不超过透支额度）

### 3.2 银行卡息费

**息费上限：**
- 透支利率上限（日利率万分之五）
- 违约金上限（每期最低还款额未还部分的5%）

**计费方式：**
- 透支本金计费
- 复利计算（受限制）

### 3.3 银行责任

**安全保障义务：**
- 识别伪卡
- 交易监控
- 及时通知

**举证责任：**
- 银行举证持卡人存在过错
- 银行举证不存在盗刷

## 四、票据纠纷

### 4.1 票据权利

**付款请求权：**
- 持票人向付款人请求支付票据金额

**追索权：**
- 被拒绝付款时，向背书人、出票人等行使
- 可追索全部金额+利息+费用

### 4.2 票据行为效力

**有效票据行为：**
- 行为人具有票据能力
- 意思表示真实
- 形式要件符合法律规定

**无效情形：**
- 票据金额中文大写与数码不一致
- 票据金额、日期、收款人名称更改

### 4.3 票据抗辩

**对物抗辩：**
- 票据无效
- 票据权利已消灭
- 欠缺必要记载事项

**对人抗辩：**
- 直接当事人之间
- 恶意取得票据
- 无对价取得

### 4.4 公示催告

**适用范围：**
- 票据被盗、遗失、灭失
- 票据权利人不明

**程序：**
- 申请公示催告
- 公告催告
- 无人申报可除权判决

## 五、信用证纠纷

### 5.1 信用证独立性

**独立性原则：**
- 信用证独立于基础交易
- 银行不受基础交易影响

**欺诈例外：**
- 受益人欺诈
- 提交虚假单据

### 5.2 审单标准

**表面相符：**
- 单据与信用证条款表面相符
- 单据之间表面相符

**不符点：**
- 单据存在不符点
- 银行可拒绝付款

## 六、期货纠纷

### 6.1 期货交易

**交易主体：**
- 期货公司
- 客户
- 期货交易所

**交易规则：**
- 当日无负债结算
- 保证金制度
- 强行平仓

### 6.2 强行平仓

**适用情形：**
- 保证金不足
- 持仓超出限额
- 违规超仓

**责任承担：**
- 因行情变化，期货公司执行强行平仓，不承担责任
- 期货公司执行时间不当，造成损失，承担相应责任

### 6.3 透支交易

**透支利息：**
- 客户保证金不足仍进行交易
- 期货公司收取利息

**损失承担：**
- 期货公司过错导致透支交易，造成客户损失，承担赔偿责任

## 七、非法集资

### 7.1 非法吸收公众存款罪

**构成要件：**
1. 未经批准
2. 公开宣传
3. 向不特定对象
4. 承诺还本付息或给付回报

**数额标准：**
| 情节 | 数额/人数 |
|------|------------|
| 较大 | 20万元以上/30人以上 |
| 巨大 | 100万元以上/150人以上 |
| 特别巨大 | 500万元以上/500人以上 |

### 7.2 集资诈骗罪

**非法占有目的：**
- 集资后不用于生产经营/用于生产经营但与筹集资金规模明显不成比例
- 肆意挥霍集资款
- 携带集资款逃匿
- 将集资款用于违法犯罪活动
- 抽逃转移资金、隐匿财产
- 隐匿销毁账目/搞假破产假倒闭
- 其他非法占有资金、拒不返还的情形

**数额标准：**
| 情节 | 数额 |
|------|------|
| 数额较大 | 10万元以上 |
| 数额巨大 | 100万元以上 |
| 数额特别巨大 | 500万元以上 |

### 7.3 关联犯罪

| 行为 | 罪名 |
|------|------|
| 非法经营证券、期货、保险业务 | 非法经营罪 |
| 擅自发行股票、公司企业债券 | 擅自发行股票、公司企业债券罪 |
| 虚假广告 | 虚假广告罪 |
| 传销 | 组织、领导传销活动罪 |

## 九、适用要点汇总表

### 9.1 证券虚假陈述损失计算

| 计算步骤 | 方法 |
|----------|------|
| 买入平均价 | 买入总金额 ÷ 买入数量 |
| 卖出/持有 | 揭露日后卖出/持续持有至基准日 |
| 投资差额损失 | (买入平均价 - 卖出/基准价) × 卖出/持有数量 |

### 9.2 银行卡盗刷责任

| 情形 | 责任主体 |
|------|----------|
| 伪卡盗刷 | 发卡行 |
| 网络盗刷 | 发卡行/收单机构/支付机构 |
| 持卡人有过错 | 持卡人按过错程度承担 |
| 银行未尽安全保障 | 银行承担相应责任 |

### 9.3 票据权利时效

| 票据类型 | 付款请求权 | 追索权 |
|----------|------------|--------|
| 银行汇票 | 1年 | 6个月 |
| 商业汇票 | 1年（到期日起） | 6个月（被拒绝付款日起） |
| 银行本票 | 1年 | - |
| 支票 | 6个月 | - |
