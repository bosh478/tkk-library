# 人民检察院民事诉讼监督规则

（2021年7月26日发布，2021年8月1日起施行）

## 一、总则核心

### 监督主体与职责
- 最高人民检察院领导地方各级人民检察院和专门人民检察院的民事诉讼监督工作
- 上级人民检察院领导下级人民检察院的民事诉讼监督工作
- 实行检察官办案责任制，检察官、检察长、检察委员会在各自职权范围内作出决定

### 监督方式
人民检察院通过以下方式对民事诉讼活动实行法律监督：
- **抗诉**：向人民法院提出抗诉
- **检察建议**：向人民法院提出再审检察建议、审判违法检察建议、执行检察建议等

### 监督原则
以事实为根据，以法律为准绳，坚持公开、公平、公正和诚实信用原则，尊重和保障当事人诉讼权利，监督和支持人民法院依法行使审判权和执行权。

---

## 二、监督范围

### 1. 对生效判决、裁定、调解书的监督

| 监督情形 | 法律依据 |
|----------|----------|
| 原判决、裁定认定的基本事实缺乏证据证明 | 《民事诉讼法》第200条第2项 |
| 原判决、裁定认定事实的主要证据是伪造的 | 《民事诉讼法》第200条第3项 |
| 原判决、裁定认定事实的主要证据未经质证 | 《民事诉讼法》第200条第4项 |
| 对审理案件需要的主要证据，当事人因客观原因不能自行收集，书面申请人民法院调查收集，人民法院未调查收集 | 《民事诉讼法》第200条第5项 |
| 审判组织的组成不合法或者依法应当回避的审判人员没有回避 | 《民事诉讼法》第200条第6项 |
| 无诉讼行为能力人未经法定代理人代为诉讼或者应当参加诉讼的当事人因不能归责于本人或其诉讼代理人的事由未参加诉讼 | 《民事诉讼法》第200条第7项 |
| 违反法律规定，剥夺当事人辩论权利 | 《民事诉讼法》第200条第9项 |
| 未经传票传唤，缺席判决 | 《民事诉讼法》第200条第10项 |
| 原判决、裁定遗漏或者超出诉讼请求 | 《民事诉讼法》第200条第11项 |
| 据以作出原判决、裁定的法律文书被撤销或者变更 | 《民事诉讼法》第200条第13项 |
| 适用法律确有错误，导致原判决、裁定结果错误 | 《民事诉讼法》第200条第6项 |
| 审判人员在审理该案件时有贪污受贿，徇私舞弊，枉法裁判行为 | 《民事诉讼法》第200条第13项 |
| 民事调解书损害国家利益、社会公共利益 | 《民事诉讼法》第208条 |

### 2. 对审判程序中审判人员违法行为的监督

审判程序范围：第一审普通程序、简易程序、第二审程序、特别程序、审判监督程序、督促程序、公示催告程序、海事诉讼特别程序、破产程序。

| 违法情形 | 监督方式 |
|----------|----------|
| 判决、裁定确有错误，但不适用再审程序纠正 | 检察建议 |
| 调解违反自愿原则或调解协议内容违反法律 | 检察建议 |
| 应当立案而不立案 | 检察建议 |
| 审理案件适用审判程序错误 | 检察建议 |
| 保全和先予执行违反法律规定 | 检察建议 |
| 诉讼中止或者诉讼终结违反法律规定 | 检察建议 |
| 违反法定审理期限 | 检察建议 |
| 对当事人采取罚款、拘留等妨害民事诉讼的强制措施违反法律规定 | 检察建议 |
| 违反法律规定送达 | 检察建议 |
| 审判人员有《法官法》第46条规定的违法行为且可能影响案件公正审判、执行 | 检察建议 |

### 3. 对执行活动的监督

| 监督情形 | 监督方式 |
|----------|----------|
| 决定是否受理、执行管辖权的移转以及审查和处理执行异议、复议、申诉等执行审查活动存在违法、错误 | 检察建议 |
| 实施财产调查、控制、处分、交付和分配以及罚款、拘留、信用惩戒措施等执行实施活动存在违法、错误 | 检察建议 |
| 存在消极执行、拖延执行等情形 | 检察建议 |
| 执行人员存在违法行为 | 检察建议 |

### 4. 依职权启动监督的情形

人民检察院在履行职责中发现民事案件有下列情形之一的，应当依职权启动监督程序，不受当事人是否申请再审的限制：
- 损害国家利益或者社会公共利益的
- 审判、执行人员有贪污受贿，徇私舞弊，枉法裁判等违法行为的
- 当事人存在虚假诉讼等妨害司法秩序行为的
- 人民法院作出的已经发生法律效力的民事公益诉讼判决、裁定、调解书确有错误，审判程序中审判人员存在违法行为，或者执行活动存在违法情形的
- 依照有关规定需要人民检察院跟进监督的
- 具有重大社会影响等确有必要进行监督的情形

## 三、监督程序

### 1. 受理程序

**受理条件**：
- 当事人向人民检察院申请监督符合第19条规定
- 申请人提供的材料符合规定
- 属于本院受理案件范围
- 不具有不予受理情形

**申请监督期限**：
- 当事人依照第19条第1项规定申请监督，应当在人民法院作出驳回再审申请裁定或者再审判决、裁定发生法律效力之日起**两年内**提出
- 此期间为不变期间，不适用中止、中断、延长

**不予受理情形**（第27条）：
- 当事人未向人民法院申请再审的
- 当事人申请再审超过法律规定的期限的
- 人民法院在法定期限内正在对民事再审申请进行审查的
- 人民法院已经裁定再审且尚未审结的
- 判决、调解解除婚姻关系，但对财产分割部分不服的除外
- 人民检察院已经审查终结作出决定的
- 民事判决、裁定、调解书是人民法院根据人民检察院的抗诉或者再审检察建议再审后作出的
- 申请监督超过规定期限的

**案件受理后的移交**：
- 负责控告申诉检察的部门应当在决定受理之日起3日内将案件材料移送负责民事检察的部门
- 同时将《受理通知书》抄送负责案件管理的部门

### 2. 审查程序

**审查期限**：
- 受理后应当在**三个月内**审查终结并作出决定
- 调卷、鉴定、评估、审计、专家咨询等期间不计入审查期限

**审查方式**：
- 围绕申请人的申请监督请求、争议焦点以及第37条规定的情形，对人民法院民事诉讼活动是否合法进行全面审查
- 听取当事人意见，必要时可以听证或调查核实
- 调阅人民法院诉讼卷宗（副卷需严格保密措施）

**审查决定类型**（第50条）：
- 提出再审检察建议
- 提请抗诉或者提请其他监督
- 提出抗诉
- 提出检察建议
- 终结审查
- 不支持监督申请
- 复查维持

### 3. 听证程序

**听证适用范围**：人民检察院审查民事诉讼监督案件，认为确有必要的，可以组织有关当事人听证。

**听证参加人**：人大代表、政协委员、人民监督员、特约检察员、专家咨询委员、人民调解员、当事人所在单位或居住地的居民委员会、村民委员会成员以及专家、学者等。

**听证步骤**（第59条）：
1. 承办检察官介绍案件情况和需要听证的问题
2. 当事人及其他参加人分别说明情况
3. 听证员向当事人或者其他参加人提问
4. 主持人宣布休会，听证员讨论
5. 主持人宣布复会，听证员或听证员代表发表意见
6. 当事人发表最后陈述意见
7. 主持人进行总结

### 4. 调查核实程序

**调查核实情形**（第62条）：
- 民事判决、裁定、调解书可能存在法律规定需要监督的情形，仅通过阅卷及审查现有材料难以认定的
- 民事审判程序中审判人员可能存在违法行为的
- 民事执行活动可能存在违法情形的
- 其他需要调查核实的情形

**调查核实措施**（第63条）：
- 查询、调取、复制相关证据材料
- 询问当事人或者案外人
- 咨询专业人员、相关部门或者行业协会等对专门问题的意见
- 委托鉴定、评估、审计
- 勘验物证、现场
- 其他必要措施

**禁止性规定**：调查核实不得采取限制人身自由和查封、扣押、冻结财产等强制性措施。

**调查人员要求**：应当由二人以上共同进行，调查笔录经被调查人校阅后签名或盖章。

### 5. 中止与终结审查

**中止审查情形**（第72条）：
- 申请监督的自然人死亡，需要等待继承人表明是否继续申请监督
- 申请监督的法人或者非法人组织终止，尚未确定权利义务承受人
- 本案必须以另一案的处理结果为依据，而另一案尚未审结
- 其他可以中止审查的情形

**终结审查情形**（第73条）：
- 人民法院已经裁定再审或者已经纠正违法行为的
- 申请人撤回监督申请，且不损害国家利益、社会公共利益或他人合法权益的
- 申请人在和解协议中声明放弃申请监督权利，且不损害国家利益、社会公共利益或他人合法权益的
- 申请监督的自然人死亡，没有继承人或者继承人放弃申请，且没有发现其他应当监督的违法情形
- 申请监督的法人或者非法人组织终止，没有权利义务承受人或者权利义务承受人放弃申请，且没有发现其他应当监督的违法情形
- 发现已经受理的案件不符合受理条件的
- 人民检察院依职权启动监督程序的案件，经审查不需要采取监督措施的

## 四、监督方式

### 1. 再审检察建议

**适用情形**：地方各级人民检察院发现同级人民法院已经发生法律效力的民事判决、裁定有第81条规定情形之一的，可以向同级人民法院提出再审检察建议。

**程序要求**：
- 应当经本院检察委员会决定
- 在决定提出再审检察建议之日起15日内将《再审检察建议书》连同案件卷宗移送同级人民法院
- 应当制作决定提出再审检察建议的《通知书》，发送当事人
- 应当报上一级人民检察院备案

### 2. 提请抗诉

**适用情形**：
- 判决、裁定是经同级人民法院再审后作出的
- 判决、裁定是经同级人民法院审判委员会讨论作出的
- 原判决、裁定适用法律确有错误的
- 审判人员在审理该案件时有贪污受贿，徇私舞弊，枉法裁判行为的

**程序要求**：
- 在决定提请抗诉之日起15日内将《提请抗诉报告书》连同案件卷宗报送上一级人民检察院
- 制作决定提请抗诉的《通知书》，发送当事人

### 3. 抗诉

**适用情形**：最高人民检察院对各级人民法院、上级人民检察院对下级人民法院发现已经发生法律效力的民事判决、裁定、调解书发现有《民事诉讼法》第200条、第208条规定情形的，应当向同级人民法院提出抗诉。

**程序要求**：
- 在决定抗诉之日起15日内将《抗诉书》连同案件卷宗移送同级人民法院
- 人民法院向当事人送达再审裁定时一并送达《抗诉书》
- 人民检察院应当派员出席法庭

### 4. 检察建议

**审判违法检察建议**：向同级人民法院提出，针对审判程序违法行为。

**执行检察建议**：向同级人民法院提出，针对执行活动违法行为。

**社会治理检察建议**：发现人民法院在多起同一类型民事案件中有同类问题适用法律不一致、适用法律存在同类错误等情形的，可以提出检察建议；发现有关单位的工作制度、管理方法、工作程序违法或者不当的，可以提出检察建议。

**程序要求**：应当经检察长或者检察委员会决定，在决定之日起15日内将《检察建议书》连同案件卷宗移送同级人民法院，并制作决定提出检察建议的《通知书》，发送当事人。

## 五、救济程序

### 1. 申请复查

当事人认为人民检察院对同级人民法院已经发生法律效力的民事判决、裁定、调解书作出的不支持监督申请决定存在明显错误的，可以在不支持监督申请决定作出之日起**一年内向上一级人民检察院申请复查一次**。

**复查情形**（第126条）：
- 有新的证据，足以推翻原判决、裁定的
- 有证据证明原判决、裁定认定事实的主要证据是伪造的
- 据以作出原判决、裁定的法律文书被撤销或者变更的
- 有证据证明审判人员审理该案件时有贪污受贿，徇私舞弊，枉法裁判等行为的
- 有证据证明检察人员办理该案件时有贪污受贿，徇私舞弊，滥用职权等行为的
- 其他确有必要进行复查的情形

### 2. 再次监督

有下列情形之一的，人民检察院可以按照有关规定再次监督或者提请上级人民检察院监督：
- 人民法院审理民事抗诉案件作出的判决、裁定、调解书仍有明显错误的
- 人民法院对检察建议未在规定的期限内作出处理并书面回复的
- 人民法院对检察建议的处理结果错误的

## 六、适用要点汇总表

| 事项 | 要点 |
|------|------|
| **申请监督期限** | 收到驳回再审申请裁定或再审判决、裁定生效后2年内；不变期间，不适用中止中断延长 |
| **不予受理** | 未申请再审、超过法定期限、检察院已审查终结、再审后判决、重复申请等8种情形 |
| **审查期限** | 受理后3个月内作出决定，调卷等期间不计入 |
| **监督方式选择** | 同级法院生效判决→再审检察建议；再审后判决/审委会决定→提请抗诉；上级检察院→直接抗诉 |
| **依职权监督** | 不受申请期限限制，包括国家利益受损、审判人员违法、虚假诉讼、公益诉讼等情形 |
| **调查核实限制** | 不得采取限制人身自由和查封、扣押、冻结财产等强制性措施 |
| **复查期限** | 不支持监督申请决定作出后1年内可申请复查一次 |
| **案件受理费** | 不收取案件受理费；复印、鉴定、审计、勘验等费用由申请人直接支付 |

## 七、附则要点

- 本规则自2021年8月1日起施行
- 《人民检察院民事诉讼监督规则（试行）》同时废止
- 本院之前公布的其他规定与本规则内容不一致的，以本规则为准
- 检察建议案件的办理，未规定的适用《人民检察院检察建议工作规定》
- 民事公益诉讼监督案件的办理，适用本规则及有关公益诉讼检察司法解释的规定
