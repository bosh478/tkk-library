# 最高人民法院"前沿法评"核心观点汇编

## 一、民法与民事司法

### 1. 民法典合同编的债法总则功能
**王利明（中国法学会副会长、中国人民大学教授）**

核心观点：
- 民法典未设形式债法总则，但通过合同编发挥实质债法总则功能，构建独具中国特色的债法体系
- 合同编通则可广泛适用于非因合同关系产生的债权债务（民法典第468条）
- 此模式便利法官找法：通过准用条款减少规范竞合、实现集约化供给
- 区分意定之债与法定之债，合同编与侵权责任编体系分置，尊重两类债务差异性
- 法官应运用文义解释、目的解释、体系解释等方法，提炼实质债法总则规则

### 2. 民法典在司法审判中的精准实施
**姚辉（中国人民大学教授）**

核心观点：
- 民法典颁布五年，司法适用使抽象民事权利获得清晰边界和更具操作性保护路径
- 司法适用六大强化方向：
  1. 民法典与特别法的衔接及公法协同
  2. 司法适用上的体系思维（总则统领分则）
  3. 裁判中探求规范意旨（文义、体系、历史、目的解释）
  4. 清理不一致司法解释
  5. 发挥指导性案例示范作用
  6. 强化裁判文书释法说理

### 3. 劳动合同"已经不能履行"的认定
**林嘉（中国人民大学教授）**

核心观点：
- 《劳动争议司法解释（二）》第16条明确六种"劳动合同已经不能继续履行"情形：
  - 仲裁诉讼期间劳动合同期满（无续订/续延情形）
  - 劳动者已开始享受基本养老保险待遇
  - 用人单位被宣告破产
  - 用人单位解散（非因合并/分立）
  - 劳动者已与其他单位建立劳动关系影响原工作且拒解除
  - 客观不能履行的其他情形
- 兜底条款限定为"客观不能"，主观不能（信任丧失）一般不单独作为判断因素

### 4. 混同用工的司法规制
**沈建峰（中央财经大学教授）**

核心观点：
- 《劳动争议司法解释（二）》第3条专门规定混同用工
- 混同用工：多个存在关联关系的单位交替或同时对同一劳动者进行用工管理
- 用人单位确定规则：
  - 签订劳动合同的，尊重劳动者选择
  - 未签劳动合同的，根据用工管理行为、工作时间、内容、工资报酬发放、社保缴纳等因素综合判断
- 责任承担：劳动关系确认与责任承担可有限分离，关联单位可共同承担劳动报酬、福利待遇责任（基于共同之债理论）

### 5. 竞业限制"双阶"规则体系
**叶静漪（北京大学教授）**

核心观点：
- 《劳动争议司法解释（二）》构建"效力—责任"双阶规则
- 效力认定要件：主体适格（接触商业秘密）+ 范围适当（业务/地域/期限与保密义务相适应）
- 在职竞业限制条款有效：用人单位可与高管、高技术人员约定在职期间竞业禁止，不以支付补偿为生效要件
- 违反竞业限制责任：返还已支付经济补偿 + 支付违约金（可按公平原则调减）

### 6. 转包、分包、挂靠的用工主体责任
**王天玉（中国社会科学院研究员）**

核心观点：
- 《劳动争议司法解释（二）》第1、2条确立"用工主体责任"
- 承包人责任：向不具备合法经营资格主体转包/分包时，承担用工主体责任（不问主观过错，以资质缺失+权益受损为触发条件）
- 被挂靠单位责任：出借名义/账户/印章等挂靠行为，产生"用工单位形式"合理信赖，承担同等用工主体责任
- 责任范围：工资、加班费等劳动报酬及工伤保险待遇（不含经济补偿、二倍工资等）

## 二、刑事司法

### 7. 帮助信息网络犯罪活动罪的司法适用
**汪斌（最高人民法院刑三庭庭长）**

核心观点：
- 2025年7月"两高一部"发布《帮信意见》
- 全链条打击：上游下游全面打击各类主体、各个环节
- 严格依法认定"主观明知"，慎用推定，防止扩大打击面
- 宽严相济：对组织性/职业性/跨境犯罪从严；对末端情节较轻者从宽；未成年人"教育感化挽救"方针
- 行刑衔接：仅提供本人银行卡、获利少量者可不行刑事追诉
- 职业禁止/禁止令适用：利用职业便利犯罪者禁业；"卡农"、未成年人可宣告禁止令

### 8. 掩饰、隐瞒犯罪所得罪的司法适用
**罗国良（最高人民法院刑四庭庭长）**

核心观点：
- 2025年8月"两高"发布《掩隐罪解释》
- 综合性入罪规定：摒弃单纯数额标准，综合考虑上游犯罪性质、掩隐行为情节、后果
- 加重处罚标准优化：根据上游犯罪类型区分：非法采矿罪等高标准犯罪（五百万）和一般犯罪（五十万）
- 严格认定"明知"：不能从行为某方面异常推定"明知"，慎用推定
- 准确界分掩隐罪与帮信罪：掩隐罪"明知"更具体（赃款赃物）；帮信罪"明知"相对概括（可能被用于犯罪资金）

### 9-11. 东京审判的法理价值与国际法意义
**何勤华、张顺（华东政法大学）/ 张建伟（清华大学教授）/ 王秀梅（北京师范大学教授）**

核心观点：
- 东京审判历时两年零七个月，人类历史上规模最大的国际审判
- 对国际法五大贡献：
  1. 战争非法化的司法实践（追究侵略罪责）
  2. 个人刑责原则确立（驳斥国家责任论）
  3. 指挥官责任原则制度化
  4. 侵略罪概念的法律演进（"反和平罪"构成现代侵略罪直接法源）
  5. 贯彻和平主义价值观（促成日本和平宪法第9条）
- 未违反罪刑法定原则：行为时国际法已禁止相关行为；法不溯及既往需服从更高人道主义原则
- 对后来国际刑事司法的影响：前南斯拉夫、卢旺达国际刑事法庭、卢旺达问题国际刑事法庭均受其启示

### 12. 吸毒入刑的辨析
**罗翔（中国政法大学教授）**

核心观点：
- 应然角度：吸毒入刑有一定道理（三年有期徒刑作为轻/重罪分界，行政拘留性质上严厉于管制/缓刑）
- 实然角度：吸毒并非一律入罪，但关联行为均已入刑（以贩养吸→贩卖毒品罪；持有数量较大→非法持有毒品罪；唆使他人吸→引诱教唆吸毒罪等）
- 精神药品分药用/非药用类：确有证据证明出于治疗目的的不以毒品犯罪论处（2023年纪要）
- 核心立场：罪刑相当、比例原则，重罪重刑、轻罪轻刑、微罪微处、无罪不罚，摒弃对重刑主义的依赖

### 13. 民营经济的刑事法平等保护
**谢望原（中国人民大学教授）**

核心观点：
- 《民营经济促进法》明确规定"民营经济组织与其他各类经济组织享有平等法律地位"
- 立法层面完善：贪污罪与职务侵占罪、挪用公款罪与挪用资金罪等量刑差异体现公有/私有财产保护力度不同，需加强私有财产刑事保护
- 司法层面落实：
  - 严格贯彻既有保护民营经济法律、司法解释
  - 坚决杜绝以刑事手段干预经济纠纷
  - 严格落实"三个规定"，杜绝对司法的不法干预
- 公检法互相制约：检察机关应加大对违法刑事手段干预民营经济的监督力度

## 三、司法改革与法院建设

### 14. 数字改革助推审判工作现代化
**贾宇（上海市高级人民法院院长）**

核心观点：
- 上海法院"五大核心板块"：数助办案、数助监督、数助便民、数助治理、数助政务（1100余应用场景）
- 三大赋能方向：
  1. 公正与效率：关联案件信息推送（死亡/注销自动预警）、虚假诉讼甄别（"虚假民间借贷"等20多类场景）
  2. 管案与管人：大数据质量评查、廉洁监督（"涉车牌买卖骗取案款预警"）
  3. 诉前与诉后：矛盾纠纷多元化解（"一人多卡"预警）、社会治理（企业涉诉信息澄清）

### 15. "如我在诉"意识的实践
**张泽军（青海省高级人民法院院长）**

核心观点：
- 更新司法理念：从"法官思维"向"群众视角"转变
- 践行"如我在诉"三维度：
  1. 与时俱进更新司法理念（"如我在诉"贯穿审判执行全过程）
  2. 发挥"关键少数"表率作用（院庭长办案、青海高院院庭长办案占43.03%）
  3. 发扬实干精神（流动审判庭、数字法院"一张网"试点）

### 16. 审判体系现代化的"四个三"
**朱玉（湖南省高级人民法院院长）**

核心观点：
- 三大审判协调推进：刑事做精、民商事做强、行政做实
- 三大环节有机衔接：立案（精确分类）、审判（提质增效）、执行（综合治理）
- 三大程序梯次发力：一审重事实查明源头解纷、二审重法律适用定分止争、再审重监督指导统一尺度
- 三级法院整体提升：优化机构职能、完善管辖机制、统筹提升效能

### 17. 一体推进"三个素质"建设
**安长海（宁夏回族自治区高级人民法院院长）**

核心观点：
- 政治素质：强化政治忠诚、坚定政治信仰、提高政治能力，"从政治上看、从法治上办"
- 业务素质：后备人才培养、员额动态管理、专业审判人才（评选审判业务专家、建立审判人才库）
- 职业道德素质：严管厚爱、党纪学习教育、"三个规定"落实、弘扬英模精神

### 18. 薄弱法院建设
**茆荣华（贵州省高级人民法院院长）**

核心观点：
- "最高法院统筹、高级法院主导、中院主抓、基层法院主责"脱薄原则
- 五个能力提升：过硬政治能力、公正司法能力、依法履职能力、审判管理能力、狠抓落实能力
- 指导帮扶三要点：压实责任（"四个一对一"措施）、跟踪问效（一院一档）、争取党委政府支持

### 19. 做实定分止争
**徐家新（吉林省高级人民法院院长）**

核心观点：
- 四大维度理解"做实定分止争"：
  1. 政治维度：落实"让人民群众在每一个司法案件中感受到公平正义"
  2. 治理维度：源头预防、多元调解、实质性化解
  3. 民生维度：减少群众诉讼成本、化解"心结"
  4. 发展维度："控增量"+"提质量"
- 四大理念：全流程理念、最后一道程序理念、前后端协同贯通理念、穿透性理念

### 20-21. 矛盾纠纷预防化解
**寇昉（北京市高级人民法院院长）/ 李静（天津市高级人民法院院长）/ 游劝荣（湖北省高级人民法院院长）**

核心观点：
- 源头预防：12368"一号响应"机制（北京）、综治中心规范化入驻
- 多元解纷："总对总"诉调对接（北京、天津已入驻综治中心）、"枫桥式人民法庭"创建
- 行政争议化解：推动行政机关"一把手"出庭应诉（湖北出庭应诉率达95.9%）
- 实质化解：调解优先、判后答疑、"案-件比""案-访比"考核

### 22. 完善司法公正实现机制
**江必新（最高人民法院咨询委副主任委员）**

核心观点：
- 十大机制构建司法公正实现体系：
  1. 司法职权科学配置
  2. 事实认定精准保障
  3. 法律适用统一规范
  4. 诉讼程序正当运行
  5. 司法权力制约监督
  6. 司法公开阳光透明
  7. 司法为民便民服务
  8. 司法人员素能提升
  9. 错案预防与纠错
  10. 司法公正社会认同

## 四、知识产权

### 23. 高水平知识产权保护促推高质量发展
**陶凯元（最高人民法院副院长）**

核心观点：
- 知识产权保护模式根本性转变：从"适应性保护"转向"引领性保护"；从"追随型规则"转向"创设型规则"
- 三个维度建构中国自主知识产权法学知识体系：
  1. 植根中国实践（全球最大规模创新实践）
  2. 融通古今中外（传统文化智慧+世界文明成果）
  3. 面向未来发展（密切跟踪科技前沿）
- 系统观念平衡：保护"力"与"度"、"统"与"分"、"破"与"立"

## 五、环境资源与生态保护

### 24. 长江流域执法司法协同
**吴兆祥（最高人民法院环境资源审判庭庭长）**

核心观点：
- 2025年12家中央和国家机关联合印发《长江流域生态环境保护意见》
- 三大方面18条措施：
  1. 强化政治引领（贯彻习近平生态文明思想）
  2. 守正创新（落实长江保护法规定）
  3. 问题导向（解决协作不顺畅、层次低等突出问题）

### 25. 长江流域法治协同治理
**秦天宝（武汉大学教授）**

核心观点：
- 多维联动：行政机关内部配合 + 执法司法分工协作 + 公众参与
- 责任衔接：预防性+恢复性理念；民事/行政/刑事责任体系协调；司法谦抑（恪守裁判者角色）
- 内外协同：统筹国内法治和涉外法治，服务长江经济带绿色发展

### 26. 长江上游生态司法保护
**李永利（重庆市高级人民法院院长）**

核心观点：
- 强化"上游意识"：从政治上看、从法治上办
- 扛起"上游责任"：维护生态安全、防治污染、落实恢复性司法（增殖放流、补植复绿等）
- 展现"上游担当"：绿色转型（"技改抵扣"）、双碳目标、司法协同

### 27. 沙漠边缘阻击战司法保障
**杨临萍（最高人民法院副院长）**

核心观点：
- 五大司法举措：
  1. 提高政治站位（增强荒漠化综合防治责任担当）
  2. 发挥职能作用（严惩犯罪、助推绿色发展、丰富生态修复措施）
  3. 深化执法司法协同（区域司法协作、执法司法联动）
  4. 守正创新（专业化审判机制）
  5. 全球视野（国际司法交流合作）

### 28. 国家公园司法保护
**杨临萍（最高人民法院副院长）**

核心观点：
- 《国家公园法》2026年1月1日施行
- 五方面司法服务保障：
  1. 依法保护生态系统原真性和完整性
  2. 统筹绿色发展和民生改善
  3. 坚持保护优先、自然恢复为主
  4. 深化司法协作和执法司法协同
  5. 完善裁判规则（司法解释、典型案例）

### 29. 西南生态安全司法保护
**张宏伟（云南省高级人民法院院长）**

核心观点：
- 预防性保护理念："绿孔雀案"确立预防性保护裁判规则
- 恢复性保护理念：补植复绿、增殖放流、碳汇认购（"恢复性司法实践+社会化综合治理"模式）
- 协同保护："三合一"集中管辖、跨区域司法协作（长江上游、赤水河等）
- 统筹保护与发展：刺破公司面纱追责（"闽某纸业案"）

## 六、商事与金融

### 30. 民营经济司法保护
**刘贵祥（最高人民法院审判委员会专职委员）**

核心观点：
- 《民营经济促进法》"两个毫不动摇"写入法律
- 《指导意见》五方面重点工作：
  1. 平等保护（产权保护、打击内部腐败、公平竞争）
  2. 纾困解难（保障账款支付、保护人格权、规范执法）
  3. 引导规范经营（完善公司治理、履行社会责任）
  4. 优化服务保障（多元解纷、诉讼服务）
  5. 涉外司法（国际商事法庭）

### 31. 民营经济促进法落实
**夏道虎（江苏省高级人民法院院长）**

核心观点：
- 江苏民营经济贡献全省58.2%经济总量、92.2%高新技术企业
- 三大着力点：
  1. 稳预期（公平竞争、打击犯罪、区分罪错）
  2. 提信心（破解融资难题、知识产权保护、破产重整）
  3. 优服务（多元解纷、实质化解、信用治理）

### 32. 失信惩戒分级分类
**黄文俊（最高人民法院执行局局长）**

核心观点：
- 失信惩戒"减存遏增"：2023-2024年新纳入失信人数同比下降3.1%、23.4%；信用修复人数同比上升15.9%、35.4%
- 四方面完善：
  1. 坚持党的领导（60余部门联合惩戒）
  2. 护航民营经济（信用修复"容错纠正"）
  3. 以"信"促"治"（失信惩戒宽限期、执前和解）
  4. 严格公正司法（规范精准适用、有错必纠）

### 33. 企业破产法修改
**杜万华（最高人民法院咨询委原副主任）**

核心观点：
- 破产制度定位为市场经济基础制度
- 修改三大原则：
  1. 落实基础制度地位（与产权保护、市场准入、信用制度并列）
  2. 坚持人民性（保护性、救济性、治理性特征）
  3. 建立个人破产制度（保护小微经济、遏制公司有限责任异化、稳定婚姻家庭经济基础）

### 34. 新仲裁法修订
**刘凯湘（北京大学教授）**

核心观点：
- 六大亮点：
  1. 国际化：支持境外设立业务机构、明确"仲裁地"概念
  2. 临时仲裁：首次规定临时仲裁规则
  3. 仲裁机构独立性：公益性非营利法人定位
  4. 仲裁员要求：公道正派、良好专业素质、勤勉尽责、恪守职业道德
  5. 仲裁员信息披露制度：强制披露可能导致独立性、公正性疑虑的情形
  6. 行为保全：仲裁前/仲裁中均可申请

## 九、人工智能与新技术

### 40. 人工智能与司法工作融合
**陈杰（哈尔滨工业大学党委书记、中国工程院院士）**

核心观点：
- 稳慎融合的理论逻辑：融合的必然性 + 稳慎的必要性
- 现实逻辑：
  1. 法治护航人工智能规范发展
  2. 人工智能加速解放司法生产力
  3. 稳慎融合守护法治核心价值（公平正义）
- 实践逻辑：准确"识变"（多模态大模型跃迁）、主动"求变"（岗位迭代升级）、积极"应变"（可解释性/不可解释性统筹）

### 41-42. 人工智能侵权责任
**张新宝（中国人民大学教授）/ 程啸（清华大学教授）**

核心观点：
- 人工智能侵权是"人的责任"而非"人工智能体责任"
- 产品责任适用边界：
  1. 产品需具备具体特定用途（自动驾驶等）
  2. 产品需具备合理可行的质检标准
- 归责原则：过错责任为主 + 特殊场景过错推定
- 责任主体：营运者（而非设计者）承担主要责任
- 保险改革：从交强险逐步过渡到"产品+服务"责任保险

### 43. 网络生态治理司法保障

  2. 构建精准高效网络司法治理体系（类型化裁判、规则创制、协同联动）

## 结语

"前沿法评"栏目汇聚法学名家与司法实务界智慧，覆盖民事、商事、刑事、行政、知识产权、环境资源、涉外法治、人工智能等前沿领域，集中展现习近平法治思想引领下法治中国建设的新成效。57篇文章的核心共识在于：以高质量司法服务保障中国式现代化，需要始终坚持党的领导、坚持人民至上、坚持系统观念、坚持守正创新，在法治轨道上推进国家治理体系和治理能力现代化。
