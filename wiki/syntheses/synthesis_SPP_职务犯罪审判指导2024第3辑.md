# 职务犯罪审判指导2024第3辑

> **来源**：最高人民法院刑事审判第二庭编《职务犯罪审判指导》第3辑，法律出版社2024年12月第1版，ISBN 978-7-5197-9891-8

## 裁判要旨汇总

### 案例1：纪委监委派驻机构出具的情况说明能否作为立功依据 [^1]

| 项目 | 内容 |
|------|------|
| **案号** | [编号028] |
| **法院** | 二审法院 |
| **裁判要旨** | 纪委监委派驻机构根据授权依法依规进行的调查合法有效，相关情况说明等材料可以作为认定被告人立功的依据。被检举、揭发对象是否移送司法机关追究刑事责任不影响对被告人立功的认定。 |

**裁判理由摘要**：
- 依据《纪检监察机关派驻机构工作规则》第十九条第三款，派驻机构根据派出机关授权，依法调查驻在单位监察对象涉嫌职务违法、职务犯罪案件，有权就被检举、揭发对象查处的情况进行说明
- 对"查证属实"的理解：关键在于审查被检举、揭发对象是否已进入立案或起诉、审判程序
- 即使根据监督执纪"四种形态"最终未追究刑事责任，仍不影响立功认定

[^1]: 来源：韦宗昆、何锦玥撰稿，赵卫东审编，载《职务犯罪审判指导2024》第3辑第1-25页

### 案例2：集体研究是否阻却国有公司人员滥用职权的认定 [^2]

| 项目 | 内容 |
|------|------|
| **案号** | [编号029] |
| **法院** | — |
| **裁判要旨** | 国有公司人员滥用职权认定的关键在于行为人是否违反公司规章制度，如属违规经营，即使经过集体研究，也系滥用职权。若致使国家利益遭受重大损失，则在决策过程中起决定性作用的国有公司负责人，原则上应承担刑事责任。 |

**裁判理由摘要**：
- 国有公司人员滥用职权罪的核心要素是"滥用职权"和"国家利益遭受重大损失"
- 集体研究难以避免以"个意志"代替"集体意志"，不能阻却个人刑事责任
- 依据《最高人民法院、最高人民检察院关于办理渎职刑事案件适用法律若干问题的解释（一）》第五条，以"集体研究"形式实施的渎职犯罪应追究国家机关负有责任的人员的刑事责任

[^2]: 来源：潘庸鲁、段凰撰稿，刘琳琳审编，载《职务犯罪审判指导2024》第3辑第26-41页

### 案例3：职务犯罪中"影子公司"实际控制人的认定及合同真实性判断 [^3]

| 项目 | 内容 |
|------|------|
| **案号** | [编号030] |
| **法院** | — |
| **裁判要旨** | 认定国家工作人员是否为企业实际控制人，应综合企业重大事项的决策程序、利润分配流向、主要负责人与国家工作人员的关系、主营业务与国家工作人员职权的关系等因素进行研判。 |

**裁判理由摘要**：
- 国家工作人员充当企业实际控制人的四个判断维度：
  1. 企业重大事项的决策程序
  2. 企业资金流向
  3. 企业主要负责人与国家工作人员的关系
  4. 企业主营业务与国家工作人员职权的关系
- "影子公司"合同真实性判断五个维度：
  1. 参考合同相对人认定
  2. 根据合同订立前的预备行为认定
  3. 根据合同的订立背景认定
  4. 结合合同的约定内容认定
  5. 根据合同的履行情况认定

[^3]: 来源：徐兵撰稿，高洪江审编，载《职务犯罪审判指导2024》第3辑第42-71页

### 案例4：电话通知到指定地点能否认定为自动投案 [^4]

| 项目 | 内容 |
|------|------|
| **案号** | [编号031] |
| **法院** | 二审法院 |
| **裁判要旨** | 职务犯罪在"自动投案"的认定上，与普通刑事犯罪既有一致性也有特殊性。国家工作人员接驻单位纪检监察组电话通知到指定地点，是否能认定自动投案需要结合投案的时间点、投案意愿、调查机关掌握的情况等进行实质分析。 |

**裁判理由摘要**：
- 普通刑事犯罪：接到办案机关电话后有机会逃跑却选择将自己置于司法机关控制之下，一般足以体现投案的主动性和自愿性
- 职务犯罪特殊情况：
  1. 国家工作人员行迹具有更高的可预测性
  2. 国家工作人员依法承担接受单位组织、纪检、监察部门函询、谈话等的义务
  3. 主观态度：与本单位各部门人员存在工作交集，接到电话可能未联想到犯罪

[^4]: 来源：段凰、顾珊珊撰稿，赵卫东审编，载《职务犯罪审判指导2024》第3辑第72-94页

### 案例5：粮食购销储领域贪腐案件的司法认定 [^5]

| 项目 | 内容 |
|------|------|
| **案号** | [编号032] |
| **法院** | 一审/二审法院 |
| **裁判要旨** | 非国有单位依据政府采购合同履行管理、经营属于国有财产的政府储备粮的职责，符合贪污罪受委托管理、经营国有财产的人员的主体要件。在受委托管理、经营国有财产期间，侵吞、窃取、骗取或者以其他手段非法占有国有财产的，应以贪污论。 |

**裁判理由摘要**：
- 卢某某等人具有受委托从事公务的主体身份（制度拟制）
- 企业采购和承储储备粮是行政职能单位的委托行为
- 储备粮的性质：政府储备粮所有权属于国家，承储企业依据政府采购合同管理国有财产
- 骗取财政补贴的行为符合贪污罪的犯罪构成

[^5]: 来源：廖丽红、曹治华撰稿，赵卫东审编，载《职务犯罪审判指导2024》第3辑第95-126页

### 案例6：受委托经营中私人财产以公共财产论 [^6]

| 项目 | 内容 |
|------|------|
| **案号** | [编号033] |
| **裁判要旨** | 《刑法》第九十一条（1997-10-01 施行 / 2024-12-27 最新修正）第二款的立法本意在于强调国有单位对私人财产享有的占有权和承担的保管责任。在受委托经营法律关系中，非国有单位接受国有单位的授权或指示管理、使用私人财产，此时的私人财产处于国有单位的管理、使用之下，以公共财产论。 |

**裁判理由摘要**：
- "以公共财产论"不能仅局限于物在法律上的所有权归属，还应当对物的占有、持有以及相应的责任关系进行实质性考察
- 非国有企业受国有企业委托经营、管理公共财物的情形下，私人财产处于国有单位的管理、使用之中

[^6]: 来源：郑毅撰稿，赵卫东审编，载《职务犯罪审判指导2024》第3辑第127-139页

### 案例7：商业机会型受贿的认定思路 [^7]

| 项目 | 内容 |
|------|------|
| **案号** | [编号034] |
| **裁判要旨** | 利用职权接受商业机会的行为，应当结合具体案情，综合考虑收送双方之间的主观动机、谋利事项、收受财物和风险承担等情节，透过现象发现权钱交易的行为本质，作出精准认定。 |

**裁判理由摘要**：
- 商业机会型受贿与正常商业机会的区分：
  1. 具有针对性（针对特定对象定制）
  2. 一般具有排斥风险性（只享收益不承担风险）
  3. 获利具有权钱交易性（超出市场正常水平）
- 主要形式：增设交易环节、直接转卖变现、定向采购贸易

[^7]: 来源：田亮撰稿，于同志审编，载《职务犯罪审判指导2024》第3辑第140-170页

### 案例8：贿赂犯罪中"中介人"的行为定性 [^8]

| 项目 | 内容 |
|------|------|
| **案号** | [编号035] |
| **裁判要旨** | 贿赂犯罪中"中介人"的行为应结合主观故意、客观行为进行综合考察：构成要件不同定性不同。 |

**裁判理由摘要**：
- "中介人"行为定性分类：
  1. 与受贿人通谋，共同占有财物 → 受贿罪共犯
  2. 与行贿人共谋，共同谋取不正当利益 → 行贿罪共犯
  3. 居间介绍，促成行受贿 → 介绍贿赂罪
  4. 虚构关系骗取财物 → 诈骗罪

### 案例9：转贷型"借鸡生蛋"受贿行为的认定 [^9]

| 项目 | 内容 |
|------|------|
| **案号** | [编号036] |
| **裁判要旨** | 国家工作人员为请托人的请托事项提供斡旋帮助，无偿借用请托人资金转贷给第三方收息的行为构成受贿罪。在主客观一致范围内，将国家工作人员知晓的第三方借款人支付的实际利息额认定为受贿额更为适宜。 |

**裁判理由摘要**：
- 无偿借用请托人资金转贷第三方收息，本质上是"借鸡生蛋"型受贿
- 利用商业机会但未实质性承担经营风险或未付出实质性经营活动而获取收益构成受贿罪
- 受贿数额的认定应当遵循主客观一致原则

[^9]: 来源：鲁照兴、张莹撰稿，刘琳琳审编，载《职务犯罪审判指导2024》第3辑第198-223页

### 案例10："旋转门"型受贿的认定因素 [^10]

| 项目 | 内容 |
|------|------|
| **案号** | [编号037] |
| **裁判要旨** | "旋转门"型受贿的认定应结合四个因素综合考量：利用职务便利为他人谋取利益、事先约定、关联性、收受远高于实际工作的"报酬"。 |

**裁判理由摘要**：
- 认定因素：
  1. 存在利用职务便利为他人谋取利益的行为
  2. 国家工作人员身份存续期间的事先约定
  3. 离职后收受财物行为与离职前谋取利益行为具有较强的关联性
  4. 存在收受远高于实际工作产生的"报酬"
- 受贿金额 = 约定"报酬" - 合理报酬

[^10]: 来源：赵星天、崔佳明撰稿，高洪江审编，载《职务犯罪审判指导2024》第3辑第224-248页

### 案例13：经党纪处理后的收受财物事实的认定 [^13]

| 项目 | 内容 |
|------|------|
| **案号** | [编号041] |
| **裁判要旨** | 行为人经党纪处理后的受贿行为是否累计为犯罪数额，要视不同情况区别对待。党纪处理过的受贿行为一般不再移送司法机关处理，但通过贿赂、打招呼等违法手段得以按党纪处分的，撤销原党纪处分后应一并作为犯罪事实处理。 |

### 案例15：受贿人案发前向行贿人支付贿赂物价款的性质 [^15]

| 项目 | 内容 |
|------|------|
| **案号** | [编号043] |
| **裁判要旨** | 受贿人收受贿赂物后为掩饰犯罪向行贿人支付该贿赂物价款的，贿赂物兼具受贿人违法所得及行贿人供犯罪所用财物的性质，应当予以追缴、上缴国库；贿赂物价款属于行贿人的违法所得，如该款来源于受贿人的合法财产，则应予以追缴并返还受贿人。 |

- 追缴原物优先于价值替代原则

### 案例16：受贿人"退物收钱"情形中受贿数额的认定 [^16]

| 项目 | 内容 |
|------|------|
| **案号** | [编号044] |
| **裁判要旨** | 对收受行贿物后退还行贿人行为性质的认定，应当结合受贿人退还的主观目的和客观行为进行综合判断。如果受贿人为了获取更多金钱，将行贿人送给的物品退还，而后再收取行贿人金钱的，相当于用行贿物进行交易，属于二次受贿。 |

**裁判理由摘要**：
- 退还财物排除犯罪的条件：主观上有受贿故意 + 客观上无积极主动退还行为
- "退物收钱"行为属于交易型受贿
- 受贿数额 = 第一次贿赂物的价格 + 交易物品的差额

[^16]: 来源：黄武、杜峰、崔芳撰稿，刘琳琳审编，载《职务犯罪审判指导2024》第3辑第364-393页

## 案例A：国家工作人员接驻单位纪检监察组电话通知到指定地点，能否认定为自动投案

**案号/法院**：最高人民法院刑二庭 / 北京市第三中级人民法院

**问题意识**：职务犯罪中，犯罪事实已经被办案机关掌握，因客观情况未实施抓捕，由驻被告人单位纪检监察组工作人员电话通知被告人回单位核实情况，被告人是否构成自动投案？

**裁判要旨**：

被告人万某某的行为**不属于自动投案**，不宜认定为自首。

### 职务犯罪中"电话通知到案"的认定要素

| 要素 | 内容 |
|------|------|
| 踪迹可预测性 | 国家工作人员行踪更具有稳定性（稳定工作场所、家庭住址、社会关系），办案机关可便利获取其踪迹 |
| 特殊义务 | 国家工作人员依法履公职，接受单位组织、纪检、监察部门的函询、谈话等是其应当履行的义务 |
| 主观态度 | 职务犯罪嫌疑人与本单位各部门人员存在工作交集，日常联系较紧密，接到电话通知可能未意识到将被调查 |

### 普通刑事犯罪 vs 职务犯罪的区别

| 类型 | 电话通知到案的效力 |
|------|-------------------|
| 普通刑事犯罪 | 犯罪嫌疑人接到办案机关电话后有机会逃跑却选择将自己置于司法机关的控制之下，一般足以体现其投案的主动性和自愿性，应认定为自首 |
| 职务犯罪 | 犯罪嫌疑人接到电话后到达指定地点并不能直接得出具有投案主动性和自愿性的结论，需要进一步进行实质分析 |

### 本案结论

万某某接到电话不知道监察机关已经掌握其犯罪的线索并在单位等候，未意识到纪检监察组是要核实其自身的违法犯罪问题，因此赶回单位**不能被视为"主动投案"的表现**。

**原文引用**：
> "对于普通刑事犯罪而言，犯罪嫌疑人接到办案机关电话后有机会逃跑却选择将自己置于司法机关的控制之下，一般足以体现其投案的主动性和自愿性；但对于职务犯罪而言，犯罪嫌疑人接到电话后到达指定地点并不能直接得出嫌疑人具有投案主动性和自愿性的结论，需要进一步进行实质分析。" ①来源：L951

## 案例B：粮食购销储领域贪腐案件的司法认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：非国有单位受托承储政府储备粮，侵吞、骗取财政补贴，如何定性？

**裁判要旨**：

非国有单位依据政府采购合同履行管理、经营属于国有财产的政府储备粮的职责，符合贪污罪**受委托管理、经营国有财产的人员**的主体要件。

### 主体身份认定

卢某某等人从事公务的主体身份**因制度拟制而成**：
1. **案件背景及政府储备粮承储主体的制度设定**：LQ公司受G市储备粮管理中心、L区发展和改革局委托承储市、区两级政府储备粮
2. **卢某某、罗某某具有受委托从事公务的主体身份**：代表政府储备粮管理机构履行储备粮管理职责

### 本案犯罪事实

| 涉案内容 | 数额 |
|----------|------|
| 贪污L区级财政补贴 | 649.584971万元 |
| 贪污G市级财政补贴 | 1115.742793万元 |
| **合计** | **1765.327764万元** |

### 核心规则

1. **企业采购和承储储备粮是行政职能单位的委托行为**：政府储备粮的采购、承储、管理属于行政职能的延伸
2. **犯罪对象是国有财物**：卢某某骗取的补贴是其经营管理的国有财物
3. **法条竞合下的罪名适用**：应以贪污罪论处

**原文引用**：
> "非国有单位依据政府采购合同履行管理、经营属于国有财产的政府储备粮的职责，符合贪污罪受委托管理、经营国有财产的人员的主体要件。在受委托管理、经营国有财产期间，侵吞、窃取、骗取或者以其他手段非法占有国有财产的，应以贪污论。" ①来源：L983

## 案例C：受委托经营法律关系中，国有单位授权非国有单位管理、使用的私人财产，以公共财产论

**案号/法院**：最高人民法院刑二庭

**问题意识**：非国有企业受国有企业委托经营、管理公共财物时，公共财物的范围如何界定？

**裁判要旨**：

非国有企业受国有企业委托经营、管理公共财物的情形下：
- 被告人高某某等具有组织实施代农加工服务的职务便利
- 所管理和使用的财物中包含国有单位委托管理的公共财产
- 这些财产应以**公共财产**论

### 核心规则

受委托经营中私人财产以公共财产论的条件：
1. 存在国有单位授权非国有单位管理、使用的关系
2. 非国有企业实际控制和管理这些财产
3. 财产用于国有单位委托的特定目的

## 案例D：商业机会型受贿的认定思路探析

**案号/法院**：最高人民法院刑二庭

**问题意识**：国家工作人员利用职务便利为请托人谋取商业机会，是否构成受贿？商业机会如何认定？

**裁判要旨**：

### 商业机会与商业机会型受贿的区分

商业机会本身不等同于财物，但**利用职务便利获取商业机会并收受财物**可能构成受贿。

### 商业机会型受贿的主要形式

| 形式 | 说明 |
|------|------|
| 增设交易环节 | 利用职务便利在正常交易中增设环节，让请托人获取额外商业机会 |
| 直接转卖变现 | 将商业机会直接转卖给请托人获取财物 |
| 定向采购贸易 | 通过定向采购让请托人获取商业机会并收受财物 |

### 除外情形

1. 正常的商业竞争行为
2. 市场价格下的公平交易
3. 无权钱交易关系

**原文引用**：
> "商业机会型受贿的认定思路探析" ①来源：L112

## 案例E：贿赂犯罪中"中介人"的行为如何定性

**案号/法院**：最高人民法院刑二庭

**问题意识**：在行贿人和受贿人之间充当"中介人"的角色，如何定性？

**裁判要旨**：

### "中介人"的定性分类

| 行为方式 | 定性 |
|----------|------|
| 在请托和受贿之间牵线搭桥 | 构成**介绍贿赂罪** |
| 以帮助贿赂为由骗取财物 | 构成**诈骗罪** |
| 与国家工作人员共谋受贿 | 构成**受贿罪共犯** |
| 单纯介绍而不知是贿赂 | 不构成犯罪 |

### 本案结论

被告人巴某某的行为符合**受贿罪**的构成要件（与国家工作人员共谋）。

## 案例F：转贷型"借鸡生蛋"受贿行为的认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：国家工作人员将收受的贿赂款转贷给请托人获取利息，是否构成受贿？数额如何计算？

**裁判要旨**：

转贷型"借鸡生蛋"受贿行为的认定：
1. **核心要素**：国家工作人员利用职务便利为请托人谋取利益，收受贿赂后将款项转贷获取利息
2. **受贿数额**：遵循主客观相一致原则，以实际获取的利息计算
3. **犯罪构成**：权钱交易的本质不变

## 案例G："旋转门"型受贿的认定因素

**案号/法院**：最高人民法院刑二庭

**问题意识**：离职后的国家工作人员收受"报酬"，如何认定是否构成利用影响力受贿罪？

**裁判要旨**：

### "旋转门"型受贿的认定因素

| 因素 | 内容 |
|------|------|
| 存在利用职务便利为他人谋取利益的行为 | 在职时利用职务便利为请托人谋取利益 |
| 离职后收取"报酬" | 利用原职权或者地位形成的便利条件 |
| 报酬与实际工作不相当 | 收受远高于实际工作的"报酬" |

### 核心规则

离职后的国家工作人员收受远高于实际工作的"报酬"，应当认定为**利用影响力受贿罪**。

## 案例H：离职后利用原职权或者地位形成的便利条件为他人谋取不正当利益并收取"咨询费""顾问费"等行为的性质认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：离职后收取"咨询费""顾问费"，是正常劳务所得还是利用影响力受贿？

**裁判要旨**：

### "谋取不正当利益"的认定

离职后为他人谋取不正当利益并收取"咨询费""顾问费"，符合利用影响力受贿罪的构成要件。

### 核心规则

1. 利用原职权或者地位形成的便利条件
2. 为他人谋取不正当利益
3. 收取"咨询费""顾问费"等名义的财物
4. 数额与实际劳务不相符

## 案例I：参与国家医保药品目录调整工作的医学专家身份性质的认定

**案号/法院**：最高人民法院刑二庭

**问题意识**：参与国家医保药品目录调整工作的医学专家，是否属于"其他依照法律从事公务的人员"？

**裁判要旨**：

### 核心判断标准

1. **熊某某、胡某系在特定条件下行使国家行政管理职权**：参与国家医保药品目录调整工作具有公共管理属性
2. **熊某某、胡某等咨询专家系依法参与国家医保药品目录调整工作**：属于依照法律从事公务

### 认定结论

参与国家医保药品目录调整工作的医学专家，在履行药品目录调整职责时，属于**"其他依照法律从事公务的人员"**。
