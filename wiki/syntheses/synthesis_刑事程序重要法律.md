## 一、刑事诉讼法核心要点（2018修正）

### 1. 任务与基本原则

**立法目的**：保证准确、及时地查明犯罪事实，正确应用法律，惩罚犯罪分子，保障无罪的人不受刑事追究，尊重和保障人权。

**基本原则**：
- 依靠群众，以事实为根据，以法律为准绳
- 分工负责，互相配合，互相制约
- 人民检察院依法对刑事诉讼实行法律监督
- 未经人民法院依法判决，对任何人都不得确定有罪
- 两审终审制（第十条）
- 公开审判（第十一条，但法定情形除外）

### 2. 管辖

| 法院级别 | 管辖案件类型 |
|----------|--------------|
| 基层法院 | 第一审普通刑事案件（除上级管辖外） |
| 中级法院 | 危害国家安全、恐怖活动案件；可能判处无期徒刑、死刑的案件 |
| 高级法院 | 全省（自治区、直辖市）性的重大刑事案件 |
| 最高法院 | 全国性的重大刑事案件 |

**地域管辖**：犯罪地法院管辖为主，被告人居住地法院管辖为辅（第二十五条）。

### 3. 强制措施体系

| 措施类型 | 适用条件 | 期限/特点 |
|----------|----------|-----------|
| 拘传 | 犯罪嫌疑人、被告人 | 12小时；案情特别重大复杂需逮捕的，不超过24小时 |
| 取保候审 | 可能判处轻刑或社会危险性较低者 | 最长12个月 |
| 监视居住 | 符合逮捕条件但不适宜羁押者 | 最长6个月；可折抵刑期 |
| 拘留 | 现行犯或重大嫌疑分子（公安机关自行决定） | 24小时内讯问；24小时内通知家属（除例外情形） |
| 逮捕 | 人民检察院批准或人民法院决定 | 侦查羁押期限：一般2个月，可延长 |

**逮捕条件**（第八十一条）：有证据证明有犯罪事实，可能判处徒刑以上刑罚，且具有社会危险性。

### 4. 证据制度

**证据种类**（第五十条）：物证、书证、证人证言、被害人陈述、犯罪嫌疑人/被告人供述和辩解、鉴定意见、勘验/检查/辨认/侦查实验笔录、视听资料/电子数据。

**证据确实、充分的标准**（第五十五条）：
1. 定罪量刑的事实都有证据证明
2. 据以定案的证据均经法定程序查证属实
3. 综合全案证据，对所认定事实已排除合理怀疑

**非法证据排除**（第五十六条）：
- 刑讯逼供等非法方法收集的供述，应当排除
- 暴力、威胁等非法方法收集的证人证言、被害人陈述，应当排除
- 程序违法可能严重影响司法公正的物证、书证，应予补正或合理解释

### 5. 侦查程序

| 侦查行为 | 要点 |
|----------|------|
| 讯问犯罪嫌疑人 | 不少于2人；看守所内进行；全程录音录像（可能判死刑等重大案件） |
| 询问证人 | 个别进行；可现场、单位、住处或公安机关进行 |
| 搜查 | 必须出示搜查证；紧急情况可无证搜查 |
| 扣押 | 与案件无关不得扣押；3日内退还 |
| 技术侦查 | 严格批准手续；有效期3个月，可延长 |

**侦查羁押期限**：一般2个月，经批准可延长（第一百五十六条）。

### 6. 审判程序

| 程序类型 | 适用条件 | 审理期限 |
|----------|----------|----------|
| 普通程序 | 事实清楚、证据充分 | 受理后2-3个月 |
| 简易程序 | 事实清楚、证据充分；被告人认罪且无异议 | 20日内；三年以上可延至1.5月 |
| 速裁程序 | 可能判处3年以下；有期徒刑；被告人认罪认罚同意适用 | 10日内；一年以上可延至15日 |
| 未成年人案件 | 教育为主、惩罚为辅；附条件不起诉 | 考验期6个月至1年 |

### 7. 第二审程序

**上诉/抗诉期限**：判决10日，裁定5日（第二百三十条）。

**全面审查原则**（第二百三十三条）：不受上诉或抗诉范围限制。

**上诉不加刑**（第二百三十七条）：二审不得加重被告人刑罚；但人民检察院抗诉或自诉人上诉不受此限。

### 8. 死刑复核程序

- 死刑立即执行：由最高人民法院核准（第二百四十六条）
- 死刑缓期二年执行：由高级人民法院核准（第二百四十八条）
- 最高法院复核应当讯问被告人；辩护律师提出要求的，应当听取意见

### 9. 执行程序

| 刑罚类型 | 执行机关 |
|----------|----------|
| 死刑立即执行 | 最高人民法院院长签发命令；7日内执行 |
| 死刑缓期二年执行 | 高级人民法院核准；监狱执行 |
| 有期徒刑/无期徒刑 | 公安机关送交监狱；剩余刑期3个月以下由看守所代为执行 |
| 拘役 | 公安机关执行 |
| 管制、缓刑、假释 | 社区矫正机构负责 |
| 财产刑 | 人民法院执行（可会同公安机关） |

### 10. 特别程序

- **未成年人刑事案件**：附条件不起诉（第二百八十二条）、犯罪记录封存（第二百八十六条）
- **当事人和解公诉案件**：因民间纠纷引起的轻刑案件、过失犯罪案件（第二百八十八条）
- **缺席审判**：贪污贿赂、危害国家安全、恐怖活动犯罪（犯罪嫌疑人被告人在境外）（第二百九十一条）
- **违法所得没收**：逃匿、死亡案件（第二百九十八条）
- **强制医疗**：不负刑事责任的精神病人（第三百零二条）

## 二、人民武装警察法核心要点（2020修订）

### 1. 部队性质与领导体制

- **组成**：内卫部队、机动部队、海警部队、院校和研究机构
- **领导体制**：党中央、中央军事委员会集中统一领导
- **任务范围**：执勤、处置突发社会安全事件、防范和处置恐怖活动、海上维权执法、抢险救援、防卫作战

### 2. 指挥关系

| 任务类型 | 指挥主体 |
|----------|----------|
| 平时执行任务 | 中央军委或授权武警部队组织指挥 |
| 平时参与非战争军事行动（抢险救援、维稳处突等） | 中央军委授权战区指挥 |
| 战时执行任务 | 中央军委或授权战区组织指挥 |

### 3. 主要执勤任务

1. 警卫对象、重要警卫目标的武装警卫
2. 重大活动的安全保卫
3. 重要公共设施、核设施、企业、仓库、水源地、水利工程、电力设施、通信枢纽等核心要害部位的武装守卫
4. 重要桥梁和隧道的武装守护
5. 监狱、看守所等场所的外围武装警戒
6. 直辖市、省会城市等重点区域和特定内陆边界的武装巡逻
7. 协助执行逮捕、追捕、押解、押运任务

### 4. 处置突发社会安全事件任务

- 保卫重要目标安全
- 封锁、控制有关场所和道路
- 实施隔离、疏导、带离、驱散行动
- 营救和救护受困人员
- 武装巡逻，恢复社会秩序

### 5. 执法权限

**可依法采取的措施**（第十九条）：
- 检查进出警戒区域的人员、物品、交通工具
- 盘问有违法犯罪嫌疑的人员并查验证件
- 协助执行交通管制或现场管制
- 制止危害公共安全或执勤目标安全的行为
- 实施必要侦察

**优先权**（第二十四条）：
- 优先乘坐公共交通工具
- 遇交通阻碍时优先通行

**紧急征用权**（第二十五条）：经现场指挥员出示证件，可优先使用或依法征用个人和组织的设备、设施、场地等，任务完成后归还或恢复原状，并支付费用或补偿。

### 6. 义务与纪律

**禁止行为**（第二十九条）：
- 违抗决定和命令、行动消极或临阵脱逃
- 违反规定使用警械、武器
- 非法剥夺、限制他人人身自由
- 体罚、虐待、殴打监管羁押对象
- 滥用职权、徇私舞弊
- 包庇、纵容违法犯罪活动
- 泄露国家秘密、军事秘密

### 7. 保障措施

- **情报信息共享**：中央国家机关、县级以上政府应及时通报社会安全信息、恐怖事件情报、气象水文等信息
- **经费保障**：与经济社会发展相适应
- **执勤保障**：执勤目标单位提供执勤设施、生活设施
- **抚恤优待**：执行任务牺牲、伤残的，按军人抚恤优待规定执行

### 8. 法律责任

| 违法行为 | 法律责任 |
|----------|----------|
| 执行任务中不履行职责或有违纪行为 | 中央军委有关规定给予处分 |
| 侮辱、威胁、围堵、拦截、袭击正在执行任务的武警 | 治安管理处罚 |
| 强行冲闯警戒带、警戒区 | 治安管理处罚 |
| 拒绝或阻碍执行追捕、检查、搜查、救险、警戒等任务 | 治安管理处罚 |
| 非法制造、买卖、持有、使用专用标志、警械装备、证件、印章 | 15日以下拘留或警告，可并处违法所得1-5倍罚款 |
| 构成犯罪 | 依法追究刑事责任 |

## 三、适用要点汇总表

### 1. 刑事诉讼程序要点

| 程序阶段 | 关键时限 | 重要规定 |
|----------|----------|----------|
| 立案 | 应当立即接受报案、控告、举报 | 不属于管辖范围的应先采取紧急措施后移送 |
| 拘留 | 24小时内讯问；24小时内通知家属（除例外） | 公安机关自行决定，无需检察院批准 |
| 逮捕 | 检察院批准或法院决定；公安机关执行 | 7日内作出批准决定，可延长至30日（重大复杂案件） |
| 侦查羁押 | 一般2个月，可延长至7个月（重大复杂） | 可重新计算侦查羁押期限（发现另有重要罪行） |
| 审查起诉 | 1个月+15日；速裁10-15日 | 可退回补充侦查（1个月以内，最多2次） |
| 一审审理 | 2-3个月；简易20日-1.5月；速裁10-15日 | 改变管辖重新计算审理期限 |
| 上诉/抗诉 | 判决10日；裁定5日 | 二审全面审查；上诉不加刑 |
| 死刑复核 | 最高人民法院核准 | 讯问被告人；听取辩护律师意见 |
| 执行 | 死刑7日内执行 | 停止执行须报最高法院裁定 |

### 2. 武警执法与刑事诉讼衔接要点

| 衔接事项 | 法律依据 | 要点 |
|----------|----------|------|
| 武警参与刑事案件 | 《人民武装警察法》第二十条 | 发现正在犯罪、通缉在案、携带危险物品等情形，应及时控制并移交公安机关 |
| 武警协助搜查、扣押 | 《人民武装警察法》第二十一条 | 协助公安机关、国家安全机关执行逮捕、追捕任务时，可协助搜查 |
| 武警使用武器 | 《人民武装警察法》第二十二条 | 依照人民警察使用警械和武器的规定执行 |
| 武警执法监督 | 《人民武装警察法》第四十一条 | 接受中央军委监察委员会、人民政府及有关部门监督 |
| 阻碍武警执行职务 | 《人民武装警察法》第四十四条 | 构成治安管理处罚；构成犯罪追究刑事责任 |

## 四、中华人民共和国引渡法核心要点（2000年）

### 1. 引渡基本原则
- 平等互惠基础进行引渡合作
- 不得损害中华人民共和国的主权、安全和社会公共利益
- 引渡通过外交途径联系，外交部为指定联系机关

### 2. 引渡条件
**应当准予引渡**（同时满足）：
- 引渡请求所指行为依中国法律和请求国法律均构成犯罪
- 为提起刑事诉讼而请求引渡：可判1年以上有期徒刑
- 为执行刑罚而请求引渡：未服完刑期至少6个月

### 3. 应当拒绝引渡的情形
- 中国公民（国籍）
- 已作出生效判决或已终止刑事诉讼程序
- 政治犯罪或已给予受庇护权利
- 可能因种族、宗教、国籍等受到不公正待遇
- 纯属军事犯罪
- 已过追诉时效或已被赦免
- 可能遭受酷刑或不人道待遇
- 缺席判决（除非承诺重新审判）

### 4. 可以拒绝引渡的情形
- 中国有刑事管辖权且正在追诉
- 被请求人年龄、健康等人道主义原因

### 5. 引渡审查程序
| 程序 | 主体 |
|------|------|
| 外交部审查 | 形式审查 |
| 高级人民法院审查 | 实质审查（合议庭3人） |
| 最高人民法院复核 | 最终复核 |
| 国务院决定 | 最终决定（准予引渡） |

### 6. 引渡强制措施
- **引渡拘留**：紧急情况可先行采取，30日+15日延长期
- **引渡逮捕**：高级人民法院决定
- **引渡监视居住**：适用于患有严重疾病、孕妇、哺乳期妇女

### 7. 暂缓引渡与临时引渡
- 暂缓引渡：因其他犯罪正在追诉或执行刑罚
- 临时引渡：不妨碍中国刑事诉讼且请求国保证送回

## 五、中华人民共和国监狱法核心要点（2012修正）

### 1. 监狱性质
- 国家刑罚执行机关
- 执行被判处死刑缓期二年执行、无期徒刑、有期徒刑的罪犯

### 2. 监狱管理体制
| 机关 | 职责 |
|------|------|
| 国务院司法行政部门 | 主管全国监狱工作 |
| 监狱 | 刑罚执行机关 |
| 人民检察院 | 监督监狱执行刑罚是否合法 |

### 3. 刑罚执行程序
| 程序 | 要点 |
|------|------|
| 收监 | 法院送达执行通知书等文件；身体检查；5日内通知家属 |
| 申诉处理 | 检察院或法院应当及时处理；6个月内答复 |
| 监外执行 | 符合条件可暂予监外执行 |
| 减刑假释 | 监狱提出建议；法院1个月内裁定；检察院监督 |
| 释放 | 按期释放并发给释放证明书；公安机关办理户籍 |

### 4. 减刑条件
**应当减刑的重大立功表现**：
1. 阻止他人重大犯罪活动
2. 检举监狱内外重大犯罪活动经查证属实
3. 发明创造或重大技术革新
4. 日常生产生活中舍己救人
5. 抗御自然灾害或排除重大事故中突出表现
6. 对国家和社会有其他重大贡献

### 5. 假释条件
- 执行原判刑期二分之一以上
- 一贯表现好，离开监狱不致再危害社会
- 社区矫正机构负责执行

### 6. 狱政管理
| 管理内容 | 要点 |
|----------|------|
| 分押分管 | 成年男犯/女犯/未成年犯分开关押；女性由女警管理 |
| 警戒 | 武警部队负责武装警戒 |
| 通信会见 | 来往信件须经监狱检查；可会见亲属监护人 |
| 生活卫生 | 国家规定生活标准；医疗保健列入地区卫生防疫计划 |

### 7. 对罪犯权利保障
- 人格不受侮辱
- 人身安全、合法财产不受侵犯
- 辩护、申诉、控告、检举权利不受侵犯
- 获得劳动报酬和劳动保护

## 六、中华人民共和国社区矫正法核心要点（2020年）

### 1. 适用范围
对被判处**管制、宣告缓刑、假释和暂予监外执行**的罪犯依法实行社区矫正

### 2. 矫正原则
- 监督管理与教育帮扶相结合
- 专门机关与社会力量相结合
- 分类管理、个别化矫正

### 3. 社区矫正对象权利
- 人身权利、财产权利和其他权利不受侵犯
- 就业、就学、享受社会保障方面不受歧视
- 申诉、控告、检举权

### 4. 矫正执行
| 程序 | 内容 |
|------|------|
| 决定与接收 | 法院判处时确定执行地；10日内报到 |
| 矫正方案 | 根据个体特征制定有针对性矫正方案 |
| 矫正小组 | 司法所、村居委会、监护人、社工、志愿者等组成 |
| 监督管理 | 报告、会客、外出、迁居、保外就医等规定 |

### 5. 电子定位
适用情形：
1. 违反人民法院禁止令
2. 无正当理由未经批准离开所居住的市、县
3. 拒不按规定报告活动情况被警告
4. 违反监督管理规定被治安管理处罚
5. 拟提请撤销缓刑、假释或暂予监外执行收监

期限：一般不超过3个月，可延长（每次不超3个月）

### 6. 教育帮扶
- 法治、道德教育
- 职业技能培训、就业指导
- 社区资源帮扶
- 社会救助、社会保险、法律援助

### 7. 未成年人特别规定
- 针对性矫正措施
- 矫正小组吸收熟悉未成年人身心特点人员
- 与成年人分别进行
- 复学、升学、就业平等权利

### 8. 解除与终止
| 情形 | 处理 |
|------|------|
| 矫正期满或被赦免 | 发放解除社区矫正证明书 |
| 裁定撤销缓刑、假释 | 社区矫正终止 |
| 决定收监执行 | 社区矫正终止 |
| 社区矫正对象死亡 | 社区矫正终止 |

### 3. 强制措施对比

| 措施 | 决定机关 | 执行机关 | 期限 | 备注 |
|------|----------|----------|------|------|
| 拘传 | 公检法 | 公检法 | 12-24小时 | 不得连续传唤变相拘禁 |
| 取保候审 | 公检法 | 公安机关 | 最长12个月 | 可收取保证金 |
| 监视居住 | 公检法 | 公安机关 | 最长6个月 | 指定居所可折抵刑期 |
| 拘留 | 公安机关 | 公安机关 | 24小时讯问；24小时通知家属 | 特殊情形可不通知 |
| 逮捕 | 检察院批准/法院决定 | 公安机关 | 侦查羁押2-7个月 | 检察院需审查羁押必要性 |

### 4. 证据排除规则

| 证据类型 | 非法方法 | 法律后果 |
|----------|----------|----------|
| 犯罪嫌疑人/被告人供述 | 刑讯逼供等非法方法 | 应当排除 |
| 证人证言、被害人陈述 | 暴力、威胁等非法方法 | 应当排除 |
| 物证、书证 | 程序违法可能严重影响司法公正 | 补正或合理解释；不能则排除 |

### 5. 特别程序适用范围

| 程序类型 | 适用案件 | 关键条件 |
|----------|----------|----------|
| 未成年人附条件不起诉 | 刑法第4、5、6章，可能判1年以下 | 认罪悔罪；检察院决定；考验期6个月-1年 |
| 当事人和解 | 民间纠纷引起的轻刑案件；过失犯罪 | 真诚悔罪；获得被害人谅解；5年内无故意犯罪 |
| 缺席审判 | 贪污贿赂；国安、恐怖（重大）；被告人在境外 | 最高检核准；法院审查决定 |
| 违法所得没收 | 贪污贿赂、恐怖活动等重大犯罪；逃匿1年不能到案或死亡 | 检察院申请；中级法院管辖 |
| 强制医疗 | 暴力行为危害公共安全或公民人身安全；不负刑事责任；可能有继续危害社会可能 | 法院决定；可临时的保护性约束措施 |
