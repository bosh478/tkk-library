## 一、认罪认罚案件听取意见同步录音录像规定

### 1.1 适用范围

人民检察院办理认罪认罚案件，对于检察官围绕量刑建议、程序适用等事项听取犯罪嫌疑人、被告人、辩护人或者值班律师意见、签署具结书活动，应当同步录音录像。

**不包括：** 讯问过程（但讯问与听取意见、签署具结书同时进行的，可以一并录制）

**多次听取意见：** 至少要对量刑建议形成、确认以及最后的具结书签署过程进行同步录音录像

### 1.2 录音录像内容

同步录音录像一般应当包含：

1. 告知犯罪嫌疑人、被告人、辩护人或者值班律师对听取意见过程进行同步录音录像的情况
2. 告知犯罪嫌疑人、被告人诉讼权利义务和认罪认罚法律规定，释明认罪认罚的法律性质和法律后果
3. 告知犯罪嫌疑人、被告人无正当理由反悔的法律后果
4. 告知认定的犯罪事实、罪名、处理意见，提出的量刑建议、程序适用建议并进行说明
5. 检察官听取犯罪嫌疑人、被告人、辩护人或者值班律师意见
6. 根据需要开示证据的情况
7. 犯罪嫌疑人、被告人签署具结书及辩护人或者值班律师见证的情况

### 1.3 录音录像要求

- 客观、全面地反映听取意见的参与人员、听取意见过程
- 画面完整、端正，声音和影像清晰可辨
- 保持完整、连续，不得选择性录制，不得篡改、删改
- 画面起始和结束由检察官宣布
- 保存期限：**十年**

### 1.4 调取使用

- 实行有条件调取使用
- 因人民法院、犯罪嫌疑人、被告人、辩护人或者值班律师对认罪认罚自愿性、真实性、合法性提出异议或疑问，需要查阅的，人民检察院可以出示
- 因案件质量评查、检务督察等工作需要查阅的，应当履行审批手续

## 二、认罪认罚案件量刑建议工作指导意见

### 2.1 量刑建议原则

| 原则 | 内容 |
|------|------|
| 宽严相济 | 根据犯罪具体情况，综合考虑从重、从轻、减轻或免除处罚等情节，做到该宽则宽，当严则严 |
| 依法建议 | 依照刑法、刑事诉讼法及相关司法解释规定提出 |
| 客观公正 | 全面收集、审查有罪、无罪、罪轻、罪重证据 |
| 罪责刑相适应 | 体现从宽同时考虑罪行轻重、刑事责任和社会危险性 |
| 量刑均衡 | 情节基本相同的案件，量刑建议应当保持基本均衡 |

### 2.2 量刑建议类型

**确定刑量刑建议：**
- 一般应当提出确定刑量刑建议
- 应当明确主刑适用刑种、刑期和是否适用缓刑
- 建议判处拘役的，一般应当提出确定刑量刑建议
- 建议判处罚金刑的，应当提出确定的数额

**幅度刑量刑建议：**
- 适用于新类型、不常见犯罪案件，量刑情节复杂的重罪案件等
- 应当严格控制幅度
- 不得兼跨两种以上主刑

| 刑期幅度 | 建议幅度上限 |
|----------|--------------|
| 6个月以上不满1年 | 不超过2个月 |
| 1年以上不满3年 | 不超过6个月 |
| 3年以上不满10年 | 不超过1年 |
| 10年以上 | 不超过2年 |
| 管制 | 不超过3个月 |

### 2.3 从宽幅度

**认罪认罚从宽与自首坦白的比较：**
- 主动认罪认罚优于被动认罪认罚
- 早认罪认罚优于晚认罪认罚
- 彻底认罪认罚优于不彻底认罪认罚
- 稳定认罪认罚优于不稳定认罪认罚
- 认罪认罚的从宽幅度一般**大于仅有坦白**，或虽认罪但不认罚

**从宽幅度限制：** 具有自首、坦白情节同时认罪认罚的，应当在法定刑幅度内给予相对更大的从宽幅度

### 2.4 从严情形

犯罪嫌疑人虽然认罪认罚，但具有下列情形之一的，从严把握从宽幅度或依法不予从宽：

1. 危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织犯罪的首要分子、主犯
2. 犯罪性质和危害后果特别严重、犯罪手段特别残忍、社会影响特别恶劣的
3. 罪行较轻但具有累犯、惯犯等恶劣情节的
4. 性侵等严重侵害未成年人的
5. 其他应当从严把握从宽幅度或不宜从宽的情形

### 2.5 量刑建议提出程序

**听取意见：** 应当告知犯罪嫌疑人及其辩护人/值班律师拟认定的犯罪事实、涉嫌罪名、量刑情节、拟提出的量刑建议及法律依据

**具结书签署：**
- 辩护人应当在场见证，不得绕开辩护人安排值班律师代为见证
- 未成年犯罪嫌疑人签署具结书时，法定代理人应当到场并签字确认

**量刑建议调整：**
- 人民法院认为量刑建议明显不当或异议合理的，应当调整
- 开庭前或休庭期间调整的，应当重新听取意见
- 被告人反悔不再认罪认罚的，应当建议法院不适用认罪认罚从宽制度

## 三、认罪认罚案件监督管理办法

### 3.1 监督内容

| 监督要点 | 内容 |
|----------|------|
| 程序合法性 | 听取意见、具结书签署等程序是否符合规定 |
| 自愿性保障 | 犯罪嫌疑人认罪认罚是否真实自愿 |
| 量刑建议质量 | 量刑建议是否规范、合理 |
| 具结书效力 | 具结书签署后是否有违法撤销、变更情形 |

### 3.2 监督机制

- 检察官联席会议的会商咨询
- 部门负责人审核把关
- 检察长、检察委员会决定重大案件
- 审判阶段对量刑建议的审查监督

## 四、适用要点汇总表

| 要点 | 具体内容 |
|------|----------|
| 录音录像范围 | 量刑建议形成、确认、具结书签署过程 |
| 录音录像保存期限 | 十年 |
| 量刑建议类型 | 一般为确定刑，新类型/复杂案件可为幅度刑 |
| 从宽幅度比较 | 认罪认罚 > 坦白 > 不认罪 |
| 从宽上限 | 根据主动程度、彻底程度、稳定性综合判断 |
| 量刑建议调整 | 法院建议合理应调整，被告人反悔应撤回从宽建议 |
| 不予从宽情形 | 恐怖活动主犯、手段特别残忍、性侵未成年人等 |
