## 一、依法保障律师执业权利的十条意见

### 1.1 保障律师执业权利的基本要求

**总体要求**：
- 依法保障律师执业权利
- 维护律师合法权益
- 规范律师执业行为
- 构建良性互动关系

### 1.2 会见权保障

| 情形 | 保障措施 |
|------|----------|
| 了解案情 | 及时安排会见，不得限制次数和时间 |
| 国家安全类案件 | 依法依规办理，遵守相关保密规定 |
| 会见场所 | 提供符合规定的会见场所 |

### 1.3 阅卷权保障

- 依法保障律师查阅案卷材料的权利
- 提供必要的便利条件
- 复制、摘抄案卷材料

### 1.4 调查取证权保障

- 依法保障律师调查取证权
- 协助律师收集证据
- 核实相关证据材料

### 1.5 辩护权保障

- 认真听取律师意见
- 律师意见应当记入笔录
- 采纳律师意见应当说明理由

### 1.6 执业权利救济

| 救济途径 | 内容 |
|----------|------|
| 申诉控告 | 律师执业权利受到侵害可以申诉控告 |
| 检察机关监督 | 人民检察院依法监督保障律师执业权利 |
| 投诉处理 | 建立投诉处理机制 |

## 二、依法惩治侵害英雄烈士名誉、荣誉违法犯罪的意见

### 2.1 保护对象

英雄烈士：
- 为国家、人民和民族解放事业牺牲的烈士
- 人民英雄、革命烈士
- 其他值得纪念的英烈

### 2.2 违法行为类型

| 行为类型 | 具体表现 |
|----------|----------|
| 侮辱行为 | 恶意诋毁、贬损英雄烈士名誉、荣誉 |
| 诽谤行为 | 编造事实损害英雄烈士名誉、荣誉 |
| 丑化行为 | 歪曲、丑化英雄烈士形象 |
| 否认行为 | 否认、淡化英雄烈士事迹 |
| 传播行为 | 传播损害英雄烈士名誉、荣誉的信息 |

### 2.3 罪名认定

| 罪名 | 适用情形 |
|------|----------|
| **侮辱罪** | 以暴力或其他方法公然侮辱英雄烈士 |
| **诽谤罪** | 捏造事实诽谤英雄烈士 |
| **寻衅滋事罪** | 利用信息网络辱骂、恐吓英雄烈士，情节严重 |
| **损害商业信誉、商品声誉罪** | 针对特定英雄烈士进行商业诋毁 |

### 2.4 公益诉讼

**检察机关提起公益诉讼**：
- 英雄烈士没有近亲属或近亲属无法提起诉讼的
- 人民检察院可以提起民事公益诉讼
- 请求行为人承担停止侵害、恢复名誉、消除影响、赔礼道歉等民事责任

### 2.5 从重处罚情节

- 造成恶劣社会影响
- 严重损害国家形象
- 引发群体性事件的
- 针对重要英雄烈士实施的

|------|----------|
