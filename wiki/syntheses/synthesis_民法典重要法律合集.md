## 一、民法典核心要点

### 1. 民法典概况

《中华人民共和国民法典》于2020年5月28日第十三届全国人民代表大会第三次会议通过，2021年1月1日起施行，共7编、1260条。

| 编章 | 主要内容 |
|------|----------|
| 第一编 总则 | 基本规定、自然人、法人、非法人组织、民事权利、民事法律行为、代理、民事责任、诉讼时效、期间计算 |
| 第二编 物权 | 通则、所有权、用益物权、担保物权、占有 |
| 第三编 合同 | 通则、典型合同（买卖、租赁、借款、保证等）、准合同（无因管理、不当得利） |
| 第四编 人格权 | 生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权、个人信息保护 |
| 第五编 婚姻家庭 | 结婚、家庭关系、离婚、收养 |
| 第六编 继承 | 法定继承、遗嘱继承、遗产处理 |
| 第七编 侵权责任 | 损害赔偿、产品责任、交通责任、医疗责任、环境污染责任、高度危险责任、动物损害责任、建筑物责任 |

### 2. 核心基本原则

- **平等原则**（第4条）：民事主体在民事活动中的法律地位一律平等
- **自愿原则**（第5条）：按照自己的意思设立、变更、终止民事法律关系
- **公平原则**（第6条）：合理确定各方的权利和义务
- **诚信原则**（第7条）：不得违反法律，不得违背公序良俗
- **绿色原则**（第9条）：节约资源，保护生态环境

### 3. 民事主体

| 主体类型 | 核心规定 |
|----------|----------|
| 自然人 | 民事权利能力一律平等；民事行为能力分三类（完全民事行为能力、限制民事行为能力、无民事行为能力） |
| 法人 | 营利法人、非营利法人、特别法人；法人以其全部财产独立承担责任 |
| 非法人组织 |  个人独资企业、合伙企业、不具有法人资格的专业服务机构 |

### 4. 物权编要点

- **不动产登记**（第209-214条）：不动产物权设立、变更、转让、消灭经登记发生效力
- **动产交付**（第224-228条）：动产物权交付发生效力
- **抵押权**（第394-422条）：抵押财产范围、抵押合同效力、抵押权实现
- **质权**（第423-442条）：动产质权、权利质权
- **留置权**（第447-457条）：债权人留置合法占有的债务人财产

### 5. 合同编要点

- **合同订立**（第469-495条）：要约、承诺方式；电子合同成立时间
- **合同效力**（第502-545条）：有效、无效、可撤销、效力待定情形
- **合同履行**（第509-534条）：全面履行原则；履行抗辩权；情势变更
- **合同保全**（第535-550条）：债权人代位权、撤销权
- **违约责任**（第577-594条）：继续履行、补救措施、损害赔偿、违约金

### 6. 人格权编要点

- **个人信息保护**（第1034-1039条）：自然人个人信息受保护；处理个人信息应遵循合法、正当、必要原则
- **肖像权**（第1018-1023条）：不得丑化、污损、伪造等方式侵害肖像权
- **隐私权**（第1032-1033条）：自然人享有隐私权；禁止以刺探、侵扰等方式侵害

### 7. 侵权责任编要点

| 责任类型 | 核心规定 |
|----------|----------|
| 产品责任（第1202-1207条） | 生产者承担无过错责任；销售者有过错的连带责任 |
| 机动车交通事故（第1208-1233条） | 机动车交通事故责任认定；保险公司先行赔偿 |
| 医疗损害（第1218-1235条） | 医疗机构及其医务人员过错推定责任 |
| 环境侵权（第1229-1235条） | 污染者无过错责任；惩罚性赔偿 |

## 二、公司法核心要点（2023修订）

### 1. 有限责任公司核心制度

- **设立条件**（第42条）：一个以上五十个以下股东出资设立
- **注册资本认缴制**（第47条）：全体股东认缴出资额由股东按公司章程规定自公司成立之日起五年内缴足
- **股权转让**（第84条）：股东之间可自由转让；向股东以外的人转让应书面通知其他股东，其他股东有优先购买权
- **股东失权制度**（第52条）：股东未按期缴纳出资，经催缴后仍不履行的，可以发出失权通知

### 2. 股份有限公司核心制度

- **设立方式**（第91条）：发起设立或募集设立
- **发起人人数**（第92条）：一人以上二百人以下为发起人，半数以上发起人在境内有住所
- **股份转让**（第157条）：股东持有的股份可以向其他股东或股东以外的人转让
- **董事会**（第120条）：股份有限公司设董事会；上市公司设独立董事

### 3. 公司治理结构

| 机构 | 组成 | 职权 |
|------|------|------|
| 股东会 | 全体股东 | 选举董事监事、审议批准报告、增减资本、合并分立解散、修改章程 |
| 董事会 | 三人以上 | 召集股东会、执行决议、决定经营计划和投资方案、决定经理 |
| 监事会 | 三人以上 | 检查公司财务、监督董事高管行为、提议召开临时股东会 |
| 经理 | 董事会聘任 | 主持日常经营管理工作 |

### 4. 股东权利保护

- **股东知情权**（第57条）：股东有权查阅、复制公司章程、股东名册、会议记录、财务报告；可查阅会计账簿和凭证
- **股东诉讼权**（第189条）：董事高管损害公司利益的，股东可书面请求监事会提起诉讼
- **关联交易规制**（第182-185条）：董事、监事、高管与公司交易需经董事会或股东会决议；关联董事回避表决

## 三、企业破产法核心要点

### 1. 破产程序类型

| 程序 | 适用条件 | 核心特征 |
|------|----------|----------|
| 重整 | 企业法人不能清偿到期债务，有挽救可能 | 可停止行使担保权；债务人可自行管理财产 |
| 和解 | 债务人直接申请 | 债权人对债务人减免部分债务 |
| 破产清算 | 企业法人不能清偿到期债务且资产不足以清偿全部债务 | 公平清理债权债务 |

### 2. 破产申请与受理

- **申请条件**（第2条）：不能清偿到期债务，且资产不足以清偿全部债务或明显缺乏清偿能力
- **管辖**（第3条）：由债务人住所地人民法院管辖
- **受理效力**（第16-21条）：个别清偿无效；保全措施解除；执行程序中止

### 3. 债务人财产

- **财产范围**（第30条）：受理时属于债务人的全部财产及受理后至程序终结前取得的财产
- **撤销行为**（第31-32条）：受理前一年内无偿转让、以不合理价格交易、提供财产担保、提前清偿、放弃债权
- **追回权**（第34条）：因撤销行为取得的财产，管理人有权追回

### 4. 债权清偿顺序

| 顺序 | 债权类型 |
|------|----------|
| 第一顺序 | 所欠职工工资和医疗、伤残补助、抚恤费用、基本养老保险、基本医疗保险费用、法定补偿金 |
| 第二顺序 | 欠缴的社会保险费用和税款 |
| 第三顺序 | 普通破产债权 |

### 5. 重整计划

- **草案提交期限**（第79条）：裁定重整之日起六个月内提交
- **表决通过**（第84条）：同一表决组债权人过半数同意，且所代表债权额占该组债权总额三分之二以上
- **批准条件**（第87条）：各表决组均通过；或者部分未通过但符合法定条件

## 四、保险法核心要点（2015修正）

### 1. 保险合同基本规定

- **保险利益原则**（第12条）：人身保险投保人在订立合同时对被保险人应有保险利益；财产保险被保险人在事故发生时对保险标的应有保险利益
- **最大诚信原则**（第5条）：保险活动当事人行使权利、履行义务应遵循诚实信用原则
- **告知义务**（第16条）：投保人应如实告知；故意或重大过失未履行告知义务的，保险人可解除合同

### 2. 人身保险合同

| 条款 | 内容 |
|------|------|
| 保险利益（第31条） | 本人、配偶、子女、父母、与投保人有抚养赡养关系的近亲属；同意投保的视为有保险利益 |
| 受益人指定（第39条） | 由被保险人或投保人指定；投保人指定须经被保险人同意 |
| 保险合同解除（第15条） | 合同成立后，投保人可解除合同，保险人不得解除（另有规定除外） |
| 诉讼时效（第26条） | 人寿保险以外保险：2年；人寿保险：5年 |

### 3. 财产保险合同

- **保险标的转让**（第49条）：保险标的转让的，受让人承继被保险人权利义务；应通知保险人
- **重复保险**（第56条）：各保险人赔偿金额总和不得超过保险价值
- **代位求偿权**（第60条）：保险人赔偿后可代位行使被保险人对第三者请求赔偿的权利

### 4. 保险公司监管

- **注册资本最低限额**（第69条）：人民币二亿元；必须为实缴货币资本
- **业务范围**（第95条）：人身保险业务、财产保险业务；不得兼营
- **偿付能力监管**（第101条）：保险公司应有与其业务规模相适应的最低偿付能力

## 五、电子商务法核心要点

### 1. 电子商务经营者

- **市场主体登记**（第10条）：电子商务经营者应依法办理登记；个人销售自产农副产品等除外
- **纳税义务**（第11条）：电子商务经营者应依法履行纳税义务并享受税收优惠
- **个人信息保护**（第23条）：应遵守法律、行政法规有关个人信息保护的规定

### 2. 电子商务平台经营者

| 义务 | 内容 |
|------|------|
| 核验义务（第27条） | 核验、登记平台内经营者身份信息，定期核验更新 |
| 信息报送（第28条） | 向市场监督管理部门报送经营者身份信息；向税务部门报送纳税有关信息 |
| 规则公示（第33条） | 在首页显著位置持续公示平台服务协议和交易规则 |
| 知识产权保护（第42-45条） | 知道侵权应采取必要措施；否则与侵权人承担连带责任 |

### 3. 电子合同

- **合同成立时间**（第49条）：用户选择商品或服务并提交订单成功，合同成立（当事人另有约定除外）
- **交付时间**（第51条）：快递物流方式交付的，收货人签收时间为交付时间；在线传输方式交付的，进入指定系统时间为交付时间
- **电子支付**（第53-57条）：支付指令错误应及时采取措施；未经授权的支付由服务提供者承担（用户过错除外）

### 4. 消费者权益保护

- **押金退还**（第21条）：应明示退还方式、程序，不得设置不合理条件
- **先行赔偿责任**（第58条）：消费者可要求平台经营者先行赔偿
- **信用评价**（第39条）：不得删除消费者评价；竞价排名应显著标明"广告"

## 适用要点汇总表

| 法律 | 生效日期 | 核心适用场景 | 关键条文 |
|------|----------|--------------|----------|
| 民法典 | 2021.01.01 | 民商事领域基本法；调整人身关系和财产关系 | 第1-10条基本原则；第209-214条不动产物权登记 |
| 公司法（2023） | 2024.07.01 | 公司设立、治理、股权转让、合并分立 | 第42-84条有限责任公司；第91-162条股份公司 |
| 企业破产法 | 2007.06.01 | 企业不能清偿债务时的重整、和解、清算 | 第2条申请条件；第113条清偿顺序 |
| 保险法 | 2015.04.24 | 保险合同签订、保险公司监管 | 第16条告知义务；第49条保险标的转让 |
| 电子商务法 | 2019.01.01 | 电子商务活动、平台责任、消费者保护 | 第38条平台连带责任；第49条合同成立时间 |

### 实务要点

1. **民法典与单行法的关系**：民法典施行后，《婚姻法》《继承法》《民法通则》《收养法》《担保法》《合同法》《物权法》《侵权责任法》《民法总则》同时废止
2. **公司法修订过渡期**：2024年7月1日前已登记设立的公司，出资期限超过5年的应逐步调整（国务院另行规定除外）
3. **破产程序选择**：优先考虑重整程序；和解程序可由债务人直接申请；破产清算是最后手段
4. **保险合同解除**：投保人享有随时解除权；但人身保险合同已交足两年以上保险费的，保险人不得解除
5. **电商平台审核义务**：对关系消费者生命健康的商品或服务，平台对经营者资质资格未尽审核义务的，承担相应责任
