## 一、公诉人出庭概述

### 1.1 出庭任务

1. **代表国家指控、揭露和证实犯罪**
2. **对法庭审判活动是否合法进行监督**
3. **维护诉讼参与人的合法权利**
4. **结合案情进行法治宣传和教育**

### 1.2 基本原则

1. **系统性原则**：出庭各环节之间的关联
2. **关联性原则**：证据之间的关联、证据与事实之间的关联、事实与法律之间的关联
3. **规范性原则**
4. **充分性原则**
5. **客观性原则**

### 1.3 基本要求

1. **扎实的庭前准备**
   - 积极引导侦查，提高案件质量
   - 细致审查证据，强化证明效力
   - 发挥庭前会议作用

2. **精心制作出庭预案**
   - 探求行之有效的讯问方式
   - 做好相关人员出庭准备
   - 科学合理布局示证体系
   - 全面准确预测辩护观点
   - 准备细致透彻的公诉意见
   - 提出客观公正的量刑建议

3. **采用适当的方法和技巧**
   - 层次清晰地开展法庭调查
   - 扎实有效地进行法庭辩论

4. **展示良好公诉形象**
5. **稳定沉着应变，从容化解危机**

## 二、庭前准备

### 2.1 庭前准备概述

**主要工作**：
1. 进一步熟悉案情，掌握证据情况
2. 深入研究与本案有关的法律政策问题
3. 充实审判中可能涉及的专业知识
4. 拟定讯问、询问、举证质证计划
5. 拟定证据合法性争议的应对方案
6. 拟定公诉意见，准备辩论提纲
7. 做好证人保护等相关准备

### 2.2 庭前会议

**启动与参与**：
- 法院决定召开
- 公诉人参与

**基本职能**：
- 管辖权异议
- 回避申请
- 非法证据排除
- 证据开示
- 争点整理

**常见问题及应对**：
- 被告人提出更换公诉人（依据回避理由）
- 被告人要求移送全部同步录音录像
- 管辖权异议
- 合议庭组成人员应回避而未回避
- 辩护人资格异议
- 指定辩护人未指定

## 三、法庭讯问

### 3.1 讯问的目标定位

通过讯问核实案件事实，完善证据体系

### 3.2 讯问原则

1. 针对性
2. 合法性
3. 有效性

### 3.3 常见问题及应对

| 情形 | 应对要点 |
|------|----------|
| 被告人当庭翻供否认犯罪 | 核查翻供原因，运用其他证据佐证 |
| 被告人以未看笔录为由翻供 | 说明笔录制作过程合法 |
| 被告人拒绝回答 | 宣布如实回答的法律义务 |
| 被告人对提问答非所问 | 适时引导，归纳要点 |
| 被告人随意打断公诉人发问 | 请求法庭维持秩序 |
| 共同犯罪被告交头接耳 | 请求法庭警告或隔离 |
| 辩护人发问不当而法庭不采纳 | 记录在案，保留异议 |
| 聋哑/少数民族被告人翻译问题 | 核实翻译资质，必要时申请更换 |
| 认罪认罚被告人当庭翻供 | 核实自愿性，说明后果 |
| 被告人当庭提出新量刑情节 | 审查真实性，依法处理 |

## 四、举证质证

### 4.1 举证原则

1. **合法性**：程序合法
2. **关联性**：与待证事实相关
3. **系统性**：逻辑清晰
4. **有效性**：证明力强

### 4.2 质证原则

1. **针对性**：直击证据弱点
2. **专业性**：法理阐述
3. **策略性**：把握时机

### 4.3 常见问题及应对

| 情形 | 应对要点 |
|------|----------|
| 被告人反对分组举证 | 说明分组示证的法律依据 |
| 被告人要求重新出示证据 | 说明已依法出示 |
| 公诉机关未全部移送证据 | 说明依法移送情况 |
| 被告人提出新证据 | 审查是否属于新证据 |
| 被告人要求出示无罪证据 | 说明举证范围 |
| 被告人质疑供述完整性 | 说明取证合法性 |
| 申请调取新证据 | 说明证据关联性 |
| 物证收集不符合法定程序 | 补正或说明合理性 |
| 当庭提出精神病鉴定 | 审查申请理由 |
| 被告人质疑证据复印件 | 说明证据复制规定 |

### 4.4 非法证据排除应对

**情形**：被告人提出供述系刑讯逼供取得

**应对**：
1. 说明取证程序合法
2. 提供同步录音录像
3. 说明不存在刑讯逼供
4. 援引合法性规定

## 五、法庭辩论

### 5.1 公诉意见

**内容**：
1. 案件事实认定
2. 证据采信情况
3. 法律适用
4. 量刑建议
5. 法治教育

### 5.2 辩论技巧

1. **逻辑严密**：论证推理清晰
2. **法理充分**：引用法律准确
3. **临场应变**：应对突发情况
4. **文明用语**：尊重对方
