## ❓ 常见问题

> 问：公诉人出庭的基本原则是什么？
> 答：五项原则——系统性原则、关联性原则、规范性原则、充分性原则、客观性原则。

> 问：被告人当庭翻供如何应对？
> 答：区分翻供原因——以刑讯逼供为由翻供的，需证明取证合法性；以未看笔录为由翻供的，出示同步录音录像；认罪认罚案件翻供的，建议法院调整量刑建议。

> 问：公诉人举证的基本方法是什么？
> 答：分组举证、一证一质、多媒体示证相结合，根据案件类型选择不同举证策略。

## 章节结构

### 第一编：公诉人出庭概述

**第一章 公诉人出庭的目的与任务**
1. 代表国家指控、揭露和证实犯罪
2. 对法庭审判活动是否合法进行监督
3. 维护诉讼参与人的合法权利
4. 结合案情进行法治宣传和教育

**第二章 公诉人出庭的基本原则**

| 原则 | 说明 |
|------|------|
| 系统性原则 | 出庭各环节形成有机整体 |
| 关联性原则 | 证据之间、证据与事实之间、事实与法律之间的关联 |
| 规范性原则 | 出庭行为符合规范要求 |
| 充分性原则 | 举证质证充分到位 |
| 客观性原则 | 客观公正，不偏不倚 |

**第三章 公诉人出庭的基本要求**

**扎实的庭前准备**：
- 积极引导侦查，提高案件质量
- 细致审查证据，强化证明效力
- 发挥庭前会议作用

**精心制作出庭预案**：
- 探求行之有效的讯问方式
- 做好相关人员出庭准备
- 科学合理布局示证体系
- 全面准确预测辩护观点
- 准备细致透彻的公诉意见
- 提出客观公正的量刑建议

**展示良好公诉形象**：
- 抬头发言，规范举止
- 语言感染力
- 稳定沉着应变

**第四章 公诉人出庭的常见问题**
1. 发言时不抬头作规范
2. 宣读起诉书时不起立
3. 发言缺乏感染力
4. 遇突发情况进退失据
5. 庭审发言激化矛盾
6. 庭审时消极懈怠
7. 庭后需要补强
8. 出庭拖沓冗长

## 核心内容

### 一、公诉人出庭的基本原则

**五项原则**：

| 原则 | 内涵 |
|------|------|
| 系统性 | 出庭各环节（讯问、举证、辩论）相互衔接形成整体 |
| 关联性 | 证据之间、证据与事实之间、事实与法律之间的逻辑关联 |
| 规范性 | 出庭行为符合法律规定和职业规范 |
| 充分性 | 举证质证充分到位，不留漏洞 |
| 客观性 | 兼顾有罪证据和无罪证据，客观公正 |

### 二、庭前准备的核心要素

**六项准备**：
1. 熟悉案情，掌握证据
2. 研究法律政策问题
3. 充实专业知识
4. 拟定讯问、举证计划
5. 准备证据合法性证明
6. 拟定公诉意见和辩论提纲

### 三、讯问被告人的方法

**按案件类型分类**：

| 案件类型 | 讯问方法 |
|----------|----------|
| 一罪名一被告人 | 按犯罪构成要件逐一讯问 |
| 多罪名一被告人 | 按罪名分别讯问 |
| 共同犯罪一罪名 | 按被告人分别讯问 |
| 共同犯罪多罪名 | 按罪名和被告人交叉讯问 |

### 四、举证质证的方法策略

**举证方法**：
- 分组举证：按证据种类或证明事项分组
- 一证一质：每组证据质证后再出示下一组
- 多媒体示证：运用科技手段增强示证效果

**质证方法**：
- 围绕三性（真实性、合法性、关联性）发表意见
- 对辩护方证据提出有针对性的质疑
- 注意证据的综合分析

### 五、常见翻供的应对策略

| 翻供理由 | 应对方法 |
|----------|----------|
| 刑讯逼供 | 证明取证合法性（同步录音录像、体检记录等） |
| 未看笔录 | 出示同步录音录像证明供述自愿性 |
| 指供诱供 | 证明讯问程序合法 |
| 认罪认罚后翻供 | 调整量刑建议，说明认罪认罚的法律后果 |

### 六、认罪认罚案件的特殊处理

**被告人签署具结书后的问题**：
- 当庭翻供：调整量刑建议
- 认为量刑过重：说明量刑建议的依据
- 提出新量刑情节：核实后决定是否调整
- 当庭表示认罪认罚：记录在案，建议从宽处理

### 七、非法证据排除的应对

**应对步骤**：
1. 判断是否属于非法证据排除范围
2. 提供取证合法性证明
3. 申请侦查人员出庭说明
4. 出示同步录音录像
5. 提供其他证据印证

## 实务问答(L4 必填·12 条·4 段式)

### Q1. 公诉人出庭的根本任务是什么?

**答复**:公诉人出庭的根本任务是通过出庭支持公诉,履行法律监督职责,实现「指控犯罪+保障人权+维护法治」三位一体的目标。

**类案指引**:最高检强调,公诉人出庭应从「指控证明犯罪」向「指控证明犯罪+保障人权」并重转变,体现现代司法理念。

**法律依据**:①《刑事诉讼法》第8条(检察院职责)②《人民检察院刑事诉讼规则》

### Q2. 庭前准备应包括哪些核心环节?

**答复**:①阅卷形成「阅卷看法」;②拟制出庭公诉意见;③制定庭审预案;④与当事人、辩护律师沟通;⑤开展庭前会议(必要时);⑥检查出庭材料与设备。

**类案指引**:陈增宝法官在《法官如何阅卷》中强调,公诉人与法官在庭前准备上应「换位思考」,理解对方关注点。

**法律依据**:①《人民检察院刑事诉讼规则》第二章②《最高人民检察院关于公诉人出庭若干问题的规定》

### Q3. 庭前会议有何作用?如何发挥?

**答复**:庭前会议作用:①明确争议焦点;②解决程序性问题;③促成证据展示;④协商认罪认罚;⑤提高庭审效率。发挥方式——主动申请、积极参与、有效沟通。

**类案指引**:最高检强调,庭前会议是「庭审准备的关键环节」,公诉人应「会开、善用」庭前会议。

**法律依据**:①《刑事诉讼法》第187条第2款②《最高人民法院关于适用<刑事诉讼法>的解释》

### Q4. 讯问被告人的有效方式有哪些?

**答复**:①针对性讯问(围绕争议焦点);②渐进式讯问(由浅入深);③矛盾揭露式讯问(针对翻供);④证据印证式讯问(结合证据);⑤心理突破式讯问(根据被告心理)。

**类案指引**:陈增宝法官《法官如何庭审》中强调,公诉人讯问应避免「诱导性」,注重「实效性」。

**法律依据**:①《刑事诉讼法》第190条②《人民检察院刑事诉讼规则》

### Q5. 法庭辩论应避免哪些操作误区?

**答复**:①偏离焦点(辩论跑题);②重复质证(重复举证内容);③情绪化(与辩护人争吵);④无证据支持(空泛辩论);⑤超时(辩论时间过长)。

**类案指引**:陈增宝法官在《法官如何庭审》中指出,法庭辩论偏离焦点是常见问题,法官应及时引导。

**法律依据**:①《刑事诉讼法》第198条②《人民检察院刑事诉讼规则》

### Q6. 如何提高法庭辩论的质效?

**答复**:①紧扣争议焦点;②论点鲜明(罪与非罪、此罪彼罪、量刑轻重);③论据充分(法律+证据+逻辑);④语言精练;⑤预判反驳(预判辩护人观点并预先回应);⑥灵活应变(应对突发情况)。

**类案指引**:最高检强调,法庭辩论应从「质效」角度,实现「指控有力、答辩有据、说理充分」。

**法律依据**:①《刑事诉讼法》第198条②《人民检察院刑事诉讼规则》

### Q7. 认罪认罚从宽制度中,公诉人应注意什么?

**答复**:①审查认罪自愿性(是否真心认罪);②审查认罪明知性(是否理解认罪后果);③审查认罪真实性(是否如实供述);④提出精准量刑建议;⑤加强法律监督。

**类案指引**:认罪认罚从宽制度是 2018 年《刑事诉讼法》修改的重大制度,适用率逐年提升,2023 年已超 85%。

**法律依据**:①《刑事诉讼法》第15条②《人民检察院刑事诉讼规则》③两高三部《关于适用认罪认罚从宽制度的指导意见》

### Q8. 网络犯罪案件的举证质证有何特殊问题?

**答复**:①电子数据取证(合法性、真实性、关联性);②网络空间与现实空间的对应;③海量数据的筛选;④技术鉴定的运用;⑤跨境取证的复杂性。

**类案指引**:近年来网络犯罪案件激增,电子数据举证质证成为新挑战,最高检发布多个指导案例(如「帮助信息网络犯罪活动罪」)。

**法律依据**:①《刑事诉讼法》第50条②《最高人民法院、最高人民检察院、公安部关于办理刑事案件收集提取和审查判断电子数据若干问题的规定》③《刑法》第287条之二(帮信罪)

### Q9. 公诉人出庭的职业礼仪规范有哪些?

**答复**:①着装规范(着检察服或正装);②仪表端庄;③语言文明(规范法言法语);④行为得体(尊重法庭、尊重当事人);⑤准时出庭;⑥遵守法庭纪律。

**类案指引**:陈增宝法官在《法官如何庭审》中强调,公诉人应保持「等腰正三角」中「控方」位置,体现国家公诉人的职业形象。

**法律依据**:①《人民检察院检察人员着装管理规定》②《人民法院法庭规则》

### Q10. 简易程序案件中,公诉人如何出庭?

**答复**:①审查是否符合简易程序条件;②出庭支持公诉(可简化);③对量刑建议重点说明;④对程序适用提出意见;⑤加强法律监督。

**类案指引**:简易程序适用于「案件事实清楚、证据充分、被告人认罪、可能判处三年以下有期徒刑」的案件,2023 年适用率约 50%。

**法律依据**:①《刑事诉讼法》第214-222条②《最高人民法院关于适用<刑事诉讼法>的解释》

### Q11. 被告人翻供时,公诉人如何应对?

**答复**:①冷静分析翻供原因(记忆偏差 / 外部压力 / 真正无罪);②针对性讯问(围绕矛盾点);③出示证据(原始证据、印证证据);④申请证人/鉴定人出庭;⑤综合全案证据,依法履行指控。

**类案指引**:陈增宝法官在《法官如何庭审》中强调,翻供案件需「全案证据综合判断」,公诉人应加强举证质证。

**法律依据**:①《刑事诉讼法》第55条②《人民检察院刑事诉讼规则》

### Q12. 二审出庭与一审出庭有何区别?

**答复**:①审查重点不同(一审查事实,二审重法律适用+审查一审);②举证质证范围不同(可补充新证据);③辩论重点不同(一审全面辩论,二审围绕上诉理由);④法律监督重点不同(重点监督一审裁判)。

**类案指引**:二审出庭是「对一审的检验」,公诉人应重点关注一审是否存在程序违法、证据不足、法律适用错误等问题。

**法律依据**:①《刑事诉讼法》第234条②《人民检察院刑事诉讼规则》
