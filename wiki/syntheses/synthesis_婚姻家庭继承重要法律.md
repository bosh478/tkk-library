# 婚姻家庭继承重要法律核心要点

## 一、婚姻家庭编核心要点（民法典第五编）

### 1. 结婚制度

| 要点 | 内容 |
|------|------|
| 法定婚龄 | 男不得早于二十二周岁，女不得早于二十周岁 |
| 结婚条件 | 完全民事行为能力、双方自愿、非近亲属、无重婚、非禁止结婚的疾病 |
| 无效婚姻 | 重婚、近亲属结婚、婚前患有重大疾病未如实告知 |
| 可撤销婚姻 | 因胁迫结婚、婚前隐瞒重大疾病 |

**《民法典》第1049-1054条**

### 2. 夫妻财产制度

**夫妻共同财产范围（第1062条）：**
- 工资、奖金、劳务报酬
- 生产、经营、投资的收益
- 知识产权的收益
- 继承或受赠所得财产（遗嘱或赠与合同确定归一方的除外）
- 其他应当归共同所有的财产

**夫妻一方个人财产（第1063条）：**
- 一方婚前财产
- 因人身损害获得的赔偿或补偿
- 遗嘱或赠与合同确定只归一方的财产
- 一方专用的生活用品
- 其他应当归一方的财产

**夫妻财产约定（第1065条）：**
- 约定采用书面形式
- 可以约定婚姻关系存续期间所得财产归各自所有、共同所有或部分各自所有、部分共同所有
- 对第三人知情时，第三人可主张按约定处理

### 3. 家庭关系

**夫妻相互义务：**
- 互相扶养义务（第1059条）
- 互相继承遗产权利（第1061条）
- 忠实义务（第1043条）

**父母子女关系（第1067-1075条）：**
- 父母对子女有抚养、教育和保护的义务
- 成年子女对父母有赡养、扶助和保护的义务
- 子女（包括婚生子女、非婚生子女、养子女、有抚养关系的继子女）适用同等规定

**抚养费/赡养费要点：**
- 抚养费包括生活费、教育费、医疗费等（第1067条）
- 有固定收入的，抚养费按月总收入20%-30%给付
- 抚养费给付至子女18周岁止（16周岁以上以劳动收入为主要生活来源者可停止）

### 4. 离婚制度

**协议离婚（第1076-1077条）：**
- 双方自愿离婚
- 签订书面离婚协议
- 亲自到婚姻登记机关申请
- 三十日冷静期

**诉讼离婚（第1079条）：**
- 感情确已破裂，调解无效，应准予离婚
- 法定情形：重婚、家庭暴力、赌博吸毒、感情分居满二年等
- 被宣告失踪，另一方起诉离婚，应准予离婚

**离婚时财产分割（第1087-1088条）：**
- 协议优先
- 协议不成，由法院根据财产具体情况判决
- 照顾子女、女方和无过错方权益

**离婚损害赔偿（第1091条）：**
- 重婚、与他人同居、家庭暴力、虐待遗弃家庭成员、重大过错
- 无过错方有权请求损害赔偿

### 5. 收养制度（第1095-1118条）

**收养条件：**
- 收养人无子女或只有一名子女
- 有抚养、教育和保护被收养人的能力
- 未患有在医学上认为不应当收养子女的疾病
- 年满三十周岁
- 无不利于被收养人健康成长的违法犯罪记录

**收养程序：**
- 向县级以上人民政府民政部门登记
- 收养关系自登记之日起成立

**收养效力：**
- 养子女与养父母及其近亲属间的权利义务，适用亲生父母子女关系规定
- 养子女与生父母及其他近亲属间的权利义务消除

## 二、继承编核心要点（民法典第六编）

### 1. 一般规定（第1120-1123条）

**继承权保护（第1120条）：**
- 国家保护自然人的继承权
- 继承权不得被非法剥夺或限制

**继承开始时间：**
- 继承从被继承人生理死亡或被宣告死亡时开始
- 宣告死亡的，以判决确定的死亡日期为继承开始时间

**遗产范围：**
- 自然人死亡时遗留的个人合法财产
- 法律允许继承的财产权利

### 2. 法定继承（第1124-1132条）

**法定继承人范围及顺序：**

| 顺序 | 继承人 |
|------|--------|
| 第一顺序 | 配偶、子女、父母 |
| 第二顺序 | 兄弟姐妹、祖父母、外祖父母 |

- 子女包括：婚生子女、非婚生子女、养子女、有扶养关系的继子女
- 父母包括：生父母、养父母、有扶养关系的继父母
- 兄弟姐妹包括：同父母兄弟姐妹、同父异母或同母异父兄弟姐妹、养兄弟姐妹、有扶养关系的继兄弟姐妹

**丧偶儿媳/女婿：**
- 对公婆、岳父母尽了主要赡养义务的，作为第一顺序继承人
- 不影响其子女的代位继承

**遗产分配原则（第1130条）：**
- 同一顺序继承人一般均等
- 对被继承人尽了主要扶养义务或与被继承人共同生活的，可以多分
- 有扶养能力和条件不尽义务的，可以少分或不分

### 3. 遗嘱继承和遗赠（第1133-1143条）

**遗嘱形式：**
- 自书遗嘱：亲笔书写，签名，注明年、月、日
- 代书遗嘱：两个以上见证人
- 打印遗嘱：两个以上见证人
- 录音录像遗嘱：两个以上见证人
- 口头遗嘱：危急情况，两个以上见证人

**遗嘱见证人资格限制：**
- 无民事行为能力人或限制民事行为能力人
- 继承人、受遗赠人及其债权人、债务人、合伙人
- 与继承人、受遗赠人有利害关系的人

**必留份制度（第1141条）：**
- 遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产份额

**遗赠扶养协议（第1158条）：**
- 自然人可以与继承人以外的组织或个人签订遗赠扶养协议
- 该组织或个人承担生养死葬义务，享受遗赠

### 4. 遗产处理（第1144-1163条）

**遗产管理人（第1145条）：**
- 继承开始后，遗嘱执行人为遗产管理人
- 无遗嘱执行人的，由继承人推选；推选不成的，由继承人共同担任
- 继承人均放弃继承或无继承人的，由死者生前住所地的民政部门或村委会担任

**遗产分割原则：**
- 有约定的按约定
- 有利于生产和生活需要
- 不损害遗产效用
- 各继承人份额一般均等

**债务清偿（第1161条）：**
- 继承人以所得遗产实际价值为限清偿被继承人债务
- 超过遗产实际价值的，继承人自愿偿还的不在此限
- 继承人放弃继承的，不承担清偿责任

## 三、司法解释重要规定

### 婚姻家庭编解释（一）要点

| 条文 | 要点 |
|------|------|
| 第5条 | 彩礼返还情形：未登记、登记未共同生活、给付导致生活困难 |
| 第24条 | 知识产权收益指婚姻存续期间实际取得或明确可取得的财产性收益 |
| 第25条 | 住房公积金、住房补贴、养老金可认定为夫妻共同财产 |
| 第26条 | 个人财产婚后收益：孳息和自然增值属个人财产，其他为共同财产 |
| 第49条 | 抚养费比例：有固定收入者，月总收入20%-30%，两个以上子女可提高至50% |
| 第86条 | 离婚损害赔偿包括物质损害和精神损害 |

### 继承编解释（一）要点

| 条文 | 要点 |
|------|------|
| 第1条 | 继承从被继承人生理死亡或被宣告死亡时开始 |
| 第14条 | 代位继承人不受辈数限制 |
| 第25条 | 未保留缺乏劳动能力又无生活来源继承人份额的遗嘱部分无效 |
| 第27条 | 遗书处分死后财产，有本人签名和日期，可按自书遗嘱对待 |
| 第40条 | 遗赠扶养协议解除：无正当理由不履行的，不能享有受遗赠权利 |

## 五、实务要点

### 1. 婚姻家庭案件

1. **彩礼返还**：未登记应返还；登记但未共同生活应返还；给付导致生活困难应返还（以离婚为条件）
2. **房产分割**：婚前支付首付款、婚后共同还贷的，婚后共同还贷部分及对应增值为共同财产
3. **抚养费调整**：可依据实际情况请求增加或降低
4. **忠诚协议**：夫妻间忠诚协议单独起诉不予受理

### 2. 继承案件

1. **继承权丧失**：虐待被继承人、伪造篡改遗嘱、杀害被继承人等
2. **代位继承**：被继承人子女先于死亡的，其直系晚辈血亲可代位继承
3. **遗嘱效力**：无民事行为能力人或限制行为能力人所立遗嘱无效；须有两个见证人的遗嘱，见证人资格受限
4. **遗产分割**：有利于生产和生活需要，不损害遗产效用
