## 概述

《刑事审判精要：法官裁判思维与进路》由刘静坤主编，全国各地资深法官编写，2025年法律出版社出版。本书聚焦刑事审判方法论，系统阐述了刑事审判的理念、原则与方法，是法官、检察官、律师和法科生的重要参考书目。

## 一、刑事审判的四大理念

### 1.1 程序正当性与独立性

现代刑事诉讼的灵魂在于程序正义。审判程序缺乏正当性或丧失独立性，公正无从谈起。必须彻底摒弃"重实体、轻程序"的陈旧观念。正当程序承载着约束权力、保障人权、彰显正义的独立价值。一份经由正当程序得出的裁判，才具备无可置疑的权威性和公信力。

### 1.2 刑事一体化的系统思维

刑事审判是一项系统工程，不可孤立、割裂地适用法律。需突破刑法、刑事诉讼法、证据法之间的部门法藩篱，实现三者的有机融合与统一适用。定罪量刑（实体法）必须通过正当程序（程序法）来实现，而正当程序的运行又必须建立在证据裁判（证据法）的基础之上。

### 1.3 以审判为中心的诉讼理念

这是我国刑事诉讼制度改革的核心方向。强调以审判为中心，关键在于确保审判在整个刑事诉讼中的决定性地位，保证庭审在查明事实、认定证据、保护诉权、公正裁判中发挥决定性作用。需扭转侦查中心主义理念，推动以审判为中心的刑事诉讼制度落到实处。

### 1.4 审判程序多元化与精细化

科学的审判体系应当是多元化的：从繁简分流的角度，需区分普通程序与简化程序；从审理对象的角度，需区分普通程序与特别程序；从案件性质的角度，需区分刑事程序与附带民事诉讼程序，实现刑民责任的协同解决。

## 二、刑事审判的三大原则

### 2.1 罪刑法定原则

"法无明文规定不为罪，法无明文规定不处罚"。这是刑事审判的金科玉律。针对刑事法网"扩张"、宽泛的"口袋罪"以及刑法解释"泛化"等问题，需要坚持禁止随意入罪、禁止溯及既往、禁止类推解释等要求。罪刑法定原则的松动，意味着出入人罪，这是不可逾越的法治底线。

### 2.2 无罪推定原则

任何人在被法庭依法认定有罪之前，都应当被视为无罪。有罪推定、确证偏见难以根除，疑罪从无难以落实，给案件质量埋下严重隐患。为贯彻无罪推定原则，需要坚持证据裁判，禁止主观臆断；坚持控方证明责任，禁止强迫自证其罪；坚持法定证明标准，禁止疑罪从有、疑罪从轻、疑罪从挂。

### 2.3 程序公正原则

看得见的正义，是审判的理想追求。直接言词、程序参与、控辩平等、及时审判等要求，是审判程序公正性的基本内核。程序公正是审判的基本要求，适用于各类案件、各类程序，不能基于功利考量随意克减诉讼权利，降低程序保障水平。

## 三、刑事审判的方法体系

### 3.1 审判流程框架

刑事审判呈现高度的程式化特点：从立案审查、庭前准备，到法庭审理、作出裁判，这些审判程式构成了环环相扣的精密系统。

| 审判环节 | 要点 |
|---------|------|
| 立案审查 | 审判之门的入口，不能限制追诉权的正当行使，但要确保案件符合审判条件 |
| 庭前准备 | 庭审质效的保障，通过庭前会议解决可能导致庭审中断的程序争议，但不能弱化更不能取代庭审 |
| 法庭审判 | 诉讼的核心环节，通过实质化的庭审，实现查明事实、认定证据、保护诉权、公正裁判的目标 |

### 3.2 案件类型的差异化审理

| 案件类型 | 审理要点 |
|---------|---------|
| 附带民事诉讼案件 | 统筹协调刑事责任与民事赔偿责任的认定 |
| 死刑案件 | 必须适用最严格的证明标准和最审慎的审理程序 |
| 单位犯罪案件 | 准确把握单位意志的认定和责任人的区分 |
| 共同犯罪案件 | 厘清各被告人的地位、作用及罪责 |
| 涉外案件 | 注意管辖权、文书送达及司法协助等特殊程序规定 |

### 3.3 审判要素体系

法官的核心工作围绕以下关键审判要素展开：

1. **证据审查分析**：证据与事实的关系，证据裁判规则
2. **案件事实认定**：事实审查与法律评价的关系
3. **案件裁判**：定罪与量刑的关系
4. **刑罚适用**：刑罚的种类与幅度
5. **涉案财物处理**：对人之诉与对物之诉的关系
