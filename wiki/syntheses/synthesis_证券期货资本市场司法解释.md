## 一、证券市场虚假陈述侵权民事赔偿（法〔2022〕23号）

### （一）案件受理与通报

**通报机制**：
- 人民法院受理案件后，**10个工作日内**向发行人、上市或挂牌公司所在辖区的证监会派出机构通报
- 派出机构接到通报后应当及时向证监会报告

### （二）调查取证协调

**基本原则**：
- 人民法院可以向证监会有关部门或派出机构调查收集证据
- 有利于监管部门履行监管职责
- 有利于查明民事案件事实

**证据规则**：
- 依法向证监会有关部门或派出机构调查收集证据
- 依照民事诉讼法及相关司法解释规定
- 涉及国家秘密、工作秘密、商业秘密和个人隐私的，不得公开质证

### （三）专业问题征求意见

- 人民法院可以就诉争虚假陈述行为违反信息披露义务规定情况
- 损失计算等专业问题征求证监会或相关派出机构、证券交易场所、证券业自律管理组织、投资者保护机构等单位的意见
- 征求意见的时间，**不计入案件审理期限**

### （四）取消前置程序

- 取消行政处罚/刑事判决前置程序
- 人民法院根据辖区实际情况积极开展专家咨询
- 探索专业人士担任人民陪审员
- 证监会派出机构做好相关专家、专业人士担任人民陪审员的推荐等配合工作

## 二、资本市场高质量发展指导意见（法发〔2025〕9号）

### （一）投资者权益保护

**全面保护投资者合法权益**：
- 知情权
- 参与公司治理权
- 获取合理回报权
- 公平参与市场交易权

**优化市场生态**：
- 强化投资者保护意识
- 提高上市公司质量
- 常态化开展证券纠纷代表人诉讼
- 落实民事赔偿责任优先原则

### （二）上市公司质量提升

**重点任务**：
- 依法打击资本违规隐形入股、违法违规"造富"行为
- 发行人关于股东、实际控制人的信息披露及陈述内容应当真实、准确、完整
- 依法支持股东积极行使股东权利
- 支持上市公司并购重组
- 依法支持上市公司退市

### （三）欺诈发行和信息披露造假打击

**"追首恶""打帮凶"并重**：
- 依法严格追究发行人及其控股股东、实际控制人法律责任
- 追究中介机构法律责任
- 追究配合财务造假的第三方（供应商等）法律责任

**追偿权**：
- 发行人被民事追偿后，可向控股股东、实际控制人、董事、监事、高级管理人员等责任主体追偿

### （四）虚假陈述民事赔偿

**损失计算规则**：
- 交易因果关系审查
- 重大性认定
- 故意与重大过失认定
- 损失因果关系认定

**统一规则**：
- "三日一价"认定
- 系统风险和非系统风险计算指标选取
- 损失测算科学性和合理性

### （五）便利投资者维权

**便民措施**：
- 在线立案、举证、调解、庭审
- 人民法院投资者司法保护综合平台
- 表格化、要素式民事起诉状、答辩状示范文本
- "示范判决+平行案件处理"机制

**代表人诉讼**：
- 特别代表人诉讼常态化
- 投资者保护机构50名以上投资者委托可直接提起普通代表人诉讼
- 简化工作流程

### （六）民事赔偿责任优先

- 行政罚没款和刑事罚金制度衔接
- 避免双重处罚
- 涉案财产优先用于民事赔偿
- 确保投资者受损权益得到快速救济

### （七）规范市场参与人行为

**证券期货基金经营机构**：
- 规范关联交易
- 客户利益优先
- 公平对待客户

**私募基金**：
- 管理人忠实勤勉义务
- 基金财产独立
- 维护投资者合法权益

### （八）多层次资本市场

| 市场 | 定位 |
|------|------|
| 主板 | 大盘蓝筹企业 |
| 科创板 | "硬科技"企业 |
| 创业板 | "三创四新"企业 |
| 北交所/新三板 | 创新型中小企业主阵地 |
| 区域性股权市场 | 中小微企业私募股权投融资 |

### （九）纠纷多元化解

**"总对总"在线诉调对接机制**：
- 健全有机衔接、协调联动、高效便民的证券期货纠纷多元化解机制
- 加大立案后委托证券行业专业调解组织调解力度
- 推动"抓前端、治未病"

## 三、上市公司破产重整案件审理纪要

### （一）基本原则

- 市场化、法治化
- 债权人利益平衡
- 维护社会稳定
- 挽救困境企业

### （二）重整申请审查

**申请主体**：
- 债务人
- 债权人
- 出资人

**法院审查**：
- 裁定是否受理
- 指定管理人

### （三）重整计划草案

**内容要求**：
- 债权分类
- 债权调整方案
- 出资人权益调整方案
- 经营方案
- 执行期限

**表决程序**：
- 债权人分组表决
- 出资人组表决
- 法院批准

### （四）职工权益保护

- 优先保护职工债权
- 职工安置方案
- 社会稳定

### （五）股东权益调整

- 股权调整
- 引入战略投资人
- 稀释或让渡股份

### （六）执行与监督

- 管理人执行
- 法院监督
- 债权人监督

| 罪名 | 刑法条文 | 行为类型 |
|------|----------|----------|
| 欺诈发行股票、债券罪 | 第160条 | 发行文件虚假记载 |
| 违规披露/不披露重要信息罪 | 第161条 | 信息披露违法 |
| 擅自设立金融机构罪 | 第174条 | 非法设立机构 |
| 伪造、变造股票/公司/企业债券罪 | 第178条 | 伪造变造债券 |
| 擅自发行股票/公司/企业债券罪 | 第179条 | 擅自发行 |

### （二）投资者保护机制

| 机制 | 内容 |
|------|------|
| 民事赔偿责任优先 | 涉案财产优先用于民事赔偿 |
| 代表人诉讼 | 特别代表人诉讼常态化 |
| 先行赔付 | 便于投资者快速获得赔偿 |
| 在线诉讼 | 便利投资者维权 |

### （三）上市公司破产重整程序

| 阶段 | 主要内容 |
|------|----------|
| 重整申请 | 债务人/债权人/出资人申请 |
| 法院审查受理 | 裁定重整 |
| 重整计划制定 | 债务人制定 |
| 债权人分组表决 | 有财产担保/职工/税款/普通债权 |
| 出资人组表决 | 股东权益调整 |
| 法院批准 | 批准重整计划 |
| 执行重整计划 | 按计划清偿债务 |
