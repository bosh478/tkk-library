## ❓ 常见问题

> 问：案件汇报的基本要求是什么？
> 答：四点——简明扼要、客观全面、重点突出、观点明确。书面汇报要让阅卷笔录成为审查报告草稿，口头汇报要用最简单的语言把案情说清楚。

> 问：合议庭评议中如何防止"合而不议"？
> 答：遵循七项规则——充分讨论、合理提炼归纳、禁止弃权、限定发言顺序、限制复议、禁止结论性简单表态、同时亮出观点（投票）。

> 问：专业法官会议讨论应遵循哪些原则？
> 答：十二项原则——动议中心、主持中立、机会均等、立场明确、发言完整、面对主持、限时限次、一时一件、遵守裁判、文明表达、充分辩论、多数裁决。

## 章节结构

### 引论：以集体讨论为基础的司法决策

**核心命题**：
- 裁判中的"一案多解"现象
- 集体讨论的重要性：从合议制到审委会讨论制
- 讨论规则的程序制约功能
- 司法中人的因素：讨论能力培养

### 第一讲：讨论的品性与构成

**专题一：讨论的普遍性与讨论方法的重要性**
- 讨论无处不在
- 寻求以最短时间达成最佳结果的讨论方法

**专题二：作为决策过程的案件讨论**
- 决策五步骤：
  1. 发现问题
  2. 确立目标
  3. 收集信息
  4. 建构决定
  5. 选择方案

**专题三：案件讨论的形式与种类**
- 合议庭讨论
- 专业法官会议讨论
- 审判委员会讨论

### 第二讲：合议庭的讨论原理与规则

**专题一：群体决策——合议制的灵魂**
- 群体决策的概念和决策形式
- 群体决策的主要优势

**专题二：合议制运行中可能存在的问题**
- 合议庭成员缺乏全程参与
- 成员作用发挥不够：
  - "合而不议"
  - "陪而不审"
  - "一言堂"

**专题三：理想情境中的合议制——走向理性化的群体决策**

**群体决策的心理机制**：
1. 遵循多数决策规则
2. 保证个体有效获取决策信息
3. 促进个体成员克服从众心理
4. 防止被少数人控制与多数人服从
5. 明确各个成员的具体责任

**合议庭评议表决规则的理性构建**：
| 规则 | 说明 |
|------|------|
| 充分讨论 | 每位成员必须发表意见 |
| 合理提炼归纳 | 审判长归纳各方观点 |
| 禁止弃权 | 必须明确表态 |
| 限定发言顺序 | 承办法官先发言，审判长最后发言 |
| 限制复议 | 非法定事由不得复议 |
| 禁止结论性简单表态 | 必须说明理由 |
| 同时亮出观点 | 投票时同时亮票 |

**院庭长阅核制度**：
- 阅核的概念及功能定位
- 阅核的现实意义及制度价值
- 阅核的适用场景和操作原则

### 第三讲：专业法官会议的讨论原理与规则

**专题一：专业法官会议的会议属性**
- 议题的提交
- 会议的召开（最小构成、礼节规范、会议程序）
- 会议的主持（会前准备、出席人数、会议作风、主持姿态）

**专题二：专业法官会议讨论的主要步骤**
- 汇报 → 讨论 → 表决

**专题三：专业法官会议运行中可能存在的问题**
- 议事程序行政化
- 审议程序简单化
- 缺少当事人参与
- 责任追究有待细化
- 会议成果转化不足

**专题四：专业法官会议讨论案件的十二项原则**

| 原则 | 核心要求 |
|------|----------|
| 动议中心原则 | 动议是议事基本单元，一次一个议题 |
| 主持中立原则 | 主持人不参与辩论，保持中立 |
| 机会均等原则 | 经主持人准许发言，申请在先 |
| 立场明确原则 | 先讲态度再讲理由 |
| 发言完整原则 | 原则上不得打断他人发言 |
| 面对主持原则 | 发言面向主持人，禁止直接辩论 |
| 限时限次原则 | 至少发言一次，遵循限时限次 |
| 一时一件原则 | 一次只讨论一个议题 |
| 遵守裁判原则 | 服从主持人裁决 |
| 文明表达原则 | 遵守礼仪规范 |
| 充分辩论原则 | 真理越辩越明 |
| 多数裁决原则 | 过半数表决，特殊案件三分之二 |

### 第四讲：审委会讨论案件的原理与规则

**专题一：审委会的历史沿革及其制度定位**
- 审委会的历史沿革
- 改革历程：一五至四五改革纲要
- 制度定位：
  - 本质是集体决策
  - 经实践检验符合中国国情
  - 在坚持中不断发展完善

**专题二：审委会的会议属性及其议事规则**
- 会议属性
- 议事规则：
  - 汇报：详细案情介绍与问答
  - 讨论：处理意见的审议与辩论
  - 表决：民主集中制的运用
  - 固化：会议纪要、笔录的制作

**专题三：审委会与专业法官会议的异同和衔接**

| 比较维度 | 审委会 | 专业法官会议 |
|----------|--------|-------------|
| 历史渊源 | 历史悠久 | 近年改革产物 |
| 制度定位 | 最高审判组织 | 咨询议事机构 |
| 职能范围 | 讨论决定重大案件 | 讨论法律适用问题 |
| 意见形成规则 | 民主集中制 | 协商讨论 |
| 意见效力 | 具有约束力 | 参考性质 |

**衔接机制**：专业法官会议讨论后认为需提交审委会的，报请审委会讨论

**专题四：审委会运行中可能存在的问题与改革方向**
- "宏观指导"职能有待强化
- "议事规则"有待健全
- "直接审案"有待探索
- "审理者裁判，裁判者负责"有待厘清

**专题五：审委会秘书的角色定位与职业规范**
- 审委会办公室的主要职责
- 审委会秘书的职业规范：依法办事、按政策办事、按组织纪律办事

### 第五讲：案件汇报

**专题一：汇报的原理**
- 汇报作为双向信息沟通过程
- 影响信息沟通的六个要素：空间距离、背景参考、人的因素、物的因素、途径、反馈

**专题二：案件汇报的基本要求**

**书面汇报**：
- 让阅卷笔录成为审查报告草稿
- 事实证据排列符合认知规律
- 站在"听众"立场撰写报告

**口头汇报**：
1. 开场白的设定
2. 被告人基本情况
3. 案件侦破及抓获经过
4. 案件事实及证据问题
5. 控辩双方争议及分析意见
6. 存在问题及所做工作

**专题三：案件汇报的基本方法**
- 顺叙汇报法
- 倒叙汇报法
- 人物关系汇报法
- 逐罪汇报法
- 逐次汇报法
- 表格式汇报法

**专题四：几种典型案件的汇报技巧**
- 命案的汇报技巧
- 经济犯罪案件的汇报技巧
- 毒品犯罪案件的汇报技巧
- 事实证据分歧案件的汇报技巧
- 法律适用分歧案件的汇报技巧
- 量刑分歧案件的汇报技巧

### 第六讲：案件讨论

**专题一：讨论的一般方法**
- 提出有效问题的方法：策略性提问、开放式问题、焦点问题自由讨论
- 积极倾听的方法：提问与反馈、重复转述、各抒己见
- 针对书面材料讨论的方法
- 让讨论民主化的方法

**专题二：案件讨论的步骤与方法（以合议庭评议为重点）**
- 一人多次犯一罪：逐次评议法/逐段评议法
- 一人多次犯数罪：逐罪评议法/逐次评议法
- 多人多次犯一罪：逐人评议法/逐人逐次评议法
- 多人多次犯数罪：分别评议法

**专题三：几类典型案件的讨论技巧**
- 命案：整体评议法/重点评议法
- 经济犯罪：原貌评议法/局部评议法
- 毒品犯罪：逐次评议法/逐人评议法

## 核心内容

### 一、群体决策的理论基础

合议制的灵魂在于群体决策。群体决策的优势：
- 信息汇集更全面
- 视角更多元
- 决策更理性
- 责任更分散

但群体决策也存在风险：
- 从众心理
- 群体极化
- 责任分散
- "一言堂"

### 二、三级讨论机制的衔接

```
合议庭讨论（一审组织）
    ↓ 争议案件
专业法官会议（咨询议事）
    ↓ 重大疑难
审判委员会（最高审判组织）
```

### 三、案件汇报的核心技能

**书面汇报要点**：
- 阅卷笔录→审查报告→汇报材料的转化
- 事实证据排列要符合认知规律（先客观后主观，先主要后次要）
- 站在听众立场，预判问题

**口头汇报要点**：
- 开场白简明扼要
- 先说结论再展开
- 重点突出，避免面面俱到
- 准备应答预案

### 四、议事规则的实践价值

十二项原则的内在逻辑：
- **程序公正**：主持中立、机会均等、发言完整
- **效率保障**：限时限次、一时一件、动议中心
- **决策质量**：充分辩论、立场明确、多数裁决
- **文明秩序**：文明表达、面对主持、遵守裁判
