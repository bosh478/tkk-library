## ❓ 常见问题

> 问：案件汇报的基本要求是什么？
> 答：四点——简明扼要、客观全面、重点突出、观点明确。书面汇报要让阅卷笔录成为审查报告草稿，口头汇报要用最简单的语言把案情说清楚。

> 问：合议庭评议中如何防止"合而不议"？
> 答：遵循七项规则——充分讨论、合理提炼归纳、禁止弃权、限定发言顺序、限制复议、禁止结论性简单表态、同时亮出观点（投票）。

> 问：专业法官会议讨论应遵循哪些原则？
> 答：十二项原则——动议中心、主持中立、机会均等、立场明确、发言完整、面对主持、限时限次、一时一件、遵守裁判、文明表达、充分辩论、多数裁决。

1. 遵循多数决策规则
2. 保证个体有效获取决策信息
3. 促进个体成员克服从众心理
4. 防止被少数人控制与多数人服从
5. 明确各个成员的具体责任

| 禁止结论性简单表态 | 必须说明理由 |
| 同时亮出观点 | 投票时同时亮票 |

**专题一：专业法官会议的会议属性**
- 议题的提交
- 会议的召开（最小构成、礼节规范、会议程序）

**专题二：专业法官会议讨论的主要步骤**
- 汇报 → 讨论 → 表决

**专题三：专业法官会议运行中可能存在的问题**
- 议事程序行政化
- 审议程序简单化
- 缺少当事人参与
- 责任追究有待细化
- 会议成果转化不足

**专题四：专业法官会议讨论案件的十二项原则**

| 原则 | 核心要求 |
|------|----------|
| 动议中心原则 | 动议是议事基本单元，一次一个议题 |
| 主持中立原则 | 主持人不参与辩论，保持中立 |
| 机会均等原则 | 经主持人准许发言，申请在先 |
| 立场明确原则 | 先讲态度再讲理由 |
| 发言完整原则 | 原则上不得打断他人发言 |
| 面对主持原则 | 发言面向主持人，禁止直接辩论 |
| 限时限次原则 | 至少发言一次，遵循限时限次 |
| 一时一件原则 | 一次只讨论一个议题 |
| 遵守裁判原则 | 服从主持人裁决 |
| 文明表达原则 | 遵守礼仪规范 |
| 充分辩论原则 | 真理越辩越明 |
| 多数裁决原则 | 过半数表决，特殊案件三分之二 |

## 核心内容

### 一、群体决策的理论基础

合议制的灵魂在于群体决策。群体决策的优势：
- 信息汇集更全面
- 视角更多元
- 决策更理性
- 责任更分散

但群体决策也存在风险：
- 从众心理
- 群体极化
- 责任分散
- "一言堂"

### 二、三级讨论机制的衔接

```
合议庭讨论（一审组织）
    ↓ 争议案件
专业法官会议（咨询议事）
    ↓ 重大疑难
审判委员会（最高审判组织）
```

### 三、案件汇报的核心技能

**书面汇报要点**：
- 阅卷笔录→审查报告→汇报材料的转化
- 事实证据排列要符合认知规律（先客观后主观，先主要后次要）
- 站在听众立场，预判问题

**口头汇报要点**：
- 开场白简明扼要
- 先说结论再展开
- 重点突出，避免面面俱到
- 准备应答预案

### 四、议事规则的实践价值

十二项原则的内在逻辑：
- **程序公正**：主持中立、机会均等、发言完整
- **效率保障**：限时限次、一时一件、动议中心
- **决策质量**：充分辩论、立场明确、多数裁决
- **文明秩序**：文明表达、面对主持、遵守裁判

## 实务问答(L4 必填·12 条·4 段式)

### Q1. 何为「一案多解」现象?

**答复**:同一案件因法律解释、事实认定、价值判断的不同,可能存在多个合理解释。「一案多解」是司法实践中的客观现象,反映了法律适用的复杂性。

**类案指引**:陈增宝法官强调,「一案多解」的存在恰恰说明集体讨论的必要性——通过合议制、专业法官会议、审委会等机制,寻求最佳解释。

**法律依据**:①《人民法院组织法》②《最高人民法院关于人民法院合议庭工作的若干规定》

### Q2. 司法决策为什么要引入「集体讨论」?

**答复**:集体讨论是司法决策的重要机制,可以从合议制到审委会讨论制。集体讨论的优势:①集思广益,避免个人认知偏差;②相互制衡,确保决策公正;③增强司法公信力。

**类案指引**:合议庭是基层审判单元,专业法官会议提供专业咨询,审委会处理重大复杂案件,形成「金字塔型」决策体系。

**法律依据**:①《人民法院组织法》②《最高人民法院关于健全完善人民法院审判委员会工作机制的意见》

### Q3. 「讨论规则」为什么重要?

**答复**:讨论规则是程序制约的核心。没有规则的讨论容易演变为「一言堂」或「走过场」,无法实现真正的集体决策。讨论规则包括:发言顺序、表决程序、回避制度、记录规范等。

**类案指引**:陈增宝法官强调,程序制约下的汇报技能与讨论方法,是「司法中人的因素」的重要体现。

**法律依据**:①《最高人民法院关于人民法院合议庭工作的若干规定》②《审判委员会议事规则》

### Q4. 案件讨论的「决策五步法」是什么?

**答复**:①发现问题(明确争议焦点);②确立目标(讨论要达成的目标);③收集信息(证据、法律、判例);④建构决定(拟定裁判方案);⑤选择方案(在多个方案中选择最佳)。

**类案指引**:陈增宝法官将案件讨论视为「决策过程」,五步法贯穿始终。

**法律依据**:①《人民法院合议规则》

### Q5. 案件讨论的「三种形式」有何区别?

**答复**:①合议庭讨论(基层单元,3-7 名法官合议,简单多数表决);②专业法官会议(专业化咨询,提供裁判参考);③审委会(最高决策,讨论重大复杂案件)。三种形式层层递进,形成完整讨论体系。

**类案指引**:合议庭是常态形式,专业法官会议是辅助形式,审委会是例外形式。三者比例应符合「让审理者裁判、让裁判者负责」原则。

**法律依据**:①《人民法院组织法》第36-37条②《最高人民法院关于健全完善人民法院审判委员会工作机制的意见》

### Q6. 合议庭运行中存在哪些问题?

**答复**:①有的合议庭成员缺乏全程参与(「合而不议」);②部分合议庭成员作用发挥不够(「议而不决」);③表决规则不健全(「决而不公」);④监督机制不完善。

**类案指引**:陈增宝法官提出,应加强合议庭成员的搭配合理性、适时适度交流轮岗、建立科学的评议表决规则。

**法律依据**:①《最高人民法院关于人民法院合议庭工作的若干规定》

### Q7. 专业法官会议的「制度定位」和「运行机制」是什么?

**答复**:制度定位——为合议庭审理复杂、疑难案件提供专业咨询的机制。运行机制——①不直接作出裁判,只提供参考意见;②按专业领域分组;③讨论结果供合议庭参考;④与审委会讨论形成衔接。

**类案指引**:陈增宝法官强调,专业法官会议是「专业化的智库」,发挥集体智慧,但不替代合议庭裁判。

**法律依据**:①《最高人民法院关于完善人民法院专业法官会议工作机制的指导意见》

### Q8. 审委会的「基本原则」和「职能定位」是什么?

**答复**:基本原则——①民主集中制;②少数服从多数;③集体讨论决定;④回避制度。职能定位——①讨论重大、复杂、疑难案件;②总结审判经验;③制定审判指导文件;④监督审判工作。

**类案指引**:审委会是「最高审判决策机构」,但应「有所为有所不为」,避免过度干预个案。

**法律依据**:①《人民法院组织法》第36条②《最高人民法院关于健全完善人民法院审判委员会工作机制的意见》

### Q9. 司法中的「人的因素」有哪些?

**答复**:陈增宝法官强调,司法决策不仅是法律适用,也是「人的决策」。人的因素包括:①认知能力(法律素养、经验积累);②沟通能力(讨论、说服);③品格操守(公正、廉洁);④情绪管理(冷静、理性);⑤责任意识(担当、决断)。

**类案指引**:「司法中人的因素」是讨论能力培养的核心,法官的综合素质决定讨论质量。

**法律依据**:①《法官法》第3-7条(法官义务与职责)

### Q10. 案件汇报应遵循哪些方法?

**答复**:①客观真实——准确反映案件事实;②条理清晰——按争议焦点组织汇报;③重点突出——突出关键证据和争议问题;④语言精练——避免冗长;⑤回应质疑——对预判的反对意见预先回应。

**类案指引**:陈增宝法官提出,「程序制约下的汇报技能」是讨论有效性的前提。

**法律依据**:①《最高人民法院关于人民法院合议庭工作的若干规定》

### Q11. 群体决策理论如何检视合议制?

**答复**:陈增宝法官运用群体决策理论分析合议制,提出:①避免「群体极化」(决策倾向比个体更极端);②避免「信息瀑布」(信息不对称下的从众);③避免「责任分散」(集体决策下的责任弱化);④追求「集体智慧」。

**类案指引**:合议制的优势在于集思广益,风险在于「平庸化」,需通过规则设计平衡。

**法律依据**:①《最高人民法院关于人民法院合议庭工作的若干规定》

### Q12. 如何加强合议庭的监管和建设?

**答复**:①合议庭成员搭配合理(资历、经验、专业互补);②适时适度交流轮岗(避免长期固化);③建立科学的评议表决规则;④完善合议庭工作记录;⑤加强合议庭成员的培训。

**类案指引**:陈增宝法官强调,合议庭是「基层审判单元」,应通过制度化建设提升合议质量。

**法律依据**:①《最高人民法院关于人民法院合议庭工作的若干规定》第10-15条
