## 概述

《人民检察院行政诉讼监督规则》于2021年4月8日最高人民检察院第十三届检察委员会第六十五次会议通过，2021年9月1日起施行，共137条。

**核心功能**：监督人民法院依法审判和执行，促进行政机关依法行使职权，维护司法公正和司法权威，保护公民、法人和其他组织的合法权益，推动行政争议实质性化解。

**监督方式**：提出抗诉、检察建议等方式

## 监督范围

### 一、对生效行政判决、裁定、调解书的监督

人民检察院受理当事人申请监督的案件类型：

| 申请情形 | 具体内容 |
|----------|----------|
| 驳回再审申请或逾期未裁定 | 当事人对已生效行政判决、裁定、调解书认为确有错误的 |
| 再审判决、裁定确有错误 | 认为再审行政判决、裁定确有错误的 |
| 审判程序违法 | 认为行政审判程序中审判人员存在违法行为的 |
| 执行活动违法 | 认为人民法院行政案件执行活动存在违法情形的 |

**申请期限**：
- 一般情形：送达驳回再审申请裁定之日或再审判决、裁定发生法律效力之日起**六个月**内
- 特殊情形（新的证据、证据伪造、法律文书被撤销变更、审判人员贪腐枉法等）：知道或应当知道之日起**六个月**内
- 审判人员违法、执行违法：知道或应当知道之日起**六个月**内

### 二、对行政审判程序中审判人员违法行为的监督

监督范围涵盖**一审普通程序、简易程序、二审程序、审判监督程序**，适用于法官、人民陪审员、法官助理、书记员。

具体违法情形包括：
- 判决、裁定确有错误，但不适用再审程序纠正的
- 调解违反自愿原则或调解协议内容违法的
- 未在法定期限内决定是否立案的
- 审理案件适用审判程序错误的
- 保全、先予执行、停止执行或不停止执行行政行为裁定违反法律规定的
- 违反法定审理期限的
- 对当事人采取罚款、拘留等强制措施违反法律规定的
- 违反法律规定送达的

### 三、对行政案件执行活动的监督

监督范围包括：
- **执行裁定、决定违法**：提级管辖/指定管辖违反法律规定、裁定受理/不予受理/中止执行/终结执行等违反法律规定、变更追加执行主体错误、财产调查控制处置措施违反法律规定、审查执行异议/复议/案外人异议作出的裁定违反法律规定等
- **执行实施措施违法**：采取调查、查封、扣押、冻结、评估、拍卖、变卖、保管、发还财产，以及信用惩戒等违反规定
- **不履行或怠于履行执行职责**：对应当受理的执行申请不予受理又不作出不予受理裁定、对已受理案件不作出执行裁定或无正当理由未采取执行措施、违法不受理执行异议/复议或受理后逾期未作出裁定决定、暂缓执行/停止执行/中止执行原因消失后不按规定恢复执行等

### 四、依职权监督情形

人民检察院在履行职责中发现以下情形，应当依职权监督，**不受当事人是否申请再审的限制**：
1. 损害国家利益或社会公共利益的
2. 审判人员、执行人员审理和执行行政案件时有贪污受贿、徇私舞弊、枉法裁判等行为的
3. 依照有关规定需要人民检察院跟进监督的
4. 人民检察院作出的不支持监督申请决定确有错误的
5. 其他确有必要进行监督的情形

## 监督程序

### 一、受理程序

**受理途径**：
1. 当事人向人民检察院申请监督
2. 当事人以外的公民、法人或其他组织向人民检察院控告
3. 人民检察院依职权发现

**受理部门**：负责控告申诉检察的部门受理，7日内作出处理决定

**案件移送**：决定受理之日起3日内将案件材料移送负责行政检察的部门，同时抄送负责案件管理的部门

### 二、审查程序

**审查原则**：
- 围绕申请人的申请监督请求、争议焦点及依职权监督情形进行全面审查
- 实行繁简分流，繁案精办、简案快办
- 重大疑难复杂问题可向专家咨询或组织专家论证

**审查方式**：
- 听取当事人意见（当面、视频、电话、传真、电子邮件、书面提交等方式）
- 调查核实有关情况
- 举行听证
- 调阅人民法院诉讼卷宗、执行卷宗
- 全面检索相关指导性案例、典型案例和关联案例

**调查核实措施**：
- 查询、调取、复制相关证据材料
- 询问当事人、有关知情人员或其他相关人员
- 咨询专业人员、相关部门或行业协会
- 委托鉴定、评估、审计
- 勘验物证、现场

**审查期限**：
- 对生效行政判决、裁定、调解书的监督：**三个月**内审查终结（调卷、鉴定、评估、审计、专家咨询等期间不计入）
- 对审判人员违法行为和执行活动违法行为的监督：参照上述期限执行

### 三、决定程序

人民检察院对审查终结的案件，依法作出下列决定：

| 决定类型 | 适用情形 |
|----------|----------|
| 提出再审检察建议 | 发现同级人民法院已生效判决、裁定有法定情形（如不予立案/驳回起诉确有错误、有新证据、原判决认定事实主要证据不足/未经质证或系伪造、违反诉讼程序影响公正审判、遗漏诉讼请求、法律文书被撤销变更等） |
| 提请抗诉 | 判决裁定经同级人民法院再审后作出、经审判委员会讨论作出、或其他不适宜由同级人民法院再审纠正的；原判决裁定适用法律确有错误、审判人员有贪腐枉法行为的 |
| 提出抗诉 | 最高检对各级法院已生效判决裁定、上级检察院对下级法院已生效判决裁定发现有法定情形的 |
| 提出检察建议 | 审判人员违法行为、执行活动违法等情形 |
| 不支持监督申请 | 不符合监督条件的 |
| 终结审查 | 法院已裁定再审或已纠正违法行为、申请人撤回监督申请、与当事人达成和解协议放弃申请监督权利等 |

### 四、出席法庭程序

人民检察院提出抗诉的案件，人民法院再审时，人民检察院**应当派员出席法庭**，并全程参加庭审活动。

**出庭任务**：
1. 宣读抗诉书
2. 对人民检察院调查取得的证据予以出示和说明
3. 经审判长许可，对证据采信、法律适用和案件情况予以说明，针对争议焦点客观公正阐述法律监督意见
4. 对法庭审理中违反诉讼程序的情况予以记录
5. 依法从事其他诉讼活动

### 五、检察建议程序

**适用情形**：
- 行政审判程序中审判人员违法行为
- 行政案件执行活动中违法行为
- 人民法院多起同一类行政案件中存在同类问题适用法律不一致、适用法律存在同类错误等

**程序要求**：经检察长批准或检察委员会决定，制作《检察建议书》，在决定之日起15日内将《检察建议书》连同案件卷宗移送同级人民法院

## 听证程序

### 适用情形

人民检察院审查行政诉讼监督案件，在事实认定、法律适用、案件处理等方面存在**较大争议**，或者有**重大社会影响**，需要当面听取当事人和其他相关人员意见的，可以召开听证会。

### 听证参加人

- 人大代表、政协委员、人民监督员、特约检察员、专家咨询委员、人民调解员
- 当事人所在单位、居住地的居民委员会、村民委员会成员
- 专家、学者、律师等其他社会人士

人民检察院应当邀请人民监督员参加听证会，依照有关规定接受人民监督员监督。

### 听证步骤

1. 承办检察官介绍案件情况和需要听证的问题
2. 申请人陈述申请监督请求、事实和理由
3. 其他当事人发表意见
4. 申请人和其他当事人提交新证据的，应当出示并予以说明
5. 出示人民检察院调查取得的证据
6. 案件各方当事人陈述对听证中所出示证据的意见
7. 听证员、检察官向申请人和其他当事人提问
8. 当事人发表最后陈述意见
9. 主持人对听证会进行总结

---

## 不予受理情形

当事人向人民检察院申请监督，有下列情形之一的，**不予受理**：

1. 当事人对生效行政判决、裁定、调解书未向人民法院申请再审的
2. 当事人申请再审超过法律规定的期限的
3. 人民法院在法定期限内正在对再审申请进行审查的
4. 人民法院已经裁定再审且尚未审结的
5. 人民检察院已经审查终结作出决定的
6. 行政判决、裁定、调解书是人民法院根据人民检察院的抗诉或者再审检察建议再审后作出的
7. 申请监督超过规定期限的
8. 根据法律规定可以对人民法院的执行活动提出异议、申请复议或提起诉讼，当事人等没有提出异议、申请复议或提起诉讼的（但有正当理由或检察院依职权监督的除外）
9. 当事人提出执行异议、申请复议、申诉或提起诉讼后，人民法院已经受理并正在审查处理的（但超过法定期限未作出处理的除外）
10. 其他不应当受理的情形

## 适用要点汇总表

| 事项 | 要点 |
|------|------|
| **监督对象** | 人民法院行政诉讼活动（包括审判程序和执行活动） |
| **监督方式** | 抗诉、检察建议、再审检察建议 |
| **申请主体** | 当事人；当事人以外的公民、法人或其他组织（控告）；检察院依职权 |
| **申请期限** | 一般6个月；特殊情形6个月（知道或应当知道）；审判违法/执行违法6个月（知道或应当知道） |
| **受理部门** | 负责控告申诉检察的部门 |
| **审查部门** | 负责行政检察的部门 |
| **审查期限** | 3个月（调卷、鉴定、评估、审计、专家咨询期间不计入） |
| **调查核实** | 可查询调取证据、询问、咨询、委托鉴定评估审计、勘验现场（不得限制人身自由和查封扣押冻结财产） |
| **听证情形** | 事实认定、法律适用、案件处理有较大争议或有重大社会影响 |
| **简易案件** | 原一审适用简易程序审理、案件事实清楚法律关系简单的，可简化程序 |
| **监督生效判决** | 可提再审检察建议、提请抗诉、提出抗诉 |
| **监督审判违法** | 向同级人民法院提出检察建议 |
| **监督执行违法** | 向同级人民法院提出检察建议 |
| **不予受理情形** | 未申请再审、超过再审期限、法院正在审查、检察院已审查终结、依据抗诉/再审检察建议再审后作出的判决等 |
| **跟进监督** | 法院再审判决仍符合抗诉条件且有明显错误、法院行政机关对检察建议未在规定期限回复或处理错误的 |
| **费用** | 不收取案件受理费；复印鉴定审计勘验等费用由申请人直接支付 |
