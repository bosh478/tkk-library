## 📋 案例概览

| 字段 | 内容 |
|------|------|
| 案号 | 一审 |
| 被告人 | 赵雨蝶 |
| 被害人 | 黄某某（3岁幼童） |
| 罪名 | 虐待罪、故意伤害罪 |
| 审理法院 | 上海市第一中级人民法院 |
| 判决结果 | 虐待罪：有期徒刑二年；故意伤害罪：死刑缓期二年执行，剥夺政治权利终身；数罪并罚 |
| 判决日期 | 2026年4月21日 |

## 📌 核心要点

- 虐待罪：频繁采用殴打背部、臀部、腿部及牙咬腿部等方式实施虐待，情节恶劣
- 故意伤害罪：用手拍打头面部、树枝抽打、用脚踢踹、将幼童从堤岸拎甩至地面致颅脑损伤死亡
- 主观认定：具有伤害故意但不希望死亡后果，构成故意伤害罪而非故意杀人罪
- 量刑考量：如实供述但不从轻，虽有送医施救行为仍从严惩处

## 案件事实

### 虐待行为（2024年7月至8月23日）

被告人与男友黄某理及黄某理儿子黄某某（3岁）共同生活期间，以黄某某顽皮不听话等为由，频繁采用殴打背部、臀部、腿部等处及牙咬腿部等方式实施虐待。

### 故意伤害行为（2024年8月24日傍晚）

在上海市浦东新区一开放式公园内，因不满黄某某乱跑等原因：
- 多次用手拍打黄某某头面部
- 用树枝抽打、用脚踢踹黄某某身体其他部位
- 将黄某某从河道岸堤下斜坡拎甩至堤面，致黄某某侧身倒地后头部撞击地面

当日20时许，黄某某在家中昏迷倒地，被告人将其送至医院抢救。黄某某因抢救无效于同年9月4日死亡。

### 鉴定意见

- 死因：钝性外力作用致颅脑损伤，引起中枢神经系统功能障碍死亡
- 轻伤一级：背部皮肤软组织挫伤；2024年8月24日晚就诊时体表多处皮肤软组织挫伤已达轻伤一级
- 轻微伤：面部、胸部皮肤软组织挫伤分别达到轻微伤；左小腿咬伤致皮肤破损达到轻微伤

### 到案情况

2024年8月29日，公安机关在赵雨蝶暂住处将其抓获。赵雨蝶到案后如实供述了主要犯罪事实。

## 裁判理由

### 虐待罪

根据《刑法》第260条（1997-10-01 施行 / 2024-12-27 最新修正），虐待家庭成员，情节恶劣的，处二年以下有期徒刑、拘役或者管制。本案中：
- 被害人系家庭成员黄某某（3岁幼童）
- 频繁采用殴打、牙咬等方式实施虐待
- 导致黄某某轻伤等危害后果
- 情节恶劣，造成不良社会影响
- 虽如实供述但不从轻处罚

① 来源：行28

### 故意伤害罪

根据《刑法》第234条（1997-10-01 施行 / 2024-12-27 最新修正），故意伤害致人死亡的，处十年以上有期徒刑、无期徒刑或者死刑。

法院认定：
- 被告人明知拍打、用力拎甩一名三岁幼童可能导致伤害后果
- 依然实施相关行为，直接导致被害人死亡
- 主观上具有伤害故意，客观上实施了伤害行为
- 从赵雨蝶作案行为特征及在黄某某昏倒后即将其送医施救等表现看，不希望造成死亡后果
- 故构成故意伤害罪而非故意杀人罪

① 来源：行32

### 量刑考量

关于故意伤害罪的量刑：
- 被告人作为黄某某父亲的同居女友，在共同生活期间非但没有妥善照顾，反而故意伤害致其死亡
- 即便有施救行为，到案后如实供述，依法仍应从严惩处
- 故判处死刑缓期二年执行，剥夺政治权利终身

① 来源：行34

## 判后答疑要点

### 问题一：虐待罪定罪量刑依据

《刑法》第260条（1997-10-01 施行 / 2024-12-27 最新修正）规定，虐待家庭成员，情节恶劣的，处二年以下有期徒刑、拘役或者管制。被告人以殴打等方式频繁对年仅三岁的家庭成员实施虐待，导致轻伤等，情节恶劣，构成虐待罪。虽如实供述但不从轻处罚。

### 问题二：故意伤害罪定罪量刑依据

- 被告人明知拍打、用力拎甩幼童可能导致伤害后果，仍实施相关行为
- 直接导致被害人死亡，但无希望死亡之意
- 主观有伤害故意，客观实施了伤害行为
- 根据《刑法》第234条（1997-10-01 施行 / 2024-12-27 最新修正），故意伤害致人死亡处十年以上有期徒刑、无期徒刑或死刑
- 依法应从严惩处

① 来源：行28-34

### 问题三：网传信息核实

经审查，网传"用牙签刺戳背部创口"、"因饥饿在垃圾桶翻找食物"、"死前长时间未进食胃里有小石子"等情节均不属实。

① 来源：行38

### 问题四：父亲是否存在虐待

经审查在案证据及相关材料，没有反映出黄某某的父亲存在参与、隐瞒、纵容赵雨蝶虐待黄某某的情况。

① 来源：行42
