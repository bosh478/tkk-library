## 概述

本指引由广东省高级人民法院于2024年1月18日发布，共18条，是涉港澳商事纠纷司法规则衔接指引的第二部分，确立港澳证人资格认定、交叉询问规则、在线作证等制度。

## 核心规则

### 1. 港澳证人定义

本指引所称"港澳证人"，指永久性居民身份所在地或者经常居所地在香港特别行政区、澳门特别行政区的证人。

### 2. 证人资格认定

| 要点 | 内容 |
|------|------|
| 资格标准 | 符合内地《民事诉讼法》规定的证人资格条件，即具有证人资格 |
| 否定资格 | 当事人依据港澳法律主张证人不具有资格的，人民法院不予支持 |
| 豁免情形 | 港澳证人可依据港澳法律免于对特定事项在内地法院作证 |

### 3. 作证方式

- 人民法院可通知港澳证人出庭作证
- 可请求港澳法院协助提取、调取港澳证人证言
- 港澳证人可采用视听传输技术（在线形式）出庭作证

### 4. 交叉询问规则

本指引确立了"当事人主导询问"模式替代传统的"法官主导询问"模式，交叉询问依次进行：

```
申请方主询问 → 对方反询问 → 申请方复询问 → 审判人员补充询问
```

#### 主询问规则
- 一般围绕出庭作证申请书载明的作证主要内容进行

#### 反询问规则
- 一般围绕前序询问中证人作答的内容及其真实性、合法性、关联性进行

### 5. 交叉询问适用范围

人民法院可根据案件情况，组织当事人及其诉讼代理人对证人进行交叉询问。

### 6. 程序规则

| 程序事项 | 规定 |
|----------|------|
| 通知期限 | 组织交叉询问的，应在七日前通知当事人及其他诉讼参与人 |
| 申请书副本 | 同时发送出庭作证申请书副本 |
| 证人排序 | 一方申请两名以上证人出庭的，由法院确定出庭顺序 |
| 多方申请 | 当事人均申请证人出庭的，先组织对事实负有举证证明责任一方申请的证人出庭 |
| 顺序变更 | 法院可根据案件情况变更询问顺序或组织多轮交叉询问 |

### 7. 不适当引导证人的认定

下列行为认定为不适当引导证人（证人作答内容不得作为认定案件事实的根据）：

1. 将待证事实假定为已证事实后加以提问
2. 明示或者暗示希望证人作答的内容
3. 借助语气、动作等对证人作答进行提示或影响
4. 其他不适当引导证人的行为

### 8. 异议权

当事人及其诉讼代理人认为询问存在威胁、侮辱证人或不适当引导等情形的，可以提出异议。

### 9. 审判人员应当询问的内容

下列内容审判人员应当询问证人：
- 涉及可能损害国家利益、社会公共利益的
- 涉及身份关系的
- 涉及《民事诉讼法》第58条规定诉讼的
- 当事人有恶意串通损害他人合法权益可能的
- 涉及依职权追加当事人、中止诉讼、终结诉讼、回避等程序性事项的
- 其他应当由审判人员询问证人的内容

### 10. 其他规定

| 情形 | 规则 |
|------|------|
| 证人查阅材料 | 证人基于作证需要，申请查阅与作证内容相关的书面材料后作答的，法院可以准许 |
| 对质 | 法院认为有必要的，可以要求证人与证人、当事人之间进行对质 |
| 虚假陈述申辩 | 证人申请对故意作虚假陈述的指控进行申辩的，法院可以准许 |

### 11. 费用补偿

| 费用类型 | 计算标准 |
|----------|----------|
| 交通、住宿、就餐 | 按内地机关事业单位工作人员差旅费用和补贴标准计算 |
| 误工损失 | 按港澳政府统计主管部门公布的上一年度工资中位数，按误工当日汇率折合人民币计算 |

## 制度创新

### 交叉询问模式转变

本指引最重要的创新在于将证人询问从"法官主导"转变为"当事人主导"，目的包括：
- 依托证人证言建构待证事实
- 通过交叉询问辨别证人证言真伪
- 查明案件事实

### 专家评价

香港城市大学法律学院院长林峰表示："证据规则是整个诉讼制度的核心，此举创新优化了证人资格审查程序和证人出庭作证方式等多项机制，对进一步规范涉港澳审判程序、推动大湾区司法规则衔接具有重要意义。"

澳门大学法学院教授表示："《指引》将充分发挥港澳证人出庭作证对涉港澳商事纠纷事实查明的作用，着力推动粤港澳大湾区诉讼规则衔接。"
