## 概述

本建议稿于2025年6月发布，由中国人民大学陈卫东教授主持编写研究团队完成。建议稿分为七编，共1077条，具有体例法典化、规范完备化、内容创新化三大特色。

## 核心要点

### 一、体例法典化

1. **编章体例调整**：由现行刑诉法五编增至七编，将证据和证明单列为一编，增加涉外刑事诉讼程序编（第一编至第七编结构重组）

2. **章节整合删减**：删除监视居住、公诉案件当事人和解程序；重新提炼基本原则；增设单位犯罪诉讼程序、涉案财物处置程序、在线诉讼程序（第一编通则、第六编特别程序调整）

3. **条文数量大幅增加**：本建议稿由现行法的308条增加至1077条，体现法典化规范完备化的特点

4. **立法技术提升**：体例科学、规范完备、内容协调，实现立法精细化和缜密化

### 二、规范完备化

1. **司法解释上升为立法**：将刑事执法司法实践中行之有效的司法解释及规范性文件的规定上升为立法规定

2. **填补立法空白**：针对现行刑诉法条文过少、规定过疏的问题，完善必要内容

3. **减少司法解释依赖**：现行刑诉法精密化和完备化不足，导致各类司法解释、规范性文件过多，本建议稿力图改变这一状况

4. **各类诉讼程序规范**：从立案到执行，从普通程序到特别程序，全面加以规范

### 三、内容创新化

1. **新技术立法**：增设大数据侦查、强制采样等侦查措施规定，应对互联网技术普及化、大数据运用常态化等挑战

2. **利用新技术赋能**：增设在线诉讼程序，规定在线诉讼程序的适用范围、效力、程序转换等

3. **轻罪化治理应对**：顺应中国轻罪化治理的时代需要，扩大和完善附条件不起诉制度

4. **涉外交流合作加强**：增设涉外刑事诉讼程序专编，规定涉外刑事案件的处理程序和国际刑事司法协助

5. **被害人权利保障强化**：完善未成年被害人特殊保护规定，增加双向保护原则

6. **辩护制度实质化**：增设辩护律师在场权、有效辩护制度，强化辩护权的实质保障

### 四、各编修改要点

#### 第一编通则（182条）

1. **基本原则体系重新厘定**：增加审判中心原则、一事不再理原则、比例原则等

2. **管辖规定完善**：规范指定管辖，增设管辖异议制度

3. **辩护制度完备**：增设辩护律师在场权、有效辩护制度

4. **强制措施完善**：取消监视居住，将羁押必要性审查作为一节加以规定

5. **附带民事诉讼财产保全**：增设附带民事诉讼的财产保全制度

#### 第二编证据和证明（94条）

1. **证据裁判原则、自由心证原则**：增设证据基本原则

2. **意见证据规则、相似事实证据规则**：完善证据规则体系

3. **非法证据排除规则完善**：全流程排非

4. **专门性问题报告**：新增证据种类

5. **证据种类细化**：九节内容细化各类证据的审查判断

#### 第三编立案侦查和公诉（249条）

1. **立案程序完善**：详细规定受案、立案和撤案程序

2. **立案备案与监督**：增设公安机关立案或者不立案报送同级人民检察院备案制度

3. **被害人救济**：完善被害人或者控告人对立案或者不立案异议的救济程序

4. **侦查措施体系调整**：由11节增加至19节

5. **新增侦查措施**：调取、强制采样、辨认、侦查实验、限制出境、大数据侦查等

6. **审查起诉实质化**：完善审查起诉实质化的相关规定

7. **附条件不起诉**：增设附条件不起诉制度，适用范围设定为可能判处3年以下有期徒刑之刑罚的轻罪案件

8. **核准追诉程序**：增设核准追诉程序

#### 第四编审判（241条）

1. **陪审合议庭完善**：细化陪审组织的规定

2. **庭前审查实质化**：强化庭前审查的实质化，增设分案和并案的规定

3. **庭前会议制度完善**：完善庭前会议制度

4. **庭审规则增设**：增设庭审中反询问、交叉询问规则

5. **第二审程序分节**：将第二审程序分为"通则"、"对判决的上诉、抗诉"、"对裁定的上诉、抗诉"三节

6. **二审一律开庭**：增加对判决上诉、抗诉一律开庭审理的规定

7. **死刑复核程序诉讼化**：强化诉讼化审理的规定

8. **再审程序分类**：将再审程序分为为原审被告人利益的再审和不利于原审被告人的再审

#### 第五编执行（71条）

1. **执行主体明确**：将死刑执行权赋予司法行政机关

2. **执行章节增加**：增设"一般规定"、"轻微犯罪记录封存"两章

3. **减刑假释程序完善**：增设减刑、假释审理程序开庭审理、公示程序的规定

4. **犯罪记录封存细化**：规定除危害国家安全犯罪等特定案件外，法定最高刑为3年有期徒刑以下之刑罚的罪犯适用犯罪记录封存制度

#### 第六编特别程序（167条）

1. **章数增加**：由五章增至七章

2. **未成年人保护强化**：增加对未成年犯罪嫌疑人、被告人、被害人信息保护等特别保护措施

3. **单位犯罪程序新增**：增设单位刑事案件诉讼程序的特别规定

4. **缺席审判适用范围扩大**：完善缺席审判程序的相关规定

5. **涉案财物处置新增**：增设涉案财物处置程序

6. **在线诉讼新增**：增设在线诉讼程序

#### 第七编涉外刑事诉讼程序（73条）

1. **专编新增**：现行刑诉法无此编，本编为新增内容

2. **基本原则规定**：规定国家主权原则、信守国际条约原则、平等互惠原则等

3. **管辖规定**：采用保护管辖、普遍管辖、属人管辖、集中管辖等

4. **权利保障**：规定外籍犯罪嫌疑人、被告人的辩护权、会见权、探视权等诉讼权利

5. **国际刑事司法协助**：规定刑事司法协助相关程序

### 五、立法过程与参与人员

1. **研究团队组建**：2023年11月组建刑事诉讼法典专家建议稿研究团队

2. **统稿会召开**：2024年6月在河南安阳召开第一次统稿会

3. **论证会召开**：2024年7月在山东烟台组织召开论证会，全国学者、立法和司法实务界代表百余人参会

4. **参与人员**：研究团队由陈卫东教授主持，成员包括各章节负责人

### 六、与现行法的比较

| 项目 | 现行刑诉法 | 本建议稿 |
|------|-----------|---------|
| 编数 | 五编 | 七编 |
| 条文数 | 308条 | 1077条 |
| 体例 | 不够完备 | 体例科学完备 |
| 内容 | 规定过疏 | 规范缜密 |
| 涉外程序 | 无 | 专编规定 |
| 在线诉讼 | 无 | 专章规定 |
| 单位犯罪程序 | 无 | 专章规定 |

### 七、主要特色总结

1. **体例法典化**：重新编排立法体例，由五编增至七编，条文数量增加至1077条

2. **规范完备化**：将司法解释及规范性文件的规定上升为立法规定，减少对司法解释的依赖

3. **内容创新化**：回应新技术挑战、顺应轻罪化治理需要、加强涉外交流合作
