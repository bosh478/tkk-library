## 一、犯罪主体与定罪标准

### 1. 定点医药机构（第5条）

以非法占有为目的，骗取医疗保障基金支出的，对**组织、策划、实施人员**，以**诈骗罪**定罪处罚。① 来源：第5条

**八种行为类型**：
| 序号 | 行为类型 | 说明 |
|------|----------|------|
| （1） | 冒名/虚假就医 | 诱导、协助他人冒名或虚假就医、购药，提供虚假证明材料，串通虚开费用单据 |
| （2） | 伪造资料 | 伪造、变造、隐匿、涂改、销毁医学文书、医学证明、会计凭证、电子信息、检测报告 |
| （3） | 虚构服务 | 虚构医药服务项目、虚开医疗服务费用 |
| （4） | 分解住院 | 分解住院、挂床住院 |
| （5） | 违规收费 | 重复收费、超标准收费、分解项目收费 |
| （6） | 串换项目 | 串换药品、医用耗材、诊疗项目和服务设施 |
| （7） | 超范围纳入 | 将不属于医保支付范围的医药费用纳入结算 |
| （8） | 其他 | 其他骗取医疗保障基金支出的行为 |

**特殊规定**：定点医药机构的**国家工作人员**，利用职务便利实施上述行为的，以**贪污罪**定罪处罚（《刑法》第382条（1997-10-01 施行 / 2024-12-27 最新修正）、第383条）。① 来源：第5条第3款 ✅ VERIFIED

### 2. 参保人员（第6条）

以非法占有为目的，骗取医疗保障基金支出的，以**诈骗罪**定罪处罚。① 来源：第6条

**六种行为类型**：
| 序号 | 行为类型 |
|------|----------|
| （1） | 伪造资料 |
| （2） | 使用他人医疗保障凭证冒名就医、购药 |
| （3） | 虚构医药服务项目 |
| （4） | 重复享受医疗保障待遇 |
| （5） | 转卖药品接受返还现金等 |
| （6） | 其他骗取行为 |

**合法行为排除**：参保人员个人账户按照有关规定为他人支付的个人负担医疗费用，**不属于**冒名就医、购药。① 来源：第6条第2款

### 3. 行政部门工作人员（第7条）

医疗保障行政部门及经办机构工作人员利用职务便利骗取医保基金的，以**贪污罪**定罪处罚。① 来源：第7条 ✅ VERIFIED

### 4. 购买/盗窃医保凭证（第8条）

| 行为 | 定罪 |
|------|------|
| 以骗取医保基金为目的，购买他人医保凭证并使用 | 择一重罪（买卖身份证件罪/使用虚假身份证件罪/诈骗罪） |
| 盗窃他人医保凭证并盗刷个人账户资金 | **盗窃罪**（《刑法》第264条（1997-10-01 施行 / 2024-12-27 最新修正）） ✅ VERIFIED |

① 来源：第8条

### 5. 非法收购销售骗保药品（第9条）

| 行为 | 定罪 |
|------|------|
| 明知是骗保购买的药品而非法收购、销售 | **掩饰、隐瞒犯罪所得罪**（《刑法》第312条（1997-10-01 施行 / 2024-12-27 最新修正）） ✅ VERIFIED |
| 指使、教唆、授意他人骗保购买药品，进而收购销售 | **诈骗罪**（《刑法》第266条（1997-10-01 施行 / 2024-12-27 最新修正）） ✅ VERIFIED |

**主观明知认定标准**（第9条第3款，6种情形）：
1. 药品价格明显异于市场价格
2. 曾因同类行为受过刑事或行政处罚
3. 以非法收购、销售基本医疗保险药品为业
4. 长期或多次向不特定交易对象收购、销售
5. 利用互联网、邮寄等非接触式渠道多次收购、销售
6. 其他足以认定主观明知

**但书**：行为人能够说明药品合法来源或作出合理解释的除外。

**独立评价**：行为人是否被追究刑事责任，**不影响**对非法收购销售者定罪处罚。① 来源：第9条第2款

## 二、量刑情节

### 从重处罚情节（第10条）

具有下列情形之一的，**可以从重处罚**：
1. 组织、指挥犯罪团伙骗取医保基金
2. 曾因医保骗保犯罪受过刑事追究
3. 拒不退赃退赔或者转移财产
4. 造成其他严重后果或恶劣社会影响

① 来源：第10条

### 从宽处罚（第12条）

- 对涉案不深的**初犯、偶犯**从轻处罚
- 对认罪认罚的**医务人员、患者**可以从宽处罚
- 犯罪情节轻微的，可以依法**不起诉**或**免除处罚**
- 情节显著轻微、危害不大的，**不作为犯罪处理**

① 来源：第12条

### 缓刑限制（第13条）

**一般不适用缓刑**的情形：
1. 犯罪集团的首要分子
2. 职业骗保人
3. 曾因医保骗保犯罪受过刑事追究
4. 毁灭、伪造、隐藏证据
5. 拒不退赃退赔或转移财产逃避责任

① 来源：第13条

### 财产刑（第14条）

依法用足用好财产刑，加大罚金、没收财产力度，综合考虑犯罪数额、退赃退赔、认罪认罚等情节决定罚金数额。① 来源：第14条

## 三、证据规则

### 证据收集（第15-18条）

- 注重收集处方、病历等**原始证据材料**及证明伪造骗取事实的**核心证据材料**（第15条）
- 医保行政部门在监督检查中收集的物证、书证、视听资料、电子数据等，经法庭查证属实且程序合法的，**可以作为定案根据**（第18条）

### 间接证据认定（第19条）

确因证人人数众多等客观条件限制，无法逐一收集证人证言的，可以结合已收集的证人证言及银行账户交易记录、第三方支付结算凭证、审计报告、医保信息系统数据、电子数据等，**综合认定诈骗数额**。① 来源：第19条

### 追赃挽损（第21-22条）

- 犯罪所得一切财物应当依法**追缴或责令退赔**
- 无法查明去向或价值灭失的，可以追缴**等值财产**
- 等值财产追缴数额限于依法查明应当追缴违法所得数额，已追缴或退赔部分应予扣除

① 来源：第21条

## 四、协同配合机制

### 行刑衔接（第23条）

- 公安机关对医保行政部门移送的犯罪线索要及时调查
- 不构成犯罪、依法不起诉或免予刑事处罚的，应当依法**移送行政处罚**

### 信息共享（第24条）

- 健全线索发现、核查、移送、处理和反馈机制
- 构建**实时分析预警监测模型**，力争"发现在早、打击在早"

① 来源：第23-24条

## 相比同类旧规定的核心差异

本指导意见是**首个**专门针对医保骗保刑事案件的系统性规范文件。① 来源：文件性质

| 维度 | 本指导意见（法发〔2024〕6号） | 以往实践 |
|------|-------------------------------|----------|
| 犯罪主体分类 | 明确四类主体（定点机构、参保人员、行政部门、收购销售者） | 未系统分类 |
| 定点机构国家工作人员 | 明确以贪污罪定罪 | 实践中存在争议 |
| 骗保药品收购销售 | 明确掩饰隐瞒犯罪所得罪 + 6种明知推定情形 | 缺乏明确规定 |
| 间接证据认定 | 明确可以综合多种证据认定数额 | 缺乏统一标准 |
| 缓刑限制 | 列明5类一般不适用缓刑的情形 | 无专门规定 |
| 等值财产追缴 | 明确可以追缴等值财产 | 缺乏明确规定 |

## ❓ 常见问题

> 问：定点医药机构工作人员骗保，是诈骗罪还是贪污罪？
> 答：如果是**国家工作人员**利用职务便利骗取医保基金，以**贪污罪**定罪处罚（第5条第3款）；如果是非国家工作人员（如普通医务人员），以**诈骗罪**定罪处罚。

> 问：购买他人医保卡并使用，怎么定罪？
> 答：以骗取医保基金为目的的，同时构成买卖身份证件罪、使用虚假身份证件罪、诈骗罪，**择一重罪**处罚（第8条第1款）。

> 问：收购骗保药品的人是否需要知道药品来源？
> 答：需要**主观明知**，但可以通过6种情形推定（第9条第3款）。行为人能够说明药品合法来源或作出合理解释的，可以排除明知。
