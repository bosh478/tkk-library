## 核心内容

### 一、管辖原则

| 情形 | 管辖法院 |
|------|----------|
| 在中华人民共和国内水、领海发生的犯罪 | 犯罪地或者被告人登陆地；被告人居住地更适宜的，由居住地法院 |
| 在中国船舶内的犯罪（中华人民共和国领域外） | 最初停泊的中国口岸所在地或者被告人登陆地、入境地 |
| 中国公民在领海以外海域犯罪 | 登陆地、入境地、离境前居住地或者现居住地 |
| 外国人在领海以外海域对中国或中国公民犯罪 | 登陆地、入境地、入境后居住地或者被害人离境前居住地、现居住地 |
| 条约义务范围内行使刑事管辖权 | 被告人被抓获地、登陆地或者入境地 |

### 二、立案侦查

- 海上发生的刑事案件由海警机构根据管辖原则进行立案侦查
- 管辖地未设置海警机构的，由有关海警局商同级人民检察院、人民法院指定管辖

### 三、审查起诉级别管辖

| 海警机构 | 对应检察院 |
|----------|------------|
| 沿海省、自治区、直辖市海警局 | 省级人民检察院 |
| 海警局（中国海警局各分局、直属局） | 设区的市级人民检察院 |
| 海警工作站 | 基层人民检察院 |

### 四、检察监督

- 海警机构办理重大、疑难、复杂的刑事案件，可以商请人民检察院介入侦查活动
- 人民检察院认为确有必要时，可以派员介入侦查活动，对收集证据、适用法律提出意见，监督侦查活动是否合法
