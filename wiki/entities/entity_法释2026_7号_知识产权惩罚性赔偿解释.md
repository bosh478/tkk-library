## 文件背景

为充分发挥惩罚性赔偿制度的重要作用，不断总结《最高人民法院关于审理侵害知识产权民事案件适用惩罚性赔偿的解释》（法释〔2021〕4号）施行以来的新情况新问题，进一步完善知识产权领域惩罚性赔偿适用规则，统一案件裁判尺度，为当事人提供明确诉讼指引，为市场提供明确的行为预期。

## 主要内容

### 一、细化"故意"认定情形（第六条）

**综合考虑因素**：知识产权客体的类型、权利状态和知名度，被告与原告或者利害关系人的关系等。

**可以认定故意的情形**：
1. 经原告或者利害关系人有效通知后，仍继续实施侵权行为的
2. 被告或其法定代表人、管理人是原告或者利害关系人的法定代表人、管理人、实际控制人，知道或者应当知道被侵害的知识产权的
3. 与原告或者利害关系人之间存在劳动、劳务、合作、许可、经销、代理、代表等关系，且基于前述关系接触过被侵害的知识产权的
4. 与原告或者利害关系人之间有业务往来或者为达成合同等进行过磋商，且基于前述关系接触过被侵害的知识产权的
5. 实施盗版、假冒注册商标、假冒他人专利行为的
6. **与原告达成和解并同意停止侵权行为后，再次实施相同或者类似侵权行为的**（新增）
7. 通过设立关联公司、变更法定代表人或者控股股东、隐名设立公司等方式掩盖实际控制关系，或者签订免责协议，逃避侵害涉案知识产权法律责任的
8. 其他可以认定为故意的情形

### 二、细化"情节严重"认定（第七条）

**综合考虑因素**：侵权手段、次数，侵权行为的持续时间、地域范围、规模、后果，侵权人对其侵权行为的认识、基本态度等。

**应当认定为情节严重的情形**：
1. 因侵权被行政处罚或者法院裁判承担法律责任后，再次实施相同或者类似侵权行为的
2. 无正当理由拒不履行保全裁定的
3. 伪造、毁坏或者隐匿侵权证据的
4. **以侵权行为为主营业务或者以侵权获利为主要利润来源等以侵害知识产权为业的**（新增）
5. 侵权获利巨大或者侵权行为导致权利人商誉、市场份额等严重受损的
6. 侵权行为危害或者可能危害国家利益、社会公共利益的
7. 其他应当认定为情节严重的情形

### 三、明确基数计算方法（第八、九条）

| 计算基数 | 计算方式 |
|----------|----------|
| 一般情形 | 实际损失数额、违法所得数额、因侵权所获得的利益 |
| 参照营业利润 | 以被告的违法所得或者侵权获利作为基数 |
| 参照销售利润 | 被告以侵害知识产权为业 |
| 同行业利润率 | 利润率无法确定时，参照统计部门、行业协会等公布的同时期、同行业的平均利润率或者权利人的利润率 |

**重要规则**：法定赔偿数额**不能作为**惩罚性赔偿的计算基数。

### 四、完善倍数确定方法（第十一、十三条）

- 人民法院确定惩罚性赔偿的倍数时，应当综合考虑被告主观过错程度、侵权行为的情节严重程度等因素
- 惩罚性赔偿的倍数在法定范围内确定，**可以不是整数**
- 因同一侵权行为已经被处以罚款或者罚金且执行完毕的，人民法院在确定惩罚性赔偿的倍数时应予考虑，**不以当事人提出请求为前提**

### 五、最高限额（第十二条）

> 人民法院适用惩罚性赔偿确定的赔偿数额总额，**最高为计算基数的五倍**。权利人为制止侵权行为所支付的合理开支在该总额之外另行计算。

## 核心条款速览

| 条款 | 要点 |
|------|------|
| 第一条 | 故意+情节严重 → 支持惩罚性赔偿 |
| 第二条 | 请求惩罚性赔偿应提出明确的赔偿数额、计算方法及事实理由 |
| 第三条 | 一审法庭辩论终结前可增加惩罚性赔偿请求；二审增加的仅能调解 |
| **第四条** | 一审未请求惩罚性赔偿，经释明仍未请求，诉讼终结后另行起诉请求惩罚性赔偿的，**不予受理** |
| 第五条 | 侵害商业秘密以外的不正当竞争行为请求惩罚性赔偿的，不予支持 |
| 第十条 | 被告拒不提供账簿资料或提供虚假的，可根据原告主张和在案证据确定计算基数 |
| **第十二条** | 赔偿总额最高为基数**5倍** |
| **第十四条** | 2026年5月1日起施行，法释〔2021〕4号同时废止 |
