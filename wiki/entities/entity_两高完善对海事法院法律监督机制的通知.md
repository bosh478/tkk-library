## 通知要点

确定下列设区的市级人民检察院对海事法院的民事诉讼、行政诉讼、执行活动履行法律监督职责：

| 海事法院 | 监督检察院 |
|----------|------------|
| 大连海事法院 | 辽宁省大连市人民检察院 |
| 青岛海事法院 | 山东省青岛市人民检察院 |
| 南京海事法院 | 江苏省南京市人民检察院 |
| 宁波海事法院 | 浙江省宁波市人民检察院 |
| 厦门海事法院 | 福建省厦门市人民检察院 |
| 北海海事法院 | 广西壮族自治区北海市人民检察院 |
| 海口海事法院 | 海南省人民检察院第一分院 |
| 上海海事法院 | 上海市人民检察院第三分院 |
| 天津海事法院 | 天津市人民检察院第三分院 |
| 广州海事法院 | 广东省人民检察院广州铁路运输分院 |
| 武汉海事法院 | 湖北省人民检察院武汉铁路运输分院 |
