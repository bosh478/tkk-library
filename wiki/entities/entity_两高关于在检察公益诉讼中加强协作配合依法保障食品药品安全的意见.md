## 关键要素

- **发文机关**：最高人民检察院、中央网信办、国务院食品安全办、司法部、农业农村部、国家卫生健康委员会、海关总署、国家市场监督管理总局、国家广播电视总局、国家粮食和物资储备局、国家药品监督管理局
- **发布日期**：2020.07.28
- **生效日期**：2020.07.28
- **时效性**：现行有效

## 线索移送重点

- 校园及其周边、餐饮聚集区、农贸批发市场
- 种养殖生产基地、"菜篮子"产品主产区、屠宰场
- 食品和副食品批发市场、冷库物流中心
- 违法行为规模化、组织化、链条化
- 涉及婴幼儿食品和药品
- 利用网络、电商平台、社交媒体、电视购物
- 人民群众反映强烈、社会影响恶劣、舆论高度关注

## 协作机制

| 机制 | 内容 |
|------|------|
| 线索移送机制 | 行政执法与刑事司法衔接，食品药品有关部门发现线索及时移送检察机关 |
| 交流会商机制 | 定期会商研判，重大案件、事件和舆情及时相互通报 |
| 信息共享机制 | 逐步建立食品药品领域行政监管与检察公益诉讼信息共享平台 |
| 立案管辖 | 一般由违法行使职权或不作为的行政机关所在地的同级检察院立案 |
| 调查取证 | 食品药品有关部门在检验检测、鉴定评估等方面提供专业咨询和技术支持 |

## 诉前程序

- 立案后七日内告知食品药品有关部门，听取行政机关意见
- 被监督行政机关15日内未采纳意见或国家利益、社会公共利益未得到有效保护的，继续调查
- 食品药品有关部门接到检察建议书后应书面反馈
