# 违反公安行政管理行为名称释义与实务指南

## 概述

《违反公安行政管理行为名称释义与实务指南》（2021年版）由主编孙茂利编著，中国民主法制出版社2021年3月出版。本书依据公安部《违反公安行政管理行为的名称及其适用意见》（公通字〔2020〕8号），对783种违反公安行政管理行为的名称进行了详细释义。

## 八大类违反公安行政管理行为

### 一、境外非政府组织境内活动管理（1-20）

共20种违法行为，主要依据《境外非政府组织境内活动管理法》。

| 序号 | 行为名称 | 法律依据 |
|------|----------|----------|
| 1 | 未按规定办理涉境外非政府组织变更登记、备案相关事项 | 《境外非政府组织境内活动管理法》第45条 |
| 2 | 未按涉境外非政府组织登记、备案事项开展活动 | 同上 |
| 3 | 涉境外非政府组织在境内从事、资助营利性活动、募捐、违规发展会员 | 同上 |
| 4 | 违反涉境外非政府组织规定取得使用资金、开立使用银行账户、进行会计核算 | 同上 |
| 5 | 代表机构未按规定报送年度计划、报送公开年度报告 | 同上 |
| 6 | 拒不接受、不按规定接受涉境外非政府组织监督检查 | 同上 |
| 7-20 | 非法取得代表机构登记证书、伪造变造证件、危害国家安全等 | 《境外非政府组织境内活动管理法》第46-47条 |

**核心要点：**
- 境外非政府组织在中国境内不得从事营利性活动、政治活动，不得非法从事或资助宗教活动
- 代表机构应于每年12月31日前报送下一年度活动计划
- 境外非政府组织应于每年1月31日前向业务主管单位报送上一年度工作报告
- 境外人员违反规定的，可依法限期出境、遣送出境或驱逐出境

### 二、治安管理（21-441）

共421种违法行为，是本书占比最大的部分，依据《治安管理处罚法》《人民警察法》等法律法规。

**核心要点：**

## 违法行为认定要点

### 一、主体分类

违反公安行政管理行为的主体可分为：

1. **一般主体**：大多数违法行为，如盗窃、殴打他人、扰乱公共场所秩序等
2. **特殊主体**：需具备特定身份或资质，如：
   - 境外非政府组织代表机构
   - 人民警察（非法持有使用警用标志的主体为非警察）
   - 旅馆业经营者、房屋出租人
   - 网络运营者
   - 交通运输工具负责人

### 二、主观方面

1. **故意**：大多数违法行为要求故意，如招摇撞骗、伪造证件、赌博、卖淫嫖娼等
2. **过失**：部分行为包含过失要件，如：
   - 过失引起火灾
   - 危险物质被盗、被抢、丢失不报
   - 发生危险货物泄漏不报

### 三、违法与犯罪的界限

| 违法行为 | 犯罪标准 | 立案追诉标准 |
|----------|----------|--------------|
| 非法制造贩卖警用标志 | 情节严重 | 成套制式服装30套以上，或警械10件以上，或非法经营额5000元以上 |
| 盗窃 | 多次盗窃、入户盗窃、携带凶器盗窃、扒窃（刑法第264条） | - |
| 赌博 | 聚众赌博、以赌博为业（刑法第303条） | - |
| 寻衅滋事 | 情节严重或恶劣（刑法第293条） | - |
| 非法侵入住宅 | 情节严重（刑法第245条） | - |

### 四、共性与差异

| 类别 | 共同特征 | 差异要点 |
|------|----------|----------|
| 扰乱单位秩序 vs 聚众冲击国家机关 | 主体、客体相似 | 聚众冲击国家机关针对特定国家机关 |
| 盗窃 vs 抢夺 vs 抢劫 | 侵犯财产 | 暴力程度递增 |
| 非法侵入住宅 vs 非法搜查 | 侵犯住宅权 | 搜查需特定法律授权 |
| 治安拘留 vs 刑事拘留 | 限制人身自由 | 性质、法律依据、期限不同 |

## 处罚裁量标准

### 治安管理处罚档次

| 档次 | 罚款金额 | 拘留期限 | 适用情形 |
|------|----------|----------|----------|
| 情节较轻 | 500元以下 | 5日以下 | 危害后果小、主动消除影响 |
| 一般 | 500元以下 | 5-10日 | 常规违法情形 |
| 情节较重 | 500-1000元 | 10-15日 | 造成较重后果、拒不改正 |

### 单位违法的处罚

1. **双罚制**：对单位处罚款，对直接负责的主管人员和其他直接责任人员处罚款或拘留
2. **直接负责的主管人员**：起决定、批准、授意、纵容、指挥作用的人员
3. **其他直接责任人员**：具体实施并起较大作用的人员

### 从重处罚情节

1. 阻碍人民警察依法执行职务
2. 拒不停止违法行为，造成严重后果
3. 针对残疾人、老年人、未成年人实施
4. 六个月内曾受过治安管理处罚
