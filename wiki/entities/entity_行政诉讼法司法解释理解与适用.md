## 概述

《最高人民法院关于适用〈中华人民共和国行政诉讼法〉的解释》（法释〔2018〕1号）于2017年11月13日由最高人民法院审判委员会第1726次会议讨论通过，2018年2月8日正式施行。

本解释共163条，分为十三个部分，是对《若干解释》（法释〔2000〕8号）、《适用解释》（法释〔2015〕9号）的全面修改、补充和完善。

**主要内容**：
1. 明确行政诉讼受案范围边界
2. 总结行政诉讼管辖改革成果
3. 明确界定当事人资格
4. 完善行政诉讼证据规则
5. 全面落实立案登记制度
6. 规范审理判决程序
7. 规范行政机关负责人出庭应诉
8. 落实复议机关作共同被告制度
9. 细化规范性文件附带审查

## 一、受案范围（第1-2条）

### 可诉行政行为的标准（第1条）

**可诉行政行为的特征**：
1. **外部性**：行政机关对公民、法人或其他组织实施
2. **终局性**：已对相对人权利义务产生实际影响
3. **法效性**：直接产生法律效果

### 五种不可诉行为（第1条）

1. **内部行为**：不产生外部法律效力的行为（内部沟通、会签意见、层报咨询等）
2. **过程性行为**：为作出行政行为而进行的准备、论证、研究等
3. **协助执行行为**：依照法院生效裁判作出的行为（行政机关扩大执行范围或采取违法方式的除外）
4. **内部层级监督行为**：上下级之间的内部管理事务
5. **信访办理行为**：登记、受理、交办、转送等，对信访人不具强制力

### "法律"的界定（第2条）

- **"国家行为"**：国务院、中央军事委员会、国防部、外交部等根据宪法和法律的授权，以国家名义实施的有关国防和外交事务的行为
- **"具有普遍约束力的决定、命令"**：行政机关针对不特定对象发布的能反复适用的规范性文件
- **"对行政机关工作人员的奖惩、任免等决定"**：行政机关作出的涉及行政机关工作人员公务员权利义务的决定
- **"法律规定由行政机关最终裁决的行政行为"中的"法律"**：全国人民代表大会及其常务委员会制定、通过的规范性文件

## 二、管辖（第3-11条）

### 级别管辖

| 法院 | 管辖案件 |
|------|----------|
| 基层法院 | 一般第一审行政案件 |
| 中级法院 | 海关案件；本辖区重大复杂案件；国务院部门或县级以上政府为被告的案件 |

### 地域管辖

- **被告所在地法院**管辖
- **不动产专属管辖**：因行政行为导致不动产物权变动而提起的诉讼

### 跨行政区划改革（第3条）

- 经最高法批准，高级法院可确定若干法院跨行政区域管辖行政案件
- 铁路运输法院等专门法院审理行政案件，应执行行政诉讼法第十八条第二款规定
- 专门人民法院不审理行政案件（知识产权法院、海事法院经授权的除外）

### 管辖恒定原则（第4条）

立案后，受诉人民法院的管辖权不受当事人住所地改变、追加被告等事实和法律状态变更的影响。

### "重大复杂案件"的认定（第5条）

1. 社会影响重大的共同诉讼案件
2. 涉外或者涉及香港、澳门、台湾地区的案件
3. 其他重大、复杂案件

### 原告所在地（第8条）

包括：户籍所在地、经常居住地、被限制人身自由地

### 管辖异议（第10-11条）

- 当事人应在接到起诉状副本之日起**十五日内**提出管辖异议
- 法院审查后确定有管辖权的，不因当事人增加或变更诉讼请求而改变（违反级别管辖、专属管辖的除外）
- 发回重审或按一审程序再审的案件，当事人提出管辖异议的，不予审查

## 三、诉讼参加人（第12-33条）

### 原告资格

**"利害关系"的认定**（第12条）：
1. 被诉行政行为涉及其相邻权或者公平竞争权
2. 在行政复议等行政程序中被追加为第三人
3. 要求行政机关依法追究加害人法律责任
4. 撤销或者变更行政行为涉及其合法权益
5. 为维护自身合法权益向行政机关投诉，具有处理投诉职责的行政机关作出或者未作出处理
6. 其他与行政行为有利害关系的情形

**特殊主体原告资格**：
- **投诉举报者**（第12条）：为维护自身合法权益向行政机关投诉，具有处理投诉职责的行政机关作出或未作出处理
- **债权人**（第13条）：以行政机关对债务人所作行政行为损害债权实现为由（但行政机关作出行政行为时依法应予保护或应予考虑的除外）
- **非营利法人出资人**（第17条）：事业单位、社会团体、基金会、社会服务机构等非营利法人的出资人、设立人
- **业主委员会**（第18条）：对涉及业主共有利益的行政行为，可以自己的名义起诉

### 被告资格

| 类型 | 被告确定规则 |
|------|-------------|
| **经批准的行政行为**（第19条） | 以在对外发生法律效力的文书上署名的机关为被告 |
| **内设机构、派出机构**（第20条） | 组建并赋予行政管理职能但不具有独立承担法律责任能力的机构 → 组建机关；超出法定授权范围的 → 实施机构或组织；无授权的 → 委托的行政机关 |
| **开发区管理机构**（第21条） | 国务院、省级政府批准设立的 → 该机构；其职能部门作出的 → 职能部门；其他 → 开发区管理机构；无行政主体资格的 → 设立的地方政府 |
| **复议机关"改变原行政行为"**（第22条） | 仅改变处理结果；改变认定的主要事实和证据、适用的规范依据但未改变处理结果的，视为维持 |
| **村委会、居委会**（第24条） | 依据法律、法规、规章授权履行行政管理职责的 |
| **事业单位、行业协会**（第24条） | 高等学校、律师协会、注册会计师协会等依据法律、法规、规章授权实施行政行为的 |
| **房屋征收部门**（第25条） | 市、县级人民政府确定的房屋征收部门 |

### 共同诉讼

- **必要共同诉讼**：当事人一方或双方为两人以上，因同一行政行为发生行政争议，必须合并审理（第27条）
- **普通共同诉讼**：因同类行政行为发生的行政案件，法院认为可以合并审理并经当事人同意（第73条）

### 诉讼代理人

**"近亲属"的范围**（第14条）：配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女和其他具有扶养、赡养关系的亲属

## 四、证据（第34-47条）

### 举证期限

| 主体 | 期限规定 |
|------|----------|
| 被告 | 收到起诉状副本之日起**十五日内**提出 |
| 原告、第三人 | 应当在开庭审理前或者人民法院指定的期限提交 |

### 非法证据排除（第43条）

"以非法手段取得的证据"包括：
1. 严重违反法定程序收集的证据材料
2. 违反法律强制性规定的手段获取且侵害他人合法权益的证据材料
3. 以利诱、欺诈、胁迫、暴力等手段获取的证据材料

### 当事人到庭义务（第44条）

- 法院可要求当事人本人或行政机关执法人员到庭接受询问
- 拒绝到庭、拒绝接受询问或拒绝签署保证书 → 待证事实欠缺其他证据佐证的，不予认定

### 举证责任分配

| 情形 | 举证责任规则 |
|------|-------------|
| **被告原因导致损害**（第47条） | 由被告承担举证责任 |
| **损失无法认定** | 由负有举证责任的当事人申请鉴定（法律、法规规定应评估或鉴定的除外）；拒绝申请的，承担不利后果 |
| **客观原因无法鉴定** | 法院结合当事人主张和在案证据，遵循法官职业道德，运用逻辑推理和生活经验，酌情确定赔偿数额 |

---

## 五、期间、送达（第48-52条）

### 期间计算

- **立案期限**：人民法院接到起诉状后7日内决定是否立案
- **审理期限**：第一审案件6个月；第二审案件3个月；再审案件按原程序

### 送达

- 直接送达：送达诉讼文书，义不容辞在当事人住所地
- 在当事人住所地以外向当事人直接送达诉讼文书须经两次未果后才能公告送达

---

## 六、起诉与受理（第53-70条）

### 立案登记要求（第53-54条）

**起诉人须提交的材料**：
1. 原告身份证明及有效联系方式
2. 被诉行政行为或不作为存在的材料
3. 原告与被诉行为具有利害关系的材料
4. 其他法院认为需要的材料

### 审查权力与释明义务（第55条）

- 法院应当审查起诉状内容和材料是否完备
- 材料欠缺的，必须**一次性**告知需要补正的内容、期限
- 当事人拒绝补正或经补正仍不符合条件的，退回诉状并记录在册

### 起诉期限

| 情形 | 期限规定 |
|------|----------|
| **复议维持双被告**（第59条） | 以复议决定送达时间确定起诉期限 |
| **未告知诉权和起诉期限**（第64条） | 从知道或应当知道起诉期限之日起计算，但从知道或应当知道行政行为内容之日起最长不得超过**1年** |
| **不知道行政行为内容**（第65条） | 从知道或应当知道行政行为内容之日起计算，涉及不动产的**20年**，其他**5年** |
| **不履行法定职责**（第66条） | 起诉期限从履行期限届满之日起计算；未规定履行期限的，从作出要求履行决定之日起计算；紧急情况立即请求的，期限从知道或应当知道时起算 |

### 驳回起诉情形（第69条）

1. 不符合起诉条件
2. 被告不适格且不同意变更
3. 未预交诉讼费按撤诉处理后重复起诉
4. 其他法定情形

---

## 七、审理与判决（第71-136条）

### 审理程序

**普通程序**（第71条）：
- 传唤诉讼参与人
- 延期开庭须在开庭3日前通知
- 合并审理须经当事人同意（第73条）

**简易程序**（第102-105条）：

| 适用条件 | 内容 |
|---------|------|
| 法定情形 | 涉及金额30万元以下；政府信息公开案件；当事人各方同意适用 |
| 传唤方式 | 电话、传真、手机短信等简便方式通知 |
| 审理期限 | 45日 |
| 举证答辩期 | 不得超过15日 |

### 判决类型

| 判决类型 | 适用条件 |
|---------|---------|
| **撤销判决** | 行政行为违法或主要证据不足 |
| **重作判决**（第90条） | 撤销判决的同时可以判决重新作出行政行为 |
| **履行判决**（第91条） | 行政机关不履行法定职责 |
| **给付判决**（第92条） | 行政机关依法负有给付义务 |
| **确认违法判决**（第96条） | 撤销已无实际意义；行为程序违法但撤销会影响公共利益 |
| **确认无效判决**（第99条） | 重大且明显违法 |
| **驳回诉讼请求** | 行政行为合法或原告请求无事实和法律依据 |

### 调解（第84-86条）

- 行政诉讼可以调解
- 调解应当遵循自愿、合法原则
- 调解协议不得损害国家利益、社会公共利益和他人合法权益

### 被告改变行政行为（第81条）

被告在一审期间改变被诉行政行为，应当书面告知人民法院。原告或者第三人不同意改变的，不影响案件审理。

### 赔偿与补偿（第95-98条）

- **违法赔偿**：被诉行政行为违法或无效造成原告损失，原告可请求行政赔偿
- **共同过错**：原告或第三人的损失系由其自身过错和行政机关的违法行政行为共同造成的，依据各方行为与损害结果之间的因果关系和作用力大小确定责任
- **不作为赔偿**：因行政机关不履行、拖延履行法定职责致使原告遭受损害的，承担赔偿责任

## 八、行政机关负责人出庭应诉（第128-132条）

### 行政机关负责人的范围（第128条）

包括：
- 正职、副职负责人
- 其他参与分管的负责人

**出庭应诉要求**：
- 负责人出庭应诉的，可另行委托1-2名诉讼代理人
- 负责人不能出庭的，应当委托**行政机关相应的工作人员**出庭
- **不得仅委托律师出庭**

### "绝对保留"出庭情形（第129条）

**必须出庭**的情形：
1. 涉及**重大公共利益**的案件
2. **社会高度关注**的案件
3. **可能引发群体性事件**的案件
4. 人民法院**书面建议**行政机关负责人出庭的案件

### 不出庭的法律后果（第132条）

- 负责人和工作人员均不出庭，仅委托律师出庭的
- 或者人民法院书面建议负责人出庭而负责人不出庭的
- 人民法院应当**记录在案**并在裁判文书中载明
- 可以**建议有关机关**依法作出处理

---

## 九、复议机关作共同被告（第133-136条）

### 共同被告的确定（第133-134条）

**构成共同被告的情形**：
1. 复议机关决定**维持**原行政行为
2. 复议决定既有维持又有改变或不予受理申请内容
3. 复议机关**驳回复议申请**（以复议申请不符合受理条件为由驳回的除外）

**原告只起诉其中一个的**：
- 法院应当告知追加
- 不同意追加的，法院依职权追加为共同被告

**级别管辖**：以作出原行政行为的行政机关确定

### 审查对象与举证责任（第135条）

| 审查对象 | 举证责任 |
|---------|---------|
| **原行政行为合法性** | 作出原行政行为的行政机关和复议机关**共同承担**举证责任，可由其中一个机关实施 |
| **复议决定合法性** | 复议机关单独承担 |
| **复议程序中收集的证据** | 可作为认定原行政行为合法的依据 |

### 裁判方式（第136条）

| 情形 | 裁判方式 |
|------|---------|
| 原行政行为和复议决定均合法 | 判决驳回原告针对两者的诉讼请求 |
| 原行政行为和复议决定均违法 | 一并撤销，可判决重新作出 |
| 原行政行为违法、复议决定合法 | 撤销复议决定或确认违法，驳回针对原行政行为的诉讼请求 |
| 原行政行为合法、复议决定违法 | 撤销复议决定或确认违法 |
| **赔偿** | 原行政机关承担；复议决定**加重损害**的，复议机关对**加重部分**承担 |

## 十、相关民事争议一并审理（第137-144条）

### 适用范围（第137-139条）

**可以一并审理的情形**：
- 涉及**行政许可、登记、征收、征用**的行政诉讼
- 行政机关对**民事争议**所作的裁决的行政诉讼

**提出时间**：
- 第一审开庭审理前
- 有正当理由的，可在法庭调查中提出

**排除情形**：
1. 法律规定应当由行政机关先行处理的
2. 违反民事诉讼法专属管辖规定或协议管辖约定的
3. 约定仲裁或已经提起民事诉讼的
4. 其他不宜一并审理的情形

### 审判组织（第140条）

- 民事争议应当**单独立案**
- 由审理行政案件的**同一审判组织**审理
- 审理行政机关对民事争议所作裁决的案件，**不另行立案**

### 法律适用（第141条）

- 适用**民事法律规范**的相关规定
- 当事人在调解中对民事权益的处分，**不能作为审查被诉行政行为合法性的根据**

## 十一、规范性文件一并审查（第145-151条）

### 审查程序（第145-147条）

| 程序事项 | 内容 |
|---------|------|
| **管辖** | 由行政行为案件管辖法院一并审查 |
| **提出时间** | 第一审开庭审理前；有正当理由的，可在法庭调查中提出 |
| **听取意见** | 发现规范性文件可能不合法的，应当听取制定机关的意见 |
| **出庭陈述** | 制定机关申请出庭陈述意见的，法院应当准许 |

### "规范性文件不合法"的认定（第148条）

1. **超越职权**：超越制定机关的法定职权或者超越法律、法规、规章的授权范围
2. **抵触上位法**：与法律、法规、规章等上位法的规定相抵触
3. **违法增减义务**：没有法律、法规、规章依据，违法增加公民、法人和其他组织义务或减损其合法权益
4. **程序违法**：未履行法定批准程序、公开发布程序，严重违反制定程序
5. **其他违法**：其他违反法律、法规以及规章规定的情形

### 处理方式（第149-150条）

| 审查结论 | 处理方式 |
|---------|---------|
| **合法** | 作为认定行政行为合法的依据 |
| **不合法** | 不作为认定行政行为合法的依据，在裁判理由中予以阐明 |

**司法建议**：
- 法院可在裁判生效之日起**3个月**内向制定机关提出修改或废止的司法建议
- 可抄送制定机关的同级人民政府、上一级行政机关、监察机关以及备案机关
- 涉及多个部门联合制定的，向主办机关或共同上一级行政机关发送

---

## 十二、执行（第152-161条）

### 执行名义（第152条）

行政诉讼的执行名义包括：
1. 生效的判决书、裁定书
2. 调解书
3. 行政赔偿判决书

### 申请强制执行期限（第153条）

| 情形 | 期限 |
|------|------|
| **公民** | 1年 |
| **法人或其他组织** | 180日 |
| **行政机关** | 180日（申请执行生效判决书、裁定书） |

### 非诉执行（第155-161条）

**申请条件**：
1. 行政行为已生效
2. 给付义务已届满
3. 当事人不履行
4. 在法定期限内提出

**审查期限**：30日内作出裁定；情况复杂的，经院长批准可以延长30日

**不准予执行的情形**：
1. 明显缺乏事实根据
2. 明显缺乏法律依据
3. 其他明显违法并损害被执行人合法权益的情形

## 核心要点速查

### 复议维持双被告
- 原告只起诉一个 → 法院应告知追加 → 不同意追加的，法院依职权追加
- 举证责任：原行政行为由两机关共同举证；复议决定由复议机关单独举证

### 起诉期限要点
- 未告知诉权和起诉期限：**1年**（从知道行政行为内容之日起最长不超过1年）
- 不知道行政行为内容：不动产**20年**，其他**5年**
- 复议维持双被告：以复议决定送达时间确定

### 行政机关负责人出庭
- **必须出庭**：重大公共利益、社会高度关注、可能引发群体性事件、法院书面建议
- **不能出庭**：须委托相应工作人员，不得仅委托律师

### 规范性文件审查
- 提出时间：第一审开庭审理前
- 不合法的处理：法院可发送司法建议，制定机关应在**60日内**书面答复
