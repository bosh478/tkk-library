## 概述

《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号）于2023年5月23日通过，2023年12月5日起施行，共69个条文。最高人民法院民事审判第二庭、研究室编著。

本解释是新中国成立以来第一部以"法典"命名的法律的配套司法解释，系统规定了合同编通则适用中的核心疑难问题，贯彻历史思维、体系思维、辩证思维、程序思维四大方法论。

---

## 核心要点

### 一、一般规定

#### 1. 合同条款解释规则（第一条）

人民法院依据《民法典》第一百四十二条第一款、第四百六十六条第一款解释合同条款时，应当以**词句的通常含义**为基础，结合：
- 相关条款
- 合同的性质和目的
- 习惯
- 诚信原则
- 缔约背景、磋商过程、履行行为等因素

**解释选择原则**：
- 对合同条款有两种以上解释，可能影响该条款效力的 → **选择有利于该条款有效的解释**
- 属于**无偿合同**的 → 选择对债务人负担较轻的解释

#### 2. 交易习惯的认定（第二条）

认定为《民法典》所称"交易习惯"的条件：
1. 不违反法律、行政法规的强制性规定且不违背公序良俗
2. 符合下列情形之一：
   - 当事人之间在交易活动中的**惯常做法**
   - 在交易行为**当地或者某一领域、某一行业**通常采用并为交易对方订立合同时所知道或者应当知道的做法
3. **举证责任**：由提出主张的当事人一方承担

---

### 二、合同的订立

#### 3. 合同成立要件（第三条）

当事人对合同是否成立存在争议，人民法院能够确定**当事人姓名或者名称、标的和数量**的，一般应当认定合同成立（法律另有规定或当事人另有约定除外）。

**实务要点**：
- 合同不成立时，法院应将合同是否成立作为**焦点问题**进行审理
- 可根据案件情况**重新指定举证期限**

#### 4. 竞价方式订立合同（第四条）

| 方式 | 合同成立时间 |
|------|--------------|
| 招标 | **中标通知书到达中标人时** |
| 现场拍卖、网络拍卖 | **拍卖师落槌、电子交易系统确认成交时** |
| 产权交易所等机构主持拍卖、挂牌 | **公布的拍卖公告、交易规则等确定的成立条件具备时** |

#### 5. 第三人欺诈、胁迫（第五条）

- 第三人实施欺诈、胁迫行为，使当事人在违背真实意思的情况下订立合同
- **受损失的当事人**请求第三人承担赔偿责任的 → 人民法院依法予以支持
- 当事人亦有违背诚信原则的行为的 → 根据各自过错确定相应的责任

#### 6. 预约合同的认定（第六条）

当事人以**认购书、订购书、预订书**等形式约定在将来一定期限内订立合同，或者为担保在将来一定期限内订立合同交付了定金，**能够确定将来所要订立合同的主体、标的等内容的**，人民法院应当认定预约合同成立。

**不构成预约**：
- 仅表达交易意向
- 未约定在一定期限内订立合同
- 虽然有约定但难以确定主体、标的等内容

**本约合同认定**：已就合同标的、数量、价款或报酬等主要内容达成合意 + 未明确约定另行订立合同 / 一方已实施履行行为且对方接受

#### 7. 违反预约合同的认定（第七条）

预约合同生效后，当事人一方：
- **拒绝订立本约合同**，或
- **在磋商订立本约合同时违背诚信原则**导致未能订立本约合同

→ 人民法院应当认定该当事人不履行预约合同约定的义务

**判断是否违背诚信原则**：综合考虑提出的条件是否明显背离预约合同约定的内容、是否已尽合理努力进行协商等因素

#### 8. 违反预约合同的违约责任（第八条）

- **有约定**：按照约定
- **没有约定**：综合考虑预约合同在内容上的完备程度、订立本约合同的条件的成就程度等因素**酌定**
- **不能要求强制履行本约**：仅能请求赔偿损失

### 三、合同的效力

#### 9. "缺乏判断能力"的认定（第十一条）

根据当事人的**年龄、智力、知识、经验**并结合交易的复杂程度，能够认定其对合同的性质、合同订立的法律后果或者交易中存在的特定风险**缺乏应有的认知能力的**，人民法院可以认定构成《民法典》第一百五十一条规定的"缺乏判断能力"。

→ 可据此请求撤销合同

#### 10. 批准生效合同的法律适用（第十二条）

合同依法成立后，负有**报批义务的当事人不履行报批义务或者履行不符合约定/规定的**：
- 对方请求继续履行报批义务 → **支持**
- 对方主张解除合同并请求承担违反报批义务的赔偿责任 → **支持**

**判决后仍不履行**：对方主张解除合同并参照违约责任请求承担赔偿责任的 → **支持**

**未获批准的责任**：
- 报批义务人已办理申请批准手续/已履行生效判决确定的报批义务，批准机关决定不予批准 → **不承担**赔偿责任
- 因可归责于报批义务人的原因（如迟延履行）导致合同未获批准 → **承担**损失

#### 11. 备案/批准合同效力（第十三条）

合同存在无效或可撤销情形，当事人以该合同已在有关行政管理部门**办理备案**、已经**批准机关批准**或已**办理财产权利变更登记、移转登记**等为由主张合同有效的 → **不予支持**

#### 12. 多份合同的效力认定（第十四条）

**阴阳合同**：
- 以虚假意思表示订立的合同 → **无效**
- 隐藏的真实意思表示合同 → 依据《民法典》第一百五十三条（违法）或第五百零二条第二款（批准）认定效力

**合同变更**：
- 多份合同均系真实意思表示 + 不存在其他影响合同效力情形 → 在查明成立顺序和实际履行情况基础上认定合同内容是否发生变更
- 法律、行政法规**禁止变更**合同内容的 → 该变更**无效**

#### 13. 名实不符与合同效力（第十五条）

不拘泥于合同使用的名称，根据合同约定的**内容**认定权利义务关系：
- 当事人主张的权利义务关系与根据合同内容认定的不一致 → 结合缔约背景、交易目的、交易结构、履行行为、是否存在虚构交易标的等事实认定**实际民事法律关系**

#### 14. 违法无效的例外情形（第十六条）

合同违反法律、行政法规的强制性规定，**不导致无效**的五种情形（符合《民法典》第一百五十三条第一款"该强制性规定不导致该民事法律行为无效的除外"）：

1. 强制性规定旨在维护社会公共秩序，但合同履行对公共秩序造成的影响**显著轻微**，认定无效将导致处理结果**有失公平公正**
2. 强制性规定旨在维护**国家利益**（税收、土地出让金等）或其他民事主体的合法利益，认定有效**不影响该规范目的实现**
3. 强制性规定旨在要求当事人一方加强**风险控制、内部管理**，对方无能力或无义务审查是否违反，认定无效将使其承担不利后果
4. 当事人在合同订立时违反强制性规定，但订立后已具备补正条件却**违背诚信原则**不予补正
5. 法律、司法解释规定的其他情形

**但书**：如果强制性规定旨在规制**合同订立后的履行行为**，当事人以合同违反强制性规定为由请求认定无效 → **不予支持**，但合同履行必然导致违反强制性规定或法律、司法解释另有规定的除外

#### 15. 违背公序良俗无效（第十七条）

合同虽然不违反法律、行政法规的强制性规定，但有下列情形之一的，依据《民法典》第一百五十三条第二款认定无效：
1. 影响**政治安全、经济安全、军事安全**等国家安全的
2. 影响**社会稳定、公平竞争秩序**或损害社会公共利益等违背**社会公共秩序**的
3. 背离**社会公德、家庭伦理**或有损**人格尊严**等违背**善良风俗**的

**认定考量因素**（综合判断）：
- 当事人的主观动机和交易目的
- 政府部门的监管强度
- 一定期限内当事人从事类似交易的频次
- 行为的社会后果
- 当事人确因生活需要进行交易

#### 16. 无权处分的合同效力（第十九条）

- 以转让或者设定财产权利为目的订立的合同，当事人或真正权利人仅以让与人订立合同时对标的物**没有所有权或处分权**为由主张合同无效 → **不予支持**
- 合同有效，但因未取得真正权利人事后同意或让与人事后未取得处分权导致不能履行 → 受让人可主张**解除合同并请求赔偿**
- 合同被认定有效 + 让与人已交付或移转登记至受让人 → 真正权利人可请求认定财产权利未发生变动或请求**返还财产**（受让人符合善意取得条件的除外）

#### 17. 越权代表的合同效力（第二十条）

法定代表人、负责人未取得授权以法人、非法人组织名义订立合同：
- 相对人未尽**合理审查义务** → 合同**不对**法人、非法人组织发生效力（但可请求其承担相应赔偿责任）
- 相对人已尽**合理审查义务** → 构成**表见代表**，依据《民法典》第五百零四条处理

**超越权限的类型**：
1. 依法应当由权力机构或决策机构决议的事项
2. 依法应当由执行机构决定的事项
3. 依法应当由法定代表人、负责人代表法人、非法人组织实施的事项
4. 不属于通常情形下依其职权可以处理的事项

#### 18. 印章与合同效力（第二十二条）

- 合同加盖的印章不是备案印章或系伪造 → **不能以此为由**主张合同对法人、非法人组织不发生效力
- 仅有法定代表人、负责人或工作人员签名/按指印而未加盖印章 → 相对人能证明其未超越权限的 → **对法人、非法人组织发生效力**
- 仅加盖印章而无人员签名 → 相对人能证明合同系在其权限范围内订立的 → **对法人、非法人组织发生效力**

### 四、合同的履行

#### 19. 从给付义务的履行与救济（第二十六条）

- 当事人一方未根据法律规定或合同约定履行**开具发票、提供证明文件**等非主要债务
- 对方请求继续履行该债务并赔偿因怠于履行造成的损失 → **支持**
- 对方请求解除合同 → **不予支持**，但不履行致使不能实现合同目的或当事人另有约定的除外

#### 20. 债务履行期限届满后达成的以物抵债协议（第二十七条）

- **诺成合同**：自当事人意思表示一致时生效（非实践合同）
- 债务人或第三人未按照约定履行，经催告后在合理期限内仍不履行 → 债权人可**选择请求履行原债务或以物抵债协议**

**重要澄清**：
- 人民法院根据该协议制作调解书 → 债权人**不能**主张财产权利自调解书生效时发生变动或具有对抗善意第三人的效力
- 让与担保：债务人或第三人已将财产权利转移至债权人名下 → 可依据《民法典担保制度司法解释》第六十八条主张优先受偿

#### 21. 债务履行期限届满前达成的以物抵债协议（第二十八条）

**清算型**（约定可以拍卖、变卖、折价）：约定有效
**归属型**（约定抵债财产归债权人所有）：约定无效，但不影响其他部分效力

- 未将财产权利转移至债权人名下 → 债权人主张优先受偿 → **不予支持**
- 已将财产权利转移至债权人名下 → 依据《民法典担保制度司法解释》第六十八条处理

#### 22. 向第三人履行的合同（第二十九条）

- 第三人请求债务人向自己履行债务 → **支持**
- 第三人请求行使撤销权、解除权等民事权利 → **不予支持**（法律另有规定除外）
- 合同依法被撤销或被解除 → 债务人请求债权人返还财产 → **支持**

#### 23. 第三人代为清偿（第三十条）

认定为对履行债务具有**合法利益**的第三人：
1. 保证人或者提供物的担保的第三人
2. 担保财产的受让人、用益物权人、合法占有人
3. 担保财产上的后顺位担保权人
4. 对债务人的财产享有合法权益且该权益将因财产被强制执行而丧失的第三人
5. 债务人为法人或非法人组织的，其出资人或设立人
6. 债务人为自然人的，其近亲属
7. 其他对履行债务具有合法利益的第三人

#### 24. 同时履行抗辩权与先履行抗辩权（第三十一条）

- 一方以对方没有履行非主要债务为由拒绝履行自己的主要债务 → **不予支持**
- 被告主张同时履行抗辩权且抗辩成立，未提起反诉 → 判决被告在原告履行债务的同时履行自己的债务，并在判项中明确**原告申请强制执行的条件**
- 被告主张先履行抗辩权且抗辩成立 → **驳回原告诉讼请求**（但不影响原告履行债务后另行起诉）

#### 25. 情势变更（第三十二条）

**适用条件**：
- 政策调整或市场供求关系异常变动导致价格发生当事人在订立合同时无法预见的、不属于商业风险的涨跌
- 继续履行对当事人一方明显不公平

**排除情形**：市场属性活跃、长期以来价格波动较大的**大宗商品以及股票、期货等风险投资型金融产品**

**法律效果**：
- 当事人请求变更合同 → **不得解除**
- 一方请求变更，对方请求解除 / 一方请求解除，对方请求变更 → 根据公平原则判决变更或解除
- 当事人事先约定排除适用 → **无效**

### 五、合同的保全

#### 26. 代位权（第三十三条至第四十一条）

**怠于行使权利的认定**：不以诉讼或仲裁方式向相对人主张其享有的债权或者与该债权有关的从权利，致使债权人的到期债权未能实现

**专属债权**（第五百三十五条第一款规定的"专属于债务人自身的权利"）：
1. 抚养费、赡养费或者扶养费请求权
2. 人身损害赔偿请求权
3. 劳动报酬请求权（超过债务人及其所扶养家属的生活必需费用的部分除外）
4. 请求支付基本养老保险金、失业保险金、最低生活保障金等保障当事人基本生活的权利
5. 其他专属于债务人自身的权利

**管辖**：被告住所地人民法院（不适用协议管辖）

**与仲裁协议的关系**：债务人或相对人以仲裁协议为由提出主管异议 → **不予支持**；但债务人或相对人在**首次开庭前**申请仲裁的 → 中止代位权诉讼

#### 27. 撤销权（第四十二条至第四十六条）

**明显不合理低价/高价的认定**：
- **低价**：未达到交易时交易地市场交易价或指导价的**70%**
- **高价**：高于交易时交易地市场交易价或指导价的**30%**
- **特殊情形**：债务人与相对人存在亲属关系、关联关系的 → 不受70%、30%限制

**可撤销的行为**：互易财产、以物抵债、出租或承租财产、知识产权许可使用等

**费用**：合理的律师代理费、差旅费等可认定为"必要费用"

### 六、合同的变更和转让

#### 28. 债权多重转让（第五十条）

- 债务人以已经向**最先通知**的受让人履行为由主张不再履行 → **支持**
- 债务人明知接受履行的受让人不是最先通知的受让人 → 最先通知的受让人可请求债务人继续履行或请求让与人承担违约责任
- 债务人已向非最先通知的受让人履行，最先通知的受让人请求接受履行的受让人返还财产 → **不予支持**（但受让人明知的除外）

#### 29. 债务加入人的追偿权（第五十一条）

- 第三人加入债务并与债务人约定追偿权 → 其履行债务后向债务人追偿 → **支持**
- 没有约定追偿权 → 依照不当得利等规定在其已履行债务范围内请求债务人向其履行 → **支持**（但第三人知道或应当知道加入债务会损害债务人利益的除外）

### 七、合同的权利义务终止

#### 30. 协商解除（第五十二条）

当事人就解除合同协商一致时未对违约责任、结算和清理等问题作出处理，一方主张合同已经解除 → **支持**（当事人另有约定除外）

#### 31. 通知解除合同的异议期限（第五十三条）

当事人以通知方式解除合同，以对方未在**约定的异议期限**或其他**合理期限**内提出异议为由主张合同已解除 → 人民法院应当审查其是否享有**法律规定或合同约定的解除权**：
- 享有解除权 → 合同自通知到达对方时解除
- 不享有解除权 → 不发生合同解除效力

#### 32. 抵销（第五十五条至第五十八条）

- 抵销权行使的效力：通知到达对方时生效
- 参照适用抵充规则
- **侵权行为人不得主张抵销**：故意实施侵权行为的人不得主张以其债务与受害人的债务抵销
- **已过诉讼时效债权的抵销**：债务人引用诉讼时效已过的债权进行抵销 → **不予支持**（但债务人知道或应当知道该债权诉讼时效已过的除外）

---

### 八、违约责任

#### 33. 合同终止时间（第五十九条）

- 依裁判终止合同 → 原则上以**起诉状副本送达对方的时间**作为合同权利义务关系终止的时间
- 根据案件情况以其他时间终止更符合公平原则和诚信原则的 → 人民法院在说明理由的基础上也可选择该时间

#### 34. 可得利益损失的计算（第六十条）

守约方可主张的损失包括因违约遭受的损失和合同履行后可以获得的利益（**可得利益**），受**可预见性规则**限制。

**计算方式**：
1. 扣除守约方为订立、履行合同支出的费用等**合理成本**后
2. 按照守约方能够获得的**生产利润、经营利润或转售利润**等计算
3. 不能将为取得利益而应当支出的成本作为损失重复计算

**替代交易**：守约方依法行使合同解除权并实施替代交易 → 按替代交易价格与合同价格的差额确定
**未实施替代交易**：按违约行为发生后合理期间内市场价格的差额确定

#### 35. 持续性定期合同中的可得利益（第六十一条）

以持续履行的债务为内容的定期合同（如租金、长期供应合同），一方不履行支付价款、租金等金钱债务，对方请求解除合同 → 参考合同主体、交易类型、市场价格变化、剩余履行期限等因素确定**寻找替代交易的合理期限**，按该期限对应的价款扣除相应履约成本确定可得利益

#### 36. 定金规则（第六十七条、第六十八条）

详见本解释关于定金罚则的具体规定。
