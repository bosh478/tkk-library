## 解释概述

《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》共69个条文，内容涉及《民法典》合同编通则部分的各个部分，是在清理《合同法司法解释（一）》《合同法司法解释（二）》等司法解释基础上，结合审判实践中的疑难问题制定而成。

### 指导思想

1. **尊重立法原意**：准确理解贯彻《民法典》的立法意图，确保司法解释条文符合立法原意
2. **坚持问题导向**：所有条文具有针对性，致力于解决实际问题，具有可操作性
3. **保持司法政策延续性**：对与《民法典》并无冲突且仍行之有效的规定尽可能保留
4. **坚持系统观念和辩证思维**：重视制度之间的联系，做到全面解决问题

## 条文结构

### 一、一般规定（第一条-第二条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第一条 | 合同条款的解释规则 | 以词句通常含义为基础，结合相关条款、合同性质目的、习惯、诚信原则，参考缔约背景、磋商过程、履行行为等因素确定争议条款含义 |
| 第二条 | 交易习惯的认定 | 当事人之间惯常做法或特定领域通常做法，可认定为"交易习惯" |

### 二、合同的订立（第三条-第十条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第三条 | 合同成立与合同内容 | 能确定当事人姓名或名称、标的、数量，一般认定合同成立 |
| 第四条 | 以竞价方式订立合同 | 招标方式自中标通知书到达中标人时成立；拍卖自落槌或电子交易系统确认成交时成立 |
| 第五条 | 合同订立中的第三人责任 | 第三人实施欺诈、胁迫，受损失当事人可请求第三人承担赔偿责任 |
| 第六条 | 预约合同的认定 | 认购书、订购书、预订书等形式约定将来订合同，或交付定金担保订立合同，可认定预约合同成立 |
| 第七条 | 违反预约合同的认定 | 拒绝订立本约或在磋商时违背诚信原则导致未能订立本约，认定违反预约合同 |
| 第八条 | 违反预约合同的违约责任 | 损失赔偿范围根据交易成熟度在信赖利益与履行利益之间酌定 |
| 第九条 | 格式条款的认定 | "为了重复使用"指目的而非实际使用；合同示范文本不排除格式条款认定 |
| 第十条 | 格式条款订入合同 | 提示义务针对"异常条款"；电子合同中勾选、弹窗等方式需举证证明符合提示要求 |

### 三、合同的效力（第十一条-第二十五条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第十一条 | "缺乏判断能力"的认定 | 根据当事人年龄、智力、知识、经验并结合交易复杂程度认定 |
| 第十二条 | 批准生效合同的法律适用 | 报批义务独立生效；判决履行后仍拒绝可请求解除并承担违约责任 |
| 第十三条 | 备案合同或已批准合同的效力 | 备案或批准不阻却合同无效或可撤销事由 |
| 第十四条 | 多份合同的效力认定 | 虚假意思表示订立的合同无效；隐藏合同依据《民法典》第153条第1款或第502条第2款认定效力 |
| 第十五条 | 名实不符与合同效力 | 根据合同约定的权利义务关系认定实际民事法律关系 |
| 第十六条 | 《民法典》第153条第1款但书的适用 | 违反强制性规定不导致合同无效的五种情形 |
| 第十七条 | 《民法典》第153条第2款的适用 | 违背公序良俗合同无效的认定考量因素 |
| 第十八条 | 不适用《民法典》第153条第1款的情形 | 强制性规定旨在限制或赋予民事权利的，依民事法律后果认定合同效力 |
| 第十九条 | 无权处分的合同效力 | 合同不因让与人无处分权而无效；受让人可请求解除合同并承担违约责任 |
| 第二十条 | 越权代表的合同效力 | 法定代表人和负责人未经授权以法人名义订合同，尽到合理审查义务的相对人可主张合同对法人发生效力 |
| 第二十一条 | 职务代理与合同效力 | 工作人员超越职权范围以法人名义订合同，法人有过错的可判决承担相应赔偿责任 |
| 第二十二条 | 印章与合同效力 | 印章真伪不是认定合同效力的唯一因素；综合签名、人员身份等认定 |
| 第二十三条 | 恶意串通的合同效力 | 法定代表人、负责人或代理人与相对人恶意串通损害法人利益，合同对法人不发生效力 |
| 第二十四条 | 合同不成立、无效、被撤销或确定不发生效力的法律后果 | 财产能够返还的应返还；不能返还或无必要返还的折价补偿 |
| 第二十五条 | 价款返还及其利息计算 | 按LPR计算资金占用费；无过错按存款基准利率计算 |

### 四、合同的履行（第二十六条-第三十二条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第二十六条 | 从给付义务的履行与救济 | 未履行开具发票等非主要债务，对方可请求继续履行并赔偿损失 |
| 第二十七条 | 债务履行期限届满后达成的以物抵债协议 | 诺成合同，自意思表示一致时生效；新债清偿规则 |
| 第二十八条 | 债务履行期限届满前达成的以物抵债协议 | 担保型以物抵债；约定到期不履行可拍卖、变卖、折价；约定归债权人所有无效 |
| 第二十九条 | 向第三人履行的合同 | 第三人可请求债务人向自己履行债务，但不得主张撤销权、解除权 |
| 第三十条 | 第三人代为清偿规则 | 明确对履行债务具有合法利益的第三人范围 |
| 第三十一条 | 同时履行抗辩权与先履行抗辩权 | 同时履行判决应在判项中明确申请强制执行的条件 |
| 第三十二条 | 情势变更制度的适用 | 价格异常波动不属于商业风险的，可认定情势变更；市场属性活跃的大宗商品、股票期货除外 |

### 五、合同的保全（第三十三条-第四十六条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第三十三条 | 怠于行使权利的认定 | 不以诉讼或仲裁方式向相对人主张到期债权，致使债权人到期债权未能实现 |
| 第三十四条 | 专属于债务人自身的权利 | 抚养费、赡养费、扶养费请求权；人身损害赔偿请求权；劳动报酬请求权等 |
| 第三十五条 | 代位权诉讼的管辖 | 被告住所地法院管辖；协议管辖不适用 |
| 第三十六条 | 代位权诉讼与仲裁协议 | 债权人可提起代位权诉讼；首次开庭前相对人申请仲裁的诉讼中止 |
| 第三十七条 | 代位权诉讼的当事人及合并审理 | 追加债务人为第三人；多个债权人可合并审理 |
| 第三十八条 | 起诉债务人后又提起代位权诉讼 | 同一法院管辖的可合并审理；不同管辖应告知另行起诉 |
| 第三十九条 | 代位权诉讼中债务人起诉相对人 | 债权超出代位请求数额部分可合并审理 |
| 第四十条 | 代位权不成立的处理 | 驳回诉讼请求；不影响债权人根据新事实再次起诉 |
| 第四十一条 | 代位权诉讼中债务人处分行为的限制 | 债务人无正当理由减免相对人债务或延长履行期限，相对人以此抗辩不予支持 |
| 第四十二条 | 明显不合理低价或高价的认定 | 低于市场价的70%为明显不合理低价；高于指导价的130%为明显不合理高价 |
| 第四十三条 | 其他不合理交易行为的认定 | 互易财产、以物抵债、出租或承租财产、知识产权许可使用等 |
| 第四十四条 | 撤销权诉讼的当事人、管辖及合并审理 | 债务人和相对人为共同被告；可合并审理 |
| 第四十五条 | 撤销权的效力范围及"必要费用"的认定 | 律师代理费、差旅费可认定为必要费用 |
| 第四十六条 | 撤销权行使的法律效果 | 债权人可请求相对人向债务人承担返还财产、折价补偿等法律后果 |

### 六、合同的变更和转让（第四十七条-第五十一条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第四十七条 | 债权债务转让纠纷的诉讼第三人 | 债权转让后债务人可追加让与人为第三人；债务转移可追加原债务人 |
| 第四十八条 | 债权转让通知 | 通知前已向让与人履行不支持受让人请求；通知后仍向让与人履行支持受让人请求 |
| 第四十九条 | 表见让与、债务人确认债权存在 | 债务人确认债权真实存在后不得以债权不存在抗辩受让人 |
| 第五十条 | 债权的多重转让 | 最先通知的受让人优先；债务人向最先通知的受让人履行后不再履行 |
| 第五十一条 | 债务加入人的追偿权 | 约定追偿权从约定；无约定可主张不当得利返还；知道加入债务损害债务人利益的除外 |

### 七、合同的权利义务终止（第五十二条-第五十八条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第五十二条 | 协商解除合同的法律适用 | 协商一致解除未处理违约责任等，按《民法典》第566条规定处理 |
| 第五十三条 | 通知解除合同的审查 | 审查是否享有解除权；享有解除权的通知到达时解除 |
| 第五十四条 | 撤诉后再次起诉解除时合同解除时间的认定 | 起诉状副本送达对方时解除 |
| 第五十五条 | 抵销权行使的效力 | 通知到达时双方互负债务在同等数额内消灭 |
| 第五十六条 | 抵销参照适用抵充规则 | 参照《民法典》第560条规定抵销顺序 |
| 第五十七条 | 侵权行为人不得主张抵销的情形 | 侵害自然人人身权益或故意重大过失侵害财产权益的损害赔偿债务 |
| 第五十八条 | 已过诉讼时效债权的抵销 | 诉讼时效抗辩成立；时效届满的债权可主动抵销 |

### 八、违约责任（第五十九条-第六十八条）

| 条文 | 主题 | 核心内容 |
|------|------|----------|
| 第五十九条 | 合同终止的时间 | 以起诉状副本送达对方的时间为准；公平原则和诚信原则下可调整 |
| 第六十条 | 可得利益损失的计算 | 生产利润、经营利润或转售利润；替代交易参照市场价格 |
| 第六十一条 | 持续性定期合同中可得利益的赔偿 | 按剩余履行期限对应的价款扣除履约成本确定 |
| 第六十二条 | 无法确定可得利益时的赔偿 | 综合考虑违约方获得的利益、过错程度等因素确定 |
| 第六十三条 | 违约损失赔偿额的确定 | 可预见性规则；扣除扩大损失、与有过失、获得额外利益等 |
| 第六十四条 | 请求调整违约金的方式与举证责任 | 反诉或抗辩方式；违约方举证证明过分高于；非违约方举证证明合理 |
| 第六十五条 | 违约金的司法酌减 | 超过损失30%一般认定过分高于；恶意违约一般不支持减少 |
| 第六十六条 | 违约金调整的释明与改判 | 未释明可在二审直接释明并判决适当减少 |
| 第六十七条 | 定金规则 | 未约定定金性质不适用定金罚则；约定不明主张违约定金支持 |
| 第六十八条 | 定金罚则的法律适用 | 双方均有违约不适用；轻微违约方主张对方也有违约的抗辩不支持 |

## 适用重点

### 合同违法无效的认定（第16条）

违反强制性规定不导致合同无效的五种情形：
1. 合同实际履行对社会公共秩序影响显著轻微，认定无效有失公平公正
2. 强制性规定旨在维护国家利益或其他民事主体合法利益而非合同当事人权益
3. 强制性规定旨在要求一方加强风险控制、内部管理，对方无能力或无义务审查
4. 当事人在合同订立后已具备补正条件却违背诚信原则不予补正
5. 法律、司法解释规定的其他情形

### 未经批准合同的效力（第12条）

- 合同未生效不意味着不产生其他效力
- 报批义务条款独立生效
- 判决继续履行报批义务后仍拒绝履行，可解除合同并承担违约责任
- 报批义务人全面履行但未获批准，不承担赔偿责任；因过错导致未获批准承担缔约过失责任

### 违约方请求终止合同（第59条）

- 《民法典》第580条第2款允许违约方在非金钱债务中请求终止合同
- 合同僵局下，守约方故意不主动解除时，违约方可请求终止
- 终止时间以起诉状副本送达对方为准，公平原则下可调整

### 预约合同的认定与救济（第6-8条）

- 预约合同成立要件：当事人约定在将来一定期限内订立合同，能确定主体、标的
- 违反预约认定：明确拒绝订立或在磋商中违背诚信原则
- 违约责任范围：根据交易成熟度在信赖利益与履行利益之间酌定
- 不支持强制履行预约合同

### 无权处分与合同效力（第19条）

- 合同不因让与人无处分权而无效
- 未取得处分权或未获追认导致不能履行，受让人可解除合同并请求违约责任
- 买受人能否取得所有权适用善意取得制度

### 以物抵债协议（第27-28条）

- 债务履行期限届满后达成的以物抵债：诺成合同，新债清偿规则
- 债务履行期限届满前达成的以物抵债：让与担保，约定归属债权人无效但可请求拍卖、变卖、折价

### 格式条款（第九-十条）

- "为了重复使用"是目的而非实际使用
- 提示义务针对"异常条款"
- 电子合同勾选、弹窗需举证符合提示要求
- 当事人约定排除格式条款规定不发生效力
